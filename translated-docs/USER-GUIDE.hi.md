# उपयोगकर्ता निर्देशिका

<br/>

<a id="introduction"></a>
## परिचय

ट्रांसरीव्रट आपको किसी टेक्स्ट के साथ तीन मुख्य तरीकों से काम करने में सहायता करता है:

- **अनुवाद** - एक भाषा से दूसरी भाषा में टेक्स्ट को परिवर्तित करना।
- **पुन:लेखन** - स्पष्टता, संक्षिप्तता या औपचारिकता जैसे भिन्न शैली में टेक्स्ट को पुनः शब्दित करना।
- **रूपांतरण** - संकेतों नामक कस्टम एआई निर्देशों का उपयोग कर टेक्स्ट को प्रक्रिया (प्रोसेस) करना।

<br/>

इस निर्देशिका में ऐप को स्थापित करने और चलाने के बाद इसके उपयोग की व्याख्या की गई है। स्थापना के चरणों के लिए मुख्य **[README](README.hi.md)** देखें।

<br/>

> ℹ️ **ध्यान दें**<br/>
> Transrewrt विंडोज़ और लिनक्स के लिए एक डेस्कटॉप ऐप के रूप में उपलब्ध है, और स्व-होस्टेड वेब ऐप के रूप में भी। इस निर्देशिका में ऐप के दैनिक उपयोग पर केंद्रित है। जहां कुछ विशेष रूप से एक संस्करण पर लागू होता है, वहां स्पष्ट रूप से चिह्नित किया गया है।

<a id="before-you-start"></a>

## शुरू करने से पहले

Transrewrt का उपयोग करने के लिए, आपको कम से कम एक AI प्रदाता तक पहुँच की आवश्यकता होती है। समर्थित प्रदाता हैं: [OpenRouter](https://openrouter.ai) (जो कई मॉडलों को एकत्रित करता है), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, और स्थानीय मॉडलों के लिए [Ollama](https://ollama.com)।

शुरू करने के लिए किसी पेड मॉडल का चयन करने की आवश्यकता नहीं है। एक बार जब आप अपनी OpenRouter API कुंजी जोड़ते हैं, तो ऐप स्वचालित रूप से एक अंतर्निहित **मुफ्त** OpenRouter विकल्प सक्षम कर देता है। इससे आप तुरंत पाठ का अनुवाद, पुनर्लेखन और रूपांतरण शुरू कर सकते हैं।

सरल भाषा में:

- एक **मॉडल** वह AI इंजन है जो काम करता है। मॉडल्स को **प्रदाता उपसर्ग** के साथ सूचीबद्ध किया जाता है (उदाहरण के लिए `openrouter/…`, `openai/…`, `ollama/…`)।
- एक **API कुंजी** (या, Ollama के लिए, एक **बेस URL**) ऐप की उस प्रदाता तक पहुँचने की विधि है।

यदि आप **डेस्कटॉप ऐप** का उपयोग कर रहे हैं, तो प्रत्येक प्रदाता के लिए [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) में कुंजियाँ जोड़ें। केवल OpenRouter के उपयोग के लिए नीचे दिए गए [एक API कुंजी कैसे प्राप्त करें](#how-to-get-an-api-key-desktop-app) देखें। यदि आप कुंजी का उपयोग नहीं करना चाहते हैं, तो आप Ollama ([ollama.com](https://ollama.com) से) स्थापित कर सकते हैं और स्थानीय मॉडलों का उपयोग कर सकते हैं।

यदि आप **वेब संस्करण** का उपयोग कर रहे हैं, तो सर्वर धारक पर्यावरण चर के माध्यम से प्रदाताओं को कॉन्फ़िगर करता है, इसलिए आपको आम तौर पर स्वयं API कुंजियाँ दर्ज करने की आवश्यकता नहीं होगी।

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### मुफ्त OpenRouter API कुंजी कैसे प्राप्त करें (डेस्कटॉप ऐप)

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं, तो इन चरणों का पालन करें:

1. अपने वेब ब्राउज़र में [OpenRouter](https://openrouter.ai) पर जाएँ।
2. एक खाता बनाएँ या साइन इन करें।
3. [Keys](https://openrouter.ai/keys) पृष्ठ खोलें।
4. एक नई API कुंजी बनाने के लिए बटन पर क्लिक करें।
5. ताकि आप इसे बाद में पहचान सकें, कुंजी का नाम दें।
6. नई API कुंजी को कॉपी करें।
7. Transrewrt पर वापस जाएँ और **सेटिंग्स** > **API कॉन्फ़िग** खोलें।
8. **OpenRouter API कुंजी** में कुंजी पेस्ट करें (**सेटिंग्स** > **API कॉन्फ़िग** के अंतर्गत)।
9. यह सुनिश्चित करने के लिए कि काम कर रहा है, **OpenRouter कुंजी परीक्षण करें** पर क्लिक करें।

<br/>

> ℹ️ **नोट**<br/>
> आप क्रेडिट कार्ड जोड़े बिना OpenRouter के मुफ्त मार्ग या अन्य उपलब्ध मुफ्त मॉडलों में से किसी एक के साथ शुरू कर सकते हैं। कई मामलों में, इससे Transrewrt का उपयोग शुरू करने के लिए किसी पेड मॉडल के चयन की आवश्यकता नहीं होती। विकल्प के रूप में, आप किसी भी API कुंजी के बिना स्थानीय रूप से मॉडल चलाने के लिए Ollama का उपयोग कर सकते हैं।

<a id="getting-started"></a>
## प्रारंभ करना

यदि यह आपका Transrewrt का पहला उपयोग है, तो इस क्रम का पालन करें:

1. ऐप खोलें।
2. आवश्यकता पड़ने पर ग्लोब आइकन से अपनी **इंटरफ़ेस भाषा** चुनें।
3. यदि आप **डेस्कटॉप ऐप** पर हैं, तो [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें, कम से कम एक प्रदाता (उदाहरण के लिए OpenRouter) के लिए एक API कुंजी जोड़ें, और यह सुनिश्चित करने के लिए **परीक्षण** पर क्लिक करें कि यह काम करता है।
4. [**सेटिंग्स** > **मॉडल**](#models) खोलें और एक या एक से अधिक मॉडल **चयनित मॉडल** में जोड़ें।
5. [**सेटिंग्स** > **भाषाएँ**](#languages) खोलें और अपनी सबसे ज्यादा उपयोग की जाने वाली भाषाओं को पहले दिखाने के लिए अपनी **शीर्ष भाषाएँ** चुनें।
6. **अनुवाद** पर जाएँ और सब कुछ काम कर रहा है यह सुनिश्चित करने के लिए एक साधारण अनुवाद चलाएँ।
7. एक बार यह काम करने लगे, तो **पुनर्लेखन** और फिर **रूपांतरण** आजमाएँ।

इस क्रम का महत्व है। यह सबसे आम पहले उपयोग की समस्या को रोकता है: काम तब शुरू करने की कोशिश करना जब ऐप के पास काम करने वाला API कनेक्शन या चयनित मॉडल न हो।

### टूलबार

टूलबार की दिखावट थोड़ी-बहुत परिवर्तित होती है, इस पर निर्भर करते हुए कि आप ऐप में कहाँ हैं।

- बाईं ओर, यह वर्तमान पृष्ठ का नाम दिखाता है।
- दाईं ओर, यह **मॉडल चयनकर्ता** और **इंटरफेस भाषा** नियंत्रण दिखाता है।

**मॉडल चयनकर्ता** आपको वर्तमान कार्य के लिए कौन सा एआई इंजन उपयोग करना है चुनने की अनुमति देता है।

  ![मॉडल चयनकर्ता](../images/screenshots/hi/model-selector.png)

> ℹ️ **नोट**<br/>
> कुछ मुफ्त मॉडल हमेशा उपलब्ध नहीं हो सकते — कभी-कभी वे ऑफलाइन होते हैं या उपयोग की सीमा होती है। ऐसा होने पर, ऐप उपलब्ध सूची से उस मॉडल को स्वचालित रूप से हटा देगा।<br/>
> कौन से मॉडल दिखाई दें, इसे नियंत्रित करने के लिए, [**सेटिंग्स** > **मॉडल**](#models) पर जाएं और अपनी मॉडल सूची संपादित करें।
> आप टूलबार में मॉडल नाम के बाईं ओर प्रदाता आइकन पर क्लिक करके सीधे मॉडल सेटिंग्स भी खोल सकते हैं।

<br/>

**भूमंडल चिन्ह + भाषा कोड** ऐप के इंटरफ़ेस की भाषा को बदलता है, जैसे मेनू और बटन। यह **अनुवाद** में उपयोग होने वाली अनुवाद भाषाओं को **नहीं** बदलता है।

  ![इंटरफेस भाषा चयनकर्ता](../images/screenshots/hi/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### इनपुट और आउटपुट पैनल

अधिकांश कार्यक्षेत्र बाईं ओर का **इनपुट** पैनल और दाईं ओर का **आउटपुट** पैनल उपयोग करते हैं।

**इनपुट** पैनल दिखाता है:

- अक्षर संख्या
- शब्द संख्या
- पैराग्राफ संख्या

**आउटपुट** पैनल दिखा सकता है:

- कार्य पूरा होने में लगा समय
- कार्य की लागत (यदि उपलब्ध हो)
- आपकी कुल लागत
- **TPS** (प्रति सेकंड टोकन)
- अक्षर, शब्द और पैराग्राफ की गणना
- उपयोग किया गया मॉडल

यदि आप तकनीकी शब्दों के बारे में प्रश्न कर रहे हैं:

- **टोकन** का अर्थ है पाठ का छोटा टुकड़ा। आप इसे किसी शब्द के एक हिस्से या संक्षिप्त शब्द के रूप में समझ सकते हैं।
- **TPS** का अर्थ है कितने पाठ के टुकड़ों को मॉडल प्रति सेकंड प्रसंस्कृत करता है।

<a id="translate"></a>
## अनुवाद

**अनुवाद** का उपयोग तब करें जब आप एक भाषा के पाठ को दूसरी भाषा में बदलना चाहते हैं।

![अनुवाद कार्यक्षेत्र](../images/screenshots/hi/translate.png)

<br/>

<a id="translate-text"></a>
### पाठ का अनुवाद करें

1. **अनुवाद** खोलें।
2. **से** में भाषा चयन करें।
3. **तक** में भाषा चुनें।
4. टूलबार में मॉडल चुनें।
5. **इनपुट** में पाठ टाइप करें या पेस्ट करें।
6. **अनुवाद करें** पर क्लिक करें।
7. **आउटपुट** में परिणाम पढ़ें।
8. परिणाम कॉपी करने के लिए कॉपी बटन का उपयोग करें।

<br/>

<a id="language-selection"></a>
### भाषा चयन

- **से** एक विशिष्ट भाषा या **भाषा का पता लगाएं** हो सकती है।
- **तक** वह भाषा है जिसमें आप परिणाम चाहते हैं।

आपकी चयनित **शीर्ष भाषाएं** सूची के ऊपर दिखाई देती हैं। आप इन्हें [**सेटिंग्स** > **भाषाएं**](#languages) में सेट कर सकते हैं।

<br/>

<a id="helpful-translation-settings"></a>
### उपयोगी अनुवाद सेटिंग्स

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में, आप बदल सकते हैं कि अनुवाद कैसे व्यवहार करे:

- **पेस्ट करने पर स्वचालित अनुवाद** तुरंत अनुवाद चलाता है जैसे ही आप पाठ पेस्ट करते हैं।
- **परिणाम को क्लिपबोर्ड पर स्वचालित रूप से कॉपी करें** सफलतापूर्वक चलने के बाद परिणाम को स्वचालित रूप से कॉपी करता है।
- **वास्तविक समय में अनुवाद (टाइप करते समय)** टाइप करते समय अनुवाद चलाता है।
- **टाइमआउट (मिलीसेकंड)** नियंत्रित करता है कि रियल-टाइम अनुवाद शुरू करने से पहले ऐप कितनी देर तक प्रतीक्षा करता है।

<br/>

<a id="keyboard-shortcuts"></ deputy>
### कीबोर्ड शॉर्टकट्स

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में, कीबोर्ड से `Enter` दबाने पर क्या होगा इसे **ENTER का व्यवहार** नियंत्रित करता है:

- **Enter** कार्य चला सकता है और **Shift+Enter** नई पंक्ति जोड़ सकता है।
- या ऐप इसके विपरीत कर सकता है।

वर्तमान मोड **अनुवाद** बटन पर भी दिखाया जाता है।

## पुनर्लेखन

- पाठ को अधिक स्पष्ट बनाने के लिए

- पाठ को छोटा या लंबा करने के लिए
- पाठ को अधिक तकनीकी लगने के लिए

> सुधारों को दिखाने या छिपाने के लिए इस बटन पर क्लिक करके आपके पाठ में किए गए विशिष्ट परिवर्तनों को टॉगल करें।

<a id="transform"></a>
## परिवर्तन

जब आप चाहते हैं कि एआई अनुदेशों के एक कस्टम सेट का पालन करे, तो **परिवर्तन** का उपयोग करें।

![परिवर्तन कार्यक्षेत्र](../images/screenshots/hi/transform.png)

यह ऐप का सबसे लचीला हिस्सा है। आप इसका उपयोग निम्नलिखित कार्यों के लिए कर सकते हैं:

- नोट्स का सारांश तैयार करना
- अधूरे पाठ को एक सुव्यवस्थित ईमेल में बदलना
- प्रमुख बिंदुओं को निकालना
- पाठ को एक विशिष्ट प्रारूप में बदलना

<br/>

<a id="run-an-existing-prompt"></a>
### मौजूदा प्रॉम्प्ट चलाएँ

1. **परिवर्तन** खोलें।
2. प्रॉम्प्ट सूची से एक प्रॉम्प्ट चुनें।
3. यदि एक **लक्ष्य** भाषा बॉक्स दिखाई दे, तो यदि चाहें तो एक भाषा चुनें।
4. **इनपुट** में पाठ टाइप या पेस्ट करें।
5. **परिवर्तन** पर क्लिक करें।
6. **आउटपुट** में परिणाम पढ़ें।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### यदि आपके पास अभी तक कोई प्रॉम्प्ट नहीं है

यदि आपकी प्रॉम्प्ट सूची खाली है, तो **नमूना प्रॉम्प्ट लोड करें** पर क्लिक करें। इससे आप त्वरित शुरुआत करने के लिए बिल्ट-इन उदाहरण जोड़ देता है।

<br/>

> ℹ️ **नोट**<br/>
> नमूना प्रॉम्प्ट अंग्रेजी में उपलब्ध कराए जाते हैं। उन्हें लोड करने के बाद, आप एक प्रॉम्प्ट को संपादित कर सकते हैं और इसे अपनी भाषा में अनुवाद करने के लिए **प्रॉम्प्ट अनुवाद करें** का उपयोग कर सकते हैं।

<br/>

<a id="create-a-prompt-quickly"></a>
### जल्दी से एक प्रॉम्प्ट बनाएँ

एक प्रॉम्प्ट बनाने का सबसे तेज़ तरीका है:

1. **नया प्रॉम्प्ट** पर क्लिक करें।
2. **प्रॉम्प्ट उत्पन्न करें** पर क्लिक करें।
3. वर्णन करें कि आप चाहते हैं कि प्रॉम्प्ट क्या करे।
4. एक मॉडल चुनें।
5. ऐप को आपके लिए एक ड्राफ्ट तैयार करने दें।
6. ड्राफ्ट की समीक्षा करें और **सहेजें** पर क्लिक करें।

![प्रॉम्प्ट उत्पन्न करें](../images/screenshots/hi/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### एक प्रॉम्प्ट को संपादित करें

जब आप कोई प्रॉम्प्ट बनाते या संपादित करते हैं, तो संपादक बाईं ओर दिखाई देता है और एक परीक्षण क्षेत्र दाईं ओर दिखाई देता है।

![परिवर्तन प्रॉम्प्ट संपादक](../images/screenshots/hi/transform-prompt-edit.png)

मुख्य फ़ील्ड हैं:

- **प्रॉम्प्ट नाम**: वह नाम जो प्रॉम्प्ट सूची में दिखाई देता है।
- **प्रॉम्प्ट निर्देश (वैकल्पिक)**: संक्षिप्त संकेत जो प्रॉम्प्ट चलाने पर उपयोगकर्ता को दिखाई देता है।
- **मॉडल भूमिका**: एआई को दी गई समग्र भूमिका, जैसे 'आप एक सहायक सहायक हैं।'
- **मॉडल निर्देश (प्रति पंक्ति एक)**: विशिष्ट नियम जिनका एआई को पालन करना है।
- **आउटपुट विवरण**: परिणाम का वर्णन करने वाला संक्षिप्त शब्द, जैसे 'सारांश' या 'पुनःलेखन'।
- **तापमान (0.0 → 1.0)**: मॉडल कैसे व्यवहार करेगा; नीचे देखें।
- **लक्ष्य भाषा के लिए पूछें**: जब प्रॉम्प्ट चलाया जाए, तो एक लक्ष्य भाषा चयनकर्ता जोड़ता है।

यदि तकनीकी शब्द **तापमान** आपके लिए नया है, तो इसे इस तरह समझें:

- **कम** तापमान स्थिर, अधिक भविष्यवाणी योग्य परिणाम देता है।
- **उच्च** तापमान अधिक विविधता और रचनात्मकता प्रदान करता है।

आप इसका भी उपयोग कर सकते हैं:

- **`प्रॉम्प्ट उत्पन्न करें`**: एक सरल वर्णन से एक नया ड्राफ्ट बनाने के लिए
- **`प्रॉम्प्ट में सुधार करें`**: मौजूदा प्रॉम्प्ट में सुधार करने के लिए
- **`प्रॉम्प्ट अनुवाद करें`**: प्रॉम्प्ट फ़ील्ड का अनुवाद करने के लिए

<br/>

> ⚠️ **चेतावनी**<br/>
> **`वापस चलाने के लिए`** पर क्लिक करने से पहले **`सहेजें`** पर क्लिक करें। यदि आप बिना सहेजे वापस जाते हैं, तो आपके परिवर्तन खो जाएंगे।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### उपयोग से पहले एक प्रॉम्प्ट का परीक्षण करें

दाईं ओर स्थित परीक्षण पैनल आपको अपने दैनिक कार्य में इसका उपयोग करने से पहले नमूना पाठ के साथ अपने प्रॉम्प्ट का परीक्षण करने की अनुमति देता है।

यह तब उपयोगी है जब:

- आप एक नया प्रॉम्प्ट बना रहे हों
- आप दो प्रॉम्प्ट संस्करणों की तुलना कर रहे हों
- आप टोन, लंबाई या आउटपुट प्रारूप की जाँच करना चाहते हों

<br/>

<a id="manage-saved-prompts"></a>
### सहेजे गए प्रॉम्प्ट प्रबंधित करें

एक ही स्थान पर सहेजे गए प्रॉम्प्ट को प्रबंधित करने के लिए, [**सेटिंग्स** > **परिवर्तन प्रॉम्प्ट**](#transform-prompts) खोलें।

वहाँ आप कर सकते हैं:

- अपने प्रॉम्प्ट की सूची बनाएँ और हटाएँ
- प्रॉम्प्ट को **JSON**, **CSV**, या **XLSX** के रूप में निर्यात करें
- एक फ़ाइल से प्रॉम्प्ट आयात करें

![डैशबोर्ड फ़िल्टर](../images/screenshots/hi/dashboard-filter.png)

- **सारांश** उपयोग और लागत का एक सामान्य अवलोकन प्रदान करता है।
- **उपयोग द्वारा** गतिविधि को अनुवाद भाषा, पुनर्लेखन मोड और ट्रांसफ़ॉर्म प्रॉम्प्ट के आधार पर विभाजित करता है।

- **प्रतिदिन द्वारा** दैनिक कुल योग दिखाता है।
- **सभी कॉल्स** पूर्ण कॉल इतिहास दिखाता है और इसे निर्यात करने की अनुमति देता है।

<a id="general-settings"></a>

### सामान्य सेटिंग्स

**सामान्य सेटिंग्स** का उपयोग टाइपिंग व्यवहार को नियंत्रित करने, **इतिहास** के लिए निष्पादन विवरण संग्रहीत करने, और दिखावट को नियंत्रित करने के लिए करें।

**व्यवहार**

- **ENTER के लिए व्यवहार** तय करता है कि क्या `Enter` टास्क चलाएगा या नई पंक्ति डालेगा।
- **पेस्ट करने पर स्वत: अनुवाद** पाठ पेस्ट करते ही अनुवाद शुरू कर देता है।
- **परिणाम को स्वचालित रूप से क्लिपबोर्ड पर कॉपी करें** सफल परिणामों को स्वचालित रूप से कॉपी करता है।
- **वास्तविक समय में अनुवाद (टाइपिंग के दौरान)** आप टाइप करते समय अनुवाद करता है।
- **टाइमआउट (मिलीसेकंड)** वास्तविक समय अनुवाद के लिए प्रतीक्षा समय निर्धारित करता है।

**इतिहास**

- **निष्पादन इतिहास रखें** यह नियंत्रित करता है कि क्या प्रत्येक अनुवाद, पुनर्लेखन और परिवर्तन साइडबार के लिए [**इतिहास**](#history) दृश्य में **इनपुट और आउटपुट पाठ** संग्रहीत करे। इसे बंद करने पर पुष्टि मांगी जाएगी; यदि आप पुष्टि करते हैं, तो संग्रहीत इतिहास पाठ डेटाबेस से हटा दिया जाएगा।
- **इतिहास डेटा हटाएं** आपको उम्र के आधार पर (उदाहरण के लिए कुछ महीनों से पुराना, या **सभी डेटा (साफ़ करें)**) स्टोर किया गया पाठ हटाने की अनुमति देता है **डेटा हटाएं** का उपयोग करके। यह केवल **इतिहास** दृश्य के लिए सहेजे गए निष्पादन पाठ को प्रभावित करता है; यह **लागत या उपयोग कुल राशि को नहीं हटाता**। **लागत** डेटा को हटाने या समायोजित करने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) का उपयोग करें।

**दिखावट**

- **लागत भिन्‍न अंक** लागत दशमलव को कैसे प्रदर्शित किया जाए, इसे बदलता है।
- **केवल वेब:** ऐप के चारों ओर **मार्जिन दिखाएं** इंटरफेस के चारों ओर अतिरिक्त स्थान जोड़ता है।
- **फॉण्ट परिवार** पाठ पैनलों में लेखन फ़ॉन्ट बदलता है।
- **आकार** फॉन्ट का आकार बदलता है।

<br/>

<a id="models"></a>
### मॉडल

टूलबार में कौन से मॉडल दिखाई दें, इसे चुनने के लिए **सेटिंग्स** > **मॉडल** का उपयोग करें।

![सेटिंग्स मॉडल टैब](../images/screenshots/hi/settings-models.png)

पृष्ठ में दो सूचियां हैं:

- बाईं ओर **उपलब्ध मॉडल**
- दाईं ओर **चयनित मॉडल**

उपयोगी नियंत्रण में शामिल हैं:

- **मॉडल खोजें...** नाम से मॉडल ढूंढने के लिए
- **प्रदाता** चिप्स एक इंजन पर सूची को सीमित करने के लिए (OpenRouter, OpenAI, Ollama, …)
- **केवल मुफ्त** केवल मुफ्त मॉडल दिखाने के लिए
- **ताज़ा करें** सूची को पुनः लोड करने के लिए
- **सभी विस्तारित करें** और **सभी संक्षिप्त करें** जब आप प्रदाता के आधार पर क्रमादेशित कर रहे हों

मॉडल आईडी में प्रदाता उपसर्ग शामिल हैं (उदाहरण के लिए `openrouter/…` बनाम `openai/…`)। बैज जैसे **OpenAI (OpenRouter)** बनाम **OpenAI (डायरेक्ट)** दिखाते हैं कि ट्रैफ़िक कैसे मार्गीकृत है।

क्रियाएं:

 - मॉडल जोड़ने के लिए, **जोड़ें** पर या प्रविष्टि में कहीं भी क्लिक करें।

 - मॉडल हटाने के लिए, **चयनित मॉडल** में इसके बगल में **X** पर या उपलब्ध मॉडल में प्रविष्टि पर **चयनित** पर क्लिक करें।

 - सूची साफ़ करने के लिए, **सभी का चयन हटाएं** पर क्लिक करें। आवश्यक मुफ्त मॉडल सूची में बना रहेगा।

<br/>

> ℹ️ **नोट**<br/>
> यदि आप OpenRouter में तुरंत क्रेडिट जोड़ना नहीं चाहते हैं, तो **केवल मुफ्त** सक्षम करने से शुरुआत करें और मुफ्त मॉडल (क्रेडिट कार्ड की आवश्यकता नहीं) चुनें। आप किसी भी API कुंजी के बिना मॉडल को स्थानीय स्तर पर चलाने के लिए Ollama का उपयोग भी कर सकते हैं।

<a id="languages"></a>
### भाषाएं

ऐप में उपयोग की जाने वाली भाषा सूचियों को व्यवस्थित करने के लिए **सेटिंग्स** > **भाषाएं** का उपयोग करें।

- **शीर्ष भाषाएं** **अनुवाद** और **परिवर्तन** में भाषा सूचियों के ऊपरी भाग के पास स्थिर होती हैं।
- **कस्टम भाषा** आपको अंतर्निहित सूची में नहीं होने वाली भाषा जोड़ने की अनुमति देती है।

यदि आप एक कस्टम भाषा जोड़ते हैं, तो यह अंतर्निहित विकल्पों के साथ भाषा चुनने वालों में दिखाई देगी।

<a id="cost-tracking"></a>
### लागत ट्रैकिंग

लागत सूचना का प्रबंधन करने के लिए **सेटिंग्स** > **लागत ट्रैकिंग** का उपयोग करें।

- **कुल लागत** चल रहा कुल राशि दिखाता है।
- **मान कॉपी करें** कुल राशि को क्लिपबोर्ड पर कॉपी करता है।
- **लागत रीसेट करें** संग्रहीत कुल राशि को शून्य पर सेट करता है।
- **API कुंजी उपयोग के साथ सिंक करें** कुल राशि को आपके OpenRouter खाते द्वारा रिपोर्ट किए गए उपयोग के अनुरूप सेट करता है (केवल OpenRouter)।
- **API कुंजी उपयोग** OpenRouter उपयोग विवरण दिखाता है, यदि उपलब्ध हो।
- **लागत डेटा हटाएं** सभी डेटा हटा देता है, या केवल चयनित तिथि से पुराने प्रविष्टियां।

**लागत ट्रैकिंग:** जब आप OpenRouter मॉडल का उपयोग करते हैं, तो ऐप आपके वास्तविक उपयोग और खर्च को OpenRouter के डेटा के आधार पर दिखाता है। सभी अन्य प्रदाताओं के लिए, ऐप OpenRouter द्वारा प्रकाशित मूल्यों का उपयोग करके लागत का अनुमान लगाता है, यदि मूल्य उपलब्ध नहीं है, तो अनुमान शून्य हो सकता है।

<br/>

> ℹ️ **नोट**<br/>
> **सभी लागत आंकड़े केवल आपके संदर्भ के लिए अनुमान हैं, आधिकारिक बिलिंग विवरण नहीं हैं।**

<br/>

> ⚠️ **चेतावनी**<br/>
> डेटा हटाने की क्रिया को पूर्ववत नहीं किया जा सकता। हटाने से पहले, अपने डेटा का बैकअप सुनिश्चित करें या इसे [**डैशबोर्ड** > **सभी कॉल**](#dashboard-tabs) के माध्यम से निर्यात करें, अन्यथा यह स्थायी रूप से खो जाएगा। <br/> 
> प्रत्येक API कॉल प्रविष्टि से संबंधित सभी इतिहास भी हटा दिया जाएगा।

<a id="transform-prompts"></a>

### प्रॉम्प्ट्स को ट्रांसफॉर्म करें

**सेटिंग्स** > **ट्रांसफॉर्म प्रॉम्प्ट्स** का उपयोग बल्क में प्रॉम्प्ट्स को प्रबंधित करने के लिए करें।

आप कर सकते हैं:

- अपने सहेजे गए प्रॉम्प्ट्स की समीक्षा करें
- प्रॉम्प्ट्स हटाएं
- फ़ाइल से प्रॉम्प्ट्स आयात करें
- बैकअप या साझाकरण के लिए प्रॉम्प्ट्स निर्यात करें

<a id="api-config"></a>
### एपीआई कॉन्फ़िग

समर्थित प्रदाता हैं: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, और **Ollama** (बेस URL के माध्यम से स्थानीय मॉडल)। आपको केवल उन प्रदाताओं को कॉन्फ़िगर करने की आवश्यकता है जिनका आप उपयोग करते हैं।

**वेब एप्लिकेशन: केवल प्रशासक**

एपीआई कुंजियों को सिस्टम या डॉकर पर्यावरण चर के माध्यम से कॉन्फ़िगर किया जाता है — उन्हें वेब यूआई में दर्ज नहीं किया जाता है। यह पृष्ठ दिखाता है कि किन प्रदाताओं के लिए कुंजी कॉन्फ़िगर की गई है और आप प्रत्येक का परीक्षण करने के लिए **`टेस्ट`** बटन पर क्लिक करके प्रदाता का परीक्षण कर सकते हैं।

<br/>

> ℹ️ **नोट**<br/>
> किसी एपीआई कुंजी को बदलने के लिए, अपने सिस्टम या डॉकर कॉन्फ़िगरेशन में पर्यावरण चर को अपडेट करें और सर्वर या कंटेनर को पुनरारंभ करें।

<br/>

**डेस्कटॉप अनुप्रयोग**

आपके द्वारा उपयोग किए जाने वाले प्रत्येक प्रदाता के लिए एपीआई कुंजियाँ संग्रहीत करने के लिए **एपीआई कॉन्फ़िग** का उपयोग करें। Ollama के लिए, एपीआई कुंजी के बजाय **बेस URL** दर्ज करें।

<br/>

> 💡 **सुझाव** <br/>
> यदि आप एपीआई कुंजी का उपयोग नहीं करना चाहते या उपयोग के लिए भुगतान नहीं करना चाहते हैं, तो आप [Ollama डाउनलोड](https://ollama.com) कर सकते हैं और अपने मशीन पर स्थानीय रूप से मॉडल निःशुल्क चला सकते हैं। वैकल्पिक रूप से, आप उनके नि: शुल्क मॉडल का उपयोग करने के लिए एक मुफ्त OpenRouter खाता बना सकते हैं (क्रेडिट कार्ड की आवश्यकता नहीं)।

- केवल उन प्रदाताओं को जोड़ें जिनकी आपको आवश्यकता है। **सेटिंग्स** > **मॉडल** में, प्रत्येक मॉडल आईडी प्रदाता के साथ शुरू होती है (उदाहरण के लिए `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

कोई एपीआई कुंजी जोड़ने के लिए, मान को टेक्स्ट फ़ील्ड में टाइप करें और **`सहेजें`** पर क्लिक करें। मौजूदा कुंजी को बदलने के लिए, **`संपादित करें`** पर क्लिक करें। कुंजी काम कर रही है या नहीं, यह जांचने के लिए प्रदाता के बगल में **`परीक्षण`** पर क्लिक करें।

<br/>

> ℹ️ **नोट**<br/>
> आप एपीआई कुंजी का वर्तमान मान नहीं देख सकते हैं। आप केवल **`संपादित करें`** बटन का उपयोग करके इसे बदल सकते हैं।
> एपीआई कुंजियों को कॉन्फ़िगरेशन फ़ाइल में एन्क्रिप्टेड रूप में संग्रहीत किया जाता है।

<br/>

OpenRouter कुंजी प्राप्त करने के विस्तृत चरणों के लिए, ऊपर [किसी एपीआई कुंजी को कैसे प्राप्त करें](#how-to-get-an-api-key-desktop-app) देखें।

<a id="common-issues"></a>
## सामान्य समस्याएँ

यदि कुछ अपेक्षित रूप से काम नहीं कर रहा है, तो पहले निम्न बिंदुओं की जांच करें।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ऐप टेक्स्ट का अनुवाद, पुनर्लेखन या परिवर्तन नहीं करता

इस बात की जांच करें:

- आपने टूलबार में कोई मॉडल चुना है
- कम से कम एक मॉडल [**सेटिंग्स** > **मॉडल**](#models) में सूचीबद्ध है
- आपका एपीआई सेटअप काम कर रहा है

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं:

1. [**सेटिंग्स** > **एपीआई कॉन्फ़िग**](#api-config) खोलें।
2. सुनिश्चित करें कि कम से कम एक एपीआई कुंजी सहेजी गई है।
3. कुंजी के सही काम करने की पुष्टि करने के लिए प्रदाता के पास **टेस्ट** पर क्लिक करें।

<br/>

<a id="the-model-list-is-empty"></a>
### मॉडल सूची खाली है

[**सेटिंग्स** > **मॉडल**](#models) खोलें और **ताज़ा करें** पर क्लिक करें।

यदि आवश्यकता हो:

- किसी मॉडल की खोज करें
- **केवल नि: शुल्क** चालू करें
- **चयनित मॉडल्स** में एक या अधिक मॉडल्स जोड़ें

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### परिणाम बहुत धीमा या बहुत महंगा है

इनमें से एक या अधिक का प्रयास करें:

- एक अलग मॉडल चुनें
- छोटा इनपुट उपयोग करें
- [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में **वास्तविक समय अनुवाद (टाइप करते समय)** बंद कर दें
- सरल कार्यों के लिए मुफ्त मॉडल का उपयोग करें (देखें [मॉडल्स](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### इंटरफ़ेस गलत भाषा में है

[टूलबार](#toolbar) में ग्लोब आइकन पर क्लिक करें और अपनी पसंदीदा **इंटरफ़ेस भाषा** चुनें।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### टेक्स्ट बहुत छोटा या पढ़ने में कठिन है

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और बदलें:

- **फ़ॉन्ट परिवार**
- **आकार**

<br/>

<a id="dashboard-charts-are-empty"></a>
### डैशबोर्ड चार्ट खाली हैं

यह सामान्य है यदि:

- आप केवल **मुफ़्त मॉडल** का उपयोग करते हैं (लागत चार्ट खाली रहेंगे)
- चयनित **समय फ़िल्टर** उस अवधि को नहीं कवर करता जब कॉल की गई थीं — जाँच करने के लिए **सभी** का प्रयास करें

यदि **सभी** का चयन करने के बाद भी चार्ट खाली हैं, तो पुष्टि करें कि कॉल [**इतिहास**](#history) या **सभी कॉल** टैब में दिखाई दे रही हैं।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### लागत "उपलब्ध नहीं" दिखाती है या गलत प्रतीत होती है

जब आप **OpenRouter** के माध्यम से मॉडल का उपयोग करते हैं, तो ऐप आपके वास्तविक खर्च को OpenRouter द्वारा रिपोर्ट किए गए अनुसार दिखाता है।

**अन्य प्रदाताओं** (सीधे OpenAI, सीधे Anthropic, आदि) के लिए, लागत OpenRouter द्वारा प्रकाशित मूल्य डेटा से अनुमानित होती है। यदि किसी मॉडल के लिए मिलती-जुलती कीमत नहीं मिलती है, तो लागत **उपलब्ध नहीं** के रूप में दिखाई देगी और आपके कुल योग में शामिल नहीं की जाएगी।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### कुल लागत मेरे प्रदाता के बिल से मेल नहीं खाती

ऐप में दिखाई जाने वाली सभी लागत आंकड़े केवल **संदर्भ के लिए अनुमान** हैं, आधिकारिक बिलिंग विवरण नहीं।

आपके वास्तविक OpenRouter खर्च के करीब कुल योग लाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) खोलें और **API कुंजी उपयोग के साथ सिंक करें** पर क्लिक करें।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### साइडबार में इतिहास पृष्ठ गायब है

**कार्यान्वयन इतिहास बनाए रखें** बंद हो सकता है। [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और इसे सक्षम करें। ध्यान दें कि इसे चालू करने से पहले हटाए गए इतिहास डेटा को पुनर्स्थापित नहीं किया जाएगा।

<br/>

<a id="web-app-session-expired"></a>
### वेब ऐप: अप्रत्याशित रूप से लॉगिन पृष्ठ पर पुनः निर्देशित किया गया

आपका सत्र समाप्त हो सकता है। फिर से लॉगिन करें। यदि यह बार-बार होता है, तो सत्र आयु सेटिंग के लिए सर्वर कॉन्फ़िगरेशन की जाँच करें।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### डैशबोर्ड दूसरे उपयोगकर्ताओं के लिए कोई डेटा नहीं दिखाता (वेब)

केवल **प्रशासक** **उपयोगकर्ता** फ़िल्टर के माध्यम से सभी उपयोगकर्ताओं के डेटा को देख सकते हैं। सामान्य उपयोगकर्ता केवल अपनी गतिविधि देखते हैं, यह डिज़ाइन के अनुसार है।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### मैंने एक प्रॉम्प्ट बदल दिया और संपादन खो दिए

प्रॉम्प्ट संपादित करते समय, हमेशा **बैक टू रन** पर क्लिक करने से पहले **सहेजें** पर क्लिक करें।

<a id="quick-tips"></a>
## त्वरित सुझाव

- आगे बढ़ने से पहले यह सुनिश्चित करने के लिए कि आपका सेटअप काम कर रहा है, [**अनुवाद करें**](#translate) से प्रारंभ करें, फिर [**पुनर्लेखन**](#rewrite) या [**परिवर्तन**](#transform) पर जाएँ।
- दैनिक शब्दावली सुधार के लिए [**पुनर्लेखन**](#rewrite) का उपयोग करें।
- किसी विशिष्ट कार्य के लिए दोहराने योग्य कार्यप्रवाह की आवश्यकता होने पर [**परिवर्तन**](#transform) का उपयोग करें।
- उपयोग और लागत पर नज़र रखने के लिए [**डैशबोर्ड**](#dashboard) का उपयोग करें।
- पिछले संचालन और उनके पूर्ण इनपुट/आउटपुट पाठ की समीक्षा करने के लिए [**इतिहास**](#history) का उपयोग करें।
- यदि आप एक प्रॉम्प्ट लाइब्रेरी बना रहे हैं जिसे आप सुरक्षित रखना चाहते हैं (देखें [प्रॉम्प्ट्स परिवर्तित करें](#transform-prompts)) या अन्यों के साथ साझा करना चाहते हैं, तो प्रॉम्प्ट्स को नियमित रूप से निर्यात करें।
