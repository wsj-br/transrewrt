# उपयोगकर्ता गाइड

<br/>

<a id="introduction"></a>
## परिचय

Transrewrt आपको तीन मुख्य तरीकों से टेक्स्ट के साथ काम करने में मदद करता है:

- **अनुवाद करें** - एक भाषा से दूसरी भाषा में पाठ को परिवर्तित करें।
- **पुनर्लेखन** - स्पष्ट, छोटा या अधिक औपचारिक जैसी विभिन्न शैली में पाठ को फिर से लिखें।
- **परिवर्तित करें** - प्रॉम्प्ट नामक कस्टम एआई निर्देशों का उपयोग कर पाठ को संसाधित करें।

डिफ़ॉल्ट रूप से ऐप **आसान** मोड में चलता है: आप सेटिंग्स में एक **प्रीसेट** (जैसे मुफ्त (ओपनराउटर), मानक, उन्नत, या तकनीकी) और एक **प्रदाता** चुनते हैं, बिना मॉडल आईडी चुने। अगर आप [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) से क्लासिक मॉडल सूची चाहते हैं तो [**सेटिंग्स** > **मॉडल**](#models) में **उन्नत** पर स्विच करें।

<br/>

यह गाइड समझाती है कि ऐप स्थापित और चल रहा होने के बाद इसका उपयोग कैसे करें। स्थापना चरणों के लिए मुख्य [**README**](README.hi.md) देखें।

<br/>

> ℹ️ **नोट**<br/>
> Transrewrt Windows और Linux के लिए डेस्कटॉप ऐप के रूप में और स्व-होस्टेड वेब ऐप के रूप में उपलब्ध है। यह गाइड ऐप के दैनिक उपयोग पर केंद्रित है। जहां कुछ केवल एक संस्करण पर लागू होता है, वहां स्पष्ट रूप से चिह्नित किया गया है।

<a id="before-you-start"></a>
## शुरू करने से पहले

Transrewrt का उपयोग करने के लिए, आपको कम से कम एक AI प्रदाता तक पहुँच की आवश्यकता है। समर्थित प्रदाता हैं: [OpenRouter](https://openrouter.ai) (जो कई मॉडल को एकत्रित करता है), OpenAI, एंथ्रोपिक, Google Gemini, डीपसीक, ग्रॉक, मिस्ट्रल, एक्सएआई, सेरेब्रस, और स्थानीय मॉडल के लिए [Ollama](https://ollama.com)।

शुरुआत करने के लिए आपको कोई भुगतान वाला मॉडल चुनने की आवश्यकता नहीं है। जैसे ही आप अपनी OpenRouter API कुंजी जोड़ते हैं, ऐप स्वचालित रूप से एक अंतर्निहित **मुफ्त** OpenRouter विकल्प सक्षम कर देता है। इससे आप तुरंत पाठ का अनुवाद, पुनर्लेखन और परिवर्तन शुरू कर सकते हैं। वैकल्पिक रूप से, आप Cerebras, Google, Groq, या Mistral AI से एक मुफ्त API कुंजी भी प्राप्त कर सकते हैं।

सरल भाषा में:

- **आसान** मोड में, एक **प्रीसेट** (मुफ्त (ओपनराउटर), Standard, उन्नत, या Technical) आपके चयनित **प्रदाता** (ओपनराउटर, ओपनएआई, ओलामा, और अन्य) के लिए एक मॉडल से मैप होता है। केवल वे प्रीसेट जिनका वर्तमान प्रदाता के लिए मैपिंग है, टूलबार में दिखाई देते हैं। आप अनुवाद करें, पुनर्लेखन, और परिवर्तित करें पर प्रीसेट चुनते हैं।
- **उन्नत** मोड में, एक **मॉडल** वह AI इंजन है जिसे आप सीधे चुनते हैं। मॉडल आईडी एक **प्रदाता उपसर्ग** का उपयोग करती हैं (उदाहरण के लिए `openrouter/…`, `openai/…`, `ollama/…`)।
- एक **API कुंजी** (या, ओलामा के लिए, एक **बेस URL**) वह तरीका है जिससे ऐप उस प्रदाता तक पहुँचता है।

यदि आप **डेस्कटॉप ऐप** का उपयोग कर रहे हैं, तो प्रत्येक प्रदाता के लिए [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) में कुंजी जोड़ें। केवल OpenRouter के उपयोग के लिए, नीचे [मुफ्त OpenRouter API कुंजी कैसे प्राप्त करें](#how-to-get-a-free-openrouter-api-key-desktop-app) देखें। यदि आप API कुंजी का उपयोग नहीं करना चाहते हैं, तो आप ओलामा स्थापित कर सकते हैं ( [ollama.com](https://ollama.com) से) और इसके बजाय स्थानीय मॉडलों का उपयोग कर सकते हैं, जैसे `translategemma:4b`।

यदि आप **वेब संस्करण** का उपयोग कर रहे हैं, तो सर्वर के मालिक पर्यावरण चर के माध्यम से प्रदाताओं को कॉन्फ़िगर करते हैं, इसलिए आप ऐप में सीधे API कुंजियाँ दर्ज नहीं कर सकते।

<br/>

<a id="how-to-get-a-free-openrouter-api-key-desktop-app"></a>
### मुफ्त OpenRouter API कुंजी कैसे प्राप्त करें (डेस्कटॉप ऐप)

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं, तो इन चरणों का पालन करें:

1. अपने वेब ब्राउज़र में [OpenRouter](https://openrouter.ai) पर जाएँ।
2. एक खाता बनाएँ या साइन इन करें।
3. [Keys](https://openrouter.ai/keys) पृष्ठ खोलें।
4. एक नई API कुंजी बनाने के लिए बटन पर क्लिक करें।
5. बाद में पहचानने के लिए कुंजी को एक नाम दें।
6. नई API कुंजी की कॉपी करें।
7. Transrewrt पर वापस जाएँ और **सेटिंग्स** > **API कॉन्फ़िग** खोलें।
8. कुंजी को **OpenRouter API कुंजी** में पेस्ट करें (**सेटिंग्स** > **API कॉन्फ़िग** के अंतर्गत)।
9. यह सुनिश्चित करने के लिए कि यह काम करता है, **OpenRouter कुंजी का परीक्षण करें** पर क्लिक करें।

<br/><br/>

<a id="getting-started"></a>
## शुरुआत

यदि आप Transrewrt का पहली बार उपयोग कर रहे हैं, तो इस क्रम का पालन करें:

1. ऐप खोलें।
2. आवश्यकता होने पर ग्लोब आइकन से अपनी **इंटरफ़ेस भाषा** चुनें।
3. यदि आप **डेस्कटॉप ऐप** पर हैं, तो [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें, कम से कम एक प्रदाता (उदाहरण के लिए ओपनराउटर) के लिए एक API कुंजी जोड़ें, और यह सत्यापित करने के लिए **परीक्षण** पर क्लिक करें कि यह काम करता है।
4. [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें। **आसान** मोड (डिफ़ॉल्ट) में, एक कॉन्फ़िगर की गई कुंजी वाले **प्रदाता** को चुनें। **उन्नत** मोड में, [**सेटिंग्स** > **मॉडल**](#models) खोलें और एक या अधिक मॉडल को **चयनित मॉडल** में जोड़ें।
5. **अनुवाद** पर, टूलबार में एक **प्रीसेट** (आसान) या **मॉडल** (उन्नत) चुनें।
6. [**सेटिंग्स** > **भाषाएँ**](#languages) खोलें और अगर आप चाहते हैं कि आपकी सबसे अधिक उपयोग की जाने वाली भाषाएं पहले दिखाई दें, तो अपने **शीर्ष भाषाएं** चुनें।
7. सब कुछ काम कर रहा है, इसकी पुष्टि करने के लिए एक सरल अनुवाद चलाएं, फिर **पुनर्लेखन** और **परिवर्तन** आज़माएं।

यह क्रम महत्वपूर्ण है। यह सबसे सामान्य पहले उपयोग की समस्या को रोकता है: एक कार्य को चलाने की कोशिश करना इससे पहले कि ऐप के पास एक कार्यशील एपीआई कनेक्शन या चयनित प्रीसेट/मॉडल हो।

        <li><strong>डैशबोर्ड</strong> उपयोग और लागत की जानकारी दिखाता है।</li><br/>
        <li><strong>सेटिंग्स</strong> सेटिंग्स पैनल खोलता है।</li><br/>
        <li><strong>इतिहास</strong> इनपुट और आउटपुट पाठ के साथ उपयोग इतिहास दिखाता है</li><br/>
        <li><strong>उपयोगकर्ता</strong> लॉग इन किए गए उपयोगकर्ता का उपयोगकर्ता नाम दिखाता है (केवल वेब)।</li>
      </ul>
    </td>
  </tr>
</table>

<a id="toolbar"></a>
### टूलबार

टूलबार थोड़ा-थोड़ा बदल जाता है जिसके आधार पर आप ऐप में कहाँ हैं।

- बाईं ओर, यह वर्तमान पृष्ठ का नाम दिखाता है।
- दाईं ओर, यह **प्रीसेट या मॉडल चयनकर्ता** और **इंटरफ़ेस भाषा** नियंत्रण दिखाता है।

**आसान** मोड में, टूलबार में एक **प्रीसेट चयनकर्ता** होता है जिसमें अंतर्निहित प्रीसेट **मुफ्त (ओपनराउटर)**, **मानक**, **उन्नत**, और **तकनीकी** होते हैं। कौन से प्रीसेट दिखाई देते हैं, यह उस **प्रदाता** पर निर्भर करता है जिसे आपने [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में चुना है—उदाहरण के लिए, **मुफ्त (ओपनराउटर)** केवल तब सूचीबद्ध होता है जब प्रदाता ओपनराउटर हो। यदि **प्रदाता** **ओलामा** है, तो टूलबार आपके स्थापित स्थानीय मॉडलों को प्रीसेट के बजाय सूचीबद्ध करता है।

**उन्नत** मोड में, **मॉडल चयनकर्ता** आपको वर्तमान कार्य के लिए कौन सा एआई इंजन उपयोग करना है चुनने की अनुमति देता है।

![Model selector](../images/screenshots/hi/preset-selector.png)

उन्नत मोड में, कुछ मुफ्त मॉडल हमेशा उपलब्ध नहीं हो सकते हैं—वे ऑफ़लाइन हो सकते हैं या उपयोग सीमा तक पहुँच सकते हैं। ऐप उस मॉडल को आपकी सूची से स्वचालित रूप से हटा सकता है। जो मॉडल दिखाई दें इसे नियंत्रित करने के लिए, [**सेटिंग्स** > **मॉडल**](#models) पर जाएँ। आप टूलबार में मॉडल नाम के बाईं ओर प्रदाता आइकन से मॉडल सेटिंग्स खोल सकते हैं।

<br/>

**ग्लोब आइकन + भाषा कोड** ऐप इंटरफ़ेस भाषा, जैसे मेनू और बटन, बदलता है। यह **अनुवाद करें** में उपयोग की जाने वाली अनुवाद भाषाओं को **नहीं** बदलता है।

![Interface language selector](../images/screenshots/hi/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### इनपुट और आउटपुट पैनल

अधिकांश कार्यक्षेत्र बाएं तरफ के **इनपुट** पैनल और दाएं तरफ के **आउटपुट** पैनल का उपयोग करते हैं।

प्रत्येक पैनल भी दिखाता है:

| **इनपुट**                                                          | **आउटपुट**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - अक्षर गणना <br/>- शब्द गणना <br/>- पैराग्राफ गणना   <br/> | - कार्य को पूरा करने में कितना समय लगा<br/>- **TPS** (प्रति सेकंड टोकन)<br/>- अक्षर, शब्द और पैराग्राफ गणना<br/>- उपयोग किया गया मॉडल |

यदि आप तकनीकी शब्दों के बारे में सोच रहे हैं:

- **टोकन** का अर्थ है पाठ का एक छोटा टुकड़ा। आप इसे एक शब्द के हिस्से या एक छोटे शब्द के रूप में समझ सकते हैं।
- **TPS** का अर्थ है कि मॉडल ने प्रति सेकंड कितने ऐसे पाठ टुकड़े प्रसंस्कृत किए।

<br/>

आप प्रत्येक ऑपरेशन की लागत (यदि उपलब्ध हो) और कुल लागत की भी निगरानी कर सकते हैं, विकल्प सक्षम करके `Show cost information on the actions` [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) पर।

<a id="translate"></a>
## अनुवाद करें

जब आप एक भाषा से दूसरी भाषा में पाठ परिवर्तित करना चाहते हैं तो **अनुवाद करें** का उपयोग करें।

![Translate workspace](../images/screenshots/hi/translate.png)

<br/>

<a id="translate-text"></a>
### पाठ का अनुवाद करें

1. **अनुवाद** खोलें।
2. **से** में एक भाषा चुनें।
3. **में** में एक भाषा चुनें।
4. टूलबार में एक प्रीसेट (आसान) या मॉडल (उन्नत) चुनें।
5. **इनपुट** में पाठ टाइप करें या पेस्ट करें।
6. **अनुवाद करें** पर क्लिक करें।
7. **आउटपुट** में परिणाम पढ़ें।
8. यदि आप परिणाम कॉपी करना चाहते हैं तो कॉपी बटन का उपयोग करें।

<br/>

<a id="language-selection"></a>
### भाषा चयन

- **से** एक विशिष्ट भाषा या **भाषा का पता लगाएं** हो सकता है।
- **करने के लिए** वह भाषा है जिसमें आप परिणाम चाहते हैं।

आपकी चयनित **शीर्ष भाषाएँ** सूची के शीर्ष पर दिखाई देती हैं। आप इन्हें [**सेटिंग्स** > **भाषाएँ**](#languages) में सेट कर सकते हैं।

<br/>

<a id="helpful-translation-settings"></a>
### उपयोगी अनुवाद सेटिंग्स

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में, आप यह बदल सकते हैं कि अनुवाद कैसे व्यवहार करे:

- **पेस्ट पर स्वतः अनुवाद** तुरंत पाठ पेस्ट करने पर अनुवाद चलाता है।
- **परिणाम को क्लिपबोर्ड पर स्वतः कॉपी करें** सफल चलने के बाद परिणाम को स्वचालित रूप से कॉपी कर देता है।
- **रीयल-टाइम अनुवाद (टाइप करते समय)** टाइप करते समय अनुवाद चलाता है।
- **टाइमआउट (मिलीसेकंड)** नियंत्रित करता है कि ऐप रीयल-टाइम अनुवाद चलाने से पहले कितनी देर तक प्रतीक्षा करता है।
- **ENTER के लिए व्यवहार** नियंत्रित करता है कि जब आप `Enter` दबाते हैं तो क्या होता है:
  - **Enter** अनुवाद या पुनर्लेखन चलाता है (डिफ़ॉल्ट)।
  - **Shift + Enter** अनुवाद या पुनर्लेखन चलाता है; सामान्य **Enter** एक नई पंक्ति डालता है।

<a id="rewrite"></a>
## पुनर्लेखन

जब आप मुख्य अर्थ को बदले बिना शब्दों में सुधार करना चाहते हैं तो **पुनर्लेखन** का उपयोग करें।

![Rewrite workspace](../images/screenshots/hi/rewrite.png)

यह उपयोगी है:

- वर्तनी और व्याकरण ठीक करना (**वर्तनी और व्याकरण जांचें**)
- पाठ को स्पष्ट बनाना (**स्पष्टता में सुधार करें**)
- एक रन में कई अलग-अलग पुनर्लेखन (**वैकल्पिक संस्करण**)
- पाठ को अधिक औपचारिक या अधिक अनौपचारिक बनाना (**औपचारिक बनाएं** / **अनौपचारिक बनाएं**)
- पाठ को छोटा करने या विस्तारित करने के लिए (**छोटा करें** / **विस्तारित करें**)
- पाठ को अधिक तकनीकी बनाने के लिए (**तकनीकी बनाएं**)

<br/>

> 💡 **टिप**<br/>
> जब आप "**वर्तनी और व्याकरण जांचें**" मोड का उपयोग करते हैं, तो आउटपुट पैनल में ( **कॉपी** के बगल में) **परिवर्तन दिखाएं** स्विच दिखाई देता है।
> अपने पाठ पर लागू विशिष्ट सुधारों को दिखाने या छिपाने के लिए इसे चालू या बंद करें।

<a id="transform"></a>
## परिवर्तित करें

जब आप चाहते हैं कि एआई निर्देशों के कस्टम सेट का पालन करे तो **परिवर्तित करें** का उपयोग करें।

![Transform workspace](../images/screenshots/hi/transform.png)

यह ऐप का सबसे लचीला क्षेत्र है। आप इसे निम्नलिखित कार्यों के लिए उपयोग कर सकते हैं:

- नोट्स का सारांश तैयार करना
- कच्चे पाठ को एक परिष्कृत ईमेल में बदलना
- मुख्य बिंदु निकालना
- पाठ को एक विशिष्ट प्रारूप में परिवर्तित करना
- इनपुट पाठ के साथ कोई अन्य कस्टम गतिविधि

<br/>

<a id="run-an-existing-prompt"></a>
### मौजूदा प्रॉम्प्ट चलाएं

1. **परिवर्तित करें** खोलें।
2. प्रॉम्प्ट सूची से एक प्रॉम्प्ट चुनें।
3. यदि **लक्ष्य** भाषा बॉक्स दिखाई दे, तो यदि आप चाहें तो एक भाषा चुनें।
4. **इनपुट** में पाठ टाइप या पेस्ट करें।
5. **परिवर्तित करें** पर क्लिक करें।
6. **आउटपुट** में परिणाम पढ़ें।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### यदि आपके पास अभी तक कोई प्रॉम्प्ट नहीं है

यदि आपकी प्रॉम्प्ट सूची खाली है, तो परिवर्तित करें वर्कस्पेस में **नमूना प्रॉम्प्ट लोड करें** पर क्लिक करें। निर्यात/आयात पंक्ति में [**सेटिंग्स** > **परिवर्तित करें**](#transform-settings) पर यही नियंत्रण हमेशा उपलब्ध है। दोनों अंतर्निहित उदाहरण जोड़ते हैं ताकि आप त्वरित शुरुआत कर सकें।

<br/>

> ℹ️ **नोट**<br/>
> नमूना प्रॉम्प्ट अंग्रेजी में उपलब्ध कराए जाते हैं। उन्हें लोड करने के बाद, आप किसी प्रॉम्प्ट को संपादित कर सकते हैं और इसे अपनी भाषा में अनुवाद करने के लिए **प्रॉम्प्ट अनुवाद करें** का उपयोग कर सकते हैं।

<br/>

<a id="create-a-prompt-quickly"></a>
### जल्दी से एक प्रॉम्प्ट बनाएं

एक प्रॉम्प्ट बनाने का सबसे तेज़ तरीका है:

1. **नया प्रॉम्प्ट** पर क्लिक करें।
2. **प्रॉम्प्ट उत्पन्न करें** पर क्लिक करें।
3. बताएं कि आप प्रॉम्प्ट से क्या करना चाहते हैं।
4. एक प्रीसेट (आसान) या मॉडल (उन्नत) चुनें।
5. ऐप को आपके लिए एक मसौदा बनाने दें।
6. मसौदे की समीक्षा करें और **सहेजें** पर क्लिक करें।

![Generate prompt](../images/screenshots/hi/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### एक प्रॉम्प्ट संपादित करें

जब आप कोई प्रॉम्प्ट बनाते या संपादित करते हैं, तो संपादक बाईं ओर दिखाई देता है और दाईं ओर एक परीक्षण क्षेत्र दिखाई देता है।

![Transform prompt editor](../images/screenshots/hi/transform-prompt-edit.png)

मुख्य फ़ील्ड्स हैं:

- **प्रॉम्प्ट नाम**: प्रॉम्प्ट सूची में दिखाया गया नाम।
- **प्रॉम्प्ट निर्देश (वैकल्पिक)**: एक छोटी सूचना जो प्रॉम्प्ट चलाते समय उपयोगकर्ता को दिखाई जाती है।
- **मॉडल भूमिका**: एआई को दी गई समग्र भूमिका, जैसे 'आप एक सहायक सहायक हैं।'
- **मॉडल निर्देश (एक प्रति पंक्ति)**: विशिष्ट नियम जो आप चाहते हैं कि एआई अनुसरण करे।
- **आउटपुट विवरण**: परिणाम का वर्णन करने वाला एक छोटा शब्द, जैसे 'सारांश' या 'पुनर्लेखन'।
- **तापमान (0.0 → 1.0)**: मॉडल कैसे व्यवहार करेगा; नीचे देखें।
- **लक्ष्य भाषा के लिए पूछें**: जब प्रॉम्प्ट चलाया जाता है तो लक्ष्य भाषा चयनकर्ता जोड़ता है।

यदि तकनीकी शब्द **तापमान** आपके लिए नया है, तो इसे इस तरह समझें:

- एक **निम्न** तापमान स्थिर, अधिक भविष्यानुमेय परिणाम देता है।
- एक **उच्च** तापमान अधिक विविधता और रचनात्मकता देता है।

आप इसका भी उपयोग कर सकते हैं:

- `Generate prompt` एक सरल विवरण से एक नया मसौदा बनाने के लिए
- `Improve prompt` मौजूदा प्रॉम्प्ट को सुधारने के लिए
- `Translate prompt` प्रॉम्प्ट फ़ील्ड्स का अनुवाद करने के लिए

<br/>

> ⚠️ **चेतावनी**<br/>
> `Back to Run` पर क्लिक करने से पहले `Save` पर क्लिक करें। यदि आप बिना सहेजे वापस जाते हैं, तो आपके परिवर्तन खो जाएंगे।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### उपयोग से पहले एक प्रॉम्प्ट का परीक्षण करें

दाएं ओर स्थित परीक्षण पैनल आपको दैनिक कार्य में उपयोग करने से पहले नमूना पाठ के साथ अपना प्रॉम्प्ट आज़माने की अनुमति देता है।

यह तब उपयोगी होता है जब:

- आप एक नया प्रॉम्प्ट बना रहे हैं
- आप एक प्रॉम्प्ट के दो संस्करणों की तुलना कर रहे हैं
- आप टोन, लंबाई या आउटपुट प्रारूप की जांच करना चाहते हैं

<br/>

> ℹ️ **नोट**<br/>
> आप [**सेटिंग्स** > **परिवर्तित करें**](#transform-settings) में सहेजे गए प्रॉम्प्ट का निर्यात और आयात कर सकते हैं।

जब आप प्रॉम्प्ट संपादक में **प्रॉम्प्ट उत्पन्न करें**, **प्रॉम्प्ट में सुधार करें** या **प्रॉम्प्ट अनुवाद करें** का उपयोग करते हैं, तो **आसान** मोड अनुवाद और पुनर्लेखन के समान प्रीसेट चयनकर्ता प्रदान करता है; **उन्नत** मोड मॉडल सूची का उपयोग करता है।

### डैशबोर्ड टैब

- **सारांश** KPI कार्ड दिखाता है: कुल लागत, उपयोग किए गए मॉडल, प्रति-मोड कॉल गणना और लागत (कुल कॉल का हिस्सा), प्रति कॉल औसत लागत, औसत TPS, और कॉल गणना के आधार पर शीर्ष तीन मॉडल।
- **मॉडल द्वारा** प्रत्येक मॉडल को कुल कॉल, कुल लागत और औसत TPS के साथ सूचीबद्ध करता है; अनुवाद, पुनर्लेखन और परिवर्तन के लिए विस्तार के लिए पंक्ति का विस्तार करें।
- **सभी कॉल** पूर्ण कॉल लॉग दिखाता है (चौड़े लेआउट पर पृष्ठांकित, संकीर्ण स्क्रीन पर कार्ड), और आपको इसे निर्यात करने की अनुमति देता है।

> ⚠️ **चेतावनी**<br/>
> संग्रहीत रिकॉर्ड हटाने की प्रक्रिया को वापस नहीं किया जा सकता। केवल तभी इसका उपयोग करें जब आपको यकीन हो कि आपको उस इतिहास की आवश्यकता नहीं है।

सभी डेटा को हटाने या उनकी आयु के आधार पर रिकॉर्ड हटाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) पर जाएँ। वहाँ आपको सभी संग्रहीत डेटा या केवल एक निश्चित तारीख से पुराने डेटा को हटाने के विकल्प मिलेंगे।

ऐप के व्यवहार को अनुकूलित करने के लिए साइडबार से **सेटिंग्स** खोलें।

उपलब्ध टैब प्लेटफ़ॉर्म और आपकी भूमिका पर निर्भर करते हैं:

| टैब              | डेस्कटॉप | वेब (एडमिन) | वेब (सामान्य उपयोगकर्ता) | टिप्पणियाँ                                        |
  |------------------|:-------:|:-----------:|:------------------:|----------------------------------------------|
  | सामान्य सेटिंग्स |   हाँ   |     हाँ     |        हाँ         | **एआई अनुभव** (आसान / उन्नत) शामिल है |
  | मॉडल           |   हाँ   |     हाँ     |        हाँ         | केवल जब **एआई अनुभव** **उन्नत** हो |
  | भाषाएँ        |   हाँ   |     हाँ     |        हाँ         |                                              |
  | लागत ट्रैकिंग    |   हाँ   |     हाँ     |         -          |                                              |
  | परिवर्तित करें        |   हाँ   |     हाँ     |        हाँ         | ट्रांसफ़ॉर्म प्रॉम्प्ट का बल्क आयात/निर्यात      |
  | उपयोगकर्ता            |    -    |     हाँ     |         -          |                                              |
  | API कॉन्फ़िग       |   हाँ   |     हाँ     |         -          |                                              |
  | बारे में            |   हाँ   |     हाँ     |        हाँ         |                                              |

**आसान** मोड में, मॉडल चयन टूलबार में प्रीसेट और सामान्य सेटिंग्स में **प्रदाता** के माध्यम से होता है; **मॉडल** टैब छिपा होता है।

> ℹ️ **नोट**<br/>

<a id="general-settings"></a>
### सामान्य सेटिंग्स

टाइपिंग व्यवहार, यह नियंत्रित करने के लिए कि निष्पादन विवरण **इतिहास** के लिए संग्रहीत किए जाएँ या नहीं, दिखावट और आप अनुवाद, पुनर्लेखन और परिवर्तन के लिए एआई का चयन कैसे करते हैं, को नियंत्रित करने के लिए **सामान्य सेटिंग्स** का उपयोग करें।

**एआई अनुभव**

- **आसान** (डिफ़ॉल्ट): एक **प्रदाता** चुनें (ओपनराउटर, ओपनएआई, एंथ्रोपिक, गूगल जेमिनी, डीपसीक, ग्रॉक, मिस्ट्रल, एक्सएआई, सेरेब्रस, या ओलामा)। क्लाउड प्रदाता टूलबार में अंतर्निहित प्रीसेट का उपयोग करते हैं। **ओलामा** प्रीसेट के बजाय आपके मशीन पर स्थापित मॉडल सूचीबद्ध करता है। आसान मोड में, **प्रीसेट कैटलॉग** कैटलॉग संस्करण और अंतिम अद्यतन समय दिखाता है; नवीनतम प्रीसेट सूची प्राप्त करने के लिए **प्रीसेट कैटलॉग ताज़ा करें** पर क्लिक करें (ऐप पृष्ठभूमि में भी समय-समय पर जांचता है)।
- **उन्नत**: टूलबार में व्यक्तिगत मॉडल चुनें; सूची को [**सेटिंग्स** > **मॉडल**](#models) के तहत प्रबंधित करें।

**वेब ऐप** में, कौन से प्रदाता दिखाई देते हैं यह सर्वर वातावरण में सेट API कुंजियों पर निर्भर करता है। **डेस्कटॉप ऐप** में, [**API कॉन्फ़िग**](#api-config) के तहत कुंजियाँ कॉन्फ़िगर करें।

**व्यवहार**

- **ENTER के लिए व्यवहार** यह चुनता है कि क्या `Enter` कार्य चलाएगा या एक नई पंक्ति डालेगा।
- **पेस्ट पर स्वतः अनुवाद** तुरंत अनुवाद शुरू कर देता है जैसे ही आप पाठ पेस्ट करते हैं।
- **परिणाम को क्लिपबोर्ड पर स्वतः कॉपी करें** सफल परिणामों को स्वचालित रूप से कॉपी कर देता है।
- **रीयल-टाइम अनुवाद (टाइप करते समय)** टाइप करते समय अनुवाद करता है।
- **टाइमआउट (ms)** रीयल-टाइम अनुवाद के लिए प्रतीक्षा समय निर्धारित करता है।

**हिस्ट्री**

- **कार्यान्वयन इतिहास रखें** नियंत्रित करता है कि प्रत्येक अनुवाद, पुनर्लेखन और परिवर्तित कार्य के लिए साइडबार [**इतिहास**](#history) दृश्य में **इनपुट और आउटपुट पाठ** संग्रहीत हों या नहीं। इसे बंद करने पर पुष्टि के लिए कहा जाएगा; यदि आप पुष्टि करते हैं, तो संग्रहीत इतिहास पाठ डेटाबेस से हटा दिया जाएगा। यदि लेबल में *प्रशासक द्वारा अक्षम किया गया* दिखाई दे रहा है, तो आपके इंस्टॉल में पर्यावरण में `HISTORY_DISABLED` सेट है (देखें [README](README.hi.md#configuration-and-environment)); आप UI से इतिहास को फिर से चालू नहीं कर सकते।
- **इतिहास डेटा हटाएं** आपको आयु के आधार पर (उदाहरण के लिए कुछ महीनों से पुराना, या **सभी डेटा (साफ़ करें)**) **डेटा हटाएं** का उपयोग करके संग्रहीत पाठ को हटाने की अनुमति देता है। यह केवल **इतिहास** दृश्य के लिए सहेजे गए कार्यान्वयन पाठ को प्रभावित करता है; यह **लागत या उपयोग कुल राशि** को नहीं हटाता है। **लागत** डेटा को हटाने या कम करने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) का उपयोग करें।

**दिखावट**

- **थीम** हल्का, गहरा, और सिस्टम दिखावट के बीच स्विच करती है।
- **क्रियाओं पर लागत सूचना दिखाएं** प्रति ऑपरेशन (यदि उपलब्ध हो) और अनुवाद, पुनर्लेखन, और परिवर्तित करने के आउटपुट पैनलों पर कुल लागत के प्रदर्शन को नियंत्रित करती है।
- **लागत अंशांकित अंक** लागत दशमलव को प्रदर्शित करने के तरीके को बदलता है।
- **वेब केवल:** **ऐप के चारों ओर मार्जिन दिखाएं** इंटरफेस के चारों ओर अतिरिक्त स्थान जोड़ता है।
- **फॉन्ट परिवार** टेक्स्ट पैनलों में लेखन फ़ॉन्ट को बदलता है।
- **आकार** फ़ॉन्ट का आकार बदलता है।

**कॉन्फ़िगरेशन बैकअप** (डेस्कटॉप ऐप और वेब प्रशासकों के लिए ही)

- **बैकअप में उपयोग डेटा शामिल करें** - जब सक्षम हो, तो ZIP में कार्यान्वयन इतिहास और API कॉल डेटा भी शामिल होते हैं।
- **कॉन्फ़िगरेशन बैकअप** - एकल ZIP (UTC में `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` डिफ़ॉल्ट रूप से) बनाता है जिसमें `config.json`, `state.json`, वैकल्पिक एन्क्रिप्शन कुंजी, उपयोगकर्ता, पसंदीदा, कस्टम प्रॉम्प्ट और उपयोग डेटा शामिल होते हैं यदि आपने सहमति दी है। सफल बैकअप के बाद, पुष्टि सहेजी गई फ़ाइल का नाम दिखाती है।
- **बैकअप से पुनर्स्थापित करें** - पहले एक **पुष्टि संवाद** खोलता है। संवाद के अंदर बैकअप ZIP चुनें (**ब्राउज़** / फ़ाइल पिकर या समर्थित जगहों पर ड्रैग-एंड-ड्रॉप), फिर विकल्पों की समीक्षा करें:
  - **उपयोग डेटा पुनर्स्थापित करें** - जब उपयोग शामिल करके बैकअप लिया गया हो तो ZIP से उपयोग/इतिहास आयात करें; यदि आप केवल सेटिंग्स और प्रॉम्प्ट चाहते हैं तो इसे बंद रखें।
  - **पुनर्स्थापित करने से पहले पुराना उपयोग डेटा साफ़ करें** - बैकअप लागू करने से पहले इस स्थापना पर मौजूदा उपयोग/इतिहास हटा दें (वैकल्पिक; जब आप एक साफ़ प्रतिस्थापन चाहते हैं तो उपयोग करें)।

वेब या डेस्कटॉप संस्करण में बनाए गए बैकअप दूसरे में पुनर्स्थापित किए जा सकते हैं। जब वेब संस्करण में डेस्कटॉप बैकअप को पुनर्स्थापित किया जाता है, तो डेटा व्यवस्थापक उपयोगकर्ता में पुनर्स्थापित किया जाएगा।

<br/>

<a id="models"></a>
### मॉडल

यह टैब केवल तभी उपलब्ध है जब [**सामान्य सेटिंग्स**](#general-settings) में **एआई अनुभव** को **उन्नत** पर सेट किया गया हो। टूलबार में दिखने वाले मॉडल चुनने के लिए **सेटिंग्स** > **मॉडल** का उपयोग करें।

![Settings Models tab](../images/screenshots/hi/settings-general.png)

पृष्ठ में दो सूचियाँ हैं:

- बाईं ओर **उपलब्ध मॉडल**
- दाईं ओर **चयनित मॉडल**

उपयोगी नियंत्रण में शामिल हैं:

- **मॉडल खोजें...** नाम से मॉडल ढूंढने के लिए
- सूची को एक इंजन (ओपनराउटर, ओपनएआई, ओलामा, …) तक सीमित करने के लिए **प्रदाता** चिप्स
- केवल मुफ्त मॉडल दिखाने के लिए **केवल मुफ्त**
- सूची को पुनः लोड करने के लिए **ताज़ा करें**
- प्रदाता के अनुसार क्रमबद्ध करते समय **सभी विस्तारित करें** और **सभी संक्षिप्त करें**

मॉडल आईडी में प्रदाता उपसर्ग शामिल हैं (उदाहरण के लिए `openrouter/…` बनाम `openai/…`)। **ओपनएआई (ओपनराउटर)** बनाम **ओपनएआई (सीधा)** जैसे बैज दिखाते हैं कि ट्रैफ़िक को कैसे मार्गदर्शित किया जाता है।

> ℹ️ **नोट**<br/>
> **ओपनराउटर बॉडी बिल्डर** (`openrouter/bodybuilder`) एक राउटर मॉडल है, सामान्य चैट मॉडल नहीं: इसका उत्तर JSON है जो ओपनराउटर API अनुरोध बॉडी का वर्णन करता है (उदाहरण के लिए `requests` सरणी में `model` और `messages` के साथ)। यदि आप इसका उपयोग **अनुवाद करें**, **पुनर्लेखन** या **परिवर्तित करें** के लिए करते हैं, तो आउटपुट पैनल में तैयार पाठ के बजाय वह JSON दिखाई देगा। इन कार्यों के लिए एक सामान्य पाठ मॉडल चुनें। ओपनराउटर पर [बॉडी बिल्डर मॉडल पृष्ठ](https://openrouter.ai/openrouter/bodybuilder) देखें।

क्रियाएँ:

- मॉडल जोड़ने के लिए, **जोड़ें** पर क्लिक करें या प्रविष्टि में कहीं भी क्लिक करें।

- मॉडल हटाने के लिए, **चयनित मॉडल** में इसके बगल में **X** पर क्लिक करें या उपलब्ध मॉडल में प्रविष्टि पर **चयनित** पर क्लिक करें।

- सूची साफ़ करने के लिए, **सभी अचयनित करें** पर क्लिक करें। आवश्यक मुफ्त मॉडल सूची में बना रहेगा।

<br/>

> ℹ️ **नोट**<br/>
> यदि आप तुरंत ओपनराउटर पर क्रेडिट जोड़ना नहीं चाहते हैं, तो **केवल मुफ्त** सक्षम करके शुरू करें और मुफ्त मॉडल चुनें (क्रेडिट कार्ड की आवश्यकता नहीं है)। आप बिना किसी API कुंजी के मॉडल को स्थानीय रूप से चलाने के लिए ओलामा का उपयोग भी कर सकते हैं।

<a id="languages"></a>
### भाषाएँ

ऐप में उपयोग की जाने वाली भाषा सूचियों को व्यवस्थित करने के लिए **सेटिंग्स** > **भाषाएँ** का उपयोग करें।

- **शीर्ष भाषाएँ** **अनुवाद करें** और **परिवर्तित करें** में भाषा सूचियों के ऊपरी हिस्से में पिन की गई हैं।
- **कस्टम भाषा** आपको अंतर्निहित सूची में नहीं आने वाली भाषा जोड़ने की अनुमति देती है।

यदि आप एक कस्टम भाषा जोड़ते हैं, तो यह अंतर्निहित विकल्पों के साथ भाषा चयनकर्ताओं में दिखाई देगी।

<a id="cost-tracking"></a>
### लागत ट्रैकिंग

लागत जानकारी को प्रबंधित करने के लिए **सेटिंग्स** > **लागत ट्रैकिंग** का उपयोग करें।

- **कुल लागत** चल रहे कुल योग को दिखाता है।
- **मान कॉपी करें** कुल योग को क्लिपबोर्ड पर कॉपी करता है।
- **लागत रीसेट करें** संग्रहीत कुल योग को शून्य पर रीसेट करता है।
- **API कुंजी उपयोग के साथ सिंक करें** कुल योग को आपके ओपनराउटर खाते द्वारा रिपोर्ट किए गए उपयोग के अनुरूप सेट करता है (केवल ओपनराउटर)।
- **API कुंजी उपयोग** उपलब्ध होने पर ओपनराउटर उपयोग विवरण दिखाता है।
- **लागत डेटा हटाएं** सभी डेटा या केवल चयनित तारीख से पुराने प्रविष्टियाँ हटा देता है।

**लागत ट्रैकिंग:** जब आप ओपनराउटर मॉडल का उपयोग करते हैं, तो ऐप ओपनराउटर से लागत जानकारी के आधार पर आपके वास्तविक उपयोग और खर्च को दिखाता है। अन्य सभी प्रदाताओं के लिए, ऐप ओपनराउटर द्वारा प्रकाशित मूल्यों का उपयोग करके लागत का अनुमान लगाता है, यदि मूल्य अनुपलब्ध है, तो अनुमान शून्य हो सकता है।

<br/>

> ℹ️ **नोट**<br/>
> **सभी लागत आंकड़े केवल आपके संदर्भ के लिए अनुमान हैं, आधिकारिक बिलिंग विवरण नहीं।**

<br/>

> ⚠️ **चेतावनी**<br/>
> डेटा हटाने की प्रक्रिया को पूर्ववत नहीं किया जा सकता। हटाने से पहले, अपने डेटा का बैकअप लें या इसे [**इतिहास**](#history)
> या [**डैशबोर्ड** > **सभी कॉल**](#dashboard-tabs) के माध्यम से निर्यात करें, अन्यथा यह स्थायी रूप से खो जाएगा।
> प्रत्येक API कॉल प्रविष्टि से संबंधित सभी इनपुट/आउटपुट इतिहास को भी हटा दिया जाएगा।

<a id="transform-settings"></a>
### परिवर्तित करें (सेटिंग्स टैब)

बल्क में प्रॉम्प्ट प्रबंधित करने के लिए **सेटिंग्स** > **परिवर्तित करें** का उपयोग करें।

आप कर सकते हैं:

- अपने सहेजे गए प्रॉम्प्ट की समीक्षा करें
- प्रॉम्प्ट हटाएं
- फ़ाइल से प्रॉम्प्ट आयात करें
- बैकअप या साझा करने के लिए प्रॉम्प्ट निर्यात करें
- प्रॉम्प्ट सूची में नमूना प्रॉम्प्ट लोड करें

<a id="users"></a>
### उपयोगकर्ता

वेब संस्करण में उपयोगकर्ता खातों को प्रबंधित करने के लिए **उपयोगकर्ता** का उपयोग करें। आप उपयोगकर्ता जोड़ सकते हैं, उनके विवरण अपडेट कर सकते हैं, पासवर्ड रीसेट कर सकते हैं और खाते हटा सकते हैं।

<a id="api-config"></a>
### API कॉन्फ़िग

समर्थित प्रदाता हैं: ओपनराउटर, ओपनएआई, एंथ्रोपिक, गूगल जेमिनी, डीपसीक, ग्रॉक, मिस्ट्रल, एक्सएआई, सेरेब्रस, और **ओलामा** (बेस URL के माध्यम से स्थानीय मॉडल)। आपको केवल उन प्रदाताओं को कॉन्फ़िगर करने की आवश्यकता है जिनका आप उपयोग करते हैं।

**वेब एप्लिकेशन: केवल प्रशासक**

API कुंजियों को सिस्टम या डॉकर वातावरण चर के माध्यम से कॉन्फ़िगर किया जाता है - उन्हें वेब UI में दर्ज नहीं किया जाता है। यह पृष्ठ दिखाता है कि किन प्रदाताओं के लिए कुंजी कॉन्फ़िगर की गई है और आपको `Test` बटन पर क्लिक करके प्रत्येक का परीक्षण करने की अनुमति देता है।

<br/>

> ℹ️ **नोट**<br/>
> किसी API कुंजी को बदलने के लिए, अपने सिस्टम या डॉकर कॉन्फ़िगरेशन में वातावरण चर को अपडेट करें और सर्वर या कंटेनर को पुनः आरंभ करें।

<br/>

> ℹ️ **नोट**<br/>
> **कॉन्फ़िगरेशन बैकअप** (देखें [**सामान्य सेटिंग्स** → कॉन्फ़िगरेशन बैकअप](#general-settings)) ZIP के `config.json` के अंदर **हल किए गए** प्रदाता कुंजी को एम्बेड कर सकते हैं। उस ZIP को पुनर्स्थापित करना उन कुंजी को सर्वर की स्थायी कॉन्फ़िग फ़ाइल में **नहीं** कॉपी करता - लाइव कुंजी अभी भी वातावरण और वहां वर्णित मौजूदा फ़ाइल स्थिति से आती हैं।

<br/>

**डेस्कटॉप एप्लिकेशन**

प्रत्येक प्रदाता के लिए API कुंजियों को संग्रहीत करने के लिए **API कॉन्फ़िग** का उपयोग करें। ओलामा के लिए, API कुंजी के बजाय **बेस URL** दर्ज करें।

<br/>

> 💡 **टिप** <br/>
> यदि आप कोई API कुंजी का उपयोग नहीं करना चाहते या उपयोग के लिए भुगतान नहीं करना चाहते हैं, तो आप [ओलामा डाउनलोड](https://ollama.com) कर सकते हैं और मुफ्त में अपने मशीन पर मॉडल (जैसे `translategemma:4b`) स्थानीय रूप से चला सकते हैं। वैकल्पिक रूप से, आप उनके मुफ्त मॉडल का उपयोग करने के लिए मुफ्त ओपनराउटर खाता बना सकते हैं (क्रेडिट कार्ड की आवश्यकता नहीं), या सेरेब्रस, गूगल, ग्रॉक, या मिस्ट्रल एआई से मुफ्त API कुंजी प्राप्त कर सकते हैं।

<br/>

- केवल उन प्रदाताओं को जोड़ें जिनकी आपको आवश्यकता है। **सेटिंग्स** > **मॉडल** में, प्रत्येक मॉडल आईडी प्रदाता के साथ शुरू होती है (उदाहरण के लिए `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

API कुंजी जोड़ने के लिए, पाठ फ़ील्ड में मान दर्ज करें और `Save` पर क्लिक करें। मौजूदा कुंजी को बदलने के लिए, `Edit` पर क्लिक करें। यह सत्यापित करने के लिए कि कुंजी काम कर रही है, `Test` पर क्लिक करें। ओलामा बेस URL के लिए, संपर्क की जांच करने के लिए हमेशा `Test` पर क्लिक करें।

<br/>

> ℹ️ **नोट**<br/>
> आप वर्तमान API कुंजी के मान को नहीं देख सकते। आप केवल `Edit` बटन का उपयोग करके इसे बदल सकते हैं।
> API कुंजियाँ कॉन्फ़िगरेशन में एन्क्रिप्टेड रूप से संग्रहीत की जाती हैं।

<a id="common-issues"></a>
## सामान्य समस्याएँ

यदि कुछ अपेक्षा के अनुसार काम नहीं कर रहा है, तो पहले निम्नलिखित बिंदुओं की जांच करें।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ऐप अनुवाद, पुनर्लेखन, या पाठ को परिवर्तित नहीं करेगा

जांचें कि:

- आपने टूलबार में एक **प्रीसेट** (आसान) या **मॉडल** (उन्नत) का चयन किया है
- **आसान** मोड में, [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में एक **प्रदाता** है जिसके पास एक कार्यरत कुंजी (या ओलामा URL) और उस प्रदाता के लिए कम से कम एक प्रीसेट है
- **उन्नत** मोड में, [**सेटिंग्स** > **मॉडल**](#models) में कम से कम एक मॉडल सूचीबद्ध है
- आपका API सेटअप काम कर रहा है

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं:

1. [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें।
2. जांचें कि कम से कम एक API कुंजी सहेजी गई है।
3. कुंजी काम कर रही है यह पुष्टि करने के लिए प्रदाता के बगल में **परीक्षण** पर क्लिक करें।

<br/>

<a id="the-model-list-is-empty"></a>
### मॉडल सूची खाली है

**आसान** मोड में, [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें, पुष्टि करें कि **प्रदाता** सेट है, और [**API कॉन्फ़िग**](#api-config) में कुंजियाँ जोड़ें या परीक्षण करें (डेस्कटॉप) या अपने प्रशासक से पूछें (वेब)। **ओलामा** के लिए, बेस URL पर **परीक्षण** चलाएँ और सुनिश्चित करें कि मॉडल स्थानीय रूप से स्थापित हैं।

**उन्नत** मोड में, [**सेटिंग्स** > **मॉडल**](#models) खोलें और **ताज़ा करें** पर क्लिक करें। यदि आवश्यकता हो, तो किसी मॉडल की खोज करें, **केवल मुफ्त** चालू करें, और मॉडल को **चयनित मॉडल** में जोड़ें।

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### परिणाम बहुत धीमा या बहुत महंगा है

इनमें से एक या अधिक प्रयास करें:

- एक अलग प्रीसेट (आसान) या मॉडल (उन्नत) चुनें
- इनपुट को छोटा करें
- [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में **वास्तविक समय अनुवाद (टाइप करते समय)** को बंद करें
- सरल कार्यों के लिए मुफ्त मॉडल का उपयोग करें ([मॉडल](#models) देखें)

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### इंटरफ़ेस गलत भाषा में है

[टूलबार](#toolbar) में ग्लोब आइकन पर क्लिक करें और अपनी पसंदीदा **इंटरफ़ेस भाषा** चुनें।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### पाठ बहुत छोटा या पढ़ने में कठिन है

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और बदलें:

- **फ़ॉन्ट फ़ैमिली**
- **आकार**

<br/>

<a id="dashboard-summary-looks-empty"></a>
### डैशबोर्ड सारांश खाली दिख रहा है

यह सामान्य है यदि:

- आप केवल **मुफ्त मॉडल** का उपयोग कर रहे हैं और आप **लागत** आंकड़ों को देख रहे हैं (वे शून्य हो सकते हैं); **सारांश** पर कॉल-गणना KPI को अभी भी चयनित अवधि से डेटा की आवश्यकता होती है
- चयनित **समय फ़िल्टर** उस अवधि को शामिल नहीं करता है जब कॉल की गई थी — जाँच करने के लिए **सभी** का उपयोग करें

यदि **सभी** चुनने के बाद भी KPI शून्य हैं, तो पुष्टि करें कि कॉल [**इतिहास**](#history) या **सभी कॉल** टैब में दिखाई दे रही हैं।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### लागत "उपलब्ध नहीं" दिखाती है या गलत लगती है

जब आप **ओपनराउटर** के माध्यम से मॉडल का उपयोग करते हैं, तो ऐप ओपनराउटर द्वारा रिपोर्ट किए गए आपके वास्तविक खर्च को दिखाता है।

**अन्य प्रदाता** (ओपनएआई सीधा, एंथ्रोपिक सीधा, आदि) के लिए, लागत ओपनराउटर द्वारा प्रकाशित मूल्य डेटा से अनुमानित की जाती है। यदि किसी मॉडल के लिए कोई मिलता-जुलता मूल्य नहीं मिलता है, तो लागत **उपलब्ध नहीं** के रूप में दिखाई देगी और आपके कुल योग में नहीं जोड़ी जाएगी।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### कुल लागत आपके प्रदाता के बिल से मेल नहीं खाती

ऐप में सभी लागत आंकड़े केवल **संदर्भ के लिए अनुमानित** हैं, आधिकारिक बिलिंग स्टेटमेंट नहीं।

कुल योग को आपके वास्तविक ओपनराउटर खर्च के करीब लाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) खोलें और **API कुंजी उपयोग के साथ सिंक करें** पर क्लिक करें।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### साइडबार में इतिहास पृष्ठ गायब है

**कार्यान्वयन इतिहास रखें** बंद हो सकता है। [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और इसे सक्षम करें, जब तक कि इतिहास *प्रशासक द्वारा अक्षम किया गया* न हो (पर्यावरण में `HISTORY_DISABLED` — देखें [README](README.hi.md#configuration-and-environment))। इतिहास को चालू करने से पहले हटाए गए पाठ को पुनर्स्थापित नहीं किया जाता है।

<br/>

<a id="web-app-session-expired"></a>
### वेब ऐप: अप्रत्याशित रूप से लॉगिन पृष्ठ पर पुनर्निर्देशित किया जाता है

आपका सत्र समाप्त हो गया हो सकता है। पुनः लॉग इन करें। यदि यह बार-बार होता है, तो सत्र जीवनकाल सेटिंग्स के लिए सर्वर कॉन्फ़िगरेशन की जांच करें।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### वेब एडमिन: पासवर्ड भूल गए या खो गए

यह **स्व-होस्टेड वेब ऐप** (डॉकर) पर लागू होता है, डेस्कटॉप (इलेक्ट्रॉन) ऐप पर नहीं।

- यदि कोई अन्य एडमिनिस्ट्रेटर अभी भी साइन इन कर सकता है, तो वे [**सेटिंग्स** > **उपयोगकर्ता**](#users) खोल सकते हैं, खाते का चयन कर सकते हैं और वहां एक **नया पासवर्ड** सेट कर सकते हैं।
- यदि आप **लॉक आउट** हैं लेकिन मशीन या कंटेनर पर **शेल एक्सेस** है, तो छवि के साथ आने वाले हेल्पर का उपयोग करके पासवर्ड रीसेट करें (डिफ़ॉल्ट नाम बदलने पर `transrewrt` को बदलें, और यदि पासवर्ड में स्पेस या विशेष अक्षर हैं तो उसे उद्धृत करें):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

डिफ़ॉल्ट एडमिन उपयोगकर्ता नाम `admin` है यदि आपने कभी अन्य खाते नहीं बनाए हैं। जब आप केवल एक तर्क पास करते हैं, तो इसे `admin` के लिए नया पासवर्ड माना जाता है।

यदि आप डॉकर के बजाय एक **स्रोत चेकआउट** से चला रहे हैं, तो उपयोग करें:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

स्क्रिप्ट SQLite डेटाबेस में उपयोगकर्ता रिकॉर्ड को अपडेट करती है (और यदि `admin` उपयोगकर्ता गायब है तो उसे बना भी सकती है)। पुनः स्थापित करने के बाद, नए पासवर्ड के साथ साइन इन करें।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### डैशबोर्ड अन्य उपयोगकर्ताओं के लिए कोई डेटा नहीं दिखाता है (वेब)

केवल **प्रशासक** **उपयोगकर्ता** फ़िल्टर के माध्यम से सभी उपयोगकर्ताओं के डेटा को देख सकते हैं। नियमित उपयोगकर्ता केवल अपनी गतिविधि देख सकते हैं, यह डिज़ाइन के अनुसार है।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### मैंने एक प्रॉम्प्ट बदल दिया और संपादन खो दिए

प्रॉम्प्ट संपादित करते समय, **सहेजें** पर क्लिक करना न भूलें, फिर **रन पर वापस जाएं** पर क्लिक करें।

<a id="quick-tips"></a>
## त्वरित सुझाव

- आगे बढ़ने से पहले अपने सेटअप को सुनिश्चित करने के लिए [**अनुवाद करें**](#translate) से शुरुआत करें, फिर [**पुनर्लेखन**](#rewrite) या [**परिवर्तित करें**](#transform) पर जाएं।
- दैनिक शब्दावली सुधार के लिए [**पुनर्लेखन**](#rewrite) का उपयोग करें।
- किसी विशिष्ट कार्य के लिए दोहराए जाने योग्य कार्यप्रवाह की आवश्यकता होने पर [**परिवर्तित करें**](#transform) का उपयोग करें।
- यदि आप उपयोग और लागत पर नज़र रखना चाहते हैं तो [**डैशबोर्ड**](#dashboard) का उपयोग करें।
- अतीत के संचालन और उनके पूर्ण इनपुट/आउटपुट पाठ की समीक्षा करने के लिए [**इतिहास**](#history) का उपयोग करें।
- यदि आप एक प्रॉम्प्ट लाइब्रेरी बना रहे हैं जिसे आप सुरक्षित रखना चाहते हैं (देखें [परिवर्तित करें](#transform)) या यदि आप इसे अन्य लोगों के साथ साझा करना चाहते हैं, तो नियमित रूप से प्रॉम्प्ट निर्यात करें।
- जब तक आपको मॉडल आईडी पर सूक्ष्म नियंत्रण की आवश्यकता न हो, तब तक **आसान** मोड पर रहें; जब आप पहले से जानते हैं कि आप किन मॉडल का उपयोग करना चाहते हैं, तब **उन्नत** पर स्विच करें।
