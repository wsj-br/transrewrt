# उपयोगकर्ता मार्गदर्शिका

<br/>

<a id="introduction"></a>
## परिचय

Transrewrt आपको तीन मुख्य तरीकों से पाठ के साथ काम करने में मदद करता है:

- **अनुवाद करें** - एक भाषा से दूसरी भाषा में पाठ को परिवर्तित करें।
- **रीराइट** - स्पष्ट, छोटा या अधिक औपचारिक जैसी अलग शैली में पाठ को फिर से लिखें।
- **ट्रांसफ़ॉर्म** - प्रॉम्प्ट कहलाने वाले कस्टम एआई निर्देशों का उपयोग करके पाठ को प्रोसेस करें।

<br/>

यह मार्गदर्शिका बताती है कि ऐप को स्थापित और चल रहा होने के बाद इसका उपयोग कैसे करें। स्थापना के चरणों के लिए मुख्य **[README](README.hi.md)** देखें।

<br/>

> ℹ️ **नोट**<br/>
> Transrewrt विंडोज़ और लिनक्स के लिए डेस्कटॉप ऐप के रूप में और स्वयं-होस्टेड वेब ऐप के रूप में उपलब्ध है। यह मार्गदर्शिका ऐप के दैनिक उपयोग पर केंद्रित है। जहां कुछ केवल एक संस्करण पर लागू होता है, वह स्पष्ट रूप से चिह्नित किया गया है।

<a id="before-you-start"></a>
## शुरू करने से पहले

Transrewrt का उपयोग करने के लिए, आपको कम से कम एक AI प्रदाता तक पहुँच की आवश्यकता होती है। समर्थित प्रदाता हैं: [OpenRouter](https://openrouter.ai) (जो कई मॉडलों को एकत्रित करता है), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, और स्थानीय मॉडलों के लिए [Ollama](https://ollama.com)।

शुरू करने के लिए आपको कोई भुगतान वाला मॉडल चुनने की आवश्यकता नहीं है। जैसे ही आप अपनी OpenRouter API कुंजी जोड़ते हैं, ऐप स्वचालित रूप से एक अंतर्निहित **मुफ़्त** OpenRouter विकल्प सक्षम कर देता है। इससे आप तुरंत टेक्स्ट का अनुवाद, पुनर्लेखन और रूपांतरण शुरू कर सकते हैं। वैकल्पिक रूप से, आप Cerebras, Google, Groq, या Mistral AI से एक मुफ़्त API कुंजी भी प्राप्त कर सकते हैं।

सरल भाषा में:

- एक **मॉडल** वह AI इंजन है जो काम करता है। मॉडलों को एक **प्रदाता उपसर्ग** के साथ सूचीबद्ध किया जाता है (उदाहरण के लिए `openrouter/…`, `openai/…`, `ollama/…`)।
- एक **API कुंजी** (या Ollama के लिए, एक **बेस URL**) वह तरीका है जिससे ऐप उस प्रदाता तक पहुँचता है।

यदि आप **डेस्कटॉप ऐप** का उपयोग कर रहे हैं, तो प्रत्येक प्रदाता के लिए [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) में कुंजियाँ जोड़ें। केवल OpenRouter के उपयोग के लिए, नीचे [एक API कुंजी कैसे प्राप्त करें](#how-to-get-an-api-key-desktop-app) देखें। यदि आप कोई API कुंजी उपयोग नहीं करना चाहते हैं, तो आप [ollama.com](https://ollama.com) से Ollama स्थापित कर सकते हैं और `translategemma:4b` जैसे स्थानीय मॉडलों का उपयोग कर सकते हैं।

यदि आप **वेब संस्करण** का उपयोग कर रहे हैं, तो सर्वर मालिक पर्यावरण चर के साथ प्रदाताओं को कॉन्फ़िगर करता है, इसलिए आप ऐप में सीधे API कुंजियाँ दर्ज नहीं कर सकते हैं।

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### एक मुफ़्त OpenRouter API कुंजी कैसे प्राप्त करें (डेस्कटॉप ऐप)

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं, तो इन चरणों का पालन करें:

1. अपने वेब ब्राउज़र में [OpenRouter](https://openrouter.ai) पर जाएँ।
2. एक खाता बनाएँ या साइन इन करें।
3. [Keys](https://openrouter.ai/keys) पृष्ठ खोलें।
4. एक नई API कुंजी बनाने के लिए बटन पर क्लिक करें।
5. बाद में पहचानने के लिए कुंजी को एक नाम दें।
6. नई API कुंजी को कॉपी करें।
7. Transrewrt पर वापस जाएँ और **सेटिंग्स** > **API कॉन्फ़िग** खोलें।
8. कुंजी को **OpenRouter API कुंजी** में चिपकाएँ (**सेटिंग्स** > **API कॉन्फ़िग** के अंतर्गत)।
9. यह सुनिश्चित करने के लिए कि यह काम करती है, **OpenRouter कुंजी का परीक्षण करें** पर क्लिक करें।

<a id="getting-started"></a>
## शुरुआत

यदि यह आपका Transrewrt का पहला उपयोग है, तो इस क्रम का पालन करें:

1. ऐप खोलें।
2. आवश्यकता होने पर ग्लोब आइकन से अपनी **इंटरफ़ेस भाषा** चुनें।
3. यदि आप **डेस्कटॉप ऐप** पर हैं, तो [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें, कम से कम एक प्रदाता (उदाहरण के लिए OpenRouter) के लिए एक API कुंजी जोड़ें, और यह सत्यापित करने के लिए **परीक्षण** पर क्लिक करें कि यह काम करती है।
4. [**सेटिंग्स** > **मॉडल**](#models) खोलें और **चयनित मॉडल** में एक या अधिक मॉडल जोड़ें।
5. [**सेटिंग्स** > **भाषाएँ**](#languages) खोलें और यदि आप चाहते हैं कि आपकी सबसे अधिक उपयोग की जाने वाली भाषाएँ पहले दिखाई दें, तो अपनी **शीर्ष भाषाएँ** चुनें।
6. **अनुवाद** पर जाएँ और सब कुछ काम कर रहा है यह सुनिश्चित करने के लिए एक सरल अनुवाद चलाएँ।
7. एक बार यह काम करने लगे, तो **रीराइट** और फिर **ट्रांसफ़ॉर्म** का प्रयास करें।

इस क्रम का महत्व है। यह सबसे आम पहले उपयोग की समस्या को रोकता है: कार्य चलाने का प्रयास करना तब जब ऐप के पास काम करने वाला API कनेक्शन या चयनित मॉडल नहीं होता है।

<a id="toolbar"></a>
### टूलबार

ऐप में आप कहाँ हैं, इसके आधार पर टूलबार में थोड़ा बदलाव आता है।

- बाईं ओर, यह वर्तमान पृष्ठ का नाम दिखाता है।
- दाईं ओर, यह **मॉडल चयनकर्ता** और **इंटरफ़ेस भाषा** नियंत्रण दिखाता है।

**मॉडल चयनकर्ता** आपको वर्तमान कार्य के लिए कौन सा एआई इंजन उपयोग करना है, यह चुनने की अनुमति देता है।

![Model selector](../images/screenshots/hi/model-selector.png)

कुछ मुफ़्त मॉडल हमेशा उपलब्ध नहीं हो सकते हैं—कभी-कभी वे ऑफ़लाइन होते हैं या उपयोग की सीमा होती है। ऐसा होने पर, ऐप स्वचालित रूप से उस मॉडल को आपकी उपलब्ध सूची से हटा देगा। जो मॉडल दिखें, इसे नियंत्रित करने के लिए, [**सेटिंग्स** > **मॉडल**](#models) पर जाएँ और अपनी मॉडल सूची संपादित करें।
आप टूलबार में मॉडल नाम के बाईं ओर प्रदाता आइकन पर क्लिक करके सीधे मॉडल सेटिंग्स भी खोल सकते हैं।

<br/>

**ग्लोब आइकन + भाषा कोड** ऐप इंटरफ़ेस भाषा, जैसे मेनू और बटन, बदलता है। यह **अनुवाद** में उपयोग की जाने वाली भाषाओं को **नहीं** बदलता है।

![Interface language selector](../images/screenshots/hi/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### इनपुट और आउटपुट पैनल

अधिकांश कार्यक्षेत्र बाईं ओर के **इनपुट** पैनल और दाईं ओर के **आउटपुट** पैनल का उपयोग करते हैं।

प्रत्येक पैनल निम्नलिखित भी दिखाता है:

| **इनपुट**                                                          | **आउटपुट**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - अक्षर गणना <br/>- शब्द गणना <br/>- पैराग्राफ गणना   <br/> | - कार्य पूरा होने में कितना समय लगा<br/>- **TPS** (प्रति सेकंड टोकन)<br/>- अक्षर, शब्द और पैराग्राफ गणना<br/>- उपयोग किया गया मॉडल |

यदि आप तकनीकी शब्दों के बारे में सोच रहे हैं:

- **टोकन** का अर्थ है पाठ का एक छोटा टुकड़ा। आप इसे एक शब्द के भाग या एक छोटे शब्द के रूप में समझ सकते हैं।
- **TPS** का अर्थ है कि मॉडल ने प्रति सेकंड कितने ऐसे पाठ टुकड़े संसाधित किए।

<br/>

आप प्रत्येक क्रिया की लागत (यदि उपलब्ध हो) और कुल लागत की भी निगरानी कर सकते हैं, विकल्प `क्रियाओं पर लागत की जानकारी दिखाएँ` को [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में सक्षम करके।

<a id="rewrite"></a>
## रीराइट

मुख्य अर्थ को बदले बिना शब्दावली में सुधार करने के लिए **रीराइट** का उपयोग करें।

![Rewrite workspace](../images/screenshots/hi/rewrite.png)

यह निम्नलिखित के लिए उपयोगी है:

- वर्तनी और व्याकरण ठीक करने के लिए (**वर्तनी और व्याकरण जाँचें**)
- पाठ को स्पष्ट बनाने के लिए (**स्पष्टता सुधारें**)
- एक ही चलाने में कई अलग-अलग पुनर्सूत्रीकरण के लिए (**वैकल्पिक संस्करण**)
- पाठ को अधिक औपचारिक या अनौपचारिक बनाने के लिए (**औपचारिक** / **अनौपचारिक**)
- पाठ को संक्षिप्त या विस्तारित करने के लिए (**संक्षिप्त करें** / **विस्तार करें**)
- पाठ को अधिक तकनीकी लगने के लिए (**तकनीकी बनाएँ**)

<br/>

> 💡 **टिप**<br/>
> जब आप "**वर्तनी और व्याकरण जाँचें**" मोड का उपयोग करते हैं, तो आउटपुट पैनल में (**कॉपी** के बगल में) **परिवर्तन दिखाएं** स्विच दिखाई देता है।
> अपने पाठ में लागू किए गए विशिष्ट सुधारों को दिखाने या छिपाने के लिए इसे चालू या बंद करें।

<a id="transform"></a>
## ट्रांसफ़ॉर्म

जब आप चाहते हैं कि एआई अनुदेशों के कस्टम सेट का पालन करे तो **ट्रांसफ़ॉर्म** का उपयोग करें।

![Transform workspace](../images/screenshots/hi/transform.png)

यह ऐप का सबसे लचीला क्षेत्र है। आप इसे निम्नलिखित कार्यों के लिए उपयोग कर सकते हैं:

- नोट्स का सारांश तैयार करना
- कच्चे पाठ को एक परिष्कृत ईमेल में बदलना
- मुख्य बिंदुओं को निकालना
- पाठ को एक विशिष्ट प्रारूप में परिवर्तित करना
- इनपुट पाठ के साथ कोई अन्य कस्टम गतिविधि

<br/>

<a id="run-an-existing-prompt"></a>
### मौजूदा प्रॉम्प्ट चलाएँ

1. **ट्रांसफ़ॉर्म** खोलें।
2. प्रॉम्प्ट सूची से एक प्रॉम्प्ट चुनें।
3. यदि **लक्ष्य** भाषा बॉक्स दिखाई दे, तो यदि आप चाहें तो एक भाषा चुनें।
4. **इनपुट** में पाठ टाइप या पेस्ट करें।
5. **ट्रांसफ़ॉर्म** पर क्लिक करें।
6. **आउटपुट** में परिणाम पढ़ें।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### यदि आपके पास अभी तक कोई प्रॉम्प्ट नहीं है

यदि आपकी प्रॉम्प्ट सूची खाली है, तो ट्रांसफ़ॉर्म वर्कस्पेस में **नमूना प्रॉम्प्ट लोड करें** पर क्लिक करें। निर्यात/आयात पंक्ति में [**सेटिंग्स** > **ट्रांसफ़ॉर्म प्रॉम्प्ट**](#transform-prompts) पर यही नियंत्रण हमेशा उपलब्ध रहता है। दोनों आपको त्वरित शुरुआत करने के लिए आंतरिक उदाहरण जोड़ते हैं।

<br/>

> ℹ️ **नोट**<br/>
> नमूना प्रॉम्प्ट अंग्रेजी में प्रदान किए गए हैं। उन्हें लोड करने के बाद, आप एक प्रॉम्प्ट को संपादित कर सकते हैं और इसे अपनी भाषा में अनुवाद करने के लिए **प्रॉम्प्ट अनुवाद करें** का उपयोग कर सकते हैं।

<br/>

<a id="create-a-prompt-quickly"></a>
### त्वरित रूप से एक प्रॉम्प्ट बनाएँ

एक प्रॉम्प्ट बनाने का सबसे तेज़ तरीका है:

1. **नया प्रॉम्प्ट** पर क्लिक करें।
2. **प्रॉम्प्ट उत्पन्न करें** पर क्लिक करें।
3. वर्णन करें कि आप चाहते हैं कि प्रॉम्प्ट क्या करे।
4. एक मॉडल चुनें।
5. ऐप को आपके लिए एक मसौदा बनाने दें।
6. मसौदे की समीक्षा करें और **सहेजें** पर क्लिक करें।

![Generate prompt](../images/screenshots/hi/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### एक प्रॉम्प्ट संपादित करें

जब आप कोई प्रॉम्प्ट बनाते या संपादित करते हैं, तो संपादक बाईं ओर दिखाई देता है और परीक्षण क्षेत्र दाईं ओर दिखाई देता है।

![Transform prompt editor](../images/screenshots/hi/transform-prompt-edit.png)

मुख्य फ़ील्ड हैं:

- **प्रॉम्प्ट नाम**: प्रॉम्प्ट सूची में दिखाया गया नाम।
- **प्रॉम्प्ट निर्देश (वैकल्पिक)**: एक छोटा संकेत जो प्रॉम्प्ट चलाते समय उपयोगकर्ता को दिखाया जाता है।
- **मॉडल भूमिका**: एआई को दी गई समग्र भूमिका, जैसे 'आप एक सहायक सहायक हैं।'
- **मॉडल निर्देश (प्रति पंक्ति एक)**: विशिष्ट नियम जो आप चाहते हैं कि एआई अनुसरण करे।
- **आउटपुट विवरण**: परिणाम का वर्णन करने वाला एक छोटा शब्द, जैसे 'सारांश' या 'रीराइट'।
- **तापमान (0.0 → 1.0)**: मॉडल कैसे व्यवहार करेगा; नीचे देखें।
- **लक्ष्य भाषा पूछें**: प्रॉम्प्ट चलाते समय लक्ष्य भाषा चयनकर्ता जोड़ता है।

यदि तकनीकी शब्द **तापमान** आपके लिए नया है, तो इसे इस तरह समझें:

- **कम** तापमान स्थिर, अधिक भविष्यवाणी योग्य परिणाम देता है।
- **उच्च** तापमान अधिक विविधता और रचनात्मकता देता है।

आप इसका भी उपयोग कर सकते हैं:

- **`प्रॉम्प्ट उत्पन्न करें`** एक सरल विवरण से एक नया मसौदा बनाने के लिए
- **`प्रॉम्प्ट में सुधार करें`** मौजूदा प्रॉम्प्ट को सुधारने के लिए
- **`प्रॉम्प्ट अनुवाद करें`** प्रॉम्प्ट फ़ील्ड का अनुवाद करने के लिए

<br/>

> ⚠️ **चेतावनी**<br/>
> **`वापस चलाने के लिए`** पर क्लिक करने से पहले **`सहेजें`** पर क्लिक करें। यदि आप बिना सहेजे वापस जाते हैं, तो आपके परिवर्तन खो जाएंगे।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### उपयोग करने से पहले एक प्रॉम्प्ट का परीक्षण करें

दाईं ओर परीक्षण पैनल आपको अपने प्रॉम्प्ट का परीक्षण नमूना पाठ के साथ करने की अनुमति देता है, इससे पहले कि आप इसे दैनिक कार्य में उपयोग करें।

यह तब उपयोगी होता है जब:

- आप एक नया प्रॉम्प्ट बना रहे हैं
- आप एक प्रॉम्प्ट के दो संस्करणों की तुलना कर रहे हैं
- आप टोन, लंबाई या आउटपुट प्रारूप की जांच करना चाहते हैं

<br/>

> ℹ️ **नोट**<br/>
> आप [**सेटिंग्स** > **ट्रांसफ़ॉर्म प्रॉम्प्ट**](#transform-prompts) में सहेजे गए प्रॉम्प्ट का निर्यात और आयात कर सकते हैं।

<br/>

<a id="dashboard-tabs"></a>
### डैशबोर्ड टैब

- **सारांश** आपको उपयोग और लागत का एक समेकित दृष्टिकोण प्रदान करता है। इसमें **समय के साथ उपयोग** (अनुवाद, पुनर्लेखन और ट्रांसफ़ॉर्म के लिए दिन के अनुसार संचित **कॉल गणना** के रूप में चित्रित) और **मॉडल द्वारा उपयोग** (ट्रांसफ़ॉर्म सहित प्रति मॉडल कुल **कॉल**) शामिल हैं।
- **उपयोग अनुसार** गतिविधि को अनुवाद भाषा, पुनर्लेखन मोड और ट्रांसफ़ॉर्म प्रॉम्प्ट के आधार पर विभाजित करता है।
- **मॉडल के अनुसार** दिखाता है कि आपने कौन से मॉडल का उपयोग किया और उनकी लागत क्या थी।
- **दिन के अनुसार** दैनिक कुल योग दिखाता है।
- **सभी कॉल** पूर्ण कॉल इतिहास दिखाता है और आपको इसे निर्यात करने की अनुमति देता है।

<a id="delete-stored-records-for-a-model"></a>
### किसी मॉडल के लिए संग्रहीत रिकॉर्ड हटाएँ

**मॉडल के अनुसार** या **सभी कॉल** में, आप "कचरा बिन" आइकन पर क्लिक करके किसी मॉडल के लिए संग्रहीत रिकॉर्ड हटा सकते हैं।

> ⚠️ **चेतावनी**<br/>
> संग्रहीत रिकॉर्ड हटाने की प्रक्रिया को पूर्ववत नहीं किया जा सकता। केवल तभी इसका उपयोग करें जब आपको यकीन हो कि आपको उस इतिहास की आवश्यकता नहीं है।

सभी डेटा हटाने या उनकी आयु के आधार पर रिकॉर्ड हटाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) पर जाएं। वहां आपको सभी संग्रहीत डेटा या केवल एक निश्चित तिथि से पुराने डेटा को हटाने के विकल्प मिलेंगे।

<a id="general-settings"></a>
### सामान्य सेटिंग्स

टाइपिंग व्यवहार, निष्पादन विवरण को **हिस्ट्री** के लिए संग्रहीत करना और दिखावट को नियंत्रित करने के लिए **सामान्य सेटिंग्स** का उपयोग करें।

**व्यवहार**

- **ENTER के लिए व्यवहार** चुनता है कि `Enter` कार्य चलाए या नई पंक्ति डाले।
- **पेस्ट करने पर ऑटो-अनुवाद** तुरंत टेक्स्ट पेस्ट करने पर अनुवाद शुरू करता है।
- **परिणाम ऑटो-कॉपी क्लिपबोर्ड पर** सफल परिणामों को स्वचालित रूप से कॉपी करता है।
- **रीयल-टाइम अनुवाद (टाइपिंग के दौरान)** टाइप करते समय अनुवाद करता है।
- **टाइमआउट (ms)** रीयल-टाइम अनुवाद के लिए प्रतीक्षा समय निर्धारित करता है।

**हिस्ट्री**

- **निष्पादन हिस्ट्री बनाए रखें** नियंत्रित करता है कि प्रत्येक अनुवाद, रीराइट और ट्रांसफ़ॉर्म साइडबार [**हिस्ट्री**](#history) दृश्य के लिए **इनपुट और आउटपुट पाठ** संग्रहीत करता है या नहीं। इसे बंद करने पर पुष्टि के लिए कहा जाता है; यदि आप पुष्टि करते हैं, तो संग्रहीत हिस्ट्री पाठ डेटाबेस से हटा दिया जाता है।
- **हिस्ट्री डेटा हटाएं** आपको आयु के आधार पर (उदाहरण के लिए कुछ महीनों से पुराना, या **सभी डेटा (साफ़ करें)**) **डेटा हटाएँ** का उपयोग करके संग्रहीत पाठ हटाने की अनुमति देता है। यह केवल **हिस्ट्री** दृश्य के लिए सहेजे गए निष्पादन पाठ को प्रभावित करता है; यह लागत या उपयोग कुल राशि को **नहीं** हटाता है। **लागत** डेटा को हटाने या कम करने के लिए [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) का उपयोग करें।

**दिखावट**

- **क्रियाओं पर लागत जानकारी दिखाएं** संचालन प्रति लागत (यदि उपलब्ध हो) और अनुवाद, रीराइट और ट्रांसफ़ॉर्म आउटपुट पैनल पर कुल लागत के प्रदर्शन को नियंत्रित करता है।
- **लागत भिन्न अंक** लागत दशमलव के प्रदर्शन को बदलता है।
- **केवल वेब:** **ऐप के चारों ओर मार्जिन दिखाएँ** इंटरफ़ेस के चारों ओर अतिरिक्त स्थान जोड़ता है।
- **फ़ॉन्ट फ़ैमिली** पाठ पैनल में लेखन फ़ॉन्ट बदलता है।
- **आकार** फ़ॉन्ट आकार बदलता है।

**कॉन्फ़िगरेशन बैकअप**

- **बैकअप में उपयोग डेटा शामिल करें** — जब सक्षम हो, तो ZIP में निष्पादन हिस्ट्री और API कॉल डेटा भी शामिल होता है।
- **कॉन्फ़िगरेशन बैकअप करें** — एकल ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` डिफ़ॉल्ट रूप से UTC में) बनाता है जिसमें `config.json`, `state.json`, वैकल्पिक एन्क्रिप्शन कुंजी, उपयोगकर्ता, पसंदीदा, कस्टम प्रॉम्प्ट और उपयोग डेटा शामिल होता है यदि आपने इसे शामिल करने का चयन किया है। सफल बैकअप के बाद, पुष्टि सहेजे गए फ़ाइल नाम को दिखाती है।
- **बैकअप से पुनर्स्थापित करें** — पहले एक **पुष्टि संवाद** खोलता है। संवाद के अंदर बैकअप ZIP चुनें (**ब्राउज़** / फ़ाइल पिकर या समर्थित जगहों पर ड्रैग-एंड-ड्रॉप), फिर विकल्पों की समीक्षा करें:
  - **उपयोग डेटा को पुनर्स्थापित करें** — जब उपयोग शामिल करके बैकअप लिया गया हो तो ZIP से उपयोग/हिस्ट्री आयात करें; यदि आप केवल सेटिंग्स और प्रॉम्प्ट चाहते हैं तो बंद छोड़ दें।
  - **पुनर्स्थापित करने से पहले पुराना उपयोग डेटा साफ़ करें** — बैकअप लागू करने से पहले इस स्थापना पर मौजूदा उपयोग/हिस्ट्री को हटा दें (वैकल्पिक; जब आप एक साफ़ प्रतिस्थापन चाहते हों तो उपयोग करें)।

वेब या डेस्कटॉप संस्करण में बनाए गए बैकअप दूसरे में पुनर्स्थापित किए जा सकते हैं। वेब संस्करण में डेस्कटॉप बैकअप को पुनर्स्थापित करते समय, डेटा व्यवस्थापक उपयोगकर्ता में पुनर्स्थापित किया जाएगा।

<a id="models"></a>
### मॉडल

टूलबार में कौन से मॉडल दिखाई दें यह चुनने के लिए **सेटिंग्स** > **मॉडल** का उपयोग करें।

![Settings Models tab](../images/screenshots/hi/settings-models.png)

पृष्ठ में दो सूचियाँ हैं:

- बाईं ओर **उपलब्ध मॉडल**
- दाईं ओर **चयनित मॉडल**

उपयोगी नियंत्रण में शामिल हैं:

- **मॉडल खोजें...** नाम से मॉडल खोजने के लिए
- **प्रदाता** चिप्स एक इंजन (OpenRouter, OpenAI, Ollama, …) के लिए सूची को सीमित करने के लिए
- **केवल मुफ़्त** केवल मुफ़्त मॉडल दिखाने के लिए
- **रीफ़्रेश** सूची को पुनः लोड करने के लिए
- **सभी विस्तृत करें** और **सभी संक्षिप्त करें** जब आप प्रदाता के अनुसार क्रमबद्ध कर रहे हों

मॉडल आईडी में प्रदाता उपसर्ग शामिल होता है (उदाहरण के लिए `openrouter/…` बनाम `openai/…`)। **OpenAI (OpenRouter)** बनाम **OpenAI (सीधा)** जैसे बैज दिखाते हैं कि ट्रैफ़िक कैसे रूट किया जा रहा है।

> ℹ️ **नोट**<br/>
> **OpenRouter बॉडी बिल्डर** (`openrouter/bodybuilder`) एक राउटर मॉडल है, सामान्य चैट मॉडल नहीं: इसकी प्रतिक्रिया JSON होती है जो OpenRouter API अनुरोध बॉडी का वर्णन करती है (उदाहरण के लिए `model` और `messages` के साथ एक `requests` सरणी)। यदि आप इसका उपयोग **अनुवाद करें**, **रीराइट**, या **ट्रांसफ़ॉर्म** के लिए करते हैं, तो आउटपुट पैनल तैयार पाठ के बजाय उस JSON को दिखाएगा। इन कार्यों के लिए एक सामान्य पाठ मॉडल चुनें। OpenRouter पर [बॉडी बिल्डर मॉडल पृष्ठ](https://openrouter.ai/openrouter/bodybuilder) देखें।

क्रियाएं:

- मॉडल जोड़ने के लिए, **जोड़ें** पर क्लिक करें या एंट्री में कहीं भी क्लिक करें।

- मॉडल हटाने के लिए, **चयनित मॉडल** में इसके बगल में **X** पर क्लिक करें या उपलब्ध मॉडल में एंट्री पर **चयनित** पर क्लिक करें।

- सूची साफ़ करने के लिए, **सभी अचयनित करें** पर क्लिक करें। आवश्यक मुफ़्त मॉडल सूची में बना रहेगा।

<br/>

> ℹ️ **नोट**<br/>
> यदि आप OpenRouter में तुरंत क्रेडिट जोड़ना नहीं चाहते हैं, तो **केवल मुफ़्त** सक्षम करके शुरू करें और मुफ़्त मॉडल चुनें (क्रेडिट कार्ड की आवश्यकता नहीं है)। आप किसी भी API कुंजी के बिना मॉडल को स्थानीय रूप से चलाने के लिए Ollama का उपयोग भी कर सकते हैं।

<a id="languages"></a>
### भाषाएँ

ऐप में उपयोग की जाने वाली भाषा सूचियों को व्यवस्थित करने के लिए **सेटिंग्स** > **भाषाएँ** का उपयोग करें।

- **शीर्ष भाषाएँ** **अनुवाद करें** और **ट्रांसफ़ॉर्म** में भाषा सूचियों के ऊपर के पास पिन की गई होती हैं।
- **कस्टम भाषा** आपको बिल्ट-इन सूची में नहीं मौजूद एक भाषा जोड़ने की अनुमति देती है।

यदि आप एक कस्टम भाषा जोड़ते हैं, तो यह बिल्ट-इन विकल्पों के साथ भाषा चयनकर्ताओं में दिखाई देती है।

<a id="cost-tracking"></a>
### लागत ट्रैकिंग

लागत जानकारी प्रबंधित करने के लिए **सेटिंग्स** > **लागत ट्रैकिंग** का उपयोग करें।

- **कुल लागत** चल रहे कुल योग को दिखाता है।
- **मान कॉपी करें** कुल योग को क्लिपबोर्ड पर कॉपी करता है।
- **लागत रीसेट करें** संग्रहीत कुल योग को शून्य पर रीसेट करता है।
- **API कुंजी उपयोग के साथ सिंक करें** कुल योग को आपके OpenRouter खाते द्वारा रिपोर्ट किए गए उपयोग के अनुरूप सेट करता है (केवल OpenRouter)।
- **API Key उपयोग** OpenRouter उपयोग विवरण दिखाता है, यदि उपलब्ध हो।
- **लागत डेटा हटाएँ** सभी डेटा या केवल चयनित तिथि से पुराने प्रविष्टियाँ हटा देता है।

**लागत ट्रैकिंग:** जब आप OpenRouter मॉडल का उपयोग करते हैं, तो ऐप OpenRouter से लागत जानकारी के आधार पर आपके वास्तविक उपयोग और खर्च को दिखाता है। अन्य सभी प्रदाताओं के लिए, ऐप OpenRouter द्वारा प्रकाशित मूल्यों का उपयोग करके लागत का अनुमान लगाता है, यदि मूल्य अनुपलब्ध है, तो अनुमान शून्य हो सकता है।

<br/>

> ℹ️ **नोट**<br/>
>  **सभी लागत आंकड़े केवल आपके संदर्भ के लिए अनुमान हैं, आधिकारिक बिलिंग स्टेटमेंट नहीं।**

<br/>

> ⚠️ **चेतावनी**<br/>
> डेटा हटाने की क्रिया को पूर्ववत नहीं किया जा सकता। हटाने से पहले, सुनिश्चित करें कि आप अपने डेटा का बैकअप ले लें या [**हिस्ट्री**](#history) के माध्यम से या [**डैशबोर्ड** > **सभी कॉल**](#dashboard-tabs) के माध्यम से इसे निर्यात कर लें, अन्यथा यह स्थायी रूप से खो जाएगा।
> प्रत्येक API कॉल प्रविष्टि से संबंधित सभी इनपुट/आउटपुट इतिहास भी हटा दिया जाएगा।

<br/>

<a id="transform-prompts"></a>
### ट्रांसफ़ॉर्म प्रॉम्प्ट

बल्क में प्रॉम्प्ट प्रबंधित करने के लिए **सेटिंग्स** > **ट्रांसफ़ॉर्म प्रॉम्प्ट** का उपयोग करें।

आप कर सकते हैं:

- अपने सहेजे गए प्रॉम्प्ट की समीक्षा करें  
- प्रॉम्प्ट हटाएँ  
- फ़ाइल से प्रॉम्प्ट आयात करें  
- बैकअप या साझाकरण के लिए प्रॉम्प्ट निर्यात करें  
- प्रॉम्प्ट सूची में नमूना प्रॉम्प्ट लोड करें

<a id="users"></a>
### उपयोगकर्ता

वेब संस्करण में उपयोगकर्ता खातों को प्रबंधित करने के लिए **उपयोगकर्ता** का उपयोग करें। आप उपयोगकर्ता जोड़ सकते हैं, उनके विवरण अपडेट कर सकते हैं, पासवर्ड रीसेट कर सकते हैं और खाते हटा सकते हैं।

<br/>

<a id="api-config"></a>
### API कॉन्फ़िग

समर्थित प्रदाता हैं: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, और **Ollama** (बेस URL के माध्यम से स्थानीय मॉडल)। आपको केवल उन प्रदाताओं को कॉन्फ़िगर करने की आवश्यकता है जिनका आप उपयोग करते हैं।

**वेब एप्लिकेशन: केवल प्रशासक**

API कुंजियों को सिस्टम या डॉकर पर्यावरण चर के माध्यम से कॉन्फ़िगर किया जाता है — उन्हें वेब UI में दर्ज नहीं किया जाता है। यह पृष्ठ दिखाता है कि किन प्रदाताओं के लिए कुंजी कॉन्फ़िगर की गई है और आपको **`टेस्ट`** बटन पर क्लिक करके प्रत्येक का परीक्षण करने की अनुमति देता है।

<br/>

> ℹ️ **नोट**<br/>
> किसी API कुंजी को बदलने के लिए, अपने सिस्टम या डॉकर कॉन्फ़िगरेशन में पर्यावरण चर को अपडेट करें और सर्वर या कंटेनर को पुनः आरंभ करें।

> ℹ️ **नोट**<br/>
> **कॉन्फ़िगरेशन बैकअप** ([**सामान्य सेटिंग्स** → कॉन्फ़िगरेशन बैकअप](#general-settings) देखें) ZIP के `config.json` में **हल की गई** प्रदाता कुंजियाँ एम्बेड कर सकते हैं। उस ZIP को पुनर्स्थापित करने से उन कुंजियों को सर्वर की स्थायी कॉन्फ़िग फ़ाइल में वापस नहीं कॉपी किया जाता है — जैसा कि वहाँ वर्णित है, लाइव कुंजियाँ अभी भी पर्यावरण और मौजूदा फ़ाइल स्थिति से आती हैं।

<br/>

**डेस्कटॉप एप्लिकेशन**

प्रत्येक प्रदाता के लिए API कुंजियाँ संग्रहीत करने के लिए **API कॉन्फ़िग** का उपयोग करें। Ollama के लिए, API कुंजी के बजाय **बेस URL** दर्ज करें।

<br/>

> 💡 **टिप** <br/>
> यदि आप कोई API कुंजी का उपयोग नहीं करना चाहते या उपयोग के लिए भुगतान नहीं करना चाहते हैं, तो आप अपने मशीन पर मुफ़्त में मॉडल (जैसे `translategemma:4b`) चलाने के लिए [Ollama डाउनलोड](https://ollama.com) कर सकते हैं। वैकल्पिक रूप से, आप उनके मुफ़्त मॉडल का उपयोग करने के लिए कोई मुफ़्त OpenRouter खाता बना सकते हैं (क्रेडिट कार्ड की आवश्यकता नहीं), या Cerebras, Google, Groq, या Mistral AI से मुफ़्त API कुंजी प्राप्त कर सकते हैं।

<br/>

- केवल उन प्रदाताओं को जोड़ें जिनकी आपको आवश्यकता है। **सेटिंग्स** > **मॉडल** में, प्रत्येक मॉडल ID प्रदाता से शुरू होता है (उदाहरण के लिए `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

API कुंजी जोड़ने के लिए, पाठ फ़ील्ड में मान दर्ज करें और **`सेव`** पर क्लिक करें। मौजूदा कुंजी को बदलने के लिए, **`संपादित करें`** पर क्लिक करें। यह सत्यापित करने के लिए कि कुंजी काम कर रही है, **`टेस्ट`** पर क्लिक करें। Ollama बेस URL के लिए, कनेक्शन की जाँच करने के लिए हमेशा **`टेस्ट`** पर क्लिक करें।

<br/>

> ℹ️ **नोट**<br/>
> आप एक API कुंजी के वर्तमान मान को नहीं देख सकते। आप केवल **`संपादित करें`** बटन का उपयोग करके इसे बदल सकते हैं।
> API कुंजियों को कॉन्फ़िगरेशन में एन्क्रिप्टेड रूप में संग्रहीत किया जाता है।

<a id="common-issues"></a>
## सामान्य समस्याएँ

यदि कुछ अपेक्षानुसार काम नहीं कर रहा है, तो पहले निम्नलिखित बिंदुओं की जाँच करें।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ऐप टेक्स्ट का अनुवाद, रीराइट या ट्रांसफ़ॉर्म नहीं करेगा

जाँचें कि:

- आपने टूलबार में एक मॉडल चयनित किया है  
- कम से कम एक मॉडल [**सेटिंग्स** > **मॉडल**](#models) में सूचीबद्ध है  
- आपकी API सेटअप काम कर रही है

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं:

1. [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें।  
2. जाँचें कि कम से कम एक API कुंजी सहेजी गई है।  
3. पुष्टि करने के लिए प्रदाता के बगल में **टेस्ट** पर क्लिक करें कि कुंजी काम कर रही है।

<br/>

<a id="the-model-list-is-empty"></a>
### मॉडल सूची खाली है

[**सेटिंग्स** > **मॉडल**](#models) खोलें और **रीफ़्रेश** पर क्लिक करें।

यदि आवश्यक हो:

- कोई मॉडल खोजें  
- **केवल मुफ़्त** चालू करें  
- एक या अधिक मॉडल **चयनित मॉडल** में जोड़ें

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### परिणाम बहुत धीमा या बहुत महंगा है

इनमें से एक या अधिक का प्रयास करें:

- एक अलग मॉडल चुनें  
- छोटा इनपुट उपयोग करें  
- [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में **रीयल-टाइम अनुवाद (टाइपिंग के दौरान)** बंद करें  
- सरल कार्यों के लिए मुफ़्त मॉडल का उपयोग करें (देखें [मॉडल](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### इंटरफ़ेस गलत भाषा में है

[टूलबार](#toolbar) में ग्लोब आइकन पर क्लिक करें और अपनी पसंदीदा **इंटरफ़ेस भाषा** चुनें।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### टेक्स्ट बहुत छोटा या पढ़ने में कठिन है

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और बदलें:

- **फ़ॉन्ट फ़ैमिली**  
- **आकार**

<br/>

<a id="dashboard-charts-are-empty"></a>
### डैशबोर्ड चार्ट खाली हैं

यह सामान्य है यदि:

- आप केवल **मुफ़्त मॉडल** का उपयोग करते हैं और आप **लागत** आंकड़ों को देख रहे हैं (वे शून्य हो सकते हैं); **सारांश** पर **उपयोग** कॉल-गणना चार्ट को चयनित अवधि से डेटा की आवश्यकता होती है  
- चयनित **समय फ़िल्टर** उस अवधि को शामिल नहीं करता जब कॉल की गई थीं — जाँच के लिए **सभी** का प्रयास करें

यदि **सभी** का चयन करने के बाद भी चार्ट खाली हैं, तो पुष्टि करें कि कॉल [**हिस्ट्री**](#history) या **सभी कॉल** टैब में दिखाई दे रही हैं।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### लागत "उपलब्ध नहीं" दिखाती है या गलत लगती है

जब आप **OpenRouter** के माध्यम से मॉडल का उपयोग करते हैं, तो ऐप आपके द्वारा OpenRouter द्वारा रिपोर्ट किए गए वास्तविक खर्च को दिखाता है।

**अन्य प्रदाताओं** (OpenAI सीधा, Anthropic सीधा, आदि) के लिए, लागत OpenRouter द्वारा प्रकाशित मूल्य डेटा से अनुमानित होती है। यदि किसी मॉडल के लिए कोई मिलता-जुलता मूल्य नहीं मिलता है, तो लागत **उपलब्ध नहीं** के रूप में दिखाई देगी और आपके कुल योग में नहीं जुड़ेगी।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### कुल लागत आपके प्रदाता के बिल से मेल नहीं खाती

ऐप में सभी लागत आंकड़े केवल **संदर्भ के लिए अनुमानित** हैं, आधिकारिक बिलिंग विवरण नहीं।

कुल योग को आपके वास्तविक OpenRouter खर्च के करीब लाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) खोलें और **API कुंजी उपयोग के साथ सिंक करें** पर क्लिक करें।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### साइडबार में हिस्ट्री पेज गायब है

**निष्पादन हिस्ट्री बनाए रखें** बंद हो सकता है। [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और इसे सक्षम करें। ध्यान दें कि इसे चालू करने से पहले हटाए गए इतिहास डेटा को पुनर्स्थापित नहीं किया जाता है।

<br/>

<a id="web-app-session-expired"></a>
### वेब ऐप: अप्रत्याशित रूप से लॉग इन पेज पर पुनर्निर्देशित किया जा रहा है

आपका सत्र समाप्त हो गया हो सकता है। फिर से लॉग इन करें। यदि यह बार-बार होता है, तो सत्र आयु सेटिंग्स के लिए सर्वर कॉन्फ़िगरेशन की जांच करें।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### वेब व्यवस्थापक: पासवर्ड भूल गए या खो गए

यह **स्व-होस्टेड वेब ऐप** (Docker) पर लागू होता है, डेस्कटॉप (Electron) ऐप पर नहीं।

- यदि कोई अन्य व्यवस्थापक अभी भी साइन इन कर सकता है, तो वे [**सेटिंग्स** > **उपयोगकर्ता**](#users) खोल सकते हैं, खाता चुन सकते हैं और वहां **नया पासवर्ड** सेट कर सकते हैं।
- यदि आप **लॉक आउट** हैं लेकिन मशीन या कंटेनर पर **शेल एक्सेस** है, तो इमेज के साथ आने वाले हेल्पर का उपयोग करके पासवर्ड रीसेट करें (डिफ़ॉल्ट नाम बदलने पर `transrewrt` को बदलें, और यदि पासवर्ड में स्पेस या विशेष अक्षर हैं तो पासवर्ड को उद्धृत करें):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

यदि आपने कभी अन्य खाते नहीं बनाए हैं, तो डिफ़ॉल्ट व्यवस्थापक उपयोगकर्ता नाम `admin` है। जब आप केवल एक तर्क पास करते हैं, तो इसे `admin` के लिए नया पासवर्ड माना जाता है।

यदि आप डॉकर के बजाय एक **स्रोत चेकआउट** से चला रहे हैं, तो उपयोग करें:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

स्क्रिप्ट SQLite डेटाबेस में उपयोगकर्ता रिकॉर्ड को अपडेट करता है (और यदि गायब है तो `admin` उपयोगकर्ता बना सकता है)। पुनर्स्थापित करने के बाद, नए पासवर्ड के साथ साइन इन करें।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### डैशबोर्ड अन्य उपयोगकर्ताओं के लिए कोई डेटा नहीं दिखाता है (वेब)

केवल **व्यवस्थापक** **उपयोगकर्ता** फ़िल्टर के माध्यम से सभी उपयोगकर्ताओं के डेटा को देख सकते हैं। नियमित उपयोगकर्ता केवल अपनी गतिविधि देखते हैं।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### मैंने एक प्रॉम्प्ट बदल दिया और संपादन खो दिए

प्रॉम्प्ट संपादित करते समय, हमेशा **सहेजें** पर क्लिक करें और फिर **रन पर वापस जाएँ** पर क्लिक करें।

<a id="quick-tips"></a>
## त्वरित सुझाव

- अपनी सेटअप की जांच सुनिश्चित करने के लिए [**अनुवाद करें**](#translate) से शुरुआत करें, उसके बाद [**रीराइट**](#rewrite) या [**ट्रांसफ़ॉर्म**](#transform) पर जाएँ।
- दैनिक शब्दावली में सुधार के लिए [**रीराइट**](#rewrite) का उपयोग करें।
- किसी विशिष्ट कार्य के लिए दोहराए जाने वाले कार्यप्रवाह की आवश्यकता होने पर [**ट्रांसफ़ॉर्म**](#transform) का उपयोग करें।
- उपयोग और लागत पर नज़र रखने के लिए [**डैशबोर्ड**](#dashboard) का उपयोग करें।
- पिछले संचालन और उनके पूर्ण इनपुट/आउटपुट पाठ की समीक्षा करने के लिए [**हिस्ट्री**](#history) का उपयोग करें।
- यदि आप एक प्रॉम्प्ट लाइब्रेरी बना रहे हैं जिसे आप सुरक्षित रखना चाहते हैं (देखें [ट्रांसफ़ॉर्म प्रॉम्प्ट](#transform-prompts)) या दूसरों के साथ साझा करना चाहते हैं, तो नियमित रूप से प्रॉम्प्ट निर्यात करें।
