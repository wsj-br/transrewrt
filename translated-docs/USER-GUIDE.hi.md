# उपयोगकर्ता मार्गदर्शिका

<br/>

<a id="introduction"></a>

## परिचय

Transrewrt आपको तीन मुख्य तरीकों से पाठ के साथ काम करने में मदद करता है:

- **अनुवाद करें** - एक भाषा से दूसरी भाषा में पाठ को परिवर्तित करना।
- **पुनः लिखें** - अलग शैली में पाठ को फिर से लिखना, जैसे स्पष्ट, छोटा या अधिक औपचारिक।
- **रूपांतरित करें** - उपयोगकर्ता द्वारा परिभाषित AI निर्देश, जिन्हें संकेत (प्रॉम्प्ट) कहा जाता है, का उपयोग कर पाठ को संसाधित करना।

<br/>

यह गाइड स्थापित और चल रहे ऐप का उपयोग कैसे करें, इसकी व्याख्या करता है। स्थापना के चरणों के लिए, मुख्य **[README](README.hi.md)** देखें।

<br/>

> ℹ️ **नोट**<br/>
> Transrewrt Windows और Linux के लिए डेस्कटॉप ऐप के रूप में उपलब्ध है, और स्वयं-होस्ट किए गए वेब ऐप के रूप में भी। यह गाइड ऐप के दैनिक उपयोग पर ध्यान केंद्रित करता है। जहां कुछ केवल एक संस्करण पर लागू होता है, वह स्पष्ट रूप से चिह्नित किया गया है।

<a id="before-you-start"></a>

## शुरू करने से पहले

ट्रांसरीवर्ट का उपयोग करने के लिए, आपको कम से कम एक एआई प्रदाता तक पहुँच की आवश्यकता है। समर्थित प्रदाता हैं: [OpenRouter](https://openrouter.ai) (जो कई मॉडल्स को समेकित करता है), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, और स्थानीय मॉडल्स के लिए [Ollama](https://ollama.com)।

शुरुआत करने के लिए आपको भुगतान योग्य मॉडल का चयन करने की आवश्यकता नहीं है। जैसे ही आप अपनी OpenRouter API कुंजी जोड़ते हैं, ऐप स्वतः ही एक आंतरिक **मुफ्त** OpenRouter विकल्प सक्षम कर देता है। इससे आप तुरंत पाठ का अनुवाद, पुनःलेखन और रूपांतरण शुरू कर सकते हैं। वैकल्पिक रूप से, आप Cerebras, Google, Groq, या Mistral AI से एक मुफ्त API कुंजी भी प्राप्त कर सकते हैं।

सरल भाषा में:

- एक **मॉडल** वह एआई इंजन है जो काम करता है। मॉडल्स को एक **प्रदाता उपसर्ग** के साथ सूचीबद्ध किया गया है (उदाहरण के लिए `openrouter/…`, `openai/…`, `ollama/…`)।
- एक **API कुंजी** (या, Ollama के लिए, एक **बेस URL**) वह साधन है जिसके द्वारा ऐप उस प्रदाता तक पहुँचता है।

यदि आप **डेस्कटॉप ऐप** का उपयोग कर रहे हैं, तो प्रत्येक प्रदाता के लिए [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) में कुंजियाँ जोड़ें। केवल OpenRouter के उपयोग हेतु नीचे दिए गए [एक API कुंजी प्राप्त करने की विधि](#how-to-get-an-api-key-desktop-app) देखें। यदि आप एक API कुंजी का उपयोग नहीं करना चाहते हैं, तो आप Ollama को [ollama.com](https://ollama.com) से स्थापित कर सकते हैं और `translategemma:4b` जैसे स्थानीय मॉडल का उपयोग कर सकते हैं।

यदि आप **वेब संस्करण** का उपयोग कर रहे हैं, तो सर्वर के मालिक वातावरणीय चर (एन्वायरनमेंट वेरिएबल्स) के माध्यम से प्रदाताओं को कॉन्फ़िगर करते हैं, इसलिए आप आवेदन में सीधे API कुंजियाँ दर्ज नहीं कर सकते।

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>

### निःशुल्क OpenRouter API कुंजी कैसे प्राप्त करें (डेस्कटॉप ऐप)

अगर आप डेस्कटॉप ऐप का उपयोग कर रहे हैं, तो इन चरणों का पालन करें:

1. अपने वेब ब्राउज़र में [OpenRouter](https://openrouter.ai) पर जाएँ।
2. एक खाता बनाएं या साइन इन करें।
3. [Keys](https://openrouter.ai/keys) पृष्ठ खोलें।
4. एक नई API कुंजी बनाने के लिए बटन पर क्लिक करें।
5. भविष्य में पहचानने के लिए कुंजी का नाम दें।
6. नई API कुंजी की प्रतिलिपि बनाएँ।
7. Transrewrt पर वापस जाएँ और **सेटिंग्स** > **API कॉन्फ़िग** खोलें।
8. **OpenRouter API कुंजी** में कुंजी को पेस्ट करें (**सेटिंग्स** > **API कॉन्फ़िग** के अंतर्गत)।
9. सुनिश्चित करने के लिए कि यह काम करती है, **OpenRouter कुंजी का परीक्षण करें** पर क्लिक करें।

<a id="getting-started"></a>

## शुरुआत करना

अगर आप Transrewrt का पहली बार उपयोग कर रहे हैं, तो इस क्रम का पालन करें:

1. ऐप खोलें।
2. यदि आवश्यक हो, तो ग्लोब आइकन से अपनी **इंटरफ़ेस भाषा** चुनें।
3. यदि आप **डेस्कटॉप ऐप** का उपयोग कर रहे हैं, तो [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें, कम से कम एक प्रदाता के लिए एक API कुंजी जोड़ें (उदाहरण के लिए OpenRouter), और सत्यापित करने के लिए **परीक्षण** पर क्लिक करें कि यह काम करती है।
4. [**सेटिंग्स** > **मॉडल**](#models) खोलें और **चयनित मॉडल** में एक या अधिक मॉडल जोड़ें।
5. [**सेटिंग्स** > **भाषाएँ**](#languages) खोलें और यदि आप चाहते हैं कि आपकी सबसे अधिक उपयोग की जाने वाली भाषाएँ पहले दिखाई दें, तो अपनी **शीर्ष भाषाएँ** चुनें।
6. **अनुवाद** पर जाएं और सभी कार्यों की पुष्टि करने के लिए एक साधारण अनुवाद चलाएं।
7. एक बार यह काम करने लगे, तो **पुनर्लेखन** और फिर **रूपांतरण** का प्रयास करें।

इस क्रम का अनुसरण करना महत्वपूर्ण है। यह सबसे आम पहली बार के उपयोग की समस्या से बचाता है: ऐप के पास कार्यशील API कनेक्शन या चयनित मॉडल होने से पहले कार्य चलाने का प्रयास करना।

### टूलबार

ऐप में आप जहाँ भी हों, टूलबार में थोड़ा बदलाव होता है।

- बाईं ओर, यह वर्तमान पृष्ठ का नाम दिखाता है।
- दाईं ओर, यहां **मॉडल सिलेक्टर** और **इंटरफ़ेस भाषा** नियंत्रण दिख रहा है।

**मॉडल सिलेक्टर** आपको वर्तमान कार्य के लिए कौन सा एआई इंजन उपयोग करना है चुनने की सुविधा देता है।

  ![मॉडल सिलेक्टर](../images/screenshots/hi/model-selector.png)

कुछ मुफ्त मॉडल्स हमेशा उपलब्ध नहीं हो सकते हैं — कभी-कभी वे ऑफलाइन हो सकते हैं या उपयोग की सीमा हो सकती है। ऐसे में, ऐप उस मॉडल को उपलब्ध सूची से स्वचालित रूप से हटा देगा। जिन मॉडल्स को दिखाया जाए इसे नियंत्रित करने के लिए, [**सेटिंग्स** > **मॉडल्स**](#models) पर जाएं और अपनी मॉडल सूची को संपादित करें।
आप टूलबार में मॉडल नाम के बाईं ओर मौजूद प्रदाता आइकन पर क्लिक करके सीधे मॉडल सेटिंग्स भी खोल सकते हैं।

<br/>

**भाषांतर प्रतीक + भाषा कोड** ऐप इंटरफ़ेस की भाषा, जैसे मेनू और बटन, को बदलता है। यह **अनुवाद** में उपयोग होने वाली अनुवाद भाषाओं को **नहीं** बदलता है।

![इंटरफ़ेस भाषा चयनकर्ता](../images/screenshots/hi/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>

### इनपुट और आउटपुट पैनल

अधिकांश कार्यस्थलों में बाईं ओर का **इनपुट** पैनल और दाईं ओर का **आउटपुट** पैनल उपयोग किया जाता है।

प्रत्येक पैनल दिखाता है:

| **इनपुट**                                                          | **आउटपुट**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - अक्षर गणना <br/>- शब्द गणना <br/>- पैराग्राफ गणना   <br/>         | - कार्य पूरा करने में लगा समय<br/>- **TPS** (प्रति सेकंड टोकन)<br/>- अक्षर, शब्द और पैराग्राफ गणना<br/>- उपयोग किया गया मॉडल |

यदि आप तकनीकी शब्दों के बारे में सोच रहे हैं:

- **टोकन** का अर्थ है पाठ का एक छोटा टुकड़ा। आप इसे एक शब्द के भाग या एक छोटे शब्द के रूप में समझ सकते हैं।
- **TPS** का अर्थ है कि मॉडल ने प्रति सेकंड उन पाठ के टुकड़ों में से कितने को संसाधित किया।

<br/>

आप प्रत्येक क्रिया की लागत (यदि उपलब्ध हो) और कुल लागत को भी मॉनिटर कर सकते हैं, विकल्प सक्षम करके [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में `क्रियाओं पर लागत जानकारी दिखाएं`।

## अनुवाद करें

जब आप किसी एक भाषा से दूसरी भाषा में पाठ बदलना चाहते हैं, तो **अनुवाद** का उपयोग करें।

<a id="translate-text"></a>

### पाठ का अनुवाद करें

1. **अनुवाद** खोलें।
2. **से** में एक भाषा चुनें।
3. **के लिए** में एक भाषा चुनें।
4. टूलबार में एक मॉडल चुनें।
5. **इनपुट** में पाठ टाइप या पेस्ट करें।

7. **आउटपुट** में परिणाम पढ़ें।
8. यदि आप परिणाम की प्रतिलिपि बनाना चाहते हैं, तो कॉपी बटन का उपयोग करें।

- **से** एक विशिष्ट भाषा या **भाषा का पता लगाएँ** हो सकता है।
- **को** वह भाषा है जिसमें आप परिणाम चाहते हैं।

- **परिणाम को क्लिपबोर्ड पर स्वत: कॉपी करें** सफल अनुवाद के बाद परिणाम को स्वचालित रूप से कॉपी कर देता है।

## पुनःलेखन

उस समय **पुनःलेखन** का उपयोग करें जब आप मुख्य अर्थ को बदले बिना शब्दों में सुधार करना चाहते हैं।

![पुनःलेखन कार्यक्षेत्र](../images/screenshots/hi/rewrite.png)

यह निम्नलिखित उद्देश्यों के लिए उपयोगी है:

- वर्तनी और व्याकरण में सुधार (**वर्तनी और व्याकरण की जाँच करें**)
- पाठ को स्पष्ट बनाने के लिए (**स्पष्टता में सुधार करें**)
- एक ही बार में कई अलग-अलग पुनर्गठन (**वैकल्पिक संस्करण**)
- पाठ को अधिक औपचारिक या अनौपचारिक बनाने के लिए (**औपचारिक** / **अनौपचारिक**)
- पाठ को संक्षिप्त या विस्तारित करना (**संक्षिप्त करें** / **विस्तार करें**)
- पाठ को अधिक तकनीकी बनाना (**तकनीकी बनाएँ**)

<br/>

> 💡 **सुझाव**<br/>
> जब आप "**वर्तनी और व्याकरण की जाँच करें**" मोड का उपयोग करते हैं, तो आउटपुट पैनल में (**कॉपी** के पास) **परिवर्तन दिखाएँ** स्विच दिखाई देता है।
> अपने पाठ में लागू विशिष्ट सुधारों को दिखाने या छिपाने के लिए इसे चालू या बंद करें।

<a id="transform"></a>

## रूपांतरित करें

जब आप चाहते हैं कि AI अपने स्वयं के निर्देशों का पालन करे, तो **रूपांतरित करें (Transform)** का उपयोग करें।

![ट्रांसफॉर्म कार्यस्थल](../images/screenshots/hi/transform.png)

यह ऐप का सबसे लचीला हिस्सा है। आप इसका उपयोग निम्नलिखित कार्यों जैसे के लिए कर सकते हैं:

- नोट्स का सारांश निकालना
- कच्चे पाठ को सुधरे हुए ईमेल में बदलना
- मुख्य बिंदुओं को निकालना
- पाठ को किसी विशिष्ट प्रारूप में परिवर्तित करना
- इनपुट पाठ के साथ कोई भी अन्य अनुकूल कार्य

<br/>

<a id="run-an-existing-prompt"></a>

### मौजूदा प्रॉम्प्ट चलाएँ

1. **ट्रांसफॉर्म** खोलें।
2. प्रॉम्प्ट सूची से एक प्रॉम्प्ट चुनें।
3. यदि एक **लक्ष्य** भाषा बॉक्स दिखाई दे, तो आवश्यकता होने पर एक भाषा चुनें।
4. **इनपुट** में पाठ टाइप करें या पेस्ट करें।
5. **ट्रांसफॉर्म** पर क्लिक करें।
6. **आउटपुट** में परिणाम पढ़ें।

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### यदि आपके पास अभी तक कोई प्रॉम्प्ट नहीं हैं

यदि आपकी प्रॉम्प्ट सूची खाली है, तो ट्रांसफॉर्म वर्कस्पेस में **नमूना प्रॉम्प्ट लोड करें** पर क्लिक करें। यही विकल्प सदैव [**सेटिंग्स** > **ट्रांसफॉर्म प्रॉम्प्ट्स**](#transform-prompts) में निर्यात/आयात पंक्ति पर उपलब्ध होता है। दोनों अंतर्निहित उदाहरण जोड़ते हैं ताकि आप त्वरित शुरुआत कर सकें।

<br/>

> ℹ️ **नोट**<br/>
> नमूना प्रॉम्प्ट अंग्रेजी में उपलब्ध कराए जाते हैं। उन्हें लोड करने के बाद, आप किसी प्रॉम्प्ट को संपादित कर सकते हैं और इसे अपनी भाषा में अनुवादित करने के लिए **प्रॉम्प्ट अनुवाद करें** का उपयोग कर सकते हैं।

<br/>

<a id="create-a-prompt-quickly"></a>

### त्वरित रूप से एक प्रॉम्प्ट बनाएँ

एक प्रॉम्प्ट बनाने का सबसे तेज़ तरीका है:

1. **नया प्रॉम्प्ट** पर क्लिक करें।
2. **प्रॉम्प्ट उत्पन्न करें** पर क्लिक करें।
3. वर्णन करें कि आप चाहते हैं कि प्रॉम्प्ट क्या करे।
4. एक मॉडल चुनें।
5. ऐप को आपके लिए एक ड्राफ्ट बनाने दें।
6. ड्राफ्ट की समीक्षा करें और **सहेजें** पर क्लिक करें।

![प्रॉम्प्ट उत्पन्न करें](../images/screenshots/hi/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>

### एक प्रॉम्प्ट में संपादन करें

जब आप कोई प्रॉम्प्ट बनाते हैं या संपादित करते हैं, तो संपादक बाईं ओर दिखाई देता है और दाईं ओर एक परीक्षण क्षेत्र दिखाई देता है।

![ट्रांसफॉर्म प्रॉम्प्ट संपादक](../images/screenshots/hi/transform-prompt-edit.png)

मुख्य फ़ील्ड्स हैं:

- **प्रॉम्प्ट का नाम**: प्रॉम्प्ट सूची में दिखाया गया नाम।
- **प्रॉम्प्ट निर्देश (वैकल्पिक)**: एक छोटी सूचना जो प्रॉम्प्ट चलाने पर उपयोगकर्ता को दिखाई जाती है।
- **मॉडल भूमिका**: कृत्रिम बुद्धिमत्ता के लिए निर्धारित समग्र भूमिका, जैसे 'आप एक सहायक सहायक हैं।'
- **मॉडल निर्देश (प्रति पंक्ति एक)**: विशिष्ट नियम जो आप चाहते हैं कि एआई अनुसरण करे।
- **आउटपुट विवरण**: परिणाम का वर्णन करने वाला एक छोटा शब्द, जैसे 'सारांश' या 'पुनःलेखन'।
- **तापमान (0.0 → 1.0)**: मॉडल के व्यवहार का तरीका; नीचे देखें।
- **लक्ष्य भाषा माँगें**: जब प्रॉम्प्ट चलाया जाता है तो लक्ष्य भाषा चयनकर्ता जोड़ता है।

यदि तकनीकी शब्द **तापमान** आपके लिए नया है, तो इसे इस प्रकार समझें:

- एक **निम्न** तापमान स्थिर और अधिक भविष्यवाणी योग्य परिणाम देता है।

- एक **उच्चतर** तापमान अधिक विविधता और रचनात्मकता देता है।

आप इसका भी उपयोग कर सकते हैं:

- **`प्रॉम्प्ट उत्पन्न करें`** एक साधारण विवरण से नया मसौदा बनाने के लिए
- **`प्रॉम्प्ट सुधारें`** मौजूदा प्रॉम्प्ट को निखारने के लिए
- **`प्रॉम्प्ट अनुवाद करें`** प्रॉम्प्ट के फ़ील्ड का अनुवाद करने के लिए

<br/>

> ⚠️ **चेतावनी**<br/>
> **`Run पर वापस जाएं`** पर क्लिक करने से पहले **`सहेजें`** पर क्लिक करें। यदि आप बिना सहेजे वापस जाते हैं, तो आपके परिवर्तन खो जाएंगे।

<br/>

<a id="test-a-prompt-before-using-it"></a>

### उपयोग से पहले एक प्रॉम्प्ट का परीक्षण करें

दाईं ओर स्थित परीक्षण पैनल आपको दैनिक कार्य में उपयोग करने से पहले नमूना पाठ के साथ अपने प्रॉम्प्ट को आजमाने की अनुमति देता है।

यह तब उपयोगी होता है जब:

- आप एक नया प्रॉम्प्ट बना रहे हैं
- आप प्रॉम्प्ट के दो संस्करणों की तुलना कर रहे हैं
- आप टोन, लंबाई या आउटपुट प्रारूप की जाँच करना चाहते हैं

<br/>

> ℹ️ **नोट**<br/>
> आप [**सेटिंग्स** > **ट्रांसफॉर्म प्रॉम्प्ट्स**](#transform-prompts) में सहेजे गए प्रॉम्प्ट्स को निर्यात और आयात कर सकते हैं।

![डैशबोर्ड सारांश](../images/screenshots/hi/dashboard-summary.png)


<br/>

> ℹ️ **ध्यान दें**<br/>
> यदि आप केवल **मुफ्त** मॉडल का उपयोग करते हैं, तो **लागत** की राशि शून्य हो सकती है और लागत-केंद्रित सारांश खाली दिख सकते हैं। **सारांश**, **समय के साथ उपयोग** और **मॉडल के अनुसार उपयोग** में चयनित अवधि में गतिविधि होने पर अभी भी कॉल की **संख्या** (अनुवाद, पुनर्लेखन और परिवर्तन) दिखाई जाती है।

<a id="filter-the-data"></a>

### डेटा को फ़िल्टर करें

समय रेंज बदलने के लिए ऊपर दिए गए फ़िल्टर बटन का उपयोग करें।

![डैशबोर्ड फ़िल्टर](../images/screenshots/hi/dashboard-filter.png)

<br/>

> ℹ️ **नोट**<br/>
> वेब संस्करण में **उपयोगकर्ता** फ़िल्टर केवल व्यवस्थापकों के लिए दृश्यमान होता है। सामान्य उपयोगकर्ताओं को यह फ़िल्टर दिखाई नहीं देगा, और डेस्कटॉप ऐप में यह उपलब्ध नहीं है।

<br/>

<a id="dashboard-tabs"></a>

### डैशबोर्ड टैब

- **सारांश** उपयोग और लागत की एक समीक्षा प्रदान करता है। इसमें **समय के साथ उपयोग** (अनुवाद, पुनर्लेखन और रूपांतरण के लिए दिन के आधार पर संचित **कॉल गणना** का एक स्तरित चार्ट) तथा **मॉडल के अनुसार उपयोग** (प्रति मॉडल कुल **कॉल**, रूपांतरण सहित) शामिल है।
- **उपयोग अनुसार** गतिविधि को अनुवाद भाषा, पुनर्लेखन मोड और रूपांतरण प्रॉम्प्ट के आधार पर विभाजित करता है।
- **मॉडल अनुसार** दिखाता है कि आपने कौन-से मॉडल का उपयोग किया और उनकी लागत क्या थी।
- **प्रति दिन** दैनिक कुल योग दिखाता है।
- **सभी कॉल** पूर्ण कॉल इतिहास दिखाता है और आपको इसे निर्यात करने की अनुमति देता है।

- **JSON**
- **CSV**
- **XLSX**

यदि आप ऐप के बाहर गतिविधि की समीक्षा करना चाहते हैं या कोई रिपोर्ट साझा करना चाहते हैं, तो यह उपयोगी है।

<a id="delete-stored-records-for-a-model"></a>

### किसी मॉडल के संग्रहीत रिकॉर्ड्स को हटाएं

**मॉडल द्वारा** या **सभी कॉल्स** में, आप किसी मॉडल के संग्रहीत रिकॉर्ड्स को "कचरा बिन" आइकन पर क्लिक करके हटा सकते हैं।

> ⚠️ **चेतावनी**<br/>
> संग्रहीत रिकॉर्ड्स को हटाने की प्रक्रिया को वापस नहीं लाया जा सकता। केवल तभी इसका उपयोग करें जब आप पूरी तरह सुनिश्चित हों कि आपको इतिहास की आवश्यकता नहीं है।

सभी डेटा को हटाने या उनकी आयु के आधार पर रिकॉर्ड्स को निकालने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) पर जाएं। वहां आपको सभी संग्रहीत डेटा या केवल एक निश्चित तारीख से पुराने डेटा को हटाने के विकल्प मिलेंगे।

<a id="general-settings"></a>

### सामान्य सेटिंग्स

**सामान्य सेटिंग्स** का उपयोग टाइपिंग व्यवहार को नियंत्रित करने, यह तय करने और स्वरूप के लिए करें कि क्या **इतिहास** के लिए निष्पादन के विवरण संग्रहीत किए गए हैं।

**व्यवहार**

- **ENTER के लिए व्यवहार** यह चुनता है कि क्या `एंटर` कार्य चलाए या एक नई पंक्ति सम्मिलित करे।
- **पेस्ट के समय स्वत: अनुवाद** तुरंत पाठ पेस्ट करने पर अनुवाद शुरू करता है।
- **परिणाम को क्लिपबोर्ड पर स्वत: कॉपी करें** सफल परिणामों को स्वचालित रूप से कॉपी करता है।
- **वास्तविक समय अनुवाद (टाइप करते समय)** टाइप करते समय अनुवाद करता है।
- **समय सीमा (मिलीसेकंड)** वास्तविक समय अनुवाद के लिए प्रतीक्षा समय निर्धारित करता है।

**इतिहास**

- **निष्पादन इतिहास रखें** यह नियंत्रित करता है कि क्या प्रत्येक अनुवाद, पुनर्लेखन और परिवर्तन साइडबार [**इतिहास**](#history) दृश्य के लिए **इनपुट और आउटपुट पाठ** संग्रहीत करते हैं। इसे बंद करने पर पुष्टि के लिए कहा जाता है; यदि आप पुष्टि करते हैं, तो भंडारित इतिहास पाठ डेटाबेस से हटा दिया जाता है।

- **इतिहास डेटा हटाएं** आपको आयु के आधार पर संग्रहीत पाठ को हटाने की अनुमति देता है (उदाहरण के लिए कुछ महीनों से पुराना, या **सभी डेटा (साफ़ करें)**) **डेटा हटाएं** का उपयोग करके। यह केवल **इतिहास** दृश्य के लिए सहेजे गए निष्पादन पाठ को प्रभावित करता है; यह लागत या उपयोग के कुल मूल्य को **नहीं** हटाता है। **लागत** डेटा को हटाने या संपादित करने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) का उपयोग करें।

**दिखावट**

- **क्रियाओं पर लागत जानकारी दिखाएं** ऑपरेशन प्रति लागत (यदि उपलब्ध हो) और अनुवाद, पुनर्लेखन तथा रूपांतरण आउटपुट पैनलों पर कुल लागत के प्रदर्शन को नियंत्रित करता है।
- **लागत भिन्न अंक** लागत दशमलव के प्रदर्शन को बदलते हैं।
- **केवल वेब:** **ऐप के चारों ओर मार्जिन दिखाएं** इंटरफ़ेस के चारों ओर अतिरिक्त स्थान जोड़ता है।
- **फ़ॉन्ट फ़ैमिली** पाठ पैनलों में लिखने के फ़ॉन्ट को बदलती है।
- **आकार** फ़ॉन्ट आकार को बदलता है।

**विन्यास बैकअप**

- **बैकअप में उपयोग डेटा शामिल करें** — जब सक्षम हो, तो ZIP में निष्पादन इतिहास और API कॉल डेटा भी शामिल होता है।

- **बैकअप कॉन्फ़िगरेशन** — डिफ़ॉल्ट रूप से UTC में एकल ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`) बनाता है जिसमें `config.json`, `state.json`, वैकल्पिक एन्क्रिप्शन कुंजी, उपयोगकर्ता, प्राथमिकताएँ, कस्टम प्रॉम्प्ट्स और, यदि आपने सम्मिलित किया है तो उपयोग डेटा भी शामिल होता है। एक सफल बैकअप के बाद, पुष्टि में सहेजी गई फ़ाइल का नाम दिखाया जाता है।
- **बैकअप से पुनर्स्थापित करें** — पहले एक **पुष्टि संवाद** खोलता है। संवाद में बैकअप ZIP चुनें (**ब्राउज़**/फ़ाइल चयनकर्ता या समर्थित क्षेत्र में ड्रैग-एंड-ड्रॉप), फिर विकल्पों की समीक्षा करें:
  - **उपयोग डेटा को पुनर्स्थापित करें** — तब बैकअप के समय उपयोग शामिल होने पर उपयोग/इतिहास का आयात करें; यदि आप केवल सेटिंग्स और प्रॉम्प्ट्स चाहते हैं तो इसे अक्षम रखें।
  - **पुनर्स्थापित करने से पहले पुराने उपयोग डेटा को साफ़ करें** — बैकअप लागू करने से पहले इस स्थापना पर मौजूदा उपयोग/इतिहास को हटा दें (वैकल्पिक; जब आप साफ़ प्रतिस्थापन चाहते हैं तब इसका उपयोग करें)।

वेब या डेस्कटॉप संस्करण में बनाए गए बैकअप को दूसरे में पुनर्स्थापित किया जा सकता है। वेब संस्करण में डेस्कटॉप बैकअप को पुनर्स्थापित करते समय, डेटा को व्यवस्थापक उपयोगकर्ता में पुनर्स्थापित किया जाएगा।

<a id="models"></a>

### मॉडल

टूलबार में कौन से मॉडल दिखाई दें इसे चुनने के लिए **सेटिंग्स** > **मॉडल** का उपयोग करें।

![सेटिंग्स मॉडल टैब](../images/screenshots/hi/settings-models.png)

इस पृष्ठ में दो सूचियाँ होती हैं:

- बाईं ओर **उपलब्ध मॉडल**
- दाईं ओर **चयनित मॉडल**

उपयोगी नियंत्रणों में शामिल हैं:

- **मॉडल खोजें...** नाम द्वारा मॉडल ढूंढने के लिए
- **प्रदाता** चिप्स, सूची को एक इंजन तक सीमित करने के लिए (OpenRouter, OpenAI, Ollama, ...)
- केवल नि: शुल्क मॉडल दिखाने के लिए **केवल नि: शुल्क**
- सूची को पुनः लोड करने के लिए **ताज़ा करें**
- प्रदाता के आधार पर क्रमबद्ध करते समय **सभी विस्तारित करें** और **सभी संक्षिप्त करें**

मॉडल आईडी में प्रदाता उपसर्ग शामिल होता है (उदाहरण के लिए `openrouter/…` बनाम `openai/…`)। **OpenAI (OpenRouter)** बनाम **OpenAI (सीधा)** जैसे बैज दर्शाते हैं कि ट्रैफ़िक को कैसे मार्ग प्रदान किया जाता है।

> ℹ️ **नोट**<br/>

> **OpenRouter बॉडी बिल्डर** (`openrouter/bodybuilder`) एक राउटर मॉडल है, सामान्य चैट मॉडल नहीं: इसका उत्तर JSON होता है जो OpenRouter API अनुरोध बॉडी का वर्णन करता है (उदाहरण के लिए `model` और `messages` के साथ एक `requests` सरणी)। यदि आप इसे **अनुवाद**, **पुनर्लेखन**, या **परिवर्तन** के लिए उपयोग करते हैं, तो आउटपुट पैनल में तैयार पाठ के बजाय यह JSON दिखाई देगा। ऐसे कार्यों के लिए एक सामान्य पाठ मॉडल चुनें। OpenRouter पर [बॉडी बिल्डर मॉडल पृष्ठ](https://openrouter.ai/openrouter/bodybuilder) देखें।

क्रियाएँ:

 - कोई मॉडल जोड़ने के लिए, **Add** पर क्लिक करें या प्रविष्टि में कहीं भी क्लिक करें।

 - कोई मॉडल हटाने के लिए, **Selected Models** में उसके बगल में **X** पर क्लिक करें या उपलब्ध मॉडल्स में प्रविष्टि पर **Selected** पर क्लिक करें।

 - सूची साफ़ करने के लिए, **Deselect all** पर क्लिक करें। आवश्यक निःशुल्क मॉडल सूची में बना रहेगा।

<br/>

> ℹ️ **नोट**<br/>

> यदि आप OpenRouter को तुरंत श्रेय नहीं देना चाहते हैं, तो **केवल मुफ्त** सक्षम करके शुरुआत करें और मुफ्त मॉडल चुनें (क्रेडिट कार्ड की आवश्यकता नहीं है)। आप कोई एपीआई कुंजी के बिना मॉडल को स्थानीय रूप से चलाने के लिए Ollama का उपयोग भी कर सकते हैं।

<a id="languages"></a>

### भाषाएँ

ऐप में उपयोग की जाने वाली भाषा सूचियों को व्यवस्थित करने के लिए **सेटिंग्स** > **भाषाएँ** का उपयोग करें।

- **शीर्ष भाषाएँ** **अनुवाद** और **परिवर्तन** में भाषा सूचियों के ऊपरी हिस्से के पास स्थिर रहती हैं।
- **अनुकूल भाषा** आपको अंतर्निहित सूची में न शामिल एक भाषा जोड़ने की अनुमति देती है।

यदि आप एक अनुकूल भाषा जोड़ते हैं, तो यह अंतर्निहित विकल्पों के साथ भाषा चयनकर्ताओं में दिखाई देती है।

<br/>

<a id="cost-tracking"></a>

### लागत ट्रैकिंग

अपनी लागत की जानकारी प्रबंधित करने के लिए **सेटिंग्स** > **लागत ट्रैकिंग** का उपयोग करें।

- **कुल लागत** चल रहे कुल योग को दर्शाती है।
- **मान कॉपी करें** कुल राशि को क्लिपबोर्ड पर कॉपी कर देता है।
- **लागत रीसेट करें** संग्रहित कुल राशि को शून्य पर रीसेट कर देता है।
- **API कुंजी उपयोग के साथ सिंक** OpenRouter खाते द्वारा रिपोर्ट किए गए उपयोग से मेल खाने के लिए कुल राशि सेट करता है (केवल OpenRouter के लिए)।
- **API कुंजी उपयोग** उपलब्ध होने पर OpenRouter उपयोग के बारे में विवरण दिखाता है।
- **लागत डेटा हटाएं** सभी डेटा या चयनित तारीख से पुराने केवल प्रविष्टियाँ हटा देता है।

**लागत ट्रैकिंग:** जब आप OpenRouter मॉडल का उपयोग करते हैं, तो एप्लिकेशन OpenRouter के लागत संबंधी जानकारी के आधार पर आपके वास्तविक उपयोग और खर्च को दर्शाता है। अन्य सभी प्रदाताओं के लिए, एप्लिकेशन OpenRouter द्वारा प्रकाशित कीमतों का उपयोग करके लागत का अनुमान लगाता है, यदि कोई कीमत उपलब्ध नहीं है, तो अनुमान शून्य भी हो सकता है।

<br/>

> ℹ️ **नोट**<br/>
> **सभी लागत आंकड़े केवल आपके संदर्भ के लिए अनुमानित हैं, आधिकारिक बिलिंग स्टेटमेंट नहीं हैं।**

<br/>

> ⚠️ **चेतावनी**<br/>

> डेटा हटाने की प्रक्रिया को वापस नहीं लाया जा सकता। हटाने से पहले, कृपया अपने डेटा का बैकअप लें या [**इतिहास**](#history) के माध्यम से या [**डैशबोर्ड** > **सभी कॉल**](#dashboard-tabs) के माध्यम से निर्यात करें, अन्यथा यह स्थायी रूप से खो जाएगा।  
> प्रत्येक API कॉल एंट्री से संबंधित सभी इनपुट/आउटपुट इतिहास भी हटा दिया जाएगा।

<br/>

<a id="transform-prompts"></a>

### प्रॉम्प्ट्स को परिवर्तित करें

**सेटिंग्स** > **प्रॉम्प्ट्स परिवर्तित करें** का उपयोग बल्क में प्रॉम्प्ट्स के प्रबंधन के लिए करें।

आप इन कार्यों को कर सकते हैं:

- अपने सहेजे गए प्रॉम्प्ट्स की समीक्षा करें
- प्रॉम्प्ट्स को हटाएं
- फ़ाइल से प्रॉम्प्ट्स आयात करें
- बैकअप या साझाकरण के लिए प्रॉम्प्ट्स निर्यात करें
- प्रॉम्प्ट सूची में नमूना प्रॉम्प्ट्स लोड करें

<br/>

<a id="users"></a>

### उपयोगकर्ता

वेब संस्करण में उपयोगकर्ता खातों को प्रबंधित करने के लिए **उपयोगकर्ता** का उपयोग करें। आप उपयोगकर्ता जोड़ सकते हैं, उनके विवरण अपडेट कर सकते हैं, पासवर्ड रीसेट कर सकते हैं और खाते हटा सकते हैं।

<br/>

<a id="api-config"></a>

### एपीआई कॉन्फ़िगरेशन

समर्थित प्रदाता हैं: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, और **Ollama** (बेस URL के माध्यम से स्थानीय मॉडल)। आपको केवल उन प्रदाताओं को कॉन्फ़िगर करने की आवश्यकता है जिनका उपयोग आप करते हैं।

**वेब एप्लिकेशन: केवल प्रशासक**

एपीआई कुंजियाँ सिस्टम या डॉकर पर्यावरण चर के माध्यम से कॉन्फ़िगर की जाती हैं — उन्हें वेब यूआई में दर्ज नहीं किया जाता है। यह पृष्ठ दर्शाता है कि किन प्रदाताओं के लिए कुंजी कॉन्फ़िगर की गई है तथा आप **`परीक्षण`** बटन पर क्लिक करके प्रत्येक का परीक्षण कर सकते हैं।

<br/>

> ℹ️ **नोट**<br/>
> किसी एपीआई कुंजी को बदलने के लिए अपने सिस्टम या डॉकर कॉन्फ़िगरेशन में पर्यावरण चर अपडेट करें और सर्वर या कंटेनर को पुनः आरंभ करें।

> ℹ️ **नोट**<br/>

> **कॉन्फ़िगरेशन बैकअप** (देखें [**सामान्य सेटिंग्स** → कॉन्फ़िगरेशन बैकअप](#general-settings)) ZIP के `config.json` में **रिज़ॉल्व की गई** प्रदाता कुंजियाँ शामिल कर सकते हैं। उस ZIP को पुनर्स्थापित करने से उन कुंजियों को सर्वर की संग्रहीत कॉन्फ़िग फ़ाइल में वापस नहीं कॉपी किया जाता है — जीवित कुंजियाँ अभी भी पर्यावरण और वहाँ वर्णित फ़ाइल स्थिति से आती हैं।

<br/>

**डेस्कटॉप ऐप्लिकेशन**

प्रत्येक प्रयोग किए जाने वाले प्रदाता के लिए API कुंजियों को संग्रहीत करने के लिए **API कॉन्फ़िग** का उपयोग करें। Ollama के लिए, किसी API कुंजी के बजाय **बेस URL** दर्ज करें।


<br/>

> 💡 **सुझाव** <br/>
> यदि आप किसी API कुंजी का उपयोग नहीं करना चाहते या उपयोग के लिए भुगतान नहीं करना चाहते हैं, तो आप मुफ्त में अपने कंप्यूटर पर मॉडल (जैसे `translategemma:4b`) चलाने के लिए [Ollama डाउनलोड](https://ollama.com) कर सकते हैं। वैकल्पिक रूप से, आप उनके मुफ्त मॉडल का उपयोग करने या Cerebras, Google, Groq, या Mistral AI से एक मुफ्त API कुंजी प्राप्त करने के लिए मुफ्त OpenRouter खाता बना सकते हैं (क्रेडिट कार्ड की आवश्यकता नहीं है)।

<br/>

- केवल उन प्रोवाइडर्स को जोड़ें जिनकी आपको आवश्यकता है। **सेटिंग्स** > **मॉडल्स** में, प्रत्येक मॉडल आईडी प्रोवाइडर के साथ शुरू होती है (उदाहरण के लिए `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

किसी एपीआई कुंजी को जोड़ने के लिए, पाठ फ़ील्ड में मान दर्ज करें और **`सहेजें`** पर क्लिक करें। मौजूदा कुंजी को बदलने के लिए, **`संपादित करें`** पर क्लिक करें। यह सुनिश्चित करने के लिए कि कुंजी काम कर रही है, **`परीक्षण`** पर क्लिक करें। ओलमा बेस यूआरएल के लिए, संपर्क की जाँच करने के लिए हमेशा **`परीक्षण`** पर क्लिक करें।

<br/>

> ℹ️ **नोट**<br/>
> आप किसी एपीआई कुंजी के वर्तमान मान को नहीं देख सकते हैं। आप केवल **`संपादित करें`** बटन का उपयोग करके इसे प्रतिस्थापित कर सकते हैं।
> एपीआई कुंजियों को कॉन्फ़िगरेशन में एन्क्रिप्टेड रूप में संग्रहीत किया जाता है।

<a id="common-issues"></a>

## सामान्य समस्याएँ

अगर कुछ भी अपेक्षित रूप से काम नहीं कर रहा है, तो पहले निम्नलिखित बिंदुओं की जाँच करें।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### ऐप पाठ का अनुवाद, पुनर्लेखन या रूपांतरण नहीं करेगा

जांचें कि:

- आपने टूलबार में एक मॉडल चुना है
- कम से कम एक मॉडल [**सेटिंग्स** > **मॉडल**](#models) में सूचीबद्ध है
- आपका एपीआई सेटअप काम कर रहा है

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं:

1. [**सेटिंग्स** > **एपीआई कॉन्फ़िग**](#api-config) खोलें।
2. जांचें कि कम से कम एक एपीआई कुंजी सहेजी गई है।
3. प्रदाता के बगल में **परीक्षण** पर क्लिक करके पुष्टि करें कि कुंजी काम कर रही है।

<br/>

<a id="the-model-list-is-empty"></a>

### मॉडल सूची खाली है

[**सेटिंग्स** > **मॉडल**](#models) खोलें और **ताज़ा करें** पर क्लिक करें।

यदि आवश्यक हो, तो:

- किसी मॉडल की खोज करें
- केवल **मुफ्त** चालू करें
- **चयनित मॉडल** में एक या अधिक मॉडल जोड़ें

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>

### परिणाम बहुत धीमा या महंगा है

इनमें से एक या अधिक विकल्पों का प्रयास करें:

- एक अलग मॉडल चुनें
- छोटा इनपुट प्रयोग करें
- [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में **वास्तविक समय अनुवाद (टाइप करते समय)** बंद करें
- सरल कार्यों के लिए मुफ्त मॉडल का उपयोग करें (देखें [मॉडल्स](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>

### इंटरफेस गलत भाषा में है

[टूलबार](#toolbar) में ग्लोब आइकन पर क्लिक करें और अपनी पसंदीदा **इंटरफेस भाषा** चुनें।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>

### पाठ बहुत छोटा या पढ़ने में कठिन है

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और बदलें:

- **फ़ॉन्ट फैमिली**
- **आकार**

<br/>

<a id="dashboard-charts-are-empty"></a>

### डैशबोर्ड चार्ट खाली हैं

यह सामान्य है यदि:

- आप केवल **फ्री मॉडल** का उपयोग कर रहे हैं और आप **लागत** आंकड़ों को देख रहे हैं (वे शून्य हो सकते हैं); **सारांश** पर **उपयोग** कॉल-गणना चार्ट को अभी भी चयनित अवधि से डेटा की आवश्यकता होती है
- चयनित **समय फ़िल्टर** उस अवधि को शामिल नहीं करता है जब कॉल किए गए थे — जांच करने के लिए **सभी** का उपयोग करें

अगर **सभी** का चयन करने के बाद भी चार्ट खाली हैं, तो पुष्टि करें कि कॉल [**इतिहास**](#history) या **सभी कॉल** टैब में दिखाई दे रहे हैं।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### लागत "उपलब्ध नहीं" दिखाती है या गलत लगती है

जब आप **OpenRouter** के माध्यम से मॉडल का उपयोग करते हैं, तो ऐप आपके OpenRouter द्वारा रिपोर्ट किए गए वास्तविक खर्च को दिखाता है।

**अन्य प्रदाताओं** (OpenAI प्रत्यक्ष, Anthropic प्रत्यक्ष, आदि) के लिए, लागत OpenRouter द्वारा प्रकाशित मूल्य निर्धारण डेटा से अनुमानित होती है। यदि किसी मॉडल के लिए कोई मिलती-जुलती कीमत नहीं मिलती है, तो लागत **उपलब्ध नहीं** के रूप में दिखाई देगी और आपके कुल योग में शामिल नहीं की जाएगी।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### कुल लागत आपके प्रदाता के बिल से मेल नहीं खाती

ऐप में सभी लागत आंकड़े केवल **संदर्भ के लिए अनुमानित** हैं, आधिकारिक बिलिंग स्टेटमेंट नहीं।

कुल राशि को आपके वास्तविक OpenRouter खर्च के करीब लाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) खोलें और **API कुंजी उपयोग के साथ सिंक करें** पर क्लिक करें।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### साइडबार में इतिहास पृष्ठ लापता है

**निष्पादन इतिहास सुरक्षित रखें** बंद हो सकता है। [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और इसे सक्षम करें। ध्यान दें कि इसे सक्षम करने से पहले हटाए गए इतिहास डेटा पुनर्स्थापित नहीं होगा।

<br/>

<a id="web-app-session-expired"></a>

### वेब ऐप: लॉगिन पृष्ठ पर अप्रत्याशित रूप से पुनःनिर्देशित

आपका सत्र समाप्त हो गया हो सकता है। पुनः लॉगिन करें। यदि यह लगातार हो रहा है, तो सत्र के जीवनकाल की सेटिंग्स के लिए सर्वर कॉन्फ़िगरेशन की जाँच करें।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### वेब एडमिन: पासवर्ड भूल गए या खो गए

यह **स्व-होस्टेड वेब ऐप** (डॉकर) पर लागू होता है, डेस्कटॉप (इलेक्ट्रॉन) ऐप पर नहीं।

- यदि कोई अन्य एडमिनिस्ट्रेटर अभी भी साइन इन कर सकता है, तो वह [**सेटिंग्स** > **उपयोगकर्ता**](#users) खोल सकता है, खाता चुन सकता है और वहाँ एक **नया पासवर्ड** सेट कर सकता है।
- यदि आपको **एक्सेस बंद** कर दिया गया है, लेकिन आपके पास मशीन या कंटेनर में **शेल एक्सेस** है, तो इमेज के साथ आने वाले हेल्पर का उपयोग करके पासवर्ड रीसेट करें (यदि आप डिफ़ॉल्ट नाम बदलते हैं, तो `transrewrt` को बदलें, और यदि पासवर्ड में स्पेस या विशेष अक्षर हैं, तो पासवर्ड को उद्धरण चिह्न में लपेटें):

```bash
docker exec transrewrt reset-web-password '<उपयोगकर्तानाम>' '<नया-पासवर्ड>'
```

यदि आपने कभी अन्य खाते नहीं बनाए हैं, तो डिफ़ॉल्ट एडमिन उपयोगकर्तानाम `admin` है। जब आप केवल एक तर्क देते हैं, तो उसे `admin` के लिए नया पासवर्ड माना जाता है।

यदि आप डॉकर के बजाय **स्रोत कोड** से चला रहे हैं, तो इसका उपयोग करें:

```bash
pnpm run reset-web-password -- <उपयोगकर्तानाम> <नया-पासवर्ड>

स्क्रिप्ट SQLite डेटाबेस में उपयोगकर्ता रिकॉर्ड को अपडेट करती है (और यदि आवश्यक हो तो `admin` उपयोगकर्ता बना सकती है)। रीसेट करने के बाद, नया पासवर्ड उपयोग करके साइन इन करें।

<a id="quick-tips"></a>

## त्वरित सुझाव

- [**अनुवाद करें**](#translate) से शुरुआत करें ताकि सुनिश्चित हो सके कि आपका सेटअप काम कर रहा है, इससे पहले कि आप [**पुनः लिखें**](#rewrite) या [**परिवर्तित करें**](#transform) पर जाएँ।
- दैनिक शब्दों में सुधार के लिए [**पुनः लिखें**](#rewrite) का उपयोग करें।
- किसी विशिष्ट कार्य के लिए दोहराए जाने योग्य कार्यप्रवाह की आवश्यकता होने पर [**परिवर्तित करें**](#transform) का उपयोग करें।
- उपयोग और लागत पर नज़र रखने के लिए [**डैशबोर्ड**](#dashboard) का उपयोग करें।
- पिछले संचालन और उनके पूरे इनपुट/आउटपुट पाठ की समीक्षा करने के लिए [**इतिहास**](#history) का उपयोग करें।
- यदि आप एक प्रॉम्प्ट लाइब्रेरी बना रहे हैं जिसे आप सुरक्षित रखना चाहते हैं (देखें [परिवर्तित प्रॉम्प्ट्स](#transform-prompts)), या इसे दूसरों के साथ साझा करना चाहते हैं, तो नियमित रूप से प्रॉम्प्ट्स निर्यात करें।
