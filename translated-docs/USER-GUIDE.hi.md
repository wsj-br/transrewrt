# उपयोगकर्ता मार्गदर्शिका

<br/>

<a id="introduction"></a>
## परिचय

ट्रांसरीवर्ट आपको निम्नलिखित तीन मुख्य तरीकों से पाठ के साथ कार्य करने में मदद करता है:

- **अनुवाद करें** - एक भाषा से दूसरी भाषा में पाठ को परिवर्तित करें।
- **पुनर्लेखन करें** - पाठ को विभिन्न शैली में फिर से लिखें, जैसे स्पष्ट, संक्षिप्त या अधिक औपचारिक।
- **परिवर्तित करें** - ट्रिग्गर नामक कस्टम AI निर्देशों का उपयोग कर पाठ को संसाधित करें।

<br/>

इस मार्गदर्शिका में स्थापित और चल रहे ऐप का उपयोग कैसे करें, यह समझाया गया है। स्थापना चरणों के लिए मुख्य **[README](README.hi.md)** देखें।

<br/>

> ℹ️ **नोट**<br/>
> ट्रांसरीवर्ट Windows और Linux के लिए डेस्कटॉप ऐप के रूप में तथा स्वयं-होस्टेड वेब ऐप के रूप में उपलब्ध है। यह मार्गदर्शिका ऐप के दैनिक उपयोग पर केंद्रित है। जहां कुछ केवल एक संस्करण पर लागू होता है, उसकी स्पष्ट रूप से पहचान की जाती है।

<a id="before-you-start"></a>

## शुरू करने से पहले

Transrewrt का उपयोग करने के लिए, आपको कम से कम एक AI प्रदाता तक पहुँच की आवश्यकता होती है। समर्थित प्रदाता ये हैं: [OpenRouter](https://openrouter.ai) (जो कई मॉडलों को एकत्रित करता है), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, और स्थानीय मॉडलों के लिए [Ollama](https://ollama.com)।

आरंभ करने के लिए आपको कोई पेड मॉडल चुनने की आवश्यकता नहीं है। जैसे ही आप अपनी OpenRouter API कुंजी जोड़ते हैं, ऐप स्वचालित रूप से एक आंतरिक **मुफ़्त** OpenRouter विकल्प सक्षम कर देता है। इससे आप तुरंत टेक्स्ट का अनुवाद, पुनर्लेखन और परिवर्तन शुरू कर सकते हैं। वैकल्पिक रूप से, आप Cerebras, Google, Groq या Mistral AI से मुफ्त API कुंजी भी प्राप्त कर सकते हैं।

सरल भाषा में:

- एक **मॉडल** AI इंजन है जो कार्य करता है। मॉडलों को **प्रदाता उपसर्ग** के साथ सूचीबद्ध किया जाता है (उदाहरण के लिए `openrouter/…`, `openai/…`, `ollama/…`)।
- एक **API कुंजी** (या Ollama के लिए एक **बेस URL**) वह तरीका है जिससे ऐप उस प्रदाता तक पहुँचता है।

यदि आप **डेस्कटॉप ऐप** का उपयोग कर रहे हैं, तो प्रत्येक प्रदाता के लिए [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) में कुंजी जोड़ें। केवल OpenRouter के उपयोग के लिए नीचे दिए गए [एक API कुंजी कैसे प्राप्त करें](#how-to-get-an-api-key-desktop-app) देखें। यदि आप किसी API कुंजी का उपयोग नहीं करना चाहते हैं, तो आप [ollama.com](https://ollama.com) से Ollama स्थापित कर सकते हैं और `translategemma:4b` जैसे स्थानीय मॉडलों का उपयोग कर सकते हैं।

यदि आप **वेब संस्करण** का उपयोग कर रहे हैं, तो सर्वर के मालिक पर्यावरण चर के माध्यम से प्रदाताओं को कॉन्फ़िगर करते हैं, इसलिए आप ऐप में सीधे API कुंजियां दर्ज नहीं कर सकते हैं।

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### मुफ्त OpenRouter API कुंजी कैसे प्राप्त करें (डेस्कटॉप ऐप)

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं, तो निम्न चरणों का पालन करें:

1. अपने वेब ब्राउज़र में [OpenRouter](https://openrouter.ai) पर जाएं।
2. एक खाता बनाएं या साइन इन करें।
3. [कुंजियां (Keys)](https://openrouter.ai/keys) पृष्ठ खोलें।
4. एक नई API कुंजी बनाने के लिए बटन पर क्लिक करें।
5. भविष्य में पहचानने के लिए कुंजी को एक नाम दें।
6. नई API कुंजी की प्रतिलिपि बनाएं।
7. Transrewrt पर वापस जाएँ और **सेटिंग्स** > **API कॉन्फ़िग** खोलें।
8. कुंजी को **OpenRouter API कुंजी** में पेस्ट करें (**सेटिंग्स** > **API कॉन्फ़िग** के अंतर्गत)।
9. यह सुनिश्चित करने के लिए कि यह काम करती है, **OpenRouter कुंजी का परीक्षण करें** पर क्लिक करें।

<a id="getting-started"></a>
## आरंभ करना

यदि यह आपका पहली बार है जब आप Transrewrt का उपयोग कर रहे हैं, तो इस क्रम का पालन करें:

1. ऐप खोलें।
2. आवश्यकता होने पर ग्लोब आइकन से अपनी **इंटरफ़ेस भाषा** चुनें।
3. यदि आप **डेस्कटॉप ऐप** में हैं, तो [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें, कम से कम एक प्रदाता (उदाहरण के लिए OpenRouter) के लिए एक API कुंजी जोड़ें और यह सत्यापित करने के लिए **परीक्षण** पर क्लिक करें कि कुंजी काम कर रही है या नहीं।
4. [**सेटिंग्स** > **मॉडल**](#models) खोलें और **चयनित मॉडल** में एक या अधिक मॉडल जोड़ें।
5. [**सेटिंग्स** > **भाषाएं**](#languages) खोलें और यदि आप चाहते हैं कि आपकी सबसे अधिक उपयोग की जाने वाली भाषाएं पहले दिखाई दें, तो अपनी **शीर्ष भाषाएँ** चुनें।
6. **अनुवाद** पर जाएं और सब कुछ ठीक काम कर रहा है यह सुनिश्चित करने के लिए एक सरल अनुवाद चलाएँ।
7. एक बार यह काम कर जाए, **पुनर्लेखन** और फिर **परिवर्तन** का प्रयास करें।

इस क्रम का ध्यान रखना महत्वपूर्ण है। यह सबसे आम प्रथम उपयोग समस्या को रोकता है: कार्य शुरू करने का प्रयास तब किया जाता है जब ऐप में काम करने वाला API कनेक्शन या चयनित मॉडल नहीं होता है।

<a id="toolbar"></a>

### टूलबार

टूलबार थोड़ा-थोड़ा बदल जाता है, इस पर निर्भर करता है कि आप ऐप में कहाँ हैं।

- बाईं ओर, यह वर्तमान पृष्ठ का नाम दिखाता है।
- दाईं ओर, यहाँ **मॉडल चयनकर्ता** और **इंटरफ़ेस भाषा** नियंत्रण होता है।

**मॉडल चयनकर्ता** आपको वर्तमान कार्य के लिए कौन सी एआई इंजन का उपयोग करना है, वह चुनने देता है।

  ![मॉडल चयनकर्ता](../images/screenshots/hi/model-selector.png)

 कुछ मुफ्त मॉडल सदैव उपलब्ध नहीं हो सकते—कभी-कभी वे ऑफलाइन होते हैं या उपयोग की सीमा होती है। ऐसा होने पर, ऐप स्वचालित रूप से उस मॉडल को आपकी उपलब्ध सूची से हटा देगा। कौन से मॉडल दिखाई दें, इसे नियंत्रित करने के लिए [**सेटिंग्स** > **मॉडल**](#models) पर जाएँ और अपनी मॉडल सूची संपादित करें।
 आप सीधे टूलबार में मॉडल नाम के बाईं ओर प्रदाता के आइकन पर क्लिक करके मॉडल सेटिंग्स भी खोल सकते हैं।

<br/>

**ग्लोब आइकन + भाषा कोड** ऐप इंटरफ़ेस भाषा को बदल देता है, जैसे मेनू और बटन। यह **अनुवाद** में उपयोग की जाने वाली अनुवाद भाषाओं को **नहीं बदलता**।

  ![इंटरफ़ेस भाषा चयनकर्ता](../images/screenshots/hi/language-selector.png)

<a id="input-and-output-panels"></a>
### इनपुट और आउटपुट पैनल

अधिकांश कार्यक्षेत्र बाईं ओर के **इनपुट** पैनल और दाईं ओर के **आउटपुट** पैनल का उपयोग करते हैं।

प्रत्येक पैनल भी दिखाते हैं:

| **इनपुट**                                                          | **आउटपुट**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - अक्षर गणना <br/>- शब्द गणना <br/>- पैराग्राफ गणना   <br/> | - कार्य पूरा होने में कितना समय लगा<br/>- **TPS** (प्रति सेकंड टोकन)<br/>- अक्षर, शब्द और पैराग्राफ गणना<br/>- उपयोग किया गया मॉडल |


यदि आप तकनीकी शब्दों के बारे में सोच रहे हैं:

- **टोकन** का अर्थ है पाठ का छोटा टुकड़ा। आप इसे एक शब्द के भाग या एक छोटे शब्द के रूप में सोच सकते हैं।
- **TPS** का अर्थ है कि मॉडल ने प्रति सेकंड उन पाठ के कितने टुकड़े संसाधित किए।

<br/>

आप प्रत्येक संचालन की लागत (यदि उपलब्ध हो) और कुल लागत की निगरानी भी कर सकते हैं, [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) पर `क्रियाओं पर लागत की जानकारी दिखाएँ` विकल्प सक्षम करके।

<a id="transform"></a>

## रूपांतरित करें

उस समय **रूपांतरित करें** का उपयोग करें जब आप चाहते हों कि आर्टिफिशियल इंटेलिजेंस कस्टम निर्देशों का पालन करे।

![ट्रांसफ़ॉर्म वर्कस्पेस](../images/screenshots/hi/transform.png)

यह ऐप का सबसे लचीला हिस्सा है। आप इसे निम्नलिखित कार्यों के लिए उपयोग कर सकते हैं:

- नोट्स का सारांश निकालना
- कच्चे पाठ को एक सुव्यवस्थित ईमेल में बदलना
- मुख्य बिंदुओं को निकालना
- पाठ को एक विशिष्ट प्रारूप में परिवर्तित करना
- इनपुट पाठ के साथ कोई अन्य कस्टम कार्य

<br/>

<a id="run-an-existing-prompt"></a>
### मौजूदा प्रॉम्प्ट चलाएँ

1. **रूपांतरित करें** खोलें।
2. प्रॉम्प्ट सूची से एक प्रॉम्प्ट चुनें।
3. यदि **लक्ष्य** भाषा बॉक्स दिखाई दे, तो अपनी भाषा चुनें।
4. **इनपुट** में पाठ टाइप या पेस्ट करें।
5. **रूपांतरित करें** पर क्लिक करें।
6. **आउटपुट** में परिणाम पढ़ें।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### अगर आपके पास अभी तक कोई प्रॉम्प्ट नहीं है

यदि आपकी प्रॉम्प्ट सूची खाली है, तो **नमूना प्रॉम्प्ट लोड करें** पर क्लिक करें। इससे बिल्ट-इन उदाहरण जोड़े जाएँगे ताकि आप जल्दी शुरुआत कर सकें।

<br/>

> ℹ️ **नोट**<br/>
> नमूना प्रॉम्प्ट अंग्रेजी में उपलब्ध हैं। उन्हें लोड करने के बाद, आप किसी प्रॉम्प्ट को संपादित कर सकते हैं और **प्रॉम्प्ट अनुवाद करें** का उपयोग करके इसे अपनी भाषा में अनुवाद कर सकते हैं।

<br/>

<a id="create-a-prompt-quickly"></a>
### जल्दी से एक प्रॉम्प्ट बनाएँ

एक प्रॉम्प्ट बनाने का सबसे तेज़ तरीका है:

1. **नया प्रॉम्प्ट** पर क्लिक करें।
2. **प्रॉम्प्ट उत्पन्न करें** पर क्लिक करें।
3. बताएँ कि आप प्रॉम्प्ट से क्या करना चाहते हैं।
4. एक मॉडल चुनें।
5. ऐप को आपके लिए एक प्रारूप बनाने दें।
6. प्रारूप की समीक्षा करें और **सहेजें** पर क्लिक करें।

![प्रॉम्प्ट उत्पन्न करें](../images/screenshots/hi/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### एक प्रॉम्प्ट संपादित करें

जब आप कोई प्रॉम्प्ट बनाते या संपादित करते हैं, तो संपादक बाईं ओर दिखाई देता है और दाईं ओर एक परीक्षण क्षेत्र दिखाई देता है।

![ट्रांसफ़ॉर्म प्रॉम्प्ट संपादक](../images/screenshots/hi/transform-prompt-edit.png)

मुख्य फ़ील्ड्स हैं:

- **प्रॉम्प्ट नाम**: प्रॉम्प्ट सूची में दिखाया गया नाम।
- **प्रॉम्प्ट निर्देश (वैकल्पिक)**: छोटी सूचना जो प्रॉम्प्ट चलाते समय उपयोगकर्ता को दिखाई देती है।
- **मॉडल भूमिका**: एआई को दी गई समग्र भूमिका, जैसे 'आप एक सहायक सहायक हैं।'
- **मॉडल निर्देश (प्रति लाइन एक)**: विशिष्ट नियम जिनका एआई को पालन करना है।
- **आउटपुट विवरण**: परिणाम का वर्णन करने वाला एक छोटा शब्द, जैसे 'सारांश' या 'पुनः लेखन'।
- **तापमान (0.0 → 1.0)**: मॉडल किस प्रकार व्यवहार करेगा; नीचे देखें।
- **लक्ष्य भाषा के लिए पूछें**: प्रॉम्प्ट चलाते समय लक्ष्य भाषा चयनकर्ता जोड़ता है।

यदि आपके लिए **तापमान** नामक तकनीकी शब्द नया है, तो इसे इस प्रकार समझें:

- एक **कम** तापमान स्थिर, अधिक भविष्यवाणी योग्य परिणाम देता है।
- एक **अधिक** तापमान अधिक विविधता और रचनात्मकता देता है।

आप इसका भी उपयोग कर सकते हैं:

- **`प्रॉम्प्ट उत्पन्न करें`** एक सरल विवरण से एक नया प्रारूप बनाने के लिए
- **`प्रॉम्प्ट में सुधार करें`** मौजूदा प्रॉम्प्ट में सुधार करने के लिए
- **`प्रॉम्प्ट अनुवाद करें`** प्रॉम्प्ट फ़ील्ड्स का अनुवाद करने के लिए

<br/>

> ⚠️ **चेतावनी**<br/>
> **`वापस चलाने के लिए`** पर क्लिक करने से पहले **`सहेजें`** पर क्लिक करें। बिना सहेजे वापस जाने पर आपके परिवर्तन खो जाएँगे।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### उपयोग करने से पहले प्रॉम्प्ट का परीक्षण करें

दाईं ओर का परीक्षण पैनल आपको दैनिक कार्य में उपयोग करने से पहले नमूना पाठ के साथ अपने प्रॉम्प्ट का परीक्षण करने की अनुमति देता है।

यह निम्नलिखित स्थितियों में उपयोगी है:

- जब आप एक नया प्रॉम्प्ट बना रहे हों
- जब आप किसी प्रॉम्प्ट के दो संस्करणों की तुलना कर रहे हों
- जब आप स्वरूप, लंबाई या आउटपुट प्रारूप की जांच करना चाहते हों

<br/>

> ℹ️ **नोट**<br/>
> आप [**सेटिंग्स** > **ट्रांसफ़ॉर्म प्रॉम्प्ट्स**](#transform-prompts) में सहेजे गए प्रॉम्प्ट्स निर्यात और आयात कर सकते हैं।

<a id="delete-stored-records-for-a-model"></a>
### किसी मॉडल के लिए संग्रहीत रिकॉर्ड हटाएं

**मॉडल के हिसाब से** या **सभी कॉल** में, आप मॉडल के लिए संग्रहीत रिकॉर्ड को "कचरा बिन" आइकन पर क्लिक करके हटा सकते हैं।

> ⚠️ **चेतावनी**<br/>
> संग्रहीत रिकॉर्ड को हटाने की क्रिया पूर्ववत् नहीं की जा सकती। केवल तभी इसका उपयोग करें जब आपको यकीन हो कि आपको इस इतिहास की आवश्यकता नहीं है।

सभी डेटा हटाने या उनकी आयु के आधार पर रिकॉर्ड हटाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) पर जाएं। वहां आपको सभी संग्रहीत डेटा हटाने या एक निश्चित तिथि से पुराने केवल डेटा हटाने के विकल्प मिलेंगे।

<a id="general-settings"></a>
### सामान्य सेटिंग्स

टाइपिंग व्यवहार, यह नियंत्रित करने के लिए कि क्या क्रियान्वयन विवरण **इतिहास** के लिए संग्रहीत किए जाएं, और दिखावट नियंत्रित करने के लिए **सामान्य सेटिंग्स** का उपयोग करें।

**व्यवहार**

- **ENTER के लिए व्यवहार** यह चुनता है कि `Enter` कार्य को चलाए या एक नई पंक्ति सम्मिलित करे।
- **पेस्ट करने पर स्वचालित अनुवाद** जैसे ही आप पाठ पेस्ट करते हैं, अनुवाद शुरू करता है।
- **क्लिपबोर्ड में परिणाम को स्वचालित रूप से कॉपी करें** सफल परिणामों को स्वचालित रूप से कॉपी कर देता है।
- **वास्तविक समय अनुवाद (टाइप करते समय)** आपके टाइप करते समय अनुवाद करता है।
- **टाइमआउट (ms)** वास्तविक समय अनुवाद के लिए प्रतीक्षा समय को सेट करता है।

**इतिहास**

- **क्रियान्वयन इतिहास रखें** नियंत्रित करता है कि क्या प्रत्येक अनुवाद, पुनर्लेखन और ट्रांसफॉर्म साइडबार [**इतिहास**](#history) दृश्य के लिए **इनपुट और आउटपुट पाठ** संग्रहीत करते हैं। इसे बंद करने पर पुष्टि के लिए कहा जाता है; यदि आप पुष्टि करते हैं, तो डेटाबेस से संग्रहीत इतिहास पाठ हटा दिया जाता है।
- **इतिहास डेटा हटाएँ** आपको **डेटा हटाएं** का उपयोग करके आयु के आधार पर (उदाहरण के लिए कुछ महीनों से अधिक पुराने, या **सभी डेटा (साफ करें)**) संग्रहीत पाठ हटाने की अनुमति देता है। यह केवल **इतिहास** दृश्य के लिए सहेजे गए क्रियान्वयन पाठ को प्रभावित करता है; यह **लागत या उपयोग कुल योग** को नहीं हटाता है। **लागत** डेटा हटाने या काटने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) का उपयोग करें।

**दिखावट**

- **क्रियाओं पर लागत जानकारी दिखाएँ** प्रति ऑपरेशन लागत (यदि उपलब्ध हो) और अनुवाद, पुनर्लेखन और ट्रांसफॉर्म आउटपुट पैनलों पर कुल लागत के प्रदर्शन को नियंत्रित करता है।
- **लागत अंश अंक** लागत दशमलवों को कैसे प्रदर्शित किया जाए, इसे बदलता है।
- **केवल वेब:** **ऐप के आसपास मार्जिन दिखाएँ** इंटरफ़ेस के चारों ओर अतिरिक्त स्थान जोड़ता है।
- **फॉन्ट परिवार** पाठ पैनलों में लेखन फ़ॉन्ट बदलता है।
- **आकार** फ़ॉन्ट आकार को बदलता है।

<a id="models"></a>

### मॉडल

**सेटिंग्स** > **मॉडल** का उपयोग करके तय करें कि टूलबार पर कौन से मॉडल दिखें।

![सेटिंग्स मॉडल टैब](../images/screenshots/hi/settings-models.png)

पेज के पास दो सूचियाँ हैं:

- **उपलब्ध मॉडल** बाएं
- **चुने हुए मॉडल** दाएं

उपयोगी नियंत्रण इनमें शामिल हैं:

- मॉडल को नाम से खोजने के लिए **मॉडल खोजें...**
- सूची को एक इंजन (OpenRouter, OpenAI, Ollama, …) तक सीमित करने के लिए **प्रोवाइडर** टैग
- केवल मुफ्त मॉडल दिखाने के लिए **केवल मुफ्त**
- सूची को रीलोड करने के लिए **रीफ्रेश**
- जब आप प्रोवाइडर के अनुसार सॉर्टिंग कर रहे हों, **सभी विस्तार करें** और **सभी संकुचित करें**

मॉडल आईडी में प्रोवाइडर प्रीफिक्स शामिल होता है (उदाहरण के लिए `openrouter/…` बनाम `openai/…`)। **OpenAI (OpenRouter)** बनाम **OpenAI (प्रत्यक्ष)** जैसे बैज दिखाते हैं कि ट्रैफिक कैसे राउट होता है।

> ℹ️ **नोट**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) एक राउटर मॉडल है, एक सामान्य चैट मॉडल नहीं: इसका जवाब JSON होता है जो OpenRouter API अनुरोध बॉडी का वर्णन करता है (उदाहरण के लिए एक `requests` ₹ields के साथ `model` और `messages`)। यदि आप इसे **अनुवाद**, **पुनलेखन**, या **रूपांतरण** के लिए उपयोग करते हैं, तो आउटपुट पैनल पर समाप्त टेक्स्ट के बजाय JSON दिखेगा। इन कार्यों के लिए एक सामान्य टेक्स्ट मॉडल चुनें। OpenRouter पर [बॉडी बिल्डर मॉडल पेज](https://openrouter.ai/openrouter/bodybuilder) देखें।

क्रियाएं:

 - मॉडल जोड़ने के लिए, **जोड़ें** पर क्लिक करें या प्रविष्टि के किसी भी हिस्से पर क्लिक करें।
 - मॉडल हटाने के लिए, **चुने हुए मॉडल** में उसके आगे **X** पर क्लिक करें या उपलब्ध मॉडल में प्रविष्टि पर **चयनित** पर क्लिक करें।
 - सूची साफ करने के लिए, **सभी का चयन रद्द करें** पर क्लिक करें। आवश्यक मुफ्त मॉडल सूची में बने रहेगा।

<br/>

> ℹ️ **नोट**<br/>
> यदि आप सीधे OpenRouter में क्रेडिट जोड़ना नहीं चाहते, तो पहले **केवल मुफ्त** सक्षम करें और मुफ्त मॉडलों को चुनें (क्रेडिट कार्ड आवश्यक नहीं)। आप किसी भी API की जगह स्थानी रूप से मॉडल चलाने के लिए Ollama का भी उपयोग कर सकते हैं।

<a id="languages"></a>
### भाषाएं

एप में प्रयोग की जाने वाली भाषा सूचियों को व्यवस्थित करने के लिए **सेटिंग्स** > **भाषाएं** का उपयोग करें।

- **शीर्ष भाषाएं** **अनुवाद** और **रूपांतरण** में भाषा सूचियों के ऊपर पिन की जाती हैं।
- **विशेष भाषा** आपको ऐसी भाषा जोड़ने देती है जि ऐसी सूची में नहीं है।

यदि आप कोई विशेष भाषा जोड़ते हैं, तो वह निर्मित विकल्पों के साथ भाषा सेलेक्टर में दिखाई देती है।

<a id="cost-tracking"></a>
### लागत ट्रैकिंग

लागत जानकारी प्रबंधित करने के लिए **सेटिंग्स** > **लागत ट्रैकिंग** का उपयोग करें।

- **कुल लागत** चलते हुए कुल योग दिखाती है।
- **मान कॉपी करें** कुल को क्लिपबोर्ड पर कॉपी करता है।
- **लागत रीसेट करें** स्टोर्ड कुल को शून्य पर रीसेट करता है।
- **API की उपयोगता के साथ सिंक करें** कुल को अपने OpenRouter खाते द्वारा रिपोर्ट की गई उपयोगता से मिलाने लगाता है (केवल OpenRouter)।
- **API की उपयोगता** OpenRouter उपयोगता विवरण दिखाती है, यदि उपलब्ध हो।
- **लागत डेटा हटाएं** सभी डेटा को हटा देता है, या केवल चुनी हुई तिथि से पुराने प्रविष्टियों को।

 **लागत ट्रैकिंग:** जब आप OpenRouter मॉडल का उपयोग करते हैं, तो ऐप आपकी वास्तविक उपयोगता और खर्च OpenRouter से आई लागत जानकारी पर आधारित दिखाता है। अन्य सभी प्रोवाइडर के लिए, ऐप OpenRouter द्वारा प्रकाशित कीमतों का उपयोग करके लागत का अनुमान लगाता है, यदि कीमत उपलब्ध नहीं है, तो अनुमान शून्य हो सकता है।

<br/>

> ℹ️ **नोट**<br/>
>  **सभी लागत अंक केवल आपके संदर्भ के लिए अनुमान हैं, आधिकारिक बिलिंग स्टेटमेंट नहीं हैं।**


<br/>

> ⚠️ **चेतावनी**<br/>
> डेटा हटाना पूर्ववत नहीं किया जा सकता। डेटा हटाने से पहले, अपना डेटा बैकअप करना या [**इतिहास**](#history) या [**डैशबोर्ड** > **सभी कॉल्स**](#dashboard-tabs) के माध्यम से निर्यात करना सुनिश्चित करें, अन्यथा यह स्थायी रूप से खो जाएगा।  
> प्रत्येक API कॉल प्रविष्टि से संबंधित सभी इनपुट/आउटपुट इतिहास भी हटा दिया जाएगा।


<br/>

<a id="transform-prompts"></a>
### ट्रांसफॉर्म प्रॉम्प्ट

बल्क में प्रॉम्प्ट प्रबंधित करने के लिए **सेटिंग्स** > **ट्रांसफॉर्म प्रॉम्प्ट** का उपयोग करें।

आप:

- अपने सहेजे हुए प्रॉम्प्ट की समीक्षा कर सकते हैं
- प्रॉम्प्ट हटा सकते हैं
- एक फ़ाइल से प्रॉम्प्ट आयात कर सकते हैं
- बैकअप या साझाकर्ती के लिए प्रॉम्प्ट निर्यात कर सकते हैं

<br/>

<a id="users"></a>
### उपयोगकर्ता

वेब संस्करण में उपयोगकर्ता खातों प्रबंधित करने के लिए **उपयोगकर्ता** का उपयोग करें। आप उपयोगकर्ता जोड़ सकते हैं, उनकी विवरण सुधार सकते हैं, पासवर्ड रीसेट कर सकते हैं, और खाते हटा सकते हैं।

<a id="api-config"></a>
### API कॉन्फिग

समर्थित प्रोवाइडर हैं: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, और **Ollama** (एक बेस URL के माध्यम से स्थानी मॉडल)। आपको केवल उन प्रोवाइडर कॉन्फिग करने की आवश्यकता है जिनका आप उपयोग करते हैं।

**वेब एप्लिकेशन: केवल व्यवस्थापक**

API कुंजियाँ सिस्टम या डॉकर एनवायरनमेंट वेरिएबल के माध्यम से कॉन्फिग की जाती हैं — वे वेब UI में दर्ज नहीं की जाती। यह पेज दिखाता है कि कौन से प्रोवाइडर की कुंजी कॉन्फिग की गई है और **`टेस्ट`** बटन पर क्लिक करके प्रत्येक का परीक्षण करने देता है।

<br/>

> ℹ️ **नोट**<br/>
> एक API कुंजी बदलने के लिए, अपने सिस्टम या डॉकर कॉन्फिगरेशन में एनवायरनमेंट वेरिएबल अपडेट करें और सर्वर या कंटेनर रिस्टार्ट करें।

<br/>

**डेस्कटॉप एप्लिकेशन**

API कुंजी स्टोर करने के लिए **API कॉन्फिग** का उपयोग करें। Ollama के लिए, API कुंजी के बजाय **बेस URL** दर्ज करें।


<br/>

> 💡 **सुझाव** <br/>
> यदि आप API की जगह का उपयोग नहीं करना चाहते या उपयोग के लिए भुगतान नहीं करना चाहते, तो आप [Ollama](https://ollama.com) डाउनलोड कर सकते हैं और अपने मशीन पर मुफ्त में मॉडल (जैसे `translategemma:4b`) स्थानी रूप से चला सकते हैं। वैकल्पिक रूप से, आप उनके मुफ्त मॉडलों का उपयोग करने के लिए एक मुफ्त OpenRouter खाता बना सकते हैं (क्रेडिट कार्ड आवश्यक नहीं), या Cerebras, Google, Groq, या Mistral AI से एक मुफ्त API कुंजी प्राप्त कर सकते हैं।

<br/>

- केवल उन प्रोवाइडर जोड़ें जिनकी आपको आवश्यकता है। **सेटिंग्स** > **मॉडल** में, प्रत्येक मॉडल आईडी प्रोवाइडर से शुरू होती है (उदाहरण के लिए `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

एक API कुंजी जोड़ने के लिए, मान टेक्स्ट फ़ील्ड में दर्ज करें और **`सेव`** पर क्लिक करें। एक मौजूदा कुंजी को बदलने के लिए, **`संपादन`** पर क्लिक करें। कि कुंजी कार्य कर रही है, इसकी पुष्टि करने के लिए **`टेस्ट`** पर क्लिक करें। Ollama बेस URL के लिए, कनेक्शन जांचने के लिए हमेशा **`टेस्ट`** पर क्लिक करें।

<br/>

> ℹ️ **नोट**<br/>
> आप API कुंजी का वर्तमान मान नहीं देख सकते। आप केवल **`संपादन`** बटन का उपयोग करके इसे बदल सकते हैं।
> API कुंजियाँ कॉन्फिगरेशन में एन्क्रिप्टेड स्टोर की जाती हैं।

<a id="common-issues"></a>
## सामान्य समस्याएँ

यदि कुछ अपेक्षानुसार काम नहीं कर रहा है, तो पहले निम्न बातों की जाँच करें।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ऐप पाठ का अनुवाद, पुनर्लेखन या रूपांतरण नहीं करेगा

यह सुनिश्चित करें कि:

- आपने टूलबार में एक मॉडल का चयन किया है
- कम से कम एक मॉडल [**सेटिंग्स** > **मॉडल्स**](#models) में सूचीबद्ध है
- आपकी API सेटअप काम कर रही है

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं:

1. [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें।
2. यह सुनिश्चित करें कि कम से कम एक API कुंजी सहेजी गई है।
3. कुंजी के काम करने की पुष्टि करने के लिए प्रदाता के बगल में **टेस्ट** पर क्लिक करें।

<br/>

<a id="the-model-list-is-empty"></a>
### मॉडल सूची खाली है

[**सेटिंग्स** > **मॉडल्स**](#models) खोलें और **रीफ्रेश** पर क्लिक करें।

यदि आवश्यकता हो:

- कोई मॉडल खोजें
- **केवल मुफ्त** चालू करें
- **चयनित मॉडल्स** में एक या अधिक मॉडल्स जोड़ें

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### परिणाम बहुत धीमा है या बहुत महंगा लग रहा है

इनमें से एक या अधिक का प्रयास करें:

- एक अलग मॉडल चुनें
- छोटा इनपुट उपयोग करें
- [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में **रीयल-टाइम अनुवाद (टाइप करते समय)** बंद करें
- सरल कार्यों के लिए मुफ्त मॉडल्स का उपयोग करें (देखें [मॉडल्स](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### इंटरफ़ेस गलत भाषा में है

[टूलबार](#toolbar) में ग्लोब आइकन पर क्लिक करें और अपनी पसंदीदा **इंटरफ़ेस भाषा** चुनें।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### पाठ बहुत छोटा है या पढ़ने में कठिन है

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और बदलें:

- **फ़ॉन्ट फ़ैमिली**
- **आकार**

<br/>

<a id="dashboard-charts-are-empty"></a>
### डैशबोर्ड चार्ट खाली हैं

यदि:

- आप केवल **मुफ्त मॉडल्स** का उपयोग करते हैं (लागत चार्ट खाली रहेंगे)
- चयनित **समय फ़िल्टर** उस अवधि को नहीं कवर करता है जब कॉल किए गए थे — जाँच करने के लिए **सभी** का उपयोग करें

यदि **सभी** चुनने के बाद चार्ट अभी भी खाली हैं, तो यह सुनिश्चित करें कि कॉल [**इतिहास**](#history) या **सभी कॉल्स** टैब में दिखाई दे रहे हैं।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### लागत "उपलब्ध नहीं" दिखाती है या गलत लग रही है

जब आप **OpenRouter** के माध्यम से मॉडल का उपयोग करते हैं, तो ऐप आपके द्वारा OpenRouter को रिपोर्ट किए गए वास्तविक खर्च को दिखाता है।

**अन्य प्रदाता** (OpenAI सीधे, Anthropic सीधे इत्यादि) के लिए, लागत OpenRouter द्वारा प्रकाशित मूल्य डेटा से अनुमानित होती है। यदि किसी मॉडल के लिए कोई मेल खाता मूल्य नहीं मिलता है, तो लागत **उपलब्ध नहीं** के रूप में दिखाई देगी और आपके कुल योग में नहीं जुड़ेगी।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### कुल लागत मेरे प्रदाता के बिल से मेल नहीं खाती

ऐप में सभी लागत आंकड़े **केवल संदर्भ के लिए अनुमानित** हैं, आधिकारिक बिलिंग स्टेटमेंट नहीं।

कुल योग को आपके वास्तविक OpenRouter खर्च के करीब लाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) खोलें और **API कुंजी उपयोग के साथ सिंक करें** पर क्लिक करें।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### इतिहास पृष्ठ साइडबार से गायब है

**निष्पादन इतिहास बनाए रखें** बंद हो सकता है। [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और इसे सक्षम करें। ध्यान दें कि इसे चालू करने से पहले डिलीट किए गए इतिहास डेटा बहाल नहीं होते।

<br/>

<a id="web-app-session-expired"></a>
### वेब ऐप: अप्रत्याशित रूप से लॉगिन पेज पर पुनर्निर्देशित

हो सकता है कि आपका सत्र समाप्त हो गया हो। पुनः लॉगिन करें। यदि यह बार-बार होता है, तो सत्र आयु सेटिंग्स के लिए सर्वर कॉन्फ़िगरेशन की जाँच करें।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### डैशबोर्ड अन्य उपयोगकर्ताओं के लिए कोई डेटा नहीं दिखाता (वेब)

केवल **प्रशासक** **उपयोगकर्ता** फ़िल्टर के माध्यम से सभी उपयोगकर्ताओं के डेटा देख सकते हैं। सामान्य उपयोगकर्ता डिज़ाइन के अनुसार केवल अपनी गतिविधि देख सकते हैं।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### मैंने एक प्रॉम्प्ट बदली और संपादन खो दिए

जब आप कोई प्रॉम्प्ट संपादित कर रहे हों, तो हमेशा **बैक टू रन** पर क्लिक करने से पहले **सेव** पर क्लिक करें।

<br/><br/>

<a id="quick-tips"></a>
## त्वरित सुझाव

- अपनी सेटअप की जाँच करने के लिए सबसे पहले [**अनुवाद**](#translate) से शुरू करें, फिर [**पुनर्लेखन**](#rewrite) या [**रूपांतरण**](#transform) पर बढ़ें।
- दैनिक शब्दावली सुधारों के लिए [**पुनर्लेखन**](#rewrite) का उपयोग करें।
- जब आपको किसी विशिष्ट कार्य के लिए एक दोहराई जा सकने वाला कार्यप्रवाह चाहिए, तो [**रूपांतरण**](#transform) का उपयोग करें।
- उपयोग और लागत पर नज़र रखने के लिए [**डैशबोर्ड**](#dashboard) का उपयोग करें।
- पिछले संचालन और उनके पूर्ण इनपुट/आउटपुट पाठ की समीक्षा करने के लिए [**इतिहास**](#history) का उपयोग करें।
- यदि आप एक प्रॉम्प्ट लाइब्रेरी बना रहे हैं जिसे आप सुरक्षित रखना चाहते हैं (देखें [रूपांतरण प्रॉम्प्ट्स](#transform-prompts)) या दूसरों के साथ साझा करना चाहते हैं तो नियमित रूप से प्रॉम्प्ट्स निर्यात करें।
