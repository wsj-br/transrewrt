# उपयोगकर्ता गाइड

<br/>

<a id="introduction"></a>
## परिचय

ट्रांसरीव्रट आपको तीन मुख्य तरीकों से पाठ के साथ काम करने में मदद करता है:

- **अनुवाद** - एक भाषा से दूसरी भाषा में पाठ परिवर्तित करना।
- **पुनर्लेखन** - स्पष्ट, संक्षिप्त या अधिक औपचारिक जैसी एक अलग शैली में पाठ को पुनः लिखना।
- **रूपांतरण** - उत्तेजक नामक कस्टम एआई निर्देश का उपयोग कर पाठ को प्रसंस्कृत करना।

<br/>

यह गाइड एप्लिकेशन स्थापित और चल रहा होने के बाद इसे कैसे उपयोग करना है, इसकी व्याख्या करती है। स्थापना के चरणों के लिए मुख्य **[README](README.hi.md)** देखें।

<br/>

> ℹ️ **नोट**<br/>
> ट्रांसरीव्रट विंडोज और लिनक्स के लिए एक डेस्कटॉप ऐप के रूप में उपलब्ध है, तथा स्व-होस्टेड वेब ऐप के रूप में भी। यह गाइड ऐप के दैनिक उपयोग पर केंद्रित है। जहां कुछ केवल एक संस्करण पर लागू होता है, वहां स्पष्ट रूप से चिह्नित किया गया है।

## शुरू करने से पहले

Transrewrt का उपयोग करने के लिए आपको कम से कम एक एआई प्रदाता तक पहुँच की आवश्यकता होती है। समर्थित प्रदाता हैं: [OpenRouter](https://openrouter.ai) (जो कई मॉडल्स को एकत्रित करता है), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras और स्थानीय मॉडल्स के लिए [Ollama](https://ollama.com)।

शुरू करने के लिए किसी प्रीमियम मॉडल का चयन करने की कोई आवश्यकता नहीं है। जैसे ही आप अपनी OpenRouter API कुंजी जोड़ते हैं, ऐप स्वचालित रूप से एक बिल्ट-इन **निःशुल्क** OpenRouter विकल्प सक्षम कर देता है। इससे आप तुरंत टेक्स्ट का अनुवाद, पुनर्लेखन और रूपांतरण शुरू कर सकते हैं। वैकल्पिक रूप से, आप Cerebras, Google, Groq, या Mistral AI से एक निःशुल्क API कुंजी भी प्राप्त कर सकते हैं।

सरल भाषा में:

- एक **मॉडल** वह एआई इंजन है जो कार्य करता है। मॉडल्स को एक **प्रदाता प्रत्यय** के साथ सूचीबद्ध किया गया है (उदाहरण के लिए `openrouter/…`, `openai/…`, `ollama/…`)।
- एक **API कुंजी** (या Ollama के लिए, एक **बेस URL**) वह तरीका है जिससे ऐप उस प्रदाता तक पहुँचता है।

यदि आप **डेस्कटॉप ऐप** का उपयोग कर रहे हैं, तो [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) में प्रत्येक प्रदाता के लिए कुंजियाँ जोड़ें। केवल OpenRouter का उपयोग करने के लिए, नीचे [एक API कुंजी कैसे प्राप्त करें](#how-to-get-an-api-key-desktop-app) देखें। यदि आप कोई API कुंजी उपयोग नहीं करना चाहते हैं, तो आप [ollama.com](https://ollama.com) से Ollama स्थापित कर सकते हैं और `translategemma:4b` जैसे स्थानीय मॉडल्स के बजाय उपयोग कर सकते हैं।

यदि आप **वेब संस्करण** का उपयोग कर रहे हैं, तो सर्वर मालिक पर्यावरण चर के माध्यम से प्रदाताओं को कॉन्फ़िगर करता है, इसलिए आप ऐप में सीधे API कुंजियाँ दर्ज नहीं कर सकते हैं।

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### निःशुल्क OpenRouter API कुंजी कैसे प्राप्त करें (डेस्कटॉप ऐप)

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं, तो इन चरणों का पालन करें:

1. अपने वेब ब्राउज़र में [OpenRouter](https://openrouter.ai) पर जाएँ।
2. एक खाता बनाएँ या साइन इन करें।
3. [कुंजियाँ](https://openrouter.ai/keys) पृष्ठ खोलें।
4. एक नई API कुंजी बनाने के लिए बटन पर क्लिक करें।
5. बाद में पहचानने के लिए कुंजी का नाम दें।
6. नई API कुंजी को कॉपी करें।
7. Transrewrt पर वापस जाएँ और **सेटिंग्स** > **API कॉन्फ़िग** खोलें।
8. कुंजी को **OpenRouter API कुंजी** में पेस्ट करें (**सेटिंग्स** > **API कॉन्फ़िग** के अंतर्गत)।
9. यह सुनिश्चित करने के लिए कि यह कार्य करती है, **OpenRouter कुंजी का परीक्षण करें** पर क्लिक करें।

<a id="getting-started"></a>
## प्रारंभ करने के लिए

यदि Transrewrt का उपयोग पहली बार कर रहे हैं, तो इस क्रम का पालन करें:

1. ऐप खोलें।
2. आवश्यकता होने पर ग्लोब आइकन से अपनी **इंटरफ़ेस भाषा** चुनें।
3. यदि आप **डेस्कटॉप ऐप** पर हैं, तो [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें, कम से कम एक प्रदाता (उदाहरण के लिए OpenRouter) के लिए एक API कुंजी जोड़ें और सत्यापित करने के लिए **परीक्षण** पर क्लिक करें।
4. [**सेटिंग्स** > **मॉडल्स**](#models) खोलें और **चयनित मॉडल्स** में एक या अधिक मॉडल्स जोड़ें।
5. [**सेटिंग्स** > **भाषाएँ**](#languages) खोलें और, यदि आप चाहें कि आपकी सबसे अधिक उपयोग की जाने वाली भाषाएँ पहले दिखाई दे, तो अपनी **शीर्ष भाषाएँ** चुनें।
6. **अनुवाद** पर जाएँ और सब कुछ ठीक काम कर रहा है यह सुनिश्चित करने के लिए एक साधारण अनुवाद चलाएँ।
7. एक बार यह सफल हो जाने के बाद, **पुनर्लेखन** और फिर **रूपांतरण** का प्रयास करें।

इस क्रम का महत्व है। यह सबसे आम पहले उपयोग की समस्या को रोकता है: ऐप के पास काम करने वाला API कनेक्शन या चयनित मॉडल होने से पहले कार्य चलाने का प्रयास करना।

### टूलबार

टूलबार उस जगह के आधार पर थोड़ा बदल जाता है जहाँ आप ऐप में हैं।

- बाईं ओर, वर्तमान पृष्ठ का नाम दिखाया जाता है।
- दाईं ओर, **मॉडल चयनकर्ता** और **इंटरफ़ेस भाषा** नियंत्रण दिखाया जाता है।

**मॉडल चयनकर्ता** आपको वर्तमान कार्य के लिए कौन सा एआई इंजन उपयोग करना है, यह चुनने की अनुमति देता है।

  ![मॉडल चयनकर्ता](../images/screenshots/hi/model-selector.png)

कुछ मुफ्त मॉडल्स हमेशा उपलब्ध नहीं हो सकते — कभी-कभी वे ऑफ़लाइन होते हैं या उपयोग सीमा होती है। ऐसा होने पर, ऐप स्वचालित रूप से आपकी उपलब्ध सूची से उस मॉडल को हटा देगा। यह नियंत्रित करने के लिए कि कौन से मॉडल दिखाई दें, [**सेटिंग्स** > **मॉडल्स**](#models) पर जाएँ और अपनी मॉडल सूची संपादित करें।
आप टूलबार में मॉडल नाम के बाईं ओर प्रदाता आइकन पर क्लिक करके मॉडल सेटिंग्स को सीधे भी खोल सकते हैं।

<br/>

**ग्लोब आइकन + भाषा कोड** ऐप इंटरफ़ेस की भाषा को बदलते हैं, जैसे मेनू और बटन। इससे **अनुवाद** में उपयोग की जाने वाली अनुवाद भाषाएँ नहीं बदलती हैं।

  ![इंटरफ़ेस भाषा चयनकर्ता](../images/screenshots/hi/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### इनपुट और आउटपुट पैनल

अधिकांश कार्यस्थानों में बाईं ओर का **इनपुट** पैनल और दाईं ओर का **आउटपुट** पैनल उपयोग किया जाता है।

प्रत्येक पैनल में निम्न भी दिखाये जाते हैं:

| **इनपुट**                                                          | **आउटपुट**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - अक्षर गणना <br/>- शब्द गणना <br/>- पैराग्राफ गणना   <br/> | - कार्य पूरा होने में लगा समय<br/>- **TPS** (प्रति सेकंड टोकन)<br/>- अक्षर, शब्द और पैराग्राफ गणना<br/>- उपयोग किया गया मॉडल |


यदि आप तकनीकी शब्दों के बारे में सोच रहे हैं:

- **टोकन** का अर्थ है पाठ का छोटा टुकड़ा। आप इसे एक शब्द के भाग या एक छोटे शब्द के रूप में समझ सकते हैं।
- **TPS** का अर्थ है कि मॉडल प्रति सेकंड कितने ऐसे पाठ टुकड़ों को संसाधित करता है।

<br/>

आप प्रत्येक क्रिया की लागत (यदि उपलब्ध हो) और कुल लागत की जांच भी कर सकते हैं, विकल्प सक्षम करके `क्रियाओं पर लागत सूचना दिखाएं` [**सेटिंग्स** > **जनरल सेटिंग्स**](#general-settings) पर।

<a id="transform"></a>

## रूपांतरण

तब **रूपांतरण** का उपयोग करें जब आप चाहते हों कि कृत्रिम बुद्धिमत्ता निर्देशों के अपने कस्टम सेट का अनुसरण करे।

![रूपांतरण वर्कस्पेस](../images/screenshots/hi/transform.png)

ऐप का यह सबसे लचीला भाग है। आप इसे निम्नलिखित जैसे कार्यों के लिए उपयोग कर सकते हैं:

- नोट्स का सारांशन
- कच्चे पाठ को सुव्यवस्थित ईमेल में बदलना
- मुख्य बिंदुओं को निकालना
- पाठ को विशिष्ट प्रारूप में परिवर्तित करना
- इनपुट पाठ के साथ कोई भी अन्य कस्टम गतिविधि

<br/>

<a id="run-an-existing-prompt"></a>
### मौजूदा प्रॉम्प्ट को चलाएं

1. **रूपांतरण** खोलें।
2. प्रॉम्प्ट सूची से एक प्रॉम्प्ट चुनें।
3. यदि **लक्ष्य** भाषा बॉक्स दिखाई दे, तो यदि आप चाहें, तो एक भाषा चुनें।
4. **इनपुट** में पाठ टाइप या पेस्ट करें।
5. **रूपांतरण** पर क्लिक करें।
6. **आउटपुट** में परिणाम पढ़ें।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### यदि आपके पास अभी तक कोई प्रॉम्प्ट नहीं है

यदि आपकी प्रॉम्प्ट सूची खाली है, तो **नमूना प्रॉम्प्ट लोड करें** पर क्लिक करें। इससे आंतरिक उदाहरण जोड़े जाते हैं ताकि आप त्वरित शुरुआत कर सकें।

<br/>

> ℹ️ **नोट**<br/>
> नमूना प्रॉम्प्ट अंग्रेजी में दिए गए हैं। उन्हें लोड करने के बाद, आप किसी प्रॉम्प्ट को संपादित कर सकते हैं और अपनी भाषा में उसका अनुवाद करने के लिए **प्रॉम्प्ट का अनुवाद करें** का उपयोग कर सकते हैं।

<br/>

<a id="create-a-prompt-quickly"></a>
### त्वरित प्रॉम्प्ट बनाएं

कोई प्रॉम्प्ट बनाने का सबसे तेज़ तरीका है:

1. **नया प्रॉम्प्ट** पर क्लिक करें।
2. **प्रॉम्प्ट जनरेट करें** पर क्लिक करें।
3. वर्णन करें कि आप चाहते हैं कि प्रॉम्प्ट क्या करे।
4. एक मॉडल चुनें।
5. ऐप को आपके लिए एक मसौदा बनाने दें।
6. मसौदे की समीक्षा करें और **सहेजें** पर क्लिक करें।

![प्रॉम्प्ट जनरेट करें](../images/screenshots/hi/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### एक प्रॉम्प्ट को संपादित करें

जब आप कोई प्रॉम्प्ट बनाते या संपादित करते हैं, तो संपादक बाईं ओर दिखाई देता है और एक परीक्षण क्षेत्र दाईं ओर दिखाई देता है।

![रूपांतरण प्रॉम्प्ट संपादक](../images/screenshots/hi/transform-prompt-edit.png)

मुख्य फ़ील्ड्स हैं:

- **प्रॉम्प्ट नाम**: प्रॉम्प्ट सूची में दिखाया गया नाम।
- **प्रॉम्प्ट निर्देश (वैकल्पिक)**: प्रॉम्प्ट चलाते समय उपयोगकर्ता को दिखाया जाने वाला संक्षिप्त सुझाव।
- **मॉडल भूमिका**: कृत्रिम बुद्धिमत्ता को दी गई समग्र भूमिका, जैसे 'आप एक सहायक सहायक हैं।'
- **मॉडल निर्देश (प्रति लाइन एक)**: विशिष्ट नियम जिन्हें आप चाहते हैं कि आई अनुसरण करे।
- **आउटपुट विवरण**: परिणाम का वर्णन करने वाला एक छोटा शब्द, जैसे 'सारांश' या 'पुनर्लेखन'।
- **तापमान (0.0 → 1.0)**: मॉडल कैसे व्यवहार करेगा; नीचे देखें।
- **लक्ष्य भाषा के लिए पूछें**: प्रॉम्प्ट चलाते समय एक लक्ष्य भाषा सेलेक्टर जोड़ता है।

यदि आपके लिए तकनीकी शब्द **तापमान** नया है, तो इसे इस तरह सोचें:

- **कम** तापमान स्थिर, अधिक भविष्यसूचक परिणाम देता है।
- **उच्च** तापमान अधिक विविधता और रचनात्मकता देता है।

आप इसका भी उपयोग कर सकते हैं:

- **`प्रॉम्प्ट जनरेट करें`** एक सरल विवरण से एक नया मसौदा बनाने के लिए
- **`प्रॉम्प्ट सुधारें`** मौजूदा प्रॉम्प्ट को सुधारने के लिए
- **`प्रॉम्प्ट का अनुवाद करें`** प्रॉम्प्ट फ़ील्ड का अनुवाद करने के लिए

<br/>

> ⚠️ **चेतावनी**<br/>
> **`वापस चलाने के लिए`** पर क्लिक करने से पहले **`सहेजें`** पर क्लिक करें। यदि बिना सहेजे आप वापस जाते हैं, तो आपके परिवर्तन खो जाएंगे।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### उपयोग करने से पहले प्रॉम्प्ट का परीक्षण करें

दाईं ओर स्थित परीक्षण पैनल आपको नमूना पाठ के साथ अपने प्रॉम्प्ट का परीक्षण करने की अनुमति देता है इससे पहले कि आप उसका दैनिक कार्य में उपयोग करें।

यह तब उपयोगी है जब:

- आप एक नया प्रॉम्प्ट बना रहे हैं
- आप दो संस्करणों की तुलना कर रहे हैं
- आप स्वर, लंबाई या आउटपुट प्रारूप की जांच करना चाहते हैं

<br/>

> ℹ️ **नोट**<br/>
> आप [**सेटिंग्स** > **रूपांतरण प्रॉम्प्ट**](#transform-prompts) में सहेजे गए प्रॉम्प्ट को निर्यात और आयात कर सकते हैं।

### डैशबोर्ड टैब

- **सारांश** उपयोग और लागत का एक समेकित अवलोकन देता है।
- **उपयोग अनुसार** गतिविधि को अनुवाद भाषा, पुनर्लेखन मोड और परिवर्तन प्रॉम्प्ट के आधार पर विभाजित करता है।
- **मॉडल अनुसार** दर्शाता है कि आपने कौन से मॉडल का उपयोग किया और उनकी लागत क्या थी।
- **दिनांक अनुसार** दैनिक कुल योग दिखाता है।
- **सभी कॉल** पूर्ण कॉल इतिहास दिखाता है और आपको इसे निर्यात करने की सुविधा देता है।

- **XLSX**

यह तब उपयोगी होता है जब आप एप्लिकेशन के बाहर गतिविधि की समीक्षा करना चाहते हैं या कोई रिपोर्ट साझा करना चाहते हैं।

<br/>

<a id="delete-stored-records-for-a-model"></a>
### किसी मॉडल के लिए संग्रहित रिकॉर्ड हटाएँ

**मॉडल के अनुसार** या **सभी कॉल** में, आप मॉडल के लिए संग्रहित रिकॉर्ड को "कचरा बिन" आइकन पर क्लिक करके हटा सकते हैं।

> ⚠️ **चेतावनी**<br/>
> संग्रहित रिकॉर्ड को हटाने की प्रक्रिया वापस नहीं की जा सकती। केवल तभी इसका उपयोग करें जब आपको यकीन हो कि आपको उस इतिहास की आवश्यकता नहीं है।

सभी डेटा हटाने या उम्र के आधार पर रिकॉर्ड हटाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) पर जाएँ। वहाँ आपको सभी संग्रहित डेटा या किसी निश्चित तारीख से पुराने डेटा को हटाने के विकल्प मिलेंगे।

## सेटिंग्स

ऐप के व्यवहार को अनुकूलित करने के लिए साइडबार से **सेटिंग्स** खोलें।

उपलब्ध टैब प्लेटफॉर्म और आपकी भूमिका के आधार पर निर्भर करते हैं:

  | टैब                     | डेस्कटॉप | वेब (व्यवस्थापक) | वेब (सामान्य उपयोगकर्ता) |
  |-------------------------|:-------:|:-----------:|:------------------:|
  | सामान्य सेटिंग्स       |   हाँ   |     हाँ     |        हाँ         |
  | मॉडल                   |   हाँ   |     हाँ     |        हाँ         |
  | भाषाएँ                |   हाँ   |     हाँ     |        हाँ         |
  | लागत ट्रैकिंग          |   हाँ   |     हाँ     |         —          |
  | परिवर्तन प्रॉम्प्ट     |   हाँ   |     हाँ     |        हाँ         |
  | उपयोगकर्ता              |    —    |     हाँ     |         —          |
  | API कॉन्फ़िग           |   हाँ   |     हाँ     |         —          |
  | बारे में               |   हाँ   |     हाँ     |        हाँ         |

<br/>

> ℹ️ **नोट**<br/>
> वेब संस्करण में, प्रत्येक उपयोगकर्ता की अपनी कॉन्फ़िगरेशन होती है। चयनित मॉडल, भाषाएँ, सामान्य विकल्प और परिवर्तन प्रॉम्प्ट जैसी सेटिंग्स प्रत्येक उपयोगकर्ता के लिए संग्रहित होती हैं। आपके द्वारा किए गए परिवर्तन अन्य उपयोगकर्ताओं को प्रभावित नहीं करते।

<a id="general-settings"></a>
### सामान्य सेटिंग्स

टाइपिंग व्यवहार नियंत्रित करने के लिए, **इतिहास** के लिए निष्पादन विवरण संग्रहित करने के लिए, और दिखावट के लिए **सामान्य सेटिंग्स** का उपयोग करें।

**व्यवहार**

- **ENTER के लिए व्यवहार** चुनता है कि `Enter` कार्य को चलाए या नई पंक्ति डाले।
- **पेस्ट पर स्वचालित अनुवाद** तुरंत अनुवाद शुरू करता है जब आप पाठ चिपकाते हैं।
- **क्लिपबोर्ड पर परिणाम की प्रति स्वचालित रूप से कॉपी करें** सफल परिणामों को स्वचालित रूप से कॉपी करता है।
- **वास्तविक समय अनुवाद (टाइप करते समय)** आपके टाइप करते समय अनुवाद करता है।
- **समय समाप्ति (मिलीसेकंड)** वास्तविक समय अनुवाद के लिए प्रतीक्षा समय निर्धारित करता है।

**इतिहास**

- **निष्पादन इतिहास बनाए रखें** नियंत्रित करता है कि प्रत्येक अनुवाद, पुनर्लेखन और परिवर्तन **इनपुट और आउटपुट पाठ** को साइडबार [**इतिहास**](#history) दृश्य के लिए संग्रहित करता है। इसे बंद करने पर पुष्टि के लिए कहा जाएगा; अगर आप पुष्टि करते हैं, तो संग्रहित इतिहास पाठ डेटाबेस से हटा दिया जाएगा।
- **इतिहास डेटा हटाएँ** आयु के आधार पर (उदाहरण के लिए कुछ महीनों से पुराना, या **सभी डेटा (साफ करें)**) संग्रहित पाठ को **डेटा हटाएँ** का उपयोग करके हटाने की अनुमति देता है। यह केवल **इतिहास** दृश्य के लिए सहेजे गए निष्पादन पाठ को प्रभावित करता है; यह **लागत या उपयोग के कुल योग** को नहीं हटाता है। **लागत** डेटा को हटाने या काटने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) का उपयोग करें।

**दिखावट**

- **क्रियाओं पर लागत जानकारी दिखाएँ** प्रति संचालन लागत (यदि उपलब्ध हो) और अनुवाद, पुनर्लेखन और परिवर्तन आउटपुट पैनलों पर कुल लागत के प्रदर्शन को नियंत्रित करता है।
- **लागत भिन्न अंक** लागत दशमलव को कैसे प्रदर्शित करना है, उसे बदलता है।
- **केवल वेब के लिए:** **ऐप के चारों ओर मार्जिन दिखाएँ** इंटरफ़ेस के चारों ओर अतिरिक्त स्थान जोड़ता है।
- **फॉन्ट फैमिली** पाठ पैनलों में लिखाई का फ़ॉन्ट बदलता है।
- **आकार** फ़ॉन्ट आकार को बदलता है।

<br/>

<a id="models"></a>

### मॉडल

टूलबार में दिखने वाले मॉडल चुनने के लिए **सेटिंग्स** > **मॉडल** का उपयोग करें।

![सेटिंग्स मॉडल टैब](../images/screenshots/hi/settings-models.png)

इस पृष्ठ पर दो सूचियां हैं:

- बाईं ओर **उपलब्ध मॉडल**
- दाईं ओर **चयनित मॉडल**

उपयोगी नियंत्रण में शामिल हैं:

- **मॉडल खोजें...** — नाम से मॉडल खोजने के लिए
- **प्रदाता** चिप्स — सूची को एक इंजन (OpenRouter, OpenAI, Ollama, …) तक सीमित करने के लिए
- केवल **मुफ्त** — केवल मुफ्त मॉडल दिखाने के लिए
- **ताज़ा करें** — सूची को पुनः लोड करने के लिए
- **सभी विस्तारित करें** और **सभी संक्षिप्त करें**, जब आप प्रदाता द्वारा क्रमबद्ध कर रहे हों

मॉडल आईडी में प्रदाता प्रिफ़िक्स शामिल होता है (उदाहरण के लिए `openrouter/…` बनाम `openai/…`)। बैज जैसे **OpenAI (OpenRouter)** या **OpenAI (सीधा)** यह दिखाते हैं कि ट्रैफ़िक कैसे मार्ग प्रस्तुत करता है।

> ℹ️ **नोट**<br/>
> **OpenRouter बॉडी बिल्डर** (`openrouter/bodybuilder`) एक मार्ग मॉडल है, सामान्य चैट मॉडल नहीं: इसका उत्तर JSON है जो OpenRouter API अनुरोध निकायों का विवरण देता है (जैसे `model` और `messages` के साथ `requests` सरणी)। यदि आप इसका उपयोग **अनुवाद**, **पुनर्लेखन**, या **परिवर्तन** के लिए करते हैं, तो आउटपुट पैनल तैयार पाठ के बजाय वह JSON दिखाएगा। इन कार्यों के लिए एक सामान्य पाठ मॉडल चुनें। OpenRouter पर [बॉडी बिल्डर मॉडल पृष्ठ](https://openrouter.ai/openrouter/bodybuilder) देखें।

क्रियाएँ:

 - कोई मॉडल जोड़ने के लिए, **जोड़ें** पर क्लिक करें या एंट्री में कहीं भी क्लिक करें।

 - कोई मॉडल हटाने के लिए, **चयनित मॉडल** में इसके बगल में **X** पर क्लिक करें या उपलब्ध मॉडल में एंट्री पर **चयनित** पर क्लिक करें।

 - सूची साफ़ करने के लिए, **सभी अचयनित करें** पर क्लिक करें। आवश्यक मुफ्त मॉडल सूची में बना रहेगा।

<br/>

> ℹ️ **नोट**<br/>
> यदि आप OpenRouter में तुरंत क्रेडिट जोड़ना नहीं चाहते हैं, तो **केवल मुफ्त** सक्षम करने से शुरू करें और मुफ्त मॉडल (क्रेडिट कार्ड की आवश्यकता नहीं) चुनें। आप Ollama का उपयोग करके किसी भी API कुंजी के बिना मॉडल स्थानीय रूप से भी चला सकते हैं।

<br/>

<a id="languages"></a>
### भाषाएँ

ऐप में उपयोग की जाने वाली भाषा सूचियों को व्यवस्थित करने के लिए **सेटिंग्स** > **भाषाएँ** का उपयोग करें।

- **शीर्ष भाषाएँ**, **अनुवाद** और **परिवर्तन** में भाषा सूचियों के ऊपरी हिस्से में पिन की गई होती हैं।
- **कस्टम भाषा** आपको निर्मित सूची में नहीं होने वाली भाषा जोड़ने की अनुमति देती है।

यदि आप एक कस्टम भाषा जोड़ते हैं, तो यह अंतर्निर्मित विकल्पों के साथ भाषा चयनकर्ताओं में दिखाई देगी।

<br/>

<a id="cost-tracking"></a>
### लागत ट्रैकिंग

लागत सूचना को प्रबंधित करने के लिए **सेटिंग्स** > **लागत ट्रैकिंग** का उपयोग करें।

- **कुल लागत** चल रहे कुल को दिखाता है।
- **मान कॉपी करें** कुल राशि को क्लिपबोर्ड पर कॉपी करता है।
- **रीसेट लागत** संग्रहीत कुल को शून्य पर रीसेट करता है।
- **API कुंजी उपयोग के साथ सिंक** कुल को OpenRouter खाते द्वारा रिपोर्ट कुल उपयोग से मिलाता है (केवल OpenRouter)।
- **API कुंजी उपयोग** OpenRouter उपयोग विवरण दिखाता है, यदि उपलब्ध हो।
- **लागत डेटा हटाएँ** सभी डेटा हटाता है, या केवल चयनित तिथि से पुराने प्रविष्टियाँ।

**लागत ट्रैकिंग:** जब आप OpenRouter मॉडल का उपयोग करते हैं, तो ऐप OpenRouter से लागत सूचना के आधार पर आपके वास्तविक उपयोग और खर्च को दिखाता है। अन्य सभी प्रदाताओं के लिए, ऐप OpenRouter द्वारा प्रकाशित मूल्यों का उपयोग करके लागत का अनुमान लगाता है, यदि कोई मूल्य उपलब्ध नहीं है, तो अनुमान शून्य हो सकता है।

<br/>

> ℹ️ **नोट**<br/>
> सभी लागत आँकड़े केवल आपके संदर्भ के लिए अनुमान हैं, आधिकारिक बिलिंग विवरण नहीं।

<br/>

> ⚠️ **चेतावनी**<br/>
> डेटा हटाने की प्रक्रिया को वापस नहीं किया जा सकता। हटाने से पहले, कृपया अपने डेटा का बैकअप लें या [**इतिहास**](#history) या [**डैशबोर्ड** > **सभी कॉल**](#dashboard-tabs) के माध्यम से निर्यात करें, अन्यथा यह स्थायी रूप से खो जाएगा। प्रत्येक API कॉल प्रविष्टि से संबंधित सभी इनपुट/आउटपुट इतिहास को भी हटा दिया जाएगा।

<br/>

<a id="transform-prompts"></a>
### परिवर्तन संकेतक

**सेटिंग्स** > **परिवर्तन संकेतक** का उपयोग मुख्य रूप से प्रॉम्प्ट को प्रबंधित करने के लिए करें।

आप कर सकते हैं:

- अपने सहेजे गए प्रॉम्प्ट की समीक्षा करें
- प्रॉम्प्ट हटाएँ
- एक फाइल से प्रॉम्प्ट आयात करें
- बैकअप या साझाकरण के लिए प्रॉम्प्ट निर्यात करें

<br/>

<a id="users"></a>
### उपयोगकर्ता

वेब संस्करण में उपयोगकर्ता खातों का प्रबंधन करने के लिए **उपयोगकर्ता** का उपयोग करें। आप उपयोगकर्ता जोड़ सकते हैं, उनकी जानकारी अपडेट कर सकते हैं, पासवर्ड रीसेट कर सकते हैं और खाते हटा सकते हैं।

<br/>

<a id="api-config"></a>
### API कॉन्फ़िग

समर्थित प्रदाता हैं: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, और **Ollama** (बेस URL के माध्यम से स्थानीय मॉडल)। आप केवल उन प्रदाताओं को कॉन्फ़िगर करने की आवश्यकता है जिनका उपयोग आप करते हैं।

**वेब एप्लिकेशन: केवल प्रशासक के लिए**

API कुंजियाँ सिस्टम या Docker पर्यावरण चर के माध्यम से कॉन्फ़िगर की जाती हैं — वे वेब UI में दर्ज नहीं की जातीं। यह पृष्ठ दर्शाता है कि किन प्रदाताओं के लिए कुंजी कॉन्फ़िगर की गई है और **`परीक्षण`** बटन पर क्लिक करके प्रत्येक का परीक्षण करने की अनुमति देता है।

<br/>

> ℹ️ **नोट**<br/>
> किसी API कुंजी को बदलने के लिए, अपने सिस्टम या Docker कॉन्फ़िगरेशन में पर्यावरण चर को अपडेट करें और सर्वर या कंटेनर को पुनः आरंभ करें।

<br/>

**डेस्कटॉप एप्लिकेशन**

अपने उपयोग किए गए प्रत्येक प्रदाता के लिए API कुंजियों को संग्रहीत करने के लिए **API कॉन्फ़िग** का उपयोग करें। Ollama के लिए, कोई API कुंजी दर्ज करने के बजाय **बेस URL** दर्ज

### बारे में

**बारे में** टैब में दिखाया जाता है:

- ऐप का नाम
- संस्करण संख्या
- बिल्ड तिथि
- प्रोजेक्ट रिपॉजिटरी का लिंक

<br/><br/>

<a id="common-issues"></a>
## सामान्य समस्याएँ

यदि कुछ अपेक्षित रूप से काम नहीं कर रहा है, तो पहले निम्न बिंदुओं की जाँच करें।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ऐप पाठ का अनुवाद, पुनर्लेखन या रूपांतरण नहीं करता है

इसकी जाँच करें:

- क्या आपने टूलबार में एक मॉडल चुना है
- कम से कम एक मॉडल [**सेटिंग्स** > **मॉडल्स**](#models) में सूचीबद्ध है
- आपका API सेटअप काम कर रहा है

यदि आप डेस्कटॉप ऐप का उपयोग कर रहे हैं:

1. [**सेटिंग्स** > **API कॉन्फ़िग**](#api-config) खोलें।
2. जाँच करें कि कम से कम एक API कुंजी सहेजी गई है।
3. कुंजी काम कर रही है यह पुष्टि करने के लिए प्रदाता के बगल में **टेस्ट** पर क्लिक करें।

<br/>

<a id="the-model-list-is-empty"></a>
### मॉडल सूची खाली है

[**सेटिंग्स** > **मॉडल्स**](#models) खोलें और **रिफ्रेश** पर क्लिक करें।

यदि आवश्यक हो:

- किसी मॉडल की खोज करें
- **केवल मुफ़्त** चालू करें
- **चयनित मॉडल्स** में एक या अधिक मॉडल जोड़ें

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### परिणाम बहुत धीमा या बहुत महँगा है

इनमें से एक या अधिक का प्रयास करें:

- एक अलग मॉडल चुनें
- छोटा इनपुट उपयोग करें
- [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) में **रीयल-टाइम अनुवाद (टाइपिंग के दौरान)** को बंद करें
- सरल कार्यों के लिए मुफ्त मॉडल का उपयोग करें (देखें [मॉडल्स](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### इंटरफ़ेस गलत भाषा में है

[टूलबार](#toolbar) में ग्लोब आइकन पर क्लिक करें और अपनी पसंदीदा **इंटरफ़ेस भाषा** चुनें।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### पाठ बहुत छोटा या पढ़ने में कठिन है

[**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और बदलें:

- **फ़ॉन्ट फ़ैमिली**
- **आकार**

<br/>

<a id="dashboard-charts-are-empty"></a>
### डैशबोर्ड चार्ट खाली हैं

यह सामान्य है यदि:

- आप केवल **मुफ्त मॉडल्स** का उपयोग कर रहे हैं (लागत चार्ट खाली रहेंगे)
- चयनित **समय फ़िल्टर** उस अवधि को कवर नहीं करता है जब कॉल किए गए थे — जाँच करने के लिए **सभी** का प्रयास करें

यदि **सभी** चुनने के बाद भी चार्ट खाली हैं, तो पुष्टि करें कि कॉल [**इतिहास**](#history) या **सभी कॉल** टैब में दिखाई दे रहे हैं।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### लागत "उपलब्ध नहीं" दिखाती है या गलत लगती है

जब आप **ओपनराउटर** के माध्यम से मॉडल्स का उपयोग करते हैं, तो ऐप ओपनराउटर द्वारा रिपोर्ट की गई आपकी वास्तविक खर्च राशि दिखाता है।

**अन्य प्रदाताओं** (ओपनएआई सीधे, एंथ्रोपिक सीधे, आदि) के लिए, लागत ओपनराउटर द्वारा प्रकाशित मूल्य डेटा से अनुमानित होती है। यदि किसी मॉडल के लिए कोई मिलती-जुलती कीमत नहीं मिलती है, तो लागत **उपलब्ध नहीं** के रूप में दिखाई देगी और आपके कुल योग में नहीं जोड़ी जाएगी।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### कुल लागत मेरे प्रदाता के बिल से मेल नहीं खाती

ऐप में सभी लागत आंकड़े केवल **संदर्भ के लिए अनुमान** हैं, आधिकारिक बिलिंग स्टेटमेंट नहीं।

कुल राशि को आपके वास्तविक ओपनराउटर खर्च के करीब लाने के लिए, [**सेटिंग्स** > **लागत ट्रैकिंग**](#cost-tracking) खोलें और **API कुंजी उपयोग के साथ सिंक करें** पर क्लिक करें।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### साइडबार से इतिहास पृष्ठ लापता है

**कार्यान्वयन इतिहास रखें** बंद हो सकता है। [**सेटिंग्स** > **सामान्य सेटिंग्स**](#general-settings) खोलें और इसे सक्षम करें। ध्यान दें कि इसे चालू करने पर पहले हटाए गए इतिहास डेटा को पुनर्स्थापित नहीं किया जाता।

<br/>

<a id="web-app-session-expired"></a>
### वेब ऐप: लॉगिन पृष्ठ पर अप्रत्याशित रूप से पुनर्निर्देशित किया गया

आपका सत्र समय सीमा से बाहर हो सकता है। फिर से लॉग इन करें। यदि यह बार-बार होता है, तो सत्र जीवनकाल सेटिंग्स के लिए सर्वर कॉन्फ़िगरेशन की जाँच करें।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### डैशबोर्ड अन्य उपयोगकर्ताओं के लिए कोई डेटा नहीं दिखाता (वेब)

केवल **प्रशासक** **उपयोगकर्ता** फ़िल्टर के माध्यम से सभी उपयोगकर्ताओं के डेटा को देख सकते हैं। नियमित उपयोगकर्ता केवल अपनी गतिविधि देखते हैं, जैसा डिज़ाइन किया गया है।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### मैंने एक प्रॉम्प्ट बदली और संपादन खो गए

प्रॉम्प्ट संपादित करते समय, हमेशा **बैक टू रन** पर क्लिक करने से पहले **सेव** पर क्लिक करें।

<br/><br/>

<a id="quick-tips"></a>
## त्वरित सुझाव

- आगे बढ़ने से पहले अपने सेटअप को काम करता हुआ सुनिश्चित करने के लिए [**अनुवाद**](#translate) से शुरू करें [**पुनर्लेखन**](#rewrite) या [**रूपांतरण**](#transform) की ओर।
- रोजमर्रा की शब्दावली में सुधार के लिए [**पुनर्लेखन**](#rewrite) का उपयोग करें।
- किसी विशिष्ट कार्य के लिए एक बार-बार उपयोग करने योग्य कार्यप्रवाह के लिए [**रूपांतरण**](#transform) का उपयोग करें।
- उपयोग और लागत पर नज़र रखने के लिए [**डैशबोर्ड**](#dashboard) का उपयोग करें।
- पिछले संचालन और उनके पूर्ण इनपुट/आउटपुट पाठ की समीक्षा करने के लिए [**इतिहास**](#history) का उपयोग करें।
- यदि आप एक प्रॉम्प्ट लाइब्रेरी बना रहे हैं जिसे आप सुरक्षित रखना चाहते हैं (देखें [ट्रांसफ़ॉर्म प्रॉम्प्ट्स](#transform-prompts)) या यदि आप इसे दूसरों के साथ साझा करना चाहते हैं, तो नियमित रूप से प्रॉम्प्ट्स निर्यात करें।
