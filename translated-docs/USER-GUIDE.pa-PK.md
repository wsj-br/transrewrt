# یوزر گائیڈ

<br/>

<a id="introduction"></a>
## تعارف

Transrewrt تِن مُکھ طریقیاں نال ٹیکسٹ نال کم کرن وچ تہاڈی مدد کردا اے:

- **ترجمہ کریں** - اک بولی توں دوجی بولی وچ ٹیکسٹ نوں تبدیل کرو۔
- **دوبارہ لکھو** - ٹیکسٹ نوں وکھرے انداز وچ دوبارہ لکھو، جیویں کہ ودھ صاف، چھوٹا، یا ودھ رسمی۔
- **تبدیل کرو** - کسٹم AI ہدایات دی ورتوں کردے ہوئے ٹیکسٹ نوں پروسیس کرو جیہناں نوں پرامپٹس کہیا جاندا اے۔

پہلے توں طے شدہ طور تے ایپ **آسان** موڈ وچ چلدی اے: تُسی اک **پیش سیٹ** (مثال دے طور تے مفت (اوپن راؤٹر)، سٹینڈرڈ، اعلیٰ، یا تکنیکی) تے سیٹنگاں وچ اک **پرووائیڈر** چُندے ہو، ماڈل ID چُنے بغیر۔ جے تُسی [**سیٹنگاں** > **جنرل سیٹنگاں**](#general-settings) وچ کلاسک ماڈل لسٹ چاہندے ہو تاں [**سیٹنگاں** > **ماڈل**](#models) وچ **اعلیٰ** اُتے سوئچ کرو۔

<br/>

ایہ گائیڈ دسدا اے کہ ایپ انسٹال ہون تے چلن توں بعد ایہنوں کِویں ورتنا اے۔ انسٹالیشن دے مرحلیاں لئی، مُکھ [**README**](README.pa-PK.md) ویکھو۔

<br/>

> ℹ️ **نوٹ**<br/>
> Transrewrt ونڈوز تے لینکس لئی ڈیسک ٹاپ ایپ دے طور تے، تے اک سیلف ہوسٹڈ ویب ایپ دے طور تے دستیاب اے۔ ایہ گائیڈ ایپ دے روزانہ دے استعمال اُتے مرکوز اے۔ جتھے کوئی چیز صرف اک ورژن اُتے لاگو ہوندی اے، اوہ واضح طور تے نشان زد کیتی جاندی اے۔

<a id="before-you-start"></a>
## شروع کرن توں پہلاں

Transrewrt استعمال کرنے کے لیے، آپ کو کم از کم ایک AI پرووائیڈر تک رسائی درکار ہے۔ معاون پرووائیڈرز یہ ہیں: [OpenRouter](https://openrouter.ai) (جو بہت سے ماڈلز کو جمع کرتا ہے)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras، NVIDIA، Alibaba Cloud، apikey.fun، کوئی بھی OpenAI-مطابق پرووائیڈر، اور مقامی ماڈلز کے لیے [Ollama](https://ollama.com).

شروع کرن لئی تہانوں ادا شدہ ماڈل چنن دی لوڑ نہیں اے۔ جیویں ای تُسی اپنی OpenRouter API کی شامل کردے او، ایپ خودکار طور اُتے اک بلٹ اِن **مفت** OpenRouter آپشن نوں فعال کر دیندی اے۔ ایہ تہانوں فوراً ترجمہ، دوبارہ لکھن، تے ٹیکسٹ نوں تبدیل کرن دی اجازت دیندا اے۔ متبادل طور اُتے، تُسی Cerebras، Google، Groq، Mistral AI، یا [NVIDIA](https://build.nvidia.com/) (OpenAI-مطابق API) توں اک مفت API کی وی حاصل کر سکدے او۔

سادہ لفظاں وچ:

- **آسان** موڈ وچ، اک **پیش سیٹ** (مفت (OpenRouter)، سٹینڈرڈ، ایڈوانسڈ، یا ٹیکنیکل) تہاڈے چُنے ہوئے **پرووائیڈر** (OpenRouter، OpenAI، Ollama، تے ہور) لئی اک ماڈل نال نقشہ بناندا اے۔ صرف اوہ پیش سیٹ جہناں دا موجودہ پرووائیڈر لئی نقشہ اے، ٹول بار وچ وکھائی دیندے نیں۔ تُسی ترجمہ، دوبارہ لکھو، تے تبدیل کرو اُتے پیش سیٹ چُندے او۔
- **اعلیٰ** موڈ وچ، اک **ماڈل** اوہ AI انجن اے جہڑا تُسی براہ راست چُندے او۔ ماڈل آئی ڈیز اک **پرووائیڈر پریفکس** ورتدے نیں (مثال دے طور اُتے `openrouter/…`، `openai/…`، `ollama/…`). 
- اک **API کی** (یا، Ollama لئی، اک **بیس URL**) ایہ اے کہ ایپ اس پرووائیڈر تک کِویں پہنچدی اے۔

اگر آپ **ڈیسک ٹاپ ایپ** استعمال کر رہے ہیں، تو ہر پرووائیڈر کے لیے [**سیٹنگاں** > **API کنفِگ**](#api-config) میں کلیدز شامل کریں۔ اوپن راؤٹر کے استعمال کے لیے، نیچے [اوپن راؤٹر API کلید مفت حاصل کرنے کا طریقہ](#how-to-get-a-free-openrouter-api-key-desktop-app) دیکھیں۔ اگر آپ API کلید استعمال نہیں کرنا چاہتے ہیں، تو آپ اولاما ( [ollama.com](https://ollama.com) سے) انسٹال کر سکتے ہیں اور اس کے بجائے لوکل ماڈل استعمال کر سکتے ہیں، جیسے کہ `translategemma:4b`۔

جے تُسی **ویب ورژن** ورت رہے او، تے سرور دے مالک نے ماحول دے متغیرات نال پرووائیڈراں نوں کنفِگ کیتا اے، لہٰذا تُسی براہ راست ایپلیکیشن وچ API کیز داخل نہیں کر سکدے۔

<br/>

<a id="how-to-get-a-free-openrouter-api-key-desktop-app"></a>
### مفت OpenRouter API کی کِویں حاصل کریئے (ڈیسک ٹاپ ایپ)

جے تُسی ڈیسک ٹاپ ایپ ورت رہے او، تے ایہناں قدماں اُتے عمل کرو:

1. اپنے ویب براؤزر وچ [OpenRouter](https://openrouter.ai) اُتے جاؤ۔
2. اک اکاؤنٹ بناؤ یا سائن اِن کرو۔
3. [کیز](https://openrouter.ai/keys) صفحہ کھولو۔
4. اک نویں API کی بناؤن لئی بٹن اُتے کلک کرو۔
5. کی نوں اک نام دیو تاکہ تُسی بعد وچ ایہنوں پچھان سکو۔
6. نویں API کی کاپی کرو۔
7. Transrewrt اُتے واپس آؤ تے **سیٹنگاں** > **API کنفِگ** کھولو۔
8. کی نوں **OpenRouter API کی** وچ پیسٹ کرو (**سیٹنگاں** > **API کنفِگ** دے تھلے)۔
9. ایہ یقینی بناؤن لئی کہ ایہ کم کردا اے، **OpenRouter کی دی جانچ کرو** اُتے کلک کرو۔

<a id="getting-started"></a>
## شروع کرنا

جے تُسی پہلی وار Transrewrt ورت رہے او، تے ایہ ترتیب اپناؤ:

1. ایپ کھولو۔
2. جے لوڑ ہووے تے گلوب آئیکن توں اپنی **انٹرفیس زبان** چُنو۔
3. جے تُسی **ڈیسک ٹاپ ایپ** اُتے او، تے [**سیٹنگاں** > **API کنفِگ**](#api-config) کھولو، گھٹو گھٹ اک پرووائیڈر (مثال دے طور اُتے OpenRouter) لئی اک API کی شامل کرو، تے ایہ تصدیق کرن لئی **جانچ** اُتے کلک کرو کہ ایہ کم کردا اے۔
4. [**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) کھولو۔ **آسان** موڈ (ڈیفالٹ) وچ، اک **پرووائیڈر** چُنو جہدی اک کنفِگ کیتی گئی کی اے۔ **اعلیٰ** موڈ وچ، [**سیٹنگاں** > **ماڈل**](#models) کھولو تے **چُنے گئے ماڈل** وچ اک یا ودھ ماڈل شامل کرو۔
5. **ترجمہ** اُتے، ٹول بار وچ اک **پیش سیٹ** (آسان) یا **ماڈل** (اعلیٰ) چُنو۔
6. [**سیٹنگاں** > **بولیاں**](#languages) کھولو تے اپنی **اُتلی بولیاں** چُنو جے تُسی چاہندے او کہ تہاڈیاں سبھ توں ودھ ورتیاں جان والیاں بولیاں پہلاں وکھائی دین۔
7. ایہ تصدیق کرن لئی اک سادہ ترجمہ چلاؤ کہ سبھ کجھ کم کر رہیا اے، فیر **دوبارہ لکھو** تے **تبدیل کرو** دی کوشش کرو۔

ایہ ترتیب اہم اے۔ ایہ سبھ توں عام پہلی وار ورتن دی پریشانی نوں روکن دی کوشش کردا اے: ایپ دے کول کم کرن والا API کنکشن یا چُنیا گیا پیش سیٹ/ماڈل ہون توں پہلاں اک کم نوں چلاؤن دی کوشش کرنا۔

### ٹولبار

ٹولبار تھوڑا جیہا بدلدا اے اس گل اُتے انحصار کردا اے کہ تسیں ایپ وچ کتھے ہو۔

- کھبے پاسے، ایہہ موجودہ صفحے دا نام دکھاؤندا اے۔
- سجے پاسے، ایہہ **پیش سیٹ جاں ماڈل سلیکٹر** اتے **انٹرفیس زبان** کنٹرول دکھاؤندا اے۔

**آسان** موڈ وچ، ٹولبار اک **پیش سیٹ سلیکٹر** دکھاؤندا اے جس وچ بلٹ-اِن پیش سیٹ **مفت (اوپن راؤٹر)**، **معیاری**، **اعلیٰ**، اتے **تکنیکی** شامل ہن۔ کہڑے پیش سیٹ ظاہر ہندے ہن ایہہ اس **پرووائیڈر** اُتے انحصار کردا اے جو تسیں [**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) وچ چنیا اے — مثال وجوں، **مفت (اوپن راؤٹر)** صرف ادوں درج کیتا جاندا اے جدوں پرووائیڈر اوپن راؤٹر ہووے۔ جے **پرووائیڈر** **اولاما** اے، تاں ٹولبار پیش سیٹاں دی بجائے تہاڈے انسٹال کیتے مقامی ماڈل درج کردا اے۔

**اعلیٰ** موڈ وچ، **ماڈل سلیکٹر** تہانوں ایہہ چنن دیندا اے کہ موجودہ کم لئی کہڑا AI انجن ورتنا اے۔

![Model selector](../images/screenshots/pa-PK/preset-selector.png)

اعلیٰ موڈ وچ، کجھ مفت ماڈل ہمیشہ دستیاب نہیں ہو سکدے — اوہ آف لائن ہو سکدے ہن جاں ورتوں دی حد نوں چھو سکدے ہن۔ ایپ تہاڈی لسٹ توں اس ماڈل نوں اپنے آپ ہٹا سکدی اے۔ ایہہ کنٹرول کرن لئی کہ کہڑے ماڈل ظاہر ہندے ہن، [**سیٹنگاں** > **ماڈل**](#models) اُتے جاؤ۔ تسیں ٹولبار وچ ماڈل دے نام دے کھبے پاسے پرووائیڈر آئیکن توں ماڈل سیٹنگاں کھولھ سکدے ہو۔

<br/>

**گلوب آئیکن + زبان کوڈ** ایپ انٹرفیس دی زبان بدلدا اے، جویں کہ مینو اتے بٹن۔ ایہہ **ترجمہ کریں** وچ ورتیاں گئیاں ترجمہ بولیاں نوں **نہیں** بدلدا۔

![Interface language selector](../images/screenshots/pa-PK/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### ان پٹ اتے آؤٹ پٹ پینل

زیادہ تر ورک سپیس کھبے پاسے **ان پٹ** پینل اتے سجے پاسے **آؤٹ پٹ** پینل دی ورتوں کردے ہن۔

ہر پینل ایہہ وی دکھاؤندا اے:

| **ان پٹ**                                                          | **آؤٹ پٹ**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - اکھراں دی گنتی <br/>- شبداں دی گنتی <br/>- پیراگراف دی گنتی   <br/> | - کم وچ کنا سماں لگیا<br/>- **TPS** (ہر سیکنڈ ٹوکنز)<br/>- اکھراں، شبداں، اتے پیراگرافاں دی گنتی<br/>- ورتیا گیا ماڈل |

جے تسیں تکنیکی شبداں بارے حیران ہو:

- **ٹوکن** دا مطلب اے متن دا اک چھوٹا جیہا حصہ۔ تسیں اس نوں اک شبد دے حصے جاں اک چھوٹے شبد وجوں سوچ سکدے ہو۔
- **TPS** دا مطلب اے کہ ماڈل نے ہر سیکنڈ وچ کنے متن دے حصےآں نوں پروسیس کیتا۔

<br/>

تسیں ہر آپریشن دی لاگت (جے دستیاب ہووے) اتے کل لاگت دی وی نگرانی کر سکدے ہو، [**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) اُتے `Show cost information on the actions` آپشن نوں چالو کرکے۔

<a id="translate"></a>
## ترجمہ کریں

جب آپ متن کو ایک زبان سے دوسری زبان میں تبدیل کرنا چاہتے ہیں تو **ترجمہ کریں** کا استعمال کریں۔

![Translate workspace](../images/screenshots/pa-PK/translate.png)

<br/>

<a id="translate-text"></a>
### متن دا ترجمہ کرو

1. **ترجمہ کریں** کھولیں۔
2. **From** وچوں کوئی زبان چنیں۔
3. **To** وچوں کوئی زبان چنیں۔
4. ٹولبار وچ پیش سیٹ (آسان) یا ماڈل (اعلیٰ) چنیں۔
5. **ان پٹ** میں ٹیکسٹ ٹائپ کرو یا پیسٹ کرو۔
6. **ترجمہ کریں** پر کلک کرو۔
7. **آؤٹ پٹ** میں نتیجہ پڑھو۔
8. اگر آپ نتیجہ کاپی کرنا چاہتے ہیں تو کاپی بٹن استعمال کرو۔
9. اختیاری طور پر، **دوبارہ جملہ بندی کریں…** یا متبادل الفاظ کے ساتھ نتیجے کو بہتر بنائیں — [اپنے ترجمہ کو بہتر بنانا](#refining-translation) دیکھیں۔

<br/>

<a id="language-selection"></a>
### بولی دا انتخاب

- **From** اک خاص زبان یا **زبان دا پتہ لاؤ** ہو سکدا اے۔
- **To** اوہ زبان اے جیہدے وچ تُسی نتیجہ چاہندے او۔

تُہاڈیاں چُنیاں گئیاں **اُتّلیاں بولیاں** لسٹ دے اُتّے وکھائی دیندیاں نیں۔ تُسی ایہناں نوں [**سیٹنگاں** > **بولیاں**](#languages) وچ سیٹ کر سکدے او۔

<br/>

<a id="helpful-translation-settings"></a>
### مددگار ترجمہ سیٹنگاں

[**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) وچ، تُسی بدل سکدے او کہ ترجمہ کِداں کم کردا اے:

- **پیسٹ کرن اُتے خودکار عملدرآمد** جیویں ای تُسی متن پیسٹ کردے او، ترجمہ چلا دیندا اے۔
- **نتیجے نوں خودکار طور اُتے کلپ بورڈ اُتے کاپی کرو** کامیاب عملدرآمد توں بعد نتیجے نوں خودکار طور اُتے کاپی کردا اے۔
- **ٹائپ کردے ہوئے حقیقی وقت وچ ترجمہ** (⚠️ ایہ استعمال دے اخراجات وچ وادھا کر سکدا اے) ٹائپ کردے ہوئے ترجمے چلا دیندا اے۔
- **ٹائم آؤٹ (ms)** کنٹرول کردا اے کہ ایپ حقیقی وقت دے ترجمے نوں چلاون توں پہلاں کِنّی دیر انتظار کردی اے۔
- **ENTER لئی رویہ** ایہ چُݨدا اے کہ آیا `Enter` ٹاسک چلاندا اے یا اک نویں لائن داخل کردا اے:
  - **Enter** ترجمہ یا دوبارہ لکھو نوں چلاندا اے (ڈیفالٹ)۔
  - **Shift + Enter** ترجمہ یا دوبارہ لکھو نوں چلاندا اے؛ سادہ **Enter** اک نویں لائن داخل کردا اے۔

<br/>

<a id="refining-translation"></a>
### اپنے ترجمے نوں بہتر بنانا

اک کامیاب ترجمہ توں بعد، **دوبارہ لکھو…** تے ورژن ڈراپ ڈاؤن آؤٹ پٹ ہیڈر وچ، **تائیں:** بولی سلیکٹر دے نال ظاہر ہوندے نیں۔ تُسی اوتھے نتیجے نوں بہتر کر سکدے او:

1. **دوبارہ بیان کریں…** — اگر آؤٹ پٹ میں کوئی متن منتخب نہیں کیا گیا ہے، تو اسی ان پٹ کا ایک مکمل ترجمہ مختلف الفاظ میں حاصل کریں۔ ماڈل ہر وہ ورژن حاصل کرتا ہے جو آپ کے پاس پہلے سے موجود ہے، اس لیے نئے الفاظ پہلے سے موجود تمام ورژن سے مختلف ہو سکتے ہیں۔ آپ **پانچ** ورژن تک ذخیرہ کر سکتے ہیں اور ورژن ڈراپ ڈاؤن میں ان کے درمیان سوئچ کر سکتے ہیں۔ متن منتخب کرنے کے ساتھ، **دوبارہ بیان کریں…** انتخاب کے قریب الفاظ کے متبادل کھولتا ہے (بیلے بٹن پر کلک کرنے کی طرح)۔ کوئی انتخاب نہیں کیا گیا تو، **دوبارہ بیان کریں…** پانچ ورژن تک پہنچنے کے بعد غیر فعال ہو جاتا ہے؛ انتخاب کے ساتھ، یہ پانچ ورژن پر بھی کام کرتا ہے (صرف الفاظ کے متبادل، ورژن 5 کو اپ ڈیٹ کرتے ہوئے)۔ جب مکمل دوبارہ بیان چل رہا ہو، تو **روکو ترجمہ** پر کلک کریں تاکہ منسوخ کریں؛ آؤٹ پٹ وہ ورژن پر واپس آ جاتا ہے جو دوبارہ بیان شروع ہونے سے پہلے فعال تھا۔
2. **الفاظ کے متبادل** — آؤٹ پٹ میں ایک یا ایک سے زائد الفاظ یا ایک مختصر جملہ منتخب کریں (اگر آپ صرف ایک لفظ کا حصہ منتخب کرتے ہیں، تو ایپ پورے الفاظ تک انتخاب کو پھیلاتا ہے)، پھر دائیں بٹن پر کلک کریں یا **دوبارہ بیان کریں…** پر کلک کریں۔ انتخاب کے قریب ایک مختصر فہرست متبادل ظاہر ہوتی ہے؛ ایک پر کلک کریں تاکہ اسے بدل سکیں۔ ہر آپشن آپ کے انتخاب سے تھوڑا سا زیادہ دائرہ بدل سکتا ہے (مثلاً ایک متصل پیش لفظ یا مضمون) تاکہ جملہ گرامر کے مطابق رہے۔ اگر آپ کے پاس پانچ سے کم ورژن ہیں، تو ترمیم شدہ آؤٹ پٹ کو ایک نئے ورژن کے طور پر بچایا جاتا ہے؛ پانچ ورژن پر، صرف **ورژن 5** کو اپ ڈیٹ کیا جاتا ہے۔ کوئی انتخاب کیے بغیر دائیں بٹن پر کلک کرنے سے کوئی کام نہیں ہوتا۔ **Esc** دبائیں یا فہرست کے باہر کلک کریں تاکہ آؤٹ پٹ کو بدلے بغیر منسوخ کریں۔
3. **لاگت** — ہر مکمل **دوبارہ بیان کریں…** (کوئی انتخاب نہیں) اور ہر لفظ متبادل کی درخواست ماڈل کو دوبارہ استعمال کرتی ہے اور استعمال کی لاگت میں اضافہ کر سکتی ہے (عادی ترجمہ رن کی طرح)۔

<br/>

<a id="using-the-glossary"></a>
### لغت دا استعمال

ایک **لغت** دو زبانوں کے درمیان مخصوص زبان کے جوڑے کے لئے ماخذ/ہدف اصطلاح کے جوڑے کی فہرست ہوتی ہے۔ جب لغت چालو ہو، تو Transrewrt مطابقت رکھنے والے اصطلاحات کو ماڈل کو بھیجتا ہے تاکہ آپ کی ترجیحی لفظیں ترجموں میں لگاتار رہیں (مثلاً ایک پروڈکٹ کا نام، ایک برانڈ کا اصطلاح، یا ایک ملازمت کا عہدہ جو ہمیشہ ایک ہی طرح ترجمہ ہونا چاہئے)۔

اسے **ترجمہ کریں** صفحہ پر استعمال کرنے کے لیے:

1. ان پٹ پینل وچ **لغت** سوئچ آن کرو (آٹو-ایگزیکیوٹ اَتے آٹو-کاپی سوئچز دے نال).
2. اپنی **اَتوں** اَتے **تک** بولیاں چُنو اَتے معمول دے مطابق ترجمہ کرو. اُس زبان دے جوڑے لئی محفوظ کیتیاں گئیاں اصطلاحات خود بخود لاگو ہو جاندیاں نیں.
3. نویں جوڑے نوں فوری طور تے کیپچر کرن لئی، **لغت وچ شامل کرو** تے کلک کرو (**اَتوں:** زبان سلیکٹر دے نال). ڈائیلاگ تہاڈیاں موجودہ بولیاں نال پہلے توں بھریا ہویا اے، لہٰذا تُسیں صرف **ماخذ اصطلاح** اَتے **ہدف اصطلاح** پُرو گے.
4. آؤٹ پٹ فوٹر وچ **لغت** لنک (یا ڈائیلاگ دے اندر **لغت دا انتظام کرو** لنک) نوں [**سیٹنگاں** > **لغت**](#glossary-settings) تے جان لئی استعمال کرو اَتے اپنی ساریاں اصطلاحات دا جائزہ لوو.

تُسیں [**سیٹنگاں** > **لغت**](#glossary-settings) ٹیب وچ اصطلاحات شامل، ترمیم، درآمد اَتے برآمد کردے او — تھلے ویکھو.

<br/>

> ℹ️ **نوٹ**<br/>
> لغت دیاں اصطلاحات **زبان دے جوڑے** نال ملدیاں نیں، لہٰذا انگریزی → فرانسیسی لئی محفوظ کیتی گئی اصطلاح انگریزی → جرمن دا ترجمہ کردے ویلے لاگو نہیں ہوندی. لغت نوں ماخذ دے طور تے **زبان دا پتہ لاؤ** نال استعمال نہیں کیتا جا سکدا، کیونکہ اصطلاحات نوں ملان لئی اک مخصوص ماخذ زبان دی لوڑ ہوندی اے.

<a id="rewrite"></a>
## دوبارہ لکھو

جدوں تُسیں مرکزی معنی نوں تبدیل کیتے بغیر الفاظ نوں بہتر بنانا چاہندے او تے **دوبارہ لکھو** استعمال کرو.

![Rewrite workspace](../images/screenshots/pa-PK/rewrite.png)

ایہہ ایہناں لئی مفید اے:

- ہِجّے اَتے گرامر نوں ٹھیک کرنا (**ہِجّے اَتے گرامر چیک کرو**)
- متن نوں ہور واضح بنانا (**وضاحت بہتر کرو**)
- اک ہی رن وچ کئی وکھرے اصلاحات (**متبادل ورژنز**)
- متن نوں ہور رسمی یا ہور غیر رسمی بنانا (**رسمی بناؤ** / **غیر رسمی بناؤ**)
- متن نوں مختصر یا پھیلاؤنا (**مختصر کرو** / **پھیلاؤ**)
- متن نوں ہور تکنیکی بنانا (**تکنیکی بناؤ**)

<br/>

> 💡 **ٹِپ**<br/>
> جدوں تُسیں "**ہِجّے اَتے گرامر چیک کرو**" موڈ استعمال کردے او، تے آؤٹ پٹ پینل وچ اک **تبدیلیاں وکھاؤ** سوئچ ظاہر ہوندا اے (**کاپی کرو** دے نال).
> اپنے متن تے لاگو کیتیاں گئیاں مخصوص اصلاحات نوں وکھاؤن یا لکاؤن لئی ایہنوں آن یا آف کرو.

<a id="transform"></a>
## تبدیل کرو

جدوں تُسیں چاہندے او کہ AI ہدایات دے اک کسٹم سیٹ دی پیروی کرے تے **تبدیل کرو** استعمال کرو.

![Transform workspace](../images/screenshots/pa-PK/transform.png)

ایہہ ایپ دا سبھ توں لچکدار علاقہ اے. تُسیں ایہنوں ایہناں کماں لئی استعمال کر سکدے او جیویں کہ:

- نوٹس دا خلاصہ کرنا
- کچے متن نوں اک پالش کیتی ہوئی ای میل وچ تبدیل کرنا
- اہم نکات کڈھنا
- متن نوں اک مخصوص فارمیٹ وچ تبدیل کرنا
- ان پٹ متن دے نال کوئی ہور کسٹم سرگرمی

<br/>

<a id="run-an-existing-prompt"></a>
### اک موجودہ پرامپٹ چلاؤ

1. **تبدیل کرو** کھولو.
2. پرامپٹ لسٹ توں اک پرامپٹ چُنو.
3. جے اک **اَتوں** زبان دا ڈبہ ظاہر ہوندا اے، تے جے تُسیں چاہندے او تے اک زبان چُنو.
4. **ان پٹ** وچ متن ٹائپ یا پیسٹ کرو.
5. **تبدیل کرو** تے کلک کرو.
6. **آؤٹ پٹ** وچ نتیجہ پڑھو.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### جے تہاڈے کول حالے کوئی پرامپٹ نہیں اے

جے تہاڈی پرامپٹ لسٹ خالی اے، تے ٹرانسفارم ورک اسپیس وچ **نمونے دے پرامپٹ لوڈ کرو** تے کلک کرو. ایہی کنٹرول ہمیشہ [**سیٹنگاں** > **تبدیل کرو**](#transform-settings) وچ ایکسپورٹ/امپورٹ قطار تے دستیاب ہوندا اے. دوویں بلٹ ان مثالاں شامل کردے نیں تاکہ تُسیں جلدی شروع کر سکو.

<br/>

> ℹ️ **نوٹ**<br/>
> نمونے دے پرامپٹ انگریزی وچ فراہم کیتے جاندے نیں. ایہناں نوں لوڈ کرن توں بعد، تُسیں اک پرامپٹ وچ ترمیم کر سکدے او اَتے ایہنوں اپنی زبان وچ ترجمہ کرن لئی **پرامپٹ ترجمہ کرو** استعمال کر سکدے او.

<br/>

<a id="create-a-prompt-quickly"></a>
### جلدی نال اک پرامپٹ بناؤ

پرامپٹ بنان دا سبھ توں تیز طریقہ ایہہ اے:

1. **نواں پرامپٹ** اُتے کلک کرو۔
2. **پرامپٹ تیار کرو** اُتے کلک کرو۔
3. بیان کرو کہ تُسی پرامپٹ توں کی کروانا چاہندے او۔
4. اک پیش سیٹ (آسان) یا ماڈل (اعلیٰ) چُنو۔
5. ایپ نوں تہاڈے لئی اک ڈرافٹ بنان دیو۔
6. ڈرافٹ دا جائزہ لو تے **محفوظ کرو** اُتے کلک کرو۔

![Generate prompt](../images/screenshots/pa-PK/transform-generate.png)

<a id="edit-a-prompt"></a>
### اک پرامپٹ وچ ترمیم کرو

جدوں تُسی اک پرامپٹ بناؤندے یا ترمیم کردے او، ایڈیٹر کھبے پاسے تے اک ٹیسٹ ایریا سجے پاسے ظاہر ہوندا اے۔

![Transform prompt editor](../images/screenshots/pa-PK/transform-prompt-edit.png)

اہم فیلڈز ایہہ نیں:

- **پرامپٹ دا ناں**: پرامپٹ لسٹ وچ دکھایا گیا ناں۔
- **پرامپٹ ہدایات (اختیاری)**: یوزر نوں پرامپٹ چلاؤندے ویلے اک مختصر اشارہ دکھایا جاندا اے۔
- **ماڈل دا کردار**: AI نوں دتا گیا مجموعی کردار، جویں کہ 'تُسی اک مددگار اسسٹنٹ او۔'
- **ماڈل ہدایات (ہر لائن اُتے اک)**: اوہ مخصوص اصول جیہناں دی تُسی AI توں پیروی کروانا چاہندے او۔
- **آؤٹ پٹ دی تفصیل (مثلاً، تبدیل شدہ، خلاصہ شدہ، وغیرہ)**: نتیجے نوں بیان کرن والا اک مختصر لفظ۔
- **درجہ حرارت (0.0 → 1.0)**: ماڈل کِداں برتاؤ کرے گا؛ تھلے ویکھو۔
- **ہدف زبان منگو**: پرامپٹ چلاندے ویلے اک زبان سلیکٹر شامل کردا اے۔
جے تکنیکی اصطلاح **درجہ حرارت** تہاڈے لئی نویں اے، تے ایہنوں ایویں سمجھو:

- اک **گھٹ** درجہ حرارت زیادہ مستحکم، زیادہ پیش قیاسی نتائج دیندا اے۔
- اک **زیادہ** درجہ حرارت زیادہ قسم تے تخلیقی صلاحیت دیندا اے۔

تُسی ایہہ وی استعمال کر سکدے او:

- `Generate prompt` اک سادہ تفصیل توں اک نواں ڈرافٹ بنان لئی
- `Improve prompt` اک موجودہ پرامپٹ نوں بہتر کرن لئی
- `Translate prompt` پرامپٹ فیلڈز دا ترجمہ کرن لئی

<br/>

> ⚠️ **خبردار**<br/>
> `Back to Run` اُتے کلک کرن توں پہلاں `Save` اُتے کلک کرو۔ جے تُسی محفوظ کیتے بغیر واپس جاندے او، تہاڈیاں تبدیلیاں ضائع ہو جان گیاں۔

<br/>

<a id="test-a-prompt-before-using-it"></a>
### استعمال کرن توں پہلاں اک پرامپٹ دی جانچ کرو

سجے پاسے دا ٹیسٹ پینل تہانوں تہاڈے پرامپٹ نوں روزمرہ دے کم وچ استعمال کرن توں پہلاں نمونے دے متن نال آزمان دیندا اے۔

ایہہ اُدوں مفید اے جدوں:

- تُسی اک نواں پرامپٹ بنا رہے او
- تُسی اک پرامپٹ دے دو ورژناں دا موازنہ کر رہے او
- تُسی لہجہ، لمبائی، یا آؤٹ پٹ فارمیٹ دی جانچ کرنا چاہندے او

<br/>

> ℹ️ **نوٹ**<br/>
> تُسی محفوظ کیتے گئے پرامپٹاں نوں [**سیٹنگاں** > **تبدیل کرو**](#transform-settings) وچ برآمد تے درآمد کر سکدے او۔

جدوں تُسی پرامپٹ ایڈیٹر وچ **پرامپٹ تیار کرو**، **پرامپٹ بہتر کرو**، یا **پرامپٹ ترجمہ کرو** استعمال کردے او، **آسان** موڈ اوہی پیش سیٹ سلیکٹر پیش کردا اے جو ترجمہ تے دوبارہ لکھو؛ **اعلیٰ** موڈ ماڈل لسٹ استعمال کردا اے۔

<a id="general-settings"></a>
### عام سیٹنگاں

ٹائپنگ دے رویے نوں کنٹرول کرن لئی **عام سیٹنگاں** دا استعمال کرو، آیا ایگزیکیوشن دی تفصیلات **ہسٹری** لئی محفوظ کیتیاں جاندیاں نیں، ظاہری شکل، تے تُسی ترجمہ، دوبارہ لکھو، تے تبدیل کرو لئی AI نوں کِویں چُندے ہو۔

**AI تجربہ**

- **آسان** (ڈیفالٹ): اک **پرووائیڈر** چنو (اوپن راؤٹر، اوپن اے آئی، اینتھروپک، گوگل جیمنی، ڈیپ سیک، گروک، مسٹرل، ایکس اے آئی، سیریبراس، یا اولاما)۔ کلاؤڈ پرووائیڈر ٹول بار وچ بلٹ ان پری سیٹ استعمال کردے نیں۔ **اولاما** پری سیٹ دی بجائے تہاڈی مشین اُتے انسٹال کیتے گئے ماڈلز دی لسٹ دیندا اے۔ آسان موڈ وچ، **پری سیٹ کیٹلاگ** کیٹلاگ ورژن تے آخری اپڈیٹ دا وقت وکھاندا اے؛ پروجیکٹ ریپوزٹری توں تازہ ترین پری سیٹ لسٹ حاصل کرن لئی **پری سیٹ کیٹلاگ ریفریش کرو** اُتے کلک کرو (ایپ پس منظر وچ وی وقتاً فوقتاً چیک کردا اے)۔
- **اعلیٰ**: ٹول بار وچ انفرادی ماڈلز چنو؛ [**سیٹنگاں** > **ماڈل**](#models) دے تحت لسٹ دا انتظام کرو۔

**ظاہری شکل**

- **تھیم** ہلکے، گہرے، تے سسٹم دی ظاہری شکل دے درمیان سوئچ کردا اے۔
- **کارروائیاں اُتے لاگت دی معلومات وکھاؤ** فی آپریشن لاگت (جے دستیاب ہووے) تے ترجمہ، دوبارہ لکھو، تے تبدیل کرو آؤٹ پٹ پینلز اُتے کل لاگت دے ڈسپلے نوں کنٹرول کردا اے۔
- **لاگت دے اعشاریہ دے ہندسے** لاگت دے اعشاریہ نوں کس طرح وکھایا جاندا اے اسنوں تبدیل کردا اے۔
- **صرف ویب:** **ایپ دے آلے دوالے اک مارجن وکھاؤ** انٹرفیس دے آلے دوالے اضافی جگہ شامل کردا اے۔
- **فونٹ فیملی** ٹیکسٹ پینلز وچ لکھن والے فونٹ نوں تبدیل کردا اے۔
- **سائز** فونٹ دا سائز تبدیل کردا اے۔

**رویہ**

- **ENTER لئی رویہ** چنتا اے کہ آیا `Enter` ٹاسک نوں چلاندا اے یا اک نویں لائن داخل کردا اے۔
- **پیسٹ کرن اُتے خودکار عملدرآمد** جیویں ای تسیں ٹیکسٹ پیسٹ کردے او ترجمہ شروع کر دیندا اے۔
- **نتیجے نوں خودکار طور اُتے کلپ بورڈ اُتے کاپی کرو** کامیاب نتائج نوں خودکار طور اُتے کاپی کردا اے۔
- **ٹائپ کردے وقت حقیقی وقت وچ ترجمہ** (⚠️ اس نال استعمال دی لاگت ودھ سکدی اے) تہاڈے ٹائپ کردے وقت ترجمہ کردا اے۔
- **ٹائم آؤٹ (ms)** حقیقی وقت دے ترجمے لئی انتظار دا وقت مقرر کردا اے۔

**تاریخچہ**

- **عملدرآمد دی ہسٹری رکھو** کنٹرول کردا اے کہ آیا ہر ترجمہ، دوبارہ لکھو، تے تبدیل کرو سائیڈ بار [**تاریخچہ**](#history) ویو لئی **ان پٹ تے آؤٹ پٹ متن** نوں سٹور کردا اے۔ اسنوں بند کرن نال تصدیق منگی جاندی اے؛ جے تسیں تصدیق کردے او، سٹور کیتا گیا ہسٹری ٹیکسٹ ڈیٹا بیس توں ہٹا دتا جاندا اے۔ جے لیبل *ایڈمنسٹریٹر ولوں غیر فعال کیتا گیا* وکھاندا اے، تہاڈی انسٹالیشن وچ ماحول وچ `HISTORY_DISABLED` سیٹ اے (دیکھو [README](README.pa-PK.md#configuration-and-environment))؛ تسیں UI توں ہسٹری نوں دوبارہ آن نہیں کر سکدے۔
- **ہسٹری ڈیٹا حذف کرو** تہاڈے لئی عمر دے لحاظ نال سٹور کیتے گئے ٹیکسٹ نوں ہٹان دی اجازت دیندا اے (مثال دے طور اُتے چند مہینے توں پرانا، یا **سارا ڈیٹا (صاف کرو)**) **ڈیٹا ڈیلیٹ کرو** دا استعمال کردے ہوئے۔ ایہہ صرف **تاریخچہ** ویو لئی محفوظ کیتے گئے عملدرآمد ٹیکسٹ نوں متاثر کردا اے؛ ایہہ لاگت یا استعمال دے کل نوں حذف **نہیں** کردا۔ **لاگت** ڈیٹا نوں ہٹان یا کٹان لئی، [**سیٹنگاں** > **لاگت ٹریکنگ**](#cost-tracking) استعمال کرو۔

**کنفیگریشن بیک اپ** (صرف ڈیسک ٹاپ ایپ تے ویب ایڈمنسٹریٹر)
- **بیک اپ وچ استعمال دا ڈیٹا شامل کرو** - جدوں فعال ہووے، ZIP وچ عملدرآمد دی ہسٹری تے API کال ڈیٹا وی شامل ہوندا اے۔
- **بیک اپ کنفیگریشن** - اک واحد ZIP (مقامی وقت وچ `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`) بناندا اے جس وچ `config.json`، `state.json`، اختیاری انکرپشن کی، ورتن والے، ترجیحات، کسٹم پرامپٹ، تے استعمال دا ڈیٹا شامل ہوندا اے جے تسیں آپٹ ان کیتا ہووے۔ کامیاب بیک اپ توں بعد، تصدیق محفوظ فائل دا نام وکھاندی اے۔
- **بیک اپ توں بحال کرو** - پہلے اک **تصدیقی ڈائیلاگ** کھولدا اے۔ ڈائیلاگ دے اندر بیک اپ ZIP چنو (**براؤز کرو** / فائل پکر یا ڈریگ اینڈ ڈراپ جتھے سپورٹ ہووے)، فیر اختیارات دا جائزہ لوو:
  - **استعمال دا ڈیٹا بحال کرو** - ZIP توں استعمال/ہسٹری درآمد کرو جدوں اسنوں استعمال دے نال بیک اپ کیتا گیا سی؛ جے تسیں صرف سیٹنگاں تے پرامپٹ چاہندے او تاں اسنوں بند رکھو۔
  - **بحال کرن توں پہلاں پرانا استعمال دا ڈیٹا صاف کرو** - بیک اپ لاگو کرن توں پہلاں اس انسٹالیشن اُتے موجودہ استعمال/ہسٹری نوں ہٹاؤ (اختیاری؛ جدوں تسیں اک صاف تبدیلی چاہندے او تاں استعمال کرو)۔
ویب یا ڈیسک ٹاپ ورژن وچ بنائے گئے بیک اپ نوں دوجے وچ بحال کیتا جا سکدا اے۔ ویب ورژن وچ ڈیسک ٹاپ بیک اپ نوں بحال کردے وقت، ڈیٹا ایڈمنسٹریٹر ورتن والے نوں بحال کیتا جائے گا۔

<a id="models"></a>
### ماڈل

ایہہ ٹیب صرف ادوں دستیاب ہوندا اے جدوں [**عام سیٹنگاں**](#general-settings) وچ **AI تجربہ** نوں **اعلیٰ** اُتے سیٹ کیتا گیا ہووے۔ ٹول بار وچ کیہڑے ماڈل وکھائے جان گے ایہہ چنن لئی **سیٹنگاں** > **ماڈل** استعمال کرو۔

![Settings Models tab](../images/screenshots/pa-PK/settings-general.png)

صفحے اُتے دو لسٹاں نیں:

- کھبے پاسے **دستیاب ماڈل**
- سجے پاسے **چُنے گئے ماڈل**

مفید کنٹرولز وچ شامل نیں:

- نام دے لحاظ نال اک ماڈل تلاش کرن لئی **ماڈلز تلاش کرو...**
- لسٹ نوں اک انجن (اوپن راؤٹر، اوپن اے آئی، اولاما، …) تک محدود کرن لئی **پرووائیڈر** چپس
- صرف مفت ماڈل وکھان لئی **صرف مفت**
- لسٹ نوں دوبارہ لوڈ کرن لئی **ریفریش کرو**
- **سارے پھیلاؤ** تے **سارے سکیڑو** جدوں تسیں پرووائیڈر دے لحاظ نال ترتیب دے رہے ہو

ماڈل آئی ڈیز وچ پرووائیڈر دا سابقہ شامل ہوندا اے (مثال دے طور تے `openrouter/…` بمقابلہ `openai/…`)۔ بیجز جیویں کہ **اوپن اے آئی (اوپن راؤٹر)** بمقابلہ **اوپن اے آئی (براہ راست)** دسدے نیں کہ ٹریفک نوں کِداں روٹ کیتا جاندا اے۔

> ℹ️ **نوٹ**<br/>
> **اوپن راؤٹر باڈی بلڈر** (`openrouter/bodybuilder`) اک راؤٹر ماڈل اے، عام چیٹ ماڈل نہیں: اِس دا جواب JSON اے جو اوپن راؤٹر API درخواستاں دے باڈیز نوں بیان کردا اے (مثال دے طور تے `requests` تے `model` دے نال اک `messages` اریے)۔ جے تسیں اِس نوں **ترجمہ کریں**، **دوبارہ لکھو**، یا **تبدیل کرو** لئی استعمال کردے او، تاں آؤٹ پٹ پینل وچ تیار شدہ متن دی بجائے اوہ JSON وکھایا جائے گا۔ اوہناں کماں لئی اک عام ٹیکسٹ ماڈل چُنو۔ اوپن راؤٹر اُتے [باڈی بلڈر ماڈل صفحہ](https://openrouter.ai/openrouter/bodybuilder) ویکھو۔

کارروائیاں:

- اک ماڈل شامل کرن لئی، **شامل کرو** یا اندراج وچ کِتے وی کلک کرو۔

- اک ماڈل ہٹان لئی، **چُنے گئے ماڈل** وچ اِس دے نال **X** اُتے کلک کرو یا دستیاب ماڈلز وچ اندراج اُتے **چُنیا گیا** اُتے کلک کرو۔

- لسٹ صاف کرن لئی، **ساریاں چوناں ہٹاؤ** اُتے کلک کرو۔ مطلوبہ مفت ماڈل لسٹ وچ رہے گا۔

<br/>

> ℹ️ **نوٹ**<br/>
> جے تسیں فوری طور اُتے اوپن راؤٹر وچ کریڈٹ شامل نہیں کرنا چاہندے، تاں **صرف مفت** نوں فعال کر کے تے مفت ماڈلز چُن کے شروع کرو (کریڈٹ کارڈ دی لوڑ نہیں)۔ تسیں بغیر کسے API کی دے مقامی طور اُتے ماڈلز چلاون لئی اولاما وی استعمال کر سکدے او۔

<a id="languages"></a>
### بولیاں

ایپ وچ استعمال ہون والیاں زباناں دیاں لسٹاں نوں منظم کرن لئی **سیٹنگاں** > **بولیاں** استعمال کرو۔

- **اُتلی بولیاں** **ترجمہ کریں** تے **تبدیل کرو** وچ زباناں دیاں لسٹاں دے اُتے پن کیتیاں جاندیاں نیں۔
- **کسٹم زبان** تہانوں اک ایسی زبان شامل کرن دیندی اے جو بلٹ اِن لسٹ وچ نہیں اے۔

جے تسیں اک کسٹم زبان شامل کردے او، تاں ایہہ بلٹ اِن آپشنز دے نال زبان دے سلیکٹرز وچ ظاہر ہوندی اے۔

<a id="cost-tracking"></a>
### لاگت ٹریکنگ

لاگت دی معلومات نوں منظم کرن لئی **سیٹنگاں** > **لاگت ٹریکنگ** استعمال کرو۔

- **کل لاگت** چلدی ہوئی کل رقم وکھاندی اے۔
- **قدر کاپی کرو** کل رقم نوں کلپ بورڈ اُتے کاپی کردی اے۔
- **لاگت ریسیٹ کرو** محفوظ شدہ کل رقم نوں صفر اُتے ریسیٹ کردی اے۔
- **API کی دے استعمال نال ہم آہنگ کرو** کل رقم نوں تواڈے اوپن راؤٹر اکاؤنٹ (صرف اوپن راؤٹر) ولوں رپورٹ کیتے گئے استعمال نال ملان لئی سیٹ کردی اے۔
- **API کی دا استعمال** اوپن راؤٹر دے استعمال دیاں تفصیلاں وکھاندا اے، جے دستیاب ہوون۔
- **لاگت دا ڈیٹا ڈیلیٹ کرو** سارا ڈیٹا، یا صرف اک منتخب تاریخ توں پرانے اندراجات نوں ہٹاندا اے۔

**لاگت ٹریکنگ:** جدوں تسیں اوپن راؤٹر ماڈلز استعمال کردے او، تاں ایپ تواڈا اصل استعمال تے خرچ اوپن راؤٹر توں لاگت دی معلومات دی بنیاد اُتے وکھاندی اے۔ باقی سارے پرووائیڈرز لئی، ایپ اوپن راؤٹر ولوں شائع کیتیاں گئیاں قیمتاں دا استعمال کردے ہوئے لاگتاں دا اندازہ لاندی اے، جے کوئی قیمت دستیاب نہیں ہوندی، تاں اندازہ صفر ہو سکدا اے۔

<br/>

> ℹ️ **نوٹ**<br/>
> **ساریاں لاگت دیاں رقماں صرف تواڈے حوالہ لئی اندازے نیں، سرکاری بلنگ سٹیٹمنٹس نہیں نیں۔**

<br/>

> ⚠️ **خبردار**<br/>
> ڈیٹا نوں ڈیلیٹ کرن نوں واپس نہیں کیتا جا سکدا۔ ڈیلیٹ کرن توں پہلاں، یقینی بناؤ کہ تسیں اپنا ڈیٹا بیک اپ کر لیا اے یا اِس نوں [**تاریخچہ**](#history)
> یا [**ڈیش بورڈ** > **ساریاں کالز**](#dashboard-tabs) دے ذریعے برآمد کر لیا اے، ورنہ ایہہ مستقل طور اُتے گم ہو جائے گا۔
> ہر API کال اندراج نال متعلق سارا ان پٹ/آؤٹ پٹ تاریخچہ وی ڈیلیٹ کر دتا جائے گا۔

<a id="transform-settings"></a>
### تبدیل کرو (سیٹنگاں ٹیب)

پرامپٹ نوں وڈی مقدار وچ منظم کرن لئی **سیٹنگاں** > **تبدیل کرو** استعمال کرو۔

تسی کر سکدے او:

- اپنے محفوظ کیتے گئے پرامپٹ دا جائزہ لوو
- پرامپٹ مٹاؤ
- اک فائل توں پرامپٹ درآمد کرو
- بیک اپ یا شیئرنگ لئی پرامپٹ برآمد کرو
- پرامپٹ لسٹ وچ نمونے دے پرامپٹ لوڈ کرو

<br/>

<a id="glossary-settings"></a>
### لغت (سیٹنگاں ٹیب)

ترجمے دے دوران لاگو کیتے گئے اصطلاح دے جوڑیاں نوں منظم کرن لئی **سیٹنگاں** > **لغت** استعمال کرو (دیکھو [لغت دا استعمال](#using-the-glossary))۔ ہر اصطلاح دی اک **ماخذ زبان**، **ہدف زبان**، **ماخذ اصطلاح**، تے **ہدف اصطلاح** ہوندی اے۔

تسی کر سکدے او:

- **اک اصطلاح شامل کرو** — ٹیبل دے تھلے والی قطار وچ پُر کرو (بولیاں چنو، ماخذ تے ہدف اصطلاح ٹائپ کرو) تے **+** بٹن اُتے کلک کرو۔
- **اصطلاحاں لبھو** — لسٹ نوں **ماخذ زبان**، **ہدف زبان**، یا مفت **ٹیکسٹ** دے لحاظ نال فلٹر کرو؛ ری سیٹ کرن لئی **فلٹرز صاف کرو** اُتے کلک کرو۔
- **اک اصطلاح مٹاؤ** — اپنی قطار اُتے کوڑےدان دے آئیکن اُتے کلک کرو۔
- **درآمد کرو** — اک `.csv`، `.xlsx`، یا `.xls` فائل توں اصطلاحاں لوڈ کرو۔ فائل وچ `source_language`، `target_language`، `source_text`، تے `target_text` کالم ہونے چاہیدے نیں۔
- **CSV ایکسپورٹ کرو** / **XLSX ایکسپورٹ کرو** — بیک اپ یا شیئرنگ لئی اپنی ساریاں اصطلاحاں ڈاؤن لوڈ کرو۔
- **CSV ٹیمپلیٹ** / **XLSX ٹیمپلیٹ** — صحیح کالم ہیڈرز دے نال اک خالی فائل ڈاؤن لوڈ کرو تاکہ پُر کر کے درآمد کیتا جا سکے۔

<br/>

> ℹ️ **نوٹ**<br/>
> **ڈیسک ٹاپ ایپ** وچ، لغت مقامی طور اُتے محفوظ کیتی جاندی اے۔ **ویب ورژن** وچ، ہر ورتن والے دی اپنی لغت ہوندی اے، لہذا تہاڈیاں اصطلاحاں دوجے ورتن والیاں نوں متاثر نہیں کردیاں۔

### API کنفِگ

معاون پرووائیڈرز یہ ہیں: OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras، NVIDIA، Alibaba Cloud، apikey.fun، **Ollama** (بیس URL کے ذریعے مقامی ماڈلز)، اور ایک اختیاری **کسٹم OpenAI-مطابق پرووائیڈر** (نام، URL، اور API کلید — صرف اعلیٰ موڈ میں)۔ آپ کو صرف ان پرووائیڈرز کو کنفیگر کرنے کی ضرورت ہے جنہیں آپ استعمال کرتے ہیں۔

**ویب ایپلیکیشن: صرف ایڈمنسٹریٹر**

API کیز سسٹم یا ڈوکر ماحول دے متغیرات دے ذریعے کنفیگر کیتیاں جاندیاں نیں - اوہ ویب UI وچ داخل نہیں کیتیاں جاندیاں۔ کسٹم پرووائیڈر لئی، `CUSTOM_PROVIDER_NAME`، `CUSTOM_PROVIDER_URL`، تے `CUSTOM_PROVIDER_API_KEY` سیٹ کرو (تِنے ضروری نیں)۔ ایہہ صفحہ دسدا اے کہ کیہڑے پرووائیڈراں دی اک کی کنفیگر کیتی گئی اے تے تہانوں `Test` بٹن اُتے کلک کر کے ہر اک نوں جانچن دیندا اے۔

<br/>

> ℹ️ **نوٹ**<br/>
> اک API کی نوں تبدیل کرن لئی، اپنے سسٹم یا ڈوکر کنفیگریشن وچ ماحول دے متغیر نوں اپ ڈیٹ کرو تے سرور یا کنٹینر نوں دوبارہ شروع کرو۔

<br/>

> ℹ️ **نوٹ**<br/>
> **کنفیگریشن بیک اپ** (دیکھیں [**عام سیٹنگاں** → کنفیگریشن بیک اپ](#general-settings)) ZIP کے اندر **حل شدہ** پرووائیڈر کیز کو شامل کر سکتا ہے `config.json`. اس ZIP کو بحال کرنا ان کیز کو سرور کی محفوظ کردہ کنفیگریشن فائل میں **نہیں** کاپی کرتا - زندہ کیز ابھی بھی ماحول اور وہاں بیان کردہ موجودہ فائل کی حالت سے آتی ہیں.

<br/>

**ڈیسک ٹاپ ایپلیکیشن**

آپ جو پرووائیڈرز استعمال کرتے ہیں ان کے لیے API کلید ذخیرہ کرنے کے لیے **API کنفِگ** استعمال کریں۔ Ollama کے لیے، API کلید کے بجائے **بیس URL** درج کریں۔ ایک کسٹم OpenAI-مطابق پرووائیڈر کے لیے (کوئی بھی اینڈ پوائنٹ جو بلٹ ان فہرست میں نہیں ہے، جیسے کہ سیلف ہوسٹڈ سرور یا گیٹ وے)، ایک **پرووائیڈر نام**، **بیس URL** (جیسے `https://my-llm.example.com/v1`)، اور **API کلید** درج کریں؛ تینوں لازمی ہیں۔ URL اور نام ان لائن میں ترمیم کیے جاتے ہیں؛ API کلید کو بدلنے کے لیے **ترمیم کریں** استعمال کریں۔ کسٹم پرووائیڈر ماڈلز صرف **اعلیٰ** موڈ میں ظاہر ہوتے ہیں (سیٹنگاں > ماڈل)۔

<br/>

> 💡 **ٹِپ** <br/>
> جے تُسی API کُنجی ورتݨا یا ورتݨ لئی ادائیگی نہیں کرنا چاہندے، تُسی [Ollama ڈاؤنلوڈ](https://ollama.com) کر سکدے ہو اتے ماڈل (جیویں `translategemma:4b`) مفت وچ اپݨی مشین اُتے مقامی طور اُتے چلا سکدے ہو۔ متبادل طور اُتے، تُسی مفت OpenRouter اکاؤنٹ بݨا سکدے ہو (کریڈٹ کارڈ دی لوڑ نہیں) اوہناں دے مفت ماڈل ورتݨ لئی، یا Cerebras، Google، Groq، Mistral AI، یا [NVIDIA](https://build.nvidia.com/) توں مفت API کُنجی حاصل کر سکدے ہو۔

<br/>

- صرف وہ پرووائیڈرز شامل کریں جن کی آپ کو ضرورت ہے۔ **سیٹنگاں** > **ماڈل** میں، ہر ماڈل ID پرووائیڈر سے شروع ہوتی ہے (مثال کے طور پر `openrouter/openrouter/free`، `openai/gpt-4o`، `nvidia/nvidia/nemotron-nano-3-30b-a3b`، `ollama/llama3`، `MyProvider/…` ایک کسٹم اینڈ پوائنٹ کے لیے جس کا نام `MyProvider` ہے)۔

API کُنجی شامل کرن لئی، ٹیکسٹ فیلڈ وچ قدر درج کرو اتے `Save` اُتے کلک کرو۔ موجودہ کُنجی نوں تبدیل کرن لئی، `Edit` اُتے کلک کرو۔ ایہہ تصدیق کرن لئی کہ کُنجی کم کر رہی اے، `Test` اُتے کلک کرو۔ Ollama بیس URL لئی، کنکشن چیک کرن لئی ہمیشہ `Test` اُتے کلک کرو۔

<br/>

> ℹ️ **نوٹ**<br/>
> تُسی API کُنجی دی موجودہ قدر نہیں دیکھ سکدے ہو۔ تُسی صرف `Edit` بٹن ورت کے ایہنوں تبدیل کر سکدے ہو۔
> API کُنجیاں کنفیگریشن وچ انکرپٹڈ سٹور کیتیاں جاندیاں نیں۔

<br/>

<a id="common-issues"></a>
## عام مسائل

جے کوئی چیز امید دے مطابق کم نہیں کردی، تاں پہلے ایہناں نکات نوں چیک کرو۔

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ایپ ترجمہ، دوبارہ لکھݨ، یا ٹیکسٹ نوں تبدیل نہیں کرے گی

چیک کرو کہ:

- تُسی ٹول بار وچ اک **پیش سیٹ** (آسان) یا **ماڈل** (اعلیٰ) چُنیا اے
- **آسان** موڈ وچ، [**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) وچ اک کم کرݨ والی کُنجی (یا Ollama URL) دے نال اک **پرووائیڈر** اے اتے اوس پرووائیڈر لئی گھٹ توں گھٹ اک پیش سیٹ اے
- **اعلیٰ** موڈ وچ، [**سیٹنگاں** > **ماڈل**](#models) وچ گھٹ توں گھٹ اک ماڈل درج اے
- تہاڈا API سیٹ اپ کم کر رہیا اے

جے تُسی ڈیسک ٹاپ ایپ ورت رہے ہو:

1. [**سیٹنگاں** > **API کنفِگ**](#api-config) کھولو۔
2. چیک کرو کہ گھٹ توں گھٹ اک API کُنجی محفوظ کیتی گئی اے۔
3. کُنجی دے کم کرن دی تصدیق کرن لئی پرووائیڈر دے نال **جانچ** اُتے کلک کرو۔

<br/>

<a id="the-model-list-is-empty"></a>
### ماڈل دی فہرست خالی اے

**آسان** موڈ وچ، [**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) کھولو، تصدیق کرو کہ **پرووائیڈر** سیٹ اے، اتے [**API کنفِگ**](#api-config) (ڈیسک ٹاپ) وچ کُنجیاں شامل کرو یا جانچ کرو یا اپݨے ایڈمنسٹریٹر (ویب) توں پُچھو۔ **Ollama** لئی، بیس URL اُتے **جانچ** چلاؤ اتے یقینی بݨاؤ کہ ماڈل مقامی طور اُتے انسٹال نیں۔

**اعلیٰ** موڈ وچ، [**سیٹنگاں** > **ماڈل**](#models) کھولو اتے **ریفریش کرو** اُتے کلک کرو۔ جے لوڑ ہووے، اک ماڈل تلاش کرو، **صرف مفت** آن کرو، اتے **چُنے گئے ماڈل** وچ ماڈل شامل کرو۔

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### نتیجہ بہت سست یا بہت مہنگا اے

ایہناں وچوں اک یا ودھ کوشش کرو:

- اک وکھرا پیش سیٹ (آسان) یا ماڈل (اعلیٰ) چُنو
- اک چھوٹا ان پٹ ورتو
- [**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) وچ **ٹائپ کردے ویلے ریئل ٹائم ترجمہ** بند کرو
- سادہ کماں لئی مفت ماڈل ورتو ([ماڈل](#models) دیکھو)
<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### انٹرفیس غلط زبان وچ اے

[ٹول بار](#toolbar) وچ گلوب آئیکن اُتے کلک کرو تے اپنی پسندیدہ **انٹرفیس زبان** چُنو۔

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### متن بہت چھوٹا یا پڑھن وچ مشکل اے

[**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) کھولو تے تبدیل کرو:

- **فونٹ فیملی**
- **سائز**

<br/>

<a id="dashboard-summary-looks-empty"></a>
### ڈیش بورڈ دا خلاصہ خالی لگدا اے

ایہ عام گل اے جے:

- تُسی صرف **مفت ماڈل** استعمال کردے ہو تے تُسی **لاگت** دے اعداد و شمار دیکھ رہے ہو (اوہ صفر ہو سکدے نیں)؛ **خلاصہ** اُتے کال-کاؤنٹ KPIs نوں ہجے وی منتخب مدت توں ڈیٹا دی لوڑ اے
- منتخب **وقت فلٹر** اس مدت نوں شامل نہیں کردا جدوں کالاں کیتیاں گئیاں سن — چیک کرن لئی **سارے** دی کوشش کرو

جے **سارے** نوں منتخب کرن توں بعد وی KPIs صفر نیں، تے تصدیق کرو کہ کالاں [**تاریخچہ**](#history) وچ یا **ساریاں کالز** ٹیب وچ ظاہر ہوندیاں نیں۔

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### لاگت "دستیاب نہیں" دکھاندی اے یا غلط لگدی اے

جدوں تُسی **اوپن راؤٹر** دے ذریعے ماڈل استعمال کردے ہو، تے ایپ اوپن راؤٹر ولوں رپورٹ کیتے گئے تواڈے اصل خرچ نوں دکھاندی اے۔

**ہور پرووائیڈرز** (اوپن اے آئی ڈائریکٹ، اینتھروپک ڈائریکٹ، وغیرہ) لئی، لاگت اوپن راؤٹر ولوں شائع کیتے گئے قیمت دے ڈیٹا توں تخمینہ لائی جاندی اے۔ جے کسے ماڈل لئی کوئی مماثل قیمت نہیں ملدی، تے لاگت **دستیاب نہیں** دے طور اُتے ظاہر ہوئے گی تے تواڈے چلن والے کُل وچ شامل نہیں کیتی جائے گی۔

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### کُل لاگت میرے پرووائیڈر دے بل نال میل نہیں کھاندی

ایپ وچ لاگت دے سارے اعداد و شمار **صرف حوالہ لئی تخمینے نیں**، نہ کہ سرکاری بلنگ سٹیٹمنٹس۔

کُل نوں تواڈے حقیقی اوپن راؤٹر دے خرچ دے نیڑے لیان لئی، [**سیٹنگاں** > **لاگت ٹریکنگ**](#cost-tracking) کھولو تے **API کی دے استعمال نال ہم آہنگ کرو** اُتے کلک کرو۔

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### ہسٹری دا صفحہ سائڈ بار توں غائب اے

**عملدرآمد دی ہسٹری رکھو** بند ہو سکدا اے۔ [**سیٹنگاں** > **عام سیٹنگاں**](#general-settings) کھولو تے اس نوں فعال کرو جدوں تک کہ ہسٹری *ایڈمنسٹریٹر ولوں غیر فعال کیتا گیا* نہ ہووے (ماحول وچ `HISTORY_DISABLED` — [README](README.pa-PK.md#configuration-and-environment) دیکھو)۔ ہسٹری نوں آن کرن نال پہلے حذف کیتا گیا متن بحال نہیں ہوندا۔

<br/>

<a id="web-app-session-expired"></a>
### ویب ایپ: غیر متوقع طور اُتے لاگ ان صفحے اُتے ری ڈائریکٹ کیتا گیا

تواڈا سیشن ختم ہو گیا ہو سکدا اے۔ دوبارہ لاگ ان کرو۔ جے ایہ اکثر ہوندا اے، تے سیشن دی عمر دیاں سیٹنگاں لئی سرور کنفیگریشن چیک کرو۔

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### ویب ایڈمن: پاس ورڈ بھُل گیا یا گم ہو گیا

ایہہ **سیلف ہوسٹڈ ویب ایپ** (ڈاکر) اُتے لاگو ہوندا اے، ڈیسک ٹاپ (الیکٹران) ایپ اُتے نہیں۔

- جے کوئی ہور ایڈمنسٹریٹر ہجے وی سائن ان کر سکدا اے، تاں اوہ [**سیٹنگاں** > **ورتن والے**](#users) کھول سکدے نیں، اکاؤنٹ چُن سکدے نیں، تے اوتھے اک **نواں پاسورڈ** سیٹ کر سکدے نیں۔
- جے تسی **لاک آؤٹ** ہو گئے ہو پر مشین یا کنٹینر تک **شیل رسائی** رکھدے ہو، تاں امیج دے نال بھیجے گئے ہیلپر نال پاسورڈ ری سیٹ کرو (جے تسی ڈیفالٹ نام بدل دیندے ہو تاں `transrewrt` نوں تبدیل کرو، تے جے پاسورڈ وچ خالی جگہیں یا خاص کریکٹرز شامل نیں تاں اسنوں کوٹ کرو):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ڈیفالٹ ایڈمن یوزر نیم `admin` اے جے تسی کدی ہور اکاؤنٹ نہیں بنائے نیں۔ جدوں تسی صرف اک دلیل پاس کردے ہو، تاں اسنوں `admin` لئی نواں پاسورڈ سمجھیا جاندا اے۔

جے تسی ڈاکر دی بجائے **سورس چیک آؤٹ** توں چلدے ہو، تاں استعمال کرو:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

سکرپٹ SQLite ڈیٹا بیس وچ یوزر ریکارڈ نوں اپ ڈیٹ کردا اے (تے جے `admin` یوزر غائب ہووے تاں اسنوں بنا سکدا اے)۔ ری سیٹ کرن توں بعد، نویں پاسورڈ نال سائن ان کرو۔

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ڈیش بورڈ دوجے ورتن والیاں لئی کوئی ڈیٹا نہیں دکھاندا (ویب)

صرف **ایڈمنسٹریٹر** ہی **یوزر** فلٹر دے ذریعے سارے ورتن والیاں دا ڈیٹا ویکھ سکدے نیں۔ عام ورتن والے صرف اپنی سرگرمی ویکھدے نیں، ایہہ ڈیزائن دا حصہ اے۔

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### میں اک پرامپٹ بدلیا تے ترمیماں گوا لئیاں

اک پرامپٹ نوں ایڈٹ کردے ویلے، **رن اُتے واپس** اُتے کلک کرن توں پہلاں ہمیشہ **محفوظ کرو** اُتے کلک کرو۔

- جدوں تسی کسے خاص کم لئی دہرائے جان والے ورک فلو دی لوڑ ہووے تاں [**تبدیل کرو**](#transform) استعمال کرو۔
- جے تسی استعمال تے لاگت اُتے نظر رکھنا چاہندے ہو تاں [**ڈیش بورڈ**](#dashboard) استعمال کرو۔
- پچھلے کماں تے اوہناں دے پورے ان پٹ/آؤٹ پٹ متن نوں ویکھن لئی [**تاریخچہ**](#history) استعمال کرو۔
- جے تسی اک پرامپٹ لائبریری بنا رہے ہو جسنوں تسی محفوظ رکھنا چاہندے ہو (ویکھو [تبدیل کرو](#transform)) یا جے تسی اسنوں دوجیاں نال شیئر کرنا چاہندے ہو تاں پرامپٹس نوں باقاعدگی نال برآمد کرو۔
- **آسان** موڈ اُتے رہو جدوں تک تسی ماڈل IDs اُتے باریک کنٹرول دی لوڑ نہیں پیندی؛ جدوں تسی پہلاں ہی جاندے ہو کہ تسی کیہڑے ماڈل چاہندے ہو تاں **اعلیٰ** اُتے سوئچ کرو۔
