# ユーザーガイド

<br/>

<a id="introduction"></a>
## はじめに

Transrewrt は、テキストを次のように3つの方法で扱うことを支援します。

- **翻訳** - テキストをある言語から別の言語に変換します。
- **リライト** - より明確・簡潔・フォーマルなどの異なるスタイルに文章を言い換えます。
- **変換** - プロンプトと呼ばれるカスタムAI指示を使ってテキストを処理します。

<br/>

このガイドは、アプリをインストールして実行した後の使い方について説明しています。インストール手順については、メインの **[README](README.ja.md)** を参照してください。

<br/>

> ℹ️ **注意**<br/>
> Transrewrt は Windows および Linux 用のデスクトップアプリ、およびセルフホスト型のWebアプリとして利用可能です。本ガイドはアプリの日常的な利用方法を中心に記載しています。特定のバージョンにのみ適用される内容については明確に区別しています。

<a id="before-you-start"></a>

## はじめる前に

Transrewrt を使用するには、少なくとも 1 つの AI プロバイダーへのアクセスが必要です。対応しているプロバイダーは以下の通りです：[OpenRouter](https://openrouter.ai)（多数のモデルを統合）、OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、Mistral、xAI、Cerebras、およびローカルモデル用の [Ollama](https://ollama.com)。

始めに有料モデルを選択する必要はありません。OpenRouter の API キーを追加すると、アプリは自動的に内蔵の**無料**OpenRouter オプションを有効にします。これにより、すぐに翻訳、書き換え、テキスト変換を始められます。また、Cerebras、Google、Groq、Mistral AI のいずれかから無料の API キーを取得することもできます。

簡単に説明すると：

- **モデル**とは、作業を実行する AI エンジンのことです。モデルは**プロバイダー接頭辞**付きで表示されます（たとえば `openrouter/…`、`openai/…`、`ollama/…`）。
- **API キー**（または Ollama の場合は**ベース URL**）は、アプリがそのプロバイダーに接続するための手段です。

**デスクトップアプリ**を使用している場合、使用する各プロバイダーに対して、[**設定** > **API 設定**](#api-config) でキーを追加してください。OpenRouter 専用の使用方法については、下記の「[API キーの取得方法](#how-to-get-an-api-key-desktop-app)」を参照してください。API キーを使いたくない場合は、[ollama.com](https://ollama.com) から Ollama をインストールして `translategemma:4b` のようなローカルモデルを使用できます。

**Web バージョン**を使用している場合、サーバー管理者が環境変数を使ってプロバイダーを設定するため、アプリ内で直接 API キーを入力することはできません。

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### 無料の OpenRouter API キーの取得方法（デスクトップアプリ）

デスクトップアプリを使用している場合は、以下の手順に従ってください：

1. Web ブラウザで [OpenRouter](https://openrouter.ai) にアクセスします。
2. アカウントを作成またはサインインします。
3. [Keys](https://openrouter.ai/keys) ページを開きます。
4. 新しい API キーを作成するボタンをクリックします。
5. 後で識別できるように、キーに名前を付けます。
6. 新しい API キーをコピーします。
7. Transrewrt に戻り、**設定** > **API 設定**を開きます。
8. **OpenRouter API キー**欄（**設定** > **API 設定**内）にキーを貼り付けます。
9. **Test OpenRouter key** をクリックし、正しく動作するか確認します。

<a id="getting-started"></a>
## はじめに

初めて Transrewrt を使う場合は、以下の順序で進めてください：

1. アプリを開きます。
2. 必要に応じて、地球儀アイコンから**インターフェース言語**を選択します。
3. **デスクトップアプリ**を使用している場合、[**設定** > **API 設定**](#api-config) を開き、少なくとも 1 つのプロバイダー（例：OpenRouter）の API キーを追加して、**テスト**をクリックして動作確認します。
4. [**設定** > **モデル**](#models) を開き、**選択されたモデル**に 1 つ以上のモデルを追加します。
5. [**設定** > **言語**](#languages) を開き、よく使う言語を上位に表示させたい場合、**主要言語**を選択します。
6. **翻訳**に移動し、簡単な翻訳を実行して、すべてが正常に動作していることを確認します。
7. 動作を確認したら、次に**書き換え**、その後**変換**を試します。

この順序は重要です。アプリが有効な API 接続または選択したモデルを持たないまま処理を実行しようとする、よくある初回使用時の問題を防ぐことができます。

### ツールバー

ツールバーは、アプリ内の位置によって多少異なります。

<a id="input-and-output-panels"></a>
### 入力と出力のパネル

ほとんどのワークスペースでは、左側に**入力**パネル、右側に**出力**パネ giảmがあります。

各パネルには以下も表示されます：

| **入力**                                                            | **出力**                                                                                                                    |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - 文字数 <br/>- 単語数 <br/>- 段落数                             | - タスクにかかった時間<br/>- **TPS**（1秒あたりのトークン数）<br/>- 文字数、単語数、段落数<br/>- 使用したモデル      |


技術的な用語について気になる場合は：

- **トークン**とは、小さなテキストの断片を意味します。単語の一部、または短い単語と考えてください。
- **TPS**とは、モデルが1秒間に処理したテキスト断片の数を意味します。

<br/>

[**設定** > **全般設定**](#general-settings)でオプション「アクションに費用情報を表示する」を有効にすると、各操作の費用（利用できる場合）および合計費用を確認できます。

<a id="translate"></a>
## 翻訳

ある言語のテキストを他の言語に変換する場合、**翻訳**を使用してください。

![翻訳ワークスペース](../images/screenshots/ja/translate.png)

<br/>

<a id="translate-text"></a>
### テキストの翻訳

1. **翻訳**を開きます。
2. **元の言語**で言語を選択します。
3. **翻訳先**で言語を選択します。
4. ツールバーでモデルを選択します。
5. **入力**にテキストを入力または貼り付けます。
6. **翻訳**をクリックします。
7. **出力**で結果を読み取ります。
8. 結果をコピーしたい場合は、コピーボタンを使用します。

<br/>

<a id="language-selection"></a>
### 言語の選択

- **元の言語**には、特定の言語、または**言語を自動判別**を選択できます。
- **翻訳先**には、結果としてほしい言語を指定します。

選択した**主要言語**は、言語リストの上部に表示されます。[**設定** > **言語**](#languages)で設定できます。

<br/>

<a id="helpful-translation-settings"></a>
### 役立つ翻訳設定

[**設定** > **全般設定**](#general-settings)で、翻訳の動作を変更できます：

- **貼り付け時に自動翻訳**：テキストを貼り付けた直後に翻訳を実行します。
- **結果を自動でクリップボードにコピー**：成功後に結果を自動的にコピーします。
- **リアルタイム翻訳（入力中）**：入力中に翻訳を実行します。
- **タイムアウト（ミリ秒）**：リアルタイム翻訳を開始する前にアプリが待機する時間を設定します。
- **Enterキー**：`Enter`キーを押したときの動作を制御します。

<a id="rewrite"></a>
## リライト

主な意味を変えることなく、表現を改善したい場合に**リライト**を使用してください。

![リライトワークスペース](../images/screenshots/ja/rewrite.png)

次の用途に適しています：

- スペルと文法の修正
- テキストをより明確にする
- テキストをよりフォーマルまたはカジュアルにする
- テキストを短くまたは長くする
- テキストをより専門的な表現にする

<br/>

> 💡 **ヒント**<br/>
> 「**スペルと文法をチェック**」モードを使用すると、出力パネルに `変更を表示` ボタンが表示されます。
> このボタンをクリックすると、修正内容の表示を切り替えられ、テキストに加えられた具体的な変更を表示または非表示にできます。

<a id="transform"></a>

## 変換

**変換**は、AIにカスタムの指示セットに従って作業させたい場合に使用します。

![Transform workspace](../images/screenshots/ja/transform.png)

この機能はアプリの中で最も柔軟性があります。以下のようなタスクに利用可能です。

- メモの要約
- 乱雑な文章を洗練されたメールに変換
- 主要ポイントの抽出
- テキストを特定のフォーマットに変換
- 入力されたテキストに対するその他のカスタム処理

<br/>

<a id="run-an-existing-prompt"></a>
### 既存のプロンプトを実行する

1. **変換**を開く。
2. プロンプトリストからプロンプトを選択。
3. **対象言語**の入力欄が表示された場合は、必要に応じて言語を選択。
4. **入力**欄にテキストを入力または貼り付け。
5. **変換**をクリック。
6. **出力**欄で結果を確認。

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### プロンプトがない場合

プロンプトリストが空の場合、「サンプルプロンプトを読み込む」をクリックしてください。これにより、組み込みの例が追加され、すぐに使い始められます。

<br/>

> ℹ️ **注意**<br/>
> サンプルプロンプトは英語で提供されています。読み込んだ後、プロンプトを編集し、「プロンプトを翻訳」機能を使ってご希望の言語に翻訳できます。

<br/>

<a id="create-a-prompt-quickly"></a>
### 簡単にプロンプトを作成する

プロンプトを作成する最も速い方法は次の通りです。

1. 「新しいプロンプト」をクリック。
2. 「プロンプトを生成」をクリック。
3. そのプロンプトに何をさせたいか説明する。
4. モデルを選択。
5. アプリがドラフトを作成するのを待つ。
6. ドラフトを確認後、「保存」をクリック。

![Generate prompt](../images/screenshots/ja/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### プロンプトを編集する

プロンプトを作成または編集すると、左側にエディタが、右側にテストエリアが表示されます。

![Transform prompt editor](../images/screenshots/ja/transform-prompt-edit.png)

主な項目は以下の通りです。

- **プロンプト名**：プロンプトリストに表示される名前。
- **プロンプトの説明（オプション）**：プロンプト実行時にユーザーに表示される簡単なヒント。
- **モデルの役割**：AIに割り当てる全体的な役割。例：「あなたは役立つアシスタントです。」
- **モデルの指示（1行につき1つ）**：AIに従ってもらいたい具体的なルール。
- **出力の説明**：結果を表す短い言葉。例：「要約」や「書き直し」。
- **Temperature（0.0 → 1.0）**：モデルの動作方法。以下を参照。
- **対象言語を尋ねる**：プロンプト実行時に、対象言語の選択欄を追加。

技術用語の **Temperature** が初めての方は、次のように考えてください。

- **低い** Temperatureは、一貫性が高く予測しやすい結果を出します。
- **高い** Temperatureは、創造性や多様性のある結果を出します。

以下も使用できます：

- **`プロンプトを生成`**：簡単な説明から新しいドラフトを作成。
- **`プロンプトを改善`**：既存のプロンプトを洗練。
- **`プロンプトを翻訳`**：プロンプトの各フィールドを翻訳。

<br/>

> ⚠️ **警告**<br/>
> **`元に戻る`** をクリックする前に、必ず **`保存`** をクリックしてください。保存せずに戻ると、変更内容は失われます。

- 2つのバージョンのプロンプトを比較しているとき
- トーン、長さ、出力フォーマットを確認したいとき

<br/>

> ℹ️ **注意**<br/>

<a id="general-settings"></a>
### 一般設定

**一般設定**を使って、操作方法の設定、**履歴**に実行詳細を保存するかどうか、外観を調整できます。

**動作**

- **Enterキーの動作**：`Enter` キーでタスクを実行するか、改行を挿入するかを指定します。
- **貼り付け時の自動翻訳**：テキストを貼り付けた瞬間に翻訳を開始します。
- **結果を自動コピー**：成功した結果を自動でクリップボードにコピーします。
- **リアルタイム翻訳（入力中）**：入力中に翻訳を実行します。
- **タイムアウト (ms)**：リアルタイム翻訳の待ち時間を設定します。

**履歴**

- **実行履歴を保持**：**翻訳**、**リライト**、**変換**の実行ごとに、入力・出力テキストをサイドバーの[**履歴**](#history)に保存するかどうかを設定します。オフにすると確認メッセージが表示され、確認後、保存済みの履歴テキストはデータベースから削除されます。
- **履歴データを削除**：**データを削除**を使って、経過期間（たとえば数か月前など）または**すべてのデータ（クリア）** に基づいて保存済みテキストを削除できます。これは**履歴**ビューの保存された実行テキストのみに影響し、**コストや使用量の合計は削除されません**。**コスト**データを削除または削減したい場合は、[**設定** > **コスト追跡**](#cost-tracking) を使用してください。

**外観**

- **操作にコスト情報を表示**：利用可能な場合に、各操作のコストおよび **翻訳・リライト・変換** の出力パネルに表示される合計コストの表示/非表示を設定します。
- **コストの小数桁数**：コスト表示の小数点以下の桁数を変更します。
- **Web版のみ**：**アプリの周囲に余白を表示**：インターフェースの周囲に余白を追加します。
- **フォントファミリー**：テキストパネルのフォントを変更します。
- **サイズ**：フォントサイズを変更します。

<a id="models"></a>

### モデル

**設定** > **モデル** から、ツールバーに表示するモデルを選択できます。

![設定 モデルタブ](../images/screenshots/ja/settings-models.png)

このページには2つのリストがあります。

- 左側の **利用可能なモデル**
- 右側の **選択したモデル**

便利な操作方法：

- **モデルを検索…** モデル名で検索できます
- **プロバイダー** のチップで、一覧を特定のプロバイダー（OpenRouter、OpenAI、Ollama など）に絞り込めます
- **無料のみ** を選ぶと、無料のモデルのみ表示されます
- **更新** で一覧を再読み込みできます
- プロバイダー別に並べ替えた際に使う **すべて展開** および **すべて折りたたみ**

モデルIDにはプロバイダー名の接頭辞が含まれます（例：`openrouter/…` と `openai/…`）。**OpenAI (OpenRouter)** と **OpenAI (direct)** のようなバッジによって、通信がどの経路を通るかが示されています。

> ℹ️ **注記**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) は汎用チャットモデルではなく、ルーター用のモデルです。このモデルの応答はJSON形式で、OpenRouter APIリクエストボディの構造を示します（たとえば、`model` および `messages` を含む `requests` 配列）。これを **翻訳**、**書き換え**、**変換** のタスクで使うと、完成した文章ではなくそのJSONが出力パネルに表示されることになります。こうしたタスクには、通常のテキストモデルを選択してください。詳しくはOpenRouterの [Body Builderモデルページ](https://openrouter.ai/openrouter/bodybuilder) をご確認ください。

操作方法：

 - モデルを追加するには、**追加** ボタン、またはモデル項目の任意の部分をクリックします。

 - モデルを削除するには、**選択済みのモデル** 一覧の隣にある **X** ボタン、または **利用可能なモデル** 一覧での項目の **選択解除** をクリックします。

 - 一覧をすべてクリアするには、**すべて選択解除** をクリックします。ただし、必須の無料モデルは一覧に残ります。

<br/>

> ℹ️ **注記**<br/>
> OpenRouterにすぐにクレジットを追加したくない場合は、まず **無料のみ** を有効にし、クレジットカード不要の無料モデルを選んでください。また、Ollamaを使用すればAPIキーなしでローカルでモデルを実行することも可能です。

<a id="cost-tracking"></a>
### 料金の追跡

**設定** > **料金の追跡** で、費用情報の管理を行えます。

- **合計費用** は、現在の累計を表示します。
- **値をコピー** で、合計金額をクリップボードにコピーします。
- **費用をリセット** で、蓄積された金額をゼロにリセットします。
- **APIキーの使用量と同期** は、合計をOpenRouterアカウントで報告された使用量に合わせます（OpenRouterのみ対応）。
- **APIキー使用量** では、利用可能な場合にOpenRouterの使用詳細を表示します。
- **料金データを削除** で、すべてのデータまたは選択した日付よりも古いデータのみを削除します。

**料金の追跡について**：OpenRouterのモデルを使用している場合、アプリはOpenRouterから提供されるコスト情報をもとに、実際の使用量と料金を表示します。その他のプロバイダーでは、OpenRouterが公開している価格を使って費用を推定します。価格情報がない場合、推定料金はゼロになることがあります。

<br/>

> ℹ️ **注記**<br/>
> すべての料金は、参考用の推定値であり、正式な請求書ではありません。

<br/>

> ⚠️ **警告**<br/>
> 削除したデータは元に戻せません。削除する前に、[**履歴**](#history) または [**ダッシュボード** > **すべての呼び出し**](#dashboard-tabs) からデータをバックアップまたはエクスポートしておくことを確認してください。それを行わないと、データは完全に失われます。各API呼び出しの入出力履歴もすべて削除されます。

<a id="api-config"></a>
### API設定

サポートされているプロバイダーは、OpenRouter、OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、Mistral、xAI、Cerebras、および **Ollama**（ベースURL経由のローカルモデル）です。利用するプロバイダーのみを設定する必要があります。

**Webアプリケーション：管理者のみ**

APIキーは、システムまたはDockerの環境変数で設定します。Web UIに入力するものではありません。このページでは、APIキーが設定されているプロバイダーを確認でき、**`テスト`** ボタンをクリックしてそれぞれの接続テストができます。

<br/>

> ℹ️ **注記**<br/>
> APIキーを変更するには、システムまたはDockerの設定で環境変数を更新し、サーバーまたはコンテナを再起動してください。

<br/>

**デスクトップアプリケーション**

使用する各プロバイダーのAPIキーを **API設定** で保存します。Ollamaの場合は、APIキーの代わりに **ベースURL** を入力します。

<br/>

> 💡 **ヒント** <br/>
> APIキーを使いたくない、または利用料を払いたくない場合は、[Ollamaをダウンロード](https://ollama.com) して、`translategemma:4b` などのモデルを無料でマシン上でローカル実行できます。また、クレジットカード不要の無料OpenRouterアカウントを作成して無料モデルを使う、あるいはCerebras、Google、Groq、Mistral AIから無料APIキーを取得する方法もあります。

<br/>

- 必要なプロバイダーだけを追加してください。**設定** > **モデル** では、各モデルIDはプロバイダー名で始まります（例：`openrouter/openrouter/free`、`openai/gpt-4o`、`ollama/llama3`）。

APIキーを追加するには、テキストフィールドに値を入力し、**`保存`** をクリックします。既存のキーを置き換えるには、**`編集`** をクリックします。キーが正しく機能するか確認するには、**`テスト`** をクリックします。OllamaのベースURLの場合は、接続を確認するために必ず **`テスト`** をクリックしてください。

<br/>

> ℹ️ **注記**<br/>
> 現在のAPIキーの値を確認することはできません。**`編集`** ボタンを使ってのみ、キーを置き換えることができます。APIキーは設定ファイルに暗号化して保存されます。

<a id="common-issues"></a>
## よくある問題

何かが期待通りに動作しない場合、まず以下の項目を確認してください。

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### アプリがテキストを翻訳、書き換え、変換しない

以下の点を確認してください。

- ツールバーでモデルが選択されていること
- [**設定** > **モデル**](#models) に少なくとも1つのモデルが登録されていること
- APIの設定が正常に動作していること

デスクトップアプリを使用している場合：

1. [**設定** > **API構成**](#api-config) を開きます。
2. 少なくとも1つのAPIキーが保存されていることを確認します。
3. プロバイダー横の **テスト** をクリックし、キーの動作確認を行います。

<br/>

<a id="the-model-list-is-empty"></a>
### モデル一覧が空である

[**設定** > **モデル**](#models) を開き、**更新** をクリックします。

必要に応じて：

- モデルを検索する
- **無料のみ** を有効にする
- **選択されたモデル** に1つ以上のモデルを追加する

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### 結果が遅すぎる、または高コストである

以下のいずれかを試してください：

- 異なるモデルを選択する
- 入力テキストを短くする
- [**設定** > **一般設定**](#general-settings) で **リアルタイム翻訳（入力中に）** を無効にする
- 単純なタスクには無料モデルを使用する（[モデル](#models)を参照）

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### インターフェースの言語が正しくない

[ツールバー](#toolbar) の地球儀アイコンをクリックし、希望の **インターフェース言語** を選択します。

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### テキストが小さすぎて読みにくい

[**設定** > **一般設定**](#general-settings) を開き、以下を変更します：

- **フォントファミリー**
- **サイズ**

<br/>

<a id="dashboard-charts-are-empty"></a>
### ダッシュボードのグラフが空である

以下の場合は、これが正常です：

- **無料モデルのみ** を使用している場合（コストグラフは空白になります）
- 選択された **時間フィルター** がAPI呼び出しが行われた期間を含んでいない場合 — 試しに **すべて** を選択して確認してください

**すべて** を選択してもグラフが空のままである場合、[**履歴**](#history) または **すべての呼び出し** タブに呼び出しが表示されているか確認してください。

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### コストが「利用不可」と表示される、または誤っているように見える

**OpenRouter** 経由でモデルを使用している場合、アプリはOpenRouterが報告する実際の使用料を表示します。

**その他のプロバイダー**（OpenAI 直接、Anthropic 直接など）の場合、コストはOpenRouterが公開している価格データに基づく推定値です。モデルに一致する価格が見つからない場合、コストは **利用不可** と表示され、累計に加算されません。

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### 総コストがプロバイダーの請求額と一致しない

アプリ内のすべてのコスト数値は **参考用の推定値** であり、公式な請求書ではありません。

OpenRouterでの実際の使用料と総額をより一致させたい場合は、[**設定** > **コスト追跡**](#cost-tracking) を開き、**APIキー使用量と同期** をクリックしてください。

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### 履歴ページがサイドバーにない

**実行履歴を保持** が無効になっている可能性があります。[**設定** > **一般設定**](#general-settings) を開き、有効にしてください。ただし、オンにしても以前に削除された履歴データは復元されません。

<br/>

<a id="web-app-session-expired"></a>
### Webアプリ：予期せずログインページにリダイレクトされる

セッションがタイムアウトした可能性があります。再度ログインしてください。頻繁に起こる場合は、サーバー設定でセッション維持時間の設定を確認してください。

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ダッシュボードに他のユーザーのデータが表示されない（Web版）

**管理者** のみが **ユーザー** フィルターを使用して全ユーザーのデータを閲覧できます。通常のユーザーは、設計上、自分の活動のみを閲覧できます。

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### プロンプトを編集したが、変更内容が失われた

プロンプトを編集するときは、**戻る** をクリックする前に必ず **保存** をクリックしてください。

<br/><br/>

<a id="quick-tips"></a>
## 便利なヒント

- [**翻訳**](#translate) を最初に使い、セットアップが正しく機能することを確認してから、[**書き換え**](#rewrite) や [**変換**](#transform) に進んでください。
- 日常的な文章の改善には [**書き換え**](#rewrite) を使用してください。
- 特定のタスクで繰り返し使用できるワークフローが必要な場合は [**変換**](#transform) を使用してください。
- 使用量やコストを確認したい場合は [**ダッシュボード**](#dashboard) を使用してください。
- 過去の操作とその完全な入出力テキストを確認するには [**履歴**](#history) を使用してください。
- プロンプトライブラリを安全に保管したい場合や、他者と共有したい場合は、定期的にエクスポートを行ってください（[変換プロンプト](#transform-prompts) を参照）。
