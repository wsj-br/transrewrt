# ユーザーガイド

<br/>

<a id="introduction"></a>
## はじめに

Transrewrt は、テキストを以下のように3つの方法で処理できるアプリです。

- **翻訳 (Translate)** - ある言語のテキストを別の言語に変換。
- **書き換え (Rewrite)** - テキストをより明確、簡潔、または形式ばったスタイルに言い換え。
- **変換 (Transform)** - プロンプトと呼ばれるカスタムAI指示を用いて、テキストを処理。

<br/>

このガイドは、アプリのインストールと起動後にどのように使用するかを説明しています。インストール手順については、メインの **[README](README.ja.md)** を参照してください。

<br/>

> ℹ️ **注記**<br/>
> Transrewrt は、Windows および Linux 用のデスクトップアプリとして、および自己ホスト型のWebアプリとして利用可能です。本ガイドはアプリの日常的な使い方に焦点を当てています。特定のバージョンにのみ適用される機能は、それぞれ明記されています。

<a id="before-you-start"></a>

## はじめる前の準備

Transrewrt を使用するには、少なくとも1つのAIプロバイダーへのアクセスが必要です。対応しているプロバイダーは以下のとおりです：[OpenRouter](https://openrouter.ai)（多数のモデルを統合）、OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、Mistral、xAI、Cerebras、およびローカルモデル用の[Ollama](https://ollama.com)。

開始するのに有料のモデルを選択する必要はありません。OpenRouterのAPIキーを追加すると、アプリは自動的に内蔵の**無料**OpenRouterオプションを有効にします。これにより、すぐに翻訳、文章の書き換え、テキスト変換を始められます。または、Cerebras、Google、Groq、Mistral AIからも無料のAPIキーを取得できます。

わかりやすく説明すると：

- **モデル**とは、実際の処理を行うAIエンジンのことです。モデルは**プロバイダー接頭辞**とともに表示されます（たとえば `openrouter/…`、`openai/…`、`ollama/…` など）。
- **APIキー**（またはOllamaの場合は**ベースURL**）とは、アプリがそのプロバイダーに接続するための手段です。

**デスクトップアプリ**を使用している場合は、使用する各プロバイダーのAPIキーを[**設定** > **API設定**](#api-config)に追加してください。OpenRouterのみ使用する場合のキー取得方法は、以下の[APIキーの取得方法](#how-to-get-an-api-key-desktop-app)を参照してください。APIキーを使わずに利用する場合は、[ollama.com](https://ollama.com) からOllamaをインストールし、`translategemma:4b` などのローカルモデルを使って動作させることもできます。

**Web版**を使用している場合、サーバー管理者が環境変数を使ってプロバイダーを設定しているため、アプリ内で直接APIキーを入力することはできません。

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### 無料のOpenRouter APIキーを取得する方法（デスクトップアプリ）

デスクトップアプリを使用している場合は、以下の手順に従ってください：

1. ウェブブラウザから[OpenRouter](https://openrouter.ai)にアクセスします。
2. アカウントを作成するか、ログインします。
3. [Keys](https://openrouter.ai/keys) ページを開きます。
4. 新しいAPIキーを作成するボタンをクリックします。
5. キーを後で識別できるように、わかりやすい名前を付けます。
6. 新しく作成されたAPIキーをコピーします。
7. Transrewrtに戻り、**設定** > **API設定**を開きます。
8. **OpenRouter APIキー**（**設定** > **API設定**内）にキーを貼り付けます。
9. **OpenRouterキーをテスト**をクリックして、正しく動作するか確認します。

<a id="getting-started"></a>
## はじめに

Transrewrtを初めて使う場合は、以下の順序で操作してください：

1. アプリを開きます。
2. 必要に応じて、地球儀アイコンから**インターフェース言語**を選んでください。
3. **デスクトップアプリ**を使用している場合は、[**設定** > **API設定**](#api-config)を開き、少なくとも1つのプロバイダー（たとえばOpenRouter）のAPIキーを追加して、**テスト**をクリックし、正しく動作するか確認します。
4. [**設定** > **モデル**](#models)を開き、**選択されたモデル**に1つ以上のモデルを追加します。
5. [**設定** > **言語**](#languages)を開き、よく使う言語を優先的に表示させたい場合は**主要言語**を選んでください。
6. **翻訳**に移動し、簡単な翻訳を行い、すべてが正しく動作しているか確認します。
7. それが成功したら、次に**書き換え**、その後**変換**を試してみてください。

この順序は重要です。よくある初回使用時の問題（API接続が確立されていない、またはモデルが選択されていない状態でタスクを実行しようとする）を防ぐためです。

### ツールバー

ツールバーは、アプリ内で位置によってわずかに変化します。

- 左端には、現在表示しているページ名が表示されます。
- 右端には、**モデルセレクター**と**インターフェース言語**のコントロールが表示されます。

**モデルセレクター**では、現在のタスクに使用するAIエンジンを選択できます。

  ![モデルセレクター](../images/screenshots/ja/model-selector.png)

一部の無料モデルは、常に利用可能とは限りません。一時的にオフラインになったり、使用制限がある場合があります。その場合、アプリは自動的にそのモデルを使用可能なリストから除外します。表示されるモデルを制御するには、[**設定** > **モデル**](#models) に移動して、モデルのリストを編集してください。
また、ツールバーのモデル名の左にあるプロバイダーのアイコンをクリックすることで、モデル設定を直接開くこともできます。

<br/>

**地球儀のアイコン＋言語コード**は、メニューやボタンなどのアプリのインターフェース言語を変更します。ただし、**翻訳**機能内の翻訳言語には影響しません。

<a id="input-and-output-panels"></a>
### 入力・出力パネル

ほとんどのワークスペースでは、左側に**入力**パネル、右側に**出力**パネルが配置されています。

各パネルには次の情報も表示されます。

| **入力**                                                         | **出力**                                                                                                                  |
|-------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - 文字数 <br/>- 単語数 <br/>- 段落数  <br/> | - 処理にかかった時間<br/>- **TPS**（1秒あたりのトークン数）<br/>- 文字数・単語数・段落数<br/>- 使用したモデル |


技術用語について知りたい場合は、以下の通りです。

- **トークン** とは、小さなテキストのまとまりを意味します。単語の一部、あるいは短い単語とイメージしてください。
- **TPS** とは、モデルが1秒間に処理したトークン数を示します。

<br/>

各操作のコスト（利用可能な場合）と合計コストを監視することもできます。そのためには、[**設定** > **全般設定**](#general-settings) で `操作時に料金情報を表示` のオプションを有効にしてください。

<a id="translate"></a>
## 翻訳

**翻訳**は、テキストをある言語から別の言語へ変換したい場合に使用します。

![翻訳ワークスペース](../images/screenshots/ja/translate.png)

<br/>

<a id="translate-text"></a>
### テキストの翻訳

1. **翻訳**を開きます。
2. **元の言語**で言語を選択します。
3. **対象言語**で言語を選択します。
4. ツールバーでモデルを選択します。
5. **入力**欄にテキストを入力または貼り付けます。
6. **翻訳**をクリックします。
7. **出力**欄で結果を確認します。
8. 結果をコピーしたい場合は、コピー用ボタンを使用します。

<br/>

<a id="language-selection"></a>
### 言語の選択

- **元の言語** は特定の言語を指定するか、「言語を自動検出」が選べます。
- **対象言語** は、変換後の言語です。

上部に表示される**主要言語**は、[**設定** > **言語**](#languages) で事前に設定できます。

<br/>

<a id="helpful-translation-settings"></a>
### 便利な翻訳設定

[**設定** > **全般設定**](#general-settings) で、翻訳の動作をカスタマイズできます。

- **貼り付け時に自動翻訳**：テキストを貼り付けた瞬間に翻訳を開始します。
- **結果を自動的にクリップボードにコピー**：翻訳が完了すると、結果が自動的にコピーされます。
- **リアルタイム翻訳（入力中）**：入力中にリアルタイムで翻訳を実行します。
- **タイムアウト（ミリ秒）**：リアルタイム翻訳を開始する前にアプリが待機する時間を設定します。
- **Enterキーの動作**：`Enter`キーを押したときの挙動を設定できます。

## 書き換え

**書き換え**は、内容の本質を変えることなく、文章の表現を改善したい場合に使用します。

![書き換えワークスペース](../images/screenshots/ja/rewrite.png)

以下のような場面で便利です。

- 文章の短縮や拡張
- より技術的な表現へ変更

<br/>

> 💡 **ヒント**<br/>
> 「スペルと文法のチェック」モードを使用すると、出力パネルに `変更を表示` ボタンが表示されます。

<a id="transform"></a>

## 変換

カスタム手順に従ってAIに処理を行わせたい場合は、**変換**を使用してください。

![変換ワークスペース](../images/screenshots/ja/transform.png)

これはアプリ内で最も柔軟性のある領域です。以下のタスクなどに利用できます：

- メモの要約作成
- わかりにくい文章を洗練されたメールに変換
- 主要ポイントの抽出
- テキストを特定の形式に変換
- 入力テキストに対するその他のカスタム処理

<br/>

<a id="run-an-existing-prompt"></a>
### 既存のプロンプトを実行

1. **変換**を開く。
2. プロンプトリストからプロンプトを選ぶ。
3. **ターゲット**言語欄が表示された場合は、必要に応じて言語を選択する。
4. **入力**欄にテキストを入力または貼り付け。
5. **変換**をクリック。
6. **出力**欄で結果を確認。

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### プロンプトがない場合

プロンプトリストが空の場合は、「**サンプルプロンプトを読み込む**」をクリックしてください。組み込みの例が追加されるため、すぐに使い始められます。

<br/>

> ℹ️ **注記**<br/>
> サンプルプロンプトは英語で提供されています。読み込んだ後、プロンプトを編集し、「**プロンプトを翻訳**」機能を使って自分の言語に翻訳できます。

<br/>

<a id="create-a-prompt-quickly"></a>
### プロンプトをすばやく作成

プロンプトを作成する最も速い方法は次の通りです：

1. **新規プロンプト**をクリック。
2. **プロンプトを生成**をクリック。
3. そのプロンプトに何をしてほしいかを説明。
4. モデルを選択。
5. アプリが草稿を作成するのを待つ。
6. 草稿を確認後、**保存**をクリック。

![プロンプトの生成](../images/screenshots/ja/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### プロンプトの編集

プロンプトを作成または編集すると、左側にエディターが、右側にテストエリアが表示されます。

![変換プロンプトエディター](../images/screenshots/ja/transform-prompt-edit.png)

主な項目は以下のとおりです。

- **プロンプト名**：プロンプトリストに表示される名前。
- **プロンプトの説明（任意）**：プロンプト実行時にユーザに表示される簡単なヒント。
- **モデルの役割**：AIに割り当てる全体的な役割。たとえば「親切なアシスタントです」など。
- **モデルの指示（1行ごとに1つ）**：AIに守ってほしい具体的なルール。
- **出力の説明**：結果を表す簡単な語。たとえば「要約」や「書き直し」など。
- **温度（0.0 → 1.0）**：モデルの動作設定。下記を参照。
- **ターゲット言語の指定を求める**：プロンプト実行時に言語選択欄を追加。

技術用語の「**温度**」が初めての場合、次のように考えてください：

- **低い**温度：一貫性が高く、予測しやすい結果になる。
- **高い**温度：より多様で創造的な結果になる。

以下の機能も利用できます：

- **`プロンプトを生成`**：簡単な説明から新しい草稿を作成。
- **`プロンプトを改善`**：既存のプロンプトを洗練。
- **`プロンプトを翻訳`**：プロンプトの各項目を翻訳。

<br/>

> ⚠️ **警告**<br/>
> **`戻る`** をクリックする前に、必ず **`保存`** をクリックしてください。保存せずに戻った場合、変更内容は失われます。

これは次のような場合に便利です：

- 新しいプロンプトを制作している場合
- プロンプトの2つのバージョンを比較している場合
- トーン、長さ、出力形式を確認したい場合

<br/>

> ℹ️ **注記**<br/>
> 保存済みのプロンプトは、[**設定** > **変換プロンプト**](#transform-prompts) からエクスポートおよびインポートできます。

<a id="general-settings"></a>
### 一般設定

**一般設定**では、入力動作、実行詳細を**履歴**に保存するかどうか、外観などを設定できます。

**動作**

- **Enterキーの動作**：`Enter`キーでタスクを実行するか、改行を挿入するかを選択します。
- **貼り付け時に自動翻訳**：テキストを貼り付けると、すぐに翻訳を開始します。
- **結果をクリップボードに自動コピー**：成功した結果を自動的にクリップボードにコピーします。
- **リアルタイム翻訳（入力中に）**：入力中に翻訳を実行します。
- **タイムアウト (ms)**：リアルタイム翻訳の待機時間を設定します。

**履歴**

- **実行履歴を保持**：サイドバーの [**履歴**](#history) に、翻訳・リライト・変換の**入出力テキスト**を保存するかどうかを制御します。オフにすると確認が求められ、承認した場合、保存済みの履歴テキストがデータベースから削除されます。
- **履歴データの削除**：**データ削除**を使用して、一定期間以上経過したデータ（例：数か月以上前、または**すべてのデータ（クリア）**）を削除できます。**履歴**表示用に保存された実行テキストにのみ影響し、コストや使用量の合計は**削除されません**。**コスト**データを削除または削減するには、[**設定** > **コスト追跡**](#cost-tracking) を使用してください。

**外観**

- **操作にコスト情報を表示**：操作ごとのコスト（利用可能な場合）および合計コストを、翻訳・リライト・変換の出力パネルに表示するかどうかを制御します。
- **コストの小数点以下桁数**：コストの小数点以下の表示桁数を変更します。
- **Webのみ**：**アプリ周囲に余白を表示**：インターフェースの周囲に余白を追加します。
- **フォントファミリー**：テキストパネルの表示フォントを変更します。
- **サイズ**：フォントサイズを変更します。

<a id="models"></a>

### モデル

**設定** > **モデル**を使用して、ツールバーに表示されるモデルを選択します。

![設定 モデルタブ](../images/screenshots/ja/settings-models.png)

このページには2つのリストがあります：

- 左側の **利用可能なモデル**
- 右側の **選択済みモデル**

便利な操作機能：

- **モデルを検索…**：名前でモデルを検索
- **プロバイダー**のチップ：一覧を特定のエンジン（OpenRouter、OpenAI、Ollamaなど）に絞り込む
- **無料のみ**：無料モデルのみを表示
- **更新**：リストを再読み込み
- **すべて展開**および**すべて折りたたみ**：プロバイダー別に並べ替えているときに便利

モデルIDにはプロバイダーの接頭辞が含まれます（たとえば `openrouter/…` と `openai/…`）。**OpenAI (OpenRouter)** や **OpenAI (直接)** のようなバッジは、通信がどのようにルーティングされるかを示しています。

> ℹ️ **注記**<br/>
> **OpenRouter Body Builder**（`openrouter/bodybuilder`）は汎用チャットモデルではなく、ルーター用のモデルです。その応答はJSON形式であり、OpenRouter APIリクエストボディの構造（たとえば、`model`や`messages`を含む`requests`配列）を記述したものです。このモデルを**翻訳**、**リライト**、**変換**に使用すると、完成したテキストではなく、そのJSONが出力パネルに表示されます。これらのタスクには通常のテキストモデルを選択してください。詳細は、OpenRouterの[Body Builderモデルページ](https://openrouter.ai/openrouter/bodybuilder)を参照してください。

操作方法：

- モデルを追加するには、**追加**ボタンまたは「利用可能なモデル」内の任意のエントリをクリックします。

- モデルを削除するには、**選択済みモデル**の横にある**X**ボタン、または「利用可能なモデル」のエントリにある**選択済み**をクリックします。

- リストをすべてクリアするには、**すべて選択解除**をクリックします。ただし、必須の無料モデルはリストに残ります。

<br/>

> ℹ️ **注記**<br/>
> OpenRouterにすぐにクレジットを追加したくない場合は、まず**無料のみ**を有効にして、無料モデル（クレジットカード不要）を選択してください。また、Ollamaを使用して、APIキーなしでローカルでモデルを実行することもできます。

<a id="cost-tracking"></a>
### 料金の追跡

**設定** > **料金追跡**を使って、料金に関する情報を管理します。

- **合計料金**：累計金額を表示
- **値をコピー**：合計をクリップボードにコピー
- **料金リセット**：記録されている合計をゼロにリセット
- **APIキー使用量と同期**：保存されている合計をOpenRouterアカウントに報告された使用量と一致させる（OpenRouterのみ）
- **APIキー使用量**：利用可能な場合、OpenRouterの使用詳細を表示
- **料金データの削除**：すべてのデータ、または指定した日付より古いエントリのみを削除

**料金追跡について**：OpenRouterモデルを使用している場合、アプリはOpenRouterからの料金情報に基づいて、実際の使用量と課金額を表示します。その他のプロバイダーについては、OpenRouterが公開している価格を使用して見積もりを算出します。価格が不明な場合は、推定値がゼロになる可能性があります。

<br/>

> ℹ️ **注記**<br/>
> すべての料金情報は参考用の見積もりであり、公式の請求書ではありません。

<br/>

> ⚠️ **警告**<br/>
> データの削除は元に戻せません。削除する前に、必ずデータをバックアップするか、[**履歴**](#history) または [**ダッシュボード** > **すべての呼び出し**](#dashboard-tabs) からエクスポートしてください。削除すると、完全に失われます。各API呼び出しエントリに関連する入出力履歴もすべて削除されます。

<a id="api-config"></a>
### API設定

対応しているプロバイダーは以下のとおりです：OpenRouter、OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、Mistral、xAI、Cerebras、および**Ollama**（基本URL経由のローカルモデル）。使用するプロバイダーのみを設定する必要があります。

**Webアプリケーション：管理者のみ**

APIキーは、システムまたはDockerの環境変数で設定します。Web UIには入力しません。このページでは、どのプロバイダーにキーが設定されているかを確認でき、**`テスト`** ボタンをクリックして各プロバイダーの接続テストができます。

<br/>

> ℹ️ **注記**<br/>
> APIキーを変更するには、システムまたはDockerの設定で環境変数を更新し、サーバーまたはコンテナを再起動してください。

<br/>

**デスクトップアプリケーション**

使用する各プロバイダーのAPIキーを**API設定**に保存します。Ollamaの場合は、APIキーの代わりに**基本URL**を入力してください。

<br/>

> 💡 **ヒント**<br/>
> APIキーを使いたくない、または料金を支払いたくない場合、[Ollamaをダウンロード](https://ollama.com)して、マシン上でモデル（たとえば `translategemma:4b`）を無料でローカル実行できます。または、クレジットカード不要の無料OpenRouterアカウントを作成して無料モデルを使うか、Cerebras、Google、Groq、Mistral AIから無料APIキーを取得することもできます。

<br/>

使用するプロバイダーだけを追加してください。**設定** > **モデル**では、各モデルIDはプロバイダー名で始まります（例：`openrouter/openrouter/free`、`openai/gpt-4o`、`ollama/llama3`）。

APIキーを追加するには、テキストフィールドに値を入力し、**`保存`** をクリックしてください。既存のキーを置き換えるには、**`編集`** をクリックしてください。キーが正常に動作するか確認するには、**`テスト`** をクリックしてください。Ollamaの基本URLの場合は、必ず**`テスト`** をクリックして接続を確認してください。

<br/>

> ℹ️ **注記**<br/>
> 現在設定されているAPIキーの値は確認できません。**`編集`** ボタンを使って置き換えることしかできません。APIキーは設定内に暗号化されて保存されます。

<a id="common-issues"></a>
## よくある問題

なにかが期待通りに動作しない場合は、まず以下の点を確認してください。

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### アプリがテキストを翻訳、書き換え、変換しない

以下の項目を確認してください：

- ツールバーでモデルが選択されていること
- [**設定** > **モデル**](#models) に少なくとも1つのモデルが登録されていること
- APIの設定が正常に機能していること

デスクトップアプリをご利用の場合：

1. [**設定** > **API設定**](#api-config) を開きます。
2. 少なくとも1つのAPIキーが保存されていることを確認します。
3. プロバイダー横の **テスト** をクリックして、キーが正常に機能するか確認します。

<br/>

<a id="the-model-list-is-empty"></a>
### モデル一覧が空である

[**設定** > **モデル**](#models) を開き、**更新**をクリックします。

必要に応じて：

- モデルを検索する
- **無料のみ**を有効にする
- **選択済みモデル**に1つ以上のモデルを追加する

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### 結果が遅い、または高額すぎる

以下のいずれかを試してください：

- 違うモデルを選択する
- 入力するテキストを短くする
- [**設定** > **全般**](#general-settings) で **リアルタイム翻訳（入力中）** を無効にする
- 単純なタスクには無料モデルを使用する（[モデル](#models)参照）

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### インターフェースの言語が正しくない

[ツールバー](#toolbar) の地球儀アイコンをクリックし、希望する**インターフェース言語**を選んでください。

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### テキストが小さすぎて読みづらい

[**設定** > **全般**](#general-settings) を開き、以下の設定を変更してください：

- **フォントファミリー**
- **サイズ**

<br/>

<a id="dashboard-charts-are-empty"></a>
### ダッシュボードのグラフが空である

以下の場合、これは正常な現象です：

- **無料モデルのみ**を使用している場合（料金に関するグラフは空欄のまま）
- 選択した**期間フィルター**が実行された期間を含んでいない場合 — **すべて**を選択して確認してみてください

**すべて**を選択してもグラフが空の場合は、[**履歴**](#history) または **すべての呼び出し** タブに呼び出しが表示されているか確認してください。

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### 料金が「利用不可」と表示される、または不正確に見える

**OpenRouter経由**でモデルを使用している場合、アプリはOpenRouterが報告した実際の料金を表示します。

**その他のプロバイダー**（OpenAI直接、Anthropic直接など）については、OpenRouterが公開している価格データに基づいて料金が推定されます。モデルに一致する価格が見つからない場合、料金は **利用不可** と表示され、合計に加算されません。

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### 合計料金がプロバイダーの請求額と一致しない

アプリ内のすべての料金は、**参考用の推定値**であり、正式な請求書ではありません。

合計金額を実際のOpenRouterの利用額に近づけるには、[**設定** > **料金追跡**](#cost-tracking) を開き、**APIキー使用量と同期**をクリックしてください。

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### 履歴ページがサイドバーに表示されていない

**実行履歴を保持する** が無効になっている可能性があります。[**設定** > **全般**](#general-settings) を開き、これを有効にしてください。オンにしても、それ以前に削除された履歴データは復元されないことに注意してください。

<br/>

<a id="web-app-session-expired"></a>
### Webアプリ：ログインページに予期せずリダイレクトされる

セッションがタイムアウトした可能性があります。再度ログインしてください。頻繁に発生する場合は、サーバー設定でセッション有効期間を確認してください。

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ダッシュボードが他のユーザーのデータを表示しない（Web）

**管理者**のみが**ユーザー**フィルターを使用してすべてのユーザーのデータを表示できます。通常のユーザーは、仕様上、自分の活動のみが表示されます。

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### プロンプトを編集して変更を失ってしまった

プロンプトを編集する際は、**実行に戻る**をクリックする前に、必ず **保存** をクリックしてください。

<br/><br/>

<a id="quick-tips"></a>
## 便利なヒント

- まず[**翻訳**](#translate)を試して、設定が正常に機能しているか確認してから、[**書き換え**](#rewrite)や[**変換**](#transform)に進んでください。
- 日常の文章改善には[**書き換え**](#rewrite)を使用してください。
- 特定のタスクで繰り返し使用できるワークフローが必要な場合は、[**変換**](#transform)を使いましょう。
- 使用量とコストの確認には、[**ダッシュボード**](#dashboard)をご利用ください。
- 過去の操作とその入出力全文を確認するには、[**履歴**](#history)をご利用ください。
- プロンプトリポジトリを安全に保存したい（[変換プロンプト](#transform-prompts)参照）場合や、他の人と共有したい場合は、定期的にプロンプトをエクスポートしてください。
