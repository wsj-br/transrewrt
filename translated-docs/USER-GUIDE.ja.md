# Transrewrt ユーザーガイド

<br />

<a id="introduction"></a>
## はじめに

Transrewrt は、テキストを操作するための3つの主要な方法を提供します：

- **Translate** - ある言語から別の言語へテキストを変換します。
- **Rewrite** - より明確に、短く、またはより正式になど、異なるスタイルでテキストを言い換えます。
- **Transform** - プロンプトと呼ばれるカスタムAI指示を使用してテキストを処理します。

<br />

このガイドは、アプリをインストールして起動した後の使用方法を説明します。インストール手順については、メインの [README](../README.md) を参照してください。

<br />

> ℹ️ **注意**<br/>
> Transrewrt は、Windows および Linux 向けのデスクトップアプリ、およびセルフホスト型の Web アプリとして利用できます。このガイドでは、アプリの日常的な使用方法に焦点を当てています。特定のバージョンにのみ適用される内容については、明確に記載されています。

<a id="before-you-start"></a>

## はじめる前に

Transrewrt を使用するには、OpenRouter 経由で AI サービスにアクセスする必要があります。

開始する前に有料モデルを選択する必要はありません。このアプリには常に組み込みの**無料**モデルが含まれているため、通常の使用では、テキストの翻訳、書き換え、変換を開始するのに十分です。

簡単に言うと：

- **モデル** とは、実際に処理を行う AI エンジンです。
- **API キー** とは、そのサービスへの個人のアクセス認証情報です。

**デスクトップアプリ** を使用する場合は、API キーが必要になります。詳細な手順については、以下にある [API キーの取得方法（デスクトップアプリ）](#how-to-get-an-api-key-desktop-app) を参照してください。簡単に説明すると、[OpenRouter](https://openrouter.ai) でアカウントを作成し、[Keys](https://openrouter.ai/keys) ページを開き、新しいキーを作成して、Transrewrt の [**設定** > **API 設定**](#api-config) に貼り付けます。

**ウェブ版** を使用する場合は、通常サーバー管理者が設定するため、自分で API キーを入力する必要はありません。

<br />

<a id="how-to-get-an-api-key-desktop-app"></a>
### API キーの取得方法（デスクトップアプリ）

デスクトップアプリを使用している場合は、次の手順に従ってください：

1. ウェブブラウザで [OpenRouter](https://openrouter.ai) にアクセスします。
2. アカウントを作成するか、サインインします。
3. [Keys](https://openrouter.ai/keys) ページを開きます。
4. 新しい API キーを作成するボタンをクリックします。
5. 後で認識できるようにキーに名前を付けます。
6. 新しい API キーをコピーします。
7. Transrewrt に戻り、[**設定** > **API 設定**](#api-config) を開きます。
8. **OpenRouter API キー** にキーを貼り付けます。
9. **API 設定をテスト** をクリックして、機能することを確認します。

> ℹ️ **注意**<br/>
> OpenRouter の無料ルートまたは他の利用可能な無料モデルから開始できます。多くの場合、有料モデルを選択せずに Transrewrt の使用を開始するにはこれで十分です。

<a id="getting-started"></a>
## はじめる

Transrewrt を初めて使用する場合は、次の順序で進めてください：

1. アプリを開きます。
2. 必要に応じて、地球アイコンから **インターフェース言語** を選択します。
3. **デスクトップアプリ** をご使用の場合、[**設定** > **API 設定**](#api-config) を開き、OpenRouter API キーを貼り付け、**API 設定をテスト** をクリックします。
4. [**設定** > **モデル**](#models) を開き、1 つまたは複数のモデルを **選択されたモデル** に追加します。
5. [**設定** > **言語**](#languages) を開き、最も使用する言語を最初に表示したい場合は **優先言語** を選択します。
6. **翻訳** に進み、簡単な翻訳を実行してすべてが正常に動作することを確認します。
7. これが機能したら、**書き換え** そして **変換** を試してください。

この順序が重要です。アプリに正常な API 接続または選択されたモデルがない状態でタスクを実行しようとする、最も一般的な初回使用時の問題を防ぎます。

<a id="input-and-output-panels"></a>

### 入力および出力パネル

ほとんどのワークスペースは、左側に **入力** パネル、右側に **出力** パネルを使用します。

**入力** パネルには以下が表示されます：

- 文字数
- 単語数
- 段落数

**出力** パネルには以下を表示できます：

- タスクに要した時間
- そのタスクのコスト
- 累計コスト
- **TPS**（1秒あたりのトークン数）：単純な速度指標
- 文字数、単語数、段落数
- 使用されたモデル

専門用語について疑問がある場合は：

- **トークン** とは、テキストの小さな単位です。単語の一部または短い単語と考えることができます。
- **TPS** とは、モデルが1秒あたりに処理したそれらのテキスト単位の数を意味します。

<a id="translate"></a>
## Translate

テキストをある言語から別の言語に変換したい場合は、**Translate** を使用します。

![Translate workspace](../images/screenshots/ja/translate.png)

<br />

<a id="translate-text"></a>
### テキストの翻訳

1. **Translate** を開きます。
2. **From** で言語を選択します。
3. **To** で言語を選択します。
4. ツールバーでモデルを選択します。
5. **入力** にテキストを入力または貼り付けます。
6. **Translate** をクリックします。
7. **出力** で結果を確認します。
8. 結果をコピーする場合は、コピーボタンを使用します。

<br />

<a id="language-selection"></a>
### 言語選択

- **From** は、特定の言語または **Detect Language** にすることができます。
- **To** は、結果を取得したい言語です。

選択した **トップ言語** がリストの先頭に表示されます。これらは [**設定** > **言語**](#languages) で設定できます。

<br />

<a id="helpful-translation-settings"></a>
### 役立つ翻訳設定

[**設定** > **一般設定**](#general-settings) で、翻訳の動作を変更できます：

- **貼り付け時に自動翻訳** をオンにすると、テキストを貼り付けた瞬間に翻訳が実行されます。
- **結果を自動的にクリップボードにコピー** をオンにすると、正常に実行された後に結果が自動的にコピーされます。
- **リアルタイム翻訳（入力中）** をオンにすると、入力中に翻訳が実行されます。
- **タイムアウト（ミリ秒）** で、リアルタイム翻訳を実行するまでの待機時間を制御します。

<br />

<a id="keyboard-shortcuts"></a>
### キーボードショートカット

[**設定** > **一般設定**](#general-settings) の **Enterキーの動作** で、Enterキーを押したときの動作を制御します：

- **Enter** でタスクを実行し、**Shift+Enter** で新しい行を追加する。
- またはその逆に設定できます。

現在のショートカットは **Translate** ボタンにも表示されます。

<a id="rewrite"></a>
## Rewrite

主要な意味を変えずに文章表現を改善したい場合は、**Rewrite** を使用します。

![Rewrite workspace](../images/screenshots/ja/rewrite.png)

これは以下に便利です：

- スペルと文法の修正
- 文章を明確にすること
- 文章をより正式またはくだけたものにすること
- 文章を短くまたは長くすること
- 文章をより技術的に聞こえるようにすること

<br />

<a id="rewrite-text"></a>
### テキストの書き換え

1. **Rewrite** を開きます。
2. **モード** を選択します。
3. ツールバーでモデルを選択します。
4. **入力** にテキストを入力または貼り付けます。
5. **Rewrite** をクリックします。
6. **出力** で結果を確認します。

[**Translate**](#keyboard-shortcuts) で説明したのと同じ Enter キーの動作がここでも適用されます。

<a id="transform"></a>
## Transform

AI にカスタムの一連の指示に従わせたい場合は、**Transform** を使用します。

![Transform workspace](../images/screenshots/ja/transform.png)

これはアプリで最も柔軟な領域です。以下のようなタスクに使用できます：

- メモの要約
- 下書きのテキストを磨かれたメールに変える
- 要点の抽出
- テキストを特定の形式に変換

<br />

<a id="run-an-existing-prompt"></a>
### 既存のプロンプトの実行

1. **Transform** を開きます。
2. プロンプトリストからプロンプトを選択します。
3. **対象** 言語ボックスが表示された場合、必要な言語を選択します。
4. **入力** にテキストを入力または貼り付けます。
5. **Transform** をクリックします。
6. **出力** で結果を確認します。

<br />

<a id="if-you-have-no-prompts-yet"></a>
### まだプロンプトがない場合

プロンプトリストが空の場合は、**サンプルプロンプトを読み込む** をクリックします。これにより組み込みの例が追加され、すぐに開始できます。

> ℹ️ **注意**<br/>
> サンプルプロンプトは英語で提供されています。読み込んだ後、プロンプトを編集し、プロンプトテキストを別の言語用に調整したい場合は **プロンプトを翻訳** を使用できます。

<br />

<a id="create-a-prompt-quickly"></a>

### プロンプトをすばやく作成する

プロンプトを作成する最も高速な方法は次のとおりです。

1. **[新規プロンプト]** をクリックします。
2. **[プロンプトを生成]** をクリックします。
3. プロンプトに実行させたい内容を説明します。
4. モデルを選択します。
5. アプリが下書きを作成します。
6. 下書きを確認し、**[保存]** をクリックします。

![Generate prompt](../images/screenshots/ja/transform-generate.png)


<br />

### プロンプトを編集する

プロンプトを作成または編集すると、左側にエディター、右側にテストエリアが表示されます。

![Transform prompt editor](../images/screenshots/ja/transform-prompt-edit.png)

主なフィールドは次のとおりです。

- **プロンプト名**: プロンプトリストに表示される名前です。
- **プロンプトの指示 (オプション)**: プロンプト実行時にユーザーに表示される短いヒントです。
- **モデルの役割**: AIに割り当てる全体的な役割 (例: 'You are a helpful assistant.')。
- **モデルへの指示 (1行に1つ)**: AIに従わせたい具体的なルールです。
- **出力の説明**: 結果を表す短い単語 (例: 'summary' や 'rewrite')。
- **温度 (0.0 → 1.0)**: 創造性のスライダー。
- **ターゲット言語を要求**: プロンプト実行時にターゲット言語セレクターを追加します。

技術用語 **温度** が初めての場合、次のように考えてください。

- **低い** 温度では、安定していて予測可能な結果が得られます。
- **高い** 温度では、多様性と創造性が高まります。

また、次の機能も使用できます。

- **`プロンプトを生成`**: 簡単な説明から新しい下書きを作成します
- **`プロンプトを改善`**: 既存のプロンプトを改良します
- **`プロンプトを翻訳`**: プロンプトフィールドを翻訳します

> ⚠️ **警告**<br/>
> **`戻る`** をクリックする前に **`保存`** をクリックしてください。保存せずに戻ると、変更は失われます。

<br />

<a id="test-a-prompt-before-using-it"></a>
### 使用前にプロンプトをテストする

右側のテストパネルを使用すると、日常業務で使用する前に、サンプルテキストでプロンプトを試すことができます。

これは次の場合に役立ちます。

- 新しいプロンプトを作成しているとき
- プロンプトの2つのバージョンを比較しているとき
- トーン、長さ、または出力形式を確認したいとき

<br />

<a id="manage-saved-prompts"></a>
### 保存したプロンプトを管理する

保存したプロンプトを1箇所で管理するには、[**設定** > **変換プロンプト**](#transform-prompts) を開きます。

在那里では以下を実行できます。

- プロンプトをリスト表示して削除する
- プロンプトを **JSON**、**CSV**、または **XLSX** としてエクスポートする
- ファイルからプロンプトをインポートする

### ダッシュボードのタブ

- **概要** は、使用量とコストの概要を示します。
- **使用量別** は、翻訳言語、書き換えモード、変換プロンプト別にアクティビティを分類します。
- **モデル別** は、使用したモデルとそのコストを示します。
- **日別** は、 daily totals を示します。
- **全通話** は、完全な通話履歴を表示し、エクスポートを可能にします。

<br />

<a id="export-data"></a>
### データをエクスポートする

ダッシュボードのテーブルは、次の形式でデータをエクスポートできます。

- **JSON**
- **CSV**
- **XLSX**

これは、アプリ外でアクティビティを確認したりレポートを共有したりする場合に役立ちます。

<br />

<a id="delete-stored-records-for-a-model"></a>
### モデルの保存レコードを削除する

**モデル別** または **全通話** で、モデルの保存レコードを削除できます。

> ⚠️ **警告**<br/>
> 保存レコードの削除は元に戻せません。この履歴が不要であると確信している場合のみ使用してください。

すべてのデータを削除する、または日齢に基づいてレコードを削除するには、[**設定** > **コスト追跡**](#cost-tracking) に移動してください。在那里では、すべての保存データを削除するオプションや、特定の日より古いデータのみ削除するオプションが見つかります。

<br /><br />

<a id="settings"></a>
## 設定

サイドバーから **設定** を開いて、アプリの動作をカスタマイズします。

利用可能なタブは異なる場合があります。

- **API設定** はデスクトップアプリのみで利用可能です。
- **ユーザー** は Webアプリのみで利用可能であり、管理者のみがアクセスできます。

<br />

<a id="general-settings"></a>

### 一般設定

**一般設定** を使用して、入力動作と外観を制御します。

**動作**

- **ENTER の動作** は、Enter キーでタスクを実行するか、新しい行を挿入するかを選択します。
- **貼り付け時に自動翻訳** は、テキストを貼り付けるとすぐに翻訳を開始します。
- **結果を自動でクリップボードにコピー** は、成功した結果を自動的にコピーします。
- **リアルタイム翻訳（入力中）** は、入力しながら翻訳します。
- **タイムアウト (ミリ秒)** は、リアルタイム翻訳の待ち時間を設定します。

**外観**

- **コストの小数桁数** は、コストの小数点以下の表示方法を変更します。
- **フォント ファミリ** は、テキスト パネルの書体を変更します。
- **サイズ** は、フォント サイズを変更します。
- **Web のみ:** **アプリの周りにマージンを表示** は、インターフェースの周囲に余分なスペースを追加します。

<br />

<a id="models"></a>
### モデル

**設定** > **モデル** を使用して、ツールバーに表示されるモデルを選択します。

![設定 モデル タブ](../images/screenshots/ja/settings-models.png)

このページには 2 つのリストがあります。

- 左側の **利用可能なモデル**
- 右側の **選択されたモデル**

便利なコントロールには以下が含まれます。

- モデルを名前で検索する **モデルを検索...**
- 無料モデルのみを表示する **無料のみ**
- リストを再読み込みする **更新**
- プロバイダー別に並べ替える場合の **すべて展開** と **すべて折りたたみ**

モデルを追加するには、**追加** をクリックします。

モデルを削除するには、**選択されたモデル** 内のそのモデルの横にある **X** をクリックします。

リストをクリアするには、**すべて選択解除** をクリックします。必要な無料モデルはリストに残ります。

> ℹ️ **注意**<br/>
> OpenRouter にすぐにクレジットを追加したくない場合は、まず **無料のみ** を有効にし、無料モデルを選択することから始めてください。

<br />

<a id="languages"></a>
### 言語

**設定** > **言語** を使用して、アプリで使用される言語リストを整理します。

- **優先言語** は、**翻訳** と **変換** の言語リストの上部近くに固定されます。
- **カスタム言語** を使用すると、組み込みリストにない言語を追加できます。

カスタム言語を追加すると、組み込みオプションと一緒に言語セレクターに表示されます。

<br />

<a id="cost-tracking"></a>
### コスト追跡

**設定** > **コスト追跡** を使用して、コスト情報を管理します。

- **総コスト** は、累計を表示します。
- **値をコピー** は、合計をクリップボードにコピーします。
- **コストをリセット** は、保存された合計をゼロにリセットします。
- **API キーの使用状況と同期** は、OpenRouter から報告された使用状況に合わせて総計を設定します。
- **API キー使用状況** は、利用可能な場合、使用状況の詳細を表示します。
- **コスト データを削除** は、すべてのデータを削除するか、選択した日付より古いエントリのみを削除します。

> ⚠️ **警告**<br/>
> データ削除は元に戻せません。削除する前に、データのバックアップを取るか、[**ダッシュボード** > **すべての呼び出し**](#dashboard-tabs) からエクスポートしてください。そうしないと、データは完全に失われます。

<br />

<a id="transform-prompts"></a>
### 変換プロンプト

**設定** > **変換プロンプト** を使用して、プロンプトを一括管理します。

以下を行うことができます。

- 保存したプロンプトを確認する
- プロンプトを削除する
- ファイルからプロンプトをインポートする
- バックアップまたは共有のためにプロンプトをエクスポートする

<br />

<a id="users"></a>
### ユーザー

**Web のみ - 管理者のみ**

**ユーザー** を使用して、Web バージョンのユーザー アカウントを管理します。ユーザーの追加、詳細の更新、パスワードのリセット、アカウントの削除を行うことができます。

<br />

<a id="api-config"></a>
### API 設定

**デスクトップのみ**

**API 設定** を使用して、デスクトップ アプリを OpenRouter または Transrewrt プロキシに接続します。

- **OpenRouter API キー** は、キーを貼り付ける場所です。
- **API URL** は、サービスのアドレスです。別のアドレスが指定されていない限り、デフォルトのままにしてください。
- **Transrewrt プロキシを使用** は、リクエストを OpenRouter に直接ではなく、プロキシ サービス経由でルーティングします。
- **キー シード** は、プロキシ オプションが有効になると表示されます。
- **API 設定をテスト** は、現在のセットアップが機能しているかどうかを確認します。

API キーの取得に関する詳細な手順については、上記の [API キーの取得方法](#how-to-get-an-api-key-desktop-app) を参照してください。

> ℹ️ **注意**<br/>
> **API URL**、**Transrewrt プロキシを使用**、または **キー シード** の意味が不明な場合は、変更せずにデフォルトの OpenRouter セットアップを使用してください。プロキシの詳細は、[Transrewrt Proxy リポジトリ](https://github.com/wsj-br/transrewrt-proxy) で確認できます。

<a id="common-issues"></a>
## 一般的な問題

想定どおりに動作しない場合は、まず以下のポイントを確認してください。

<br />

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### アプリがテキストを翻訳、書き換え、変換しない

以下を確認してください：

- ツールバーでモデルが選択されていること
- [**設定** > **モデル**](#models) に少なくとも1つのモデルがリストされていること
- API設定が正しく機能していること

デスクトップアプリを使用している場合：

1. [**設定** > **API設定**](#api-config) を開く。
2. APIキーが保存されていることを確認する。
3. **API設定をテスト** をクリックする。

<br />

<a id="the-model-list-is-empty"></a>
### モデルリストが空である

[**設定** > **モデル**](#models) を開き、**更新** をクリックする。

必要に応じて：

- モデルを検索する
- **無料のみ** をオンにする
- 1つ以上のモデルを **選択したモデル** に追加する

<br />

<a id="the-result-is-too-slow-or-too-expensive"></a>
### 結果が遅すぎる、または高すぎる

以下の1つ以上を試してください：

- 別のモデルを選択する
- 入力テキストを短くする
- [**設定** > **一般設定**](#general-settings) で **リアルタイム翻訳（入力中）** をオフにする
- 簡単なタスクには無料モデルを使用する（[モデル](#models) を参照）

<br />

<a id="the-interface-is-in-the-wrong-language"></a>
### インターフェースの言語が誤っている

[ツールバー](#toolbar) の地球アイコンをクリックし、希望する **インターフェース言語** を選択してください。

<br />

<a id="the-text-is-too-small-or-hard-to-read"></a>
### テキストが小さすぎる、または読みづらい

[**設定** > **一般設定**](#general-settings) を開き、以下を変更する：

- **フォントファミリー**
- **サイズ**

<br />

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### プロンプトを編集した際、変更が失われた

プロンプトを編集する際は、**実行に戻る** をクリックする前に必ず **保存** をクリックしてください。

<br /><br />

<a id="quick-tips"></a>
## クイックヒント

- [**翻訳**](#translate) から始めて、セットアップが正常に機能することを確認してから、[**書き換え**](#rewrite) や [**変換**](#transform) に進みましょう。
- 日常的な文章の改善には [**書き換え**](#rewrite) を使用する。
- 特定のタスクに対する再利用可能なワークフローが必要な場合は [**変換**](#transform) を使用する。
- 使用量とコストを監視したい場合は [**ダッシュボード**](#dashboard) を使用する。
- プロンプトライブラリを安全に保管したい場合は、定期的にプロンプトをエクスポートする（[変換プロンプト](#transform-prompts) を参照）。
