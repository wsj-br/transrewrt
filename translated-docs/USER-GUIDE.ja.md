# ユーザーガイド

<br/>

<a id="introduction"></a>
## はじめに

Transrewrt は、テキストを以下の3つの方法で扱うのを助けます。

- **翻訳** - テキストをある言語から別の言語に変換します。
- **言い換え** - より明確に、短く、あるいはよりフォーマルなスタイルなど、異なるスタイルでテキストを言い換えます。
- **変換** - プロンプトと呼ばれるカスタムAI指示を使ってテキストを処理します。

<br/>

このガイドでは、アプリのインストールと起動後にどのように使用するかを説明しています。インストール手順については、メインの **[README](README.ja.md)** をご覧ください。

<br/>

> ℹ️ **注意**<br/>
> Transrewrt は、WindowsおよびLinux用のデスクトップアプリとして、またセルフホスト型のWebアプリとしても利用可能です。このガイドはアプリの日常的な使い方を中心に説明しています。特定のバージョンにのみ適用される機能については、明確にマークしています。

<a id="before-you-start"></a>

## はじめに

Transrewrt を使用するには、少なくとも1つのAIプロバイダーへのアクセスが必要です。対応しているプロバイダーは以下のとおりです：[OpenRouter](https://openrouter.ai)（多数のモデルを提供）、OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、Mistral、xAI、およびローカルモデル用の [Ollama](https://ollama.com)。

開始する際に有料モデルを選択する必要はありません。OpenRouterのAPIキーを追加すると、アプリは自動的に組み込みの**無料**OpenRouterオプションを有効にします。これにより、すぐにテキストの翻訳、書き換え、変換を開始できます。

平易に説明すると次のとおりです。

- **モデル**とは、処理を行うAIのエンジンです。モデルには**プロバイダー接頭辞**（例：`openrouter/…`、`openai/…`、`ollama/…`）が付いて表示されます。
- **APIキー**（Ollamaの場合は**ベースURL**）は、アプリがそのプロバイダーにアクセスするための手段です。

**デスクトップアプリ**を使用する場合、使用する各プロバイダーのAPIキーを[**設定** > **API設定**](#api-config)で登録してください。OpenRouterのみ使用する場合は、以下の[APIキーの取得方法](#how-to-get-an-api-key-desktop-app)を参照してください。APIキーを使いたくない場合は、[ollama.com](https://ollama.com) からOllamaをインストールし、ローカルモデルを使用できます。

**Web版**を使用している場合、サーバー管理者が環境変数でプロバイダーを設定しているため、通常、自分でAPIキーを入力する必要はありません。

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### 無料のOpenRouter APIキーを取得する方法（デスクトップアプリ）

デスクトップアプリを使用する場合は、以下の手順に従ってください。

1. Webブラウザで [OpenRouter](https://openrouter.ai) にアクセスする。
2. アカウントを作成またはログインする。
3. [Keys](https://openrouter.ai/keys) ページを開く。
4. 新しいAPIキーを作成するボタンをクリックする。
5. 後で識別できるようにキーに名前を付ける。
6. 新しいAPIキーをコピーする。
7. Transrewrtに戻り、**設定** > **API設定** を開く。
8. **OpenRouter APIキー**（**設定** > **API設定**内）にキーを貼り付ける。
9. **OpenRouterキーのテスト**をクリックして、正しく動作するか確認する。

<br/>

> ℹ️ **注記**<br/>
> クレジットカードを登録せずに、OpenRouterの無料プランまたは他に利用可能な無料モデルから始められます。多くの場合、有料モデルを選ばなくてもTransrewrtの利用を開始できます。また、Ollamaを使用してAPIキーなしでローカルでモデルを実行することも可能です。

<br/><br/>

<a id="getting-started"></a>
## はじめに

初めてTransrewrtを使用する場合は、以下の順序で進めてください。

1. アプリを起動する。
2. 必要に応じて、地球儀アイコンから**インターフェース言語**を選択する。
3. **デスクトップアプリ**をお使いの場合は、[**設定** > **API設定**](#api-config)を開き、少なくとも1つのプロバイダー（たとえばOpenRouter）のAPIキーを追加し、**テスト**をクリックして正常に動作するか確認する。
4. [**設定** > **モデル**](#models)を開き、1つ以上のモデルを**選択済みモデル**に追加する。
5. [**設定** > **言語**](#languages)を開き、よく使う言語を上位に表示させたい場合は**主要言語**を選択する。
6. **翻訳**に移動し、簡単な翻訳を実行してすべてが正常に動作していることを確認する。
7. 動作を確認したら、次に**書き換え**を試し、その後**変換**を試す。

この手順の順序は重要です。アプリが有効なAPI接続を持つこと、およびモデルが選択されていることを保証することで、初めて使用するときに最も起こりがちな「タスクを実行する前に接続やモデルの準備ができていなかった」という問題を防ぎます。

<a id="toolbar"></a>

### ツールバー

ツールバーの内容は、アプリ内のいる場所によって多少異なります。

- 左側には現在のページ名が表示されます。
- 右側には**モデルセレクタ**と**インターフェース言語**のコントロールが表示されます。

**モデルセレクタ**を使用すると、現在のタスクに利用するAIエンジンを選択できます。

  ![モデルセレクタ](../images/screenshots/ja/model-selector.png)

> ℹ️ **注記**<br/>
> 無料のモデルの一部は常に利用可能というわけではありません。オフラインになっている、または使用量の上限がある場合があります。そのような場合には、アプリが自動的にそのモデルを使用可能なリストから除外します。<br/>

> また、ツールバーのモデル名の左側にあるプロバイダーのアイコンをクリックすると、モデルの設定を直接開くこともできます。

<br/>

<a id="input-and-output-panels"></a>
### 入力・出力パネル

ほとんどのワークスペースでは、左側に**入力**パネル、右側に**出力**パネルを使用します。

**入力**パネルには次の情報が表示されます：

- 文字数
- 単語数
- 段落数

**出力**パネルには次の情報が表示されることがあります：

- 処理にかかった時間
- タスクのコスト（利用可能な場合）
- 累計コスト
- **TPS**（1秒あたりのトークン数）
- 文字・単語・段落の数
- 使用されたモデル

技術的な用語について気になる場合は：

- **トークン**とは、短いテキストの断片のことを指します。1語の一部または短い単語だと考えてください。
- **TPS**とは、モデルが1秒間に処理したテキストの断片数を意味します。

<a id="translate"></a>
## 翻訳

テキストをある言語から別の言語に変換したい場合は、「**翻訳**」を使います。

![翻訳ワークスペース](../images/screenshots/ja/translate.png)

<br/>

<a id="translate-text"></a>
### テキストの翻訳

1. 「**翻訳**」を開きます。
2. 「**From**（元の言語）」で言語を選択します。
3. 「**To**（翻訳先）」で言語を選択します。
4. ツールバーからモデルを選択します。
5. **入力**欄にテキストを入力または貼り付けます。
6. 「**翻訳**」をクリックします。
7. **出力**欄で結果を確認します。
8. 結果をコピーする場合は、コピー用ボタンを使用してください。

<br/>

<a id="language-selection"></a>
### 言語の選択

- 「**From**」には特定の言語を指定するか、「**言語を自動検出**」を選べます。
- 「**To**」は、翻訳結果としてほしい言語です。

選択された「**主要言語**」は、言語リストの上部に表示されます。これらは[**設定** > **言語**](#languages)で設定できます。

<br/>

<a id="helpful-translation-settings"></a>
### 便利な翻訳設定

[**設定** > **一般設定**](#general-settings)で、翻訳の動作を変更できます：

- **貼り付け時に自動翻訳**：テキストを貼り付けた瞬間に翻訳を実行します。
- **結果を自動的にクリップボードにコピー**：翻訳成功後に、結果を自動的にコピーします。
- **リアルタイム翻訳（入力中の翻訳）**：入力中に翻訳を実行します。
- **タイムアウト（ミリ秒）**：リアルタイム翻訳の実行前に、アプリがどれだけ待つかを設定します。

<br/>

<a id="keyboard-shortcuts"></a>
### キーボードショートカット

[**設定** > **一般設定**](#general-settings)の「**Enterキーの動作**」では、`Enter`キーを押したときの挙動を制御できます：

- **Enterキー**でタスクを実行し、**Shift＋Enter**で改行する。
- またはその逆の動作にする。

現在のモードは、「**翻訳**」ボタンにも表示されます。

<a id="rewrite"></a>
## 文章の書き換え

主な意味を変えずに、文章の表現を改善したい場合は、「**文章の書き換え**」を使用します。

![文章の書き換えワークスペース](../images/screenshots/ja/rewrite.png)

これは次のような場面で便利です：

- スペルや文法の修正
- 文の分かりやすさの向上
- 文をよりフォーマルまたはカジュアルにする
- 文を短くまたは長くする
- 文をより技術的に聞かせる

### テキストの書き換え

1. **書き換え** を開く。
2. **モード** を選択する。
3. ツールバーからモデルを選択する。
4. **入力**欄にテキストを入力または貼り付ける。
5. **書き換え**をクリックする。
6. **出力**欄で結果を確認する。

[**翻訳**](#keyboard-shortcuts)で説明されているEnterキーの動作は、ここでも同様に適用されます。

<br/>

> 💡 **ヒント**<br/>
> 「**スペルと文法のチェック**」モードを使用すると、出力パネルに `変更を表示` ボタンが表示されます。
> このボタンをクリックすると、テキストに加えられた修正箇所の表示を切り替えられ、具体的な変更点を表示または非表示にできます。

<a id="transform"></a>
## 変換

カスタムの指示に従ってAIに処理させたい場合に **変換** を使用します。

![変換ワークスペース](../images/screenshots/ja/transform.png)

このアプリで最も柔軟性のある領域です。以下のようなタスクに活用できます。

- メモの要約
- ざっくりした文章を洗練されたメールに変換
- 主要なポイントの抽出
- テキストを特定の形式に変換

<br/>

<a id="run-an-existing-prompt"></a>
### 既存のプロンプトを実行する

1. **変換** を開く。
2. プロンプトリストからプロンプトを1つ選択する。
3. 必要に応じて表示される **ターゲット** 言語欄から言語を選択する。
4. **入力**欄にテキストを入力または貼り付ける。
5. **変換**をクリックする。
6. **出力**欄で結果を確認する。

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### プロンプトがない場合

プロンプトリストが空の場合は、「**サンプルプロンプトを読み込む**」をクリックしてください。標準のサンプルが追加され、すぐに使い始められます。

<br/>

> ℹ️ **注意**<br/>
> サンプルプロンプトは英語で提供されています。読み込んだ後、プロンプトを編集し、「**プロンプトの翻訳**」を使ってご希望の言語に翻訳できます。

<br/>

<a id="create-a-prompt-quickly"></a>
### 簡単にプロンプトを作成する

プロンプトを作成する最も速い方法は以下のとおりです。

1. **新しいプロンプト**をクリックする。
2. **プロンプトを生成**をクリックする。
3. そのプロンプトに何をさせたいかを説明する。
4. モデルを選択する。
5. アプリにドラフトを作成させる。
6. ドラフトを確認し、「**保存**」をクリックする。

![プロンプトの生成](../images/screenshots/ja/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### プロンプトを編集する

プロンプトを作成または編集すると、画面左側にエディタが、右側にテスト領域が表示されます。

![変換プロンプトエディタ](../images/screenshots/ja/transform-prompt-edit.png)

主なフィールドは以下の通りです。

- **プロンプト名**: プロンプトリストに表示される名前。
- **プロンプトの説明（オプション）**: プロンプト実行時にユーザーに表示される簡単なヒント。
- **モデルの役割**: AIに割り当てる全体的な役割。例:「あなたは便利なアシスタントです。」
- **モデルの指示（1行に1つずつ）**: AIに従ってもらいたい具体的なルール。
- **出力の説明**: 結果の簡単な説明語。例:「要約」や「書き換え」など。
- **温度（0.0 → 1.0）**: モデルの動作方法。詳細は以下を参照。
- **ターゲット言語の指定**: プロンプト実行時に言語選択欄を追加する。

専門用語の **温度** が初めての方は、次のように考えてください。

- **低い**温度ほど、安定しており予測しやすい結果を得られます。
- **高い**温度ほど、多様性と創造性が高まります。

以下の機能も使用できます。

- **`プロンプトを生成`**: 単純な説明から新しいドラフトを作成
- **`プロンプトを改善`**: 既存のプロンプトを洗練
- **`プロンプトを翻訳`**: プロンプトの各フィールドを翻訳

<br/>

> ⚠️ **警告**<br/>
> **`保存`** をクリックしてから **`実行に戻る`** をクリックしてください。保存せずに戻ると、変更内容は失われます。

<br/>

<a id="test-a-prompt-before-using-it"></a>

右側のテストパネルでは、日常業務で使う前に、サンプルテキストを使ってプロンプトを試すことができます。

これは、以下の場面で便利です。

- プロンプトの2つのバージョンを比較しているとき
- トーン、長さ、出力形式を確認したいとき

<a id="general-settings"></a>

### 一般設定

**一般設定**を使用して、入力動作、**履歴**に実行詳細を保存するかどうか、および外観を制御できます。

**動作**

- **Enter キーの動作**：`Enter` キーでタスクを実行するか、改行を挿入するかを選択します。
- **貼り付け時に自動翻訳**：テキストを貼り付けた時点で翻訳を開始します。
- **結果をクリップボードに自動コピー**：成功した結果を自動的にコピーします。
- **リアルタイム翻訳（入力中）**：入力中に翻訳を行います。
- **タイムアウト（ミリ秒）**：リアルタイム翻訳の待機時間を設定します。

**履歴**

- **実行履歴を保持**：サイドバーの[**履歴**](#history)ビューに、各翻訳・文の書き換え・変換時の**入力と出力のテキスト**を保存するかどうかを制御します。無効にすると確認が求められ、確認後、保存された履歴のテキストはデータベースから削除されます。
- **履歴データを削除**：**削除データ**を使って、期間別（例えば数ヶ月以上前など）または**すべてのデータ（クリア）**を削除できます。これは**履歴**ビューの保存済み実行テキストにのみ影響し、**コストや利用量の合計は削除されません**。**コスト**データを削除または削減するには、[**設定** > **コスト管理**](#cost-tracking)を使用してください。

**外観**

- **コスト小数桁数**：コストの小数点以下の表示桁数を変更します。
- **Web版のみ**：**アプリの周りにマージンを表示**は、インターフェースの周囲に余白を追加します。
- **フォントファミリー**：テキストパネルの文字フォントを変更します。
- **サイズ**：フォントサイズを変更します。


<br/>

<a id="models"></a>
### モデル

**設定** > **モデル** で、ツールバーに表示されるモデルを選択できます。

![設定 モデルタブ](../images/screenshots/ja/settings-models.png)

このページには2つのリストがあります：

- 左側の**使用可能なモデル**
- 右側の**選択済みモデル**

便利なコントロール：

- **モデルを検索...**：名前でモデルを検索
- **プロバイダー**のチップ：リストを特定のプロバイダーに絞り込み（OpenRouter、OpenAI、Ollama など）
- **無料モデルのみ**：無料のモデルだけを表示
- **更新**：リストを再読み込み
- プロバイダー別に並べ替える場合の**すべて展開**および**すべて折りたたみ**

モデルIDはプロバイダーの接頭辞を含みます（例：`openrouter/…` 対 `openai/…`）。**OpenAI (OpenRouter)** や **OpenAI (直接)** のようなバッジは、通信がどのルートを通っているかを示しています。

操作方法：

- モデルを追加するには、**追加**ボタンをクリックするか、該当する項目の任意の場所をクリックします。

- モデルを削除するには、**選択済みモデル**内のモデル横の**X**をクリックするか、**使用可能なモデル**の項目にある**選択済み**をクリックします。

- リストをすべてクリアするには、**すべて選択解除**をクリックします。必須の無料モデルはリストに残ります。

<br/>

> ℹ️ **注**<br/>
> OpenRouterにすぐにクレジットを追加したくない場合は、まず**無料モデルのみ**を有効にして、クレジットカード不要の無料モデルを選択してください。またOllamaを使用して、APIキーなしでローカルでモデルを実行することもできます。

<a id="cost-tracking"></a>
### コスト管理

**設定** > **コスト管理** で、コスト情報を管理します。

- **総コスト**：累計を表示します。
- **値をコピー**：合計をクリップボードにコピーします。
- **コストリセット**：保存されている合計をゼロにリセットします。
- **APIキー使用量と同期**：合計をOpenRouterアカウントの使用量報告に合わせます（OpenRouterのみ）。
- **APIキー使用量**：利用可能な場合、OpenRouterの使用詳細を表示します。
- **コストデータ削除**：すべてのデータ、または選択した日付より古いデータを削除します。

**コスト管理について**：OpenRouterモデルを使用している場合、アプリはOpenRouterから得たデータに基づいて、実際の使用量と支出額を表示します。その他のプロバイダーの場合は、OpenRouterが公開している価格を使ってコストを推定します。価格が取得できない場合は、推定値がゼロになる場合があります。

<br/>

> ℹ️ **注**<br/>
> すべてのコスト数値は、参考のための見積もりであり、正式な請求書ではありません。

<br/>

> ⚠️ **警告**<br/>
> データ削除は元に戻せません。削除する前に、必ずデータをバックアップするか、[**ダッシュボード** > **すべての呼び出し**](#dashboard-tabs)からエクスポートしてください。そうしないとデータは完全に失われます。<br/>
> 各API呼び出しエントリに関連するすべての履歴も同時に削除されます。

- 必要なプロバイダーのみを追加してください。**設定** > **モデル** では、各モデルIDの先頭がプロバイダー名で始まります（例：`openrouter/openrouter/free`、`openai/gpt-4o`、`ollama/llama3`）。

APIキーを追加するには、テキストフィールドにキー値を入力し、**`保存`** をクリックします。既存のキーを変更する場合は、**`編集`** をクリックします。キーが正常に動作するか確認するには、**`テスト`** をクリックします。

> ℹ️ **注意**<br/>
> 現在設定されているAPIキーの値を確認することはできません。**`編集`** ボタンを使ってのみ、キーを置き換えることが可能です。
> APIキーは設定ファイルに暗号化されて保存されます。

<br/>

OpenRouterキーの取得手順については、上記の「[APIキーの取得方法](#how-to-get-an-api-key-desktop-app)」を参照してください。

<a id="common-issues"></a>
## よくある問題

動作に問題がある場合は、まず以下の点を確認してください。

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### テキストの翻訳、書き換え、変換が行われない

以下の項目を確認してください。

- ツールバーでモデルが選択されているか
- [**設定** > **モデル**](#models) に少なくとも1つのモデルが登録されているか
- API設定が正常に機能しているか

デスクトップアプリを使用している場合は：

1. [**設定** > **API設定**](#api-config) を開く。
2. 少なくとも1つのAPIキーが保存されているか確認。
3. プロバイダー横の **テスト** をクリックして、キーが正常に動作するか確認。

<br/>

<a id="the-model-list-is-empty"></a>
### モデルのリストが空

[**設定** > **モデル**](#models) を開き、**更新** をクリックしてください。

必要に応じて：

- モデルを検索
- **無料のみ** を有効化
- **選択済みモデル** に1つ以上のモデルを追加

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### 結果が遅すぎる、またはコストが高すぎる

以下を1つ以上試してみてください。

- 異なるモデルを選択
- 入力文字数を短くする
- [**設定** > **一般設定**](#general-settings) で **リアルタイム翻訳（入力中）** をオフにする
- 単純なタスクには無料モデルを使用（「[モデル](#models)」参照）

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### インターフェースの言語が間違っている

[ツールバー](#toolbar) の地球儀アイコンをクリックし、希望の**インターフェース言語**を選んでください。

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### テキストが小さすぎて読めない

[**設定** > **一般設定**](#general-settings) を開き、以下の項目を変更してください。

- **フォントファミリ**
- **サイズ**

<br/>

<a id="dashboard-charts-are-empty"></a>
### ダッシュボードのグラフが空

以下の場合は、グラフが空になるのは正常です。

- **無料モデル** だけを利用している場合（コストのグラフは空白のまま）
- 選択した**時間範囲フィルター**がAPIリクエストの時刻をカバーしていない場合 — **すべて** を選んで確認してください

**すべて** を選択してもグラフが空のままである場合、[**履歴**](#history) や **すべての呼び出し** タブに呼び出しが表示されるか確認してください。

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### 料金が「利用不可」と表示される、または間違っているように見える

アプリでは、**OpenRouter** 経由でモデルを使用すると、OpenRouter から報告された実際の使用額を表示します。

**その他のプロバイダー**（OpenAI 直接、Anthropic 直接など）の場合、料金は OpenRouter が公開している価格データから算出された推定値です。モデルに一致する価格データが見つからない場合、料金は **利用不可** と表示され、合計金額にも加算されません。

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### 合計料金がプロバイダーの請求額と一致しない

アプリ内に表示されるすべての料金は、**あくまで参考のための推定値**であり、正式な請求書ではありません。

合計金額を実際の OpenRouter 料金により近づけたい場合、[**設定** > **料金のトラッキング**](#cost-tracking) を開き、「API キー使用量と同期」をクリックしてください。

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### サイドバーに履歴ページが表示されない

「**実行履歴を保持**」が無効になっている可能性があります。[**設定** > **一般設定**](#general-settings) から有効にしてください。なお、この設定を有効にしても、以前に削除された履歴データは復元されません。

<br/>

<a id="web-app-session-expired"></a>
### Webアプリ：ログインページに予期せずリダイレクトされる

セッションがタイムアウトした可能性があります。再度ログインしてください。頻繁に発生する場合は、サーバーの設定でセッションの有効期間を確認してください。

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ダッシュボードに他のユーザーのデータが表示されない（Web版）

**管理者**のみ、「**ユーザー**」フィルターで全ユーザーのデータを閲覧できます。通常のユーザーは、仕様上、自身の活動データのみを表示できます。

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### プロンプトを編集したが、変更が失われた

プロンプトの編集を行う際は、「**実行に戻る**」をクリックする前に、必ず **保存** をクリックしてください。

<a id="quick-tips"></a>
## すぐに使えるヒント

- [**翻訳**](#translate)から始めて、セットアップが正しく機能することを確認してから、[**リライト**](#rewrite)や[**変換**](#transform)へ進んでください。
- 日常的な文章の改善には[**リライト**](#rewrite)を使用してください。
- 特定のタスクに対して繰り返し使用可能なワークフローが必要な場合は[**変換**](#transform)を使用してください。
- 使用量と料金を把握したい場合は[**ダッシュボード**](#dashboard)をご利用ください。
- 過去の処理内容や入出力の全文を確認するには[**履歴**](#history)をご利用ください。
- プロンプトライブラリを安全に保管したい場合や、他のユーザーと共有したい場合は、定期的にプロンプトをエクスポートしてください（[プロンプトの変換](#transform-prompts)を参照）。
