# 사용자 가이드

<br/>

<a id="introduction"></a>
## 소개

Transrewrt는 텍스트 작업을 다음 세 가지 주요 방법으로 도와줍니다:

- **번역(Translate)** - 텍스트를 한 언어에서 다른 언어로 변환합니다.
- **다시 작성(Rewrite)** - 더 명확하게, 더 짧게 또는 더 격식 있게 등 다른 스타일로 텍스트를 다시 묶습니다.
- **변환(Transform)** - 프롬프트라 불리는 사용자 지정 AI 지침을 사용해 텍스트를 처리합니다.

<br/>

이 문서는 앱을 설치하여 실행한 후 사용 방법을 설명합니다. 설치 절차는 기본 **[README](README.ko.md)** 파일을 참조하세요.

<br/>

> ℹ️ **참고**<br/>
> Transrewrt는 Windows 및 Linux용 데스크톱 앱과 자체 호스팅되는 웹 앱 형태로 제공됩니다. 이 문서는 앱의 일상 사용법에 중점을 둡니다. 버전에 따라 특정 기능이 달라지는 경우에는 명확히 표시합니다.

<a id="before-you-start"></a>

## 시작하기 전에

Transrewrt를 사용하려면 최소한 하나 이상의 AI 제공업체에 접근할 수 있어야 합니다. 지원하는 제공업체는 다음과 같습니다: [OpenRouter](https://openrouter.ai) (다양한 모델을 통합함), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras 및 로컬 모델용 [Ollama](https://ollama.com) 입니다.

시작하려면 유료 모델을 선택할 필요는 없습니다. OpenRouter API 키를 추가하는 즉시 앱에서 내장된 **무료** OpenRouter 옵션이 자동으로 활성화됩니다. 이를 통해 바로 번역, 문장 재작성, 텍스트 변환 작업을 시작할 수 있습니다. 또는 Cerebras, Google, Groq, Mistral AI에서 무료 API 키를 직접 발급받을 수도 있습니다.

간단히 설명하면 다음과 같습니다.

- **모델**(model)이란 작업을 수행하는 AI 엔진입니다. 모델은 **제공업체 접두사**(예: `openrouter/…`, `openai/…`, `ollama/…`) 와 함께 표시됩니다.
- **API 키**(또는 Ollama의 경우 **기본 URL**)는 앱이 해당 제공업체와 연결되는 수단입니다.

**데스크톱 앱**을 사용하는 경우, 사용하는 각 제공업체마다 [**설정** > **API 구성**](#api-config) 에서 키를 추가해야 합니다. OpenRouter만 사용하는 경우 아래의 [API 키 발급 방법](#how-to-get-an-api-key-desktop-app)을 참조하세요. API 키를 사용하지 않으려면 [ollama.com](https://ollama.com) 에서 Ollama를 설치한 후 `translategemma:4b` 와 같은 로컬 모델을 사용할 수 있습니다.

**웹 버전**을 사용하는 경우에는 서버 관리자가 환경 변수를 통해 제공업체를 설정하므로, 애플리케이션 내에서 직접 API 키를 입력할 수 없습니다.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### 무료 OpenRouter API 키 발급 방법 (데스크톱 앱)

데스크톱 앱을 사용하는 경우 다음 단계를 따르세요:

1. 웹 브라우저에서 [OpenRouter](https://openrouter.ai) 로 이동하세요.
2. 계정을 만들거나 로그인하세요.
3. [Keys](https://openrouter.ai/keys) 페이지를 연다.
4. 새 API 키를 생성하는 버튼을 클릭하세요.
5. 추후에 쉽게 식별할 수 있도록 키에 이름을 붙이세요.
6. 새로 생성된 API 키를 복사하세요.
7. Transrewrt로 돌아가서 **설정** > **API 구성**을 열세요.
8. 복사한 키를 **OpenRouter API 키** 항목에 붙여넣으세요. (**설정** > **API 구성** 위치)
9. **OpenRouter 키 테스트** 버튼을 클릭하여 정상 작동하는지 확인하세요.

<a id="getting-started"></a>
## 시작하기

Transrewrt를 처음 사용하시는 경우, 아래의 순서대로 진행하세요:

1. 앱을 엽니다.
2. 필요시 좌측 상단의 지구본 아이콘을 클릭하여 **인터페이스 언어**를 선택합니다.
3. **데스크톱 앱**을 사용 중이라면, [**설정** > **API 구성**](#api-config) 을 열고 하나 이상의 제공업체(예: OpenRouter)에 대한 API 키를 추가한 후 **테스트**를 클릭하여 정상 동작을 확인합니다.
4. [**설정** > **모델**](#models) 로 이동하여 하나 이상의 모델을 **선택된 모델** 목록에 추가합니다.
5. [**설정** > **언어**](#languages) 로 이동하여 자주 사용하는 언어들이 맨 위에 표시되도록 **상위 언어**를 설정할 수 있습니다.
6. **번역** 탭으로 이동하여 간단한 번역을 실행하여 모든 설정이 제대로 작동하는지 확인합니다.
7. 정상 동작을 확인한 후 **재작성** 기능을 시도하고, 그 다음 **변환** 기능을 시험해 봅니다.

이 순서는 중요합니다. 이는 앱에 작동 가능한 API 연결이나 선택된 모델이 없음에도 불구하고 작업을 시도함으로써 발생하는 가장 흔한 첫 사용 오류를 예방합니다.

### 도구 모음

도구 모음은 앱 내 어디에 있는지에 따라 약간씩 달라집니다.

<a id="input-and-output-panels"></a>
### 입력 및 출력 패널

대부분의 작업 공간은 왼쪽에 있는 **입력**(Input) 패널과 오른쪽에 있는 **출력**(Output) 패널을 사용합니다.

각 패널에는 다음 정보도 표시됩니다:

| **입력**(Input)                                                              | **출력**(Output)                                                                                                                |
|-------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| - 문자 수 <br/>- 단어 수 <br/>- 문단 수                                 | - 작업 소요 시간<br/>- **TPS**(초당 토큰 수)<br/>- 문자, 단어 및 문단 수<br/>- 사용된 모델 |


기술 용어가 궁금하다면 다음을 참고하세요:

- **토큰**(Token)은 작은 텍스트 조각을 말하며, 하나의 단어 일부 또는 짧은 단어라고 생각할 수 있습니다.
- **TPS**(Tokens Per Second)는 모델이 1초마다 처리하는 텍스트 조각의 개수를 의미합니다.

<br/>

또한 [**설정** > **일반 설정**](#general-settings)에서 `작업 시 비용 정보 표시` 옵션을 활성화하면 각 작업의 비용과 총 비용을 모니터링할 수 있습니다.

<a id="translate"></a>
## 번역 (Translate)

다른 언어로 텍스트를 변환하고 싶을 때 **번역**(Translate) 기능을 사용하세요.

![번역 작업 공간](../images/screenshots/ko/translate.png)

<br/>

<a id="translate-text"></a>
### 텍스트 번역하기

1. **번역**(Translate)을 엽니다.
2. **원본**(From)에서 언어를 선택합니다.
3. **대상**(To)에서 언어를 선택합니다.
4. 도구 모음에서 모델을 선택합니다.
5. **입력**(Input) 창에 텍스트를 입력하거나 붙여넣기합니다.
6. **번역**(Translate)을 클릭합니다.
7. **출력**(Output)에서 결과를 확인합니다.
8. 결과를 복사하고 싶다면 복사 버튼을 사용하세요.

<br/>

<a id="language-selection"></a>
### 언어 선택

- **원본**(From)은 특정 언어이거나 **언어 감지**(Detect Language)일 수 있습니다.
- **대상**(To)는 결과로 원하는 언어입니다.

선택한 **주요 언어**(Top languages)는 목록 상단에 표시됩니다. 이 언어는 [**설정** > **언어**](#languages)에서 설정할 수 있습니다.

<a id="transform"></a>

## 변환(트랜스폼)

사용자 정의 지침을 AI가 따르도록 만들고 싶을 때는 **변환**(Transform) 기능을 사용하세요.

![변환 작업 영역](../images/screenshots/ko/transform.png)

이 기능은 앱 내에서 가장 유연한 영역입니다. 다음과 같은 작업을 위해 사용할 수 있습니다.

- 메모 요약
- 초안 텍스트를 다듬어 이메일 완성
- 주요 내용 추출
- 텍스트를 특정 형식으로 변환
- 입력된 텍스트로 할 수 있는 기타 모든 맞춤형 작업

<br/>

<a id="run-an-existing-prompt"></a>
### 기존 프롬프트 실행하기

1. **변환**(Transform)을 엽니다.
2. 프롬프트 목록에서 원하는 프롬프트를 선택합니다.
3. **대상**(Target) 언어 상자가 나타나면 필요 시 언어를 선택합니다.
4. **입력**(Input) 영역에 텍스트를 입력하거나 붙여넣습니다.
5. **변환**(Transform)을 클릭합니다.
6. **출력**(Output)에서 결과를 확인합니다.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### 프롬프트가 아직 없는 경우

프롬프트 목록이 비어 있다면 **샘플 프롬프트 불러오기**를 클릭하세요. 내장된 예제들이 추가되어 바로 시작할 수 있습니다.

<br/>

> ℹ️ **참고**<br/>
> 샘플 프롬프트는 영어로 제공됩니다. 불러온 후 프롬프트를 편집하고 **프롬프트 번역하기**(Translate prompt) 기능을 사용하여 사용자의 언어로 번역할 수 있습니다.

<br/>

<a id="create-a-prompt-quickly"></a>
### 빠르게 프롬프트 만들기

프롬프트를 만드는 가장 빠른 방법은 다음과 같습니다.

1. **새 프롬프트**를 클릭합니다.
2. **프롬프트 생성**을 클릭합니다.
3. 프롬프트에 원하는 작업을 설명합니다.
4. 모델을 선택합니다.
5. 앱이 초안을 생성하도록 합니다.
6. 초안을 검토한 후 **저장**을 클릭합니다.

![프롬프트 생성](../images/screenshots/ko/transform-generate.png)

<a id="edit-a-prompt"></a>
### 프롬프트 편집하기

새로 만들거나 기존 프롬프트를 편집할 때 왼쪽에는 편집기, 오른쪽에는 테스트 영역이 나타납니다.

![변환 프롬프트 편집기](../images/screenshots/ko/transform-prompt-edit.png)

주요 필드는 다음과 같습니다.

- **프롬프트 이름**: 프롬프트 목록에 표시되는 이름.
- **프롬프트 지침(선택사항)**: 프롬프트 실행 시 사용자에게 보여지는 짧은 안내문.
- **모델 역할**(Model Role): '도움이 되는 조수입니다' 등과 같이 AI에 할당하는 일반적인 역할.
- **모델 지침**(Model Instructions, 한 줄에 하나씩): AI가 따라야 할 구체적인 규칙들.
- **출력 설명**: '요약', '다시 작성하기' 등의 출력 결과를 나타내는 짧은 단어.
- **온도**(Temperature, 0.0 → 1.0): 모델의 행동 방식. 아래 설명 참고.
- **대상 언어 질문하기**: 프롬프트 실행 시 대상 언어 선택 기능을 추가.

**온도**(Temperature)라는 기술적 용어가 처음이라면 이렇게 이해하세요:

- **낮은** 온도는 더 일정하고 예측 가능한 결과를 제공합니다.
- **높은** 온도는 더 다양한 결과와 창의성을 제공합니다.

또한 다음 기능들을 사용할 수 있습니다.

- **`프롬프트 생성`**: 간단한 설명에서 새 초안을 생성
- **`프롬프트 개선`**: 기존 프롬프트를 다듬기
- **`프롬프트 번역`**: 프롬프트 필드들을 번역하기

<br/>

> ⚠️ **경고**<br/>
> **`뒤로 가기`**(Back to Run)을 클릭하기 **전**에 반드시 **`저장`**(Save)을 클릭하세요. 저장하지 않고 이전 화면으로 돌아가면 변경 사항이 모두 사라집니다.

오른쪽의 테스트 패널을 사용하면 실제 업무에 프롬프트를 사용하기 전에 샘플 텍스트로 동작을 시험해 볼 수 있습니다.

> ℹ️ **참고**<br/>

<a id="general-settings"></a>
### 일반 설정

**일반 설정**을 사용하여 입력 동작, 작업 기록 저장 여부, 및 외형을 제어할 수 있습니다.

**동작**

- **ENTER 키 동작**: `Enter` 키가 작업 실행 역할을 할지, 줄 바꿈을 할지 선택합니다.
- **붙여넣기 시 자동 번역**: 텍스트를 붙여넣자마자 번역을 시작합니다.
- **결과 자동 클립보드 복사**: 성공한 결과를 자동으로 클립보드에 복사합니다.
- **실시간 번역 (입력 중)**: 타이핑하는 동안 실시간으로 번역합니다.
- **타임아웃 (ms)**: 실시간 번역을 위한 대기 시간을 설정합니다.

**기록**

- **실행 기록 유지**: 사이드바의 [**기록**](#history) 보기에서 각 번역, 재작성, 변환 작업의 **입력 및 출력 텍스트**를 저장할지를 제어합니다. 이 기능을 해제하면 확인을 요청하며, 확인 시 저장된 기록 텍스트는 데이터베이스에서 삭제됩니다.
- **기록 데이터 삭제**: **데이터 삭제**를 통해 보관 기간별(예: 몇 달 전 이전의 데이터 또는 **모든 데이터 (지우기)** )로 저장된 텍스트를 제거할 수 있습니다. 이는 **기록** 뷰를 위한 저장된 작업 텍스트에만 영향을 미치며, **비용** 또는 **사용량 집계**에는 영향을 주지 않습니다. **비용** 데이터를 삭제하거나 제한하려면 [**설정** > **비용 추적**](#cost-tracking)을 사용하세요.

**외형**

- **작업에 비용 정보 표시**: 운영 비용(가능한 경우) 및 번역, 재작성, 변환 출력 패널의 총비용 표시 여부를 제어합니다.
- **비용 소수점 자릿수**: 비용 표시 시 소수점 자릿수를 조정합니다.
- **웹 전용**: **앱 주위 여백 표시**는 인터페이스 주위에 여유 공간을 추가합니다.
- **글꼴 패밀리**: 텍스트 패널의 글꼴을 변경합니다.
- **크기**: 폰트 크기를 조정합니다.

- **제공자**(Provider) 칩: 목록을 특정 엔진(OpenRouter, OpenAI, Ollama 등)으로 좁힐 수 있습니다
- **무료 전용**: 무료 모델만 표시합니다
- **새로 고침**: 목록을 다시 로드합니다
- 제공자별로 정렬할 때 사용하는 **모두 확장**, **모두 축소**

모델 ID는 제공자 접두사가 포함됩니다(예: `openrouter/…` 대 `openai/…`). **OpenAI (OpenRouter)** 또는 **OpenAI (직접)** 등과 같은 배지들은 트래픽이 어떻게 라우팅되는지를 알려줍니다.

> ℹ️ **참고**<br/>
> **OpenRouter Body Builder**(`openrouter/bodybuilder`)는 일반 채팅 모델이 아니라 라우터 모델입니다. 응답은 JSON 형식으로 OpenRouter API 요청 본문(예: `model`과 `messages`를 포함한 `requests` 배열)을 설명합니다. 이 모델을 **번역**, **재작성** 또는 **변형** 작업에 사용하는 경우 출력 패널에 최종 텍스트가 아닌 해당 JSON이 표시됩니다. 이러한 작업에서는 일반 텍스트 모델을 선택하세요. 자세한 내용은 OpenRouter의 [Body Builder 모델 페이지](https://openrouter.ai/openrouter/bodybuilder)를 참조하세요.

작업:

- 모델을 추가하려면 **추가** 버튼이나 목록에서 해당 항목의 아무곳이나 클릭하세요.
- 모델을 제거하려면 **선택한 모델** 목록에서 옆의 **X** 버튼을 클릭하거나 사용 가능한 모델에서 항목의 **선택됨**을 클릭하세요.
- 목록을 전체 삭제하려면 **모두 선택 해제**를 클릭하세요. 필수인 무료 모델은 목록에 그대로 남아 있습니다.

<br/>

> ℹ️ **참고**<br/>
> OpenRouter에 즉시 크레딧을 추가하고 싶지 않다면, 먼저 **무료 전용**을 활성화하고 무료 모델을 선택하세요(신용카드 없이도 가능). 또는 API 키 없이 로컬에서 모델을 실행하기 위해 Ollama를 사용할 수도 있습니다.

<a id="cost-tracking"></a>
### 비용 추적

**설정** > **비용 추적**에서 비용 정보를 관리하세요.

- **총 비용**: 누적 총비용을 표시합니다.
- **복사** 클립보드에 총비용을 복사합니다.
- **비용 재설정** 저장된 총비용을 0으로 초기화합니다.
- **API 키 사용량과 동기화** OpenRouter 계정에 보고된 사용량과 일치하도록 총비용을 설정합니다(OpenRouter 전용).
- **API 키 사용량** 사용 가능할 경우 OpenRouter의 사용량 세부 정보를 표시합니다.
- **비용 데이터 삭제**: 모든 데이터를 제거하거나 선택한 날짜보다 오래된 항목만 삭제합니다.

**비용 추적**: OpenRouter 모델을 사용할 경우, 앱은 OpenRouter가 제공하는 비용 정보를 기반으로 실제 사용량과 지출을 표시합니다. 그 외의 다른 제공자들에 대해서는 OpenRouter에서 공개한 가격 정보를 기반으로 비용을 추정하며, 가격 정보가 없는 경우 추정 비용은 0일 수 있습니다.

<br/>

> ℹ️ **참고**<br/>
> **모든 비용은 참고용으로만 제공되며 공식 청구서가 아닙니다.**

<br/>

> ⚠️ **경고**<br/>
> 삭제된 데이터는 복구할 수 없습니다. 삭제 전에 반드시 데이터를 백업하거나 [**기록**](#history) 또는 [**대시보드** > **모든 호출**](#dashboard-tabs)을 통해 내보내세요. 그렇지 않으면 데이터가 영구적으로 삭제됩니다. 각 API 호출 기록과 관련된 모든 입력/출력 기록도 함께 삭제됩니다.

<a id="api-config"></a>
### API 설정

지원되는 제공자: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras 및 **Ollama**(기본 URL을 통한 로컬 모델)입니다. 사용하는 제공자만 설정하면 됩니다.

**웹 애플리케이션: 관리자 전용**

API 키는 시스템 또는 Docker 환경 변수를 통해 설정됩니다. 웹 UI에 입력하지 않습니다. 이 페이지에서는 어떤 제공자에게 키가 설정되어 있는지 보여주며, 각각의 **`테스트`** 버튼을 클릭해 연결 테스트를 할 수 있습니다.

<br/>

> ℹ️ **참고**<br/>
> API 키를 변경하려면 시스템 또는 Docker 설정의 환경 변수를 업데이트하고 서버 또는 컨테이너를 다시 시작하세요.

<br/>

**데스크톱 애플리케이션**

사용하는 각 제공자별로 API 키를 저장하려면 **API 설정**을 사용하세요. Ollama의 경우 API 키 대신 **기본 URL**을 입력하세요.

<br/>

> 💡 **팁** <br/>
> API 키를 사용하고 싶지 않거나 과금이 부담된다면, 무료로 [Ollama 다운로드](https://ollama.com)하여 기기에 로컬로 모델(예: `translategemma:4b`)을 실행할 수 있습니다. 혹은 신용카드 없이 무료 계정을 생성하여 OpenRouter의 무료 모델을 사용하거나, Cerebras, Google, Groq 또는 Mistral AI에서 무료 API 키를 발급받을 수 있습니다.

<br/>

- 필요한 제공자만 추가하세요. **설정** > **모델**에서 각 모델 ID는 제공자 이름으로 시작됩니다(예: `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

API 키를 추가하려면 텍스트 필드에 값을 입력하고 **`저장`** 을 클릭하세요. 기존 키를 교체하려면 **`수정`** 을 클릭하세요. 키가 제대로 작동하는지 확인하려면 **`테스트`** 를 클릭하세요. Ollama의 기본 URL의 경우 항상 **`테스트`** 를 클릭하여 연결 상태를 확인하세요.

<br/>

> ℹ️ **참고**<br/>
> 현재 저장된 API 키 값을 확인할 수 없습니다. **`수정`** 버튼을 통해서만 키를 교체할 수 있습니다.  
> API 키는 설정에 암호화되어 저장됩니다.

<a id="common-issues"></a>
## 자주 발생하는 문제

기대한 대로 동작하지 않을 경우, 다음 항목을 먼저 확인하세요.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### 앱이 텍스트를 번역, 재작성 또는 변환하지 않음

다음을 확인하세요:

- 도구 모음에서 모델을 선택했는지
- [**설정** > **모델**](#models)에 최소 하나 이상의 모델이 나열되어 있는지
- API 설정이 정상적으로 작동하는지

데스크톱 앱을 사용하는 경우:

1. [**설정** > **API 설정**](#api-config)을 엽니다.
2. 최소 하나 이상의 API 키가 저장되었는지 확인합니다.
3. 제공자 옆의 **테스트**를 클릭하여 키가 정상작동하는지 확인합니다.

<br/>

<a id="the-model-list-is-empty"></a>
### 모델 목록이 비어 있음

[**설정** > **모델**](#models)을 열고 **새로 고침**을 클릭하세요.

필요할 경우:

- 모델을 검색하세요
- **무료 전용**을 켭니다
- 하나 이상의 모델을 **선택한 모델**에 추가하세요

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### 결과가 지나치게 느리거나 비쌈

다음 중 하나 이상을 시도해 보세요:

- 다른 모델을 선택하세요
- 입력을 더 짧게 사용하세요
- [**설정** > **일반 설정**](#general-settings)에서 **실시간 번역(입력 중)** 을 끄세요
- 간단한 작업에는 무료 모델을 사용하세요 ([모델](#models) 참조)

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### 인터페이스 언어가 잘못됨

[도구 모음](#toolbar)에 있는 지구본 아이콘을 클릭하고 원하는 **인터페이스 언어**를 선택하세요.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### 텍스트가 너무 작거나 읽기 어려움

[**설정** > **일반 설정**](#general-settings)을 열고 다음을 변경하세요:

- **글꼴**
- **크기**

<br/>

<a id="dashboard-charts-are-empty"></a>
### 대시보드 차트가 비어 있음

다음과 같은 경우 정상입니다:

- **무료 모델**만 사용할 경우 (비용 차트는 비어 있음)
- 선택된 **시간 필터**가 호출이 이루어진 기간을 포함하지 않을 경우 — 확인하려면 **전체**를 선택해 보세요.

**전체**를 선택한 후에도 차트가 비어 있다면, [**기록**](#history) 또는 **모든 호출** 탭에 호출이 표시되는지 확인하세요.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### 비용이 "사용 불가능"으로 표시되거나 잘못된 것처럼 보임

**OpenRouter**를 통해 모델을 사용할 경우, 앱은 OpenRouter에서 보고한 실제 지출을 표시합니다.

**다른 제공자**(OpenAI 직접, Anthropic 직접 등)의 경우 비용은 OpenRouter에서 공개한 가격 정보를 기반으로 추정됩니다. 모델에 일치하는 가격 정보가 없으면 비용은 **사용 불가능**으로 표시되며, 누적 비용에 포함되지 않습니다.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### 총 비용이 제공자 청구서와 일치하지 않음

앱에 표시된 모든 비용 정보는 **참조용 추정치**이며, 공식 청구서가 아닙니다.

총 비용이 실제 OpenRouter 지출액과 더 근접하도록 하려면 [**설정** > **비용 추적**](#cost-tracking)을 열고 **API 키 사용량과 동기화**를 클릭하세요.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### 사이드바에 기록 페이지가 없음

**실행 기록 유지** 설정이 꺼져 있을 수 있습니다. [**설정** > **일반 설정**](#general-settings)을 열고 이 옵션을 활성화하세요. 이 설정을 켜도 이전에 삭제된 기록 데이터는 복원되지 않음을 유의하세요.

<br/>

<a id="web-app-session-expired"></a>
### 웹 앱: 로그인 페이지로 예기치 않게 리디렉션됨

세션이 만료되었을 수 있습니다. 다시 로그인하세요. 자주 발생한다면 서버 설정에서 세션 수명 관련 설정을 확인하세요.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### 대시보드에 다른 사용자의 데이터가 표시되지 않음 (웹)

**관리자**만 **사용자 필터**를 통해 모든 사용자의 데이터를 볼 수 있습니다. 일반 사용자는 의도적으로 본인의 활동만 볼 수 있습니다.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### 프롬프트를 수정했으나 편집 내용이 사라짐

프롬프트를 편집할 때는 항상 **뒤로 실행**을 클릭하기 전에 **저장**을 클릭해야 합니다.

## 빠른 팁
