# Transrewrt 사용자 가이드

<br />

<a id="introduction"></a>
## 소개

Transrewrt는 텍스트 작업을 세 가지 주요 방식으로 지원합니다:

- **번역** - 한 언어에서 다른 언어로 텍스트를 변환합니다.
- **재작성** - 더 명확하고 짧거나 공식적인 스타일처럼 다른 스타일로 텍스트를 재구성합니다.
- **변환** - 프롬프트라고 하는 사용자 정의 AI 지침을 사용하여 텍스트를 처리합니다.

<br />

이 가이드는 앱이 설치되어 실행된 후 사용 방법을 설명합니다. 설치 단계는 주요 [README](../README.md) 파일을 참조하세요.

<br />

> ℹ️ **참고**<br/>
> Transrewrt는 Windows 및 Linux용 데스크톱 앱과 자체 호스팅 웹 앱으로 제공됩니다. 이 가이드는 앱의 일상적인 사용에 중점을 둡니다. 특정 버전에만 적용되는 내용은 명시적으로 표시됩니다.

<a id="before-you-start"></a>

## 시작하기 전에

Transrewrt를 사용하려면 OpenRouter를 통해 AI 서비스에 접근할 수 있어야 합니다.

시작하기 전에 유료 모델을 선택할 필요는 없습니다. 이 앱은 항상 내장된 **무료** 모델을 포함하고 있으므로 일반적인 사용에는 번역, 재작성, 변형을 시작하기에 충분합니다.

간단히 말해:

- **모델**은 작업을 수행하는 AI 엔진입니다.
- **API 키**는 해당 서비스에 대한 개인 액세스 자격 증명입니다.

**데스크톱 앱**을 사용하는 경우 API 키가 필요합니다. 자세한 단계는 아래의 [API 키를 얻는 방법(데스크톱 앱)](#how-to-get-an-api-key-desktop-app)을 참조하세요. 간단히 말해: [OpenRouter](https://openrouter.ai)에서 계정을 만들고, [Keys](https://openrouter.ai/keys) 페이지를 열어 새 키를 만든 후 Transrewrt의 [**설정** > **API 구성**](#api-config)에 붙여넣으세요.

**웹 버전**을 사용하는 경우 서버 소유자가 일반적으로 이를 설정해 주므로 직접 API 키를 입력할 필요는 없습니다.

<br />

<a id="how-to-get-an-api-key-desktop-app"></a>
### API 키를 얻는 방법 (데스크톱 앱)

데스크톱 앱을 사용하는 경우 다음 단계를 따르세요:

1. 웹 브라우저에서 [OpenRouter](https://openrouter.ai)로 이동합니다.
2. 계정을 만들거나 로그인합니다.
3. [Keys](https://openrouter.ai/keys) 페이지를 엽니다.
4. 새 API 키를 만드는 버튼을 클릭합니다.
5. 나중에 인식할 수 있도록 키에 이름을 지정합니다.
6. 새 API 키를 복사합니다.
7. Transrewrt로 돌아가 **설정** > **API 구성**을 엽니다.
8. **OpenRouter API 키**에 키를 붙여넣습니다.
9. **API 구성 테스트**를 클릭하여 작동하는지 확인합니다.

> ℹ️ **참고**<br/>
> OpenRouter의 무료 라우트나 다른 사용 가능한 무료 모델로 시작할 수 있습니다. 많은 경우 유료 모델을 선택하지 않고도 Transrewrt 사용을 시작하기에 충분합니다.

<br /><br />

<a id="getting-started"></a>
## 시작하기

Transrewrt를 처음 사용하는 경우 다음 순서를 따르세요:

1. 앱을 엽니다.
2. 필요한 경우 지구 아이콘에서 **인터페이스 언어**를 선택합니다.
3. **데스크톱 앱**을 사용 중인 경우 [**설정** > **API 구성**](#api-config)을 열어 OpenRouter API 키를 붙여넣고 **API 구성 테스트**를 클릭합니다.
4. [**설정** > **모델**](#models)을 열고 **선택된 모델**에 하나 이상의 모델을 추가합니다.
5. [**설정** > **언어**](#languages)를 열고 자주 사용하는 언어를 상위에 표시하려면 **주요 언어**를 선택합니다.
6. **번역**으로 이동하여 간단한 번역을 실행하여 모든 것이 작동하는지 확인합니다.
7. 작동하면 **재작성**을 시도한 다음 **변형**을 시도합니다.

이 순서가 중요합니다. 앱에 작동하는 API 연결이나 선택된 모델이 없이 작업을 시도하는 가장 일반적인 초기 사용 문제를 방지합니다.

<a id="input-and-output-panels"></a>

### 입력 및 출력 패널

대부분의 작업 공간은 왼쪽 **입력** 패널과 오른쪽 **출력** 패널을 사용합니다.

**입력** 패널은 다음을 표시합니다:

- 문자 수
- 단어 수
- 단락 수

**출력** 패널은 다음을 표시할 수 있습니다:

- 작업에 소요된 시간
- 해당 작업의 비용
- 누적 총 비용
- **TPS**(초당 토큰 수), 이는 간단한 속도 측정값입니다.
- 문자, 단어 및 단락 수
- 사용된 모델

기술 용어에 대해 궁금하시다면:

- **Token**은 작은 텍스트 조각을 의미합니다. 단어의 일부나 짧은 단어로 생각할 수 있습니다.
- **TPS**는 모델이 초당 처리한 해당 텍스트 조각의 수를 의미합니다.

<a id="translate"></a>
## 번역

텍스트를 한 언어에서 다른 언어로 변환하려면 **번역**을 사용하세요.

![번역 작업 공간](../images/screenshots/ko/translate.png)

<br />

<a id="translate-text"></a>
### 텍스트 번역하기

1. **번역**을 엽니다.
2. **원본**에서 언어를 선택합니다.
3. **대상**에서 언어를 선택합니다.
4. 도구 모음에서 모델을 선택합니다.
5. **입력**에 텍스트를 입력하거나 붙여넣습니다.
6. **번역**을 클릭합니다.
7. **출력**에서 결과를 읽습니다.
8. 결과를 복사하려면 복사 버튼을 사용하세요.

<br />

<a id="language-selection"></a>
### 언어 선택

- **원본**은 특정 언어이거나 **언어 감지**일 수 있습니다.
- **대상**은 결과를 원하는 언어입니다.

선택한 **주요 언어**가 목록 상단에 표시됩니다. [**설정** > **언어**](#languages)에서 이를 설정할 수 있습니다.

<br />

<a id="helpful-translation-settings"></a>
### 유용한 번역 설정

[**설정** > **일반 설정**](#general-settings)에서 번역 동작을 변경할 수 있습니다:

- **붙여넣을 때 자동 번역**은 텍스트를 붙여넣는 즉시 번역을 실행합니다.
- **결과를 클립보드에 자동 복사**는 성공적인 실행 후 결과를 자동으로 복사합니다.
- **실시간 번역(입력 중)** 은 입력하는 동안 번역을 실행합니다.
- **시간 초과(ms)**는 실시간 번역을 실행하기 전에 앱이 대기하는 시간을 제어합니다.

<br />

<a id="keyboard-shortcuts"></a>
### 키보드 단축키

[**설정** > **일반 설정**](#general-settings)에서 **Enter 동작**은 Enter 키를 누를 때 발생하는 일을 제어합니다:

- **Enter**는 작업을 실행하고 **Shift+Enter**는 새 줄을 추가할 수 있습니다.
- 또는 앱이 반대로 할 수 있습니다.

현재 단축키는 **번역** 버튼에도 표시됩니다.

<a id="rewrite"></a>
## 재작성

주요 의미를 변경하지 않고 표현을 개선하려면 **재작성**을 사용하세요.

![재작성 작업 공간](../images/screenshots/ko/rewrite.png)

이것은 다음에 유용합니다:

- 철법과 문법 수정
- 텍스트를 더 명확하게 만들기
- 텍스트를 더 공식적 또는 비공식적으로 만들기
- 텍스트를 줄이거나 확장하기
- 텍스트를 더 기술적으로 들리게 만들기

<br />

<a id="rewrite-text"></a>
### 텍스트 재작성하기

1. **재작성**을 엽니다.
2. **모드**를 선택합니다.
3. 도구 모음에서 모델을 선택합니다.
4. **입력**에 텍스트를 입력하거나 붙여넣습니다.
5. **재작성**을 클릭합니다.
6. **출력**에서 결과를 검토합니다.

[**번역**](#keyboard-shortcuts)에 설명된 동일한 Enter 키 동작이 여기에도 적용됩니다.

<br /><br />

<a id="transform"></a>
## 변환

AI가 사용자 정의 지침 세트를 따르게 하려면 **변환**을 사용하세요.

![변환 작업 공간](../images/screenshots/ko/transform.png)

이것은 앱에서 가장 유연한 영역입니다. 다음과 같은 작업에 사용할 수 있습니다:

- 노트 요약하기
- 거친 텍스트를 다듬어진 이메일로 변환하기
- 핵심 포인트 추출하기
- 텍스트를 특정 형식으로 변환하기

<br />

<a id="run-an-existing-prompt"></a>
### 기존 프롬프트 실행하기

1. **변환**을 엽니다.
2. 프롬프트 목록에서 프롬프트를 선택합니다.
3. **대상** 언어 상자가 나타나면 원하는 언어를 선택합니다.
4. **입력**에 텍스트를 입력하거나 붙여넣습니다.
5. **변환**을 클릭합니다.
6. **출력**에서 결과를 읽습니다.

<br />

<a id="if-you-have-no-prompts-yet"></a>
### 아직 프롬프트가 없는 경우

프롬프트 목록이 비어 있으면 **샘플 프롬프트 로드**를 클릭하세요. 이렇게 하면 내장된 예제가 추가되어 빠르게 시작할 수 있습니다.

> ℹ️ **참고**<br/>
> 샘플 프롬프트는 영어로 제공됩니다. 로드한 후 프롬프트를 편집하고, 프롬프트 텍스트를 다른 언어로 조정하려면 **프롬프트 번역**을 사용할 수 있습니다.

<br />

<a id="create-a-prompt-quickly"></a>
## 빠르게 프롬프트 만들기

### 프롬프트 빠르게 만들기

가장 빠른 방법은 다음과 같습니다:

1. **새 프롬프트**를 클릭하세요.
2. **프롬프트 생성**을 클릭하세요.
3. 프롬프트가 수행할 작업을 설명하세요.
4. 모델을 선택하세요.
5. 앱이 초안을 생성하도록 하세요.
6. 초안을 검토하고 **저장**을 클릭하세요.

![프롬프트 생성](../images/screenshots/ko/transform-generate.png)

<br />

### 프롬프트 편집

프롬프트를 만들거나 편집할 때 편집기가 왼쪽에, 테스트 영역이 오른쪽에 나타납니다.

![변환 프롬프트 편집기](../images/screenshots/ko/transform-prompt-edit.png)

주요 필드는 다음과 같습니다:

- **프롬프트 이름**: 프롬프트 목록에 표시되는 이름입니다.
- **프롬프트 지시사항 (선택)**: 프롬프트 실행 시 사용자에게 표시되는 짧은 힌트입니다.
- **모델 역할**: AI에 부여되는 전체 역할입니다(예: '당신은 도움이 되는 조수입니다.').
- **모델 지시사항 (한 줄에 하나씩)**: AI가 따르길 원하는 구체적인 규칙입니다.
- **출력 설명**: 결과를 설명하는 짧은 단어입니다(예: '요약' 또는 '재작성').
- **온도 (0.0 → 1.0)**: 창의성 슬라이더입니다.
- **대상 언어 요청**: 프롬프트 실행 시 대상 언어 선택기를 추가합니다.

기술 용어 **온도**가 생소하다면 다음과 같이 생각하세요:

- **낮은** 온도는 더 안정적이고 예측 가능한 결과를 제공합니다.
- **높은** 온도는 더 다양한 결과와 창의성을 제공합니다.

또한 다음을 사용할 수 있습니다:

- **`Generate prompt`** 간단한 설명에서 새 초안을 생성합니다
- **`Improve prompt`** 기존 프롬프트를 개선합니다
- **`Translate prompt`** 프롬프트 필드를 번역합니다

> ⚠️ **경고**<br/>
> **`Save`**를 클릭한 후 **`Back to Run`**을 클릭하세요. 저장하지 않고 돌아가면 변경 사항이 손실됩니다.

<br />

<a id="test-a-prompt-before-using-it"></a>
### 프롬프트 사용 전 테스트

오른쪽의 테스트 패널을 통해 일상 작업에서 사용하기 전에 샘플 텍스트로 프롬프트를 시험해볼 수 있습니다.

다음과 같은 경우 유용합니다:

- 새 프롬프트를 구축 중인 경우
- 프롬프트의 두 버전을 비교하는 경우
- 어조, 길이 또는 출력 형식을 확인하려는 경우

## 설정

사이드바에서 **설정**을 열어 앱의 동작 방식을 사용자 정의할 수 있습니다.

사용 가능한 탭은 달라질 수 있습니다:

<a id="general-settings"></a>

### 일반 설정

**일반 설정**을 사용하여 입력 동작과 모양을 제어합니다.

**동작**

- **ENTER 동작**은 Enter 키가 작업을 실행할지 새 줄을 삽입할지 선택합니다.
- **붙여넣기 시 자동 번역**은 텍스트를 붙여넣는 즉시 번역을 시작합니다.
- **결과를 클립보드에 자동 복사**는 성공한 결과를 자동으로 복사합니다.
- **실시간 번역(입력 중)**은 입력하는 동안 번역합니다.
- **시간 제한(ms)**는 실시간 번역 대기 시간을 설정합니다.

**모양**

- **비용 소수점 자릿수**는 비용 소수점 표시 방법을 변경합니다.
- **글꼴**은 텍스트 패널의 글꼴을 변경합니다.
- **크기**는 글꼴 크기를 변경합니다.
- **웹 전용:** **앱 주위에 여백 표시**는 인터페이스 주변에 추가 공간을 추가합니다.

<br />

<a id="models"></a>
### 모델

**설정** > **모델**을 사용하여 도구 모음에 표시할 모델을 선택합니다.

![설정 모델 탭](../images/screenshots/ko/settings-models.png)

페이지에는 두 개의 목록이 있습니다:

- 왼쪽의 **사용 가능한 모델**
- 오른쪽의 **선택된 모델**

유용한 컨트롤은 다음과 같습니다:

- **모델 검색...**으로 이름으로 모델을 찾습니다.
- **무료만**을 사용하여 무료 모델만 표시합니다.
- **새로 고침**으로 목록을 다시 로드합니다.
- **모두 확장** 및 **모두 축소**는 공급자별로 정렬할 때 사용합니다.

모델을 추가하려면 **추가**를 클릭합니다.

모델을 제거하려면 **선택된 모델** 옆에 있는 **X**를 클릭합니다.

목록을 지우려면 **모두 선택 해제**를 클릭합니다. 필요한 무료 모델은 목록에 유지됩니다.

> ℹ️ **참고**<br/>
> 즉시 OpenRouter에 크레딧을 추가하지 않으려면 먼저 **무료만**을 활성화하고 무료 모델을 선택하세요.

<a id="api-config"></a>
### API 구성

**데스크톱 전용**

**API 구성**을 사용하여 데스크톱 앱을 OpenRouter 또는 Transrewrt 프록시에 연결합니다.

- **OpenRouter API 키**는 키를 붙여넣는 곳입니다.
- **API URL**은 서비스 주소입니다. 다른 주소가 제공되지 않은 경우 기본값으로 두세요.
- **Transrewrt 프록시 사용**은 OpenRouter로 직접 요청하는 대신 프록시 서비스를 통해 요청을 라우팅합니다.
- **키 시드**는 프록시 옵션이 활성화된 경우 나타납니다.
- **API 구성 테스트**는 현재 설정이 작동하는지 확인합니다.

API 키를 얻는 방법에 대한 자세한 단계는 위의 [**API 키를 얻는 방법**](#how-to-get-an-api-key-desktop-app)을 참조하세요.

> ℹ️ **참고**<br/>
> **API URL**, **Transrewrt 프록시 사용**, 또는 **키 시드**가 무엇을 의미하는지 확실하지 않으면 변경하지 말고 기본 OpenRouter 설정을 사용하세요. 프록시에 대한 자세한 정보는 [Transrewrt 프록시 저장소](https://github.com/wsj-br/transrewrt-proxy)에서 확인할 수 있습니다.

<a id="common-issues"></a>
## 일반적인 문제

예상대로 작동하지 않으면 먼저 다음 사항을 확인하세요.

<br />

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### 앱이 텍스트를 번역, 재 작성 또는 변환하지 않음

다음을 확인하세요:

- 툴바에서 모델을 선택했습니다
- [**설정** > **모델**](#models)에 하나 이상의 모델이 나열되어 있습니다
- API 설정이 작동하고 있습니다

데스크톱 앱을 사용하는 경우:

1. [**설정** > **API 구성**](#api-config)을 엽니다.
2. API 키가 저장되어 있는지 확인합니다.
3. **API 구성 테스트**를 클릭합니다.

<br />

<a id="the-model-list-is-empty"></a>
### 모델 목록이 비어 있음

[**설정** > **모델**](#models)를 열고 **새로 고침**을 클릭합니다.

필요한 경우:

- 모델 검색
- **무료만** 켜기
- 하나 이상의 모델을 **선택한 모델**에 추가

<br />

<a id="the-result-is-too-slow-or-too-expensive"></a>
### 결과가 너무 느리거나 비용이 너무 많이 듦

다음 중 하나 이상을 시도해 보세요:

- 다른 모델 선택
- 더 짧은 입력 사용
- [**설정** > **일반 설정**](#general-settings)에서 **실시간 번역(입력 중)** 끄기
- 간단한 작업에는 무료 모델 사용 ([모델](#models) 참조)

<br />

<a id="the-interface-is-in-the-wrong-language"></a>
### 인터페이스 언어가 잘못됨

[toolbar](#toolbar)에 있는 지구 아이콘을 클릭하고 원하는 **인터페이스 언어**를 선택합니다.

<br />

<a id="the-text-is-too-small-or-hard-to-read"></a>
### 텍스트가 너무 작거나 읽기 어려움

[**설정** > **일반 설정**](#general-settings)을 열고 다음을 변경합니다:

- **글꼴**
- **크기**

<br />

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### 프롬프트를 편집하다가 편집 내용을 잃었음

프롬프트를 편집할 때는 **뒤로**를 클릭하기 전에 항상 **저장**을 클릭합니다.

<br /><br />

<a id="quick-tips"></a>
## 빠른 팁

- [**번역**](#translate)부터 시작하여 [**재 작성**](#rewrite) 또는 [**변환**](#transform)으로 넘어가기 전에 설정이 작동하는지 확인하세요.
- 일상적인 어휘 개선에는 [**재 작성**](#rewrite)을 사용하세요.
- 특정 작업에 반복 가능한 워크플로가 필요한 경우 [**변환**](#transform)을 사용하세요.
- 사용량과 비용을 확인하려면 [**대시보드**](#dashboard)를 사용하세요.
- 프롬프트 라이브러리를 안전하게 보관하려면 정기적으로 프롬프트를 내보내세요 ([프롬프트 변환](#transform-prompts) 참조).
