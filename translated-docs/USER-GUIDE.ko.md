# 사용자 가이드

<br/>

<a id="introduction"></a>
## 소개

Transrewrt는 텍스트를 다루는 데 도움이 되는 세 가지 주요 기능을 제공합니다:

- **번역** - 한 언어에서 다른 언어로 텍스트를 변환합니다.
- **재작성** - 더 명확하거나, 더 짧게, 또는 더 격식 있게 같은 내용을 다른 스타일로 다시 표현합니다.
- **변환** - 프롬프트라고 불리는 사용자 정의 AI 지시 사항을 사용하여 텍스트를 처리합니다.

<br/>

이 가이드는 앱을 설치하고 실행한 후 사용 방법을 설명합니다. 설치 절차는 주요 **[README](README.ko.md)** 문서를 참조하세요.

<br/>

> ℹ️ **참고**<br/>
> Transrewrt는 Windows 및 Linux용 데스크톱 앱과 자체 호스팅 웹 앱으로 제공됩니다. 이 가이드는 앱의 일상적인 사용에 중점을 둡니다. 특정 기능이 한 버전에만 해당하는 경우 명확하게 표시합니다.

<a id="before-you-start"></a>
## 시작하기 전에

Transrewrt를 사용하려면 최소한 하나 이상의 AI 제공업체에 접근할 수 있어야 합니다. 지원되는 제공업체는 다음과 같습니다: [OpenRouter](https://openrouter.ai) (다양한 모델을 통합), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, 그리고 로컬 모델을 위한 [Ollama](https://ollama.com).

시작하려면 유료 모델을 선택할 필요는 없습니다. OpenRouter API 키를 추가하는 즉시 앱은 내장된 **무료** OpenRouter 옵션을 자동으로 활성화합니다. 이를 통해 바로 텍스트 번역, 재작성 및 변환을 시작할 수 있습니다. 또는 Cerebras, Google, Groq, Mistral AI에서 무료 API 키를 발급받을 수도 있습니다.

간단히 설명하면:

- **모델**은 작업을 수행하는 AI 엔진입니다. 모델은 **제공업체 접두사**와 함께 표시됩니다 (예: `openrouter/…`, `openai/…`, `ollama/…`).
- **API 키**(또는 Ollama의 경우 **기본 URL**)는 앱이 해당 제공업체에 연결하는 방법입니다.

**데스크톱 앱**을 사용하는 경우, 사용하는 각 제공업체에 대해 [**설정** > **API 설정**](#api-config)에서 키를 추가하세요. OpenRouter만 사용하는 경우 아래의 [API 키를 얻는 방법](#how-to-get-an-api-key-desktop-app)을 참조하세요. API 키를 사용하고 싶지 않다면 [ollama.com](https://ollama.com)에서 Ollama를 설치하고 `translategemma:4b`와 같은 로컬 모델을 사용할 수 있습니다.

**웹 버전**을 사용하는 경우 서버 소유자가 환경 변수를 통해 제공업체를 설정하므로, 앱 내에서 직접 API 키를 입력할 수 없습니다.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### 무료 OpenRouter API 키를 얻는 방법 (데스크톱 앱)

데스크톱 앱을 사용하는 경우 다음 단계를 따르세요:

1. 웹 브라우저에서 [OpenRouter](https://openrouter.ai)로 이동하세요.
2. 계정을 생성하거나 로그인하세요.
3. [Keys](https://openrouter.ai/keys) 페이지를 엽니다.
4. 새 API 키를 생성하는 버튼을 클릭하세요.
5. 나중에 식별할 수 있도록 키에 이름을 지정하세요.
6. 새 API 키를 복사하세요.
7. Transrewrt로 돌아가 **설정** > **API 설정**을 엽니다.
8. **OpenRouter API 키**에 키를 붙여넣으세요 (**설정** > **API 설정** 내).
9. **Test OpenRouter key**를 클릭하여 작동하는지 확인하세요.

<br/><br/>

<a id="getting-started"></a>
## 시작하기

처음으로 Transrewrt를 사용하는 경우 다음 순서를 따르세요:

1. 앱을 엽니다.
2. 필요 시 지구 아이콘에서 **인터페이스 언어**를 선택하세요.
3. **데스크톱 앱**을 사용하는 경우 [**설정** > **API 설정**](#api-config)을 열고 최소한 하나 이상의 제공업체(예: OpenRouter)에 대한 API 키를 추가하고 **테스트**를 클릭하여 작동 여부를 확인하세요.
4. [**설정** > **모델**](#models)을 열고 하나 이상의 모델을 **선택된 모델**에 추가하세요.
5. [**설정** > **언어**](#languages)를 열고 자주 사용하는 언어를 상단에 표시하려면 **상위 언어**를 선택하세요.
6. **번역**으로 이동하여 간단한 번역을 실행하여 모든 것이 제대로 작동하는지 확인하세요.
7. 정상 작동하면 **재작성**을 시도한 후 **변환**을 시도하세요.

이 순서는 중요합니다. 가장 흔한 초기 사용 문제인, 앱에 작동하는 API 연결이나 선택된 모델이 없이 작업을 실행하려는 실수를 방지할 수 있습니다.

<a id="toolbar"></a>
### 툴바

툴바는 앱 내에서 현재 위치에 따라 약간씩 달라집니다.

- 왼쪽에는 현재 페이지 이름이 표시됩니다.
- 오른쪽에는 **모델 선택기**와 **인터페이스 언어** 조정 기능이 있습니다.

**모델 선택기**를 사용하면 현재 작업에 사용할 AI 엔진을 선택할 수 있습니다.

![Model selector](../images/screenshots/ko/model-selector.png)

일부 무료 모델은 항상 사용 가능한 것은 아닙니다. 가끔 오프라인 상태이거나 사용량 제한이 있을 수 있습니다. 이런 경우 앱이 자동으로 해당 모델을 사용 가능한 목록에서 제거합니다. 표시될 모델을 제어하려면 [**설정** > **모델**](#models)로 이동하여 모델 목록을 편집하세요.
또한 툴바에서 모델 이름 왼쪽의 제공업체 아이콘을 클릭하면 모델 설정을 바로 열 수 있습니다.

<br/>

**지구본 아이콘 + 언어 코드**는 메뉴 및 버튼과 같은 앱 인터페이스 언어를 변경합니다. 이 기능은 **번역** 기능에서 사용하는 번역 언어는 **변경하지 않습니다**.

![Interface language selector](../images/screenshots/ko/language-selector.png)

<a id="input-and-output-panels"></a>
### 입력 및 출력 패널

대부분의 작업 공간은 왼쪽에 있는 **입력** 패널과 오른쪽에 있는 **출력** 패널을 사용합니다.

각 패널은 다음도 함께 표시합니다.

| **입력**                                                          | **출력**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - 문자 수 <br/>- 단어 수 <br/>- 문단 수   <br/> | - 작업 소요 시간<br/>- **초당 토큰수(TPS)**<br/>- 문자, 단어, 문단 수<br/>- 사용된 모델 |

기술적인 용어가 궁금하다면:

- **토큰**은 작은 텍스트 조각을 의미합니다. 한 단어의 일부이거나 짧은 단어라고 생각할 수 있습니다.
- **TPS**는 모델이 초당 처리한 텍스트 조각의 수를 의미합니다.

<br/>

또한 각 작업의 비용(사용 가능한 경우)과 총 비용을 모니터링할 수 있습니다. [**설정** > **일반 설정**](#general-settings)에서 `작업에 비용 정보 표시` 옵션을 활성화하세요.

<a id="translate"></a>
## 번역

**번역** 기능은 텍스트를 한 언어에서 다른 언어로 변환할 때 사용합니다.

![Translate workspace](../images/screenshots/ko/translate.png)

<br/>

<a id="translate-text"></a>
### 텍스트 번역

1. **번역**을 엽니다.
2. **원본**에서 언어를 선택합니다.
3. **대상**에서 언어를 선택합니다.
4. 툴바에서 모델을 선택합니다.
5. **입력**란에 텍스트를 입력하거나 붙여넣습니다.
6. **번역**을 클릭합니다.
7. **출력**에서 결과를 확인합니다.
8. 결과를 복사하려면 복사 버튼을 사용하세요.

<br/>

<a id="language-selection"></a>
### 언어 선택

- **원본**은 특정 언어 또는 **언어 감지**일 수 있습니다.
- **대상**은 결과를 원하는 언어입니다.

선택한 **상위 언어**가 목록 상단에 표시됩니다. [**설정** > **언어**](#languages)에서 이 언어들을 설정할 수 있습니다.

<br/>

<a id="helpful-translation-settings"></a>
### 유용한 번역 설정

[**설정** > **일반 설정**](#general-settings)에서 번역 동작 방식을 변경할 수 있습니다:

- **붙여넣을 때 자동 번역**: 텍스트를 붙여넣는 즉시 번역을 실행합니다.
- **결과를 클립보드에 자동 복사**: 성공적으로 실행된 후 결과를 자동으로 클립보드에 복사합니다.
- **실시간 번역 (입력 중)**: 입력하는 동안 번역을 실행합니다.
- **시간 초과 (ms)**: 실시간 번역을 실행하기 전에 앱이 대기하는 시간을 조절합니다.
- **Enter**: `Enter` 키를 눌렀을 때 발생하는 동작을 제어합니다:

<a id="transform"></a>
## 변환

사용자 정의 지시 사항을 AI가 따르게 하려면 **변환**을 사용하세요.

![Transform workspace](../images/screenshots/ko/transform.png)

이 기능은 앱에서 가장 유연한 영역입니다. 다음과 같은 작업에 활용할 수 있습니다:

- 메모 요약
- 초안 텍스트를 다듬어 이메일로 작성
- 핵심 내용 추출
- 텍스트를 특정 형식으로 변환
- 입력 텍스트로 수행할 수 있는 기타 사용자 정의 작업

<br/>

<a id="run-an-existing-prompt"></a>
### 기존 프롬프트 실행

1. **변환**을 엽니다.
2. 프롬프트 목록에서 원하는 프롬프트를 선택합니다.
3. **대상** 언어 상자가 나타나면 원하는 언어를 선택합니다.
4. **입력**란에 텍스트를 입력하거나 붙여넣습니다.
5. **변환**을 클릭합니다.
6. **출력**에서 결과를 확인합니다.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### 프롬프트가 아직 없을 경우

프롬프트 목록이 비어 있으면, 변환 작업 영역에서 **샘플 프롬프트 불러오기**를 클릭하세요. 동일한 기능은 [**설정** > **변환 프롬프트**](#transform-prompts)의 내보내기/가져오기 행에서도 항상 사용할 수 있습니다. 두 방법 모두 기본 제공 예제를 추가하여 빠르게 시작할 수 있도록 도와줍니다.

<br/>

> ℹ️ **참고**<br/>
> 샘플 프롬프트는 영어로 제공됩니다. 불러온 후 프롬프트를 편집하고 **프롬프트 번역**을 사용하여 귀하의 언어로 번역할 수 있습니다.

<br/>

<a id="create-a-prompt-quickly"></a>
### 빠르게 프롬프트 생성하기

프롬프트를 만드는 가장 빠른 방법은 다음과 같습니다:

1. **새 프롬프트**를 클릭합니다.
2. **프롬프트 생성**을 클릭합니다.
3. 프롬프트가 수행해야 할 작업을 설명합니다.
4. 모델을 선택합니다.
5. 앱이 초안을 작성하도록 합니다.
6. 초안을 검토한 후 **저장**을 클릭합니다.

![Generate prompt](../images/screenshots/ko/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### 프롬프트 편집

프롬프트를 생성하거나 편집할 때, 왼쪽에는 편집기가 나타나고 오른쪽에는 테스트 영역이 나타납니다.

![Transform prompt editor](../images/screenshots/ko/transform-prompt-edit.png)

주요 필드는 다음과 같습니다:

- **프롬프트 이름**: 프롬프트 목록에 표시되는 이름입니다.
- **프롬프트 지시사항(옵션)**: 프롬프트 실행 시 사용자에게 표시되는 간단한 안내입니다.
- **모델 역할**: '도움이 되는 조수입니다.'와 같이 AI에게 할당된 전반적인 역할입니다.
- **모델 지시사항(한 줄에 하나씩)**: AI가 따라야 할 구체적인 규칙입니다.
- **출력 설명**: '요약' 또는 '재작성'과 같이 결과를 설명하는 짧은 단어입니다.
- **온도 (0.0 → 1.0)**: 모델의 동작 방식을 결정합니다. 아래 설명을 참조하세요.
- **대상 언어 요청**: 프롬프트 실행 시 대상 언어 선택기를 추가합니다.

기술 용어 **온도(Temperature)**가 처음이라면, 다음과 같이 생각해 보세요:

- **낮은** 온도는 더 안정적이고 예측 가능한 결과를 제공합니다.
- **높은** 온도는 더 다양한 창의성을 제공합니다.

또한 다음 기능을 사용할 수 있습니다:

- **`프롬프트 생성`**: 간단한 설명에서 새 초안을 생성합니다.
- **`프롬프트 개선`**: 기존 프롬프트를 다듬습니다.
- **`프롬프트 번역`**: 프롬프트 필드를 번역합니다.

<br/>

> ⚠️ **경고**<br/>
> **`뒤로 실행`**을 클릭하기 전에 반드시 **`저장`**을 클릭하세요. 저장하지 않고 돌아가면 변경 사항이 모두 사라집니다.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### 사용 전 프롬프트 테스트

오른쪽의 테스트 패널을 사용하면 일상 업무에 적용하기 전에 샘플 텍스트로 프롬프트를 시험해볼 수 있습니다.

다음과 같은 경우에 유용합니다:

- 새 프롬프트를 제작할 때
- 두 개의 프롬프트 버전을 비교할 때
- 어조, 길이 또는 출력 형식을 확인하고 싶을 때

<br/>

> ℹ️ **참고**<br/>
> 저장된 프롬프트는 [**설정** > **변환 프롬프트**](#transform-prompts)에서 내보내기 및 가져오기를 할 수 있습니다.

<a id="general-settings"></a>
### 일반 설정

**일반 설정**을 사용하여 입력 동작, 실행 세부 정보를 **기록**에 저장할지 여부, 그리고 외관을 제어할 수 있습니다.

**동작**

- **ENTER 키 동작**은 `Enter` 키를 누를 때 작업을 실행할지, 아니면 새 줄을 삽입할지를 선택합니다.
- **붙여넣을 때 자동 번역**은 텍스트를 붙여넣는 즉시 번역을 시작합니다.
- **결과를 클립보드에 자동 복사**는 성공한 결과를 자동으로 클립보드에 복사합니다.
- **실시간 번역 (입력 중)** 은 입력하는 동안 실시간으로 번역합니다.
- **시간 초과 (ms)** 는 실시간 번역을 위한 대기 시간을 설정합니다.

**기록**

- **실행 기록 보관**은 사이드바의 [**기록**](#history) 보기에서 **입력 및 출력 텍스트**를 각 번역, 재작성, 변환 작업마다 저장할지 제어합니다. 이 기능을 끄면 확인을 요청하며, 확인 시 저장된 기록 텍스트가 데이터베이스에서 제거됩니다.
- **기록 데이터 삭제**는 **데이터 삭제**를 사용하여 기간별(예: 몇 개월 이상된 항목) 또는 **모든 데이터 (지우기)** 를 제거할 수 있습니다. 이는 **기록** 보기용으로 저장된 실행 텍스트에만 영향을 주며, 비용 또는 사용량 총계는 **삭제하지 않습니다**. **비용** 데이터를 제거하거나 축소하려면 [**설정** > **비용 추적**](#cost-tracking)을 사용하세요.

**외관**

- **작업 시 비용 정보 표시**는 작업당 비용(가능한 경우) 및 번역, 재작성, 변환 출력 패널의 총 비용을 표시할지 제어합니다.
- **비용 소수 자릿수**는 비용 소수점 표시 방식을 변경합니다.
- **웹 전용:** **앱 주위에 여백 표시**는 인터페이스 주위에 여분의 공간을 추가합니다.
- **글꼴 패밀리**는 텍스트 패널의 글꼴을 변경합니다.
- **크기**는 글꼴 크기를 변경합니다.

**구성 백업**

- **백업에 사용 데이터 포함** — 활성화 시 ZIP 파일에 실행 기록 및 API 호출 데이터도 포함됩니다.
- **구성 백업** — `config.json`, `state.json`, 선택적 암호화 키, 사용자, 환경 설정, 사용자 정의 프롬프트 및 사용 데이터(선택 시)를 포함한 단일 ZIP 파일(`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`, 기본적으로 UTC 기준)을 생성합니다. 백업이 성공하면 저장된 파일 이름이 확인 메시지에 표시됩니다.
- **백업에서 복원** — 먼저 **확인 대화상자**가 열립니다. 대화상자 내에서 백업 ZIP 파일을 선택하세요 (**찾아보기** / 파일 선택기 또는 지원되는 경우 드래그 앤 드롭), 이후 옵션을 검토하세요:
  - **사용 데이터 복원** — 백업 시 사용 데이터가 포함된 경우 ZIP 내 사용/기록 데이터를 가져옵니다. 설정과 프롬프트만 원할 경우 이 옵션을 해제하세요.
  - **복원 전 이전 사용 데이터 지우기** — 백업을 적용하기 전에 현재 설치의 기존 사용/기록 데이터를 제거합니다(선택 사항; 깨끗한 대체를 원할 때 사용).

웹 버전이나 데스크톱 버전에서 생성된 백업은 서로 다른 버전에서 복원할 수 있습니다. 데스크톱 백업을 웹 버전에 복원할 경우, 데이터는 관리자 사용자에게 복원됩니다.

<a id="models"></a>
### 모델

**설정** > **모델**을 사용하여 도구 모음에 표시될 모델을 선택할 수 있습니다.

![Settings Models tab](../images/screenshots/ko/settings-models.png)

이 페이지에는 두 개의 목록이 있습니다:

- 왼쪽의 **사용 가능한 모델**
- 오른쪽의 **선택된 모델**

유용한 제어 기능은 다음과 같습니다:

- **모델 검색...** — 이름으로 모델을 찾습니다.
- **제공업체** 칩 — 목록을 하나의 엔진(OpenRouter, OpenAI, Ollama 등)으로 좁힙니다.
- **무료 전용** — 무료 모델만 표시합니다.
- **새로고침** — 목록을 다시 불러옵니다.
- **모두 확장** 및 **모두 접기** — 제공업체별로 정렬할 때 사용합니다.

모델 ID에는 제공업체 접두사가 포함됩니다(예: `openrouter/…` 대 `openai/…`). **OpenAI(OpenRouter)** 또는 **OpenAI(직접)** 와 같은 배지로 트래픽이 라우팅되는 방식을 확인할 수 있습니다.

> ℹ️ **참고**<br/>
> **OpenRouter Body Builder**(`openrouter/bodybuilder`)는 일반 채팅 모델이 아니라 라우터 모델입니다. 응답은 `model` 및 `messages`와 같은 `requests` 배열을 포함하는 OpenRouter API 요청 본문을 설명하는 JSON 형식입니다. **번역**, **재작성**, 또는 **변환** 작업에 이 모델을 사용하면 출력 패널에 완성된 텍스트 대신 해당 JSON이 표시됩니다. 이러한 작업에는 일반 텍스트 모델을 선택하세요. [OpenRouter의 Body Builder 모델 페이지](https://openrouter.ai/openrouter/bodybuilder)를 참조하세요.

동작:

- 모델을 추가하려면 **추가**를 클릭하거나 항목의 아무 곳이나 클릭하세요.

- 모델을 제거하려면 **선택된 모델**에서 해당 옆의 **X**를 클릭하거나 사용 가능한 모델 목록에서 항목의 **선택됨**을 클릭하세요.

- 목록을 지우려면 **모두 선택 해제**를 클릭하세요. 필수 무료 모델은 목록에 유지됩니다.

<br/>

> ℹ️ **참고**<br/>
> OpenRouter에 즉시 크레딧을 추가하고 싶지 않다면 먼저 **무료 전용**을 활성화하고 무료 모델을 선택하세요(신용카드 필요 없음). 또한 Ollama를 사용하여 API 키 없이 로컬에서 모델을 실행할 수 있습니다.

<a id="cost-tracking"></a>
### 비용 추적

**설정** > **비용 추적**을 사용하여 비용 정보를 관리하세요.

- **총 비용**은 누적된 비용을 표시합니다.
- **값 복사**는 총액을 클립보드에 복사합니다.
- **비용 초기화**는 저장된 총액을 0으로 재설정합니다.
- **API 키 사용량과 동기화**는 OpenRouter 계정에서 보고된 사용량과 일치하도록 총액을 설정합니다(OpenRouter 전용).
- **API 키 사용량**은 사용 가능한 경우 OpenRouter 사용량 세부 정보를 표시합니다.
- **비용 데이터 삭제**는 모든 데이터 또는 선택한 날짜보다 오래된 항목만 삭제합니다.

**비용 추적:** OpenRouter 모델을 사용할 경우 앱은 OpenRouter에서 제공하는 비용 정보를 기반으로 실제 사용량과 지출을 표시합니다. 다른 모든 제공업체의 경우, OpenRouter에서 공개한 가격을 기준으로 비용을 추정하며, 가격 정보가 없을 경우 추정 비용은 0일 수 있습니다.

<br/>

> ℹ️ **참고**<br/>
>  **모든 비용 수치는 참고용 추정치이며 공식 청구서가 아닙니다.**

<br/>

> ⚠️ **경고**<br/>
>  데이터 삭제는 되돌릴 수 없습니다. 삭제하기 전에 [**기록**](#history) 또는 [**대시보드** > **모든 호출**](#dashboard-tabs)을 통해 데이터를 백업하거나 내보내야 하며, 그렇지 않으면 영구적으로 손실됩니다.
> 각 API 호출 항목과 관련된 모든 입력/출력 기록도 함께 삭제됩니다.

<a id="api-config"></a>
### API 설정

지원되는 제공업체는 OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras 및 **Ollama**(기본 URL을 통한 로컬 모델)입니다. 사용하는 제공업체만 구성하면 됩니다.

**웹 애플리케이션: 관리자 전용**

API 키는 시스템 또는 Docker 환경 변수를 통해 구성되며, 웹 UI에 입력하지 않습니다. 이 페이지는 어떤 제공업체에 키가 구성되어 있는지 보여주며, 각 제공업체의 **`테스트`** 버튼을 클릭하여 테스트할 수 있습니다.

<br/>

> ℹ️ **참고**<br/>
> API 키를 변경하려면 시스템 또는 Docker 구성의 환경 변수를 업데이트하고 서버 또는 컨테이너를 재시작하세요.

> ℹ️ **참고**<br/>
> **구성 백업**( [**일반 설정** → 구성 백업](#general-settings) 참조)은 ZIP 파일 내 `config.json`에 **해결된(resolved)** 제공업체 키를 포함할 수 있습니다. 해당 ZIP을 복원해도 키가 서버의 영구 설정 파일로 복사되지는 않습니다. 실시간 키는 여전히 해당 문서에 설명된 대로 환경 변수와 기존 파일 상태에서 가져옵니다.

<br/>

**데스크톱 애플리케이션**

사용하는 각 제공업체의 API 키를 저장하려면 **API 설정**을 사용하세요. Ollama의 경우 API 키 대신 **기본 URL**을 입력하세요.

<br/>

> 💡 **팁** <br/>
> API 키를 사용하거나 요금을 지불하고 싶지 않다면, [Ollama를 다운로드](https://ollama.com)하여 기계에서 `translategemma:4b`와 같은 모델을 무료로 로컬로 실행할 수 있습니다. 또는 무료 OpenRouter 계정을 만들거나(신용카드 필요 없음), Cerebras, Google, Groq 또는 Mistral AI에서 무료 API 키를 발급받아 무료 모델을 사용할 수 있습니다.

<br/>

- 필요한 제공업체만 추가하세요. **설정** > **모델**에서 각 모델 ID는 제공업체 이름으로 시작됩니다(예: `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

API 키를 추가하려면 텍스트 필드에 값을 입력하고 **`저장`** 버튼을 클릭하세요. 기존 키를 교체하려면 **`편집`** 버튼을 클릭하세요. 키가 제대로 작동하는지 확인하려면 **`테스트`** 버튼을 클릭하세요. Ollama 기본 URL의 경우 연결을 확인하기 위해 항상 **`테스트`** 버튼을 클릭하세요.

<br/>

> ℹ️ **참고**<br/>
> 현재 API 키의 값을 확인할 수 없습니다. 오직 **`편집`** 버튼을 사용하여 키를 교체할 수 있습니다.
> API 키는 구성 파일에 암호화되어 저장됩니다.

<a id="common-issues"></a>
## 일반적인 문제

예상대로 동작하지 않는 경우, 먼저 다음 사항을 확인하세요.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### 앱이 텍스트를 번역, 재작성 또는 변환하지 않습니다

다음 사항을 확인하세요:

- 툴바에서 모델을 선택했는지 확인하세요
- [**설정** > **모델**](#models)에 최소한 하나 이상의 모델이 나열되어 있는지 확인하세요
- API 설정이 정상적으로 작동하는지 확인하세요

데스크톱 앱을 사용하는 경우:

1. [**설정** > **API 설정**](#api-config)을 엽니다.
2. 최소한 하나 이상의 API 키가 저장되어 있는지 확인하세요.
3. 제공업체 옆의 **테스트**를 클릭하여 키가 작동하는지 확인하세요.

<br/>

<a id="the-model-list-is-empty"></a>
### 모델 목록이 비어 있습니다

[**설정** > **모델**](#models)을 열고 **새로고침**을 클릭하세요.

필요한 경우:

- 모델을 검색하세요
- **무료 전용**을 켜세요
- 하나 이상의 모델을 **선택된 모델**에 추가하세요

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### 결과가 너무 느리거나 비용이 너무 많이 듭니다

다음 중 하나 이상을 시도해 보세요:

- 다른 모델을 선택하세요
- 입력을 더 짧게 하세요
- [**설정** > **일반 설정**](#general-settings)에서 **실시간 번역 (입력 중)** 을 끄세요
- 간단한 작업에는 무료 모델을 사용하세요 ([모델](#models) 참조)

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### 인터페이스 언어가 잘못되었습니다

[툴바](#toolbar)의 지구본 아이콘을 클릭하고 원하는 **인터페이스 언어**를 선택하세요.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### 텍스트가 너무 작거나 읽기 어렵습니다

[**설정** > **일반 설정**](#general-settings)을 열고 다음을 변경하세요:

- **글꼴**
- **크기**

<br/>

<a id="dashboard-charts-are-empty"></a>
### 대시보드 차트가 비어 있습니다

다음과 같은 경우 정상입니다:

- **무료 모델**만 사용하고 있으며 **비용** 수치를 보고 있는 경우 (비용이 0일 수 있음); **요약**의 **사용량** 호출 수 차트는 여전히 선택된 기간의 데이터를 필요로 합니다
- 선택된 **시간 필터**가 호출이 발생한 기간을 포함하지 않는 경우 — 확인하려면 **전체**를 시도해 보세요

차트가 **전체**를 선택한 후에도 비어 있는 경우, [**기록**](#history) 또는 **모든 호출** 탭에 호출이 표시되는지 확인하세요.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### 비용이 "사용할 수 없음"으로 표시되거나 잘못된 것으로 보임

**OpenRouter**를 통해 모델을 사용하는 경우, 앱은 OpenRouter에서 보고한 실제 지출을 표시합니다.

**기타 제공업체**(OpenAI 직접, Anthropic 직접 등)의 경우, 비용은 OpenRouter에서 공개한 가격 정보를 기반으로 **예상**됩니다. 모델에 해당하는 가격 정보를 찾을 수 없는 경우, 비용은 **사용할 수 없음**으로 표시되며 합계에 포함되지 않습니다.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### 총 비용이 제공업체 청구서와 일치하지 않음

앱의 모든 비용 수치는 **참고용 예상치**이며, 공식 청구서가 아닙니다.

총액을 실제 OpenRouter 지출에 더 가깝게 맞추려면 [**설정** > **비용 추적**](#cost-tracking)을 열고 **API 키 사용량과 동기화**를 클릭하세요.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### 사이드바에 기록 페이지가 없음

**실행 기록 보관**이 꺼져 있을 수 있습니다. [**설정** > **일반 설정**](#general-settings)을 열고 이를 활성화하세요. 이 기능을 켜도 이전에 삭제된 기록 데이터는 복원되지 않는다는 점에 유의하세요.

<br/>

<a id="web-app-session-expired"></a>
### 웹 앱: 예기치 않게 로그인 페이지로 리디렉션됨

세션이 만료되었을 수 있습니다. 다시 로그인하세요. 자주 발생한다면 서버 구성에서 세션 수명 설정을 확인하세요.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### 웹 관리자: 비밀번호를 잊어버렸거나 분실했을 경우

이 내용은 데스크탑(Electron) 앱이 아닌 **자체 호스팅 웹 앱**(Docker)에 적용됩니다.

- 다른 관리자가 여전히 로그인할 수 있다면, [**설정** > **사용자**](#users)을 열고 해당 계정을 선택한 후 거기서 **새 비밀번호**를 설정할 수 있습니다.
- **잠겨서 로그인할 수 없지만** 머신 또는 컨테이너에 **쉘 접근 권한**이 있는 경우, 이미지와 함께 제공되는 도우미를 사용하여 비밀번호를 재설정하세요(기본 이름을 변경한 경우 `transrewrt`를 교체하고, 공백이나 특수 문자가 포함된 비밀번호는 따옴표로 묶으세요):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

다른 계정을 생성하지 않았다면 기본 관리자 사용자 이름은 `admin`입니다. 하나의 인수만 전달할 경우, 이는 `admin`의 새 비밀번호로 간주됩니다.

Docker 대신 **소스 체크아웃**에서 실행 중인 경우 다음을 사용하세요:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

이 스크립트는 SQLite 데이터베이스의 사용자 레코드를 업데이트합니다(관리자 사용자가 없을 경우 생성도 가능). 재설정 후 새 비밀번호로 로그인하세요.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### 대시보드에 다른 사용자의 데이터가 표시되지 않음(웹)

**관리자**만 **사용자** 필터를 통해 모든 사용자의 데이터를 볼 수 있습니다. 일반 사용자는 설계상 자신의 활동만 볼 수 있습니다.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### 프롬프트를 수정했지만 편집 내용을 잃어버림

프롬프트를 편집할 때는 항상 **저장**을 클릭한 후에 **실행으로 돌아가기**를 클릭해야 합니다.

<a id="quick-tips"></a>
## 빠른 팁

- [**번역**](#translate)으로 시작하여 설정이 제대로 작동하는지 확인한 후, [**재작성**](#rewrite) 또는 [**변환**](#transform)으로 넘어가세요.
- 일상적인 문장 개선에는 [**재작성**](#rewrite)을 사용하세요.
- 특정 작업을 위한 반복 가능한 워크플로우가 필요할 때는 [**변환**](#transform)을 사용하세요.
- 사용량과 비용을 확인하고 싶다면 [**대시보드**](#dashboard)를 사용하세요.
- 과거 작업과 그 전체 **입력** 및 **출력 텍스트**를 검토하려면 [**기록**](#history)을 사용하세요.
- 프롬프트 라이브러리를 안전하게 보관하거나 다른 사람과 공유하고 싶다면 정기적으로 프롬프트를 **내보내기**하세요 ([변환 프롬프트](#transform-prompts) 참조).
