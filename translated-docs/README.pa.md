ਆਈ.ਆਈ. ਦੁਆਰਾ ਸੰਚਾਲਿਤ ਪਾਠ ਟੂਲ: ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰੋ, ਵੱਖ-ਵੱਖ ਸ਼ੈਲੀਆਂ ਵਿੱਚ ਮੁੜ ਲਿਖੋ ਅਤੇ ਕਸਟਮ ਟਿਪਣੀਆਂ ਨਾਲ ਰੂਪ ਬਦਲੋ — ਮਲਟੀਪਲ ਐਆਈ ਪ੍ਰਦਾਤਾਵਾਂ (ਓਪਨਰਾਊਟਰ, ਓਪਨਏਆਈ, ਐਂਥਰੌਪਿਕ, ਗੂਗਲ ਜੈਮੀਨੀ, ਡੀਪਸੀਕ, ਗਰੌਕ, ਮਿਸਟਰਲ, ਐਕਸਏਆਈ, ਅਤੇ ਸਥਾਨਕ ਓਲਾਮਾ) ਦੀ ਵਰਤੋਂ ਕਰਕੇ। ਡੈਸਕਟਾਪ ਐਪ (ਇਲੈਕਟ੍ਰਾਨ) ਜਾਂ ਸਵ-ਹੋਸਟ ਕੀਤੀ ਵੈੱਬ ਐਪ (ਡੌਕਰ) ਵਜੋਂ ਚਲਦਾ ਹੈ।

- **ਅਨੁਵਾਦ** — ਦਰਜਨਾਂ ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ, ਸਰੋਤ ਦੀ ਆਟੋਮੈਟਿਕ ਪਛਾਣ ਨਾਲ
- **ਮੁੜ-ਲਿਖੋ** — ਵਿਆਕਰਨ ਨੂੰ ਠੀਕ ਕਰੋ, ਸਪੱਸ਼ਟਤਾ ਵਿੱਚ ਸੁਧਾਰ ਕਰੋ, ਔਪਚਾਰਿਕ/ਅਨੌਪਚਾਰਿਕ, ਛੋਟਾ ਜਾਂ ਵਧੀਆ ਕਰੋ, ਤਕਨੀਕੀ
- **ਰੂਪਾਂਤਰਣ** — ਕਸਟਮ AI ਪ੍ਰੇਰਕ; ਪ੍ਰੇਰਕਾਂ ਨੂੰ ਬਣਾਓ ਅਤੇ ਪ੍ਰਬੰਧਿਤ ਕਰੋ, ਹਰੇਕ ਪ੍ਰੇਰਕ ਲਈ ਵਿਕਲਪਿਕ ਟੀਚਾ ਭਾਸ਼ਾ
- **ਇਤਿਹਾਸ** — ਇਨਪੁਟ/ਆਉਟਪੁਟ ਸਮੱਗਰੀ ਨਾਲ ਪੂਰਾ ਕਾਰਜ ਇਤਿਹਾਸ, ਫਿਲਟਰਿੰਗ, ਅਤੇ ਨਿਰਯਾਤ
- **ਮਾਡਲ ਅਤੇ ਲਾਗਤ** — ਕਿਸੇ ਵੀ ਕੰਫਿਗਰ ਕੀਤੇ ਪ੍ਰਦਾਤਾ ਤੋਂ ਮਾਡਲ ਚੁਣੋ; ਲਾਗਤ ਅਤੇ ਵਰਤੋਂ ਡੈਸ਼ਬੋਰਡ, ਲੌਗ ਨਾਲ, ਮਾਡਲ/ਆਪਰੇਸ਼ਨ/ਦਿਨ ਅਨੁਸਾਰ ਸਾਰਾਂਸ਼
- **UI** — ਬਹੁਭਾਸ਼ੀ ਇੰਟਰਫੇਸ (30+ ਭਾਸ਼ਾਵਾਂ, RTL ਸਹਾਇਤਾ), ਫੋਂਟ, ...
- **ਵੈੱਬ ਮੋਡ** — ਐਡਮਿਨ ਰੋਲਾਂ ਨਾਲ ਮਲਟੀ-ਯੂਜ਼ਰ ਸਹਾਇਤਾ
- **ਡੈਸਕਟਾਪ** — ਵਿੰਡੋਜ਼ ਅਤੇ ਲੀਨਕਸ ਲਈ ਇਲੈਕਟ੍ਰਾਨ ਐਪ
- **ਸੈਲਫ-ਹੋਸਟਡ** — amd64 ਅਤੇ arm64 (ਰਾਸਪਬੇਰੀ ਪਾਈ-ਤਿਆਰ) ਲਈ ਡੌਕਰ ਇਮੇਜ

ਇੰਸਟਾਲ ਹੋਣ ਤੋਂ ਬਾਅਦ, ਸਾਰੇ ਫੀਚਰਾਂ ਬਾਰੇ ਪੂਰਨ ਜਾਣਕਾਰੀ ਲਈ **[ਯੂਜ਼ਰ ਗਾਈਡ](USER-GUIDE.pa.md)** ਵੇਖੋ।

## ਤੁਰੰਤ ਸ਼ੁਰੂਆਤ

**ਡੌਕਰ (ਆਪਣੇ ਨਾਲ ਹੋਸਟ ਕਰਨ ਲਈ ਸਿਫਾਰਸ਼ ਕੀਤੀ ਗਈ)**

```bash
docker pull ghcr.io/wsj-br/transrewrt:latest

OPENROUTER_API_KEY=sk-or-your-key docker run -d \
  -p 5000:5000 \
  -v transrewrt-data:/app/data \
  -e OPENROUTER_API_KEY \
  --name transrewrt-web \
  ghcr.io/wsj-br/transrewrt:latest
```

`sk-or-your-key` ਨੂੰ ਆਪਣੀ [OpenRouter API ਚਾਬੀ](https://openrouter.ai/keys) ਨਾਲ ਬਦਲੋ ( ਜਾਂ ਹੋਰ ਪ੍ਰਦਾਤਾ ਦੀਆਂ ਚਾਬੀਆਂ ਸੈੱਟ ਕਰੋ; ਵੇਖੋ [ਕਨਫਿਗਰੇਸ਼ਨ](#configuration-and-environment)). [http://localhost:5000](http://localhost:5000) ਖੋਲ੍ਹੋ ਅਤੇ ਸੇਵਾ ਨੂੰ ਬਾਹਰ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਡਿਫਾਲਟ ਐਡਮਿਨ ਪਾਸਵਰਡ ਬਦਲੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਡੌਕਰ ਵਿੱਚ, LLM ਕ੍ਰੈਡੈਂਸ਼ਿਅਲਜ਼ ਨੂੰ `OPENROUTER_API_KEY`, `OPENAI_API_KEY`, `CEREBRAS_API_KEY`, ... ਵਰਗੇ ਐਨਵਾਇਰਨਮੈਂਟ ਵੇਰੀਏਬਲਜ਼ ਨਾਲ ਸੈੱਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਵੈੱਬ UI ਵਿੱਚ ਨਹੀਂ)। ਡੈਸਕਟਾਪ (Electron) 'ਤੇ ਤੁਸੀਂ **ਸੈਟਿੰਗਜ਼ → API** ਵਿੱਚ ਚਾਬੀਆਂ ਦੀ ਸੈਟਿੰਗ ਕਰਦੇ ਹੋ।

<br/>

**ਵਿੰਡੋਜ਼**

ਨਵੀਨਤਮ `Transrewrt Setup x.y.z.exe` ਨੂੰ [ਰੀਲੀਜ਼](https://github.com/wsj-br/transrewrt/releases) ਤੋਂ ਡਾਊਨਲੋਡ ਕਰੋ, ਇੰਸਟਾਲਰ ਨੂੰ ਚਲਾਓ, ਅਤੇ ਫਿਰ ਸਟਾਰਟ ਮੀਨੂ ਜਾਂ ਡੈਸਕਟਾਪ ਸ਼ਾਰਟਕਟ ਤੋਂ ਲਾਂਚ ਕਰੋ। **ਸੈਟਿੰਗਜ਼ → API** ਵਿੱਚ ਆਪਣੀਆਂ API ਕੁੰਜੀਆਂ ਦਰਜ ਕਰੋ। ਤੁਹਾਨੂੰ ਘੱਟੋ-ਘੱਟ ਇੱਕ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰਨਾ ਹੋਵੇਗਾ, ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਲਈ OpenRouter ਆਮ ਹੈ।

<br/>

**ਲੀਨਕਸ**

ਆਪਣੇ CPU ਲਈ `.AppImage` ਨੂੰ [ਰੀਲੀਜ਼](https://github.com/wsj-br/transrewrt/releases) ਤੋਂ ਡਾਊਨਲੋਡ ਕਰੋ (`x64` ਆਮ ਪੀਸੀ ਲਈ, `arm64` ਬਹੁਤ ਸਾਰੇ ARM ਡਿਵਾਈਸਾਂ ਲਈ, ਰਾਸਪਬੇਰੀ ਪਾਈ 4+ ਸਮੇਤ), ਫਿਰ:

```bash
chmod +x Transrewrt-x.y.z-x64.AppImage && ./Transrewrt-x.y.z-x64.AppImage
```

**ਸੈਟਿੰਗਜ਼ → API** ਵਿੱਚ ਆਪਣੀਆਂ API ਕੁੰਜੀਆਂ ਦਰਜ ਕਰੋ। ਤੁਹਾਨੂੰ ਘੱਟੋ-ਘੱਟ ਇੱਕ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰਨਾ ਹੋਵੇਗਾ, ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਲਈ OpenRouter ਆਮ ਹੈ।

Debian/Ubuntu ਤੇ ਤੁਹਾਨੂੰ ਪਹਿਲਾਂ ਵਾਧੂ ਨਿਰਭਰਤਾਵਾਂ ਨੂੰ ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਲੋੜ ਪੈ ਸਕਦੀ ਹੈ:

```bash
sudo apt install libgtk-3-0 libnotify-dev libnss3 libxss1 libasound2 libxtst6 xauth
```

ਵਿਸਥਾਰ ਲਈ [ਇੰਸਟਾਲੇਸ਼ਨ → ਲੀਨਕਸ](#linux-electron) ਵੇਖੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>

> ਮੈਕਓਐਸ ਨੂੰ ਫਿਲਹਾਲ ਸਹਾਇਤਾ ਪ੍ਰਾਪਤ ਨਹੀਂ ਹੈ। ਵਿੰਡੋਜ਼, ਲੀਨਕਸ ਅਤੇ ਡੌਕਰ ਲਈ Transrewrt ਉਪਲਬਧ ਹੈ।

<br/>

ਜਦੋਂ ਐਪ ਚੱਲ ਰਹੀ ਹੋਵੇ, ਤਾਂ ਪਾਠ ਨੂੰ ਅਨੁਵਾਦ, ਪੁਨਰ-ਲੇਖਨ ਅਤੇ ਰੂਪਾਂਤਰਿਤ ਕਰਨਾ, ਪ੍ਰਾਉਟਸ ਨੂੰ ਪਰਬੰਧਿਤ ਕਰਨਾ ਅਤੇ ਮਾਡਲਾਂ ਨੂੰ ਕੰਫੀਗਰ ਕਰਨਾ ਸਿੱਖਣ ਲਈ **[ਯੂਜ਼ਰ ਗਾਈਡ](USER-GUIDE.pa.md)** ਦੇਖੋ।

## ਇੰਸਟਾਲੇਸ਼ਨ

<a id="windows-electron"></a>

### ਵਿੰਡੋਜ਼ (ਇਲੈਕਟ੍ਰੋਨ)

- [ਰੀਲੀਜ਼ਿਜ਼](https://github.com/wsj-br/transrewrt/releases) ਤੋਂ ਨਵੀਂਤਮ ਇੰਸਟਾਲਰ ਡਾਊਨਲੋਡ ਕਰੋ।
- `.exe` ਫਾਈਲ ਨੂੰ ਚਲਾਓ ਅਤੇ ਇੰਸਟਾਲਰ ਦੀ ਅਨੁਸੂਚੀ ਕਰੋ।
- ਪਹਿਲੀ ਵਾਰ ਚਲਾਉਣਾ: ਸ਼ੁਰੂ ਮੇਨੂ ਜਾਂ ਡੈਸਕਟਾਪ ਸ਼ਾਰਟਕੱਟ ਤੋਂ ਐਪ ਨੂੰ ਸ਼ੁਰੂ ਕਰੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਵਿੰਡੋਜ਼ ਸਿਕਿਓਰਿਟੀ ਚੇਤਾਵਨੀ (ਸਾਈਨ ਨਾ ਕੀਤੇ/ਸਵੈ-ਪ੍ਰਕਾਸ਼ਿਤ ਐਪਸ ਲਈ ਆਮ) ਦਿਖਾ ਸਕਦਾ ਹੈ:
>   - **ਯੂਜ਼ਰ ਅਕਾਊਂਟ ਕੰਟਰੋਲ (ਯੂਏਸੀ)**: "ਕੀ ਤੁਸੀਂ ਅਣਜਾਣ ਪ੍ਰਕਾਸ਼ਕ ਤੋਂ ਇਸ ਐਪ ਨੂੰ ਆਪਣੇ ਡਿਵਾਈਸ ਵਿੱਚ ਤਬਦੀਲੀਆਂ ਕਰਨ ਦੀ ਆਗਿਆ ਦੇਣਾ ਚਾਹੁੰਦੇ ਹੋ?" → **ਹਾਂ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
>   - **ਮਾਈਕ੍ਰੋਸਾੱਫਟ ਡਿਫੈਂਡਰ ਸਮਾਰਟਸਕਰੀਨ**: "ਵਿੰਡੋਜ਼ ਨੇ ਤੁਹਾਡਾ ਪੀਸੀ ਸੁਰੱਖਿਅਤ ਕੀਤਾ" → **ਹੋਰ ਜਾਣਕਾਰੀ** ਤੇ ਕਲਿੱਕ ਕਰੋ → **ਫਿਰ ਵੀ ਚਲਾਓ**।
>
> ਇਸ ਲਈ ਕਿ ਇਸ ਐਪ ਦਸਤਖ਼ਤ ਮਾਈਕ੍ਰੋਸਾੱਫਟ ਜਾਂ ਕਿਸੇ ਪ੍ਰਮੁੱਖ ਪ੍ਰਕਾਸ਼ਕ ਦੁਆਰਾ ਨਹੀਂ ਕੀਤਾ ਗਿਆ ਹੈ—ਜੇ ਇਸਨੂੰ ਸਾਡੇ ਅਧਿਕਾਰਿਕ ਗਿੱਥਬ ਰੀਲੀਜ਼ ਤੋਂ ਡਾਊਨਲੋਡ ਕੀਤਾ ਗਿਆ ਹੈ ਤਾਂ ਇਹ ਸੁਰੱਖਿਅਤ ਹੈ  
> (ਹੇਠਾਂ SHA256 ਚੈੱਕਸਮ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ)।

<a id="docker"></a>

### ਡਾਕਰ

- ਪੁੱਲ: `docker pull ghcr.io/wsj-br/transrewrt:latest`
- ਵਾਤਾਵਰਣ ਰਾਹੀਂ ਘੱਟ ਤੋਂ ਘੱਟ ਇੱਕ ਪ੍ਰਦਾਤਾ ਕੁੰਜੀ ਨਿਰਧਾਰਤ ਕਰੋ (ਉਦਾਹਰਣ ਲਈ, OpenRouter ਲਈ `OPENROUTER_API_KEY`)। ਰਹੱਸਾਂ ਨੂੰ ਇਮੇਜ ਵਿੱਚ ਨਾ ਸ਼ਾਮਲ ਕਰਨ ਲਈ `-e` ਜਾਂ `docker compose` / `.env` ਨਾਲ ਚਲਦੇ ਪੈਰਾਮੀਟਰ ਪਾਸ ਕਰੋ।
- ਪ੍ਰਦਾਤਾ ਕੁੰਜੀਆਂ ਵੈੱਬ UI ਵਿੱਚ ਦਰਜ ਨਹੀਂ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ; ਸਰਵਰ ਉਹਨਾਂ ਨੂੰ ਵਾਤਾਵਰਣ ਤੋਂ ਪੜ੍ਹਦਾ ਹੈ।

ਉਦਾਹਰਣ - ਸਥਾਈਤਾ ਲਈ ਨਾਮਿਤ ਵਾਲੀਉਮ (env ਰਾਹੀਂ OpenRouter ਕੁੰਜੀ):

```bash
OPENROUTER_API_KEY=sk-or-your-key docker run -d \
  -p 5000:5000 \
  -v transrewrt-data:/app/data \
  -e OPENROUTER_API_KEY \
  --name transrewrt-web \
  ghcr.io/wsj-br/transrewrt:latest
```

ਜਾਂ ਜੇਕਰ ਤੁਸੀਂ ਡਾਕਰ ਕੰਪੋਜ਼ ਵਰਤਣਾ ਪਸੰਦ ਕਰਦੇ ਹੋ, ਤਾਂ ਵਰਤੋਂ:

```
# ਕੰਪੋਜ਼ ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰੋ
wget https://github.com/wsj-br/transrewrt/raw/refs/heads/master/production.yml -O transrewrt.yml
# API_KEYS ਸ਼ਾਮਲ ਕਰਨ ਲਈ ਫਾਈਲ ਸੰਪਾਦਿਤ ਕਰੋ ਅਤੇ ਸਮਾਂ-ਖੇਤਰ (TZ) ਨੂੰ ਅਨੁਕੂਲ ਬਣਾਓ
vi transrewrt.yml
# ਕੰਟੇਨਰ ਨੂੰ ਸ਼ੁਰੂ ਕਰੋ
docker compose -f transrewrt.yml up -d

ਸਾਰੇ ਵਾਤਾਵਰਣ ਚਲਣਾਂ, ਜਿਵੇਂ `PORT`, `CONFIG_PATH`, `TZ`, ਅਤੇ LLM ਕੁੰਜੀਆਂ (`OPENROUTER_API_KEY`, `OPENAI_API_KEY`, …) ਬਾਰੇ ਜਾਣਕਾਰੀ ਲਈ [ਕਾਨਫਿਗਰੇਸ਼ਨ](#configuration-and-environment) ਵੇਖੋ।

<a id="configuring-the-timezone"></a>

### ਸਮਾਂ ਖੰਡ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰਨਾ

ਐਪਲੀਕੇਸ਼ਨ ਯੂਜ਼ਰ ਇੰਟਰਫੇਸ ਦੀ ਮਿਤੀ ਅਤੇ ਸਮਾਂ ਬ੍ਰਾਊਜ਼ਰ ਦੇ ਸਥਾਨਕ ਸਮਾਂ ਅਤੇ ਸਮਾਂ ਖੰਡ ਦੇ ਅਨੁਸਾਰ ਹੁੰਦਾ ਹੈ। ਸਰਵਰ-ਸਾਈਡ ਵਿਵਹਾਰ (ਲੌਗਿੰਗ ਅਤੇ ਹੋਰ) ਲਈ, ਕੰਟੇਨਰ `TZ` ਮੁਹੱਈਆ ਪਰਯੰਤਤਾ ਵੇਰੀਏਬਲ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ। ਮੂਲ ਰੂਪ `TZ=Europe/London` ਹੈ।

ਕਿਸੇ ਹੋਰ ਸਮਾਂ ਖੰਡ ਨੂੰ ਵਰਤਣ ਲਈ, ਆਪਣੀ ਕੰਪੋਜ਼ ਫਾਈਲ ਵਿੱਚ `TZ` ਨੂੰ ਸੈੱਟ ਕਰੋ, ਉਦਾਹਰਣ ਲਈ:

```yaml
environment:
  - TZ=America/Sao_Paulo
```

ਜਾਂ ਕੰਟੇਨਰ ਨੂੰ ਚਲਾਉਂਦੇ ਸਮੇਂ ਇਸਨੂੰ ਪਾਸ ਕਰੋ (Docker):

```bash
--env TZ=America/Sao_Paulo
```

ਕਈ ਲੀਨਕਸ ਹੋਸਟਾਂ ਉੱਤੇ, ਤੁਸੀਂ ਸਿਸਟਮ ਸਮਾਂ ਖੰਡ ਦਾ ਨਾਮ ਨਿਮਨ ਨਾਲ ਕਾਪੀ ਕਰ ਸਕਦੇ ਹੋ:

```bash
echo TZ=\"$(</etc/timezone)\"
```

ਵੈਧ ਸਮਾਂ ਖੰਡ ਨਾਮਾਂ ਦੀ ਸੂਚੀ [tz ਡੇਟਾਬੇਸ](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) (ਵਿਕੀਪੀਡੀਆ) ਵਿੱਚ ਰੱਖੀ ਗਈ ਹੈ।

<a id="getting-an-openrouter-api-key"></a>

## ਓਪਨਰਾਊਟਰ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰਨਾ

ਟਰਾਂਸਰਿਵਰਟ ਨੂੰ ਕਈ AI ਪ੍ਰਦਾਤਾ ਸਹਾਇਤਾ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ। [ਓਪਨਰਾਊਟਰ](https://openrouter.ai) ਇੱਕ ਲੋਕਪ੍ਰਿਯ ਚੋਣ ਹੈ ਕਿਉਂਕਿ ਇਹ ਇੱਕੋ ਕੁੰਜੀ ਹੇਠ ਬਹੁਤ ਸਾਰੇ ਮਾਡਲਾਂ ਨੂੰ ਇਕੱਠਾ ਕਰਦਾ ਹੈ ਅਤੇ ਮੁਫਤ ਮਾਡਲ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

1. [openrouter.ai](https://openrouter.ai) 'ਤੇ ਸਾਈਨ ਅੱਪ ਕਰੋ ਜਾਂ ਲਾਗਇਨ ਕਰੋ।
2. [Keys](https://openrouter.ai/keys) ਸਫ਼ੇ ਨੂੰ ਖੋਲ੍ਹੋ ਅਤੇ ਇੱਕ ਨਵੀਂ ਕੁੰਜੀ ਬਣਾਓ (ਇਸ ਦਾ ਨਾਮ ਰੱਖੋ, ਅਤੇ ਇੱਛਾ ਅਨੁਸਾਰ ਇੱਕ ਸਿਰਫ਼ ਸੀਮਾ ਨਿਰਧਾਰਤ ਕਰੋ)। ਤੁਸੀਂ ਸਿਰਫ ਸੀਮਾ ਜੋੜੇ ਬਿਨਾਂ ਮੁਫਤ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।
3. **ਡੈਸਕਟਾਪ (ਇਲੈਕਟ੍ਰਾਨ):** ਕੁੰਜੀ ਨੂੰ **Settings → API** ਵਿੱਚ ਪੇਸਟ ਕਰੋ। **ਡਾਕਰ**: `OPENROUTER_API_KEY` ਵਰਗੇ env ਵੇਰੀਏਬਲਸ ਨੂੰ ਸੈੱਟ ਕਰੋ (ਤੇਜ਼ ਸ਼ੁਰੂਆਤ ([#quick-start]) ਦੇਖੋ)।

ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਣ, ਜਾਂ ਪਰਿਵਰਤਨ ਲਈ ਓਪਨਰਾਊਟਰ ਦੇ **ਬਾਡੀ ਬਿਲਡਰ** ਮਾਡਲ ([`openrouter/bodybuilder`](https://openrouter.ai/openrouter/bodybuilder)) ਦੀ ਵਰਤੋਂ ਨਾ ਕਰੋ: ਇਹ JSON ਬੇਨਤੀ ਦੇ ਪੇਲੋਡ ਨੂੰ ਵਾਪਸ ਕਰਦਾ ਹੈ, ਉਹਨਾਂ ਕਾਰਜਾਂ ਲਈ ਪੂਰੀ ਕੀਤੀ ਟੈਕਸਟ ਨਹੀਂ। ਮਦਦਗਾਰ ਦਸਤਾਵੇਜ਼ ਵਿੱਚ [Settings → Models](USER-GUIDE.pa.md#models) ਵੇਖੋ।

ਤੁਸੀਂ ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ (OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras) ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ ਜਾਂ [Ollama](https://ollama.com) ਨਾਲ ਮਾਡਲਾਂ ਨੂੰ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚਲਾ ਸਕਦੇ ਹੋ। ਸਮਰਥਿਤ ਪ੍ਰਦਾਤਾਵਾਂ ਅਤੇ ਵਾਤਾਵਰਣ ਚਲਣ ਦੀ ਪੂਰੀ ਸੂਚੀ ਲਈ [ਕਾਨਫ਼ੀਗੁਰੇਸ਼ਨ](#configuration-and-environment) ਵੇਖੋ।

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਜੇਕਰ ਤੁਸੀਂ ਕਿਸੇ ਹੋਰ ਡਿਵਾਈਸ, ਕੰਟੇਨਰ, ਜਾਂ ਸਰਵਿਸ ਤੋਂ Ollama ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ Ollama ਨੂੰ ਬਾਹਰੀ ਕਨੈਕਸ਼ਨਾਂ ਨੂੰ ਸਵੀਕਾਰ ਕਰਨ ਲਈ ਕਾਨਫ਼ੀਗਰ ਕਰਨਾ ਯਾਦ ਰੱਖੋ (ਸਿਰਫ਼ ਲੋਕਲਹੋਸਟ ਨਹੀਂ)।


ਸੀਮਾਵਂ, BYOK, ਅਤੇ ਹੋਰ ਵਧੇਰੇ ਲਈ, [OpenRouter ਪ੍ਰਮਾਣਕਰਨ](https://openrouter.ai/docs/api/reference/authentication) ਦੇਖੋ।

## ਕਨਫ਼ੀਗਰੇਸ਼ਨ ਅਤੇ ਮਾਹੌਲ

**ਕਨਫ਼ੀਗ ਫਾਇਲ ਸਥਾਨ**

| ਡਿਪਲੌਇਮੈਂਟ | ਕਾਨਫਿਗ ਸਥਾਨ |
| ------------------ | ------------------------------------------------- |
| ਇਲੈਕਟ੍ਰਾਨ (ਵਿੰਡੋਜ਼) | `%APPDATA%\transrewrt\` |
| ਇਲੈਕਟ੍ਰਾਨ (ਲੀਨਕਸ) | `~/.config/transrewrt/` |
| ਵੈੱਬ / ਡੌਕਰ | `/app/data/config.json` (ਬਰਕਰਾਰ ਰੱਖਣ ਲਈ ਇੱਕ ਵਾਲੀਊਮ ਵਰਤੋਂ) |

<br/>

**ਮੁਹਾਵਰੇ ਦੇ ਚਲਣ** (ਸਿਰਫ ਵੈੱਬ/Docker ਲਈ; ਇਲੈਕਟ੍ਰਾਨ ਸਥਾਨਕ ਕਾਨਫ਼ੀਗ ਫਾਈਲ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ)

| ਚਲਨਯੋਗ       | ਮੂਲ          | ਵੇਰਵਾ |
| ------------ | ----------- | -------- |
| `PORT`           | `5000`                  | ਸਰਵਰ ਸੁਣਨ ਪੋਰਟ |
| `CONFIG_PATH`    | `/app/data/config.json` | ਕਾਨਫਿਗ ਫਾਈਲ ਲਈ ਮਾਰਗ |
| `TZ`             | `Europe/London`         | ਸਰਵਰ-ਸਾਈਡ ਸਮੇਂ ਲਈ IANA ਟਾਈਮਜ਼ੋਨ (ਲੌਗਿੰਗ, ਆਦਿ); UI ਅਜੇ ਵੀ ਬਰਾਊਜ਼ਰ ਦੀ ਪਾਲਣਾ ਕਰਦਾ ਹੈ। ਵੇਖੋ [Docker → timezone](#docker-timezone) |
| `OPENROUTER_API_KEY` | *(ਖਾਲੀ)*               | OpenRouter API ਕੁੰਜੀ |
| `OPENAI_API_KEY`     | *(ਖਾਲੀ)*               | OpenAI API ਕੁੰਜੀ |
| `CEREBRAS_API_KEY`   | *(ਖਾਲੀ)*               | Cerebras API ਕੁੰਜੀ |
| `ANTHROPIC_API_KEY`  | *(ਖਾਲੀ)*               | Anthropic API ਕੁੰਜੀ |
| `GOOGLE_API_KEY`     | *(ਖਾਲੀ)*               | Google Gemini API ਕੁੰਜੀ |
| `DEEPSEEK_API_KEY`   | *(ਖਾਲੀ)*               | DeepSeek API ਕੁੰਜੀ |
| `GROQ_API_KEY`       | *(ਖਾਲੀ)*               | Groq API ਕੁੰਜੀ |
| `MISTRAL_API_KEY`    | *(ਖਾਲੀ)*               | Mistral API ਕੁੰਜੀ |
| `OLLAMA_URL`     | *(ਖਾਲੀ)*               | Ollama ਬੁਨਿਆਦੀ URL (ਜਿਵੇਂ ਕਿ `http://host.docker.internal:11434`) |
| `XAI_API_KEY`        | *(ਖਾਲੀ)*               | xAI API ਕੁੰਜੀ |

ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰੋ ਜੋ ਤੁਸੀਂ ਵਰਤ ਰਹੇ ਹੋ। ਮਾਡਲ ਆਈਡੀਜ਼ ਨਾਂ ਸਪੇਸ ਵਿੱਚ ਹੁੰਦੀਆਂ ਹਨ (`openrouter/…`, `openai/…`, `cerebras/…`, `ollama/…`, ਆਦਿ)।

**ਲਾਗਤ ਦੀ ਵੇਰਵਾ:** ਜਦੋਂ ਲਾਗੂ ਹੋਵੇ, ਓਪਨਰਾਊਟਰ ਸਹੀ ਬਿਲਡ ਲਾਗਤ ਵਾਪਸ ਕਰਦਾ ਹੈ। ਜਦੋਂ ਓਪਨਰਾਊਟਰ ਦੀ ਚਾਬੀ ਉਪਲਬਧ ਹੋਵੇ, ਹੋਰ ਪ੍ਰਦਾਤਾ ਓਪਨਰਾਊਟਰ ਦੀ ਪਬਲਿਕ ਮਾਡਲ ਮੁੱਲ ਵਾਧੇ ਤੋਂ **ਅੰਦਾਜ਼ਾ** ਲਾਗਤ ਵਰਤਦੇ ਹਨ; ਇਸ ਤੋਂ ਬਿਨਾਂ, ਗੈਰ-ਓਪਨਰਾਊਟਰ ਲਾਗਤ `0` ਵਜੋਂ ਦਿਖਾਈ ਦੇ ਸਕਦੀ ਹੈ। ਅੰਦਾਜ਼ੇ ਬਿਲਾਂ ਦੇ ਬਰਾਬਰ ਨਹੀਂ ਹੁੰਦੇ।

<br/>

**ਡੇਟਾ ਅਤੇ ਪ੍ਰਭਾਵ:** ਡੌਕਰ ਲਈ, /app/data 'ਤੇ ਇੱਕ ਵਾਲੀਊਮ ਮਾਊਂਟ ਕਰੋ ਤਾਂ ਜੋ config.json ਅਤੇ ਸਕਾਈਲਾਈਟ ਡੇਟਾਬੇਸ ਕੋਨਟੇਨਰ ਰੀਸਟਾਰਟਾਂ ਦੇ ਦੌਰਾਨ ਬਰਕਰਾਰ ਰਹੀ। ਵਾਲੀਊਮ ਬਿਨਾਂ, ਜਦੋਂ ਕੋਨਟੇਨਰ ਰੁਕ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਸਾਰਾ ਡੇਟਾ ਗੁਆਚ ਜਾਂਦਾ ਹੈ।

**ਡਿਵੈਲਪਰ:** ਓਲਡ ਸਿੰਗਲ-ਕੀ ਕਾਨਫਿਗਰੇਸ਼ਨ ਨੂੰ ਬਦਲਣ ਵਾਲੇ ਪਰਿਵਰਤਨਾਂ ਨੂੰ ਖਿੱਚਣ ਤੋਂ ਬਾਅਦ, ਜੇਕਰ ਤੁਹਾਡੀ ਸਥਾਨਕ ਫਾਈਲ ਹਟਾਏ ਗਏ ਫੀਲਡਾਂ (api_key, api_url, ਪ੍ਰੋਕਸੀ ਵਿਕਲਪ) ਵਰਤਦੀ ਹੈ, ਤਾਂ data/config.json ਨੂੰ src/config-defaults/config_default.json ਤੋਂ ਨਵੇਂ ਡਿਫਾਲਟ ਆਕਾਰ ਨਾਲ ਰੀਸੈੱਟ ਜਾਂ ਮਰਜ਼ ਕਰੋ।

<br/>

**ਵੈਬ ਪ੍ਰਮਾਣੀਕਰਨ:**

- ਮੂਲ ਐਡਮਿਨ: `admin` / `transrewrt26`।
- **ਸੈਟਿੰਗਜ਼ → ਯੂਜਰ** ਵਿੱਚ ਯੂਜਰ ਨੂੰ ਮੈਨੇਜ਼ ਕਰੋ।

- ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰੋ: `docker exec <container> reset-web-password '<username>' '<new-password>'`
  (ਸਰੋਤ ਤੋਂ: `pnpm run reset-web-password -- <username> <new-password>`)

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਕਿਸੇ ਵੀ ਨੈੱਟਵਰਕ-ਐਕਸੈੱਸਯੋਗ ਹੋਸਟ 'ਤੇ ਤੁਰੰਤ ਡਿਫਾਲਟ ਐਡਮਿਨ ਪਾਸਵਰਡ ਨੂੰ ਬਦਲੋ।

<br/>

ਕੀ-ਸੈਟਿੰਗਾਂ (ਫਾਂਟ, ਮਾਡਲ, ਭਾਸ਼ਾਵਾਂ, ਆਦਿ) ਐਪਲੀਕੇਸ਼ਨ ਸੈਟਿੰਗਜ਼ ਵਿੱਚ ਉਪਲਬਧ ਹਨ।
