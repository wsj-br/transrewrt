# Εγχειρίδιο Χρήσης

<br/>

<a id="introduction"></a>
## Εισαγωγή

Το Transrewrt σας βοηθά να εργαστείτε με κείμενο με τρεις βασικούς τρόπους:

- **Μετάφραση** - μετατροπή κειμένου από μια γλώσσα σε άλλη.
- **Αναδιατύπωση** - αναδιατύπωση κειμένου με διαφορετικό ύφος, όπως πιο σαφές, συνοπτικό ή επίσημο.
- **Μετασχηματισμός** - επεξεργασία κειμένου με προσαρμοσμένες οδηγίες Τεχνητής Νοημοσύνης που ονομάζονται prompts.

<br/>

Αυτό το εγχειρίδιο εξηγεί πώς να χρησιμοποιήσετε την εφαρμογή μόλις εγκατασταθεί και λειτουργεί. Για τα βήματα εγκατάστασης, ανατρέξτε στο κύριο **[README](README.el.md)**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το Transrewrt είναι διαθέσιμο ως εφαρμογή επιτραπεζίου για Windows και Linux και ως εφαρμογή ιστού που μπορεί να φιλοξενηθεί από τον ίδιο τον χρήστη. Αυτό το εγχειρίδιο επικεντρώνεται στην καθημερινή χρήση της εφαρμογής. Όταν κάτι ισχύει μόνο για μια έκδοση, αναφέρεται σαφώς.

<a id="before-you-start"></a>

## Πριν ξεκινήσετε

Για να χρησιμοποιήσετε το Transrewrt, χρειάζεστε πρόσβαση σε τουλάχιστον ένα πάροχο Τεχνητής Νοημοσύνης. Οι υποστηριζόμενοι πάροχοι είναι: [OpenRouter](https://openrouter.ai) (ο οποίος συγκεντρώνει πολλά μοντέλα), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI και [Ollama](https://ollama.com) για τοπικά μοντέλα.

Δεν χρειάζεται να επιλέξετε ένα χρεωστέο μοντέλο για να ξεκινήσετε. Αμέσως μόλις προσθέσετε το κλειδί API του OpenRouter, η εφαρμογή ενεργοποιεί αυτόματα μια ενσωματωμένη **δωρεάν** επιλογή OpenRouter. Αυτό σας επιτρέπει να ξεκινήσετε άμεσα τη μετάφραση, αναδιατύπωση και μετασχηματισμό κειμένου.

Με απλά λόγια:

- Ένα **μοντέλο** είναι ο κινητήρας Τεχνητής Νοημοσύνης που κάνει τη δουλειά. Τα μοντέλα παρουσιάζονται με **πρόθεμα παρόχου** (π.χ. `openrouter/…`, `openai/…`, `ollama/…`).
- Ένα **κλειδί API** (ή, για το Ollama, μια **βασική διεύθυνση URL**) είναι ο τρόπος με τον οποίο η εφαρμογή επικοινωνεί με τον πάροχο.

Αν χρησιμοποιείτε την **εφαρμογή επιτραπεζίου**, προσθέστε κλειδιά στο [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config) για κάθε πάροχο που χρησιμοποιείτε. Για χρήση μόνο του OpenRouter, δείτε [Πώς να αποκτήσετε ένα κλειδί API](#how-to-get-an-api-key-desktop-app) παρακάτω. Αν δεν θέλετε να χρησιμοποιήσετε κλειδί API, μπορείτε να εγκαταστήσετε το Ollama (από [ollama.com](https://ollama.com)) και να χρησιμοποιήσετε τοπικά μοντέλα αντί αυτού.

Αν χρησιμοποιείτε την **διαδικτυακή έκδοση**, ο διαχειριστής του διακομιστή ρυθμίζει τους παρόχους μέσω μεταβλητών περιβάλλοντος, επομένως κανονικά δεν θα εισάγετε εσείς τα κλειδιά API.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Πώς να αποκτήσετε ένα δωρεάν κλειδί API OpenRouter (εφαρμογή επιτραπεζίου)

Αν χρησιμοποιείτε την εφαρμογή επιτραπεζίου, ακολουθήστε τα εξής βήματα:

1. Μεταβείτε στη διεύθυνση [OpenRouter](https://openrouter.ai) μέσω του προγράμματος περιήγησης σας.
2. Δημιουργήστε λογαριασμό ή συνδεθείτε.
3. Ανοίξτε τη σελίδα [Keys](https://openrouter.ai/keys).
4. Πατήστε το κουμπί για να δημιουργήσετε ένα νέο κλειδί API.
5. Δώστε ένα όνομα στο κλειδί για να μπορείτε να το αναγνωρίσετε αργότερα.
6. Αντιγράψτε το νέο κλειδί API.
7. Επιστρέψτε στο Transrewrt και ανοίξτε το **Ρυθμίσεις** > **Διαμόρφωση API**.
8. Επικολλήστε το κλειδί στο πεδίο **Κλειδί API OpenRouter** (υπό τις **Ρυθμίσεις** > **Διαμόρφωση API**).
9. Πατήστε **Δοκιμή κλειδιού OpenRouter** για να βεβαιωθείτε ότι λειτουργεί.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Μπορείτε να ξεκινήσετε με τη δωρεάν διαδρομή του OpenRouter ή οποιοδήποτε άλλο δωρεάν μοντέλο διαθέσιμο, χωρίς να προσθέσετε πιστωτική κάρτα. Σε πολλές περιπτώσεις, αυτό είναι αρκετό για να ξεκινήσετε να χρησιμοποιείτε το Transrewrt χωρίς να επιλέξετε ένα χρεωστέο μοντέλο. Εναλλακτικά, μπορείτε να χρησιμοποιήσετε το Ollama για να εκτελέσετε μοντέλα τοπικά, χωρίς κλειδί API.

<br/><br/>

<a id="getting-started"></a>
## Ξεκινώντας

Αν αυτή είναι η πρώτη φορά που χρησιμοποιείτε το Transrewrt, ακολουθήστε αυτή τη σειρά:

1. Ανοίξτε την εφαρμογή.
2. Επιλέξτε τη **γλώσσα διεπαφής** από το εικονίδιο της γης, αν χρειάζεται.
3. Εάν χρησιμοποιείτε την **εφαρμογή επιτραπεζίου**, ανοίξτε [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config), προσθέστε ένα κλειδί API για τουλάχιστον ένα πάροχο (π.χ. OpenRouter) και πατήστε **Δοκιμή** για να επιβεβαιώσετε ότι λειτουργεί.
4. Ανοίξτε [**Ρυθμίσεις** > **Μοντέλα**](#models) και προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα μοντέλα**.
5. Ανοίξτε [**Ρυθμίσεις** > **Γλώσσες**](#languages) και επιλέξτε τις **Κορυφαίες γλώσσες** σας, αν θέλετε οι πιο συχνά χρησιμοποιούμενες γλώσσες σας να εμφανίζονται πρώτες.
6. Μεταβείτε στο **Μετάφραση** και εκτελέστε μία απλή μετάφραση για να επιβεβαιώσετε ότι όλα λειτουργούν.
7. Αφού δουλέψει αυτό, δοκιμάστε **Αναδιατύπωση** και στη συνέχεια **Μετασχηματισμός**.

Η σειρά αυτή έχει σημασία. Αποτρέπει το πιο συνηθισμένο πρόβλημα πρώτης χρήσης: την προσπάθεια εκτέλεσης αποστολής πριν η εφαρμογή έχει σύνδεση API ή επιλεγμένο μοντέλο.

### Εργαλειοθήκη

Η εργαλειοθήκη αλλάζει ελαφρώς ανάλογα με το πού βρίσκεστε στην εφαρμογή.

- Στα αριστερά, εμφανίζεται το όνομα της τρέχουσας σελίδας.
- Στα δεξιά, εμφανίζεται ο **επιλογέας μοντέλου** και ο έλεγχος της **γλώσσας διεπαφής**.

Ο **επιλογέας μοντέλου** σάς επιτρέπει να επιλέξετε ποιον μηχανή τεχνητής νοημοσύνης θα χρησιμοποιήσετε για την τρέχουσα εργασία.

  ![Επιλογέας μοντέλου](../images/screenshots/el/model-selector.png)

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Ορισμένα δωρεάν μοντέλα ενδέχεται να μην είναι πάντα διαθέσιμα — είναι δυνατό να είναι offline ή να έχουν όριο χρήσης. Σε αυτήν την περίπτωση, η εφαρμογή θα αφαιρέσει αυτόματα το μοντέλο από τη διαθέσιμη λίστα σας.<br/>
> Για να ελέγξετε ποια μοντέλα εμφανίζονται, πηγαίνετε στο [**Ρυθμίσεις** > **Μοντέλα**](#models) και επεξεργαστείτε τη λίστα μοντέλων σας.  
> Μπορείτε επίσης να ανοίξετε απευθείας τις ρυθμίσεις μοντέλου κάνοντας κλικ στο εικονίδιο παρόχου αριστερά από το όνομα του μοντέλου στην εργαλειοθήκη.

<br/>

Το **εικονίδιο της γης + κωδικός γλώσσας** αλλάζει τη γλώσσα της διεπαφής της εφαρμογής, όπως των μενού και των κουμπιών. **Δεν** αλλάζει όμως τις γλώσσες μετάφρασης που χρησιμοποιούνται στην ενότητα **Μετάφραση**.

  ![Επιλογέας γλώσσας διεπαφής](../images/screenshots/el/language-selector.png)

<a id="input-and-output-panels"></a>
### Πάνελ εισόδου και εξόδου

Οι περισσότεροι χώροι εργασίας χρησιμοποιούν ένα πάνελ **Εισόδου** στα αριστερά και ένα πάνελ **Εξόδου** στα δεξιά.

Το πάνελ **Εισόδου** εμφανίζει:

- Αριθμό χαρακτήρων
- Αριθμό λέξεων
- Αριθμό παραγράφων

Το πάνελ **Εξόδου** μπορεί να εμφανίζει:

- Πόσος χρόνος έκανε η εργασία
- Το κόστος της εργασίας (αν είναι διαθέσιμο)
- Συνολικό κόστος που έχετε μέχρι στιγμής
- **TPS** (tokens ανά δευτερόλεπτο)
- Αριθμό χαρακτήρων, λέξεων και παραγράφων
- Το μοντέλο που χρησιμοποιήθηκε

Αν έχετε απορίες για τους τεχνικούς όρους:

- **Token** σημαίνει ένα μικρό κομμάτι κειμένου. Μπορείτε να το δείτε ως μέρος μιας λέξης ή μια σύντομη λέξη.
- **TPS** σημαίνει πόσα από αυτά τα κομμάτια κειμένου επεξεργάστηκε το μοντέλο ανά δευτερόλεπτο.

<a id="translate"></a>
## Μετάφραση

Χρησιμοποιήστε την ενότητα **Μετάφραση** όταν θέλετε να μετατρέψετε κείμενο από μια γλώσσα σε κάποια άλλη.

![Χώρος εργασίας Μετάφρασης](../images/screenshots/el/translate.png)

<br/>

<a id="translate-text"></a>
### Μετάφραση κειμένου

1. Ανοίξτε την ενότητα **Μετάφραση**.
2. Επιλέξτε μια γλώσσα στο πεδίο **Από**.
3. Επιλέξτε μια γλώσσα στο πεδίο **Προς**.
4. Επιλέξτε ένα μοντέλο στην εργαλειοθήκη.
5. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Εισόδου**.
6. Πατήστε **Μετάφραση**.
7. Διαβάστε το αποτέλεσμα στο **Εξόδου**.
8. Χρησιμοποιήστε το κουμπί αντιγραφής αν θέλετε να αντιγράψετε το αποτέλεσμα.

<br/>

<a id="language-selection"></a>
### Επιλογή γλώσσας

- Το **Από** μπορεί να είναι συγκεκριμένη γλώσσα ή **Ανίχνευση γλώσσας**.
- Το **Προς** είναι η γλώσσα στην οποία θέλετε το αποτέλεσμα.

Οι επιλεγμένες **Κορυφαίες γλώσσες** εμφανίζονται στην αρχή της λίστας. Μπορείτε να τις ορίσετε στο [**Ρυθμίσεις** > **Γλώσσες**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Χρήσιμες ρυθμίσεις μετάφρασης

Στο [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings), μπορείτε να αλλάξετε τη συμπεριφορά της μετάφρασης:

- **Αυτόματη μετάφραση κατά την επικόλληση** εκτελεί αμέσως μετάφραση μόλις επικολλήσετε κείμενο.
- **Αυτόματο αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει το αποτέλεσμα αυτόματα μετά την επιτυχής εκτέλεση.
- **Μετάφραση σε πραγματικό χρόνο (κατά τη διάρκεια της πληκτρολόγησης)** εκτελεί μεταφράσεις ενώ πληκτρολογείτε.
- **Χρονοπεριορισμός (ms)** καθορίζει πόσος χρόνος περνάει μέχρι να εκτελεστεί μία μετάφραση σε πραγματικό χρόνο.

<br/>

<a id="keyboard-shortcuts"></a>
### Συντομεύσεις πληκτρολογίου

Στο [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings), το **Συμπεριφορά για ENTER** καθορίζει τι συμβαίνει όταν πατήσετε `Enter`:

- Το **Enter** μπορεί να εκτελεί την εργασία και το **Shift+Enter** να προσθέτει νέα γραμμή.
- Ή, η εφαρμογή μπορεί να κάνει το αντίθετο.

Η τρέχουσα λειτουργία εμφανίζεται επίσης και στο κουμπί **Μετάφραση**.

<a id="transform"></a>
## Μετατροπή

Χρησιμοποιήστε την επιλογή **Μετατροπή** όταν θέλετε το τεχνητό νοημοσύνη να ακολουθήσει ένα προσαρμοσμένο σύνολο οδηγιών.

![Χώρος εργασίας Μετατροπής](../images/screenshots/el/transform.png)

Αυτή είναι η πιο ευέλικτη περιοχή της εφαρμογής. Μπορείτε να τη χρησιμοποιήσετε για εργασίες όπως:

- σύντομη περίληψη σημειώσεων
- μετατροπή ασαφούς κειμένου σε επεξεργασμένο email
- εξαγωγή βασικών σημείων
- μετατροπή κειμένου σε συγκεκριμένη μορφή

<br/>

<a id="run-an-existing-prompt"></a>
### Εκτέλεση υπάρχουσας προτροπής

1. Ανοίξτε την επιλογή **Μετατροπή**.
2. Επιλέξτε μια προτροπή από τη λίστα προτροπών.
3. Αν εμφανιστεί το πλαίσιο **Γλώσσα στόχος**, επιλέξτε μια γλώσσα αν θέλετε.
4. Πληκτρολογήστε ή επικολλήστε κείμενο στο πεδίο **Είσοδος**.
5. Κάντε κλικ στο **Μετατροπή**.
6. Διαβάστε το αποτέλεσμα στο πεδίο **Έξοδος**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### Αν δεν έχετε ακόμη προτροπές

Αν η λίστα προτροπών είναι κενή, κάντε κλικ στο **Φόρτωση δειγμάτων προτροπών**. Με αυτό προστίθενται ενσωματωμένα παραδείγματα, ώστε να μπορείτε να ξεκινήσετε γρήγορα.

<br/>

> ℹ️ **ΣΗΜΕΊΩΣΗ**<br/>
> Τα δειγματικά προτρέπονται παρέχονται στα Αγγλικά. Μετά τη φόρτωσή τους, μπορείτε να επεξεργαστείτε μια προτροπή και να χρησιμοποιήσετε την επιλογή **Μετάφραση προτροπής** για να τη μεταφράσετε στη γλώσσα σας.

<br/>

<a id="create-a-prompt-quickly"></a>
### Δημιουργία προτροπής γρήγορα

Ο πιο γρήγορος τρόπος δημιουργίας μιας προτροπής είναι ο ακόλουθος:

1. Κάντε κλικ στο **Νέα προτροπή**.
2. Κάντε κλικ στο **Δημιουργία προτροπής**.
3. Περιγράψτε το τι θέλετε να κάνει η προτροπή.
4. Επιλέξτε ένα μοντέλο.
5. Αφήστε την εφαρμογή να δημιουργήσει ένα προσχέδιο για εσάς.
6. Διερευνήστε το προσχέδιο και κάντε κλικ στο **Αποθήκευση**.

![Δημιουργία προτροπής](../images/screenshots/el/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### Επεξεργασία προτροπής

Όταν δημιουργείτε ή επεξεργάζεστε μια προτροπή, ο επεξεργαστής εμφανίζεται στα αριστερά και μια περιοχή δοκιμής εμφανίζεται στα δεξιά.

![Επεξεργαστής προτροπής Μετατροπής](../images/screenshots/el/transform-prompt-edit.png)

Τα κύρια πεδία είναι:

- **Όνομα προτροπής**: το όνομα που εμφανίζεται στη λίστα προτροπών.
- **Οδηγίες προτροπής (προαιρετικό)**: μια σύντομη υπόδειξη που εμφανίζεται στον χρήστη κατά την εκτέλεση της προτροπής.
- **Ρόλος μοντέλου**: ο γενικός ρόλος που ανατίθεται στην τεχνητή νοημοσύνη, όπως «Είστε ένας βοηθητικός βοηθός».
- **Οδηγίες μοντέλου (μία ανά γραμμή)**: οι συγκεκριμένοι κανόνες που θέλετε να ακολουθήσει η τεχνητή νοημοσύνη.
- **Περιγραφή εξόδου**: μια σύντομη λέξη που περιγράφει το αποτέλεσμα, όπως «περίληψη» ή «ανασύνταξη».
- **Θερμοκρασία (0.0 → 1.0)**: το πώς θα συμπεριφέρεται το μοντέλο· δείτε παρακάτω.
- **Ερώτηση για γλώσσα στόχο**: προσθέτει έναν επιλογέα γλώσσας στόχος όταν εκτελείται η προτροπή.

Αν ο τεχνικός όρος **Θερμοκρασία** είναι άγνωστος σε σας, σκεφτείτε τον ως εξής:

- Μια **χαμηλότερη** θερμοκρασία δίνει πιο σταθερά και προβλέψιμα αποτελέσματα.
- Μια **υψηλότερη** θερμοκρασία δίνει μεγαλύτερη ποικιλία και δημιουργικότητα.

Μπορείτε επίσης να χρησιμοποιήσετε:

- **`Δημιουργία προτροπής`** για τη δημιουργία νέου προσχεδίου από μια απλή περιγραφή
- **`Βελτίωση προτροπής`** για τη διαμόρφωση μιας υπάρχουσας προτροπής
- **`Μετάφραση προτροπής`** για τη μετάφραση των πεδίων της προτροπής

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Κάντε κλικ στο **`Αποθήκευση`** πριν κάνετε κλικ στο **`Πίσω στην εκτέλεση`**. Αν επιστρέψετε πίσω χωρίς να αποθηκεύσετε, οι αλλαγές σας θα χαθούν.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### Δοκιμή μιας προτροπής πριν τη χρήση της

Η περιοχή δοκιμής στα δεξιά σας επιτρέπει να δοκιμάσετε την προτροπή σας με δειγματικό κείμενο πριν τη χρησιμοποιήσετε στην καθημερινή εργασία σας.

Αυτό είναι χρήσιμο όταν:

- δημιουργείτε μια νέα προτροπή
- συγκρίνετε δύο εκδόσεις μιας προτροπής
- θέλετε να ελέγξετε τον τόνο, το μήκος ή τη μορφή εξόδου

<br/>

<a id="manage-saved-prompts"></a>
### Διαχείριση αποθηκευμένων προτροπών

Για να διαχειριστείτε αποθηκευμένες προτροπές σε ένα και μόνο σημείο, ανοίξτε τις [**Ρυθμίσεις** > **Προτροπές Μετατροπής**](#transform-prompts).

Εκεί μπορείτε:

- να καταλογίσετε και να διαγράψετε τις προτροπές σας
- να εξαγάγετε προτροπές ως **JSON**, **CSV** ή **XLSX**
- να εισαγάγετε προτροπές από αρχείο

<a id="general-settings"></a>

### Γενικές ρυθμίσεις

Χρησιμοποιήστε τις **Γενικές Ρυθμίσεις** για να ελέγξετε τη συμπεριφορά πληκτρολόγησης, αν αποθηκεύονται λεπτομέρειες εκτέλεσης στο **Ιστορικό** και την εμφάνιση.

**Συμπεριφορά**

- **Συμπεριφορά για το ENTER** επιλέγει αν το `Enter` εκτελεί την εργασία ή εισάγει νέα γραμμή.
- **Αυτόματη μετάφραση κατά την επικόλληση** ξεκινά τη μετάφραση μόλις επικολλήσετε κείμενο.
- **Αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει αυτόματα τα επιτυχημένα αποτελέσματα.
- **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** μεταφράζει καθώς πληκτρολογείτε.
- **Χρονικό όριο (ms)** καθορίζει τον χρόνο αναμονής για τη μετάφραση σε πραγματικό χρόνο.

**Ιστορικό**

- **Διατήρηση ιστορικού εκτέλεσης** ελέγχει αν κάθε μετάφραση, αναδιατύπωση και μετασχηματισμός αποθηκεύει **είσοδο και έξοδο κειμένου** για την προβολή [**Ιστορικό**](#history) στην πλευρική στήλη. Απενεργοποιώντας το, θα σας ζητηθεί επιβεβαίωση· αν επιβεβαιώσετε, τα αποθηκευμένα κείμενα θα διαγραφούν από τη βάση δεδομένων.
- **Διαγραφή δεδομένων ιστορικού** σας επιτρέπει να διαγράψετε αποθηκευμένα κείμενα με βάση την ηλικία (π.χ. παλαιότερα από μερικούς μήνες ή **όλα τα δεδομένα (εκκαθάριση)**) μέσω της επιλογής **Διαγραφή δεδομένων**. Αυτό επηρεάζει μόνο τα αποθηκευμένα κείμενα εκτέλεσης για την προβολή **Ιστορικό**· **ΔΕΝ** διαγράφει τα συνολικά ποσά κόστους ή χρήσης. Για να διαγράψετε ή να ελαχιστοποιήσετε τα δεδομένα **κόστους**, χρησιμοποιήστε [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking).

**Εμφάνιση**

- **Δεκαδικά ψηφία κόστους** αλλάζει πώς εμφανίζονται τα δεκαδικά του κόστους.
- **Μόνο web:** **εμφάνιση περιθωρίου γύρω από την εφαρμογή** προσθέτει επιπλέον χώρο γύρω από τη διεπαφή.
- **Οικογένεια γραμματοσειράς** αλλάζει τη γραμματοσειρά στα πλαίσια κειμένου.
- **Μέγεθος** αλλάζει το μέγεθος της γραμματοσειράς.


<br/>

<a id="models"></a>
### Μοντέλα

Χρησιμοποιήστε **Ρυθμίσεις** > **Μοντέλα** για να επιλέξετε ποια μοντέλα εμφανίζονται στη γραμμή εργαλείων.

![Καρτέλα Ρυθμίσεων Μοντέλων](../images/screenshots/el/settings-models.png)

Η σελίδα έχει δύο λίστες:

- **Διαθέσιμα Μοντέλα** στα αριστερά
- **Επιλεγμένα Μοντέλα** στα δεξιά

Χρήσιμα στοιχεία ελέγχου περιλαμβάνουν:

- **Αναζήτηση μοντέλων…** για να βρείτε ένα μοντέλο με βάση το όνομα
- Ετικέτες **Πάροχος** για να περιορίσετε τη λίστα σε ένα μηχανισμό (OpenRouter, OpenAI, Ollama, …)
- **Μόνο Δωρεάν** για να δείτε μόνο δωρεάν μοντέλα
- **Ανανέωση** για επαναφόρτωση της λίστας
- **Ανάπτυξη Όλων** και **Σύμπτυξη Όλων** όταν ταξινομείτε με βάση το πάροχο

Τα αναγνωριστικά μοντέλων περιλαμβάνουν το πρόθεμα του παρόχου (π.χ. `openrouter/…` έναντι `openai/…`). Ετικέτες όπως **OpenAI (OpenRouter)** έναντι **OpenAI (άμεσα)** δείχνουν πώς δρομολογείται η κίνηση.

Ενέργειες:

 - Για να προσθέσετε μοντέλο, κάντε κλικ στο **Προσθήκη** ή οπουδήποτε στην καταχώριση.

 - Για να αφαιρέσετε μοντέλο, κάντε κλικ στο **X** δίπλα του στην ενότητα **Επιλεγμένα Μοντέλα** ή στο **Επιλεγμένο** μέσα στην καταχώριση στην ενότητα Διαθέσιμα Μοντέλα.

 - Για να καθαρίσετε τη λίστα, κάντε κλικ στο **Αποεπιλογή όλων**. Το απαιτούμενο δωρεάν μοντέλο θα παραμείνει στη λίστα.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Εάν δεν επιθυμείτε να προσθέσετε πιστώσεις στο OpenRouter αμέσως, ξεκινήστε ενεργοποιώντας το **Μόνο Δωρεάν** και επιλέγοντας τα δωρεάν μοντέλα (δεν απαιτείται κάρτα πιστωτικού). Μπορείτε επίσης να χρησιμοποιήσετε το Ollama για να εκτελέσετε μοντέλα τοπικά χωρίς κλειδί API.

<br/>

<a id="languages"></a>
### Γλώσσες

Χρησιμοποιήστε **Ρυθμίσεις** > **Γλώσσες** για να οργανώσετε τις λίστες γλωσσών που χρησιμοποιούνται στην εφαρμογή.

- Οι **Κορυφαίες γλώσσες** αναρτώνται κοντά στην κορυφή των λιστών γλωσσών στις ενότητες **Μετάφραση** και **Μετασχηματισμός**.
- **Προσαρμοσμένη γλώσσα** σας επιτρέπει να προσθέσετε γλώσσα που δεν υπάρχει στην ενσωματωμένη λίστα.

Αν προσθέσετε μια προσαρμοσμένη γλώσσα, θα εμφανίζεται στους επιλογείς γλωσσών δίπλα στις ενσωματωμένες επιλογές.

<a id="cost-tracking"></a>
### Παρακολούθηση κόστους

Χρησιμοποιήστε **Ρυθμίσεις** > **Παρακολούθηση Κόστους** για να διαχειριστείτε πληροφορίες κόστους.

- **Συνολικό Κόστος** δείχνει το τρέχον σύνολο.
- **Αντιγραφή Τιμής** αντιγράφει το σύνολο στο πρόχειρο.
- **Επαναφορά Κόστους** μηδενίζει το αποθηκευμένο σύνολο.
- **Συγχρονισμός με τη χρήση κλειδιού API** ορίζει το σύνολο να ταιριάζει με τη χρήση που αναφέρεται από τον λογαριασμό OpenRouter σας (μόνο OpenRouter).
- **Χρήση Κλειδιού API** δείχνει λεπτομέρειες χρήσης OpenRouter, αν είναι διαθέσιμες.
- **Διαγραφή δεδομένων κόστους** διαγράφει όλα τα δεδομένα ή μόνο εγγραφές παλαιότερες από μια επιλεγμένη ημερομηνία.


**Παρακολούθηση κόστους:** Όταν χρησιμοποιείτε μοντέλα OpenRouter, η εφαρμογή δείχνει την πραγματική σας χρήση και δαπάνη με βάση δεδομένα από το OpenRouter. Για όλους τους άλλους παρόχους, η εφαρμογή εκτιμά το κόστος χρησιμοποιώντας τιμές που δημοσιεύονται από το OpenRouter· αν δεν υπάρχει διαθέσιμη τιμή, η εκτίμηση μπορεί να είναι μηδέν.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
>  **Όλα τα ποσά κόστους είναι εκτιμήσεις μόνο για αναφορά σας, όχι επίσημες τιμολογιώσεις.**


<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Η διαγραφή δεδομένων δεν μπορεί να αναιρεθεί. Πριν τη διαγραφή, βεβαιωθείτε ότι έχετε δημιουργήσει αντίγραφο ασφαλείας ή τα έχετε εξαγάγει μέσω της επιλογής [**Πίνακας Ελέγχου** > **Όλες οι Κλήσεις**](#dashboard-tabs), διαφορετικά θα χαθούν οριστικά. <br/> 
> Όλο το ιστορικό σχετικό με κάθε καταχώριση κλήσης API θα διαγραφεί επίσης.

- διαγράψετε προτροπές

Χρησιμοποιήστε την επιλογή **Χρήστες** για να διαχειριστείτε λογαριασμούς χρηστών στην έκδοση ιστού. Μπορείτε να προσθέτετε χρήστες, να ενημερώνετε τα στοιχεία τους, να επαναφέρετε κωδικούς πρόσβασης και να διαγράφετε λογαριασμούς.

<a id="api-config"></a>
### Διαμόρφωση API

Οι υποστηριζόμενοι πάροχοι είναι: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI και **Ollama** (τοπικά μοντέλα μέσω βασικού URL). Πρέπει να διαμορφώσετε μόνο τους παρόχους που χρησιμοποιείτε.

**Εφαρμογή ιστού: μόνο διαχειριστής**

Οι κλείδες API διαμορφώνονται μέσω μεταβλητών περιβάλλοντος στο σύστημα ή σε Docker — δεν εισάγονται στο διεπαφή ιστού. Αυτή η σελίδα δείχνει ποιοι πάροχοι έχουν διαμορφωμένη κλειδί και σας επιτρέπει να ελέγξετε κάθε έναν κάνοντας κλικ στο κουμπί **`Δοκιμή`**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Για να αλλάξετε μια κλειδί API, ενημερώστε τη μεταβλητή περιβάλλοντος στη ρύθμιση του συστήματός σας ή του Docker και επανεκκινήστε τον διακομιστή ή το δοχείο.

<br/>

**Εφαρμογή γραφείου**

Χρησιμοποιήστε την επιλογή **Διαμόρφωση API** για να αποθηκεύσετε τα κλειδιά API για κάθε πάροχο που χρησιμοποιείτε. Για το Ollama, εισάγετε το **βασικό URL** αντί για κλειδί API.

<br/>

> 💡 **Συμβουλή** <br/>
> Εάν δεν θέλετε να χρησιμοποιήσετε κλειδί API ή να πληρώσετε για χρήση, μπορείτε να [κατεβάσετε το Ollama](https://ollama.com) και να εκτελείτε μοντέλα τοπικά στον υπολογιστή σας δωρεάν. Εναλλακτικά, μπορείτε να δημιουργήσετε δωρεάν λογαριασμό στο OpenRouter (χωρίς ανάγκη για πιστωτική κάρτα) για να χρησιμοποιήσετε τα δωρεάν μοντέλα τους.

- Προσθέστε μόνο τους παρόχους που χρειάζεστε. Στις **Ρυθμίσεις** > **Μοντέλα**, κάθε αναγνωριστικό μοντέλου ξεκινά με τον πάροχο (π.χ. `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Για την προσθήκη κλειδιού API, πληκτρολογήστε την τιμή στο πεδίο κειμένου και κάντε κλικ στο **`Αποθήκευση`**. Για αντικατάσταση υπάρχοντος κλειδιού, κάντε κλικ στο **`Επεξεργασία`**. Για να ελέγξετε αν ένα κλειδί λειτουργεί, κάντε κλικ στο **`Δοκιμή`**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Δεν μπορείτε να δείτε την τρέχουσα τιμή ενός κλειδιού API. Μπορείτε μόνο να το αντικαταστήσετε χρησιμοποιώντας το κουμπί **`Επεξεργασία`**.
> Τα κλειδιά API αποθηκεύονται κρυπτογραφημένα στο αρχείο ρυθμίσεων.

<br/>

Για λεπτομερείς οδηγίες σχετικά με τη λήψη κλειδιού OpenRouter, δείτε [Πώς να λάβετε ένα κλειδί API](#how-to-get-an-api-key-desktop-app) παραπάνω.

<a id="common-issues"></a>
## Συνηθισμένα προβλήματα

Αν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα τα παρακάτω σημεία.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Η εφαρμογή δεν μεταφράζει, ανασυγγράφει ή μετατρέπει κείμενο

Ελέγξτε αν:

- έχετε επιλέξει ένα μοντέλο στη γραμμή εργαλείων
- έχει καταχωρηθεί τουλάχιστον ένα μοντέλο στις [**Ρυθμίσεις** > **Μοντέλα**](#models)
- η ρύθμιση API σας λειτουργεί σωστά

Αν χρησιμοποιείτε την εφαρμογή γραφείου:

1. Ανοίξτε τις [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config).
2. Ελέγξτε αν έχει αποθηκευτεί τουλάχιστον ένα κλειδί API.
3. Κάντε κλικ στο **Δοκιμή** δίπλα στον πάροχο για επιβεβαίωση ότι το κλειδί λειτουργεί.

<br/>

<a id="the-model-list-is-empty"></a>
### Η λίστα μοντέλων είναι κενή

Ανοίξτε τις [**Ρυθμίσεις** > **Μοντέλα**](#models) και κάντε κλικ στο **Ανανέωση**.

Αν χρειαστεί:

- αναζητήστε ένα μοντέλο
- ενεργοποιήστε το **Μόνο δωρεάν**
- προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα Μοντέλα**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Το αποτέλεσμα είναι πολύ αργό ή πολύ ακριβό

Δοκιμάστε ένα ή περισσότερα από τα εξής:

- επιλέξτε διαφορετικό μοντέλο
- χρησιμοποιήστε μικρότερο κείμενο εισόδου
- απενεργοποιήστε τη **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** στις [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings)
- χρησιμοποιήστε δωρεάν μοντέλα για απλές εργασίες (δείτε [Μοντέλα](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Η διεπαφή είναι σε λάθος γλώσσα

Κάντε κλικ στο εικονίδιο γης στη [γραμμή εργαλείων](#toolbar) και επιλέξτε την επιθυμητή **Γλώσσα διεπαφής**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Το κείμενο είναι πολύ μικρό ή δύσκολο για ανάγνωση

Ανοίξτε [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings) και αλλάξτε:

- **Οικογένεια γραμματοσειράς**
- **Μέγεθος**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Τα γραφήματα του ταμπλό είναι κενά

Αυτό είναι φυσιολογικό αν:

- χρησιμοποιείτε μόνο **δωρεάν μοντέλα** (τα γραφήματα κόστους θα είναι κενά)
- ο επιλεγμένος **φίλτρο χρόνου** δεν καλύπτει την περίοδο όπου έγιναν κλήσεις — δοκιμάστε το **Όλα** για να ελέγξετε

Αν τα γραφήματα παραμένουν κενά μετά την επιλογή **Όλα**, επιβεβαιώστε ότι οι κλήσεις εμφανίζονται στο [**Ιστορικό**](#history) ή στην καρτέλα **Όλες οι κλήσεις**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### Το κόστος εμφανίζεται ως "μη διαθέσιμο" ή φαίνεται λανθασμένο

Όταν χρησιμοποιείτε μοντέλα μέσω **OpenRouter**, η εφαρμογή εμφανίζει την πραγματική σας δαπάνη που αναφέρει το OpenRouter.

Για **άλλους παρόχους** (άμεσα OpenAI, άμεσα Anthropic, κ.λπ.), το κόστος εκτιμάται βάσει των τιμολογιακών δεδομένων που δημοσιεύει το OpenRouter. Εάν δεν βρεθεί αντίστοιχη τιμή για ένα μοντέλο, το κόστος θα εμφανιστεί ως **μη διαθέσιμο** και δεν θα προστεθεί στο συνολικό σας ποσό.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Το συνολικό κόστος δεν ταιριάζει με το λογαριασμό του παρόχου μου

Όλα τα στοιχεία κόστους στην εφαρμογή είναι **εκτιμήσεις για αναφορά μόνο**, όχι επίσημες χρεώσεις.

Για να είναι το σύνολο πιο κοντά στην πραγματική σας δαπάνη στο OpenRouter, ανοίξτε το [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking) και πατήστε **Συγχρονισμός με τη χρήση του API key**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Η σελίδα Ιστορικό λείπει από την πλευρική μπάρα

Η επιλογή **Διατήρηση ιστορικού εκτέλεσης** μπορεί να είναι απενεργοποιημένη. Ανοίξτε το [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings) και ενεργοποιήστε την. Σημειώστε ότι η ενεργοποίησή της δεν αποκαθιστά τα προηγούμενα δεδομένα του ιστορικού που διαγράφηκαν.

<br/>

<a id="web-app-session-expired"></a>
### Ιστολογική εφαρμογή: ανακατεύθυνση στη σελίδα σύνδεσης απροσδόκητα

Η σύνοδός σας μπορεί να έχει λήξει. Συνδεθείτε ξανά. Εάν συμβαίνει συχνά, ελέγξτε τη ρύθμιση του διακομιστή για τη διάρκεια της συνόδου.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### Η κεντρική πινακίδα δεν εμφανίζει δεδομένα για άλλους χρήστες (ιστολογική εφαρμογή)

Μόνο οι **διαχειριστές** μπορούν να βλέπουν δεδομένα από όλους τους χρήστες μέσω του φίλτρου **Χρήστης**. Οι κανονικοί χρήστες βλέπουν μόνο τη δική τους δραστηριότητα από σχεδιασμό.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Άλλαξα μία ερώτηση και χάθηκαν οι επεξεργασίες

Όταν επεξεργάζεστε μία ερώτηση, πάντα κάντε κλικ στο **Αποθήκευση** πριν κάνετε κλικ στο **Επιστροφή στην εκτέλεση**.

<a id="quick-tips"></a>
## Γρήγορες συμβουλές

- Ξεκινήστε με το [**Μετάφραση**](#translate) για να βεβαιωθείτε ότι η διαμόρφωσή σας λειτουργεί πριν προχωρήσετε στο [**Αναδιατύπωση**](#rewrite) ή [**Μετασχηματισμό**](#transform).
- Χρησιμοποιήστε το [**Αναδιατύπωση**](#rewrite) για καθημερινές βελτιώσεις διατύπωσης.
- Χρησιμοποιήστε το [**Μετασχηματισμό**](#transform) όταν χρειάζεστε ένα επαναλαμβανόμενο ροής εργασιών για μία συγκεκριμένη εργασία.
- Χρησιμοποιήστε το [**Κεντρική Πινακίδα**](#dashboard) αν θέλετε να παρακολουθείτε τη χρήση και το κόστος.
- Χρησιμοποιήστε το [**Ιστορικό**](#history) για να επισκοπήσετε προηγούμενες ενέργειες και το πλήρες κείμενο εισόδου/εξόδου τους.
- Εξάγετε τις ερωτήσεις σας τακτικά αν δημιουργείτε μία βιβλιοθήκη ερωτήσεων που θέλετε να διαφυλάξετε (δείτε [Μετασχηματισμός Ερωτήσεων](#transform-prompts)) ή αν θέλετε να τη μοιραστείτε με άλλους.
