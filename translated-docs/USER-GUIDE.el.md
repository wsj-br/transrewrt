# Οδηγός Χρήστη Transrewrt

<br />

<a id="introduction"></a>
## Εισαγωγή

Το Transrewrt σας βοηθά να εργάζεστε με κείμενο με τρεις κύριους τρόπους:

- **Μετάφραση** - μετατροπή κειμένου από μια γλώσσα σε άλλη.
- **Αναδιατύπωση** - διατύπωση ξανά κειμένου σε διαφορετικό στιλ, όπως πιο καθαρό, πιο σύντομο ή πιο επίσημο.
- **Μετατροπή** - επεξεργασία κειμένου χρησιμοποιώντας προσαρμοσμένες οδηγίες AI, τα λεγόμενα προμόπτους.

<br />

Αυτός ο οδηγός εξηγεί πώς να χρησιμοποιήσετε την εφαρμογή μόλις εγκατασταθεί και λειτουργήσει. Για τα βήματα εγκατάστασης, δείτε το κύριο [README](../README.md).

<br />

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το Transrewrt διατίθεται ως εφαρμογή επιφάνειας εργασίας για Windows και Linux, καθώς και ως αυτοφιλοξενημένη εφαρμογή ιστού. Αυτός ο οδηγός επικεντρώνεται στη συνήθη χρήση της εφαρμογής. Όταν κάτι ισχύει μόνο για μια έκδοση, σημειώνεται ξεκάθαρα.

<a id="before-you-start"></a>

## Πριν ξεκινήσετε

Για να χρησιμοποιήσετε το Transrewrt, χρειάζεστε πρόσβαση στην υπηρεσία AI μέσω του OpenRouter.

Δεν χρειάζεται να επιλέξετε ένα πληρωτέο μοντέλο πριν ξεκινήσετε. Η εφαρμογή περιλαμβάνει πάντα ένα ενσωματωμένο **δωρεάν** μοντέλο, οπότε για κανονική χρήση αυτό είναι αρκετό για να αρχίσετε να μεταφράζετε, επαναδιατυπώνετε και μετασχηματίζετε κείμενο.

Με απλά λόγια:

- Ένα **μοντέλο** είναι η μηχανή AI που κάνει τη δουλειά.
- Ένα **κλειδί API** είναι τα προσωπικά σας διαπιστευτήρια πρόσβασης για αυτήν την υπηρεσία.

Εάν χρησιμοποιείτε την **εφαρμογή desktop**, θα χρειαστείτε ένα κλειδί API. Για λεπτομερή βήματα, δείτε [Πώς να αποκτήσετε κλειδί API](#how-to-get-an-api-key-desktop-app) παρακάτω. Εν συντομία: δημιουργήστε λογαριασμό στο [OpenRouter](https://openrouter.ai), ανοίξτε τη σελίδα [Keys](https://openrouter.ai/keys), δημιουργήστε ένα νέο κλειδί και επικολλήστε το στο [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config) στο Transrewrt.

Εάν χρησιμοποιείτε την **ιστότοπο έκδοση**, συνήθως ο ιδιοκτήτης του διακομιστή το ρυθμίζει για εσάς, οπότε συνήθως δεν θα χρειαστεί να εισαγάγετε το κλειδί API μόνοι σας.

<br />

<a id="how-to-get-an-api-key-desktop-app"></a>
### Πώς να αποκτήσετε κλειδί API (εφαρμογή desktop)

Εάν χρησιμοποιείτε την εφαρμογή desktop, ακολουθήστε αυτά τα βήματα:

1. Μεταβείτε στο [OpenRouter](https://openrouter.ai) στο πρόγραμμα περιήγησης.
2. Δημιουργήστε λογαριασμό ή συνδεθείτε.
3. Ανοίξτε τη σελίδα [Keys](https://openrouter.ai/keys).
4. Κάντε κλικ στο κουμπί για να δημιουργήσετε ένα νέο κλειδί API.
5. Δώστε στο κλειδί ένα όνομα για να το αναγνωρίσετε αργότερα.
6. Αντιγράψτε το νέο κλειδί API.
7. Επιστρέψτε στο Transrewrt και ανοίξτε **Ρυθμίσεις** > **Διαμόρφωση API**.
8. Επικολλήστε το κλειδί στο **OpenRouter API Key**.
9. Κάντε κλικ στο **Test API Configuration** για να βεβαιωθείτε ότι λειτουργεί.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Μπορείτε να ξεκινήσετε με τη δωρεάν διαδρομή του OpenRouter ή οποιοδήποτε από τα άλλα δωρεάν μοντέλα που είναι διαθέσιμα. Σε πολλές περιπτώσεις, αυτό είναι αρκετό για να αρχίσετε να χρησιμοποιείτε το Transrewrt χωρίς να επιλέξετε πληρωτέο μοντέλο.

<a id="getting-started"></a>
## Ξεκινώντας

Εάν είστε νέος χρήστης του Transrewrt, ακολουθήστε αυτή τη σειρά:

1. Ανοίξτε την εφαρμογή.
2. Επιλέξτε τη **Γλώσσα διεπαφής** σας από το εικονίδιο του γλώσσας globe αν χρειαστεί.
3. Εάν βρίσκεστε στην **εφαρμογή desktop**, ανοίξτε [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config), επικολλήστε το κλειδί OpenRouter API σας και κάντε κλικ στο **Test API Configuration**.
4. Ανοίξτε [**Ρυθμίσεις** > **Μοντέλα**](#models) και προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα Μοντέλα**.
5. Ανοίξτε [**Ρυθμίσεις** > **Γλώσσες**](#languages) και επιλέξτε τις **Κύριες γλώσσες** σας αν θέλετε οι πιο συχνά χρησιμοποιούμενες γλώσσες να εμφανίζονται πρώτες.
6. Πηγαίνετε στο **Μετάφραση** και τρέξτε μια απλή μετάφραση για να επιβεβαιώσετε ότι όλα λειτουργούν.
7. Μόλις δουλέψει, δοκιμάστε το **Επαναδιατύπωση** και μετά το **Μετασχηματισμό**.

Αυτή η σειρά έχει σημασία. Αποφεύγει το πιο συνηθισμένο πρόβλημα κατά την πρώτη χρήση: προσπάθεια εκτέλεσης μιας εργασίας πριν η εφαρμογή έχει μια λειτουργική σύνδεση API ή ένα επιλεγμένο μοντέλο.

### Γραμμή εργαλείων

Η γραμμή εργαλείων αλλάζει ελαφρώς ανάλογα με το πού βρίσκεστε στην εφαρμογή.

- Στα αριστερά, εμφανίζει το όνομα της τρέχουσας σελίδας.
- Στα δεξιά, εμφανίζει τον **επιλογέα μοντέλου** και το **έλεγχο γλώσσας διεπαφής**.

Ο **επιλογέας μοντέλου** σας επιτρέπει να επιλέξετε ποια μηχανή AI θα χρησιμοποιηθεί για την τρέχουσα εργασία.

  ![Επιλογέας μοντέλου](../images/screenshots/el/model-selector.png)

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Μερικά δωρεάν μοντέλα μπορεί να σταματήσουν να λειτουργούν προσωρινά αν δεν είναι διαθέσιμα ή έχουν φτάσει σε όριο χρήσης. Αν συμβεί αυτό, η εφαρμογή θα αφαιρέσει αυτόματα το μοντέλο από τη λίστα σας.

Το **εικονίδιο globe + κωδικός γλώσσας** αλλάζει τη γλώσσα διεπαφής της εφαρμογής, όπως τα μενού και τα κουμπιά. **Δεν** αλλάζει τις γλώσσες μετάφρασης που χρησιμοποιούνται στο **Μετάφραση**.

<a id="input-and-output-panels"></a>

### Πλαίσια εισόδου και εξόδου

Τα περισσότερα χώρους εργασίας χρησιμοποιούν ένα **πλαίσιο εισόδου** αριστερά και ένα **πλαίσιο εξόδου** δεξιά.

Το **πλαίσιο εισόδου** εμφανίζει:

- Αριθμό χαρακτήρων
- Αριθμό λέξεων
- Αριθμό παραγράφων

Το **πλαίσιο εξόδου** μπορεί να εμφανίζει:

- Πόσο χρόνο διήρκεσε η εργασία
- Το κόστος αυτής της εργασίας
- Το συνολικό σας κόστος
- **TPS** (διαacciums ανά δευτερόλεπτο), που είναι μια απλή μέτρηση ταχύτητας
- Μετρήσεις χαρακτήρων, λέξεων και παραγράφων
- Το μοντέλο που χρησιμοποιήθηκε

Αν αναρωτιέστε για τους τεχνικούς όρους:

- **Token** σημαίνει ένα μικρό κομμάτι κειμένου. Μπορείτε να το σκέφτεστε ως μέρος μιας λέξης ή μια σύντομη λέξη.
- **TPS** σημαίνει πόσα από αυτά τα μικρά κομμάτια κειμένου επεξεργάστηκε το μοντέλο ανά δευτερόλεπτο.

<a id="translate"></a>
## Μετάφραση

Χρησιμοποιήστε **Μετάφραση** όταν θέλετε να μετατρέψετε κείμενο από μια γλώσσα σε άλλη.

![Χώρος εργασίας Μετάφρασης](../images/screenshots/el/translate.png)

<br />

<a id="translate-text"></a>
### Μετάφραση κειμένου

1. Ανοίξτε **Μετάφραση**.
2. Επιλέξτε μια γλώσσα στο **Από**.
3. Επιλέξτε μια γλώσσα στο **Σε**.
4. Επιλέξτε ένα μοντέλο στη γραμμή εργαλείων.
5. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Είσοδος**.
6. Κάντε κλικ στο **Μετάφραση**.
7. Διαβάστε το αποτέλεσμα στην **Έξοδος**.
8. Χρησιμοποιήστε το κουμπί αντιγραφής αν θέλετε να αντιγράψετε το αποτέλεσμα.

<br />

<a id="language-selection"></a>
### Επιλογή γλώσσας

- Το **Από** μπορεί να είναι μια συγκεκριμένη γλώσσα ή **Ανίχνευση γλώσσας**.
- Το **Σε** είναι η γλώσσα στην οποία θέλετε το αποτέλεσμα.

Οι επιλεγμένες σας **Κορυφαίες γλώσσες** εμφανίζονται στο επάνω μέρος της λίστας. Μπορείτε να τις ορίσετε στις [**Ρυθμίσεις** > **Γλώσσες**](#languages).

<br />

<a id="helpful-translation-settings"></a>
### Χρήσιμες ρυθμίσεις μετάφρασης

Στις [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings), μπορείτε να αλλάξετε τον τρόπο λειτουργίας της μετάφρασης:

- **Αυτόματη μετάφραση upon επικόλλησης** εκτελεί μια μετάφραση άμεfica μόλις επικολλήσετε κείμενο.
- **Αυτόματη αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει το αποτέλεσμα αυτόματα μετά από μια επιτυχή εκτέλεση.
- **Πραγματικούς χρόνου μετάφραση (κατά τη διάρκεια πληκτρολόγησης)** εκτελεί μεταφράσεις καθώς πληκτρολογείτε.
- **Χρονικό όριο (ms)** ελέγχει πόσο καιρό περιμένει η εφαρμογή πριν εκτελέσει μια μετάφραση σε πραγματικό χρόνο.

<br />

<a id="keyboard-shortcuts"></a>
### Συντομεύσεις πληκτρολογίου

Στις [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings), η **Συμπεριφορά για το ENTER** ελέγχει τι συμβαίνει όταν πατήσετε το Enter:

- Το **Enter** μπορεί να εκτελεί την εργασία και το **Shift+Enter** μπορεί να προσθέτει μια νέα γραμμή.
- Ή η εφαρμογή μπορεί να κάνει το αντίστροφο.

Η τρέχουσα συντόμευση εμφανίζεται επίσης στο κουμπί **Μετάφραση**.

<a id="rewrite"></a>
## Επανεγγραφή

Χρησιμοποιήστε **Επανεγγραφή** όταν θέλετε να βελτιώσετε τη διατύπωση χωρίς να αλλάζεται η κύρια σημασία.

![Χώρος εργασίας Επανεγγραφής](../images/screenshots/el/rewrite.png)

Αυτό είναι χρήσιμο για:

- διόρθωση ορθογραφίας και γραμματικής
- κάνετε το κείμενο πιο καθαρό
- κάνετε το κείμενο πιο επίσημο ή πιο ανεπίσημο
- μείωση ή αύξηση του κειμένου
- κάνετε το κείμενο να ακούγεται πιο τεχνικό

<br />

<a id="rewrite-text"></a>
### Επανεγγραφή κειμένου

1. Ανοίξτε **Επανεγγραφή**.
2. Επιλέξτε μια **Λειτουργία**.
3. Επιλέξτε ένα μοντέλο στη γραμμή εργαλείων.
4. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Είσοδος**.
5. Κάντε κλικ στο **Επανεγγραφή**.
6. Αναθεωρήστε το αποτέλεσμα στην **Έξοδος**.


Η ίδια συμπεριφορά πλήκτρου Enter που περιγράφεται στο [**Μετάφραση**](#keyboard-shortcuts) ισχύει επίσης εδώ.

<a id="transform"></a>
## Μετασχηματισμός

Χρησιμοποιήστε **Μετασχηματισμό** όταν θέλετε να ακολουθήσει το AI μια προσαρμοσμένη σειρά οδηγιών.

![Χώρος εργασίας Μετασχηματισμού](../images/screenshots/el/transform.png)

Αυτή είναι η πιο ευέλικτη περιοχή της εφαρμογής. Μπορείτε να την χρησιμοποιήσετε για εργασίες όπως:

- περίληψη σημειώσεων
- μετατροπή χειρόγραφου κειμένου σε μια επαγγελματική email
- εξαγωγή βασικών σημείων
- μετατροπή κειμένου σε μια συγκεκριμένη μορφή

<br />

<a id="run-an-existing-prompt"></a>
### Εκτέλεση υπάρχοντος προτύπου (prompt)

1. Ανοίξτε **Μετασχηματισμό**.
2. Επιλέξτε ένα πρότυπο (prompt) από τη λίστα προτύπων.
3. Εάν εμφανιστεί ένα πλαίσιο γλώσσας **Στόχος**, επιλέξτε μια γλώσσα αν τη χρειάζεστε.
4. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Είσοδος**.
5. Κάντε κλικ στο **Μετασχηματισμό**.
6. Διαβάστε το αποτέλεσμα στην **Έξοδος**.

<br />

<a id="if-you-have-no-prompts-yet"></a>
### Αν δεν έχετε ακόμα πρότυπα

Αν η λίστα προτύπων σας είναι κενή, κάντε κλικ στο **Φόρτωση δειγμάτων προτύπων**. Αυτό προσθέτει ενσωματωμένα παραδείγματα ώστε να μπορείτε να ξεκινήσετε γρήγορα.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Τα δείγματα προτύπων παρέχονται στα Αγγλικά. Αφού τα φορτώσετε, μπορείτε να επεξεργαστείτε ένα πρότυπο και να χρησιμοποιήσετε **Μετάφραση προτύπου** αν θέλετε να προσαρμόσετε το κείμενο του προτύπου για μια άλλη γλώσσα.

<br />

<a id="create-a-prompt-quickly"></a>

### Δημιουργία προτύπου γρήγορα

Η γρηγορότερη μέθοδος είναι:

1. Πατήστε **Νέο πρότυπο**.
2. Πατήστε **Δημιουργία προτύπου**.
3. Περιγράψτε τι θέλετε να κάνει το πρότυπο.
4. Επιλέξτε ένα μοντέλο.
5. Αφήστε την εφαρμογή να δημιουργήσει ένα σχέδιο για εσάς.
6. Ελέγξτε το σχέδιο και πατήστε **Αποθήκευση**.

![Δημιουργία προτύπου](../images/screenshots/el/transform-generate.png)


<br />

### Επεξεργασία προτύπου

Όταν δημιουργείτε ή επεξεργάζεστε ένα πρότυπο, ο επεξεργαστής εμφανίζεται στα αριστερά και μια περιοχή δοκιμής εμφανίζεται στα δεξιά.

![Επεξεργαστής προτύπου](../images/screenshots/el/transform-prompt-edit.png)

Τα κύρια πεδία είναι:

- **Όνομα προτύπου**: το όνομα που εμφανίζεται στη λίστα προτύπων.
- **Οδηγίες προτύπου (προαιρετικό)**: μια σύντομη υπόδειξη που εμφανίζεται στον χρήστη κατά τη διάρκεια εκτέλεσης του προτύπου.
- **Ρόλος μοντέλου**: ο συνολικός ρόλος που ανατίθεται στο AI, όπως για παράδειγμα 'Είσαι ένας χρήσιμος βοηθός.'
- **Οδηγίες μοντέλου (μία ανά γραμμή)**: οι συγκεκριμένοι κανόνες που θέλετε να ακολουθεί το AI.
- **Περιγραφή αποτελέσματος**: μια σύντομη λέξη που περιγράφει το αποτέλεσμα, όπως για παράδειγμα 'σύνοψη' ή 'επαναγραφή'.
- **Θερμοκρασία (0.0 → 1.0)**: ένα ρυθμιστή δημιουργικότητας.
- **Αίτηση γλώσσας στόχου**: προσθέτει έναν επιλογέα γλώσσας στόχου όταν εκτελείται το πρότυπο.

Εάν ο τεχνικός όρος **Θερμοκρασία** είναι νέος για σας, σκεφτείτε το ως εξής:

- Μια **χαμηλότερη** θερμοκρασία δίνει πιο σταθερά, πιο προβλέψιμα αποτελέσματα.
- Μια **υψηλότερη** θερμοκρασία δίνει περισσότερη ποικιλία και δημιουργικότητα.

Μπορείτε επίσης να χρησιμοποιήσετε:

- **`Generate prompt`** για να δημιουργήσετε ένα νέο σχέδιο από μια απλή περιγραφή
- **`Improve prompt`** για να βελτιώσετε ένα υπάρχον πρότυπο
- **`Translate prompt`** για να μεταφράσετε τα πεδία του προτύπου

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Πατήστε **`Save`** πριν πατήσετε **`Back to Run`**. Εάν επιστρέψετε χωρίς αποθήκευση, οι αλλαγές σας θα χαθούν.

<br />

<a id="test-a-prompt-before-using-it"></a>
### Δοκιμάστε ένα πρότυπο πριν το χρησιμοποιήσετε

Ο πίνακας δοκιμών στα δεξιά σας επιτρέπει να δοκιμάσετε το πρότυπο σας με δοκιμαστικό κείμενο πριν το χρησιμοποιήσετε στην καθημερινή εργασία.

Αυτό είναι χρήσιμο όταν:

- κατασκευάζετε ένα νέο πρότυπο
- συγκρίνετε δύο εκδόσεις ενός προτύπου
- θέλετε να ελέγξετε τον τόνο, το μήκος ή τη μορφή εξόδου

<br />

<a id="manage-saved-prompts"></a>
### Διαχείριση αποθηκευμένων προτύπων

Για να διαχειριστείτε τα αποθηκευμένα πρότυπα σε ένα σημείο, ανοίξτε [**Ρυθμίσεις** > **Μετασχηματισμός Προτύπων**](#transform-prompts).

Εκεί μπορείτε:

- να εμφανίσετε και να διαγράψετε τα πρότυπά σας
- να εξαγάγετε πρότυπα ως **JSON**, **CSV**, ή **XLSX**
- να εισαγάγετε πρότυπα από ένα αρχείο

<a id="dashboard-tabs"></a>

- **Ανά Χρήση** αναλύει τη δραστηριότητα ανά γλώσσα μετάφρασης, λειτουργία επαναγραφής και πρότυπο μετασχηματισμού.

Οι πίνακες του πίνακα ελέγχου μπορούν να εξαγάγουν δεδομένα σε:

- **CSV**
- **XLSX**

Αυτό είναι χρήσιμο αν θέλετε να ελέγξετε τη δραστηριότητα εκτός της εφαρμογής ή να μοιραστείτε μια αναφορά.

<a id="delete-stored-records-for-a-model"></a>
### Διαγραφή αποθηκευμένων εγγραφών για ένα μοντέλο

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Η διαγραφή αποθηκευμένων εγγραφών δεν μπορεί να αναιρεθεί. Χρησιμοποιήστε αυτό μόνο αν είστε βέβαιοι ότι δεν χρειάζεστε πλέον αυτό το ιστορικό.

Για να διαγράψετε όλα τα δεδομένα ή να αφαιρέσετε εγγραφές με βάση την ηλικία τους, μεταβείτε στις [**Ρυθμίσεις** > **Καταγραφή Κόστους**](#cost-tracking). Εκεί θα βρείτε επιλογές για να διαγράψετε όλα τα αποθηκευμένα δεδομένα ή μόνο δεδομένα παλαιότερα από μια συγκεκριμένη ημερομηνία.

<a id="settings"></a>
## Ρυθμίσεις

Ανοίξτε τις **Ρυθμίσεις** από το πλαϊνό μενού για να προσαρμόσετε τη συμπεριφορά της εφαρμογής.

Οι διαθέσιμες καρτέλες μπορεί να διαφέρουν:

- Η **Διαμόρφωση API** είναι διαθέσιμη μόνο στην εφαρμογή επιτραπέζιου υπολογιστή.
- Οι **Χρήστες** είναι διαθέσιμοι μόνο στην εφαρμογή web, και μόνο για διαχειριστές.

<br />

<a id="general-settings"></a>
### Γενικές ρυθμίσεις

### Γενικές ρυθμίσεις

Χρησιμοποιήστε τις **Γενικές ρυθμίσεις** για να ελέγχετε τη συμπεριφορά πληκτρολόγησης και την εμφάνιση.

**Συμπεριφορά**

- **Συμπεριφορά για το ENTER** επιλέγει αν το Enter εκτελεί την εργασία ή εισάγει νέα γραμμή.
- **Αυτόματη μετάφραση κατά την επικόλληση** ξεκινά τη μετάφραση μόλις επικολλήσετε κείμενο.
- **Αυτόματη αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει τα επιτυχή αποτελέσματα αυτόματα.
- **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** μεταφράζει κατά την πληκτρολόγηση.
- **Χρονικό όριο (ms)** ορίζει τον χρόνο αναμονής για τη μετάφραση σε πραγματικό χρόνο.

**Εμφάνιση**

- **Ψηφία κλασμάτων κόστους** αλλάζει τον τρόπο εμφάνισης των δεκαδικών ψηφίων κόστους.
- **Οικογένεια γραμματοσειρών** αλλάζει τη γραμματοσειρά στα πάνελα κειμένου.
- **Μέγεθος** αλλάζει το μέγεθος της γραμματοσειράς.
- **Μόνο για ιστό:** **εμφάνιση περιθωρίου γύρω από την εφαρμογή** προσθέτει επιπλέον χώρο γύρω από το περιβάλλον εργασίας.

<br />

<a id="models"></a>
### Μοντέλα

Χρησιμοποιήστε τις **Ρυθμίσεις** > **Μοντέλα** για να επιλέξετε ποια μοντέλα εμφανίζονται στη γραμμή εργαλείων.

![Καρτέλα Μοντέλα ρυθμίσεων](../images/screenshots/el/settings-models.png)

Η σελίδα έχει δύο λίστες:

- **Διαθέσιμα Μοντέλα** στα αριστερά
- **Επιλεγμένα Μοντέλα** στα δεξιά

Χρήσιμα στοιχεία ελέγχου περιλαμβάνουν:

- **Αναζήτηση μοντέλων...** για να βρείτε ένα μοντέλο κατά όνομα
- **Μόνο δωρεάν** για να εμφανίονται μόνο δωρεάν μοντέλα
- **Ανανέωση** για να επαναφορτώσετε τη λίστα
- **Επέκταση όλων** και **Σύμπτυξη όλων** όταν ταξινομείτε κατά πάροχο

Για να προσθέσετε ένα μοντέλο, κάντε κλικ στο **Προσθήκη**.

Για να αφαιρέσετε ένα μοντέλο, κάντε κλικ στο **X** δίπλα του στην **Επιλεγμένα Μοντέλα**.

Για να εκκαθαρίσετε τη λίστα, κάντε κλικ στο **Αποεπιλογή όλων**. Το απαραίτητο δωρεάν μοντέλο θα παραμείνει στη λίστα.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Εάν δεν θέλετε να προσθέσετε πιστώσεις στο OpenRouter αμέσως, αρχίστε ενεργοποιώντας το **Μόνο δωρεάν** και επιλέγοντας τα δωρεάν μοντέλα.

<br />

<a id="languages"></a>
### Γλώσσες

Χρησιμοποιήστε τις **Ρυθμίσεις** > **Γλώσσες** για να οργανώσετε τις λίστες γλωσσών που χρησιμοποιούνται στην εφαρμογή.

- **Κορυφαίες γλώσσες** είναι καρφιτσωμένες κοντά στην κορυφή των λιστών γλωσσών στις ενότητες **Μετάφραση** και **Μετατροπή**.
- **Προσαρμοσμένη γλώσσα** σας επιτρέπει να προσθέσετε μια γλώσσα που δεν υπάρχει στη built-in λίστα.

Εάν προσθέσετε μια προσαρμοσμένη γλώσσα, εμφανίζεται στους επιλογείς γλωσσών μαζί με τις built-in επιλογές.

<br />

<a id="cost-tracking"></a>
### Παρακολούθηση κόστους

Χρησιμοποιήστε τις **Ρυθμίσεις** > **Παρακολούθηση Κόστους** για να διαχειριστείτε τις πληροφορίες κόστους.

- **Συνολικό Κόστος** εμφανίζει το τρέχον σύνολο.
- **Αντιγραφή Τιμής** αντιγράφει το σύνολο στο πρόχειρο.
- **Επαναφορά Κόστους** επαναφέρει το αποθηκευμένο σύνολο στο μηδέν.
- **Συγχρονισμός με τη χρήση κλειδιού API** ορίζει το σύνολο ώστε να ταιριάζει με τη χρήση που αναφέρεται από το OpenRouter.
- **Χρήση Κλειδιού API** εμφανίζει λεπτομέρειες χρήσης, εάν είναι διαθέσιμες.
- **Διαγραφή δεδομένων κόστους** αφαιρεί όλα τα δεδομένα ή μόνο τις καταχωρήσεις παλαιότερες από μια επιλεγμένη ημερομηνία.

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Η διαγραφή δεδομένων δεν μπορεί να αναιρεθεί. Πριν τη διαγραφή, βεβαιωθείτε ότι έχετε κάνει αντίγραφο ασφαλείας ή εξαγάγατε τα δεδομένα μέσω του [**Πίνακα ελέγχου** > **Όλες οι κλήσεις**](#dashboard-tabs), διαφορετικά θα χαθούν μόνιμα.

<a id="api-config"></a>
### Διαμόρφωση API

**Μόνο για επιφάνεια εργασίας**

Χρησιμοποιήστε τη **Διαμόρφωση API** για να συνδέσετε την εφαρμογή επιφάνειας εργασίας με το OpenRouter ή με έναν διακομιστή μεσολαβητή Transrewrt.

- **Κλειδί API OpenRouter** είναι在那里 επικολλήσετε το κλειδί σας.
- **Διεύθυνση URL API** είναι η διεύθυνση του service. Αφήστε το στην προεπιλογή εκτός αν σας έχει δοθεί μια διαφορετική.
- **Χρήση μεσολαβητή Transrewrt** δρομολογεί τις αιτήσεις μέσω μιας υπηρεσίας μεσολαβητή αντί κατευθείας στο OpenRouter.
- **ΔInitial seed κλειδιού** εμφανίζεται όταν η επιλογή μεσολαβητή είναι ενεργοποιημένη.
- **Δοκιμή Διαμόρφωσης API** ελέγχει αν η τρέχουσα ρύθμιση λειτουργεί.

Για λεπτομερή βήματα σχετικά με την απόκτηση του κλειδιού API, ανατρέξτε στο [Πώς να αποκτήσετε ένα κλειδί API](#how-to-get-an-api-key-desktop-app) παραπάνω.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Εάν δεν είστε σίγουροι τι σημαίνουν τα **Διεύθυνση URL API**, **Χρήση μεσολαβητή Transrewrt** ή **ΔInitial seed κλειδιού**, αφήστε它们 αμετάβλητα και χρησιμοποιήστε την προεπιλεγμένη ρύθμιση OpenRouter. Περισσότερες πληροφορίες για τον μεσολαβητή είναι διαθέσιμες στο [Αποθετήριο μεσολαβητή Transrewrt](https://github.com/wsj-br/transrewrt-proxy).

<a id="common-issues"></a>
## Κοινά προβλήματα

Αν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα τα παρακάτω σημεία.

<br />

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Η εφαρμογή δεν μεταφράζει, επανεγγράφει ή μετασχηματίζει κείμενο

Ελέγξτε ότι:

- έχετε επιλέξει ένα μοντέλο στη γραμμή εργαλείων
- τουλάχιστον ένα μοντέλο αναγράφεται στις [**Ρυθμίσεις** > **Μοντέλα**](#models)
- η ρύθμιση API σας λειτουργεί

Αν χρησιμοποιείτε την εφαρμογή επιτραπέζιου υπολογιστή:

1. Ανοίξτε [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config).
2. Ελέγξτε ότι το κλειδί API σας έχει αποθηκευτεί.
3. Κάντε κλικ στο **Δοκιμή Διαμόρφωσης API**.

<br />

<a id="the-model-list-is-empty"></a>
### Ο κατάλογος μοντέλων είναι κενός

Ανοίξτε [**Ρυθμίσεις** > **Μοντέλα**](#models) και κάντε κλικ στο **Ανανέωση**.

Εάν χρειαστεί:

- αναζητήστε ένα μοντέλο
- ενεργοποιήστε το **Μόνο Δωρεάν**
- προσθέστε ένα ή περισσότερα μοντέλα στο **Επιλεγμένα Μοντέλα**

<br />

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Το αποτέλεσμα είναι πολύ αργό ή πολύ ακριβό

Δοκιμάστε ένα ή περισσότερα από τα παρακάτω:

- επιλέξτε ένα διαφορετικό μοντέλο
- χρησιμοποιήστε πιο σύντομη είσοδο
- απενεργοποιήστε τη **Μεταφραστική σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** στις [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings)
- χρησιμοποιήστε δωρεάν μοντέλα για απλά tasks (δείτε [Μοντέλα](#models))

<br />

<a id="the-interface-is-in-the-wrong-language"></a>
### Το περιβάλλον εργασίας είναι σε λάθος γλώσσα

Κάντε κλικ στο εικονίδιο του εoglobού στη [γραμμή εργαλείων](#toolbar) και επιλέξτε την **Γλώσσα διεπαφής** που προτιμάτε.

<br />

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Το κείμενο είναι πολύ μικρό ή δύσκολο να διαβαστεί

Ανοίξτε [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings) και αλλάξτε:

- **Οικογένεια Γραμματοσειράς**
- **Μέγεθος**

<br />

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Άλλαξα μια ερώτηση και χάθηκαν οι αλλαγές

Κατά την επεξεργασία μιας ερώτησης, πάντα κάντε κλικ στο **Αποθήκευση** πριν κάνετε κλικ στο **Πίσω στην Εκτέλεση**.

<br /><br />

<a id="quick-tips"></a>
## Σύντομα συμβουλές

- Ξεκινήστε με το [**Μετάφραση**](#translate) για να βεβαιωθείτε ότι η ρύθμιση σας λειτουργεί πριν προχωρήσετε στην [**Επανεγγραφή**](#rewrite) ή τη [**Μετασχηματισμό**](#transform).
- Χρησιμοποιήστε το [**Επανεγγραφή**](#rewrite) για βελτιώσεις στη φράση της καθημερινότητας.
- Χρησιμοποιήστε το [**Μετασχηματισμό**](#transform) όταν χρειάζεστε μια επανάληψη ροής εργασίας για μια συγκεκριμένη εργασία.
- Χρησιμοποιήστε το [**Πίνακας Ελέγχου**](#dashboard) αν θέλετε να παρακολουθείτε τη χρήση και το κόστος.
- Εξάγετε ερωτήσεις τακτικά αν δημιουργείτε μια βιβλιοθήκη ερωτήσεων που θέλετε να διατηρήσετε ασφαλή (δείτε [Ερωτήσεις Μετασχηματισμού](#transform-prompts)).
