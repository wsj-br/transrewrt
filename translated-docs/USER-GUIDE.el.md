# Εγχειρίδιο Χρήσης

<br/>

<a id="introduction"></a>
## Εισαγωγή

Το Transrewrt σας βοηθά να εργαστείτε με κείμενο με τρεις βασικούς τρόπους:

- **Μετάφραση** - μετατροπή κειμένου από μία γλώσσα σε άλλη.
- **Επανεκφώνηση** - αναδιατύπωση κειμένου με διαφορετικό ύφος, όπως πιο καθαρό, πιο σύντομο ή πιο επίσημο.
- **Μετασχηματισμός** - επεξεργασία κειμένου χρησιμοποιώντας προσαρμοσμένες οδηγίες τεχνητής νοημοσύνης που ονομάζονται προτροπές (prompts).

<br/>

Αυτός ο οδηγός εξηγεί πώς να χρησιμοποιήσετε την εφαρμογή αφού έχει εγκατασταθεί και τρέχει. Για τα βήματα εγκατάστασης, δείτε το κύριο **[README](README.el.md)**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το Transrewrt είναι διαθέσιμο ως εφαρμογή για υπολογιστές Windows και Linux, και ως εφαρμογή ιστού που εγκαθίσταται από τον χρήστη. Ο παρών οδηγός επικεντρώνεται στην καθημερινή χρήση της εφαρμογής. Όπου κάτι ισχύει μόνο για μία έκδοση, το γεγονός αυτό τονίζεται ξεκάθαρα.

<a id="before-you-start"></a>

## Πριν ξεκινήσετε

Για να χρησιμοποιήσετε το Transrewrt, χρειάζεστε πρόσβαση σε τουλάχιστον έναν πάροχο τεχνητής νοημοσύνης. Οι υποστηριζόμενοι πάροχοι είναι: [OpenRouter](https://openrouter.ai) (που συγκεντρώνει πολλά μοντέλα), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και [Ollama](https://ollama.com) για τοπικά μοντέλα.

Δεν χρειάζεται να επιλέξετε ένα πληρωτέο μοντέλο για να ξεκινήσετε. Μόλις προσθέσετε το κλειδί API του OpenRouter, η εφαρμογή ενεργοποιεί αυτόματα μια ενσωματωμένη **δωρεάν** επιλογή OpenRouter. Αυτό σας επιτρέπει να ξεκινήσετε αμέσως τη μετάφραση, αναδιατύπωση και μετασχηματισμό κειμένου. Εναλλακτικά, μπορείτε επίσης να λάβετε δωρεάν κλειδί API από τις εταιρείες Cerebras, Google, Groq ή Mistral AI.

Με απλά λόγια:

- Ένα **μοντέλο** είναι ο μηχανισμός τεχνητής νοημοσύνης που κάνει τη δουλειά. Τα μοντέλα παρουσιάζονται με ένα **πρόθεμα παρόχου** (π.χ. `openrouter/…`, `openai/…`, `ollama/…`).
- Ένα **κλειδί API** (ή, για το Ollama, μια **βασική διεύθυνση URL**) είναι το μέσο μέσω του οποίου η εφαρμογή επικοινωνεί με τον πάροχο.

Αν χρησιμοποιείτε την **εφαρμογή για υπολογιστή**, προσθέστε κλειδιά στην ενότητα [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config) για κάθε πάροχο που χρησιμοποιείτε. Για χρήση μόνο OpenRouter, δείτε παρακάτω [Πώς να πάρετε κλειδί API](#how-to-get-an-api-key-desktop-app). Αν δεν θέλετε να χρησιμοποιήσετε κλειδί API, μπορείτε να εγκαταστήσετε το Ollama (από το [ollama.com](https://ollama.com)) και να χρησιμοποιήσετε τοπικά μοντέλα αντί αυτών, όπως το `translategemma:4b`.

Αν χρησιμοποιείτε την **έκδοση στο web**, ο διαχειριστής του διακομιστή διαμορφώνει τους παρόχους μέσω μεταβλητών περιβάλλοντος, επομένως δεν μπορείτε να εισαγάγετε κλειδιά API απευθείας στην εφαρμογή.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Πώς να πάρετε ένα δωρεάν κλειδί OpenRouter API (εφαρμογή υπολογιστή)

Αν χρησιμοποιείτε την εφαρμογή για υπολογιστή, ακολουθήστε τα εξής βήματα:

1. Μεταβείτε στο [OpenRouter](https://openrouter.ai) μέσω του προγράμματος περιήγησής σας.
2. Δημιουργήστε λογαριασμό ή συνδεθείτε.
3. Ανοίξτε τη σελίδα [Keys](https://openrouter.ai/keys).
4. Κάντε κλικ στο κουμπί για δημιουργία νέου κλειδιού API.
5. Δώστε ένα όνομα στο κλειδί για να μπορείτε να το αναγνωρίσετε αργότερα.
6. Αντιγράψτε το νέο κλειδί API.
7. Επιστρέψτε στο Transrewrt και ανοίξτε το **Ρυθμίσεις** > **Διαμόρφωση API**.
8. Επικολλήστε το κλειδί στο πεδίο **OpenRouter API key** (μέσω **Ρυθμίσεις** > **Διαμόρφωση API**).
9. Κάντε κλικ στο **Test OpenRouter key** για να επιβεβαιώσετε ότι λειτουργεί.

<a id="getting-started"></a>
## Αρχική χρήση

Αν είναι η πρώτη φορά σας που χρησιμοποιείτε το Transrewrt, ακολουθήστε αυτή τη σειρά:

1. Ανοίξτε την εφαρμογή.
2. Επιλέξτε τη **Γλώσσα διεπαφής** από το εικονίδιο της σφαίρας αν χρειαστεί.
3. Αν χρησιμοποιείτε την **εφαρμογή για υπολογιστή**, ανοίξτε [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config), προσθέστε κλειδί API για τουλάχιστον έναν πάροχο (π.χ. OpenRouter) και κάντε κλικ στο **Δοκιμή** για επαλήθευση.
4. Ανοίξτε [**Ρυθμίσεις** > **Μοντέλα**](#models) και προσθέστε ένα ή περισσότερα μοντέλα στο **Επιλεγμένα μοντέλα**.
5. Ανοίξτε [**Ρυθμίσεις** > **Γλώσσες**](#languages) και επιλέξτε τις **Κύριες γλώσσες σας** αν θέλετε οι πιο συχνά χρησιμοποιούμενες να εμφανίζονται πρώτες.
6. Μεταβείτε στην ενότητα **Μετάφραση** και κάντε μια απλή μετάφραση για να επιβεβαιώσετε ότι όλα λειτουργούν.
7. Μόλις λειτουργήσει, δοκιμάστε το **Αναδιατύπωση** και στη συνέχεια το **Μετασχηματισμός**.

Η σειρά αυτή είναι σημαντική. Αποτρέπει το πιο συνηθισμένο πρόβλημα της πρώτης χρήσης: την προσπάθεια εκτέλεσης μιας εργασίας πριν η εφαρμογή έχει επιτυχή σύνδεση API ή επιλεγμένο μοντέλο.

### Μπάρα εργαλείων

Η μπάρα εργαλείων αλλάζει ελαφρώς ανάλογα με το πού βρίσκεστε στην εφαρμογή.

- Στα αριστερά, εμφανίζεται το όνομα της τρέχουσας σελίδας.
- Στα δεξιά, εμφανίζεται ο **επιλογέας μοντέλου** και ο έλεγχος της γλώσσας διεπαφής.

Ο **επιλογέας μοντέλου** σας επιτρέπει να επιλέξετε ποια μηχανή τεχνητής νοημοσύνης θα χρησιμοποιηθεί για την τρέχουσα εργασία.

  ![Επιλογέας μοντέλου](../images/screenshots/el/model-selector.png)

Κάποια δωρεάν μοντέλα ενδέχεται να μην είναι πάντα διαθέσιμα — μερικές φορές είναι εκτός σύνδεσης ή έχουν όριο χρήσης. Σε αυτήν την περίπτωση, η εφαρμογή θα αφαιρέσει αυτόματα το μοντέλο από τη διαθέσιμη λίστα σας. Για να ελέγξετε ποια μοντέλα εμφανίζονται, μεταβείτε στις [**Ρυθμίσεις** > **Μοντέλα**](#models) και τροποποιήστε τη λίστα των μοντέλων σας. 
Μπορείτε επίσης να ανοίξετε απευθείας τις ρυθμίσεις του μοντέλου κάνοντας κλικ στο εικονίδιο παρόχου στα αριστερά του ονόματος του μοντέλου στη μπάρα εργαλείων.

<br/>

Το **εικονίδιο με τη γη και τον κωδικό γλώσσας** αλλάζει τη γλώσσα της διεπαφής της εφαρμογής, όπως τα μενού και τα κουμπιά. ΔΕΝ αλλάζει τις γλώσσες μετάφρασης που χρησιμοποιούνται στη λειτουργία **Μετάφραση**.

  ![Επιλογέας γλώσσας διεπαφής](../images/screenshots/el/language-selector.png)

<a id="input-and-output-panels"></a>
### Πάνελ εισόδου και εξόδου

Η πλειονότητα των χώρων εργασίας χρησιμοποιεί ένα πάνελ **Εισόδου** στα αριστερά και ένα πάνελ **Εξόδου** στα δεξιά.

Κάθε πάνελ επίσης δείχνει:

| **Είσοδος**                                                          | **Έξοδος**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Αριθμός χαρακτήρων <br/>- Αριθμός λέξεων <br/>- Αριθμός παραγράφων   <br/> | - Διάρκεια εργασίας<br/>- **TPS** (τοκεν ανά δευτερόλεπτο)<br/>- Αριθμός χαρακτήρων, λέξεων και παραγράφων<br/>- Το χρησιμοποιούμενο μοντέλο |


Αν αναρωτιέστε για τους τεχνικούς όρους:

- **Τοκεν** σημαίνει ένα μικρό κομμάτι κειμένου. Μπορείτε να το θεωρήσετε ως μέρος μιας λέξης ή μία μικρή λέξη.
- **TPS** σημαίνει πόσα από αυτά τα κομμάτια κειμένου επεξεργάζεται το μοντέλο κάθε δευτερόλεπτο.

<br/>

Μπορείτε επίσης να παρακολουθείτε το κόστος κάθε λειτουργίας (αν είναι διαθέσιμο) και το συνολικό κόστος, ενεργοποιώντας την επιλογή `Εμφάνιση πληροφοριών κόστους στις ενέργειες` στις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings).

<a id="translate"></a>
## Μετάφραση

Χρησιμοποιήστε την επιλογή **Μετάφραση** όταν θέλετε να μετατρέψετε κείμενο από μία γλώσσα σε άλλη.

![Χώρος εργασίας μετάφρασης](../images/screenshots/el/translate.png)

<br/>

<a id="translate-text"></a>
### Μετάφραση κειμένου

1. Ανοίξτε την επιλογή **Μετάφραση**.
2. Επιλέξτε μια γλώσσα στο **Από**.
3. Επιλέξτε μια γλώσσα στο **Προς**.
4. Επιλέξτε ένα μοντέλο στη μπάρα εργαλείων.
5. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Είσοδος**.
6. Κάντε κλικ στο **Μετάφραση**.
7. Διαβάστε το αποτέλεσμα στο **Έξοδος**.
8. Χρησιμοποιήστε το κουμπί αντιγραφής αν θέλετε να αντιγράψετε το αποτέλεσμα.

<br/>

<a id="language-selection"></a>
### Επιλογή γλώσσας

- Το **Από** μπορεί να είναι μια συγκεκριμένη γλώσσα ή η επιλογή **Ανίχνευση γλώσσας**.
- Το **Προς** είναι η γλώσσα στην οποία θέλετε να είναι το αποτέλεσμα.

Οι επιλεγμένες **Κορυφαίες γλώσσες** σας εμφανίζονται στην κορυφή της λίστας. Μπορείτε να τις καθορίσετε στις [**Ρυθμίσεις** > **Γλώσσες**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Χρήσιμες ρυθμίσεις μετάφρασης

<a id="transform"></a>

## Μετασχηματισμός

Χρησιμοποιήστε την επιλογή **Μετασχηματισμός** όταν θέλετε το τεχνητό νοημοσύνης να ακολουθήσει ένα προσαρμοσμένο σύνολο οδηγιών.

![Χώρος εργασίας Μετασχηματισμού](../images/screenshots/el/transform.png)

Αυτή είναι η πιο εύκαμπτη περιοχή της εφαρμογής. Μπορείτε να τη χρησιμοποιήσετε για εργασίες όπως:

- σύντομη παρουσίαση σημειώσεων
- μετατροπή πρόχειρου κειμένου σε επαγγελματικό email
- εξαγωγή βασικών σημείων
- μετατροπή του κειμένου σε συγκεκριμένη μορφή
- οποιαδήποτε άλλη προσαρμοσμένη ενέργεια με το εισαγόμενο κείμενο

<br/>

<a id="run-an-existing-prompt"></a>
### Εκτέλεση υπάρχουσας προτροπής

1. Ανοίξτε την επιλογή **Μετασχηματισμός**.
2. Επιλέξτε μία προτροπή από τη λίστα προτροπών.
3. Εάν εμφανιστεί ένα πλαίσιο για τη **Γλώσσα στόχος**, επιλέξτε μία γλώσσα, αν το επιθυμείτε.
4. Πληκτρολογήστε ή επικολλήστε κείμενο στο πεδίο **Είσοδος**.
5. Κάντε κλικ στο **Μετασχηματισμός**.
6. Διαβάστε το αποτέλεσμα στο πεδίο **Έξοδος**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### Αν δεν έχετε ακόμη προτροπές

Εάν η λίστα προτροπών σας είναι κενή, κάντε κλικ στο **Φόρτωση δειγμάτων προτροπών**. Έτσι προστίθενται ενσωματωμένα παραδείγματα ώστε να ξεκινήσετε γρήγορα.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Τα δείγματα προτροπών δίνονται στα Αγγλικά. Αφού τα φορτώσετε, μπορείτε να επεξεργαστείτε μία προτροπή και να χρησιμοποιήσετε το **Μετάφραση προτροπής** για να τη μεταφράσετε στη γλώσσα σας.

<br/>

<a id="create-a-prompt-quickly"></a>
### Δημιουργία προτροπής με γρήγορο τρόπο

Ο ταχύτερος τρόπος για να δημιουργήσετε μία προτροπή είναι:

1. Κάντε κλικ στο **Νέα προτροπή**.
2. Κάντε κλικ στο **Δημιουργία προτροπής**.
3. Περιγράψτε τι θέλετε να κάνει η προτροπή.
4. Επιλέξτε ένα μοντέλο.
5. Αφήστε την εφαρμογή να δημιουργήσει ένα προσχέδιο για εσάς.
6. Ελέγξτε το προσχέδιο και κάντε κλικ στο **Αποθήκευση**.

![Δημιουργία προτροπής](../images/screenshots/el/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### Επεξεργασία προτροπής

Όταν δημιουργείτε ή επεξεργάζεστε μια προτροπή, ο επεξεργαστής εμφανίζεται στα αριστερά και μία περιοχή δοκιμής εμφανίζεται στα δεξιά.

![Επεξεργαστής προτροπής μετασχηματισμού](../images/screenshots/el/transform-prompt-edit.png)

Οι κύριες περιοχές είναι:

- **Όνομα προτροπής**: το όνομα που εμφανίζεται στη λίστα των προτροπών.
- **Οδηγίες προτροπής (προαιρετικό)**: μία σύντομη υπόδειξη που εμφανίζεται στον χρήστη κατά την εκτέλεση της προτροπής.
- **Ρόλος Μοντέλου**: ο συνολικός ρόλος που δίνεται στην τεχνητή νοημοσύνη, όπως «Είσαι ένας βοηθητικός βοηθός».
- **Οδηγίες μοντέλου (μία ανά γραμμή)**: οι συγκεκριμένοι κανόνες που θέλετε να ακολουθεί το τεχνητό νοημοσύνης.
- **Περιγραφή εξόδου**: μία σύντομη λέξη που περιγράφει το αποτέλεσμα, όπως «περίληψη» ή «επαναδιατύπωση».
- **Θερμοκρασία (0,0 → 1,0)**: το πώς θα συμπεριφερθεί το μοντέλο· βλέπε πιο κάτω.
- **Ζήτηση γλώσσας στόχου**: προσθέτει επιλογέα γλώσσας-στόχου όταν εκτελείται η προτροπή.

Εάν ο τεχνικός όρος **Θερμοκρασία** σας είναι νέος, να τον αντιμετωπίζετε ως εξής:

- Μία **χαμηλότερη** θερμοκρασία δίνει πιο σταθερά και προβλέψιμα αποτελέσματα.
- Μία **υψηλότερη** θερμοκρασία δίνει μεγαλύτερη ποικιλία και δημιουργικότητα.

Μπορείτε επίσης να χρησιμοποιήσετε:

- **`Δημιουργία προτροπής`** για να δημιουργήσετε ένα νέο προσύνολο από μία απλή περιγραφή
- **`Βελτίωση προτροπής`** για να βελτιώσετε μία υπάρχουσα προτροπή
- **`Μετάφραση προτροπής`** για να μεταφράσετε τα πεδία της προτροπής

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Κάντε κλικ στο **`Αποθήκευση`** πριν κάνετε κλικ στο **`Πίσω στην Εκτέλεση`**. Αν επιστρέψετε πίσω χωρίς να αποθηκεύσετε, οι αλλαγές σας θα χαθούν.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### Δοκιμάστε μία προτροπή πριν τη χρησιμοποιήσετε

Το πάνελ δοκιμής στα δεξιά σας επιτρέπει να δοκιμάσετε την προτροπή με δείγματα κειμένου πριν την χρησιμοποιήσετε στην καθημερινή εργασία σας.

Αυτό είναι χρήσιμο όταν:

- Δημιουργείτε μία νέα προτροπή
- Συγκρίνετε δύο εκδόσεις της ίδιας προτροπής
- Θέλετε να ελέγξετε τον τόνο, το μήκος ή τη μορφή της εξόδου

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Μπορείτε να εξάγετε και να εισάγετε αποθηκευμένες προτροπές από την ενότητα [**Ρυθμίσεις** > **Προτροπές Μετασχηματισμού**](#transform-prompts).

<a id="general-settings"></a>
### Γενικές Ρυθμίσεις

Χρησιμοποιήστε τις **Γενικές Ρυθμίσεις** για να ελέγξετε τη συμπεριφορά του πληκτρολογίου, αν αποθηκεύονται λεπτομέρειες εκτέλεσης στο **Ιστορικό**, και για να τροποποιήσετε την εμφάνιση.

**Συμπεριφορά**

- **Συμπεριφορά για ENTER** επιλέγει αν το `Enter` θα εκτελεί την εργασία ή θα εισάγει νέα γραμμή.
- **Αυτόματη μετάφραση κατά την επικόλληση** ξεκινά τη μετάφραση αμέσως μόλις επικολλήσετε κείμενο.
- **Αυτόματη αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει αυτόματα τα επιτυχημένα αποτελέσματα.
- **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** μεταφράζει καθώς πληκτρολογείτε.
- **Χρονικό όριο (ms)** ορίζει τον χρόνο αναμονής για τη μετάφραση σε πραγματικό χρόνο.

**Ιστορικό**

- **Διατήρηση ιστορικού εκτέλεσης** ελέγχει αν κάθε μετάφραση, αναδιατύπωση και μετασχηματισμός αποθηκεύει **το κείμενο εισόδου και εξόδου** για την προβολή του [**Ιστορικού**](#history) στην πλευρική μπάρα. Η απενεργοποίηση του ζητά επιβεβαίωση· αν την επιβεβαιώσετε, τα αποθηκευμένα κείμενα ιστορικού αφαιρούνται από τη βάση δεδομένων.
- **Διαγραφή δεδομένων ιστορικού** σας επιτρέπει να αφαιρέσετε αποθηκευμένο κείμενο με βάση την ηλικία του (π.χ. παλαιότερο από λίγους μήνες, ή **όλα τα δεδομένα (εκκαθάριση)**) μέσω της επιλογής **Διαγραφή δεδομένων**. Αυτό επηρεάζει μόνο τα αποθηκευμένα κείμενα για την προβολή του **Ιστορικού**· **δεν** διαγράφει συνολικά κόστη ή στατιστικά χρήσης. Για να αφαιρέσετε ή να περιορίσετε τα δεδομένα **κόστους**, χρησιμοποιήστε την επιλογή [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking).

**Εμφάνιση**

- **Εμφάνιση πληροφοριών κόστους στις ενέργειες** ελέγχει την εμφάνιση του κόστους ανά λειτουργία (αν είναι διαθέσιμο) και του συνολικού κόστους στα πίνακες εξόδου των λειτουργιών Μετάφρασης, Αναδιατύπωσης και Μετασχηματισμού.
- **Ψηφία κλάσματος κόστους** αλλάζει τον τρόπο εμφάνισης των δεκαδικών ψηφίων του κόστους.
- **Μόνο ιστός:** **εμφάνιση περιθωρίου γύρω από την εφαρμογή** προσθέτει επιπλέον χώρο γύρω από τη διεπαφή.
- **Οικογένεια γραμματοσειρών** αλλάζει τη γραμματοσειρά στα πλαίσια κειμένου.
- **Μέγεθος** αλλάζει το μέγεθος της γραμματοσειράς.

<br/>

<a id="models"></a>

### Μοντέλα

Χρησιμοποιήστε **Ρυθμίσεις** > **Μοντέλα** για να επιλέξετε ποια μοντέλα θα εμφανίζονται στη γραμμή εργαλείων.

![Καρτέλα Ρυθμίσεις Μοντέλων](../images/screenshots/el/settings-models.png)

Η σελίδα έχει δύο λίστες:

- **Διαθέσιμα Μοντέλα** στα αριστερά
- **Επιλεγμένα Μοντέλα** στα δεξιά

Χρήσιμα στοιχεία ελέγχου περιλαμβάνουν:

- **Αναζήτηση μοντέλων...** για εύρεση μοντέλου βάσει ονόματος
- **Πλακίδια Πάροχου** για να περιοριστεί η λίστα σε μία μηχανή (OpenRouter, OpenAI, Ollama, …)
- **Μόνο Δωρεάν** για να εμφανιστούν μόνο δωρεάν μοντέλα
- **Ανανέωση** για φόρτωση ξανά της λίστας
- **Ανάπτυξη Όλων** και **Σύμπτυξη Όλων** όταν ταξινομείτε ανά πάροχο

Οι ταυτότητες μοντέλων περιλαμβάνουν το πρόθεμα του παρόχου (για παράδειγμα `openrouter/…` έναντι `openai/…`). Ετικέτες όπως **OpenAI (OpenRouter)** έναντι **OpenAI (άμεσα)** δείχνουν πώς δρομολογείται η κίνηση.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το **OpenRouter Body Builder** (`openrouter/bodybuilder`) είναι ένα μοντέλο δρομολόγησης, όχι ένα γενικό μοντέλο συνομιλίας: η απάντησή του είναι JSON που περιγράφει σώματα αιτημάτων OpenRouter API (για παράδειγμα έναν πίνακα `requests` με `model` και `messages`). Εάν το χρησιμοποιήσετε για **Μετάφραση**, **Επανεγγραφή** ή **Μετασχηματισμό**, το παράθυρο εξόδου θα εμφανίσει αυτό το JSON αντί για τελειωμένο κείμενο. Επιλέξτε ένα κανονικό μοντέλο κειμένου για αυτές τις εργασίες. Δείτε τη [σελίδα μοντέλου Body Builder](https://openrouter.ai/openrouter/bodybuilder) στο OpenRouter.

Ενέργειες:

 - Για να προσθέσετε ένα μοντέλο, κάντε κλικ στο **Προσθήκη** ή οπουδήποτε στην καταχώριση.

 - Για να αφαιρέσετε ένα μοντέλο, κάντε κλικ στο **X** δίπλα του στην **Επιλεγμένα Μοντέλα** ή **Επιλεγμένο** στην καταχώρηση των Διαθέσιμων Μοντέλων.

 - Για να εκκαθαρίσετε τη λίστα, κάντε κλικ στο **Αποεπιλογή όλων**. Το απαιτούμενο δωρεάν μοντέλο θα παραμείνει στη λίστα.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Εάν δεν επιθυμείτε να προσθέσετε πιστωτικούς πόντους στο OpenRouter αμέσως, ξεκινήστε ενεργοποιώντας το **Μόνο Δωρεάν** και επιλέγοντας τα δωρεάν μοντέλα (χωρίς απαίτηση πιστωτικής κάρτας). Μπορείτε επίσης να χρησιμοποιήσετε το Ollama για να εκτελέσετε μοντέλα τοπικά χωρίς κλειδί API.

### Γλώσσες

- **Κορυφαίες γλώσσες** παραμένουν προσκολλημένες κοντά στην κορυφή των λιστών γλωσσών στις λειτουργίες **Μετάφραση** και **Μετασχηματισμός**.
- **Προσαρμοσμένη γλώσσα** σας επιτρέπει να προσθέσετε μια γλώσσα που δεν υπάρχει στην προκαθορισμένη λίστα.

Εάν προσθέσετε προσαρμοσμένη γλώσσα, θα εμφανίζεται στα πεδία επιλογής γλωσσών μαζί με τις προκαθορισμένες επιλογές.

<a id="cost-tracking"></a>
### Παρακολούθηση κόστους

Χρησιμοποιήστε **Ρυθμίσεις** > **Παρακολούθηση Κόστους** για να διαχειριστείτε τις πληροφορίες κόστους.

- **Συνολικό Κόστος** εμφανίζει το μερικό άθροισμα.
- **Αντιγραφή Τιμής** αντιγράφει το συνολικό στο πρόχειρο.
- **Επαναφορά Κόστους** μηδενίζει το αποθηκευμένο σύνολο.
- **Συγχρονισμός με χρήση κλειδιού API** ορίζει το σύνολο ώστε να αντιστοιχεί με τη χρήση που αναφέρει ο λογαριασμός OpenRouter σας (μόνο για OpenRouter).
- **Χρήση Κλειδιού API** εμφανίζει λεπτομέρειες χρήσης OpenRouter, εφόσον είναι διαθέσιμες.
- **Διαγραφή δεδομένων κόστους** διαγράφει όλα τα δεδομένα, ή μόνο καταχωρήσεις παλαιότερες από μια ορισμένη ημερομηνία.

**Παρακολούθηση κόστους:** Όταν χρησιμοποιείτε μοντέλα OpenRouter, η εφαρμογή σας δείχνει την πραγματική χρήση και δαπάνη με βάση τα στοιχεία κόστους από το OpenRouter. Για όλους τους άλλους παρόχους, η εφαρμογή υπολογίζει κόστη χρησιμοποιώντας τιμές που δημοσιεύει το OpenRouter· εάν η τιμή δεν είναι διαθέσιμη, η εκτίμηση μπορεί να είναι μηδέν.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> **Όλα τα στοιχεία κόστους είναι εκτιμήσεις μόνο για αναφορά σας, όχι επίσημες εκκαθαρίσεις χρέωσης.**

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Η διαγραφή δεδομένων δεν μπορεί να αναιρεθεί. Πριν από τη διαγραφή, βεβαιωθείτε ότι έχετε δημιουργήσει αντίγραφο ασφαλείας ή τα έχετε εξαγάγει μέσω [**Ιστορικό**](#history) 
> ή [**Κεντρικός Πίνακας** > **Όλες οι Κλήσεις**](#dashboard-tabs), αλλιώς θα χαθούν μόνιμα. 
> Όλο το ιστορικό εισόδου/εξόδου που σχετίζεται με κάθε καταχώριση κλήσης API θα διαγραφεί επίσης.

<a id="api-config"></a>
### Διαμόρφωση API

Οι υποστηριζόμενοι πάροχοι είναι: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και **Ollama** (τοπικά μοντέλα μέσω μιας βασικής URL). Χρειάζεται να διαμορφώσετε μόνο τους παρόχους που χρησιμοποιείτε.

**Εφαρμογή διαδικτύου: μόνο διαχειριστής**

Τα κλειδιά API διαμορφώνονται μέσω συστημικών μεταβλητών περιβάλλοντος ή μεταβλητών περιβάλλοντος Docker — δεν εισάγονται στο διεπαφή χρήστη ιστού. Αυτή η σελίδα εμφανίζει ποιοι πάροχοι έχουν κλειδί διαμορφωμένο και σας επιτρέπει να ελέγξετε κάθε έναν κάνοντας κλικ στο κουμπί **`Δοκιμή`**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Για να αλλάξετε ένα κλειδί API, ενημερώστε τη μεταβλητή περιβάλλοντος στη σύστησή σας ή τη διαμόρφωση Docker και επανεκκινήστε τον διακομιστή ή τον δοχείο.

<br/>

**Εφαρμογή υπολογιστή**

Χρησιμοποιήστε **Διαμόρφωση API** για να αποθηκεύσετε κλειδιά API για κάθε πάροχο που χρησιμοποιείτε. Για το Ollama, εισάγετε τη **βασική διεύθυνση URL** αντί για κλειδί API.

<br/>

> 💡 **Συμβουλή** <br/>
> Εάν δεν επιθυμείτε να χρησιμοποιήσετε κλειδί API ή να πληρώσετε για χρήση, μπορείτε να [κατεβάσετε το Ollama](https://ollama.com) και να τρέξετε μοντέλα (όπως το `translategemma:4b`) τοπικά στον υπολογιστή σας δωρεάν. Εναλλακτικά, μπορείτε να δημιουργήσετε έναν δωρεάν λογαριασμό OpenRouter (χωρίς απαίτηση πιστωτικής κάρτας) για να χρησιμοποιήσετε δωρεάν μοντέλα τους, ή να λάβετε δωρεάν κλειδί API από την Cerebras, Google, Groq ή Mistral AI.

<br/>

- Προσθέστε μόνο τους παρόχους που χρειάζεστε. Στο **Ρυθμίσεις** > **Μοντέλα**, κάθε ταυτότητα μοντέλου ξεκινάει με τον πάροχο (παράδειγμα: `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Για να προσθέσετε ένα κλειδί API, εισαγάγετε την τιμή στο πεδίο κειμένου και πατήστε **`Αποθήκευση`**. Για να αντικαταστήσετε ένα υπάρχον κλειδί, κάντε κλικ στο **`Επεξεργασία`**. Για να επαληθεύσετε ότι ένα κλειδί λειτουργεί, κάντε κλικ στο **`Δοκιμή`**. Για τη βασική διεύθυνση URL του Ollama, κάντε πάντα κλικ στο **`Δοκιμή`** για να ελέγξετε τη σύνδεση.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Δεν μπορείτε να δείτε την τρέχουσα τιμή ενός κλειδιού API. Μπορείτε μόνο να το αντικαταστήσετε χρησιμοποιώντας το κουμπί **`Επεξεργασία`**.
> Τα κλειδιά API αποθηκεύονται κρυπτογραφημένα στη διαμόρφωση.

<a id="common-issues"></a>
## Συνηθισμένα προβλήματα

Αν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα τα παρακάτω σημεία.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Η εφαρμογή δεν μεταφράζει, δεν ξαναγράφει ή δεν μετασχηματίζει το κείμενο

Ελέγξτε τα εξής:

- έχετε επιλέξει ένα μοντέλο στη γραμμή εργαλείων
- τουλάχιστον ένα μοντέλο εμφανίζεται στα [**Ρυθμίσεις** > **Μοντέλα**](#models)
- η διαμόρφωση του API λειτουργεί σωστά

Αν χρησιμοποιείτε την εφαρμογή για υπολογιστή:

1. Ανοίξτε τις [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config).
2. Βεβαιωθείτε ότι έχει αποθηκευτεί τουλάχιστον ένα κλειδί API.
3. Κάντε κλικ στο **Δοκιμή** δίπλα στο πάροχο για να επιβεβαιώσετε ότι το κλειδί λειτουργεί.

<br/>

<a id="the-model-list-is-empty"></a>
### Η λίστα μοντέλων είναι κενή

Ανοίξτε τις [**Ρυθμίσεις** > **Μοντέλα**](#models) και κάντε κλικ στο **Ανανέωση**.

Αν χρειαστεί:

- αναζητήστε ένα μοντέλο
- ενεργοποιήστε την επιλογή **Μόνο δωρεάν**
- προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα μοντέλα**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Το αποτέλεσμα είναι πολύ αργό ή πολύ ακριβό

Δοκιμάστε ένα ή περισσότερα από τα παρακάτω:

- επιλέξτε διαφορετικό μοντέλο
- χρησιμοποιήστε μικρότερο κείμενο εισόδου
- απενεργοποιήστε την επιλογή **Μετάφραση σε πραγματικό χρόνο (κατά τη δακτυλογράφηση)** στις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings)
- χρησιμοποιήστε δωρεάν μοντέλα για απλές εργασίες (δείτε [Μοντέλα](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Η διεπαφή είναι σε λάθος γλώσσα

Κάντε κλικ στο εικονίδιο της γης στη [γραμμή εργαλείων](#toolbar) και επιλέξτε την επιθυμητή **Γλώσσα διεπαφής**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Το κείμενο είναι πολύ μικρό ή δύσκολο στην ανάγνωση

Ανοίξτε τις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings) και αλλάξτε:

- **Οικογένεια γραμματοσειράς**
- **Μέγεθος**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Τα διαγράμματα του πίνακα ελέγχου είναι κενά

Αυτό είναι φυσιολογικό αν:

- χρησιμοποιείτε μόνο **δωρεάν μοντέλα** (τα διαγράμματα κόστους θα είναι άδεια)
- το επιλεγμένο **φίλτρο χρόνου** δεν καλύπτει την περίοδο κατά την οποία έγιναν κλήσεις — δοκιμάστε **Όλα** για έλεγχο

Αν τα διαγράμματα παραμένουν άδεια αφού επιλέξετε **Όλα**, βεβαιωθείτε ότι οι κλήσεις εμφανίζονται στην [**Ιστορικό**](#history) ή στην καρτέλα **Όλες οι κλήσεις**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Το κόστος εμφανίζεται ως "μη διαθέσιμο" ή φαίνεται λανθασμένο

Όταν χρησιμοποιείτε μοντέλα μέσω **OpenRouter**, η εφαρμογή εμφανίζει τα πραγματικά σας έξοδα όπως τα αναφέρει το OpenRouter.

Για **άλλους παρόχους** (OpenAI απευθείας, Anthropic απευθείας, κ.λπ.), το κόστος υπολογίζεται βάσει των δημοσιευμένων τιμών από το OpenRouter. Εάν δεν βρεθεί αντίστοιχη τιμή για ένα μοντέλο, το κόστος θα εμφανίζεται ως **μη διαθέσιμο** και δεν θα προστεθεί στο συνολικό ποσό σας.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Το συνολικό κόστος δεν ταιριάζει με τον λογαριασμό του παρόχου

Όλα τα ποσά κόστους στην εφαρμογή είναι **εκτιμήσεις για αναφορά μόνο** και όχι επίσημες λογαριασίες.

Για να πλησιάσετε το σύνολο προς τα πραγματικά σας έξοδα σε OpenRouter, ανοίξτε τις [**Ρυθμίσεις** > **Παρακολούθηση κόστους**](#cost-tracking) και κάντε κλικ στο **Συγχρονισμός με χρήση του κλειδιού API**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Η σελίδα Ιστορικό λείπει από την πλευρική μπάρα

Η επιλογή **Διατήρηση ιστορικού εκτέλεσης** μπορεί να είναι απενεργοποιημένη. Ανοίξτε τις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings) και ενεργοποιήστε την. Σημειώστε ότι η ενεργοποίηση αυτής της επιλογής δεν επαναφέρει τα δεδομένα του ιστορικού που διαγράφηκαν προηγουμένως.

<br/>

<a id="web-app-session-expired"></a>
### Ιστοσελίδα: ανακατεύθυνση στη σελίδα σύνδεσης απροσδόκητα

Η συνεδρία σας ίσως έχει λήξει. Συνδεθείτε ξανά. Αν συμβαίνει συχνά, ελέγξτε τη διαμόρφωση του διακομιστή για τις ρυθμίσεις διάρκειας συνεδρίας.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### Ο πίνακας ελέγχου δεν εμφανίζει δεδομένα για άλλους χρήστες (ιστοσελίδα)

Μόνο οι **διαχειριστές** μπορούν να δουν δεδομένα από όλους τους χρήστες μέσω του φίλτρου **Χρήστης**. Οι συνηθισμένοι χρήστες δουν μόνο τη δραστηριότητά τους από σχεδιασμό.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Άλλαξα ένα προτρεπτικό (prompt) και έχασα τις αλλαγές

Κατά την επεξεργασία ενός προτρεπτικού, κάντε πάντα κλικ στο **Αποθήκευση** πριν κάνετε κλικ στο **Επιστροφή στην εκτέλεση**.

<br/><br/>

<a id="quick-tips"></a>
## Γρήγορες συμβουλές

- Ξεκινήστε με [**Μετάφραση**](#translate) για να βεβαιωθείτε ότι η διαμόρφωση σας δουλεύει πριν προχωρήσετε στην [**Ξανάγραψη**](#rewrite) ή [**Μετασχηματισμό**](#transform).
- Χρησιμοποιήστε [**Ξανάγραψη**](#rewrite) για καθημερινές βελτιώσεις στη διατύπωση.
- Χρησιμοποιήστε [**Μετασχηματισμό**](#transform) όταν χρειάζεστε επαναλήψιμη ροή εργασιών για συγκεκριμένη εργασία.
- Χρησιμοποιήστε [**Πίνακα Ελέγχου**](#dashboard) αν θέλετε να ελέγχετε τη χρήση και το κόστος.
- Χρησιμοποιήστε [**Ιστορικό**](#history) για να επαναθεωρείτε προηγούμενες ενέργειες και τα πλήρη κείμενα εισόδου/εξόδου.
- Εξάγετε τα προτρεπτικά τακτικά αν φτιάχνετε βιβλιοθήκη προτρεπτικών που θέλετε να διατηρήσετε ασφαλή (δείτε [Μετασχηματισμός προτρεπτικών](#transform-prompts)) ή αν θέλετε να τη μοιραστείτε με άλλους.
