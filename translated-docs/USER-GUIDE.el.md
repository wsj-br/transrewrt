# Εγχειρίδιο Χρήστη

<br/>

<a id="introduction"></a>
## Εισαγωγή

Το Transrewrt σας βοηθά να επεξεργαστείτε κείμενο με τρεις βασικούς τρόπους:

- **Μετάφραση** - μετατροπή κειμένου από μία γλώσσα σε άλλη.
- **Αναδιατύπωση** - αναδιατύπωση κειμένου με διαφορετικό ύφος, όπως πιο σαφές, πιο σύντομο ή πιο επίσημο.
- **Μετασχηματισμός** - επεξεργασία κειμένου χρησιμοποιώντας προσαρμοσμένες οδηγίες τεχνητής νοημοσύνης που ονομάζονται ερωτήματα.

<br/>

Αυτό το εγχειρίδιο εξηγεί πώς να χρησιμοποιήσετε την εφαρμογή αφού έχει εγκατασταθεί και εκτελείται. Για τα βήματα εγκατάστασης, δείτε το κύριο [**README**](README.el.md).

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το Transrewrt είναι διαθέσιμο ως εφαρμογή επιτραπεζίου για Windows και Linux, καθώς και ως εφαρμογή ιστού που μπορείτε να φιλοξενήσετε μόνοι σας. Αυτό το εγχειρίδιο επικεντρώνεται στην καθημερινή χρήση της εφαρμογής. Όπου κάτι ισχύει μόνο για μία έκδοση, αναφέρεται ρητά.

<a id="before-you-start"></a>
## Πριν ξεκινήσετε

Για να χρησιμοποιήσετε το Transrewrt, χρειάζεστε πρόσβαση σε τουλάχιστον έναν πάροχο τεχνητής νοημοσύνης. Οι υποστηριζόμενοι πάροχοι είναι: [OpenRouter](https://openrouter.ai) (ο οποίος συγκεντρώνει πολλά μοντέλα), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και [Ollama](https://ollama.com) για τοπικά μοντέλα.

Δεν χρειάζεται να επιλέξετε ένα μοντέλο με χρέωση για να ξεκινήσετε. Μόλις προσθέσετε το κλειδί API του OpenRouter, η εφαρμογή ενεργοποιεί αυτόματα μια ενσωματωμένη **δωρεάν** επιλογή OpenRouter. Αυτό σας επιτρέπει να ξεκινήσετε αμέσως τη μετάφραση, αναδιατύπωση και μετασχηματισμό κειμένου. Εναλλακτικά, μπορείτε επίσης να λάβετε ένα δωρεάν κλειδί API από τους Cerebras, Google, Groq ή Mistral AI.

Με απλά λόγια:

- Ένα **μοντέλο** είναι η μηχανή τεχνητής νοημοσύνης που εκτελεί την εργασία. Τα μοντέλα εμφανίζονται με **πρόθεμα παρόχου** (π.χ. `openrouter/…`, `openai/…`, `ollama/…`).
- Ένα **κλειδί API** (ή, για το Ollama, μια **βασική διεύθυνση URL**) είναι ο τρόπος με τον οποίο η εφαρμογή επικοινωνεί με τον πάροχο.

Αν χρησιμοποιείτε την **εφαρμογή για υπολογιστή**, προσθέστε κλειδιά στο [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config) για κάθε πάροχο που χρησιμοποιείτε. Για χρήση μόνο OpenRouter, δείτε παρακάτω [Πώς να λάβετε ένα κλειδί API](#how-to-get-an-api-key-desktop-app). Αν δεν θέλετε να χρησιμοποιήσετε κλειδί API, μπορείτε να εγκαταστήσετε το Ollama (από το [ollama.com](https://ollama.com)) και να χρησιμοποιήσετε τοπικά μοντέλα, όπως το `translategemma:4b`.

Αν χρησιμοποιείτε την **έκδοση ιστού**, ο διαχειριστής του διακομιστή ρυθμίζει τους παρόχους μέσω μεταβλητών περιβάλλοντος, οπότε δεν μπορείτε να εισάγετε κλειδιά API απευθείας στην εφαρμογή.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Πώς να λάβετε ένα δωρεάν κλειδί API από το OpenRouter (εφαρμογή για υπολογιστή)

Αν χρησιμοποιείτε την εφαρμογή για υπολογιστή, ακολουθήστε αυτά τα βήματα:

1. Μεταβείτε στο [OpenRouter](https://openrouter.ai) μέσω του προγράμματος περιήγησής σας.
2. Δημιουργήστε λογαριασμό ή συνδεθείτε.
3. Ανοίξτε τη σελίδα [Keys](https://openrouter.ai/keys).
4. Κάντε κλικ στο κουμπί για να δημιουργήσετε ένα νέο κλειδί API.
5. Δώστε ένα όνομα στο κλειδί για να μπορείτε να το αναγνωρίσετε αργότερα.
6. Αντιγράψτε το νέο κλειδί API.
7. Επιστρέψτε στο Transrewrt και ανοίξτε **Ρυθμίσεις** > **Διαμόρφωση API**.
8. Επικολλήστε το κλειδί στο πεδίο **OpenRouter API key** (υπό **Ρυθμίσεις** > **Διαμόρφωση API**).
9. Κάντε κλικ στο **Δοκιμή κλειδιού OpenRouter** για να βεβαιωθείτε ότι λειτουργεί.

<br/><br/>

<a id="getting-started"></a>
## Ξεκινώντας

Αν χρησιμοποιείτε για πρώτη φορά το Transrewrt, ακολουθήστε αυτή τη σειρά:

1. Ανοίξτε την εφαρμογή.
2. Επιλέξτε την **Γλώσσα διεπαφής** σας από το εικονίδιο της γης, αν χρειάζεται.
3. Αν χρησιμοποιείτε την **εφαρμογή για υπολογιστή**, ανοίξτε [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config), προσθέστε ένα κλειδί API για τουλάχιστον έναν πάροχο (π.χ. OpenRouter) και κάντε κλικ στο **Δοκιμή** για να επιβεβαιώσετε ότι λειτουργεί.
4. Ανοίξτε [**Ρυθμίσεις** > **Μοντέλα**](#models) και προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα μοντέλα**.
5. Ανοίξτε [**Ρυθμίσεις** > **Γλώσσες**](#languages) και επιλέξτε τις **Κορυφαίες γλώσσες** σας, αν θέλετε οι πιο συχνά χρησιμοποιούμενες γλώσσες σας να εμφανίζονται πρώτες.
6. Μεταβείτε στο **Μετάφραση** και εκτελέστε μια απλή μετάφραση για να επιβεβαιώσετε ότι όλα λειτουργούν.
7. Μόλις λειτουργήσει, δοκιμάστε το **Αναδιατύπωση** και στη συνέχεια το **Μετασχηματισμός**.

Η σειρά αυτή έχει σημασία. Αποτρέπει το πιο συνηθισμένο πρόβλημα κατά την πρώτη χρήση: την προσπάθεια εκτέλεσης μιας εργασίας πριν η εφαρμογή έχει μια λειτουργική σύνδεση API ή ένα επιλεγμένο μοντέλο.

### Γραμμή εργαλείων

Η γραμμή εργαλείων αλλάζει ελαφρώς ανάλογα με το πού βρίσκεστε στην εφαρμογή.

- Στα αριστερά, εμφανίζει το όνομα της τρέχουσας σελίδας.
- Στα δεξιά, εμφανίζει τον **επιλογέα μοντέλου** και τον έλεγχο της **Γλώσσας διεπαφής**.

Ο **επιλογέας μοντέλου** σας επιτρέπει να επιλέξετε ποια μηχανή τεχνητής νοημοσύνης θα χρησιμοποιηθεί για την τρέχουσα εργασία.

![Model selector](../images/screenshots/el/model-selector.png)

Ορισμένα δωρεάν μοντέλα ενδέχεται να μην είναι πάντα διαθέσιμα — μερικές φορές είναι offline ή έχουν όριο χρήσης. Σε αυτήν την περίπτωση, η εφαρμογή θα αφαιρέσει αυτόματα το μοντέλο από τη διαθέσιμη λίστα σας. Για να ελέγξετε ποια μοντέλα εμφανίζονται, μεταβείτε στις [**Ρυθμίσεις** > **Μοντέλα**](#models) και επεξεργαστείτε τη λίστα μοντέλων. Μπορείτε επίσης να ανοίξετε απευθείας τις ρυθμίσεις μοντέλου κάνοντας κλικ στο εικονίδιο παρόχου στα αριστερά του ονόματος του μοντέλου στη γραμμή εργαλείων.

<br/>

Το **εικονίδιο γης + κωδικός γλώσσας** αλλάζει τη γλώσσα της διεπαφής της εφαρμογής, όπως τα μενού και τα κουμπιά. **Δεν** αλλάζει τις γλώσσες μετάφρασης που χρησιμοποιούνται στην ενότητα **Μετάφραση**.

![Interface language selector](../images/screenshots/el/language-selector.png)

<a id="input-and-output-panels"></a>
### Πάνελ εισόδου και εξόδου

Η πλειονότητα των χώρων εργασίας χρησιμοποιεί ένα αριστερό πάνελ **Εισόδου** και ένα δεξί πάνελ **Εξόδου**.

Κάθε πάνελ εμφανίζει επίσης:

| **Είσοδος**                                                          | **Έξοδος**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Αριθμός χαρακτήρων <br/>- Αριθμός λέξεων <br/>- Αριθμός παραγράφων   <br/> | - Διάρκεια εργασίας<br/>- **TPS** (tokens ανά δευτερόλεπτο)<br/>- Αριθμός χαρακτήρων, λέξεων και παραγράφων<br/>- Το μοντέλο που χρησιμοποιήθηκε |

Αν αναρωτιέστε για τους τεχνικούς όρους:

- **Token** σημαίνει ένα μικρό τμήμα κειμένου. Μπορείτε να το θεωρήσετε ως μέρος μιας λέξης ή μια σύντομη λέξη.
- **TPS** σημαίνει πόσα από αυτά τα τμήματα κειμένου επεξεργάστηκε το μοντέλο κάθε δευτερόλεπτο.

<br/>

Μπορείτε επίσης να παρακολουθείτε το κόστος κάθε λειτουργίας (αν είναι διαθέσιμο) και το συνολικό κόστος, ενεργοποιώντας την επιλογή `Show cost information on the actions` στις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings).

<a id="translate"></a>
## Μετάφραση

Χρησιμοποιήστε την ενότητα **Μετάφραση** όταν θέλετε να μετατρέψετε κείμενο από μια γλώσσα σε άλλη.

![Translate workspace](../images/screenshots/el/translate.png)

<br/>

<a id="translate-text"></a>
### Μετάφραση κειμένου

1. Ανοίξτε την ενότητα **Μετάφραση**.
2. Επιλέξτε μια γλώσσα στο **Από**.
3. Επιλέξτε μια γλώσσα στο **Προς**.
4. Επιλέξτε ένα μοντέλο στη γραμμή εργαλείων.
5. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Input**.
6. Κάντε κλικ στο **Translate**.
7. Διαβάστε το αποτέλεσμα στο **Output**.
8. Χρησιμοποιήστε το κουμπί αντιγραφής αν θέλετε να αντιγράψετε το αποτέλεσμα.

<br/>

<a id="language-selection"></a>
### Επιλογή γλώσσας

- Το **From** μπορεί να είναι μια συγκεκριμένη γλώσσα ή **Detect Language**.
- Το **To** είναι η γλώσσα στην οποία θέλετε να εμφανιστεί το αποτέλεσμα.

Οι επιλεγμένες **Top languages** εμφανίζονται στην κορυφή της λίστας. Μπορείτε να τις ορίσετε στις [**Ρυθμίσεις** > **Γλώσσες**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Χρήσιμες ρυθμίσεις μετάφρασης

<a id="transform"></a>
## Μετασχηματισμός

Χρησιμοποιήστε το **Μετασχηματισμός** όταν θέλετε το AI να ακολουθήσει ένα προσαρμοσμένο σύνολο οδηγιών.

![Transform workspace](../images/screenshots/el/transform.png)

Αυτή είναι η πιο ευέλικτη περιοχή της εφαρμογής. Μπορείτε να τη χρησιμοποιήσετε για εργασίες όπως:

- σύνοψη σημειώσεων
- μετατροπή ασαφούς κειμένου σε επεξεργασμένο email
- εξαγωγή βασικών σημείων
- μετατροπή κειμένου σε συγκεκριμένη μορφή
- οποιαδήποτε άλλη προσαρμοσμένη ενέργεια με το κείμενο εισόδου

<br/>

<a id="run-an-existing-prompt"></a>
### Εκτέλεση υπάρχοντος ερωτήματος

1. Ανοίξτε το **Μετασχηματισμός**.
2. Επιλέξτε ένα ερώτημα από τη λίστα ερωτημάτων.
3. Αν εμφανιστεί το πλαίσιο **Προορισμός** γλώσσας, επιλέξτε μια γλώσσα αν το επιθυμείτε.
4. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Είσοδος**.
5. Κάντε κλικ στο **Μετασχηματισμός**.
6. Διαβάστε το αποτέλεσμα στο **Έξοδος**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### Αν δεν έχετε ακόμη ερωτήματα

Αν η λίστα ερωτημάτων σας είναι κενή, κάντε κλικ στο **Φόρτωση δειγμάτων ερωτημάτων** στο χώρο εργασίας Μετασχηματισμού. Ο ίδιος έλεγχος είναι πάντα διαθέσιμος στο [**Ρυθμίσεις** > **Ερωτήματα μετασχηματισμού**](#transform-prompts) στη γραμμή εξαγωγής/εισαγωγής. Και τα δύο προσθέτουν ενσωματωμένα παραδείγματα ώστε να μπορείτε να ξεκινήσετε γρήγορα.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Τα δείγματα ερωτημάτων παρέχονται στα αγγλικά. Μετά τη φόρτωσή τους, μπορείτε να επεξεργαστείτε ένα ερώτημα και να χρησιμοποιήσετε την επιλογή **Μετάφραση ερωτήματος** για να το μεταφράσετε στη γλώσσα σας.

<br/>

<a id="create-a-prompt-quickly"></a>
### Δημιουργία ερωτήματος γρήγορα

Ο πιο γρήγορος τρόπος για να δημιουργήσετε ένα ερώτημα είναι:

1. Κάντε κλικ στο **Νέο ερώτημα**.
2. Κάντε κλικ στο **Δημιουργία ερωτήματος**.
3. Περιγράψτε τι θέλετε να κάνει το ερώτημα.
4. Επιλέξτε ένα μοντέλο.
5. Αφήστε την εφαρμογή να δημιουργήσει ένα προσχέδιο για εσάς.
6. Ελέγξτε το προσχέδιο και κάντε κλικ στο **Αποθήκευση**.

![Generate prompt](../images/screenshots/el/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### Επεξεργασία ερωτήματος

Όταν δημιουργείτε ή επεξεργάζεστε ένα ερώτημα, ο επεξεργαστής εμφανίζεται στα αριστερά και μια περιοχή δοκιμής εμφανίζεται στα δεξιά.

![Transform prompt editor](../images/screenshots/el/transform-prompt-edit.png)

Τα κύρια πεδία είναι:

- **Όνομα ερωτήματος**: το όνομα που εμφανίζεται στη λίστα ερωτημάτων.
- **Οδηγίες ερωτήματος (προαιρετικό)**: μια σύντομη υπόδειξη που εμφανίζεται στον χρήστη όταν εκτελείται το ερώτημα.
- **Ρόλος μοντέλου**: ο γενικός ρόλος που ανατίθεται στον τεχνητό νοημοσύνη, όπως 'Είσαι ένας χρήσιμος βοηθός.'
- **Οδηγίες μοντέλου (μία ανά γραμμή)**: οι συγκεκριμένοι κανόνες που θέλετε να ακολουθεί η τεχνητή νοημοσύνη.
- **Περιγραφή εξόδου**: μια σύντομη λέξη που περιγράφει το αποτέλεσμα, όπως 'περίληψη' ή 'αναδιατύπωση'.
- **Θερμοκρασία (0,0 → 1,0)**: το πώς θα συμπεριφέρεται το μοντέλο· δείτε παρακάτω.
- **Ερώτηση για γλώσσα προορισμού**: προσθέτει επιλογέα γλώσσας προορισμού όταν εκτελείται το ερώτημα.

Αν ο τεχνικός όρος **Θερμοκρασία** είναι καινούριος για εσάς, σκεφτείτε τον ως εξής:

- Μια **χαμηλότερη** θερμοκρασία δίνει πιο σταθερά και προβλέψιμα αποτελέσματα.
- Μια **υψηλότερη** θερμοκρασία δίνει περισσότερη ποικιλία και δημιουργικότητα.

Μπορείτε επίσης να χρησιμοποιήσετε:

- `Generate prompt` για να δημιουργήσετε ένα νέο προσχέδιο από μια απλή περιγραφή
- `Improve prompt` για να βελτιώσετε ένα υπάρχον ερώτημα
- `Translate prompt` για να μεταφράσετε τα πεδία του ερωτήματος

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Κάντε κλικ στο `Save` πριν κάνετε κλικ στο `Back to Run`. Αν επιστρέψετε πίσω χωρίς να αποθηκεύσετε, οι αλλαγές σας θα χαθούν.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### Δοκιμή ερωτήματος πριν τη χρήση του

Το πίνακας δοκιμής στα δεξιά σας επιτρέπει να δοκιμάσετε το ερώτημα σας με δείγμα κειμένου πριν το χρησιμοποιήσετε στην καθημερινή εργασία.

Αυτό είναι χρήσιμο όταν:

- δημιουργείτε ένα νέο ερώτημα
- συγκρίνετε δύο εκδόσεις ενός ερωτήματος
- θέλετε να ελέγξετε τον τόνο, το μήκος ή τη μορφή εξόδου

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Μπορείτε να εξαγάγετε και να εισαγάγετε αποθηκευμένα ερωτήματα στις [**Ρυθμίσεις** > **Ερωτήματα μετασχηματισμού**](#transform-prompts).

<a id="general-settings"></a>
### Γενικές ρυθμίσεις

Χρησιμοποιήστε τις **Γενικές ρυθμίσεις** για να ελέγξετε τη συμπεριφορά πληκτρολόγησης, αν αποθηκεύονται λεπτομέρειες εκτέλεσης για το **Ιστορικό**, και την εμφάνιση.

**Συμπεριφορά**

- **Συμπεριφορά για ENTER** επιλέγει αν το `Enter` εκτελεί την εργασία ή εισάγει νέα γραμμή.
- **Αυτόματη μετάφραση κατά την επικόλληση** ξεκινά τη μετάφραση μόλις επικολλήσετε κείμενο.
- **Αυτόματη αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει αυτόματα τα επιτυχημένα αποτελέσματα.
- **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** μεταφράζει καθώς πληκτρολογείτε.
- **Χρονικό όριο (ms)** ορίζει τον χρόνο αναμονής για τη μετάφραση σε πραγματικό χρόνο.

**Ιστορικό**

- **Διατήρηση ιστορικού εκτέλεσης** ελέγχει αν κάθε μετάφραση, αναδιατύπωση και μετασχηματισμός αποθηκεύει **είσοδο και έξοδο κειμένου** για την προβολή [**Ιστορικό**](#history) στην πλευρική μπάρα. Η απενεργοποίηση ζητά επιβεβαίωση· αν επιβεβαιώσετε, το αποθηκευμένο κείμενο ιστορικού αφαιρείται από τη βάση δεδομένων.
- **Διαγραφή δεδομένων ιστορικού** σας επιτρέπει να αφαιρέσετε αποθηκευμένο κείμενο ανά ηλικία (π.χ. παλαιότερο από μερικούς μήνες, ή **όλα τα δεδομένα (εκκαθάριση)**) χρησιμοποιώντας το **Διαγραφή δεδομένων**. Αυτό επηρεάζει μόνο το αποθηκευμένο κείμενο εκτέλεσης για την προβολή **Ιστορικό**· **δεν** διαγράφει τα συνολικά κόστη ή τα συνολικά δεδομένα χρήσης. Για να αφαιρέσετε ή να περικόψετε δεδομένα **κόστους**, χρησιμοποιήστε [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking).

**Εμφάνιση**

- **Εμφάνιση πληροφοριών κόστους στις ενέργειες** ελέγχει την εμφάνιση του κόστους ανά λειτουργία (αν είναι διαθέσιμο) και του συνολικού κόστους στα πάνελ εξόδου Μετάφρασης, Αναδιατύπωσης και Μετασχηματισμού.
- **Ψηφία κλάσματος κόστους** αλλάζει τον τρόπο εμφάνισης των δεκαδικών κόστους.
- **Μόνο για ιστό:** **εμφάνιση περιθωρίου γύρω από την εφαρμογή** προσθέτει επιπλέον χώρο γύρω από τη διεπαφή.
- **Οικογένεια γραμματοσειράς** αλλάζει τη γραμματοσειρά στα πάνελ κειμένου.
- **Μέγεθος** αλλάζει το μέγεθος της γραμματοσειράς.

**Αντίγραφο ασφαλείας διαμόρφωσης**

- **Συμπερίληψη δεδομένων χρήσης στο αντίγραφο ασφαλείας** - όταν ενεργοποιημένο, το ZIP περιέχει επίσης ιστορικό εκτέλεσης και δεδομένα κλήσεων API.
- **Δημιουργία αντιγράφου ασφαλείας διαμόρφωσης** - δημιουργεί ένα μοναδικό ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` σε UTC από προεπιλογή) με `config.json`, `state.json`, προαιρετικό κλειδί κρυπτογράφησης, χρήστες, προτιμήσεις, προσαρμοσμένα ερωτήματα και δεδομένα χρήσης αν το έχετε επιλέξει. Μετά από επιτυχή δημιουργία αντιγράφου ασφαλείας, η επιβεβαίωση εμφανίζει το όνομα του αποθηκευμένου αρχείου.
- **Επαναφορά από αντίγραφο ασφαλείας** - ανοίγει πρώτα ένα **παράθυρο επιβεβαίωσης**. Επιλέξτε το ZIP αντιγράφου ασφαλείας μέσα στο παράθυρο (**Περιήγηση** / επιλογή αρχείου ή σύρσιμο-και-απόθεση όπου υποστηρίζεται), στη συνέχεια ελέγξτε τις επιλογές:
  - **Επαναφορά δεδομένων χρήσης** - εισάγει δεδομένα χρήσης/ιστορικού από το ZIP όταν είχε δημιουργηθεί αντίγραφο ασφαλείας με συμπεριλαμβανόμενη χρήση· αφήστε το απενεργοποιημένο αν θέλετε μόνο ρυθμίσεις και ερωτήματα.
  - **Εκκαθάριση παλαιών δεδομένων χρήσης πριν την επαναφορά** - αφαιρεί τα υπάρχοντα δεδομένα χρήσης/ιστορικού σε αυτή την εγκατάσταση πριν εφαρμοστεί το αντίγραφο ασφαλείας (προαιρετικό· χρησιμοποιήστε όταν θέλετε καθαρή αντικατάσταση).

Τα αντίγραφα ασφαλείας που δημιουργούνται στην έκδοση ιστού ή στην επιτραπέζια έκδοση μπορούν να επαναφερθούν στην άλλη. Όταν επαναφέρετε ένα επιτραπέζιο αντίγραφο ασφαλείας στην έκδοση ιστού, τα δεδομένα θα επαναφερθούν στον χρήστη διαχειριστή.

<a id="models"></a>
### Μοντέλα

Χρησιμοποιήστε τις **Ρυθμίσεις** > **Μοντέλα** για να επιλέξετε ποια μοντέλα εμφανίζονται στη γραμμή εργαλείων.

![Settings Models tab](../images/screenshots/el/settings-models.png)

Η σελίδα έχει δύο λίστες:

- **Διαθέσιμα μοντέλα** στα αριστερά
- **Επιλεγμένα μοντέλα** στα δεξιά

Χρήσιμοι έλεγχοι περιλαμβάνουν:

- **Αναζήτηση μοντέλων...** για να βρείτε ένα μοντέλο με βάση το όνομά του
- **Πάροχος** chips για να περιορίσετε τη λίστα σε ένα μηχανή (OpenRouter, OpenAI, Ollama, …)
- **Μόνο δωρεάν** για να εμφανίσετε μόνο δωρεάν μοντέλα
- **Ανανέωση** για να φορτώσετε ξανά τη λίστα
- **Ανάπτυξη όλων** και **Σύμπτυξη όλων** όταν ταξινομείτε ανά πάροχο

Τα αναγνωριστικά μοντέλων περιλαμβάνουν το πρόθεμα παρόχου (π.χ. `openrouter/…` έναντι `openai/…`). Οι ετικέτες όπως **OpenAI (OpenRouter)** έναντι **OpenAI (άμεση)** δείχνουν πώς δρομολογείται η κίνηση.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το **OpenRouter Body Builder** (`openrouter/bodybuilder`) είναι ένα μοντέλο δρομολόγησης, όχι ένα γενικό μοντέλο συνομιλίας: η απάντησή του είναι JSON που περιγράφει σώματα αιτημάτων API του OpenRouter (π.χ. ένας πίνακας `requests` με `model` και `messages`). Αν το χρησιμοποιήσετε για **Μετάφραση**, **Αναδιατύπωση** ή **Μετασχηματισμό**, το παράθυρο εξόδου θα εμφανίσει αυτό το JSON αντί για ολοκληρωμένο κείμενο. Επιλέξτε ένα κανονικό μοντέλο κειμένου για αυτές τις εργασίες. Δείτε τη [σελίδα μοντέλου Body Builder](https://openrouter.ai/openrouter/bodybuilder) στο OpenRouter.

Ενέργειες:

- Για να προσθέσετε ένα μοντέλο, κάντε κλικ στο **Προσθήκη** ή οπουδήποτε στην καταχώριση.

- Για να αφαιρέσετε ένα μοντέλο, κάντε κλικ στο **X** δίπλα του στα **Επιλεγμένα μοντέλα** ή στο **Επιλεγμένα** στην καταχώριση στα Διαθέσιμα μοντέλα.

- Για να εκκαθαρίσετε τη λίστα, κάντε κλικ στο **Αποεπιλογή όλων**. Το απαιτούμενο δωρεάν μοντέλο θα παραμείνει στη λίστα.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Αν δεν θέλετε να προσθέσετε πιστωτικούς μονάδες στο OpenRouter αμέσως, ξεκινήστε ενεργοποιώντας το **Μόνο δωρεάν** και επιλέγοντας τα δωρεάν μοντέλα (δεν απαιτείται πιστωτική κάρτα). Μπορείτε επίσης να χρησιμοποιήσετε το Ollama για να εκτελέσετε μοντέλα τοπικά χωρίς κλειδί API.

<a id="cost-tracking"></a>
### Παρακολούθηση Κόστους

Χρησιμοποιήστε το **Ρυθμίσεις** > **Παρακολούθηση Κόστους** για να διαχειριστείτε τις πληροφορίες κόστους.

- **Συνολικό κόστος** εμφανίζει το συνολικό ποσό.
- **Αντιγραφή Τιμής** αντιγράφει το σύνολο στο πρόχειρο.
- **Επαναφορά κόστους** μηδενίζει το αποθηκευμένο σύνολο.
- **Συγχρονισμός με χρήση κλειδιού API** ορίζει το σύνολο να ταιριάζει με τη χρήση που αναφέρεται από τον λογαριασμό OpenRouter σας (μόνο για OpenRouter).
- **Χρήση Κλειδιού API** εμφανίζει λεπτομέρειες χρήσης του OpenRouter, αν είναι διαθέσιμες.
- **Διαγραφή δεδομένων κόστους** αφαιρεί όλα τα δεδομένα ή μόνο καταχωρίσεις παλαιότερες από μια επιλεγμένη ημερομηνία.

**Παρακολούθηση κόστους:** Όταν χρησιμοποιείτε μοντέλα OpenRouter, η εφαρμογή εμφανίζει την πραγματική σας χρήση και δαπάνη με βάση τις πληροφορίες κόστους από το OpenRouter. Για όλους τους άλλους παρόχους, η εφαρμογή εκτιμά τα κόστη χρησιμοποιώντας τις τιμές που δημοσιεύονται από το OpenRouter· αν δεν υπάρχει διαθέσιμη τιμή, η εκτίμηση μπορεί να είναι μηδέν.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> **Όλα τα στοιχεία κόστους είναι εκτιμήσεις για αναφορά σας, όχι επίσημες χρεώσεις.**

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Η διαγραφή δεδομένων δεν μπορεί να αναιρεθεί. Πριν τη διαγραφή, βεβαιωθείτε ότι έχετε δημιουργήσει αντίγραφο ασφαλείας ή το έχετε εξαγάγει μέσω [**Ιστορικό**](#history)
> ή [**Επιτραπέζιος πίνακας** > **Όλες οι κλήσεις**](#dashboard-tabs), διαφορετικά θα χαθεί οριστικά.
> Όλο το ιστορικό εισόδου/εξόδου που σχετίζεται με κάθε καταχώριση κλήσης API θα διαγραφεί επίσης.

<a id="api-config"></a>
### Διαμόρφωση API

Οι υποστηριζόμενοι πάροχοι είναι: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και **Ollama** (τοπικά μοντέλα μέσω βασικού URL). Χρειάζεται να διαμορφώσετε μόνο τους παρόχους που χρησιμοποιείτε.

**Εφαρμογή ιστού: μόνο διαχειριστής**

Οι API keys διαμορφώνονται μέσω μεταβλητών περιβάλλοντος του συστήματος ή του Docker – δεν εισάγονται στο διεπαφή ιστού. Αυτή η σελίδα εμφανίζει ποιοι πάροχοι έχουν διαμορφωμένο κλειδί και σας επιτρέπει να το δοκιμάσετε κάνοντας κλικ στο κουμπί `Test`.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Για να αλλάξετε ένα κλειδί API, ενημερώστε τη μεταβλητή περιβάλλοντος στη ρύθμιση του συστήματος ή του Docker και επανεκκινήστε τον διακομιστή ή τον δοχείο.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Τα **αντίγραφα ασφαλείας διαμόρφωσης** (δείτε [**Γενικές ρυθμίσεις** → Αντίγραφο ασφαλείας διαμόρφωσης](#general-settings)) μπορούν να ενσωματώνουν **επιλυμένα** κλειδιά παρόχου μέσα στο `config.json` του ZIP. Η επαναφορά αυτού του ZIP **δεν** αντιγράφει αυτά τα κλειδιά πίσω στο αρχείο διαμόρφωσης του διακομιστή – τα ενεργά κλειδιά προέρχονται ακόμα από το περιβάλλον και την υπάρχουσα κατάσταση του αρχείου, όπως περιγράφεται εκεί.

<br/>

**Εφαρμογή υπολογιστή**

Χρησιμοποιήστε την επιλογή **Διαμόρφωση API** για να αποθηκεύσετε τα κλειδιά API για κάθε πάροχο που χρησιμοποιείτε. Για το Ollama, εισάγετε το **βασικό URL** αντί για κλειδί API.

<br/>

> 💡 **Συμβουλή** <br/>
> Εάν δεν θέλετε να χρησιμοποιήσετε κλειδί API ή να πληρώσετε για χρήση, μπορείτε να [κατεβάσετε το Ollama](https://ollama.com) και να εκτελέσετε μοντέλα (όπως το `translategemma:4b`) τοπικά στον υπολογιστή σας δωρεάν. Εναλλακτικά, μπορείτε να δημιουργήσετε δωρεάν λογαριασμό στο OpenRouter (χωρίς κάρτα πιστώσεως) για να χρησιμοποιήσετε τα δωρεάν μοντέλα τους, ή να αποκτήσετε δωρεάν κλειδί API από τις εταιρείες Cerebras, Google, Groq ή Mistral AI.

<br/>

- Προσθέστε μόνο τους παρόχους που χρειάζεστε. Στις **Ρυθμίσεις** > **Μοντέλα**, κάθε αναγνωριστικό μοντέλου ξεκινά με τον πάροχο (π.χ. `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Για να προσθέσετε ένα κλειδί API, εισάγετε την τιμή στο πεδίο κειμένου και κάντε κλικ στο `Save`. Για να αντικαταστήσετε ένα υπάρχον κλειδί, κάντε κλικ στο `Edit`. Για να επαληθεύσετε ότι ένα κλειδί λειτουργεί, κάντε κλικ στο `Test`. Για το βασικό URL του Ollama, κάντε πάντα κλικ στο `Test` για να ελέγξετε τη σύνδεση.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Δεν μπορείτε να δείτε την τρέχουσα τιμή ενός κλειδιού API. Μπορείτε μόνο να το αντικαταστήσετε χρησιμοποιώντας το κουμπί `Edit`.
> Τα κλειδιά API αποθηκεύονται κρυπτογραφημένα στη διαμόρφωση.

<a id="common-issues"></a>
## Συνηθισμένα προβλήματα

Αν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα τα παρακάτω σημεία.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Η εφαρμογή δεν μεταφράζει, αναδιατυπώνει ή μετασχηματίζει το κείμενο

Ελέγξτε ότι:

- έχετε επιλέξει ένα μοντέλο στη γραμμή εργαλείων
- τουλάχιστον ένα μοντέλο εμφανίζεται στις [**Ρυθμίσεις** > **Μοντέλα**](#models)
- η διαμόρφωση του API λειτουργεί σωστά

Αν χρησιμοποιείτε την εφαρμογή για υπολογιστή:

1. Ανοίξτε τις [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config).
2. Ελέγξτε ότι έχει αποθηκευτεί τουλάχιστον ένα κλειδί API.
3. Κάντε κλικ στο **Δοκιμή** δίπλα στον πάροχο για να επιβεβαιώσετε ότι το κλειδί λειτουργεί.

<br/>

<a id="the-model-list-is-empty"></a>
### Η λίστα μοντέλων είναι κενή

Ανοίξτε τις [**Ρυθμίσεις** > **Μοντέλα**](#models) και κάντε κλικ στο **Ανανέωση**.

Αν χρειαστεί:

- αναζητήστε ένα μοντέλο
- ενεργοποιήστε την επιλογή **Μόνο δωρεάν**
- προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα μοντέλα**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Το αποτέλεσμα είναι πολύ αργό ή πολύ ακριβό

Δοκιμάστε ένα ή περισσότερα από τα εξής:

- επιλέξτε διαφορετικό μοντέλο
- χρησιμοποιήστε μικρότερη είσοδο
- απενεργοποιήστε την **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** στις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings)
- χρησιμοποιήστε δωρεάν μοντέλα για απλές εργασίες (δείτε [Μοντέλα](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Η διεπαφή είναι στη λάθος γλώσσα

Κάντε κλικ στο εικονίδιο της γης στη [γραμμή εργαλείων](#toolbar) και επιλέξτε την επιθυμητή **Γλώσσα διεπαφής**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Το κείμενο είναι πολύ μικρό ή δύσκολο στην ανάγνωση

Ανοίξτε τις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings) και αλλάξτε:

- **Οικογένεια γραμματοσειράς**
- **Μέγεθος**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Οι γραφικές παραστάσεις του επιτραπέζιου πίνακα είναι κενές

Αυτό είναι φυσιολογικό αν:

- χρησιμοποιείτε μόνο **δωρεάν μοντέλα** και εξετάζετε τα στοιχεία **κόστους** (μπορεί να είναι μηδενικά)· τα διαγράμματα κλήσεων **χρήσης** στην **Περίληψη** χρειάζονται ακόμα δεδομένα από την επιλεγμένη περίοδο  
- το επιλεγμένο **φίλτρο χρόνου** δεν καλύπτει την περίοδο κατά την οποία έγιναν οι κλήσεις· δοκιμάστε **Όλα** για να ελέγξετε

Αν οι γραφικές παραστάσεις παραμένουν κενές ακόμη και μετά την επιλογή **Όλα**, επιβεβαιώστε ότι εμφανίζονται κλήσεις στο [**Ιστορικό**](#history) ή στην καρτέλα **Όλες οι κλήσεις**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Το κόστος εμφανίζει «μη διαθέσιμο» ή φαίνεται λανθασμένο

Όταν χρησιμοποιείτε μοντέλα μέσω **OpenRouter**, η εφαρμογή εμφανίζει την πραγματική σας δαπάνη όπως αναφέρεται από το OpenRouter.

Για **άλλους παρόχους** (OpenAI άμεση, Anthropic άμεση, κ.λπ.), το κόστος εκτιμάται από δεδομένα τιμολόγησης που δημοσιεύονται από το OpenRouter. Εάν δεν βρεθεί αντίστοιχη τιμή για ένα μοντέλο, το κόστος θα εμφανίζεται ως **μη διαθέσιμο** και δεν θα προστίθεται στο συνολικό σας ποσό.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Το συνολικό κόστος δεν ταιριάζει με το λογαριασμό του παρόχου μου

Όλα τα στοιχεία κόστους στην εφαρμογή είναι **εκτιμήσεις για αναφορά μόνο**, όχι επίσημες χρεώσεις.

Για να πλησιάσετε το συνολικό κόστος στην πραγματική σας δαπάνη στο OpenRouter, ανοίξτε [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking) και κάντε κλικ στο **Συγχρονισμός με χρήση κλειδιού API**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Η σελίδα Ιστορικό λείπει από την πλευρική μπάρα

Η επιλογή **Διατήρηση ιστορικού εκτέλεσης** μπορεί να είναι απενεργοποιημένη. Ανοίξτε [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings) και ενεργοποιήστε την. Σημειώστε ότι η ενεργοποίησή της δεν επαναφέρει δεδομένα που έχουν διαγραφεί προηγουμένως.

<br/>

<a id="web-app-session-expired"></a>
### Ιστοσελίδα: ανακατεύθυνση στη σελίδα σύνδεσης απροσδόκητα

Η συνεδρία σας μπορεί να έχει λήξει. Συνδεθείτε ξανά. Αν συμβαίνει συχνά, ελέγξτε τη διαμόρφωση του διακομιστή για τις ρυθμίσεις διάρκειας συνεδρίας.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### Διαχειριστής ιστού: ξέχασα ή έχασα τον κωδικό πρόσβασης

Αυτό ισχύει για την **εφαρμογή ιστού με αυτο-φιλοξενία** (Docker), όχι για την εφαρμογή επιφάνειας εργασίας (Electron).

- Αν κάποιος άλλος διαχειριστής μπορεί ακόμη να συνδεθεί, μπορεί να ανοίξει [**Ρυθμίσεις** > **Χρήστες**](#users), να επιλέξει τον λογαριασμό και να ορίσει έναν **νέο κωδικό πρόσβασης** εκεί.
- Αν είστε **κλειδωμένος έξω** αλλά έχετε **πρόσβαση σε κέλυφος** στη μηχανή ή τον δοχεία, επαναφέρετε τον κωδικό πρόσβασης με το εργαλείο που παρέχεται με την εικόνα (αλλάξτε το `transrewrt` αν έχετε αλλάξει το προεπιλεγμένο όνομα, και βάλτε εισαγωγικά στον κωδικό αν περιέχει κενά ή ειδικούς χαρακτήρες):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Το προεπιλεγμένο όνομα χρήστη διαχειριστή είναι το `admin` αν δεν έχετε δημιουργήσει άλλους λογαριασμούς. Όταν δίνετε μόνο ένα όρισμα, αυτό αντιμετωπίζεται ως ο νέος κωδικός πρόσβασης για το `admin`.

Αν εκτελείτε από **πηγαίο κώδικα** αντί για Docker, χρησιμοποιήστε:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

Το σενάριο ενημερώνει το αρχείο χρήστη στη βάση δεδομένων SQLite (και μπορεί να δημιουργήσει τον `admin` χρήστη αν λείπει). Μετά την επαναφορά, συνδεθείτε με το νέο κωδικό πρόσβασης.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### Ο επιτραπέζιος πίνακας δεν εμφανίζει δεδομένα για άλλους χρήστες (ιστός)

Μόνο οι **διαχειριστές** μπορούν να δουν δεδομένα από όλους τους χρήστες μέσω του φίλτρου **Χρήστη**. Οι συνηθισμένοι χρήστες βλέπουν μόνο τη δική τους δραστηριότητα, όπως έχει σχεδιαστεί.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Άλλαξα ένα ερώτημα και έχασα τις επεξεργασίες

Όταν επεξεργάζεστε ένα ερώτημα, κάντε πάντα κλικ στο **Αποθήκευση** πριν κάνετε κλικ στο **Επιστροφή στην Εκτέλεση**.

<a id="quick-tips"></a>
## Γρήγορες συμβουλές

- Ξεκινήστε με [**Μετάφραση**](#translate) για να βεβαιωθείτε ότι η ρύθμισή σας λειτουργεί πριν προχωρήσετε στο [**Αναδιατύπωση**](#rewrite) ή στο [**Μετασχηματισμό**](#transform).
- Χρησιμοποιήστε την [**Αναδιατύπωση**](#rewrite) για καθημερινές βελτιώσεις διατύπωσης.
- Χρησιμοποιήστε τον [**Μετασχηματισμό**](#transform) όταν χρειάζεστε επαναλαμβανόμενη ροή εργασιών για μια συγκεκριμένη εργασία.
- Χρησιμοποιήστε τον [**Επιτραπέζιο πίνακα**](#dashboard) αν θέλετε να παρακολουθείτε τη χρήση και το κόστος.
- Χρησιμοποιήστε το [**Ιστορικό**](#history) για να ελέγξετε τις προηγούμενες λειτουργίες και το πλήρες κείμενο εισόδου/εξόδου τους.
- Εξάγετε τα ερωτήματα τακτικά αν δημιουργείτε μια βιβλιοθήκη ερωτημάτων που θέλετε να διατηρήσετε ασφαλή (δείτε [Ερωτήματα μετασχηματισμού](#transform-prompts)) ή αν θέλετε να την μοιραστείτε με άλλους.
