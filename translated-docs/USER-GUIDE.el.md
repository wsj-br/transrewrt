# Εγχειρίδιο Χρήστη

<br/>

<a id="introduction"></a>
## Εισαγωγή

Το Transrewrt σας βοηθά να εργάζεστε με κείμενο με τρεις βασικούς τρόπους:

- **Μετάφραση** - μετατροπή κειμένου από μία γλώσσα σε άλλη.
- **Αναδιατύπωση** - επαναδιατύπωση κειμένου με διαφορετικό ύφος, όπως πιο σαφές, πιο σύντομο ή πιο επίσημο.
- **Μετασχηματισμός** - επεξεργασία κειμένου χρησιμοποιώντας προσαρμοσμένες οδηγίες τεχνητής νοημοσύνης που ονομάζονται ερωτήματα.

<br/>

Αυτό το εγχειρίδιο εξηγεί πώς να χρησιμοποιήσετε την εφαρμογή αφού εγκατασταθεί και εκτελείται. Για τα βήματα εγκατάστασης, δείτε το κύριο **[README](README.el.md)**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το Transrewrt είναι διαθέσιμο ως εφαρμογή επιφάνειας εργασίας για Windows και Linux, και ως εφαρμογή ιστού που μπορείτε να φιλοξενήσετε εσείς οι ίδιοι. Αυτό το εγχειρίδιο επικεντρώνεται στην καθημερινή χρήση της εφαρμογής. Όπου κάτι ισχύει μόνο για μία έκδοση, σημειώνεται ρητά.

<a id="before-you-start"></a>
## Πριν ξεκινήσετε

Για να χρησιμοποιήσετε το Transrewrt, χρειάζεστε πρόσβαση σε τουλάχιστον έναν πάροχο τεχνητής νοημοσύνης. Οι υποστηριζόμενοι πάροχοι είναι: [OpenRouter](https://openrouter.ai) (ο οποίος συγκεντρώνει πολλά μοντέλα), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και [Ollama](https://ollama.com) για τοπικά μοντέλα.

Δεν χρειάζεται να επιλέξετε ένα μοντέλο με χρέωση για να ξεκινήσετε. Μόλις προσθέσετε το κλειδί API OpenRouter, η εφαρμογή ενεργοποιεί αυτόματα μία ενσωματωμένη επιλογή **δωρεάν** OpenRouter. Αυτό σας επιτρέπει να ξεκινήσετε αμέσως τη μετάφραση, αναδιατύπωση και μετασχηματισμό κειμένου. Εναλλακτικά, μπορείτε επίσης να αποκτήσετε ένα δωρεάν κλειδί API από τους Cerebras, Google, Groq ή Mistral AI.

Με απλά λόγια:

- Ένα **μοντέλο** είναι η μηχανή τεχνητής νοημοσύνης που κάνει τη δουλειά. Τα μοντέλα παρουσιάζονται με **πρόθεμα παρόχου** (π.χ. `openrouter/…`, `openai/…`, `ollama/…`).
- Ένα **κλειδί API** (ή, για το Ollama, μια **βασική διεύθυνση URL**) είναι ο τρόπος με τον οποίο η εφαρμογή επικοινωνεί με τον πάροχο.

Εάν χρησιμοποιείτε την **εφαρμογή για υπολογιστή**, προσθέστε κλειδιά στην ενότητα [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config) για κάθε πάροχο που χρησιμοποιείτε. Για χρήση μόνο του OpenRouter, δείτε παρακάτω [Πώς να αποκτήσετε ένα κλειδί API δωρεάν](#how-to-get-an-api-key-desktop-app). Εάν δεν θέλετε να χρησιμοποιήσετε κλειδί API, μπορείτε να εγκαταστήσετε το Ollama (από το [ollama.com](https://ollama.com)) και να χρησιμοποιήσετε τοπικά μοντέλα αντί αυτού, όπως το `translategemma:4b`.

Εάν χρησιμοποιείτε την **έκδοση ιστού**, ο διαχειριστής του διακομιστή διαμορφώνει τους παρόχους μέσω μεταβλητών περιβάλλοντος, οπότε δεν μπορείτε να εισαγάγετε κλειδιά API απευθείας στην εφαρμογή.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Πώς να αποκτήσετε δωρεάν κλειδί API OpenRouter (εφαρμογή για υπολογιστή)

Εάν χρησιμοποιείτε την εφαρμογή για υπολογιστή, ακολουθήστε αυτά τα βήματα:

1. Μεταβείτε στο [OpenRouter](https://openrouter.ai) μέσω του προγράμματος περιήγησής σας.
2. Δημιουργήστε λογαριασμό ή συνδεθείτε.
3. Ανοίξτε τη σελίδα [Κλειδιά](https://openrouter.ai/keys).
4. Κάντε κλικ στο κουμπί για να δημιουργήσετε ένα νέο κλειδί API.
5. Δώστε ένα όνομα στο κλειδί ώστε να μπορείτε να το αναγνωρίσετε αργότερα.
6. Αντιγράψτε το νέο κλειδί API.
7. Επιστρέψτε στο Transrewrt και ανοίξτε **Ρυθμίσεις** > **Διαμόρφωση API**.
8. Επικολλήστε το κλειδί στο πεδίο **OpenRouter API key** (υπό **Ρυθμίσεις** > **Διαμόρφωση API**).
9. Κάντε κλικ στο **Δοκιμή κλειδιού OpenRouter** για να βεβαιωθείτε ότι λειτουργεί.

<a id="getting-started"></a>
## Ξεκινώντας

Εάν είναι η πρώτη φορά που χρησιμοποιείτε το Transrewrt, ακολουθήστε αυτή τη σειρά:

1. Ανοίξτε την εφαρμογή.
2. Επιλέξτε τη **Γλώσσα διεπαφής** σας από το εικονίδιο της γης, αν χρειαστεί.
3. Αν χρησιμοποιείτε την **εφαρμογή επιφάνειας εργασίας**, ανοίξτε [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config), προσθέστε ένα κλειδί API για τουλάχιστον ένα πάροχο (π.χ. OpenRouter) και κάντε κλικ στο **Δοκιμή** για να επαληθεύσετε ότι λειτουργεί.
4. Ανοίξτε [**Ρυθμίσεις** > **Μοντέλα**](#models) και προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα μοντέλα**.
5. Ανοίξτε [**Ρυθμίσεις** > **Γλώσσες**](#languages) και επιλέξτε τις **Κορυφαίες γλώσσες** σας, αν θέλετε οι πιο συχνά χρησιμοποιούμενες γλώσσες σας να εμφανίζονται πρώτες.
6. Μεταβείτε στο **Μετάφραση** και εκτελέστε μια απλή μετάφραση για να επιβεβαιώσετε ότι όλα λειτουργούν.
7. Όταν αυτό λειτουργήσει, δοκιμάστε το **Αναδιατύπωση** και στη συνέχεια το **Μετασχηματισμός**.

Η σειρά αυτή έχει σημασία. Αποτρέπει το πιο συνηθισμένο πρόβλημα κατά την πρώτη χρήση: την προσπάθεια εκτέλεσης μιας εργασίας πριν η εφαρμογή έχει μια λειτουργική σύνδεση API ή ένα επιλεγμένο μοντέλο.

### Γραμμή εργαλείων

Η γραμμή εργαλείων αλλάζει ελαφρώς ανάλογα με το πού βρίσκεστε στην εφαρμογή.

- Στα αριστερά, εμφανίζει το όνομα της τρέχουσας σελίδας.
- Στα δεξιά, εμφανίζει τον **επιλογέα μοντέλου** και τον έλεγχο της **Γλώσσας διεπαφής**.

Ο **επιλογέας μοντέλου** σας επιτρέπει να επιλέξετε ποια μηχανή τεχνητής νοημοσύνης θα χρησιμοποιηθεί για την τρέχουσα εργασία.

![Model selector](../images/screenshots/el/model-selector.png)

Ορισμένα δωρεάν μοντέλα ενδέχεται να μην είναι πάντα διαθέσιμα — μερικές φορές είναι offline ή έχουν όριο χρήσης. Αν συμβεί αυτό, η εφαρμογή θα αφαιρέσει αυτόματα το μοντέλο από τη διαθέσιμη λίστα σας. Για να ελέγξετε ποια μοντέλα εμφανίζονται, μεταβείτε στις [**Ρυθμίσεις** > **Μοντέλα**](#models) και επεξεργαστείτε τη λίστα μοντέλων σας. 
Μπορείτε επίσης να ανοίξετε απευθείας τις ρυθμίσεις μοντέλου κάνοντας κλικ στο εικονίδιο παρόχου στα αριστερά του ονόματος του μοντέλου στη γραμμή εργαλείων.

<br/>

Το **εικονίδιο γης + κωδικός γλώσσας** αλλάζει τη γλώσσα της διεπαφής της εφαρμογής, όπως τα μενού και τα κουμπιά. **Δεν** αλλάζει τις γλώσσες μετάφρασης που χρησιμοποιούνται στη λειτουργία **Μετάφραση**.

![Interface language selector](../images/screenshots/el/language-selector.png)

<a id="input-and-output-panels"></a>
### Πάνελ εισόδου και εξόδου

Οι περισσότεροι χώροι εργασίας χρησιμοποιούν ένα πάνελ **Εισόδου** στα αριστερά και ένα πάνελ **Εξόδου** στα δεξιά.

Κάθε πάνελ εμφανίζει επίσης:

| **Είσοδος**                                                          | **Έξοδος**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Αριθμός χαρακτήρων <br/>- Αριθμός λέξεων <br/>- Αριθμός παραγράφων   <br/> | - Πόσο διήρκησε η εργασία<br/>- **TPS** (νομίσματα ανά δευτερόλεπτο)<br/>- Αριθμός χαρακτήρων, λέξεων και παραγράφων<br/>- Το μοντέλο που χρησιμοποιήθηκε |

Αν αναρωτιέστε για τους τεχνικούς όρους:

- **Νόμισμα** σημαίνει ένα μικρό τμήμα κειμένου. Μπορείτε να το θεωρήσετε ως μέρος μιας λέξης ή μια σύντομη λέξη.
- **TPS** σημαίνει πόσα από αυτά τα τμήματα κειμένου επεξεργάστηκε το μοντέλο κάθε δευτερόλεπτο.

<br/>

Μπορείτε επίσης να παρακολουθείτε το κόστος κάθε λειτουργίας (αν είναι διαθέσιμο) και το συνολικό κόστος, ενεργοποιώντας την επιλογή `Show cost information on the actions` στις [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings).

<a id="translate"></a>
## Μετάφραση

Χρησιμοποιήστε τη λειτουργία **Μετάφραση** όταν θέλετε να μετατρέψετε κείμενο από μια γλώσσα σε άλλη.

![Translate workspace](../images/screenshots/el/translate.png)

<br/>

<a id="translate-text"></a>
### Μετάφραση κειμένου

1. Ανοίξτε το **Μετάφραση**.
2. Επιλέξτε μια γλώσσα στο **Από**.
3. Επιλέξτε μια γλώσσα στο **Προς**.
4. Επιλέξτε ένα μοντέλο στη μπάρα εργαλείων.
5. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Είσοδος**.
6. Κάντε κλικ στο **Μετάφραση**.
7. Διαβάστε το αποτέλεσμα στο **Έξοδος**.
8. Χρησιμοποιήστε το κουμπί αντιγραφής αν θέλετε να αντιγράψετε το αποτέλεσμα.

<br/>

<a id="language-selection"></a>
### Επιλογή γλώσσας

- Το **Από** μπορεί να είναι μια συγκεκριμένη γλώσσα ή **Ανίχνευση γλώσσας**.
- Το **Προς** είναι η γλώσσα στην οποία θέλετε το αποτέλεσμα.

Οι επιλεγμένες **Κορυφαίες γλώσσες** εμφανίζονται στην κορυφή της λίστας. Μπορείτε να τις ορίσετε στις [**Ρυθμίσεις** > **Γλώσσες**](#languages).

<a id="run-an-existing-prompt"></a>
### Εκτέλεση υπάρχοντος ερωτήματος

Ο ίδιος έλεγχος είναι πάντα διαθέσιμος στο [**Ρυθμίσεις** > **Ερωτήματα μετατροπής**](#transform-prompts) στη γραμμή εξαγωγής/εισαγωγής. Και τα δύο προσθέτουν ενσωματωμένα παραδείγματα ώστε να μπορείτε να ξεκινήσετε γρήγορα.

<a id="create-a-prompt-quickly"></a>
### Δημιουργία ερωτήματος γρήγορα

Ο ταχύτερος τρόπος για να δημιουργήσετε ένα ερώτημα είναι:

1. Κάντε κλικ στο **Νέα προτροπή**.
2. Κάντε κλικ στο **Δημιουργία προτροπής**.
3. Περιγράψτε τι θέλετε να κάνει η προτροπή.
4. Επιλέξτε ένα μοντέλο.
5. Αφήστε την εφαρμογή να δημιουργήσει ένα προσχέδιο για εσάς.
6. Ελέγξτε το προσχέδιο και κάντε κλικ στο **Αποθήκευση**.

![Generate prompt](../images/screenshots/el/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### Επεξεργασία ερωτήματος

Όταν δημιουργείτε ή επεξεργάζεστε ένα ερώτημα, ο επεξεργαστής εμφανίζεται στα αριστερά και μια περιοχή δοκιμής εμφανίζεται στα δεξιά.

![Transform prompt editor](../images/screenshots/el/transform-prompt-edit.png)

Τα κύρια πεδία είναι:

- **Όνομα προτροπής**: το όνομα που εμφανίζεται στη λίστα προτροπών.
- **Οδηγίες προτροπής (προαιρετικό)**: μια σύντομη υπόδειξη που εμφανίζεται στον χρήστη κατά την εκτέλεση της προτροπής.
- **Ρόλος μοντέλου**: ο γενικός ρόλος που ανατίθεται στον Τεχνητό Νοημοσύνη, όπως 'Είσαι ένας βοηθητικός βοηθός.'
- **Οδηγίες μοντέλου (μία ανά γραμμή)**: οι συγκεκριμένοι κανόνες που θέλετε να ακολουθεί ο Τεχνητός Νοημοσύνη.
- **Περιγραφή εξόδου**: μια σύντομη λέξη που περιγράφει το αποτέλεσμα, όπως 'περίληψη' ή 'επανεκφώνηση'.
- **Θερμοκρασία (0,0 → 1,0)**: το πώς θα συμπεριφέρεται το μοντέλο· δείτε παρακάτω.
- **Ζήτηση γλώσσας στόχου**: προσθέτει επιλογέα γλώσσας στόχου όταν εκτελείται η προτροπή.

Αν ο τεχνικός όρος **Θερμοκρασία** είναι νέος για εσάς, σκεφτείτε τον ως εξής:

- Μια **χαμηλότερη** θερμοκρασία δίνει πιο σταθερά και προβλέψιμα αποτελέσματα.
- Μια **υψηλότερη** θερμοκρασία δίνει περισσότερη ποικιλία και δημιουργικότητα.

Μπορείτε επίσης να χρησιμοποιήσετε:

- **`Generate prompt`** για να δημιουργήσετε ένα νέο πρόχειρο από μια απλή περιγραφή
- **`Improve prompt`** για να βελτιώσετε ένα υπάρχον ερώτημα
- **`Translate prompt`** για να μεταφράσετε τα πεδία του ερωτήματος

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Κάντε κλικ στο **`Save`** πριν κάνετε κλικ στο **`Back to Run`**. Αν επιστρέψετε πίσω χωρίς να αποθηκεύσετε, οι αλλαγές σας θα χαθούν.

<br/>

Το πίνακας δοκιμής στα δεξιά σας επιτρέπει να δοκιμάσετε το ερώτημά σας με δείγμα κειμένου πριν το χρησιμοποιήσετε στην καθημερινή εργασία.

Αυτό είναι χρήσιμο όταν:

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>

<a id="general-settings"></a>
### Γενικές ρυθμίσεις

Χρησιμοποιήστε τις **Γενικές Ρυθμίσεις** για να ελέγξετε τη συμπεριφορά κατά την πληκτρολόγηση, αν αποθηκεύονται λεπτομέρειες εκτέλεσης για το **Ιστορικό**, και την εμφάνιση.

**Συμπεριφορά**

- **Συμπεριφορά για ENTER** επιλέγει αν το `Enter` εκτελεί την εργασία ή εισάγει νέα γραμμή.
- **Αυτόματη μετάφραση κατά την επικόλληση** ξεκινά τη μετάφραση μόλις επικολλήσετε κείμενο.
- **Αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει αυτόματα τα επιτυχημένα αποτελέσματα.
- **Μετάφραση σε πραγματικό χρόνο (κατά τη δακτυλογράφηση)** μεταφράζει καθώς πληκτρολογείτε.
- **Χρονικό όριο (ms)** ορίζει τον χρόνο αναμονής για τη μετάφραση σε πραγματικό χρόνο.

**Ιστορικό**

- **Διατήρηση ιστορικού εκτέλεσης** ελέγχει αν κάθε μετάφραση, αναδιατύπωση και μετασχηματισμός αποθηκεύει **είσοδο και έξοδο κειμένου** για την προβολή [**Ιστορικό**](#history) στην πλευρική μπάρα. Η απενεργοποίηση ζητά επιβεβαίωση· αν επιβεβαιώσετε, το αποθηκευμένο κείμενο ιστορικού αφαιρείται από τη βάση δεδομένων.
- **Διαγραφή δεδομένων ιστορικού** σας επιτρέπει να αφαιρέσετε αποθηκευμένο κείμενο βάσει ηλικίας (π.χ. παλαιότερο από μερικούς μήνες, ή **όλα τα δεδομένα (εκκαθάριση)**) χρησιμοποιώντας το **Διαγραφή δεδομένων**. Αυτό επηρεάζει μόνο το αποθηκευμένο κείμενο εκτέλεσης για την προβολή **Ιστορικό**· **δεν** διαγράφει το κόστος ή τα συνολικά στοιχεία χρήσης. Για να αφαιρέσετε ή να περικόψετε δεδομένα **κόστους**, χρησιμοποιήστε [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking).

**Εμφάνιση**

- **Εμφάνιση πληροφοριών κόστους στις ενέργειες** ελέγχει την εμφάνιση του κόστους ανά λειτουργία (αν είναι διαθέσιμο) και του συνολικού κόστους στα πάνελ εξόδου Μετάφρασης, Αναδιατύπωσης και Μετασχηματισμού.
- **Δεκαδικά ψηφία κόστους** αλλάζει τον τρόπο εμφάνισης των δεκαδικών του κόστους.
- **Μόνο για ιστό:** **εμφάνιση περιθωρίου γύρω από την εφαρμογή** προσθέτει επιπλέον χώρο γύρω από τη διεπαφή.
- **Οικογένεια γραμματοσειράς** αλλάζει τη γραμματοσειρά στα πάνελ κειμένου.
- **Μέγεθος** αλλάζει το μέγεθος της γραμματοσειράς.

**Αντίγραφο ασφαλείας διαμόρφωσης**

- **Συμπερίληψη δεδομένων χρήσης στο αντίγραφο ασφαλείας** - όταν ενεργοποιημένο, το ZIP περιλαμβάνει επίσης ιστορικό εκτελέσεων και δεδομένα κλήσεων API. 
- **Δημιουργία αντιγράφου ασφαλείας** - δημιουργεί ένα μοναδικό ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` σε UTC από προεπιλογή) με `config.json`, `state.json`, προαιρετικό κλειδί κρυπτογράφησης, χρήστες, προτιμήσεις, προσαρμοσμένες ερωτήσεις και δεδομένα χρήσης αν το έχετε επιλέξει. Μετά από επιτυχή δημιουργία αντιγράφου ασφαλείας, η επιβεβαίωση εμφανίζει το όνομα του αποθηκευμένου αρχείου.
- **Επαναφορά από αντίγραφο ασφαλείας** - ανοίγει πρώτα ένα **παράθυρο επιβεβαίωσης**. Επιλέξτε το ZIP αντιγράφου ασφαλείας μέσα στο παράθυρο (**Περιήγηση** / επιλογέας αρχείων ή σύρσιμο-και-απόθεση όπου υποστηρίζεται), στη συνέχεια ελέγξτε τις επιλογές:
  - **Επαναφορά δεδομένων χρήσης** - εισαγωγή χρήσης/ιστορικού από το ZIP όταν είχε δημιουργηθεί με συμπεριλαμβανόμενη τη χρήση· αφήστε το απενεργοποιημένο αν θέλετε μόνο ρυθμίσεις και ερωτήσεις.
  - **Διαγραφή παλαιών δεδομένων χρήσης πριν την επαναφορά** - διαγράφει τα υπάρχοντα δεδομένα χρήσης/ιστορικό σε αυτή την εγκατάσταση πριν εφαρμοστεί το αντίγραφο ασφαλείας (προαιρετικό· χρησιμοποιήστε όταν θέλετε καθαρή αντικατάσταση).

Τα αντίγραφα ασφαλείας που δημιουργούνται είτε στην έκδοση ιστού είτε στην έκδοση desktop μπορούν να επαναφερθούν στην άλλη. Όταν επαναφέρετε ένα αντίγραφο ασφαλείας desktop στην έκδοση ιστού, τα δεδομένα θα επαναφερθούν στον χρήστη διαχειριστή.

<a id="models"></a>
### Μοντέλα

Χρησιμοποιήστε τις **Ρυθμίσεις** > **Μοντέλα** για να επιλέξετε ποια μοντέλα εμφανίζονται στη γραμμή εργαλείων.

![Settings Models tab](../images/screenshots/el/settings-models.png)

Η σελίδα έχει δύο λίστες:

- **Διαθέσιμα μοντέλα** στα αριστερά
- **Επιλεγμένα μοντέλα** στα δεξιά

Χρήσιμες ρυθμίσεις περιλαμβάνουν:

- **Αναζήτηση μοντέλων...** για εύρεση μοντέλου με βάση το όνομα
- Ετικέτες **Πάροχος** για περιορισμό της λίστας σε ένα μηχανή (OpenRouter, OpenAI, Ollama, …)
- **Μόνο Δωρεάν** για εμφάνιση μόνο δωρεάν μοντέλων
- **Ανανέωση** για επαναφόρτωση της λίστας
- **Επέκταση Όλων** και **Σύμπτυξη Όλων** όταν ταξινομείτε κατά πάροχο

Τα ids μοντέλων περιλαμβάνουν το πρόθεμα του παρόχου (για παράδειγμα `openrouter/…` vs `openai/…`). Τα σήματα όπως **OpenAI (OpenRouter)** vs **OpenAI (άμεσο)** δείχνουν πώς κατευθύνεται η κίνηση.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) είναι ένα μοντέλο δρομολογητή, όχι ένα γενικό μοντέλο συνομιλίας: η απάντησή του είναι JSON που περιγράφει τα σώματα αιτημάτων API του OpenRouter (για παράδειγμα, ένα `requests` πίνακα με `model` και `messages`). Αν το χρησιμοποιήσετε για **Μετάφραση**, **Αναδιατύπωση** ή **Μετασχηματισμός**, το πάνελ εξόδου θα δείξει αυτό το JSON αντί για τελικό κείμενο. Επιλέξτε ένα κανονικό μοντέλο κειμένου για αυτές τις εργασίες. Δείτε τη [σελίδα μοντέλου Body Builder](https://openrouter.ai/openrouter/bodybuilder) στο OpenRouter.

Ενέργειες:

- Για να προσθέσετε ένα μοντέλο, κάντε κλικ στο **Προσθήκη** ή οπουδήποτε στην καταχώριση.

- Για να αφαιρέσετε ένα μοντέλο, κάντε κλικ στο **X** δίπλα του στα **Επιλεγμένα μοντέλα** ή **Επιλεγμένα** στην καταχώριση στα Διαθέσιμα μοντέλα.

- Για να εκκαθαρίσετε τη λίστα, κάντε κλικ στο **Απαλοιφή όλων**. Το απαιτούμενο δωρεάν μοντέλο θα παραμείνει στη λίστα.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Αν δεν θέλετε να προσθέσετε πιστώσεις στο OpenRouter αμέσως, ξεκινήστε ενεργοποιώντας το **Μόνο δωρεάν** και επιλέγοντας τα δωρεάν μοντέλα (δεν απαιτείται πιστωτική κάρτα). Μπορείτε επίσης να χρησιμοποιήσετε το Ollama για να εκτελέσετε μοντέλα τοπικά χωρίς κανένα κλειδί API.

<a id="cost-tracking"></a>
### Παρακολούθηση Κόστους

Χρησιμοποιήστε **Ρυθμίσεις** > **Παρακολούθηση Κόστους** για να διαχειριστείτε τις πληροφορίες κόστους.

- **Συνολικό Κόστος** εμφανίζει το συνεχιζόμενο σύνολο.
- **Αντιγραφή Τιμής** αντιγράφει το σύνολο στο πρόχειρο.
- **Επαναφορά Κόστους** επαναφέρει το αποθηκευμένο σύνολο στο μηδέν.
- **Συγχρονισμός με χρήση κλειδιού API** ορίζει το σύνολο να ταιριάζει με τη χρήση που αναφέρεται από το λογαριασμό OpenRouter (μόνο OpenRouter).
- **Χρήση Κλειδιού API** εμφανίζει λεπτομέρειες χρήσης OpenRouter, αν είναι διαθέσιμες.
- **Διαγραφή δεδομένων κόστους** διαγράφει όλα τα δεδομένα ή μόνο καταχωρήσεις πριν από μια επιλεγμένη ημερομηνία.

**Παρακολούθηση Κόστους:** Όταν χρησιμοποιείτε μοντέλα OpenRouter, η εφαρμογή δείχνει τη πραγματική σας χρήση και δαπάνες με βάση τις πληροφορίες κόστους από το OpenRouter. Για όλους τους άλλους παρόχους, η εφαρμογή εκτιμά τα κόστη χρησιμοποιώντας τις τιμές που δημοσιεύονται από το OpenRouter, αν μια τιμή δεν είναι διαθέσιμη, η εκτίμηση μπορεί να είναι μηδέν.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
>  **Όλες οι αριθμητικές τιμές κόστους είναι εκτιμήσεις μόνο για αναφορά σας, όχι επίσημες δηλώσεις χρέωσης.**

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Η διαγραφή δεδομένων δεν μπορεί να αναιρεθεί. Πριν τη διαγραφή, βεβαιωθείτε ότι έχετε δημιουργήσει αντίγραφο ασφαλείας ή έχετε εξαγάγει τα δεδομένα σας μέσω [**Ιστορικό**](#history)
> ή [**Ταμπλό** > **Όλες οι κλήσεις**](#dashboard-tabs), διαφορετικά θα χαθούν οριστικά.
> Όλο το ιστορικό εισόδου/εξόδου που σχετίζεται με κάθε καταχώριση κλήσης API θα διαγραφεί επίσης.

<a id="api-config"></a>
### Διαμόρφωση API

Οι υποστηριζόμενοι πάροχοι είναι: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και **Ollama** (τοπικά μοντέλα μέσω βασικού URL). Χρειάζεται να διαμορφώσετε μόνο τους παρόχους που χρησιμοποιείτε.

**Εφαρμογή ιστού: μόνο διαχειριστής**

Οι κλειδιά API διαμορφώνονται μέσω συστημικών ή μεταβλητών περιβάλλοντος Docker - δεν εισάγονται στο διεπαφή ιστού. Αυτή η σελίδα δείχνει ποιοι πάροχοι έχουν διαμορφωμένο κλειδί και σας επιτρέπει να τους δοκιμάσετε κάνοντας κλικ στο κουμπί **`Test`**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Για να αλλάξετε ένα κλειδί API, ενημερώστε τη μεταβλητή περιβάλλοντος στη ρύθμιση του συστήματος ή του Docker και επανεκκινήστε τον διακομιστή ή τον δοχείο.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Τα **αντίγραφα ασφαλείας διαμόρφωσης** (δείτε [**Γενικές Ρυθμίσεις** → Αντίγραφο ασφαλείας διαμόρφωσης](#general-settings)) μπορούν να ενσωματώσουν **επιλυμένα** κλειδιά παρόχου μέσα στο `config.json` του ZIP. Η επαναφορά αυτού του ZIP **δεν** αντιγράφει αυτά τα κλειδιά πίσω στο αρχείο διαμόρφωσης του διακομιστή - τα ενεργά κλειδιά εξακολουθούν να προέρχονται από το περιβάλλον και την υπάρχουσα κατάσταση αρχείου όπως περιγράφεται εκεί.

<br/>

**Εφαρμογή για υπολογιστή**

Χρησιμοποιήστε την επιλογή **Διαμόρφωση API** για να αποθηκεύσετε κλειδιά API για κάθε πάροχο που χρησιμοποιείτε. Για το Ollama, εισάγετε το **βασικό URL** αντί για κλειδί API.

<br/>

> 💡 **Συμβουλή** <br/>
> Αν δεν θέλετε να χρησιμοποιήσετε κλειδί API ή να πληρώσετε για χρήση, μπορείτε [να κατεβάσετε το Ollama](https://ollama.com) και να εκτελέσετε μοντέλα (όπως το `translategemma:4b`) τοπικά στον υπολογιστή σας δωρεάν. Εναλλακτικά, μπορείτε να δημιουργήσετε δωρεάν λογαριασμό στο OpenRouter (χωρίς απαίτηση πιστωτικής κάρτας) για να χρησιμοποιήσετε τα δωρεάν μοντέλα τους, ή να αποκτήσετε δωρεάν κλειδί API από την Cerebras, Google, Groq ή Mistral AI.

<br/>

- Προσθέστε μόνο τους παρόχους που χρειάζεστε. Στις **Ρυθμίσεις** > **Μοντέλα**, κάθε αναγνωριστικό μοντέλου ξεκινά με τον πάροχο (π.χ. `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Για να προσθέσετε κλειδί API, εισάγετε την τιμή στο πεδίο κειμένου και κάντε κλικ στο **`Save`**. Για να αντικαταστήσετε ένα υπάρχον κλειδί, κάντε κλικ στο **`Edit`**. Για να επαληθεύσετε ότι ένα κλειδί λειτουργεί, κάντε κλικ στο **`Test`**. Για το βασικό URL του Ollama, κάντε πάντα κλικ στο **`Test`** για να ελέγξετε τη σύνδεση.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Δεν μπορείτε να δείτε την τρέχουσα τιμή ενός κλειδιού API. Μπορείτε μόνο να το αντικαταστήσετε χρησιμοποιώντας το κουμπί **`Edit`**.
> Τα κλειδιά API αποθηκεύονται κρυπτογραφημένα στη διαμόρφωση.

<a id="common-issues"></a>
## Συνηθισμένα προβλήματα

Αν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα τα παρακάτω σημεία.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Η εφαρμογή δεν μεταφράζει, αναδιατυπώνει ή μετασχηματίζει το κείμενο

Ελέγξτε ότι:

- έχετε επιλέξει ένα μοντέλο στη γραμμή εργαλείων
- τουλάχιστον ένα μοντέλο εμφανίζεται στο [**Ρυθμίσεις** > **Μοντέλα**](#models)
- η διαμόρφωση του API σας λειτουργεί

Αν χρησιμοποιείτε την εφαρμογή για υπολογιστή:

1. Ανοίξτε το [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config).
2. Ελέγξτε ότι έχει αποθηκευτεί τουλάχιστον ένα κλειδί API.
3. Κάντε κλικ στο **Δοκιμή** δίπλα στον πάροχο για να επιβεβαιώσετε ότι το κλειδί λειτουργεί.

<br/>

<a id="the-model-list-is-empty"></a>
### Η λίστα μοντέλων είναι κενή

Ανοίξτε το [**Ρυθμίσεις** > **Μοντέλα**](#models) και κάντε κλικ στο **Ανανέωση**.

Αν χρειαστεί:

- αναζητήστε ένα μοντέλο
- ενεργοποιήστε το **Μόνο δωρεάν**
- προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα μοντέλα**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Το αποτέλεσμα είναι πολύ αργό ή πολύ ακριβό

Δοκιμάστε ένα ή περισσότερα από τα εξής:

- επιλέξτε διαφορετικό μοντέλο
- χρησιμοποιήστε μικρότερη είσοδο
- απενεργοποιήστε τη **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** στο [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings)
- χρησιμοποιήστε δωρεάν μοντέλα για απλές εργασίες (δείτε [Μοντέλα](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Η διεπαφή είναι στη λάθος γλώσσα

Κάντε κλικ στο εικονίδιο της γης στη [γραμμή εργαλείων](#toolbar) και επιλέξτε την επιθυμητή **Γλώσσα διεπαφής**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Το κείμενο είναι πολύ μικρό ή δύσκολο στην ανάγνωση

Ανοίξτε [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings) και αλλάξτε:

- **Οικογένεια γραμματοσειράς**
- **Μέγεθος**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Τα διαγράμματα του ταμπλό είναι κενά

Αυτό είναι φυσιολογικό αν:

- χρησιμοποιείτε μόνο **δωρεάν μοντέλα** και εξετάζετε τα στοιχεία **κόστους** (μπορεί να είναι μηδενικά· τα διαγράμματα αριθμού **κλήσεων χρήσης** στην καρτέλα **Περίληψη** χρειάζονται ακόμη δεδομένα από την επιλεγμένη περίοδο)
- το επιλεγμένο **φίλτρο χρόνου** δεν καλύπτει την περίοδο κατά την οποία έγιναν οι κλήσεις· δοκιμάστε **Όλα** για να ελέγξετε

Αν τα διαγράμματα παραμένουν κενά αφού επιλέξετε **Όλα**, επιβεβαιώστε ότι οι κλήσεις εμφανίζονται στην καρτέλα [**Ιστορικό**](#history) ή στην καρτέλα **Όλες οι κλήσεις**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Το κόστος εμφανίζει «μη διαθέσιμο» ή φαίνεται λανθασμένο

Όταν χρησιμοποιείτε μοντέλα μέσω **OpenRouter**, η εφαρμογή εμφανίζει την πραγματική σας δαπάνη όπως αναφέρεται από το OpenRouter.

Για **άλλους παρόχους** (OpenAI άμεσο, Anthropic άμεσο κ.λπ.), το κόστος εκτιμάται από δημοσιευμένα στοιχεία τιμολόγησης του OpenRouter. Εάν δεν βρεθεί αντίστοιχη τιμή για ένα μοντέλο, το κόστος θα εμφανίζεται ως **μη διαθέσιμο** και δεν θα προστίθεται στο συνολικό σας ποσό.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Το συνολικό κόστος δεν ταιριάζει με το λογαριασμό του παρόχου μου

Όλα τα στοιχεία κόστους στην εφαρμογή είναι **εκτιμήσεις για αναφορά μόνο**, όχι επίσημες εκκαθαριστικές πράξεις.

Για να πλησιάσετε το σύνολο στην πραγματική σας δαπάνη στο OpenRouter, ανοίξτε [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking) και κάντε κλικ στο **Συγχρονισμός με χρήση κλειδιού API**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Η σελίδα Ιστορικό λείπει από την πλευρική μπάρα

Η επιλογή **Διατήρηση ιστορικού εκτέλεσης** μπορεί να είναι απενεργοποιημένη. Ανοίξτε [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings) και ενεργοποιήστε την. Σημειώστε ότι η ενεργοποίησή της δεν επαναφέρει προηγούμενα διαγραμμένα δεδομένα ιστορικού.

<br/>

<a id="web-app-session-expired"></a>
### Ιστοσελίδα: ανακατεύθυνση στη σελίδα σύνδεσης απροσδόκητα

Η συνεδρία σας μπορεί να έχει λήξει. Συνδεθείτε ξανά. Αν συμβαίνει συχνά, ελέγξτε τη διαμόρφωση του διακομιστή για τις ρυθμίσεις διάρκειας συνεδρίας.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### Διαχειριστής ιστοσελίδας: ξέχασα ή έχασα τον κωδικό πρόσβασης

Αυτό ισχύει για την εφαρμογή ιστού **αυτο-φιλοξενούμενης** (Docker), όχι για την εφαρμογή επιφάνειας εργασίας (Electron).

- Αν άλλος διαχειριστής μπορεί ακόμη να συνδεθεί, μπορεί να ανοίξει [**Ρυθμίσεις** > **Χρήστες**](#users), να επιλέξει τον λογαριασμό και να ορίσει έναν **νέο κωδικό πρόσβασης** εκεί.
- Αν είστε **κλειδωμένοι έξω** αλλά έχετε **πρόσβαση σε κέλυφος** στη μηχανή ή τον δοχεία, επαναφέρετε τον κωδικό πρόσβασης με το εργαλείο βοηθό που παρέχεται με την εικόνα (αλλάξτε το `transrewrt` αν αλλάξετε το προεπιλεγμένο όνομα, και περικλείστε τον κωδικό πρόσβασης σε εισαγωγικά αν περιέχει κενά ή ειδικούς χαρακτήρες):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Το προεπιλεγμένο όνομα χρήστη διαχειριστή είναι το `admin` αν δεν έχετε δημιουργήσει ποτέ άλλους λογαριασμούς. Όταν δώσετε μόνο ένα όρισμα, αυτό θεωρείται ως ο νέος κωδικός πρόσβασης για το `admin`.

Αν εκτελέσετε από **έλεγχο πηγής** αντί για Docker, χρησιμοποιήστε:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

Το σενάριο ενημερώνει την εγγραφή του χρήστη στη βάση δεδομένων SQLite (και μπορεί να δημιουργήσει τον `admin` χρήστη αν λείπει). Μετά την επαναφορά, συνδεθείτε με τον νέο κωδικό πρόσβασης.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### Το Ταμπλό δεν εμφανίζει δεδομένα για άλλους χρήστες (ιστός)

Μόνο οι **διαχειριστές** μπορούν να δουν δεδομένα από όλους τους χρήστες μέσω του φίλτρου **Χρήστη**. Οι συνηθισμένοι χρήστες βλέπουν μόνο τη δική τους δραστηριότητα από σχεδιασμό.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Άλλαξα ένα ερώτημα και έχασα τις επεξεργασίες

Όταν επεξεργάζεστε ένα ερώτημα, κάντε πάντα κλικ στο **Αποθήκευση** πριν κάνετε κλικ στο **Επιστροφή στο Εκτέλεση**.

<a id="quick-tips"></a>
## Γρήγορες συμβουλές

- Ξεκινήστε με [**Μετάφραση**](#translate) για να βεβαιωθείτε ότι η διαμόρφωσή σας λειτουργεί πριν προχωρήσετε στην [**Αναδιατύπωση**](#rewrite) ή τον [**Μετασχηματισμό**](#transform).
- Χρησιμοποιήστε [**Αναδιατύπωση**](#rewrite) για καθημερινές βελτιώσεις διατύπωσης.
- Χρησιμοποιήστε [**Μετασχηματισμό**](#transform) όταν χρειάζεστε επαναλαμβανόμενη ροή εργασιών για μια συγκεκριμένη εργασία.
- Χρησιμοποιήστε [**Ταμπλό**](#dashboard) αν θέλετε να παρακολουθείτε τη χρήση και το κόστος.
- Χρησιμοποιήστε [**Ιστορικό**](#history) για να ελέγξετε προηγούμενες λειτουργίες και το πλήρες κείμενο εισόδου/εξόδου τους.
- Εξάγετε ερωτήσεις τακτικά αν δημιουργείτε βιβλιοθήκη ερωτήσεων που θέλετε να διατηρήσετε ασφαλή (δείτε [Μετασχηματισμός Ερωτήσεων](#transform-prompts)) ή αν θέλετε να την μοιραστείτε με άλλους.
