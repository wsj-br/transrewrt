# Εγχειρίδιο χρήστη

<br/>

<a id="introduction"></a>
## Εισαγωγή

Το Transrewrt σας βοηθά να εργαστείτε με κείμενο με τρεις βασικούς τρόπους:

- **Μετάφραση** - μετατροπή κειμένου από μια γλώσσα σε άλλη.
- **Επαναδιατύπωση** - αναδιατύπωση κειμένου με διαφορετικό ύφος, όπως πιο ξεκάθαρο, πιο σύντομο ή πιο επίσημο.
- **Μετασχηματισμός** - επεξεργασία κειμένου με προσαρμοσμένες οδηγίες τεχνητής νοημοσύνης, που ονομάζονται προτροπές (prompts).

<br/>

Αυτό το εγχειρίδιο εξηγεί πώς να χρησιμοποιήσετε την εφαρμογή όταν εγκατασταθεί και εκτελείται. Για τα βήματα εγκατάστασης, δείτε το κύριο αρχείο **[README](README.el.md)**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το Transrewrt είναι διαθέσιμο ως εφαρμογή επιτραπεζίου για Windows και Linux, καθώς και ως εφαρμογή ιστού που μπορείτε να φιλοξενήσετε δική σας. Αυτό το εγχειρίδιο επικεντρώνεται στην καθημερινή χρήση της εφαρμογής. Όταν κάτι ισχύει μόνο για μία έκδοση, αναφέρεται ρητά.

<a id="before-you-start"></a>

## Πριν ξεκινήσετε

Για να χρησιμοποιήσετε το Transrewrt, χρειάζεστε πρόσβαση σε τουλάχιστον έναν πάροχο τεχνητής νοημοσύνης. Οι υποστηριζόμενοι πάροχοι είναι: [OpenRouter](https://openrouter.ai) (ο οποίος συγκεντρώνει πολλά μοντέλα), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και [Ollama](https://ollama.com) για τοπικά μοντέλα.

Δεν χρειάζεται να επιλέξετε ένα μοντέλο με χρέωση για να ξεκινήσετε. Μόλις προσθέσετε το κλειδί API του OpenRouter, η εφαρμογή ενεργοποιεί αυτόματα μια ενσωματωμένη **δωρεάν** επιλογή του OpenRouter. Αυτό σας επιτρέπει να ξεκινήσετε αμέσως τη μετάφραση, την αναδιατύπωση και τον μετασχηματισμό κειμένου. Εναλλακτικά, μπορείτε επίσης να λάβετε ένα δωρεάν κλειδί API από τις Cerebras, Google, Groq ή Mistral AI.

Με απλά λόγια:

- Ένα **μοντέλο** είναι ο μηχανισμός τεχνητής νοημοσύνης που εκτελεί την εργασία. Τα μοντέλα εμφανίζονται με **πρόθεμα παρόχου** (π.χ. `openrouter/…`, `openai/…`, `ollama/…`).
- Ένα **κλειδί API** (ή για το Ollama, μια **βασική διεύθυνση URL**) είναι ο τρόπος με τον οποίο η εφαρμογή επικοινωνεί με αυτόν τον πάροχο.

Αν χρησιμοποιείτε την **εφαρμογή για υπολογιστή**, προσθέστε κλειδιά στο [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config) για κάθε πάροχο που χρησιμοποιείτε. Για χρήση αποκλειστικά του OpenRouter, δείτε παρακάτω την ενότητα [Πώς να λάβετε ένα κλειδί API](#how-to-get-an-api-key-desktop-app). Αν δεν θέλετε να χρησιμοποιήσετε κλειδί API, μπορείτε να εγκαταστήσετε το Ollama (από τη διεύθυνση [ollama.com](https://ollama.com)) και να χρησιμοποιήσετε τοπικά μοντέλα, όπως το `translategemma:4b`.

Αν χρησιμοποιείτε την **έκδοση ιστού**, ο διαχειριστής του διακομιστή διαμορφώνει τους παρόχους μέσω μεταβλητών περιβάλλοντος, επομένως δεν μπορείτε να εισάγετε κλειδιά API απευθείας στην εφαρμογή.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Πώς να λάβετε ένα δωρεάν κλειδί API του OpenRouter (πρόγραμμα υπολογιστή)

Αν χρησιμοποιείτε την εφαρμογή για υπολογιστή, ακολουθήστε τα εξής βήματα:

1. Μεταβείτε στη διεύθυνση [OpenRouter](https://openrouter.ai) με το πρόγραμμα περιήγησής σας.
2. Δημιουργήστε λογαριασμό ή συνδεθείτε.
3. Ανοίξτε τη σελίδα [Keys](https://openrouter.ai/keys).
4. Κάντε κλικ στο κουμπί για δημιουργία νέου κλειδιού API.
5. Δώστε ένα όνομα στο κλειδί για να το αναγνωρίζετε αργότερα.
6. Αντιγράψτε το νέο κλειδί API.
7. Επιστρέψτε στο Transrewrt και ανοίξτε **Ρυθμίσεις** > **Διαμόρφωση API**.
8. Επικολλήστε το κλειδί στο πεδίο **Κλειδί API OpenRouter** (υπό **Ρυθμίσεις** > **Διαμόρφωση API**).
9. Κάντε κλικ στο **Δοκιμή κλειδιού OpenRouter** για να βεβαιωθείτε ότι λειτουργεί.

<a id="getting-started"></a>
## Ξεκινώντας

Αν χρησιμοποιείτε το Transrewrt για πρώτη φορά, ακολουθήστε την παρακάτω σειρά:

1. Ανοίξτε την εφαρμογή.
2. Επιλέξτε τη **Γλώσσα διεπαφής** σας από το εικονίδιο της γης, αν χρειαστεί.
3. Αν χρησιμοποιείτε την **εφαρμογή υπολογιστή**, ανοίξτε το [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config), προσθέστε ένα κλειδί API για τουλάχιστον έναν πάροχο (π.χ. OpenRouter) και κάντε κλικ στο **Δοκιμή** για να το επιβεβαιώσετε.
4. Ανοίξτε το [**Ρυθμίσεις** > **Μοντέλα**](#models) και προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα μοντέλα**.
5. Ανοίξτε το [**Ρυθμίσεις** > **Γλώσσες**](#languages) και επιλέξτε τις **Κορυφαίες γλώσσες** σας, αν θέλετε οι πιο συχνά χρησιμοποιούμενες γλώσσες σας να εμφανίζονται πρώτες.
6. Μεταβείτε στο **Μετάφραση** και εκτελέστε μια απλή μετάφραση για να επιβεβαιώσετε ότι όλα λειτουργούν.
7. Μόλις τα καταφέρετε, δοκιμάστε το **Αναδιατύπωση** και στη συνέχεια το **Μετασχηματισμός**.

Η σειρά αυτή έχει σημασία. Προλαμβάνει το πιο συνηθισμένο πρόβλημα για τους νέους χρήστες: να προσπαθήσουν να εκτελέσουν μια εργασία πριν η εφαρμογή έχει μια λειτουργική σύνδεση API ή ένα επιλεγμένο μοντέλο.

### Γραμμή εργαλείων

Η γραμμή εργαλείων αλλάζει ελαφρώς ανάλογα με το πού βρίσκεστε μέσα στην εφαρμογή.

- Στα αριστερά, εμφανίζεται το όνομα της τρέχουσας σελίδας.
- Στα δεξιά, εμφανίζεται ο **επιλογέας μοντέλου** και ο έλεγχος της **Γλώσσας διεπαφής**.

Ο **επιλογέας μοντέλου** σας επιτρέπει να επιλέξετε ποια μηχανή τεχνητής νοημοσύνης θα χρησιμοποιηθεί για την τρέχουσα εργασία.

  ![Επιλογέας μοντέλου](../images/screenshots/el/model-selector.png)

 Κάποια δωρεάν μοντέλα μπορεί να μην είναι πάντα διαθέσιμα — μερικές φορές βρίσκονται offline ή έχουν όριο χρήσης. Σε αυτή την περίπτωση, η εφαρμογή θα αφαιρέσει αυτόματα το μοντέλο από τη διαθέσιμη λίστα. Για να ελέγξετε ποια μοντέλα εμφανίζονται, μεταβείτε στο [**Ρυθμίσεις** > **Μοντέλα**](#models) και επεξεργαστείτε τη λίστα των μοντέλων σας. 
 Μπορείτε επίσης να ανοίξετε απευθείας τις ρυθμίσεις του μοντέλου κάνοντας κλικ στο εικονίδιο του πάροχου στα αριστερά του ονόματος του μοντέλου στη γραμμή εργαλείων.

<br/>

Το **εικονίδιο με τη γη και ο κωδικός γλώσσας** αλλάζει τη γλώσσα της διεπαφής της εφαρμογής, όπως τα μενού και τα κουμπιά. ΔΕΝ αλλάζει τις γλώσσες μετάφρασης που χρησιμοποιούνται στην ενότητα **Μετάφραση**.

  ![Επιλογέας γλώσσας διεπαφής](../images/screenshots/el/language-selector.png)

<a id="input-and-output-panels"></a>
### Πλαίσια εισόδου και εξόδου

Οι περισσότεροι χώροι εργασίας χρησιμοποιούν ένα πλαίσιο **Εισόδου** στα αριστερά και ένα πλαίσιο **Εξόδου** στα δεξιά.

Κάθε πλαίσιο επίσης εμφανίζει:

| **Είσοδος**                                                          | **Έξοδος**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Μέτρηση χαρακτήρων <br/>- Μέτρηση λέξεων <br/>- Μέτρηση παραγράφων   <br/> | - Πόσο διήρκεσε η εργασία<br/>- **ΤPS** (τοκεν ανά δευτερόλεπτο)<br/>- Μέτρηση χαρακτήρων, λέξεων και παραγράφων<br/>- Το μοντέλο που χρησιμοποιήθηκε |


Αν σας ενδιαφέρουν οι τεχνικοί όροι:

- **Τοκέν** σημαίνει ένα μικρό τμήμα κειμένου. Μπορείτε να το θεωρήσετε ως ένα τμήμα λέξης ή μια σύντομη λέξη.
- **TPS** σημαίνει πόσα από αυτά τα τμήματα κειμένου επεξεργάστηκε το μοντέλο κάθε δευτερόλεπτο.

<br/>

Μπορείτε επίσης να παρακολουθείτε το κόστος κάθε λειτουργίας (αν είναι διαθέσιμο) και το συνολικό κόστος, ενεργοποιώντας την επιλογή `Εμφάνιση πληροφοριών κόστους στις ενέργειες` στις [**Ρυθμίσεις** > **Γενικές ρυθμίσεις**](#general-settings).

<a id="translate"></a>
## Μετάφραση

Χρησιμοποιήστε την **Μετάφραση** όταν θέλετε να μετατρέψετε κείμενο από μία γλώσσα σε μία άλλη.

![Χώρος εργασίας Μετάφρασης](../images/screenshots/el/translate.png)

<br/>

<a id="translate-text"></a>
### Μετάφραση κειμένου

1. Ανοίξτε την ενότητα **Μετάφραση**.
2. Επιλέξτε μία γλώσσα στο **Από**.
3. Επιλέξτε μία γλώσσα στο **Προς**.
4. Επιλέξτε ένα μοντέλο στη γραμμή εργαλείων.
5. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Είσοδος**.
6. Κάντε κλικ στο **Μετάφραση**.
7. Διαβάστε το αποτέλεσμα στο **Έξοδος**.
8. Χρησιμοποιήστε το κουμπί αντιγραφής αν θέλετε να αντιγράψετε το αποτέλεσμα.

<br/>

<a id="language-selection"></a>
### Επιλογή γλώσσας

- Το **Από** μπορεί να είναι μία συγκεκριμένη γλώσσα ή **Ανίχνευση γλώσσας**.
- Το **Προς** είναι η γλώσσα στην οποία θέλετε το αποτέλεσμα.

Οι επιλεγμένες **Κύριες γλώσσες** εμφανίζονται στην κορυφή της λίστας. Μπορείτε να τις ορίσετε στις [**Ρυθμίσεις** > **Γλώσσες**](#languages).

Χρησιμοποιήστε την επιλογή **Μετατροπή** όταν θέλετε το τεχνητό νοημοσύνη να ακολουθήσει ένα προσαρμοσμένο σύνολο οδηγιών.

<a id="run-an-existing-prompt"></a>
### Εκτέλεση υπάρχουσας ερώτησης

1. Ανοίξτε την επιλογή **Μετατροπή**.
2. Επιλέξτε μια ερώτηση από τη λίστα ερωτήσεων.
3. Αν εμφανιστεί το πεδίο **Γλώσσα προορισμού**, επιλέξτε μια γλώσσα αν επιθυμείτε.
4. Πληκτρολογήστε ή επικολλήστε κείμενο στο πεδίο **Είσοδος**.
5. Κάντε κλικ στο **Μετατροπή**.
6. Διαβάστε το αποτέλεσμα στο πεδίο **Έξοδος**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>

Αν η λίστα ερωτήσεων σας είναι κενή, κάντε κλικ στο **Φόρτωση δειγματικών ερωτήσεων**. Έτσι προστίθενται ενσωματωμένα παραδείγματα, ώστε να μπορείτε να ξεκινήσετε γρήγορα.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Οι δειγματικές ερωτήσεις παρέχονται στα Αγγλικά. Αφού τις φορτώσετε, μπορείτε να επεξεργαστείτε μια ερώτηση και να χρησιμοποιήσετε την επιλογή **Μετάφραση ερώτησης** για να τη μεταφράσετε στη γλώσσα σας.

<a id="create-a-prompt-quickly"></a>

3. Περιγράψτε τι θέλετε να κάνει η ερώτηση.
4. Επιλέξτε ένα μοντέλο.
5. Αφήστε την εφαρμογή να δημιουργήσει ένα πρόχειρο για εσάς.
6. Ελέγξτε το πρόχειρο και κάντε κλικ στο **Αποθήκευση**.

![Δημιουργία ερώτησης](../images/screenshots/el/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### Επεξεργασία ερώτησης

Όταν δημιουργείτε ή επεξεργάζεστε μια ερώτηση, ο επεξεργαστής εμφανίζεται στα αριστερά και μια περιοχή δοκιμής εμφανίζεται στα δεξιά.

![Επεξεργαστής ερωτήσεων Μετατροπής](../images/screenshots/el/transform-prompt-edit.png)

Τα κύρια πεδία είναι:

- **Όνομα ερώτησης**: το όνομα που εμφανίζεται στη λίστα ερωτήσεων.
- **Οδηγίες ερώτησης (προαιρετικό)**: μια σύντομη υπόδειξη που εμφανίζεται στο χρήστη κατά την εκτέλεση της ερώτησης.
- **Ρόλος μοντέλου**: ο γενικός ρόλος που αποδίδεται στο τεχνητό νοημοσύνη, όπως π.χ. «Είσαι ένας βοηθητικός βοηθός».
- **Οδηγίες μοντέλου (μία ανά γραμμή)**: οι συγκεκριμένοι κανόνες που θέλετε να ακολουθεί το τεχνητό νοημοσύνη.
- **Περιγραφή εξόδου**: μια σύντομη λέξη που περιγράφει το αποτέλεσμα, όπως «περίληψη» ή «επανεκπόνηση».
- **Θερμοκρασία (0.0 → 1.0)**: η συμπεριφορά του μοντέλου· βλ. παρακάτω.
- **Ερώτηση για γλώσσα προορισμού**: προσθέτει επιλογέα γλώσσας προορισμού κατά την εκτέλεση της ερώτησης.

Αν ο τεχνικός όρος **Θερμοκρασία** σας είναι καινούριος, σκεφτείτε τον ως εξής:

- Μια **χαμηλότερη** θερμοκρασία δίνει πιο σταθερά και προβλέψιμα αποτελέσματα.
- Μια **υψηλότερη** θερμοκρασία δίνει μεγαλύτερη ποικιλία και δημιουργικότητα.

Μπορείτε επίσης να χρησιμοποιήσετε:

- **`Δημιουργία ερώτησης`** για να δημιουργήσετε ένα νέο πρόχειρο από μια απλή περιγραφή
- **`Βελτίωση ερώτησης`** για να βελτιώσετε μια υπάρχουσα ερώτηση
- **`Μετάφραση ερώτησης`** για να μεταφράσετε τα πεδία της ερώτησης

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Κάντε κλικ στο **`Αποθήκευση`** πριν πατήσετε **`Πίσω στην Εκτέλεση`**. Αν επιστρέψετε πίσω χωρίς να αποθηκεύσετε, οι αλλαγές σας θα χαθούν.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### Δοκιμή μιας ερώτησης πριν τη χρήση της

Το πίνακας δοκιμής στα δεξιά σας επιτρέπει να δοκιμάσετε την ερώτηση σας με δειγματικό κείμενο πριν τη χρησιμοποιήσετε στην καθημερινή εργασία σας.

Αυτό είναι χρήσιμο όταν:

- δημιουργείτε μια νέα ερώτηση
- συγκρίνετε δύο εκδόσεις μιας ερώτησης
- θέλετε να ελέγξετε τον τόνο, το μήκος ή τη μορφή της εξόδου

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>

<a id="general-settings"></a>
### Γενικές Ρυθμίσεις

Χρησιμοποιήστε τις **Γενικές Ρυθμίσεις** για να ελέγξετε τη συμπεριφορά πληκτρολόγησης, αν αποθηκεύονται λεπτομέρειες εκτέλεσης για το **Ιστορικό**, καθώς και την εμφάνιση.

**Συμπεριφορά**

- **Συμπεριφορά για ENTER** επιλέγει αν το `Enter` ξεκινά την εργασία ή εισάγει νέα γραμμή.
- **Αυτόματη μετάφραση κατά την επικόλληση** ξεκινά τη μετάφραση αμέσως μόλις επικολλήσετε κείμενο.
- **Αυτόματη αντιγραφή αποτελέσματος στο πρόχειρο** αντιγράφει αυτόματα τα επιτυχημένα αποτελέσματα.
- **Μετάφραση σε πραγματικό χρόνο (κατά την πληκτρολόγηση)** μεταφράζει ενώ πληκτρολογείτε.
- **Χρόνος αναμονής (ms)** ορίζει το χρόνο αναμονής για τη μετάφραση σε πραγματικό χρόνο.

**Ιστορικό**

- **Διατήρηση ιστορικού εκτέλεσης** ελέγχει αν κάθε μετάφραση, ανασύνταξη και μετασχηματισμός αποθηκεύουν **εισαγόμενο και εξερχόμενο κείμενο** για την προβολή της πλευρικής μπάρας [**Ιστορικό**](#history). Η απενεργοποίηση ζητά επιβεβαίωση· αν επιβεβαιώσετε, το αποθηκευμένο κείμενο ιστορικού αφαιρείται από τη βάση δεδομένων.
- **Διαγραφή δεδομένων ιστορικού** σας επιτρέπει να αφαιρέσετε αποθηκευμένα κείμενα βάσει ηλικίας (για παράδειγμα παλαιότερα από μερικούς μήνες, ή **όλα τα δεδομένα (εκκαθάριση)**) χρησιμοποιώντας την εντολή **Διαγραφή δεδομένων**. Αυτό επηρεάζει μόνο το αποθηκευμένο κείμενο εκτέλεσης για την προβολή **Ιστορικό**· **δεν** διαγράφει τα σύνολα κόστους ή χρήσης. Για να αφαιρέσετε ή να περικόψετε **δεδομένα κόστους**, χρησιμοποιήστε τις [**Ρυθμίσεις** > **Παρακολούθηση Κόστους**](#cost-tracking).

**Εμφάνιση**

- **Εμφάνιση πληροφοριών κόστους στις ενέργειες** ελέγχει την εμφάνιση του κόστους ανά λειτουργία (αν είναι διαθέσιμο) και του συνολικού κόστους στα πάνελ εξόδου Μετάφρασης, Ανασύνταξης και Μετασχηματισμού.
- **Δεκαδικά ψηφία κόστους** αλλάζει τον τρόπο εμφάνισης των δεκαδικών ψηφίων κόστους.
- **Μόνο για ιστός:** **εμφάνιση περιθωρίου γύρω από την εφαρμογή** προσθέτει επιπλέον χώρο γύρω από τη διεπαφή.
- **Οικογένεια γραμματοσειρών** αλλάζει τη γραμματοσειρά στα πάνελ κειμένου.
- **Μέγεθος** αλλάζει το μέγεθος της γραμματοσειράς.


<br/>

<a id="models"></a>

### Μοντέλα

Χρησιμοποιήστε την επιλογή **Ρυθμίσεις** > **Μοντέλα** για να επιλέξετε ποια μοντέλα εμφανίζονται στη γραμμή εργαλείων.

![Tab μοντέλων στις ρυθμίσεις](../images/screenshots/el/settings-models.png)

Η σελίδα περιλαμβάνει δύο λίστες:

- **Διαθέσιμα μοντέλα** στα αριστερά
- **Επιλεγμένα μοντέλα** στα δεξιά

Χρήσιμα στοιχεία ελέγχου περιλαμβάνουν:

- **Αναζήτηση μοντέλων...** για εύρεση μοντέλου με βάση το όνομα
- **Ετικέτες πάροχου** για περιορισμό της λίστας σε έναν πάροχο (OpenRouter, OpenAI, Ollama, …)
- **Μόνο δωρεάν** για εμφάνιση μόνο δωρεάν μοντέλων
- **Ανανέωση** για επαναφόρτωση της λίστας
- **Επέκταση όλων** και **Σύμπτυξη όλων** όταν ταξινομείτε ανά πάροχο

Οι ταυτότητες των μοντέλων συμπεριλαμβάνουν το πρόθεμα παρόχου (για παράδειγμα `openrouter/…` έναντι `openai/…`). Ετικέτες όπως **OpenAI (OpenRouter)** έναντι **OpenAI (άμεσα)** δείχνουν πώς δρομολογείται η κίνηση.

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Το **OpenRouter Body Builder** (`openrouter/bodybuilder`) είναι ένα μοντέλο δρομολόγησης, όχι ένα γενικό μοντέλο συνομιλίας: η απάντησή του είναι JSON που περιγράφει τα σώματα αιτημάτων της OpenRouter API (για παράδειγμα έναν πίνακα `requests` με `model` και `messages`). Αν το χρησιμοποιήσετε για **Μετάφραση**, **Αναδιατύπωση** ή **Μετασχηματισμό**, το πλαίσιο εξόδου θα εμφανίσει αυτό το JSON αντί για τελικό κείμενο. Επιλέξτε ένα κανονικό μοντέλο κειμένου για αυτές τις εργασίες. Δείτε τη σελίδα μοντέλου [Body Builder model](https://openrouter.ai/openrouter/bodybuilder) στην OpenRouter.

Ενέργειες:

- Για να προσθέσετε ένα μοντέλο, κάντε κλικ στο **Προσθήκη** ή οπουδήποτε στην καταχώριση.

- Για να αφαιρέσετε ένα μοντέλο, κάντε κλικ στο **X** δίπλα του στην ενότητα **Επιλεγμένα Μοντέλα** ή στο **Επιλεγμένο** στην καταχώριση της λίστας Διαθέσιμα Μοντέλα.

- Για να καθαρίσετε τη λίστα, κάντε κλικ στο **Απεπιλογή όλων**. Το απαιτούμενο δωρεάν μοντέλο θα παραμείνει στη λίστα.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Αν δεν θέλετε να προσθέσετε πιστωτικά στην OpenRouter αμέσως, αρχίστε ενεργοποιώντας το **Μόνο δωρεάν** και επιλέγοντας τα δωρεάν μοντέλα (χωρίς απαιτούμενη κάρτα). Μπορείτε επίσης να χρησιμοποιήσετε το Ollama για να εκτελέσετε μοντέλα τοπικά χωρίς κλειδί API.

<br/>

<a id="languages"></a>
### Γλώσσες

Χρησιμοποιήστε την επιλογή **Ρυθμίσεις** > **Γλώσσες** για να οργανώσετε τις λίστες γλωσσών που χρησιμοποιούνται στην εφαρμογή.

- **Κορυφαίες γλώσσες** είναι καρφιτσωμένες στην κορυφή των λιστών γλωσσών στις εργασίες **Μετάφραση** και **Μετασχηματισμός**.
- **Προσαρμοσμένη γλώσσα** σας επιτρέπει να προσθέσετε γλώσσα που δεν υπάρχει στην ενσωματωμένη λίστα.

Αν προσθέσετε μια προσαρμοσμένη γλώσσα, θα εμφανιστεί στους επιλογείς γλωσσών δίπλα στις ενσωματωμένες επιλογές.

<br/>

<a id="cost-tracking"></a>
### Παρακολούθηση κόστους

Χρησιμοποιήστε την επιλογή **Ρυθμίσεις** > **Παρακολούθηση Κόστους** για διαχείριση των πληροφοριών κόστους.

- **Συνολικό κόστος** εμφανίζει το τρέχον άθροισμα.
- **Αντιγραφή αξίας** αντιγράφει το σύνολο στο πρόχειρο.
- **Επαναφορά κόστους** επαναφέρει την αποθηκευμένη τιμή στο μηδέν.
- **Συγχρονισμός με τη χρήση κλειδιού API** ορίζει το άθροισμα ώστε να αντιστοιχεί στη χρήση που αναφέρεται από τον λογαριασμό OpenRouter (μόνο για OpenRouter).
- **Χρήση κλειδιού API** εμφανίζει λεπτομέρειες χρήσης από την OpenRouter, αν είναι διαθέσιμες.
- **Διαγραφή δεδομένων κόστους** διαγράφει όλα τα δεδομένα, ή μόνο εγγραφές πριν από μια καθορισμένη ημερομηνία.

**Παρακολούθηση κόστους:** Όταν χρησιμοποιείτε μοντέλα OpenRouter, η εφαρμογή εμφανίζει την πραγματική σας χρήση και δαπάνη με βάση πληροφορίες κόστους από την OpenRouter. Για όλους τους υπόλοιπους παρόχους, η εφαρμογή εκτιμά το κόστος χρησιμοποιώντας τιμές που δημοσιεύει η OpenRouter· αν δεν υπάρχει διαθέσιμη τιμή, η εκτίμηση μπορεί να είναι μηδενική.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Όλα τα ποσά κόστους είναι εκτιμήσεις μόνο για τη δική σας αναφορά, όχι επίσημα τιμολόγια.

<br/>

> ⚠️ **ΠΡΟΕΙΔΟΠΟΙΗΣΗ**<br/>
> Η διαγραφή δεδομένων δεν μπορεί να αναιρεθεί. Πριν από διαγραφή, βεβαιωθείτε ότι έχετε δημιουργήσει αντίγραφο ασφαλείας ή εξαγάγει τα δεδομένα σας μέσω της επιλογής [**Ιστορικό**](#history) ή της επιλογής [**Ταμπλό** > **Όλες οι κλήσεις**](#dashboard-tabs), διαφορετικά θα χαθούν για πάντα. Όλο το ιστορικό εισόδου/εξόδου που σχετίζεται με κάθε καταχώριση κλήσης API θα διαγραφεί επίσης.

<br/>

<a id="api-config"></a>
### Διαμόρφωση API

Οι υποστηριζόμενοι πάροχοι είναι: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras και **Ollama** (τοπικά μοντέλα μέσω μιας βασικής διεύθυνσης URL). Πρέπει να διαμορφώσετε μόνο τους παρόχους που χρησιμοποιείτε.

**Εφαρμογή ιστού: μόνο για διαχειριστή**

Τα κλειδιά API διαμορφώνονται μέσω συστήματος ή περιβαλλοντικών μεταβλητών Docker — δεν εισάγονται στο γραφικό περιβάλλον. Αυτή η σελίδα εμφανίζει ποιοι πάροχοι έχουν διαμορφωμένο κλειδί και σας επιτρέπει να ελέγξετε τον καθέναν κάνοντας κλικ στο κουμπί **`Δοκιμή`**.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Για να αλλάξετε ένα κλειδί API, ενημερώστε την περιβαλλοντική μεταβλητή στη ρύθμιση σας του συστήματος ή του Docker και επανεκκινήστε τον διακομιστή ή τον αποθήκευτρο.

<br/>

**Εφαρμογή ηλεκτρονικού υπολογιστή**

Χρησιμοποιήστε την επιλογή **Διαμόρφωση API** για αποθήκευση κλειδιών API για κάθε πάροχο που χρησιμοποιείτε. Για το Ollama, εισάγετε την **βασική διεύθυνση URL** αντί για κλειδί API.

<br/>

> 💡 **Συμβουλή** <br/>
> Αν δεν θέλετε να χρησιμοποιήσετε κλειδί API ή να πληρώσετε για χρήση, μπορείτε να [κατεβάσετε το Ollama](https://ollama.com) και να εκτελέσετε μοντέλα (όπως το `translategemma:4b`) τοπικά στον υπολογιστή σας δωρεάν. Εναλλακτικά, μπορείτε να δημιουργήσετε δωρεάν λογαριασμό OpenRouter (χωρίς απαιτούμενη κάρτα) για να χρησιμοποιήσετε τα δωρεάν μοντέλα τους ή να αποκτήσετε δωρεάν κλειδί API από την Cerebras, την Google, την Groq ή την Mistral AI.

<br/>

- Προσθέστε μόνο τους παρόχους που χρειάζεστε. Στις **Ρυθμίσεις** > **Μοντέλα**, κάθε ταυτότητα μοντέλου ξεκινά με τον πάροχο (π.χ. `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Για να προσθέσετε ένα κλειδί API, εισάγετε την τιμή στο πεδίο κειμένου και κάντε κλικ στο **`Αποθήκευση`**. Για να αντικαταστήσετε ένα υπάρχον κλειδί, κάντε κλικ στο **`Επεξεργασία`**. Για να επαληθεύσετε ότι ένα κλειδί λειτουργεί, κάντε κλικ στο **`Δοκιμή`**. Για τη βασική διεύθυνση URL του Ollama, κάντε πάντα κλικ στο **`Δοκιμή`** για έλεγχο σύνδεσης.

<br/>

> ℹ️ **ΣΗΜΕΙΩΣΗ**<br/>
> Δεν μπορείτε να δείτε την τρέχουσα τιμή ενός κλειδιού API. Μπορείτε μόνο να την αντικαταστήσετε χρησιμοποιώντας το κουμπί **`Επεξεργασία`**.
> Τα κλειδιά API αποθηκεύονται κρυπτογραφημένα στη ρύθμιση.

<a id="common-issues"></a>
## Συνηθισμένα προβλήματα

Αν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα τα παρακάτω σημεία.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Η εφαρμογή δεν μεταφράζει, δεν ξαναγράφει ή δεν μετασχηματίζει κείμενο

Ελέγξτε ότι:

- έχετε επιλέξει ένα μοντέλο στη γραμμή εργαλείων
- παρατίθεται τουλάχιστον ένα μοντέλο στο [**Ρυθμίσεις** > **Μοντέλα**](#models)
- η διαμόρφωση του API δουλεύει σωστά

Αν χρησιμοποιείτε την εφαρμογή για υπολογιστή:

1. Ανοίξτε το [**Ρυθμίσεις** > **Διαμόρφωση API**](#api-config).
2. Βεβαιωθείτε ότι αποθηκεύτηκε τουλάχιστον ένα κλειδί API.
3. Κάντε κλικ στο **Δοκιμή** δίπλα στο πάροχο για να επιβεβαιώσετε ότι το κλειδί λειτουργεί.

<br/>

<a id="the-model-list-is-empty"></a>
### Η λίστα μοντέλων είναι κενή

Ανοίξτε [**Ρυθμίσεις** > **Μοντέλα**](#models) και κάντε κλικ στο **Ανανέωση**.

Αν χρειαστεί:

- αναζητήστε ένα μοντέλο
- ενεργοποιήστε το **Μόνο Δωρεάν**
- προσθέστε ένα ή περισσότερα μοντέλα στα **Επιλεγμένα Μοντέλα**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Το αποτέλεσμα είναι πολύ αργό ή υπερβολικά ακριβό

Δοκιμάστε μία ή περισσότερες από τις παρακάτω ενέργειες:

- επιλέξτε διαφορετικό μοντέλο
- χρησιμοποιήστε μικρότερο κείμενο εισόδου
- απενεργοποιήστε την **Μετάφραση σε πραγματικό χρόνο (κατά τη δακτυλογράφηση)** στις [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings)
- χρησιμοποιήστε δωρεάν μοντέλα για απλές εργασίες (δείτε [Μοντέλα](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Η διεπαφή είναι στη λάθος γλώσσα

Κάντε κλικ στο εικονίδιο της γης στην [γραμμή εργαλείων](#toolbar) και επιλέξτε την επιθυμητή **Γλώσσα Διεπαφής**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Το κείμενο είναι πολύ μικρό ή δύσκολο προς ανάγνωση

Ανοίξτε [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings) και αλλάξτε:

- **Οικογένεια Γραμματοσειράς**
- **Μέγεθος**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Τα διαγράμματα της Κεντρικής Σελίδας είναι κενά

Αυτό είναι φυσιολογικό αν:

- χρησιμοποιείτε μόνο **δωρεάν μοντέλα** (τα διαγράμματα δαπανών θα παραμείνουν άδεια)
- το επιλεγμένο **φίλτρο χρόνου** δεν αφορά την περίοδο που έγιναν οι κλήσεις — δοκιμάστε **Όλα** για να ελέγξετε

Αν τα διαγράμματα εξακολουθούν να είναι κενά αφού επιλέξετε **Όλα**, βεβαιωθείτε ότι εμφανίζονται κλήσεις στο [**Ιστορικό**](#history) ή στην καρτέλα **Όλες οι κλήσεις**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Η δαπάνη εμφανίζει "μη διαθέσιμο" ή φαίνεται λανθασμένη

Όταν χρησιμοποιείτε μοντέλα μέσω του **OpenRouter**, η εφαρμογή εμφανίζει την πραγματική σας δαπάνη όπως αναφέρεται από το OpenRouter.

Για **άλλους παρόχους** (OpenAI απευθείας, Anthropic απευθείας, κ.λπ.), η δαπάνη υπολογίζεται βάσει των τιμών που δημοσιεύονται από το OpenRouter. Αν δεν βρεθεί αντίστοιχη τιμή για ένα μοντέλο, η δαπάνη θα εμφανίζεται ως **μη διαθέσιμη** και δεν θα προστεθεί στο συνολικό σας ποσό.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Το συνολικό κόστος δεν ταιριάζει με το λογαριασμό του παρόχου

Όλα τα στοιχεία κόστους στην εφαρμογή είναι **εκτιμήσεις για αναφορά μόνο**, όχι επίσημες λογαριασίες.

Για να πλησιάσετε το συνολικό ποσό στα πραγματικά σας έξοδα στο OpenRouter, ανοίξτε [**Ρυθμίσεις** > **Παρακολούθηση Δαπανών**](#cost-tracking) και κάντε κλικ στο **Συγχρονισμός με χρήση κλειδιού API**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Η σελίδα Ιστορικό λείπει από την πλευρική μπάρα

Η επιλογή **Διατήρηση ιστορικού εκτελέσεων** μπορεί να είναι απενεργοποιημένη. Ανοίξτε [**Ρυθμίσεις** > **Γενικές Ρυθμίσεις**](#general-settings) και ενεργοποιήστε την. Σημειώστε ότι η ενεργοποίησή της δεν επαναφέρει ιστορικά δεδομένα που έχουν διαγραφεί.

<br/>

<a id="web-app-session-expired"></a>
### Web εφαρμογή: ανακατεύθυνση στη σελίδα σύνδεσης απροσδόκητα

Η συνεδρία σας ενδέχεται να έχει λήξει. Συνδεθείτε ξανά. Αν συμβαίνει συχνά, ελέγξτε τη ρύθμιση του διακομιστή για τη διάρκεια ζωής της συνεδρίας.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### Η Κεντρική Σελίδα δεν εμφανίζει δεδομένα για άλλους χρήστες (web)

Μόνο οι **διαχειριστές** μπορούν να δουν δεδομένα από όλους τους χρήστες μέσω του φίλτρου **Χρήστης**. Κατά σχεδιασμό, οι απλοί χρήστες βλέπουν μόνο τις δικές τους ενέργειες.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Άλλαξα μια ερώτηση και έχασα τις επεξεργασίες

Όταν επεξεργάζεστε μια ερώτηση, κάντε πάντα κλικ στο **Αποθήκευση** πριν κάνετε κλικ στο **Πίσω στην Εκτέλεση**.

<br/><br/>

<a id="quick-tips"></a>
## Γρήγορες συμβουλές

- Ξεκινήστε με το [**Μετάφραση**](#translate) για να βεβαιωθείτε ότι η διαμόρφωσή σας λειτουργεί πριν προχωρήσετε στο [**Ξαναγράφημα**](#rewrite) ή στο [**Μετασχηματισμό**](#transform).
- Χρησιμοποιήστε το [**Ξαναγράφημα**](#rewrite) για καθημερινές βελτιώσεις στον τρόπο διατύπωσης.
- Χρησιμοποιήστε το [**Μετασχηματισμό**](#transform) όταν χρειάζεστε ένα επαναλαμβανόμενο ροή εργασιών για κάποια συγκεκριμένη εργασία.
- Χρησιμοποιήστε το [**Πίνακα Ελέγχου**](#dashboard) αν θέλετε να παρακολουθείτε τη χρήση και το κόστος.
- Χρησιμοποιήστε το [**Ιστορικό**](#history) για να επανεξετάσετε προηγούμενες λειτουργίες και το πλήρες κείμενο εισόδου/εξόδου.
- Εξάγετε τις ερωτήσεις σας τακτικά αν δημιουργείτε μια βιβλιοθήκη ερωτήσεων που θέλετε να διατηρήσετε ασφαλείς (δείτε [Μετασχηματισμός Ερωτήσεων](#transform-prompts)) ή αν τις επιθυμείτε να μοιραστείτε με άλλους.
