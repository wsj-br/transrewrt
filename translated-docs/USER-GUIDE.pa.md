# ਵਰਤੋਂਕਾਰ ਗਾਈਡ

<br/>

<a id="introduction"></a>
## ਪਰਿਚੈ

ਟ੍ਰਾਂਸਰਾਈਟ ਤੁਹਾਡੀ ਟੈਕਸਟ ਨਾਲ ਕੰਮ ਕਰਨ ਵਿੱਚ ਤਿੰਨ ਮੁੱਖ ਤਰੀਕਿਆਂ ਨਾਲ ਮਦਦ ਕਰਦਾ ਹੈ:

- **ਅਨੁਵਾਦ** - ਇੱਕ ਭਾਸ਼ਾ ਵਿੱਚੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਬਦਲਣਾ।
- **ਮੁੜ ਲਿਖੋ** - ਸਪੱਸ਼ਟ, ਛੋਟਾ ਜਾਂ ਹੋਰ ਔਪਚਾਰਿਕ ਵਰਗੀ ਵੱਖਰੀ ਸ਼ੈਲੀ ਵਿੱਚ ਟੈਕਸਟ ਨੂੰ ਮੁੜ ਵਿਗਿਆਨ।
- **ਪਰਿਵਰਤਨ** - ਪ੍ਰਾਪਤੀਆਂ ਨਾਮਕ ਪਸ਼ੂ ਐਆਈ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਟੈਕਸਟ ਨੂੰ ਸੰਸਾਧਿਤ ਕਰਨਾ।

<br/>

ਇਸ ਗਾਈਡ ਵਿੱਚ ਸਥਾਪਤ ਹੋਣ ਅਤੇ ਚੱਲ ਰਹੇ ਐਪ ਨੂੰ ਵਰਤਣ ਬਾਰੇ ਸਮਝਾਇਆ ਜਾਂਦਾ ਹੈ। ਸਥਾਪਤ ਕਰਨ ਦੇ ਕਦਮਾਂ ਲਈ, ਮੁੱਖ **[README](README.pa.md)** ਦੇਖੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਟ੍ਰਾਂਸਰਾਈਟ ਵਿੰਡੋਜ਼ ਅਤੇ ਲੀਨਕਸ ਲਈ ਡੈਸਕਟਾਪ ਐਪ ਵਜੋਂ ਅਤੇ ਆਪਣੇ ਆਪ ਹੋਸਟ ਕੀਤੇ ਵੈੱਬ ਐਪ ਵਜੋਂ ਉਪਲਬਧ ਹੈ। ਇਸ ਗਾਈਡ ਵਿੱਚ ਐਪ ਦੀ ਰੋਜ਼ਾਨਾ ਵਰਤੋਂ 'ਤੇ ਧਿਆਨ ਕੇਂਦਰਤ ਕੀਤਾ ਗਿਆ ਹੈ। ਜਿੱਥੇ ਕੁਝ ਸਿਰਫ਼ ਇੱਕ ਸੰਸਕਰਣ ‘ਤੇ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਉੱਥੇ ਇਸਨੂੰ ਸਪੱਸ਼ਟ ਰੂਪ ਵਿੱਚ ਚਿੰਨਹਿਤ ਕੀਤਾ ਗਿਆ ਹੈ।

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

Transrewrt ਵਰਤਣ ਲਈ, ਤੁਹਾਡੇ ਕੋਲ ਘੱਟੋ-ਘੱਟ ਇੱਕ AI ਪ੍ਰੋਵਾਈਡਰ ਤੱਕ ਪਹੁੰਚ ਹੋਣੀ ਚਾਹੀਦੀ ਹੈ। ਸਹਾਇਤਾ ਪ੍ਰਾਪਤ ਪ੍ਰੋਵਾਈਡਰ ਹਨ: [OpenRouter](https://openrouter.ai) (ਜੋ ਕਿ ਬਹੁਤ ਸਾਰੇ ਮਾਡਲਾਂ ਨੂੰ ਇਕੱਠਾ ਕਰਦਾ ਹੈ), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਲਈ [Ollama](https://ollama.com)।

ਸ਼ੁਰੂਆਤ ਕਰਨ ਲਈ ਭੁਗਤਾਨਯੋਗ ਮਾਡਲ ਦੀ ਚੋਣ ਕਰਨ ਦੀ ਜ਼ਰੂਰਤ ਨਹੀਂ ਹੈ। ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਆਪਣੀ OpenRouter API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਐਪ ਆਪਣੇ-ਆਪ ਇੱਕ ਅੰਦਰੂਨੀ **ਮੁਫ਼ਤ** OpenRouter ਵਿਕਲਪ ਚਾਲੂ ਕਰ ਦਿੰਦਾ ਹੈ। ਇਸ ਨਾਲ ਤੁਸੀਂ ਤੁਰੰਤ ਪਾਠ ਦਾ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਣ ਅਤੇ ਰੂਪਾਂਤਰਣ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ। ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ Cerebras, Google, Groq, ਜਾਂ Mistral AI ਤੋਂ ਮੁਫ਼ਤ API ਕੁੰਜੀ ਵੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦੇ ਹੋ।

ਸਧਾਰਨ ਭਾਸ਼ਾ ਵਿੱਚ:

- ਇੱਕ **ਮਾਡਲ** AI ਇੰਜਣ ਹੁੰਦਾ ਹੈ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ। ਮਾਡਲਾਂ ਨੂੰ **ਪ੍ਰੋਵਾਈਡਰ ਉਪਸਰਗ** ਨਾਲ ਸੂਚੀਬੱਧ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `openrouter/…`, `openai/…`, `ollama/…`)।
- ਇੱਕ **API ਕੁੰਜੀ** (ਜਾਂ Ollama ਲਈ, ਇੱਕ **ਬੇਸ URL**) ਉਹ ਤਰੀਕਾ ਹੁੰਦਾ ਹੈ ਜਿਸ ਨਾਲ ਐਪ ਉਸ ਪ੍ਰੋਵਾਈਡਰ ਤੱਕ ਪਹੁੰਚਦਾ ਹੈ।

ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਹਰੇਕ ਪ੍ਰੋਵਾਈਡਰ ਲਈ [**Settings** > **API Config**](#api-config) ਵਿੱਚ ਕੰਜੀਆਂ ਸ਼ਾਮਲ ਕਰੋ। ਸਿਰਫ਼ OpenRouter ਵਰਤਣ ਲਈ, ਹੇਠਾਂ ਦਿੱਤੇ [API ਕੁੰਜੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੇਂ](#how-to-get-an-api-key-desktop-app) 'ਤੇ ਜਾਓ। ਜੇ ਤੁਸੀਂ API ਕੁੰਜੀ ਵਰਤਣਾ ਨਹੀਂ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਤੁਸੀਂ ਸਥਾਨਕ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ [ollama.com](https://ollama.com) ਤੋਂ Ollama ਸਥਾਪਿਤ ਕਰ ਸਕਦੇ ਹੋ, ਉਦਾਹਰਣ ਲਈ `translategemma:4b`।

ਜੇ ਤੁਸੀਂ **ਵੈੱਬ ਵਰਜਨ** ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਸਰਵਰ ਮਾਲਕ ਵਾਤਾਵਰਣ ਚਲ (environment variables) ਨਾਲ ਪ੍ਰੋਵਾਈਡਰਾਂ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਐਪਲੀਕੇਸ਼ਨ ਵਿੱਚ ਸਿੱਧੇ ਤੌਰ 'ਤੇ API ਕੁੰਜੀਆਂ ਨਹੀਂ ਦਰਜ ਕਰ ਸਕਦੇ ਹੋ।

<a id="how-to-get-an-api-key-desktop-app"></a>
### ਮੁਫ਼ਤ OpenRouter API ਕੁੰਜੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰਨ (ਡੈਸਕਟਾਪ ਐਪ)

ਜੇ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਇਹਨਾਂ ਕਦਮਾਂ ਨੂੰ ਅਨੁਸਰਣ ਕਰੋ:

1. ਆਪਣੇ ਵੈੱਬ ਬਰਾਊਜ਼ਰ ਵਿੱਚ [OpenRouter](https://openrouter.ai) 'ਤੇ ਜਾਓ।
2. ਇੱਕ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਸਾਈਨ ਇਨ ਕਰੋ।
3. [Keys](https://openrouter.ai/keys) ਸਫ਼ਾ ਖੋਲ੍ਹੋ।
4. ਇੱਕ ਨਵੀਂ API ਕੁੰਜੀ ਬਣਾਉਣ ਲਈ ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
5. ਕੁੰਜੀ ਨੂੰ ਤੁਹਾਡੇ ਲਈ ਪਛਾਣਯੋਗ ਬਣਾਉਣ ਲਈ ਇੱਕ ਨਾਮ ਦਿਓ।
6. ਨਵੀਂ API ਕੁੰਜੀ ਨੂੰ ਕਾਪੀ ਕਰੋ।
7. Transrewrt ਵਾਪਸ ਜਾਓ ਅਤੇ **Settings** > **API Config** ਖੋਲ੍ਹੋ।
8. **OpenRouter API key** ਵਿੱਚ ਕੁੰਜੀ ਪੇਸਟ ਕਰੋ (**Settings** > **API Config** ਨੂੰ ਹੇਠਾਂ)।
9. ਇਸ ਦੇ ਕੰਮ ਕਰਨ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ **Test OpenRouter key** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/><br/>

<a id="getting-started"></a>
## ਸ਼ੁਰੂਆਤ ਕਰ ਰਹੇ ਹੋ

ਜੇ ਇਹ ਤੁਹਾਡੀ Transrewrt ਵਰਤਣ ਦੀ ਪਹਿਲੀ ਵਾਰ ਹੈ, ਤਾਂ ਇਸ ਕ੍ਰਮ ਨੂੰ ਅਨੁਸਰਣ ਕਰੋ:

1. ਐਪ ਨੂੰ ਖੋਲ੍ਹੋ।
2. ਲੋੜ ਪੈਣ 'ਤੇ ਗਲੋਬ ਆਈਕਾਨ ਤੋਂ **Interface language** ਚੁਣੋ।
3. ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** 'ਤੇ ਹੋ, [**Settings** > **API Config**](#api-config) ਖੋਲ੍ਹੋ, ਘੱਟੋ-ਘੱਟ ਇੱਕ ਪ੍ਰੋਵਾਈਡਰ (ਉਦਾਹਰਣ ਲਈ OpenRouter) ਲਈ API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰੋ, ਅਤੇ ਇਸ ਦੇ ਕੰਮ ਕਰਨ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ **Test** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
4. [**Settings** > **Models**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **Selected Models** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ।
5. [**Settings** > **Languages**](#languages) ਖੋਲ੍ਹੋ ਅਤੇ ਜੇ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ ਤੁਹਾਡੀਆਂ ਸਭ ਤੋਂ ਵੱਧ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਭਾਸ਼ਾਵਾਂ ਪਹਿਲਾਂ ਦਿਖਾਈ ਦੇਣ, ਤਾਂ **Top languages** ਚੁਣੋ।
6. **Translate** 'ਤੇ ਜਾਓ ਅਤੇ ਸਧਾਰਨ ਅਨੁਵਾਦ ਚਲਾਓ ਤਾਂ ਜੋ ਸਭ ਕੁਝ ਕੰਮ ਕਰ ਰਿਹਾ ਹੈ ਇਹ ਪੁਸ਼ਟੀ ਕੀਤੀ ਜਾ ਸਕੇ।
7. ਇਕ ਵਾਰ ਜਦੋਂ ਇਹ ਕੰਮ ਕਰਨਾ ਸ਼ੁਰੂ ਕਰ ਦੇਵੇ, ਤਾਂ **Rewrite** ਅਤੇ ਉਸ ਤੋਂ ਬਾਅਦ **Transform** ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

ਇਸ ਕ੍ਰਮ ਦਾ ਮਹੱਤਵ ਹੈ। ਇਹ ਸਭ ਤੋਂ ਆਮ ਪਹਿਲੀ ਵਾਰ ਵਰਤਣ ਦੀ ਸਮੱਸਿਆ ਨੂੰ ਰੋਕਦਾ ਹੈ: ਐਪ ਕੋਲ ਕੰਮ ਕਰਨ ਵਾਲਾ API ਕਨੈਕਸ਼ਨ ਜਾਂ ਚੁਣਿਆ ਮਾਡਲ ਹੋਣ ਤੋਂ ਪਹਿਲਾਂ ਕਿਸੇ ਕੰਮ ਨੂੰ ਚਲਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨਾ।

### ਟੂਲਬਾਰ

ਐਪ ਵਿੱਚ ਤੁਸੀਂ ਜਿੱਥੇ ਵੀ ਹੋਵੋਗੇ, ਉੱਥੇ ਟੂਲਬਾਰ ਵਿੱਚ ਥੋੜ੍ਹਾ ਅੰਤਰ ਆਉਂਦਾ ਹੈ।

- ਖੱਬੇ ਪਾਸੇ, ਮੌਜੂਦਾ ਸਫ਼ੇ ਦਾ ਨਾਮ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ।
- ਸੱਜੇ ਪਾਸੇ, **ਮਾਡਲ ਚੁਣੋ** ਅਤੇ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਨੂੰ ਕੰਟਰੋਲ ਕਰੋ।

**ਮਾਡਲ ਚੁਣੋ** ਤੁਹਾਨੂੰ ਮੌਜੂਦਾ ਕੰਮ ਲਈ ਕਿਹੜਾ ਐਆਈ ਇੰਜਣ ਵਰਤਣਾ ਹੈ, ਉਸਦੀ ਚੋਣ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

  ![ਮਾਡਲ ਚੁਣੋ](../images/screenshots/pa/model-selector.png)

ਕੁਝ ਮੁਫਤ ਮਾਡਲ ਹਮੇਸ਼ਾ ਉਪਲਬਧ ਨਹੀਂ ਹੁੰਦੇ—ਕਦੇ ਉਹ ਆਫਲਾਈਨ ਜਾਂ ਵਰਤੋਂ ਦੀ ਸੀਮਾ ਵਿੱਚ ਹੁੰਦੇ ਹਨ। ਜੇ ਇਹ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਐਪ ਆਪਣੇ ਆਪ ਤੁਹਾਡੀ ਉਪਲਬਧ ਸੂਚੀ ਵਿੱਚੋਂ ਉਸ ਮਾਡਲ ਨੂੰ ਹਟਾ ਦੇਵੇਗੀ। ਦਿਖਾਏ ਜਾਣ ਵਾਲੇ ਮਾਡਲਾਂ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਮਾਡਲ**](#models) ਤੇ ਜਾਓ ਅਤੇ ਆਪਣੀ ਮਾਡਲ ਸੂਚੀ ਨੂੰ ਸੋਧੋ।
ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਮਾਡਲ ਨਾਮ ਦੇ ਖੱਬੇ ਪਾਸੇ ਪ੍ਰੋਵਾਈਡਰ ਆਈਕਾਨ 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਸਿੱਧੇ ਮਾਡਲ ਸੈਟਿੰਗਸ ਵੀ ਖੋਲ੍ਹ ਸਕਦੇ ਹੋ।

<br/>

**ਭਾਸ਼ਾ ਦਾ ਨਿਸ਼ਾਨ + ਭਾਸ਼ਾ ਕੋਡ** ਐਪ ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ ਨੂੰ ਬਦਲ ਦਿੰਦਾ ਹੈ, ਜਿਵੇਂ ਕਿ ਮੇਨੂ ਅਤੇ ਬਟਨ। ਇਹ **ਅਨੁਵਾਦ** ਵਿੱਚ ਵਰਤੇ ਗਏ ਅਨੁਵਾਦ ਭਾਸ਼ਾਵਾਂ ਨੂੰ ਨਹੀਂ ਬਦਲਦਾ।

<a id="input-and-output-panels"></a>
### ਇਨਪੁਟ ਅਤੇ ਆਊਟਪੁਟ ਪੈਨਲ

ਆਮ ਤੌਰ 'ਤੇ, ਕੰਮ ਦੀ ਥਾਂ ਖੱਬੇ ਪਾਸੇ ਇੱਕ **ਇਨਪੁਟ** ਪੈਨਲ ਅਤੇ ਸੱਜੇ ਪਾਸੇ ਇੱਕ **ਆਊਟਪੁਟ** ਪੈਨਲ ਵਰਤਦੀ ਹੈ।

ਹਰੇਕ ਪੈਨਲ ਵੀ ਦਰਸਾਉਂਦਾ ਹੈ:

| **ਇਨਪੁਟ**                                                              | **ਆਊਟਪੁਟ**                                                                                                               |
|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - ਅੱਖਰ ਗਿਣਤੀ <br/>- ਸ਼ਬਦ ਗਿਣਤੀ <br/>- ਪੈਰਾ ਗਿਣਤੀ       <br/> | - ਕੰਮ ਨੂੰ ਕਰਨ ਵਿੱਚ ਕਿੰਨਾ ਸਮਾਂ ਲੱਗਿਆ <br/>- **TPS** (ਪ੍ਰਤੀ ਸਕਿੰਟ ਟੋਕਨ)<br/>- ਅੱਖਰ, ਸ਼ਬਦ ਅਤੇ ਪੈਰੇ ਗਿਣਤੀ<br/>- ਵਰਤਿਆ ਗਿਆ ਮਾਡਲ |


ਜੇ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦਾਂ ਬਾਰੇ ਸੋਚ ਰਹੇ ਹੋ:

- **ਟੋਕਨ** ਦਾ ਅਰਥ ਹੈ ਪਾਠ ਦਾ ਛੋਟਾ ਟੁਕੜਾ। ਤੁਸੀਂ ਇਸਨੂੰ ਸ਼ਬਦ ਦਾ ਹਿੱਸਾ ਜਾਂ ਛੋਟਾ ਸ਼ਬਦ ਸਮਝ ਸਕਦੇ ਹੋ।
- **TPS** ਦਾ ਅਰਥ ਹੈ ਕਿ ਮਾਡਲ ਹਰ ਸਕਿੰਟ ਕਿੰਨੇ ਪਾਠਾਂ ਨੂੰ ਸੰਸਾਧਿਤ ਕਰਦਾ ਹੈ।

<br/>

ਤੁਸੀਂ ਹਰੇਕ ਕਾਰਵਾਈ ਦੀ ਲਾਗਤ (ਜੇ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਕੁੱਲ ਲਾਗਤ ਨੂੰ ਵੀ ਨਿਗਰਾਨੀ ਕਰ ਸਕਦੇ ਹੋ, [**ਸੈਟਿੰਗਸ** > **ਜਨਰਲ ਸੈਟਿੰਗਸ**](#general-settings) ਉੱਤੇ `ਕਾਰਵਾਈਆਂ 'ਤੇ ਲਾਗਤ ਦੀ ਜਾਣਕਾਰੀ ਦਿਖਾਓ` ਚੋਣ ਨੂੰ ਚਾਲੂ ਕਰਕੇ।

## ਅਨੁਵਾਦ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਪਾਠ ਨੂੰ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਅਨੁਵਾਦ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਅਨੁਵਾਦ ਕਾਰਜਸਥਾਨ](../images/screenshots/pa/translate.png)

<br/>

<a id="translate-text"></a>
### ਪਾਠ ਦਾ ਅਨੁਵਾਦ ਕਰੋ

1. **ਅਨੁਵਾਦ** ਖੋਲ੍ਹੋ।
2. **ਤੋਂ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
3. **ਨੂੰ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. **ਇਨਪੁਟ** ਵਿੱਚ ਪਾਠ ਟਾਈਪ ਜਾਂ ਪੇਸਟ ਕਰੋ।
6. **ਅਨੁਵਾਦ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
7. **ਆਊਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।
8. ਨਤੀਜਾ ਕਾਪੀ ਕਰਨ ਲਈ ਕਾਪੀ ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।

<br/>

<a id="language-selection"></a>
### ਭਾਸ਼ਾ ਦੀ ਚੋਣ

- **ਤੋਂ** ਇੱਕ ਖਾਸ ਭਾਸ਼ਾ ਹੋ ਸਕਦੀ ਹੈ ਜਾਂ **ਭਾਸ਼ਾ ਪਛਾਣੋ**।
- **ਨੂੰ** ਉਹ ਭਾਸ਼ਾ ਹੈ ਜਿਸ ਵਿੱਚ ਤੁਸੀਂ ਨਤੀਜਾ ਚਾਹੁੰਦੇ ਹੋ।

ਤੁਹਾਡੀ ਚੁਣੀ ਹੋਈ **ਟੌਪ ਭਾਸ਼ਾਵਾਂ** ਸੂਚੀ ਦੀ ਸਿਖਰ 'ਤੇ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ। ਤੁਸੀਂ ਇਹਨਾਂ ਨੂੰ [**ਸੈਟਿੰਗਸ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਉੱਤੇ ਸੈਟ ਕਰ ਸਕਦੇ ਹੋ।

### ਲਾਭਦਾਇਕ ਅਨੁਵਾਦ ਸੈਟਿੰਗਸ

- **ਰਿਜ਼ਲਟ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਲਿਪਬੋਰਡ 'ਤੇ ਕਾਪੀ ਕਰੋ** ਕਾਰਵਾਈ ਪੂਰੀ ਹੋਣ ਤੋਂ ਬਾਅਦ ਨਤੀਜੇ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।

<a id="rewrite"></a>

- ਸਹੀ ਹਰਫ, ਵਿਆਕਰਣ ਠੀਕ ਕਰਨਾ
- ਪਾਠ ਨੂੰ ਸਪਸ਼ਟ ਬਣਾਉਣਾ
- ਪਾਠ ਨੂੰ ਵੱਧ ਰਸਮੀ ਜਾਂ ਘੱਟ ਰਸਮੀ ਬਣਾਉਣਾ
- ਪਾਠ ਨੂੰ ਛੋਟਾ ਜਾਂ ਵੱਡਾ ਕਰਨਾ
- ਪਾਠ ਨੂੰ ਵੱਧ ਤਕਨੀਕੀ ਲੱਗਣਾ

> 💡 **ਟਿਪ**<br/>

> ਸੁਧਾਰਾਂ ਦਾ ਪ੍ਰਦਰਸ਼ਨ ਟੌਗਲ ਕਰਨ ਲਈ, ਆਪਣੇ ਪਾਠ ਵਿੱਚ ਕੀਤੀਆਂ ਗਈਆਂ ਖਾਸ ਤਬਦੀਲੀਆਂ ਨੂੰ ਦਿਖਾਉਣ ਜਾਂ ਲੁਕਾਉਣ ਲਈ ਇਸ ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="transform"></a>

## ਤਬਦੀਲੀ

ਜਦੋਂ ਵੀ ਤੁਸੀਂ ਆਈਆਈ ਨੂੰ ਕਸਟਮ ਨਿਰਦੇਸ਼ਾਂ ਦਾ ਪਾਲਣ ਕਰਨ ਲਈ ਸੱਦਾ ਦੇਣਾ ਚਾਹੁੰਦੇ ਹੋ, **ਤਬਦੀਲੀ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਤਬਦੀਲੀ ਕਾਰਜ ਸਥਾਨ](../images/screenshots/pa/transform.png)

ਇਹ ਐਪ ਦਾ ਸਭ ਤੋਂ ਲਚਕਦਾਰ ਹਿੱਸਾ ਹੈ। ਤੁਸੀਂ ਇਸ ਨੂੰ ਅਜਿਹੇ ਕੰਮਾਂ ਲਈ ਵਰਤ ਸਕਦੇ ਹੋ:

- ਨੋਟਾਂ ਦਾ ਸਾਰ ਬਣਾਉਣਾ
- ਕਚਰੇ ਵਾਲੇ ਟੈਕਸਟ ਨੂੰ ਪੌਲਿਸ਼ ਕੀਤਾ ਈਮੇਲ ਵਿੱਚ ਬਦਲਣਾ
- ਮੁੱਖ ਬਿੰਦੂਆਂ ਨੂੰ ਬਾਹਰ ਕੱਢਣਾ
- ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਖਾਸ ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲਣਾ
- ਦਰਜ ਕੀਤੇ ਟੈਕਸਟ ਵਿੱਚ ਹੋਰ ਕੋਈ ਵੀ ਕਸਟਮ ਗਤੀਵਿਧੀ

<br/>

<a id="run-an-existing-prompt"></a>
### ਇੱਕ ਮੌਜੂਦਾ ਪ੍ਰਾਪਤ ਸੰਕੇਤ ਨੂੰ ਚਲਾਓ

1. **ਤਬਦੀਲੀ** ਖੋਲ੍ਹੋ।
2. ਸੂਚੀ ਵਿੱਚੋਂ ਇੱਕ ਸੰਕੇਤ ਚੁਣੋ।
3. ਜੇਕਰ **ਟੀਚਾ** ਭਾਸ਼ਾ ਬਾਕਸ ਦਿਖਾਈ ਦੇਵੇ ਤਾਂ, ਜੇ ਤੁਸੀਂ ਚਾਹੋ ਤਾਂ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. **ਇਨਪੁਟ** ਵਿੱਚ ਟੈਕਸਟ ਲਿਖੋ ਜਾਂ ਪੇਸਟ ਕਰੋ।
5. **ਤਬਦੀਲੀ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
6. **ਆਉਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### ਜੇਕਰ ਤੁਹਾਡੇ ਕੋਲ ਹਾਲੇ ਤੱਕ ਕੋਈ ਸੰਕੇਤ ਨਾ ਹੋਵੇ

ਜੇਕਰ ਤੁਹਾਡੀ ਸੂਚੀ ਖਾਲੀ ਹੈ, ਤਾਂ **ਨਮੂਨਾ ਸੰਕੇਤ ਲੋਡ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਸ ਨਾਲ ਅੰਦਰੂਨੀ ਉਦਾਹਰਣਾਂ ਜੋੜੀਆਂ ਜਾਣਗੀਆਂ ਤਾਂ ਜੋ ਤੁਸੀਂ ਜਲਦੀ ਸ਼ੁਰੂਆਤ ਕਰ ਸਕੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਨਮੂਨਾ ਸੰਕੇਤ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਉਪਲਬਧ ਕਰਵਾਏ ਗਏ ਹਨ। ਉਹਨਾਂ ਨੂੰ ਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਤੁਸੀਂ ਇੱਕ ਸੰਕੇਤ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ **ਸੰਕੇਤ ਨੂੰ ਅਨੁਵਾਦ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਆਪਣੀ ਭਾਸ਼ਾ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="create-a-prompt-quickly"></a>
### ਤੇਜ਼ੀ ਨਾਲ ਇੱਕ ਸੰਕੇਤ ਬਣਾਓ

ਸੰਕੇਤ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਤਰੀਕਾ ਹੈ:

1. **ਨਵਾਂ ਸੰਕੇਤ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
2. **ਸੰਕੇਤ ਪੈਦਾ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਸੰਕੇਤ ਨਾਲ ਤੁਸੀਂ ਕੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਇਸ ਦਾ ਵੇਰਵਾ ਦਿਓ।
4. ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. ਐਪ ਨੂੰ ਆਪਣੇ ਲਈ ਡਰਾਫਟ ਬਣਾਉਣ ਦਿਓ।
6. ਡਰਾਫਟ ਦੀ ਜਾਂਚ ਕਰੋ ਅਤੇ **ਸੇਵ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

![ਸੰਕੇਤ ਪੈਦਾ ਕਰੋ](../images/screenshots/pa/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### ਇੱਕ ਸੰਕੇਤ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਸੰਕੇਤ ਬਣਾਉਂਦੇ ਹੋ ਜਾਂ ਸੰਪਾਦਿਤ ਕਰਦੇ ਹੋ, ਸੰਪਾਦਕ ਖੱਬੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ ਅਤੇ ਸੱਜੇ ਪਾਸੇ ਇੱਕ ਪਰਖ ਖੇਤਰ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

![ਤਬਦੀਲੀ ਸੰਕੇਤ ਸੰਪਾਦਕ](../images/screenshots/pa/transform-prompt-edit.png)

ਮੁੱਖ ਖੇਤਰ ਹਨ:

- **ਸੰਕੇਤ ਨਾਮ**: ਸੰਕੇਤ ਸੂਚੀ ਵਿੱਚ ਦਿਖਾਏ ਨਾਮ।
- **ਸੰਕੇਤ ਨਿਰਦੇਸ਼ (ਵੈਕਲਪਿਕ)**: ਸੰਕੇਤ ਨੂੰ ਚਲਾਉਂਦੇ ਸਮੇਂ ਉਪਭੋਗਤਾ ਨੂੰ ਵੇਖਾਇਆ ਜਾਣ ਵਾਲਾ ਸੰਖੇਪ ਸੁਝਾਅ।
- **ਮਾਡਲ ਭੂਮਿਕਾ**: ਆਈਆਈ ਨੂੰ ਦਿੱਤੀ ਜਾਣ ਵਾਲੀ ਮੁੱਖ ਭੂਮਿਕਾ, ਜਿਵੇਂ 'ਤੁਸੀਂ ਇੱਕ ਸਹਾਇਕ ਸਹਾਇਕ ਹੋ।'
- **ਮਾਡਲ ਨਿਰਦੇਸ਼ (ਹਰ ਲਾਈਨ ਵਿਚ ਇੱਕ)**: ਥੋੜਾ ਨਿਯਮ ਜਿਸਦਾ ਪਾਲਣ ਕਰਨਾ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ।
- **ਆਉਟਪੁੱਟ ਵੇਰਵਾ**: ਨਤੀਜੇ ਨੂੰ ਦਰਸਾਉਣ ਵਾਲਾ ਸੰਖੇਪ ਸ਼ਬਦ, ਜਿਵੇਂ 'ਸਾਰ, ' ਜਾਂ 'ਦੁਬਾਰਾ ਬਿਲੀਅਰੋਮ, and stopped a flood. That's the way.    I don’t track my boys, I point it at the gate. It's not recording my yard. Simple. You say it’s not backup? Call it another brick in the wall. Like a lock on my door.    You want layers, I’ve got  em. But when I’m not home? That second layer? That’s not weakness. It’s smart.

**Temperature (0.0 → 1.0)**: ਮਾਡਲ ਦੀ ਵਿਵਹਾਰ; ਹੇਠਾਂ ਵੇਖੋ।
- **ਟੀਚਾ ਭਾਸ਼ਾ ਲਈ ਪੁੱਛੋ**: ਜਦੋਂ ਸੰਕੇਤ ਨੂੰ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਤੁਸੀਂ ਨਿਸ਼ਾਨਾ ਭਾਸ਼ਾ ਚੁਣ ਸਕਦੇ ਹੋ।

ਜੇਕਰ ਤੁਹਾਨੂੰ ਤਕਨੀਕੀ ਸ਼ਬਦ **ਟੈਂਪਰੇਚਰ** ਨਵਾਂ ਲੱਗਦਾ ਹੈ, ਤਾਂ ਇਸ ਤਰ੍ਹਾਂ ਸੋਚੋ:

- **ਘੱਟ** ਟੈਂਪਰੇਚਰ ਸਥਿਰ ਅਤੇ ਜ਼ਿਆਦਾ ਮੁਲਾਂਕਣਯੋਗ ਨਤੀਜੇ ਦਿੰਦਾ ਹੈ।
- **ਉੱਚ** ਟੈਂਪਰੇਚਰ ਵਿਭਿੰਨਤਾ ਅਤੇ ਰਚਨਾਤਮਕਤਾ ਦਿੰਦਾ ਹੈ।

ਤੁਸੀਂ ਇਹ ਵੀ ਵਰਤ ਸਕਦੇ ਹੋ:

- **`Generate prompt`** ਸੰਖੇਪ ਵਰਣਨ ਤੋਂ ਨਵਾਂ ਡਰਾਫਟ ਬਣਾਉਣ ਲਈ
- **`Improve prompt`** ਮੌਜੂਦਾ ਸੰਕੇਤ ਨੂੰ ਸੁਧਾਰਨ ਲਈ
- **`Translate prompt`** ਸੰਕੇਤ ਫੀਲਡ ਨੂੰ ਅਨੁਵਾਦ ਕਰਨ ਲਈ

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> **`Back to Run`** ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **`Save`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਜੇਕਰ ਤੁਸੀਂ ਬਿਨਾਂ ਸੰਭਾਲੇ ਵਾਪਸ ਜਾਂਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਡੀਆਂ ਤਬਦੀਲੀਆਂ ਗੁਆਚ ਜਾਣਗੀਆਂ।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ਇਸ ਨੂੰ ਵਰਤਣ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਸੰਕੇਤ ਦੀ ਪ੍ਰੀਖਿਆ ਕਰੋ

ਸੱਜੇ ਪਾਸੇ ਪ੍ਰੀਖਿਆ ਪੈਨਲ ਤੁਹਾਨੂੰ ਸੈਂਪਲ ਟੈਕਸਟ ਨਾਲ ਆਪਣੇ ਸੰਕੇਤ ਨੂੰ ਰੋਜ਼ਾਨਾ ਕੰਮ ਵਿੱਚ ਵਰਤ

### ਡੈਸ਼ਬੋਰਡ ਟੈਬ

- **ਸਾਰ** ਤੁਹਾਨੂੰ ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ ਦਾ ਜਨਰਲ ਵਿਚਾਰ ਦਿੰਦਾ ਹੈ।
- **ਵਰਤੋਂ ਅਨੁਸਾਰ** ਗਤੀਵਿਧੀ ਨੂੰ ਅਨੁਵਾਦ ਭਾਸ਼ਾ, ਪੁਨਰਲੇਖਨ ਮੋਡ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਪ੍ਰੋਮਪਟ ਅਨੁਸਾਰ ਵੰਡਦਾ ਹੈ।
- **ਮਾਡਲ ਅਨੁਸਾਰ** ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਕਿਹੜੇ ਮਾਡਲ ਵਰਤੇ ਹਨ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀ ਕੀ ਲਾਗਤ ਆਈ।
- **ਦਿਨ ਅਨੁਸਾਰ** ਰੋਜ਼ਾਨਾ ਕੁੱਲ ਦਿਖਾਉਂਦਾ ਹੈ।
- **ਸਾਰੇ ਕਾਲ** ਪੂਰੀ ਕਾਲ ਇਤਿਹਾਸ ਦਿਖਾਉਂਦਾ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ ਇਸਨੂੰ ਨਿਰਯਾਤ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<br/>

<a id="export-data"></a>
### ਡਾਟਾ ਨੂੰ ਨਿਰਯਾਤ ਕਰੋ

ਡੈਸ਼ਬੋਰਡ ਟੇਬਲ ਦੇ ਡਾਟੇ ਨੂੰ ਨਿਰਯਾਤ ਕਰ ਸਕਦੇ ਹਨ:

- **JSON**
- **CSV**
- **XLSX**

ਜੇਕਰ ਤੁਸੀਂ ਐਪ ਤੋਂ ਬਾਹਰ ਗਤੀਵਿਧੀ ਦੀ ਸਮੀਖਿਆ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਜਾਂ ਰਿਪੋਰਟ ਸਾਂਝੀ ਕਰਨੀ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਇਹ ਉਪਯੋਗੀ ਹੈ।

<br/>

<a id="delete-stored-records-for-a-model"></a>
### ਕਿਸੇ ਮਾਡਲ ਲਈ ਸਟੋਰ ਕੀਤੇ ਰਿਕਾਰਡ ਨੂੰ ਹਟਾਓ

**ਮਾਡਲ ਅਨੁਸਾਰ** ਜਾਂ **ਸਾਰੇ ਕਾਲ**, ਤੁਸੀਂ "ਕੂੜੇਦਾਨ" ਚਿੰਨ੍ਹ ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਕਿਸੇ ਮਾਡਲ ਲਈ ਸਟੋਰ ਕੀਤੇ ਰਿਕਾਰਡ ਨੂੰ ਹਟਾ ਸਕਦੇ ਹੋ।

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਸਟੋਰ ਕੀਤੇ ਰਿਕਾਰਡ ਨੂੰ ਮਿਟਾਉਣਾ ਉਲਟਾ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਇਸਦੀ ਵਰਤੋਂ ਤਾਂ ਹੀ ਕਰੋ ਜੇਕਰ ਤੁਸੀਂ ਯਕੀਨੀ ਹੋ ਕਿ ਤੁਹਾਨੂੰ ਉਸ ਇਤਿਹਾਸ ਦੀ ਹੁਣੇ ਲੋੜ ਨਹੀਂ ਹੈ।

ਸਾਰੇ ਡਾਟੇ ਨੂੰ ਮਿਟਾਉਣ ਲਈ ਜਾਂ ਉਮਰ ਦੇ ਆਧਾਰ 'ਤੇ ਰਿਕਾਰਡ ਹਟਾਉਣ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਤੇ ਜਾਓ। ਉੱਥੇ ਤੁਹਾਨੂੰ ਸਟੋਰ ਕੀਤੇ ਸਾਰੇ ਡਾਟੇ ਜਾਂ ਕਿਸੇ ਨਿਸ਼ਚਿਤ ਮਿਤੀ ਤੋਂ ਪਹਿਲਾਂ ਦੇ ਡਾਟੇ ਨੂੰ ਮਿਟਾਉਣ ਦੇ ਵਿਕਲਪ ਮਿਲਣਗੇ।

<a id="general-settings"></a>
### ਜਨਰਲ ਸੈਟਿੰਗਸ

**ਜਨਰਲ ਸੈਟਿੰਗਸ** ਦੀ ਵਰਤੋਂ ਟਾਈਪਿੰਗ ਵਿਵਹਾਰ, ਹਰੇਕ ਕਾਰਵਾਈ ਦੇ ਵੇਰਵੇ ਨੂੰ **ਇਤਿਹਾਸ** ਲਈ ਸਟੋਰ ਕਰਨ ਅਤੇ ਰੂਪ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ ਕਰੋ।

**ਵਿਹਾਰ**

- **ENTER ਲਈ ਵਿਵਹਾਰ** ਚੁਣਦਾ ਹੈ ਕਿ `Enter` ਕਾਰਵਾਈ ਨੂੰ ਚਲਾਉਂਦਾ ਹੈ ਜਾਂ ਨਵੀਂ ਲਾਈਨ ਪੇਸ਼ ਕਰਦਾ ਹੈ।
- **ਪੇਸਟ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਸੀਂ ਜਿਵੇਂ ਹੀ ਟੈਕਸਟ ਪੇਸਟ ਕਰਦੇ ਹੋ, ਅਨੁਵਾਦ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- **ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਨਤੀਜਾ ਸਵੈਚਲਿਤ ਕਾਪੀ ਕਰੋ** ਸਫਲ ਨਤੀਜੇ ਨੂੰ ਸਵੈਚਲਿਤ ਤੌਰ 'ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪਿੰਗ ਦੌਰਾਨ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ।
- **ਸਮਾਂ-ਬਾਹਰ (ਐਮਐਸ)** ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਲਈ ਉਡੀਕ ਸਮਾਂ ਸੈੱਟ ਕਰਦਾ ਹੈ।

**ਇਤਿਹਾਸ**

- **ਚਲਾਉਣ ਇਤਿਹਾਸ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖੋ** ਨਿਯੰਤਰਣ ਕਰਦਾ ਹੈ ਕਿ ਹਰੇਕ ਅਨੁਵਾਦ, ਪੁਨਰਲੇਖਨ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ **ਇਨਪੁਟ ਅਤੇ ਆਉਟਪੁਟ ਟੈਕਸਟ** ਨੂੰ ਸਾਈਡਬਾਰ [**ਇਤਿਹਾਸ**](#history) ਵਿਚਾਰ ਲਈ ਸਟੋਰ ਕਰਦਾ ਹੈ ਕਿ ਨਹੀਂ। ਇਸਨੂੰ ਬੰਦ ਕਰਨਾ ਪੁਸ਼ਟੀ ਦੀ ਮੰਗ ਕਰਦਾ ਹੈ; ਜੇਕਰ ਤੁਸੀਂ ਪੁਸ਼ਟੀ ਕਰਦੇ ਹੋ, ਤਾਂ ਸਟੋਰ ਕੀਤਾ ਗਿਆ ਇਤਿਹਾਸ ਟੈਕਸਟ ਡੇਟਾਬੇਸ ਤੋਂ ਹਟਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।
- **ਇਤਿਹਾਸ ਡਾਟਾ ਹਟਾਉਂਓ** ਤੁਹਾਨੂੰ **ਡਾਟਾ ਨੂੰ ਮਿਟਾਓ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਉਮਰ ਅਨੁਸਾਰ (ਉਦਾਹਰਣ ਲਈ ਕੁਝ ਮਹੀਨੇ ਪੁਰਾਣੇ, ਜਾਂ **ਸਾਰੇ ਡਾਟੇ (ਸਪੱਸ਼ਟ)**) ਸਟੋਰ ਕੀਤਾ ਟੈਕਸਟ ਨੂੰ ਹਟਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਇਸਦਾ ਪ੍ਰਭਾਵ ਸਿਰਫ਼ **ਇਤਿਹਾਸ** ਵਿਚਾਰ ਲਈ ਸੰਭਾਲੇ ਗਏ ਚਲਾਉਣ ਵਾਲੇ ਟੈਕਸਟ 'ਤੇ ਪੈਂਦਾ ਹੈ; ਇਹ ਲਾਗਤ ਜਾਂ ਵਰਤੋਂ ਦੇ ਕੁੱਲ ਅੰਕੜੇ ਨਹੀਂ ਮਿਟਾਉਂਦਾ। **ਲਾਗਤ** ਦੇ ਅੰਕੜੇ ਨੂੰ ਹਟਾਉਣ ਜਾਂ ਕੱਟਣ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਦਿੱਖ**

- **ਕਾਰਵਾਈਆਂ 'ਤੇ ਲਾਗਤ ਜਾਣਕਾਰੀ ਦਿਖਾਓ** ਕਾਰਵਾਈ ਪ੍ਰਤੀ ਲਾਗਤ (ਜੇਕਰ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਅਨੁਵਾਦ, ਪੁਨਰਲੇਖਨ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਆਉਟਪੁਟ ਪੈਨਲਾਂ 'ਤੇ ਕੁੱਲ ਲਾਗਤ ਦੀ ਵੇਖਾਈ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।
- **ਲਾਗਤ ਭਿੰਨਾਤਮਕ ਅੰਕ** ਲਾਗਤ ਦਸ਼ਮਲਵਾਂ ਨੂੰ ਕਿਵੇਂ ਪ੍ਰਦਰਸ਼ਿਤ ਕਰਨਾ ਬਦਲਦਾ ਹੈ।
- **ਸਿਰਫ਼ ਵੈੱਬ:** **ਐਪ ਦੇ ਚਾਰੇ ਪਾਸੇ ਮਾਰਜਿਨ ਦਿਖਾਓ** ਇੰਟਰਫੇਸ ਦੇ ਚਾਰੇ ਪਾਸੇ ਵਾਧੂ ਸਪੇਸ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਫਾਂਟ ਫੈਮਿਲੀ** ਟੈਕਸਟ ਪੈਨਲਾਂ ਵਿੱਚ ਲਿਖਣ ਦੇ ਫਾਂਟ ਨੂੰ ਬਦਲਦਾ ਹੈ।
- **ਆਕਾਰ** ਫਾਂਟ ਦੇ ਆਕਾਰ ਨੂੰ ਬਦਲਦਾ ਹੈ।

<a id="models"></a>

### ਮਾਡਲ

ਟੂਲਬਾਰ ਵਿੱਚ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ, ਇਸਨੂੰ ਚੁਣਨ ਲਈ **ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਸੈਟਿੰਗਜ਼ ਮਾਡਲ ਟੈਬ](../images/screenshots/pa/settings-models.png)

ਪੇਜ ਵਿੱਚ ਦੋ ਲਿਸਟ ਹੁੰਦੀਆਂ ਹਨ:

- ਖੱਬੇ ਪਾਸੇ **ਉਪਲਬਧ ਮਾਡਲ**
- ਸੱਜੇ ਪਾਸੇ **ਚੁਣੇ ਹੋਏ ਮਾਡਲ**

ਵਰਤਮਾਨ ਕੰਟਰੋਲਸ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:

- ਨਾਮ ਨਾਲ ਮਾਡਲ ਲੱਭਣ ਲਈ **ਮਾਡਲ ਖੋਜੋ...**
- ਇੱਕ ਇੰਜਣ ’ਤੇ (OpenRouter, OpenAI, Ollama, …) ਲਿਸਟ ਨੂੰ ਸੀਮਤ ਕਰਨ ਲਈ **ਪ੍ਰੋਵਾਈਡਰ** ਚਿਪਸ
- ਸਿਰਫ਼ ਮੁਫਤ ਮਾਡਲ ਦਿਖਾਉਣ ਲਈ **ਸਿਰਫ਼ ਮੁਫਤ**
- ਲਿਸਟ ਨੂੰ ਦੁਬਾਰਾ ਲੋਡ ਕਰਨ ਲਈ **ਰੀਫਰੇਸ**
- ਤੁਸੀਂ ਪ੍ਰੋਵਾਈਡਰ ਨਾਲ ਕ੍ਰਮਬੱਧ ਕਰ ਰਹੇ ਹੋਣ ਤਾਂ **ਸਾਰੇ ਵਿਸਤ੍ਰਿਤ ਕਰੋ** ਅਤੇ **ਸਾਰੇ ਸੰਕੋਚੋ**

ਮਾਡਲ ID ਵਿੱਚ ਪ੍ਰੋਵਾਈਡਰ ਪਰਵਰਿਥੀ (ਉਦਾਹਰਨ ਲਈ `ਓਪਰ ਰਾਉਟਰ/...` ਬਨਾਮ `openai/...`). ਬੈਜ ਜਿਵੇਂ ਕਿ **OpenAI (OpenRouter)** ਬਨਾਮ **OpenAI (ਸਿੱਧਾ)** ਦਰਸਾਉਂਦੇ ਹਨ ਕਿ ਟਰੈਫਿਕ ਕਿਵੇਂ ਰੂਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

> ℹ️ **ਨੋਟ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) ਇੱਕ ਰਾਊਟਰ ਮਾਡਲ ਹੈ, ਜਨਰਲ ਚੈਟ ਮਾਡਲ ਨਹੀਂ: ਇਸਦਾ ਜਵਾਬ ਜੇਐਸਓਐਨ ਹੈ ਜੋ OpenRouter API ਰਿਕਵੈਸਟ ਬਾਡੀ ਨੂੰ ਵਰਨਨ ਕਰਦਾ ਹੈ (ਉਦਾਹਰਨ ਲਈ `model` ਅਤੇ `messages` ਨਾਲ `requests` ਐਰੇ). ਜੇਕਰ ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ **ਅਨੁਵਾਦ**, **ਰੀਆਈਟ**, ਜਾਂ **ਟਰਾਂਸਫਾਰਮ** ਲਈ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁਟ ਪੈਨਲ ਪੂਰਾ ਟੈਕਸਟ ਦੀ ਬਜਾਏ ਉਹ ਜੇਐਸਓਐਨ ਦਿਖਾਏਗਾ। ਇਹਨਾਂ ਕੰਮਾਂ ਲਈ ਇੱਕ ਸਾਧਾਰਨ ਟੈਕਸਟ ਮਾਡਲ ਚੁਣੋ। OpenRouter ਉੱਤੇ ਜਾਓ [Body Builder ਮਾਡਲ ਪੇਜ](https://openrouter.ai/openrouter/bodybuilder)।

ਕਾਰਵਾਈਆਂ:

- ਕੋਈ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, **ਸ਼ਾਮਲ ਕਰੋ** ਜਾਂ ਐਂਟਰੀ ਦੇ ਕਿਸੇ ਵੀ ਸਥਾਨ ’ਤੇ ਕਲਿੱਕ ਕਰੋ।

- ਕੋਈ ਮਾਡਲ ਹਟਾਉਣ ਲਈ, **ਚੁਣੇ ਮਾਡਲ** ਵਿੱਚ ਇਸਦੇ ਨੇੜੇ **X** ’ਤੇ ਜਾਂ **ਉਪਲਬਧ ਮਾਡਲ** ਵਿੱਚ ਐਂਟਰੀ ਉੱਤੇ **ਚੁਣਿਆ** ’ਤੇ ਕਲਿੱਕ ਕਰੋ।

- ਲਿਸਟ ਨੂੰ ਸਾਫ਼ ਕਰਨ ਲਈ, **ਸਾਰੇ ਵਾਪਸ ਕਰੋ** ’ਤੇ ਕਲਿੱਕ ਕਰੋ। ਲੋੜੀਂਦਾ ਮੁਫਤ ਮਾਡਲ ਲਿਸਟ ਵਿੱਚ ਰਹੇਗਾ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਜੇਕਰ ਤੁਸੀਂ OpenRouter ’ਤੇ ਕਰੈਡਿਟਸ ਤੁਰੰਤ ਸ਼ਾਮਲ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ **ਸਿਰਫ਼ ਮੁਫਤ** ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ, ਮੁਫਤ ਮਾਡਲ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ) ਚੁਣ ਕੇ ਸ਼ੁਰੂ ਕਰੋ। ਬਿਨਾਂ ਕਿਸੇ ਏਪੀਆਈ ਕੁੰਜੀ ਦੇ ਮਾਡਲ ਚਲਾਉਣ ਲਈ ਤੁਸੀਂ Ollama ਵੀ ਵਰਤ ਸਕਦੇ ਹੋ।

<a id="languages"></a>
### ਭਾਸ਼ਾਵਾਂ

ਐਪ ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਂਦੀਆਂ ਭਾਸ਼ਾਵਾਂ ਦੀਆਂ ਲਿਸਟਾਂ ਨੂੰ ਜੋੜਨ ਲਈ **ਸੈਟਿੰਗਜ਼** > **ਭਾਸ਼ਾਵਾਂ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਸਿਖਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** **ਅਨੁਵਾਦ** ਅਤੇ **ਟਰਾਂਸਫਾਰਮ** ਵਿੱਚ ਭਾਸ਼ਾਵਾਂ ਦੀਆਂ ਲਿਸਟਾਂ ਵਿੱਚ ਉੱਪਰਲੇ ਭਾਗ ਵਿੱਚ ਪਿੰਨ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- **ਕਸਟਮ ਭਾਸ਼ਾ** ਕਹਿੰਦੀ ਹੈ ਕਿ ਤੁਸੀਂ ਬਿਲਟ-ਇਨ ਲਿਸਟ ਵਿੱਚ ਨਾ ਹੋਣ ਵਾਲੀ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹੋ।

ਜੇਕਰ ਤੁਸੀਂ ਕੋਈ ਕਸਟਮ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਤਾਂ ਇਹ ਬਿਲਟ-ਇਨ ਵਿਕਲਪਾਂ ਨਾਲ ਜੁੜ ਕੇ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲੇ ਵਿੱਚ ਪ੍ਰਗਟ ਹੁੰਦੀ ਹੈ।

<br/>

<a id="cost-tracking"></a>
### ਖਰਚ ਟਰੈਕਿੰਗ

ਖਰਚ ਸਬੰਧੀ ਜਾਣਕਾਰੀ ਨੂੰ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਜ਼** > **ਖਰਚ ਟਰੈਕਿੰਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਕੁੱਲ ਖਰਚ** ਨਿਰੰਤਰ ਕੁੱਲ ਦਿਖਾਉਂਦਾ ਹੈ।
- **ਮੁੱਲ ਕਾਪੀ ਕਰੋ** ਕੁੱਲ ਨੂੰ ਕਲਿੱਪਬੋਰਡ ’ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਖਰਚ ਰੀਸੈੱਟ ਕਰੋ** ਸਟੋਰ ਕੀਤੀ ਗਈ ਕੁੱਲ ਰਕਮ ਨੂੰ ਸਿਫ਼ਰ ’ਤੇ ਰੀਸੈੱਟ ਕਰਦਾ ਹੈ।
- **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਤਾਲਮੇਲ** ਬਣਾਓ ਆਪਣੇ OpenRouter ਅਕਾਊਂਟ ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੀ ਗਈ ਵਰਤੋਂ ਦੇ ਅਨੁਸਾਰ ਕੁੱਲ ਨੂੰ ਸੈੱਟ ਕਰਦਾ ਹੈ (ਸਿਰਫ਼ OpenRouter).
- **API ਕੁੰਜੀ ਵਰਤੋਂ** OpenRouter ਵਰਤੋਂ ਵੇਰਵਿਆਂ ਨੂੰ ਦਿਖਾਉਂਦੀ ਹੈ, ਜੇਕਰ ਉਪਲਬਧ ਹੋਵੇ।
- **ਖਰਚ ਅੰਕੜੇ ਮਿਟਾਓ** ਸਭ ਅੰਕੜੇ ਨੂੰ ਮਿਟਾਉਂਦਾ ਹੈ, ਜਾਂ ਸਿਰਫ਼ ਚੁਣੀ ਹੋਈ ਮਿਤੀ ਤੋਂ ਪਹਿਲਾਂ ਦੇ ਦਰਜਾਂ ਨੂੰ।


**ਖਰਚ ਟਰੈਕਿੰਗ:** ਜਦੋਂ ਤੁਸੀਂ OpenRouter ਮਾਡਲ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ ਵਰਤੋਂ ਅਤੇ ਖਰਚ ਦਾ ਅਸਲੀ ਅੰਕੜਾ OpenRouter ਤੋਂ ਪ੍ਰਾਪਤ ਖਰਚ ਸਬੰਧੀ ਜਾਣਕਾਰੀ ਦੇ ਆਧਾਰ ’ਤੇ ਦਿਖਾਉਂਦਾ ਹੈ। ਹੋਰ ਸਾਰੇ ਪ੍ਰੋਵਾਈਡਰਾਂ ਲਈ, ਐਪ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਤ ਕੀਤੀਆਂ ਕੀਮਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਖਰਚੇ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਂਦਾ ਹੈ, ਜੇਕਰ ਕੋਈ ਕੀਮਤ ਉਪਲਬਧ ਨਾ ਹੋਵੇ, ਤਾਂ ਅੰਦਾਜ਼ਾ ਸਿਫਰ ਹੋ ਸਕਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> **ਸਾਰੇ ਖਰਚ ਇੱਕ ਅੰਦਾਜ਼ਾ ਹੁੰਦੇ ਹਨ, ਤੁਹਾਡੀ ਸੰਦਰਭ ਲਈ ਹੀ, ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।**


<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਡਾਟਾ ਨੂੰ ਮਿਟਾਉਣਾ ਉਲਟਾ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਮਿਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਆਪਣੇ ਡਾਟਾ ਨੂੰ ਬੈਕ-ਅੱਪ ਕਰਨਾ ਜਾਂ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ [**ਡੈਸ਼ਬੋਰਡ** > **ਸਭ ਕਾਲ**](#dashboard-tabs) ਰਾਹੀਂ ਨਿਰਯਾਤ ਕਰਨਾ ਯਕੀਨੀ ਬਣਾਓ, ਬਿਨਾਂ ਇਸਦੇ ਇਸਨੂੰ ਹਮੇਸ਼ਾ ਲਈ ਨੁਕਸਾਨ ਹੋਵੇਗਾ। ਹਰੇਕ API ਕਾਲ ਐਂਟਰੀ ਨਾਲ ਸਬੰਧਤ ਸਾਰਾ ਇਨਪੁਟ/ਆਉਟਪੁਟ ਇਤਿਹਾਸ ਵੀ ਮਿਟ ਜਾਵੇਗਾ।


<br/>

<a id="transform-prompts"></a>
### ਟਰਾਂਸਫਾਰਮ ਪ੍ਰੌਪਟ

ਜਮਾਤ ਵਿੱਚ ਪ੍ਰੌਪਟ ਨੂੰ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਜ਼** > **ਟਰਾਂਸਫਾਰਮ ਪ੍ਰੌਪਟ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

ਤੁਸੀਂ ਕਰ ਸਕਦੇ ਹੋ:

- ਆਪਣੇ ਸੰਭਾਲੇ ਗਏ ਪ੍ਰੌਪਟਾਂ ਦੀ ਸਮੀਖਿਆ ਕਰੋ
- ਪ੍ਰੌਪਟ ਮਿਟਾਓ
- ਕਿਸੇ ਫਾਈਲ ਤੋਂ ਪ੍ਰੌਪਟ ਆਯਾਤ ਕਰੋ
- ਬੈਕ-ਅਪ ਜਾਂ ਸਾਂਝ ਲਈ ਪ੍ਰੌਪਟ ਨਿਰਯਾਤ ਕਰੋ

<a id="users"></a>
### ਵਰਤੋਂਕਾਰ

ਵੈਬ ਵਰਜਨ ਵਿੱਚ ਵਰਤੋਂਕਾਰ ਅਕਾਊਂਟਾਂ ਨੂੰ ਮੈਨੇਜ ਕਰਨ ਲਈ **ਵਰਤੋਂਕਾਰ** ਦੀ ਵਰਤੋਂ ਕਰੋ। ਤੁਸੀਂ ਵਰਤੋਂਕਾਰਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹੋ, ਉਹਨਾਂ ਦੇ ਵੇਰਵੇ ਅਪਡੇਟ ਕਰ ਸਕਦੇ ਹੋ, ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ, ਅਤੇ ਅਕਾਊਂਟ ਮਿਟਾ ਸਕਦੇ ਹੋ।

<a id="api-config"></a>
### ਏਪੀਆਈ ਕਾਨਫਿਗ

<a id="common-issues"></a>
## ਆਮ ਸਮੱਸਿਆਵਾਂ

ਜੇ ਕੁਝ ਉਮੀਦ ਮੁਤਾਬਿਕ ਕੰਮ ਨਾ ਕਰੇ, ਤਾਂ ਪਹਿਲਾਂ ਹੇਠਾਂ ਦਿੱਤੀਆਂ ਚੀਜ਼ਾਂ ਦੀ ਜਾਂਚ ਕਰੋ।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ਐਪ ਪਾਠ ਦਾ ਅਨੁਵਾਦ, ਪੁਨਰ-ਲੇਖਨ ਜਾਂ ਰੂਪਾਂਤਰ ਨਹੀਂ ਕਰੇਗਾ

ਜਾਂਚ ਕਰੋ ਕਿ:

- ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣਿਆ ਹੈ
- ਘੱਟੋ-ਘੱਟ ਇੱਕ ਮਾਡਲ [**ਸੈਟਿੰਗਸ** > **ਮਾਡਲਜ਼**](#models) ਵਿੱਚ ਸੂਚੀਬੱਧ ਹੈ
- ਤੁਹਾਡੀ API ਸੈਟਅੱਪ ਕੰਮ ਕਰ ਰਹੀ ਹੈ

ਜੇ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਵਰਤ ਰਹੇ ਹੋ:

1. [**ਸੈਟਿੰਗਸ** > **API ਕਾਨਫ਼ੀਗ**](#api-config) ਖੋਲ੍ਹੋ।
2. ਜਾਂਚ ਕਰੋ ਕਿ ਘੱਟੋ-ਘੱਟ ਇੱਕ API ਕੁੰਜੀ ਸੰਭਾਲੀ ਗਈ ਹੈ।
3. ਕੁੰਜੀ ਦੀ ਜਾਂਚ ਕਰਨ ਲਈ, ਪ੍ਰੋਵਾਈਡਰ ਦੇ ਨਾਲ **ਟੈਸਟ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-model-list-is-empty"></a>
### ਮਾਡਲ ਸੂਚੀ ਖਾਲੀ ਹੈ

[**ਸੈਟਿੰਗਸ** > **ਮਾਡਲਜ਼**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਰੀਫਰੈਸ਼** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

ਜੇ ਲੋੜ ਹੋਵੇ:

- ਇੱਕ ਮਾਡਲ ਲਈ ਖੋਜ ਕਰੋ
- **ਸਿਰਫ਼ ਮੁਫ਼ਤ** ਚਾਲੂ ਕਰੋ
- ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲਾਂ ਨੂੰ **ਚੁਣੇ ਗਏ ਮਾਡਲਾਂ** ਵਿੱਚ ਸ਼ਾਮਲ ਕਰੋ

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ਨਤੀਜਾ ਬਹੁਤ ਧੀਮਾ ਜਾਂ ਬਹੁਤ ਮਹਿੰਗਾ ਹੈ

ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਜਾਂ ਵੱਧ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ:

- ਇੱਕ ਵੱਖਰਾ ਮਾਡਲ ਚੁਣੋ
- ਛੋਟਾ ਇਨਪੁਟ ਵਰਤੋਂ
- [**ਸੈਟਿੰਗਸ** > **ਜਨਰਲ ਸੈਟਿੰਗਸ**](#general-settings) ਵਿੱਚ **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਬੰਦ ਕਰੋ
- ਸਰਲ ਕਾਰਜਾਂ ਲਈ ਮੁਫ਼ਤ ਮਾਡਲ ਵਰਤੋਂ (ਵੇਖੋ [ਮਾਡਲਜ਼](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ਇੰਟਰਫੇਸ ਗਲਤ ਭਾਸ਼ਾ ਵਿੱਚ ਹੈ

[ਟੂਲਬਾਰ](#toolbar) ਵਿੱਚ ਲੋਕੈਸ਼ਨ ਆਈਕਨ ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਆਪਣੀ ਪਸੰਦੀਦਾ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ਪਾਠ ਬਹੁਤ ਛੋਟਾ ਜਾਂ ਪੜ੍ਹਨ ਲਈ ਮੁਸ਼ਕਲ ਹੈ

[**ਸੈਟਿੰਗਸ** > **ਜਨਰਲ ਸੈਟਿੰਗਸ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਬਦਲੋ:

- **ਫੌਂਟ ਫੈਮਿਲੀ**
- **ਆਕਾਰ**

<br/>

<a id="dashboard-charts-are-empty"></a>
### ਡੈਸ਼ਬੋਰਡ ਗ੍ਰਾਫ਼ ਖਾਲੀ ਹਨ

ਜੇ:

- ਤੁਸੀਂ ਸਿਰਫ਼ **ਮੁਫ਼ਤ ਮਾਡਲ** ਵਰਤਦੇ ਹੋ (ਲਾਗਤ ਗ੍ਰਾਫ਼ ਖਾਲੀ ਹੋਣਗੇ)
- ਚੁਣਿਆ ਗਿਆ **ਸਮਾਂ ਫਿਲਟਰ** ਉਸ ਮਿਆਦ ਨੂੰ ਸ਼ਾਮਲ ਨਹੀਂ ਕਰਦਾ ਜਦੋਂ ਕਾਲਾਂ ਮਿਲੀਆਂ—ਜਾਂਚ ਕਰਨ ਲਈ **ਸਭ** ਕੋਸ਼ਿਸ਼ ਕਰੋ

ਜੇ **ਸਭ** ਚੁਣਨ ਤੋਂ ਬਾਅਦ ਵੀ ਚਾਰਟਸ ਖਾਲੀ ਹਨ, ਤਾਂ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕਾਲਾਂ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ **ਸਭ ਕਾਲਾਂ** ਟੈਬ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ਲਾਗਤ "ਉਪਲਬਧ ਨਹੀਂ" ਦਿਖਾਉਂਦੀ ਹੈ ਜਾਂ ਗਲਤ ਲੱਗਦੀ ਹੈ

ਜਦੋਂ ਤੁਸੀਂ **OpenRouter** ਰਾਹੀਂ ਮਾਡਲ ਵਰਤਦੇ ਹੋ, ਤਾਂ ਐਪ OpenRouter ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੀ ਤੁਹਾਡੀ ਅਸਲ ਖਰਚ ਦਿਖਾਉਂਦੀ ਹੈ।

**ਹੋਰ ਪ੍ਰੋਵਾਈਡਰਾਂ** (ਸਿੱਧੇ OpenAI, ਐਂਥਰੋਪਿਕ ਸਿੱਧੇ, ਆਦਿ) ਲਈ, ਕੀਮਤ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਤ ਕੀਮਤ ਜਾਣਕਾਰੀ ਤੋਂ ਅਨੁਮਾਨਿਤ ਹੈ। ਜੇ ਕਿਸੇ ਮਾਡਲ ਲਈ ਮੇਲ ਕੀਮਤ ਨਾ ਮਿਲੇ, ਤਾਂ ਲਾਗਤ **ਉਪਲਬਧ ਨਹੀਂ** ਵਜੋਂ ਦਿਖਾਈ ਦੇਵੇਗੀ ਅਤੇ ਤੁਹਾਡੀ ਕੁੱਲ ਰਕਮ ਵਿੱਚ ਨਹੀਂ ਜੁੜੇਗੀ।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ਕੁੱਲ ਲਾਗਤ ਮੇਰੇ ਪ੍ਰੋਵਾਈਡਰ ਦੇ ਬਿੱਲ ਨਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੀ

ਐਪ ਵਿੱਚ ਸਾਰੀਆਂ ਲਾਗਤਾਂ ਕੇਵਲ ** ਹਵਾਲਾ ਉਦੇਸ਼ ਲਈ ਅਨੁਮਾਨ ** ਹਨ, ਅਧਿਕਾਰਤ ਬਿੱਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।

ਜੇ ਤੁਹਾਡੇ OpenRouter ਖਰਚ ਨਾਲ ਨੇੜਿਓਂ ਮੇਲ ਕਰਨ ਲਈ ਕੁੱਲ ਨੂੰ ਲਿਆਉਣਾ ਹੈ, ਤਾਂ [**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਖੋਲ੍ਹੋ ਅਤੇ **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### ਸੈਡਬਾਰ ਵਿੱਚੋਂ ਇਤਿਹਾਸ ਪੰਨਾ ਗਾਇਬ ਹੈ

**ਕਾਰਵਾਈ ਇਤਿਹਾਸ ਨੂੰ ਬਣਾਈ ਰੱਖੋ** ਬੰਦ ਹੋ ਸਕਦਾ ਹੈ। [**ਸੈਟਿੰਗਸ** > **ਜਨਰਲ ਸੈਟਿੰਗਸ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਇਸਨੂੰ ਸਮਰੱਥ ਕਰੋ। ਧਿਆਨ ਰੱਖੋ ਕਿ ਇਸਨੂੰ ਚਾਲੂ ਕਰਨਾ ਪਹਿਲਾਂ ਹਟਾਏ ਗਏ ਇਤਿਹਾਸ ਡੇਟਾ ਨੂੰ ਬਹਾਲ ਨਹੀਂ ਕਰੇਗਾ।

<br/>

<a id="web-app-session-expired"></a>
### ਵੈੱਬ ਐਪ: ਲਾਗਇਨ ਪੰਨੇ 'ਤੇ ਅਣਜਾਣੇ ਵਿੱਚ ਨਿਰਦੇਸ਼ਤ ਕੀਤਾ ਗਿਆ

ਤੁਹਾਡਾ ਸੈਸ਼ਨ ਸਮਾਪਤ ਹੋ ਸਕਦਾ ਹੈ। ਦੁਬਾਰਾ ਲਾਗਇਨ ਕਰੋ। ਜੇ ਅਕਸਰ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਸਰਵਰ ਸੈਟਅੱਪ ਵਿੱਚ ਸੈਸ਼ਨ ਜੀਵਨ ਸਮਾਂ ਸੈਟਿੰਗਾਂ ਨੂੰ ਜਾਂਚੋ।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ਡੈਸ਼ਬੋਰਡ ਹੋਰ ਯੂਜ਼ਰਾਂ ਲਈ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਦਿਖਾਉਂਦਾ (ਵੈੱਬ)

ਸਿਰਫ਼ **ਪ੍ਰਸ਼ਾਸਕ** **ਯੂਜ਼ਰ** ਫਿਲਟਰ ਰਾਹੀਂ ਸਭ ਯੂਜ਼ਰਾਂ ਦਾ ਡਾਟਾ ਵੇਖ ਸਕਦੇ ਹਨ। ਰੂਪ ਦੇ ਤੌਰ 'ਤੇ ਨਿਯਮਿਤ ਯੂਜ਼ਰ ਸਿਰਫ਼ ਆਪਣੀ ਗਤੀਵਿਧੀ ਨੂੰ ਵੇਖਦੇ ਹਨ।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ਮੈਂ ਇੱਕ ਅਹੁਦਾ ਬਦਲਿਆ ਅਤੇ ਸੰਪਾਦਨ ਗੁਆ ਦਿੱਤੇ

ਕਿਸੇ ਅਹੁਦੇ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰਦੇ ਸਮੇਂ, **ਬੈਕ ਤੋ ਰੱਨ** ਉੱਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਹਮੇਸ਼ਾ **ਸੇਵ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="quick-tips"></a>
## ਤੇਜ਼ ਸੁਝਾਅ

- [**ਅਨੁਵਾਦ**](#translate) ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਤਾਂ ਜੋ ਤੁਹਾਡੀ ਸੈਟਅੱਪ ਕੰਮ ਕਰਦੀ ਹੈ, ਇਸ ਤੋਂ ਪਹਿਲਾਂ ਕਿ ਤੁਸੀਂ [**ਪੁਨਰ-ਲੇਖਨ**](#rewrite) ਜਾਂ [**ਰੂਪਾਂਤਰ**](#transform) ਵੱਲ ਵਧੋ।
- ਰੋਜ਼ਾਨਾ ਭਾਸ਼ਾ ਸੁਧਾਰਾਂ ਲਈ [**ਪੁਨਰ-ਲੇਖਨ**](#rewrite) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਇੱਕ ਖਾਸ ਕੰਮ ਲਈ ਦੁਹਰਾਉਣਯੋਗ ਕਾਰਜ ਪ੍ਰਵਾਹ ਦੀ ਲੋੜ ਹੋਣ ਸਮੇਂ [**ਰੂਪਾਂਤਰ**](#transform) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇ ਤੁਸੀਂ ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ 'ਤੇ ਨਜ਼ਰ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ [**ਡੈਸ਼ਬੋਰਡ**](#dashboard) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਪਿਛਲੇ ਕੰਮਾਂ ਨੂੰ ਸਮੀਖਿਆ ਕਰਨ ਅਤੇ ਉਹਨਾਂ ਦੇ ਪੂਰੇ ਇਨਪੁਟ/ਆਉਟਪੁਟ ਪਾਠ ਦੀ ਵਰਤੋਂ [**ਇਤਿਹਾਸ**](#history) ਵਰਤੋਂ।
- ਜੇ ਤੁਸੀਂ ਇੱਕ ਅਹੁਦਾ ਲਾਇਬ੍ਰੇਰੀ ਬਣਾ ਰਹੇ ਹੋ ਜੋ ਤੁਸੀਂ ਸੁਰੱਖਿਅਤ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ (ਵੇਖੋ [ਰੂਪਾਂਤਰ ਅਹੁਦਾ](#transform-prompts)) ਜਾਂ ਇਸਨੂੰ ਹੋਰਾਂ ਨਾਲ ਸਾਂਝਾ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਨਿਯਮਿਤ ਤੌਰ 'ਤੇ ਅਹੁਦਿਆਂ ਨੂੰ ਐਕਸਪੋਰਟ ਕਰੋ।
