# ਯੂਜ਼ਰ ਗਾਈਡ

<br/>

<a id="introduction"></a>
## ਪਰਿਚਈ

Transrewrt ਤੁਹਾਡੀ ਮਦਦ ਕਰਦਾ ਹੈ ਤਿੰਨ ਮੁੱਖ ਤਰੀਕਿਆਂ ਨਾਲ ਪਾਠ ਨਾਲ ਕੰਮ ਕਰਨ ਲਈ:

- **ਅਨੁਵਾਦ ਕਰੋ** - ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਪਾਠ ਨੂੰ ਬਦਲੋ।
- **ਮੁੜ-ਲਿਖਤ** - ਪਾਠ ਨੂੰ ਵੱਖਰੀ ਸ਼ੈਲੀ ਵਿੱਚ ਮੁੜ ਲਿਖੋ, ਜਿਵੇਂ ਕਿ ਸਪੱਸ਼ਟ, ਛੋਟਾ, ਜਾਂ ਹੋਰ ਔਪਚਾਰਿਕ।
- **ਟ੍ਰਾਂਸਫਾਰਮ** - ਪ੍ਰੌਂਪਟ ਕਹੇ ਜਾਂਦੇ ਕਸਟਮ AI ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਪਾਠ ਨੂੰ ਪ੍ਰੋਸੈਸ ਕਰੋ।

<br/>

ਇਹ ਗਾਈਡ ਸਮਝਾਉਂਦੀ ਹੈ ਕਿ ਐਪ ਨੂੰ ਇੰਸਟਾਲ ਅਤੇ ਚਲਾਉਣ ਤੋਂ ਬਾਅਦ ਇਸਦੀ ਵਰਤੋਂ ਕਿਵੇਂ ਕਰਨੀ ਹੈ। ਇੰਸਟਾਲੇਸ਼ਨ ਕਦਮਾਂ ਲਈ, ਮੁੱਖ **[README](README.pa.md)** ਵੇਖੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> Transrewrt ਵਿੰਡੋਜ਼ ਅਤੇ ਲੀਨਕਸ ਲਈ ਡੈਸਕਟਾਪ ਐਪ ਦੇ ਰੂਪ ਵਿੱਚ ਅਤੇ ਸਵੈ-ਹੋਸਟ ਕੀਤੇ ਵੈੱਬ ਐਪ ਦੇ ਰੂਪ ਵਿੱਚ ਉਪਲਬਧ ਹੈ। ਇਹ ਗਾਈਡ ਐਪ ਦੀ ਰੋਜ਼ਾਨਾ ਵਰਤੋਂ 'ਤੇ ਕੇਂਦਰਤ ਹੈ। ਜਿੱਥੇ ਕੁਝ ਸਿਰਫ਼ ਇੱਕ ਸੰਸਕਰਣ ਲਈ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਉੱਥੇ ਇਸਨੂੰ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਚਿੰਨ੍ਹਿਤ ਕੀਤਾ ਗਿਆ ਹੈ।

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

Transrewrt ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ, ਤੁਹਾਨੂੰ ਘੱਟ ਤੋਂ ਘੱਟ ਇੱਕ AI ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚ ਦੀ ਲੋੜ ਹੈ। ਸਮਰਥਿਤ ਪ੍ਰਦਾਤਾ ਹਨ: [OpenRouter](https://openrouter.ai) (ਜੋ ਕਿ ਬਹੁਤ ਸਾਰੇ ਮਾਡਲਾਂ ਨੂੰ ਇਕੱਠਾ ਕਰਦਾ ਹੈ), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਲਈ [Ollama](https://ollama.com)।

ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਤੁਹਾਨੂੰ ਭੁਗਤਾਨ ਕੀਤੇ ਮਾਡਲ ਦੀ ਚੋਣ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਆਪਣੀ OpenRouter API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਐਪ ਸਵੈਚਲਿਤ ਤੌਰ 'ਤੇ ਇੱਕ ਅੰਦਰੂਨੀ **ਮੁਫ਼ਤ** OpenRouter ਵਿਕਲਪ ਨੂੰ ਸਮਰੱਥ ਕਰਦਾ ਹੈ। ਇਸ ਨਾਲ ਤੁਸੀਂ ਤੁਰੰਤ ਟੈਕਸਟ ਦਾ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਤ ਅਤੇ ਰੂਪਾਂਤਰਣ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ। ਵਿਕਲਪਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ Cerebras, Google, Groq, ਜਾਂ Mistral AI ਤੋਂ ਮੁਫ਼ਤ API ਕੁੰਜੀ ਵੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦੇ ਹੋ।

ਸਧਾਰਨ ਭਾਸ਼ਾ ਵਿੱਚ:

- ਇੱਕ **ਮਾਡਲ** AI ਇੰਜਣ ਹੈ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ। ਮਾਡਲਾਂ ਨੂੰ ਇੱਕ **ਪ੍ਰਦਾਤਾ ਉਪਸਰਗ** ਨਾਲ ਸੂਚੀਬੱਧ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `openrouter/…`, `openai/…`, `ollama/…`)।
- ਇੱਕ **API ਕੁੰਜੀ** (ਜਾਂ, Ollama ਲਈ, ਇੱਕ **ਬੇਸ URL**) ਉਹ ਤਰੀਕਾ ਹੈ ਜਿਸ ਨਾਲ ਐਪ ਉਸ ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚਦਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਲਈ [**ਸੈਟਿੰਗਾਂ** > **API ਸੰਰਚਨਾ**](#api-config) ਵਿੱਚ ਕੁੰਜੀਆਂ ਸ਼ਾਮਲ ਕਰੋ। ਸਿਰਫ਼ OpenRouter ਦੀ ਵਰਤੋਂ ਲਈ, ਹੇਠਾਂ [ਇੱਕ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰਨ ਦਾ ਤਰੀਕਾ](#how-to-get-an-api-key-desktop-app) ਵੇਖੋ। ਜੇਕਰ ਤੁਸੀਂ API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ Ollama ਸਥਾਪਤ ਕਰ ਸਕਦੇ ਹੋ ( [ollama.com](https://ollama.com) ਤੋਂ) ਅਤੇ `translategemma:4b` ਵਰਗੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।

ਜੇਕਰ ਤੁਸੀਂ **ਵੈੱਬ ਵਰਜਨ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਸਰਵਰ ਮਾਲਕ ਵਾਤਾਵਰਣ ਚਲਾ ਕੇ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਐਪਲੀਕੇਸ਼ਨ ਵਿੱਚ ਸਿੱਧੇ ਤੌਰ 'ਤੇ API ਕੁੰਜੀਆਂ ਦਰਜ ਨਹੀਂ ਕਰ ਸਕਦੇ।

<a id="how-to-get-an-api-key-desktop-app"></a>
### ਮੁਫ਼ਤ OpenRouter API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰਨ ਦਾ ਤਰੀਕਾ (ਡੈਸਕਟਾਪ ਐਪ)

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਇਹ ਕਦਮ ਅਨੁਸਰਣ ਕਰੋ:

1. ਆਪਣੇ ਵੈੱਬ ਬਰਾਊਜ਼ਰ ਵਿੱਚ [OpenRouter](https://openrouter.ai) 'ਤੇ ਜਾਓ।
2. ਇੱਕ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਸਾਈਨ ਇਨ ਕਰੋ।
3. [ਕੁੰਜੀਆਂ](https://openrouter.ai/keys) ਪੰਨੇ 'ਤੇ ਜਾਓ।
4. ਇੱਕ ਨਵੀਂ API ਕੁੰਜੀ ਬਣਾਉਣ ਲਈ ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
5. ਕੁੰਜੀ ਨੂੰ ਇੱਕ ਨਾਮ ਦਿਓ ਤਾਂ ਜੋ ਤੁਸੀਂ ਇਸਨੂੰ ਬਾਅਦ ਵਿੱਚ ਪਛਾਣ ਸਕੋ।
6. ਨਵੀਂ API ਕੁੰਜੀ ਨੂੰ ਕਾਪੀ ਕਰੋ।
7. Transrewrt ਵਾਪਸ ਜਾਓ ਅਤੇ **ਸੈਟਿੰਗਾਂ** > **API ਸੰਰਚਨਾ** ਖੋਲ੍ਹੋ।
8. ਕੁੰਜੀ ਨੂੰ **OpenRouter API ਕੁੰਜੀ** ( **ਸੈਟਿੰਗਾਂ** > **API ਸੰਰਚਨਾ** ਹੇਠਾਂ) ਵਿੱਚ ਪੇਸਟ ਕਰੋ।
9. ਇਹ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਕਿ ਇਹ ਕੰਮ ਕਰਦਾ ਹੈ, **OpenRouter ਕੁੰਜੀ ਦੀ ਜਾਂਚ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="getting-started"></a>
## ਸ਼ੁਰੂਆਤ

ਜੇਕਰ ਇਹ ਤੁਹਾਡੀ ਪਹਿਲੀ ਵਾਰ ਹੈ ਜਦੋਂ ਤੁਸੀਂ Transrewrt ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਇਸ ਕ੍ਰਮ ਨੂੰ ਅਨੁਸਰਣ ਕਰੋ:

1. ਐਪ ਖੋਲ੍ਹੋ।
2. ਲੋੜ ਪੈਣ 'ਤੇ ਗਲੋਬ ਆਈਕਾਨ ਤੋਂ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।
3. ਜੇਕਰ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** 'ਤੇ ਹੋ, ਤਾਂ [**ਸੈਟਿੰਗਾਂ** > **API ਸੰਰਚਨਾ**](#api-config) ਖੋਲ੍ਹੋ, ਘੱਟ ਤੋਂ ਘੱਟ ਇੱਕ ਪ੍ਰਦਾਤਾ (ਉਦਾਹਰਣ ਲਈ OpenRouter) ਲਈ API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰੋ, ਅਤੇ ਇਹ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ **ਜਾਂਚ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਕਿ ਇਹ ਕੰਮ ਕਰਦਾ ਹੈ।
4. [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ।
5. [**ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਖੋਲ੍ਹੋ ਅਤੇ ਜੇਕਰ ਤੁਸੀਂ ਆਪਣੀਆਂ ਸਭ ਤੋਂ ਵੱਧ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਭਾਸ਼ਾਵਾਂ ਨੂੰ ਪਹਿਲਾਂ ਦਿਖਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਉੱਪਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** ਚੁਣੋ।
6. **ਅਨੁਵਾਦ** 'ਤੇ ਜਾਓ ਅਤੇ ਸਭ ਕੁਝ ਕੰਮ ਕਰ ਰਿਹਾ ਹੈ ਇਹ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਇੱਕ ਸਧਾਰਨ ਅਨੁਵਾਦ ਚਲਾਓ।
7. ਇਕ ਵਾਰ ਜਦੋਂ ਇਹ ਕੰਮ ਕਰ ਜਾਵੇ, **ਮੁੜ-ਲਿਖਤ** ਅਤੇ ਫਿਰ **ਟ੍ਰਾਂਸਫਾਰਮ** ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

ਇਸ ਕ੍ਰਮ ਦਾ ਮਹੱਤਵ ਹੈ। ਇਹ ਸਭ ਤੋਂ ਆਮ ਪਹਿਲੀ ਵਰਤੋਂ ਦੀ ਸਮੱਸਿਆ ਨੂੰ ਰੋਕਦਾ ਹੈ: ਐਪ ਵਿੱਚ ਕੰਮ ਕਰ ਰਹੀ API ਕੁਨੈਕਸ਼ਨ ਜਾਂ ਚੁਣਿਆ ਹੋਇਆ ਮਾਡਲ ਹੋਣ ਤੋਂ ਪਹਿਲਾਂ ਕੋਈ ਕੰਮ ਚਲਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨਾ।

### ਟੂਲਬਾਰ

ਟੂਲਬਾਰ ਥੋੜ੍ਹਾ ਬਹੁਤ ਬਦਲ ਜਾਂਦਾ ਹੈ ਜਿੱਥੇ ਵੀ ਤੁਸੀਂ ਐਪ ਵਿੱਚ ਹੋਵੋ।

- ਖੱਬੇ ਪਾਸੇ, ਇਹ ਮੌਜੂਦਾ ਪੰਨੇ ਦਾ ਨਾਮ ਦਿਖਾਉਂਦਾ ਹੈ।
- ਸੱਜੇ ਪਾਸੇ, ਇਹ **ਮਾਡਲ ਚੋਣਕਰਤਾ** ਅਤੇ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਨਿਯੰਤਰਣ ਦਿਖਾਉਂਦਾ ਹੈ।

**ਮਾਡਲ ਚੋਣਕਰਤਾ** ਤੁਹਾਨੂੰ ਮੌਜੂਦਾ ਕੰਮ ਲਈ ਕਿਹੜੇ ਏਆਈ ਇੰਜਣ ਦੀ ਵਰਤੋਂ ਕਰਨੀ ਹੈ, ਚੁਣਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

![Model selector](../images/screenshots/pa/model-selector.png)

ਕੁਝ ਮੁਫ਼ਤ ਮਾਡਲ ਹਮੇਸ਼ਾ ਉਪਲਬਧ ਨਹੀਂ ਹੁੰਦੇ-ਕਦੇ ਕਦੇ ਉਹ ਆਫਲਾਈਨ ਹੁੰਦੇ ਹਨ ਜਾਂ ਉਹਨਾਂ ਦੀ ਵਰਤੋਂ ਕੈਪ ਹੁੰਦੀ ਹੈ। ਜੇਕਰ ਇਹ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਐਪ ਆਪਣੇ ਆਪ ਉਸ ਮਾਡਲ ਨੂੰ ਤੁਹਾਡੀ ਉਪਲਬਧ ਸੂਚੀ ਵਿੱਚੋਂ ਹਟਾ ਦੇਵੇਗਾ। ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦੇਣ, ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਵਿੱਚ ਜਾਓ ਅਤੇ ਆਪਣੀ ਮਾਡਲ ਸੂਚੀ ਨੂੰ ਸੋਧੋ।
ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਮਾਡਲ ਨਾਮ ਦੇ ਖੱਬੇ ਪਾਸੇ ਪ੍ਰਦਾਤਾ ਆਈਕਾਨ 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਸਿੱਧੇ ਮਾਡਲ ਸੈਟਿੰਗਾਂ ਨੂੰ ਵੀ ਖੋਲ੍ਹ ਸਕਦੇ ਹੋ।

<br/>

**ਗਲੋਬ ਆਈਕਾਨ + ਭਾਸ਼ਾ ਕੋਡ** ਐਪ ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ, ਜਿਵੇਂ ਮੇਨੂ ਅਤੇ ਬਟਨ, ਨੂੰ ਬਦਲਦਾ ਹੈ। ਇਹ **ਅਨੁਵਾਦ ਕਰੋ** ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਅਨੁਵਾਦ ਭਾਸ਼ਾਵਾਂ ਨੂੰ **ਨਹੀਂ** ਬਦਲਦਾ।

<a id="input-and-output-panels"></a>
### ਇਨਪੁੱਟ ਅਤੇ ਆਉਟਪੁੱਟ ਪੈਨਲ

ਜ਼ਿਆਦਾਤਰ ਕਾਰਜਸਥਾਨ ਖੱਬੇ ਪਾਸੇ **ਇਨਪੁੱਟ** ਪੈਨਲ ਅਤੇ ਸੱਜੇ ਪਾਸੇ **ਆਉਟਪੁੱਟ** ਪੈਨਲ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹਨ।

ਹਰੇਕ ਪੈਨਲ ਵੀ ਦਿਖਾਉਂਦਾ ਹੈ:

| **ਇਨਪੁੱਟ**                                                          | **ਆਉਟਪੁੱਟ**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - ਅੱਖਰ ਗਿਣਤੀ <br/>- ਸ਼ਬਦ ਗਿਣਤੀ <br/>- ਪੈਰੇ ਗਿਣਤੀ   <br/> | - ਕੰਮ ਨੂੰ ਕਰਨ ਵਿੱਚ ਕਿੰਨਾ ਸਮਾਂ ਲੱਗਾ<br/>- **TPS** (ਪ੍ਰਤੀ ਸਕਿੰਟ ਟੋਕਨ)<br/>- ਅੱਖਰ, ਸ਼ਬਦ, ਅਤੇ ਪੈਰੇ ਦੀ ਗਿਣਤੀ<br/>- ਵਰਤਿਆ ਗਿਆ ਮਾਡਲ |

ਜੇਕਰ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦਾਂ ਬਾਰੇ ਸੋਚ ਰਹੇ ਹੋ:

- **ਟੋਕਨ** ਦਾ ਅਰਥ ਹੈ ਟੈਕਸਟ ਦਾ ਛੋਟਾ ਟੁਕੜਾ। ਤੁਸੀਂ ਇਸਨੂੰ ਇੱਕ ਸ਼ਬਦ ਦਾ ਹਿੱਸਾ ਜਾਂ ਇੱਕ ਛੋਟਾ ਸ਼ਬਦ ਸਮਝ ਸਕਦੇ ਹੋ।
- **TPS** ਦਾ ਅਰਥ ਹੈ ਕਿ ਮਾਡਲ ਨੇ ਹਰ ਸਕਿੰਟ ਵਿੱਚ ਕਿੰਨੇ ਟੈਕਸਟ ਟੁਕੜੇ ਪ੍ਰੋਸੈੱਸ ਕੀਤੇ।

<br/>

ਤੁਸੀਂ ਹਰੇਕ ਕਾਰਵਾਈ ਦੀ ਲਾਗਤ (ਜੇਕਰ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਕੁੱਲ ਲਾਗਤ ਦੀ ਵੀ ਨਿਗਰਾਨੀ ਕਰ ਸਕਦੇ ਹੋ, [**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ `ਕਾਰਵਾਈਆਂ 'ਤੇ ਲਾਗਤ ਜਾਣਕਾਰੀ ਦਿਖਾਓ` ਵਿਕਲਪ ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ।

<a id="translate"></a>
## ਅਨੁਵਾਦ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਨੂੰ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਅਨੁਵਾਦ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![Translate workspace](../images/screenshots/pa/translate.png)

<br/>

<a id="translate-text"></a>
### ਟੈਕਸਟ ਦਾ ਅਨੁਵਾਦ ਕਰੋ

1. **ਅਨੁਵਾਦ ਕਰੋ** ਖੋਲ੍ਹੋ।
2. **ਤੋਂ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
3. **ਨੂੰ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. **ਇਨਪੁੱਟ** ਵਿੱਚ ਟੈਕਸਟ ਟਾਈਪ ਜਾਂ ਪੇਸਟ ਕਰੋ।
6. **ਅਨੁਵਾਦ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
7. **ਆਉਟਪੁੱਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।
8. ਜੇਕਰ ਤੁਸੀਂ ਨਤੀਜਾ ਕਾਪੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਕਾਪੀ ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।

<br/>

<a id="language-selection"></a>
### ਭਾਸ਼ਾ ਚੋਣ

- **ਤੋਂ** ਇੱਕ ਖਾਸ ਭਾਸ਼ਾ ਜਾਂ **ਭਾਸ਼ਾ ਪਛਾਣੋ** ਹੋ ਸਕਦੀ ਹੈ।
- **ਨੂੰ** ਉਹ ਭਾਸ਼ਾ ਹੈ ਜਿਸ ਵਿੱਚ ਤੁਸੀਂ ਨਤੀਜਾ ਚਾਹੁੰਦੇ ਹੋ।

ਤੁਹਾਡੀਆਂ ਚੁਣੀਆਂ **ਸਿਖਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** ਸੂਚੀ ਦੇ ਸਿਖਰ 'ਤੇ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ। ਤੁਸੀਂ ਇਨ੍ਹਾਂ ਨੂੰ [**ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਵਿੱਚ ਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="helpful-translation-settings"></a>
### ਮਦਦਗਾਰ ਅਨੁਵਾਦ ਸੈਟਿੰਗਾਂ

[**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ, ਤੁਸੀਂ ਅਨੁਵਾਦ ਦੇ ਵਿਵਹਾਰ ਨੂੰ ਬਦਲ ਸਕਦੇ ਹੋ:

- **ਪੇਸਟ ਕਰਨ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਸੀਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰਦੇ ਹੀ ਇੱਕ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।
- **ਨਤੀਜਾ ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਆਟੋ-ਕਾਪੀ** ਸਫਲਤਾਪੂਰਵਕ ਚਲਣ ਤੋਂ ਬਾਅਦ ਨਤੀਜਾ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰ ਦਿੰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।
- **ਟਾਈਮਆਊਟ (ms)** ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ ਕਿ ਐਪ ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਕਿੰਨੀ ਦੇਰ ਤੱਕ ਉਡੀਕਦਾ ਹੈ।
- **ਦਾਖਲ** ਇਹ ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ ਕਿ ਜਦੋਂ ਤੁਸੀਂ `ਦਾਖਲ` ਦਬਾਉਂਦੇ ਹੋ ਤਾਂ ਕੀ ਹੁੰਦਾ ਹੈ:

<a id="rewrite"></a>
## ਮੁੜ-ਲਿਖਤ

ਜਦੋਂ ਤੁਸੀਂ ਮੁੱਖ ਅਰਥ ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ ਸ਼ਬਦਾਵਲੀ ਨੂੰ ਸੁਧਾਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਮੁੜ-ਲਿਖਤ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![Rewrite workspace](../images/screenshots/pa/rewrite.png)

ਇਹ ਇਹਨਾਂ ਲਈ ਵਰਤੋਂ ਵਿੱਚ ਆਉਂਦਾ ਹੈ:

- ਸਪੈਲਿੰਗ ਅਤੇ ਵਿਆਕਰਨ ਨੂੰ ਠੀਕ ਕਰਨਾ (**ਸਪੈਲਿੰਗ ਅਤੇ ਵਿਆਕਰਨ ਜਾਂਚੋ**)
- ਟੈਕਸਟ ਨੂੰ ਸਪੱਸ਼ਟ ਬਣਾਉਣਾ (**ਸਪੱਸ਼ਟਤਾ ਸੁਧਾਰੋ**)
- ਇੱਕ ਚੱਲਣ ਵਿੱਚ ਕਈ ਵੱਖਰੇ ਪੁਨਰ-ਨਿਰਮਾਣ (**ਵੈਕਲਪਿਕ ਸੰਸਕਰਣ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਔਪਚਾਰਿਕ ਜਾਂ ਘੱਟ ਔਪਚਾਰਿਕ ਬਣਾਉਣਾ (**ਔਪਚਾਰਿਕ** / **ਅਨੌਪਚਾਰਿਕ**)
- ਟੈਕਸਟ ਨੂੰ ਛੋਟਾ ਜਾਂ ਵਧਾਉਣਾ (**ਛੋਟਾ ਕਰੋ** / **ਵਧਾਓ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਤਕਨੀਕੀ ਲੱਗਣ ਲਈ ਬਣਾਉਣਾ (**ਤਕਨੀਕੀ ਬਣਾਓ**)

<br/>

> 💡 **ਟਿਪ**<br/>
> ਜਦੋਂ ਤੁਸੀਂ "**ਸਪੈਲਿੰਗ ਅਤੇ ਵਿਆਕਰਨ ਜਾਂਚੋ**" ਮੋਡ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁੱਟ ਪੈਨਲ ਵਿੱਚ (**ਕਾਪੀ** ਦੇ ਨੇੜੇ) **ਤਬਦੀਲੀਆਂ ਵੇਖੋ** ਸਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।
> ਆਪਣੇ ਟੈਕਸਟ 'ਤੇ ਲਾਗੂ ਕੀਤੀਆਂ ਗਈਆਂ ਖਾਸ ਸੁਧਾਰਾਂ ਨੂੰ ਵੇਖਣ ਜਾਂ ਲੁਕਾਉਣ ਲਈ ਇਸਨੂੰ ਚਾਲੂ ਜਾਂ ਬੰਦ ਕਰੋ।

<br/><br/>

<a id="transform"></a>
## ਟ੍ਰਾਂਸਫਾਰਮ

ਜਦੋਂ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ AI ਨਿਰਦੇਸ਼ਾਂ ਦੇ ਇੱਕ ਕਸਟਮ ਸੈੱਟ ਦੀ ਪਾਲਣਾ ਕਰੇ ਤਾਂ **ਟ੍ਰਾਂਸਫਾਰਮ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![Transform workspace](../images/screenshots/pa/transform.png)

ਇਹ ਐਪ ਦਾ ਸਭ ਤੋਂ ਲਚਕਦਾਰ ਹਿੱਸਾ ਹੈ। ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ ਇਹਨਾਂ ਕੰਮਾਂ ਲਈ ਕਰ ਸਕਦੇ ਹੋ:

- ਨੋਟਾਂ ਦਾ ਸਾਰ ਕੱਢਣਾ
- ਕੱਚੇ ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਪਾਲਿਸ਼ ਕੀਤਾ ਈਮੇਲ ਵਿੱਚ ਬਦਲਣਾ
- ਮੁੱਖ ਬਿੰਦੂਆਂ ਨੂੰ ਕੱਢਣਾ
- ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਖਾਸ ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲਣਾ
- ਇਨਪੁੱਟ ਟੈਕਸਟ ਨਾਲ ਕੋਈ ਵੀ ਹੋਰ ਕਸਟਮ ਗਤੀਵਿਧੀ

<br/>

<a id="run-an-existing-prompt"></a>
### ਮੌਜੂਦਾ ਪ੍ਰੋਂਪਟ ਚਲਾਓ

1. **ਟ੍ਰਾਂਸਫਾਰਮ** ਖੋਲ੍ਹੋ।
2. ਪ੍ਰੋਂਪਟ ਸੂਚੀ ਵਿੱਚੋਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਚੁਣੋ।
3. ਜੇਕਰ **ਟਾਰਗੇਟ** ਭਾਸ਼ਾ ਬਾਕਸ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ, ਤਾਂ ਜੇ ਤੁਸੀਂ ਚਾਹੋ ਤਾਂ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. **ਇਨਪੁੱਟ** ਵਿੱਚ ਟਾਈਪ ਕਰੋ ਜਾਂ ਪਾਠ ਪੇਸਟ ਕਰੋ।
5. **ਟ੍ਰਾਂਸਫਾਰਮ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
6. **ਆਉਟਪੁੱਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### ਜੇ ਤੁਹਾਡੇ ਕੋਲ ਹਾਲੇ ਤੱਕ ਕੋਈ ਪ੍ਰੋਂਪਟ ਨਹੀਂ ਹੈ

ਜੇਕਰ ਤੁਹਾਡੀ ਪ੍ਰੋਂਪਟ ਸੂਚੀ ਖਾਲੀ ਹੈ, ਤਾਂ ਟ੍ਰਾਂਸਫਾਰਮ ਵਰਕਸਪੇਸ ਵਿੱਚ **ਨਮੂਨਾ ਪ੍ਰੌਂਪਟ ਲੋਡ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਐਕਸਪੋਰਟ/ਇੰਪੋਰਟ ਕਤਾਰ ਵਿੱਚ [**ਸੈਟਿੰਗਾਂ** > **ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ**](#transform-prompts) ਵਿੱਚ ਇਹੀ ਕੰਟਰੋਲ ਹਮੇਸ਼ਾ ਉਪਲਬਧ ਹੈ। ਦੋਵੇਂ ਅੰਦਰੂਨੀ ਉਦਾਹਰਣਾਂ ਜੋੜਦੇ ਹਨ ਤਾਂ ਜੋ ਤੁਸੀਂ ਤੁਰੰਤ ਸ਼ੁਰੂ ਕਰ ਸਕੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਨਮੂਨਾ ਪ੍ਰੋਂਪਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਪ੍ਰਦਾਨ ਕੀਤੇ ਜਾਂਦੇ ਹਨ। ਉਨ੍ਹਾਂ ਨੂੰ ਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੋਧ ਸਕਦੇ ਹੋ ਅਤੇ **ਪ੍ਰੋਂਪਟ ਦਾ ਅਨੁਵਾਦ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਇਸਨੂੰ ਆਪਣੀ ਭਾਸ਼ਾ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="create-a-prompt-quickly"></a>
### ਤੇਜ਼ੀ ਨਾਲ ਇੱਕ ਪ੍ਰੋਂਪਟ ਬਣਾਓ

ਇੱਕ ਪ੍ਰੋਂਪਟ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਤਰੀਕਾ ਹੈ:

1. **ਨਵਾਂ ਪ੍ਰੋਂਪਟ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
2. **ਪ੍ਰਾਮਟ ਤਿਆਰ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਉਸ ਚੀਜ਼ ਦਾ ਵੇਰਵਾ ਦਿਓ ਜੋ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ ਪ੍ਰੋਂਪਟ ਕਰੇ।
4. ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. ਐਪ ਨੂੰ ਤੁਹਾਡੇ ਲਈ ਇੱਕ ਡ੍ਰਾਫਟ ਬਣਾਉਣ ਦਿਓ।
6. ਡ੍ਰਾਫਟ ਦੀ ਸਮੀਖਿਆ ਕਰੋ ਅਤੇ **ਸੇਵ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

![Generate prompt](../images/screenshots/pa/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ਇੱਕ ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੋਧੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਬਣਾਉਂਦੇ ਜਾਂ ਸੋਧਦੇ ਹੋ, ਤਾਂ ਸੰਪਾਦਕ ਖੱਬੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ ਅਤੇ ਇੱਕ ਟੈਸਟ ਖੇਤਰ ਸੱਜੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

![Transform prompt editor](../images/screenshots/pa/transform-prompt-edit.png)

ਮੁੱਖ ਖੇਤਰ ਹਨ:

- **ਪ੍ਰੋਂਪਟ ਨਾਮ**: ਪ੍ਰੋਂਪਟ ਸੂਚੀ ਵਿੱਚ ਦਿਖਾਇਆ ਗਿਆ ਨਾਮ।
- **ਪ੍ਰੋਂਪਟ ਹਦਾਇਤਾਂ (ਵਿਕਲਪਿਕ)**: ਪ੍ਰੋਂਪਟ ਨੂੰ ਚਲਾਉਂਦੇ ਸਮੇਂ ਯੂਜ਼ਰ ਨੂੰ ਦਿਖਾਇਆ ਜਾਣ ਵਾਲਾ ਇੱਕ ਛੋਟਾ ਸੁਝਾਅ।
- **ਮਾਡਲ ਭੂਮਿਕਾ**: ਏਆਈ ਨੂੰ ਦਿੱਤੀ ਗਈ ਸਮੁੱਚੀ ਭੂਮਿਕਾ, ਜਿਵੇਂ 'ਤੁਸੀਂ ਇੱਕ ਸਹਾਇਕ ਸਹਾਇਕ ਹੋ।'
- **ਮਾਡਲ ਹਦਾਇਤਾਂ (ਇੱਕ ਪ੍ਰਤੀ ਲਾਈਨ)**: ਉਹ ਖਾਸ ਨਿਯਮ ਜੋ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ ਏਆਈ ਪਾਲਣਾ ਕਰੇ।
- **ਆਉਟਪੁੱਟ ਵਰਣਨ**: ਨਤੀਜੇ ਨੂੰ ਦਰਸਾਉਣ ਵਾਲਾ ਇੱਕ ਛੋਟਾ ਸ਼ਬਦ, ਜਿਵੇਂ 'ਸਾਰ' ਜਾਂ 'ਮੁੜ-ਲਿਖਤ'।
- **ਤਾਪਮਾਨ (0.0 → 1.0)**: ਮਾਡਲ ਕਿਵੇਂ ਵਿਵਹਾਰ ਕਰੇਗਾ; ਹੇਠਾਂ ਦੇਖੋ।
- **ਨਿਸ਼ਾਨਾ ਭਾਸ਼ਾ ਪੁੱਛੋ**: ਜਦੋਂ ਪ੍ਰੋਂਪਟ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ ਤਾਂ ਇੱਕ ਟਾਰਗੇਟ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲਾ ਜੋੜਦਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦ **ਤਾਪਮਾਨ** ਨੂੰ ਨਹੀਂ ਜਾਣਦੇ, ਤਾਂ ਇਸ ਬਾਰੇ ਇਸ ਤਰ੍ਹਾਂ ਸੋਚੋ:

- ਇੱਕ **ਘੱਟ** ਤਾਪਮਾਨ ਸਥਿਰ, ਵਧੇਰੇ ਭਰੋਸੇਯੋਗ ਨਤੀਜੇ ਦਿੰਦਾ ਹੈ।
- ਇੱਕ **ਉੱਚ** ਤਾਪਮਾਨ ਵਧੇਰੇ ਵਿਭਿੰਨਤਾ ਅਤੇ ਰਚਨਾਤਮਕਤਾ ਦਿੰਦਾ ਹੈ।

ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ ਵੀ ਕਰ ਸਕਦੇ ਹੋ:

- **`ਪ੍ਰਾਮਟ ਤਿਆਰ ਕਰੋ`** ਇੱਕ ਸਧਾਰਨ ਵੇਰਵੇ ਤੋਂ ਇੱਕ ਨਵਾਂ ਡ੍ਰਾਫਟ ਬਣਾਉਣ ਲਈ
- **`ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੁਧਾਰੋ`** ਮੌਜੂਦਾ ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੁਧਾਰਨ ਲਈ
- **`ਪ੍ਰੋਂਪਟ ਦਾ ਅਨੁਵਾਦ ਕਰੋ`** ਪ੍ਰੋਂਪਟ ਫੀਲਡਾਂ ਦਾ ਅਨੁਵਾਦ ਕਰਨ ਲਈ

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> **`ਪਿੱਛੇ ਜਾਓ`** ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **`ਸੇਵ ਕਰੋ`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਜੇਕਰ ਤੁਸੀਂ ਬਿਨਾਂ ਸੇਵ ਕੀਤੇ ਵਾਪਸ ਜਾਂਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਡੀਆਂ ਤਬਦੀਲੀਆਂ ਖਤਮ ਹੋ ਜਾਣਗੀਆਂ।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ਇਸਦੀ ਵਰਤੋਂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਦੀ ਜਾਂਚ ਕਰੋ

ਸੱਜੇ ਪਾਸੇ ਟੈਸਟ ਪੈਨਲ ਤੁਹਾਨੂੰ ਰੋਜ਼ਾਨਾ ਕੰਮ ਵਿੱਚ ਇਸਦੀ ਵਰਤੋਂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਨਮੂਨਾ ਪਾਠ ਨਾਲ ਆਪਣੇ ਪ੍ਰੋਂਪਟ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

ਇਹ ਤਦ ਉਪਯੋਗੀ ਹੁੰਦਾ ਹੈ ਜਦੋਂ:

- ਤੁਸੀਂ ਇੱਕ ਨਵਾਂ ਪ੍ਰੋਂਪਟ ਬਣਾ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਦੇ ਦੋ ਸੰਸਕਰਣਾਂ ਦੀ ਤੁਲਨਾ ਕਰ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਲਹਿਜ਼ਾ, ਲੰਬਾਈ ਜਾਂ ਆਉਟਪੁੱਟ ਫਾਰਮੈਟ ਦੀ ਜਾਂਚ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ [**ਸੈਟਿੰਗਾਂ** > **ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ**](#transform-prompts) ਵਿੱਚ ਸੰਭਾਲੇ ਗਏ ਪ੍ਰੌਂਪਟ ਨੂੰ ਐਕਸਪੋਰਟ ਅਤੇ ਇੰਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ।

<br/><br/>

<a id="general-settings"></a>
### ਆਮ ਸੈਟਿੰਗਾਂ

ਟਾਈਪਿੰਗ ਵਰਤਾਓ, ਨਿਸ਼ਪਾਦਨ ਵੇਰਵੇ **ਇਤਿਹਾਸ** ਲਈ ਸਟੋਰ ਕੀਤੇ ਜਾਂਦੇ ਹਨ ਜਾਂ ਨਹੀਂ, ਅਤੇ ਦਿੱਖ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ **ਆਮ ਸੈਟਿੰਗਾਂ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਵਰਤਾਓ**

- **ENTER ਲਈ ਵਰਤਾਓ** ਚੁਣਦਾ ਹੈ ਕਿ `Enter` ਕਾਰਜ ਨੂੰ ਚਲਾਉਂਦਾ ਹੈ ਜਾਂ ਨਵੀਂ ਲਾਈਨ ਨੂੰ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਪੇਸਟ ਕਰਨ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਸੀਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰਨ ਦੇ ਨਾਲ ਹੀ ਅਨੁਵਾਦ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- **ਨਤੀਜਾ ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਆਟੋ-ਕਾਪੀ** ਸਫਲ ਨਤੀਜਿਆਂ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ।
- **ਟਾਈਮਆਊਟ (ms)** ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਲਈ ਉਡੀਕ ਸਮਾਂ ਸੈੱਟ ਕਰਦਾ ਹੈ।

**ਇਤਿਹਾਸ**

- **ਨਿਸ਼ਪਾਦਨ ਇਤਿਹਾਸ ਰੱਖੋ** ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ ਕਿ ਹਰੇਕ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਤ, ਅਤੇ ਟ੍ਰਾਂਸਫਾਰਮ **ਇਨਪੁੱਟ ਅਤੇ ਆਉਟਪੁੱਟ ਟੈਕਸਟ** ਸਾਈਡਬਾਰ [**ਇਤਿਹਾਸ**](#history) ਵਿਊ ਲਈ ਸਟੋਰ ਕਰਦਾ ਹੈ। ਇਸਨੂੰ ਬੰਦ ਕਰਨ ਨਾਲ ਪੁਸ਼ਟੀ ਲਈ ਪੁੱਛਿਆ ਜਾਵੇਗਾ; ਜੇਕਰ ਤੁਸੀਂ ਪੁਸ਼ਟੀ ਕਰਦੇ ਹੋ, ਤਾਂ ਸਟੋਰ ਕੀਤਾ ਇਤਿਹਾਸ ਟੈਕਸਟ ਡੇਟਾਬੇਸ ਤੋਂ ਹਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।
- **ਇਤਿਹਾਸ ਡਾਟਾ ਮਿਟਾਓ** ਤੁਹਾਨੂੰ ਉਮਰ ਅਨੁਸਾਰ (ਉਦਾਹਰਣ ਲਈ ਕੁਝ ਮਹੀਨਿਆਂ ਤੋਂ ਪੁਰਾਣਾ, ਜਾਂ **ਸਾਰਾ ਡਾਟਾ (ਸਾਫ਼ ਕਰੋ)**) **ਡੇਟਾ ਮਿਟਾਓ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਸਟੋਰ ਕੀਤਾ ਟੈਕਸਟ ਹਟਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਇਸ ਨਾਲ ਸਿਰਫ਼ **ਇਤਿਹਾਸ** ਵਿਊ ਲਈ ਸੇਵ ਕੀਤਾ ਨਿਸ਼ਪਾਦਨ ਟੈਕਸਟ ਪ੍ਰਭਾਵਿਤ ਹੁੰਦਾ ਹੈ; ਇਹ **ਲਾਗਤ** ਜਾਂ ਵਰਤੋਂ ਦੇ ਕੁੱਲ ਅੰਕੜੇ ਨਹੀਂ ਮਿਟਾਉਂਦਾ। **ਲਾਗਤ** ਡਾਟਾ ਨੂੰ ਹਟਾਉਣ ਜਾਂ ਕੱਟਣ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਦਿੱਖ**

- **ਕਾਰਵਾਈਆਂ 'ਤੇ ਖਰਚ ਜਾਣਕਾਰੀ ਵੇਖਾਓ** ਕਾਰਵਾਈ ਪ੍ਰਤੀ ਲਾਗਤ (ਜੇ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਅਨੁਵਾਦ ਕਰੋ, ਮੁੜ-ਲਿਖਤ ਅਤੇ ਟ੍ਰਾਂਸਫਾਰਮ ਆਉਟਪੁੱਟ ਪੈਨਲਾਂ 'ਤੇ ਕੁੱਲ ਲਾਗਤ ਦੇ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।
- **ਲਾਗਤ ਭਿੰਨ ਅੰਕ** ਇਹ ਬਦਲ ਦਿੰਦੇ ਹਨ ਕਿ ਲਾਗਤ ਦਸਮਲਵਾਂ ਨੂੰ ਕਿਵੇਂ ਦਰਸਾਇਆ ਜਾਂਦਾ ਹੈ।
- **ਸਿਰਫ਼ ਵੈੱਬ:** **ਐਪ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਹਾਸ਼ੀਆ ਦਿਖਾਓ** ਇੰਟਰਫੇਸ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਵਾਧੂ ਥਾਂ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਫ਼ੋਂਟ ਫੈਮਿਲੀ** ਟੈਕਸਟ ਪੈਨਲਾਂ ਵਿੱਚ ਲਿਖਣ ਦੇ ਫ਼ੋਂਟ ਨੂੰ ਬਦਲਦਾ ਹੈ।
- **ਆਕਾਰ** ਫ਼ੋਂਟ ਆਕਾਰ ਨੂੰ ਬਦਲਦਾ ਹੈ।

**ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਬੈਕਅਪ**

- **ਬੈਕਅਪ ਵਿੱਚ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਸ਼ਾਮਲ ਕਰੋ** - ਜਦੋਂ ਸਮਰੱਥ ਹੋਵੇ, ਜ਼ਿਪ ਵਿੱਚ ਚਲਾਉਣ ਦਾ ਇਤਿਹਾਸ ਅਤੇ ਐਪੀਆਈ ਕਾਲ ਦੇ ਅੰਕੜੇ ਵੀ ਸ਼ਾਮਲ ਹੁੰਦੇ ਹਨ। 
- **ਬੈਕਅਪ ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ** - `config.json`, `state.json`, ਚੋਣਵੇਂ ਐਨਕ੍ਰਿਪਸ਼ਨ ਕੁੰਜੀ, ਉਪਭੋਗਤਾ, ਪਸੰਦੀਦਾ, ਕਸਟਮ ਪ੍ਰਾਮਟ, ਅਤੇ ਜੇ ਤੁਸੀਂ ਸਹਿਮਤ ਹੋਏ ਤਾਂ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਨਾਲ ਇੱਕ ਏਕੀਕ੍ਰਿਤ ਜ਼ਿਪ (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` ਡਿਫ਼ਾਲਟ ਵਜੋਂ UTC ਵਿੱਚ) ਬਣਾਉਂਦਾ ਹੈ। ਇੱਕ ਸਫਲ ਬੈਕਅਪ ਤੋਂ ਬਾਅਦ, ਪੁਸ਼ਟੀ ਸੰਭਾਲੇ ਗਏ ਫਾਈਲ ਨਾਮ ਨੂੰ ਦਰਸਾਉਂਦੀ ਹੈ।
- **ਬੈਕਅਪ ਤੋਂ ਮੁੜ-ਸਥਾਪਤ** - ਪਹਿਲਾਂ **ਪੁਸ਼ਟੀ ਸੰਵਾਦ** ਖੋਲ੍ਹਦਾ ਹੈ। ਸੰਵਾਦ ਵਿੱਚ ਬੈਕਅਪ ਜ਼ਿਪ ਚੁਣੋ (**ਬਰਾਊਜ਼** / ਫਾਈਲ ਪਿਕਰ ਜਾਂ ਡਰੈਗ-ਐਂਡ-ਡਰਾਪ ਜਿੱਥੇ ਸਮਰੱਥ) ਫਿਰ ਵਿਕਲਪਾਂ ਨੂੰ ਸਮੀਖਿਆ ਕਰੋ:
  - **ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਵਾਪਸ ਲਾਓ** - ਜਦੋਂ ਵਰਤੋਂ ਸ਼ਾਮਲ ਕਰਕੇ ਬੈਕਅਪ ਲਿਆ ਗਿਆ ਹੋਵੇ ਤਾਂ ਜ਼ਿਪ ਤੋਂ ਵਰਤੋਂ/ਇਤਿਹਾਸ ਨੂੰ ਆਯਾਤ ਕਰੋ; ਜੇ ਤੁਸੀਂ ਸਿਰਫ਼ ਸੈਟਿੰਗਾਂ ਅਤੇ ਪ੍ਰਾਮਟ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਬੰਦ ਛੱਡੋ।
  - **ਮੁੜ-ਸਥਾਪਤ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਪੁਰਾਣੇ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਮਿਟਾਓ** - ਬੈਕਅਪ ਲਾਗੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇਸ ਇੰਸਟਾਲੇਸ਼ਨ 'ਤੇ ਮੌਜੂਦਾ ਵਰਤੋਂ/ਇਤਿਹਾਸ ਨੂੰ ਹਟਾਓ (ਚੋਣਵੇਂ; ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਸਾਫ਼ ਬਦਲਾਅ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਵਰਤੋਂ)।

ਵੈੱਬ ਜਾਂ ਡੈਸਕਟਾਪ ਵਰਜਨ ਵਿੱਚ ਬਣਾਏ ਗਏ ਬੈਕਅਪਾਂ ਨੂੰ ਦੂਜੇ ਵਿੱਚ ਮੁੜ-ਸਥਾਪਤ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ। ਜਦੋਂ ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ ਡੈਸਕਟਾਪ ਬੈਕਅਪ ਨੂੰ ਮੁੜ-ਸਥਾਪਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਡਾਟਾ ਐਡਮਿਨਿਸਟਰੇਟਰ ਉਪਭੋਗਤਾ ਨੂੰ ਮੁੜ-ਸਥਾਪਤ ਕੀਤਾ ਜਾਵੇਗਾ।

<a id="models"></a>
### ਮਾਡਲ

ਟੂਲਬਾਰ ਵਿੱਚ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ, ਇਹ ਚੁਣਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ** ਵਰਤੋਂ।

![Settings Models tab](../images/screenshots/pa/settings-models.png)

ਪੇਜ ਵਿੱਚ ਦੋ ਸੂਚੀਆਂ ਹਨ:

- ਖੱਬੇ ਪਾਸੇ **ਉਪਲਬਧ ਮਾਡਲ**
- ਸੱਜੇ ਪਾਸੇ **ਚੁਣੇ ਹੋਏ ਮਾਡਲ**

ਵਰਤੋਂਯੋਗ ਨਿਯੰਤਰਣਾਂ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:

- ਨਾਮ ਨਾਲ ਮਾਡਲ ਲੱਭਣ ਲਈ **ਮਾਡਲ ਖੋਜੋ...**
- ਇੱਕ ਇੰਜਣ (OpenRouter, OpenAI, Ollama, …) ਲਈ ਸੂਚੀ ਨੂੰ ਸੀਮਿਤ ਕਰਨ ਲਈ **ਪ੍ਰਦਾਤਾ** ਚਿਪਸ
- ਸਿਰਫ਼ ਮੁਫ਼ਤ ਮਾਡਲ ਦਿਖਾਉਣ ਲਈ **ਸਿਰਫ਼ ਮੁਫ਼ਤ**
- ਸੂਚੀ ਨੂੰ ਮੁੜ-ਲੋਡ ਕਰਨ ਲਈ **ਰਿਫ਼ਰੈਸ਼**
- ਜਦੋਂ ਤੁਸੀਂ ਪ੍ਰਦਾਤਾ ਅਨੁਸਾਰ ਕ੍ਰਮਬੱਧ ਕਰ ਰਹੇ ਹੋ ਤਾਂ **ਸਭ ਫੈਲਾਓ** ਅਤੇ **ਸਭ ਸਮੇਟੋ**

ਮਾਡਲ ਆਈਡੀਆਂ ਵਿੱਚ ਪ੍ਰਦਾਤਾ ਪ੍ਰੀਫਿਕਸ ਸ਼ਾਮਲ ਹੁੰਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `openrouter/…` ਬਨਾਮ `openai/…`)। ਬੈਜ ਜਿਵੇਂ **OpenAI (OpenRouter)** ਬਨਾਮ **OpenAI (ਸਿੱਧਾ)** ਦੱਸਦੇ ਹਨ ਕਿ ਟ੍ਰੈਫਿਕ ਕਿਵੇਂ ਰੂਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

> ℹ️ **ਨੋਟ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) ਇੱਕ ਰਾਊਟਰ ਮਾਡਲ ਹੈ, ਆਮ ਚੈਟ ਮਾਡਲ ਨਹੀਂ: ਇਸਦਾ ਜਵਾਬ ਜੇਸਨ ਹੁੰਦਾ ਹੈ ਜੋ OpenRouter ਐਪੀਆਈ ਰਿਕੁਐਸਟ ਬਾਡੀਆਂ ਦਾ ਵੇਰਵਾ ਦਿੰਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `requests` ਐਰੇ ਨਾਲ `model` ਅਤੇ `messages`)। ਜੇ ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ **ਅਨੁਵਾਦ ਕਰੋ**, **ਮੁੜ-ਲਿਖਤ**, ਜਾਂ **ਟ੍ਰਾਂਸਫਾਰਮ** ਲਈ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁੱਟ ਪੈਨਲ ਉਸ ਜੇਸਨ ਨੂੰ ਦਿਖਾਏਗਾ ਬਜਾਏ ਪੂਰੇ ਟੈਕਸਟ ਦੇ। ਇਹਨਾਂ ਕੰਮਾਂ ਲਈ ਇੱਕ ਆਮ ਟੈਕਸਟ ਮਾਡਲ ਚੁਣੋ। OpenRouter 'ਤੇ [ਬਾਡੀ ਬਿਲਡਰ ਮਾਡਲ ਪੇਜ](https://openrouter.ai/openrouter/bodybuilder) ਵੇਖੋ।

ਕਾਰਵਾਈਆਂ:

- ਇੱਕ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, **ਸ਼ਾਮਲ ਕਰੋ** ਜਾਂ ਐਂਟਰੀ ਵਿੱਚ ਕਿਤੇ ਵੀ ਕਲਿੱਕ ਕਰੋ।

- ਇੱਕ ਮਾਡਲ ਨੂੰ ਹਟਾਉਣ ਲਈ, **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇਸਦੇ ਨਾਲ **X** 'ਤੇ ਜਾਂ ਉਪਲਬਧ ਮਾਡਲ ਵਿੱਚ ਐਂਟਰੀ 'ਤੇ **ਚੁਣਿਆ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

- ਸੂਚੀ ਨੂੰ ਸਾਫ਼ ਕਰਨ ਲਈ, **ਸਭ ਅਣ-ਚੁਣੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਲੋੜੀਂਦਾ ਮੁਫ਼ਤ ਮਾਡਲ ਸੂਚੀ ਵਿੱਚ ਰਹੇਗਾ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਜੇ ਤੁਸੀਂ OpenRouter ਨੂੰ ਤੁਰੰਤ ਕ੍ਰੈਡਿਟ ਸ਼ਾਮਲ ਕਰਨਾ ਨਹੀਂ ਚਾਹੁੰਦੇ, ਤਾਂ **ਸਿਰਫ਼ ਮੁਫ਼ਤ** ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ ਅਤੇ ਮੁਫ਼ਤ ਮਾਡਲ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ) ਚੁਣ ਕੇ ਸ਼ੁਰੂ ਕਰੋ। ਤੁਸੀਂ ਕੋਈ ਐਪੀਆਈ ਕੁੰਜੀ ਦੀ ਲੋੜ ਤੋਂ ਬਿਨਾਂ ਮਾਡਲ ਨੂੰ ਚਲਾਉਣ ਲਈ Ollama ਦੀ ਵਰਤੋਂ ਵੀ ਕਰ ਸਕਦੇ ਹੋ।

### ਭਾਸ਼ਾਵਾਂ

ਐਪ ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਨੂੰ ਵਿਵਸਥਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ** ਵਰਤੋਂ।

- **ਸਭ ਤੋਂ ਉੱਪਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** ਨੂੰ **ਅਨੁਵਾਦ ਕਰੋ** ਅਤੇ **ਟ੍ਰਾਂਸਫਾਰਮ** ਵਿੱਚ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਦੇ ਉੱਪਰਲੇ ਹਿੱਸੇ ਵਿੱਚ ਪਿੰਨ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।  
- **ਕਸਟਮ ਭਾਸ਼ਾ** ਤੁਹਾਨੂੰ ਬਿਲਟ-ਇਨ ਸੂਚੀ ਵਿੱਚ ਨਾ ਹੋਣ ਵਾਲੀ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦੀ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ ਕਸਟਮ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਤਾਂ ਇਹ ਬਿਲਟ-ਇਨ ਵਿਕਲਪਾਂ ਨਾਲ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲਿਆਂ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦੀ ਹੈ।

### ਲਾਗਤ ਟਰੈਕਿੰਗ

ਲਾਗਤ ਜਾਣਕਾਰੀ ਨੂੰ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਕੁੱਲ ਲਾਗਤ** ਚੱਲ ਰਹੇ ਕੁੱਲ ਮੁੱਲ ਨੂੰ ਦਰਸਾਉਂਦੀ ਹੈ।  
- **ਮੁੱਲ ਕਾਪੀ ਕਰੋ** ਕੁੱਲ ਮੁੱਲ ਨੂੰ ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।  
- **ਲਾਗਤ ਰੀਸੈੱਟ ਕਰੋ** ਸਟੋਰ ਕੀਤੇ ਕੁੱਲ ਮੁੱਲ ਨੂੰ ਸਿਫ਼ਰ 'ਤੇ ਰੀਸੈੱਟ ਕਰਦਾ ਹੈ।  
- **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ ਕਰੋ** ਕੁੱਲ ਮੁੱਲ ਨੂੰ ਤੁਹਾਡੇ OpenRouter ਖਾਤੇ ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੀ ਵਰਤੋਂ ਨਾਲ ਮੇਲ ਕਰਨ ਲਈ ਸੈੱਟ ਕਰਦਾ ਹੈ (ਸਿਰਫ਼ OpenRouter)।  
- **API ਕੁੰਜੀ ਵਰਤੋਂ** OpenRouter ਵਰਤੋਂ ਦੀਆਂ ਵੇਰਵੇ ਦਿਖਾਉਂਦੀ ਹੈ, ਜੇਕਰ ਉਪਲਬਧ ਹੋਵੇ।  
- **ਲਾਗਤ ਡੇਟਾ ਮਿਟਾਓ** ਸਭ ਡੇਟਾ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ, ਜਾਂ ਸਿਰਫ਼ ਚੁਣੀ ਮਿਤੀ ਤੋਂ ਪਹਿਲਾਂ ਦੀਆਂ ਐਂਟਰੀਆਂ ਨੂੰ।

**ਲਾਗਤ ਟਰੈਕਿੰਗ:** ਜਦੋਂ ਤੁਸੀਂ OpenRouter ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ ਅਸਲ ਵਰਤੋਂ ਅਤੇ OpenRouter ਤੋਂ ਲਾਗਤ ਜਾਣਕਾਰੀ ਦੇ ਆਧਾਰ 'ਤੇ ਖਰਚ ਦਿਖਾਉਂਦਾ ਹੈ। ਸਾਰੇ ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ ਲਈ, ਐਪ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਮਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਲਾਗਤਾਂ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਂਦਾ ਹੈ, ਜੇਕਰ ਕੀਮਤ ਉਪਲਬਧ ਨਾ ਹੋਵੇ, ਤਾਂ ਅੰਦਾਜ਼ਾ ਸਿਫ਼ਰ ਹੋ ਸਕਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
>  **ਸਾਰੇ ਲਾਗਤ ਅੰਕੜੇ ਸਿਰਫ਼ ਤੁਹਾਡੇ ਹਵਾਲੇ ਲਈ ਅੰਦਾਜ਼ੇ ਹਨ, ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।**

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਡੇਟਾ ਨੂੰ ਮਿਟਾਉਣਾ ਉਲਟਾ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਮਿਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ, [**ਇਤਿਹਾਸ**](#history) ਜਾਂ [**ਡੈਸ਼ਬੋਰਡ** > **ਸਾਰੀਆਂ ਕਾਲਾਂ**](#dashboard-tabs) ਰਾਹੀਂ ਆਪਣੇ ਡੇਟਾ ਦਾ ਬੈਕਅਪ ਲਓ ਜਾਂ ਇਸਨੂੰ ਐਕਸਪੋਰਟ ਕਰੋ, ਨਹੀਂ ਤਾਂ ਇਹ ਸਥਾਈ ਤੌਰ 'ਤੇ ਖੋ ਜਾਵੇਗਾ।  
> ਹਰੇਕ API ਕਾਲ ਐਂਟਰੀ ਨਾਲ ਸਬੰਧਤ ਸਾਰਾ ਇਨਪੁੱਟ/ਆਉਟਪੁੱਟ ਇਤਿਹਾਸ ਵੀ ਮਿਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।

<a id="transform-prompts"></a>
### ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ

ਪ੍ਰੌਂਪਟਾਂ ਨੂੰ ਬਲਕ ਵਿੱਚ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

ਤੁਸੀਂ ਕਰ ਸਕਦੇ ਹੋ:

- ਆਪਣੇ ਸੰਭਾਲੇ ਗਏ ਪ੍ਰੌਂਪਟਾਂ ਦੀ ਸਮੀਖਿਆ ਕਰੋ  
- ਪ੍ਰੌਂਪਟ ਮਿਟਾਓ  
- ਇੱਕ ਫਾਈਲ ਤੋਂ ਪ੍ਰੌਂਪਟ ਆਯਾਤ ਕਰੋ  
- ਬੈਕਅਪ ਜਾਂ ਸਾਂਝ ਕਰਨ ਲਈ ਪ੍ਰੌਂਪਟ ਐਕਸਪੋਰਟ ਕਰੋ  
- ਪ੍ਰੌਂਪਟ ਸੂਚੀ ਵਿੱਚ ਨਮੂਨਾ ਪ੍ਰੌਂਪਟ ਲੋਡ ਕਰੋ

<a id="users"></a>
### ਉਪਭੋਗਤਾ

ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ ਉਪਭੋਗਤਾ ਖਾਤਿਆਂ ਨੂੰ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਲਈ **ਉਪਭੋਗਤਾ** ਦੀ ਵਰਤੋਂ ਕਰੋ। ਤੁਸੀਂ ਉਪਭੋਗਤਾ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹੋ, ਉਨ੍ਹਾਂ ਦੀਆਂ ਜਾਣਕਾਰੀਆਂ ਅਪਡੇਟ ਕਰ ਸਕਦੇ ਹੋ, ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ, ਅਤੇ ਖਾਤੇ ਮਿਟਾ ਸਕਦੇ ਹੋ।

<a id="api-config"></a>
### API ਸੰਰਚਨਾ

ਸਮਰਥਿਤ ਪ੍ਰਦਾਤਾ ਹਨ: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, ਅਤੇ **Ollama** (ਬੇਸ URL ਰਾਹੀਂ ਸਥਾਨਕ ਮਾਡਲ)। ਤੁਹਾਨੂੰ ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰਨ ਦੀ ਲੋੜ ਹੈ ਜਿਨ੍ਹਾਂ ਦੀ ਤੁਸੀਂ ਵਰਤੋਂ ਕਰਦੇ ਹੋ।

**ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ: ਸਿਰਫ਼ ਪ੍ਰਸ਼ਾਸਕ**

API ਕੁੰਜੀਆਂ ਸਿਸਟਮ ਜਾਂ Docker ਵਾਤਾਵਰਣ ਚਲਾਂ ਰਾਹੀਂ ਸੰਰਚਿਤ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ - ਇਹ ਵੈੱਬ UI ਵਿੱਚ ਦਰਜ ਨਹੀਂ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ। ਇਹ ਸਫ਼ਾ ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਕਿਹੜੇ ਪ੍ਰਦਾਤਾਵਾਂ ਲਈ ਇੱਕ ਕੁੰਜੀ ਸੰਰਚਿਤ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ **`ਟੈਸਟ`** ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਹਰੇਕ ਦੀ ਪਰਖ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਇੱਕ API ਕੁੰਜੀ ਨੂੰ ਬਦਲਣ ਲਈ, ਆਪਣੇ ਸਿਸਟਮ ਜਾਂ Docker ਸੰਰਚਨਾ ਵਿੱਚ ਵਾਤਾਵਰਣ ਚਲ ਨੂੰ ਅਪਡੇਟ ਕਰੋ ਅਤੇ ਸਰਵਰ ਜਾਂ ਕੰਟੇਨਰ ਨੂੰ ਮੁੜ ਚਾਲੂ ਕਰੋ।

> ℹ️ **ਨੋਟ**<br/>
> **ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਬੈਕਅਪ** (ਵੇਖੋ [**ਆਮ ਸੈਟਿੰਗਾਂ** → ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਬੈਕਅਪ](#general-settings)) ZIP ਦੇ `config.json` ਵਿੱਚ **ਰੀਸਾਲਵਡ** ਪ੍ਰਦਾਤਾ ਕੁੰਜੀਆਂ ਨੂੰ ਏਮਬੈੱਡ ਕਰ ਸਕਦੇ ਹਨ। ਉਸ ZIP ਨੂੰ ਬਹਾਲ ਕਰਨਾ ਉਹਨਾਂ ਕੁੰਜੀਆਂ ਨੂੰ ਸਰਵਰ ਦੀ ਸਥਾਈ ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਫਾਈਲ ਵਿੱਚ ਵਾਪਸ ਨਹੀਂ ਕਾਪੀ ਕਰਦਾ - ਜਿਵੇਂ ਕਿ ਉੱਥੇ ਦੱਸਿਆ ਗਿਆ ਹੈ, ਲਾਈਵ ਕੁੰਜੀਆਂ ਅਜੇ ਵੀ ਵਾਤਾਵਰਣ ਅਤੇ ਮੌਜੂਦਾ ਫਾਈਲ ਸਥਿਤੀ ਤੋਂ ਆਉਂਦੀਆਂ ਹਨ।

<br/>

**ਡੈਸਕਟਾਪ ਐਪਲੀਕੇਸ਼ਨ**

ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਲਈ API ਕੁੰਜੀਆਂ ਸਟੋਰ ਕਰਨ ਲਈ **API ਸੰਰਚਨਾ** ਵਰਤੋਂ। Ollama ਲਈ, API ਕੁੰਜੀ ਦੀ ਬਜਾਏ **ਬੇਸ URL** ਦਿਓ।

<br/>

> 💡 **ਸੁਝਾਅ** <br/>
> ਜੇਕਰ ਤੁਸੀਂ API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਕਰਨਾ ਜਾਂ ਵਰਤੋਂ ਲਈ ਭੁਗਤਾਨ ਕਰਨਾ ਨਹੀਂ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ [Ollama ਡਾਊਨਲੋਡ](https://ollama.com) ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ ਮੁਫ਼ਤ ਵਿੱਚ ਆਪਣੇ ਮਸ਼ੀਨ 'ਤੇ ਮਾਡਲ (ਜਿਵੇਂ `translategemma:4b`) ਚਲਾ ਸਕਦੇ ਹੋ। ਇਸ ਦੀ ਬਜਾਏ, ਤੁਸੀਂ ਮੁਫ਼ਤ ਮਾਡਲ ਵਰਤਣ ਲਈ ਮੁਫ਼ਤ OpenRouter ਖਾਤਾ ਬਣਾ ਸਕਦੇ ਹੋ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ), ਜਾਂ Cerebras, Google, Groq, ਜਾਂ Mistral AI ਤੋਂ ਮੁਫ਼ਤ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

- ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰੋ ਜਿਹਨਾਂ ਦੀ ਤੁਹਾਨੂੰ ਲੋੜ ਹੈ। **ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ** ਵਿੱਚ, ਹਰੇਕ ਮਾਡਲ ID ਪ੍ਰਦਾਤਾ ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦੀ ਹੈ (ਉਦਾਹਰਣ ਵਜੋਂ `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, ਟੈਕਸਟ ਫੀਲਡ ਵਿੱਚ ਮੁੱਲ ਦਿਓ ਅਤੇ **`ਸੇਵ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਮੌਜੂਦਾ ਕੁੰਜੀ ਨੂੰ ਬਦਲਣ ਲਈ, **`ਸੋਧ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਹ ਜਾਂਚਣ ਲਈ ਕਿ ਕੀ ਕੁੰਜੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ, **`ਟੈਸਟ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। Ollama ਬੇਸ URL ਲਈ, ਕਨੈਕਸ਼ਨ ਜਾਂਚਣ ਲਈ ਹਮੇਸ਼ਾ **`ਟੈਸਟ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ API ਕੁੰਜੀ ਦਾ ਮੌਜੂਦਾ ਮੁੱਲ ਨਹੀਂ ਵੇਖ ਸਕਦੇ। ਤੁਸੀਂ ਇਸਨੂੰ ਸਿਰਫ਼ **`ਸੋਧ`** ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਬਦਲ ਸਕਦੇ ਹੋ।
> API ਕੁੰਜੀਆਂ ਸੰਰਚਨਾ ਵਿੱਚ ਇਨਕ੍ਰਿਪਟਿਡ ਸਟੋਰ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।

## ਆਮ ਸਮੱਸਿਆਵਾਂ

ਜੇਕਰ ਕੁਝ ਉਮੀਦ ਮੁਤਾਬਕ ਕੰਮ ਨਾ ਕਰੇ, ਤਾਂ ਪਹਿਲਾਂ ਹੇਠ ਲਿਖੇ ਬਿੰਦੂਆਂ ਨੂੰ ਜਾਂਚੋ।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ਐਪ ਟੈਕਸਟ ਦਾ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਤ ਜਾਂ ਟ੍ਰਾਂਸਫਾਰਮ ਨਹੀਂ ਕਰਦਾ

ਜਾਂਚੋ ਕਿ:

- ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣਿਆ ਹੈ
- ਘੱਟੋ ਘੱਟ ਇੱਕ ਮਾਡਲ [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਵਿੱਚ ਸੂਚੀਬੱਧ ਹੈ
- ਤੁਹਾਡੀ API ਸੈਟਅੱਪ ਕੰਮ ਕਰ ਰਹੀ ਹੈ

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਵਰਤ ਰਹੇ ਹੋ:

1. [**ਸੈਟਿੰਗਾਂ** > **API ਸੰਰਚਨਾ**](#api-config) ਖੋਲ੍ਹੋ।
2. ਜਾਂਚੋ ਕਿ ਘੱਟੋ ਘੱਟ ਇੱਕ API ਕੁੰਜੀ ਸੇਵ ਹੈ।
3. ਪ੍ਰਦਾਤਾ ਦੇ ਨਾਲ **ਟੈਸਟ** 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕੁੰਜੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।

<br/>

<a id="the-model-list-is-empty"></a>
### ਮਾਡਲ ਸੂਚੀ ਖਾਲੀ ਹੈ

[**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਰਿਫ਼ਰੈਸ਼** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਜੇ ਲੋੜ ਹੋਵੇ:

- ਇੱਕ ਮਾਡਲ ਲਈ ਖੋਜੋ
- **ਸਿਰਫ਼ ਮੁਫ਼ਤ** ਨੂੰ ਚਾਲੂ ਕਰੋ
- **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ਨਤੀਜਾ ਬਹੁਤ ਧੀਮਾ ਜਾਂ ਬਹੁਤ ਮਹਿੰਗਾ ਹੈ

ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਜਾਂ ਵੱਧ ਕੋਸ਼ਿਸ਼ ਕਰੋ:

- ਇੱਕ ਵੱਖਰਾ ਮਾਡਲ ਚੁਣੋ
- ਇੱਕ ਛੋਟਾ ਇਨਪੁੱਟ ਵਰਤੋਂ
- [**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਨੂੰ ਬੰਦ ਕਰੋ
- ਸਧਾਰਨ ਕੰਮਾਂ ਲਈ ਮੁਫ਼ਤ ਮਾਡਲ ਵਰਤੋਂ (ਵੇਖੋ [ਮਾਡਲ](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ਇੰਟਰਫੇਸ ਗਲਤ ਭਾਸ਼ਾ ਵਿੱਚ ਹੈ

[ਟੂਲਬਾਰ](#toolbar) ਵਿੱਚ ਗਲੋਬ ਆਈਕਾਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਆਪਣੀ ਪਸੰਦੀਦਾ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ਟੈਕਸਟ ਬਹੁਤ ਛੋਟਾ ਜਾਂ ਪੜ੍ਹਨ ਲਈ ਮੁਸ਼ਕਲ ਹੈ

[**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਬਦਲੋ:

- **ਫਾਂਟ ਫੈਮਿਲੀ**
- **ਆਕਾਰ**

<a id="dashboard-charts-are-empty"></a>
### ਡੈਸ਼ਬੋਰਡ ਚਾਰਟ ਖਾਲੀ ਹਨ

ਜੇਕਰ ਇਹ ਸਾਧਾਰਨ ਹੈ:

- ਤੁਸੀਂ ਸਿਰਫ਼ **ਮੁਫ਼ਤ ਮਾਡਲ** ਵਰਤਦੇ ਹੋ ਅਤੇ ਤੁਸੀਂ **ਲਾਗਤ** ਅੰਕੜਿਆਂ ਨੂੰ ਵੇਖ ਰਹੇ ਹੋ (ਉਹ ਸਿਫ਼ਰ ਹੋ ਸਕਦੇ ਹਨ); **ਸਾਰ** ਵਿੱਚ **ਵਰਤੋਂ** ਕਾਲ-ਗਿਣਤੀ ਚਾਰਟਾਂ ਨੂੰ ਅਜੇ ਵੀ ਚੁਣੇ ਹੋਏ ਸਮੇਂ ਦੇ ਅੰਕੜੇ ਦੀ ਲੋੜ ਹੈ
- ਚੁਣਿਆ ਹੋਇਆ **ਸਮਾਂ ਫਿਲਟਰ** ਉਸ ਸਮੇਂ ਦੀ ਮਿਆਦ ਨੂੰ ਸ਼ਾਮਲ ਨਹੀਂ ਕਰਦਾ ਜਦੋਂ ਕਾਲਾਂ ਕੀਤੀਆਂ ਗਈਆਂ ਸਨ - ਜਾਂਚ ਲਈ **ਸਭ** ਕੋਸ਼ਿਸ਼ ਕਰੋ

ਜੇਕਰ **ਸਭ** ਚੁਣਨ ਤੋਂ ਬਾਅਦ ਵੀ ਚਾਰਟ ਖਾਲੀ ਹਨ, ਤਾਂ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕਾਲਾਂ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ **ਸਾਰੀਆਂ ਕਾਲਾਂ** ਟੈਬ ਵਿੱਚ ਦਿਖਾਈ ਦੇ ਰਹੀਆਂ ਹਨ।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ਲਾਗਤ "ਉਪਲਬਧ ਨਹੀਂ" ਦਿਖਾਉਂਦੀ ਹੈ ਜਾਂ ਗਲਤ ਲੱਗਦੀ ਹੈ

ਜਦੋਂ ਤੁਸੀਂ **OpenRouter** ਰਾਹੀਂ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ OpenRouter ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੇ ਗਏ ਤੁਹਾਡੇ ਅਸਲ ਖਰਚ ਨੂੰ ਦਿਖਾਉਂਦਾ ਹੈ।

**ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ** (OpenAI ਸਿੱਧਾ, Anthropic ਸਿੱਧਾ, ਆਦਿ) ਲਈ, ਲਾਗਤ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਿਤ ਮੁੱਲ ਦੇ ਅੰਕੜਿਆਂ ਤੋਂ ਅਨੁਮਾਨਿਤ ਹੁੰਦੀ ਹੈ। ਜੇਕਰ ਕਿਸੇ ਮਾਡਲ ਲਈ ਮੈਚ ਕਰਨ ਵਾਲਾ ਮੁੱਲ ਨਹੀਂ ਮਿਲਦਾ, ਤਾਂ ਲਾਗਤ **ਉਪਲਬਧ ਨਹੀਂ** ਦਿਖਾਈ ਦੇਵੇਗੀ ਅਤੇ ਤੁਹਾਡੇ ਕੁੱਲ ਜੋੜ ਵਿੱਚ ਸ਼ਾਮਲ ਨਹੀਂ ਕੀਤੀ ਜਾਵੇਗੀ।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ਕੁੱਲ ਲਾਗਤ ਤੁਹਾਡੇ ਪ੍ਰਦਾਤਾ ਦੇ ਬਿੱਲ ਨਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੀ

ਐਪ ਵਿੱਚ ਸਾਰੇ ਲਾਗਤ ਅੰਕੜੇ ਸਿਰਫ਼ **ਹਵਾਲੇ ਲਈ ਅਨੁਮਾਨ** ਹਨ, ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।

ਕੁੱਲ ਨੂੰ ਤੁਹਾਡੇ ਅਸਲ OpenRouter ਖਰਚ ਨਾਲ ਨੇੜੇ ਲਿਆਉਣ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਖੋਲ੍ਹੋ ਅਤੇ **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### ਸਾਈਡਬਾਰ ਵਿੱਚ ਇਤਿਹਾਸ ਪੰਨਾ ਗਾਇਬ ਹੈ

**ਨਿਸ਼ਪਾਦਨ ਇਤਿਹਾਸ ਰੱਖੋ** ਨੂੰ ਬੰਦ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ। [**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਇਸਨੂੰ ਚਾਲੂ ਕਰੋ। ਧਿਆਨ ਰੱਖੋ ਕਿ ਇਸਨੂੰ ਚਾਲੂ ਕਰਨ ਨਾਲ ਪਹਿਲਾਂ ਹਟਾਏ ਗਏ ਇਤਿਹਾਸ ਡਾਟਾ ਮੁੜ ਸਥਾਪਤ ਨਹੀਂ ਹੁੰਦਾ।

<br/>

<a id="web-app-session-expired"></a>
### ਵੈੱਬ ਐਪ: ਲੌਗਇਨ ਪੇਜ ਤੇ ਅਣਜਾਣੇ ਵਿੱਚ ਰੀਡਾਇਰੈਕਟ ਕੀਤਾ ਗਿਆ

ਤੁਹਾਡਾ ਸੈਸ਼ਨ ਸਮਾਪਤ ਹੋ ਸਕਦਾ ਹੈ। ਮੁੜ ਲੌਗ ਇਨ ਕਰੋ। ਜੇਕਰ ਇਹ ਅਕਸਰ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਸਰਵਰ ਕਾਨਫਿਗਰੇਸ਼ਨ ਵਿੱਚ ਸੈਸ਼ਨ ਜੀਵਨ ਕਾਲ ਸੈਟਿੰਗਾਂ ਦੀ ਜਾਂਚ ਕਰੋ।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### ਵੈੱਬ ਐਡਮਿਨ: ਪਾਸਵਰਡ ਭੁੱਲ ਗਏ ਜਾਂ ਗੁਆ ਦਿੱਤਾ

ਇਹ **ਸਵੈ-ਹੋਸਟ ਕੀਤੇ ਵੈੱਬ ਐਪ** (Docker) ਤੇ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਡੈਸਕਟਾਪ (Electron) ਐਪ ਤੇ ਨਹੀਂ।

- ਜੇਕਰ ਕੋਈ ਹੋਰ ਐਡਮਿਨਿਸਟਰੇਟਰ ਅਜੇ ਵੀ ਸਾਇਨ ਇਨ ਕਰ ਸਕਦਾ ਹੈ, ਤਾਂ ਉਹ [**ਸੈਟਿੰਗਾਂ** > **ਉਪਭੋਗਤਾ**](#users) ਖੋਲ੍ਹ ਸਕਦਾ ਹੈ, ਖਾਤਾ ਚੁਣ ਸਕਦਾ ਹੈ, ਅਤੇ ਇੱਥੇ **ਨਵਾਂ ਪਾਸਵਰਡ** ਸੈੱਟ ਕਰ ਸਕਦਾ ਹੈ।
- ਜੇਕਰ ਤੁਸੀਂ **ਬਲਾਕ ਆਊਟ** ਹੋ ਪਰ ਮਸ਼ੀਨ ਜਾਂ ਕੰਟੇਨਰ ਤੱਕ **ਸ਼ੈੱਲ ਐਕਸੈਸ** ਹੈ, ਤਾਂ ਇਮੇਜ ਨਾਲ ਆਉਣ ਵਾਲੇ ਹੈਲਪਰ ਨਾਲ ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰੋ (ਡਿਫਾਲਟ ਨਾਮ ਬਦਲਣ ਤੇ `transrewrt` ਨੂੰ ਬਦਲੋ, ਅਤੇ ਜੇਕਰ ਪਾਸਵਰਡ ਵਿੱਚ ਸਪੇਸ ਜਾਂ ਖਾਸ ਅੱਖਰ ਹਨ ਤਾਂ ਪਾਸਵਰਡ ਨੂੰ ਕੋਟ ਵਿੱਚ ਰੱਖੋ):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ਜੇਕਰ ਤੁਸੀਂ ਕਦੇ ਵੀ ਹੋਰ ਖਾਤੇ ਨਹੀਂ ਬਣਾਏ ਹਨ, ਤਾਂ ਡਿਫਾਲਟ ਐਡਮਿਨ ਯੂਜ਼ਰ ਨਾਮ `admin` ਹੈ। ਜਦੋਂ ਤੁਸੀਂ ਸਿਰਫ਼ ਇੱਕ ਤਰਕ ਦਿੰਦੇ ਹੋ, ਤਾਂ ਇਸਨੂੰ `admin` ਲਈ ਨਵਾਂ ਪਾਸਵਰਡ ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ Docker ਦੀ ਬਜਾਏ **ਸਰੋਤ ਚੈੱਕਆਊਟ** ਤੋਂ ਚਲਾ ਰਹੇ ਹੋ, ਤਾਂ ਵਰਤੋਂ:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

ਸਕ੍ਰਿਪਟ SQLite ਡੇਟਾਬੇਸ ਵਿੱਚ ਯੂਜ਼ਰ ਰਿਕਾਰਡ ਨੂੰ ਅਪਡੇਟ ਕਰਦਾ ਹੈ (ਅਤੇ `admin` ਯੂਜ਼ਰ ਬਣਾ ਸਕਦਾ ਹੈ ਜੇਕਰ ਇਹ ਗਾਇਬ ਹੈ)। ਰੀਸੈੱਟ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਨਵੇਂ ਪਾਸਵਰਡ ਨਾਲ ਸਾਇਨ ਇਨ ਕਰੋ।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ਡੈਸ਼ਬੋਰਡ ਹੋਰ ਉਪਭੋਗਤਾਵਾਂ ਲਈ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਦਿਖਾਉਂਦਾ (ਵੈੱਬ)

ਸਿਰਫ਼ **ਐਡਮਿਨਿਸਟਰੇਟਰ** **ਯੂਜ਼ਰ** ਫਿਲਟਰ ਰਾਹੀਂ ਸਾਰੇ ਉਪਭੋਗਤਾਵਾਂ ਦਾ ਡਾਟਾ ਵੇਖ ਸਕਦੇ ਹਨ। ਨਿਯਮਤ ਉਪਭੋਗਤਾ ਸਿਰਫ਼ ਆਪਣੀ ਗਤੀਵਿਧੀ ਨੂੰ ਵੇਖਦੇ ਹਨ।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ਮੈਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਬਦਲਿਆ ਅਤੇ ਸੋਧਾਂ ਨੂੰ ਗੁਆ ਦਿੱਤਾ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੋਧ ਰਹੇ ਹੋ, ਹਮੇਸ਼ਾ **ਸੇਵ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ ਇਸ ਤੋਂ ਪਹਿਲਾਂ ਕਿ **ਰਨ ਤੇ ਵਾਪਸ ਜਾਓ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/><br/>

<a id="quick-tips"></a>
## ਤੁਰੰਤ ਸੁਝਾਅ

- ਆਪਣੀ ਸੈਟਅੱਪ ਦੀ ਜਾਂਚ ਕਰਨ ਲਈ [**ਅਨੁਵਾਦ ਕਰੋ**](#translate) ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਇਸ ਤੋਂ ਪਹਿਲਾਂ ਕਿ ਤੁਸੀਂ [**ਮੁੜ-ਲਿਖਤ**](#rewrite) ਜਾਂ [**ਟ੍ਰਾਂਸਫਾਰਮ**](#transform) ਤੇ ਜਾਓ।
- ਰੋਜ਼ਾਨਾ ਸ਼ਬਦਾਵਲੀ ਸੁਧਾਰਾਂ ਲਈ [**ਮੁੜ-ਲਿਖਤ**](#rewrite) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜਦੋਂ ਤੁਹਾਨੂੰ ਇੱਕ ਖਾਸ ਕੰਮ ਲਈ ਦੁਹਰਾਉਣਯੋਗ ਵਰਕਫਲੋ ਦੀ ਲੋੜ ਹੋਵੇ, ਤਾਂ [**ਟ੍ਰਾਂਸਫਾਰਮ**](#transform) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇਕਰ ਤੁਸੀਂ ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ ਉੱਤੇ ਨਜ਼ਰ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ [**ਡੈਸ਼ਬੋਰਡ**](#dashboard) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਪਿਛਲੀਆਂ ਕਾਰਵਾਈਆਂ ਅਤੇ ਉਨ੍ਹਾਂ ਦੇ ਪੂਰੇ ਇਨਪੁੱਟ/ਆਊਟਪੁਟ ਟੈਕਸਟ ਨੂੰ ਦੇਖਣ ਲਈ [**ਇਤਿਹਾਸ**](#history) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਲਾਇਬ੍ਰੇਰੀ ਬਣਾ ਰਹੇ ਹੋ ਜਿਸਨੂੰ ਤੁਸੀਂ ਸੁਰੱਖਿਅਤ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ (ਵੇਖੋ [ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੋਂਪਟ](#transform-prompts)) ਜਾਂ ਜੇਕਰ ਤੁਸੀਂ ਇਸਨੂੰ ਦੂਜਿਆਂ ਨਾਲ ਸਾਂਝਾ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਨਿਯਮਤ ਤੌਰ ਤੇ ਪ੍ਰੋਂਪਟ ਨੂੰ ਐਕਸਪੋਰਟ ਕਰੋ।
