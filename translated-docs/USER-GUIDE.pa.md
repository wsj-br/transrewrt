# ਵਰਤੋਂਕਾਰ ਗਾਈਡ

<br/>

<a id="introduction"></a>
## ਪਰਿਚਈ

Transrewrt ਤਿੰਨ ਮੁੱਖ ਤਰੀਕਿਆਂ ਨਾਲ ਪਾਠ ਨਾਲ ਕੰਮ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ:

- **ਅਨੁਵਾਦ** – ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਪਾਠ ਨੂੰ ਬਦਲਣਾ।
- **ਮੁੜ ਲਿਖੋ** – ਸਪੱਸ਼ਟ, ਛੋਟਾ ਜਾਂ ਵਧੇਰੇ ਔਪਚਾਰਿਕ ਵਰਗੀ ਵੱਖਰੀ ਸ਼ੈਲੀ ਵਿੱਚ ਪਾਠ ਨੂੰ ਮੁੜ ਤਰਜਮਾ ਕਰਨਾ।
- **ਰੂਪਾਂਤਰਿਤ ਕਰਨਾ** – ਪ੍ਰਾਂਪਟਾਂ ਕਹੇ ਜਾਂਦੇ ਕਸਟਮ AI ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਪਾਠ ਨੂੰ ਪ੍ਰੋਸੈੱਸ ਕਰਨਾ।

<br/>

ਇਹ ਗਾਈਡ ਸੰਸਥਾਪਤ ਅਤੇ ਚੱਲ ਰਹੇ ਹੋਣ ਤੋਂ ਬਾਅਦ ਐਪ ਨੂੰ ਵਰਤਣ ਬਾਰੇ ਦੱਸਦੀ ਹੈ। ਇੰਸਟਾਲੇਸ਼ਨ ਕਦਮਾਂ ਲਈ ਮੁੱਖ **[README](README.pa.md)** ਵੇਖੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਟਰਾਂਸਰਿਵਰਟ Windows ਅਤੇ Linux ਲਈ ਡੈਸਕਟਾਪ ਐਪ ਅਤੇ ਸੈਲਫ-ਹੋਸਟੇਡ ਵੈੱਬ ਐਪ ਦੇ ਤੌਰ 'ਤੇ ਉਪਲਬਧ ਹੈ। ਇਹ ਗਾਈਡ ਐਪ ਦੀ ਰੋਜ਼ਾਨਾ ਵਰਤੋਂ 'ਤੇ ਧਿਆਨ ਕੇਂਦਰਤ ਕਰਦੀ ਹੈ। ਕਿਤੇ ਵੀ ਜਿੱਥੇ ਕੋਈ ਚੀਜ਼ ਸਿਰਫ ਇੱਕ ਵਰਜਨ ਲਈ ਲਾਗੂ ਹੁੰਦੀ ਹੈ, ਉਹ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਮਾਰਕ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

<a id="before-you-start"></a>

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

Transrewrt ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ, ਘੱਟੋ-ਘੱਟ ਇੱਕ AI ਪ੍ਰਦਾਤਾ ਨੂੰ ਪਹੁੰਚ ਪ੍ਰਾਪਤ ਹੋਣੀ ਚਾਹੀਦੀ ਹੈ। ਸਹਾਇਤਾ ਪ੍ਰਾਪਤ ਪ੍ਰਦਾਤਾ ਹਨ: [OpenRouter](https://openrouter.ai) (ਜੋ ਕਿ ਬਹੁਤ ਸਾਰੇ ਮਾਡਲਾਂ ਨੂੰ ਇਕੱਤਰ ਕਰਦਾ ਹੈ), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਲਈ [Ollama](https://ollama.com)।

ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਭੁਗਤਾਨ ਵਾਲੇ ਮਾਡਲ ਨੂੰ ਚੁਣਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਆਪਣੀ OpenRouter API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਐਪ ਆਪਮੈਟਿਕ ਤੌਰ 'ਤੇ ਇੱਕ ਅੰਤਰਨਿਰਮਿਤ **ਮੁਫ਼ਤ** OpenRouter ਵਿਕਲਪ ਨੂੰ ਸਮਰੱਥ ਕਰਦਾ ਹੈ। ਇਹ ਤੁਹਾਨੂੰ ਤੁਰੰਤ ਪਾਠ ਅਨੁਵਾਦ, ਮੁੜ ਲੇਖਨ ਅਤੇ ਰੂਪਾੰਤਰ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

ਸਧਾਰਨ ਭਾਸ਼ਾ ਵਿੱਚ:

- ਇੱਕ **ਮਾਡਲ** AI ਇੰਜਨ ਹੈ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ। ਮਾਡਲਾਂ ਨੂੰ **ਪ੍ਰਦਾਤਾ ਪ੍ਰੀਫਿਕਸ** ਨਾਲ ਸੂਚੀਬੱਧ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `openrouter/…`, `openai/…`, `ollama/…`)।
- ਇੱਕ **API ਕੁੰਜੀ** (ਜਾਂ Ollama ਲਈ, ਇੱਕ **ਬੇਸ URL**) ਉਹ ਤਰੀਕਾ ਹੈ ਜਿਸ ਨਾਲ ਐਪ ਉਸ ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚਦਾ ਹੈ।

ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਆਪਣੇ ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਲਈ [**ਸੈਟਿੰਗਜ਼** > **API ਕਾਨਫਿਗ**](#api-config) ਵਿੱਚ ਕੁੰਜੀਆਂ ਸ਼ਾਮਲ ਕਰੋ। ਕੇਵਲ OpenRouter ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ, ਹੇਠਾਂ [ਕਿਵੇਂ ਇੱਕ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰਨੀ ਹੈ](#how-to-get-an-api-key-desktop-app) ਵੇਖੋ। ਜੇ ਤੁਸੀਂ API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ Ollama (from [ollama.com](https://ollama.com)) ਸਥਾਪਤ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।

ਜੇ ਤੁਸੀਂ **ਵੈੱਬ ਸੰਸਕਰਣ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਸਰਵਰ ਮਾਲਕ ਵਾਤਾਵਰਣ ਚਲ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਆਮ ਤੌਰ 'ਤੇ ਆਪਣੀਆਂ API ਕੁੰਜੀਆਂ ਆਪ ਦਾਖਲ ਨਹੀਂ ਕਰੋਗੇ।

<a id="how-to-get-an-api-key-desktop-app"></a>
### ਮੁਫ਼ਤ OpenRouter API ਕੁੰਜੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੇ (ਡੈਸਕਟਾਪ ਐਪ)

ਜੇ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਇਹ ਕਦਮ ਅਨੁਸਰਣ ਕਰੋ:

1. ਆਪਣੇ ਵੈੱਬ ਬਰਾਊਜ਼ਰ ਵਿੱਚ [OpenRouter](https://openrouter.ai) 'ਤੇ ਜਾਓ।
2. ਇੱਕ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਲਾਗਇਨ ਕਰੋ।
3. [Keys](https://openrouter.ai/keys) ਸਫ਼ੇ 'ਤੇ ਜਾਓ।
4. ਇੱਕ ਨਵੀਂ API ਕੁੰਜੀ ਬਣਾਉਣ ਲਈ ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
5. ਕੁੰਜੀ ਨੂੰ ਬਾਦ ਵਿੱਚ ਪਛਾਣਨ ਲਈ ਇੱਕ ਨਾਮ ਦਿਓ।
6. ਨਵੀਂ API ਕੁੰਜੀ ਨੂੰ ਕਾਪੀ ਕਰੋ।
7. Transrewrt ਵਿੱਚ ਵਾਪਸ ਜਾਓ ਅਤੇ **Settings** > **API Config** ਖੋਲ੍ਹੋ।
8. ਕੁੰਜੀ ਨੂੰ **OpenRouter API key** (ਅਧੀਨ **Settings** > **API Config**) ਵਿੱਚ ਪੇਸਟ ਕਰੋ।
9. ਇਹ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ ਕਿ ਇਹ ਕੰਮ ਕਰਦੀ ਹੈ, **Test OpenRouter key** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਸ਼ਾਮਲ ਕੀਤੇ ਬਿਨਾਂ OpenRouter ਦੇ ਮੁਫ਼ਤ ਮਾਰਗ ਜਾਂ ਉਪਲਬਧ ਹੋਰ ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਵਿੱਚੋਂ ਕਿਸੇ ਦੇ ਨਾਲ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ। ਬਹੁਤ ਸਾਰੇ ਮਾਮਲਿਆਂ ਵਿੱਚ, ਕੋਈ ਭੁਗਤਾਨ ਮਾਡਲ ਚੁਣੇ ਬਿਨਾਂ Transrewrt ਦੀ ਵਰਤੋਂ ਕਰਨਾ ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਇਹ ਕਾਫ਼ੀ ਹੈ। ਵਿਕਲਪਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ ਕੋਈ ਵੀ API ਕੁੰਜੀ ਬਿਨਾਂ ਮਾਡਲ ਚਲਾਉਣ ਲਈ Ollama ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।

<br/><br/>

<a id="getting-started"></a>
## ਸ਼ੁਰੂਆਤ

ਜੇ ਇਹ Transrewrt ਦੀ ਪਹਿਲੀ ਵਾਰ ਵਰਤੋਂ ਹੈ, ਤਾਂ ਇਸ ਕ੍ਰਮ ਦੀ ਪਾਲਣਾ ਕਰੋ:

1. ਐਪ ਖੋਲ੍ਹੋ।
2. ਲੋੜ ਪੈਣ 'ਤੇ ਗਲੋਬ ਆਈਕਾਨ ਤੋਂ ਆਪਣੀ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।
3. ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** 'ਤੇ ਹੋ, [**ਸੈਟਿੰਗਜ਼** > **API ਕਾਨਫਿਗ**](#api-config) ਖੋਲ੍ਹੋ, ਘੱਟੋ-ਘੱਟ ਇੱਕ ਪ੍ਰਦਾਤਾ (ਉਦਾਹਰਣ ਲਈ OpenRouter) ਲਈ ਇੱਕ API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰੋ, ਅਤੇ ਇਹ ਜਾਂਚਣ ਲਈ ਕਿ ਕੀ ਇਹ ਕੰਮ ਕਰਦੀ ਹੈ, **ਟੈਸਟ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
4. [**ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਚੁਣੇ ਮਾਡਲਾਂ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਇਕ ਤੋਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ।
5. [**ਸੈਟਿੰਗਜ਼** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਖੋਲ੍ਹੋ ਅਤੇ ਜੇ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ ਤੁਹਾਡੀਆਂ ਸਭ ਤੋਂ ਵੱਧ ਵਰਤੀਆਂ ਗਈਆਂ ਭਾਸ਼ਾਵਾਂ ਪਹਿਲਾਂ ਦਿਖਾਈ ਦੇਣ, ਤਾਂ ਆਪਣੀਆਂ **ਸਿਖਰ ਭਾਸ਼ਾਵਾਂ** ਚੁਣੋ।
6. **ਅਨੁਵਾਦ** 'ਤੇ ਜਾਓ ਅਤੇ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਇੱਕ ਸਧਾਰਨ ਅਨੁਵਾਦ ਚਲਾਓ ਕਿ ਹਰ ਚੀਜ਼ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।
7. ਇਹ ਕੰਮ ਕਰਨ ਤੋਂ ਬਾਅਦ, **ਮੁੜ ਲੇਖਨ** ਅਤੇ ਫਿਰ **ਰੂਪਾੰਤਰ** ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

ਇਸ ਕ੍ਰਮ ਦਾ ਮਹੱਤਵ ਹੈ। ਇਹ ਸਭ ਤੋਂ ਆਮ ਪਹਿਲੀ ਵਰਤੋਂ ਦੀ ਸਮੱਸਿਆ ਤੋਂ ਰੋਕਦਾ ਹੈ: ਐਪ ਕੋਲ ਕੰਮ ਕਰ ਰਹੀ API ਕਨੈਕਸ਼ਨ ਜਾਂ ਚੁਣਿਆ ਮਾਡਲ ਹੋਣ ਤੋਂ ਪਹਿਲਾਂ ਕੰਮ ਚਲਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨਾ।

<br/><br

### ਟੂਲਬਾਰ

ਐਪ ਵਿੱਚ ਤੁਸੀਂ ਜਿੱਥੇ ਵੀ ਹੋਵੋਗੇ, ਟੂਲਬਾਰ ਥੋੜਾ ਬਹੁਤ ਬਦਲ ਜਾਂਦਾ ਹੈ।

- ਖੱਬੇ ਪਾਸੇ, ਇਹ ਮੌਜੂਦਾ ਸਫ਼ੇ ਦਾ ਨਾਮ ਦਿਖਾਉਂਦਾ ਹੈ।
- ਸੱਜੇ ਪਾਸੇ, ਇਹ **ਮਾਡਲ ਸਿਲੈਕਟਰ** ਅਤੇ **ਇੰਟਰਫ਼ੇਸ ਭਾਸ਼ਾ** ਕੰਟਰੋਲ ਦਿਖਾਉਂਦਾ ਹੈ।

**ਮਾਡਲ ਸਿਲੈਕਟਰ** ਤੁਹਾਨੂੰ ਮੌਜੂਦਾ ਕੰਮ ਲਈ ਕਿਹੜਾ AI ਇੰਜਣ ਵਰਤਣਾ ਚਣਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

  ![ਮਾਡਲ ਸਿਲੈਕਟਰ](../images/screenshots/pa/model-selector.png)

> ℹ️ **ਨੋਟ**<br/>
> ਕੁਝ ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਕਦੇ-ਕਦੇ ਉਪਲਬਧ ਨਹੀਂ ਹੁੰਦੀਆਂ—ਕਦੇ ਉਹ ਆਫ਼ਲਾਈਨ ਜਾਂ ਉਪਯੋਗ ਸੀਮਾ ਤੋਂ ਵੱਧ ਜਾਂਦੀਆਂ ਹਨ। ਇਹ ਹੋਣ ਤੇ, ਐਪ ਉਸ ਮਾਡਲ ਨੂੰ ਤੁਹਾਡੀ ਉਪਲਬਧ ਸੂਚੀ ਤੋਂ ਆਟੋਮੈਟਿਕ ਤੌਰ 'ਤੇ ਹਟਾ ਦੇਵੇਗੀ।<br/>
> ਕਿਹੜੀਆਂ ਮਾਡਲਾਂ ਦਿਸਣ, ਇਸ ਨੂੰ ਕੰਟਰੋਲ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ**](#models) ਉੱਤੇ ਜਾਓ ਅਤੇ ਆਪਣੀ ਮਾਡਲ ਸੂਚੀ ਨੂੰ ਸੋਧੋ। 
> ਤੁਸੀਂ ਮਾਡਲ ਸੈਟਿੰਗਜ਼ ਨੂੰ ਸਿੱਧੇ ਟੂਲਬਾਰ ਵਿੱਚ ਮਾਡਲ ਨਾਮ ਦੇ ਖੱਬੇ ਪਾਸੇ ਪ੍ਰਦਾਤਾ ਆਈਕਾਨ ਉੱਤੇ ਕਲਿੱਕ ਕਰਕੇ ਖੋਲ੍ਹ ਸਕਦੇ ਹੋ।

<br/>

**ਗਲੋਬ ਆਈਕਾਨ + ਭਾਸ਼ਾ ਕੋਡ** ਐਪ ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ, ਜਿਵੇਂ ਕਿ ਮੇਨੂ ਅਤੇ ਬਟਨ, ਨੂੰ ਬਦਲਦਾ ਹੈ। ਇਹ **ਅਨੁਵਾਦ** ਵਿੱਚ ਵਰਤੀ ਗਈ ਅਨੁਵਾਦ ਭਾਸ਼ਾਵਾਂ ਨੂੰ **ਨਹੀਂ** ਬਦਲਦਾ।

  ![ਇੰਟਰਫ਼ੇਸ ਭਾਸ਼ਾ ਸਿਲੈਕਟਰ](../images/screenshots/pa/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### ਇਨਪੁਟ ਅਤੇ ਆਊਟਪੁਟ ਪੈਨਲ

ਜ਼ਿਆਦਾਤਰ ਵਰਕਸਪੇਸ ਖੱਬੇ ਪਾਸੇ ਇੱਕ **ਇਨਪੁਟ** ਪੈਨਲ ਅਤੇ ਸੱਜੇ ਪਾਸੇ ਇੱਕ **ਆਊਟਪੁਟ** ਪੈਨਲ ਵਰਤਦੇ ਹਨ।

**ਇਨਪੁਟ** ਪੈਨਲ ਦਿਖਾਉਂਦਾ ਹੈ:

- ਅੱਖਰਾਂ ਦੀ ਗਿਣਤੀ
- ਸ਼ਬਦਾਂ ਦੀ ਗਿਣਤੀ
- ਪੈਰੇ ਦੀ ਗਿਣਤੀ

**ਆਊਟਪੁਟ** ਪੈਨਲ ਦਿਖਾ ਸਕਦਾ ਹੈ:

- ਕੰਮ ਲਈ ਕਿੰਨਾ ਸਮਾਂ ਲੱਗਾ
- ਕੰਮ ਦੀ ਕੀਮਤ (ਜੇਕਰ ਉਪਲਬਧ ਹੋਵੇ)
- ਤੁਹਾਡੀ ਕੁੱਲ ਖਰਚਿਆ ਜਾ ਰਹੀ ਕੀਮਤ
- **TPS** (ਸਕਿੰਟ ਪ੍ਰਤੀ ਟੋਕਨ)
- ਅੱਖਰ, ਸ਼ਬਦ, ਅਤੇ ਪੈਰੇ ਦੀਆਂ ਗਿਣਤੀਆਂ
- ਵਰਤਿਆ ਗਿਆ ਮਾਡਲ

ਜੇਕਰ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦਾਂ ਬਾਰੇ ਸੋਚ ਰਹੇ ਹੋ:

- **ਟੋਕਨ** ਦਾ ਅਰਥ ਹੈ ਛੋਟੇ ਟੁਕੜੇ ਦਾ ਪਾਠ। ਤੁਸੀਂ ਇਸ ਬਾਰੇ ਸੋਚ ਸਕਦੇ ਹੋ ਕਿ ਇਹ ਇੱਕ ਸ਼ਬਦ ਦਾ ਭਾਗ ਜਾਂ ਇੱਕ ਛੋਟਾ ਸ਼ਬਦ ਹੈ।
- **TPS** ਦਾ ਅਰਥ ਹੈ ਕਿ ਮਾਡਲ ਨੇ ਪ੍ਰਤੀ ਸਕਿੰਟ ਕਿੰਨੇ ਉਹਨਾਂ ਪਾਠ ਟੁਕੜਿਆਂ ਨੂੰ ਪ੍ਰੋਸੈੱਸ ਕੀਤਾ।

<a id="translate"></a>
## ਅਨੁਵਾਦ

**ਅਨੁਵਾਦ** ਦੀ ਵਰਤੋਂ ਕਰੋ ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਪਾਠ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ।

![ਅਨੁਵਾਦ ਵਰਕਸਪੇਸ](../images/screenshots/pa/translate.png)

<br/>

<a id="translate-text"></a>
### ਪਾਠ ਦਾ ਅਨੁਵਾਦ ਕਰੋ

1. **ਅਨੁਵਾਦ** ਖੋਲ੍ਹੋ।
2. **ਤੋਂ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
3. **ਨੂੰ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. **ਇਨਪੁਟ** ਵਿੱਚ ਪਾਠ ਲਿਖੋ ਜਾਂ ਚਿਪਕਾਓ।
6. **ਅਨੁਵਾਦ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
7. **ਆਊਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।
8. ਜੇਕਰ ਤੁਸੀਂ ਨਤੀਜਾ ਕਾਪੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਕਾਪੀ ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।

<br/>

<a id="language-selection"></a>
### ਭਾਸ਼ਾ ਚੋਣ

- **ਤੋਂ** ਇੱਕ ਖਾਸ ਭਾਸ਼ਾ ਹੋ ਸਕਦੀ ਹੈ ਜਾਂ **ਭਾਸ਼ਾ ਪਛਾਣੋ**।
- **ਨੂੰ** ਉਹ ਭਾਸ਼ਾ ਹੈ ਜਿਸ ਵਿੱਚ ਤੁਸੀਂ ਨਤੀਜਾ ਚਾਹੁੰਦੇ ਹੋ।

ਤੁਹਾਡੀਆਂ ਚੁਣੀਆਂ **ਉੱਤੇ ਭਾਸ਼ਾਵਾਂ** ਸੂਚੀ ਦੇ ਸਿਖਰ 'ਤੇ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ। ਤੁਸੀਂ ਇਨ੍ਹਾਂ ਨੂੰ [**ਸੈਟਿੰਗਜ਼** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਵਿੱਚ ਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="helpful-translation-settings"></a>
### ਮਦਦਗਾਰ ਅਨੁਵਾਦ ਸੈਟਿੰਗਜ਼

[**ਸੈਟਿੰਗਜ਼** > **ਜਨਰਲ ਸੈਟਿੰਗਜ਼**](#general-settings) ਵਿੱਚ, ਤੁਸੀਂ ਅਨੁਵਾਦ ਨੂੰ ਵਰਤਣ ਬਾਰੇ ਵਿਵਹਾਰ ਨੂੰ ਬਦਲ ਸਕਦੇ ਹੋ:

- **ਪੇਸਟ ਉੱਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਉਦੋਂ ਹੀ ਇੱਕ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ ਜਦੋਂ ਤੁਸੀਂ ਪਾਠ ਪੇਸਟ ਕਰਦੇ ਹੋ।
- **ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਆਟੋ-ਨਤੀਜਾ ਕਾਪੀ** ਸਫ਼ਲ ਚੱਲਣ ਤੋਂ ਬਾਅਦ ਨਤੀਜੇ ਨੂੰ ਆਟੋਮੈਟਿਕਲੀ ਕਾਪੀ ਕਰ ਲੈਂਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦਾਂ ਨੂੰ ਚਲਾਉਂਦਾ ਹੈ।
- **ਟਾਈਮਆਊਟ (ms)** ਐਪ ਨੂੰ ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਕਿੰਨਾ ਸਮਾਂ ਉਡੀਕਣਾ ਚਾਹੀਦਾ ਹੈ, ਇਸ ਨੂੰ ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ।

<br/>

<a id="keyboard-shortcuts"></a>
### ਕੀਬੋਰਡ ਸ਼ਾਰਟਕੱਟ

[**ਸੈਟਿੰਗਜ਼** > **ਜਨਰਲ ਸੈਟਿੰਗਜ਼**](#general-settings) ਵਿੱਚ, **ENTER ਲਈ ਵਿਵਹਾਰ** ਨੂੰ ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ ਕਿ `Enter` ਦਬਾਏ ਜਾਣ ਵੇਲ

### ਟੈਕਸਟ ਨੂੰ ਮੁੜ ਲਿਖੋ

1. **ਮੁੜ ਲਿਖੋ** ਖੋਲ੍ਹੋ।
2. ਇੱਕ **ਮੋਡ** ਚੁਣੋ।
3. ਟੂਲਬਾਰ ਵਿੱਚੋਂ ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
4. **ਇਨਪੁੱਟ** ਵਿੱਚ ਟੈਕਸਟ ਟਾਈਪ ਕਰੋ ਜਾਂ ਪੇਸਟ ਕਰੋ।
5. **ਮੁੜ ਲਿਖੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
6. **ਆਉਟਪੁੱਟ** ਵਿੱਚ ਨਤੀਜਾ ਵੇਖੋ।

[**ਅਨੁਵਾਦ ਕਰੋ**](#keyboard-shortcuts) ਵਿੱਚ ਦੱਸੇ ਗਏ Enter ਕੀ ਵਰਤੋਂ ਵਾਲਾ ਵਿਵਹਾਰ ਇੱਥੇ ਵੀ ਲਾਗੂ ਹੁੰਦਾ ਹੈ।

<br/>

> 💡 **ਸੁਝਾਅ**<br/>
> ਜਦੋਂ ਤੁਸੀਂ "**ਸਪੈਲਿੰਗ ਅਤੇ ਵਿਆਕਰਨ ਦੀ ਜਾਂਚ ਕਰੋ**" ਮੋਡ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁੱਟ ਪੈਨਲ ਵਿੱਚ `ਤਬਦੀਲੀਆਂ ਵੇਖੋ` ਬਟਨ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।
> ਸੁਧਾਰਾਂ ਦੇ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਟੌਗਲ ਕਰਨ ਲਈ ਇਸ ਬਟਨ ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ, ਤੁਹਾਡੇ ਟੈਕਸਟ ਵਿੱਚ ਕੀਤੀਆਂ ਗਈਆਂ ਖਾਸ ਤਬਦੀਲੀਆਂ ਨੂੰ ਦਿਖਾਉਣ ਜਾਂ ਲੁਕਾਉਣ ਲਈ।

<a id="transform"></a>
## ਤਬਦੀਲ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ AI ਨਿਰਦੇਸ਼ਾਂ ਦੇ ਵੱਖਰੇ ਸੈੱਟ ਨੂੰ ਪਾਲਣਾ ਕਰੇ ਤਾਂ **ਤਬਦੀਲ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਟਰਾਂਸਫਾਰਮ ਵਰਕਸਪੇਸ](../images/screenshots/pa/transform.png)

ਇਹ ਐਪ ਦਾ ਸਭ ਤੋਂ ਲਚਕਦਾਰ ਹਿੱਸਾ ਹੈ। ਤੁਸੀਂ ਇਸਨੂੰ ਅਜਿਹੇ ਕੰਮਾਂ ਲਈ ਵਰਤ ਸਕਦੇ ਹੋ:

- ਨੋਟਾਂ ਦਾ ਸਾਰ ਬਣਾਉਣਾ
- ਕੱਚੇ ਟੈਕਸਟ ਨੂੰ ਸੁਧਰੇ ਈਮੇਲ ਵਿੱਚ ਬਦਲਣਾ
- ਮੁੱਖ ਬਿੰਦੂਆਂ ਨੂੰ ਕੱਢਣਾ
- ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਖਾਸ ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲਣਾ

<br/>

<a id="run-an-existing-prompt"></a>
### ਮੌਜੂਦਾ ਪ੍ਰਾਮਟ ਨੂੰ ਚਲਾਓ

1. **ਤਬਦੀਲ ਕਰੋ** ਖੋਲ੍ਹੋ।
2. ਪ੍ਰਾਮਟ ਸੂਚੀ ਵਿੱਚੋਂ ਇੱਕ ਪ੍ਰਾਮਟ ਚੁਣੋ।
3. ਜੇਕਰ ਇੱਕ **ਟੀਚਾ** ਭਾਸ਼ਾ ਬਾਕਸ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ, ਤਾਂ ਜੇ ਤੁਸੀਂ ਚਾਹੋ ਤਾਂ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. **ਇਨਪੁੱਟ** ਵਿੱਚ ਟੈਕਸਟ ਟਾਈਪ ਕਰੋ ਜਾਂ ਪੇਸਟ ਕਰੋ।
5. **ਤਬਦੀਲ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
6. **ਆਉਟਪੁੱਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### ਜੇਕਰ ਅਜੇ ਤੁਹਾਡੇ ਕੋਲ ਕੋਈ ਪ੍ਰਾਮਟ ਨਹੀਂ ਹਨ

ਜੇਕਰ ਤੁਹਾਡੀ ਪ੍ਰਾਮਟ ਸੂਚੀ ਖਾਲੀ ਹੈ, ਤਾਂ **ਨਮੂਨੇ ਵਾਲੇ ਪ੍ਰਾਮਟ ਲੋਡ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਸ ਨਾਲ ਬਿਲਟ-ਇੰਨ ਉਦਾਹਰਣਾਂ ਜੋੜੀਆਂ ਜਾਂਦੀਆਂ ਹਨ ਤਾਂ ਜੋ ਤੁਸੀਂ ਜਲਦੀ ਸ਼ੁਰੂ ਕਰ ਸਕੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਨਮੂਨੇ ਵਾਲੇ ਪ੍ਰਾਮਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਦਿੱਤੇ ਗਏ ਹਨ। ਉਨ੍ਹਾਂ ਨੂੰ ਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਤੁਸੀਂ ਇੱਕ ਪ੍ਰਾਮਟ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ **ਪ੍ਰਾਮਟ ਦਾ ਅਨੁਵਾਦ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਇਸਨੂੰ ਆਪਣੀ ਭਾਸਹ ਵਿੱਚ ਤਬਦੀਲ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="create-a-prompt-quickly"></a>
### ਤੇਜ਼ੀ ਨਾਲ ਇੱਕ ਪ੍ਰਾਮਟ ਬਣਾਓ

ਪ੍ਰਾਮਟ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਢੰਗ ਹੈ:

1. **ਨਵਾਂ ਪ੍ਰਾਮਟ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
2. **ਪ੍ਰਾਮਟ ਬਣਾਓ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਦੱਸੋ ਕਿ ਤੁਸੀਂ ਪ੍ਰਾਮਟ ਕੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।
4. ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. ਐਪ ਨੂੰ ਤੁਹਾਡੇ ਲਈ ਇੱਕ ਡਰਾਫਟ ਬਣਾਉਣ ਦਿਓ।
6. ਡਰਾਫਟ ਦੀ ਸਮੀਖਿਆ ਕਰੋ ਅਤੇ **ਸੰਭਾਲੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

![ਪ੍ਰਾਮਟ ਬਣਾਓ](../images/screenshots/pa/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### ਇੱਕ ਪ੍ਰਾਮਟ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰਾਮਟ ਬਣਾਉਂਦੇ ਹੋ ਜਾਂ ਸੰਪਾਦਿਤ ਕਰਦੇ ਹੋ, ਤਾਂ ਸੰਪਾਦਕ ਖੱਬੇ ਪਾਸੇ ਦਿਸਾਈ ਦਿੰਦਾ ਹੈ ਅਤੇ ਇੱਕ ਪ੍ਰੀਖਿਆ ਖੇਤਰ ਸੱਜੇ ਪਾਸੇ ਦਿਸਾਈ ਦਿੰਦਾ ਹੈ।

![ਟਰਾਂਸਫਾਰਮ ਪ੍ਰਾਮਟ ਸੰਪਾਦਕ](../images/screenshots/pa/transform-prompt-edit.png)

ਮੁੱਖ ਫੀਲਡ ਹਨ:

- **ਪ੍ਰਾਮਟ ਦਾ ਨਾਮ**: ਪ੍ਰਾਮਟ ਸੂਚੀ ਵਿੱਚ ਦਿਖਾਇਆ ਗਿਆ ਨਾਮ।
- **ਪ੍ਰਾਮਟ ਨਿਰਦੇਸ਼ (ਵਿਕਲਪਿਕ)**: ਪ੍ਰਾਮਟ ਚਲਾਉਂਦੇ ਸਮੇਂ ਉਪਭੋਗਤਾ ਨੂੰ ਦਿਖਾਈ ਦੇਣ ਵਾਲੀ ਇੱਕ ਛੋਟੀ ਸੂਚਨਾ।
- **ਮਾਡਲ ਭੂਮਿਕਾ**: AI ਨੂੰ ਦਿੱਤੀ ਗਈ ਕੁੱਲ ਭੂਮਿਕਾ, ਜਿਵੇਂ 'ਤੁਸੀਂ ਇੱਕ ਮਦਦਗਾਰ ਸਹਾਇਕ ਹੋ।'
- **ਮਾਡਲ ਨਿਰਦੇਸ਼ (ਹਰੇਕ ਲਾਈਨ ਇੱਕ)**: ਤੁਸੀਂ ਜੋ ਖਾਸ ਨਿਯਮ ਚਾਹੁੰਦੇ ਹੋ ਕਿ AI ਪਾਲਣਾ ਕਰੇ।
- **ਆਉਟਪੁੱਟ ਵਿਵਰਣ**: ਨਤੀਜੇ ਨੂੰ ਦਰਸਾਉਣ ਵਾਲਾ ਇੱਕ ਛੋਟਾ ਸ਼ਬਦ, ਜਿਵੇਂ 'ਸਾਰ' ਜਾਂ 'ਮੂੜ-ਲਿਖੋ'।
- **ਤਾਪਮਾਨ (0.0 → 1.0)**: ਮਾਡਲ ਕਿਸ ਤਰਾਂ ਵਿਵਹਾਰ ਕਰੇਗਾ; ਹੇਠਾਂ ਦੇਖੋ।
- **ਟੀਚੇ ਦੀ ਭਾਸ਼ਾ ਮੰਗੋ**: ਜਦੋਂ ਪ੍ਰਾਮਟ ਚਲਦਾ ਹੈ, ਤਾਂ ਟੀਚੇ ਦੀ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲਾ ਜੋੜਦਾ ਹੈ।

ਜੇਕਰ ਤੁਹਾਡੇ ਲਈ **ਤਾਪਮਾਨ** ਨਾਮਕ ਤਕਨੀਕੀ ਸ਼ਬਦ ਨਵਾਂ ਹੈ, ਤਾਂ ਇਸ ਤਰਾਂ ਦੇਖੋ:

- **ਘੱਟ** ਤਾਪਮਾਨ ਵਧੇਰੇ ਸਥਿਰ, ਭਰੋਸੇਯੋਗ ਨਤੀਜੇ ਦਿੰਦਾ ਹੈ।
- **ਵੱਧ** ਤਾਪਮਾਨ ਵਿਵਿਧਤਾ ਅਤੇ ਰਚਨਾਤਮਕਤਾ ਦਿੰਦਾ ਹੈ।

ਤੁਸੀਂ ਵਰਤ ਸਕਦੇ ਹੋ:

- **`ਪ੍ਰਾਮਟ ਬਣਾਓ`** ਇੱਕ ਸਧਾਰਨ ਵਿਵਰਣ ਤੋਂ ਇੱਕ ਨਵਾਂ ਡਰਾਫਟ ਬਣਾਉਣ ਲਈ
- **`ਪ੍ਰਾਮਟ ਸੁਧਾਰੋ`** ਮੌਜੂਦਾ ਪ੍ਰਾਮਟ ਨੂੰ ਸੁਧਾਰਨ ਲਈ
- **`ਪ੍ਰਾਮਟ ਦਾ ਅਨੁਵਾਦ ਕਰੋ`** ਪ੍ਰਾਮਟ ਫੀਲਡਾਂ ਦਾ ਅਨੁਵਾਦ ਕਰਨ ਲਈ

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> **`ਵਾਪਸ ਚਲਾਓ`** ਉੱਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **`ਸੰਭਾਲੋ`** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ। ਜੇਕਰ ਬਿਨਾਂ ਸੰਭਾਲੇ ਬੈਕ ਕਰ ਜਾਓ, ਤਾਂ ਤੁਹਾਡੀਆਂ ਤਬਦੀਲੀਆਂ ਗਵਾਚ ਜਾਣਗੀਆਂ।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ਉਸ ਦੀ ਵਰਤੋਂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਪ੍ਰਾਮਟ ਦੀ ਪ੍ਰੀਖਿਆ ਕਰੋ

ਸੱਜੇ ਪਾਸੇ ਦਾ ਪ੍ਰੀਖਿਆ ਪੈਨਲ ਤੁਹਾਨੂੰ ਆਪਣੀ ਰੋਜ਼ਾਨਾ ਦੀ ਵਰਤੋਂ ਤੋਂ ਪਹਿਲਾਂ ਨਮੂਨਾ ਟੈਕਸਟ ਨਾਲ ਆਪਣੇ ਪ੍ਰਾਮਟ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

ਇਹ ਅਜਿਹੀਆਂ ਸਥਿਤੀਆਂ ਵਿੱਚ ਵਰਤੋਂਕਾਰੀ ਹੈ ਜਦੋਂ:

- ਤੁਸੀਂ ਇੱਕ ਨਵਾਂ ਪ੍ਰਾਮਟ ਬਣਾ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਦੋ ਪ੍ਰਾਮਟ ਦੇ ਸੰਸਕਰਣਾਂ ਦੀ ਤੁਲਨਾ ਕਰ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਟੋਨ, ਲੰਬਾਈ, ਜਾਂ ਆਉਟਪੁੱਟ ਫਾਰਮੈਟ ਦੀ ਜਾਂਚ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ

<br/>

<a id="manage-saved-prompts"></a>
### ਸੰਭਾਲੇ ਗਏ ਪ੍ਰਾਮਟ ਪਰਬੰਧਿਤ ਕਰੋ

ਸਾਰੇ ਸੰਭਾਲੇ ਗਏ ਪ੍ਰਾਮਟ ਇੱਕ ਸਥਾਨ ਤੇ ਪਰਬੰਧਿਤ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਟਰਾਂਸਫਾਰਮ ਪ੍ਰਾਮਟ**](#transform-prompts) ਖੋਲ੍ਹੋ।

ਉੱਥੇ ਤੁਸੀਂ:

- ਆਪਣੇ ਪ੍ਰਾਮਟਾਂ ਦੀ ਸੂਚੀ ਬਣਾ ਸਕਦੇ ਹੋ ਅਤੇ ਹਟਾ ਸਕਦੇ ਹੋ
- **JSON**, **CSV**, ਜਾਂ **XLSX** ਵਜੋਂ ਪ੍ਰਾਮਟ ਨੂੰ ਐਕਸਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ
- ਫਾਈਲ ਤੋਂ ਪ੍ਰਾਮਟ ਨੂੰ ਆਯਾਤ ਕਰ ਸਕਦੇ ਹੋ

<a id="dashboard-tabs"></a>
### ਡੈਸ਼ਬੋਰਡ ਟੈਬ

- **ਸਾਰਾਂਸ਼** ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ ਬਾਰੇ ਇੱਕ ਜਨਰਲ ਜਾਣਕਾਰੀ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।
- **ਵਰਤੋਂ ਅਨੁਸਾਰ** ਗਤੀਵਿਧੀ ਨੂੰ ਅਨੁਵਾਦ ਭਾਸ਼ਾ, ਰੀਵਰਾਈਟ ਮੋਡ ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਪ੍ਰਾਮਟ ਅਨੁਸਾਰ ਤੋੜਦਾ ਹੈ।
- **ਮਾਡਲ ਅਨੁਸਾਰ** ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਕਿਹੜੇ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀ ਕੀ ਲਾਗਤ ਆਈ।
- **ਦਿਨ ਅਨੁਸਾਰ** ਰੋਜ਼ਾਨਾ ਕੁੱਲ ਰਕਮ ਦਰਸਾਉਂਦਾ ਹੈ।
- **ਸਾਰੇ ਕਾਲ** ਪੂਰੀ ਕਾਲ ਇਤਿਹਾਸ ਦਿਖਾਉਂਦੇ ਹਨ ਅਤੇ ਤੁਹਾਨੂੰ ਇਸਨੂੰ ਐਕਸਪੋਰਟ ਕਰਨ ਦੀ ਇਜਾਜ਼ਤ ਦਿੰਦੇ ਹਨ।

<a id="export-data"></a>
### ਅੰਕੜਿਆਂ ਨੂੰ ਐਕਸਪੋਰਟ ਕਰੋ

<a id="delete-stored-records-for-a-model"></a>
### ਕਿਸੇ ਮਾਡਲ ਲਈ ਸਟੋਰ ਕੀਤੀਆਂ ਰਿਕਾਰਡਾਂ ਨੂੰ ਮਿਟਾਓ

**ਮਾਡਲ ਅਨੁਸਾਰ** ਜਾਂ **ਸਾਰੇ ਕਾਲਾਂ** ਵਿੱਚ, ਤੁਸੀਂ "ਕੂੜਾ ਦੀ ਡੱਬੇ" ਆਈਕਾਨ ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਕਿਸੇ ਮਾਡਲ ਲਈ ਸਟੋਰ ਕੀਤੀਆਂ ਰਿਕਾਰਡਾਂ ਨੂੰ ਹਟਾ ਸਕਦੇ ਹੋ।

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਸਟੋਰ ਕੀਤੀਆਂ ਰਿਕਾਰਡਾਂ ਨੂੰ ਮਿਟਾਉਣਾ ਉਲਟਾ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਕੇਵਲ ਇਸੇ ਕਰੋ ਜੇਕਰ ਤੁਸੀਂ ਯਕੀਨੀ ਹੋ ਕਿ ਤੁਹਾਨੂੰ ਉਸ ਇਤਿਹਾਸ ਦੀ ਹੁਣ ਜ਼ਰੂਰਤ ਨਹੀਂ।

ਸਾਰੇ ਡੇਟਾ ਨੂੰ ਮਿਟਾਉਣ ਜਾਂ ਉਮਰ ਅਨੁਸਾਰ ਰਿਕਾਰਡਾਂ ਨੂੰ ਹਟਾਉਣ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਤੇ ਜਾਓ। ਉੱਥੇ ਤੁਹਾਨੂੰ ਸਟੋਰ ਕੀਤਾ ਸਾਰਾ ਡੇਟਾ ਮਿਟਾਉਣ ਜਾਂ ਸਿਰਫ਼ ਇੱਕ ਖਾਸ ਮਿਤੀ ਤੋਂ ਪਹਿਲਾਂ ਦੇ ਡੇਟਾ ਨੂੰ ਹਟਾਉਣ ਦੇ ਵਿਕਲਪ ਮਿਲਣਗੇ।

<a id="general-settings"></a>

### ਜਨਰਲ ਸੈਟਿੰਗਾਂ

**ਜਨਰਲ ਸੈਟਿੰਗਾਂ** ਦੀ ਵਰਤੋਂ ਟਾਈਪਿੰਗ ਦੇ ਵਿਵਹਾਰ, **ਇਤਿਹਾਸ** ਲਈ ਚਲਾਉਣ ਦੇ ਵੇਰਵੇ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ ਜਾਂ ਨਹੀਂ, ਅਤੇ ਦਿੱਖ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ ਕਰੋ।

**ਵਿਵਹਾਰ**

- **ENTER ਲਈ ਵਿਵਹਾਰ** ਚੁਣਦਾ ਹੈ ਕਿ `Enter` ਕਾਰਜ ਨੂੰ ਚਲਾਉਂਦਾ ਹੈ ਜਾਂ ਨਵੀਂ ਲਾਈਨ ਦਰਜ ਕਰਦਾ ਹੈ।
- **ਪੇਸਟ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਸੀਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰਦੇ ਹੀ ਅਨੁਵਾਦ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- **ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਨਤੀਜਾ ਆਟੋ-ਕਾਪੀ** ਸਫਲ ਨਤੀਜਿਆਂ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪਿੰਗ ਦੌਰਾਨ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ।
- **ਟਾਈਮਆਊਟ (ms)** ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਲਈ ਉਡੀਕ ਸਮਾਂ ਸੈੱਟ ਕਰਦਾ ਹੈ।

**ਇਤਿਹਾਸ**

- **ਚਲਾਉਣ ਦਾ ਇਤਿਹਾਸ ਰੱਖੋ** ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ ਕਿ ਹਰੇਕ ਅਨੁਵਾਦ, ਰੀਆਈਟ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਸਾਈਡਬਾਰ [**ਇਤਿਹਾਸ**](#history) ਵਿਊ ਲਈ **ਇਨਪੁਟ ਅਤੇ ਆਉਟਪੁਟ ਟੈਕਸਟ** ਨੂੰ ਸੰਭਾਲਦਾ ਹੈ ਜਾਂ ਨਹੀਂ। ਇਸਨੂੰ ਬੰਦ ਕਰਨ 'ਤੇ ਪੁਸ਼ਟੀ ਲਈ ਕਿਹਾ ਜਾਵੇਗਾ; ਜੇ ਤੁਸੀਂ ਪੁਸ਼ਟੀ ਕਰਦੇ ਹੋ, ਤਾਂ ਸੰਭਾਲੇ ਗਏ ਇਤਿਹਾਸ ਟੈਕਸਟ ਡੇਟਾਬੇਸ ਤੋਂ ਹਟਾ ਦਿੱਤੇ ਜਾਣਗੇ।
- **ਇਤਿਹਾਸ ਡਾਟਾ ਹਟਾਓ** ਤੁਹਾਨੂੰ ਉਮਰ ਨਾਲ (ਉਦਾਹਰਣ ਲਈ ਕੁਝ ਮਹੀਨਿਆਂ ਤੋਂ ਪੁਰਾਣਾ, ਜਾਂ **ਸਾਰਾ ਡਾਟਾ (ਸਾਫ਼ ਕਰੋ)**) **ਡਾਟਾ ਹਟਾਓ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਸੰਭਾਲੇ ਗਏ ਟੈਕਸਟ ਨੂੰ ਹਟਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਇਹ ਕੇਵਲ **ਇਤਿਹਾਸ** ਵਿਊ ਲਈ ਸੰਭਾਲੇ ਗਏ ਚਲਾਉਣ ਵਾਲੇ ਟੈਕਸਟ ਨੂੰ ਪ੍ਰਭਾਵਿਤ ਕਰਦਾ ਹੈ; ਇਹ ਕੀਮਤ ਜਾਂ ਵਰਤੋਂ ਕੁੱਲ ਨੂੰ **ਨਹੀਂ** ਹਟਾਉਂਦਾ। **ਕੀਮਤ** ਡਾਟਾ ਨੂੰ ਹਟਾਉਣ ਜਾਂ ਕੱਟਣ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਕੀਮਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਦਿੱਖ**

- **ਕੀਮਤ ਫਰੈਕਸ਼ਨ ਅੰਕ** ਬਦਲਦਾ ਹੈ ਕਿ ਕੀਮਤ ਦਸ਼ਮਲਵ ਕਿਵੇਂ ਵੇਖਾਈ ਦਿੰਦੇ ਹਨ।
- **ਕੇਵਲ ਵੈੱਬ:** **ਐਪ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਮਾਰਜਿਨ ਵੇਖੋ** ਇੰਟਰਫੇਸ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਵਾਧੂ ਥਾਂ ਜੋੜਦਾ ਹੈ।
- **ਫਾਂਟ ਫੈਮਿਲੀ** ਟੈਕਸਟ ਪੈਨਲਾਂ ਵਿੱਚ ਲਿਖਣ ਵਾਲੇ ਫਾਂਟ ਨੂੰ ਬਦਲਦਾ ਹੈ।
- **ਸਾਈਜ਼** ਫਾਂਟ ਸਾਈਜ਼ ਨੂੰ ਬਦਲਦਾ ਹੈ।

<a id="models"></a>
### ਮਾਡਲ

ਟੂਲਬਾਰ ਵਿੱਚ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ, ਇਸਨੂੰ ਚੁਣਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਸੈਟਿੰਗਾਂ ਮਾਡਲ ਟੈਬ](../images/screenshots/pa/settings-models.png)

ਪੇਜ਼ ਵਿੱਚ ਦੋ ਸੂਚੀਆਂ ਹਨ:

- ਖੱਬੇ ਪਾਸੇ **ਉਪਲੱਬਧ ਮਾਡਲ**
- ਸੱਜੇ ਪਾਸੇ **ਚੁਣੇ ਗਏ ਮਾਡਲ**

ਇੱਥੇ ਕਈ ਉਪਯੋਗੀ ਨਿਯੰਤਰਣ ਸ਼ਾਮਲ ਹਨ:

- **ਮਾਡਲਾਂ ਨੂੰ ਖੋਜੋ...** ਨਾਮ ਨਾਲ ਮਾਡਲ ਲੱਭਣ ਲਈ
- ਲਿਸਟ ਨੂੰ ਇੱਕ ਇੰਜਣ (OpenRouter, OpenAI, Ollama, …) ਤੱਕ ਸੀਮਿਤ ਕਰਨ ਲਈ **ਪ੍ਰੋਵਾਈਡਰ** ਚਿੱਪਸ
- ਕੇਵਲ ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਦਿਖਾਉਣ ਲਈ **ਸਿਰਫ਼ ਮੁਫ਼ਤ**
- ਲਿਸਟ ਨੂੰ ਮੁੜ ਲੋਡ ਕਰਨ ਲਈ **ਰੀਫਰੈਸ਼**
- ਜਦੋਂ ਤੁਸੀਂ ਪ੍ਰੋਵਾਈਡਰ ਅਨੁਸਾਰ ਕ੍ਰਮਬੱਧ ਕਰ ਰਹੇ ਹੋਵੋ ਤਾਂ **ਸਾਰੇ ਵਿਸਤ੍ਰਿਤ ਕਰੋ** ਅਤੇ **ਸਾਰੇ ਸੰਖੇਪ ਕਰੋ**

ਮਾਡਲ ਆਈਡੀਆਂ ਵਿੱਚ ਪ੍ਰੋਵਾਈਡਰ ਪਰਤ (ਉਦਾਹਰਣ ਲਈ `openrouter/…` ਬਨਾਮ `openai/…`) ਸ਼ਾਮਲ ਹੈ। ਬੈਜ ਵਰਗੇ **OpenAI (OpenRouter)** ਬਨਾਮ **OpenAI (direct)** ਦਿਖਾਉਂਦੇ ਹਨ ਕਿ ਟ੍ਰੈਫਿਕ ਕਿਵੇਂ ਰੂਟ ਕੀਤਾ ਗਿਆ ਹੈ।

ਕਾਰਵਾਈਆਂ:

 - ਮਾਡਲ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, **ਸ਼ਾਮਲ ਕਰੋ** ਜਾਂ ਇੰਟਰੀ ਵਿੱਚ ਕਿਤੇ ਵੀ ਕਲਿੱਕ ਕਰੋ।

 - ਮਾਡਲ ਹਟਾਉਣ ਲਈ, **ਚੁਣੇ ਗਏ ਮਾਡਲ** ਵਿੱਚ ਇਸ ਦੇ ਨਾਲ **X** ਤੇ ਜਾਂ ਉਪਲਬਧ ਮਾਡਲਾਂ ਵਿੱਚ ਇੰਟਰੀ ਵਿੱਚ **ਚੁਣੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

 - ਸੂਚੀ ਨੂੰ ਸਾਫ਼ ਕਰਨ ਲਈ, **ਸਾਰੇ ਚੁਣੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਲੋੜੀਂਦਾ ਮੁਫਤ ਮਾਡਲ ਸੂਚੀ ਵਿੱਚ ਰਹੇਗਾ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਜੇ ਤੁਸੀਂ OpenRouter ਨੂੰ ਸਿੱਧੇ ਕ੍ਰੈਡਿਟ ਸ਼ਾਮਲ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ **ਸਿਰਫ਼ ਮੁਫਤ** ਨੂੰ ਚਾਲੂ ਕਰਨ ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਅਤੇ ਮੁਫਤ ਮਾਡਲ (ਕਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ) ਚੁਣੋ। ਤੁਸੀਂ ਕੋਈ API ਕੁੰਜੀ ਦਿੱਤੇ ਬਿਨਾਂ ਮਾਡਲ ਨੂੰ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚਲਾਉਣ ਲਈ Ollama ਦੀ ਵਰਤੋਂ ਵੀ ਕਰ ਸਕਦੇ ਹੋ।

### ਭਾਸ਼ਾਵਾਂ

ਐਪ ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਂਦੀਆਂ ਭਾਸ਼ਾਵਾਂ ਦੀਆਂ ਸੂਚੀਆਂ ਨੂੰ ਵਿਵਸਥਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਸਿਖਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** **ਅਨੁਵਾਦ** ਅਤੇ **ਟਰਾਂਸਫਾਰਮ** ਵਿੱਚ ਭਾਸ਼ਾ ਸੂਚੀ ਦੇ ਉੱਪਰ ਨੇੜੇ ਪਿੰਨ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- **ਕਸਟਮ ਭਾਸ਼ਾ** ਤੁਹਾਨੂੰ ਬਣਾਈਆਂ ਗਈਆਂ ਸੂਚੀ ਵਿੱਚ ਨਾ ਹੋਣ ਵਾਲੀ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦੀ ਹੈ।

ਜੇ ਤੁਸੀਂ ਕੋਈ ਕਸਟਮ ਭਾਸ਼ਾ ਜੋੜਦੇ ਹੋ, ਤਾਂ ਇਹ ਬਣਾਈਆਂ ਗਈਆਂ ਚੋਣਾਂ ਦੇ ਨਾਲ ਹੀ ਭਾਸ਼ਾ ਚੋਣਕਰਤਾਵਾਂ ਵਿੱਚ ਦਿਖਾਈ ਦੇਵੇਗੀ।

<br/>

<a id="cost-tracking"></a>
### ਕੀਮਤ ਟਰੈਕਿੰਗ

ਕੀਮਤ ਜਾਣਕਾਰੀ ਨੂੰ ਮੈਨੇਜ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਕੀਮਤ ਟਰੈਕਿੰਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਕੁੱਲ ਕੀਮਤ** ਚਲ ਰਹੇ ਕੁੱਲ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ।
- **ਕੀਮਤ ਨਕਲ** ਕੁੱਲ ਨੂੰ ਕਲਿੱਪਬੋਰਡ ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਕੀਮਤ ਰੀਸੈੱਟ ਕਰੋ** ਸੰਭਾਲੇ ਗਏ ਕੁੱਲ ਨੂੰ ਸਿਫ਼ਰ 'ਤੇ ਰੀਸੈੱਟ ਕਰਦਾ ਹੈ।
- **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ ਕਰੋ** ਕੁੱਲ ਨੂੰ ਤੁਹਾਡੇ OpenRouter ਖਾਤੇ ਵੱਲੋਂ ਉਪਲਬਧ ਵਰਤੋਂ ਨਾਲ ਮੇਲ ਕੇ ਸੈੱਟ ਕਰਦਾ ਹੈ (ਕੇਵਲ OpenRouter)।
- **API ਕੁੰਜੀ ਵਰਤੋਂ** ਉਪਲਬਧ ਹੋਣ 'ਤੇ OpenRouter ਵਰਤੋਂ ਦੇ ਵੇਰਵੇ ਵੇਖਾਉਂਦਾ ਹੈ।
- **ਕੀਮਤ ਡਾਟਾ ਹਟਾਓ** ਸਾਰਾ ਡਾਟਾ, ਜਾਂ ਸਿਰਫ਼ ਚੁਣੇ ਗਏ ਮਿਤੀ ਤੋਂ ਪੁਰਾਣੀਆਂ ਐਂਟਰੀਆਂ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ।


**ਕੀਮਤ ਟਰੈਕਿੰਗ:** ਜਦੋਂ ਤੁਸੀਂ OpenRouter ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ ਵਰਤੋਂ ਅਤੇ ਖਰਚ ਨੂੰ OpenRouter ਦੇ ਡੇਟਾ ਦੇ ਆਧਾਰ ‘ਤੇ ਵੇਖਾਉਂਦਾ ਹੈ। ਹੋਰ ਸਾਰੇ ਪ੍ਰੋਵਾਈਡਰਾਂ ਲਈ, ਐਪ OpenRouter ਵੱਲੋਂ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਮਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਕੀਮਤਾਂ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਂਦਾ ਹੈ, ਜੇ ਕੀਮਤ ਉਪਲਬਧ ਨਹੀਂ ਹੈ, ਤਾਂ ਅੰਦਾਜ਼ੇ ਸਿਫਰ ਹੋ ਸਕਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> **ਸਾਰੇ ਕੀਮਤ ਅੰਕ ਕੇਵਲ ਤੁਹਾਡੇ ਹਵਾਲੇ ਲਈ ਅੰਦਾਜ਼ੇ ਹਨ, ਅਧਿਕਾਰਤ ਬਿੱਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।**


<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਡਾਟਾ ਹਟਾਉਣਾ ਉਲਟ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਹਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ, ਆਪਣੇ ਡਾਟਾ ਨੂੰ ਬੈਕਅੱਪ ਕਰਨਾ ਜਾਂ [**ਡੈਸ਼ਬੋਰਡ** > **ਸਾਰੇ ਕਾਲ**](#dashboard-tabs) ਦੁਆਰਾ ਇਸਨੂੰ ਐਕਸਪੋਰਟ ਕਰਨਾ ਯਕੀਨੀ ਬਣਾਓ, ਨਹੀਂ ਤਾਂ ਇਹ ਸਥਾਈ ਤੌਰ 'ਤੇ ਖ਼ਤਮ ਹੋ ਜਾਵੇਗਾ।<br/> 
> ਹਰੇਕ API ਕਾਲ ਐਂਟਰੀ ਨਾਲ ਸਬੰਧਤ ਸਾਰਾ ਇਤਿਹਾਸ ਵੀ ਹਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।


<br/>

<a id="transform-prompts"></a>

### ਟਰਾਂਸਫਾਰਮ ਪ੍ਰਾਮਿਟ

**ਸੈਟਿੰਗਜ਼** > **ਟਰਾਂਸਫਾਰਮ ਪ੍ਰਾਮਿਟ** ਦੀ ਵਰਤੋਂ ਬਲਕ ਵਿੱਚ ਪ੍ਰਾਮਿਟਸ ਨੂੰ ਮੈਨੇਜ ਕਰਨ ਲਈ ਕਰੋ।

ਤੁਸੀਂ ਕਰ ਸਕਦੇ ਹੋ:

- ਆਪਣੇ ਸੇਵ ਕੀਤੇ ਪ੍ਰਾਮਿਟਸ ਨੂੰ ਦੁਬਾਰਾ ਵੇਖਣਾ
- ਪ੍ਰਾਮਿਟਸ ਨੂੰ ਮਿਟਾਉਣਾ
- ਫਾਈਲ ਤੋਂ ਪ੍ਰਾਮਿਟਸ ਨੂੰ ਇੰਪੋਰਟ ਕਰਨਾ
- ਬੈਕਅੱਪ ਜਾਂ ਸ਼ੇਅਰਿੰਗ ਲਈ ਪ੍ਰਾਮਿਟਸ ਨੂੰ ਐਕਸਪੋਰਟ ਕਰਨਾ

<br/>

<a id="users"></a>
### ਉਪਭੋਗਤਾ

**ਵੈੱਬ: ਸਿਰਫ਼ ਐਡਮਿਨ**

**ਉਪਯੋਗਕਰਤਾ** ਦੀ ਵਰਤੋਂ ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ ਉਪਭੋਗਤਾ ਅਕਾਊਂਟਸ ਨੂੰ ਮੈਨੇਜ ਕਰਨ ਲਈ ਕਰੋ। ਤੁਸੀਂ ਉਪਭੋਗਤਾ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹੋ, ਉਨ੍ਹਾਂ ਦੇ ਵੇਰਵੇ ਅਪਡੇਟ ਕਰ ਸਕਦੇ ਹੋ, ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ, ਅਤੇ ਅਕਾਊਂਟਸ ਨੂੰ ਮਿਟਾ ਸਕਦੇ ਹੋ।

<br/>

<a id="api-config"></a>
### API ਕਾਨਫ਼ੀਗ

ਸਮਰਥਿਤ ਪ੍ਰਦਾਤਾ ਹਨ: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, ਅਤੇ **Ollama** (ਬੇਸ URL ਰਾਹੀਂ ਸਥਾਨਕ ਮਾਡਲ)। ਤੁਹਾਨੂੰ ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰਨ ਦੀ ਲੋੜ ਹੈ ਜਿਹਨਾਂ ਦੀ ਤੁਸੀਂ ਵਰਤੋਂ ਕਰਦੇ ਹੋ।

**ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ: ਸਿਰਫ਼ ਐਡਮਿਨ**

API ਕੀਜ਼ ਨੂੰ ਸਿਸਟਮ ਜਾਂ ਡਾਕਰ (Docker) ਏਨਵਾਇਰਨਮੈਂਟ ਵੇਰੀਏਬਲਸ ਰਾਹੀਂ ਕਾਨਫਿਗਰ ਕੀਤਾ ਗਿਆ ਹੈ — ਉਹਨਾਂ ਨੂੰ ਵੈੱਬ UI ਵਿੱਚ ਦਰਜ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ। ਇਹ ਸਫ਼ਾ ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਕਿਹੜੇ ਪ੍ਰਦਾਤਾਵਾਂ ਲਈ ਕੀ ਨੂੰ ਕਾਨਫਿਗਰ ਕੀਤਾ ਗਿਆ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ **`ਟੈਸਟ`** ਬਟਨ ਨੂੰ ਕਲਿੱਕ ਕਰਕੇ ਹਰੇਕ ਨੂੰ ਟੈਸਟ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> API ਕੀ ਨੂੰ ਬਦਲਣ ਲਈ, ਆਪਣੇ ਸਿਸਟਮ ਜਾਂ ਡਾਕਰ ਕਾਨਫਿਗਰੇਸ਼ਨ ਵਿੱਚ ਏਨਵਾਇਰਨਮੈਂਟ ਵੇਰੀਏਬਲ ਨੂੰ ਅਪਡੇਟ ਕਰੋ ਅਤੇ ਸਰਵਰ ਜਾਂ ਕੰਟੇਨਰ ਨੂੰ ਮੁੜ ਚਾਲੂ ਕਰੋ।

<br/>

**ਡੈਸਕਟਾਪ ਐਪਲੀਕੇਸ਼ਨ**

ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਲਈ API ਕੀਜ਼ ਨੂੰ ਸਟੋਰ ਕਰਨ ਲਈ **API ਕਾਨਫ਼ੀਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ। Ollama ਲਈ, ਇੱਕ API ਕੀ ਦੀ ਬਜਾਏ **ਬੇਸ URL** ਦਰਜ ਕਰੋ।

<br/>

> 💡 **ਸੁਝਾਅ** <br/>
> ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ API ਕੀ ਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ ਜਾਂ ਵਰਤੋਂ ਲਈ ਭੁਗਤਾਨ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ [Ollama ਡਾਊਨਲੋਡ](https://ollama.com) ਅਤੇ ਆਪਣੇ ਮਸ਼ੀਨ 'ਤੇ ਸਥਾਨਕ ਮਾਡਲ ਮੁਫਤ ਵਿੱਚ ਚਲਾ ਸਕਦੇ ਹੋ। ਜਾਂ, ਉਹਨਾਂ ਦੇ ਮੁਫਤ ਮਾਡਲ ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ, ਤੁਸੀਂ ਇੱਕ ਮੁਫਤ OpenRouter ਅਕਾਊਂਟ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਲੋੜ ਨਹੀਂ) ਬਣਾ ਸਕਦੇ ਹੋ।

- ਕੇਵਲ ਉਹ ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ ਜਿਹੜੇ ਤੁਹਾਨੂੰ ਚਾਹੀਦੇ ਹਨ। **ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ** ਵਿੱਚ, ਹਰੇਕ ਮਾਡਲ ਆਈਡੀ ਪ੍ਰਦਾਤਾ ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦੀ ਹੈ (ਉਦਾਹਰਣ ਵਜੋਂ `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

API ਕੀ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, ਟੈਕਸਟ ਬਾਕਸ ਵਿੱਚ ਮੁੱਲ ਟਾਈਪ ਕਰੋ ਅਤੇ **`ਸੇਵ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਮੌਜੂਦਾ ਕੀ ਨੂੰ ਬਦਲਣ ਲਈ, **`ਐਡਿਟ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਹ ਪਤਾ ਲਗਾਉਣ ਲਈ ਕਿ ਕੀ ਇੱਕ ਕੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ, **`ਟੈਸਟ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ ਇੱਕ API ਕੀ ਦਾ ਵਰਤਮਾਨ ਮੁੱਲ ਨਹੀਂ ਵੇਖ ਸਕਦੇ। ਤੁਸੀਂ ਕੇਵਲ ਇਸਨੂੰ **`ਐਡਿਟ`** ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਬਦਲ ਸਕਦੇ ਹੋ।
> API ਕੀਜ਼ ਕਾਨਫ਼ੀਗ੍ਰੇਸ਼ਨ ਫਾਈਲ ਵਿੱਚ ਖੰਡਿਤ (encrypted) ਸਟੋਰ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।

<br/>

ਇੱਕ OpenRouter ਕੀ ਪ੍ਰਾਪਤ ਕਰਨ ਬਾਰੇ ਵੇਰਵਾ ਕਦਮਾਂ ਲਈ, ਉੱਪਰ [ਇੱਕ API ਕੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੇ](#how-to-get-an-api-key-desktop-app) ਦੇਖੋ।

<a id="common-issues"></a>
## ਆਮ ਮੁੱਦੇ

ਜੇਕਰ ਕੁਝ ਉਮੀਦ ਮੁਤਾਬਿਕ ਕੰਮ ਨਾ ਕਰੇ, ਤਾਂ ਪਹਿਲਾਂ ਹੇਠ ਲਿਖੇ ਬਿੰਦੂਆਂ ਨੂੰ ਜਾਂਚੋ।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ਐਪਲੀਕੇਸ਼ਨ ਟੈਕਸਟ ਨੂੰ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖ ਜਾਂ ਟਰਾਂਸਫਾਰਮ ਨਹੀਂ ਕਰੇਗੀ

ਜਾਂਚੋ ਕਿ:

- ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣਿਆ ਹੈ
- ਘੱਟੋ ਘੱਟ ਇੱਕ ਮਾਡਲ [**ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ**](#models) ਵਿੱਚ ਸੂਚੀਬੱਧ ਹੈ
- ਤੁਹਾਡੀ API ਸਥਾਪਨਾ ਕੰਮ ਕਰ ਰਹੀ ਹੈ

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ:

1. [**ਸੈਟਿੰਗਜ਼** > **API ਕਾਨਫ਼ੀਗ**](#api-config) ਖੋਲ੍ਹੋ।
2. ਜਾਂਚੋ ਕਿ ਘੱਟੋ ਘੱਟ ਇੱਕ API ਕੀ ਸੇਵ ਕੀਤੀ ਗਈ ਹੈ।
3. ਪੁਸਤਕ ਨੇੜੇ **ਟੈਸਟ** 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।

<br/>

<a id="the-model-list-is-empty"></a>
### ਮਾਡਲ ਸੂਚੀ ਖਾਲੀ ਹੈ

[**ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਰੀਫਰੇਸ਼** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਜੇ ਲੋੜ ਹੋਵੇ:

- ਇੱਕ ਮਾਡਲ ਲਈ ਖੋਜੋ
- **ਸਿਰਫ਼ ਮੁਫਤ** ਚਾਲੂ ਕਰੋ
- **ਚੁਣੇ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ਨਤੀਜਾ ਬਹੁਤ ਹੌਲੀ ਜਾਂ ਬਹੁਤ ਮਹਿੰਗਾ ਹੈ

ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਜਾਂ ਵੱਧ ਦੀ ਵਰਤੋਂ ਕਰੋ:

- ਇੱਕ ਵੱਖਰਾ ਮਾਡਲ ਚੁਣੋ
- ਛੋਟੀ ਇਨਪੁਟ ਦੀ ਵਰਤੋਂ ਕਰੋ
- [**ਸੈਟਿੰਗਜ਼** > **ਜਨਰਲ ਸੈਟਿੰਗਜ਼**](#general-settings) ਵਿੱਚ **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪਿੰਗ ਵੇਲੇ)** ਨੂੰ ਬੰਦ ਕਰੋ
- ਸਧਾਰਣ ਕੰਮਾਂ ਲਈ ਮੁਫਤ ਮਾਡਲ ਦੀ ਵਰਤੋਂ ਕਰੋ (ਵੇਖੋ [ਮਾਡਲ](#models))

<a id="the-interface-is-in-the-wrong-language"></a>
### ਇੰਟਰਫੇਸ ਗਲਤ ਭਾਸ਼ਾ ਵਿੱਚ ਹੈ

[ਟੂਲਬਾਰ](#toolbar) ਵਿੱਚ ਗਲੋਬ ਆਈਕਾਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਆਪਣੀ ਪਸੰਦੀਦਾ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ਟੈਕਸਟ ਬਹੁਤ ਛੋਟਾ ਜਾਂ ਪੜ੍ਹਨ ਲਈ ਮੁਸ਼ਕਲ ਹੈ

[**ਸੈਟਿੰਗਜ਼** > **ਜਨਰਲ ਸੈਟਿੰਗਜ਼**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਬਦਲੋ:

- **ਫਾਂਟ ਪਰਿਵਾਰ**
- **ਆਕਾਰ**

<a id="dashboard-charts-are-empty"></a>
### ਡੈਸ਼ਬੋਰਡ ਚਾਰਟ ਖਾਲੀ ਹਨ

ਇਹ ਸਾਧਾਰਨ ਹੈ ਜੇ:

- ਤੁਸੀਂ ਕੇਵਲ **ਮੁਫਤ ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ (ਖਰਚ ਚਾਰਟ ਖਾਲੀ ਹੋਣਗੇ)
- ਚੁਣਿਆ ਗਿਆ **ਸਮਾਂ ਫਿਲਟਰ** ਉਸ ਸਮੇਂ ਲਈ ਨਹੀਂ ਹੈ ਜਦੋਂ ਕਾਲਾਂ ਲਗਾਈਆਂ ਗਈਆਂ ਸਨ — ਜਾਂਚ ਲਈ **ਸਭ** ਦੀ ਵਰਤੋਂ ਕਰੋ

ਜੇ ਚਾਰਟਾਂ ਨੂੰ **ਸਭ** ਚੁਣਨ ਤੋਂ ਬਾਅਦ ਵੀ ਖਾਲੀ ਰਹਿੰਦੇ ਹਨ, ਤਾਂ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕਾਲਾਂ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ **ਸਾਰੀਆਂ ਕਾਲਾਂ** ਟੈਬ ਵਿੱਚ ਦਿਖਾਈ ਦੇ ਰਹੀਆਂ ਹਨ।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### ਕੀਮਤ “ਉਪਲਬਧ ਨਹੀਂ” ਵਜੋਂ ਦਿਖਾਈ ਦਿੰਦੀ ਹੈ ਜਾਂ ਗਲਤ ਲੱਗਦੀ ਹੈ

ਜਦੋਂ ਤੁਸੀਂ **OpenRouter** ਰਾਹੀਂ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ OpenRouter ਵੱਲੋਂ ਰਿਪੋਰਟ ਕੀਤੀ ਗਈ ਅਸਲ ਖਰਚ ਵੋਖਲਾਉਂਦੀ ਹੈ।

**ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ** (ਸਿੱਧੇ OpenAI, ਸਿੱਧੇ Anthropic, ਆਦਿ) ਲਈ, ਕੀਮਤ ਨੂੰ OpenRouter ਵੱਲੋਂ ਪ੍ਰਕਾਸ਼ਤ ਕੀਮਤ ਦੇ ਅੰਕੜਿਆਂ ਤੋਂ ਅਨੁਮਾਨਿਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਜੇ ਕਿਸੇ ਮਾਡਲ ਲਈ ਮੇਲ ਖਾਂਦੀ ਕੀਮਤ ਨਹੀਂ ਮਿਲਦੀ, ਤਾਂ ਕੀਮਤ **ਉਪਲਬਧ ਨਹੀਂ** ਦੇ ਤੌਰ 'ਤੇ ਦਿਖਾਈ ਦੇਵੇਗੀ ਅਤੇ ਤੁਹਾਡੀ ਜਾਰੀ ਕੁੱਲ ਰਕਮ ਵਿੱਚ ਸ਼ਾਮਲ ਨਹੀਂ ਕੀਤੀ ਜਾਵੇਗੀ।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ਕੁੱਲ ਕੀਮਤ ਮੇਰੇ ਪ੍ਰਦਾਤਾ ਬਿੱਲ ਨਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੀ

ਐਪ ਵਿੱਚ ਸਾਰੇ ਖਰਚ ਅੰਕੜੇ **ਸਿਰਫ਼ ਹਵਾਲਾ ਲੈਣ ਲਈ ਅਨੁਮਾਨ** ਹਨ, ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਸਟੇਟਮੈਂਟ ਨਹੀਂ।

ਕੁੱਲ ਰਾਸ਼ੀ ਨੂੰ ਤੁਹਾਡੇ ਅਸਲ OpenRouter ਖਰਚ ਦੇ ਨੇੜੇ ਲਿਆਉਣ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਕੀਮਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਖੋਲ੍ਹੋ ਅਤੇ **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਮਕਾਲੀਕਰਣ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### ਸਾਈਡਬਾਰ ਵਿੱਚੋਂ ਹਿਸਟਰੀ ਪੇਜ਼ ਗੁੰਮ ਗਿਆ ਹੈ

**ਚੱਲ ਰਹੀ ਹਿਸਟਰੀ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖੋ** ਬੰਦ ਹੋ ਸਕਦਾ ਹੈ। [**ਸੈਟਿੰਗਾਂ** > **ਜਨਰਲ ਸੈਟਿੰਗਾਂ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਇਸ ਨੂੰ ਚਾਲੂ ਕਰੋ। ਨੋਟ ਕਰੋ ਕਿ ਇਸ ਨੂੰ ਚਾਲੂ ਕਰਨ ਨਾਲ ਪਹਿਲਾਂ ਮਿਟਾਏ ਗਏ ਇਤਿਹਾਸ ਅੰਕੜੇ ਮੁੜ-ਪ੍ਰਾਪਤ ਨਹੀਂ ਹੋਣਗੇ।

<br/>

<a id="web-app-session-expired"></a>
### ਵੈੱਬ ਐਪ: ਲੌਗਇਨ ਪੇਜ 'ਤੇ ਅਣਚਾਹੇ ਤੌਰ 'ਤੇ ਰੀਡਾਇਰੈਕਟ ਕੀਤਾ ਗਿਆ

ਤੁਹਾਡਾ ਸੈਸ਼ਨ ਸਮਾਂ-ਸੀਮਾ ਵਿੱਚ ਖਤਮ ਹੋ ਸਕਦਾ ਹੈ। ਮੁੜ ਲੌਗਇਨ ਕਰੋ। ਜੇ ਇਹ ਲਗਾਤਾਰ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਸਰਵਰ ਕੰਫਿਗਰੇਸ਼ਨ ਵਿੱਚ ਸੈਸ਼ਨ ਜੀਵਨ-ਕਾਲ ਸੈਟਿੰਗਸ ਲਈ ਜਾਂਚ ਕਰੋ।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ਡੈਸ਼ਬੋਰਡ (ਵੈੱਬ) ਵਿੱਚ ਹੋਰ ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਦਿਖਾ ਰਿਹਾ

ਸਿਰਫ਼ **ਪ੍ਰਸ਼ਾਸਕ** **ਯੂਜ਼ਰ** ਫਿਲਟਰ ਰਾਹੀਂ ਸਾਰੇ ਵਰਤੋਂਕਾਰਾਂ ਦੇ ਡਾਟੇ ਨੂੰ ਵੇਖ ਸਕਦੇ ਹਨ। ਸਾਮਾਨ ਵਰਤੋਂਕਾਰ ਕੇਵਲ ਆਪਣੀ ਕਿਰਿਆਸ਼ੀਲਤਾ ਨੂੰ ਡਿਜ਼ਾਇਨ ਮੁਤਾਬਕ ਵੇਖਦੇ ਹਨ।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ਮੈਨੂੰ ਕੋਈ ਪ੍ਰਾਮਟ ਤਬਦੀਲ ਕਰਕੇ ਸੋਧਾਂ ਗੁੰਮ ਗਈਆਂ

ਜਦੋਂ ਕੋਈ ਪ੍ਰਾਮਟ ਸੋਧਦੇ ਹੋ, ਹਮੇਸ਼ਾ **ਰਨ ਲਈ ਵਾਪਸ** 'ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **ਸੇਵ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="quick-tips"></a>
## ਤੇਜ਼ ਟਿਪਸ

- [**ਟਰਾਂਸਲੇਟ**](#translate) ਨਾਲ ਸ਼ੁਰੂਆਤ ਕਰੋ ਤਾਂ ਜੋ ਆਪਣੀ ਸੈਟਅੱਪ ਜਾਂਚ ਲਵੋ ਕਿ ਇਹ ਕੰਮ ਕਰਦੀ ਹੈ, ਇਸ ਤੋਂ ਬਾਅਦ [**ਰੀਆਰਾਈਟ**](#rewrite) ਜਾਂ [**ਟਰਾਂਸਫਾਰਮ**](#transform) ਵੱਲ ਜਾਓ।
- [**ਰੀਆਰਾਈਟ**](#rewrite) ਦੀ ਵਰਤੋਂ ਰੋਜ਼ਾਨਾ ਸ਼ਬਦਾਵਲੀ ਸੁਧਾਰਾਂ ਲਈ ਕਰੋ।
- [**ਟਰਾਂਸਫਾਰਮ**](#transform) ਦੀ ਵਰਤੋਂ ਤਾਂ ਕਰੋ ਜਦੋਂ ਤੁਹਾਨੂੰ ਕਿਸੇ ਖਾਸ ਕੰਮ ਲਈ ਮੁੜ-ਵਰਤੇ ਜਾ ਸਕਣ ਵਾਲਾ ਵਰਕਫਲੋ ਚਾਹੀਦਾ ਹੋਵੇ।
- ਵਰਤੋਂ ਅਤੇ ਕੀਮਤ ਉੱਤੇ ਨਜ਼ਰ ਰੱਖਣ ਲਈ [**ਡੈਸ਼ਬੋਰਡ**](#dashboard) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਪਿਛਲੀਆਂ ਕਿਰਿਆਵਾਂ ਅਤੇ ਉਹਨਾਂ ਦੇ ਪੂਰੇ ਇੰਪੁੱਟ/ਆਉਟਪੁੱਟ ਟੈਕਸਟ ਨੂੰ ਜਾਂਚਣ ਲਈ [**ਇਤਿਹਾਸ**](#history) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇ ਤੁਸੀਂ ਇੱਕ ਅਜਿਹੀ ਪ੍ਰਾਮਟ ਲਾਇਬਰੇਰੀ ਬਣਾ ਰਹੇ ਹੋ ਜਿਸਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ (ਵੇਖੋ [Transform Prompts](#transform-prompts)) ਜਾਂ ਇਸਨੂੰ ਹੋਰਾਂ ਨਾਲ ਸਾਂਝਾ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਨਿਯਮਤ ਤੌਰ 'ਤੇ ਪ੍ਰਾਮਟਾਂ ਨੂੰ ਐਕਸਪੋਰਟ ਕਰੋ।
