# ਯੂਜ਼ਰ ਗਾਈਡ

<br/>

<a id="introduction"></a>
## ਪਰਿਚੈ

Transrewrt ਤੁਹਾਨੂੰ ਤਿੰਨ ਮੁੱਖ ਤਰੀਕਿਆਂ ਨਾਲ ਟੈਕਸਟ ਨਾਲ ਕੰਮ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ:

- **ਅਨੁਵਾਦ ਕਰੋ** - ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਨੂੰ ਬਦਲੋ।
- **ਮੁੜ-ਲਿਖਤ** - ਟੈਕਸਟ ਨੂੰ ਵੱਖਰੀ ਸ਼ੈਲੀ ਵਿੱਚ ਮੁੜ ਲਿਖੋ, ਜਿਵੇਂ ਕਿ ਸਪਸ਼ਟ, ਛੋਟਾ ਜਾਂ ਹੋਰ ਔਪਚਾਰਿਕ।
- **ਟ੍ਰਾਂਸਫਾਰਮ** - ਪ੍ਰਾਮਿਟਾਂ ਕਹੇ ਜਾਂਦੇ ਕਸਟਮ ਏਆਈ ਹਿਦਾਇਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਟੈਕਸਟ ਨੂੰ ਪ੍ਰੋਸੈਸ ਕਰੋ।

<br/>

ਇਹ ਗਾਈਡ ਸਮਝਾਉਂਦੀ ਹੈ ਕਿ ਐਪ ਨੂੰ ਇੰਸਟਾਲ ਅਤੇ ਚਲਾਉਣ ਤੋਂ ਬਾਅਦ ਇਸਦੀ ਵਰਤੋਂ ਕਿਵੇਂ ਕਰਨੀ ਹੈ। ਇੰਸਟਾਲੇਸ਼ਨ ਕਦਮਾਂ ਲਈ, ਮੁੱਖ **[README](README.pa.md)** ਵੇਖੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> Transrewrt ਵਿੰਡੋਜ਼ ਅਤੇ ਲੀਨਕਸ ਲਈ ਡੈਸਕਟਾਪ ਐਪ ਵਜੋਂ ਅਤੇ ਸਵੈ-ਹੋਸਟ ਕੀਤੀ ਵੈੱਬ ਐਪ ਵਜੋਂ ਉਪਲਬਧ ਹੈ। ਇਹ ਗਾਈਡ ਐਪ ਦੀ ਰੋਜ਼ਾਨਾ ਵਰਤੋਂ 'ਤੇ ਕੇਂਦਰਤ ਹੈ। ਜਿੱਥੇ ਕੁਝ ਸਿਰਫ਼ ਇੱਕ ਵਰਜਨ ਲਈ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਉੱਥੇ ਇਸਨੂੰ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਚਿੰਨ੍ਹਿਤ ਕੀਤਾ ਗਿਆ ਹੈ।

<a id="before-you-start"></a>
## ਸ਼ੁਰੂਆਤ ਤੋਂ ਪਹਿਲਾਂ

Transrewrt ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ, ਤੁਹਾਨੂੰ ਘੱਟੋ-ਘੱਟ ਇੱਕ AI ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚ ਦੀ ਲੋੜ ਹੈ। ਸਮਰਥਤ ਪ੍ਰਦਾਤਾ ਹਨ: [OpenRouter](https://openrouter.ai) (ਜੋ ਕਿ ਬਹੁਤ ਸਾਰੇ ਮਾਡਲਾਂ ਨੂੰ ਇਕੱਠਾ ਕਰਦਾ ਹੈ), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਲਈ [Ollama](https://ollama.com)।

ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਤੁਹਾਨੂੰ ਭੁਗਤਾਨਯੋਗ ਮਾਡਲ ਚੁਣਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਆਪਣੀ OpenRouter API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਐਪ ਆਪਣੇ ਆਪ ਇੱਕ ਅੰਦਰੂਨੀ **ਮੁਫ਼ਤ** OpenRouter ਵਿਕਲਪ ਨੂੰ ਸਮਰੱਥ ਕਰ ਦਿੰਦਾ ਹੈ। ਇਸ ਨਾਲ ਤੁਸੀਂ ਤੁਰੰਤ ਟੈਕਸਟ ਦਾ ਅਨੁਵਾਦ, ਪੁਨਰ-ਲੇਖਨ ਅਤੇ ਰੂਪਾੰਤਰਣ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ। ਵਿਕਲਪਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ Cerebras, Google, Groq, ਜਾਂ Mistral AI ਤੋਂ ਮੁਫ਼ਤ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦੇ ਹੋ।

ਸਧਾਰਨ ਭਾਸ਼ਾ ਵਿੱਚ:

- ਇੱਕ **ਮਾਡਲ** AI ਇੰਜਣ ਹੈ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ। ਮਾਡਲਾਂ ਨੂੰ **ਪ੍ਰਦਾਤਾ ਉਪਸਰਗ** ਨਾਲ ਸੂਚੀਬੱਧ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `openrouter/…`, `openai/…`, `ollama/…`)।
- ਇੱਕ **API ਕੁੰਜੀ** (ਜਾਂ, Ollama ਲਈ, ਇੱਕ **ਬੇਸ URL**) ਉਹ ਤਰੀਕਾ ਹੈ ਜਿਸ ਨਾਲ ਐਪ ਉਸ ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚਦਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਲਈ [**ਸੈਟਿੰਗਾਂ** > **API ਸੰਰਚਨਾ**](#api-config) ਵਿੱਚ ਕੁੰਜੀਆਂ ਸ਼ਾਮਲ ਕਰੋ। ਕੇਵਲ OpenRouter ਦੀ ਵਰਤੋਂ ਲਈ, ਹੇਠਾਂ [ਇੱਕ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰਨ ਦਾ ਤਰੀਕਾ](#how-to-get-an-api-key-desktop-app) ਵੇਖੋ। ਜੇਕਰ ਤੁਸੀਂ API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ Ollama (https://ollama.com ਤੋਂ [ollama.com]) ਸਥਾਪਤ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ `translategemma:4b` ਵਰਗੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।

ਜੇਕਰ ਤੁਸੀਂ **ਵੈੱਬ ਵਰਜਨ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਸਰਵਰ ਮਾਲਕ ਵਾਤਾਵਰਣ ਚਲਾਂ ਨਾਲ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਐਪਲੀਕੇਸ਼ਨ ਵਿੱਚ ਸਿੱਧੇ API ਕੁੰਜੀਆਂ ਦਰਜ ਨਹੀਂ ਕਰ ਸਕਦੇ।

<a id="how-to-get-an-api-key-desktop-app"></a>
### ਮੁਫ਼ਤ OpenRouter API ਕੁੰਜੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰਨੀ ਹੈ (ਡੈਸਕਟਾਪ ਐਪ)

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਇਹ ਕਦਮ ਅਨੁਸਰਣ ਕਰੋ:

1. ਆਪਣੇ ਵੈੱਬ ਬਰਾਊਜ਼ਰ ਵਿੱਚ [OpenRouter](https://openrouter.ai) ਨੂੰ ਖੋਲ੍ਹੋ।
2. ਇੱਕ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਸਾਈਨ ਇਨ ਕਰੋ।
3. [ਕੁੰਜੀਆਂ](https://openrouter.ai/keys) ਸਫ਼ੇ ਨੂੰ ਖੋਲ੍ਹੋ।
4. ਇੱਕ ਨਵੀਂ API ਕੁੰਜੀ ਬਣਾਉਣ ਲਈ ਬਟਨ ਤੇ ਕਲਿੱਕ ਕਰੋ।
5. ਕੁੰਜੀ ਨੂੰ ਇੱਕ ਨਾਮ ਦਿਓ ਤਾਂ ਜੋ ਤੁਸੀਂ ਇਸਨੂੰ ਬਾਅਦ ਵਿੱਚ ਪਛਾਣ ਸਕੋ।
6. ਨਵੀਂ API ਕੁੰਜੀ ਨੂੰ ਕਾਪੀ ਕਰੋ।
7. Transrewrt ਵਾਪਸ ਜਾਓ ਅਤੇ **ਸੈਟਿੰਗਾਂ** > **API ਕਾਨਫਿਗ** ਖੋਲ੍ਹੋ।
8. ਕੁੰਜੀ ਨੂੰ **OpenRouter API ਕੁੰਜੀ** ਵਿੱਚ ਪੇਸਟ ਕਰੋ (**ਸੈਟਿੰਗਾਂ** > **API ਕਾਨਫਿਗ** ਹੇਠ)।
9. ਇਹ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ ਕਿ ਇਹ ਕੰਮ ਕਰਦੀ ਹੈ, **OpenRouter ਕੁੰਜੀ ਦੀ ਜਾਂਚ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="getting-started"></a>
## ਸ਼ੁਰੂਆਤ

ਜੇਕਰ ਇਹ ਤੁਹਾਡੀ Transrewrt ਦੀ ਪਹਿਲੀ ਵਰਤੋਂ ਹੈ, ਤਾਂ ਇਸ ਕ੍ਰਮ ਨੂੰ ਅਨੁਸਰਣ ਕਰੋ:

1. ਐਪ ਨੂੰ ਖੋਲ੍ਹੋ।
2. ਲੋੜ ਪੈਣ 'ਤੇ ਗਲੋਬ ਆਈਕਨ ਤੋਂ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।
3. ਜੇਕਰ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** 'ਤੇ ਹੋ, ਤਾਂ [**ਸੈਟਿੰਗਾਂ** > **API ਕਾਨਫਿਗ**](#api-config) ਖੋਲ੍ਹੋ, ਘੱਟੋ-ਘੱਟ ਇੱਕ ਪ੍ਰਦਾਤਾ (ਉਦਾਹਰਣ ਲਈ OpenRouter) ਲਈ API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰੋ, ਅਤੇ ਇਹ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ **ਜਾਂਚ** ਤੇ ਕਲਿੱਕ ਕਰੋ ਕਿ ਇਹ ਕੰਮ ਕਰਦੀ ਹੈ।
4. [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਚੁਣੇ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ।
5. [**ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਖੋਲ੍ਹੋ ਅਤੇ ਜੇਕਰ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ ਤੁਹਾਡੀਆਂ ਸਭ ਤੋਂ ਵੱਧ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਭਾਸ਼ਾਵਾਂ ਪਹਿਲਾਂ ਦਿਖਾਈ ਦੇਣ, ਤਾਂ **ਸਿਖਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** ਚੁਣੋ।
6. **ਅਨੁਵਾਦ** ਤੇ ਜਾਓ ਅਤੇ ਸਭ ਕੁਝ ਕੰਮ ਕਰ ਰਿਹਾ ਹੈ, ਇਹ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਇੱਕ ਸਧਾਰਨ ਅਨੁਵਾਦ ਚਲਾਓ।
7. ਇਕ ਵਾਰ ਜਦੋਂ ਇਹ ਕੰਮ ਕਰ ਜਾਂਦਾ ਹੈ, ਤਾਂ **ਦੁਬਾਰਾ ਲਿਖੋ** ਅਤੇ ਫਿਰ **ਤਬਦੀਲ ਕਰੋ** ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

ਇਸ ਕ੍ਰਮ ਦਾ ਮਹੱਤਵ ਹੈ। ਇਹ ਪਹਿਲੀ ਵਰਤੋਂ ਦੀ ਸਭ ਤੋਂ ਆਮ ਸਮੱਸਿਆ ਨੂੰ ਰੋਕਦਾ ਹੈ: ਐਪ ਵਿੱਚ ਕੰਮ ਕਰ ਰਹੇ API ਕਨੈਕਸ਼ਨ ਜਾਂ ਚੁਣੇ ਹੋਏ ਮਾਡਲ ਤੋਂ ਪਹਿਲਾਂ ਕੰਮ ਨੂੰ ਚਲਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨਾ।

### ਟੂਲਬਾਰ

ਟੂਲਬਾਰ ਥੋੜ੍ਹਾ ਬਹੁਤ ਬਦਲ ਜਾਂਦਾ ਹੈ ਜਿੱਥੇ ਵੀ ਤੁਸੀਂ ਐਪ ਵਿੱਚ ਹੋਵੋ।

- ਖੱਬੇ ਪਾਸੇ, ਇਹ ਮੌਜੂਦਾ ਪੇਜ ਨਾਮ ਦਿਖਾਉਂਦਾ ਹੈ।
- ਸੱਜੇ ਪਾਸੇ, ਇਹ **ਮਾਡਲ ਚੋਣਕਰਤਾ** ਅਤੇ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਵਾਲਾ ਵਿਕਲਪ ਦਿਖਾਉਂਦਾ ਹੈ।

**ਮਾਡਲ ਚੋਣਕਰਤਾ** ਤੁਹਾਨੂੰ ਮੌਜੂਦਾ ਕੰਮ ਲਈ ਕਿਹੜੇ ਏਆਈ ਇੰਜਣ ਦੀ ਵਰਤੋਂ ਕਰਨੀ ਹੈ, ਇਹ ਚੁਣਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

![Model selector](../images/screenshots/pa/model-selector.png)

ਕੁਝ ਮੁਫ਼ਤ ਮਾਡਲ ਹਮੇਸ਼ਾ ਉਪਲਬਧ ਨਹੀਂ ਹੁੰਦੇ - ਕਦੇ-ਕਦੇ ਉਹ ਆਫਲਾਈਨ ਹੁੰਦੇ ਹਨ ਜਾਂ ਉਨ੍ਹਾਂ ਦੀ ਵਰਤੋਂ ਦੀ ਸੀਮਾ ਹੁੰਦੀ ਹੈ। ਜੇਕਰ ਇਹ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਐਪ ਆਪਣੇ ਆਪ ਉਸ ਮਾਡਲ ਨੂੰ ਤੁਹਾਡੀ ਉਪਲਬਧ ਸੂਚੀ ਵਿੱਚੋਂ ਹਟਾ ਦੇਵੇਗਾ। ਇਹ ਕੰਟਰੋਲ ਕਰਨ ਲਈ ਕਿ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦੇਣ, [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਵਿੱਚ ਜਾਓ ਅਤੇ ਆਪਣੀ ਮਾਡਲ ਸੂਚੀ ਨੂੰ ਸੋਧੋ।
ਤੁਸੀਂ ਸਿੱਧੇ ਟੂਲਬਾਰ ਵਿੱਚ ਮਾਡਲ ਨਾਮ ਦੇ ਖੱਬੇ ਪਾਸੇ ਪ੍ਰਦਾਤਾ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਮਾਡਲ ਸੈਟਿੰਗਾਂ ਨੂੰ ਵੀ ਖੋਲ੍ਹ ਸਕਦੇ ਹੋ।

<br/>

**ਗਲੋਬ ਆਈਕਨ + ਭਾਸ਼ਾ ਕੋਡ** ਐਪ ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ ਨੂੰ ਬਦਲਦਾ ਹੈ, ਜਿਵੇਂ ਕਿ ਮੇਨੂ ਅਤੇ ਬਟਨ। ਇਹ **ਅਨੁਵਾਦ ਕਰੋ** ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਅਨੁਵਾਦ ਭਾਸ਼ਾਵਾਂ ਨੂੰ **ਨਹੀਂ** ਬਦਲਦਾ।

<a id="input-and-output-panels"></a>
### ਇਨਪੁੱਟ ਅਤੇ ਆਉਟਪੁੱਟ ਪੈਨਲ

ਆਮ ਤੌਰ 'ਤੇ ਕਈ ਕੰਮ ਦੀਆਂ ਥਾਵਾਂ ਵਿੱਚ ਖੱਬੇ ਪਾਸੇ **ਇਨਪੁੱਟ** ਪੈਨਲ ਅਤੇ ਸੱਜੇ ਪਾਸੇ **ਆਉਟਪੁੱਟ** ਪੈਨਲ ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

ਹਰੇਕ ਪੈਨਲ ਵਿੱਚ ਹੇਠ ਲਿਖਿਆਂ ਨੂੰ ਵੀ ਦਰਸਾਇਆ ਗਿਆ ਹੈ:

| **ਇਨਪੁੱਟ**                                                          | **ਆਉਟਪੁੱਟ**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - ਅੱਖਰ ਗਿਣਤੀ <br/>- ਸ਼ਬਦ ਗਿਣਤੀ <br/>- ਪੈਰੇ ਦੀ ਗਿਣਤੀ   <br/> | - ਕੰਮ ਨੂੰ ਪੂਰਾ ਕਰਨ ਵਿੱਚ ਲੱਗਿਆ ਸਮਾਂ<br/>- **TPS** (ਪ੍ਰਤੀ ਸਕਿੰਟ ਟੋਕਨ)<br/>- ਅੱਖਰ, ਸ਼ਬਦ, ਅਤੇ ਪੈਰੇ ਦੀ ਗਿਣਤੀ<br/>- ਵਰਤਿਆ ਗਿਆ ਮਾਡਲ |

ਜੇਕਰ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦਾਂ ਬਾਰੇ ਸੋਚ ਰਹੇ ਹੋ:

- **ਟੋਕਨ** ਦਾ ਅਰਥ ਹੈ ਪਾਠ ਦਾ ਇੱਕ ਛੋਟਾ ਟੁਕੜਾ। ਤੁਸੀਂ ਇਸਨੂੰ ਇੱਕ ਸ਼ਬਦ ਦਾ ਹਿੱਸਾ ਜਾਂ ਇੱਕ ਛੋਟਾ ਸ਼ਬਦ ਸਮਝ ਸਕਦੇ ਹੋ।
- **TPS** ਦਾ ਅਰਥ ਹੈ ਕਿ ਮਾਡਲ ਨੇ ਹਰੇਕ ਸਕਿੰਟ ਵਿੱਚ ਇਹਨਾਂ ਪਾਠ ਦੇ ਟੁਕੜਿਆਂ ਵਿੱਚੋਂ ਕਿੰਨੇ ਪ੍ਰਕਿਰਿਆ ਕੀਤੇ।

<br/>

ਤੁਸੀਂ ਹਰੇਕ ਕਾਰਵਾਈ ਦੀ ਲਾਗਤ (ਜੇ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਕੁੱਲ ਲਾਗਤ ਨੂੰ ਵੀ ਮਾਨੀਟਰ ਕਰ ਸਕਦੇ ਹੋ, ਜੋ ਕਿ [**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ ਵਿਕਲਪ `Show cost information on the actions` ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ ਸੰਭਵ ਹੁੰਦਾ ਹੈ।

<a id="translate"></a>
## ਅਨੁਵਾਦ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਨੂੰ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਅਨੁਵਾਦ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![Translate workspace](../images/screenshots/pa/translate.png)

<br/>

<a id="translate-text"></a>
### ਟੈਕਸਟ ਦਾ ਅਨੁਵਾਦ ਕਰੋ

1. **ਅਨੁਵਾਦ** ਖੋਲ੍ਹੋ।
2. **ਤੋਂ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
3. **ਨੂੰ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. **ਇਨਪੁਟ** ਵਿੱਚ ਪਾਠ ਟਾਈਪ ਕਰੋ ਜਾਂ ਪੇਸਟ ਕਰੋ।
6. **ਅਨੁਵਾਦ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
7. **ਆਊਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।
8. ਜੇਕਰ ਤੁਸੀਂ ਨਤੀਜਾ ਕਾਪੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਕਾਪੀ ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।

<br/>

<a id="language-selection"></a>
### ਭਾਸ਼ਾ ਚੋਣ

- **ਤੋਂ** ਇੱਕ ਖਾਸ ਭਾਸ਼ਾ ਜਾਂ **ਭਾਸ਼ਾ ਪਛਾਣੋ** ਹੋ ਸਕਦੀ ਹੈ।
- **ਨੂੰ** ਉਹ ਭਾਸ਼ਾ ਹੈ ਜਿਸ ਵਿੱਚ ਤੁਸੀਂ ਨਤੀਜਾ ਚਾਹੁੰਦੇ ਹੋ।

ਤੁਹਾਡੀਆਂ ਚੁਣੀਆਂ **ਸਿਖਰ ਭਾਸ਼ਾਵਾਂ** ਸੂਚੀ ਦੇ ਸਿਖਰ 'ਤੇ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ। ਤੁਸੀਂ ਇਨ੍ਹਾਂ ਨੂੰ [**ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਵਿੱਚ ਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="helpful-translation-settings"></a>
### ਮਦਦਗਾਰ ਅਨੁਵਾਦ ਸੈਟਿੰਗਾਂ

[**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ, ਤੁਸੀਂ ਇਹ ਬਦਲ ਸਕਦੇ ਹੋ ਕਿ ਅਨੁਵਾਦ ਕਿਵੇਂ ਵਿਵਹਾਰ ਕਰਦਾ ਹੈ:

- **ਪੇਸਟ ਕਰਨ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਸੀਂ ਜਦੋਂ ਵੀ ਟੈਕਸਟ ਪੇਸਟ ਕਰਦੇ ਹੋ ਤਾਂ ਤੁਰੰਤ ਇੱਕ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।
- **ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਨਤੀਜਾ ਆਟੋ-ਕਾਪੀ** ਸਫਲਤਾਪੂਰਵਕ ਚਲਣ ਤੋਂ ਬਾਅਦ ਨਤੀਜਾ ਸਵੈਚਾਲਤ ਤੌਰ 'ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।
- **ਟਾਈਮਆਊਟ (ms)** ਨਿਯੰਤਰਣ ਕਰਦਾ ਹੈ ਕਿ ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਐਪ ਕਿੰਨੀ ਦੇਰ ਤੱਕ ਉਡੀਕਦੀ ਹੈ।
- **ਦਾਖਲ** ਇਹ ਨਿਯੰਤਰਣ ਕਰਦਾ ਹੈ ਕਿ ਜਦੋਂ ਤੁਸੀਂ `Enter` ਦਬਾਉਂਦੇ ਹੋ ਤਾਂ ਕੀ ਹੁੰਦਾ ਹੈ:

<a id="rewrite"></a>
## ਮੁੜ-ਲਿਖਤ

ਜਦੋਂ ਤੁਸੀਂ ਮੁੱਖ ਅਰਥ ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ ਸ਼ਬਦਾਵਲੀ ਵਿੱਚ ਸੁਧਾਰ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਮੁੜ-ਲਿਖਤ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![Rewrite workspace](../images/screenshots/pa/rewrite.png)

ਇਹ ਇਸ ਲਈ ਉਪਯੋਗੀ ਹੈ:

- ਸ਼ਬਦ-ਜੋੜ ਅਤੇ ਵਿਆਕਰਨ ਠੀਕ ਕਰਨਾ (**ਸਪੈਲਿੰਗ ਅਤੇ ਵਿਆਕਰਨ ਦੀ ਜਾਂਚ ਕਰੋ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਸਪਸ਼ਟ ਬਣਾਉਣਾ (**ਸਪਸ਼ਟਤਾ ਸੁਧਾਰੋ**)
- ਇੱਕ ਚੱਲਣ ਵਿੱਚ ਕਈ ਵੱਖ-ਵੱਖ ਪੁਨਰ-ਢਾਂਚਾਬੰਦੀਆਂ (**ਵੈਕਲਪਿਕ ਸੰਸਕਰਣ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਔਪਚਾਰਿਕ ਜਾਂ ਘੱਟ ਔਪਚਾਰਿਕ ਬਣਾਉਣਾ (**ਔਪਚਾਰਿਕ** / **ਅਣਔਪਚਾਰਿਕ**)
- ਟੈਕਸਟ ਨੂੰ ਛੋਟਾ ਜਾਂ ਲੰਬਾ ਕਰਨਾ (**ਛੋਟਾ ਕਰੋ** / **ਵਧਾਓ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਤਕਨੀਕੀ ਬਣਾਉਣਾ (**ਤਕਨੀਕੀ ਬਣਾਓ**)

<br/>

> 💡 **ਟਿਪ**<br/>
> ਜਦੋਂ ਤੁਸੀਂ "**ਸਪੈਲਿੰਗ ਅਤੇ ਵਿਆਕਰਨ ਜਾਂਚੋ**" ਮੋਡ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁੱਟ ਪੈਨਲ ਵਿੱਚ (**ਕਾਪੀ** ਦੇ ਨੇੜੇ) **ਤਬਦੀਲੀਆਂ ਵੇਖੋ** ਸਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।
> ਆਪਣੇ ਟੈਕਸਟ ਵਿੱਚ ਲਾਗੂ ਕੀਤੀਆਂ ਗਈਆਂ ਖਾਸ ਸੁਧਾਰਾਂ ਨੂੰ ਦਿਖਾਉਣ ਜਾਂ ਲੁਕਾਉਣ ਲਈ ਇਸਨੂੰ ਚਾਲੂ ਜਾਂ ਬੰਦ ਕਰੋ।

<a id="transform"></a>
## ਟ੍ਰਾਂਸਫਾਰਮ

ਤੁਸੀਂ ਕਸਟਮ ਹਿਦਾਇਤਾਂ ਦੇ ਸੈੱਟ ਨੂੰ ਲਾਗੂ ਕਰਨ ਲਈ AI ਨੂੰ ਵਰਤਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਟ੍ਰਾਂਸਫਾਰਮ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![Transform workspace](../images/screenshots/pa/transform.png)

ਐਪ ਦਾ ਇਹ ਸਭ ਤੋਂ ਲਚਕਦਾਰ ਖੇਤਰ ਹੈ। ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ ਹੇਠ ਲਿਖੇ ਕੰਮਾਂ ਲਈ ਕਰ ਸਕਦੇ ਹੋ:

- ਨੋਟਾਂ ਦਾ ਸਾਰ-ਸੰਗ੍ਰਹਿ ਕਰਨਾ
- ਕੱਚੇ ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਪਾਲਿਸ਼ ਕੀਤੀ ਈਮੇਲ ਵਿੱਚ ਬਦਲਣਾ
- ਮੁੱਖ ਬਿੰਦੂਆਂ ਨੂੰ ਕੱਢਣਾ
- ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਖਾਸ ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲਣਾ
- ਇਨਪੁਟ ਟੈਕਸਟ ਨਾਲ ਕੋਈ ਵੀ ਹੋਰ ਕਸਟਮ ਗਤੀਵਿਧੀ

<br/>

<a id="run-an-existing-prompt"></a>
### ਮੌਜੂਦਾ ਪ੍ਰੋਂਪਟ ਚਲਾਓ

1. **ਟਰਾਂਸਫਾਰਮ** ਖੋਲ੍ਹੋ।
2. ਪ੍ਰਾਮਟ ਸੂਚੀ ਵਿੱਚੋਂ ਇੱਕ ਪ੍ਰਾਮਟ ਚੁਣੋ।
3. ਜੇਕਰ **ਟੀਚਾ** ਭਾਸ਼ਾ ਬਾਕਸ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ, ਤਾਂ ਜੇਕਰ ਤੁਸੀਂ ਚਾਹੋ ਤਾਂ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. **ਇਨਪੁਟ** ਵਿੱਚ ਟੈਕਸਟ ਟਾਈਪ ਕਰੋ ਜਾਂ ਪੇਸਟ ਕਰੋ।
5. **ਟਰਾਂਸਫਾਰਮ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
6. **ਆਉਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### ਜੇ ਤੁਹਾਡੇ ਕੋਲ ਹਾਲੇ ਤੱਕ ਕੋਈ ਪ੍ਰੋਂਪਟ ਨਹੀਂ ਹੈ

ਜੇਕਰ ਤੁਹਾਡੀ ਪ੍ਰੋਂਪਟ ਸੂਚੀ ਖਾਲੀ ਹੈ, ਤਾਂ ਟ੍ਰਾਂਸਫਾਰਮ ਵਰਕਸਪੇਸ ਵਿੱਚ **ਨਮੂਨਾ ਪ੍ਰੌਂਪਟ ਲੋਡ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਐਕਸਪੋਰਟ/ਇੰਪੋਰਟ ਕਤਾਰ ਵਿੱਚ [**ਸੈਟਿੰਗਾਂ** > **ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ**](#transform-prompts) ਵਿੱਚ ਇਹੀ ਕੰਟਰੋਲ ਹਮੇਸ਼ਾ ਉਪਲਬਧ ਹੁੰਦਾ ਹੈ। ਦੋਵੇਂ ਅੰਦਰੂਨੀ ਉਦਾਹਰਣਾਂ ਸ਼ਾਮਲ ਕਰਦੇ ਹਨ ਤਾਂ ਜੋ ਤੁਸੀਂ ਤੁਰੰਤ ਸ਼ੁਰੂ ਕਰ ਸਕੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਨਮੂਨਾ ਪ੍ਰੋਂਪਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਦਿੱਤੇ ਗਏ ਹਨ। ਉਨ੍ਹਾਂ ਨੂੰ ਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੋਧ ਸਕਦੇ ਹੋ ਅਤੇ ਇਸਨੂੰ ਆਪਣੀ ਭਾਸ਼ਾ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰਨ ਲਈ **ਟਰਾਂਸਲੇਟ ਪ੍ਰੌਮਟ** ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="create-a-prompt-quickly"></a>
### ਨਵਾਂ ਪ੍ਰੋਂਪਟ

ਪ੍ਰੋਂਪਟ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਤਰੀਕਾ ਹੈ:

1. **ਨਵਾਂ ਪ੍ਰਾਮਟ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
2. **ਪ੍ਰਾਮਟ ਬਣਾਓ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਦੱਸੋ ਕਿ ਤੁਸੀਂ ਪ੍ਰਾਮਟ ਨੂੰ ਕੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।
4. ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. ਐਪ ਨੂੰ ਤੁਹਾਡੇ ਲਈ ਡ੍ਰਾਫਟ ਬਣਾਉਣ ਦਿਓ।
6. ਡ੍ਰਾਫਟ ਦੀ ਸਮੀਖਿਆ ਕਰੋ ਅਤੇ **ਸੇਵ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

![Generate prompt](../images/screenshots/pa/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ਪ੍ਰੋਂਪਟ ਸੋਧੋ

ਜਦੋਂ ਤੁਸੀਂ ਪ੍ਰੋਂਪਟ ਬਣਾਉਂਦੇ ਜਾਂ ਸੋਧਦੇ ਹੋ, ਤਾਂ ਸੰਪਾਦਕ ਖੱਬੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ ਅਤੇ ਟੈਸਟ ਖੇਤਰ ਸੱਜੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

![Transform prompt editor](../images/screenshots/pa/transform-prompt-edit.png)

ਮੁੱਖ ਖੇਤਰ ਹਨ:

- **ਪ੍ਰਾਮਟ ਨਾਮ**: ਪ੍ਰਾਮਟ ਸੂਚੀ ਵਿੱਚ ਦਿਖਾਏ ਗਏ ਨਾਮ।
- **ਪ੍ਰਾਮਟ ਨਿਰਦੇਸ਼ (ਵੈਕਲਪਿਕ)**: ਇੱਕ ਛੋਟੀ ਸੂਚਨਾ ਜੋ ਪ੍ਰਾਮਟ ਚਲਾਉਂਦੇ ਸਮੇਂ ਉਪਭੋਗਤਾ ਨੂੰ ਦਿਖਾਈ ਦਿੰਦੀ ਹੈ।
- **ਮਾਡਲ ਭੂਮਿਕਾ**: ਏਆਈ ਨੂੰ ਦਿੱਤੀ ਗਈ ਸਮੁੱਚੀ ਭੂਮਿਕਾ, ਜਿਵੇਂ 'ਤੁਸੀਂ ਇੱਕ ਮਦਦਗਾਰ ਸਹਾਇਕ ਹੋ।'
- **ਮਾਡਲ ਨਿਰਦੇਸ਼ (ਇੱਕ ਲਾਈਨ ਪ੍ਰਤੀ)**: ਖਾਸ ਨਿਯਮ ਜੋ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ ਏਆਈ ਪਾਲਣ ਕਰੇ।
- **ਆਉਟਪੁਟ ਵਿਵਰਣ**: ਨਤੀਜੇ ਨੂੰ ਦਰਸਾਉਣ ਵਾਲਾ ਇੱਕ ਛੋਟਾ ਸ਼ਬਦ, ਜਿਵੇਂ 'ਸਾਰ-ਸੰਗ੍ਰਹਿ' ਜਾਂ 'ਰੀਆਈਟ'।
- **ਤਾਪਮਾਨ (0.0 → 1.0)**: ਮਾਡਲ ਕਿਵੇਂ ਵਿਵਹਾਰ ਕਰੇਗਾ; ਹੇਠਾਂ ਵੇਖੋ।
- **ਟੀਚਾ ਭਾਸ਼ਾ ਲਈ ਪੁੱਛੋ**: ਜਦੋਂ ਪ੍ਰਾਮਟ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ ਤਾਂ ਟੀਚਾ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲਾ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।

ਜੇਕਰ ਤਕਨੀਕੀ ਸ਼ਬਦ **ਤਾਪਮਾਨ** ਤੁਹਾਡੇ ਲਈ ਨਵਾਂ ਹੈ, ਤਾਂ ਇਸ ਬਾਰੇ ਇਸ ਤਰ੍ਹਾਂ ਸੋਚੋ:

- **ਘੱਟ** ਤਾਪਮਾਨ ਨਾਲ ਸਥਿਰ, ਵਧੇਰੇ ਭਰੋਸੇਯੋਗ ਨਤੀਜੇ ਮਿਲਦੇ ਹਨ।
- **ਉੱਚ** ਤਾਪਮਾਨ ਨਾਲ ਵੱਧ ਵਿਭਿੰਨਤਾ ਅਤੇ ਰਚਨਾਤਮਕਤਾ ਮਿਲਦੀ ਹੈ।

ਤੁਸੀਂ ਇਸ ਦੀ ਵਰਤੋਂ ਵੀ ਕਰ ਸਕਦੇ ਹੋ:

- ਇੱਕ ਸਧਾਰਨ ਵਿਵਰਣ ਤੋਂ ਇੱਕ ਨਵਾਂ ਡਰਾਫਟ ਬਣਾਉਣ ਲਈ **`Generate prompt`**
- ਮੌਜੂਦਾ ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੁਧਾਰਨ ਲਈ **`Improve prompt`**
- ਪ੍ਰੋਂਪਟ ਫੀਲਡਾਂ ਨੂੰ ਅਨੁਵਾਦ ਕਰਨ ਲਈ **`Translate prompt`**

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> **`Back to Run`** ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **`Save`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਜੇਕਰ ਤੁਸੀਂ ਬਿਨਾਂ ਸੰਭਾਲੇ ਵਾਪਸ ਜਾਂਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਡੀਆਂ ਤਬਦੀਲੀਆਂ ਖਤਮ ਹੋ ਜਾਣਗੀਆਂ।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ਇਸਤੇਮਾਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਦਾ ਟੈਸਟ ਕਰੋ

ਸੱਜੇ ਪਾਸੇ ਟੈਸਟ ਪੈਨਲ ਤੁਹਾਨੂੰ ਰੋਜ਼ਾਨਾ ਕੰਮ ਵਿੱਚ ਇਸਤੇਮਾਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਨਮੂਨਾ ਪਾਠ ਨਾਲ ਆਪਣਾ ਪ੍ਰੋਂਪਟ ਅਜ਼ਮਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

ਇਹ ਉਪਯੋਗੀ ਹੈ ਜਦੋਂ:

- ਤੁਸੀਂ ਇੱਕ ਨਵਾਂ ਪ੍ਰੋਂਪਟ ਬਣਾ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਦੇ ਦੋ ਸੰਸਕਰਣਾਂ ਦੀ ਤੁਲਨਾ ਕਰ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਟੋਨ, ਲੰਬਾਈ ਜਾਂ ਆਉਟਪੁੱਟ ਫਾਰਮੈਟ ਦੀ ਜਾਂਚ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ [**ਸੈਟਿੰਗਾਂ** > **ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ**](#transform-prompts) ਵਿੱਚ ਸੰਭਾਲੇ ਗਏ ਪ੍ਰੋਂਪਟ ਨੂੰ ਐਕਸਪੋਰਟ ਅਤੇ ਇੰਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ।

<br/><br/>

<a id="general-settings"></a>
### ਆਮ ਸੈਟਿੰਗਾਂ

**ਆਮ ਸੈਟਿੰਗਾਂ** ਦੀ ਵਰਤੋਂ ਟਾਈਪਿੰਗ ਵਰਤਾਓ, ਇਹ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ ਕਰੋ ਕਿ ਕੀ ਨਿਰਵਹਨ ਵੇਰਵੇ **ਇਤਿਹਾਸ** ਲਈ ਸਟੋਰ ਕੀਤੇ ਜਾਂਦੇ ਹਨ, ਅਤੇ ਦਿੱਖ ਲਈ।

**ਵਰਤਾਓ**

- **ENTER ਲਈ ਵਿਵਹਾਰ** ਚੁਣਦਾ ਹੈ ਕਿ `Enter` ਕਾਰਜ ਨੂੰ ਚਲਾਉਂਦਾ ਹੈ ਜਾਂ ਇੱਕ ਨਵੀਂ ਲਾਈਨ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਪੇਸਟ ਕਰਨ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਸੀਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰਨ ਦੇ ਨਾਲ ਹੀ ਅਨੁਵਾਦ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- **ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਨਤੀਜਾ ਆਟੋ-ਕਾਪੀ** ਸਫਲ ਨਤੀਜਿਆਂ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ।
- **ਟਾਈਮਆਊਟ (ms)** ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਲਈ ਉਡੀਕ ਸਮਾਂ ਸੈੱਟ ਕਰਦਾ ਹੈ।

**ਇਤਿਹਾਸ**

- **ਨਿਸ਼ਪਾਦਨ ਇਤਿਹਾਸ ਰੱਖੋ** ਨਿਯੰਤਰਣ ਕਰਦਾ ਹੈ ਕਿ ਹਰੇਕ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਤ ਅਤੇ ਟ੍ਰਾਂਸਫਾਰਮ ਸਾਈਡਬਾਰ [**ਇਤਿਹਾਸ**](#history) ਵਿਊ ਲਈ **ਇਨਪੁੱਟ ਅਤੇ ਆਊਟਪੁੱਟ ਟੈਕਸਟ** ਸਟੋਰ ਕਰਦਾ ਹੈ ਜਾਂ ਨਹੀਂ। ਇਸਨੂੰ ਬੰਦ ਕਰਨ ਨਾਲ ਪੁਸ਼ਟੀ ਲਈ ਕਿਹਾ ਜਾਂਦਾ ਹੈ; ਜੇਕਰ ਤੁਸੀਂ ਪੁਸ਼ਟੀ ਕਰਦੇ ਹੋ, ਤਾਂ ਸਟੋਰ ਕੀਤਾ ਗਿਆ ਇਤਿਹਾਸ ਟੈਕਸਟ ਡੇਟਾਬੇਸ ਤੋਂ ਹਟਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।
- **ਇਤਿਹਾਸ ਡਾਟਾ ਮਿਟਾਓ** ਤੁਹਾਨੂੰ ਉਮਰ ਅਨੁਸਾਰ (ਉਦਾਹਰਣ ਲਈ ਕੁਝ ਮਹੀਨਿਆਂ ਤੋਂ ਪੁਰਾਣਾ, ਜਾਂ **ਸਾਰਾ ਡਾਟਾ (ਸਾਫ਼ ਕਰੋ)**) ਸਟੋਰ ਕੀਤਾ ਗਿਆ ਟੈਕਸਟ ਹਟਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ **ਡੇਟਾ ਮਿਟਾਓ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ। ਇਸ ਨਾਲ ਸਿਰਫ਼ **ਇਤਿਹਾਸ** ਵਿਊ ਲਈ ਸੰਭਾਲੇ ਗਏ ਨਿਸ਼ਪਾਦਨ ਟੈਕਸਟ 'ਤੇ ਅਸਰ ਪੈਂਦਾ ਹੈ; ਇਹ **ਲਾਗਤ** ਜਾਂ ਵਰਤੋਂ ਦੇ ਕੁੱਲ ਅੰਕੜੇ ਨਹੀਂ ਮਿਟਾਉਂਦਾ। **ਲਾਗਤ** ਡਾਟਾ ਨੂੰ ਹਟਾਉਣ ਜਾਂ ਛੋਟਾ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਦਿੱਖ**

- **ਕਾਰਵਾਈਆਂ 'ਤੇ ਲਾਗਤ ਜਾਣਕਾਰੀ ਵੇਖੋ** ਓਪਰੇਸ਼ਨ ਪ੍ਰਤੀ ਲਾਗਤ (ਜੇ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਅਨੁਵਾਦ, ਰੀਆਈਟ ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਆਉਟਪੁਟ ਪੈਨਲਾਂ 'ਤੇ ਕੁੱਲ ਲਾਗਤ ਦੇ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।
- **ਲਾਗਤ ਫਰੈਕਸ਼ਨ ਡਿਜ਼ੀਟ** ਲਾਗਤ ਦਸ਼ਮਲਵਾਂ ਦੇ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਬਦਲਦਾ ਹੈ।
- **ਸਿਰਫ ਵੈੱਬ:** **ਐਪ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਮਾਰਜਿਨ ਵੇਖੋ** ਇੰਟਰਫੇਸ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਵਾਧੂ ਥਾਂ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਫੌਂਟ ਫੈਮਲੀ** ਟੈਕਸਟ ਪੈਨਲਾਂ ਵਿੱਚ ਲਿਖਣ ਵਾਲੇ ਫੌਂਟ ਨੂੰ ਬਦਲਦਾ ਹੈ।
- **ਆਕਾਰ** ਫੌਂਟ ਆਕਾਰ ਨੂੰ ਬਦਲਦਾ ਹੈ।

**ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਬੈਕਅਪ**

- **ਬੈਕਅੱਪ ਵਿੱਚ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਸ਼ਾਮਲ ਕਰੋ** - ਜਦੋਂ ਸਮਰੱਥ, ਜ਼ਿਪ ਵਿੱਚ ਨਿਰਵਹਨ ਇਤਿਹਾਸ ਅਤੇ API ਕਾਲ ਡਾਟਾ ਵੀ ਸ਼ਾਮਲ ਹੁੰਦਾ ਹੈ। 
- **ਬੈਕਅੱਪ ਕਨਫਿਗਰੇਸ਼ਨ** - ਇੱਕ ਏਕੀਕ੍ਰਿਤ ਜ਼ਿਪ (UTC ਵਿੱਚ `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` ਦੁਆਰਾ ਡਿਫਾਲਟ ਵਜੋਂ) ਬਣਾਉਂਦਾ ਹੈ ਜਿਸ ਵਿੱਚ `config.json`, `state.json`, ਵਿਕਲਪਿਕ ਇਨਕ੍ਰਿਪਸ਼ਨ ਕੁੰਜੀ, ਉਪਭੋਗਤਾ, ਪਸੰਦ, ਕਸਟਮ ਪ੍ਰਾਮਟ, ਅਤੇ ਜੇ ਤੁਸੀਂ ਸਹਿਮਤ ਹੋਏ ਤਾਂ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਵੀ ਸ਼ਾਮਲ ਹੁੰਦੇ ਹਨ। ਇੱਕ ਸਫਲ ਬੈਕਅੱਪ ਤੋਂ ਬਾਅਦ, ਪੁਸ਼ਟੀ ਵਿੱਚ ਸੰਭਾਲੀ ਗਈ ਫਾਈਲ ਦਾ ਨਾਮ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ।
- **ਬੈਕਅੱਪ ਤੋਂ ਮੁੜ-ਸਥਾਪਿਤ ਕਰੋ** - ਪਹਿਲਾਂ **ਪੁਸ਼ਟੀ ਡਾਇਲਾਗ** ਖੋਲ੍ਹਦਾ ਹੈ। ਡਾਇਲਾਗ ਵਿੱਚ ਬੈਕਅੱਪ ਜ਼ਿਪ ਚੁਣੋ (**ਬਰਾਊਜ਼** / ਫਾਈਲ ਪਿਕਰ ਜਾਂ ਡਰੈਗ-ਐਂਡ-ਡਰਾਪ ਜਿੱਥੇ ਸਮਰੱਥ), ਫਿਰ ਵਿਕਲਪਾਂ ਦੀ ਸਮੀਖਿਆ ਕਰੋ:
  - **ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਮੁੜ-ਸਥਾਪਿਤ ਕਰੋ** - ਜਦੋਂ ਬੈਕਅੱਪ ਵਿੱਚ ਵਰਤੋਂ ਸ਼ਾਮਲ ਹੋਵੇ ਤਾਂ ਜ਼ਿਪ ਤੋਂ ਵਰਤੋਂ/ਇਤਿਹਾਸ ਨੂੰ ਆਯਾਤ ਕਰੋ; ਜੇ ਤੁਸੀਂ ਸਿਰਫ ਸੈਟਿੰਗਾਂ ਅਤੇ ਪ੍ਰਾਮਟ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਇਸਨੂੰ ਬੰਦ ਰੱਖੋ।
  - **ਮੁੜ-ਸਥਾਪਨਾ ਤੋਂ ਪਹਿਲਾਂ ਪੁਰਾਣੇ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਮਿਟਾਓ** - ਬੈਕਅੱਪ ਲਾਗੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇਸ ਇੰਸਟਾਲੇਸ਼ਨ 'ਤੇ ਮੌਜੂਦਾ ਵਰਤੋਂ/ਇਤਿਹਾਸ ਨੂੰ ਹਟਾਓ (ਵਿਕਲਪਿਕ; ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਸਾਫ਼ ਬਦਲ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਵਰਤੋ)।

ਵੈੱਬ ਜਾਂ ਡੈਸਕਟਾਪ ਵਰਜਨ ਵਿੱਚ ਬਣਾਏ ਗਏ ਬੈਕਅਪ ਨੂੰ ਦੂਜੇ ਵਿੱਚ ਮੁੜ-ਸਥਾਪਤ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ। ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ ਡੈਸਕਟਾਪ ਬੈਕਅਪ ਨੂੰ ਮੁੜ-ਸਥਾਪਤ ਕਰਦੇ ਸਮੇਂ, ਡਾਟਾ ਐਡਮਿਨਿਸਟਰੇਟਰ ਯੂਜ਼ਰ ਨੂੰ ਮੁੜ-ਸਥਾਪਤ ਕੀਤਾ ਜਾਵੇਗਾ।

<a id="models"></a>
### ਮਾਡਲ

ਟੂਲਬਾਰ ਵਿੱਚ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ ਉਹ ਚੁਣਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![Settings Models tab](../images/screenshots/pa/settings-models.png)

ਪੇਜ ਵਿੱਚ ਦੋ ਸੂਚੀਆਂ ਹਨ:

- **ਉਪਲਬਧ ਮਾਡਲ** ਖੱਬੇ ਪਾਸੇ
- **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਸੱਜੇ ਪਾਸੇ

ਵਰਤੋਂ ਵਿੱਚ ਲਿਆਉਣ ਵਾਲੇ ਨਿਯੰਤਰਣ ਸ਼ਾਮਲ ਹਨ:

- **ਮਾਡਲਾਂ ਦੀ ਖੋਜ...** ਨਾਮ ਨਾਲ ਮਾਡਲ ਲੱਭਣ ਲਈ
- **ਪ੍ਰਦਾਤਾ** ਚਿਪਸ ਸੂਚੀ ਨੂੰ ਇੱਕ ਇੰਜਣ (OpenRouter, OpenAI, Ollama, …) ਤੱਕ ਸੀਮਿਤ ਕਰਨ ਲਈ
- **ਸਿਰਫ ਮੁਫਤ** ਸਿਰਫ ਮੁਫਤ ਮਾਡਲਾਂ ਨੂੰ ਵੇਖਣ ਲਈ
- **ਰੀਫਰੈਸ਼** ਸੂਚੀ ਨੂੰ ਮੁੜ-ਲੋਡ ਕਰਨ ਲਈ
- **ਸਭ ਕੁਝ ਵਿਸਤ੍ਰਿਤ ਕਰੋ** ਅਤੇ **ਸਭ ਕੁਝ ਸੰਖੇਪ ਕਰੋ** ਜਦੋਂ ਤੁਸੀਂ ਪ੍ਰਦਾਤਾ ਅਨੁਸਾਰ ਕ੍ਰਮਬੱਧ ਕਰ ਰਹੇ ਹੋ

ਮਾਡਲ ਆਈਡੀਆਂ ਵਿੱਚ ਪ੍ਰਦਾਤਾ ਪ੍ਰੀਫਿਕਸ ਸ਼ਾਮਲ ਹੈ (ਉਦਾਹਰਣ ਲਈ `openrouter/…` ਬਨਾਮ `openai/…`)। **OpenAI (OpenRouter)** ਬਨਾਮ **OpenAI (ਸਿੱਧਾ)** ਵਰਗੇ ਬੈਜ ਦੱਸਦੇ ਹਨ ਕਿ ਟ੍ਰੈਫਿਕ ਕਿਵੇਂ ਰੂਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

> ℹ️ **ਨੋਟ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) ਇੱਕ ਰਾਊਟਰ ਮਾਡਲ ਹੈ, ਆਮ ਚੈਟ ਮਾਡਲ ਨਹੀਂ: ਇਸਦਾ ਜਵਾਬ ਜੇਸਨ ਹੈ ਜੋ OpenRouter API ਰਿਕੁਐਸਟ ਬਾਡੀਆਂ ਦਾ ਵੇਰਵਾ ਦਿੰਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `requests` ਐਰੇ ਨਾਲ `model` ਅਤੇ `messages`)। ਜੇ ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ **ਅਨੁਵਾਦ ਕਰੋ**, **ਮੁੜ-ਲਿਖਤ**, ਜਾਂ **ਟ੍ਰਾਂਸਫਾਰਮ** ਲਈ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁੱਟ ਪੈਨਲ ਉਸ ਜੇਸਨ ਨੂੰ ਦਿਖਾਏਗਾ ਬਜਾਏ ਪੂਰੀ ਹੋਈ ਟੈਕਸਟ ਦੇ। ਇਹਨਾਂ ਕੰਮਾਂ ਲਈ ਇੱਕ ਸਾਧਾਰਨ ਟੈਕਸਟ ਮਾਡਲ ਚੁਣੋ। OpenRouter 'ਤੇ [ਬਾਡੀ ਬਿਲਡਰ ਮਾਡਲ ਪੇਜ](https://openrouter.ai/openrouter/bodybuilder) ਵੇਖੋ।

ਕਾਰਵਾਈਆਂ:

- ਇੱਕ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, **ਸ਼ਾਮਲ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਜਾਂ ਐਂਟਰੀ ਵਿੱਚ ਕਿਤੇ ਵੀ।

- ਇੱਕ ਮਾਡਲ ਨੂੰ ਹਟਾਉਣ ਲਈ, **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇਸ ਦੇ ਨਾਲ **X** 'ਤੇ ਜਾਂ ਉਪਲਬਧ ਮਾਡਲਾਂ ਵਿੱਚ ਐਂਟਰੀ 'ਤੇ **ਚੁਣਿਆ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

- ਸੂਚੀ ਨੂੰ ਸਾਫ਼ ਕਰਨ ਲਈ, **ਸਭ ਅਣ-ਚੁਣੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਲੋੜੀਂਦਾ ਮੁਫ਼ਤ ਮਾਡਲ ਸੂਚੀ ਵਿੱਚ ਰਹੇਗਾ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਜੇਕਰ ਤੁਸੀਂ OpenRouter ਨੂੰ ਤੁਰੰਤ ਕ੍ਰੈਡਿਟ ਸ਼ਾਮਲ ਕਰਨਾ ਨਹੀਂ ਚਾਹੁੰਦੇ, ਤਾਂ **ਸਿਰਫ਼ ਮੁਫ਼ਤ** ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ ਅਤੇ ਮੁਫ਼ਤ ਮਾਡਲਾਂ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ) ਚੁਣ ਕੇ ਸ਼ੁਰੂ ਕਰੋ। ਤੁਸੀਂ Ollama ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਕੋਈ ਵੀ API ਕੁੰਜੀ ਤੋਂ ਬਿਨਾਂ ਮਾਡਲਾਂ ਨੂੰ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚਲਾ ਸਕਦੇ ਹੋ।

<a id="languages"></a>
### ਭਾਸ਼ਾਵਾਂ

ਐਪ ਵਿੱਚ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਨੂੰ ਵਿਵਸਥਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਸਿਖਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** **ਅਨੁਵਾਦ ਕਰੋ** ਅਤੇ **ਟ੍ਰਾਂਸਫਾਰਮ** ਵਿੱਚ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਦੇ ਉਪਰਲੇ ਹਿੱਸੇ ਵਿੱਚ ਪਿੰਨ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- **ਕਸਟਮ ਭਾਸ਼ਾ** ਤੁਹਾਨੂੰ ਬਿਲਟ-ਇਨ ਸੂਚੀ ਵਿੱਚ ਨਾ ਹੋਣ ਵਾਲੀ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦੀ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ ਕਸਟਮ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਤਾਂ ਇਹ ਬਿਲਟ-ਇਨ ਵਿਕਲਪਾਂ ਨਾਲ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲਿਆਂ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦੀ ਹੈ।

<a id="cost-tracking"></a>
### ਲਾਗਤ ਟਰੈਕਿੰਗ

ਲਾਗਤ ਜਾਣਕਾਰੀ ਨੂੰ ਪਰਬੰਧਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਕੁੱਲ ਲਾਗਤ** ਚੱਲ ਰਹੀ ਕੁੱਲ ਰਕਮ ਦਿਖਾਉਂਦਾ ਹੈ।
- **ਮੁੱਲ ਕਾਪੀ ਕਰੋ** ਕੁੱਲ ਰਕਮ ਨੂੰ ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਲਾਗਤ ਰੀਸੈੱਟ ਕਰੋ** ਸਟੋਰ ਕੀਤੀ ਕੁੱਲ ਰਕਮ ਨੂੰ ਸਿਫ਼ਰ 'ਤੇ ਰੀਸੈੱਟ ਕਰਦਾ ਹੈ।
- **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ** ਕੁੱਲ ਰਕਮ ਨੂੰ ਤੁਹਾਡੇ OpenRouter ਖਾਤੇ ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੀ ਗਈ ਵਰਤੋਂ ਨਾਲ ਮੇਲ ਕਰਨ ਲਈ ਸੈੱਟ ਕਰਦਾ ਹੈ (ਸਿਰਫ OpenRouter)।
- **API ਕੁੰਜੀ ਵਰਤੋਂ** OpenRouter ਵਰਤੋਂ ਦੇ ਵੇਰਵੇ ਦਿਖਾਉਂਦਾ ਹੈ, ਜੇ ਉਪਲਬਧ ਹੋਵੇ।
- **ਲਾਗਤ ਡਾਟਾ ਮਿਟਾਓ** ਸਭ ਡਾਟਾ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ, ਜਾਂ ਸਿਰਫ ਚੁਣੀ ਗਈ ਮਿਤੀ ਤੋਂ ਪਹਿਲਾਂ ਦੀਆਂ ਐਂਟਰੀਆਂ ਨੂੰ।

**ਲਾਗਤ ਟਰੈਕਿੰਗ:** ਜਦੋਂ ਤੁਸੀਂ OpenRouter ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ ਅਸਲ ਵਰਤੋਂ ਅਤੇ OpenRouter ਤੋਂ ਲਾਗਤ ਜਾਣਕਾਰੀ ਦੇ ਆਧਾਰ 'ਤੇ ਖਰਚ ਦਿਖਾਉਂਦਾ ਹੈ। ਸਾਰੇ ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ ਲਈ, ਐਪ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਤੀਆਂ ਕੀਮਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਲਾਗਤਾਂ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਂਦਾ ਹੈ, ਜੇਕਰ ਕੋਈ ਕੀਮਤ ਉਪਲਬਧ ਨਾ ਹੋਵੇ, ਤਾਂ ਅੰਦਾਜ਼ਾ ਸਿਫ਼ਰ ਹੋ ਸਕਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
>  **ਸਾਰੇ ਲਾਗਤ ਅੰਕੜੇ ਤੁਹਾਡੇ ਹਵਾਲੇ ਲਈ ਅੰਦਾਜ਼ੇ ਹਨ, ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।**

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਡੇਟਾ ਨੂੰ ਮਿਟਾਉਣਾ ਉਲਟਾ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਮਿਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ, ਆਪਣੇ ਡੇਟਾ ਨੂੰ ਬੈਕਅੱਪ ਕਰਨਾ ਜਾਂ [**ਇਤਿਹਾਸ**](#history) ਰਾਹੀਂ ਜਾਂ [**ਡੈਸ਼ਬੋਰਡ** > **ਸਾਰੀਆਂ ਕਾਲਾਂ**](#dashboard-tabs) ਰਾਹੀਂ ਐਕਸਪੋਰਟ ਕਰਨਾ ਯਕੀਨੀ ਬਣਾਓ, ਨਹੀਂ ਤਾਂ ਇਹ ਸਥਾਈ ਤੌਰ 'ਤੇ ਖੋ ਜਾਵੇਗਾ। 
> ਹਰੇਕ API ਕਾਲ ਐਂਟਰੀ ਨਾਲ ਸਬੰਧਤ ਸਭ ਇਨਪੁੱਟ/ਆਉਟਪੁੱਟ ਇਤਿਹਾਸ ਵੀ ਮਿਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।

<a id="transform-prompts"></a>
### ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ

**ਸੈਟਿੰਗਾਂ** > **ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਂਪਟ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਤੁਸੀਂ ਇਕੱਠੇ ਪ੍ਰੌਂਪਟ ਪਰ ਕੰਮ ਕਰ ਸਕਦੇ ਹੋ।

ਤੁਸੀਂ ਕਰ ਸਕਦੇ ਹੋ:

- ਆਪਣੇ ਸੰਭਾਲੇ ਗਏ ਪ੍ਰਾਮਟਾਂ ਦੀ ਸਮੀਖਿਆ ਕਰੋ
- ਪ੍ਰਾਮਟ ਮਿਟਾਓ
- ਇੱਕ ਫਾਈਲ ਤੋਂ ਪ੍ਰਾਮਟ ਆਯਾਤ ਕਰੋ
- ਬੈਕਅੱਪ ਜਾਂ ਸਾਂਝਾ ਕਰਨ ਲਈ ਪ੍ਰਾਮਟ ਨਿਰਯਾਤ ਕਰੋ
- ਪ੍ਰਾਮਟ ਸੂਚੀ ਵਿੱਚ ਨਮੂਨਾ ਪ੍ਰਾਮਟ ਲੋਡ ਕਰੋ

<a id="users"></a>
### ਉਪਭੋਗਤਾ

**ਉਪਭੋਗਤਾ** ਨੂੰ ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ ਉਪਭੋਗਤਾ ਖਾਤਿਆਂ ਨੂੰ ਪਰਬੰਧਿਤ ਕਰਨ ਲਈ ਵਰਤੋਂ। ਤੁਸੀਂ ਉਪਭੋਗਤਾ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹੋ, ਉਨ੍ਹਾਂ ਦੀਆਂ ਜਾਣਕਾਰੀਆਂ ਨੂੰ ਅਪਡੇਟ ਕਰ ਸਕਦੇ ਹੋ, ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ, ਅਤੇ ਖਾਤੇ ਮਿਟਾ ਸਕਦੇ ਹੋ।

<a id="api-config"></a>
### API ਸੰਰਚਨਾ

ਸਮਰਥਿਤ ਪ੍ਰਦਾਤਾ ਹਨ: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, ਸੇਰੇਬਰਸ, ਅਤੇ **Ollama** (ਆਧਾਰ URL ਰਾਹੀਂ ਸਥਾਨਕ ਮਾਡਲ)। ਤੁਹਾਨੂੰ ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰਨ ਦੀ ਲੋੜ ਹੈ ਜਿਨ੍ਹਾਂ ਦੀ ਵਰਤੋਂ ਤੁਸੀਂ ਕਰਦੇ ਹੋ।

**ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ: ਸਿਰਫ਼ ਪ੍ਰਸ਼ਾਸਕ**

API ਕੁੰਜੀਆਂ ਸਿਸਟਮ ਜਾਂ ਡਾਕਰ ਵਾਤਾਵਰਣ ਚਲਣ ਰਾਹੀਂ ਸੰਰਚਿਤ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ - ਉਹ ਵੈੱਬ UI ਵਿੱਚ ਦਰਜ ਨਹੀਂ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ। ਇਹ ਸਫ਼ਾ ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਕਿਹੜੇ ਪ੍ਰਦਾਤਾ ਕੋਲ ਇੱਕ ਕੁੰਜੀ ਸੰਰਚਿਤ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ **`Test`** ਬਟਨ ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਹਰੇਕ ਦਾ ਪਰੀਖਿਆ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> API ਕੁੰਜੀ ਬਦਲਣ ਲਈ, ਆਪਣੇ ਸਿਸਟਮ ਜਾਂ Docker ਸੰਰਚਨਾ ਵਿੱਚ ਵਾਤਾਵਰਨ ਵੇਰੀਏਬਲ ਨੂੰ ਅੱਪਡੇਟ ਕਰੋ ਅਤੇ ਸਰਵਰ ਜਾਂ ਕੰਟੇਨਰ ਨੂੰ ਮੁੜ ਚਾਲੂ ਕਰੋ।

> ℹ️ **ਨੋਟ**<br/>
> **ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਬੈਕਅਪ** ([**ਆਮ ਸੈਟਿੰਗਾਂ** → ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਬੈਕਅਪ](#general-settings) ਵੇਖੋ) ZIP ਦੇ `config.json` ਵਿੱਚ **ਹੱਲ ਕੀਤੀਆਂ** ਪ੍ਰਦਾਤਾ ਕੁੰਜੀਆਂ ਨੂੰ ਏਮਬੈਡ ਕਰ ਸਕਦੇ ਹਨ। ਉਸ ZIP ਨੂੰ ਬਹਾਲ ਕਰਨਾ ਉਹਨਾਂ ਕੁੰਜੀਆਂ ਨੂੰ ਸਰਵਰ ਦੀ ਸੰਭਾਲੀ ਗਈ ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਫ਼ਾਈਲ ਵਿੱਚ ਵਾਪਸ ਕਾਪੀ **ਨਹੀਂ** ਕਰਦਾ - ਲਾਈਵ ਕੁੰਜੀਆਂ ਅਜੇ ਵੀ ਵਾਤਾਵਰਨ ਅਤੇ ਮੌਜੂਦਾ ਫ਼ਾਈਲ ਸਥਿਤੀ ਤੋਂ ਆਉਂਦੀਆਂ ਹਨ ਜਿਵੇਂ ਉੱਥੇ ਦੱਸਿਆ ਗਿਆ ਹੈ।

<br/>

**ਡੈਸਕਟੌਪ ਐਪਲੀਕੇਸ਼ਨ**

ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਜਿਸ ਨੂੰ ਤੁਸੀਂ ਵਰਤਦੇ ਹੋ, ਲਈ API ਕੁੰਜੀਆਂ ਸਟੋਰ ਕਰਨ ਲਈ **API ਸੰਰਚਨਾ** ਵਰਤੋ। Ollama ਲਈ, API ਕੁੰਜੀ ਦੀ ਬਜਾਏ **ਬੇਸ URL** ਦਰਜ ਕਰੋ।

<br/>

> 💡 **ਸੁਝਾਅ** <br/>
> ਜੇਕਰ ਤੁਸੀਂ API ਕੁੰਜੀ ਵਰਤਣਾ ਜਾਂ ਵਰਤੋਂ ਲਈ ਭੁਗਤਾਨ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ [Ollama ਡਾਊਨਲੋਡ ਕਰ ਸਕਦੇ ਹੋ](https://ollama.com) ਅਤੇ ਮਾਡਲ (ਜਿਵੇਂ `translategemma:4b`) ਆਪਣੀ ਮਸ਼ੀਨ 'ਤੇ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਮੁਫ਼ਤ ਚਲਾ ਸਕਦੇ ਹੋ। ਵਿਕਲਪਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ ਇੱਕ ਮੁਫ਼ਤ OpenRouter ਖਾਤਾ ਬਣਾ ਸਕਦੇ ਹੋ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ) ਉਹਨਾਂ ਦੇ ਮੁਫ਼ਤ ਮਾਡਲ ਵਰਤਣ ਲਈ, ਜਾਂ ਸੇਰੇਬਰਸ, Google, Groq, ਜਾਂ Mistral AI ਤੋਂ ਮੁਫ਼ਤ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

- ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰੋ ਜਿਹਨਾਂ ਦੀ ਤੁਹਾਨੂੰ ਲੋੜ ਹੈ। **ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ** ਵਿੱਚ, ਹਰੇਕ ਮਾਡਲ ID ਪ੍ਰਦਾਤਾ ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦੀ ਹੈ (ਉਦਾਹਰਣ ਲਈ `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, ਟੈਕਸਟ ਫੀਲਡ ਵਿੱਚ ਮੁੱਲ ਦਰਜ ਕਰੋ ਅਤੇ **`Save`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਮੌਜੂਦਾ ਕੁੰਜੀ ਨੂੰ ਬਦਲਣ ਲਈ, **`Edit`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਹ ਜਾਂਚਣ ਲਈ ਕਿ ਕੀ ਕੁੰਜੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ, **`Test`** ਤੇ ਕਲਿੱਕ ਕਰੋ। Ollama ਬੇਸ URL ਲਈ, ਸੰਪਰਕ ਦੀ ਜਾਂਚ ਕਰਨ ਲਈ ਹਮੇਸ਼ਾ **`Test`** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ API ਕੁੰਜੀ ਦਾ ਮੌਜੂਦਾ ਮੁੱਲ ਨਹੀਂ ਵੇਖ ਸਕਦੇ। ਤੁਸੀਂ ਇਸਨੂੰ ਸਿਰਫ਼ **`Edit`** ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਬਦਲ ਸਕਦੇ ਹੋ।
> API ਕੁੰਜੀਆਂ ਕੰਫਿਗਰੇਸ਼ਨ ਵਿੱਚ ਇੰਕ੍ਰਿਪਟਿਡ ਰੂਪ ਵਿੱਚ ਸਟੋਰ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।

<a id="common-issues"></a>
## ਆਮ ਸਮੱਸਿਆਵਾਂ

ਜੇਕਰ ਕੁਝ ਵੀ ਉਮੀਦ ਮੁਤਾਬਕ ਕੰਮ ਨਾ ਕਰੇ, ਤਾਂ ਪਹਿਲਾਂ ਹੇਠਾਂ ਦਿੱਤੇ ਬਿੰਦੂਆਂ ਨੂੰ ਜਾਂਚੋ।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### ਐਪ ਟੈਕਸਟ ਨੂੰ ਅਨੁਵਾਦ ਕਰਨ, ਮੁੜ-ਲਿਖਤ ਕਰਨ ਜਾਂ ਟ੍ਰਾਂਸਫਾਰਮ ਕਰਨ ਵਿੱਚ ਅਸਮਰੱਥ ਹੈ

ਜਾਂਚ ਕਰੋ ਕਿ:

- ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣਿਆ ਹੈ
- ਘੱਟੋ ਘੱਟ ਇੱਕ ਮਾਡਲ [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਵਿੱਚ ਸੂਚੀਬੱਧ ਹੈ
- ਤੁਹਾਡੀ API ਸੈਟਅੱਪ ਕੰਮ ਕਰ ਰਹੀ ਹੈ

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਵਰਤ ਰਹੇ ਹੋ:

1. [**ਸੈਟਿੰਗਾਂ** > **API ਸੰਰਚਨਾ**](#api-config) ਖੋਲ੍ਹੋ।
2. ਜਾਂਚ ਕਰੋ ਕਿ ਘੱਟੋ ਘੱਟ ਇੱਕ API ਕੁੰਜੀ ਸੰਭਾਲੀ ਗਈ ਹੈ।
3. ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਪ੍ਰਦਾਤਾ ਦੇ ਨਾਲ **ਟੈਸਟ** ਤੇ ਕਲਿੱਕ ਕਰੋ ਕਿ ਕੁੰਜੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।

<br/>

<a id="the-model-list-is-empty"></a>
### ਮਾਡਲ ਸੂਚੀ ਖਾਲੀ ਹੈ

[**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਰਿਫ਼ਰੈਸ਼** ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਜੇ ਲੋੜ ਹੋਵੇ:

- ਇੱਕ ਮਾਡਲ ਲਈ ਖੋਜੋ
- **ਸਿਰਫ਼ ਮੁਫ਼ਤ** ਨੂੰ ਚਾਲੂ ਕਰੋ
- **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ਨਤੀਜਾ ਬਹੁਤ ਧੀਮਾ ਜਾਂ ਬਹੁਤ ਮਹਿੰਗਾ ਹੈ

ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਜਾਂ ਵੱਧ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ:

- ਇੱਕ ਵੱਖਰਾ ਮਾਡਲ ਚੁਣੋ
- ਇੱਕ ਛੋਟਾ ਇਨਪੁੱਟ ਵਰਤੋਂ
- [**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਨੂੰ ਬੰਦ ਕਰੋ
- ਸਧਾਰਨ ਕੰਮਾਂ ਲਈ ਮੁਫ਼ਤ ਮਾਡਲ ਵਰਤੋਂ (ਵੇਖੋ [ਮਾਡਲ](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ਇੰਟਰਫੇਸ ਗਲਤ ਭਾਸ਼ਾ ਵਿੱਚ ਹੈ

[ਟੂਲਬਾਰ](#toolbar) ਵਿੱਚ ਗਲੋਬ ਆਈਕਾਨ ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਆਪਣੀ ਪਸੰਦੀਦਾ **Interface language** ਚੁਣੋ।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ਟੈਕਸਟ ਬਹੁਤ ਛੋਟਾ ਜਾਂ ਪੜ੍ਹਨ ਲਈ ਮੁਸ਼ਕਲ ਹੈ

[**Settings** > **General Settings**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਬਦਲੋ:

- **Font Family**
- **Size**

<a id="dashboard-charts-are-empty"></a>
### ਡੈਸ਼ਬੋਰਡ ਚਾਰਟ ਖਾਲੀ ਹਨ

ਇਹ ਸਧਾਰਨ ਹੈ ਜੇ:

- ਤੁਸੀਂ ਸਿਰਫ਼ **ਮੁਫ਼ਤ ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ ਅਤੇ ਤੁਸੀਂ **ਲਾਗਤ** ਅੰਕੜਿਆਂ ਨੂੰ ਵੇਖ ਰਹੇ ਹੋ (ਇਹ ਸਿਫ਼ਰ ਹੋ ਸਕਦੇ ਹਨ); **ਸਾਰ** ਵਿੱਚ **ਵਰਤੋਂ** ਕਾਲ-ਗਿਣਤੀ ਚਾਰਟ ਨੂੰ ਅਜੇ ਵੀ ਚੁਣੇ ਹੋਏ ਸਮੇਂ ਦੀਆਂ ਜਾਣਕਾਰੀਆਂ ਦੀ ਲੋੜ ਹੈ
- ਚੁਣਿਆ ਹੋਇਆ **ਸਮਾਂ ਫਿਲਟਰ** ਉਸ ਸਮੇਂ ਦੀ ਮਿਆਦ ਨੂੰ ਸ਼ਾਮਲ ਨਹੀਂ ਕਰਦਾ ਜਦੋਂ ਕਾਲਾਂ ਕੀਤੀਆਂ ਗਈਆਂ ਸਨ - ਜਾਂਚ ਲਈ **ਸਭ** ਦੀ ਵਰਤੋਂ ਕਰੋ

ਜੇ **ਸਭ** ਚੁਣਨ ਤੋਂ ਬਾਅਦ ਵੀ ਚਾਰਟ ਖਾਲੀ ਹਨ, ਤਾਂ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ **ਸਾਰੀਆਂ ਕਾਲਾਂ** ਟੈਬ ਵਿੱਚ ਕਾਲਾਂ ਦਿਖਾਈ ਦੇ ਰਹੀਆਂ ਹਨ।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ਲਾਗਤ "ਉਪਲਬਧ ਨਹੀਂ" ਦਰਸਾਉਂਦੀ ਹੈ ਜਾਂ ਗਲਤ ਲੱਗਦੀ ਹੈ

ਜਦੋਂ ਤੁਸੀਂ **OpenRouter** ਰਾਹੀਂ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਤਾਂ ਐਪ ਤੁਹਾਡੇ ਦੁਆਰਾ OpenRouter ਨੂੰ ਰਿਪੋਰਟ ਕੀਤੇ ਅਸਲ ਖਰਚ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ।

**ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ** (OpenAI ਸਿੱਧਾ, Anthropic ਸਿੱਧਾ, ਆਦਿ) ਲਈ, ਲਾਗਤ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਤੀਆਂ ਕੀਮਤਾਂ ਦੇ ਅਧਾਰ ਤੇ ਅਨੁਮਾਨਿਤ ਕੀਤੀ ਜਾਂਦੀ ਹੈ। ਜੇਕਰ ਕਿਸੇ ਮਾਡਲ ਲਈ ਮੇਲ ਖਾਂਦੀ ਕੀਮਤ ਨਹੀਂ ਮਿਲਦੀ, ਤਾਂ ਲਾਗਤ **ਉਪਲਬਧ ਨਹੀਂ** ਦਿਖਾਈ ਦੇਵੇਗੀ ਅਤੇ ਤੁਹਾਡੇ ਚੱਲ ਰਹੇ ਕੁੱਲ ਵਿੱਚ ਸ਼ਾਮਲ ਨਹੀਂ ਕੀਤੀ ਜਾਵੇਗੀ।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ਕੁੱਲ ਲਾਗਤ ਤੁਹਾਡੇ ਪ੍ਰਦਾਤਾ ਦੇ ਬਿੱਲ ਨਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੀ

ਐਪ ਵਿੱਚ ਸਾਰੇ ਲਾਗਤ ਅੰਕੜੇ **ਸਿਰਫ਼ ਹਵਾਲਾ ਲਈ ਅਨੁਮਾਨ** ਹਨ, ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।

ਕੁੱਲ ਨੂੰ ਤੁਹਾਡੇ ਅਸਲ OpenRouter ਖਰਚ ਨਾਲ ਹੋਰ ਨੇੜੇ ਲਿਆਉਣ ਲਈ, [**ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਖੋਲ੍ਹੋ ਅਤੇ **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### ਸਾਈਡਬਾਰ ਵਿੱਚ ਇਤਿਹਾਸ ਪੇਜ਼ ਗਾਇਬ ਹੈ

**ਨਿਸ਼ਪਾਦਨ ਇਤਿਹਾਸ ਰੱਖੋ** ਬੰਦ ਹੋ ਸਕਦਾ ਹੈ। [**ਸੈਟਿੰਗਾਂ** > **ਆਮ ਸੈਟਿੰਗਾਂ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਇਸਨੂੰ ਚਾਲੂ ਕਰੋ। ਨੋਟ ਕਰੋ ਕਿ ਇਸਨੂੰ ਚਾਲੂ ਕਰਨ ਨਾਲ ਪਹਿਲਾਂ ਹਟਾਏ ਗਏ ਇਤਿਹਾਸ ਡਾਟਾ ਮੁੜ ਸਥਾਪਤ ਨਹੀਂ ਹੁੰਦਾ।

<br/>

<a id="web-app-session-expired"></a>
### ਵੈੱਬ ਐਪ: ਅਚਾਨਕ ਲੌਗਇਨ ਪੇਜ਼ ਤੇ ਰੀਡਾਇਰੈਕਟ ਕੀਤਾ ਗਿਆ

ਤੁਹਾਡਾ ਸੈਸ਼ਨ ਸਮਾਪਤ ਹੋ ਸਕਦਾ ਹੈ। ਮੁੜ ਲੌਗ ਇਨ ਕਰੋ। ਜੇ ਇਹ ਅਕਸਰ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਸਰਵਰ ਕੌਂਫਿਗਰੇਸ਼ਨ ਵਿੱਚ ਸੈਸ਼ਨ ਜੀਵਨ ਕਾਲ ਸੈਟਿੰਗਾਂ ਲਈ ਜਾਂਚ ਕਰੋ।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### ਵੈੱਬ ਐਡਮਿਨ: ਪਾਸਵਰਡ ਭੁੱਲ ਗਏ ਜਾਂ ਗੁਆ ਦਿੱਤਾ

ਇਹ **ਸਵੈ-ਹੋਸਟ ਕੀਤੇ ਵੈੱਬ ਐਪ** (Docker) ਲਈ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਡੈਸਕਟਾਪ (Electron) ਐਪ ਲਈ ਨਹੀਂ।

- ਜੇਕਰ ਕੋਈ ਹੋਰ ਐਡਮਿਨ ਅਜੇ ਵੀ ਸਾਇਨ ਇਨ ਕਰ ਸਕਦਾ ਹੈ, ਤਾਂ ਉਹ [**ਸੈਟਿੰਗਾਂ** > **ਉਪਭੋਗਤਾ**](#users) ਖੋਲ੍ਹ ਸਕਦਾ ਹੈ, ਖਾਤਾ ਚੁਣ ਸਕਦਾ ਹੈ, ਅਤੇ ਉੱਥੇ ਇੱਕ **ਨਵਾਂ ਪਾਸਵਰਡ** ਸੈੱਟ ਕਰ ਸਕਦਾ ਹੈ।
- ਜੇਕਰ ਤੁਸੀਂ **ਬੰਦ ਕਰ ਦਿੱਤੇ ਗਏ** ਹੋ ਪਰ ਮਸ਼ੀਨ ਜਾਂ ਕੰਟੇਨਰ ਨੂੰ **ਸ਼ੈੱਲ ਐਕਸੈਸ** ਹੈ, ਤਾਂ ਇਮੇਜ ਨਾਲ ਆਉਣ ਵਾਲੇ ਹੈਲਪਰ ਨਾਲ ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰੋ (ਡਿਫਾਲਟ ਨਾਮ ਬਦਲਣ ਤੇ `transrewrt` ਬਦਲੋ, ਅਤੇ ਜੇਕਰ ਪਾਸਵਰਡ ਵਿੱਚ ਸਪੇਸ ਜਾਂ ਖਾਸ ਅੱਖਰ ਹਨ ਤਾਂ ਪਾਸਵਰਡ ਨੂੰ ਕੋਟ ਵਿੱਚ ਰੱਖੋ):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ਜੇਕਰ ਤੁਸੀਂ ਕਦੇ ਵੀ ਹੋਰ ਖਾਤੇ ਨਹੀਂ ਬਣਾਏ ਹਨ, ਤਾਂ ਡਿਫਾਲਟ ਐਡਮਿਨ ਯੂਜ਼ਰ ਨਾਮ `admin` ਹੈ। ਜਦੋਂ ਤੁਸੀਂ ਸਿਰਫ ਇੱਕ ਤਰਕ ਪਾਸ ਕਰਦੇ ਹੋ, ਤਾਂ ਇਸਨੂੰ `admin` ਲਈ ਨਵੇਂ ਪਾਸਵਰਡ ਵਜੋਂ ਲਿਆ ਜਾਂਦਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ Docker ਦੀ ਬਜਾਏ **ਸਰੋਤ ਚੈੱਕਆਊਟ** ਤੋਂ ਚਲਾ ਰਹੇ ਹੋ, ਤਾਂ ਵਰਤੋਂ:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

ਸਕ੍ਰਿਪਟ SQLite ਡੇਟਾਬੇਸ ਵਿੱਚ ਯੂਜ਼ਰ ਰਿਕਾਰਡ ਨੂੰ ਅਪਡੇਟ ਕਰਦਾ ਹੈ (ਅਤੇ ਜੇਕਰ ਗਾਇਬ ਹੈ ਤਾਂ `admin` ਯੂਜ਼ਰ ਬਣਾ ਸਕਦਾ ਹੈ)। ਰੀਸੈੱਟ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਨਵੇਂ ਪਾਸਵਰਡ ਨਾਲ ਸਾਇਨ ਇਨ ਕਰੋ।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ਡੈਸ਼ਬੋਰਡ ਹੋਰ ਉਪਭੋਗਤਾਵਾਂ ਲਈ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਦਿਖਾਉਂਦਾ (ਵੈੱਬ)

ਸਿਰਫ **ਪ੍ਰਸ਼ਾਸਕ** **ਯੂਜ਼ਰ** ਫਿਲਟਰ ਰਾਹੀਂ ਸਾਰੇ ਉਪਭੋਗਤਾਵਾਂ ਦਾ ਡਾਟਾ ਵੇਖ ਸਕਦੇ ਹਨ। ਨਿਯਮਤ ਉਪਭੋਗਤਾ ਸਿਰਫ ਆਪਣੀ ਗਤੀਵਿਧੀ ਵੇਖ ਸਕਦੇ ਹਨ।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ਮੈਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਨੂੰ ਬਦਲਿਆ ਅਤੇ ਸੰਪਾਦਨ ਗੁਆ ਦਿੱਤੇ

ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰਦੇ ਸਮੇਂ, **ਰਨ ਤੇ ਵਾਪਸ ਜਾਓ** ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਹਮੇਸ਼ਾ **ਸੇਵ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="quick-tips"></a>
## ਤੇਜ਼ ਸੁਝਾਅ

- [**ਅਨੁਵਾਦ**](#translate) ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਤਾਂ ਜੋ ਤੁਸੀਂ [**ਰੀਆਈਟ**](#rewrite) ਜਾਂ [**ਟਰਾਂਸਫਾਰਮ**](#transform) ਵੱਲ ਜਾਣ ਤੋਂ ਪਹਿਲਾਂ ਆਪਣੀ ਸੈਟਅੱਪ ਦੀ ਪੁਸ਼ਟੀ ਕਰ ਸਕੋ।
- ਰੋਜ਼ਾਨਾ ਸ਼ਬਦਾਵਲੀ ਸੁਧਾਰਾਂ ਲਈ [**ਰੀਆਈਟ**](#rewrite) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਇੱਕ ਖਾਸ ਕਾਰਜ ਲਈ ਦੁਹਰਾਉਣਯੋਗ ਵਰਕਫਲੋ ਦੀ ਲੋੜ ਹੋਣ 'ਤੇ [**ਟਰਾਂਸਫਾਰਮ**](#transform) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇ ਤੁਸੀਂ ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ 'ਤੇ ਨਜ਼ਰ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ [**ਡੈਸ਼ਬੋਰਡ**](#dashboard) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਪਿਛਲੇ ਕਾਰਜਾਂ ਅਤੇ ਉਨ੍ਹਾਂ ਦੇ ਪੂਰੇ ਇਨਪੁਟ/ਆਉਟਪੁਟ ਟੈਕਸਟ ਦੀ ਸਮੀਖਿਆ ਕਰਨ ਲਈ [**ਇਤਿਹਾਸ**](#history) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰਾਮਟ ਲਾਇਬ੍ਰੇਰੀ ਬਣਾ ਰਹੇ ਹੋ ਜਿਸਨੂੰ ਤੁਸੀਂ ਸੁਰੱਖਿਅਤ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ (ਵੇਖੋ [ਟਰਾਂਸਫਾਰਮ ਪ੍ਰਾਮਟ](#transform-prompts)) ਜਾਂ ਜੇ ਤੁਸੀਂ ਇਸਨੂੰ ਦੂਸਰਿਆਂ ਨਾਲ ਸਾਂਝਾ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਨਿਯਮਤ ਤੌਰ 'ਤੇ ਪ੍ਰਾਮਟ ਨਿਰਯਾਤ ਕਰੋ।
