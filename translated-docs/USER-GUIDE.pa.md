# ਵਰਤੋਂਕਰਤਾ ਗਾਈਡ

<br/>

<a id="introduction"></a>

## ਪਰਿਚਈ

ਟ੍ਰਾਂਸਰੀਵਰਟ ਤੁਹਾਡੀ ਟੈਕਸਟ ਨਾਲ ਕੰਮ ਕਰਨ ਵਿੱਚ ਤਿੰਨ ਮੁੱਖ ਤਰੀਕਿਆਂ ਨਾਲ ਮਦਦ ਕਰਦਾ ਹੈ:

- **ਅਨੁਵਾਦ ਕਰੋ** - ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਨੂੰ ਬਦਲੋ।
- **ਮੁੜ ਲਿਖੋ** - ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਵੱਖਰੀ ਸ਼ੈਲੀ ਵਿੱਚ ਫਿਰ ਤੋਂ ਲਿਖੋ, ਜਿਵੇਂ ਕਿ ਸਪਸ਼ਟ, ਛੋਟਾ ਜਾਂ ਹੋਰ ਅਧਿਕਾਰਤ ਢੰਗ ਨਾਲ।
- **ਬਦਲੋ** - ਨਿਰਦੇਸ਼ਾਂ ਨੂੰ ਕਹੇ ਜਾਂਦੇ ਕਸਟਮ ਏਆਈ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਟੈਕਸਟ ਨੂੰ ਪ੍ਰਕਿਰਿਆ ਕਰੋ।

<br/>

ਇਹ ਗਾਈਡ ਤੁਹਾਨੂੰ ਦੱਸਦੀ ਹੈ ਕਿ ਐਪ ਨੂੰ ਇੰਸਟਾਲ ਕਰਨ ਅਤੇ ਚਲਾਉਣ ਤੋਂ ਬਾਅਦ ਇਸਦੀ ਵਰਤੋਂ ਕਿਵੇਂ ਕਰਨੀ ਹੈ। ਇੰਸਟਾਲੇਸ਼ਨ ਕਦਮਾਂ ਲਈ, ਮੁੱਖ **[README](README.pa.md)** ਵੇਖੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਟ੍ਰਾਂਸਰੀਵਰਟ ਵਿੰਡੋਜ਼ ਅਤੇ ਲੀਨਕਸ ਲਈ ਇੱਕ ਡੈਸਕਟਾਪ ਐਪ ਦੇ ਤੌਰ 'ਤੇ ਅਤੇ ਇੱਕ ਆਪਣੇ ਸਰਵਰ 'ਤੇ ਵੈੱਬ ਐਪ ਦੇ ਤੌਰ 'ਤੇ ਉਪਲਬਧ ਹੈ। ਇਹ ਗਾਈਡ ਐਪ ਦੀ ਰੋਜ਼ਾਨਾ ਵਰਤੋਂ 'ਤੇ ਕੇਂਦਰਤ ਹੈ। ਜਿੱਥੇ ਕੁਝ ਸਿਰਫ਼ ਇੱਕ ਵਰਜਨ 'ਤੇ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਉੱਥੇ ਇਸਨੂੰ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਚਿੰਨ੍ਹਿਤ ਕੀਤਾ ਗਿਆ ਹੈ।

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

ਟਰਾਂਸਰੀਵਰਟ ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ, ਤੁਹਾਨੂੰ ਘੱਟੋ-ਘੱਟ ਇੱਕ ਏਆਈ ਪ੍ਰੋਵਾਈਡਰ ਤੱਕ ਪਹੁੰਚ ਦੀ ਲੋੜ ਹੈ। ਸਹਿਯੋਗੀ ਪ੍ਰੋਵਾਈਡਰ ਹਨ: [ਓਪਨਰਾਊਟਰ](https://openrouter.ai) (ਜੋ ਕਿ ਕਈ ਮਾਡਲਾਂ ਨੂੰ ਇਕੱਠਾ ਕਰਦਾ ਹੈ), ਓਪਨਐਆਈ, ਐਂਥਰੌਪਿਕ, ਗੂਗਲ ਜੈਮੀਨੀ, ਡੀਪਸੀਕ, ਗਰੌਕ, ਮਿਸਟਰਲ, ਐਕਸਏਆਈ, ਸੇਰੀਬਰਾਸ ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਲਈ [ਓਲਾਮਾ](https://ollama.com)।

ਸ਼ੁਰੂਆਤ ਕਰਨ ਲਈ ਭੁਗਤਾਨਯੋਗ ਮਾਡਲ ਦੀ ਚੋਣ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਆਪਣੀ ਓਪਨਰਾਊਟਰ ਏਪੀਆਈ ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਐਪ ਆਪਣੇ ਆਪ ਇੱਕ ਅੰਦਰੂਨੀ **ਮੁਫਤ** ਓਪਨਰਾਊਟਰ ਵਿਕਲਪ ਨੂੰ ਸਮਰੱਥ ਕਰ ਦਿੰਦਾ ਹੈ। ਇਹ ਤੁਹਾਨੂੰ ਤੁਰੰਤ ਪਾਠ ਦਾ ਅਨੁਵਾਦ, ਮੁੜਲਿਖਣ ਅਤੇ ਰੂਪਾਂਤਰ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਵਿਕਲਪਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ ਸੇਰੀਬਰਾਸ, ਗੂਗਲ, ਗਰੌਕ ਜਾਂ ਮਿਸਟਰਲ ਏਆਈ ਤੋਂ ਮੁਫਤ ਏਪੀਆਈ ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦੇ ਹੋ।

ਸਾਧਾਰਨ ਭਾਸ਼ਾ ਵਿੱਚ:

- ਇੱਕ **ਮਾਡਲ** ਏਆਈ ਇੰਜਣ ਹੈ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ। ਮਾਡਲਾਂ ਨੂੰ ਇੱਕ **ਪ੍ਰੋਵਾਈਡਰ ਪਰਿਉਪਰਤ** (ਉਦਾਹਰਣ ਲਈ `openrouter/…`, `openai/…`, `ollama/…`) ਨਾਲ ਸੂਚੀਬੱਧ ਕੀਤਾ ਗਿਆ ਹੈ।
- ਇੱਕ **ਏਪੀਆਈ ਕੁੰਜੀ** (ਜਾਂ, ਓਲਾਮਾ ਲਈ, ਇੱਕ **ਬੇਸ ਯੂਆਰਐਲ**) ਉਹ ਤਰੀਕਾ ਹੈ ਜਿਸ ਦੁਆਰਾ ਐਪ ਉਸ ਪ੍ਰੋਵਾਈਡਰ ਤੱਕ ਪਹੁੰਚਦਾ ਹੈ।

ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਲਈ [**ਸੈਟਿੰਗਜ਼** > **API ਕਾਨਫਿਗ**](#api-config) ਵਿੱਚ ਕੁੰਜੀਆਂ ਸ਼ਾਮਲ ਕਰੋ। ਕੇਵਲ OpenRouter ਵਰਤਣ ਲਈ, ਹੇਠਾਂ ਦਿੱਤੇ [API ਕੁੰਜੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੇਂ](#how-to-get-an-api-key-desktop-app) ਵੇਖੋ। ਜੇਕਰ ਤੁਸੀਂ API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ Ollama (ollema.com ਤੋਂ) ਇੰਸਟਾਲ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ `translategemma:4b` ਵਰਗੇ ਸਥਾਨਕ ਮਾਡਲ ਵਰਤ ਸਕਦੇ ਹੋ।

ਜੇਕਰ ਤੁਸੀਂ **ਵੈੱਬ ਵਰਜਨ** ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਸਰਵਰ ਓਨਰ ਵਾਤਾਵਰਣ ਚਲਾ ਕੇ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਕਾਨਫਿਗਰ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਐਪਲੀਕੇਸ਼ਨ ਵਿੱਚ ਸਿੱਧੇ API ਕੁੰਜੀਆਂ ਦਰਜ ਨਹੀਂ ਕਰ ਸਕਦੇ।

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>

### ਮੁਫਤ ਓਪਨਰਾਊਟਰ API ਕੁੰਜੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰਨੀ ਹੈ (ਡੈਸਕਟਾਪ ਐਪ)

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਹੇਠਾਂ ਦਿੱਤੀਆਂ ਚਰਨਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ:

1. ਆਪਣੇ ਵੈੱਬ ਬਰਾਊਜ਼ਰ ਵਿੱਚ [ਓਪਨਰਾਊਟਰ](https://openrouter.ai) ਨੂੰ ਜਾਓ।
2. ਇੱਕ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਸਾਈਨ ਇਨ ਕਰੋ।
3. [ਕੁੰਜੀਆਂ](https://openrouter.ai/keys) ਪੰਨੇ ਨੂੰ ਖੋਲ੍ਹੋ।
4. ਇੱਕ ਨਵੀਂ API ਕੁੰਜੀ ਬਣਾਉਣ ਲਈ ਬਟਨ ਤੇ ਕਲਿੱਕ ਕਰੋ।
5. ਕੁੰਜੀ ਨੂੰ ਇੱਕ ਨਾਮ ਦਿਓ ਤਾਂ ਜੋ ਤੁਸੀਂ ਇਸਨੂੰ ਬਾਅਦ ਵਿੱਚ ਪਛਾਣ ਸਕੋ।
6. ਨਵੀਂ API ਕੁੰਜੀ ਨੂੰ ਕਾਪੀ ਕਰੋ।
7. ਟ੍ਰਾਂਜ਼ਰਿਵਰਟ ਨੂੰ ਵਾਪਸ ਜਾਓ ਅਤੇ **ਸੈਟਿੰਗਜ਼** > **API ਕਾਨਫਿਗ** ਖੋਲ੍ਹੋ।
8. **ਓਪਨਰਾਊਟਰ API ਕੁੰਜੀ** (ਹੇਠਾਂ **ਸੈਟਿੰਗਜ਼** > **API ਕਾਨਫਿਗ**) ਵਿੱਚ ਕੁੰਜੀ ਪੇਸਟ ਕਰੋ।
9. ਇਹ ਸੁਨਿਸ਼ਚਿਤ ਕਰਨ ਲਈ ਕਿ ਇਹ ਕੰਮ ਕਰਦੀ ਹੈ, **ਓਪਨਰਾਊਟਰ ਕੁੰਜੀ ਟੈਸਟ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/><br/>

<a id="getting-started"></a>

## ਸ਼ੁਰੂਆਤ

ਜੇਕਰ ਤੁਸੀਂ ਪਹਿਲੀ ਵਾਰ Transrewrt ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਹੇਠ ਲਿਖੇ ਕ੍ਰਮ ਦੀ ਪਾਲਣਾ ਕਰੋ:

1. ਐਪ ਖੋਲ੍ਹੋ।
2. ਜੇ ਲੋੜ ਹੋਵੇ ਤਾਂ, ਗਲੋਬ ਆਈਕਨ ਤੋਂ ਆਪਣੀ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।
3. ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਵਿੱਚ ਹੋ, ਤਾਂ [**ਸੈਟਿੰਗਾਂ** > **API ਕੌਨਫਿਗ**](#api-config) ਖੋਲ੍ਹੋ, ਘੱਟੋ-ਘੱਟ ਇੱਕ ਪ੍ਰਦਾਤਾ (ਉਦਾਹਰਨ ਲਈ OpenRouter) ਲਈ ਇੱਕ API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰੋ ਅਤੇ ਇਸਦੇ ਕੰਮ ਕਰਨ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ **ਟੈਸਟ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
4. [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਚੁਣੇ ਗਏ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ।
5. [**ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਖੋਲ੍ਹੋ ਅਤੇ, ਜੇ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਆਪਣੀਆਂ **ਪ੍ਰਮੁੱਖ ਭਾਸ਼ਾਵਾਂ** ਚੁਣੋ, ਤਾਂ ਜੋ ਤੁਹਾਡੀਆਂ ਸਭ ਤੋਂ ਜ਼ਿਆਦਾ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀ ਭਾਸ਼ਾਵਾਂ ਪਹਿਲਾਂ ਨਜ਼ਰ ਆਉਣ।
6. **ਅਨੁਵਾਦ ਕਰੋ** ਤੇ ਜਾਓ ਅਤੇ ਇਹ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਇੱਕ ਸਧਾਰਨ ਅਨੁਵਾਦ ਚਲਾਉ, ਕਿ ਸਭ ਕੁਝ ਠੀਕ ਕੰਮ ਕਰ ਰਿਹਾ ਹੈ।
7. ਇਕ ਵਾਰ ਜਦੋਂ ਇਹ ਕੰਮ ਕਰ ਜਾਵੇ, ਤਾਂ **ਮੁੜ ਲਿਖੋ** ਅਤੇ ਫਿਰ **ਰੂਪਾੰਤਰਿਤ ਕਰੋ** ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

ਇਸ ਕ੍ਰਮ ਦਾ ਮਹੱਤਵ ਹੈ। ਇਹ ਪਹਿਲੀ ਵਰਤੋਂ ਵੇਲੇ ਹੋਣ ਵਾਲੀਆਂ ਸਭ ਤੋਂ ਆਮ ਸਮੱਸਿਆਵਾਂ ਨੂੰ ਰੋਕਦਾ ਹੈ: ਐਪ ਵਿੱਚ ਕੰਮ ਕਰ ਰਹੀ API ਕੁਨੈਕਸ਼ਨ ਜਾਂ ਚੁਣਿਆ ਹੋਇਆ ਮਾਡਲ ਤੋਂ ਪਹਿਲਾਂ ਕਿਸੇ ਕਾਰਜ ਨੂੰ ਚਲਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨਾ।

### ਟੂਲਬਾਰ

ਐਪ ਵਿੱਚ ਤੁਸੀਂ ਜਿੱਥੇ ਵੀ ਹੋਵੋਂਗੇ, ਉੱਥੇ ਟੂਲਬਾਰ ਥੋੜ੍ਹਾ ਬਦਲ ਜਾਂਦਾ ਹੈ।

- ਖੱਬੇ ਪਾਸੇ, ਇਸ ਵਿੱਚ ਮੌਜੂਦਾ ਪੰਨੇ ਦਾ ਨਾਮ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ।
- ਸੱਜੇ ਪਾਸੇ, ਇਸ ਵਿੱਚ **ਮਾਡਲ ਚੋਣਕਰਤਾ** ਅਤੇ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਵਾਲਾ ਭਾਗ ਹੁੰਦਾ ਹੈ।

**ਮਾਡਲ ਚੋਣਕਰਤਾ** ਤੁਹਾਨੂੰ ਮੌਜੂਦਾ ਕਾਰਜ ਲਈ ਕਿਹੜਾ ਐਆਈ ਇੰਜਨ ਵਰਤਣਾ ਹੈ, ਚੁਣਨ ਦੀ ਸੁਵਿਧਾ ਦਿੰਦਾ ਹੈ।

  ![ਮਾਡਲ ਚੋਣਕਰਤਾ](../images/screenshots/pa/model-selector.png)

ਕੁਝ ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਨੂੰ ਹਮੇਸ਼ਾ ਉਪਲਬਧ ਨਹੀਂ ਹੁੰਦਾ—ਕਈ ਵਾਰ ਉਹ ਆਫਲਾਈਨ ਜਾਂ ਵਰਤੋਂ ਦੀ ਸੀਮਾ ਵਿੱਚ ਹੁੰਦੇ ਹਨ। ਜੇਕਰ ਇਹ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਐਪ ਆਪਣੇ ਆਪ ਉਸ ਮਾਡਲ ਨੂੰ ਤੁਹਾਡੀ ਉਪਲਬਧ ਸੂਚੀ ਵਿੱਚੋਂ ਹਟਾ ਦੇਵੇਗੀ। ਜੋ ਮਾਡਲ ਦਿਖਾਈ ਦੇਣਗੇ, ਉਹਨਾਂ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਮਾਡਲ**](#models) ਵੱਲ ਜਾਓ ਅਤੇ ਆਪਣੀ ਮਾਡਲ ਸੂਚੀ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰੋ।
ਤੁਸੀਂ ਮਾਡਲ ਦੀਆਂ ਸੈਟਿੰਗਸ ਨੂੰ ਸਿੱਧੇ ਟੂਲਬਾਰ ਵਿੱਚ ਮਾਡਲ ਦੇ ਨਾਮ ਦੇ ਖੱਬੇ ਪਾਸੇ ਪ੍ਰਦਾਤਾ ਆਈਕਾਨ ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਖੋਲ੍ਹ ਸਕਦੇ ਹੋ।

<a id="input-and-output-panels"></a>

### ਇਨਪੁਟ ਅਤੇ ਆਊਟਪੁਟ ਪੈਨਲ

ਬਹੁਤ ਸਾਰੇ ਵਰਕਸਪੇਸਿਸ ਬਾਏਂ ਪਾਸੇ ਦੇ **ਇਨਪੁਟ** ਪੈਨਲ ਅਤੇ ਸੱਜੇ ਪਾਸੇ ਦੇ **ਆਊਟਪੁਟ** ਪੈਨਲ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹਨ।

ਹਰੇਕ ਪੈਨਲ ਵਿੱਚ ਹੇਠ ਲਿਖਿਆਂ ਦਾ ਵੀ ਪ੍ਰਦਰਸ਼ਨ ਕੀਤਾ ਜਾਂਦਾ ਹੈ:

| **ਇਨਪੁਟ**                                                          | **ਆਉਟਪੁਟ**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - ਅੱਖਰਾਂ ਦੀ ਗਿਣਤੀ <br/>- ਸ਼ਬਦਾਂ ਦੀ ਗਿਣਤੀ <br/>- ਪੈਰੇ ਦੀ ਗਿਣਤੀ   <br/> | - ਕੰਮ ਪੂਰਾ ਕਰਨ ਵਿੱਚ ਕਿੰਨਾ ਸਮਾਂ ਲੱਗਾ<br/>- **TPS** (ਪ੍ਰਤੀ ਸਕਿੰਟ ਟੋਕਨ)<br/>- ਅੱਖਰ, ਸ਼ਬਦ ਅਤੇ ਪੈਰੇ ਦੀ ਗਿਣਤੀ<br/>- ਵਰਤਿਆ ਗਿਆ ਮਾਡਲ |

ਜੇਕਰ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦਾਂ ਬਾਰੇ ਸੋਚ ਰਹੇ ਹੋ:

- **ਟੋਕਨ** ਦਾ ਅਰਥ ਹੈ ਪਾਠ ਦਾ ਛੋਟਾ ਹਿੱਸਾ। ਤੁਸੀਂ ਇਸਨੂੰ ਸ਼ਬਦ ਦਾ ਹਿੱਸਾ ਜਾਂ ਛੋਟਾ ਸ਼ਬਦ ਸਮਝ ਸਕਦੇ ਹੋ।
- **TPS** ਦਾ ਅਰਥ ਹੈ ਕਿ ਮਾਡਲ ਨੇ ਹਰ ਸੈਕਿੰਡ ਵਿੱਚ ਕਿੰਨੇ ਪਾਠ ਹਿੱਸੇ ਪ੍ਰਕਿਰਿਆ ਕੀਤੇ।

<br/>

ਤੁਸੀਂ ਹਰੇਕ ਕਾਰਵਾਈ ਦੀ ਲਾਗਤ (ਜੇ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਕੁੱਲ ਲਾਗਤ ਨੂੰ ਵੀ ਨਿਗਰਾਨੀ ਕਰ ਸਕਦੇ ਹੋ, [**ਸੈਟਿੰਗਾਂ** > **ਜਨਰਲ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ `ਕਾਰਵਾਈਆਂ 'ਤੇ ਲਾਗਤ ਜਾਣਕਾਰੀ ਵੇਖੋ` ਵਿਕਲਪ ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ।

<br/><br/>

<a id="translate"></a>

## ਅਨੁਵਾਦ

**ਅਨੁਵਾਦ** ਨੂੰ ਤਦ ਵਰਤੋਂ ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਭਾਸ਼ਾ ਵਿੱਚੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਨੂੰ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ।

![ਅਨੁਵਾਦ ਕਾਰਜਸਥਾਨ](../images/screenshots/pa/translate.png)

<br/>

<a id="translate-text"></a>

### ਟੈਕਸਟ ਅਨੁਵਾਦ ਕਰੋ

1. **ਅਨੁਵਾਦ** ਖੋਲ੍ਹੋ।
2. **ਤੋਂ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
3. **ਨੂੰ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. **ਇਨਪੁਟ** ਵਿੱਚ ਟਾਈਪ ਕਰੋ ਜਾਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰੋ।
6. **ਅਨੁਵਾਦ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
7. **ਆਉਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।
8. ਜੇਕਰ ਤੁਸੀਂ ਨਤੀਜਾ ਕਾਪੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਕਾਪੀ ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।

<br/>

<a id="language-selection"></a>

### ਭਾਸ਼ਾ ਚੋਣ

- **From** ਇੱਕ ਖਾਸ ਭਾਸ਼ਾ ਜਾਂ **ਭਾਸ਼ਾ ਪਛਾਣਨਾ** ਹੋ ਸਕਦੀ ਹੈ।
- **To** ਉਹ ਭਾਸ਼ਾ ਹੈ ਜਿਸ ਵਿੱਚ ਤੁਸੀਂ ਨਤੀਜਾ ਚਾਹੁੰਦੇ ਹੋ।

ਤੁਹਾਡੀ ਚੁਣੀ ਹੋਈ **ਟੌਪ ਭਾਸ਼ਾਵਾਂ** ਸੂਚੀ ਦੇ ਸਿਖਰ 'ਤੇ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ। ਤੁਸੀਂ ਇਨ੍ਹਾਂ ਨੂੰ [**ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਵਿੱਚ ਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="helpful-translation-settings"></a>

### ਸਹਾਇਕ ਅਨੁਵਾਦ ਸੈਟਿੰਗਾਂ

[**ਸੈਟਿੰਗਾਂ** > **ਜਨਰਲ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ, ਤੁਸੀਂ ਅਨੁਵਾਦ ਦੇ ਵਿਵਹਾਰ ਨੂੰ ਬਦਲ ਸਕਦੇ ਹੋ:

- **ਪੇਸਟ ਕਰਨ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਰੰਤ ਟੈਕਸਟ ਪੇਸਟ ਕਰਨ ਦੇ ਬਾਅਦ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।
- **ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਨਤੀਜਾ ਆਟੋ-ਕਾਪੀ** ਸਫਲਤਾਪੂਰਵਕ ਚਲਣ ਤੋਂ ਬਾਅਦ ਨਤੀਜਾ ਆਟੋਮੈਟਿਕ ਤੌਰ 'ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।
- **ਸਮਾਂ-ਬਾਹਰ (ms)** ਐਪ ਨੂੰ ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਕਿੰਨਾ ਸਮਾਂ ਇੰਤਜ਼ਾਰ ਕਰਨਾ ਚਾਹੀਦਾ ਹੈ, ਇਸ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।
- **ਐਂਟਰ** ਇਹ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ ਕਿ ਜਦੋਂ ਤੁਸੀਂ `ਐਂਟਰ` ਦਬਾਉਂਦੇ ਹੋ ਤਾਂ ਕੀ ਹੁੰਦਾ ਹੈ:

<br/><br/>

<a id="rewrite"></a>

## ਮੁੜ ਲਿਖੋ

ਜਦੋਂ ਮੁੱਖ ਅਰਥ ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ ਸ਼ਬਦਾਂ ਵਿੱਚ ਸੁਧਾਰ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਰੀਆਈਟ** ਵਰਤੋਂ।

![ਮੁੜ ਲੇਖਣ ਕਾਰਜਸਥਾਨ](../images/screenshots/pa/rewrite.png)

ਇਹ ਹੇਠ ਲਿਖਿਆਂ ਲਈ ਵਰਤੋਂ ਲਈ ਉਪਯੋਗੀ ਹੈ:

- ਸ਼ਬਦਾਂ ਦੀ ਸੋਧ ਅਤੇ ਵਿਆਕਰਣ ਠੀਕ ਕਰਨਾ (**ਸ਼ਬਦਾਂ ਦੀ ਸੋਧ ਅਤੇ ਵਿਆਕਰਣ ਦੀ ਜਾਂਚ ਕਰੋ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਸਪਸ਼ਟ ਬਣਾਉਣਾ (**ਸਪਸ਼ਟਤਾ ਵਿੱਚ ਸੁਧਾਰ ਕਰੋ**)
- ਇੱਕ ਹੀ ਚੱਕਰ ਵਿੱਚ ਨਿਸ਼ਚਿਤ ਮੁੜ-ਢਾਂਚੇ ਦੇਣਾ (**ਵਿਕਲਪਕ ਸੰਸਕਰਣ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਅਧਿਕਾਰਤ ਜਾਂ ਘੱਟ ਅਧਿਕਾਰਤ ਬਣਾਉਣਾ (**ਅਧਿਕਾਰਤ** / **ਅਨਫਾਰਮਲ**)
- ਟੈਕਸਟ ਨੂੰ ਛੋਟਾ ਜਾਂ ਲੰਮਾ ਕਰਨਾ (**ਛੋਟਾ ਕਰੋ** / **ਵਧਾਓ**)
- ਟੈਕਸਟ ਨੂੰ ਹੋਰ ਤਕਨੀਕੀ ਆਵਾਜ਼ ਦੇਣਾ (**ਤਕਨੀਕੀ ਬਣਾਓ**)

<br/>

> 💡 **ਸੁਝਾਅ**<br/>
> ਜਦੋਂ ਤੁਸੀਂ "**ਸ਼ਬਦਾਂ ਦੀ ਸੋਧ ਅਤੇ ਵਿਆਕਰਣ ਦੀ ਜਾਂਚ ਕਰੋ**" ਮੋਡ ਵਰਤਦੇ ਹੋ ਤਾਂ ਆਉਟਪੁੱਟ ਪੈਨਲ ਵਿੱਚ ਇੱਕ **ਤਬਦੀਲੀਆਂ ਵੇਖੋ** ਸਵਿੱਚ (Coppy ਦੇ ਨੇੜੇ-ਤੇੜੇ) ਪ੍ਰਗਟ ਹੁੰਦੀ ਹੈ।
> ਟੈਕਸਟ ਵਿੱਚ ਲਾਗੂ ਕੀਤੀਆਂ ਤਬਦੀਲੀਆਂ ਨੂੰ ਵੇਖਣ ਜਾਂ ਓਹਲੇ ਕਰਨ ਲਈ ਇਸਨੂੰ ਚਾਲੂ ਜਾਂ ਬੰਦ ਕਰੋ।

<a id="transform"></a>

## ਤਬਦੀਲੀ

ਜਦੋਂ ਤੁਸੀਂ ਚਾਹੋ ਕਿ ਏਆਈ ਨਿਰਦੇਸ਼ਾਂ ਦੇ ਇੱਕ ਆਪਣੇ ਸੈੱਟ ਦੀ ਪਾਲਣਾ ਕਰੇ ਤਾਂ **ਤਬਦੀਲੀ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਤਬਦੀਲੀ ਵਰਕਸਪੇਸ](../images/screenshots/pa/transform.png)

ਐਪ ਦਾ ਇਹ ਸਭ ਤੋਂ ਲਚਕੀਲਾ ਹਿੱਸਾ ਹੈ। ਤੁਸੀਂ ਕੰਮਾਂ ਲਈ ਇਸ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ ਜਿਵੇਂ:

- ਨੋਟਾਂ ਦਾ ਸਾਰ ਕੱਢਣਾ
- ਕੱਚੇ ਟੈਕਸਟ ਨੂੰ ਤਿਆਰ ਈਮੇਲ ਵਿੱਚ ਬਦਲਣਾ
- ਮੁੱਖ ਬਿੰਦੂਆਂ ਨੂੰ ਕੱਢਣਾ
- ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਖਾਸ ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲਣਾ
- ਇਨਪੁਟ ਟੈਕਸਟ ਨਾਲ ਹੋਰ ਵੀ ਕੋਈ ਆਪਣੀ ਮਰਜ਼ੀ ਦੀ ਗਤੀਵਿਧੀ

<br/>

<a id="run-an-existing-prompt"></a>

### ਇੱਕ ਮੌਜੂਦਾ ਪ੍ਰਾਮਟ ਚਲਾਓ

1. **ਟਰਾਂਸਫਾਰਮ** ਖੋਲ੍ਹੋ।
2. ਪ੍ਰਾਮਟ ਸੂਚੀ ਤੋਂ ਇੱਕ ਪ੍ਰਾਮਟ ਚੁਣੋ।
3. ਜੇਕਰ **ਟਾਰਗੇਟ** ਭਾਸ਼ਾ ਬਾਕਸ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ, ਤਾਂ ਜੇ ਤੁਸੀਂ ਚਾਹੋ ਤਾਂ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. **ਇਨਪੁਟ** ਵਿੱਚ ਟਾਈਪ ਕਰੋ ਜਾਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰੋ।
5. **ਟਰਾਂਸਫਾਰਮ** ਤੇ ਕਲਿੱਕ ਕਰੋ।
6. **ਆਉਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### ਜੇਕਰ ਤੁਹਾਡੇ ਕੋਲ ਹਾਲੇ ਤੱਕ ਕੋਈ ਪ੍ਰੌਪਟ ਨਹੀਂ ਹੈ

ਜੇਕਰ ਤੁਹਾਡੀ ਪ੍ਰੌਪਟ ਸੂਚੀ ਖਾਲੀ ਹੈ, ਤਾਂ ਟਰਾਂਸਫਾਰਮ ਵਰਕਸਪੇਸ ਵਿੱਚ **ਨਮੂਨੇ ਪ੍ਰੌਪਟ ਲੋਡ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਨਿਰਯਾਤ/ਆਯਾਤ ਕਤਾਰ ਵਿੱਚ [**ਸੈਟਿੰਗਾਂ** > **ਟਰਾਂਸਫਾਰਮ ਪ੍ਰੌਪਟ**](#transform-prompts) ਵਿੱਚ ਹਮੇਸ਼ਾ ਉਹੀ ਕੰਟਰੋਲ ਉਪਲਬਧ ਹੈ। ਦੋਵੇਂ ਅੰਦਰੂਨੀ ਉਦਾਹਰਣਾਂ ਜੋੜਦੇ ਹਨ ਤਾਂ ਜੋ ਤੁਸੀਂ ਤੇਜ਼ੀ ਨਾਲ ਸ਼ੁਰੂ ਕਰ ਸਕੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਨਮੂਨੇ ਪ੍ਰੌਪਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਪ੍ਰਦਾਨ ਕੀਤੇ ਗਏ ਹਨ। ਉਨ੍ਹਾਂ ਨੂੰ ਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੌਪਟ ਨੂੰ ਸੋਧ ਸਕਦੇ ਹੋ ਅਤੇ ਇਸ ਨੂੰ ਆਪਣੀ ਭਾਸ਼ਾ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰਨ ਲਈ **ਪ੍ਰੌਪਟ ਅਨੁਵਾਦ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="create-a-prompt-quickly"></a>

### ਤੁਰੰਤ ਇੱਕ ਪ੍ਰੌਪਟ ਬਣਾਓ

ਪ੍ਰੌਪਟ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਤਰੀਕਾ ਇਹ ਹੈ:

1. **ਨਵਾਂ ਪ੍ਰੌਪਟ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
2. **ਪ੍ਰੌਪਟ ਪੈਦਾ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਦੱਸੋ ਕਿ ਤੁਸੀਂ ਪ੍ਰੌਪਟ ਨਾਲ ਕੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।
4. ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. ਐਪ ਨੂੰ ਤੁਹਾਡੇ ਲਈ ਇੱਕ ਡ੍ਰਾਫਟ ਬਣਾਉਣ ਦਿਓ।
6. ਡ੍ਰਾਫਟ ਦੀ ਸਮੀਖਿਆ ਕਰੋ ਅਤੇ **ਸੰਭਾਲੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

![ਪ੍ਰੌਪਟ ਪੈਦਾ ਕਰੋ](../images/screenshots/pa/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>

### ਇੱਕ ਪ੍ਰੌਪਟ ਨੂੰ ਸੋਧੋ

ਜਦੋਂ ਤੁਸੀਂ ਕੋਈ ਪ੍ਰੌਪਟ ਬਣਾਉਂਦੇ ਹੋ ਜਾਂ ਸੋਧਦੇ ਹੋ, ਤਾਂ ਸੰਪਾਦਕ ਖੱਬੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ ਅਤੇ ਇੱਕ ਟੈਸਟ ਖੇਤਰ ਸੱਜੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

![ਟਰਾਂਸਫਾਰਮ ਪ੍ਰੌਪਟ ਸੰਪਾਦਕ](../images/screenshots/pa/transform-prompt-edit.png)

ਮੁੱਖ ਖੇਤਰ ਹਨ:

- **ਪ੍ਰੌਪਟ ਦਾ ਨਾਮ**: ਪ੍ਰੌਪਟ ਸੂਚੀ ਵਿੱਚ ਦਿਖਾਇਆ ਗਿਆ ਨਾਮ।
- **ਪ੍ਰੌਪਟ ਨਿਰਦੇਸ਼ (ਵਿਕਲਪਕ)**: ਉਪਭੋਗਤਾ ਨੂੰ ਪ੍ਰੌਪਟ ਚਲਾਉਂਦੇ ਸਮੇਂ ਵੇਖਾਇਆ ਜਾਣ ਵਾਲਾ ਛੋਟਾ ਸੰਕੇਤ।
- **ਮਾਡਲ ਭੂਮਿਕਾ**: ਐਆਈ ਨੂੰ ਦਿੱਤੀ ਗਈ ਸਮੁੱਚੀ ਭੂਮਿਕਾ, ਜਿਵੇਂ 'ਤੁਸੀਂ ਇੱਕ ਸਹਾਇਕ ਸਹਾਇਕ ਹੋ।'
- **ਮਾਡਲ ਨਿਰਦੇਸ਼ (ਇੱਕ ਲਾਈਨ ਪ੍ਰਤੀ)**: ਉਹ ਖਾਸ ਨਿਯਮ ਜੋ ਤੁਸੀਂ ਐਆਈ ਨੂੰ ਅਨੁਸਰਨ ਕਰਨ ਲਈ ਚਾਹੁੰਦੇ ਹੋ।
- **ਆਉਟਪੁੱਟ ਵਿਵਰਣ**: ਨਤੀਜੇ ਨੂੰ ਦਰਸਾਉਣ ਵਾਲਾ ਛੋਟਾ ਸ਼ਬਦ, ਜਿਵੇਂ 'ਸਾਰ' ਜਾਂ 'ਮੁੜ-ਲਿਖੋ'।
- **ਤਾਪਮਾਨ (0.0 → 1.0)**: ਮਾਡਲ ਕਿਵੇਂ ਵਿਵਹਾਰ ਕਰੇਗਾ; ਹੇਠਾਂ ਦੇਖੋ।
- **ਟੀਚਾ ਭਾਸ਼ਾ ਪੁੱਛੋ**: ਜਦੋਂ ਪ੍ਰੌਪਟ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ ਤਾਂ ਟੀਚਾ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲਾ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।

ਜੇਕਰ ਤਕਨੀਕੀ ਸ਼ਬਦ **ਤਾਪਮਾਨ** ਤੁਹਾਡੇ ਲਈ ਨਵਾਂ ਹੈ, ਤਾਂ ਇਸ ਬਾਰੇ ਇਸ ਤਰ੍ਹਾਂ ਸੋਚੋ:

- ਇੱਕ **ਘੱਟ** ਤਾਪਮਾਨ ਵਧੇਰੇ ਸਥਿਰ, ਭਰੋਸੇਯੋਗ ਨਤੀਜੇ ਦਿੰਦਾ ਹੈ।

- **ਵੱਧ** ਤਾਪਮਾਨ ਵੱਧ ਵਿਭਿੰਨਤਾ ਅਤੇ ਰਚਨਾਤਮਕਤਾ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

ਤੁਸੀਂ ਵਰਤ ਸਕਦੇ ਹੋ:

- ਸਧਾਰਨ ਵੇਰਵੇ ਤੋਂ ਇੱਕ ਨਵਾਂ ਡ੍ਰਾਫਟ ਬਣਾਉਣ ਲਈ **`Generate prompt`**
- ਮੌਜੂਦਾ ਪ੍ਰਾਮਟ ਨੂੰ ਸੁਧਾਰਨ ਲਈ **`Improve prompt`**
- ਪ੍ਰਾਮਟ ਫੀਲਡਾਂ ਨੂੰ ਅਨੁਵਾਦਿਤ ਕਰਨ ਲਈ **`Translate prompt`**

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> **`Back to Run`** ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **`Save`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਜੇਕਰ ਤੁਸੀਂ ਬਿਨਾਂ ਸੰਭਾਲੇ ਵਾਪਸ ਜਾਂਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਡੇ ਬਦਲਾਅ ਖ਼ਤਮ ਹੋ ਜਾਣਗੇ।

<a id="test-a-prompt-before-using-it"></a>

ਸੱਜੇ ਪੈਨਲ ਵਿੱਚ ਟੈਸਟ ਪੈਨਲ ਤੁਹਾਨੂੰ ਆਪਣੀ ਦਿਨ-ਬ-ਦਿਨ ਦੀ ਵਰਤੋਂ ਤੋਂ ਪਹਿਲਾਂ ਨਮੂਨਾ ਟੈਕਸਟ ਨਾਲ ਆਪਣੇ ਪ੍ਰਾਮਿਪਟ ਨੂੰ ਅਜ਼ਮਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

- **ਵਰਤੋਂ ਅਨੁਸਾਰ** ਗਤੀਵਿਧੀ ਨੂੰ ਅਨੁਵਾਦ ਭਾਸ਼ਾ, ਮੁੜ ਲੇਖਨ ਮੋਡ, ਅਤੇ ਰੂਪਾਂਤਰਣ ਪੰਜੀ ਨਾਲ ਤੋੜਦਾ ਹੈ।
- **ਮਾਡਲ ਅਨੁਸਾਰ** ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਕਿਹੜੇ ਮਾਡਲ ਵਰਤੇ ਅਤੇ ਉਹਨਾਂ ਦੀ ਕੀ ਲਾਗਤ ਆਈ।
- **ਹਰ ਦਿਨ ਅਨੁਸਾਰ** ਰੋਜ਼ਾਨਾ ਕੁੱਲ ਰਕਮ ਦਰਸਾਉਂਦਾ ਹੈ।
- **ਸਾਰੇ ਕਾਲ** ਪੂਰੀ ਕਾਲ ਇਤਿਹਾਸ ਦਿਖਾਉਂਦੇ ਹਨ ਅਤੇ ਤੁਹਾਨੂੰ ਇਸਨੂੰ ਐਕਸਪੋਰਟ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦੇ ਹਨ।

**ਵਿਵਹਾਰ**

- **ENTER ਲਈ ਵਿਵਹਾਰ** `Enter`ਨੂੰ ਟਾਸਕ ਚਲਾਉਣ ਜਾਂ ਨਵੀਂ ਲਾਈਨ ਸ਼ਾਮਲ ਕਰਨ ਵਿੱਚੋਂ ਚੁਣਦਾ ਹੈ।
- **ਪੇਸਟ ਕਰਨ ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਤੁਸੀਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰਦੇ ਹੀ ਅਨੁਵਾਦ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- **ਨਤੀਜਾ ਕਲਿੱਪਬੋਰਡ ਵਿੱਚ ਆਟੋ-ਕਾਪੀ ਕਰੋ** ਸਫਲ ਨਤੀਜਿਆਂ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪਿੰਗ ਦੌਰਾਨ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ।
- **ਸਮਾਂ-ਸੀਮਾ (ms)** ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਲਈ ਉਡੀਕ ਸਮਾਂ ਨਿਰਧਾਰਤ ਕਰਦਾ ਹੈ।

**ਇਤਿਹਾਸ**

- **ਚੱਲਣ ਇਤਿਹਾਸ ਰੱਖੋ** ਸਾਈਡਬਾਰ ਦੇ [**ਇਤਿਹਾਸ**](#history) ਵਿਊ ਲਈ ਹਰੇਕ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਣ ਅਤੇ ਤਬਦੀਲੀ ਲਈ **ਇਨਪੁਟ ਅਤੇ ਆਉਟਪੁਟ ਟੈਕਸਟ** ਸਟੋਰ ਕਰਨ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ। ਬੰਦ ਕਰਨ ਨਾਲ ਪੁਸ਼ਟੀ ਲਈ ਪੁੱਛਿਆ ਜਾਵੇਗਾ; ਜੇਕਰ ਤੁਸੀਂ ਪੁਸ਼ਟੀ ਕਰਦੇ ਹੋ, ਤਾਂ ਸਟੋਰ ਕੀਤਾ ਇਤਿਹਾਸ ਟੈਕਸਟ ਡੇਟਾਬੇਸ ਤੋਂ ਹਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।

- **ਇਤਿਹਾਸ ਡੇਟਾ ਮਿਟਾਓ** ਤੁਹਾਨੂੰ ਉਮਰ ਅਨੁਸਾਰ ਸਟੋਰ ਕੀਤੇ ਗਏ ਟੈਕਸਟ ਨੂੰ ਹਟਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ (ਉਦਾਹਰਣ ਵਜੋਂ ਕੁਝ ਮਹੀਨਿਆਂ ਤੋਂ ਪੁਰਾਣਾ ਜਾਂ **ਸਭ ਡੇਟਾ (ਸਾਫ਼)**) **ਡੇਟਾ ਮਿਟਾਓ** ਨੂੰ ਵਰਤਦੇ ਹੋਏ। ਇਹ ਸਿਰਫ **ਇਤਿਹਾਸ** ਵੇਖੋ 'ਤੇ ਸੰਭਾਲੇ ਗਏ ਨਿਰਵਹਨ ਟੈਕਸਟ 'ਤੇ ਅਸਰ ਕਰਦਾ ਹੈ; ਇਹ ਲਾਗਤ ਜਾਂ ਵਰਤੋਂ ਕੁੱਲ ਅੰਕੜੇ ਨੂੰ** ਮਿਟਾਉਂਦਾ ਨਹੀਂ **। **ਲਾਗਤ** ਡੇਟਾ ਨੂੰ ਹਟਾਉਣ ਜਾਂ ਕੱਟਣ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਵਰਤੋਂ।

**ਦਿੱਖ**

- **ਕਾਰਵਾਈਆਂ ਉੱਤੇ ਲਾਗਤ ਜਾਣਕਾਰੀ ਵੇਖੋ** ਹਰੇਕ ਓਪਰੇਸ਼ਨ ਲਈ ਲਾਗਤ (ਜੇ ਉਪਲੱਬਧ ਹੈ) ਅਤੇ ਟਰਾਂਸਲੇਟ, ਰੀਵਰਾਈਟ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਆਉਟਪੁੱਟ ਪੈਨਲਾਂ 'ਤੇ ਕੁੱਲ ਲਾਗਤ ਦੇ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।
- **ਲਾਗਤ ਅੰਸ਼ ਅੰਕ** ਲਾਗਤ ਦਸ਼ਮਲਵ ਨੂੰ ਪ੍ਰਦਰਸ਼ਿਤ ਕਰਨ ਦੇ ਢੰਗ ਨੂੰ ਬਦਲਦੇ ਹਨ।
- **ਕੇਵਲ ਵੈੱਬ:** **ਐਪ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਮਾਰਜਿਨ ਦਿਖਾਓ** ਇੰਟਰਫੇਸ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਵਾਧੂ ਸਪੇਸ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਫੌਂਟ ਫੈਮਲੀ** ਟੈਕਸਟ ਪੈਨਲਾਂ 'ਚ ਲਿਖਣ ਵਾਲੇ ਫੌਂਟ ਨੂੰ ਬਦਲਦਾ ਹੈ।
- **ਆਕਾਰ** ਫੌਂਟ ਦੇ ਆਕਾਰ ਨੂੰ ਬਦਲਦਾ ਹੈ।

**ਕਾਨਫਿਗਰੇਸ਼ਨ ਬੈਕਅੱਪ**

- **ਬੈਕਅੱਪ ਵਿੱਚ ਵਰਤੋਂ ਦੇ ਅੰਕੜੇ ਸ਼ਾਮਲ ਕਰੋ** — ਜਦੋਂ ਚਾਲੂ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਜ਼ਿਪ ਵਿੱਚ ਨਿਰਵਹਨ ਇਤਿਹਾਸ ਅਤੇ ਏਪੀਆਈ ਕਾਲ ਡੇਟਾ ਵੀ ਸ਼ਾਮਲ ਹੁੰਦਾ ਹੈ।

- **ਬੈਕਅੱਪ ਕਾਨਫਿਗਰੇਸ਼ਨ** — ਇੱਕ ਏਕੀਕ੍ਰਿਤ ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` ਮੂਲ ਰੂਪ ਵਿੱਚ UTC ਵਿੱਚ) ਬਣਾਉਂਦਾ ਹੈ ਜਿਸ ਵਿੱਚ `config.json`, `state.json`, ਵੈਕਲਪਿਕ ਇਨਕ੍ਰਿਪਸ਼ਨ ਕੁੰਜੀ, ਵਰਤੋਂਕਾਰ, ਪਸੰਦਾਂ, ਕਸਟਮ ਪ੍ਰੌਪਟਸ ਅਤੇ ਵਰਤੋਂ ਡਾਟਾ ਸ਼ਾਮਲ ਹੁੰਦੇ ਹਨ ਜੇਕਰ ਤੁਸੀਂ ਬੈਕਅੱਪ ਲਈ ਸਹਿਮਤ ਹੋਏ ਸੀ। ਸਫਲ ਬੈਕਅੱਪ ਤੋਂ ਬਾਅਦ, ਪੁਸ਼ਟੀ ਕਰਨ ਵਾਲਾ ਸੰਦੇਸ਼ ਸੰਭਾਲੀ ਗਈ ਫਾਈਲ ਦਾ ਨਾਮ ਦਰਸਾਉਂਦਾ ਹੈ।
- **ਬੈਕਅੱਪ ਤੋਂ ਬਹਾਲ ਕਰੋ** — ਪਹਿਲਾਂ **ਪੁਸ਼ਟੀ ਸੰਵਾਦ** ਖੋਲ੍ਹਦਾ ਹੈ। ਸੰਵਾਦ ਅੰਦਰ ਬੈਕਅੱਪ ZIP ਚੁਣੋ (**ਬਰਾਊਜ਼** / ਫਾਈਲ ਪਿਕਰ ਜਾਂ ਡਰੈਗ-ਐਂਡ-ਡਰਾਪ ਜਿੱਥੇ ਸਮਰਥਿਤ ਹੈ), ਫਿਰ ਵਿਕਲਪਾਂ ਦੀ ਸਮੀਖਿਆ ਕਰੋ:
  - **ਵਰਤੋਂ ਡਾਟਾ ਬਹਾਲ ਕਰੋ** — ਬੈਕਅਪ ਕਰਦੇ ਸਮੇਂ ਵਰਤੋਂ/ਇਤਿਹਾਸ ZIP ਵਿੱਚ ਸ਼ਾਮਲ ਕੀਤਾ ਗਿਆ ਹੋਵੇ ਤਾਂ ਉਸ ਨੂੰ ਆਯਾਤ ਕਰੋ; ਜੇਕਰ ਤੁਸੀਂ ਕੇਵਲ ਸੈਟਿੰਗਾਂ ਅਤੇ ਪ੍ਰੌਪਟਸ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਛੱਡ ਦਿਓ।
  - **ਬਹਾਲੀ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਪੁਰਾਣਾ ਵਰਤੋਂ ਡਾਟਾ ਹਟਾਓ** — ਬੈਕਅੱਪ ਲਾਗੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇਸ ਇੰਸਟਾਲੇਸ਼ਨ ਤੇ ਮੌਜੂਦਾ ਵਰਤੋਂ/ਇਤਿਹਾਸ ਨੂੰ ਹਟਾਓ (ਵੈਕਲਪਿਕ; ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਸਾਫ਼ ਪ੍ਰਤੀਸਥਾਪਨ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਵਰਤੋ)।

ਵੈੱਬ ਜਾਂ ਡੈਸਕਟਾਪ ਵਰਜਨ ਵਿੱਚ ਬਣਾਏ ਗਏ ਬੈਕਅੱਪਾਂ ਨੂੰ ਦੂਸਰੇ ਵਿੱਚ ਮੁੜ ਲਾਇਆ ਜਾ ਸਕਦਾ ਹੈ। ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ ਡੈਸਕਟਾਪ ਬੈਕਅੱਪ ਨੂੰ ਮੁੜ ਲਾਉਣ ਸਮੇਂ, ਡੇਟਾ ਐਡਮਿਨਿਸਟਰੇਟਰ ਵਰਤੋਂਕਾਰ ਨੂੰ ਮੁੜ ਸੁਰਜੀਤ ਕੀਤਾ ਜਾਵੇਗਾ।

<a id="models"></a>

### ਮਾਡਲ

ਟੂਲਬਾਰ ਵਿੱਚ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦੇਣਗੇ, ਇਸ ਨੂੰ ਚੁਣਨ ਲਈ **ਸੈਟਿੰਗਸ** > **ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਸੈਟਿੰਗ ਮਾਡਲ ਟੈਬ](../images/screenshots/pa/settings-models.png)

ਇਸ ਸਫ਼ੇ ਵਿੱਚ ਦੋ ਸੂਚੀਆਂ ਹਨ:

- ਖੱਬੇ ਪਾਸੇ **ਉਪਲਬਧ ਮਾਡਲ**
- ਸੱਜੇ ਪਾਸੇ **ਚੁਣੇ ਹੋਏ ਮਾਡਲ**

ਵਰਤੋਂਯੋਗ ਨਿਯੰਤਰਣਾਂ ਵਿੱਚ ਸ਼ਾਮਲ ਹੈ:

- **ਮਾਡਲ ਖੋਜੋ...** ਨਾਮ ਨਾਲ ਮਾਡਲ ਲੱਭਣ ਲਈ
- **ਪ੍ਰਦਾਤਾ** ਚਿਪਸ, ਸੂਚੀ ਨੂੰ ਇੱਕ ਇੰਜਣ (OpenRouter, OpenAI, Ollama, …) ਤੱਕ ਸੀਮਿਤ ਕਰਨ ਲਈ
- **ਸਿਰਫ਼ ਮੁਫਤ** ਸਿਰਫ਼ ਮੁਫਤ ਮਾਡਲ ਦਿਖਾਉਣ ਲਈ
- **ਰੀਫਰੈਸ਼** ਸੂਚੀ ਨੂੰ ਦੁਬਾਰਾ ਲੋਡ ਕਰਨ ਲਈ
- **ਸਭ ਨੂੰ ਵਧਾਓ** ਅਤੇ **ਸਭ ਨੂੰ ਸੁੰਗੜਾਓ** ਜਦੋਂ ਤੁਸੀਂ ਪ੍ਰਦਾਤਾ ਅਨੁਸਾਰ ਕ੍ਰਮਬੱਧ ਕਰ ਰਹੇ ਹੋਵੋ

ਮਾਡਲ ਆਈਡੀਜ਼ ਵਿੱਚ ਪ੍ਰਦਾਤਾ ਪਰਉਪਰਤ (ਉਦਾਹਰਨ ਲਈ `openrouter/…` ਬਨਾਮ `openai/…`) ਸ਼ਾਮਲ ਹੁੰਦੀ ਹੈ। **OpenAI (OpenRouter)** ਬਨਾਮ **OpenAI (ਸਿੱਧਾ)** ਵਰਗੇ ਬੈਜ ਵਾਲਾ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਟ੍ਰੈਫਿਕ ਕਿਵੇਂ ਪ੍ਰਬੰਧਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

> ℹ️ **ਨੋਟ**<br/>

> **OpenRouter Body Builder** (`openrouter/bodybuilder`) ਇੱਕ ਰਾਊਟਰ ਮਾਡਲ ਹੈ, ਆਮ ਚੈਟ ਮਾਡਲ ਨਹੀਂ: ਇਸਦਾ ਜਵਾਬ JSON ਹੁੰਦਾ ਹੈ ਜੋ OpenRouter API ਰਿਕੁਐਸਟ ਬਾਡੀਆਂ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ (ਉਦਾਹਰਨ ਲਈ `requests` ਐਰੇ `model` ਅਤੇ `messages` ਸਮੇਤ)। ਜੇਕਰ ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ **ਅਨੁਵਾਦ**, **ਰੀਆਈਟ**, ਜਾਂ **ਟਰਾਂਸਫਾਰਮ** ਲਈ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁਟ ਪੈਨਲ ਇਸ JSON ਨੂੰ ਦਰਸਾਏਗਾ, ਤਿਆਰ ਟੈਕਸਟ ਦੀ ਬਜਾਏ। ਇਹਨਾਂ ਕੰਮਾਂ ਲਈ ਇੱਕ ਆਮ ਟੈਕਸਟ ਮਾਡਲ ਚੁਣੋ। OpenRouter 'ਤੇ [ਬਾਡੀ ਬਿਲਡਰ ਮਾਡਲ ਪੇਜ](https://openrouter.ai/openrouter/bodybuilder) ਵੇਖੋ।

ਕਾਰਵਾਈਆਂ:

 - ਕੋਈ ਮਾਡਲ ਜੋੜਨ ਲਈ, **ਜੋੜੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਜਾਂ ਐਂਟਰੀ ਵਿੱਚ ਕਿੱਥੇ ਵੀ।

 - ਕੋਈ ਮਾਡਲ ਹਟਾਉਣ ਲਈ, **ਚੁਣੇ ਮਾਡਲਾਂ** ਵਿੱਚ ਇਸਦੇ ਨਾਲ **X** 'ਤੇ ਜਾਂ ਉਪਲਬਧ ਮਾਡਲਾਂ ਵਿੱਚ ਐਂਟਰੀ ਉੱਤੇ **ਚੁਣੇ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

 - ਸੂਚੀ ਸਾਫ਼ ਕਰਨ ਲਈ, **ਸਭ ਦੀ ਚੋਣ ਰੱਦ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਜ਼ਰੂਰੀ ਮੁਕਤ ਮਾਡਲ ਸੂਚੀ ਵਿੱਚ ਰਹੇਗਾ।

<br/>

> ℹ️ **ਨੋਟ**<br/>

> ਜੇਕਰ ਤੁਸੀਂ OpenRouter ਨੂੰ ਤੁਰੰਤ ਕ੍ਰੈਡਿਟ ਨਹੀਂ ਦੇਣਾ ਚਾਹੁੰਦੇ, ਤਾਂ **ਸਿਰਫ਼ ਮੁਫਤ** ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ ਅਤੇ ਮੁਫਤ ਮਾਡਲਾਂ ਚੁਣ ਕੇ ਸ਼ੁਰੂ ਕਰੋ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ)। ਤੁਸੀਂ Ollama ਦੀ ਵਰਤੋਂ ਬਿਨਾਂ ਕਿਸੇ API ਕੁੰਜੀ ਦੇ ਸਥਾਨਕ-ਪੱਧਰ 'ਤੇ ਮਾਡਲ ਚਲਾਉਣ ਲਈ ਵੀ ਕਰ ਸਕਦੇ ਹੋ।

<a id="languages"></a>

### ਭਾਸ਼ਾਵਾਂ

ਐਪ ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਨੂੰ ਵਿਵਸਥਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਸਿਖਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** **ਅਨੁਵਾਦ** ਅਤੇ **ਟਰਾਂਸਫਾਰਮ** ਵਿੱਚ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਦੇ ਉੱਪਰਲੇ ਹਿੱਸੇ ਨੇੜੇ ਪਿੰਨ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- **ਕਸਟਮ ਭਾਸ਼ਾ** ਤੁਹਾਨੂੰ ਅੰਦਰੂਨੀ ਸੂਚੀ ਵਿੱਚ ਨਾ ਹੋਣ ਵਾਲੀ ਇੱਕ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਨ ਦੀ ਇਜਾਜ਼ਤ ਦਿੰਦੀ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ ਕਸਟਮ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਤਾਂ ਇਹ ਅੰਦਰੂਨੀ ਵਿਕਲਪਾਂ ਨਾਲ ਨਾਲ ਭਾਸ਼ਾ ਚੁਣਨ ਵਾਲਿਆਂ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦੀ ਹੈ।

<a id="cost-tracking"></a>

### ਲਾਗਤ ਟਰੈਕਿੰਗ

**ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ** ਦੀ ਵਰਤੋਂ ਲਾਗਤ ਜਾਣਕਾਰੀ ਨੂੰ ਪਰਬੰਧਿਤ ਕਰਨ ਲਈ ਕਰੋ।

- **ਕੁੱਲ ਲਾਗਤ** ਚੱਲ ਰਹੇ ਕੁੱਲ ਦਿਖਾਉਂਦਾ ਹੈ।
- **ਮੁੱਲ ਕਾਪੀ ਕਰੋ** ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਕੁੱਲ ਨੂੰ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਸੈੱਟ ਲਾਗਤ** ਸਟੋਰ ਕੀਤੇ ਕੁੱਲ ਨੂੰ ਸਿਫ਼ਰ 'ਤੇ ਰੀਸੈੱਟ ਕਰਦਾ ਹੈ।
- **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ** OpenRouter ਖਾਤੇ (ਸਿਰਫ਼ OpenRouter) ਵੱਲੋਂ ਦੱਸੀ ਗਈ ਵਰਤੋਂ ਨਾਲ ਮੇਲ ਖਾਂਦੇ ਕੁੱਲ ਨੂੰ ਸੈੱਟ ਕਰਦਾ ਹੈ।
- **API ਕੁੰਜੀ ਵਰਤੋਂ** OpenRouter ਵਰਤੋਂ ਦੀਆਂ ਵੇਰਵੇ ਦਿਖਾਉਂਦਾ ਹੈ, ਜੇਕਰ ਉਪਲਬਧ ਹੋਵੇ।
- **ਲਾਗਤ ਡਾਟਾ ਮਿਟਾਓ** ਸਭ ਡਾਟਾ ਨੂੰ ਜਾਂ ਸਿਰਫ਼ ਚੁਣੀ ਗਈ ਤਾਰੀਖ਼ ਤੋਂ ਪਹਿਲਾਂ ਦੀਆਂ ਐਂਟਰੀਆਂ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ।


**ਲਾਗਤ ਟਰੈਕਿੰਗ:** ਜਦੋਂ ਤੁਸੀਂ OpenRouter ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ ਅਸਲ ਵਰਤੋਂ ਅਤੇ OpenRouter ਤੋਂ ਲਾਗਤ ਜਾਣਕਾਰੀ ਦੇ ਆਧਾਰ 'ਤੇ ਖਰਚ ਦਿਖਾਉਂਦਾ ਹੈ। ਹਰ ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ ਲਈ, ਐਪ OpenRouter ਵੱਲੋਂ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਤੀਆਂ ਕੀਮਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਲਾਗਤਾਂ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਂਦਾ ਹੈ, ਜੇਕਰ ਕੋਈ ਕੀਮਤ ਉਪਲਬਧ ਨਾ ਹੋਵੇ, ਤਾਂ ਅੰਦਾਜ਼ਾ ਸਿਫ਼ਰ ਹੋ ਸਕਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> **ਸਾਰੇ ਲਾਗਤ ਅੰਕੜੇ ਤੁਹਾਡੇ ਹਵਾਲੇ ਲਈ ਅੰਦਾਜ਼ੇ ਹੁੰਦੇ ਹਨ, ਅਧਿਕਾਰਤ ਬਿੱਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।**


<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>

> ڈیਟਾ ਨੂੰ ਹਟਾਉਣਾ ਉਲਟਾ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਹਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ, ਆਪਣੇ ਡੇਟਾ ਨੂੰ ਬੈਕ ਅੱਪ ਕਰਨਾ ਜਾਂ ਇਸ ਨੂੰ [**ਇਤਿਹਾਸ**](#history)  
> ਜਾਂ [**ਡੈਸ਼ਬੋਰਡ** > **ਸਾਰੇ ਕਾਲ**](#dashboard-tabs) ਰਾਹੀਂ ਨਿਰਯਾਤ ਕਰਨਾ ਯਕੀਨੀ ਬਣਾਓ, ਨਹੀਂ ਤਾਂ ਇਹ ਸਥਾਈ ਤੌਰ 'ਤੇ ਖਤਮ ਹੋ ਜਾਵੇਗਾ।

- ਬੈਕਅੱਪ ਜਾਂ ਸ਼ੇਅਰ ਕਰਨ ਲਈ ਪ੍ਰੌਮਟ ਨਿਰਯਾਤ ਕਰੋ

<a id="api-config"></a>

### API ਸੰਰਚਨਾ

ਸਮਰਥਤ ਪ੍ਰਦਾਤਾ ਹਨ: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, ਅਤੇ **Ollama** (ਆਧਾਰ URL ਰਾਹੀਂ ਸਥਾਨਕ ਮਾਡਲ)। ਤੁਹਾਨੂੰ ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰਨ ਦੀ ਲੋੜ ਹੈ ਜਿਹਨਾਂ ਦੀ ਵਰਤੋਂ ਤੁਸੀਂ ਕਰਦੇ ਹੋ।

**ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ: ਸਿਰਫ਼ ਪ੍ਰਸ਼ਾਸਕ**

API ਕੁੰਜੀਆਂ ਨੂੰ ਤੁਹਾਡੇ ਸਿਸਟਮ ਜਾਂ ਡਾਕਰ ਦੇ ਵਾਤਾਵਰਣ ਚਲਾ ਕੇ ਸੰਰਚਿਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ — ਇਹ ਵੈੱਬ UI ਵਿੱਚ ਦਰਜ ਨਹੀਂ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ। ਇਹ ਸਫ਼ਾ ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਕਿਹੜੇ ਪ੍ਰਦਾਤਾ ਨੇ ਕੁੰਜੀ ਸੰਰਚਿਤ ਕੀਤੀ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ **`ਟੈਸਟ`** ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਹਰੇਕ ਦੀ ਪੜਤਾਲ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> API ਕੁੰਜੀ ਨੂੰ ਬਦਲਣ ਲਈ, ਆਪਣੇ ਸਿਸਟਮ ਜਾਂ ਡਾਕਰ ਸੰਰਚਨਾ ਵਿੱਚ ਵਾਤਾਵਰਣ ਚਲਾ ਨੂੰ ਅਪਡੇਟ ਕਰੋ ਅਤੇ ਸਰਵਰ ਜਾਂ ਕੰਟੇਨਰ ਨੂੰ ਮੁੜ ਚਾਲੂ ਕਰੋ।

> ℹ️ **ਨੋਟ**<br/>

> **ਕਨਫਿਗਰੇਸ਼ਨ ਬੈਕਅੱਪ** (ਵੇਖੋ [**ਜਨਰਲ ਸੈਟਿੰਗਜ਼** → ਕਨਫਿਗਰੇਸ਼ਨ ਬੈਕਅੱਪ](#general-settings)) ZIP ਦੀ `config.json` ਵਿੱਚ **ਹੱਲ ਕੀਤੀਆਂ** ਪ੍ਰਦਾਤਾ ਕੁੰਜੀਆਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹਨ। ਉਸ ZIP ਨੂੰ ਮੁੜ-ਸਥਾਪਿਤ ਕਰਨ ਨਾਲ ਉਹਨਾਂ ਕੁੰਜੀਆਂ ਨੂੰ ਸਰਵਰ ਦੀ ਸਥਾਈ ਕਨਫਿਗ ਫਾਈਲ ਵਿੱਚ ਮੁੜ-ਨਕਲ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ — ਲਾਈਵ ਕੁੰਜੀਆਂ ਅਜੇ ਵੀ ਉੱਥੇ ਵਰਣਿਤ ਅਨੁਸਾਰ ਮਾਹੌਲ ਅਤੇ ਮੌਜੂਦਾ ਫਾਈਲ ਸਥਿਤੀ ਤੋਂ ਆਉਂਦੀਆਂ ਹਨ।

<br/>

**ਡੈਸਕਟਾਪ ਐਪਲੀਕੇਸ਼ਨ**

ਤੁਸੀਂ ਜਿਹੜੇ ਵੀ ਪ੍ਰਦਾਤਾ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਉਹਨਾਂ ਲਈ **API ਕੁੰਜੀਆਂ** ਸਟੋਰ ਕਰਨ ਲਈ **API ਕਨਫਿਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ। Ollama ਲਈ, ਕੋਈ API ਕੁੰਜੀ ਦੀ ਬਜਾਏ **ਬੇਸ URL** ਦਰਜ ਕਰੋ।

<br/>

> 💡 **ਟਿਪ** <br/>
> ਜੇਕਰ ਤੁਸੀਂ API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ ਜਾਂ ਵਰਤੋਂ ਲਈ ਭੁਗਤਾਨ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ, ਤਾਂ ਤੁਸੀਂ [Ollama ਡਾਊਨਲੋਡ ਕਰ ਸਕਦੇ ਹੋ](https://ollama.com) ਅਤੇ ਮਫ਼ਤ ਵਿੱਚ ਆਪਣੀ ਮਸ਼ੀਨ 'ਤੇ ਮਾਡਲ (ਜਿਵੇਂ `translategemma:4b`) ਚਲਾ ਸਕਦੇ ਹੋ। ਵੈਕਲਪਿਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ ਉਹਨਾਂ ਦੇ ਮੁਫ਼ਤ ਮਾਡਲ ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ ਮੁਫਤ OpenRouter ਅਕਾਊਂਟ ਬਣਾ ਸਕਦੇ ਹੋ (ਕਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ), ਜਾਂ Cerebras, Google, Groq, ਜਾਂ Mistral AI ਤੋਂ ਮੁਫ਼ਤ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

- ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰੋਵਾਈਡਰਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰੋ ਜਿਨ੍ਹਾਂ ਦੀ ਤੁਹਾਨੂੰ ਲੋੜ ਹੈ। **ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ** ਵਿੱਚ, ਹਰੇਕ ਮਾਡਲ ਆਈਡੀ ਪ੍ਰੋਵਾਈਡਰ ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦੀ ਹੈ (ਉਦਾਹਰਣ ਵਜੋਂ `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

ਕੋਈ API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, ਮੁੱਲ ਨੂੰ ਟੈਕਸਟ ਫੀਲਡ ਵਿੱਚ ਦਰਜ ਕਰੋ ਅਤੇ **`ਸੇਵ`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਮੌਜੂਦਾ ਕੁੰਜੀ ਨੂੰ ਬਦਲਣ ਲਈ, **`ਐਡਿਟ`** ਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਹ ਜਾਂਚਣ ਲਈ ਕਿ ਕੀ ਕੁੰਜੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ, **`ਟੈਸਟ`** ਤੇ ਕਲਿੱਕ ਕਰੋ। Ollama ਬੇਸ URL ਲਈ, ਸੰਪਰਕ ਜਾਂਚਣ ਲਈ ਹਮੇਸ਼ਾ **`ਟੈਸਟ`** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>

> API ਕੁੰਜੀਆਂ ਕੰਫ਼ੀਗੂਰੇਸ਼ਨ ਵਿੱਚ ਐਨਕ੍ਰਿਪਟਿਡ (encrypted) ਸਟੋਰ ਹੁੰਦੀਆਂ ਹਨ।

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### ਐਪ ਟੈਕਸਟ ਨੂੰ ਅਨੁਵਾਦ, ਮੁੜ ਲਿਖਣ ਜਾਂ ਰੂਪਾਂਤਰਿਤ ਨਹੀਂ ਕਰੇਗੀ

ਜਾਂਚ ਕਰੋ:

- ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣਿਆ ਹੈ
- ਘੱਟ ਤੋਂ ਘੱਟ ਇੱਕ ਮਾਡਲ ਸੂਚੀਬੱਧ ਹੈ [**ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ**](#models) ਵਿੱਚ
- ਤੁਹਾਡੀ API ਸੈਟਅੱਪ ਕੰਮ ਕਰ ਰਹੀ ਹੈ

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ:

1. [**ਸੈਟਿੰਗਾਂ** > **API ਕਾਨਫ਼ੀਗ**](#api-config) ਖੋਲ੍ਹੋ।
2. ਜਾਂਚ ਕਰੋ ਕਿ ਘੱਟ ਤੋਂ ਘੱਟ ਇੱਕ API ਕੁੰਜੀ ਸੰਭਾਲੀ ਗਈ ਹੈ।
3. ਪ੍ਰਦਾਤਾ ਨੇੜੇ **ਟੈਸਟ** ਕਲਿੱਕ ਕਰੋ ਤਾਂ ਜੋ ਪੁਸ਼ਟੀ ਕੀਤੀ ਜਾ ਸਕੇ ਕਿ ਕੁੰਜੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।

<a id="the-result-is-too-slow-or-too-expensive"></a>

### ਨਤੀਜਾ ਬਹੁਤ ਧੀਮਾ ਹੈ ਜਾਂ ਮਹਿੰਗਾ ਹੈ

ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਜਾਂ ਵੱਧ ਕੋਸ਼ਿਸ਼ ਕਰੋ:

- ਇੱਕ ਵੱਖਰਾ ਮਾਡਲ ਚੁਣੋ
- ਛੋਟੇ ਇਨਪੁਟ ਦੀ ਵਰਤੋਂ ਕਰੋ
- [**ਸੈਟਿੰਗਾਂ** > **ਜਨਰਲ ਸੈਟਿੰਗਾਂ**](#general-settings) ਵਿੱਚ **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਬੰਦ ਕਰੋ
- ਸਰਲ ਕੰਮਾਂ ਲਈ ਮੁਫਤ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ (ਵੇਖੋ [ਮਾਡਲ](#models))

### ਇੰਟਰਫੇਸ ਗਲਤ ਭਾਸ਼ਾ ਵਿੱਚ ਹੈ

[ਟੂਲਬਾਰ](#toolbar) ਵਿੱਚ ਗਲੋਬ ਆਈਕਨ ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਆਪਣੀ ਪਸੰਦੀਦਾ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।

### ਟੈਕਸਟ ਬਹੁਤ ਛੋਟਾ ਜਾਂ ਪੜ੍ਹਨ ਲਈ ਮੁਸ਼ਕਲ ਹੈ

[**ਸੈਟਿੰਗਾਂ** > **ਜਨਰਲ ਸੈਟਿੰਗਾਂ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਬਦਲੋ:

- **ਫਾਂਟ ਫੈਮਿਲੀ**
- **ਆਕਾਰ**

<a id="dashboard-charts-are-empty"></a>

### ਡੈਸ਼ਬੋਰਡ ਚਾਰਟ ਖਾਲੀ ਹਨ

ਜੇਕਰ:

- ਤੁਸੀਂ ਸਿਰਫ਼ **ਮੁਫਤ ਮਾਡਲ** ਵਰਤਦੇ ਹੋ ਅਤੇ ਤੁਸੀਂ **ਲਾਗਤ** ਦੇ ਅੰਕੜੇ ਵੇਖ ਰਹੇ ਹੋ (ਇਹ ਸਿਫਰ ਹੋ ਸਕਦੇ ਹਨ); **ਸਾਰਾਂਸ਼** ਵਿੱਚ **ਵਰਤੋਂ** ਕਾਲ-ਗਿਣਤੀ ਚਾਰਟਾਂ ਨੂੰ ਚੁਣੇ ਗਏ ਸਮੇਂ ਦੀ ਮਿਆਦ ਤੋਂ ਅਜੇ ਵੀ ਡੇਟਾ ਦੀ ਲੋੜ ਹੈ
- ਚੁਣਿਆ ਗਿਆ **ਸਮਾਂ ਫਿਲਟਰ** ਉਸ ਸਮੇਂ ਦੀ ਮਿਆਦ ਨੂੰ ਕਵਰ ਨਹੀਂ ਕਰਦਾ ਜਦੋਂ ਕਾਲਾਂ ਕੀਤੀਆਂ ਗਈਆਂ ਸਨ — ਜਾਂਚ ਕਰਨ ਲਈ **ਸਭ** ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ

ਜੇਕਰ **ਸਭ** ਚੁਣਨ ਤੋਂ ਬਾਅਦ ਵੀ ਚਾਰਟ ਖਾਲੀ ਹਨ, ਤਾਂ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕਾਲਾਂ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ **ਸਭ ਕਾਲਾਂ** ਟੈਬ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### ਕੀਮਤ "ਉਪਲਬਧ ਨਹੀਂ" ਦਿਖਾਈ ਦਿੰਦੀ ਜਾਂ ਗਲਤ ਲੱਗਦੀ ਹੈ

ਜਦੋਂ ਤੁਸੀਂ **OpenRouter** ਦੁਆਰਾ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ OpenRouter ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੀ ਅਸਲ ਖਰਚ ਵੇਖਾਉਂਦਾ ਹੈ।

**ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ** (OpenAI ਡਾਇਰੈਕਟ, Anthropic ਡਾਇਰੈਕਟ, ਆਦਿ) ਲਈ, ਕੀਮਤ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਤ ਮੁੱਲ ਦੇ ਅੰਕੜਿਆਂ ਤੋਂ ਅਨੁਮਾਨਿਤ ਕੀਤੀ ਜਾਂਦੀ ਹੈ। ਜੇਕਰ ਕਿਸੇ ਮਾਡਲ ਲਈ ਕੋਈ ਮੈਚਿੰਗ ਕੀਮਤ ਨਹੀਂ ਮਿਲਦੀ, ਤਾਂ ਮੁੱਲ **ਉਪਲਬਧ ਨਹੀਂ** ਹੋਣ ਦੇ ਰੂਪ ਵਿੱਚ ਦਿਖਾਈ ਦੇਵੇਗੀ ਅਤੇ ਤੁਹਾਡੀ ਜਾਰੀ ਕੁੱਲ ਰਕਮ ਵਿੱਚ ਸ਼ਾਮਲ ਨਹੀਂ ਕੀਤੀ ਜਾਵੇਗੀ।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### ਕੁੱਲ ਲਾਗਤ ਮੇਰੇ ਪ੍ਰਦਾਤਾ ਦੇ ਬਿੱਲ ਨਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੀ

ਐਪ ਵਿੱਚ ਸਾਰੇ ਲਾਗਤ ਅੰਕੜੇ ਸਿਰਫ ਡੇਮਾਂ ਦੇ ਹਵਾਲੇ ਲਈ ਹਨ, **ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਬਿਆਨ ਨਹੀਂ ਹਨ**।

ਆਪਣੇ ਅਸਲ OpenRouter ਖਰਚ ਨਾਲ ਕੁੱਲ ਨੂੰ ਹੋਰ ਕਰੀਬ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਨਿਗਰਾਨੀ**](#cost-tracking) ਖੋਲ੍ਹੋ ਅਤੇ **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### ਸਾਈਡਬਾਰ ਵਿੱਚ ਇਤਿਹਾਸ ਪੰਨਾ ਗਾਇਬ ਹੈ

**ਐਕਜ਼ੀਕਿਊਸ਼ਨ ਇਤਿਹਾਸ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖੋ** ਬੰਦ ਹੋ ਸਕਦਾ ਹੈ। [**ਸੈਟਿੰਗਾਂ** > **ਜਨਰਲ ਸੈਟਿੰਗਾਂ**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਇਸਨੂੰ ਚਾਲੂ ਕਰੋ। ਧਿਆਨ ਦਿਉ ਕਿ ਚਾਲੂ ਕਰਨ ਨਾਲ ਪਹਿਲਾਂ ਹਟਾਏ ਗਏ ਇਤਿਹਾਸ ਡਾਟਾ ਮੁੜ ਪ੍ਰਾਪਤ ਨਹੀਂ ਹੁੰਦਾ।

<br/>

<a id="web-app-session-expired"></a>

### ਵੈੱਬ ਐਪ: ਲਾਗਇਨ ਪੇਜ ਤੇ ਅਣਜਾਣੇ ਹੀ ਰੀਡਾਇਰੈਕਟ ਕੀਤਾ ਗਿਆ

ਤੁਹਾਡਾ ਸੈਸ਼ਨ ਮਿਆਦ ਤੋਂ ਬਾਅਦ ਖਤਮ ਹੋ ਸਕਦਾ ਹੈ। ਮੁੜ ਲਾਗਇਨ ਕਰੋ। ਜੇ ਇਹ ਅਕਸਰ ਵਾਪਰਦਾ ਹੈ, ਤਾਂ ਸਰਵਰ ਕਾਨਫ਼ੀਗਰੇਸ਼ਨ ਵਿੱਚ ਸੈਸ਼ਨ ਜੀਵਨਕਾਲ ਸੈਟਿੰਗਸ ਲਈ ਜਾਂਚ ਕਰੋ।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### ਵੈੱਬ ਐਡਮਿਨ: ਪਾਸਵਰਡ ਭੁੱਲ ਗਏ ਜਾਂ ਗੁਆਚ ਗਏ

ਇਹ **ਸਰਵਰ-ਹੋਸਟ ਕੀਤੇ ਵੈੱਬ ਐਪ** (ਡੌਕਰ) ਤੇ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਡੈਸਕਟਾਪ (ਇਲੈਕਟਰਾਨ) ਐਪ 'ਤੇ ਨਹੀਂ।

- ਜੇ ਕੋਈ ਹੋਰ ਐਡਮਿਨ ਅਜੇ ਵੀ ਲੌਗ ਇਨ ਕਰ ਸਕਦਾ ਹੈ, ਤਾਂ ਉਹ [**ਸੈਟਿੰਗਜ਼** > **ਯੂਜ਼ਰ**](#users) ਖੋਲ੍ਹ ਕੇ, ਖਾਤੇ ਨੂੰ ਚੁਣ ਕੇ, ਅਤੇ ਇੱਥੇ **ਨਵਾਂ ਪਾਸਵਰਡ** ਸੈੱਟ ਕਰ ਸਕਦਾ ਹੈ।
- ਜੇ ਤੁਸੀਂ **ਬਲੌਕ ਹੋ** ਗਏ ਹੋ ਪਰ ਮਸ਼ੀਨ ਜਾਂ ਕੰਟੇਨਰ ਨੂੰ **ਸ਼ੈੱਲ ਐਕਸੈਸ** ਹੈ, ਤਾਂ ਅਹੁਦੇ ਨਾਲ ਆਉਣ ਵਾਲੇ ਹੈਲਪਰ ਨਾਲ ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰੋ (ਜੇ ਤੁਸੀਂ ਡਿਫਾਲਟ ਨਾਂ ਬਦਲਿਆ ਹੈ ਤਾਂ `transrewrt` ਬਦਲੋ, ਅਤੇ ਜੇ ਪਾਸਵਰਡ ਵਿੱਚ ਸਪੇਸ ਜਾਂ ਵਿਸ਼ੇਸ਼ ਚਿੰਨ੍ਹ ਹਨ ਤਾਂ ਪਾਸਵਰਡ ਨੂੰ ਕੋਟ ਵਿੱਚ ਰੱਖੋ):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ਜੇ ਤੁਸੀਂ ਦੂਜਾ ਖਾਤਾ ਨਹੀਂ ਬਣਾਇਆ, ਤਾਂ ਡਿਫਾਲਟ ਐਡਮਿਨ ਯੂਜ਼ਰਨੇਮ `admin` ਹੁੰਦਾ ਹੈ। ਜਦੋਂ ਤੁਸੀਂ ਸਿਰਫ ਇੱਕ ਤਰਕ ਪਾਰਿਤ ਕਰਦੇ ਹੋ, ਇਹ `admin` ਲਈ ਨਵਾਂ ਪਾਸਵਰਡ ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ। ਜੇ ਤੁਸੀਂ ਸਰੋਤ ਚੈੱਕਆਊਟ ਤੋਂ ਬਜਾਏ ਡੌਕਰ ਦੀ ਵਰਤੋਂ ਨਾਲ ਚਲਾ ਰਹੇ ਹੋ, ਤਾਂ ਵਰਤੋ:

```bash
pnpm run reset-web-password -- <username> <new-password>

ਸਕ੍ਰਿਪਟ SQLite ਡੇਟਾਬੇਸ ਵਿੱਚ ਉਪਭੋਗਤਾ ਰਿਕਾਰਡ ਨੂੰ ਅਪਡੇਟ ਕਰਦਾ ਹੈ (ਅਤੇ ਜੇ ਲੋੜ ਹੋਵੇ ਤਾਂ `admin` ਉਪਭੋਗਤਾ ਨੂੰ ਬਣਾ ਸਕਦਾ ਹੈ)। ਰੀਸੈੱਟ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਨਵੇਂ ਪਾਸਵਰਡ ਨਾਲ ਸਾਇਨ ਇਨ ਕਰੋ।


<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>

### ਡੈਸ਼ਬੋਰਡ ਵੈੱਬ 'ਤੇ ਹੋਰ ਯੂਜ਼ਰਾਂ ਲਈ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਦਿਖਾਉਂਦਾ

ਸਿਰਫ਼ **ਪ੍ਰਸ਼ਾਸਕ** **ਯੂਜ਼ਰ** ਫਿਲਟਰ ਰਾਹੀਂ ਸਾਰੇ ਯੂਜ਼ਰਾਂ ਤੋਂ ਡਾਟਾ ਵੇਖ ਸਕਦੇ ਹਨ। ਨਿਯਮਤ ਯੂਜ਼ਰ ਡਿਜ਼ਾਇਨ ਅਨੁਸਾਰ ਆਪਣੀ ਖੁਦ ਦੀ ਗਤੀਵਿਧੀ ਨੂੰ ਹੀ ਵੇਖਦੇ ਹਨ।

<a id="i-changed-a-prompt-and-lost-the-edits"></a>

### ਮੈਂ ਇੱਕ ਪ੍ਰੋਮਟ ਨੂੰ ਬਦਲ ਦਿੱਤਾ ਅਤੇ ਸੋਧਾਂ ਗੁਆ ਲਈਆਂ

ਜਦੋਂ ਕਿਸੇ ਪ੍ਰੋਮਟ ਨੂੰ ਸੋਧ ਰਹੇ ਹੋ, ਤਾਂ **ਪਿੱਛੇ ਜਾਰੀ ਰੱਖੋ** ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਹਮੇਸ਼ਾ **ਸੇਵ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="quick-tips"></a>

## ਤੁਰੰਤ ਸੁਝਾਅ

- [**ਅਨੁਵਾਦ ਕਰੋ**](#translate) ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਤਾਂ ਜੋ ਤੁਸੀਂ [**ਮੁੜ-ਲਿਖੋ**](#rewrite) ਜਾਂ [**ਰੂਪਾਂਤਰਤ ਕਰੋ**](#transform) ਤੇ ਜਾਣ ਤੋਂ ਪਹਿਲਾਂ ਆਪਣੀ ਸੈਟਅੱਪ ਠੀਕ ਕੰਮ ਕਰ ਰਹੀ ਹੈ, ਇਹ ਯਕੀਨੀ ਬਣਾ ਸਕੋ।
- ਰੋਜ਼ਾਨਾ ਸੁਧਾਰਾਂ ਲਈ [**ਮੁੜ-ਲਿਖੋ**](#rewrite) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਕਿਸੇ ਖਾਸ ਕੰਮ ਲਈ ਦੁਹਰਾਉਣਯੋਗ ਕਾਰਜ-ਪ੍ਰਵਾਹ ਦੀ ਲੋੜ ਹੋਣ ਤੇ [**ਰੂਪਾਂਤਰਤ ਕਰੋ**](#transform) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ 'ਤੇ ਨਜ਼ਰ ਰੱਖਣੀ ਹੈ ਤਾਂ [**ਡੈਸ਼ਬੋਰਡ**](#dashboard) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਪਿਛਲੇ ਕੰਮਾਂ ਅਤੇ ਉਨ੍ਹਾਂ ਦੇ ਪੂਰੇ ਇਨਪੁਟ/ਆਉਟਪੁਟ ਪਾਠ ਨੂੰ ਦੇਖਣ ਲਈ [**ਇਤਿਹਾਸ**](#history) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇਕਰ ਤੁਸੀਂ ਸੁਰੱਖਿਅਤ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਨਿਯਮਤ ਤੌਰ 'ਤੇ ਟਿਪਣੀਆਂ ਨਿਰਯਾਤ ਕਰੋ (ਵੇਖੋ [ਟਰਾਂਸਫਾਰਮ ਟਿਪਣੀਆਂ](#transform-prompts)) ਜਾਂ ਜੇਕਰ ਤੁਸੀਂ ਉਹਨਾਂ ਨੂੰ ਹੋਰਾਂ ਨਾਲ ਸਾਂਝਾ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।
