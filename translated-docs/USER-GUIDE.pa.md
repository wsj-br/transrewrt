# ਟ੍ਰਾਂਸਰਿਊਰਟ ਯੂਜ਼ਰ ਗਾਈਡ

<br />

<a id="introduction"></a>
## ਪਰਿਚਯ

ਟ੍ਰਾਂਸਰਿਊਰਟ ਤੁਹਾਨੂੰ ਤਿੰਨ ਮੁੱਢੱਢ ਵਿਅਕਤ ਤੌਰ 'ਤੇ ਟੈਕਸਟ ਨਾਲ ਕੰਮ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ:

- **ਅਨੁਵਾਦ** - ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਬਦਲੋ।
- **ਮੁਢ਼ਲ** - ਟੈਕਸਟ ਨੂੰ ਵੱਖਰੇ ਸ਼ੈਲੀ ਵਿਚ, ਜਿਵੇਂ ਕਿ ਸਪੱਸ਼ਟ, ਛੋਟਾ, ਜਾਂ ਵਧੇਰੇ ਔਫ਼ੀਸਲ ਵਿੱਚ, ਦੁਬਾਰਾ ਲਿਖੋ।
- **ਬਦਲੋ** - ਨੁਮਾਇੰਦਗੀ AI ਨੂੰ ਪ੍ਰੋਮਪਟ ਕਹਿੰਦੇ ਕਸਟਮ AI ਨੀਤੀਆਂ ਦੀ ਵਰਤੋਂ ਨਾਲ ਟੈਕਸਟ ਪ੍ਰੋਸੈਸ ਕਰੋ।

<br />

ਇਹ ਗਾਈਡ ਤੁਹਾਨੂੰ ਦੱਸਦਾ ਹੈ ਕਿ ਐਪ ਇੰਸਟਾਲ ਅਤੇ ਚੱਲ ਰਹੀ ਹੋਣ 'ਤੇ ਕਿਵੇਂ ਵਰਤੋਂ। ਇੰਸਟਾਲੇਸ਼ਨ ਸਟੈਪਸ ਲਈ, ਮੁੱਖ [README](../README.md) ਨੂੰ ਦੇਖੋ।

<br />

> ℹ️ **ਨੋਟ**<br/>
> ਟ੍ਰਾਂਸਰਿਊਰਟ Windows ਅਤੇ Linux ਲਈ ਡੈਸਕਟਾਪ ਐਪ ਵਜੋਂ, ਅਤੇ ਸਵੈ-ਹੋਸਟਡ ਵੈੱਬ ਐਪ ਵਜੋਂ ਉਪਲਬਧ ਹੈ। ਇਹ ਗਾਈਡ ਐਪ ਦੀ ਰੋਜ਼ਾਨਾ ਵਰਤੋਂ 'ਤੇ ਧਿਆਨ ਕੇਂਦਰਿਤ ਕਰਦਾ ਹੈ। ਜਿੱਥੇ ਕੁਝ ਕੀਮਤੀ ਇੱਕ ਵਰਜਨ ਲਈ ਹੀ ਲਾਗੂ ਹੁੰਦੀ ਹੈ, ਉਹ ਸਪੱਸ਼ਟ ਢੰਗ ਨਾਲ ਮਾਰਕ ਕੀਤੀ ਗਈ ਹੈ।

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

ਟਰਾਂਸਰੀਟ ਵਰਤਣ ਲਈ, ਤੁਹਾਨੂੰ ਓਪਨਰਾਊਟਰ ਰਾਹੀਂ AI ਸਰਵਿਸ ਨਾਲ ਅਸੈਸ ਦੀ ਲੋੜ ਹੈ।

ਤੁਸੀਂ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਕਿਸੇ ਪੇਦ ਮਾਡਲ ਦੀ ਚੋਣ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। ਐਪ ਹਮੇਸ਼ਾ ਇੱਕ ਬਿਲਟ-ਇਨ **ਮੁਫ਼्त** ਮਾਡਲ ਸ਼ਾਮਲ ਕਰਦੀ ਹੈ, ਇਸ ਲਈ ਆਮ ਵਰਤੋਂ ਲਈ ਇਹ ਟ੍ਰਾਂਸਲੇਟ, ਰੀ-ਰਾਈਟ, ਅਤੇ ਟੈਕਸਟ ਨੂੰ ਬਦਲਣ ਨੂੰ ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਕਾਫੀ ਹੈ।

ਸਾਫ਼ ਸ਼ਬਦਾਂ ਵਿੱਚ:

- ਇੱਕ **ਮਾਡਲ** ਉਹ AI ਐਂਜਨ ਹੈ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ।
- ਇੱਕ **API ਕੀ** ਉਸ ਸਰਵਿਸ ਲਈ ਤੁਹਾਡੀ ਨਿੱਜੀ ਪਹੁੰਚ ਦੀ ਪ੍ਰਮਾਣਪਤਰ ਹੈ।

ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਤੁਹਾਨੂੰ ਇੱਕ API ਕੀ ਦੀ ਲੋੜ ਪਏਗੀ। ਵਿਸਤਰੀਤ ਕਦਮਾਂ ਲਈ, ਹੇਠਾਂ ਦੇਖੋ [API ਕੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੋ (ਡੈਸਕਟਾਪ ਐਪ)](#how-to-get-an-api-key-desktop-app)। ਇੱਕ ਟੁਕड़ੇ ਵਿੱਚ: [ਓਪਨਰਾਊਟਰ](https://openrouter.ai) 'ਤੇ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਸਾਈਨ ਇਨ ਕਰੋ, [ਕੀਜ਼](https://openrouter.ai/keys) ਪੰਨਾ ਖੋਲ੍ਹੋ, ਨਵਾਂ API ਕੀ ਬਣਾਓ, ਅਤੇ ਟਰਾਂਸਰੀਟ ਵਿੱਚ [**ਸੈਟਿੰਗਸ** > **API ਕਾਂਫਿਗ**](#api-config) ਵਿੱਚ ਇਸ ਨੂੰ ਪੇਸਟ ਕਰੋ।

ਜੇ ਤੁਸicide **ਵੈੱਬ ਵਰਜਨ** ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਸਰਵਰ ਮਾਲਕ ਆਮ ਤੌਰ 'ਤੇ ਇਹ ਤੁਹਾਡੇ ਲਈ ਸੈੱਟ ਅਪ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਆਮ ਤੌਰ 'ਤੇ ਆਪਣੇ ਆਪ API ਕੀ ਦਾਖਲ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਮਹਿਸੂਸ ਕਰੋਗੇ।

<br />

<a id="how-to-get-an-api-key-desktop-app"></a>
### API ਕੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੋ (ਡੈਸਕਟਾਪ ਐਪ)

ਜੇ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਇਹ ਕਦਮਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ:

1. ਆਪਣੇ ਵੈੱਬ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ [ਓਪਨਰਾਊਟਰ](https://openrouter.ai) 'ਤੇ ਜਾਓ।
2. ਇੱਕ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਸਾਈਨ ਇਨ ਕਰੋ।
3. [ਕੀਜ਼](https://openrouter.ai/keys) ਪੰਨਾ ਖੋਲ੍ਹੋ।
4. ਨਵਾਂ API ਕੀ ਬਣਾਉਣ ਲਈ ਬਟਨ ਦੀ ਕਲਿੱਕ ਕਰੋ।
5. ਕੀ ਨੂੰ ਉਸ ਨਾਮ ਦਿ ਤੋਂ, ਜੋ ਤੁਹਾਨੂੰ ਬਾਅਦ ਵਿੱਚ ਪਛਾਣਣ ਵਿੱਚ ਮਦਦ ਕਰੇ।
6. ਨਵਾਂ API ਕੀ ਕਾਪੀ ਕਰ ਲਓ।
7. ਟਰਾਂਸਰੀਟ 'ਤੇ ਵਾਪਸ ਜਾਓ ਅਤੇ **ਸੈਟਿੰਗਸ** > **API ਕਾਂਫਿਗ** ਖੋਲ੍ਹੋ।
8. **ਓਪਨਰਾਊਟਰ API ਕੀ** ਵਿੱਚ ਕੀ ਪੇਸਟ ਕਰੋ।
9. ਇਹ ਸੁਨਿਸ਼ਚਿਤ ਕਰਨ ਲਈ ਕਿ ਇਹ ਕੰਮ ਕਰਦਾ ਹੈ, **API ਕਾਂਫਿਗਰੇਸ਼ਨ ਟੈਸਟ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ ਓਪਨਰਾਊਟਰ ਦੇ ਮੁਫ਼ਤ ਰਾਉਟ ਜਾਂ ਹੋਰ ਸਾਰੇ ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਨਾਲ ਸ਼ੁਰੂਆਤ ਕਰ ਸਕਦੇ ਹੋ। ਕਈ ਮਾਮਲਿਆਂ ਵਿੱਚ, ਇਹ ਟਰਾਂਸਰੀਟ ਦੀ ਵਰਤੋਂ ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਕਾਫੀ ਹੈ, ਕਿਸੇ ਪੇਦ ਮਾਡਲ ਦੀ ਚੋਣ ਕਰਨ ਦੀ ਲੋੜ ਪੈਦਾ ਨਹੀਂ ਕਰਦਾ।

<a id="getting-started"></a>
## ਸ਼ੁਰੂਆਤ ਕਰਨਾ

ਜੇ ਇਹ ਤੁਹਾਡੀ ਪਹਿਲੀ ਵਾਰ ਟਰਾਂਸਰੀਟ ਵਰਤਣ ਹੈ, ਤਾਂ ਇਹ ਕ੍ਰਮ ਦੀ ਪਾਲਣਾ ਕਰੋ:

1. ਐਪ ਖੋਲ੍ਹੋ।
2. ਆਵਸ਼ਿਕ ਹੋਣ 'ਤੇ ਗਲਾਬ ਆਈਕਨ ਤੋਂ ਆਪਣੀ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।
3. ਜੇ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** 'ਤੇ ਹੋ, ਤਾਂ [**ਸੈਟਿੰਗਸ** > **API ਕਾਂਫਿਗ**](#api-config) ਖੋਲ੍ਹੋ, ਆਪਣਾ ਓਪਨਰਾਊਟਰ API ਕੀ ਪੇਸਟ ਕਰੋ, ਅਤੇ **API ਕਾਂਫਿਗਰੇਸ਼ਨ ਟੈਸਟ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
4. [**ਸੈਟਿੰਗਸ** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲਾਂ ਸ਼ਾਮਲ ਕਰੋ।
5. [**ਸੈਟਿੰਗਸ** > **ਭਾਸ਼ਾਵਾਂ**](#languages) ਖੋਲ੍ਹੋ ਅਤੇ ਜੇ ਤੁਸੀਂ ਆਪਣੀਆਂ ਸਭ ਤੋਂ ਵੱਡੀਆਂ ਵਰਤੀਆਂ ਭਾਸ਼ਾਵਾਂ ਨੂੰ ਪਹਿਲਾਂ ਆਉਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਆਪਣੀਆਂ **ਟਾਪ ਭਾਸ਼ਾਵਾਂ** ਚੁਣੋ।
6. **ਟਰਾਂਸਲੇਟ** 'ਤੇ ਜਾਓ ਅਤੇ ਸਭ ਕੁਝ ਕੰਮ ਕਰ ਰਿਹਾ ਹੈ ਇਹ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਇੱਕ ਸਧਾਰਨ ਅਨੁਵਾਦ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ।
7. ਇੱਕ ਵਾਰ ਇਹ ਕੰਮ ਕਰ ਲੱਗੇ, ਤਾਂ **ਰੀ-ਰਾਈਟ** ਅਤੇ ਫਿਰ **ਟਰਾਂਸਫਾਰਮ** ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ।

ਇਹ ਕ੍ਰਮ ਮਹੱਤਵਪੂਰਨ ਹੈ। ਇਹ ਸਭ ਤੋਂ ਆਮ ਪਹਿਲੇ-ਵਰਤੋਂ ਸਮੱਸਿਆ ਨੂੰ ਰੋਕਦਾ ਹੈ: ਐਪ ਦੇ ਕੰਮ ਕਰਦੇ API ਕਨੈਕਸ਼ਨ ਜਾਂ ਚੁਣੇ ਮਾਡਲ ਤੋਂ ਬਿਲਕੁਲ ਪਹਿਲਾਂ ਕਿਸੇ ਕਾਰਜ ਨੂੰ ਚਲਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨਾ।

### ਇਨਪੁੱਟ ਅਤੇ ਆਟਪੁੱਟ ਪੈਨਲ

ਬਹੁਤ ਸਾਰੇ ਵਰਕਸਪੇਸ ਖੱਬੇ ਹੱਥੇ **ਇਨਪੁੱਟ** ਪੈਨਲ ਅਤੇ ਸੱਜੇ ਹੱਥੇ **ਆਟਪੁੱਟ** ਪੈਨਲ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹਨ।

**ਇਨਪੁੱਟ** ਪੈਨਲ ਇਹ ਦਿਖਾਉਂਦਾ ਹੈ:

- ਕੈਰੈਕਟਰ ਗਿਣਤੀ
- ਸ਼ਬਦ ਗਿਣਤੀ
- ਪੈਰਾ ਗਿਣਤੀ

**ਆਟਟਪੁੱਟ** ਪੈਨਲ ਇਹ ਦਿਖਾ ਸਕਦਾ ਹੈ:

- ਟਸਕ ਦਾ ਟਾਈਮ ਕਿੱਨਾ ਰਹਿਆ
- ਉਸ ਟਸਕ ਦੀ ਲਾਗਤ
- ਤੁਹਾਡੀ ਕੁੱਲ ਚੱਲਦੀ ਲਾਗਤ
- **ਟੀਪੀਐਸ** (ਟੋਕਨ ਪ੍ਰਤੀ ਸੈਕੰਡ), ਜੋ ਇੱਕ ਸਧਾਰਨ ਗਤੀ ਮਾਪ ਹੈ
- ਕੈਰੈਕਟਰ, ਸ਼ਬਦ, ਅਤੇ ਪੈਰੇ ਦੀ ਗਿਣਤੀ
- ਵਰਤਿਆ ਮਾਡਲ

ਜੇ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦਾਂ ਬਾਰੇ ਸੋਚ ਰਹੇ ਹੋ:

- **ਟੋਕਨ** ਦਾ ਮਤਲਬ ਹੈ ਟੈਕਸਟ ਦਾ ਛੋਟਾ ਟੁਕੜਾ। ਤੁਸੀਂ ਇਸਨੂੰ ਇੱਕ ਸ਼ਬਦ ਦੇ ਹਿੱਸੇ ਜਾਂ ਇੱਕ ਛੋਟੇ ਸ਼ਬਦ ਵਜੋਂ ਸੋਚ ਸਕਦੇ ਹੋ।
- **ਟੀਪੀਐਸ** ਦਾ ਮਤਲਬ ਹੈ ਕਿ ਕਿੱਨੇ ਉਹਨਾਂ ਟੈਕਸਟ ਟੁਕੜਿਆਂ ਨੂੰ ਮਾਡਲ ਹਰ ਸੈਕੰਡ ਪ੍ਰੋਸੈਸ ਕਰਦਾ ਹੈ।

## ਟਰਾਂਸਫ਼ਾਰਮ

**ਟਰਾਂਸਫ਼ਾਰਮ** ਦੀ ਵਰਤੋਂ ਕਰੋ ਜਦੋਂ ਤੁਸੀਂ Artificial Intelligence ਨੂੰ ਕਸਟਮ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਸੈੱਟ ਦੇਣੀ ਚਾਹੁੰਦੇ ਹੋ।

![ਟਰਾਂਸਫ਼ਾਰਮ ਵਰਕਸਪੇਸ](../images/screenshots/pa/transform.png)

ਇਹ ਐਪ ਦਾ ਸਭ ਤੋਂ ਲਚਕਦਾਰ ਹਿੱਸਾ ਹੈ। ਤੁਸੀਂ ਇਸਨੂੰ ਇਹਨਾਂ ਟਾਸਕਾਂ ਲਈ ਵਰਤ ਸਕਦੇ ਹੋ:

- ਨੋਟਾਂ ਦਾ ਸਾਰ
- ਰੱਲੇ ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਪਾਲਿਸ਼ਡ ਈਮੇਲ ਵਿੱਚ ਬਦਲਣਾ
- ਮੁੱਖ ਬਿੰਦੂਾਂ ਨੂੰ ਨਿਕਾਲਣਾ
- ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਖਾਸ ਫਾਰਮੈਟ ਵਿੱਚ ਤਬਦੀਲ ਕਰਨਾ

<br />

<a id="run-an-existing-prompt"></a>
### ਮੌਜੂਦਾ ਪ੍ਰੋਂਪਟ ਚਲਾਓ

1. **ਟਰਾਂਸਫ਼ਾਰਮ** ਖੋਲ੍ਹੋ।
2. ਪ੍ਰੋਂਪਟ ਸੂਚੀ ਤੋਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਚੁਣੋ।
3. ਜੇ **ਟਾਰਗੇਟ** ਭਾਸ਼ਾ ਬਾਕਸ ਦਿਖਾਈ ਦੇਂਦਾ ਹੈ, ਤਾਂ ਜੇ ਤੁਸੀਂ ਇੱਕ ਭਾਸ਼ਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਚੁਣੋ।
4. **ਇਨਪੁੱਟ** ਵਿੱਚ ਟੈਕਸਟ ਟਾਇਪ ਕਰੋ ਜਾਂ ਪੇਸਟ ਕਰੋ।
5. **ਟਰਾਂਸਫ਼ਾਰਮ** ਉੱਤੇ ਕਲਿਕ ਕਰੋ।
6. **ਆਟਪੁੱਟ** ਵਿੱਚ ਨਤੀਜ਼ਾ ਪੜ੍ਹੋ।

<br />

<a id="if-you-have-no-prompts-yet"></a>
### ਜੇ ਤੁਹਾਡੇ ਕੋਈ ਪ੍ਰੋਂਪਟ ਹੈ ਨਹੀਂ ਹੋਣੇ

ਜੇ ਤੁਹਾਡੀ ਪ੍ਰੋਂਪਟ ਸੂਚੀ ਖਾਲੀ ਹੈ, **ਲੋਡ ਸੈਂਪਲ ਪ੍ਰੋਂਪਟਸ** 'ਤੇ ਕਲਿਕ ਕਰੋ। ਇਹ ਬਿਲਟ-ਇਨ ਉਦਾਹਰਨ ਉੱਡਾਉਂਦਾ ਹੈ ਤਾਂ ਜੋ ਤੁਸੀਂ ਤੇਜ਼ੀ ਨਾਲ ਸ਼ੁਰੂ ਕਰ ਸਕੋ।

> ℹ️ **ਨੋਟ**<br/>
> ਸੈਂਪਲ ਪ੍ਰੋਂਪਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਦਿੱਤੇ ਗਏ ਹਨ। ਉਹਨਾਂ ਨੂੰ ਲੋਡ ਕਰਨ ਦੇ ਬਾਅਦ, ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੋਂਪਟ ਨੂੰ ਸੋਧ ਸਕਦੇ ਹੋ ਅਤੇ ਜੇ ਤੁਸੀਂ ਪ੍ਰੋਂਪਟ ਟੈਕਸਟ ਨੂੰ ਕਿਸੇ ਹੋਰ ਭਾਸ਼ਾ ਲਈ ਅਨੁਕੂਲ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਪ੍ਰੋਂਪਟ ਟਰਾਂਸਲੇਟ** ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।

<br />

<a id="create-a-prompt-quickly"></a>

### ਤੁਹਾਡਾ ਪ੍ਰਾਂਪਟ ਤੇਜ਼ੀ ਨਾਲ ਬਣਾਓ

ਪ੍ਰਾਂਪਟ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਰਸਤਾ ਹੈ:

1. **ਨਵਾਂ ਪ੍ਰਾਂਪਟ** 'ਤੇ ਕਲਿਕ ਕਰੋ।
2. **ਪ੍ਰਾਂਪਟ ਜਨਰੇਟ ਕਰੋ** 'ਤੇ ਕਲਿਕ ਕਰੋ।
3. ਵਿਸਤਰਿਤ ਦਿਓ ਕਿ ਤੁਸੀਂ ਪ੍ਰਾਂਪਟ ਕੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।
4. ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. ਐਪ ਤੁਹਾਡੇ ਲਈ ਇੱਕ ਖੱਕ ਦੀ ਬਣਾਈ ਦੇ।
6. ਖੱਕ ਨੂੰ ਜਾਂਚੋ ਅਤੇ **ਸੰਭਾਲੋ** 'ਤੇ ਕਲਿਕ ਕਰੋ।

![ਪ੍ਰਾਂਪਟ ਜਨਰੇਟ ਕਰੋ](../images/screenshots/pa/transform-generate.png)


<br />

### ਪ੍ਰਾਂਪਟ ਸੋਧੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰਾਂਪਟ ਬਣਾਉਂਦੇ ਹੋ ਜਾਂ ਸੋਧਦੇ ਹੋ, ਖੇਡਰ ਖੱਬੇ ਪਾਸੇ ਅਤੇ ਟੈਸਟ ਖੇਤਰ ਸੱਜੇ ਪਾਸੇ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

![ਪ੍ਰਾਂਪਟ ਸੋਧ ਸੰਦਰਭ](../images/screenshots/pa/transform-prompt-edit.png)

ਮੁੱਖ ਖੇਤਰ ਹਨ:

- **ਪ੍ਰਾਂਪਟ ਨਾਂ**: ਪ੍ਰਾਂਪਟ ਸੂਚੀ ਵਿੱਚ ਦਿਖਾਇਆ ਗਿਆ ਨਾਂ।
- **ਪ੍ਰਾਂਪਟ ਨਿਦੇਸ਼ (ਵੈਕਲਪਿਕ)**: ਪ੍ਰਾਂਪਟ ਨੂੰ ਚਲਾਉਂਦੇ ਸਮੇਂ ਯੂਜ਼ਰ ਨੂੰ ਦਿਖਾਇਆ ਜਾਣ ਵਾਲਾ ਇੱਕ ਛੋਟਾ ਸੰਦੇਸ਼।
- **ਮਾਡਲ ਰੋਲ**: AI ਨੂੰ ਦਿੱਤਾ ਗਿਆ ਸਮੁੱਚਾ ਰੋਲ, ਜਿਵੇਂ 'ਤੁਸੀਂ ਇੱਕ ਮਦਦਗਾਰ ਸਹਾਇਕ ਹੋ।'
- **ਮਾਡਲ ਨਿਦੇਸ਼ (ਹਰੇਕ ਲਾਈਨ 'ਤੇ)**: ਉਹ ਖਾਸ ਨਿਯਮ ਜੋ ਤੁਸੀਂ AI ਨੂੰ ਪਾਲਣ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।
- **ਆਉਟਪੁੱਟ ਵਰਣਨ**: ਨਤੀਜੇ ਦੇ ਬਾਰੇ ਇੱਕ ਸ਼ਬਦ, ਜਿਵੇਂ 'ਸਾਰ' ਜਾਂ 'ਰੀਵਰਾਈਟ'।
- **ਤਾਪਮਾਨ (0.0 → 1.0)**: ਇੱਕ ਰਚਨਾਤਮਕਤਾ ਸਲਾਈਡਰ।
- **ਟਾਰਗੇਟ ਭਾਸ਼ਾ ਲਈ ਪੁੱਛੋ**: ਜਦੋਂ ਪ੍ਰਾਂਪਟ ਚੱਲਦਾ ਹੈ, ਤਾਂ ਇੱਕ ਟਾਰਗੇਟ ਭਾਸ਼ਾ ਚੋਣਕਾਰ ਜੋੜ ਦਿੰਦਾ ਹੈ।

ਜੇ ਤੁਹਾਨੂੰ ਤਕਨੀਕੀ ਸ਼ਬਦ **ਤਾਪਮਾਨ** ਬਾਰੇ ਪਹਿਲਾਂ ਨਹੀਂ ਪਤਾ, ਤਾਂ ਇਸ ਨੂੰ ਇਸ ਤਰ੍ਹਾਂ ਸੋਚੋ:

- ਇੱਕ **ਨੀਵੀਂ** ਤਾਪਮਾਨ ਨਾਲ ਸਥਿਰ, ਹੋਰ ਪਛਾਣਯੋਗ ਨਤੀਜੇ ਮਿਲਦੇ ਹਨ।
- ਇੱਕ **ਉੱਚੀ** ਤਾਪਮਾਨ ਨਾਲ ਵੱਖ-ਵੱਖ ਰਚਨਾਵਾਂ ਅਤੇ ਰਚਨਾਤਮਕਤਾ ਮਿਲਦੀ ਹੈ।

ਤੁਸੀਂ ਇਹ ਵੀ ਵਰਤ ਸਕਦੇ ਹੋ:

- **`Generate prompt`** ਨਵਾਂ ਖੱਕ ਬਣਾਉਣ ਲਈ ਇੱਕ ਸਧਾਰਨ ਵਰਣਨ ਤੋਂ
- **`Improve prompt`** ਮੌਜੂਦਾ ਪ੍ਰਾਂਪਟ ਨੂੰ ਬਿਹਤਰ ਬਣਾਉਣ ਲਈ
- **`Translate prompt`** ਪ੍ਰਾਂਪਟ ਖੇਤਰਾਂ ਨੂੰ ਅਨੁਵਾਦ ਕਰਨ ਲਈ

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> **`Save`** 'ਤੇ ਕਲਿਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **`Back to Run`** 'ਤੇ ਕਲਿਕ ਕਰੋ। ਜੇ ਤੁਸੀਂ ਸੰਭਾਲੇ ਬਿਨਾਂ ਵਾਪਸ ਜਾਂਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਡੇ ਬਦਲਾਵ ਗੁਆਬ ਹੋ ਜਾਣਗੇ।

<br />

<a id="test-a-prompt-before-using-it"></a>
### ਵਰਤਣ ਤੋਂ ਪਹਿਲਾਂ ਪ੍ਰਾਂਪਟ ਟੈਸਟ ਕਰੋ

ਸੱਜੇ ਪਾਸੇ ਦੇ ਟੈਸਟ ਪੈਨਲ ਤੁਹਾਨੂੰ ਤੁਹਾਡੇ ਪ੍ਰਾਂਪਟ ਨੂੰ ਰੋਜ਼ਾਨਾ ਕੰਮ ਵਿੱਚ ਵਰਤਣ ਤੋਂ ਪਹਿਲਾਂ ਨਮੂਨਾ ਟੈਕਸਟ ਨਾਲ ਟਰਾਇ ਕਰਨ ਦਿੰਦਾ ਹੈ।

ਇਹ ਲਾਭਦਾਇਕ ਹੈ ਜਦੋਂ:

- ਤੁਸੀਂ ਇੱਕ ਨਵਾਂ ਪ੍ਰਾਂਪਟ ਬਣਾ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਪ੍ਰਾਂਪਟ ਦੇ ਦੋ ਵਰਜਨਾਂ ਨੂੰ ਤੁਲਨਾ ਕਰ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਸੁਰ, ਲੰਬਾਈ, ਜਾਂ ਆਉਟਪੁੱਟ ਫਾਰਮੇਟ ਜਾਂਚਣਾ ਚਾਹੁੰਦੇ ਹੋ

<br />

<a id="manage-saved-prompts"></a>
### ਸੰਭਾਲੇ ਪ੍ਰਾਂਪਟਾਂ ਨੂੰ ਪ੍ਰਬੰਧਿਤ ਕਰੋ

ਸੰਭਾਲੇ ਪ੍ਰਾਂਪਟਾਂ ਨੂੰ ਇੱਕ ਥਾਂ ਵਿੱਚ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਪ੍ਰਾਂਪਟਾਂ ਨੂੰ ਪਰਿਵਰਤਨ**](#transform-prompts) ਖੋਲੋ।

ਉੱਥੇ ਤੁਸੀਂ:

- ਆਪਣੇ ਪ੍ਰਾਂਪਟ ਸੂਚੀਬੱਧ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ ਮਿਟਾ ਸਕਦੇ ਹੋ
- ਪ੍ਰਾਂਪਟਾਂ ਨੂੰ **JSON**, **CSV**, ਜਾਂ **XLSX** ਵਜੋਂ ਐਕਸਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ
- ਇੱਕ ਫਾਈਲ ਤੋਂ ਪ੍ਰਾਂਪਟਾਂ ਇੰਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ

## ਡੈਸ਼ਬੋਰਡ

**ਡੈਸ਼ਬੋਰਡ** ਦੀ ਵਰਤੋਂ ਕਰੋ ਤਾਂ ਜੋ ਤੁਸੀਂ ਜਾਣ ਸਕੋ ਕਿ ਤੁਸੀਂ ਐਪ ਦੀ ਕਿੰਨੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ ਅਤੇ ਇਹ ਕਿੰਨਾ ਖਰਚਾ ਹੋ ਰਿਹਾ ਹੈ।

![ਡੈਸ਼ਬੋਰਡ ਸਾਰ](../images/screenshots/pa/dashboard-summary.png)

<br />

<a id="filter-the-data"></a>
### ਡੇਟਾ ਫਿਲਟਰ ਕਰੋ

ਟਾਈਮ ਰੇਂਜ ਬਦਲਣ ਲਈ ਉੱਪਰ ਫਿਲਟਰ ਬਟਨਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਡੈਸ਼ਬੋਰਡ ਫਿਲਟਰ](../images/screenshots/pa/dashboard-filter.png)

> ℹ️ **ਨੋਟ**<br/>
> ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ, ਪਰਿਬੰਧਕਾਂ ਨੂੰ **ਉਪਭੋਗਤਾ** ਫਿਲਟਰ ਵੀ ਦੇਖਣ ਦੀ ਆਗਿਆ ਹੋ ਸਕਦੀ ਹੈ। ਇਹ ਉਨ੍ਹਾਂ ਨੂੰ **ਸਾਰੇ ਉਪਭੋਗਤੇ** ਅਤੇ ਇੱਕ ਵੱਖੇ ਉਪਭੋਗਤੇ ਦਰਮਿਆਨ ਸਵੈਚ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<br />

<a id="dashboard-tabs"></a>
### ਡੈਸ਼ਬੋਰਡ ਟੈਬਸ

- **ਸਾਰ** ਤੁਹਾਨੂੰ ਵਰਤੋਂ ਅਤੇ ਖਰਚੇ ਦੇ ਅਧੀਨ ਇੱਕ ਝਲਕ ਦਿੰਦਾ ਹੈ।
- **ਵਰਤੋਂ ਦੇ ਅਨੁਸਾਰ** ਗਤੀਵਿਧੀ ਨੂੰ ਅਨੁਵਾਦ ਭਾਸ਼ਾ, ਰੀਵਰਾਈਟ ਮੋਡ, ਅਤੇ ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰਾਂਪਟ ਦੇ ਅਨੁਸਾਰ ਵੰਡਦਾ ਹੈ।
- **ਮਾਡਲ ਦੇ ਅਨੁਸਾਰ** ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਕਿਨ੍ਹਾਂ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਅਤੇ ਉਹ ਕਿੰਨੇ ਮੁੱਲ ਵਾਲੇ ਹਨ।
- **ਦਿਨ ਦੇ ਅਨੁਸਾਰ** ਦਿਨਾਲਾ ਕੁੱਲਾਂ ਦਿਖਾਉਂਦਾ ਹੈ।
- **ਸਾਰੇ ਕਾਲ** ਪੂਰੀ ਕਾਲ ਹਿਸਟਾਰੀ ਦਿਖਾਉਂਦਾ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ ਇਸਨੂੰ ਐਕਸਪੋਰਟ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<a id="delete-stored-records-for-a-model"></a>
### ਇੱਕ ਮਾਡਲ ਲਈ ਸੰਭਾਲੇ ਰਿਕਾਰਡਾਂ ਨੂੰ ਮਿਟਾਓ

**ਮਾਡਲ ਦੇ ਅਨੁਸਾਰ** ਜਾਂ **ਸਾਰੇ ਕਾਲ** ਵਿੱਚ, ਤੁਸੀਂ ਇੱਕ ਮਾਡਲ ਲਈ ਸੰਭਾਲੇ ਰਿਕਾਰਡਾਂ ਨੂੰ ਹਟਾ ਸਕਦੇ ਹੋ।

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਸੰਭਾਲੇ ਰਿਕਾਰਡਾਂ ਨੂੰ ਮਿਟਾਉਣਾ ਵਾਪਸ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਸਿਰਫ਼ ਇਸ ਤਰ੍ਹਾਂ ਵਰਤੋ ਜੇ ਤੁਸੀਂ ਉਹ ਇਤਿਹਾਸ ਹੋਰ ਲੋੜੀਂਦੇ ਨਹੀਂ ਹੋ।

ਸਾਰੇ ਡੇਟਾ ਨੂੰ ਮਿਟਾਉਣ ਲਈ ਜਾਂ ਉਹਨਾਂ ਦੀ ਉਮਰ ਦੇ ਅਨੁਸਾਰ ਰਿਕਾਰਡਾਂ ਨੂੰ ਹਟਾਉਣ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਖਰਚੇ ਟਰੈਕਿੰਗ**](#cost-tracking) ਉੱਤੇ ਜਾਓ। ਉੱਥੇ ਤੁਹਾਡੇ ਕੋਇਂ ਵਲੇ ਸਾਰੇ ਸੰਭਾਲੇ ਡੇਟਾ ਨੂੰ ਮਿਟਾਉਣ ਦੇ ਵਿਕਲਪ ਜਾਂ ਸਿਰਫ਼ ਉਹ ਡੇਟਾ ਜੋ ਇੱਕ ਨਿਸ਼ਾਨੀ ਤਾਰੀਖ ਤੋਂ ਪੁਰਾਣਾ ਹੋ ਜਾਂਦੇ ਹਨ।

<a id="settings"></a>
## ਸੈਟਿੰਗਸ

ਸਾਈਡਬਾਰ ਤੋਂ **ਸੈਟਿੰਗਸ** ਖੋਲੋ ਤਾਂ ਜੋ ਤੁਸੀਂ ਐਪ ਦੇ ਵਿਵਰਤੀ ਨੂੰਕ ਸੁਲਭ ਕਰ ਸਕੋ।

ਉਪਲੱਬਧ ਟੈਬ ਵੱਖ-ਵੱਖ ਹੋ ਸਕਦੇ ਹਨ:

- **API ਸੰਰਚਨਾ** ਸਿਰਫ਼ ਡੈਸਕਟਾਪ ਐਪ ਵਿੱਚ ਉਪਲੱਬਧ ਹੈ।
- **ਉਪਭੋਗਤੇ** ਸਿਰਫ਼ ਵੈੱਬ ਐਪ ਵਿੱਚ ਉਪਲੱਬਧ ਹੈ, ਅਤੇ ਸਿਰਫ਼ ਪਰਿਬੰਧਕਾਂ ਲਈ।

<br />

<a id="general-settings"></a>

### ਆਮ ਸੈਟਿੰਗ्स

**ਆਮ ਸੈਟਿੰਗ्स** ਦੀ ਵਰਤੋਂ ਟਾਈਪਿੰਗ ਵਿਵਹਾਰ ਅਤੇ ਰੂਪ ਨੂੰ ਕਾਬੂ ਕਰਨ ਲਈ ਕਰੋ।

**ਵਿਵਹਾਰ**

- **ENTER ਲਈ ਵਿਵਹਾਰ** ਚੁਣਦਾ ਹੈ ਕਿ Enter ਟਾਸਕ ਨੂੰ ਚਲਾਏਗਾ ਜਾਂ ਨਵੀੰ ਲਾਈਨ ਦੇਵੇਗਾ।
- **ਪੇਸਟ ਕਰਨ 'ਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਟੈਕਸਟ ਪੇਸਟ ਕਰਨ ਤOnAction ਆਨੁਵਾਦ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- **ਆਟੋ-ਕਾਪੀ ਨਤੀਜਾ ਕਲਿੱਪਬੋਰਡ 'ਤੇ** ਸਫਲ ਨਤੀਜਿਆਂ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪਿੰਗ ਦੌਰਾਨ)** ਤੁਹਾਡੇ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ।
- **ਟਾਈਮਆਉਟ (ਮਿ.ਸ)** ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਲਈ ਜਾਂਟੀ ਟਾਈਮ ਸੈੱਟ ਕਰਦਾ ਹੈ।

**ਝਲਕ**

- **ਲਾਗਤ ਦਸ਼ਮਲਵ ਅੰਕ** ਲਾਗਤ ਦਸ਼ਮਲਵ ਦੀ ਡਿਸਪਲੇ ਨੂੰ ਨਵਾਂ ਕਰਦੀ ਹੈ।
- **ਫਾਂਟ ਫੈਮਿਲੀ** ਟੈਕਸਟ ਪੈਨਲਾਂ ਵਿੱਚ ਲਿਖਣ ਦਾ ਫਾਂਟ ਬਦਲਦੀ ਹੈ।
- **ਸਾਈਜ਼** ਫਾਂਟ ਦਾ ਸਾਈਜ਼ ਬਦਲਦੀ ਹੈ।
- **ਕੇਵਲ ਵੈੱਬ:** **ਐਪਲੀਕੇਸ਼ਨ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਮਾਰਜਿਨ ਦਿਖਾਓ** ਇੰਟਰਫੇਸ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਵਧੇਰੇ ਖਾਲੀ ਥਾਂ ਪੈਦਾ ਕਰਦੀ ਹੈ।

<a id="models"></a>
### ਮਾਡਲ

**ਸੈਟਿੰਗਸ** > **ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰੋ, ਜੋ ਕਿ ਟੂਲਬਾਰ ਵਿੱਚ ਦਿਖਾਈ ਦੇਣ ਵਾਲੇ ਮਾਡਲ ਚੁਣਨ ਲਈ ਹੈ।

![ਸੈਟਿੰਗਸ ਮਾਡਲ ਟੈਬ](../images/screenshots/pa/settings-models.png)

ਇਸ ਪੰਨਾ ਦੇ ਦੋ ਸੂਚੀਆਂ ਹਨ:

- **ਉਪਲਬਧ ਮਾਡਲ** ਖੱਬੇ ਪਾਸੇ
- **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਸੱਜੇ ਪਾਸੇ

ਲਾਭਦਾਇਕ ਕੰਟਰੋਲਾਂ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:

- **ਮਾਡਲ ਲੱਭੋ...** ਮਾਡਲ ਨਾਂ ਦੁਆਰਾ ਲੱਭਣ ਲਈ
- **ਕੇਵਲ ਮੁਫ਼ਤ** ਸਿਰਫ਼ ਮੁਫ਼ਤ ਮਾਡਲ ਦਿਖਾਉਣ ਲਈ
- **ਰੀਫ੍ਰੈਸ਼** ਸੂਚੀ ਨੂੰ ਮੁੜ ਲੋਡ ਕਰਨ ਲਈ
- **ਸਭ ਫੈਲਾਓ** ਅਤੇ **ਸਭ ਰਟਾੜ** ਜਦੋਂ ਤੁਸੀਂ ਪ੍ਰੋਵਾਈਡਰ ਦੁਆਰਾ ਛਾਂਟ ਰਹੇ ਹੋ

ਮਾਡਲ ਜੋੜਨ ਲਈ, **Add** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਮਾਡਲ ਹਟਾਉਣ ਲਈ, **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇਸ ਦੇ ਬਾਗੇ **X** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਸੂਚੀ ਸਾਫ਼ ਕਰਨ ਲਈ, **Deselect all** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਲੋੜੀਂਦਾ ਮੁਫ਼ਤ ਮਾਡਲ ਸੂਚੀ ਵਿੱਚ ਬਣਿਆ ਰਹੇਗਾ।

> ℹ️ **ਨੋਟ**<br/>
> ਜੇ ਤੁਸੀਂ ਤੁਰंत OpenRouter 'ਤੇ ਕ੍ਰੈਡਿਟ ਜੋੜਨਾ ਨਹੀਂ ਚਾਹੁੰਦੇ, ਤਾਂ **Free Only** ਨੂੰ ਸਮਰੱਥ ਕਰਕੇ ਅਤੇ ਮੁਫ਼ਤ ਮਾਡਲ ਚੁਣਕੇ ਸ਼ੁਰੂ ਆਓ।

### ਭਾਸ਼ਾਵਾਂ

**ਸੈਟਿੰਗਸ** > **ਭਾਸ਼ਾਵਾਂ** ਦੀ ਵਰਤੋਂ ਕਰੋ, ਤਾਂ ਜੋ ਐਪ ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਂਦੀਆਂ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਨੂੰ ਪ੍ਰਬੰਧ ਕੀਤਾ ਜਾ ਸਕੇ।

- **ਟੌਪ ਭਾਸ਼ਾਵਾਂ** **ਅਨੁਵਾਦ** ਅਤੇ **ਟਰਾਂਸਫ਼ਾਰਮ** ਵਿੱਚ ਭਾਸ਼ਾ ਸੂਚੀਆਂ ਦੇ ਉੱਪਰ ਦੇ ਨੇੜੇ ਪਿਨ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- **ਕਸਟਮ ਭਾਸ਼ਾ** ਤੁਹਾਨੂੰ ਇੱਕ ਅਜੇੱਬ ਭਾਸ਼ਾ ਜੋੜਨ ਦੀ ਆਗਿਆ ਕਰਦੀ ਹੈ ਜੋ ਬਿਲਟ-ਇਨ ਸੂਚੀ ਵਿੱਚ ਨਹੀਂ ਹੈ।

ਜੇ ਤੁਸੀਂ ਕਸਟਮ ਭਾਸ਼ਾ ਜੋੜਦੇ ਹੋ, ਤਾਂ ਇਹ ਬਿਲਟ-ਇਨ ਵਿਕਲਪਾਂ ਦੇ ਨਾਲ-ਨਾਲ ਭਾਸ਼ਾ ਸੈਲੈਕਟਰਾਂ ਵਿੱਚ ਦਿਖਾਈ ਦੇਵੀ ਗੀ।

<a id="cost-tracking"></a>
### ਲਾਗਤ ਟਰੈਕਿੰਗ

**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ, ਲਾਗਤ ਜਾਣਕਾਰੀ ਨੂੰ ਪ੍ਰਬੰਧ ਕਰਨ ਲਈ।

- **ਟੋਟਲ ਲਾਗਤ** ਚੱਲਦਾ ਕੁੱਲ ਦਿਖਾਉਂਦੀ ਹੈ।
- **ਕਾਪੀ ਵੈਲੂ** ਕੁੱਲ ਨੂੰ ਕਲਿੱਪਬੋਰਡ 'ਤੇ ਕਾਪੀ ਕਰਦੀ ਹੈ।
- **ਰੀਸੈੱਟ ਲਾਗਤ** ਸਟੋਰ ਕੀਤਾ ਕੁੱਲ ਨੂੰ ਜ਼ੀਰੋ 'ਤੇ ਰੀਸੈੱਟ ਕਰਦੀ ਹੈ।
- **API ਕੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ** ਕੁੱਲ ਨੂੰ OpenRouter ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੀ ਵਰਤੋਂ ਨਾਲ ਮੈਚ ਕਰਨ ਲਈ ਸੈੱਟ ਕਰਦੀ ਹੈ।
- **API ਕੀ ਵਰਤੋਂ** ਵਰਤੋਂ ਦੇ ਵੇਰਵੇ ਦਿਖਾਉਂਦੀ ਹੈ, ਜੇ ਉਪਲਬਧ ਹੋਣ।
- **ਲਾਗਤ ਡਾਟਾ ਡੀਲੀਟ** ਸਾਰੇ ਡਾਟਾ ਨੂੰ ਹਟਾਉਂਦੀ ਹੈ, ਜਾਂ ਸਿਰਫ਼ ਚੁਣੀ ਗਈ ਮਿਤੀ ਤੋਂ ਪੁਰਾਣੀ ਐਂਟਰੀ।

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਡਾਟਾ ਹਟਾਉਣਾ ਵਾਪਸ ਨਹੀਂ ਲੱਭ ਸਕਦਾ। ਸੁੱਟਣ ਤੋਂ ਪਹਿਲਾਂ, ਆਪਣਾ ਡਾਟਾ ਬੈਕਅਪ ਕਰਨ ਯਾ [**ਡੈਸ਼ਬੋਰਡ** > **ਸਭ ਕਾਲ**](#dashboard-tabs) ਰਾਹੀਂ ਐਕਸਪੋਰਟ ਕਰਨ ਯਕੀਨੀ ਬਣਾਓ, ਨਹੀਂ ਤਾਂ ਇਹ ਸਦੇ ਵਾਸਤੇ ਗੁਆ ਜਾਵੇਗਾ।

### ਟਰਾਂਸਫ਼ਾਰਮ ਪ੍ਰਾਮਪਟਸ

**ਸੈਟਿੰਗਸ** > **ਟਰਾਂਸਫ਼ਾਰਮ ਪ੍ਰਾਮਪਟਸ** ਦੀ ਵਰਤੋਂ ਕਰੋ, ਪ੍ਰਾਮਪਟਸ ਨੂੰ ਵੱਡੇ ਪੱਧਰ 'ਤੇ ਪ੍ਰਬੰਧ ਕਰਨ ਲਈ।

ਤੁਸੀਂ:

- ਆਪਣੇ ਸੇਵ ਕੀਤੇ ਪ੍ਰਾਮਪਟਸ ਦਾ ਸਮੀਖਿਆ ਕਰ ਸਕਦੇ ਹੋ
- ਪ੍ਰਾਮਪਟਸ ਡੀਲੀਟ ਕਰ ਸਕਦੇ ਹੋ
- ਫਾਈਲ ਤੋਂ ਪ੍ਰਾਮਪਟਸ ਇੰਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ
- ਬੈਕਅਪ ਜਾਂ ਸਾਂਝੇ ਕਰਨ ਲਈ ਪ੍ਰਾਮਪਟਸ ਐਕਸਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ

<a id="users"></a>
### ਉਪਭੋਗਤਾ

**ਵੈੱਬ ਸਿਰਫ - ਏਡਮੀਨਿਸਟਰੇਟਰ ਸਿਰਫ**

**ਉਪਭੋਗਤਾ** ਦੀ ਵਰਤੋਂ ਕਰੋ, ਵੈੱਬ ਵਰਜਨ ਵਿੱਚ ਉਪਭੋਗਤਾ ਖਾਤਿਆਂ ਨੂੰ ਪ੍ਰਬੰਧ ਕਰਨ ਲਈ। ਤੁਸੀਂ ਉਪਭੋਗਤਾ ਜੋੜ ਸਕਦੇ ਹੋ, ਉਹਨਾਂ ਦੇ ਵੇਰਵਿਆਂ ਅਪਡੇਟ ਕਰ ਸਕਦੇ ਹੋ, ਪਾਸਵਰਡ ਰੀਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ, ਅਤੇ ਖਾਤੇ ਹਟਾ ਸਕਦੇ ਹੋ।

<a id="api-config"></a>
### API ਕਨਫਿਗ

**ਡੈසਕਟਾਪ ਸਿਰਫ**

**API ਕਨਫਿਗ** ਦੀ ਵਰਤੋਂ ਕਰੋ, ਡੈਸਕਟਾਪ ਐਪ ਨੂੰ OpenRouter ਜਾਂ Transrewrt ਪਰੋਟਾਕਸੇ ਨਾਲ ਜੋੜਨ ਲਈ।

- **OpenRouter API Key** ਉਹ ਥਾਂ ਹੈ ਜਿਸ 'ਤੇ ਤੁਹਾਡੀ ਕੀ ਪੇਸਟ ਕਰਦੇ ਹੋ।
- **API URL** ਸਰਵਿਸ ਪਤਾ ਹੈ। ਇਸ ਨੂੰ ਡਿਫਾਲਟ 'ਤੇ ਛੱਡੋ, ਜਦ ਤੱਕ ਤੁਹਾਨੂੰ ਵੱਖਰਾ ਪਤਾ ਦਿੱਤਾ ਨਾ ਗਿਆ ਹੋ।
- **Transrewrt Proxy ਵਰਤੋਂ** ਬਿਲਕੁਲ OpenRouter ਤੱਕ ਸਿੱਧੀ ਬਪਾਰ ਹੋਣ ਦੀ bajae ਇੱਕ ਪਰੋਟਾ ਸਰਵਿਸ ਰਾਹੀਂ ਬਣਾਇਆਂ ਗਈ ਮੰਗਾਂ ਨੂੰ ਰਾਊਟ ਕਰਦਾ ਹੈ।
- **Key Seed** ਉਭਰਦਾ ਹੈ ਜਦੋਂ ਪਰੋਟਾ ਐਪਸ਼ਨ ਸਮਰੱਥ ਹੁੰਦੀ ਹੈ।
- **API Configuration ਟੈਸਟ** ਜਾਂਚ ਕਰਦਾ ਹੈ ਕਿ ਕੀ ਮੌਜੂਦਾ ਸੈਟਿੰਗ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।

ਆਪਣੇ API ਕੀ ਪ੍ਰਾਪਤ ਕਰਨ ਬਾਰੇ ਵਿਸਥਾਰ ਨੂੰ ਉੱਪਰ ਦੇਖੋ [API ਕੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੀਏ](#how-to-get-an-api-key-desktop-app)।

> ℹ️ **ਨੋਟ**<br/>
> ਜੇ ਤੁਸੀਂ ਨਹੀਂ ਜਾਣਦੇ ਕਿ **API URL**, **Transrewrt Proxy ਵਰਤੋਂ**, ਜਾਂ **Key Seed** ਦੀ ਅਰਥ ਸ਼ਾਈਲੀ ਹੈ, ਤਾਂ ਉਹਨਾਂ ਨੂੰ ਬਣਾਈ ਰੱਖੋ ਅਤੇ ਡਿਫਾਲਟ OpenRouter ਸੈਟਿੰਗ ਦੀ ਵਰਤੋਂ ਕਰੋ। ਪਰੋਟਾ ਬਾਰੇ ਹੋਰ ਜਾਣਕਾਰੀ [Transrewrt Proxy ਰਿਪੋਜ਼ੀਟਰੀ](https://github.com/wsj-br/transrewrt-proxy) ਵਿੱਚ ਉਪਲਬਧ ਹੈ।

- ਬਿਲਡ ਤਾਰੀਖ

### ਐਪ ਟੈਕਸਟ ਦਾ ਅਨੁਵਾਦ, ਰੀਲਾਈਟ, ਜਾਂ ਟ੍ਰਾਂਸਫਾਰਮ ਨਹੀਂ ਕਰੇਗੀ

ਯਕੀਨ ਬਣਾਓ ਕਿ:

- ਤੁਹਾਡੇ ਨੇ ਟੂਲਬਾਰ ਵਿੱਚ ਕੋਈ ਮਾਡਲ ਚੁਣਿਆ ਹੈ
- [**ਸੈਟਿੰਗਸ** > **ਮਾਡਲ**](#models) ਵਿੱਚ ਕਮੋਂ ਕੋਈ ਮਾਡਲ ਸੂਚੀਬੱਧ ਹੈ
- ਤੁਹਾਡੀ API ਸੈਟਅਪ ਕੰਮ ਕਰ ਰਹੀ ਹੈ

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ:

1. [**ਸੈਟਿੰਗਸ** > **API ਸੈਟਿੰਗ**](#api-config) ਖੋਲੋ।
2. ਯਕੀਨ ਬਣਾਓ ਕਿ ਤੁਹਾਡੀ API ਕੀ ਸੇਵ ਕੀਤੀ ਗਈ ਹੈ।
3. **API ਸੈਟਿੰਗ ਟੈਸਟ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br />

<a id="the-model-list-is-empty"></a>
### ਮਾਡਲ ਲਿਸਟ ਖਾਲੀ ਹੈ

[**ਸੈਟਿੰਗਸ** > **ਮਾਡਲ**](#models) ਖੋਲੋ ਅਤੇ **ਰੀਫ੍ਰੈਸ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਜਰੂਰਤ ਪੈਂਦੇ:

- ਕੋਈ ਮਾਡਲ ਲੱਭੋ
- **ਫਰੀ ਹੀ** ਚਾਲੂ ਕਰੋ
- **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ > ਘੱਟ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ

<br />

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ਨਤੀਜਾ ਬਹੁਤ ਧੀਮਾ ਜਾਂ ਬਹੁਤ ਮਹਿੰਗਾ ਹੈ

ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਜਾਂ > ਕੋਸ਼ਿਸ਼ ਕਰੋ:

- ਇੱਕ ਵੱਖਰਾ ਮਾਡਲ ਚੁਣੋ
- ਛੋਟੇ ਇਨਪੁਟ ਦੀ ਵਰਤੋਂ ਕਰੋ
- [**ਸੈਟਿੰਗਸ** > **ਜਨਰਲ ਸੈਟਿੰਗਸ**](#general-settings) ਵਿੱਚ **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪਿੰਗ ਦੌਰਾਨ)** ਬੰਦ ਕਰੋ
- ਸਧਾਰਨ ਕੰਮਾਂ ਲਈ ਫਰੀ ਮਾਡਲ ਦੀ ਵਰਤੋਂ ਕਰੋ (ikki [ਮਾਡਲ](#models) ਦੇਖੋ)

<br />

<a id="the-interface-is-in-the-wrong-language"></a>
### ਇੰਟਰਫੇਸ ਗਲਤ ਭਾਸ਼ਾ ਵਿੱਚ ਹੈ

[ਟੂਲਬਾਰ](#toolbar) ਵਿੱਚ ਗਲੋਬ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਆਪਣੀ ਪਸੰਦੀਦਾ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।

<br />

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ਟੈਕਸਟ ਬਹੁਤ ਛੋਟਾ ਹੈ ਜਾਂ ਪੜ੍ਹਨ ਵਿੱਚ ਮੁਸ਼ਕਲ

[**ਸੈਟਿੰਗਸ** > **ਜਨਰਲ ਸੈਟਿੰਗਸ**](#general-settings) ਖੋਲੋ ਅਤੇ ਬਦਲੋ:

- **ਫਾਂਟ ਫੈਮਲੀ**
- **ਸਾਈਜ਼**

<br />

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ਮੈਂ ਪ੍ਰੌਮਪਟ ਬਦਲਿਆ ਅਤੇ ਸੰਪਾਦਨ ਗੁਆ ਮਿਆ

ਪ੍ਰੌਮਪਟ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰਦੇ ਸਮੇਂ, ਹਮੇಶਾ **ਸੇਵ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਪਹਿਲਾਂ ਕਿ **ਰਨ ਕਰਨ 'ਤੇ ਵਾਪਸ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="quick-tips"></a>
## ਤੁਰੰਤ ਸਲਾਹ

- [**ਅਨੁਵਾਦ**](#translate) ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਤਾਂ ਜੋ ਤੁਹਾਡੀ ਸੈਟਅਪ ਕੰਮ ਕਰਦੀ ਹੈ, ਅਗੇ [**ਰੀਲਾਈਟ**](#rewrite) ਜਾਂ [**ਟ੍ਰਾਂਸਫਾਰਮ**](#transform) 'ਤੇ ਜਾਣ ਤੋਂ ਪਹਿਲਾਂ।
- ਰੋਜ਼ਾਨਾ ਵਰਗੀਆਂ ਸ਼ਬਦ ਸੁਧਾਰਨ ਲਈ [**ਰੀਲਾਈਟ**](#rewrite) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜਦੋਂ ਤੁਹਾਨੂੰ ਕਿਸੇ ਖਾਸ ਕੰਮ ਲਈ ਦੁਹਰਾਉਣਯੋਗ ਵਰਕਫਲੋ ਦੀ ਲੋੜ ਹੋਵੇ ਤਾਂ [**ਟ੍ਰਾਂਸਫਾਰਮ**](#transform) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- [**ਡੈਸ਼ਬੋਰਡ**](#dashboard) ਦੀ ਵਰਤੋਂ ਕਰੋ ਜੇਕਰ ਤੁਸੀਂ ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ 'ਤੇ ਨਜ਼ਰ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ।
- ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੌਮਪਟ ਲਾਇਬ੍ਰੇਰੀ ਬਣਾਉਂਦੇ ਹੋ ਜੋ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਨਿਯਮਤ ਰੂਪ ਨਾਲ ਪ੍ਰੌਮਪਟ ਐਕਸਪੋਰਟ ਕਰੋ (ikki [ਟ੍ਰਾਂਸਫਾਰਮ ਪ੍ਰੌਮਪਟ](#transform-prompts) ਦੇਖੋ)।
