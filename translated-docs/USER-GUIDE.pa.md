# ਵਰਤੋਂਕਾਰ ਗਾਈਡ

<br/>

<a id="introduction"></a>
## ਪਰਿਚਈ

ਟਰਾਂਸਰੀਵਰਟ ਤੁਹਾਡੇ ਨਾਲ ਟੈਕਸਟ ਨਾਲ ਕੰਮ ਕਰਨ ਵਿੱਚ ਤਿੰਨ ਮੁੱਖ ਤਰੀਕਿਆਂ ਨਾਲ ਮਦਦ ਕਰਦਾ ਹੈ:

- **ਅਨੁਵਾਦ** - ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਟੈਕਸਟ ਨੂੰ ਬਦਲਣਾ।
- **ਮੁੜ ਲਿਖੋ** - ਟੈਕਸਟ ਨੂੰ ਵੱਖਰੀ ਸ਼ੈਲੀ ਵਿੱਚ ਮੁੜ ਲਿਖਣਾ, ਜਿਵੇਂ ਕਿ ਸਪਸ਼ਟ, ਛੋਟਾ, ਜਾਂ ਹੋਰ ਔਪਚਾਰਿਕ।
- **ਬਦਲੋ** - ਪ੍ਰਾਪਤੀਆਂ ਨਾਮਕ ਕਸਟਮ ਏਆਈ ਨਿਰਦੇਸ਼ਾਂ ਨਾਲ ਟੈਕਸਟ ਦੀ ਪ੍ਰਕਿਰਿਆ ਕਰਨਾ।

<br/>

ਇਹ ਗਾਈਡ ਸੰਸਥਾਪਨ ਤੋਂ ਬਾਅਦ ਅਤੇ ਚੱਲ ਰਹੇ ਐਪ ਦੀ ਵਰਤੋਂ ਕਿਵੇਂ ਕਰਨੀ ਹੈ, ਬਾਰੇ ਦੱਸਦੀ ਹੈ। ਸੰਸਥਾਪਨ ਕਦਮਾਂ ਲਈ, ਮੁੱਖ **[README](README.pa.md)** ਵੇਖੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਟਰਾਂਸਰੀਵਰਟ ਵਿੰਡੋਜ਼ ਅਤੇ ਲੀਨਕਸ ਲਈ ਡੈਸਕਟਾਪ ਐਪ ਦੇ ਤੌਰ ਤੇ ਉਪਲਬਧ ਹੈ, ਅਤੇ ਡੇਜ਼ੀ-ਹੋਸਟੇਡ ਵੈੱਬ ਐਪ ਦੇ ਤੌਰ ਤੇ ਵੀ। ਇਹ ਗਾਈਡ ਐਪ ਦੀ ਰੋਜ਼ਾਨਾ ਵਰਤੋਂ ਉੱਤੇ ਧਿਆਨ ਕੇਂਦਰਿਤ ਕਰਦੀ ਹੈ। ਜਿੱਥੇ ਕੁਝ ਸਿਰਫ਼ ਇੱਕ ਸੰਸਕਰਣ ਤੱਕ ਲਾਗੂ ਹੁੰਦਾ ਹੈ, ਉੱਥੇ ਇਸਨੂੰ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਚਿਹਨਿਤ ਕੀਤਾ ਗਿਆ ਹੈ।

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

Transrewrt ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ, ਤੁਹਾਨੂੰ ਘੱਟੋ ਘੱਟ ਇੱਕ AI ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚ ਦੀ ਲੋੜ ਹੈ। ਸਮਰਥਿਤ ਪ੍ਰਦਾਤਾ ਹਨ: [OpenRouter](https://openrouter.ai) (ਜੋ ਕਿ ਕਈ ਮਾਡਲਾਂ ਨੂੰ ਇੱਕਜੁੱਟ ਕਰਦਾ ਹੈ), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਲਈ [Ollama](https://ollama.com)।

ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਭੁਗਤਾਨਯੋਗ ਮਾਡਲ ਚੁਣਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਆਪਣੀ OpenRouter API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਐਪ ਸਵਚਾਲਤ ਤੌਰ 'ਤੇ ਇੱਕ ਅੰਦਰੂਨੀ **ਮੁਫ਼ਤ** OpenRouter ਵਿਕਲਪ ਸਮਰ੍ਹਿਤ ਕਰ ਦਿੰਦਾ ਹੈ। ਇਸ ਨਾਲ ਤੁਸੀਂ ਤੁਰੰਤ ਪਾਠ ਅਨੁਵਾਦ, ਪੁਨਰ-ਲੇਖਣ ਅਤੇ ਤਬਦੀਲੀ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ। ਮੁਫ਼ਤ API ਕੁੰਜੀ, Cerebras, Google, Groq, ਜਾਂ Mistral AI ਤੋਂ ਹਾਸਲ ਕਰਨ ਦਾ ਇੱਕ ਵਿਕਲਪ ਵੀ ਉਪਲਬਧ ਹੈ।

ਸਧਾਰਣ ਭਾਸ਼ਾ ਵਿੱਚ:

- ਇੱਕ **ਮਾਡਲ** AI ਇੰਜਣ ਹੈ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ। ਮਾਡਲਾਂ ਨੂੰ **ਪ੍ਰਦਾਤਾ ਉਪਸਰਗ** (ਉਦਾਹਰਣ ਲਈ `openrouter/…`, `openai/…`, `ollama/…`) ਨਾਲ ਸੂਚੀਬੱਧ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।
- ਇੱਕ **API ਕੁੰਜੀ** (ਜਾਂ, Ollama ਲਈ, ਇੱਕ **ਬੇਸ URL**) ਐਪ ਦੁਆਰਾ ਉਸ ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚਣ ਦਾ ਤਰੀਕਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਲਈ [**Settings** > **API Config**](#api-config) ਵਿੱਚ ਕੁੰਜੀਆਂ ਸ਼ਾਮਲ ਕਰੋ। ਕੇਵਲ OpenRouter ਦੀ ਵਰਤੋਂ ਲਈ, ਹੇਠਾਂ ਦਿੱਤੇ ਅਨੁਸਾਰ [ਕਿਵੇਂ ਇੱਕ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰੇ](#how-to-get-an-api-key-desktop-app) ਵੇਖੋ। ਜੇਕਰ ਤੁਸੀਂ API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਤੁਸੀਂ Ollama (from [ollama.com](https://ollama.com)) ਸਥਾਪਤ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ ਸਥਾਨਕ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ, ਜਿਵੇਂ ਕਿ `translategemma:4b`।

ਜੇਕਰ ਤੁਸੀਂ **ਵੈਬ ਵਰਜਨ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਸਰਵਰ ਮਾਲਕ ਨੇ ਵਾਤਾਵਰਣ ਚਲਨ ਦੁਆਰਾ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਕੰਫੀਗਰ ਕੀਤਾ ਹੁੰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਐਪਲੀਕੇਸ਼ਨ ਵਿੱਚ ਸਿੱਧੇ ਤੌਰ 'ਤੇ API ਕੁੰਜੀਆਂ ਦਰਜ ਨਹੀਂ ਕਰ ਸਕਦੇ ਹੋ।

<a id="how-to-get-an-api-key-desktop-app"></a>
### ਮੁਫ਼ਤ OpenRouter API ਕੁੰਜੀ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰਨੀ ਹੈ (ਡੈਸਕਟਾਪ ਐਪ)

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਇਹਨਾਂ ਕਦਮਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ:

1. ਆਪਣੇ ਵੈੱਬ ਬਰਾਊਜ਼ਰ ਵਿੱਚ [OpenRouter](https://openrouter.ai) ‘ਤੇ ਜਾਓ।
2. ਇੱਕ ਖਾਤਾ ਬਣਾਓ ਜਾਂ ਲਾਗਇਨ ਕਰੋ।
3. [Keys](https://openrouter.ai/keys) ਸਫ਼ੇ ਨੂੰ ਖੋਲ੍ਹੋ।
4. ਇੱਕ ਨਵੀਂ API ਕੁੰਜੀ ਬਣਾਉਣ ਲਈ ਬਟਨ ‘ਤੇ ਕਲਿੱਕ ਕਰੋ।
5. ਕੁੰਜੀ ਨੂੰ ਇੱਕ ਨਾਮ ਦਿਓ ਤਾਂ ਜੋ ਕਿਬਰ ਤੁਸੀਂ ਇਸਨੂੰ ਬਾਅਦ ਵਿੱਚ ਪਛਾਣ ਸਕੋ।
6. ਨਵੀਂ API ਕੁੰਜੀ ਨੂੰ ਕਾਪੀ ਕਰੋ।
7. Transrewrt ਵਿੱਚ ਵਾਪਸ ਜਾਓ ਅਤੇ **Settings** > **API Config** ਖੋਲ੍ਹੋ।
8. ਕੁੰਜੀ ਨੂੰ **OpenRouter API key** (ਅਧੀਨ **Settings** > **API Config**) ਵਿੱਚ ਪੇਸਟ ਕਰੋ।
9. ਇਹ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ ਕਿ ਇਹ ਕੰਮ ਕਰਦਾ ਹੈ, **Test OpenRouter key** ਬਟਨ ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

## ਸ਼ੁਰੂਆਤ

ਜੇਕਰ ਇਹ ਤੁਹਾਡਾ Transrewrt ਦੀ ਵਰਤੋਂ ਕਰਨ ਦਾ ਪਹਿਲਾ ਸਮਾਂ ਹੈ, ਤਾਂ ਇਸ ਕ੍ਰਮ ਨੂੰ ਦੁਹਰਾਉ:

1. ਐਪ ਨੂੰ ਖੋਲ੍ਹੋ।
2. ਲੋੜ ਪੈਣ ਨਾਲ ਗਲੋਬ ਆਈਕਾਨ ਤੋਂ ਆਪਣੀ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।
3. ਜੇਕਰ ਤੁਸੀਂ **ਡੈਸਕਟਾਪ ਐਪ** 'ਤੇ ਹੋ, [**Settings** > **API Config**](#api-config) ਖੋਲ੍ਹੋ, ਘੱਟੋ-ਘੱਟ ਇੱਕ ਪ੍ਰਦਾਤਾ (ਉਦਾਹਰਣ ਲਈ OpenRouter) ਲਈ API ਕੁੰਜੀ ਸ਼ਾਮਲ ਕਰੋ, ਅਤੇ ਇਸਦੇ ਕੰਮ ਕਰਨ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ **Test** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।
4. [**Settings** > **Models**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **Selected Models** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ।
5. [**Settings** > **Languages**](#languages) ਨੂੰ ਖੋਲ੍ਹੋ ਅਤੇ ਜੇਕਰ ਤੁਸੀਂ ਆਪਣੀਆਂ ਸਭ ਤੋਂ ਵੱਧ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਭਾਸ਼ਾਵਾਂ ਨੂੰ ਪਹਿਲਾਂ ਦਿਖਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **Top languages** ਚੁਣੋ।
6. **Translate** ਵੱਲ ਜਾਓ ਅਤੇ ਇਹ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ ਇੱਕ ਸਧਾਰਣ ਅਨੁਵਾਦ ਚਲਾਓ ਕਿ ਹਰ ਚੀਜ਼ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।
7. ਇਕ ਵਾਰ ਜਦੋਂ ਇਹ ਕੰਮ ਕਰ ਜਾਵੇ, **Rewrite** ਅਤੇ ਫਿਰ **Transform** ਨੂੰ ਅਜ਼ਮਾਓ।

ਇਸ ਕ੍ਰਮ ਵਿੱਚ ਮਹੱਤਵ ਹੈ। ਇਹ ਪਹਿਲੀ ਵਰਤੋਂ ਦੀਆਂ ਸਭ ਤੋਂ ਆਮ ਸਮੱਸਿਆਵਾਂ ਨੂੰ ਰੋਕਦਾ ਹੈ: ਉਹ ਕੰਮ ਚਲਾਉਣਾ ਜਿਸ ਲਈ, ਐਪ ਕੋਲ ਕੰਮ ਕਰਨ ਵਾਲਾ API ਕਨੈਕਸ਼ਨ ਜਾਂ ਚੁਣਿਆ ਹੋਇਆ ਮਾਡਲ ਨਹੀਂ ਹੈ।

<a id="main-parts-of-the-window"></a>
## ਵਿੰਡੋ ਦੇ ਮੁੱਖ ਭਾਗ

ਐਪ ਤਿੰਨ ਮੁੱਖ ਖੇਤਰਾਂ ਵਿੱਚ ਵੰਡਿਆ ਹੋਇਆ ਹੈ:

- ਖੱਬੇ ਪਾਸੇ ਦਾ **ਸਾਈਡਬਾਰ**।
- ਉੱਪਰ ਦਾ **ਟੂਲਬਾਰ**।
- ਮੱਧ ਵਿੱਚ **ਕੰਮ ਕਰਨ ਦਾ ਖੇਤਰ**।

<br/>

<a id="sidebar"></a>
### ਸਾਈਡਬਾਰ

ਐਪ ਵਿੱਚ ਆਲੇ-ਦੁਆਲੇ ਜਾਣ ਲਈ ਸਾਈਡਬਾਰ ਦੀ ਵਰਤੋਂ ਕਰੋ। ਐਪ ਲੋਗੋ ਕੋਲ ਸਥਿਤ ਆਈਕਾਨ ਉੱਤੇ ਕਲਿੱਕ ਕਰਕੇ ਹੋਰ ਥਾਂ ਪ੍ਰਾਪਤ ਕਰਨ ਲਈ ਸਾਈਡਬਾਰ ਨੂੰ ਬੰਦ ਕਰ ਸ

### ਟੂਲਬਾਰ

ਐਪ ਵਿੱਚ ਤੁਸੀਂ ਕਿੱਥੇ ਹੋ ਇਸ ਉੱਤੇ ਨਿਰਭਰ ਕਰਦਿਆਂ ਟੂਲਬਾਰ ਥੋੜਾ ਜਿਹਾ ਬਦਲ ਜਾਂਦਾ ਹੈ।

- ਖੱਬੇ ਪਾਸੇ, ਇਹ ਮੌਜੂਦਾ ਸਫ਼ੇ ਦਾ ਨਾਮ ਦਿਖਾਉਂਦਾ ਹੈ।
- ਸੱਜੇ ਪਾਸੇ, ਇਹ **ਮਾਡਲ ਚੁਣੋ** ਅਤੇ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।

**ਮਾਡਲ ਚੁਣੋ** ਤੁਹਾਨੂੰ ਮੌਜੂਦਾ ਕੰਮ ਲਈ ਕਿਹੜਾ ਐਆਈ ਇੰਜਣ ਵਰਤਣਾ ਹੈ, ਇਹ ਚੁਣਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

  ![Model selector](../images/screenshots/pa/model-selector.png)

 ਕੁਝ ਮੁਫਤ ਮਾਡਲ ਹਮੇਸ਼ਾ ਉਪਲਬਧ ਨਹੀਂ ਹੁੰਦੇ—ਕਦੇ-ਕਦੇ ਉਹ ਆਫਲਾਈਨ ਹੁੰਦੇ ਹਨ ਜਾਂ ਵਰਤੋਂ ਦੀ ਸੀਮਾ ਹੁੰਦੀ ਹੈ। ਜੇਕਰ ਅਜਿਹਾ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਐਪ ਆਟੋਮੈਟਿਕ ਤੌਰ 'ਤੇ ਤੁਹਾਡੀ ਉਪਲਬਧ ਲਿਸਟ ਵਿੱਚੋਂ ਉਸ ਮਾਡਲ ਨੂੰ ਹਟਾ ਦੇਵੇਗਾ। ਜੋ ਮਾਡਲ ਦਿਖਾਈ ਦੇਣ ਚਾਹੀਦੇ ਹਨ, ਇਸ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ [**Settings** > **Models**](#models) ਉੱਤੇ ਜਾਓ ਅਤੇ ਆਪਣੀ ਮਾਡਲ ਸੂਚੀ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰੋ।
 ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਮਾਡਲ ਦੇ ਨਾਮ ਦੇ ਖੱਬੇ ਪਾਸੇ ਪ੍ਰੋਵਾਈਡਰ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਸਿੱਧੇ ਮਾਡਲ ਸੈਟਿੰਗਾਂ ਵੀ ਖੋਲ੍ਹ ਸਕਦੇ ਹੋ। 

<br/>

**ਗਲੋਬ ਆਈਕਾਨ + ਭਾਸ਼ਾ ਕੋਡ** ਐਪ ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ, ਜਿਵੇਂ ਮੀਨੂਆਂ ਅਤੇ ਬਟਨ, ਨੂੰ ਬਦਲਦਾ ਹੈ। ਇਹ **ਅਨੁਵਾਦ** ਵਿੱਚ ਵਰਤੀਆਂ ਗਈਆਂ ਅਨੁਵਾਦ ਭਾਸ਼ਾਵਾਂ ਨੂੰ ਨਹੀਂ ਬਦਲਦਾ ਹੈ।

  ![Interface language selector](../images/screenshots/pa/language-selector.png)

### ਇਨਪੁਟ ਅਤੇ ਆਉਟਪੁਟ ਪੈਨਲ

ਜ਼ਿਆਦਾਤਰ ਵਰਕਸਪੇਸ ਇੱਕ ਖੱਬੇ ਪਾਸੇ ਦੇ **ਇਨਪੁਟ** ਪੈਨਲ ਅਤੇ ਇੱਕ ਸੱਜੇ ਪਾਸੇ ਦੇ **ਆਉਟਪੁਟ** ਪੈਨਲ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹਨ।

ਹਰੇਕ ਪੈਨਲ ਵੀ ਦਰਸਾਉਂਦਾ ਹੈ:

| **ਇਨਪੁਟ**                                                          | **ਆਉਟਪੁਟ**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - ਅੱਖਰਾਂ ਦੀ ਗਿਣਤੀ <br/>- ਸ਼ਬਦਾਂ ਦੀ ਗਿਣਤੀ <br/>- ਪੈਰੇ ਦੀ ਗਿਣਤੀ   <br/> | - ਕੰਮ ਨੂੰ ਕਰਨ ਵਿੱਚ ਕਿੰਨਾ ਸਮਾਂ ਲੱਗਾ<br/>- **TPS** (ਹਰ ਸੈਕਿੰਡ ਵਿੱਚ ਟੋਕਨ)<br/>- ਅੱਖਰ, ਸ਼ਬਦਾਂ ਅਤੇ ਪੈਰੇ ਦੀ ਗਿਣਤੀ<br/>- ਵਰਤਿਆ ਗਿਆ ਮਾਡਲ |


ਜੇਕਰ ਤੁਸੀਂ ਤਕਨੀਕੀ ਸ਼ਬਦਾਂ ਬਾਰੇ ਸੋਚ ਰਹੇ ਹੋ:

- **ਟੋਕਨ** ਦਾ ਅਰਥ ਹੈ ਸੰਖੇਪ ਸ਼ਬਦ ਦਾ ਟੁਕੜਾ। ਤੁਸੀਂ ਇਸਨੂੰ ਇੱਕ ਸ਼ਬਦ ਦੇ ਹਿੱਸੇ ਜਾਂ ਇੱਕ ਛੋਟੇ ਸ਼ਬਦ ਵਜੋਂ ਸੋਚ ਸਕਦੇ ਹੋ।
- **TPS** ਦਾ ਅਰਥ ਇਹ ਹੈ ਕਿ ਮਾਡਲ ਨੇ ਹਰੇਕ ਸੈਕਿੰਡ ਵਿੱਚ ਉਹਨਾਂ ਸ਼ਬਦਾਂ ਦੇ ਟੁਕੜਿਆਂ ਨੂੰ ਕਿੰਨਾ ਪ੍ਰੋਸੈੱਸ ਕੀਤਾ।

<br/>

ਤੁਸੀਂ ਹਰੇਕ ਕਾਰਵਾਈ (ਜੇ ਉਪਲੱਬਧ ਹੋਵੇ) ਅਤੇ ਕੁੱਲ ਲਾਗਤ ਦੀ ਵੀ ਨਿਗਰਾਨੀ ਕਰ ਸਕਦੇ ਹੋ, ਇਸ ਵਿਕਲਪ ਨੂੰ ਚਾਲੂ ਕਰਨਾ "ਕਾਰਵਾਈਆਂ ਉੱਤੇ ਲਾਗਤ ਦੀ ਜਾਣਕਾਰੀ ਦਿਖਾਓ" [**Settings** > **General settings**](#general-settings) 'ਤੇ।

## ਅਨੁਵਾਦ

ਤੁਸੀਂ ਜਦੋਂ ਇੱਕ ਭਾਸ਼ਾ ਤੋਂ ਦੂਜੀ ਭਾਸ਼ਾ ਵਿੱਚ ਪਾਠ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ **ਅਨੁਵਾਦ** ਵਰਤੋ।

![Translate workspace](../images/screenshots/pa/translate.png)

<br/>

<a id="translate-text"></a>
### ਟੈਕਸਟ ਦਾ ਅਨੁਵਾਦ ਕਰੋ

1. **ਅਨੁਵਾਦ** ਖੋਲ੍ਹੋ।
2. **ਤੋਂ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
3. **ਨੂੰ** ਵਿੱਚ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. **ਇਨਪੁਟ** ਵਿੱਚ ਪਾਠ ਟਾਈਪ ਕਰੋ ਜਾਂ ਚਿਪਕਾਓ।

7. **ਆਉਟਪੁਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।
8. ਜੇਕਰ ਤੁਸੀਂ ਨਤੀਜਾ ਕਾਪੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਕਾਪੀ ਬਟਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।

<br/>

<a id="language-selection"></a>
### ਭਾਸ਼ਾ ਚੁਣੋ

- **ਤੋਂ** ਇੱਕ ਖਾਸ ਭਾਸ਼ਾ ਹੋ ਸਕਦੀ ਹੈ ਜਾਂ **ਭਾਸ਼ਾ ਪਛਾਣੋ**।
- **ਨੂੰ** ਭਾਸ਼ਾ ਹੈ ਜਿਸ ਵਿੱਚ ਤੁਸੀਂ ਨਤੀਜਾ ਚਾਹੁੰਦੇ ਹੋ।

ਤੁਹਾਡੀ ਚੁਣੀ **ਪਹਿਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** ਸੂਚੀ ਦੇ ਉੱਪਰ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ। ਤੁਸੀਂ ਇਹਨਾਂ ਨੂੰ [**Settings** > **Languages**](#languages) ਵਿੱਚ ਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="helpful-translation-settings"></a>
### ਲਾਭਦਾਇਕ ਅਨੁਵਾਦ ਸੈਟਿੰਗਾਂ

[**Settings** > **General Settings**](#general-settings) ਵਿੱਚ, ਤੁਸੀਂ ਅਨੁਵਾਦ ਕਵੰ ਵਰਤਾਓ ਕਰਦਾ ਹੈ, ਇਹ ਬਦਲ ਸਕਦੇ ਹੋ:

- **ਕਲਿੱਪਬੋਰਡ ਵਿੱਚ ਆਟੋ-ਕਾਪੀ ਨਤੀਜਾ** ਸਫਲਤਾਪੂਰਵਕ ਚਲਾਉਣ ਤੋਂ ਬਾਅਦ ਨਤੀਜਾ ਆਟੋਮੈਟਿਕ ਤੌਰ 'ਤੇ ਕਾਪੀ ਕਰ ਲੈਂਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਚਲਾਉਂਦਾ ਹੈ।
- **ਟਾਈਮਆਊਟ (ms)** ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ ਕਿ ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਐਪ ਕਿੰਨੀ ਦੇਰ ਉਡੀਕਦਾ ਹੈ।
- **Enter** ਕੀ ਘਟਿਤ ਹੋਵੇਗਾ ਜਦੋਂ ਤੁਸੀਂ `Enter` ਦਬਾਉਂਦੇ ਹੋ, ਇਸ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ:

<a id="rewrite"></a>
## ਮੁੜ-ਲਿਖੋ

ਜਦੋਂ ਤੁਸੀਂ ਮੁੱਖ ਅਰਥ ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ ਸ਼ਬਦਾਵਲੀ ਨੂੰ ਬਿਹਤਰ ਬਣਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ **ਮੁੜ-ਲਿਖੋ** ਵਰਤੋ।

![Rewrite workspace](../images/screenshots/pa/rewrite.png)

ਇਹ ਇਸ ਲਈ ਲਾਭਦਾਇਕ ਹੈ:

- ਅਕਾਰਾਂ ਅਤੇ ਵਿਆਕਰਣ ਠੀਕ ਕਰਨ ਲਈ
- ਪਾਠ ਨੂੰ ਹੋਰ ਸਪਸ਼ਟ ਬਣਾਉਣ ਲਈ
- ਪਾਠ ਨੂੰ ਹੋਰ ਔਪਚਾਰਿਕ ਜਾਂ ਗੈਰ-ਔਪਚਾਰਿਕ ਬਣਾਉਣ ਲਈ
- ਪਾਠ ਨੂੰ ਛੋਟਾ ਜਾਂ ਲੰਮਾ ਕਰਨ ਲਈ
- ਪਾਠ ਨੂੰ ਹੋਰ ਤਕਨੀਕੀ ਲੱਗਣ ਦੇਣ ਲਈ

<br/>

> 💡 **ਟਿਪ**<br/>
> ਜਦੋਂ ਤੁਸੀਂ "**ਸਪੈਲਿੰਗ ਅਤੇ ਗਰਾਮਰ ਦੀ ਜਾਂਚ ਕਰੋ**" ਮੋਡ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਤਾਂ ਆਉਟਪੁਟ ਪੈਨਲ ਵਿੱਚ `ਸ਼ੋ ਚੇਂਜ` ਬਟਨ ਪ੍ਰਗਟ ਹੁੰਦਾ ਹੈ।
> ਸੁਧਾਰਾਂ ਦੀ ਵਿਖਾਇਸ਼ ਨੂੰ ਟੌਗਲ ਕਰਨ ਲਈ ਇਸ ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ, ਤੁਹਾਡੇ ਪਾਠ ਵਿੱਚ ਕੀਤੀਆਂ ਗਈਆਂ ਖਾਸ ਤਬਦੀਲੀਆਂ ਨੂੰ ਦਿਖਾਉਣ ਜਾਂ ਓਹਲੇ ਕਰਨ ਲਈ।

ਜਦੋਂ ਕਿ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ AI ਨਿਰਦੇਸ਼ਾਂ ਦੇ ਕਸਟਮ ਸੈੱਟ ਦੀ ਪਾਲਣਾ ਕਰੇ, ਤਾਂ **ਰੂਪਾਂਤਰਨ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਰੂਪਾਂਤਰਨ ਵਰਕਸਪੇਸ](../images/screenshots/pa/transform.png)

ਇਹ ਐਪ ਦਾ ਸਭ ਤੋਂ ਲਚਕਦਾਰ ਹਿੱਸਾ ਹੈ। ਤੁਸੀਂ ਇਸਨੂੰ ਹੇਠ ਲਿਖੇ ਕੰਮਾਂ ਲਈ ਵਰਤ ਸਕਦੇ ਹੋ:

- ਨੋਟਸ ਦਾ ਸਾਰਾਂਸ਼ ਕੱਢਣਾ
- ਕੱਚੇ ਟੈਕਸਟ ਨੂੰ ਸਜੀਆਂ ਈਮੇਲ ਵਿੱਚ ਪਰਿਵਰਤਿਤ ਕਰਨਾ
- ਮੁੱਖ ਬਿੰਦੂਆਂ ਨੂੰ ਕੱਢਣਾ
- ਟੈਕਸਟ ਨੂੰ ਇੱਕ ਖਾਸ ਫਾਰਮੈਟ ਵਿੱਚ ਪਰਿਵਰਤਿਤ ਕਰਨਾ
- ਇਨਪੁੱਟ ਟੈਕਸਟ ਨਾਲ ਕੋਈ ਹੋਰ ਕਸਟਮ ਗਤੀਵਿਧੀ

<br/>

<a id="run-an-existing-prompt"></a>
### ਮੌਜੂਦਾ ਪ੍ਰੌਪਟ ਰੱਨ ਕਰੋ

1. **ਰੂਪਾਂਤਰਨ** ਖੋਲ੍ਹੋ।
2. ਪ੍ਰੌਪਟ ਲਿਸਟ ਵਿੱਚੋਂ ਇੱਕ ਪ੍ਰੌਪਟ ਚੁਣੋ।
3. ਜੇ ਇੱਕ **ਟਾਰਗੇਟ** ਭਾਸ਼ਾ ਬਾਕਸ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ, ਤਾਂ ਜੇ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਇੱਕ ਭਾਸ਼ਾ ਚੁਣੋ।
4. **ਇਨਪੁੱਟ** ਵਿੱਚ ਟਾਈਪ ਕਰੋ ਜਾਂ ਟੈਕਸਟ ਪੇਸਟ ਕਰੋ।
5. **ਰੂਪਾਂਤਰਨ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
6. **ਆਉਟਪੁੱਟ** ਵਿੱਚ ਨਤੀਜਾ ਪੜ੍ਹੋ।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### ਜੇ ਤੁਹਾਡੇ ਕੋਲ ਇਹ ਤੱਕ ਕੋਈ ਪ੍ਰੌਪਟ ਨਹੀਂ ਹਨ

ਜੇ ਤੁਹਾਡੀ ਪ੍ਰੌਪਟ ਲਿਸਟ ਖਾਲੀ ਹੈ, ਤਾਂ **ਨਮੂਨੇ ਪ੍ਰੌਪਟ ਲੋਡ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਇਸ ਨਾਲ ਅੰਦਰੂਨੀ ਉਦਾਹਰਣਾਂ ਸ਼ਾਮਲ ਕੀਤੀਆਂ ਜਾਣਗੀਆਂ ਤਾਂ ਜੋ ਤੁਸੀਂ ਤੁਰੰਤ ਸ਼ੁਰੂ ਕਰ ਸਕੋ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਨਮੂਨੇ ਪ੍ਰੌਪਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਮੁਹੱਈਆ ਕਰਵਾਏ ਜਾਂਦੇ ਹਨ। ਉਹਨਾਂ ਨੂੰ ਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੌਪਟ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ **ਪ੍ਰੌਪਟ ਨੂੰ ਅਨੁਵਾਦ ਕਰੋ** ਦੀ ਵਰਤੋਂ ਉਸਨੂੰ ਆਪਣੀ ਭਾਸ਼ਾ ਵਿੱਚ ਅਨੁਵਾਦਿਤ ਕਰਨ ਲਈ ਕਰ ਸਕਦੇ ਹੋ।

<br/>

<a id="create-a-prompt-quickly"></a>
### ਤੇਜ਼ੀ ਨਾਲ ਇੱਕ ਪ੍ਰੌਪਟ ਬਣਾਓ

ਇੱਕ ਪ੍ਰੌਪਟ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਤਰੀਕਾ ਇਹ ਹੈ:

1. **ਨਵਾਂ ਪ੍ਰੌਪਟ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
2. **ਪ੍ਰੌਪਟ ਬਣਾਓ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਦੱਸੋ ਕਿ ਤੁਸੀਂ ਪ੍ਰੌਪਟ ਨਾਲ ਕੀ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।
4. ਇੱਕ ਮਾਡਲ ਚੁਣੋ।
5. ਐਪ ਨੂੰ ਤੁਹਾਡੇ ਲਈ ਡਰਾਫਟ ਬਣਾਉਣ ਦਿਓ।
6. ਡਰਾਫਟ ਦੀ ਜਾਂਚ ਕਰੋ ਅਤੇ **ਸੰਭਾਲੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

![ਪ੍ਰੌਪਟ ਬਣਾਓ](../images/screenshots/pa/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### ਇੱਕ ਪ੍ਰੌਪਟ ਸੰਪਾਦਿਤ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੌਪਟ ਬਣਾਉਂਦੇ ਜਾਂ ਸੰਪਾਦਿਤ ਕਰਦੇ ਹੋ, ਤਾਂ ਸੰਪਾਦਕ ਖੱਬੇ ਪਾਸੇ ਪ੍ਰਗਟ ਹੁੰਦਾ ਹੈ ਅਤੇ ਟੈਸਟ ਏਰੀਆ ਸੱਜੇ ਪਾਸੇ ਪ੍ਰਗਟ ਹੁੰਦਾ ਹੈ।

![ਰੂਪਾਂਤਰਨ ਪ੍ਰੌਪਟ ਸੰਪਾਦਕ](../images/screenshots/pa/transform-prompt-edit.png)

ਮੁੱਖ ਫੀਲਡਸ ਹਨ:

- **ਪ੍ਰੌਪਟ ਨਾਮ**: ਪ੍ਰੌਪਟ ਲਿਸਟ ਵਿੱਚ ਦਿਖਾਈ ਦੇਣ ਵਾਲਾ ਨਾਮ।
- **ਪ੍ਰੌਪਟ ਨਿਰਦੇਸ਼ (ਵੈਕਲਪਿਕ)**: ਜਦੋਂ ਪ੍ਰੌਪਟ ਰੱਨ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਵਰਤੋਂਕਾਰ ਨੂੰ ਦਿਖਾਈ ਦੇਣ ਵਾਲੀ ਛੋਟੀ ਸੂਚਨਾ।
- **ਮਾਡਲ ਭੂਮਿਕਾ**: AI ਨੂੰ ਸੌਂਪੀ ਵੱਡੀ ਭੂਮਿਕਾ, ਜਿਵੇਂ 'ਤੁਸੀਂ ਇੱਕ ਮਦਦਗਾਰ ਸਹਾਇਕ ਹੋ।'
- **ਮਾਡਲ ਨਿਰਦੇਸ਼ (ਇੱਕ ਪ੍ਰਤੀ ਲਾਈਨ)**: ਤੁਸੀਂ ਜਿਹਨਾਂ ਖਾਸ ਨਿਯਮਾਂ ਦੀ ਪਾਲਣਾ ਕਰਨ ਚਾਹੁੰਦੇ ਹੋ।
- **ਆਉਟਪੁੱਟ ਵਰਣਨ**: ਨਤੀਜੇ ਲਈ ਇੱਕ ਛੋਟਾ ਸ਼ਬਦ, ਜਿਵੇਂ 'ਸਾਰਾਂਸ਼' ਜਾਂ 'ਮੁੜ ਲਿਖੋ'।
- **ਤਾਪਮਾਨ (0.0 → 1.0)**: ਮਾਡਲ ਕਿਵੇਂ ਵਿਹਾਰ ਕਰੇਗਾ; ਹੇਠਾਂ ਦੇਖੋ।
- **ਜਦੋਂ ਪ੍ਰੌਪਟ ਰੱਨ ਕੀਤਾ ਜਾਵੇ ਤਾਂ ਟਾਰਗੇਟ ਭਾਸ਼ਾ ਲਈ ਪੁੱਛੋ**: ਪ੍ਰੌਪਟ ਨੂੰ ਰੱਨ ਕਰਨ ਸਮੇਂ ਟਾਰਗੇਟ ਭਾਸ਼ਾ ਸੈਲੈਕਟਰ ਸ਼ਾਮਲ ਕਰੇਗਾ।

ਜੇਕਰ ਤੁਹਾਡੇ ਲਈ ਤਕਨੀਕੀ ਸ਼ਬਦ **ਤਾਪਮਾਨ** ਨਵਾਂ ਹੈ, ਇਸ ਬਾਰੇ ਇਸ ਤਰ੍ਹਾਂ ਸੋਚੋ:

- **ਘੱਟ** ਤਾਪਮਾਨ ਵਧੇਰੇ ਸਥਿਰ, ਭਵਿੱਖਬਾਣੀਯੋਗ ਨਤੀਜੇ ਦਿੰਦਾ ਹੈ।
- **ਵੱਧ** ਤਾਪਮਾਨ ਵੱਧ ਕਿਸਮਤ ਅਤੇ ਰਚਨਾਤਮਕਤਾ ਦਿੰਦਾ ਹੈ।

ਤੁਸੀਂ ਵੀ ਵਰਤ ਸਕਦੇ ਹੋ:

- **`ਪ੍ਰੌਪਟ ਬਣਾਓ`** ਇੱਕ ਸਧਾਰਨ ਵਰਣਨ ਤੋਂ ਨਵਾਂ ਡਰਾਫਟ ਬਣਾਉਣ ਲਈ
- **`ਪ੍ਰੌਪਟ ਸੁਧਾਰੋ`** ਇੱਕ ਮੌਜੂਦਾ ਪ੍ਰੌਪਟ ਨੂੰ ਸੁਧਾਰਨ ਲਈ
- **`ਪ੍ਰੌਪਟ ਨੂੰ ਅਨੁਵਾਦ ਕਰੋ`** ਪ੍ਰੌਪਟ ਫੀਲਡ ਨੂੰ ਅਨੁਵਾਦਿਤ ਕਰਨ ਲਈ

<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> **`ਬੈਕ ਟੂ ਰੱਨ`** 'ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **`ਸੰਭਾਲੋ`** 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਜੇਕਰ ਤੁਸੀਂ ਬਿਨਾਂ ਸੰਭਾਲੇ ਵਾਪਸ ਜਾਂਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਡੀਆਂ ਤਬਦੀਲੀਆਂ ਖਤਮ ਹੋ ਜਾਣਗੀਆਂ।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ਇਸਦੀ ਵਰਤੋਂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਪ੍ਰੌਪਟ ਦਾ ਪਰੀਖਿਆ ਕਰੋ

ਸੱਜੇ ਪਾਸੇ ਟੈਸਟ ਪੈਨਲ ਤੁਹਾਨੂੰ ਆਮ ਵਰਤੋਂ ਵਿੱਚ ਲਿਆਉਣ ਤੋਂ ਪਹਿਲਾਂ ਨਮੂਨਾ ਟੈਕਸਟ ਨਾਲ ਆਪਣੇ ਪ੍ਰੌਪਟ ਨੂੰ ਕੋਸ਼ਿਸ਼ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

ਇਹ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਹੈ ਜਦੋਂ:

- ਤੁਸੀਂ ਇੱਕ ਨਵਾਂ ਪ੍ਰੌਪਟ ਬਣਾ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਦੋ ਪ੍ਰੌਪਟ ਸੰਸਕਰਣਾਂ ਨੂੰ ਤੁਲਨਾ ਕਰ ਰਹੇ ਹੋ
- ਤੁਸੀਂ ਟੋਨ, ਲੰਬਾਈ ਜਾਂ ਆਉਟਪੁੱਟ ਫਾਰਮੈਟ ਦੀ ਜਾਂਚ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਤੁਸੀਂ [**ਸੈਟਿੰਗਾਂ** > **ਰੂਪਾਂਤਰਨ ਪ੍ਰੌਪਟ**](#transform-prompts) ਵਿੱਚ ਸੰਭਾਲੇ ਪ੍ਰੌਪਟ ਨੂੰ ਨਿਰਯਾਤ ਅਤੇ ਆਯਾਤ ਕਰ ਸਕਦੇ ਹੋ।

![ਡੈਸ਼ਬੋਰਡ ਸਾਰਾਂਸ਼](../images/screenshots/pa/dashboard-summary.png)

> ਜੇਕਰ ਤੁਸੀਂ ਕੇਵਲ ਮੁਫਤ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਤਾਂ ਲਾਗਤ ਨਾਲ ਸਬੰਧਤ ਚਾਰਟས ਖਾਲੀ ਹੋਣਗੇ।

<a id="filter-the-data"></a>
### ਅੰਕੜਿਆਂ ਨੂੰ ਫਿਲਟਰ ਕਰੋ

ਸਮੇਂ ਦੀ ਸੀਮਾ ਬਦਲਣ ਲਈ ਉੱਪਰ ਫਿਲਟਰ ਬਟਨਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਡੈਸ਼ਬੋਰਡ ਫਿਲਟਰ](../images/screenshots/pa/dashboard-filter.png)

<br/>

> ℹ️ **ਨੋਟ**<br/>
> **ਯੂਜ਼ਰ** ਫਿਲਟਰ ਵੈੱਬ ਸੰਸਕਰਣ ਵਿੱਚ ਕੇਵਲ ਪ੍ਰਸ਼ਾਸਕਾਂ ਲਈ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ। ਆਮ ਵਰਤੋਂਕਾਰ ਨੂੰ ਇਹ ਫਿਲਟਰ ਨਹੀਂ ਦਿਖੇਗਾ, ਅਤੇ ਇਹ ਡੈਸਕਟਾਪ ਐਪ ਵਿੱਚ ਉਪਲਬਧ ਨਹੀਂ ਹੈ।

<a id="dashboard-tabs"></a>

### ਡੈਸ਼ਬੋਰਡ ਟੈਬ

- **ਸਾਰਾਂਸ਼** ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ ਬਾਰੇ ਤੁਹਾਡੇ ਕੋਲ ਇੱਕ ਜਾਣ-ਪਛਾਣ ਹੁੰਦੀ ਹੈ।
- **ਵਰਤੋਂ ਅਨੁਸਾਰ** ਗਤੀਵਿਧੀ ਨੂੰ ਅਨੁਵਾਦ ਭਾਸ਼ਾ, ਰੀਆਈਰਾਈਟ ਮੋਡ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਪ੍ਰਾਮਿਟ ਅਨੁਸਾਰ ਤੋੜਦਾ ਹੈ।
- **ਮਾਡਲ ਅਨੁਸਾਰ** ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਕਿਹੜੇ ਮਾਡਲ ਵਰਤੇ ਹਨ ਅਤੇ ਉਹਨਾਂ ਦੀ ਲਾਗਤ ਕੀ ਹੈ।
- **ਦਿਨ ਅਨੁਸਾਰ** ਰੋਜ਼ਾਨਾ ਕੁੱਲ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ।
- **ਸਾਰੀਆਂ ਕਾਲਾਂ** ਪੂਰੀ ਕਾਲ ਇਤਿਹਾਸ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ ਅਤੇ ਉਸ ਨੂੰ ਨਿਰਯਾਤ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

<a id="export-data"></a>
### ਡੇਟਾ ਨੂੰ ਨਿਰਯਾਤ ਕਰੋ

ਡੈਸ਼ਬੋਰਡ ਟੇਬਲਾਂ ਡੇਟਾ ਨੂੰ ਨਿਰਯਾਤ ਕਰ ਸਕਦੀਆਂ ਹਨ:

- **ਜੇਸੋਨ (JSON)**
- **ਸੀਐਸਵੀ (CSV)**
- **ਐਕਸਐਲਐਸਐਕਸ (XLSX)**

ਇਹ ਤੁਸੀਂ ਐਪ ਤੋਂ ਬਾਹਰ ਗਤੀਵਿਧੀ ਦੀ ਸਮੀਖਿਆ ਕਰਨ ਜਾਂ ਰਿਪੋਰਟ ਸਾਂਝੀ ਕਰਨ ਦੀ ਇੱਛਾ ਰੱਖਣ ਸਮੇਂ ਵਰਤੋਂ ਵਿੱਚ ਆਉਂਦਾ ਹੈ।

<br/>

<a id="delete-stored-records-for-a-model"></a>
### ਮਾਡਲ ਲਈ ਸਟੋਰ ਕੀਤੇ ਗਏ ਰਿਕਾਰਡ ਨੂੰ ਮਿਟਾਓ

**ਮਾਡਲ ਅਨੁਸਾਰ** ਜਾਂ **ਸਾਰੀਆਂ ਕਾਲਾਂ** ਵਿੱਚ, ਤੁਸੀਂ "ਕੂੜਾ ਦੀ ਡੱਬੀ" ਆਈਕਾਨ ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਮਾਡਲ ਲਈ ਸਟੋਰ ਕੀਤੇ ਗਏ ਰਿਕਾਰਡਾਂ ਨੂੰ ਹਟਾ ਸਕਦੇ ਹੋ।

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਸਟੋਰ ਕੀਤੇ ਰਿਕਾਰਡਾਂ ਨੂੰ ਮਿਟਾਉਣਾ ਵਾਪਸ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਸਿਰਫ਼ ਤਦ ਹੀ ਇਸ ਦੀ ਵਰਤੋਂ ਕਰੋ ਜੇਕਰ ਤੁਹਾਨੂੰ ਯਕੀਨ ਹੋਵੇ ਕਿ ਤੁਹਾਨੂੰ ਉਸ ਇਤਿਹਾਸ ਦੀ ਹੋਰ ਲੋੜ ਨਹੀਂ ਹੈ।

ਸਾਰੇ ਡੇਟਾ ਨੂੰ ਮਿਟਾਉਣ ਜਾਂ ਉਮਰ ਅਨੁਸਾਰ ਰਿਕਾਰਡਾਂ ਨੂੰ ਹਟਾਉਣ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਤੇ ਜਾਓ। ਉੱਥੇ ਤੁਸੀਂ ਸਟੋਰ ਕੀਤੇ ਸਾਰੇ ਡੇਟਾ ਜਾਂ ਸਿਰਫ਼ ਕਿਸੇ ਨਿਸ਼ਚਿਤ ਮਿਤੀ ਤੋਂ ਪਹਿਲਾਂ ਦੇ ਡੇਟਾ ਨੂੰ ਹਟਾਉਣ ਦੇ ਵਿਕਲਪ ਪ੍ਰਾਪਤ ਕਰੋਗੇ।

<a id="general-settings"></a>
### ਜਨਰਲ ਸੈਟਿੰਗਸ

ਟਾਈਪਿੰਗ ਦੇ ਵਤੀਰੇ, **ਇਤਿਹਾਸ** ਲਈ ਕਾਰਵਾਈ ਦੇ ਵੇਰਵੇ ਨੂੰ ਸਟੋਰ ਕਰਨਾ, ਅਤੇ ਦਿੱਖ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਨ ਲਈ **ਜਨਰਲ ਸੈਟਿੰਗਸ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਵਤੀਰਾ**

- **ENTER ਲਈ ਵਤੀਰਾ** ਚੁਣਦਾ ਹੈ ਕਿ `ਐਂਟਰ` ਕਾਰਜ ਨੂੰ ਚਲਾਉਂਦਾ ਹੈ ਜਾਂ ਨਵੀਂ ਲਾਈਨ ਨੂੰ ਦਰਜ ਕਰਦਾ ਹੈ।
- **ਪੇਸਟ ਕਰਨ ਉੱਤੇ ਆਟੋ-ਅਨੁਵਾਦ** ਵੇਖੋ ਜਦੋਂ ਤੁਸੀਂ ਸਿੱਧਾ ਪਾਠ ਪੇਸਟ ਕਰਦੇ ਹੋ, ਤਾਂ ਅਨੁਵਾਦ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ।
- **ਨਤੀਜੇ ਨੂੰ ਕਲਿੱਪਬੋਰਡ ਵਿੱਚ ਆਟੋ-ਕਾਪੀ** ਸਫਲ ਨਤੀਜਿਆਂ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪਿੰਗ ਦੌਰਾਨ)** ਤੁਸੀਂ ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ।
- **ਸਮਾਂ-ਸੀਮਾ (ms)** ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ ਲਈ ਉਡੀਕ ਸਮਾਂ ਨਿਰਧਾਰਿਤ ਕਰਦਾ ਹੈ।

**ਇਤਿਹਾਸ**

- **ਕਾਰਜ ਇਤਿਹਾਸ ਰੱਖੋ** ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ ਕਿ ਹਰੇਕ ਅਨੁਵਾਦ, ਰੀਆਈਰਾਈਟ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਸਾਇਡਬਾਰ [**ਇਤਿਹਾਸ**](#history) ਵਿਊ ਲਈ **ਇਨਪੁੱਟ ਅਤੇ ਆਉਟਪੁੱਟ ਪਾਠ** ਨੂੰ ਸਟੋਰ ਕਰਦਾ ਹੈ। ਇਸਨੂੰ ਬੰਦ ਕਰਨ ਨਾਲ ਪੁਸ਼ਟੀ ਦੀ ਮੰਗ ਕੀਤੀ ਜਾਵੇਗੀ; ਜੇਕਰ ਤੁਸੀਂ ਪੁਸ਼ਟੀ ਕਰਦੇ ਹੋ, ਤਾਂ ਸਟੋਰ ਕੀਤਾ ਗਿਆ ਇਤਿਹਾਸ ਪਾਠ ਡਿਸਕ ਤੋਂ ਹਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।
- **ਇਤਿਹਾਸ ਡੇਟਾ ਨੂੰ ਹਟਾਓ** ਤੁਹਾਨੂੰ **ਡੇਟਾ ਹਟਾਓ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਉਮਰ (ਉਦਾਹਰਣ ਲਈ ਕੁਝ ਮਹੀਨਿਆਂ ਤੋਂ ਪੁਰਾਣਾ, ਜਾਂ **ਸਾਰਾ ਡੇਟਾ (ਸਾਫ਼)**) ਅਨੁਸਾਰ ਸਟੋਰ ਕੀਤਾ ਪਾਠ ਹਟਾਉਣ ਦੇਣਦਾ ਹੈ। ਇਹ ਸਿਰਫ਼ **ਇਤਿਹਾਸ** ਵਿਊ ਲਈ ਸੇਵ ਕੀਤੇ ਗਏ ਕਾਰਜ ਪਾਠ ਨੂੰ ਪ੍ਰਭਾਵਿਤ ਕਰਦਾ ਹੈ; ਇਹ ਲਾਗਤ ਜਾਂ ਵਰਤੋਂ ਕੁੱਲ ਨੂੰ **ਨਹੀਂ** ਮਿਟਾਉਂਦਾ। **ਲਾਗਤ** ਡੇਟਾ ਨੂੰ ਹਟਾਉਣ ਜਾਂ ਕੱਟਣ ਲਈ, [**ਸੈਟਿੰਗਸ** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਦਿੱਖ**

- **ਕਾਰਵਾਈਆਂ 'ਤੇ ਲਾਗਤ ਜਾਣਕਾਰੀ ਵੇਖੋ** ਕਾਰਜ ਪ੍ਰਤੀ ਲਾਗਤ (ਜੇਕਰ ਉਪਲਬਧ ਹੋਵੇ) ਅਤੇ ਅਨੁਵਾਦ, ਰੀਆਈਰਾਈਟ, ਅਤੇ ਟਰਾਂਸਫਾਰਮ ਆਉਟਪੁੱਟ ਪੈਨਲਾਂ 'ਤੇ ਕੁੱਲ ਲਾਗਤ ਦੀ ਵੇਖੋ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।
- **ਲਾਗਤ ਭਿੰਨ ਅੰਕ** ਦਸ਼ਮਲਵ ਦੀ ਲਾਗਤ ਕਿਵੇਂ ਵੇਖਾਈ ਦਿੰਦੀ ਹੈ ਉਸ ਨੂੰ ਬਦਲਦਾ ਹੈ।
- **ਸਿਰਫ਼ ਵੈੱਬ:** **ਐਪ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਮਾਰਜਿਨ ਵੇਖੋ** ਇੰਟਰਫੇਸ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਵਾਧੂ ਥਾਂ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਫੌਂਟ ਫੈਮਲੀ** ਟੈਕਸਟ ਪੈਨਲਾਂ ਵਿੱਚ ਲਿਖਣ ਦਾ ਫੌਂਟ ਬਦਲਦਾ ਹੈ।
- **ਆਕਾਰ** ਫੌਂਟ ਆਕਾਰ ਨੂੰ ਬਦਲਦਾ ਹੈ।

<a id="models"></a>

### ਮਾਡਲ

ਆਪਣੇ ਟੂਲਬਾਰ ਵਿੱਚ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦੇਣਗੇ, ਇਹ ਚੁਣਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਮਾਡਲ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

![ਸੈਟਿੰਗਜ਼ ਮਾਡਲ ਟੈਬ](../images/screenshots/pa/settings-models.png)

ਇਸ ਸਫ਼ੇ ਵਿੱਚ ਦੋ ਸੂਚੀਆਂ ਹਨ:

- ਖੱਬੇ ਪਾਸੇ **ਉਪਲਬਧ ਮਾਡਲ**
- ਸੱਜੇ ਪਾਸੇ **ਚੁਣੇ ਹੋਏ ਮਾਡਲ**

ਲਾਭਦਾਇਕ ਨਿਯੰਤਰਣਾਂ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:

- ਨਾਮ ਨਾਲ ਮਾਡਲ ਲੱਭਣ ਲਈ **ਮਾਡਲਾਂ ਦੀ ਖੋਜ ਕਰੋ...**
- ਸੂਚੀ ਨੂੰ ਇੱਕ ਇੰਜਣ (OpenRouter, OpenAI, Ollama, …) ਤੱਕ ਸੀਮਿਤ ਕਰਨ ਲਈ **ਪ੍ਰਦਾਤਾ** ਚਿਪਸ
- ਸਿਰਫ਼ ਮੁਫਤ ਮਾਡਲਾਂ ਵੇਖਣ ਲਈ **ਸਿਰਫ਼ ਮੁਫਤ**
- ਸੂਚੀ ਨੂੰ ਮੁੜ ਲੋਡ ਕਰਨ ਲਈ **ਰੀਫਰੈਸ਼**
- ਜਦੋਂ ਤੁਸੀਂ ਪ੍ਰਦਾਤਾ ਅਨੁਸਾਰ ਕਿਰਿਆ ਕਰ ਰਹੇ ਹੋ ਤਾਂ **ਸਭ ਕੁਝ ਵਿਸਥਾਰੋ** ਅਤੇ **ਸਭ ਕੁਝ ਸੰਖੇਪ ਕਰੋ**

ਮਾਡਲ ਆਈਡੀ ਪ੍ਰਦਾਤਾ ਪ੍ਰਤੀਤ (ਉਦਾਹਰਣ ਲਈ `openrouter/…` ਬਨਾਮ `openai/…`) ਨੂੰ ਸ਼ਾਮਲ ਕਰਦੇ ਹਨ। ਬੈਜ ਜਿਵੇਂ **OpenAI (OpenRouter)** ਬਨਾਮ **OpenAI (ਸਿੱਧਾ)** ਦਿਖਾਉਂਦੇ ਹਨ ਕਿ ਟ੍ਰੈਫਿਕ ਨੂੰ ਕਿਵੇਂ ਮਾਰਗਦਰਸ਼ਨ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

> ℹ️ **ਨੋਟ**<br/>
> **OpenRouter ਬਾਡੀ ਬਿਲਡਰ** (`openrouter/bodybuilder`) ਇੱਕ ਰਾਊਟਰ ਮਾਡਲ ਹੈ, ਜਨਰਲ ਚੈਟ ਮਾਡਲ ਨਹੀਂ: ਇਸਦਾ ਜਵਾਬ JSON ਹੁੰਦਾ ਹੈ ਜੋ OpenRouter API ਰਿਕੁਐਸਟ ਸਰੀਰਾਂ ਬਾਰੇ ਵੇਰਵਾ ਦਿੰਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `model` ਅਤੇ `messages` ਨਾਲ `requests` ਐਰੇ)। ਜੇ ਤੁਸੀਂ ਇਸ ਦੀ ਵਰਤੋਂ **ਅਨੁਵਾਦ**, **ਮੁੜ ਲਿਖੋ**, ਜਾਂ **ਪਰਿਵਰਤਨ** ਲਈ ਕਰਦੇ ਹੋ, ਆਉਟਪੁੱਟ ਪੈਨਲ ਵਿੱਚ ਮੁਕੰਮਲ ਟੈਕਸਟ ਬਜਾਏ ਉਹ JSON ਦਿਖਾਇਆ ਜਾਵੇਗਾ। ਇਹਨਾਂ ਕਾਰਜਾਂ ਲਈ ਇੱਕ ਸਧਾਰਨ ਟੈਕਸਟ ਮਾਡਲ ਚੁਣੋ। OpenRouter 'ਤੇ [ਬਾਡੀ ਬਿਲਡਰ ਮਾਡਲ ਪੇਜ](https://openrouter.ai/openrouter/bodybuilder) ਵੇਖੋ।

ਕਾਰਵਾਈਆਂ:

 - ਮਾਡਲ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, **ਸ਼ਾਮਲ ਕਰੋ** ਜਾਂ ਐਂਟਰੀ ਵਿੱਚ ਕਿਤੇ ਵੀ ਕਲਿੱਕ ਕਰੋ।

 - ਮਾਡਲ ਨੂੰ ਹਟਾਉਣ ਲਈ, **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇਸਦੇ ਨੇੜੇ **X** ਤੇ ਜਾਂ ਉਪਲਬਧ ਮਾਡਲ ਵਿੱਚ ਐਂਟਰੀ ’ਤੇ **ਚੁਣੇ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

 - ਸੂਚੀ ਨੂੰ ਖਾਲੀ ਕਰਨ ਲਈ, **ਸਭ ਕੁਝ ਹਟਾਓ** ’ਤੇ ਕਲਿੱਕ ਕਰੋ। ਲੋੜੀਂਦਾ ਮੁਫਤ ਮਾਡਲ ਸੂਚੀ ਵਿੱਚ ਬਣਿਆ ਰਹੇਗਾ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
> ਜੇ ਤੁਸੀਂ OpenRouter ਨੂੰ ਸਿੱਧੇ ਤੌਰ ਤੇ ਕ੍ਰੈਡਿਟ ਸ਼ਾਮਲ ਕਰਨਾ ਨਹੀਂ ਚਾਹੁੰਦੇ, ਤਾਂ **ਸਿਰਫ਼ ਮੁਫਤ** ਨੂੰ ਸਹਿਯੋਗ ਦੇ ਕੇ ਸ਼ੁਰੂਆਤ ਕਰੋ ਅਤੇ ਮੁਫਤ ਮਾਡਲ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਜ਼ਰੂਰਤ ਨਹੀਂ) ਚੁਣੋ। ਤੁਸੀਂ Ollama ਦੀ ਵਰਤੋਂ ਬਿਨਾਂ ਕਿਸੇ API ਕੁੰਜੀ ਦੇ ਮਾਡਲ ਸਥਾਨਕ ਤੌਰ ’ਤੇ ਚਲਾਉਣ ਲਈ ਵੀ ਕਰ ਸਕਦੇ ਹੋ।

<a id="languages"></a>
### ਭਾਸ਼ਾਵਾਂ

ਐਪ ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਭਾਸ਼ਾਵਾਂ ਦੀਆਂ ਸੂਚੀਆਂ ਨੂੰ ਵਿਵਸਥਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਭਾਸ਼ਾਵਾਂ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਉੱਪਰਲੀਆਂ ਭਾਸ਼ਾਵਾਂ** **ਅਨੁਵਾਦ** ਅਤੇ **ਪਰਿਵਰਤਨ** ਵਿੱਚ ਭਾਸ਼ਾਵਾਂ ਦੀਆਂ ਸੂਚੀਆਂ ਦੇ ਉੱਪਰਲੇ ਹਿੱਸੇ ਵਿੱਚ ਪਿੰਨ ਕੀਤੀਆਂ ਗਈਆਂ ਹਨ।
- **ਕਸਟਮ ਭਾਸ਼ਾ** ਤੁਹਾਡੇ ਨਾਲ ਨਾਲ ਬਣਾਈਆਂ ਗਈਆਂ ਸੂਚੀ ਵਿੱਚ ਨਾ ਹੋਣ ਵਾਲੀ ਭਾਸ਼ਾ ਨੂੰ ਸ਼ਾਮਲ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦੀ ਹੈ।

ਜੇ ਤੁਸੀਂ ਕਸਟਮ ਭਾਸ਼ਾ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ, ਤਾਂ ਇਹ ਅੰਦਰੂਨੀ ਵਿਕਲਪਾਂ ਨਾਲ ਨਾਲ ਭਾਸ਼ਾ ਸੈਲੇਕਟਰ ਵਿੱਚ ਦਿਖਾਈ ਦੇਵੇਗੀ।

<a id="cost-tracking"></a>
### ਲਾਗਤ ਟਰੈਕਿੰਗ

ਲਾਗਤ ਜਾਣਕਾਰੀ ਨੂੰ ਪਰਬੰਧਿਤ ਕਰਨ ਲਈ **ਸੈਟਿੰਗਾਂ** > **ਲਾਗਤ ਨਿਗਰਾਨੀ** ਦੀ ਵਰਤੋਂ ਕਰੋ।

- **ਕੁੱਲ ਲਾਗਤ** ਰਨਿੰਗ ਕੁੱਲ ਨੂੰ ਦਿਖਾਉਂਦਾ ਹੈ।
- **ਮੁੱਲ ਨੂੰ ਕਾਪੀ ਕਰੋ** ਕੁੱਲ ਨੂੰ ਕਲਿੱਪਬੋਰਡ ’ਤੇ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- **ਲਾਗਤ ਰੀਸੈੱਟ ਕਰੋ** ਸਟੋਰ ਕੀਤੀ ਕੁੱਲ ਨੂੰ ਸਿਫ਼ਰ ’ਤੇ ਰੀਸੈੱਟ ਕਰਦਾ ਹੈ।
- **API ਕੁੰਜੀ ਵਰਤੋਂ ਨਾਲ ਤਾਲਮੇਲ** ਕੁੱਲ ਨੂੰ ਤੁਹਾਡੇ OpenRouter ਖਾਤੇ ਦੁਆਰਾ ਰਿਪੋਰਟ ਕੀਤੀ ਵਰਤੋਂ ਨਾਲ ਮੇਲ ਕਰਕੇ ਸੈੱਟ ਕਰਦਾ ਹੈ (ਸਿਰਫ਼ OpenRouter)।
- **API ਕੁੰਜੀ ਵਰਤੋਂ** OpenRouter ਵਰਤੋਂ ਵੇਰਵੇ ਦਿਖਾਉਂਦਾ ਹੈ, ਜੇ ਉਪਲਬਧ ਹੈ।
- **ਲਾਗਤ ਡੇਟਾ ਨੂੰ ਹਟਾਓ** ਸਭ ਡੇਟਾ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ, ਜਾਂ ਸਿਰਫ਼ ਚੁਣੀ ਮਿਤੀ ਤੋਂ ਪਹਿਲਾਂ ਦੀਆਂ ਐਂਟਰੀਆਂ ਨੂੰ।

**ਲਾਗਤ ਨਿਗਰਾਨੀ:** ਜਦੋਂ ਤੁਸੀਂ OpenRouter ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ ਤੁਹਾਡੀ ਵਰਤੋਂ ਅਤੇ OpenRouter ਤੋਂ ਲਾਗਤ ਜਾਣਕਾਰੀ ਦੇ ਅਧਾਰ 'ਤੇ ਖਰਚ ਦਿਖਾਉਂਦੀ ਹੈ। ਦੂਜੇ ਸਾਰੇ ਪ੍ਰਦਾਤਾਵਾਂ ਲਈ, ਐਪ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਮਤਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਲਾਗਤਾਂ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਂਦੀ ਹੈ, ਜੇ ਕੋਈ ਕੀਮਤ ਉਪਲਬਧ ਨਹੀਂ ਹੈ, ਤਾਂ ਅੰਦਾਜ਼ਾ ਸਿਫ਼ਰ ਹੋ ਸਕਦਾ ਹੈ।

<br/>

> ℹ️ **ਨੋਟ**<br/>
>  **ਸਾਰੇ ਲਾਗਤ ਅੰਕੜੇ ਸਿਰਫ਼ ਤੁਹਾਡੇ ਹਵਾਲੇ ਲਈ ਅੰਦਾਜ਼ੇ ਹਨ, ਅਧਿਕਾਰਤ ਬਿਲਿੰਗ ਬਿਆਨ ਨਹੀਂ।**


<br/>

> ⚠️ **ਚੇਤਾਵਨੀ**<br/>
> ਡੇਟਾ ਨੂੰ ਹਟਾਉਣਾ ਮੁੜ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਹਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ, ਸੁਨਿਸ਼ਚਿਤ ਕਰੋ ਕਿ ਤੁਸੀਂ ਆਪਣਾ ਡੇਟਾ ਬੈਕ ਅੱਪ ਕਰ ਲਓ ਜਾਂ ਇਸਨੂੰ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ [**ਡੈਸ਼ਬੋਰਡ** > **ਸਭ ਕਾਲ**](#dashboard-tabs) ਰਾਹੀਂ ਨਿਰਯਾਤ ਕਰ ਲਓ, ਨਹੀਂ ਤਾਂ ਇਹ ਸਥਾਈ ਤੌਰ ’ਤੇ ਖੋ ਜਾਵੇਗਾ। ਹਰੇਕ API ਕਾਲ ਐਂਟਰੀ ਨਾਲ ਸਬੰਧਤ ਸਭ ਇਨਪੁੱਟ/ਆਊਟਪੁੱਟ ਇਤਿਹਾਸ ਨੂੰ ਵੀ ਹਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।

### ਐਪ ਟੈਕਸਟ ਨੂੰ ਅਨੁਵਾਦ, ਮੁੜ-ਲਿਖਣ ਜਾਂ ਬਦਲਣ ਵਿੱਚ ਅਸਫਲ ਹੈ

ਜਾਂਚ ਕਰੋ ਕਿ:

- ਤੁਸੀਂ ਟੂਲਬਾਰ ਵਿੱਚ ਇੱਕ ਮਾਡਲ ਚੁਣਿਆ ਹੈ
- ਘੱਟੋ-ਘੱਟ ਇੱਕ ਮਾਡਲ [**ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ**](#models) ਵਿੱਚ ਸੂਚੀਬੱਧ ਹੈ
- ਤੁਹਾਡੀ API ਸੈਟਅੱਪ ਕੰਮ ਕਰ ਰਹੀ ਹੈ

ਜੇਕਰ ਤੁਸੀਂ ਡੈਸਕਟਾਪ ਐਪ ਵਰਤ ਰਹੇ ਹੋ:

1. [**ਸੈਟਿੰਗਜ਼** > **API ਕਾਨਫਿਗ**](#api-config) ਖੋਲ੍ਹੋ।
2. ਜਾਂਚ ਕਰੋ ਕਿ ਘੱਟੋ-ਘੱਟ ਇੱਕ API ਕੁੰਜੀ ਸੰਭਾਲੀ ਗਈ ਹੈ।
3. ਕੁੰਜੀ ਕੰਮ ਕਰ ਰਹੀ ਹੈ ਇਹ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ ਪ੍ਰਦਾਤਾ ਦੇ ਨਾਲ **ਟੈਸਟ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-model-list-is-empty"></a>
### ਮਾਡਲ ਸੂਚੀ ਖਾਲੀ ਹੈ

[**ਸੈਟਿੰਗਜ਼** > **ਮਾਡਲ**](#models) ਖੋਲ੍ਹੋ ਅਤੇ **ਰੀਫਰੇਸ਼** ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਲੋੜ ਅਨੁਸਾਰ:

- ਕਿਸੇ ਮਾਡਲ ਲਈ ਖੋਜੋ
- **ਸਿਰਫ਼ ਮੁਫ਼ਤ** ਨੂੰ ਚਾਲੂ ਕਰੋ
- **ਚੁਣੇ ਹੋਏ ਮਾਡਲ** ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ਨਤੀਜਾ ਬਹੁਤ ਹੌਲੀ ਜਾਂ ਬਹੁਤ ਮਹਿੰਗਾ ਹੈ

ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਜਾਂ ਵੱਧ ਕੋਸ਼ਿਸ਼ ਕਰੋ:

- ਵੱਖਰਾ ਮਾਡਲ ਚੁਣੋ
- ਛੋਟੀ ਇੰਪੁੱਟ ਦੀ ਵਰਤੋਂ ਕਰੋ
- [**ਸੈਟਿੰਗਜ਼** > **ਜਨਰਲ ਸੈਟਿੰਗਜ਼**](#general-settings) ਵਿੱਚ **ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦ (ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ)** ਬੰਦ ਕਰੋ
- ਸਧਾਰਣ ਕੰਮਾਂ ਲਈ ਮੁਫਤ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ (ਵੇਖੋ [ਮਾਡਲ](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ਇੰਟਰਫੇਸ ਗ਼ਲਤ ਭਾਸ਼ਾ ਵਿੱਚ ਹੈ

[ਟੂਲਬਾਰ](#toolbar) ਵਿੱਚ ਗਲੋਬ ਆਈਕਨ ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਆਪਣੀ ਪਸੰਦੀਦਾ **ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ** ਚੁਣੋ।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ਟੈਕਸਟ ਬਹੁਤ ਛੋਟਾ ਜਾਂ ਪੜ੍ਹਨ ਲਈ ਮੁਸ਼ਕਲ ਹੈ

[**ਸੈਟਿੰਗਜ਼** > **ਜਨਰਲ ਸੈਟਿੰਗਜ਼**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਬਦਲੋ:

- **ਫੌਂਟ ਫੈਮਲੀ**
- **ਆਕਾਰ**

<br/>

<a id="dashboard-charts-are-empty"></a>
### ਡੈਸ਼ਬੋਰਡ ਚਾਰਟ ਖਾਲੀ ਹਨ

ਜੇਕਰ ਇਹ ਸਥਿਤੀ ਹੋਵੇ:

- ਤੁਸੀਂ ਸਿਰਫ਼ **ਮੁਫ਼ਤ ਮਾਡਲਾਂ** ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹੋ (ਲਾਗਤ ਚਾਰਟ ਖਾਲੀ ਹੋਣਗੇ)
- ਚੁਣੀਆਂ **ਸਮੇਂ ਦੀ ਫਿਲਟਰ** ਉਸ ਸਮੇਂ ਦੀ ਮਿਆਦ ਨੂੰ ਕਵਰ ਨਹੀਂ ਕਰਦੀ ਜਦੋਂ ਕਾਲਾਂ ਕੀਤੀਆਂ ਗਈਆਂ ਸਨ - ਜਾਂਚ ਲਈ **ਸਭ** ਕੋਸ਼ਿਸ਼ ਕਰੋ

ਜੇਕਰ **ਸਭ** ਚੁਣਨ ਤੋਂ ਬਾਅਦ ਵੀ ਚਾਰਟ ਖਾਲੀ ਹਨ, ਤਾਂ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕਾਲਾਂ [**ਇਤਿਹਾਸ**](#history) ਜਾਂ **ਸਭ ਕਾਲਾਂ** ਟੈਬ ਵਿੱਚ ਪ੍ਰਗਟ ਹੋਈਆਂ ਹਨ।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ਲਾਗਤ "ਉਪਲਬਧ ਨਹੀਂ" ਵਜੋਂ ਦਿਖਾਈ ਦੇ ਰਹੀ ਹੈ ਜਾਂ ਗਲਤ ਲੱਗਦੀ ਹੈ

ਜਦੋਂ ਤੁਸੀਂ **OpenRouter** ਦੁਆਰਾ ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋ, ਐਪ OpenRouter ਵੱਲੋਂ ਰਿਪੋਰਟ ਕੀਤੇ ਅਸਲ ਖਰਚ ਨੂੰ ਵਿਖਾਉਂਦਾ ਹੈ।

**ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ** (OpenAI ਪ੍ਰਤੱਖ, Anthropic ਪ੍ਰਤੱਖ, ਆਦਿ) ਲਈ, ਲਾਗਤ OpenRouter ਦੁਆਰਾ ਪ੍ਰਕਾਸ਼ਤ ਪ੍ਰਾਈਸਿੰਗ ਡਾਟਾ ਤੋਂ ਅੰਦਾਜ਼ਾ ਲਗਾਈ ਜਾਂਦੀ ਹੈ। ਜੇ ਕਿਸੇ ਮਾਡਲ ਲਈ ਮੈਚ ਕਰਨ ਵਾਲੀ ਕੀਮਤ ਨਹੀਂ ਮਿਲਦੀ ਹੈ, ਤਾਂ ਲਾਗਤ **ਉਪਲਬਧ ਨਹੀਂ** ਦਰਸਾਈ ਜਾਵੇਗੀ ਅਤੇ ਤੁਹਾਡੀ ਕੁੱਲ ਲਾਗਤ ਵਿੱਚ ਨਹੀਂ ਜੋੜੀ ਜਾਵੇਗੀ।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ਕੁੱਲ ਲਾਗਤ ਮੇਰੇ ਪ੍ਰਦਾਤਾ ਬਿੱਲ ਨਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੀ

ਐਪ ਵਿੱਚ ਸਭ ਲਾਗਤ ਦੇ ਅੰਕੜੇ **ਸਿਰਫ਼ ਹਵਾਲਾ ਲਈ ਅੰਦਾਜ਼ੇ** ਹਨ, ਅਧਿਕਾਰਤ ਬਿੱਲਿੰਗ ਸਟੇਟਮੈਂਟ ਨਹੀਂ।

ਕੁੱਲ ਰਕਮ ਨੂੰ ਤੁਹਾਡੇ ਅਸਲ OpenRouter ਖਰਚ ਤੋਂ ਨੇੜੇ ਲਿਆਉਣ ਲਈ, [**ਸੈਟਿੰਗਜ਼** > **ਲਾਗਤ ਟਰੈਕਿੰਗ**](#cost-tracking) ਖੋਲ੍ਹੋ ਅਤੇ **API ਕੁੰਜੀ ਦੀ ਵਰਤੋਂ ਨਾਲ ਸਿੰਕ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### ਸਾਈਡਬਾਰ ਵਿੱਚੋਂ ਇਤਿਹਾਸ ਪੰਨਾ ਗਾਇਬ ਹੈ

**ਕਾਰਵਾਈ ਇਤਿਹਾਸ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖੋ** ਬੰਦ ਹੋ ਸਕਦਾ ਹੈ। [**ਸੈਟਿੰਗਜ਼** > **ਜਨਰਲ ਸੈਟਿੰਗਜ਼**](#general-settings) ਖੋਲ੍ਹੋ ਅਤੇ ਇਸਨੂੰ ਸਹਾਇਤਾ ਪ੍ਰਦਾਨ ਕਰੋ। ਇਸਨੂੰ ਚਾਲੂ ਕਰਨ ਨਾਲ ਪਹਿਲਾਂ ਹਟਾਏ ਗਏ ਇਤਿਹਾਸ ਡਾਟੇ ਬਰਕਰਾਰ ਨਹੀਂ ਹੋਣਗੇ।

<br/>

<a id="web-app-session-expired"></a>
### ਵੈੱਬ ਐਪ: ਲਾਗਇਨ ਪੰਨੇ ਤੇ ਅਣਜਾਣੇ ਮੁੜ-ਨਿਰਦੇਸ਼ਿਤ

ਤੁਹਾਡਾ ਸੈਸ਼ਨ ਸਮਾਂ-ਸੀਮਾ ਪਾਰ ਕਰ ਸਕਦਾ ਹੈ। ਮੁੜ ਲਾਗਇਨ ਕਰੋ। ਜੇਕਰ ਇਹ ਲਗਾਤਾਰ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਸਰਵਰ ਕਾਨਫਿਗਰੇਸ਼ਨ ਵਿੱਚ ਸੈਸ਼ਨ ਦੀ ਜੀਵਨ ਸਮਾਂ ਸੈਟਿੰਗਾਂ ਲਈ ਜਾਂਚ ਕਰੋ।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ਡੈਸ਼ਬੋਰਡ ਹੋਰ ਉਪਭੋਗਤਾਵਾਂ ਲਈ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਵਿਖਾਉਂਦਾ (ਵੈੱਬ)

ਸਿਰਫ਼ **ਪ੍ਰਸ਼ਾਸਕ** **ਯੂਜ਼ਰ** ਫਿਲਟਰ ਦੁਆਰਾ ਸਾਰੇ ਉਪਭੋਗਤਾਵਾਂ ਦਾ ਡਾਟਾ ਵੇਖ ਸਕਦੇ ਹਨ। ਨਿਯਮਤ ਉਪਭੋਗਤਾ ਸਿਰਫ਼ ਉਨ੍ਹਾਂ ਦੀ ਆਪਣੀ ਗਤੀਵਿਧੀ ਨੂੰ ਡਿਜ਼ਾਈਨ ਮੁਤਾਬਿਕ ਵੇਖਦੇ ਹਨ।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ਮੈਂ ਇੱਕ ਅਹੁਦਾ ਬਦਲਿਆ ਅਤੇ ਸੋਧਾਂ ਗੁਆ ਦਿੱਤੀਆਂ

ਜਦੋਂ ਅਹੁਦੇ ਨੂੰ ਸੋਧ ਰਹੇ ਹੋ, ਹਮੇਸ਼ਾ **ਬੈਕ ਟੂ ਰਨ** ਤੇ ਕਲਿੱਕ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **ਸੇਵ** ਤੇ ਕਲਿੱਕ ਕਰੋ।

<a id="quick-tips"></a>
## ਤੁਰੰਤ ਸੁਝਾਅ

- [**ਅਨੁਵਾਦ**](#translate) ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਤਾਂ ਜੋ ਤੁਸੀਂ [**ਮੁੜ-ਲਿਖੋ**](#rewrite) ਜਾਂ [**ਬਦਲੋ**](#transform) ਵੱਲ ਜਾਣ ਤੋਂ ਪਹਿਲਾਂ ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤੁਹਾਡੀ ਸੈਟਅੱਪ ਕੰਮ ਕਰ ਰਹੀ ਹੈ।
- ਰੋਜ਼ਾਨਾ ਸ਼ਬਦਾਵਲੀ ਸੁਧਾਰਾਂ ਲਈ [**ਮੁੜ-ਲਿਖੋ**](#rewrite) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਕਿਸੇ ਖਾਸ ਕੰਮ ਲਈ ਦੁਹਰਾ ਸਕਣ ਵਾਲੀ ਪ੍ਰਕਿਰਿਆ ਲਈ [**ਬਦਲੋ**](#transform) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇਕਰ ਤੁਸੀਂ ਵਰਤੋਂ ਅਤੇ ਲਾਗਤ ਉੱਤੇ ਨਜ਼ਰ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ [**ਡੈਸ਼ਬੋਰਡ**](#dashboard) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਪਿਛਲੇ ਕੰਮਾਂ ਅਤੇ ਉਨ੍ਹਾਂ ਦੇ ਪੂਰੇ ਇੰਪੁੱਟ/ਆਉਟਪੁੱਟ ਟੈਕਸਟ ਦੀ ਸਮੀਖਿਆ ਕਰਨ ਲਈ [**ਇਤਿਹਾਸ**](#history) ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਜੇਕਰ ਤੁਸੀਂ ਇੱਕ ਪ੍ਰਾਮਿਪਟ ਲਾਇਬ੍ਰੇਰੀ ਬਣਾ ਰਹੇ ਹੋ ਜਿਸ ਨੂੰ ਤੁਸੀਂ ਸੁਰੱਖਿਅਤ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ (ਵੇਖੋ [ਮਾਡਲਾਂ ਬਦਲੋ](#transform-prompts)) ਜਾਂ ਜੇਕਰ ਤੁਸੀਂ ਇਸਨੂੰ ਹੋਰਾਂ ਨਾਲ ਸਾਂਝਾ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਨਿਯਮਤ ਤੌਰ ਤੇ ਪ੍ਰਾਮਿਪਟਸ ਨਿਰਯਾਤ ਕਰੋ।
