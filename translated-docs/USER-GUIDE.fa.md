# راهنمای کاربر

<br/>

<a id="introduction"></a>

## معرفی

ترنزرت به شما در سه روش اصلی برای کار با متن کمک می‌کند:

- **ترجمه** - تبدیل متن از یک زبان به زبان دیگر.
- **بازنویسی** - بازآفرینی متن با سبکی متفاوت، مانند روشن‌تر، کوتاه‌تر یا رسمی‌تر.
- **تبدیل** - پردازش متن با استفاده از دستورالعمل‌های هوش مصنوعی سفارشی به نام «پِرُمپت‌ها».

<br/>

این راهنما نحوه استفاده از برنامه پس از نصب و راه‌اندازی آن را توضیح می‌دهد. برای مراحل نصب، به بخش اصلی **[README](README.fa.md)** مراجعه کنید.

<br/>

> ℹ️ **ملاحظه**<br/>
> ترنزرت به صورت یک برنامه دسکتاپ برای ویندوز و لینوکس و همچنین به صورت یک برنامه تحت وب قابل استقرار شخصی در دسترس است. این راهنما بر روی استفاده روزمره از برنامه تمرکز دارد. هر جا که چیزی فقط به یک نسخه اعمال می‌شود، به وضوح مشخص شده است.

## قبل از شروع

برای استفاده از Transrewrt، باید دسترسی به حداقل یک ارائه‌دهنده هوش مصنوعی داشته باشید. ارائه‌دهندگان پشتیبانی‌شده عبارتند از: [OpenRouter](https://openrouter.ai) (که مدل‌های بسیاری را فراهم می‌کند)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و [Ollama](https://ollama.com) برای مدل‌های محلی.

برای شروع نیازی به انتخاب مدل پولی نیست. به محض اینکه کلید API خود را از OpenRouter اضافه کنید، برنامه به‌طور خودکار یک گزینه **رایگان** داخلی OpenRouter را فعال می‌کند. این امکان را فراهم می‌کند که بلافاصله شروع به ترجمه، بازنویسی و تبدیل متن کنید. به‌عنوان گزینه دیگر، می‌توانید کلید API رایگانی از Cerebras، Google، Groq یا Mistral AI تهیه کنید.

به زبان ساده:

- یک **مدل**، موتور هوش مصنوعی است که کار را انجام می‌دهد. مدل‌ها با یک پیشوند **ارائه‌دهنده** فهرست شده‌اند (مثلاً `openrouter/…`، `openai/…`، `ollama/…`).
- یک **کلید API** (یا برای Ollama، یک **آدرس URL پایه**) وسیله‌ای است که برنامه از طریق آن به ارائه‌دهنده متصل می‌شود.

اگر از **اپلیکیشن دسکتاپ** استفاده می‌کنید، کلیدهای مربوط به هر فراهم‌کننده را در بخش [**تنظیمات** > **پیکربندی API**](#api-config) اضافه کنید. در صورت استفاده فقط از OpenRouter، به بخش [نحوه دریافت کلید API](#how-to-get-an-api-key-desktop-app) در ادامه مراجعه کنید. اگر تمایلی به استفاده از کلید API ندارید، می‌توانید Ollama را (از [ollama.com](https://ollama.com)) نصب کرده و به جای آن از مدل‌های محلی مانند `translategemma:4b` استفاده کنید.

اگر از **نسخه وب** استفاده می‌کنید، تنظیم فراهم‌کنندگان توسط مالک سرور و از طریق متغیرهای محیطی انجام می‌شود، بنابراین شما نمی‌توانید مستقیماً کلیدهای API را در درون برنامه وارد کنید.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>

### نحوه دریافت کلید API رایگان OpenRouter (برنامه دسکتاپ)

اگر از برنامه دسکتاپ استفاده می‌کنید، مراحل زیر را دنبال کنید:

1. به [OpenRouter](https://openrouter.ai) در مرورگر خود بروید.
2. حساب کاربری ایجاد کنید یا وارد شوید.
3. صفحه [Keys](https://openrouter.ai/keys) را باز کنید.
4. روی دکمه ایجاد کلید API جدید کلیک کنید.
5. به کلید نامی بدهید تا بتوانید بعداً آن را شناسایی کنید.
6. کلید API جدید را کپی کنید.
7. به Transrewrt برگردید و **تنظیمات** > **پیکربندی API** را باز کنید.
8. کلید را در بخش **OpenRouter API key** (زیر **Settings** > **API Config**) جای‌گذاری کنید.
9. روی **Test OpenRouter key** کلیک کنید تا از صحت کارکرد آن اطمینان حاصل کنید.

<a id="getting-started"></a>

## شروع کار

اگر اولین بار است که از Transrewrt استفاده می‌کنید، مراحل زیر را به ترتیب دنبال کنید:

1. برنامه را باز کنید.
2. در صورت نیاز، زبان **رابط کاربری** خود را از آیکون کره‌ی جهان انتخاب کنید.
3. اگر از **برنامه دسکتاپ** استفاده می‌کنید، به [**تنظیمات** > **پیکربندی API**](#api-config) بروید، یک کلید API را برای حداقل یک ارائه‌دهنده (مثلاً OpenRouter) اضافه کنید و روی **تست** کلیک کنید تا صحت عملکرد آن تأیید شود.
4. [**تنظیمات** > **مدل‌ها**](#models) را باز کنید و یک یا چند مدل را به بخش **مدل‌های انتخاب‌شده** اضافه کنید.
5. [**تنظیمات** > **زبان‌ها**](#languages) را باز کنید و در صورت تمایل **زبان‌های اصلی** خود را انتخاب کنید تا زبان‌های پرکاربرد شما در ابتدا نمایش داده شوند.
6. به بخش **ترجمه** بروید و یک ترجمه ساده انجام دهید تا از صحت عملکرد همه چیز مطمئن شوید.
7. پس از موفقیت‌آمیز بودن ترجمه، امتحان کنید **بازنویسی** و سپس **تبدیل** را امتحان کنید.

رعایت این ترتیب مهم است. از شایع‌ترین مشکل کاربران تازه‌کار جلوگیری می‌کند: تلاش برای انجام یک کار قبل از اینکه برنامه ارتباط API مناسب یا مدل انتخاب‌شده‌ای داشته باشد.

### نوار ابزار

محتوای نوار ابزار کمی بسته به اینکه شما در کدام قسمت برنامه قرار دارید، تغییر می‌کند.

- در سمت چپ، نام صفحه‌ی فعلی نمایش داده می‌شود.
- در سمت راست، **گزینشگر مدل** و کنترل **زبان رابط** نمایش داده می‌شود.

**گزینشگر مدل** به شما امکان می‌دهد تا موتور هوش مصنوعی مناسب برای کار جاری را انتخاب کنید.

  ![گزینشگر مدل](../images/screenshots/fa/model-selector.png)

ممکن است برخی مدل‌های رایگان همیشه در دسترس نباشند—گاهی اوقات آن‌ها آفلاین هستند یا حداکثر میزان استفاده‌شان محدود است. اگر این اتفاق افتاد، برنامه به‌طور خودکار آن مدل را از لیست مدل‌های در دسترس شما حذف می‌کند. برای تنظیم مدل‌هایی که نمایش داده می‌شوند، به بخش [**تنظیمات** > **مدل‌ها**](#models) بروید و لیست مدل‌های خود را ویرایش کنید. 
همچنین می‌توانید با کلیک روی آیکون ارائه‌دهنده سمت چپ نام مدل در نوار ابزار، مستقیماً تنظیمات مدل را باز کنید.

<br/>

**آیکون کره‌ی زمین + کد زبان** زبان رابط برنامه، مثل منوها و دکمه‌ها را تغییر می‌دهد. این تنظیم **بر زبان‌های ترجمه در قسمت «ترجمه» تأثیری ندارد**.

### پنل‌های ورودی و خروجی

اکثر محیط‌های کاری از یک پنل **ورودی** در سمت چپ و یک پنل **خروجی** در سمت راست استفاده می‌کنند.

هر پنل همچنین نشان می‌دهد:

| **ورودی**                                                          | **خروجی**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - تعداد کاراکتر <br/>- تعداد کلمه <br/>- تعداد پاراگراف         | - مدت زمان انجام وظیفه<br/>- **TPS** (توکن در ثانیه)<br/>- تعداد کاراکتر، کلمه و پاراگراف<br/>- مدل استفاده‌شده |

اگر در مورد اصطلاحات فنی سؤالی دارید:

- **توکن** به معنای یک تکه کوچک متن است. می‌توانید آن را به صورت بخشی از یک کلمه یا یک کلمه کوتاه در نظر بگیرید.
- **TPS** به معنای تعداد این تکه‌های متنی است که مدل در هر ثانیه پردازش می‌کند.

<br/>

همچنین می‌توانید هزینه هر عملیات (در صورت در دسترس بودن) و هزینه کلی را نظارت کنید، برای این کار گزینه «نمایش اطلاعات هزینه در عملیات‌ها» را در بخش [**تنظیمات** > **تنظیمات عمومی**](#general-settings) فعال کنید.

## ترجمه

از **ترجمه** زمانی استفاده کنید که بخواهید متنی را از یک زبان به زبان دیگر تبدیل کنید.

![صفحه کار ترجمه](../images/screenshots/fa/translate.png)

<br/>

<a id="translate-text"></a>

### ترجمه متن

1. گزینهٔ **ترجمه** را باز کنید.
2. زبان مبدا را در بخش **از** انتخاب کنید.
3. زبان مقصد را در بخش **به** انتخاب کنید.
4. یک مدل را در نوار ابزار انتخاب کنید.
5. متن را در بخش **ورودی** تایپ یا بچسبانید.
6. روی دکمهٔ **ترجمه** کلیک کنید.
7. نتیجه را در بخش **خروجی** بخوانید.
8. اگر می‌خواهید نتیجه را کپی کنید، از دکمهٔ کپی استفاده کنید.

<br/>

<a id="language-selection"></a>

### انتخاب زبان

- **از** می‌تواند زبان خاصی باشد یا **تشخیص زبان**.
- **به** زبانی است که نتیجه را به آن می‌خواهید.

زبان‌های **برتر انتخاب‌شده** شما در بالای لیست ظاهر می‌شوند. می‌توانید آن‌ها را در بخش [**تنظیمات** > **زبان‌ها**](#languages) تنظیم کنید.

<br/>

<a id="helpful-translation-settings"></a>

### تنظیمات مفید ترجمه

در بخش [**تنظیمات** > **تنظیمات عمومی**](#general-settings)، می‌توانید نحوه عملکرد ترجمه را تغییر دهید:

- **ترجمه خودکار هنگام چسباندن** به محض قرار دادن متن، ترجمه را انجام می‌دهد.
- **کپی خودکار نتیجه در حافظه موقت** نتیجه را پس از ترجمه موفق به‌صورت خودکار کپی می‌کند.
- **ترجمه لحظه‌ای (در حین تایپ)** در حین تایپ، ترجمه را انجام می‌دهد.
- **زمان انتظار (میلی‌ثانیه)** مشخص می‌کند که برنامه چقدر منتظر بماند تا ترجمه لحظه‌ای آغاز شود.
- **Enter** تعیین می‌کند پس از فشار دادن دکمهٔ `Enter` چه اتفاقی بیفتد:

## تبدیل

از **تبدیل** زمانی استفاده کنید که بخواهید هوش مصنوعی دستورالعمل‌های سفارشی خاصی را دنبال کند.

![فضای کار تبدیل](../images/screenshots/fa/transform.png)

این بخش انعطاف‌پذیرترین قسمت برنامه است. می‌توانید از آن برای انجام وظایفی مانند موارد زیر استفاده کنید:

- خلاصه‌سازی یادداشت‌ها
- تبدیل متن ناهمگون به یک ایمیل روان
- استخراج نکات کلیدی
- تبدیل متن به یک قالب خاص
- هر فعالیت سفارشی دیگری روی متن ورودی

<br/>

<a id="run-an-existing-prompt"></a>

### اجرای یک دستور از قبل موجود

1. گزینهٔ **تبدیل** را باز کنید.
2. یک دستور را از لیست دستورها انتخاب کنید.
3. در صورتی که کادر زبان **مقصد** ظاهر شد، در صورت تمایل زبانی را انتخاب کنید.
4. متن مورد نظر را در بخش **ورودی** تایپ یا جای‌گذاری کنید.
5. روی گزینهٔ **تبدیل** کلیک کنید.
6. نتیجه را در بخش **خروجی** بخوانید.

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### اگر هنوز هیچ پرسشی ندارید

اگر فهرست پرسش‌های شما خالی باشد، در فضای کار Transform روی دکمهٔ **بارگذاری پرسش‌های نمونه** کلیک کنید. همین گزینه همیشه در بخش [**تنظیمات** > **پرسش‌های تبدیل**](#transform-prompts) در سطر واردکردن/صادرکردن موجود است. هر دو این گزینه‌ها نمونه‌های از پیش تعریف شده را اضافه می‌کنند تا بتوانید سریع شروع کنید.

<br/>

> ℹ️ **تذکر**<br/>
> پرسش‌های نمونه به زبان انگلیسی ارائه شده‌اند. پس از بارگذاری آن‌ها، می‌توانید یک پرسش را ویرایش کرده و از دکمهٔ **ترجمهٔ پرسش** برای ترجمه به زبان خود استفاده کنید.

<br/>

<a id="create-a-prompt-quickly"></a>

### ایجاد سریع یک دستورالعمل

سریع‌ترین راه برای ایجاد یک دستورالعمل این است:

1. روی **دستورالعمل جدید** کلیک کنید.
2. روی **تولید دستورالعمل** کلیک کنید.
3. توضیح دهید که می‌خواهید دستورالعمل چه کاری انجام دهد.
4. یک مدل انتخاب کنید.
5. اجازه دهید برنامه یک پیش‌نویس برای شما ایجاد کند.
6. پیش‌نویس را بررسی کرده و روی **ذخیره** کلیک کنید.

![تولید دستورالعمل](../images/screenshots/fa/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>

### ویرایش یک دستور

هنگامی که یک دستور ایجاد یا ویرایش میکنید، ویرایشگر در سمت چپ و یک ناحیهٔ آزمایش در سمت راست نمایش داده میشود.

![ویرایشگر دستور تبدیل](../images/screenshots/fa/transform-prompt-edit.png)

فیلدهای اصلی عبارتند از:

- **نام دستور**: نامی که در لیست دستورها نمایش داده میشود.
- **دستورالعمل دستور (اختیاری)**: یک راهنما کوتاه که هنگام اجرای دستور برای کاربر نمایش داده میشود.
- **نقش مدل**: نقش کلی منصوبشده به هوش مصنوعی، مانند «شما یک دستیار مفید هستید.»
- **دستورالعملهای مدل (یکی در هر خط)**: قوانین خاصی که میخواهید هوش مصنوعی پیروی کند.
- **توصیف خروجی**: یک کلمهٔ کوتاه که نتیجه را توصیف میکند، مانند «خلاصه» یا «نوشتن دوباره».
- **دما (0.0 → 1.0)**: نحوهٔ رفتار مدل؛ به بخشهای پایین مراجعه کنید.
- **درخواست زبان مقصد**: افزودن یک انتخابگر زبان مقصد هنگام اجرای دستور.

اگر اصطلاح فنی **دما** برای شما جدید است، آن را به این صورت در نظر بگیرید:

- دمای **پایینتر** نتایج ثابتتر و قابل پیشبینیتری ارائه میدهد.

- دمای **بالاتر** تنوع و خلاقیت بیشتری ایجاد می‌کند.

شما همچنین می‌توانید از موارد زیر استفاده کنید:

- **`تولید پِرُمْپت`** برای ایجاد یک پیش‌نویس جدید از یک توضیح ساده  
- **`بهبود پِرُمْپت`** برای بهینه‌سازی یک پِرُمْپت موجود  
- **`ترجمهٔ پِرُمْپت`** برای ترجمهٔ قسمت‌های پِرُمْپت

<br/>

> ⚠️ **هشدار**<br/>
> قبل از کلیک کردن روی **`بازگشت به اجرا`**، روی **`ذخیره`** کلیک کنید. اگر بدون ذخیره کردن بازگردید، تغییرات شما از بین خواهند رفت.

<br/>

<a id="test-a-prompt-before-using-it"></a>

### آزمایش یک پِرامِت قبل از استفاده

پنل سمت راست به شما امکان می‌دهد قبل از استفاده از آن در کارهای روزمره، پرامت خود را با متن نمونه امتحان کنید.

این کار در شرایط زیر مفید است:

- هنگامی که دارید یک پرامت جدید می‌سازید
- هنگامی که دو نسخه از یک پرامت را مقایسه می‌کنید
- زمانی که می‌خواهید لحن، طول یا فرمت خروجی را بررسی کنید

<br/>

> ℹ️ **یادداشت**<br/>
> شما می‌توانید پرامت‌های ذخیره‌شده را در بخش [**تنظیمات** > **تبدیل پرامت‌ها**](#transform-prompts) صادر و وارد کنید.

## داشبورد

از **داشبورد** برای مشاهده میزان استفاده خود از این برنامه و هزینه‌های آن (برای مدل‌های پولی) استفاده کنید.

![خلاصه داشبورد](../images/screenshots/fa/dashboard-summary.png)


<br/>

> ℹ️ **توجه**<br/>
> اگر فقط از مدل‌های **رایگان** استفاده کنید، مبالغ **هزینه** ممکن است صفر باشد و خلاصه‌های مربوط به هزینه خالی به نظر برسند. در بخش **خلاصه**، **میزان استفاده در طول زمان** و **استفاده بر اساس مدل**، همچنان **تعداد فراخوانی‌ها** (ترجمه، بازنویسی و تبدیل) را نشان می‌دهند، مشروط بر اینکه در بازه زمانی انتخاب‌شده فعالیتی داشته باشید.

<br/>

<a id="filter-the-data"></a>

### فیلتر داده‌ها

از دکمه‌های فیلتر در بالای صفحه برای تغییر محدوده زمانی استفاده کنید.

![فیلترهای داشبورد](../images/screenshots/fa/dashboard-filter.png)

<br/>

> ℹ️ **یادداشت**<br/>
> فیلتر **کاربر** فقط در نسخه وب برای مدیران قابل مشاهده است. کاربران عادی این فیلتر را نخواهند دید و در برنامه دسکتاپ نیز در دسترس نیست.

<br/>

<a id="dashboard-tabs"></a>

### زبانه‌های داشبورد

- **خلاصه**: به شما مروری بر میزان استفاده و هزینه‌ها ارائه می‌دهد. شامل **میزان استفاده در طول زمان** (تعداد کل تماس‌های انباشته روزانه برای ترجمه، بازنویسی و تبدیل) و **میزان استفاده بر اساس مدل** (تعداد کل تماس‌ها به ازای هر مدل، شامل تبدیل) می‌شود.
- **بر اساس استفاده**: فعالیت‌ها را بر اساس زبان ترجمه، حالت بازنویسی و پرسش تبدیل دسته‌بندی می‌کند.
- **بر اساس مدل**: نشان می‌دهد که از چه مدل‌هایی استفاده کرده‌اید و هزینه آن‌ها چقدر بوده است.
- **بر اساس روز**: جمع کل استفاده روزانه را نشان می‌دهد.
- **تمامی تماس‌ها**: تاریخچه کامل تماس‌ها را نشان می‌دهد و امکان صدور آن را فراهم می‌کند.

<br/>

<a id="export-data"></a>

### خروجی‌گیری داده

جداول داشبورد می‌توانند داده‌ها را در قالب‌های زیر خروجی بگیرند:

- **JSON**
- **CSV**
- **XLSX**

این قابلیت در صورتی که بخواهید فعالیت‌ها را خارج از برنامه بررسی کنید یا گزارشی را به اشتراک بگذارید، مفید است.

<br/>

<a id="delete-stored-records-for-a-model"></a>

### حذف رکوردهای ذخیره‌شده برای یک مدل

در بخش **بر اساس مدل** یا **تمامی فراخوانی‌ها**، می‌توانید با کلیک روی آیکون «سطل زباله»، رکوردهای ذخیره‌شده یک مدل را حذف کنید.

> ⚠️ **اخطار**<br/>
> حذف رکوردهای ذخیره‌شده قابل بازگردانی نیست. فقط در صورتی این کار را انجام دهید که مطمئن باشید دیگر به این تاریخچه نیازی ندارید.

برای حذف تمام داده‌ها یا حذف رکوردها بر اساس مدت زمان ذخیره‌سازی، به بخش [**تنظیمات** > **پیگیری هزینه**](#cost-tracking) بروید. در آنجا گزینه‌هایی برای حذف تمام داده‌های ذخیره‌شده یا تنها داده‌های قدیمی‌تر از یک تاریخ مشخص در دسترس خواهد بود.

<a id="general-settings"></a>

### تنظیمات عمومی

از **تنظیمات عمومی** برای کنترل رفتار تایپ کردن، ذخیره‌سازی جزئیات اجرا برای **تاریخچه** و نمایش استفاده کنید.

**رفتار**

- **رفتار Enter** مشخص می‌کند که کلید `Enter` آیا وظیفه را اجرا می‌کند یا یک خط جدید وارد می‌کند.
- **ترجمه خودکار هنگام چسباندن** به محض چسباندن متن، فرآیند ترجمه را شروع می‌کند.
- **کپی خودکار نتیجه در حافظه موقت** به طور خودکار نتایج موفقیت‌آمیز را کپی می‌کند.
- **ترجمه لحظه‌ای (در حین تایپ)** در حین تایپ، ترجمه را انجام می‌دهد.
- **زمان انتظار (ms)** مدت زمان انتظار برای ترجمه لحظه‌ای را تعیین می‌کند.

**تاریخچه**

- **ذخیره تاریخچه اجرا** مشخص می‌کند که آیا هر ترجمه، بازنویسی و تبدیل، **متن ورودی و خروجی** را برای نمایش در بخش کناری [**تاریخچه**](#history) ذخیره کند یا خیر. هنگام خاموش کردن آن، درخواست تأیید انجام می‌شود؛ در صورت تأیید، متن تاریخچه ذخیره‌شده از پایگاه داده حذف می‌شود.

- **حذف داده‌های تاریخچه**: با استفاده از دکمهٔ **حذف داده‌ها**، می‌توانید متن‌های ذخیره‌شده را بر اساس سن حذف کنید (مثلاً مواردی که قدیمی‌تر از چند ماه هستند یا **تمام داده‌ها (پاک کردن)**). این گزینه فقط بر روی متن‌های ذخیره‌شدهٔ بخش **تاریخچه** تأثیر دارد و **بر مجموع هزینه یا مصارف تأثیری ندارد**. برای حذف یا ویرایش داده‌های **هزینه**، از [**تنظیمات** > **پیگیری هزینه**](#cost-tracking) استفاده کنید.

**ظاهر**

- **نمایش اطلاعات هزینه روی دکمه‌ها**: نمایش هزینهٔ هر عمل (در صورت در دسترس بودن) و هزینهٔ کل را در پنل‌های خروجی ترجمه، بازنویسی و تبدیل کنترل می‌کند.
- **تعداد ارقام اعشار هزینه**: نحوهٔ نمایش اعشار هزینه را تغییر می‌دهد.
- **فقط در مرورگر وب**: **افزودن حاشیه اطراف برنامه** فضای اضافی دور رابط کاربری ایجاد می‌کند.
- **خانواده فونت**: فونت متن در پنل‌های ویرایش را تغییر می‌دهد.
- **اندازه**: اندازهٔ فونت را تغییر می‌دهد.

**پشتیبان‌گیری از تنظیمات**

- **درج داده‌های استفاده در فایل پشتیبان**: در صورت فعال بودن، فایل ZIP شامل تاریخچهٔ اجرای دستورات و داده‌های تماس API نیز خواهد بود.

- **پشتیبان‌گیری از تنظیمات** — به‌طور پیش‌فرض یک فایل فشرده ZIP تکی (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` در زمان UTC) ایجاد می‌کند که شامل `config.json`، `state.json`، کلید رمزگذاری (اختیاری)، کاربران، تنظیمات، دستورهای سفارشی و داده‌های استفاده (در صورت انتخاب شما) می‌شود. پس از انجام موفقیت‌آمیز پشتیبان‌گیری، تأییدیه‌ای نمایش داده می‌شود که نام فایل ذخیره‌شده را نشان می‌دهد.
- **بازیابی از پشتیبان** — ابتدا یک **کادر گفتگوی تأیید** باز می‌شود. در داخل این کادر، فایل فشرده پشتیبان را انتخاب کنید (**مرور کردن** / انتخاب فایل یا کشیدن و رها کردن فایل در مواردی که پشتیبانی می‌شود)، سپس گزینه‌های زیر را بررسی کنید:
  - **بازیابی داده‌های استفاده** — وارد کردن داده‌ها/تاریخچه از فایل ZIP زمانی که داده‌های استفاده در هنگام پشتیبان‌گیری شامل شده بودند؛ در صورت تمایل به بازیابی فقط تنظیمات و دستورها، این گزینه را غیرفعال بگذارید.
  - **پاک کردن داده‌های قبلی استفاده قبل از بازیابی** — حذف داده‌ها/تاریخچه موجود در نسخه نصب شده قبل از اعمال پشتیبان (اختیاری؛ زمانی استفاده شود که تمایل به جایگزینی کامل دارید).

پشتیبان‌هایی که در نسخه وب یا دسکتاپ ایجاد شده‌اند، می‌توانند در نسخه دیگر بازیابی شوند. هنگام بازیابی یک پشتیبان دسکتاپ در نسخه وب، داده‌ها به کاربر مدیریت بازیابی خواهند شد.

<a id="models"></a>

### مدل‌ها

از **تنظیمات** > **مدل‌ها** برای انتخاب مدل‌هایی که در نوار ابزار نمایش داده می‌شوند، استفاده کنید.

![زبانهٔ مدل‌های تنظیمات](../images/screenshots/fa/settings-models.png)

صفحه شامل دو لیست است:

- **مدل‌های موجود** در سمت چپ
- **مدل‌های انتخاب‌شده** در سمت راست

کنترل‌های مفید شامل این موارد هستند:

- **جستجوی مدل‌ها...** برای یافتن مدل بر اساس نام
- چیپس‌های **ارائه‌دهنده** برای محدود کردن لیست به یک موتور (OpenRouter، OpenAI، Ollama، …)
- **فقط رایگان** برای نمایش صرفاً مدل‌های رایگان
- **تازه‌سازی** برای بارگیری مجدد لیست
- **گسترش همه** و **بستن همه** هنگامی که لیست را بر اساس ارائه‌دهنده مرتب می‌کنید

شناسه‌های مدل شامل پیشوند ارائه‌دهنده هستند (مثلاً `openrouter/…` در مقابل `openai/…`). نشان‌ها مانند **OpenAI (OpenRouter)** در برابر **OpenAI (مستقیم)** نحوهٔ مسیریابی ترافیک را نشان می‌دهند.

> ℹ️ **یادداشت**<br/>

> **سازنده بدنه OpenRouter** (`openrouter/bodybuilder`) یک مدل مسیریابی است، نه یک مدل چت عمومی: پاسخ آن به صورت JSON است که ساختار درخواست‌های API OpenRouter را توصیف می‌کند (مثلاً یک آرایهٔ `requests` شامل `model` و `messages`). اگر از این مدل برای **ترجمه**، **بازنویسی** یا **تبدیل** استفاده کنید، در پنل خروجی به جای متن نهایی، این JSON نمایش داده می‌شود. برای این کارها از یک مدل متنی معمولی استفاده کنید. صفحهٔ مدل [سازنده بدنه](https://openrouter.ai/openrouter/bodybuilder) را در OpenRouter ببینید.

عملیات:

 - برای اضافه کردن یک مدل، روی **افزودن** یا هر نقطه‌ای در داخل ورودی کلیک کنید.

 - برای حذف یک مدل، در بخش **مدل‌های انتخاب‌شده** یا در **انتخاب شده** روی علامت **X** کنار آن، کلیک کنید.

 - برای پاک‌کردن لیست، روی **لغو انتخاب همه** کلیک کنید. مدل رایگان مورد نیاز در لیست باقی می‌ماند.

<br/>

> ℹ️ **توجه**<br/>

> اگر می‌خواهید بلافاصله امتیازی به OpenRouter اضافه نکنید، ابتدا گزینه **فقط رایگان** را فعال کنید و مدل‌های رایگان را انتخاب کنید (نیازی به کارت اعتباری نیست). شما همچنین می‌توانید از Ollama برای اجرای مدل‌ها به صورت محلی بدون هیچ کلید API استفاده کنید.

<a id="languages"></a>

### زبان‌ها

برای سازمان‌دهی فهرست زبان‌های مورد استفاده در برنامه، از بخش **تنظیمات** > **زبان‌ها** استفاده کنید.

- **زبان‌های برتر** در بالای فهرست زبان‌ها در بخش‌های **ترجمه** و **تبدیل** ثابت شده‌اند.
- **زبان سفارشی** امکان اضافه کردن زبانی را فراهم می‌کند که در فهرست داخلی وجود ندارد.

اگر یک زبان سفارشی اضافه کنید، این زبان در کنار گزینه‌های داخلی در انتخاب‌کننده‌های زبان نمایش داده می‌شود.

<a id="cost-tracking"></a>

### ردیابی هزینه

از بخش **تنظیمات** > **ردیابی هزینه** برای مدیریت اطلاعات مربوط به هزینه استفاده کنید.

- **هزینه کل**: مجموع فعال (جاری) را نمایش می‌دهد.
- **کپی کردن مقدار**: کل مبلغ را در حافظه موقت کپی می‌کند.
- **بازنشانی هزینه**: مجموع ذخیره‌شده را به صفر بازگردانی می‌کند.
- **همگام‌سازی با مصرف کلید API**: کل مبلغ را با مقدار مصرف گزارش‌شده توسط حساب OpenRouter شما تطبیق می‌دهد (فقط برای OpenRouter).
- **مصرف کلید API**: اگر اطلاعات موجود باشد، جزئیات مصرف OpenRouter را نشان می‌دهد.
- **حذف داده‌های هزینه**: تمام داده‌ها یا فقط مواردی را که تاریخ آن‌ها قدیمی‌تر از تاریخ انتخاب‌شده است، پاک می‌کند.


**ردیابی هزینه:** هنگامی که از مدل‌های OpenRouter استفاده می‌کنید، برنامه میزان استفاده واقعی و هزینه شما را بر اساس اطلاعات هزینه از OpenRouter نشان می‌دهد. برای تمام سایر ارائه‌دهندگان، برنامه هزینه‌ها را با استفاده از قیمت‌های منتشرشده توسط OpenRouter برآورد می‌کند؛ اگر قیمتی موجود نباشد، ممکن است برآورد صفر باشد.

<br/>

> ℹ️ **یادداشت**<br/>
> **تمام مقادیر هزینه صرفاً تخمینی هستند و تنها جهت اطلاع شما ارائه می‌شوند و معادل صورت‌حساب رسمی نیستند.**


<br/>

> ⚠️ **اخطار**<br/>

> حذف داده‌ها قابل بازگشت نیست. قبل از حذف، مطمئن شوید داده‌های خود را پشتیبان تهیه کرده‌اید یا آن‌ها را از طریق [**تاریخچه**](#history) یا [**داشبورد** > **تمامی فراخوانی‌ها**](#dashboard-tabs) صادر کرده‌اید، در غیر این صورت به طور دائم از بین خواهند رفت.  
> کل تاریخچه ورودی/خروجی مربوط به هر مدخل فراخوانی API نیز حذف خواهد شد.

<br/>

### تبدیل دستورها

برای مدیریت دستورها به صورت گروهی، از مسیر **تنظیمات** > **تبدیل دستورها** استفاده کنید.

شما می‌توانید:

- دستورهای ذخیره‌شده خود را مرور کنید
- دستورها را حذف کنید
- دستورها را از یک فایل وارد کنید
- دستورها را برای پشتیبان‌گیری یا اشتراک‌گذاری خارج کنید
- دستورهای نمونه را به لیست دستورها بارگذاری کنید

### کاربران

از بخش **کاربران** برای مدیریت حساب‌های کاربری در نسخه تحت‌وب استفاده کنید. شما می‌توانید کاربران را اضافه کنید، اطلاعات آن‌ها را به‌روزرسانی کنید، رمز عبورشان را بازنشانی کنید و یا حساب‌ها را حذف کنید.

<a id="api-config"></a>

### تنظیمات API

ارائه‌دهندگان پشتیبانی‌شده عبارتند از: OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و **Ollama** (مدل‌های محلی از طریق یک آدرس URL پایه). شما فقط نیاز دارید تا ارائه‌دهندگانی که از آن‌ها استفاده می‌کنید را پیکربندی کنید.

**برنامه تحت وب: فقط مدیر سیستم**

کلیدهای API از طریق متغیرهای محیطی سیستم یا Docker تنظیم می‌شوند — این کلیدها در رابط کاربری وب وارد نمی‌شوند. این صفحه نشان می‌دهد که برای کدام ارائه‌دهندگان کلیدی تنظیم شده است و به شما امکان تست هر یک را با کلیک روی دکمه **`تست`** می‌دهد.

<br/>

> ℹ️ **یادداشت**<br/>
> برای تغییر کلید API، متغیر محیطی را در پیکربندی سیستم یا Docker به‌روزرسانی کرده و سرور یا کانتینر را مجدداً راه‌اندازی کنید.

> ℹ️ **یادداشت**<br/>

> **پشتیبان‌گیری از تنظیمات** (نگاه کنید به [**تنظیمات عمومی** → پشتیبان‌گیری تنظیمات](#general-settings)) می‌تواند کلیدهای ارائه‌دهندهٔ **حل‌شده** را درون فایل `config.json` فایل فشرده ZIP قرار دهد. بازیابی این فایل فشرده، کلیدها را به فایل پیکربندی ذخیره‌شده روی سرور **کپی نمی‌کند** — کلیدهای فعال همانطور که قبلاً توضیح داده شد، همچنان از محیط و وضعیت فایل موجود گرفته می‌شوند.

<br/>

**برنامه دسکتاپ**

از **پیکربندی API** برای ذخیره کردن کلیدهای API هر ارائه‌دهنده‌ای که استفاده می‌کنید، استفاده کنید. برای Ollama، به جای کلید API، **آدرس پایه URL** را وارد کنید.


<br/>

> 💡 **نکته** <br/>
> اگر تمایلی به استفاده از کلید API یا پرداخت هزینه استفاده ندارید، می‌توانید [Ollama را دانلود کنید](https://ollama.com) و مدل‌ها (مثل `translategemma:4b`) را به صورت محلی و رایگان روی دستگاه خود اجرا کنید. یا می‌توانید یک حساب کاربری رایگان در OpenRouter ایجاد کنید (نیاز به کارت اعتباری نیست) تا از مدل‌های رایگان آنها استفاده کنید، یا یک کلید API رایگان از Cerebras، Google، Groq یا Mistral AI دریافت کنید.

<br/>

- فقط ارائه‌دهندگانی را اضافه کنید که نیاز دارید. در بخش **تنظیمات** > **مدل‌ها**، هر شناسهٔ مدل با نام ارائه‌دهنده شروع می‌شود (برای مثال `openrouter/openrouter/free`، `openai/gpt-4o`، `ollama/llama3`).

برای اضافه کردن یک کلید API، مقدار آن را در کادر متنی وارد کرده و روی **`ذخیره`** کلیک کنید. برای جایگزینی یک کلید موجود، روی **`ویرایش`** کلیک کنید. برای بررسی صحت عملکرد یک کلید، روی **`تست`** کلیک کنید. برای آدرس اصلی Ollama، همیشه با فشار دادن دکمهٔ **`تست`** ارتباط را بررسی کنید.

<br/>

> ℹ️ **یادداشت**<br/>
> شما نمی‌توانید مقدار فعلی یک کلید API را مشاهده کنید. تنها می‌توانید آن را با استفاده از دکمهٔ **`ویرایش`** جایگزین کنید.
> کلیدهای API به صورت رمزگذاری‌شده در پیکربندی ذخیره می‌شوند.

<a id="common-issues"></a>

## مشکلات رایج

اگر چیزی به درستی کار نمیکند، ابتدا موارد زیر را بررسی کنید.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### برنامه متن را ترجمه، بازنویسی یا تبدیل نمی‌کند

بررسی کنید که:

- یک مدل را در نوار ابزار انتخاب کرده باشید
- حداقل یک مدل در بخش [**تنظیمات** > **مدل‌ها**](#models) فهرست شده باشد
- تنظیمات API شما به درستی کار می‌کند

اگر از نسخه دسکتاپ برنامه استفاده می‌کنید:

1. بخش [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید.
2. مطمئن شوید حداقل یک کلید API ذخیره شده باشد.
3. روی دکمه **تست** کنار ارائه‌دهنده کلیک کنید تا مطمئن شوید کلید به درستی کار می‌کند.

<br/>

<a id="the-model-list-is-empty"></a>

### لیست مدل‌ها خالی است

[**تنظیمات** > **مدل‌ها**](#models) را باز کرده و روی **به‌روزرسانی** کلیک کنید.

در صورت نیاز:

- یک مدل را جست‌وجو کنید
- گزینه **فقط رایگان** را فعال کنید
- یک یا چند مدل را به **مدل‌های انتخاب‌شده** اضافه کنید

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>

### نتیجه خیلی کُند یا خیلی گران است

یکی یا چند مورد از موارد زیر را امتحان کنید:

- یک مدل دیگر انتخاب کنید
- از ورودی کوتاه‌تری استفاده کنید
- گزینه **تبدیل همزمان (در حین تایپ)** را در بخش [**تنظیمات** > **تنظیمات کلی**](#general-settings) غیرفعال کنید
- برای وظایف ساده از مدل‌های رایگان استفاده کنید (نگاه کنید به [مدل‌ها](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>

### رابط به زبان اشتباه است

روی آیکون کره‌ی زمین در [نوار ابزار](#toolbar) کلیک کرده و **زبان رابط** مورد نظر خود را انتخاب کنید.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>

### متن خیلی کوچک یا خواندنی نیست

[**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید و موارد زیر را تغییر دهید:

- **فونت**
- **اندازه**

<br/>

<a id="dashboard-charts-are-empty"></a>

### نمودارهای پیشخوان خالی هستند

این امر در صورت زیر طبیعی است:

- شما فقط از **مدل‌های رایگان** استفاده می‌کنید و به دنبال اعداد مربوط به **هزینه** هستید (این مقادیر ممکن است صفر باشند)؛ نمودارهای شمارش فراخوانی مربوط به **مصرف** در بخش **خلاصه** هنوز به داده‌های دوره انتخابی نیاز دارند.
- **فیلتر زمانی** انتخاب‌شده شامل بازه‌ای نیست که در آن فراخوانی‌ها انجام شده‌اند — برای بررسی، گزینهٔ **همه** را امتحان کنید.

اگر پس از انتخاب **همه** نمودارها همچنان خالی باشند، بررسی کنید که آیا فراخوانی‌ها در بخش [**تاریخچه**](#history) یا در برگهٔ **همهٔ فراخوانی‌ها** نمایش داده می‌شوند یا خیر.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### هزینه نمایش داده شده به صورت «در دسترس نیست» یا غلط به نظر می‌رسد

هنگام استفاده از مدل‌ها از طریق **OpenRouter**، این برنامه میزان هزینه واقعی شما را که توسط OpenRouter گزارش شده است نمایش می‌دهد.

برای **سایر ارائه‌دهندگان** (مثل OpenAI مستقیم، Anthropic مستقیم و غیره)، هزینه بر اساس داده‌های قیمت‌گذاری منتشر شده توسط OpenRouter تخمین زده می‌شود. اگر قیمتی برای یک مدل یافت نشود، هزینه به صورت **در دسترس نیست** نمایش داده می‌شود و به جمع کل هزینه‌های شما اضافه نخواهد شد.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### مبلغ کل با صورت‌حساب ارائه‌دهنده من مطابقت ندارد

تمام اعداد و ارقام هزینه در این اپلیکیشن **صرفاً تخمینی و جهت اطلاع رسانی هستند** و بیانگر صورت‌حساب رسمی نیستند.

برای نزدیک‌تر کردن مبلغ کل به هزینه واقعی شما در OpenRouter، صفحهٔ [**تنظیمات** > **پیگیری هزینه**](#cost-tracking) را باز کنید و دکمهٔ **همگام‌سازی با میزان استفاده از کلید API** را کلیک کنید.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### صفحهٔ تاریخچه در نوار کناری گم شده است

امکان **ذخیره تاریخچه اجرا** غیرفعال باشد. [**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید و آن را فعال نمایید. توجه داشته باشید که فعال کردن این گزینه، داده‌های تاریخچهٔ پاک‌شدهٔ قبلی را بازیابی نمی‌کند.

<br/>

<a id="web-app-session-expired"></a>

### برنامه تحت وب: به صفحه ورود به طور ناخواسته هدایت شد

ممکن است جلسه شما منقضی شده باشد. دوباره وارد شوید. اگر این اتفاق اغلب رخ می‌دهد، تنظیمات مدت زمان جلسه در سرور را بررسی کنید.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### مدیریت وب: فراموشی یا گم شدن رمز عبور

این موضوع مربوط به **اپلیکیشن وب مستقرشده توسط کاربر** (دکر) است، نه اپلیکیشن دسکتاپ (الکترون).

- در صورتی که **مدیر دیگری بتواند وارد شود**، می‌تواند از مسیر [**تنظیمات** > **کاربران**](#users) وارد شود، حساب کاربری مورد نظر را انتخاب کند و یک **رمز عبور جدید** تنظیم کند.
- اگر **دسترسی نداشته باشید**، ولی به **دسترسی نوع shell** به ماشین یا کانتینر داشته باشید، می‌توانید از طریق ابزار کمکی که در تصویر وجود دارد، رمز عبور را بازنشانی کنید (در صورت تغییر نام پیش‌فرض، `transrewrt` را جایگزین کنید. همچنین در صورت داشتن فاصله یا کاراکترهای خاص، رمز عبور را درون گیومه قرار دهید):

```bash
docker exec transrewrt reset-web-password '<نام-کاربری>' '<رمز-عبور-جدید>'
```

نام کاربری پیش‌فرض مدیر، `admin` است، در صورتی که حساب دیگری ایجاد نکرده باشید. اگر تنها یک آرگومان ارسال کنید، آن رمز عبور به عنوان گذرواژه جدید برای `admin` در نظر گرفته می‌شود.

اگر به جای دکر، از **نسخه سورس** استفاده می‌کنید، دستور زیر را اجرا کنید:

```bash
pnpm run reset-web-password -- <نام-کاربری> <رمز-عبور-جدید>

اسکریپت، رکورد کاربر را در پایگاه داده SQLite به‌روزرسانی می‌کند (و در صورت فقدان، می‌تواند کاربر `admin` را ایجاد کند). پس از بازنشانی، با گذرواژه جدید وارد شوید.


<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>

### داشبورد داده‌ای برای سایر کاربران نمایش نمی‌دهد (وب)

فقط **مدیران** می‌توانند از طریق فیلتر **کاربر** داده‌های تمام کاربران را مشاهده کنند. به‌طور پیش‌فرض، کاربران عادی تنها فعالیت خود را مشاهده می‌کنند.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>

### من یک پِرامِت را تغییر دادم و ویرایش‌ها از دست رفت

هنگام ویرایش یک پِرامِت، همیشه قبل از کلیک کردن روی **بازگشت به اجرا**، روی **ذخیره** کلیک کنید.

<a id="quick-tips"></a>

## نکات سریع

- قبل از اینکه به سراغ [**بازنویسی**](#rewrite) یا [**تبدیل**](#transform) بروید، با [**ترجمه**](#translate) شروع کنید تا از صحت تنظیمات خود اطمینان حاصل کنید.
- برای بهبود روزمره متن‌ها از [**بازنویسی**](#rewrite) استفاده کنید.
- زمانی که به یک جریان کاری قابل تکرار برای یک وظیفهٔ خاص نیاز دارید، از [**تبدیل**](#transform) استفاده کنید.
- در صورتی که می‌خواهید میزان استفاده و هزینه‌ها را زیر نظر داشته باشید، از [**داشبورد**](#dashboard) استفاده کنید.
- برای بازبینی عملیات گذشته و متن کامل ورودی و خروجی آن‌ها از [**تاریخچه**](#history) استفاده کنید.
- اگر در حال ساخت یک کتابخانه دستورهای تبدیل (prompt) هستید و می‌خواهید آن را ایمن نگه دارید، یا قصد به اشتراک گذاری آن با دیگران را دارید، به طور منظم دستورها را خارج کنید (نگاه کنید به [دستورهای تبدیل](#transform-prompts)).
