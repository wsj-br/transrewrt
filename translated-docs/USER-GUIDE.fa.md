# راهنمای کاربر

<br/>

<a id="introduction"></a>
## معرفی

Transrewrt به شما در کار با متن به سه روش اصلی کمک می‌کند:

- **ترجمه** - تبدیل متن از یک زبان به زبان دیگر.
- **بازنویسی** - بازنویسی متن با سبک متفاوت، مانند واضح‌تر، کوتاه‌تر یا رسمی‌تر.
- **تبدیل** - پردازش متن با استفاده از دستورالعمل‌های هوش مصنوعی سفارشی به نام دستورات.

<br/>

این راهنما نحوه استفاده از برنامه پس از نصب و راه‌اندازی آن را توضیح می‌دهد. برای مراحل نصب، به **[README](README.fa.md)** اصلی مراجعه کنید.

<br/>

> ℹ️ **توجه**<br/>
> Transrewrt به صورت برنامه دسکتاپ برای ویندوز و لینوکس و همچنین به صورت برنامه تحت وب قابل اجرا در سرور شخصی در دسترس است. این راهنما بر استفاده روزمره از برنامه تمرکز دارد. در مواردی که چیزی فقط به یک نسخه مربوط می‌شود، به وضوح مشخص شده است.

<a id="before-you-start"></a>
## قبل از شروع

برای استفاده از Transrewrt، نیاز به دسترسی به حداقل یک ارائه‌دهنده هوش مصنوعی دارید. ارائه‌دهندگان پشتیبانی شده عبارتند از: [OpenRouter](https://openrouter.ai) (که مدل‌های بسیاری را گردآوری می‌کند)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، سیبرس و [Ollama](https://ollama.com) برای مدل‌های محلی.

برای شروع نیازی به انتخاب مدل پولی ندارید. به محض اینکه کلید API OpenRouter خود را اضافه کنید، برنامه به‌طور خودکار گزینه **رایگان** داخلی OpenRouter را فعال می‌کند. این امکان را فراهم می‌کند که بلافاصله شروع به ترجمه، بازنویسی و تبدیل متن کنید. همچنین می‌توانید کلید API رایگانی از سیبرس، Google، Groq یا Mistral AI دریافت کنید.

به زبان ساده:

- یک **مدل**، موتور هوش مصنوعی است که کار را انجام می‌دهد. مدل‌ها با پیشوند **ارائه‌دهنده** فهرست می‌شوند (برای مثال `openrouter/…`, `openai/…`, `ollama/…`).
- یک **کلید API** (یا برای Ollama، یک **آدرس پایه URL**) روشی است که برنامه از طریق آن به ارائه‌دهنده متصل می‌شود.

اگر از **برنامه دسکتاپ** استفاده می‌کنید، کلیدهای خود را در بخش [**تنظیمات** > **پیکربندی API**](#api-config) برای هر ارائه‌دهنده‌ای که استفاده می‌کنید اضافه کنید. برای استفاده فقط از OpenRouter، به بخش [نحوه دریافت کلید API](#how-to-get-an-api-key-desktop-app) در ادامه مراجعه کنید. اگر نمی‌خواهید از کلید API استفاده کنید، می‌توانید Ollama (از [ollama.com](https://ollama.com)) را نصب کنید و به جای آن از مدل‌های محلی مانند `translategemma:4b` استفاده کنید.

اگر از **نسخه وب** استفاده می‌کنید، مالک سرور ارائه‌دهندگان را از طریق متغیرهای محیطی پیکربندی می‌کند، بنابراین شما نمی‌توانید کلیدهای API را مستقیماً در برنامه وارد کنید.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### نحوه دریافت کلید API رایگان OpenRouter (برنامه دسکتاپ)

اگر از برنامه دسکتاپ استفاده می‌کنید، مراحل زیر را دنبال کنید:

1. به [OpenRouter](https://openrouter.ai) در مرورگر وب خود بروید.
2. یک حساب کاربری ایجاد کنید یا وارد شوید.
3. صفحه [Keys](https://openrouter.ai/keys) را باز کنید.
4. دکمه ایجاد کلید API جدید را کلیک کنید.
5. به کلید نامی دهید تا بتوانید بعداً آن را تشخیص دهید.
6. کلید جدید را کپی کنید.
7. به Transrewrt بازگردید و بخش **تنظیمات** > **پیکربندی API** را باز کنید.
8. کلید را در بخش **OpenRouter API key** (تحت **تنظیمات** > **پیکربندی API**) چسبانده‌اید.
9. روی **Test OpenRouter key** کلیک کنید تا مطمئن شوید کار می‌کند.

<br/><br/>

<a id="getting-started"></a>
## شروع کار

اگر اولین بار است که از Transrewrt استفاده می‌کنید، مراحل زیر را به ترتیب دنبال کنید:

1. برنامه را باز کنید.
2. در صورت نیاز، **زبان رابط** خود را از آیکون کره زمین انتخاب کنید.
3. اگر از **برنامه دسکتاپ** استفاده می‌کنید، بخش [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید، کلید API را برای حداقل یک ارائه‌دهنده (برای مثال OpenRouter) اضافه کنید و روی **تست** کلیک کنید تا از صحت آن اطمینان حاصل کنید.
4. بخش [**تنظیمات** > **مدل‌ها**](#models) را باز کنید و یک یا چند مدل را به **مدل‌های انتخاب شده** اضافه کنید.
5. بخش [**تنظیمات** > **زبان‌ها**](#languages) را باز کنید و در صورت تمایل **زبان‌های برتر** خود را انتخاب کنید تا زبان‌های پرکاربرد شما اول نمایش داده شوند.
6. به بخش **ترجمه** بروید و یک ترجمه ساده انجام دهید تا از کارکرد همه چیز اطمینان حاصل کنید.
7. پس از موفقیت‌آمیز بودن این مرحله، بروید به **بازنویسی** و سپس **تبدیل**.

ترتیب این مراحل مهم است. این ترتیب از رایج‌ترین مشکل اولین استفاده جلوگیری می‌کند: تلاش برای اجرای یک وظیفه قبل از اینکه برنامه ارتباط API کارآمد یا مدل انتخاب شده‌ای داشته باشد.

<a id="toolbar"></a>
### نوار ابزار

نوار ابزار کمی بسته به اینکه در کجای برنامه هستید تغییر می‌کند.

- در سمت چپ، نام صفحه فعلی نمایش داده می‌شود.
- در سمت راست، **انتخاب‌کننده مدل** و کنترل **زبان رابط** نمایش داده می‌شود.

**انتخاب‌کننده مدل** به شما امکان می‌دهد که کدام موتور هوش مصنوعی را برای کار جاری استفاده کنید.

![Model selector](../images/screenshots/fa/model-selector.png)

برخی از مدل‌های رایگان ممکن است همیشه در دسترس نباشند — گاهی اوقات آفلاین هستند یا سقف استفاده دارند. اگر این اتفاق بیفتد، برنامه به طور خودکار آن مدل را از لیست در دسترس شما حذف می‌کند. برای کنترل مدل‌هایی که نمایش داده می‌شوند، به [**تنظیمات** > **مدل‌ها**](#models) بروید و لیست مدل‌های خود را ویرایش کنید.
همچنین می‌توانید تنظیمات مدل را مستقیماً با کلیک روی آیکون ارائه‌دهنده در سمت چپ نام مدل در نوار ابزار باز کنید.

<br/>

**آیکون کره زمین + کد زبان** زبان رابط برنامه، مانند منوها و دکمه‌ها را تغییر می‌دهد. این کار **زبان‌های ترجمه** استفاده شده در **ترجمه** را تغییر نمی‌دهد.

![Interface language selector](../images/screenshots/fa/language-selector.png)

<a id="input-and-output-panels"></a>
### پنل‌های ورودی و خروجی

اکثر فضاهای کاری از یک پنل **ورودی** در سمت چپ و یک پنل **خروجی** در سمت راست استفاده می‌کنند.

هر پنل همچنین موارد زیر را نمایش می‌دهد:

| **ورودی**                                                          | **خروجی**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - تعداد کاراکتر <br/>- تعداد کلمه <br/>- تعداد پاراگراف   <br/> | - مدت زمان انجام کار<br/>- **TPS** (رسانه ها در ثانیه)<br/>- تعداد کاراکتر، کلمه و پاراگراف<br/>- مدل استفاده شده |

اگر در مورد اصطلاحات فنی سوال دارید:

- **رسانه** به معنای یک تکه کوچک از متن است. می‌توانید آن را بخشی از یک کلمه یا یک کلمه کوتاه در نظر بگیرید.
- **TPS** به این معناست که مدل در هر ثانیه چند تا از این تکه‌های متنی را پردازش کرده است.

<br/>

همچنین می‌توانید هزینه هر عملیات (در صورت در دسترس بودن) و هزینه کل را نظارت کنید و با فعال‌سازی گزینه `نمایش اطلاعات هزینه در عملیات` در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) آن را مشاهده کنید.

<a id="translate"></a>
## ترجمه

از **ترجمه** زمانی استفاده کنید که بخواهید متنی را از یک زبان به زبان دیگر تبدیل کنید.

![Translate workspace](../images/screenshots/fa/translate.png)

<br/>

<a id="translate-text"></a>
### ترجمه متن

1. **ترجمه** را باز کنید.
2. زبانی را در **از** انتخاب کنید.
3. زبانی را در **به** انتخاب کنید.
4. مدلی را در نوار ابزار انتخاب کنید.
5. متن را در **ورودی** تایپ یا بچسبانید.
6. روی **ترجمه** کلیک کنید.
7. نتیجه را در **خروجی** بخوانید.
8. اگر می‌خواهید نتیجه را کپی کنید، از دکمه کپی استفاده کنید.

<br/>

<a id="language-selection"></a>
### انتخاب زبان

- **از** می‌تواند یک زبان خاص یا **تشخیص زبان** باشد.
- **به** زبانی است که می‌خواهید نتیجه در آن باشد.

زبان‌های **برتر انتخاب شده** شما در بالای لیست نمایش داده می‌شوند. می‌توانید آن‌ها را در [**تنظیمات** > **زبان‌ها**](#languages) تنظیم کنید.

<br/>

<a id="helpful-translation-settings"></a>
### تنظیمات مفید ترجمه

<a id="rewrite"></a>
## بازنویسی

از **بازنویسی** زمانی استفاده کنید که بخواهید بیان متن را بهبود بخشیده بدون اینکه معنای اصلی تغییر کند.

![Rewrite workspace](../images/screenshots/fa/rewrite.png)

این قابلیت برای موارد زیر مفید است:

- رفع اشکالات املایی و دستوری (**بررسی املایی و دستوری**)
- شفاف‌تر کردن متن (**افزایش وضوح**)

<a id="transform"></a>
## تبدیل

از **تبدیل** زمانی استفاده کنید که بخواهید هوش مصنوعی دستورالعمل‌های سفارشی شما را دنبال کند.

![Transform workspace](../images/screenshots/fa/transform.png)

این بخش انعطاف‌پذیرترین قسمت برنامه است. می‌توانید از آن برای کارهایی مانند:

- خلاصه‌سازی یادداشت‌ها
- تبدیل متن خام به ایمیل حرفه‌ای
- استخراج نکات کلیدی
- تبدیل متن به یک قالب خاص
- هر فعالیت سفارشی دیگری با متن ورودی استفاده کنید

<br/>

<a id="run-an-existing-prompt"></a>
### اجرای یک دستور موجود

1. بخش **تبدیل** را باز کنید.
2. یک دستور را از لیست دستورات انتخاب کنید.
3. اگر کادر **هدف** زبان ظاهر شد، در صورت تمایل زبانی را انتخاب کنید.
4. متن را در بخش **ورودی** تایپ یا بچسبانید.
5. روی **تبدیل** کلیک کنید.
6. نتیجه را در بخش **خروجی** بخوانید.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### اگر هنوز دستوری ندارید

اگر لیست دستورات شما خالی است، در فضای کار تبدیل روی **بارگذاری پرسش‌های نمونه** کلیک کنید. همین گزینه همیشه در بخش [**تنظیمات** > **دستورات تبدیل**](#transform-prompts) در سطر صادرات/واردات در دسترس است. هر دوی این گزینه‌ها نمونه‌های داخلی را اضافه می‌کنند تا بتوانید سریع شروع کنید.

<br/>

> ℹ️ **توجه**<br/>
> دستورات نمونه به زبان انگلیسی ارائه می‌شوند. پس از بارگیری، می‌توانید یک دستور را ویرایش کرده و از **درخواست ترجمه** برای ترجمه آن به زبان خود استفاده کنید.

<br/>

<a id="create-a-prompt-quickly"></a>
### ایجاد سریع یک دستور

سریع‌ترین راه برای ایجاد یک دستور این است:

1. روی **دستور جدید** کلیک کنید.
2. روی **تولید پرامپت** کلیک کنید.
3. توضیح دهید که می‌خواهید دستور چه کاری انجام دهد.
4. یک مدل را انتخاب کنید.
5. اجازه دهید برنامه یک پیش‌نویس برای شما ایجاد کند.
6. پیش‌نویس را بررسی کرده و روی **ذخیره** کلیک کنید.

![Generate prompt](../images/screenshots/fa/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ویرایش یک دستور

هنگامی که یک دستور ایجاد یا ویرایش می‌کنید، ویرایشگر در سمت چپ نمایش داده می‌شود و یک ناحیه تست در سمت راست ظاهر می‌شود.

![Transform prompt editor](../images/screenshots/fa/transform-prompt-edit.png)

فیلدهای اصلی عبارتند از:

- **نام دستور**: نامی که در لیست دستورات نمایش داده می‌شود.
- **دستورالعمل‌های دستور (اختیاری)**: یک راهنمای کوتاه که هنگام اجرای دستور به کاربر نمایش داده می‌شود.
- **نقش مدل**: نقش کلی که به هوش مصنوعی داده می‌شود، مانند «شما یک دستیار مفید هستید.»
- **دستورالعمل‌های مدل (هر دستور در یک خط)**: قوانین خاصی که می‌خواهید هوش مصنوعی دنبال کند.
- **توضیح خروجی**: یک کلمه کوتاه که نتیجه را توصیف می‌کند، مانند «خلاصه» یا «بازنویسی».
- **دما (0.0 → 1.0)**: نحوه رفتار مدل؛ به توضیحات زیر مراجعه کنید.
- **درخواست زبان مقصد**: هنگام اجرای دستور، یک انتخاب‌گر زبان مقصد اضافه می‌کند.

اگر اصطلاح فنی **دما** برای شما جدید است، آن را به این صورت در نظر بگیرید:

- **دما پایین‌تر** نتایج پایدارتر و قابل پیش‌بینی‌تری ایجاد می‌کند.
- **دما بالاتر** تنوع و خلاقیت بیشتری ایجاد می‌کند.

همچنین می‌توانید از موارد زیر استفاده کنید:

- **`ایجاد دستور`** برای ساخت یک پیش‌نویس جدید از یک توصیف ساده
- **`بهبود دستور`** برای اصلاح یک دستور موجود
- **`ترجمه دستور`** برای ترجمه فیلدهای دستور

<br/>

> ⚠️ **هشدار**<br/>
> قبل از کلیک کردن روی **`بازگشت به اجرا`**، روی **`ذخیره`** کلیک کنید. اگر بدون ذخیره بازگردید، تغییرات شما از بین خواهند رفت.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### تست یک دستور قبل از استفاده

پنل تست در سمت راست به شما امکان می‌دهد دستور خود را با متن نمونه قبل از استفاده در کارهای روزمره آزمایش کنید.

این کار در موارد زیر مفید است:

- هنگام ساخت یک دستور جدید
- هنگام مقایسه دو نسخه از یک دستور
- هنگامی که می‌خواهید لحن، طول یا قالب خروجی را بررسی کنید

<br/>

> ℹ️ **یادداشت**<br/>
> می‌توانید دستورات ذخیره‌شده را در [**تنظیمات** > **دستورات تبدیل**](#transform-prompts) صادر و وارد کنید.

![Dashboard filters](../images/screenshots/fa/dashboard-filter.png)

<br/>

> ℹ️ **یادداشت**<br/>
> فیلتر **کاربر** فقط برای مدیران در نسخه وب قابل مشاهده است. کاربران عادی این فیلتر را نمی‌بینند و در برنامه دسکتاپ نیز این فیلتر در دسترس نیست.

<br/>

<a id="dashboard-tabs"></a>
### زبانه‌های داشبورد

- **خلاصه** به شما مروری از مصرف و هزینه‌ها می‌دهد. شامل **مصرف در طول زمان** (تعداد تجمعی تماس‌ها به صورت روزانه برای ترجمه، بازنویسی و تبدیل) و **مصرف بر اساس مدل** (مجموع **تماس‌ها به ازای هر مدل**، شامل تبدیل) می‌شود.
- **بر اساس مصرف** فعالیت‌ها را بر اساس زبان ترجمه، حالت بازنویسی و درخواست پرامت تقسیم‌بندی می‌کند.
- **بر اساس مدل** نشان می‌دهد از کدام مدل‌ها استفاده کرده‌اید و هزینه آن‌ها چقدر بوده است.
- **بر اساس روز** مجموع‌های روزانه را نشان می‌دهد.
- **تمام تماس‌ها** تاریخچه کامل تماس‌ها را نشان می‌دهد و امکان صادرات آن را فراهم می‌کند.

> ⚠️ **هشدار**<br/>

برای حذف تمام داده‌ها یا حذف رکوردها بر اساس مدت زمان، به [**تنظیمات** > **پیگیری هزینه**](#cost-tracking) بروید. در آنجا گزینه‌هایی برای حذف تمام داده‌های ذخیره‌شده یا فقط داده‌های قدیمی‌تر از یک تاریخ مشخص وجود دارد.

<a id="general-settings"></a>
### تنظیمات عمومی

از **تنظیمات عمومی** برای کنترل رفتار تایپ، ذخیره‌سازی جزئیات اجرا برای **تاریخچه** و تنظیم ظاهر استفاده کنید.

**رفتار**

- **رفتار برای ENTER** مشخص می‌کند که کلید `Enter` آیا وظیفه را اجرا می‌کند یا یک خط جدید وارد می‌کند.
- **ترجمه خودکار هنگام جای‌گذاری** به محض چسباندن متن، ترجمه را شروع می‌کند.
- **کپی خودکار نتیجه در کلیپ‌برد** به طور خودکار نتایج موفق را کپی می‌کند.
- **ترجمه لحظه‌ای (در حین تایپ)** در حال تایپ شما ترجمه انجام می‌دهد.
- **مهلت زمانی (ms)** زمان انتظار برای ترجمه لحظه‌ای را تنظیم می‌کند.

**تاریخچه**

- **نگهداری تاریخچه اجرا** کنترل می‌کند که آیا هر ترجمه، بازنویسی و تبدیل، **متن ورودی و خروجی** را برای نمایش در بخش [**تاریخچه**](#history) ذخیره کند یا خیر. غیرفعال کردن این گزینه درخواست تأیید می‌کند؛ در صورت تأیید، متن‌های ذخیره‌شده از پایگاه داده حذف می‌شوند.
- **حذف داده‌های تاریخچه** به شما امکان می‌دهد تا متن‌های ذخیره‌شده را بر اساس سن (مثلاً قدیمی‌تر از چند ماه، یا **همه داده‌ها (پاک کردن)**) با استفاده از **حذف داده** حذف کنید. این عمل فقط بر روی متن‌های اجرای ذخیره‌شده برای نمایش **تاریخچه** تأثیر می‌گذارد و **بر روی** کل هزینه یا جمع کل استفاده تأثیری ندارد. برای حذف یا کاهش داده‌های **هزینه**، از [**تنظیمات** > **پیگیری هزینه**](#cost-tracking) استفاده کنید.

**ظاهر**

- **نمایش اطلاعات هزینه در عملیات‌ها** نمایش هزینه هر عملیات (در صورت موجود بودن) و هزینه کل را در پنل‌های خروجی **ترجمه**، **بازنویسی** و **تبدیل** کنترل می‌کند.
- **تعداد ارقام اعشار هزینه** نحوه نمایش اعشار هزینه را تغییر می‌دهد.
- **فقط وب:** **نمایش حاشیه حول برنامه** فضای اضافی حول رابط کاربری ایجاد می‌کند.
- **خانواده قلم** قلم نوشتن را در پنل‌های متن تغییر می‌دهد.
- **اندازه** اندازه قلم را تغییر می‌دهد.

**پشتیبان‌گیری پیکربندی**

- **شامل داده‌های استفاده در پشتیبان** — در صورت فعال بودن، فایل ZIP شامل تاریخچه اجرا و داده‌های تماس API نیز می‌شود.
- **پشتیبان‌گیری از پیکربندی** — یک فایل ZIP واحد ایجاد می‌کند (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` به صورت پیش‌فرض در زمان UTC) که شامل `config.json`، `state.json`، کلید رمزگذاری اختیاری، کاربران، ترجیحات، دستورات سفارشی و داده‌های استفاده (در صورت انتخاب) می‌شود. پس از پشتیبان‌گیری موفق، نام فایل ذخیره‌شده نمایش داده می‌شود.
- **بازیابی از پشتیبان** — ابتدا یک **پنجره تأیید** باز می‌کند. فایل ZIP پشتیبان را درون این پنجره انتخاب کنید (**مرور** / انتخاب فایل یا کشیدن و رها کردن در صورت پشتیبانی)، سپس گزینه‌ها را بررسی کنید:
  - **بازیابی داده‌های استفاده** — داده‌های استفاده/تاریخچه از زمانی که پشتیبان با شامل داده‌های استفاده گرفته شده بود را وارد می‌کند؛ در صورتی که فقط می‌خواهید تنظیمات و دستورات را بازیابی کنید، این گزینه را غیرفعال بگذارید.
  - **پاک کردن داده‌های قدیمی استفاده قبل از بازیابی** — داده‌های موجود استفاده/تاریخچه در این نصب را قبل از اعمال پشتیبان حذف می‌کند (اختیاری؛ زمانی استفاده شود که می‌خواهید جایگزینی کامل انجام دهید).

پشتیبان‌هایی که در نسخه وب یا دسکتاپ ایجاد شده‌اند، می‌توانند در نسخه دیگر بازیابی شوند. هنگام بازیابی یک پشتیبان دسکتاپ در نسخه وب، داده‌ها به کاربر مدیر بازیابی می‌شوند.

<a id="models"></a>
### مدل‌ها

از **تنظیمات** > **مدل‌ها** برای انتخاب مدل‌هایی که در نوار ابزار نمایش داده می‌شوند استفاده کنید.

![Settings Models tab](../images/screenshots/fa/settings-models.png)

این صفحه دو لیست دارد:

- **مدل‌های موجود** در سمت چپ
- **مدل‌های انتخاب شده** در سمت راست

کنترل‌های مفید شامل:

- **جستجوی مدل‌ها...** برای یافتن مدل بر اساس نام
- چیپ‌های **ارائه‌دهنده** برای محدود کردن لیست به یک موتور (OpenRouter، OpenAI، Ollama، …)
- **فقط رایگان** برای نمایش فقط مدل‌های رایگان
- **تازه‌سازی** برای بارگیری مجدد لیست
- **باز کردن همه** و **بستن همه** هنگامی که لیست را بر اساس ارائه‌دهنده مرتب می‌کنید

شناسه‌های مدل شامل پیشوند ارائه‌دهنده هستند (برای مثال `openrouter/…` در مقابل `openai/…`). نشان‌ها مانند **OpenAI (OpenRouter)** در مقابل **OpenAI (مستقیم)** نحوه مسیریابی ترافیک را نشان می‌دهند.

> ℹ️ **توجه**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) یک مدل مسیریاب است، نه یک مدل چت عمومی: پاسخ آن جیسونی است که بدنه درخواست‌های API OpenRouter را توصیف می‌کند (برای مثال یک آرایه `requests` با `model` و `messages`). اگر از آن برای **ترجمه**، **بازنویسی** یا **تبدیل** استفاده کنید، پنل خروجی آن جیسون را نشان می‌دهد نه متن نهایی. برای این وظایف یک مدل متنی معمولی انتخاب کنید. صفحه مدل [Body Builder](https://openrouter.ai/openrouter/bodybuilder) را در OpenRouter ببینید.

اقدامات:

- برای اضافه کردن یک مدل، روی **اضافه کردن** یا هر جای دیگر در آن سطر کلیک کنید.

- برای حذف یک مدل، روی **X** کنار آن در بخش **مدل‌های انتخاب شده** یا روی **انتخاب شده** در بخش مدل‌های موجود کلیک کنید.

- برای پاک کردن لیست، روی **حذف همه انتخاب‌ها** کلیک کنید. مدل رایگان اجباری در لیست باقی می‌ماند.

<br/>

> ℹ️ **توجه**<br/>
> اگر نمی‌خواهید بلافاصله اعتبار به OpenRouter اضافه کنید، با فعال کردن گزینه **فقط رایگان** شروع کنید و مدل‌های رایگان را انتخاب کنید (نیازی به کارت اعتباری نیست). همچنین می‌توانید از Ollama برای اجرای مدل‌ها به صورت محلی بدون نیاز به کلید API استفاده کنید.

<br/>

<a id="languages"></a>
### زبان‌ها

از **تنظیمات** > **زبان‌ها** برای سازماندهی لیست زبان‌های مورد استفاده در برنامه استفاده کنید.

- **زبان‌های برتر** در بالای لیست زبان‌ها در بخش‌های **ترجمه** و **تبدیل** ثابت می‌شوند.
- **زبان سفارشی** به شما امکان می‌دهد زبانی را که در لیست داخلی وجود ندارد اضافه کنید.

اگر یک زبان سفارشی اضافه کنید، در انتخاب‌گرهای زبان کنار گزینه‌های داخلی ظاهر می‌شود.

<a id="cost-tracking"></a>
### پیگیری هزینه

از **تنظیمات** > **پیگیری هزینه** برای مدیریت اطلاعات هزینه استفاده کنید.

- **هزینه کل** مجموع در حال اجرا را نشان می‌دهد.
- **کپی مقدار** مجموع را به کلیپ‌بورد کپی می‌کند.
- **بازنشانی هزینه** مجموع ذخیره شده را به صفر بازمی‌گرداند.
- **همگام‌سازی با مصرف کلید API** مجموع را برابر با مصرف گزارش شده توسط حساب OpenRouter شما تنظیم می‌کند (فقط OpenRouter).
- **مصرف کلید API** جزئیات مصرف OpenRouter را در صورت موجود بودن نشان می‌دهد.
- **حذف داده‌های هزینه** تمام داده‌ها یا فقط ورودی‌های قدیمی‌تر از یک تاریخ انتخاب شده را حذف می‌کند.

**پیگیری هزینه:** هنگامی که از مدل‌های OpenRouter استفاده می‌کنید، برنامه میزان مصرف واقعی و هزینه شما را بر اساس اطلاعات هزینه از OpenRouter نشان می‌دهد. برای تمام ارائه‌دهندگان دیگر، برنامه هزینه‌ها را با استفاده از قیمت‌های منتشر شده توسط OpenRouter تخمین می‌زند، اگر قیمتی در دسترس نباشد، تخمین ممکن است صفر باشد.

<br/>

> ℹ️ **توجه**<br/>
> تمام ارقام هزینه فقط برای اطلاع شما تخمین زده شده‌اند و بیانیه رسمی صورتحساب نیستند.

<br/>

> ⚠️ **هشدار**<br/>
> حذف داده‌ها غیرقابل بازگشت است. قبل از حذف، مطمئن شوید داده‌های خود را پشتیبان گرفته یا از طریق [**تاریخچه**](#history)
> یا [**داشبورد** > **تمام تماس‌ها**](#dashboard-tabs) صادر کرده‌اید، در غیر این صورت داده‌ها به طور دائم از بین خواهند رفت.
> تمام تاریخچه ورودی/خروجی مربوط به هر ورودی تماس API نیز حذف خواهد شد.

<br/>

<a id="api-config"></a>
### پیکربندی API

ارائه‌دهندگان پشتیبانی‌شده عبارتند از: OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و **Ollama** (مدل‌های محلی از طریق یک نشانی پایه). شما فقط نیاز دارید ارائه‌دهندگانی را که استفاده می‌کنید پیکربندی کنید.

**برنامه وب: فقط مدیر**

کلیدهای API از طریق متغیرهای محیطی سیستم یا داکر پیکربندی می‌شوند — این کلیدها در رابط کاربری وب وارد نمی‌شوند. این صفحه نشان می‌دهد کدام ارائه‌دهندگان کلید پیکربندی‌شده دارند و به شما امکان می‌دهد هر یک را با کلیک روی دکمه **`تست`** آزمایش کنید.

<br/>

> ℹ️ **توجه**<br/>
> برای تغییر یک کلید API، متغیر محیطی را در پیکربندی سیستم یا داکر به‌روز کنید و سرور یا کانتینر را مجدداً راه‌اندازی کنید.

> ℹ️ **توجه**<br/>
> **پشتیبان‌گیری پیکربندی** (نگاه کنید به [**تنظیمات عمومی** → پشتیبان‌گیری پیکربندی](#general-settings)) می‌تواند کلیدهای ارائه‌دهنده **حل‌شده** را درون فایل `config.json` داخل ZIP قرار دهد. بازیابی این فایل ZIP، این کلیدها را به فایل پیکربندی ذخیره‌شده سرور کپی نمی‌کند — کلیدهای فعال همچنان از محیط و وضعیت فایل موجود به‌صورت توصیف‌شده استخراج می‌شوند.

<br/>

**برنامه دسکتاپ**

از بخش **پیکربندی API** برای ذخیره کلیدهای API هر ارائه‌دهنده استفاده کنید. برای Ollama، به جای کلید API، **نشانی پایه** را وارد کنید.

<br/>

> 💡 **نکته** <br/>
> اگر نمی‌خواهید از کلید API استفاده کنید یا هزینه پردازش را بپردازید، می‌توانید [Ollama را دانلود کنید](https://ollama.com) و مدل‌ها (مانند `translategemma:4b`) را به صورت محلی و رایگان روی دستگاه خود اجرا کنید. همچنین می‌توانید یک حساب رایگان OpenRouter ایجاد کنید (نیاز به کارت اعتباری ندارد) تا از مدل‌های رایگان آن استفاده کنید، یا یک کلید API رایگان از Cerebras، Google، Groq یا Mistral AI دریافت کنید.

<br/>

- فقط ارائه‌دهندگانی را اضافه کنید که به آن‌ها نیاز دارید. در بخش **تنظیمات** > **مدل‌ها**، هر شناسه مدل با نام ارائه‌دهنده شروع می‌شود (برای مثال `openrouter/openrouter/free`، `openai/gpt-4o`، `ollama/llama3`).

برای افزودن یک کلید API، مقدار آن را در کادر متنی وارد کرده و روی **`ذخیره`** کلیک کنید. برای جایگزینی یک کلید موجود، روی **`ویرایش`** کلیک کنید. برای بررسی صحت کارکرد یک کلید، روی **`تست`** کلیک کنید. برای نشانی پایه Ollama، همیشه روی **`تست`** کلیک کنید تا اتصال بررسی شود.

<br/>

> ℹ️ **توجه**<br/>
> شما نمی‌توانید مقدار فعلی یک کلید API را مشاهده کنید. تنها می‌توانید آن را با استفاده از دکمه **`ویرایش`** جایگزین کنید.
> کلیدهای API به صورت رمزگذاری‌شده در پیکربندی ذخیره می‌شوند.

<a id="common-issues"></a>
## مشکلات رایج

اگر چیزی به درستی کار نمی‌کند، ابتدا موارد زیر را بررسی کنید.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### برنامه متن را ترجمه، بازنویسی یا تبدیل نمی‌کند

مطمئن شوید که:

- یک مدل را در نوار ابزار انتخاب کرده‌اید
- حداقل یک مدل در بخش [**تنظیمات** > **مدل‌ها**](#models) فهرست شده است
- پیکربندی API شما به درستی کار می‌کند

اگر از برنامه دسکتاپ استفاده می‌کنید:

1. [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید.
2. مطمئن شوید حداقل یک کلید API ذخیره شده است.
3. برای تأیید صحت کلید، روی دکمه **تست** کنار ارائه‌دهنده کلیک کنید.

<br/>

<a id="the-model-list-is-empty"></a>
### لیست مدل‌ها خالی است

[**تنظیمات** > **مدل‌ها**](#models) را باز کرده و روی **تازه‌سازی** کلیک کنید.

در صورت نیاز:

- مدلی را جستجو کنید
- گزینه **فقط رایگان** را فعال کنید
- یک یا چند مدل را به بخش **مدل‌های انتخاب شده** اضافه کنید

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### نتیجه بسیار کند یا گران است

یک یا چند مورد از موارد زیر را امتحان کنید:

- یک مدل دیگر انتخاب کنید
- از ورودی کوتاه‌تر استفاده کنید
- گزینه **ترجمه لحظه‌ای (در حین تایپ)** را در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) غیرفعال کنید
- برای کارهای ساده از مدل‌های رایگان استفاده کنید (نگاه کنید به [مدل‌ها](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### رابط به زبان اشتباه است

روی آیکون کره جهانی در [نوار ابزار](#toolbar) کلیک کرده و **زبان رابط** مورد نظر خود را انتخاب کنید.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### متن بسیار کوچک یا خواندن آن دشوار است

[**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کرده و موارد زیر را تغییر دهید:

- **خانواده قلم**
- **اندازه**

<br/>

<a id="dashboard-charts-are-empty"></a>
### نمودارهای داشبورد خالی هستند

این موضوع در صورت زیر طبیعی است:

- فقط از **مدل‌های رایگان** استفاده می‌کنید و به دنبال ارقام **هزینه** هستید (که ممکن است صفر باشد)؛ نمودارهای شمارش تماس در بخش **خلاصه** همچنان به داده‌های دوره انتخاب شده نیاز دارند
- **فیلتر زمانی** انتخاب شده شامل دوره‌ای که تماس‌ها در آن انجام شده نیست — برای بررسی، گزینه **همه** را امتحان کنید

اگر پس از انتخاب **همه** نمودارها همچنان خالی بودند، تأیید کنید که تماس‌ها در [**تاریخچه**](#history) یا در برگهٔ **تمام تماس‌ها** نمایش داده می‌شوند.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### هزینه نمایش داده شده «در دسترس نیست» یا اشتباه به نظر می‌رسد

هنگامی که از مدل‌ها از طریق **OpenRouter** استفاده می‌کنید، برنامه میزان هزینهٔ واقعی شما را که توسط OpenRouter گزارش شده نمایش می‌دهد.

برای **سایر ارائه‌دهندگان** (مثل OpenAI مستقیم، Anthropic مستقیم و غیره)، هزینه بر اساس داده‌های قیمت‌گذاری منتشر شده توسط OpenRouter **تخمین زده می‌شود**. اگر قیمت متناسبی برای یک مدل یافت نشود، هزینه به صورت **در دسترس نیست** نمایش داده می‌شود و به مجموع هزینهٔ شما اضافه نخواهد شد.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### هزینه کل با صورتحساب ارائه‌دهنده من مطابقت ندارد

تمام ارقام هزینه در این برنامه **فقط برای مرجع و تخمینی** هستند و بیانیه‌های رسمی صورتحساب محسوب نمی‌شوند.

برای نزدیک‌تر کردن مجموع به هزینه واقعی شما در OpenRouter، [**تنظیمات** > **پیگیری هزینه**](#cost-tracking) را باز کرده و روی **همگام‌سازی با مصرف کلید API** کلیک کنید.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### صفحه تاریخچه در نوار کناری وجود ندارد

ممکن است گزینهٔ **نگهداری تاریخچه اجرا** غیرفعال باشد. [**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کرده و آن را فعال کنید. توجه داشته باشید که فعال کردن این گزینه، داده‌های تاریخچهٔ حذف شدهٔ قبلی را بازیابی نمی‌کند.

<br/>

<a id="web-app-session-expired"></a>
### برنامه تحت وب: به صورت غیرمنتظره به صفحه ورود هدایت می‌شوید

ممکن است جلسه شما منقضی شده باشد. دوباره وارد شوید. اگر این اتفاق اغلب رخ دهد، تنظیمات زمان عمر جلسه در پیکربندی سرور را بررسی کنید.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### مدیر وب: رمز عبور را فراموش کرده یا از دست داده‌ام

این مورد مربوط به **برنامه تحت وب خودمیزبان** (Docker) است، نه برنامه دسکتاپ (Electron).

- اگر مدیر دیگری همچنان می‌تواند وارد شود، می‌تواند به [**تنظیمات** > **کاربران**](#users) رفته، حساب مورد نظر را انتخاب کند و یک **رمز عبور جدید** تنظیم کند.
- اگر **قفل شده‌اید** اما **دسترسی به خط فرمان** (shell) دستگاه یا کانتینر دارید، رمز عبور را با ابزار کمکی که همراه تصویر ارائه می‌شود بازنشانی کنید (در صورت تغییر نام پیش‌فرض، `transrewrt` را جایگزین کنید و اگر رمز عبور شامل فاصله یا کاراکترهای خاص است، آن را در گیومه قرار دهید):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

اگر هرگز حساب دیگری ایجاد نکرده‌اید، نام کاربری پیش‌فرض مدیر `admin` است. هنگامی که فقط یک آرگومان ارسال کنید، به عنوان رمز عبور جدید برای `admin` در نظر گرفته می‌شود.

اگر به جای Docker از **کد منبع** استفاده می‌کنید، از دستور زیر استفاده کنید:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

این اسکریپت رکورد کاربر را در پایگاه داده SQLite به‌روزرسانی می‌کند (و در صورت عدم وجود، کاربر `admin` را ایجاد می‌کند). پس از بازنشانی، با رمز عبور جدید وارد شوید.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### داشبورد داده‌ای برای سایر کاربران نمایش نمی‌دهد (وب)

فقط **مدیران** می‌توانند از طریق فیلتر **کاربر** داده‌های تمام کاربران را مشاهده کنند. کاربران معمولی به‌طور طراحی فقط فعالیت خود را می‌بینند.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### دستور را تغییر دادم و ویرایش‌ها از دست رفتند

هنگام ویرایش یک دستور، همیشه قبل از کلیک کردن روی **بازگشت به اجرا**، روی **ذخیره** کلیک کنید.

<a id="quick-tips"></a>
## نکات سریع

- با [**ترجمه**](#translate) شروع کنید تا مطمئن شوید تنظیمات شما کار می‌کند، قبل از اینکه به سراغ [**بازنویسی**](#rewrite) یا [**تبدیل**](#transform) بروید.
- از [**بازنویسی**](#rewrite) برای بهبود روزمره عبارات استفاده کنید.
- از [**تبدیل**](#transform) زمانی استفاده کنید که به یک گردش کار قابل تکرار برای یک وظیفه خاص نیاز داشته باشید.
- در صورتی که می‌خواهید میزان استفاده و هزینه را زیر نظر داشته باشید، از [**داشبورد**](#dashboard) استفاده کنید.
- از [**تاریخچه**](#history) برای بررسی عملیات گذشته و متن کامل ورودی/خروجی آنها استفاده کنید.
- اگر در حال ساخت کتابخانه‌ای از دستورات هستید که می‌خواهید از آن محافظت کنید (به [دستورات تبدیل](#transform-prompts) مراجعه کنید) یا قصد به اشتراک‌گذاری آن با دیگران را دارید، دستورات را به‌طور منظم صادر کنید.
