# راهنمای کاربر Transrewrt

<br />

<a id="introduction"></a>
## مقدمه

Transrewrt به شما در کار با متن به سه روش اصلی کمک می‌کند:

- **ترجمه** - تبدیل متن از یک زبان به زبان دیگر.
- **بازنویسی** - بازسازی متن با سبک متفاوت، مانند واضح‌تر، کوتاه‌تر یا رسمی‌تر.
- **تبدیل** - پردازش متن با استفاده از دستورات سفارشی هوش مصنوعی به نام پرامپت‌ها.

<br />

این راهنما نحوه استفاده از برنامه پس از نصب و اجرای آن را توضیح می‌دهد. برای مراحل نصب، فایل اصلی [README](../README.md) را مطالعه کنید.

<br />

> ℹ️ **توجه**<br/>
> Transrewrt به‌عنوان یک برنامه دسکتاپ برای ویندوز و لینوکس و به‌عنوان یک وب‌اپلیکیشن خودمیزبان در دسترس است. این راهنما بر استفاده روزمره از برنامه تمرکز دارد. در جایی که چیزی فقط برای یک نسخه اعمال می‌شود، به وضوح مشخص شده است.

<a id="before-you-start"></a>

## قبل از شروع

برای استفاده از Transrewrt، به دسترسی به سرویس AI از طریق OpenRouter نیاز دارید.

قبل از شروع نیازی به انتخاب یک مدل پولی ندارید. این برنامه همیشه شامل یک مدل **رایگان** داخلی است، بنابراین برای استفاده معمولی کافی است که شروع به ترجمه، بازنویسی و تبدیل متن کنید.

به زبان ساده:

- یک **مدل** موتور AI است که کار را انجام می‌دهد.
- یک **کلید API** اعتبار دسترسی شخصی شما برای آن سرویس است.

اگر از ** برنامه دسکتاپ** استفاده می‌کنید، به یک کلید API نیاز خواهید داشت. برای مراحل دقیق، به بخش [چگونه یک کلید API دریافت کنیم (برنامه دسکتاپ)](#how-to-get-an-api-key-desktop-app) زیر مراجعه کنید. به طور خلاصه: در [OpenRouter](https://openrouter.ai) یک حساب کاربری ایجاد کرده یا وارد شوید، صفحه [کلیدها](https://openrouter.ai/keys) را باز کنید، یک کلید جدید ایجاد کنید و آن را در بخش [**Settings** > **API Config**](#api-config) در Transrewrt جایگزین کنید.

اگر از **نسخه وب** استفاده می‌کنید، معمولاً مالک سرور این تنظیمات را برای شما انجام می‌دهد، بنابراین به طور معمول خودتان نیازی به وارد کردن کلید API ندارید.

<br />

<a id="how-to-get-an-api-key-desktop-app"></a>
### چگونه یک کلید API دریافت کنیم (برنامه دسکتاپ)

اگر از برنامه دسکتاپ استفاده می‌کنید، این مراحل را دنبال کنید:

1. در مرورگر وب خود به [OpenRouter](https://openrouter.ai) بروید.
2. یک حساب کاربری ایجاد کنید یا وارد شوید.
3. صفحه [کلیدها](https://openrouter.ai/keys) را باز کنید.
4. روی دکمه ایجاد کلید API جدید کلیک کنید.
5. به کلید یک نام بدهید تا بعداً بتوانید آن را تشخیص دهید.
6. کلید API جدید را کپی کنید.
7. به Transrewrt بازگردیده و **Settings** > **API Config** را باز کنید.
8. کلید را در **OpenRouter API Key** جایگزین کنید.
9. روی **Test API Configuration** کلیک کنید تا از کارکرد آن مطمئن شوید.

> ℹ️ **توجه**<br/>
> می‌توانید باentie رایگان OpenRouter یا هر یک از مدل‌های رایگان دیگر شروع کنید. در بسیاری موارد، این برای شروع استفاده از Transrewrt بدون انتخاب مدل پولی کافی است.

<br /><br />

<a id="getting-started"></a>
## شروع کار

اگر این اولین بار است که از Transrewrt استفاده می‌کنید، این ترتیب را دنبال کنید:

1. برنامه را باز کنید.
2. در صورت نیاز، **زبان رابط** خود را از آیکون گلوله انتخاب کنید.
3. اگر روی **برنامه دسکتاپ** هستید، [**Settings** > **API Config**](#api-config) را باز کرده، کلید OpenRouter API خود را جایگزین کرده و روی **Test API Configuration** کلیک کنید.
4. [**Settings** > **Models**](#models) را باز کرده و یک یا چند مدل را به **Selected Models** اضافه کنید.
5. [**Settings** > **Languages**](#languages) را باز کرده و **Top languages** خود را انتخاب کنید اگر می‌خواهید زبان‌های مورد استفاده بیشترتان اول بیایند.
6. به **Translate** بروید و یک ترجمه ساده انجام دهید تا از عملکرد همه چیز مطمئن شوید.
7. پس از اینکه کار کرد، **Rewrite** و سپس **Transform** را امتحان کنید.

این ترتیب مهم است. این از رایج‌ترین مشکل اولیه جلوگیری می‌کند: Attempt کردن اجرای یک کار قبل از اینکه برنامه یک اتصال API در حال کار یا مدل انتخاب‌شده داشته باشد.

### نوار ابزار

نوار ابزار بسته به جایی که در برنامه هستید، کمی تغییر می‌کند.

- در سمت چپ، نام صفحه فعلی را نشان می‌دهد.
- در سمت راست، **سلکتور مدل** و کنترل **زبان رابط** را نشان می‌دهد.

**سلکتور مدل** به شما امکان می‌دهد哪 موتور AI مورد استفاده برای کار فعلی را انتخاب کنید.

**آیکون گلوله + کد زبان** زبان رابط برنامه، مانند منوها و دکمه‌ها را تغییر می‌دهد. زبان‌های ترجمه‌ای که در **Translate** استفاده می‌شوند را **تغییر نمی‌دهد**.

<a id="input-and-output-panels"></a>

### پنل‌های ورودی و خروجی

اکثر فضاهای کاری از پنل **ورودی** سمت چپ و پنل **خروجی** سمت راست استفاده می‌کنند.

پنل **ورودی** موارد زیر را نشان می‌دهد:

- تعداد کاراکترها
- تعداد کلمات
- تعداد پاراگراف‌ها

پنل **خروجی** می‌تواند موارد زیر را نشان دهد:

- زمان‌گیری وظیفه
- هزینه آن وظیفه
- هزینه کل اجرایی شما
- **TPS** (توکن در ثانیه)، که یک معیار ساده سرعت است
- تعداد کاراکترها، کلمات و پاراگراف‌ها
- مدل استفاده شده

اگر در مورد اصطلاحات فنی کنجکاو هستید:

- **توکن** به معنای قطعه‌ای کوچک از متن است. می‌توانید آن را به عنوان بخشی از یک کلمه یا یک کلمه کوتاه در نظر بگیرید.
- **TPS** به معنای تعداد این قطعات متنی است که مدل هر ثانیه پردازش می‌کند.

<a id="translate"></a>
## ترجمه

از **ترجمه** زمانی که می‌خواهید متن را از یک زبان به زبان دیگر تبدیل کنید، استفاده کنید.

![فضای کاری ترجمه](../images/screenshots/fa/translate.png)

<br />

<a id="translate-text"></a>
### ترجمه متن

۱. **ترجمه** را باز کنید.
۲. یک زبان در **از** انتخاب کنید.
۳. یک زبان در **به** انتخاب کنید.
۴. یک مدل در نوار ابزار انتخاب کنید.
۵. متن را در **ورودی** تایپ یا بچسبانید.
۶. روی **ترجمه** کلیک کنید.
۷. نتیجه را در **خروجی** بخوانید.
۸. اگر می‌خواهید نتیجه را کپی کنید، از دکمه کپی استفاده کنید.

<br />

<a id="language-selection"></a>
### انتخاب زبان

- **از** می‌تواند یک زبان خاص یا **تشخیص زبان** باشد.
- **به** زبان مورد نظر شما برای نتیجه است.

زبان‌های **برتر** انتخاب شده شما در بالای لیست ظاهر می‌شوند. می‌توانید این‌ها را در [**تنظیمات** > **زبان‌ها**](#languages) تنظیم کنید.

<br />

<a id="helpful-translation-settings"></a>
### تنظیمات ترجمه مفید

در [**تنظیمات** > **تنظیمات عمومی**](#general-settings)، می‌توانید نحوه رفتار ترجمه را تغییر دهید:

- **ترجمه خودکار در چسباندن** یک ترجمه را بلافاصله پس از چسباندن متن اجرا می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد** نتیجه را به طور خودکار پس از اجرای موفقیت‌آمیز کپی می‌کند.
- **ترجمه بلادرنگ (هنگام تایپ)** ترجمه‌ها را هنگام تایپ اجرا می‌کند.
- **زمان انتظار (ms)** کنترل می‌کند که برنامه چقدر قبل از اجرای ترجمه بلادرنگ منتظر می‌ماند.

<br />

<a id="keyboard-shortcuts"></a>
### میانبرهای صفحه‌کلید

در [**تنظیمات** > **تنظیمات عمومی**](#general-settings)، **رفتار برای ENTER** کنترل می‌کند که وقتی Enter را فشار می‌دهید چه اتفاقی می‌افتد:

- **Enter** می‌تواند وظیفه را اجرا کند و **Shift+Enter** می‌تواند خط جدیدی اضافه کند.
- یا برنامه می‌تواند برعکس عمل کند.

میانبر فعلی نیز روی دکمه **ترجمه** نمایش داده می‌شود.

<a id="rewrite"></a>
## بازنویسی

از **بازنویسی** زمانی که می‌خواهید عبارت‌نویسی را بدون تغییر معنی اصلی بهبود دهید، استفاده کنید.

![فضای کاری بازنویسی](../images/screenshots/fa/rewrite.png)

این مفید است برای:

- اصلاح املاء و دستور زبان
- متن را شفاف‌تر کردن
- متن را رسمی‌تر یا غیررسمی‌تر کردن
- کوتاه‌کردن یا گسترش متن
- متن را فنی‌تر به نظر برسانید

<br />

<a id="rewrite-text"></a>
### بازنویسی متن

۱. **بازنویسی** را باز کنید.
۲. یک **حالت** انتخاب کنید.
۳. یک مدل در نوار ابزار انتخاب کنید.
۴. متن را در **ورودی** تایپ یا بچسبانید.
۵. روی **بازنویسی** کلیک کنید.
۶. نتیجه را در **خروجی** بررسی کنید.

رفتار مشابه کلید Enter که در [**ترجمه**](#keyboard-shortcuts) توضیح داده شد، در اینجا نیز اعمال می‌شود.

<a id="transform"></a>
## تبدیل

از **تبدیل** زمانی که می‌خواهید هوش مصنوعی دستورالعمل‌های سفارشی را دنبال کند، استفاده کنید.

![فضای کاری تبدیل](../images/screenshots/fa/transform.png)

این انعطاف‌پذیرترین بخش برنامه است. می‌توانید از آن برای وظایفی مانند استفاده کنید:

- خلاصه‌کردن یادداشت‌ها
- تبدیل متن خشک به یک ایمیل باکیفیت
- استخراج نکات کلیدی
- تبدیل متن به یک قالب خاص

<br />

<a id="run-an-existing-prompt"></a>
### اجرای یک دستورالعمل موجود

۱. **تبدیل** را باز کنید.
۲. یک دستورالعمل از لیست دستورالعمل‌ها انتخاب کنید.
۳. اگر کادر زبان **هدف** ظاهر شد، اگر می‌خواهید، یک زبان انتخاب کنید.
۴. متن را در **ورودی** تایپ یا بچسبانید.
۵. روی **تبدیل** کلیک کنید.
۶. نتیجه را در **خروجی** بخوانید.

<br />

<a id="if-you-have-no-prompts-yet"></a>
### اگر هیچ دستورالعمل‌ای ندارید

اگر لیست دستورالعمل‌ها شما خالی است، روی **بارگزاری نمونه دستورالعمل‌ها** کلیک کنید. این نمونه‌های داخلی را اضافه می‌کند تا بتوانید به سرعت شروع کنید.

> ℹ️ **توجه**<br/>
> نمونه دستورالعمل‌ها به زبان انگلیسی ارائه شده‌اند. پس از بارگزاری آن‌ها، می‌توانید یک دستورالعمل را ویرایش کرده و از **ترجمه دستورالعمل** استفاده کنید اگر می‌خواهید متن دستورالعمل را برای زبان دیگری تطبیق دهید.

<br />

<a id="create-a-prompt-quickly"></a>

### ایجاد سریع یک پرامپت

سریع‌ترین راه برای ایجاد یک پرامپت:

1. روی **پِرامپت جدید** کلیک کنید.
2. روی **Generate prompt** کلیک کنید.
3. توضیح دهید که می‌خواهید پرامپت چه کاری انجام دهد.
4. یک مدل انتخاب کنید.
5. بگذارید اپلیکیشن یک پیش‌نویس برای شما ایجاد کند.
6. پیش‌نویس را بررسی کرده و روی **ذخیره** کلیک کنید.

![ایجاد پرامپت](../images/screenshots/fa/transform-generate.png)


<br />

### ویرایش یک پرامپت

هنگامی که یک پرامپت ایجاد یا ویرایش می‌کنید، ویرایشگر در سمت چپ و منطقه آزمایشی در سمت راست ظاهر می‌شود.

![ویرایشگر پرامپت تبدیل](../images/screenshots/fa/transform-prompt-edit.png)

فیلدهای اصلی عبارتند از:

- **نام پرامپت**: نامی که در لیست پرامپت‌ها نمایش داده می‌شود.
- **دستورات پرامپت (اختیاری)**: یک نکته کوتاه که هنگام اجرای پرامپت به کاربر نمایش داده می‌شود.
- **نقش مدل**: نقش کلی اختصاص داده شده به هوش مصنوعی، مانند 'You are a helpful assistant.'
- **دستورات مدل (یک دستور در هر خط)**: قواعد خاصی که می‌خواهید هوش مصنوعی آن‌ها را دنبال کند.
- **توضیح خروجی**: یک کلمه کوتاه که نتیجه را توصیف می‌کند، مانند 'summary' یا 'rewrite'.
- **دمای (0.0 → 1.0)**: یک تنظیم‌گر خلاقیت.
- **درخواست زبان هدف**: یک انتخاب‌گر زبان هدف هنگام اجرای پرامپت اضافه می‌کند.

اگر اصطلاح فنی **دمای** برای شما جدید است، اینطور به آن فکر کنید:

- یک **دمای پایین‌تر** نتایج ثابت‌تر و قابل پیش‌بینی‌تری می‌دهد.
- یک **دمای بالاتر** تنوع و خلاقیت بیشتری می‌دهد.

شما همچنین می‌توانید از این موارد استفاده کنید:

- **`Generate prompt`** برای ایجاد یک پیش‌نویس جدید از یک توضیح ساده
- **`Improve prompt`** برای ارتقای یک پرامپت موجود
- **`Translate prompt`** برای ترجمه فیلدهای پرامپت

> ⚠️ **هشدار**<br/>
> قبل از کلیک بر **`Back to Run`**، روی **`Save`** کلیک کنید. اگر بدون ذخیره کردن بازگردید، تغییرات شما از دست خواهند رفت.

<br />

<a id="test-a-prompt-before-using-it"></a>
### آزمایش یک پرامپت قبل از استفاده

پنل آزمایش در سمت راست به شما امکان می‌دهد پرامپت خود را با متن نمونه قبل از استفاده در کار روزمره امتحان کنید.

این مورد وقتی مفید است که:

- شما در حال ساخت یک پرامپت جدید هستید
- شما در حال مقایسه دو نسخه از یک پرامپت هستید
- می‌خواهید لحن، طول یا فرمت خروجی را بررسی کنید

<br />

<a id="manage-saved-prompts"></a>
### مدیریت پرامپت‌های ذخیره شده

برای مدیریت پرامپت‌های ذخیره شده در یک مکان، [**تنظیمات** > **تبدیل پِرامپت‌ها**](#transform-prompts) را باز کنید.

در آنجا می‌توانید:

- پرامپت‌های خود را فهرست و حذف کنید
- پرامپت‌ها را به صورت **JSON**، **CSV** یا **XLSX** خروجی بگیرید
- پرامپت‌ها را از یک فایل وارد کنید

<a id="settings"></a>
## تنظیمات

**تنظیمات** را از نوار کناری باز کنید تا نحوه رفتار اپلیکیشن را سفارشی کنید.

زبانه‌های موجود ممکن است متفاوت باشند:

- **پیکربندی API** تنها در اپلیکیشن دسکتاپ در دسترس است.
- **کاربران** تنها در اپلیکیشن وب و فقط برای مدیران در دسترس است.

<br />

<a id="general-settings"></a>

### تنظیمات عمومی

از **تنظیمات عمومی** برای کنترل رفتار تایپ و ظاهر استفاده کنید.

**رفتار**

- **رفتار ENTER** انتخاب می‌کند که آیا Enter اجرای وظیفه را انجام دهد یا خط جدیدی درج کند.
- **ترجمه خودکار هنگام چسباندن** ترجمه را بلافاصله پس از چسباندن متش শুরু می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد** نتایج موفق را به طور خودکار کپی می‌کند.
- **ترجمه بلادرنگ (در حین تایپ)** هنگام تایپ ترجمه می‌کند.
- **زمان انتظار (میلی‌ثانیه)** زمان انتظار برای ترجمه بلادرنگ را تنظیم می‌کند.

**ظاهر**

- **رقم اعشار هزینه** نحوه نمایش اعشار هزینه را تغییر می‌دهد.
- **نوع فونت** فونت نوشتاری را در پنل‌های متغیر تغییر می‌دهد.
- **اندازه** اندازه فونت را تغییر می‌دهد.
- **فقط در وب:** **نمایش حاشیه دور برنامه** فضای اضافی دور رابط کاربری اضافه می‌کند.

<br />

<a id="models"></a>
### مدل‌ها

از **تنظیمات** > **مدل‌ها** برای انتخاب مدل‌هایی که در نوار ابزار ظاهر می‌شوند استفاده کنید.

![برگه تنظیمات مدل‌ها](../images/screenshots/fa/settings-models.png)

این صفحه دو لیست دارد:

- **مدل‌های موجود** در سمت چپ
- **مدل‌های انتخاب‌شده** در سمت راست

کنترل‌های مفید شامل موارد زیر است:

- **جستجوی مدل‌ها...** برای یافتن یک مدل بر اساس نام
- **فقط رایگان** برای نمایش فقط مدل‌های رایگان
- **تجدید لیست** برای بارگذاری مجدد لیست
- **باز کردن همه** و **بستن همه** هنگام مرتب‌سازی بر اساس ارائه‌دهنده

برای اضافه کردن یک مدل، روی **افزودن** کلیک کنید.

برای حذف یک مدل، روی **X** کنار آن در **مدل‌های انتخاب‌شده** کلیک کنید.

برای پاک کردن لیست، روی **لغو انتخاب همه** کلیک کنید. مدل رایگان مورد نیاز در لیست باقی می‌ماند.

> ℹ️ **توجه**<br/>
> اگر نمی‌خواهید بلافاصله اعتبار به OpenRouter اضافه کنید، ابتدا **فقط رایگان** را فعال کرده و مدل‌های رایگان را انتخاب کنید.

<br />

<a id="languages"></a>
### زبان‌ها

از **تنظیمات** > **زبان‌ها** برای سازماندهی لیست‌های زبان‌ای که در برنامه استفاده می‌شوند استفاده کنید.

- **زبان‌های اولویت‌دار** در بالای لیست‌های زبان در **ترجمه** و **تبدیل** سنجیده می‌شوند.
- **زبان سفارشی** به شما امکان می‌دهد زبانی که در لیست داخلی موجود نیست اضافه کنید.

اگر زبان سفارشی اضافه کنید، در انتخاب‌گرهای زبان Prozent گزینه‌های داخلی ظاهر می‌شود.

<br />

<a id="cost-tracking"></a>
### ردیابی هزینه

از **تنظیمات** > **ردیابی هزینه** برای مدیریت اطلاعات هزینه استفاده کنید.

- **هزینه کل** مجموع در حال اجرا را نشان می‌دهد.
- **کپی مقدار** مجموع را در کلیپ‌بورد کپی می‌کند.
- **بازنشانی هزینه** مجموع ذخیره‌شده را به صفر برمی‌گرداند.
- **همگام‌سازی با مصرف کلید API** مجموع را با گزارش مصرف OpenRouter تطبیق می‌دهد.
- **مصرف کلید API** جزئیات مصرف، در صورت موجود بودن، نشان می‌دهد.
- **حذف داده‌های هزینه** همه داده‌ها یا فقط رکوردهای قدیمی‌تر از تاریخی انتخاب‌شده را حذف می‌کند.

> ⚠️ **هشدار**<br/>
> حذف داده‌ها غیرقابل برگشت است. قبل از حذف، مطمئن شوید که داده‌های خود را پشتیبان‌گیری کرده‌اید یا از طریق [**داشبورد** > **تمامی تماس‌ها**](#dashboard-tabs) خروجی بگیرید، در غیر این صورت به طور دائمی از بین خواهد رفت.

<br />

<a id="transform-prompts"></a>
### دستورات تبدیل

از **تنظیمات** > **دستورات تبدیل** برای مدیریت دستورات به صورت انبوه استفاده کنید.

شما می‌توانید:

- دستورات ذخیره‌شده خود را مرور کنید
- دستورات را حذف کنید
- دستورات را از یک فایل وارد کنید
- دستورات را برای پشتیبان‌گیری یا اشتراک‌گذاری خروجی بگیرید

<a id="users"></a>
### کاربران

**فقط در وب - فقط مدیران**

از **کاربران** برای مدیریت حساب‌های کاربری در نسخه وب استفاده کنید. می‌توانید کاربران اضافه کنید، جزئیات آن‌ها را به‌روزرسانی کنید، رمز عبور را بازنشانی کرده و حساب‌ها را حذف کنید.

<br />

<a id="api-config"></a>
### پیکربندی API

**فقط در دسکتاپ**

از **پیکربندی API** برای اتصال برنامه دسکتاپ به OpenRouter یا یک پروکسی Transrewrt استفاده کنید.

- **کلید API OpenRouter** جایی است که کلید خود را درج می‌کنید.
- **آدرس API** آدرس سرویس است. این را روی پیش‌فرض رها کنید مگر اینکه آدرس متفاوتی برایتان داده شده باشد.
- **استفاده از پروکسی Transrewrt** درخواست‌ها را از طریق یک سرویس پروکسی به جای ارسال مستقیم به OpenRouter مسیردهی می‌کند.
- **بذر کلید** زمانی که گزینه پروکسی فعال است ظاهر می‌شود.
- **تست پیکربندی API** بررسی می‌کند که آیا تنظیمات فعلی کار می‌کند یا خیر.

برای مراحل جزئی‌تر در مورد دریافت کلید API خود، [چگونه یک کلید API دریافت کنیم](#how-to-get-an-api-key-desktop-app) در بالا را ببینید.

> ℹ️ **توجه**<br/>
> اگر مطمئن نیستید که **آدرس API**، **استفاده از پروکسی Transrewrt** یا **بذر کلید** به چه معنا هستند، آن‌ها را بدون تغییر رها کرده و از تنظیم پیش‌فرض OpenRouter استفاده کنید. اطلاعات بیشتری درباره پروکسی در [مخزن پروکسی Transrewrt](https://github.com/wsj-br/transrewrt-proxy) موجود است.

<a id="common-issues"></a>
## مشکلات متداول

اگر چیزی به درستی کار نکرد، ابتدا موارد زیر را بررسی کنید.

<br />

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### برنامه متن را ترجمه، بازنویسی یا تبدیل نمی‌کند

بررسی کنید که:

- مدلی در نوار ابزار انتخاب کرده‌اید
- حداقل یک مدل در [**تنظیمات** > **مدل‌ها**](#models) فهرست شده است
- پیکربندی API شما کار می‌کند

اگر از برنامه دسکتاپ استفاده می‌کنید:

1. [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید.
2. بررسی کنید که کلید API شما ذخیره شده است.
3. **تست پیکربندی API** را کلیک کنید.

<br />

<a id="the-model-list-is-empty"></a>
### لیست مدل‌ها خالی است

[**تنظیمات** > **مدل‌ها**](#models) را باز کرده و **تازه‌سازی** را کلیک کنید.

در صورت نیاز:

- مدلی را جستجو کنید
- **فقط رایگان** را فعال کنید
- یک یا چند مدل را به **مدل‌های انتخاب‌شده** اضافه کنید

<br />

<a id="the-result-is-too-slow-or-too-expensive"></a>
### نتیجه خیلی کند یا خیلی گران است

یک یا چند مورد از این‌ها را امتحان کنید:

- مدلی دیگر انتخاب کنید
- از ورودی کوتاه‌تری استفاده کنید
- **ترجمه بلادرنگ (هنگام تایپ)** را در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) خاموش کنید
- برای کارهای ساده از مدل‌های رایگان استفاده کنید (به [مدل‌ها](#models) مراجعه کنید)

<br />

<a id="the-interface-is-in-the-wrong-language"></a>
### رابط در زبان اشتباه است

آیکون کره‌زمین در [نوار ابزار](#toolbar) را کلیک کرده و **زبان رابط** دلخواه خود را انتخاب کنید.

<br />

<a id="the-text-is-too-small-or-hard-to-read"></a>
### متن خیلی کوچک یا خوانا نیست

### من یک پرامپت را تغییر دادم و ویرایش‌ها را گم کردم

هنگام ویرایش یک پرامپت، همیشه قبل از کلیک بر **بازگشت به اجرا**، **ذخیره** را کلیک کنید.

<br /><br />

<a id="quick-tips"></a>
## نکات سریع

- با [**ترجمه**](#translate) شروع کنید تا مطمئن شوید تنظیمات شما کار می‌کند، قبل از Craig به [**بازنویسی**](#rewrite) یا [**تبدیل**](#transform).
- از [**بازنویسی**](#rewrite) برای بهبودهای روزمره متن استفاده کنید.
- از [**تبدیل**](#transform) زمانی که نیاز به یک گردش کار تکرارشونده برای یک کار خاص دارید استفاده کنید.
- از [**داشبورد**](#dashboard) اگر می‌خواهید مصرف و هزینه را زیر نظر بگیرید استفاده کنید.
- پرامپت‌ها را به طور منظم برون‌بری کنید اگر کتابخانه‌ای از پرامپت می‌سازید که می‌خواهید ایمن نگه دارید (به [پرامپت‌های تبدیل](#transform-prompts) مراجعه کنید).
