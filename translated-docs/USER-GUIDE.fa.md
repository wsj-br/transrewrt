# راهنمای کاربر

<br/>

<a id="introduction"></a>
## معرفی

Transrewrt به شما کمک می‌کند تا با متن به سه روش اصلی کار کنید:

- **ترجمه** - تبدیل متن از یک زبان به زبان دیگر.
- **بازنویسی** - بازنویسی متن با سبک متفاوت، مانند واضح‌تر، کوتاه‌تر یا رسمی‌تر.
- **تبدیل** - پردازش متن با استفاده از دستورالعمل‌های سفارشی هوش مصنوعی که به آن‌ها «پرسش» گفته می‌شود.

<br/>

این راهنما نحوه استفاده از برنامه پس از نصب و راه‌اندازی آن را توضیح می‌دهد. برای مراحل نصب، به **[README](README.fa.md)** اصلی مراجعه کنید.

<br/>

> ℹ️ **یادداشت**<br/>
> Transrewrt به صورت برنامه دسکتاپ برای ویندوز و لینوکس و همچنین به صورت برنامه تحت وب قابل میزبانی شخصی در دسترس است. این راهنما بر استفاده روزمره از برنامه تمرکز دارد. در مواردی که چیزی فقط به یک نسخه اعمال می‌شود، به وضوح مشخص شده است.

<a id="before-you-start"></a>
## قبل از شروع

برای استفاده از Transrewrt، نیاز به دسترسی به حداقل یک ارائه‌دهنده هوش مصنوعی دارید. ارائه‌دهندگان پشتیبانی‌شده عبارتند از: [OpenRouter](https://openrouter.ai) (که بسیاری از مدل‌ها را گردآوری می‌کند)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و [Ollama](https://ollama.com) برای مدل‌های محلی.

نیازی به انتخاب یک مدل پولی برای شروع ندارید. به محض اینکه کلید API OpenRouter خود را اضافه کنید، برنامه به‌صورت خودکار یک گزینه **رایگان** داخلی OpenRouter را فعال می‌کند. این امکان را به شما می‌دهد که بلافاصله شروع به ترجمه، بازنویسی و تبدیل متن کنید. به‌عنوان گزینه دیگر، می‌توانید کلید API رایگان از Cerebras، Google، Groq یا Mistral AI نیز دریافت کنید.

به زبان ساده:

- یک **مدل** موتور هوش مصنوعی است که کار را انجام می‌دهد. مدل‌ها با پیشوند **ارائه‌دهنده** فهرست شده‌اند (برای مثال `openrouter/…`، `openai/…`، `ollama/…`).
- یک **کلید API** (یا برای Ollama، یک **آدرس URL پایه**) روشی است که برنامه از طریق آن به ارائه‌دهنده متصل می‌شود.

اگر از **اپلیکیشن دسکتاپ** استفاده می‌کنید، برای هر ارائه‌دهنده‌ای که به کار می‌برید کلیدها را در مسیر [**تنظیمات** > **پیکربندی API**](#api-config) اضافه کنید. برای استفاده فقط از OpenRouter، به بخش [نحوه دریافت کلید API رایگان](#how-to-get-an-api-key-desktop-app) در ادامه مراجعه کنید. اگر نمی‌خواهید از کلید API استفاده کنید، می‌توانید Ollama (از [ollama.com](https://ollama.com)) را نصب کنید و به جای آن از مدل‌های محلی مانند `translategemma:4b` استفاده کنید.

اگر از **نسخه وب** استفاده می‌کنید، مالک سرور ارائه‌دهندگان را از طریق متغیرهای محیطی پیکربندی می‌کند، بنابراین شما نمی‌توانید مستقیماً کلیدهای API را در برنامه وارد کنید.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### نحوه دریافت کلید API رایگان OpenRouter (اپلیکیشن دسکتاپ)

اگر از اپلیکیشن دسکتاپ استفاده می‌کنید، مراحل زیر را دنبال کنید:

1. در مرورگر خود به [OpenRouter](https://openrouter.ai) بروید.
2. یک حساب کاربری ایجاد کنید یا وارد شوید.
3. به صفحه [کلیدها](https://openrouter.ai/keys) بروید.
4. دکمه ایجاد کلید API جدید را کلیک کنید.
5. به کلید نامی اختصاص دهید تا بتوانید بعداً آن را تشخیص دهید.
6. کلید API جدید را کپی کنید.
7. به Transrewrt بازگردید و **تنظیمات** > **پیکربندی API** را باز کنید.
8. کلید را در فیلد **کلید API OpenRouter** (در زیر **تنظیمات** > **پیکربندی API**) قرار دهید.
9. برای اطمینان از صحت کارکرد، روی **آزمون کلید OpenRouter** کلیک کنید.

<br/><br/>

<a id="getting-started"></a>
## شروع کار

اگر اولین بار است که از Transrewrt استفاده می‌کنید، این ترتیب را دنبال کنید:

1. برنامه را باز کنید.
2. در صورت نیاز، **زبان رابط** خود را از آیکون کره زمین انتخاب کنید.
3. اگر از **برنامه دسکتاپ** استفاده می‌کنید، [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید، یک کلید API برای حداقل یک ارائه‌دهنده (مثلاً OpenRouter) اضافه کنید و روی **آزمون** کلیک کنید تا از کارکرد آن اطمینان حاصل کنید.
4. [**تنظیمات** > **مدل‌ها**](#models) را باز کنید و یک یا چند مدل را به **مدل‌های انتخاب‌شده** اضافه کنید.
5. [**تنظیمات** > **زبان‌ها**](#languages) را باز کنید و در صورت تمایل به نمایش زبان‌های پرکاربرد در ابتدا، **زبان‌های برتر** خود را انتخاب کنید.
6. به بخش **ترجمه** بروید و یک ترجمه ساده انجام دهید تا از صحت عملکرد همه چیز اطمینان حاصل کنید.
7. پس از موفقیت‌آمیز بودن این مرحله، **بازنویسی** و سپس **تبدیل** را امتحان کنید.

این ترتیب مهم است. این امر از شایع‌ترین مشکل استفاده اولیه جلوگیری می‌کند: تلاش برای اجرای یک وظیفه قبل از اینکه برنامه ارتباط API کارآمد یا مدل انتخاب شده‌ای داشته باشد.

<a id="toolbar"></a>
### نوار ابزار

نوار ابزار کمی بسته به محل قرارگیری شما در برنامه تغییر می‌کند.

- در سمت چپ، نام صفحه فعلی نمایش داده می‌شود.
- در سمت راست، **گزینشگر مدل** و کنترل **زبان رابط** نمایش داده می‌شود.

انتخاب‌کنندهٔ **مدل** به شما امکان می‌دهد که کدام موتور هوش مصنوعی را برای انجام کار جاری انتخاب کنید.

![Model selector](../images/screenshots/fa/model-selector.png)

برخی از مدل‌های رایگان ممکن است همیشه در دسترس نباشند — گاهی آفلاین هستند یا سقف استفاده دارند. اگر این اتفاق بیفتد، برنامه به‌صورت خودکار آن مدل را از لیست در دسترس شما حذف می‌کند. برای کنترل مدل‌هایی که نمایش داده می‌شوند، به [**تنظیمات** > **مدل‌ها**](#models) بروید و لیست مدل‌های خود را ویرایش کنید.  
همچنین می‌توانید تنظیمات مدل را مستقیماً با کلیک روی آیکون ارائه‌دهنده در سمت چپ نام مدل در نوار ابزار باز کنید.

<br/>

آیکون **گلوب به‌همراه کد زبان** زبان رابط برنامه، مانند منوها و دکمه‌ها را تغییر می‌دهد. این کار **زبان‌های ترجمه** استفاده شده در **ترجمه** را تغییر نمی‌دهد.

![Interface language selector](../images/screenshots/fa/language-selector.png)

<a id="input-and-output-panels"></a>
### پنل‌های ورودی و خروجی

اکثر فضاهای کاری از یک پنل **ورودی** در سمت چپ و یک پنل **خروجی** در سمت راست استفاده می‌کنند.

هر پنل همچنین موارد زیر را نشان می‌دهد:

| **ورودی**                                                          | **خروجی**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - تعداد کاراکتر <br/>- تعداد کلمه <br/>- تعداد پاراگراف   <br/> | - مدت زمان انجام کار<br/>- **TPS** (توکن در ثانیه)<br/>- تعداد کاراکتر، کلمه و پاراگراف<br/>- مدل استفاده شده |

اگر در مورد اصطلاحات فنی سوال دارید:

- **توکن** به معنای یک تکه کوچک از متن است. می‌توانید آن را به عنوان بخشی از یک کلمه یا یک کلمه کوتاه در نظر بگیرید.
- **TPS** به این معناست که مدل در هر ثانیه چند تا از این تکه‌های متنی را پردازش کرده است.

<br/>

همچنین می‌توانید هزینه هر عملیات (در صورت در دسترس بودن) و هزینه کل را با فعال‌سازی گزینه `Show cost information on the actions` در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) پیگیری کنید.

<a id="translate"></a>
## ترجمه

از **ترجمه** زمانی استفاده کنید که بخواهید متنی را از یک زبان به زبان دیگر تبدیل کنید.

![Translate workspace](../images/screenshots/fa/translate.png)

<br/>

<a id="translate-text"></a>
### ترجمه متن

1. **ترجمه** را باز کنید.
2. زبانی را در **از** انتخاب کنید.
3. زبانی را در **به** انتخاب کنید.
4. یک مدل را در نوار ابزار انتخاب کنید.
5. متن را در **ورودی** تایپ یا بچسبانید.
6. روی **ترجمه** کلیک کنید.
7. نتیجه را در **خروجی** بخوانید.
8. در صورت تمایل، از دکمه کپی برای کپی کردن نتیجه استفاده کنید.

<br/>

<a id="language-selection"></a>
### انتخاب زبان

- **از** می‌تواند یک زبان خاص یا **تشخیص زبان** باشد.
- **به** زبانی است که می‌خواهید نتیجه به آن باشد.

زبان‌های **برتر انتخاب شده** شما در بالای لیست نمایش داده می‌شوند. می‌توانید این موارد را در [**تنظیمات** > **زبان‌ها**](#languages) تنظیم کنید.

- **ترجمه خودکار هنگام چسباندن** به محض چسباندن متن، ترجمه را اجرا می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد** پس از اجرای موفق، نتیجه را به‌طور خودکار کپی می‌کند.

- **زمان انتظار (میلی‌ثانیه)** تعیین می‌کند که برنامه چه مدت منتظر بماند قبل از اجرای ترجمه لحظه‌ای.

<a id="transform"></a>
## تبدیل

از **تبدیل** زمانی استفاده کنید که بخواهید هوش مصنوعی دستورالعمل‌های سفارشی شما را دنبال کند.

![Transform workspace](../images/screenshots/fa/transform.png)

این بخش انعطاف‌پذیرترین قسمت برنامه است. می‌توانید از آن برای کارهایی مانند:

- خلاصه‌سازی یادداشت‌ها
- تبدیل متن خام به ایمیلی حرفه‌ای
- استخراج نکات کلیدی
- تبدیل متن به یک قالب خاص
- هر فعالیت سفارشی دیگری با متن ورودی

<br/>

<a id="run-an-existing-prompt"></a>
### اجرای یک پرسش موجود

1. **تبدیل** را باز کنید.
2. یک پرسش از فهرست پرسش‌ها انتخاب کنید.
3. اگر کادر **زبان مقصد** ظاهر شد، در صورت تمایل یک زبان انتخاب کنید.
4. متن را در بخش **ورودی** تایپ یا بچسبانید.
5. روی **تبدیل** کلیک کنید.
6. نتیجه را در بخش **خروجی** بخوانید.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### اگر هنوز هیچ پرسشی ندارید

اگر لیست پرسش‌های شما خالی است، در فضای کار تبدیل روی **بارگیری نمونه درخواست‌ها** کلیک کنید. همین گزینه همیشه در بخش [**تنظیمات** > **دستورات تبدیل**](#transform-prompts) در سطر صادرات/واردات موجود است. هر دوی این گزینه‌ها نمونه‌های داخلی را اضافه می‌کنند تا بتوانید سریع شروع کنید.

<br/>

> ℹ️ **یادداشت**<br/>
> نمونه پرسش‌ها به زبان انگلیسی ارائه می‌شوند. پس از بارگیری آنها، می‌توانید یک پرسش را ویرایش کرده و از **ترجمه درخواست** استفاده کنید تا آن را به زبان خود ترجمه کنید.

<br/>

<a id="create-a-prompt-quickly"></a>
### ایجاد سریع یک پرسش

سریع‌ترین روش برای ایجاد یک پرسش این است:

1. روی **پرسش جدید** کلیک کنید.
2. روی **تولید پرسش** کلیک کنید.
3. توضیح دهید که می‌خواهید پرسش چه کاری انجام دهد.
4. یک مدل انتخاب کنید.
5. اجازه دهید برنامه یک پیش‌نویس برای شما ایجاد کند.
6. پیش‌نویس را بررسی کنید و روی **ذخیره** کلیک کنید.

![Generate prompt](../images/screenshots/fa/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ویرایش یک پرسش

هنگامی که یک پرسش ایجاد یا ویرایش می‌کنید، ویرایشگر در سمت چپ نمایش داده می‌شود و یک ناحیه تست در سمت راست ظاهر می‌شود.

![Transform prompt editor](../images/screenshots/fa/transform-prompt-edit.png)

فیلدهای اصلی عبارتند از:

- **نام پرسش**: نامی که در فهرست پرسش‌ها نمایش داده می‌شود.
- **دستورالعمل‌های پرسش (اختیاری)**: یک راهنمای کوتاه که هنگام اجرای پرسش به کاربر نمایش داده می‌شود.
- **نقش مدل**: نقش کلی که به هوش مصنوعی داده می‌شود، مانند 'شما یک دستیار مفید هستید.'
- **دستورالعمل‌های مدل (یکی در هر خط)**: قوانین خاصی که می‌خواهید هوش مصنوعی دنبال کند.
- **توضیح خروجی**: یک کلمه کوتاه که نتیجه را توصیف می‌کند، مانند 'خلاصه' یا 'بازنویسی'.
- **دما (0.0 → 1.0)**: نحوه رفتار مدل؛ به پایین مراجعه کنید.
- **درخواست زبان مقصد**: هنگام اجرای پرسش، یک انتخاب‌گر زبان مقصد اضافه می‌کند.

اگر اصطلاح فنی **دما** برای شما جدید است، به این صورت فکر کنید:

- **دما** پایین‌تر، نتایج پایدارتر و قابل پیش‌بینی‌تری ایجاد می‌کند.
- **دما** بالاتر، تنوع و خلاقیت بیشتری ایجاد می‌کند.

همچنین می‌توانید از موارد زیر استفاده کنید:

- **`Generate prompt`** برای ایجاد یک پیش‌نویس جدید از یک توصیف ساده
- **`Improve prompt`** برای بهبود یک پرسش موجود
- **`Translate prompt`** برای ترجمه فیلدهای پرسش

<br/>

> ⚠️ **هشدار**<br/>
> قبل از کلیک کردن روی **`Back to Run`**، روی **`Save`** کلیک کنید. اگر بدون ذخیره بازگردید، تغییرات شما از بین خواهند رفت.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### تست یک پرسش قبل از استفاده از آن

پنل تست در سمت راست به شما امکان می‌دهد قبل از استفاده از پرسش در کارهای روزمره، آن را با متن نمونه امتحان کنید.

این کار در موارد زیر مفید است:

- هنگامی که یک پرسش جدید می‌سازید
- هنگامی که دو نسخه از یک پرسش را مقایسه می‌کنید
- هنگامی که می‌خواهید لحن، طول یا قالب خروجی را بررسی کنید

<br/>

> ℹ️ **یادداشت**<br/>
> می‌توانید پرسش‌های ذخیره‌شده را در [**تنظیمات** > **دستورات تبدیل**](#transform-prompts) صادر و وارد کنید.

<a id="dashboard-tabs"></a>
### زبانه‌های داشبورد

- **خلاصه** به شما نمای کلی از استفاده و هزینه می‌دهد. این شامل **استفاده در طول زمان** (تعداد **تماس‌های انباشته تجمعی** به تفکیک روز برای ترجمه، بازنویسی و تبدیل) و **استفاده بر اساس مدل** (تعداد کل **تماس‌ها به ازای هر مدل**، شامل تبدیل).

- **بر اساس روز** مجموع روزانه را نشان می‌دهد.
- **همه فراخوانی‌ها** تاریخچه کامل فراخوانی‌ها را نشان می‌دهد و امکان صدور آن را فراهم می‌کند.

<a id="general-settings"></a>
### تنظیمات عمومی

از **تنظیمات عمومی** برای کنترل رفتار تایپ، ذخیره جزئیات اجرا برای **تاریخچه** و ظاهر استفاده کنید.

**رفتار**

- **رفتار کلید ENTER** تعیین می‌کند که آیا `Enter` وظیفه را اجرا می‌کند یا یک خط جدید وارد می‌شود.
- **ترجمه خودکار هنگام چسباندن** به محض چسباندن متن، ترجمه را شروع می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد** نتایج موفق را به‌طور خودکار کپی می‌کند.
- **ترجمه لحظه‌ای (در حین تایپ)** در حین تایپ، ترجمه انجام می‌شود.
- **زمان‌بندی (میلی‌ثانیه)** مدت زمان انتظار برای ترجمه لحظه‌ای را تنظیم می‌کند.

**تاریخچه**

- **نگه‌داری تاریخچه اجرا** کنترل می‌کند که آیا هر ترجمه، بازنویسی و تبدیل، **متن ورودی و خروجی** را برای نمایش در بخش [**تاریخچه**](#history) نوار کناری ذخیره کند. غیرفعال کردن این گزینه از شما تأیید می‌خواهد؛ در صورت تأیید، متن تاریخچه ذخیره شده از پایگاه داده حذف می‌شود.
- **حذف داده‌های تاریخچه** به شما امکان می‌دهد تا متن ذخیره شده را بر اساس سن (مثلاً قدیمی‌تر از چند ماه یا **همه داده‌ها (پاک کردن)**) با استفاده از **حذف داده** حذف کنید. این تنها بر متن اجرای ذخیره شده برای نمایش **تاریخچه** تأثیر می‌گذارد و **بر روی** کل هزینه یا مجموع مصرف تأثیری ندارد. برای حذف یا کاهش داده‌های **هزینه**، از [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) استفاده کنید.

**ظاهر**

- **نمایش اطلاعات هزینه در عملیات** نمایش هزینه هر عمل (در صورت موجود بودن) و هزینه کل در پنل‌های خروجی ترجمه، بازنویسی و تبدیل را کنترل می‌کند.
- **تعداد ارقام اعشار هزینه** نحوه نمایش اعشار هزینه را تغییر می‌دهد.
- **فقط در وب:** **نمایش حاشیه دور برنامه** فضای اضافی دور رابط کاربری ایجاد می‌کند.
- **خانواده فونت** فونت متن در پنل‌های ویرایش را تغییر می‌دهد.
- **اندازه** اندازه فونت را تغییر می‌دهد.

**پشتیبان‌گیری پیکربندی**

- **شامل داده‌های مصرف در پشتیبان شود** - در صورت فعال بودن، فایل ZIP شامل تاریخچه اجرا و داده‌های فراخوانی API نیز می‌شود. 
- **پشتیبان‌گیری از تنظیمات** - یک فایل ZIP واحد ایجاد می‌کند (به‌طور پیش‌فرض `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` به زمان UTC) که شامل `config.json`، `state.json`، کلید رمزگذاری اختیاری، کاربران، ترجیحات، دستورات سفارشی و داده‌های مصرف (در صورت انتخاب) می‌شود. پس از پشتیبان‌گیری موفق، نام فایل ذخیره‌شده نمایش داده می‌شود.
- **بازیابی از پشتیبان** - ابتدا یک **پنجره تأیید نمایش داده می‌شود**. فایل ZIP پشتیبان را درون پنجره انتخاب کنید (**مرور** / انتخاب‌گر فایل یا کشیدن و رها کردن در صورت پشتیبانی)، سپس گزینه‌ها را بررسی کنید:
  - **بازیابی داده‌های مصرف** - داده‌های مصرف/تاریخچه از ZIP را وارد می‌کند در صورتی که در هنگام پشتیبان‌گیری شامل مصرف بوده باشد؛ در صورتی که فقط تنظیمات و دستورات مدنظرتان باشد، این گزینه را غیرفعال نگه دارید.
  - **پاک‌سازی داده‌های قدیمی مصرف قبل از بازیابی** - داده‌های مصرف/تاریخچه موجود در این نصب را قبل از اعمال پشتیبان حذف می‌کند (اختیاری؛ زمانی استفاده شود که می‌خواهید جایگزینی کامل انجام دهید).

پشتیبان‌های ایجاد شده در نسخه وب یا دسکتاپ می‌توانند در نسخه دیگر بازیابی شوند. هنگام بازیابی یک پشتیبان دسکتاپ در نسخه وب، داده‌ها به کاربر مدیر بازیابی می‌شوند.

<a id="models"></a>
### مدل‌ها

از **تنظیمات** > **مدل‌ها** برای انتخاب مدل‌هایی که در نوار ابزار نمایش داده می‌شوند استفاده کنید.

![Settings Models tab](../images/screenshots/fa/settings-models.png)

این صفحه دارای دو لیست است:

- **مدل‌های موجود** در سمت چپ  
- **مدل‌های انتخاب شده** در سمت راست

کنترل‌های مفید شامل موارد زیر هستند:

- **جست‌وجوی مدل‌ها...** برای یافتن مدل بر اساس نام
- **برچسب‌های ارائه‌دهنده** برای محدود کردن لیست به یک موتور (OpenRouter، OpenAI، Ollama، …)
- **فقط رایگان** برای نمایش فقط مدل‌های رایگان
- **تازه‌سازی** برای بارگیری مجدد لیست
- **بسط همه** و **جمع کردن همه** هنگامی که لیست بر اساس ارائه‌دهنده مرتب شده است

شناسه‌های مدل شامل پیشوند ارائه‌دهنده هستند (برای مثال `openrouter/…` در مقابل `openai/…`). نشان‌ها مانند **OpenAI (OpenRouter)** در مقابل **OpenAI (مستقیم)** نشان می‌دهند که ترافیک چگونه مسیریابی می‌شود.

> ℹ️ **توجه**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) یک مدل مسیریاب است، نه یک مدل چت عمومی: پاسخ آن JSON است که بدنه درخواست‌های API OpenRouter را توصیف می‌کند (برای مثال یک آرایه `requests` با `model` و `messages`). اگر از آن برای **ترجمه**، **بازنویسی** یا **تبدیل** استفاده کنید، پنل خروجی آن JSON را نشان می‌دهد نه متن نهایی. برای این وظایف یک مدل متنی معمولی انتخاب کنید. صفحه مدل [Body Builder](https://openrouter.ai/openrouter/bodybuilder) را در OpenRouter ببینید.

اقدامات:

- برای افزودن یک مدل، روی **افزودن** یا هر جای دیگر در آن مدخل کلیک کنید.

- برای حذف یک مدل، روی **X** کنار آن در بخش **مدل‌های انتخاب شده** یا روی **انتخاب شده** در مدخل مدل در بخش مدل‌های موجود کلیک کنید.

- برای پاک کردن لیست، روی **لغو انتخاب همه** کلیک کنید. مدل رایگان اجباری در لیست باقی می‌ماند.

<br/>

> ℹ️ **توجه**<br/>
> اگر نمی‌خواهید بلافاصله اعتبار به OpenRouter اضافه کنید، ابتدا **فقط رایگان** را فعال کنید و مدل‌های رایگان را انتخاب کنید (نیازی به کارت اعتباری نیست). همچنین می‌توانید از Ollama برای اجرای مدل‌ها به صورت محلی بدون نیاز به کلید API استفاده کنید.

<br/>

<a id="languages"></a>
### زبان‌ها

از **تنظیمات** > **زبان‌ها** برای سازماندهی لیست‌های زبان استفاده کنید.

- **زبان‌های برتر** در بالای لیست زبان‌ها در بخش‌های **ترجمه** و **تبدیل** ثابت شده‌اند.  
- **زبان سفارشی** به شما امکان می‌دهد زبانی را که در لیست داخلی وجود ندارد اضافه کنید.

اگر یک زبان سفارشی اضافه کنید، در انتخاب‌گرهای زبان در کنار گزینه‌های داخلی ظاهر می‌شود.

<a id="cost-tracking"></a>
### ردیابی هزینه

از **تنظیمات** > **ردیابی هزینه** برای مدیریت اطلاعات هزینه استفاده کنید.

- **هزینه کل** مجموع جاری را نشان می‌دهد.
- **کپی مقدار** مقدار کل را در کلیپ‌بورد کپی می‌کند.
- **بازنشانی هزینه** مجموع ذخیره‌شده را به صفر بازمی‌گرداند.
- **همگام‌سازی با مصرف کلید API** مجموع را برابر با مصرف گزارش‌شده توسط حساب OpenRouter شما تنظیم می‌کند (فقط OpenRouter).
- **مصرف کلید API** جزئیات مصرف OpenRouter را در صورت موجود بودن نشان می‌دهد.
- **حذف داده‌های هزینه** تمام داده‌ها یا فقط موارد قدیمی‌تر از یک تاریخ مشخص را حذف می‌کند.

**ردیابی هزینه:** هنگامی که از مدل‌های OpenRouter استفاده می‌کنید، برنامه میزان استفاده و هزینه واقعی شما را بر اساس اطلاعات هزینه از OpenRouter نشان می‌دهد. برای تمام ارائه‌دهندگان دیگر، برنامه هزینه‌ها را با استفاده از قیمت‌های منتشر شده توسط OpenRouter تخمین می‌زند و اگر قیمتی در دسترس نباشد، تخمین ممکن است صفر باشد.

<br/>

> ℹ️ **توجه**<br/>
>  **تمام ارقام هزینه صرفاً تخمینی هستند و فقط برای مرجع شما ارائه می‌شوند، نه بیانیه‌های رسمی صورتحساب.**

<br/>

> ⚠️ **اخطار**<br/>
> حذف داده‌ها غیرقابل بازگشت است. قبل از حذف، مطمئن شوید که داده‌های خود را از طریق [**تاریخچه**](#history) 
> یا [**داشبورد** > **همه فراخوانی‌ها**](#dashboard-tabs) پشتیبان‌گیری یا صادرات کرده‌اید، در غیر این صورت به‌طور دائم از بین خواهند رفت. 
> تمام تاریخچه ورودی/خروجی مربوط به هر مورد فراخوانی API نیز حذف خواهد شد.

<br/>

<a id="api-config"></a>
### پیکربندی API

ارائه‌دهندگان پشتیبانی‌شده عبارتند از: OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و **Ollama** (مدل‌های محلی از طریق یک آدرس پایه). شما فقط نیاز دارید ارائه‌دهندگانی را که استفاده می‌کنید پیکربندی کنید.

**برنامه وب: فقط مدیر سیستم**

کلیدهای API از طریق متغیرهای محیطی سیستم یا داکر پیکربندی می‌شوند — این کلیدها در رابط کاربری وب وارد نمی‌شوند. این صفحه نشان می‌دهد که کدام ارائه‌دهندگان کلید پیکربندی‌شده دارند و به شما امکان می‌دهد هر کدام را با کلیک روی دکمه **`Test`** تست کنید.

<br/>

> ℹ️ **یادداشت**<br/>
> برای تغییر یک کلید API، متغیر محیطی را در پیکربندی سیستم یا داکر خود به‌روز کنید و سرور یا کانتینر را مجدداً راه‌اندازی کنید.

> ℹ️ **یادداشت**<br/>
> **پشتیبان‌گیری پیکربندی** (نگاه کنید به [**تنظیمات عمومی** → پشتیبان‌گیری پیکربندی](#general-settings)) می‌تواند کلیدهای ارائه‌دهندهٔ **حل‌شده** را درون فایل فشردهٔ `config.json` قرار دهد. بازیابی این فایل فشرده، آن کلیدها را به فایل پیکربندی ذخیره‌شدهٔ سرور **کپی نمی‌کند** — کلیدهای فعال همچنان از محیط و وضعیت موجود فایل‌ها به‌صورت توضیح‌داده‌شده در آنجا تأمین می‌شوند.

<br/>

**برنامه دسکتاپ**

از **پیکربندی API** برای ذخیره کلیدهای API برای هر ارائه‌دهنده‌ای که استفاده می‌کنید استفاده کنید. برای Ollama، به جای کلید API، **آدرس پایه** را وارد کنید.

<br/>

> 💡 **نکته** <br/>
> اگر نمی‌خواهید از کلید API استفاده کنید یا هزینه پردازش را بپردازید، می‌توانید [Ollama را دانلود کنید](https://ollama.com) و مدل‌ها (مانند `translategemma:4b`) را به‌صورت رایگان روی دستگاه خود اجرا کنید. همچنین می‌توانید یک حساب رایگان OpenRouter ایجاد کنید (نیازی به کارت اعتباری نیست) تا از مدل‌های رایگان آن استفاده کنید، یا یک کلید رایگان API از Cerebras، Google، Groq یا Mistral AI دریافت کنید.

<br/>

- فقط ارائه‌دهندگانی را اضافه کنید که نیاز دارید. در **تنظیمات** > **مدل‌ها**، هر شناسه مدل با ارائه‌دهنده شروع می‌شود (برای مثال `openrouter/openrouter/free`، `openai/gpt-4o`، `ollama/llama3`).

برای افزودن یک کلید API، مقدار آن را در کادر متنی وارد کرده و روی **`Save`** کلیک کنید. برای جایگزینی یک کلید موجود، روی **`Edit`** کلیک کنید. برای بررسی اینکه کلید کار می‌کند یا نه، روی **`Test`** کلیک کنید. برای آدرس پایه Ollama، همیشه روی **`Test`** کلیک کنید تا اتصال بررسی شود.

<br/>

> ℹ️ **یادداشت**<br/>
> شما نمی‌توانید مقدار فعلی یک کلید API را ببینید. شما فقط می‌توانید آن را با استفاده از دکمه **`Edit`** جایگزین کنید.
> کلیدهای API به صورت رمزگذاری‌شده در پیکربندی ذخیره می‌شوند.

<a id="common-issues"></a>
## مشکلات رایج

اگر چیزی به درستی کار نمی‌کند، ابتدا موارد زیر را بررسی کنید.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### برنامه متن را ترجمه، بازنویسی یا تبدیل نمی‌کند

مطمئن شوید که:

- یک مدل را در نوار ابزار انتخاب کرده‌اید
- حداقل یک مدل در بخش [**تنظیمات** > **مدل‌ها**](#models) فهرست شده است
- تنظیمات API شما به درستی کار می‌کند

اگر از برنامه دسکتاپ استفاده می‌کنید:

1. [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید.
2. مطمئن شوید حداقل یک کلید API ذخیره شده است.
3. کلید **تست** را در کنار ارائه‌دهنده کلیک کنید تا از صحت کارکرد کلید اطمینان حاصل کنید.

<br/>

<a id="the-model-list-is-empty"></a>
### لیست مدل‌ها خالی است

[**تنظیمات** > **مدل‌ها**](#models) را باز کرده و دکمهٔ **تازه‌سازی** را کلیک کنید.

در صورت نیاز:

- مدلی را جستجو کنید
- گزینهٔ **فقط رایگان** را فعال کنید
- یک یا چند مدل را به بخش **مدل‌های انتخاب شده** اضافه کنید

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### نتیجه بسیار کند یا بسیار گران است

یک یا چند مورد از موارد زیر را امتحان کنید:

- یک مدل دیگر انتخاب کنید
- از ورودی کوتاه‌تری استفاده کنید
- گزینهٔ **ترجمه لحظه‌ای (در حین تایپ)** را در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) غیرفعال کنید
- برای وظایف ساده از مدل‌های رایگان استفاده کنید (به [مدل‌ها](#models) مراجعه کنید)

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### رابط به زبان اشتباه است

روی آیکون کره‌ی زمین در [نوار ابزار](#toolbar) کلیک کرده و **زبان رابط** مورد نظر خود را انتخاب کنید.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### متن بسیار کوچک یا خواندن آن دشوار است

[**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید و تغییرات زیر را اعمال کنید:

- **خانواده قلم**
- **اندازه**

<br/>

<a id="dashboard-charts-are-empty"></a>
### نمودارهای داشبورد خالی هستند

این وضعیت در صورت زیر طبیعی است:

- شما فقط از **مدل‌های رایگان** استفاده می‌کنید و به ارقام **هزینه** نگاه می‌کنید (که ممکن است صفر باشند); نمودارهای شمارش فراخوانی **استفاده** در بخش **خلاصه** هنوز به داده‌های دوره انتخاب شده نیاز دارند
- **فیلتر زمانی** انتخاب شده شامل دوره‌ای که فراخوانی‌ها در آن انجام شده نیست — برای بررسی، گزینه **همه** را امتحان کنید

اگر پس از انتخاب **همه** نمودارها همچنان خالی باشند، تأیید کنید که فراخوانی‌ها در بخش [**تاریخچه**](#history) یا در برگهٔ **همه فراخوانی‌ها** نمایش داده می‌شوند.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### هزینه نمایش داده شده «در دسترس نیست» یا اشتباه به نظر می‌رسد

هنگامی که از طریق **OpenRouter** از مدل‌ها استفاده می‌کنید، برنامه مقدار واقعی هزینه‌ای که توسط OpenRouter گزارش شده را نمایش می‌دهد.

برای **سایر ارائه‌دهندگان** (OpenAI مستقیم، Anthropic مستقیم و غیره)، هزینه بر اساس داده‌های قیمت‌گذاری منتشر شده توسط OpenRouter تخمین زده می‌شود. اگر قیمت متناظری برای یک مدل یافت نشود، هزینه به صورت **غیرقابل دسترس** نمایش داده می‌شود و به مجموع در حال اجرا شما اضافه نخواهد شد.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### هزینه کل با صورتحساب ارائه‌دهنده من مطابقت ندارد

تمام ارقام هزینه در برنامه **فقط برای مرجع و تخمینی** هستند و بیانیه‌های رسمی صورتحساب محسوب نمی‌شوند.

برای نزدیک‌تر کردن مجموع به هزینه واقعی شما در OpenRouter، [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) را باز کنید و روی **همگام‌سازی با استفاده از کلید API** کلیک کنید.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### صفحه تاریخچه در نوار کناری وجود ندارد

ممکن است گزینهٔ **نگه‌داری تاریخچه اجرا** غیرفعال باشد. [**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید و آن را فعال کنید. توجه داشته باشید که فعال کردن این گزینه، داده‌های تاریخچه حذف شده قبلی را بازیابی نمی‌کند.

<br/>

<a id="web-app-session-expired"></a>
### برنامه تحت وب: به صورت غیرمنتظره به صفحه ورود هدایت می‌شوید

ممکن است جلسه کاری شما منقضی شده باشد. دوباره وارد شوید. اگر این اتفاق اغلب رخ دهد، تنظیمات مدت عمر جلسه در پیکربندی سرور را بررسی کنید.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### مدیریت وب: فراموشی یا از دست دادن گذرواژه

این مورد مربوط به **برنامه تحت وب خودمیزبان** (داکر) است، نه برنامه دسکتاپ (الکترون).

- اگر مدیر دیگری همچنان می‌تواند وارد شود، می‌تواند [**تنظیمات** > **کاربران**](#users) را باز کند، حساب مورد نظر را انتخاب کند و یک **رمز عبور جدید** تنظیم کند.
- اگر شما **قفل شده‌اید** اما به **دسترسی شل** به ماشین یا کانتینر دارید، با استفاده از ابزار کمکی که همراه تصویر ارائه می‌شود، گذرواژه را بازنشانی کنید (در صورت تغییر نام پیش‌فرض `transrewrt` آن را جایگزین کنید و اگر گذرواژه شامل فاصله یا کاراکترهای خاص است، آن را درون گیومه قرار دهید):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

نام کاربری پیش‌فرض مدیر `admin` است اگر هرگز حساب دیگری ایجاد نکرده باشید. هنگامی که فقط یک آرگومان وارد کنید، به عنوان گذرواژه جدید برای `admin` در نظر گرفته می‌شود.

اگر به جای داکر از **بررسی منبع** اجرا کنید، از این دستور استفاده کنید:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

این اسکریپت رکورد کاربر را در پایگاه داده SQLite به‌روز می‌کند (و در صورت عدم وجود، می‌تواند کاربر `admin` را ایجاد کند). پس از بازنشانی، با رمز عبور جدید وارد شوید.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### داشبورد داده‌ای برای سایر کاربران نمایش نمی‌دهد (وب)

فقط **مدیران** می‌توانند از طریق فیلتر **کاربر** داده‌های تمام کاربران را مشاهده کنند. کاربران عادی به‌طور طراحی فقط فعالیت خود را می‌بینند.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### یک پرسش را تغییر دادم و ویرایش‌ها از دست رفتند

هنگام ویرایش یک پرسش، همیشه قبل از کلیک روی **بازگشت به اجرا** روی **ذخیره** کلیک کنید.

<a id="quick-tips"></a>
## نکات سریع

- ابتدا با [**ترجمه**](#translate) شروع کنید تا از صحت تنظیمات خود اطمینان حاصل کنید، قبل از اینکه به سراغ [**بازنویسی**](#rewrite) یا [**تبدیل**](#transform) بروید.
- از [**بازنویسی**](#rewrite) برای بهبودهای روزمره متن استفاده کنید.
- از [**تبدیل**](#transform) زمانی استفاده کنید که به یک گردش کار قابل تکرار برای یک وظیفه خاص نیاز داشته باشید.
- از [**داشبورد**](#dashboard) استفاده کنید اگر می‌خواهید مصرف و هزینه را زیر نظر داشته باشید.
- از [**تاریخچه**](#history) برای بررسی عملیات گذشته و متن کامل ورودی/خروجی آن‌ها استفاده کنید.
- به‌طور منظم دستورات خود را خروجی بگیرید اگر در حال ساخت یک کتابخانه دستورات هستید که می‌خواهید از آن محافظت کنید (نگاه کنید به [دستورات تبدیل](#transform-prompts)) یا اگر می‌خواهید آن را با دیگران به اشتراک بگذارید.
