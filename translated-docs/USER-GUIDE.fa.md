# راهنمای کاربر

<br/>

<a id="introduction"></a>
## معرفی

ترانس‌رایت (Transrewrt) به شما در کار با متن به سه روش اصلی کمک می‌کند:

- **ترجمه** - تبدیل متن از یک زبان به زبان دیگر.
- **بازنویسی** - بازنویسی متن با سبک‌های متفاوت، مانند شفاف‌تر، کوتاه‌تر یا رسمی‌تر.
- **تبدیل** - پردازش متن با استفاده از دستورالعمل‌های هوش مصنوعی سفارشی که به آن‌ها «پرامپت» (prompts) می‌گوییم.

<br/>

این راهنما نحوه استفاده از این اپلیکیشن را پس از نصب و راه‌اندازی شرح می‌دهد. برای مراحل نصب، به **[فایل راهنما (README)](README.fa.md)** اصلی مراجعه کنید.

<br/>

> ℹ️ **یادداشت**<br/>
> ترانس‌رایت به صورت یک اپلیکیشن دسکتاپ برای ویندوز و لینوکس و همچنین یک اپلیکیشن تحت وب قابل اجرا در سرور شخصی در دسترس است. این راهنما بر استفاده روزمره از اپلیکیشن تمرکز دارد. در مواردی که یک ویژگی فقط به یک نسخه خاص اعمال می‌شود، به وضوح مشخص شده است.

<a id="before-you-start"></a>

## قبل از شروع

برای استفاده از Transrewrt، باید دسترسی به حداقل یک ارائه‌دهنده هوش مصنوعی داشته باشید. ارائه‌دهندگان پشتیبانی‌شده عبارتند از: [OpenRouter](https://openrouter.ai) (که مدل‌های بسیاری را فراهم می‌کند)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و [Ollama](https://ollama.com) برای مدل‌های محلی.

برای شروع نیازی به انتخاب مدل پولی ندارید. به محض وارد کردن کلید API خود برای OpenRouter، برنامه به‌طور خودکار یک گزینه **رایگان** داخلی OpenRouter را فعال می‌کند. این امکان را به شما می‌دهد که بلافاصله شروع به ترجمه، بازنویسی و تبدیل متن کنید. به‌عنوان گزینه دیگر، می‌توانید به‌صورت رایگان از Cerebras، Google، Groq یا Mistral AI نیز یک کلید API دریافت کنید.

به زبان ساده:

- یک **مدل**، موتور هوش مصنوعی است که کار را انجام می‌دهد. مدلهای موجود با یک **پیشوند ارائه‌دهنده** فهرست می‌شوند (برای مثال `openrouter/…`، `openai/…`، `ollama/…`).
- یک **کلید API** (یا برای Ollama، یک **آدرس پایه URL**) روشی است که برنامه از طریق آن به ارائه‌دهنده متصل می‌شود.

اگر از **برنامه دسکتاپ** استفاده می‌کنید، کلیدها را در بخش [**تنظیمات** > **پیکربندی API**](#api-config) برای هر ارائه‌دهنده‌ای که استفاده می‌کنید وارد کنید. برای استفاده فقط از OpenRouter، به بخش [چگونه یک کلید API رایگان تهیه کنیم](#how-to-get-an-api-key-desktop-app) در ادامه مراجعه کنید. اگر نمی‌خواهید از کلید API استفاده کنید، می‌توانید Ollama را از [ollama.com](https://ollama.com) نصب کرده و به‌جای آن از مدل‌های محلی مانند `translategemma:4b` استفاده کنید.

اگر از **نسخه وبی** برنامه استفاده می‌کنید، مدیر سرور ارائه‌دهندگان را از طریق متغیرهای محیطی پیکربندی می‌کند، بنابراین امکان وارد کردن مستقیم کلید API در برنامه وجود ندارد.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### چگونه یک کلید رایگان OpenRouter API بگیریم (برنامه دسکتاپ)

اگر از برنامه دسکتاپ استفاده می‌کنید، مراحل زیر را دنبال کنید:

1. به [OpenRouter](https://openrouter.ai) در مرورگر وب خود بروید.
2. یک حساب کاربری ایجاد کنید یا وارد شوید.
3. به صفحه [Keys](https://openrouter.ai/keys) بروید.
4. روی دکمه ایجاد یک کلید API جدید کلیک کنید.
5. به کلید نامی دهید تا بتوانید آن را در آینده شناسایی کنید.
6. کلید API جدید را کپی کنید.
7. به Transrewrt بازگردید و به بخش **تنظیمات** > **پیکربندی API** بروید.
8. کلید را در بخش **کلید API OpenRouter** (تحت **تنظیمات** > **پیکربندی API**) قرار دهید.
9. روی **تست کلید OpenRouter** کلیک کنید تا مطمئن شوید کلید کار می‌کند.

<br/><br/>

<a id="getting-started"></a>
## شروع کار

اگر برای اولین بار از Transrewrt استفاده می‌کنید، مراحل زیر را به ترتیب دنبال کنید:

1. برنامه را باز کنید.
2. در صورت نیاز، زبان **رابط کاربری** خود را از آیکون کره جهانی انتخاب کنید.
3. اگر از **برنامه دسکتاپ** استفاده می‌کنید، به [**تنظیمات** > **پیکربندی API**](#api-config) بروید، یک کلید API برای حداقل یک ارائه‌دهنده (مثلاً OpenRouter) اضافه کنید و روی **تست** کلیک کنید تا مطمئن شوید کلید کار می‌کند.
4. به [**تنظیمات** > **مدل‌ها**](#models) بروید و یک یا چند مدل را به بخش **مدل‌های انتخاب‌شده** اضافه کنید.
5. به [**تنظیمات** > **زبان‌ها**](#languages) بروید و اگر می‌خواهید زبان‌های پرکاربرد خود اول نمایش داده شوند، **زبان‌های برتر** خود را انتخاب کنید.
6. به بخش **ترجمه** بروید و یک ترجمه ساده انجام دهید تا مطمئن شوید همه‌چیز به‌درستی کار می‌کند.
7. پس از آن، **بازنویسی** و سپس **تبدیل** را امتحان کنید.

ترتیب این مراحل مهم است. این ترتیب از شایع‌ترین مشکل استفاده اولیه جلوگیری می‌کند: تلاش برای اجرای یک وظیفه قبل از آنکه برنامه ارتباط API کارآمدی داشته باشد یا مدلی انتخاب کرده باشید.

### نوار ابزار

ظاهر نوار ابزار کمی بسته به اینکه شما در کدام قسمت برنامه هستید، متفاوت خواهد بود.

- در سمت چپ، نام صفحه‌ی فعلی نمایش داده می‌شود.
- در سمت راست، **گزینشگر مدل** و کنترل **زبان رابط** قرار دارد.

**گزینشگر مدل** به شما امکان می‌دهد تا موتور هوش مصنوعی مناسب برای کار جاری را انتخاب کنید.

  ![گزینشگر مدل](../images/screenshots/fa/model-selector.png)

ممکن است برخی از مدل‌های رایگان همیشه در دسترس نباشند — گاهی اوقات این مدل‌ها آفلاین هستند یا محدودیت استفاده دارند. در این صورت، برنامه به طور خودکار آن مدل را از لیست در دسترس شما حذف می‌کند. برای مدیریت مدل‌های نمایش‌داده‌شده، به بخش [**تنظیمات** > **مدل‌ها**](#models) بروید و لیست مدل‌های خود را ویرایش کنید. 
همچنین می‌توانید مستقیماً با کلیک روی آیکون ارائه‌دهندهٔ سمت چپ نام مدل در نوار ابزار، به تنظیمات آن مدل دسترسی پیدا کنید.

<br/>

**آیکون کره‌ی زمین + کد زبان** زبان رابط کاربری برنامه (مانند منوها و دکمه‌ها) را تغییر می‌دهد. این گزینه **زبان‌های ترجمه** در بخش **ترجمه** را تغییر نمی‌دهد.

<a id="input-and-output-panels"></a>
### پنل‌های ورودی و خروجی

بیشتر فضاهای کاری از یک پنل **ورودی** در سمت چپ و یک پنل **خروجی** در سمت راست استفاده می‌کنند.

هر پنل شامل اطلاعات زیر است:

| **ورودی**                                                          | **خروجی**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - تعداد نویسه <br/>- تعداد کلمه <br/>- تعداد پاراگراف        | - مدت زمان انجام کار<br/>- **TPS** (توکن در ثانیه)<br/>- تعداد نویسه، کلمه و پاراگراف<br/>- مدل استفاده‌شده |


اگر در مورد اصطلاحات فنی کنجکاو هستید:

- **توکن** به معنای یک تکه کوچک از متن است. می‌توانید آن را بخشی از یک کلمه یا یک کلمهٔ کوتاه در نظر بگیرید.
- **TPS** به این معناست که مدل در هر ثانیه چند تا از این تکه‌های متنی را پردازش کرده است.

<br/>

همچنین می‌توانید هزینهٔ هر عملیات (در صورت در دسترس بودن) و هزینهٔ کلی را نظارت کنید، با فعال‌کردن گزینهٔ `نمایش اطلاعات هزینه در اقدامات` در بخش [**تنظیمات** > **تنظیمات کلی**](#general-settings).

<a id="translate"></a>
## ترجمه

از بخش **ترجمه** زمانی استفاده کنید که بخواهید متنی را از یک زبان به زبان دیگر تبدیل کنید.

![فضای کاری ترجمه](../images/screenshots/fa/translate.png)

<br/>

<a id="translate-text"></a>
### ترجمهٔ متن

1. بخش **ترجمه** را باز کنید.
2. زبان مبدأ را در فیلد **از** انتخاب کنید.
3. زبان مقصد را در فیلد **به** انتخاب کنید.
4. یک مدل را در نوار ابزار انتخاب کنید.
5. متن را در پنل **ورودی** تایپ یا بچسبانید.
6. روی دکمهٔ **ترجمه** کلیک کنید.
7. نتیجه را در پنل **خروجی** بخوانید.
8. در صورت تمایل، از دکمهٔ کپی برای کپی کردن نتیجه استفاده کنید.

<br/>

<a id="transform"></a>

## تبدیل

از بخش **تبدیل** زمانی استفاده کنید که می‌خواهید هوش مصنوعی دستورالعمل‌های سفارشی شما را دنبال کند.

![فضای کار تبدیل](../images/screenshots/fa/transform.png)

این بخش انعطاف‌پذیرترین بخش برنامه است. می‌توانید از آن برای انجام کارهایی مانند زیر استفاده کنید:

- خلاصه‌سازی یادداشت‌ها
- تبدیل متن خام به ایمیلی روان و حرفه‌ای
- استخراج نکات کلیدی
- تبدیل متن به فرمت مشخصی
- هر فعالیت سفارشی دیگری با متن ورودی

<br/>

<a id="run-an-existing-prompt"></a>
### اجرای یک دستور از پیش تعریف شده

1. بخش **تبدیل** را باز کنید.
2. یک دستور (prompt) را از لیست دستورها انتخاب کنید.
3. اگر کادر **زبان مقصد** نمایش داده شد، در صورت تمایل زبانی را انتخاب کنید.
4. متن را در بخش **ورودی** تایپ یا قرار دهید.
5. روی دکمه **تبدیل** کلیک کنید.
6. نتیجه را در بخش **خروجی** بخوانید.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### اگر هنوز دستوری ندارید

اگر لیست دستورها خالی است، روی **بارگذاری دستورهای نمونه** کلیک کنید. این کار به شما چند مثال از پیش تعریف شده اضافه می‌کند تا بتوانید سریع شروع کنید.

<br/>

> ℹ️ **یادداشت**<br/>
> دستورهای نمونه به زبان انگلیسی ارائه می‌شوند. پس از بارگیری، می‌توانید یک دستور را ویرایش کنید و از گزینه **ترجمه دستور** استفاده کنید تا آن را به زبان خود ترجمه کنید.

<br/>

<a id="create-a-prompt-quickly"></a>
### سریع ایجاد کردن یک دستور

سریع‌ترین راه برای ایجاد یک دستور این است:

1. روی **دستور جدید** کلیک کنید.
2. روی **تولید دستور** کلیک کنید.
3. توضیح دهید که می‌خواهید دستور چه کاری انجام دهد.
4. یک مدل را انتخاب کنید.
5. اجازه دهید برنامه یک پیش‌نویس برای شما ایجاد کند.
6. پیش‌نویس را بررسی و سپس روی **ذخیره** کلیک کنید.

![تولید دستور](../images/screenshots/fa/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### ویرایش یک دستور

هنگام ایجاد یا ویرایش یک دستور، ویرایشگر در سمت چپ ظاهر می‌شود و یک فضای آزمایشی در سمت راست نمایش داده می‌شود.

![ویرایشگر دستور تبدیل](../images/screenshots/fa/transform-prompt-edit.png)

فیلدهای اصلی عبارتند از:

- **نام دستور**: نامی که در لیست دستورها نمایش داده می‌شود.
- **دستورالعمل‌های دستور (اختیاری)**: یک راهنمای کوتاه که هنگام اجرای دستور به کاربر نمایش داده می‌شود.
- **نقش مدل**: نقش کلی که به هوش مصنوعی تعلق می‌گیرد، مانند «شما یک دستیار مفید هستید.»
- **دستورالعمل‌های مدل (یکی در هر خط)**: قوانین خاصی که می‌خواهید هوش مصنوعی دنبال کند.
- **توضیح خروجی**: یک کلمه کوتاه که نتیجه را توصیف می‌کند، مانند «خلاصه» یا «بازنویسی».
- **دما (0.0 → 1.0)**: رفتار مدل؛ به پایین‌تر توضیح داده شده است.
- **درخواست زبان مقصد**: هنگام اجرای دستور، یک انتخاب‌گر برای زبان مقصد اضافه می‌کند.

اگر اصطلاح فنی **دما** برای شما جدید است، می‌توانید آن را به این شکل در نظر بگیرید:

- **دمای پایین‌تر** نتایجی پایدارتر و قابل پیش‌بینی‌تر ارائه می‌دهد.
- **دمای بالاتر** تنوع و خلاقیت بیشتری ایجاد می‌کند.

همچنین می‌توانید از این گزینه‌ها استفاده کنید:

- **`تولید دستور`** برای ایجاد یک پیش‌نویس جدید بر اساس یک توصیف ساده
- **`بهبود دستور`** برای بهینه‌سازی دستور موجود
- **`ترجمه دستور`** برای ترجمه فیلدهای دستور

<br/>

> ⚠️ **هشدار**<br/>
> قبل از اینکه روی **`بازگشت به اجرا`** کلیک کنید، روی **`ذخیره`** کلیک کنید. در صورتی که بدون ذخیره بازگردید، تغییرات شما از بین می‌رود.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### آزمایش دستور قبل از استفاده از آن

صفحه آزمایش در سمت راست، امکان تست دستور شما با متن نمونه را پیش از استفاده در کارهای روزمره فراهم می‌کند.

این کار در شرایط زیر مفید است:

- هنگام ساخت یک دستور جدید
- هنگام مقایسه دو نسخه مختلف از یک دستور
- هنگام چک کردن لحن، طول یا فرمت خروجی

<br/>

> ℹ️ **یادداشت**<br/>
> می‌توانید دستورهای ذخیره‌شده را در بخش [**تنظیمات** > **دستورهای تبدیل**](#transform-prompts) صادر و وارد کنید.

<a id="general-settings"></a>
### تنظیمات عمومی

از **تنظیمات عمومی** برای کنترل رفتار تایپ کردن، ذخیره شدن جزئیات اجرا برای بخش **تاریخچه** و ظاهر برنامه استفاده کنید.

**رفتار**

- **رفتار کلید ENTER**: مشخص می‌کند که `Enter` کار را اجرا کند یا خط جدیدی ایجاد کند.
- **ترجمه خودکار هنگام قراردادن**: به محض قرار دادن متن، ترجمه را شروع می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد**: نتایج موفق را به صورت خودکار کپی می‌کند.
- **ترجمه لحظه‌ای (هنگام تایپ)**: در حین تایپ، ترجمه انجام می‌شود.
- **زمان انتظار (میلی‌ثانیه)**: مدت زمان انتظار برای ترجمه لحظه‌ای را تنظیم می‌کند.

**تاریخچه**

- **نگهداری تاریخچه اجرا**: تعیین می‌کند که آیا ورودی و خروجی هر ترجمه، بازنویسی و تبدیل برای دیدن در [**تاریخچه**](#history) نوار کناری ذخیره شود یا خیر. با غیرفعال کردن آن درخواست تأیید می‌شود؛ در صورت تأیید، متن تاریخچه ذخیره‌شده از پایگاه داده حذف می‌شود.
- **حذف داده‌های تاریخچه**: با استفاده از **حذف داده** امکان حذف متن ذخیره‌شده بر اساس سن (مثلاً قدیمی‌تر از چند ماه یا **همه داده‌ها (پاک‌سازی)**) فراهم است. این عمل فقط بر متن‌های اجرای ذخیره‌شده برای نمایش در بخش **تاریخچه** اثر دارد و **بر روی** جمع‌بندی‌های هزینه یا میزان استفاده تأثیر **ندارد**. برای حذف یا کاهش داده‌های **هزینه**، از [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) استفاده کنید.

**ظاهر**

- **نمایش اطلاعات هزینه در عملیات**: نمایش هزینه هر عمل (در صورت موجود بودن) و کل هزینه را در پنل‌های خروجی ترجمه، بازنویسی و تبدیل کنترل می‌کند.
- **تعداد ارقام اعشار هزینه**: نحوه نمایش اعشار هزینه را تغییر می‌دهد.
- **فقط وب:** **نمایش حاشیه‌ای در اطراف برنامه** فضای اضافی در اطراف رابط کاربری ایجاد می‌کند.
- **خانواده فونت**: فونت نوشتن را در پنل‌های متنی تغییر می‌دهد.
- **اندازه**: اندازه فونت را تغییر می‌دهد.


<br/>

<a id="models"></a>

### مدل‌ها

برای انتخاب اینکه کدام مدل‌ها در نوار ابزار نمایش داده شوند، از **تنظیمات** > **مدل‌ها** استفاده کنید.

![زبانه مدل‌های تنظیمات](../images/screenshots/fa/settings-models.png)

این صفحه دارای دو لیست است:

- **مدل‌های موجود** در سمت چپ
- **مدل‌های انتخاب‌شده** در سمت راست

کنترل‌های مفید شامل موارد زیر هستند:

- **جستجوی مدل‌ها...** برای یافتن مدلی با نام مشخص
- **چیپس ارائه‌دهنده** برای محدود کردن لیست به یک موتور (OpenRouter، OpenAI، Ollama، …)
- **فقط رایگان** برای نمایش تنها مدل‌های رایگان
- **تازه‌سازی** برای بارگیری مجدد لیست
- **گسترش همه** و **جمع‌کردن همه** هنگام مرتب‌سازی بر اساس ارائه‌دهنده

شناسه‌های مدل شامل پیشوند ارائه‌دهنده هستند (برای مثال `openrouter/…` در مقابل `openai/…`). نشان‌هایی مانند **OpenAI (OpenRouter)** در مقابل **OpenAI (مستقیم)** نشان می‌دهند که ترافیک چگونه مسیریابی می‌شود.

> ℹ️ **یادداشت**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) یک مدل مسیریاب است، نه یک مدل گفتگوی عمومی: پاسخ آن JSON است که بدن درخواست‌های API OpenRouter را توصیف می‌کند (برای مثال یک آرایه `requests` با `model` و `messages`). اگر آن را برای **ترجمه**، **بازنویسی** یا **تبدیل** استفاده کنید، پنل خروجی این JSON را نشان می‌دهد نه متن نهایی. برای این کارها یک مدل متنی معمولی را انتخاب کنید. صفحه مدل [Body Builder](https://openrouter.ai/openrouter/bodybuilder) در OpenRouter را ببینید.

عملیات:

 - برای افزودن یک مدل، روی **افزودن** یا هر جای دیگر در آن مدل کلیک کنید.

 - برای حذف مدل، روی **X** کنار آن در بخش **مدل‌های انتخاب‌شده** کلیک کنید یا در لیست مدل‌های موجود، روی **انتخاب‌شده** کلیک کنید.

 - برای پاک کردن لیست، روی **لغو انتخاب همه** کلیک کنید. مدل رایگان لازم در لیست باقی خواهد ماند.

<br/>

> ℹ️ **یادداشت**<br/>
> اگر نمی‌خواهید بلافاصله اعتبار به OpenRouter اضافه کنید، ابتدا **فقط رایگان** را فعال کنید و مدل‌های رایگان را انتخاب نمایید (نیازی به کارت اعتباری نیست). همچنین می‌توانید از Ollama برای اجرای مدل‌ها به‌صورت محلی بدون هیچ کلید API استفاده کنید.

<br/>

<a id="languages"></a>
### زبان‌ها

از **تنظیمات** > **زبان‌ها** برای مدیریت لیست زبان‌های مورد استفاده در برنامه استفاده کنید.

- **زبان‌های برتر** در بالای لیست زبان‌ها در بخش **ترجمه** و **تبدیل** ثابت شده‌اند.
- **زبان سفارشی** به شما امکان افزودن زبانی که در لیست داخلی وجود ندارد را می‌دهد.

اگر یک زبان سفارشی اضافه کنید، در کنار گزینه‌های داخلی در انتخاب‌کننده‌های زبان ظاهر خواهد شد.

<br/>

<a id="cost-tracking"></a>
### ردیابی هزینه

از **تنظیمات** > **ردیابی هزینه** برای مدیریت اطلاعات هزینه استفاده کنید.

- **هزینه کل** مجموع رو به رشد را نشان می‌دهد.
- **کپی کردن مقدار** کل مقدار را به کلیپ‌بورد کپی می‌کند.
- **بازنشانی هزینه** مجموع ذخیره‌شده را به صفر برمی‌گرداند.
- **همگام‌سازی با مصرف کلید API** کل مجموع را برابر با مصرف گزارش‌شده از حساب OpenRouter شما تنظیم می‌کند (فقط OpenRouter).
- **مصرف کلید API** جزئیات مصرف OpenRouter را در صورت در دسترس بودن نشان می‌دهد.
- **حذف داده هزینه** تمام داده‌ها یا تنها موارد قدیمی‌تر از یک تاریخ مشخص را پاک می‌کند.

**ردیابی هزینه:** هنگام استفاده از مدل‌های OpenRouter، برنامه مصرف واقعی و هزینه شما را بر اساس اطلاعات هزینه از OpenRouter نشان می‌دهد. برای سایر ارائه‌دهندگان، برنامه هزینه را با استفاده از قیمت‌های انتشار یافته توسط OpenRouter تخمین می‌زند؛ اگر قیمتی موجود نباشد، تخمین ممکن است صفر باشد.

<br/>

> ℹ️ **یادداشت**<br/>
> **تمام ارقام هزینه تنها تخمینی هستند و صرفاً جهت اطلاع‌رسانی شما ارائه می‌شوند، نه بیانیه‌های رسمی صورتحساب.**

<br/>

> ⚠️ **هشدار**<br/>
> حذف داده‌ها قابل بازگردانی نیست. قبل از حذف، از داده‌های خود پشتیبان تهیه کنید یا آن‌ها را از طریق [**تاریخچه**](#history) یا [**داده‌بازار** > **تمامی فراخوانی‌ها**](#dashboard-tabs) خارج کنید؛ در غیر این صورت به‌طور دائم از بین خواهند رفت. تمام تاریخچه ورودی/خروجی مربوط به هر مورد فراخوانی API نیز حذف خواهد شد.

<br/>

<a id="transform-prompts"></a>
### دستورات تبدیل

از **تنظیمات** > **دستورات تبدیل** برای مدیریت دستورها به صورت گروهی استفاده کنید.

شما می‌توانید:

- دستورهای ذخیره‌شده خود را مرور کنید
- دستورها را حذف نمایید
- دستورها را از یک فایل وارد کنید
- دستورها را برای پشتیبان‌گیری یا اشتراک‌گذاری خارج کنید

<br/>

<a id="users"></a>
### کاربران

از بخش **کاربران** برای مدیریت حساب‌های کاربری در نسخه وب استفاده کنید. می‌توانید کاربر اضافه کنید، اطلاعات آن‌ها را به‌روز کنید، رمزهای عبور را بازنشانی و حساب‌ها را حذف کنید.

<br/>

<a id="api-config"></a>
### تنظیمات API

ارائه‌دهندگان پشتیبانی‌شده عبارتند از: OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و **Ollama** (مدل‌های محلی از طریق یک آدرس URL اصلی). فقط نیاز دارید که ارائه‌دهندگانی را که استفاده می‌کنید پیکربندی کنید.

**برنامه وب: فقط مدیر**

کلیدهای API از طریق متغیرهای محیطی سیستم یا داکر پیکربندی می‌شوند — وارد رابط کاربری وب نمی‌شوند. این صفحه نشان می‌دهد که کدام ارائه‌دهندگان دارای کلید پیکربندی‌شده هستند و به شما امکان تست هر یک را با کلیک بر دکمه **`آزمون`** می‌دهد.

<br/>

> ℹ️ **یادداشت**<br/>
> برای تغییر یک کلید API، متغیر محیطی را در تنظیمات سیستم یا داکر به‌روز کنید و سرور یا کانتینر را مجدداً راه‌اندازی کنید.

<br/>

**برنامه دسکتاپ**

از **پیکربندی API** برای ذخیره کلیدهای API هر ارائه‌دهنده‌ای که استفاده می‌کنید استفاده کنید. برای Ollama، به جای کلید API آدرس **URL اصلی** را وارد کنید.

<br/>

> 💡 **نکته** <br/>
> اگر نمی‌خواهید از کلید API استفاده کنید یا هزینه پرداخت کنید، می‌توانید [Ollama را دانلود](https://ollama.com) و مدل‌هایی (مانند `translategemma:4b`) را به صورت رایگان روی ماشین خود اجرا کنید. همچنین می‌توانید یک حساب رایگان OpenRouter ایجاد کنید (نیازی به کارت اعتباری نیست) تا از مدل‌های رایگان آن استفاده کنید، یا یک کلید رایگان API از Cerebras، Google، Groq یا Mistral AI دریافت کنید.

<br/>

- فقط ارائه‌دهندگانی را اضافه کنید که نیاز دارید. در بخش **تنظیمات** > **مدل‌ها**، هر شناسه مدل با ارائه‌دهنده شروع می‌شود (برای مثال `openrouter/openrouter/free`، `openai/gpt-4o`، `ollama/llama3`).

برای افزودن یک کلید API، مقدار آن را در کادر متنی وارد کرده و روی **`ذخیره`** کلیک کنید. برای جایگزینی یک کلید موجود، روی **`ویرایش`** کلیک کنید. برای بررسی اینکه آیا کلید کار می‌کند، روی **`آزمون`** کلیک کنید. برای URL اصلی Ollama، همیشه روی **`آزمون`** کلیک کنید تا اتصال بررسی شود.

<br/>

> ℹ️ **یادداشت**<br/>
> شما نمی‌توانید مقدار فعلی یک کلید API را مشاهده کنید. فقط می‌توانید آن را با دکمه **`ویرایش`** جایگزین کنید.
> کلیدهای API به صورت رمزگذاری شده در پیکربندی ذخیره می‌شوند.

<a id="common-issues"></a>
## مشکلات رایج

اگر چیزی به شکل انتظار عمل نمی‌کند، ابتدا موارد زیر را بررسی کنید.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### برنامه متن را ترجمه، بازنویسی یا تبدیل نمی‌کند

مطمئن شوید:

- یک مدل را در نوار ابزار انتخاب کرده‌اید
- حداقل یک مدل در بخش [**تنظیمات** > **مدل‌ها**](#models) فهرست شده است
- تنظیمات API شما به درستی کار می‌کند

اگر از نسخهٔ دسکتاپ استفاده می‌کنید:

1. بخش [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید.
2. مطمئن شوید حداقل یک کلید API ذخیره شده است.
3. روی **تست** کنار ارائه‌دهنده کلیک کنید تا فعال بودن کلید تأیید شود.

<br/>

<a id="the-model-list-is-empty"></a>
### لیست مدل‌ها خالی است

به [**تنظیمات** > **مدل‌ها**](#models) بروید و روی **تازه‌سازی** کلیک کنید.

در صورت نیاز:

- یک مدل را جستجو کنید
- گزینهٔ **فقط رایگان** را فعال کنید
- یک یا چند مدل را به بخش **مدل‌های انتخاب شده** اضافه کنید

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### نتیجه بسیار کند یا گران است

یک یا چند مورد از موارد زیر را امتحان کنید:

- یک مدل دیگر را انتخاب کنید
- ورودی کوتاه‌تری استفاده کنید
- گزینهٔ **ترجمهٔ لحظه‌ای (در حین تایپ)** را در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) غیرفعال کنید
- برای کارهای ساده از مدل‌های رایگان استفاده کنید (راجب [مدل‌ها](#models) را ببینید)

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### رابط به زبان اشتباه است

روی آیکون کرهٔ زمین در [نوار ابزار](#toolbar) کلیک کنید و **زبان رابط** موردنظر خود را انتخاب کنید.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### متن بسیار کوچک یا خوانا نیست

به [**تنظیمات** > **تنظیمات عمومی**](#general-settings) بروید و موارد زیر را تغییر دهید:

- **خانوادهٔ قلم**
- **اندازه**

<br/>

<a id="dashboard-charts-are-empty"></a>
### نمودارهای داشبورد خالی هستند

این امر در شرایط زیر طبیعی است:

- فقط از **مدل‌های رایگان** استفاده می‌کنید (نمودار هزینه خالی خواهد بود)
- **فیلتر زمان** انتخاب شده شامل دوره‌ای نیست که در آن درخواست‌ها ارسال شده‌اند — فیلتر **همه** را امتحان کنید

اگر پس از انتخاب **همه** همچنان نمودارها خالی هستند، مطمئن شوید درخواست‌ها در بخش [**تاریخچه**](#history) یا در زبانهٔ **همهٔ درخواست‌ها** نمایش داده می‌شوند.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### هزینه نمایش داده شده "غیرقابل دسترسی" است یا اشتباه به نظر می‌رسد

زمانی که از مدل‌ها از طریق **OpenRouter** استفاده می‌کنید، برنامه هزینهٔ واقعی گزارش شده از سوی OpenRouter را نمایش می‌دهد.

برای **سایر ارائه‌دهندگان** (مثل OpenAI مستقیم، Anthropic مستقیم و غیره) هزینه با استفاده از داده‌های قیمت‌گذاری منتشر شده توسط OpenRouter تخمین زده می‌شود. اگر قیمتی برای یک مدل یافت نشود، هزینه به صورت **غیرقابل دسترسی** نمایش داده می‌شود و به جمع کل شما اضافه نمی‌شود.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### مجموع هزینه با صورت‌وضع حساب ارائه‌دهنده من همخوانی ندارد

همهٔ ارقام هزینه در برنامه **صرفاً تخمینی بوده و تنها برای اطلاع** هستند، نه یک صورت‌حساب رسمی.

برای نزدیک کردن مجموع به هزینهٔ واقعی شما در OpenRouter، به [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) بروید و روی **همگام‌سازی با مصرف کلید API** کلیک کنید.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### صفحهٔ تاریخچه در نوار کناری وجود ندارد

گزینهٔ **ذخیره کردن تاریخچهٔ اجرا** ممکن است غیرفعال باشد. به [**تنظیمات** > **تنظیمات عمومی**](#general-settings) بروید و آن را فعال کنید. توجه داشته باشید که فعال کردن آن، داده‌های تاریخچهٔ حذف شدهٔ قبلی را بازیابی نمی‌کند.

<br/>

<a id="web-app-session-expired"></a>
### برنامهٔ وب: به طور غیرمنتظره به صفحهٔ ورود هدایت می‌شود

ممکن است جلسهٔ شما منقضی شده باشد. دوباره وارد شوید. اگر این موضوع اغلب اتفاق می‌افتد، تنظیمات طول عمر جلسه در پیکربندی سرور را بررسی کنید.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### داشبورد داده‌ای برای کاربران دیگر نمایش نمی‌دهد (وب)

فقط **مدیران** می‌توانند از طریق فیلتر **کاربر**، داده‌های همهٔ کاربران را مشاهده کنند. کاربران عادی به طور طراحی فقط فعالیت خود را می‌بینند.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### تغییراتی اعمال کردم و ویرایش‌ها را از دست دادم

هنگام ویرایش یک پِرامِت، همیشه قبل از کلیک روی **بازگشت به اجرا**، روی **ذخیره** کلیک کنید.

<br/><br/>

<a id="quick-tips"></a>
## نکات سریع

- برای اطمینان از سالم بودن تنظیمات خود، با [**ترجمه**](#translate) شروع کنید و قبل از رفتن به [**بازنویسی**](#rewrite) یا [**تبدیل**](#transform) آن را مطمئن شوید.
- از [**بازنویسی**](#rewrite) برای بهبود سادهٔ متن روزمره استفاده کنید.
- از [**تبدیل**](#transform) هنگامی استفاده کنید که برای یک کار خاص نیاز به یک فرآیند قابل تکرار دارید.
- از [**داشبورد**](#dashboard) برای پایش مصرف و هزینه استفاده کنید.
- از [**تاریخچه**](#history) برای بازبینی عملیات گذشته و متن کامل ورودی/خروجی آن‌ها استفاده کنید.
- اگر یک کتابخانهٔ پِرامِت می‌سازید که می‌خواهید ایمن نگه دارید (نگاه کنید به [تبدیل پِرامِت‌ها](#transform-prompts)) یا آن را با دیگران به اشتراک بگذارید، به طور منظم آن‌ها را صادر کنید.
