# راهنمای کاربر

<br/>

<a id="introduction"></a>
## معرفی

Transrewrt به شما در کار با متن به سه روش اصلی کمک می‌کند:

- **ترجمه** - تبدیل متن از یک زبان به زبان دیگر.
- **بازنویسی** - بازنویسی متن با سبکی متفاوت، مانند شفاف‌تر، کوتاه‌تر یا رسمی‌تر.
- **تبدیل** - پردازش متن با استفاده از دستورالعمل‌های هوش مصنوعی سفارشی که به آن‌ها «دستورالعمل‌ها» گفته می‌شود.

به‌طور پیش‌فرض، برنامه در حالت **آسان** اجرا می‌شود: شما یک **مهارت** (به عنوان مثال رایگان (OpenRouter)، Lite، یا فنی) و یک **ارائه‌دهنده** را در تنظیمات انتخاب می‌کنید، بدون اینکه شناسه‌های مدل را انتخاب کنید. اگر می‌خواهید لیست مدل کلاسیک را از [**تنظیمات** > **مدل‌ها**](#models) مشاهده کنید، به **پیشرفته** در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) سوئیچ کنید.

<br/>

این راهنما نحوه استفاده از برنامه پس از نصب و راه‌اندازی آن را توضیح می‌دهد. برای مراحل نصب، به [**README**](README.fa.md) اصلی مراجعه کنید.

<br/>

> ℹ️ **توجه**<br/>
> Transrewrt به صورت برنامه دسکتاپ برای ویندوز و لینوکس و همچنین به صورت برنامه تحت وب قابل میزبانی شخصی در دسترس است. این راهنما بر استفاده روزمره از برنامه تمرکز دارد. هرگاه موردی فقط به یک نسخه مربوط باشد، به وضوح مشخص شده است.

<a id="before-you-start"></a>
## قبل از شروع

برای استفاده از Transrewrt، باید دسترسی به حداقل یک ارائه‌دهنده هوش مصنوعی داشته باشید. ارائه‌دهندگان پشتیبانی‌شده عبارتند از: [OpenRouter](https://openrouter.ai) (که مدل‌های زیادی را تجمیع می‌کند)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و [Ollama](https://ollama.com) برای مدل‌های محلی.

نیازی به انتخاب مدل پولی برای شروع ندارید. به محض اینکه کلید API OpenRouter خود را اضافه کنید، برنامه به‌صورت خودکار یک گزینه **رایگان** داخلی OpenRouter را فعال می‌کند. این امکان را فراهم می‌کند که بلافاصله شروع به ترجمه، بازنویسی و تبدیل متن کنید. به‌عنوان گزینه دیگر، می‌توانید کلید API رایگانی از Cerebras، Google، Groq یا Mistral AI دریافت کنید.

به زبان ساده:

- در حالت **آسان**، یک **مهارت** یک پیش‌تنظیم (رایگان (OpenRouter)، Lite، پیشرفته یا فنی) است که به یک مدل برای **ارائه‌دهنده** انتخابی شما (OpenRouter، OpenAI، Ollama و دیگران) متصل می‌شود. تنها مهارت‌هایی که برای ارائه‌دهنده فعلی نقشه‌برداری شده‌اند، در نوار ابزار ظاهر می‌شوند. شما مهارت را در ترجمه، بازنویسی و تبدیل انتخاب می‌کنید.
- در حالت **پیشرفته**، یک **مدل** موتور هوش مصنوعی است که شما به‌طور مستقیم انتخاب می‌کنید. شناسه‌های مدل از یک **پیشوند ارائه‌دهنده** استفاده می‌کنند (به‌عنوان مثال `openrouter/…`, `openai/…`, `ollama/…`).
- یک **کلید API** (یا برای Ollama، یک **آدرس پایه**) روشی است که برنامه به آن ارائه‌دهنده دسترسی پیدا می‌کند.

اگر از **برنامه دسکتاپ** استفاده می‌کنید، کلیدها را در [**تنظیمات** > **پیکربندی API**](#api-config) برای هر ارائه‌دهنده‌ای که استفاده می‌کنید، اضافه کنید. برای استفاده فقط از OpenRouter، به [چگونه یک کلید API رایگان OpenRouter بگیرید](#how-to-get-a-free-openrouter-api-key-desktop-app) در زیر مراجعه کنید. اگر نمی‌خواهید از یک کلید API استفاده کنید، می‌توانید Ollama را نصب کنید (از [ollama.com](https://ollama.com)) و از مدل‌های محلی به‌جای آن استفاده کنید، مانند `translategemma:4b`.

اگر از **نسخه وبی** استفاده می‌کنید، مالک سرور ارائه‌دهندگان را از طریق متغیرهای محیطی پیکربندی می‌کند، بنابراین شما نمی‌توانید کلیدهای API را مستقیماً در برنامه وارد کنید.

<br/>

<a id="how-to-get-a-free-openrouter-api-key-desktop-app"></a>
### چگونه یک کلید API رایگان OpenRouter بگیرید (برنامه دسکتاپ)

اگر از برنامه دسکتاپی استفاده می‌کنید، مراحل زیر را دنبال کنید:

1. در مرورگر وب خود به [OpenRouter](https://openrouter.ai) بروید.
2. یک حساب کاربری ایجاد کنید یا وارد شوید.
3. صفحه [Keys](https://openrouter.ai/keys) را باز کنید.
4. روی دکمه ایجاد کلید API جدید کلیک کنید.
5. به کلید نامی اختصاص دهید تا بتوانید بعداً آن را تشخیص دهید.
6. کلید جدید را کپی کنید.
7. به Transrewrt بازگردید و بخش **تنظیمات** > **پیکربندی API** را باز کنید.
8. کلید را در فیلد **کلید API OpenRouter** (در بخش **تنظیمات** > **پیکربندی API**) بچسبانید.
9. روی **تست کلید OpenRouter** کلیک کنید تا از صحت کارکرد آن اطمینان حاصل کنید.

<a id="getting-started"></a>
## شروع کار

اگر اولین بار است که از Transrewrt استفاده می‌کنید، مراحل زیر را به ترتیب دنبال کنید:

1. برنامه را باز کنید.
2. در صورت نیاز، **زبان رابط** خود را از آیکون کره زمین انتخاب کنید.
3. اگر از **برنامه دسکتاپ** استفاده می‌کنید، بخش [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید، یک کلید API برای حداقل یک ارائه‌دهنده (برای مثال OpenRouter) اضافه کنید و روی **تست** کلیک کنید تا از صحت آن اطمینان حاصل کنید.
4. بخش [**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید. در حالت **آسان** (پیش‌فرض)، یک **ارائه‌دهنده** که کلید آن تنظیم شده است انتخاب کنید. در حالت **پیشرفته**، بخش [**تنظیمات** > **مدل‌ها**](#models) را باز کنید و یک یا چند مدل را به بخش **مدل‌های انتخاب شده** اضافه کنید.
5. در بخش **ترجمه**، یک **مهارت** (حالت آسان) یا **مدل** (حالت پیشرفته) را در نوار ابزار انتخاب کنید.
6. بخش [**تنظیمات** > **زبان‌ها**](#languages) را باز کنید و در صورت تمایل، **زبان‌های برتر** خود را انتخاب کنید تا زبان‌های پرکاربرد شما در ابتدای لیست نمایش داده شوند.
7. یک ترجمه ساده انجام دهید تا از صحت عملکرد همه چیز اطمینان حاصل کنید، سپس از **بازنویسی** و **تبدیل** استفاده کنید.

ترتیب این مراحل مهم است. این ترتیب از شایع‌ترین مشکل در استفاده اولیه جلوگیری می‌کند: انجام یک کار قبل از اینکه برنامه ارتباط API کارآمدی داشته باشد یا مهارت/مدلی انتخاب شده باشد.

<a id="toolbar"></a>
### نوار ابزار

نوار ابزار کمی بسته به اینکه در کجای برنامه هستید تغییر می‌کند.

- در سمت چپ، نام صفحه فعلی نمایش داده می‌شود.
- در سمت راست، **انتخاب‌گر مهارت یا مدل** و کنترل **زبان رابط** قرار دارد.

در حالت **آسان**، نوار ابزار یک **انتخاب‌گر مهارت** با پیش‌تنظیم‌های داخلی **رایگان (OpenRouter)**، **Lite**، **پیشرفته** و **فنی** را نشان می‌دهد. اینکه کدام مهارت‌ها ظاهر می‌شوند به **ارائه‌دهنده**‌ای که در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) انتخاب کرده‌اید بستگی دارد—به‌عنوان مثال، **رایگان (OpenRouter)** تنها زمانی فهرست می‌شود که ارائه‌دهنده OpenRouter باشد. اگر **ارائه‌دهنده** **Ollama** باشد، نوار ابزار مدل‌های محلی نصب‌شده شما را به‌جای مهارت‌ها فهرست می‌کند.

در حالت **پیشرفته**، **انتخاب‌گر مدل** به شما امکان می‌دهد که موتور هوش مصنوعی مورد استفاده برای کار فعلی را انتخاب کنید.

![Model selector](../images/screenshots/fa/model-selector.png)

در حالت پیشرفته، برخی مدل‌های رایگان ممکن است همیشه در دسترس نباشند — ممکن است آفلاین باشند یا به سقف مصرف رسیده باشند. برنامه ممکن است به‌صورت خودکار آن مدل را از لیست شما حذف کند. برای کنترل مدل‌هایی که نمایش داده می‌شوند، به بخش [**تنظیمات** > **مدل‌ها**](#models) بروید. می‌توانید تنظیمات مدل را از طریق آیکون ارائه‌دهنده در سمت چپ نام مدل در نوار ابزار باز کنید.

<br/>

آیکون **گلوب و کد زبان** زبان رابط برنامه، مانند منوها و دکمه‌ها را تغییر می‌دهد. این تنظیم **بر زبان‌های ترجمه** استفاده شده در **ترجمه** تأثیر نمی‌گذارد.

<a id="input-and-output-panels"></a>
### پنل‌های ورودی و خروجی

بیشتر فضاهای کار از یک پنل چپ برای **ورودی** و یک پنل راست برای **خروجی** استفاده می‌کنند.

هر پنل همچنین شامل موارد زیر است:

| **ورودی**                                                          | **خروجی**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - تعداد کاراکتر <br/>- تعداد کلمه <br/>- تعداد پاراگراف   <br/> | - مدت زمان انجام کار <br/>- **TPS** (توکن در ثانیه) <br/>- تعداد کاراکتر، کلمه و پاراگراف <br/>- مدل استفاده‌شده |

اگر در مورد اصطلاحات فنی سوالی دارید:

- **توکن** به معنای یک تکه کوچک از متن است. می‌توانید آن را بخشی از یک کلمه یا یک کلمه کوتاه در نظر بگیرید.
- **TPS** به این معناست که مدل در هر ثانیه چند تکه از این متن را پردازش کرده است.

<br/>

همچنین می‌توانید هزینه هر عملیات (در صورت در دسترس بودن) و هزینه کل را با فعال‌کردن گزینه `Show cost information on the actions` در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) پیگیری کنید.

<a id="translate"></a>
## ترجمه

از **ترجمه** زمانی استفاده کنید که بخواهید متنی را از یک زبان به زبان دیگر تبدیل کنید.

![Translate workspace](../images/screenshots/fa/translate.png)

<br/>

<a id="translate-text"></a>
### ترجمه متن

1. بخش **ترجمه** را باز کنید.
2. یک زبان را در بخش **از** انتخاب کنید.
3. یک زبان را در بخش **به** انتخاب کنید.
4. یک مهارت (حالت آسان) یا مدل (حالت پیشرفته) را در نوار ابزار انتخاب کنید.
5. متن را در **ورودی** تایپ یا چسبانده کنید.
6. روی **ترجمه** کلیک کنید.
7. نتیجه را در **خروجی** بخوانید.
8. در صورت تمایل به کپی کردن نتیجه، از دکمه کپی استفاده کنید.

<br/>

<a id="language-selection"></a>
### انتخاب زبان

- **از** می‌تواند یک زبان خاص یا **تشخیص زبان** باشد.
- **به** زبانی است که می‌خواهید نتیجه به آن زبان باشد.

**زبان‌های برتر** انتخاب‌شده شما در بالای فهرست نمایش داده می‌شوند. می‌توانید این موارد را در [**تنظیمات** > **زبان‌ها**](#languages) تنظیم کنید.

<br/>

<a id="helpful-translation-settings"></a>
### تنظیمات مفید ترجمه

در [**تنظیمات** > **تنظیمات عمومی**](#general-settings)، می‌توانید نحوه عملکرد ترجمه را تغییر دهید:

- **ترجمه خودکار هنگام چسباندن** به محض چسباندن متن، ترجمه را اجرا می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد** به‌صورت خودکار پس از اجرای موفق نتیجه را کپی می‌کند.
- **ترجمه لحظه‌ای (در حین تایپ)** در حین تایپ شما ترجمه را اجرا می‌کند.
- **زمان انتظار (ms)** تعیین می‌کند که برنامه چه مدت صبر کند قبل از اجرای ترجمه لحظه‌ای.
- **رفتار برای ENTER** کنترل می‌کند که وقتی `Enter` را فشار می‌دهید چه اتفاقی می‌افتد:
  - **Enter** ترجمه یا بازنویسی را اجرا می‌کند (پیش‌فرض).
  - **Shift + Enter** ترجمه یا بازنویسی را اجرا می‌کند؛ **Enter** ساده یک خط جدید وارد می‌کند.

<a id="transform"></a>
## تبدیل

از **تبدیل** زمانی استفاده کنید که بخواهید هوش مصنوعی دستورالعمل‌های سفارشی شما را دنبال کند.

![Transform workspace](../images/screenshots/fa/transform.png)

این بخش انعطاف‌پذیرترین قسمت برنامه است. می‌توانید از آن برای کارهایی مانند:

- خلاصه‌سازی یادداشت‌ها
- تبدیل متن اولیه به یک ایمیل حرفه‌ای
- استخراج نکات کلیدی
- تبدیل متن به یک قالب خاص
- هر فعالیت سفارشی دیگری با متن ورودی

<br/>

<a id="run-an-existing-prompt"></a>
### اجرای یک دستور موجود

1. **تبدیل** را باز کنید.
2. یک دستور از فهرست دستورات انتخاب کنید.
3. اگر جعبه‌ای با عنوان **مقصد** زبان ظاهر شد، در صورت تمایل یک زبان انتخاب کنید.
4. متن را در قسمت **ورودی** تایپ یا چسبانده کنید.
5. روی **تبدیل** کلیک کنید.
6. نتیجه را در قسمت **خروجی** بخوانید.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### اگر هنوز دستوری ندارید

اگر فهرست دستورهای شما خالی است، در فضای کار تبدیل روی گزینهٔ **بارگیری پرسش‌های نمونه** کلیک کنید. همین گزینه همیشه در بخش صادرات/واردات در [**تنظیمات** > **تبدیل**](#transform-settings) در دسترس است. هر دوی این گزینه‌ها نمونه‌های داخلی را اضافه می‌کنند تا بتوانید سریع شروع کنید.

<br/>

> ℹ️ **توجه**<br/>
> دستورهای نمونه به زبان انگلیسی ارائه شده‌اند. پس از بارگیری آن‌ها، می‌توانید یک دستور را ویرایش کنید و از **ترجمه پرسش** استفاده کنید تا آن را به زبان شما ترجمه کنید.

<br/>

<a id="create-a-prompt-quickly"></a>
### ایجاد سریع یک دستور

سریع‌ترین روش برای ایجاد یک دستور این است:

1. روی **دستور جدید** کلیک کنید.
2. روی **تولید دستور** کلیک کنید.
3. توصیف کنید که می‌خواهید دستور چه کاری انجام دهد.
4. یک مهارت (آسان) یا مدل (پیشرفته) انتخاب کنید.
5. اجازه دهید برنامه یک پیش‌نویس برای شما ایجاد کند.
6. پیش‌نویس را بررسی کنید و روی **ذخیره** کلیک کنید.

![Generate prompt](../images/screenshots/fa/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ویرایش یک دستور

هنگامی که یک دستور ایجاد یا ویرایش می‌کنید، ویرایشگر در سمت چپ ظاهر می‌شود و یک ناحیه تست در سمت راست نمایش داده می‌شود.

![Transform prompt editor](../images/screenshots/fa/transform-prompt-edit.png)

فیلدهای اصلی عبارتند از:

- **نام دستور**: نامی که در فهرست دستورات نمایش داده می‌شود.
- **دستورالعمل‌های دستور (اختیاری)**: یک راهنمای کوتاه که هنگام اجرای دستور به کاربر نمایش داده می‌شود.
- **نقش مدل**: نقش کلی که به هوش مصنوعی داده می‌شود، مثلاً 'شما یک دستیار مفید هستید.'
- **دستورالعمل‌های مدل (هر خط یکی)**: قوانین خاصی که می‌خواهید هوش مصنوعی از آن‌ها پیروی کند.
- **توضیح خروجی**: یک کلمه کوتاه که نتیجه را توصیف می‌کند، مثلاً 'خلاصه' یا 'بازنویسی'.
- **دما (0.0 → 1.0)**: نحوه رفتار مدل؛ به پایین مراجعه کنید.
- **درخواست زبان مقصد**: هنگام اجرای دستور، یک انتخاب‌گر زبان مقصد اضافه می‌کند.

اگر اصطلاح فنی **دما** برای شما جدید است، آن را به این صورت در نظر بگیرید:

- دمای **پایین‌تر** نتایج پایدارتر و قابل پیش‌بینی‌تری ارائه می‌دهد.
- دمای **بالاتر** تنوع و خلاقیت بیشتری ایجاد می‌کند.

همچنین می‌توانید از موارد زیر استفاده کنید:

- `Generate prompt` برای ایجاد یک پیش‌نویس جدید از یک توصیف ساده
- `Improve prompt` برای بهبود یک دستور موجود
- `Translate prompt` برای ترجمه فیلدهای دستور

<br/>

> ⚠️ **هشدار**<br/>
> قبل از کلیک روی `Back to Run`، روی `Save` کلیک کنید. اگر بدون ذخیره بازگردید، تغییرات شما از بین خواهد رفت.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### تست یک دستور قبل از استفاده از آن

پنل تست در سمت راست به شما امکان می‌دهد تا دستور خود را با متن نمونه قبل از استفاده در کارهای روزمره امتحان کنید.

این کار در موارد زیر مفید است:

- هنگامی که دارید یک دستور جدید می‌سازید
- هنگامی که دو نسخه از یک دستور را مقایسه می‌کنید
- هنگامی که می‌خواهید لحن، طول یا قالب خروجی را بررسی کنید

<br/>

> ℹ️ **توجه**<br/>
> شما می‌توانید دستورهای ذخیره‌شده را در [**تنظیمات** > **تبدیل**](#transform-settings) صادر و وارد کنید.

هنگامی که از گزینه‌های **تولید دستور**، **بهبود دستور** یا **ترجمه پرسش** در ویرایشگر دستور استفاده می‌کنید، حالت **آسان** همان گزینه‌ی انتخاب مهارت را مانند ترجمه و بازنویسی ارائه می‌دهد؛ در حالی که حالت **پیشرفته** از فهرست مدل‌ها استفاده می‌کند.

<br/><br/>

<a id="dashboard"></a>
## داشبورد

از **داشبورد** استفاده کنید تا میزان استفاده خود از برنامه و هزینه آن (برای مدل‌های پولی) را مشاهده کنید.

![Dashboard summary](../images/screenshots/fa/dashboard-summary.png)

<br/>

> ℹ️ **توجه**<br/>
> اگر فقط از مدل‌های **رایگان** استفاده کنید، مقادیر **هزینه** ممکن است صفر باشد و شاخص‌های متمرکز بر هزینه خالی به نظر برسند. زبانهٔ **خلاصه** همچنان تعداد فراخوانی‌ها برای ترجمه، بازنویسی و تبدیل را نشان می‌دهد، مشروط بر اینکه در بازهٔ انتخاب‌شده فعالیتی وجود داشته باشد.

<br/>

<a id="filter-the-data"></a>
### فیلتر کردن داده‌ها

از دکمه‌های فیلتر در بالای صفحه برای تغییر محدوده زمانی استفاده کنید.

![Dashboard filters](../images/screenshots/fa/dashboard-filter.png)

<br/>

> ℹ️ **توجه**<br/>
> فیلتر **کاربر** فقط برای مدیران در نسخهٔ وب قابل مشاهده است. کاربران عادی این فیلتر را نمی‌بینند و در برنامهٔ دسکتاپ نیز در دسترس نیست.

<br/>

<a id="dashboard-tabs"></a>
### زبانه‌های داشبورد

- **خلاصه** شامل کارت‌های شاخص عملکرد (KPI): هزینه کل، مدل‌های استفاده‌شده، تعداد فراخوانی‌ها و هزینه‌ها به ازای هر حالت (با سهم از کل فراخوانی‌ها)، میانگین هزینه به ازای هر فراخوانی، میانگین TPS و سه مدل برتر بر اساس تعداد فراخوانی است.
- **بر اساس مدل** هر مدل را با تعداد کل فراخوانی‌ها، هزینه کل و میانگین TPS فهرست می‌کند؛ با گسترش یک سطر می‌توانید تفکیک فراخوانی‌ها را بر اساس ترجمه، بازنویسی و تبدیل مشاهده کنید.
- **همهٔ فراخوانی‌ها** سیاههٔ کامل فراخوانی‌ها را نشان می‌دهد (در طرح‌های پهن به صورت صفحه‌بندی‌شده و در صفحه‌های باریک به صورت کارتی) و امکان صادرات آن را فراهم می‌کند.

<br/>

<a id="export-data"></a>
### صادرات داده

داده‌های جداول داشبورد قابل صادرات در قالب‌های زیر هستند:

- **JSON**
- **CSV**
- **XLSX**

این قابلیت در صورتی مفید است که بخواهید فعالیت‌ها را خارج از برنامه بررسی کنید یا گزارشی را به اشتراک بگذارید.

<br/>

<a id="delete-stored-records-for-a-model"></a>
### حذف رکوردهای ذخیره‌شده یک مدل

در بخش **بر اساس مدل** یا **همهٔ فراخوانی‌ها**، می‌توانید با کلیک روی آیکون «سطل زباله»، رکوردهای ذخیره‌شده یک مدل را حذف کنید.

> ⚠️ **هشدار**<br/>
> حذف رکوردهای ذخیره‌شده قابل بازگشت نیست. فقط در صورتی این کار را انجام دهید که مطمئن باشید دیگر به آن تاریخچه نیاز ندارید.

برای حذف تمام داده‌ها یا حذف رکوردها بر اساس مدت زمان ذخیره‌شده، به [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) بروید. در آنجا گزینه‌هایی برای حذف تمام داده‌های ذخیره‌شده یا فقط داده‌های قدیمی‌تر از یک تاریخ مشخص وجود دارد.

<a id="settings"></a>
## تنظیمات

از طریق نوار کناری، **تنظیمات** را باز کنید تا رفتار برنامه را شخصی‌سازی نمایید.

زبانه‌های در دسترس بسته به پلتفرم و نقش شما متفاوت است:

| زبانه              | رومیزی | وب (مدیر) | وب (کاربر عادی) | یادداشت‌ها                                        |
  |------------------|:-------:|:-----------:|:------------------:|----------------------------------------------|
  | تنظیمات عمومی |   بله   |     بله     |        بله         | شامل **تجربه هوش مصنوعی** (آسان / پیشرفته) |
  | مدل‌ها           |   بله   |     بله     |        بله         | فقط زمانی که **تجربه هوش مصنوعی** در حالت **پیشرفته** باشد |
  | زبان‌ها        |   بله   |     بله     |        بله         |                                              |
  | ردیابی هزینه    |   بله   |     بله     |         -          |                                              |
  | تبدیل        |   بله   |     بله     |        بله         | واردات/صادرات گروهی دستورهای تبدیل      |
  | کاربران            |    -    |     بله     |         -          |                                              |
  | پیکربندی API       |   بله   |     بله     |         -          |                                              |
  | درباره            |   بله   |     بله     |        بله         |                                              |

در حالت **آسان**، انتخاب مدل از طریق مهارت‌ها در نوار ابزار و **ارائه‌دهنده** در بخش تنظیمات عمومی انجام می‌شود؛ زبانهٔ **مدل‌ها** مخفی است.

> ℹ️ **توجه**<br/>

<a id="general-settings"></a>
### تنظیمات عمومی

از **تنظیمات عمومی** برای کنترل رفتار تایپ، ذخیره یا عدم ذخیره جزئیات اجرا برای **تاریخچه**، ظاهر و نحوه انتخاب هوش مصنوعی برای ترجمه، بازنویسی و تبدیل استفاده کنید.

**تجربه هوش مصنوعی**

- **آسان** (پیش‌فرض): یک **ارائه‌دهنده** (OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras یا Ollama) انتخاب کنید. ارائه‌دهندگان ابری از پیش‌تنظیم‌های مهارت داخلی در نوار ابزار استفاده می‌کنند. **Ollama** مدل‌های نصب‌شده روی دستگاه شما را به‌جای مهارت‌ها فهرست می‌کند. در حالت آسان، **فهرست مهارت‌ها** نسخه فهرست و زمان آخرین به‌روزرسانی را نشان می‌دهد؛ روی **تازه‌سازی فهرست مهارت‌ها** کلیک کنید تا آخرین فهرست مهارت‌ها را از مخزن پروژه دریافت کنید (برنامه همچنین به‌طور دوره‌ای در پس‌زمینه بررسی می‌کند).
- **پیشرفته**: مدل‌های فردی را در نوار ابزار انتخاب کنید؛ فهرست را در [**تنظیمات** > **مدل‌ها**](#models) مدیریت کنید.

در **برنامه تحت وب**، ارائه‌دهندگانی که نمایش داده می‌شوند بسته به کلیدهای API تنظیم‌شده در محیط سرور تعیین می‌شوند. در **برنامه دسکتاپ**، کلیدها را در بخش [**پیکربندی API**](#api-config) تنظیم کنید.

**رفتار**

- **رفتار برای ENTER** مشخص می‌کند که آیا `Enter` وظیفه را اجرا می‌کند یا یک خط جدید وارد می‌کند.
- **ترجمه خودکار هنگام چسباندن** به محض چسباندن متن، ترجمه را شروع می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد** به‌صورت خودکار نتایج موفق را کپی می‌کند.
- **ترجمه لحظه‌ای (در حین تایپ)** در حین تایپ، متن را ترجمه می‌کند.
- **مهلت زمانی (ms)** زمان انتظار برای ترجمه لحظه‌ای را تنظیم می‌کند.

**تاریخچه**

- **نگه‌داری تاریخچه اجرا** کنترل می‌کند که آیا هر عمل ترجمه، بازنویسی و تبدیل، متن **ورودی و خروجی** را برای نمایش در نوار کناری [**تاریخچه**](#history) ذخیره کند یا خیر. غیرفعال کردن آن درخواست تأیید می‌کند؛ در صورت تأیید، متن‌های ذخیره‌شده از پایگاه داده حذف می‌شوند. اگر برچسب نشان دهد *توسط مدیر غیرفعال شده است*، در نصب شما متغیر `HISTORY_DISABLED` در محیط تنظیم شده است (به [README](README.fa.md#configuration-and-environment) مراجعه کنید)؛ و شما نمی‌توانید از رابط کاربری، تاریخچه را دوباره فعال کنید.
- **حذف داده‌های تاریخچه** به شما امکان می‌دهد تا متن‌های ذخیره‌شده را بر اساس سن (مثلاً قدیمی‌تر از چند ماه، یا **تمام داده‌ها (پاک کردن)**) با استفاده از **حذف داده** حذف کنید. این عمل فقط بر متن اجرای ذخیره‌شده برای نمایش **تاریخچه** تأثیر می‌گذارد و **نمی‌تواند** داده‌های هزینه یا مجموع استفاده را حذف کند. برای حذف یا کاهش داده‌های **هزینه**، از [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) استفاده کنید.

**ظاهر**

- **تم** بین ظاهر روشن، تیره و سیستم سوئیچ می‌کند.
- **نمایش اطلاعات هزینه در عملیات** کنترل می‌کند که هزینه هر عملیات (در صورت موجود بودن) و هزینه کل را در پنل‌های خروجی ترجمه، بازنویسی و تبدیل نمایش دهد.
- **اعشار هزینه** نحوه نمایش اعشار هزینه را تغییر می‌دهد.
- **فقط وب:** **نمایش حاشیه دور برنامه** فضای اضافی در اطراف رابط اضافه می‌کند.
- **خانواده فونت** فونت نوشتاری را در پنل‌های متنی تغییر می‌دهد.
- **اندازه** اندازه فونت را تغییر می‌دهد.

**پشتیبان‌گیری پیکربندی** (فقط برای مدیران برنامه دسکتاپ و وب)

- **افزودن داده‌های مصرف به پشتیبان** - در صورت فعال‌سازی، فایل ZIP شامل تاریخچه اجرا و داده‌های فراخوانی API نیز می‌شود.
- **پشتیبان‌گیری پیکربندی** - یک فایل ZIP واحد ایجاد می‌کند (به‌صورت پیش‌فرض `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` به وقت UTC) که شامل `config.json`، `state.json`، کلید رمزگذاری اختیاری، کاربران، ترجیحات، پرامت‌های سفارشی و داده‌های مصرف (در صورت انتخاب) می‌شود. پس از اتمام موفقیت‌آمیز پشتیبان‌گیری، نام فایل ذخیره‌شده در تأییدیه نمایش داده می‌شود.
- **بازیابی از پشتیبان** - ابتدا یک **پنجره تأییدیه باز می‌کند**. فایل ZIP پشتیبان را درون این پنجره انتخاب کنید (از طریق **مرور** / انتخاب‌گر فایل یا کشیدن و رها کردن در صورت پشتیبانی)، سپس گزینه‌ها را بررسی کنید:
  - **بازیابی داده‌های استفاده** - داده‌های مصرف/تاریخچه از فایل ZIP را وارد می‌کند (در صورتی که در زمان پشتیبان‌گیری این داده‌ها شامل شده بودند)؛ در صورتی که فقط تنظیمات و پرامت‌ها مدنظر باشند، این گزینه را غیرفعال نگه دارید.
  - **پاک‌کردن داده‌های قدیمی قبل از بازیابی** - داده‌های مصرف/تاریخچه موجود در این نصب را قبل از اعمال پشتیبان حذف می‌کند (اختیاری؛ زمانی استفاده شود که جایگزینی کامل مدنظر باشد).

پشتیبان‌های ایجادشده در نسخه وب یا دسکتاپ، قابلیت بازیابی در نسخه دیگر را دارند. هنگام بازیابی یک پشتیبان دسکتاپ در نسخه وب، داده‌ها به کاربر مدیر بازیابی می‌شوند.

<a id="models"></a>
### مدل‌ها

این زبانه فقط زمانی در دسترس است که **تجربه هوش مصنوعی** در [**تنظیمات عمومی**](#general-settings) روی **پیشرفته** تنظیم شده باشد. از **تنظیمات** > **مدل‌ها** برای انتخاب مدل‌هایی که در نوار ابزار نمایش داده می‌شوند استفاده کنید.

![Settings Models tab](../images/screenshots/fa/settings-models.png)

این صفحه دو لیست دارد:

- **مدل‌های موجود** در سمت چپ
- **مدل‌های انتخاب شده** در سمت راست

کنترل‌های مفید شامل:

- **جستجوی مدل‌ها...** برای یافتن مدلی بر اساس نام
- تراشه‌های **ارائه‌دهنده** برای محدود کردن لیست به یک موتور (OpenRouter، OpenAI، Ollama، …)
- **فقط رایگان** برای نمایش تنها مدل‌های رایگان
- **تازه‌سازی** برای بارگیری مجدد لیست
- **بسط همه** و **بستن همه** هنگامی که لیست را بر اساس ارائه‌دهنده مرتب می‌کنید

شناسه‌های مدل شامل پیشوند ارائه‌دهنده هستند (برای مثال `openrouter/…` در مقابل `openai/…`). نشان‌هایی مانند **OpenAI (OpenRouter)** در مقابل **OpenAI (مستقیم)** نشان می‌دهند که ترافیک چگونه مسیریابی می‌شود.

> ℹ️ **یادداشت**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) یک مدل مسیریابی است، نه یک مدل چت عمومی: پاسخ آن JSON است که بدنه درخواست‌های API OpenRouter را توصیف می‌کند (برای مثال یک آرایه `requests` با `model` و `messages`). اگر از آن برای **ترجمه**، **بازنویسی** یا **تبدیل** استفاده کنید، پنل خروجی آن JSON را نشان می‌دهد نه متن نهایی. برای این وظایف یک مدل متنی معمولی انتخاب کنید. صفحه مدل [Body Builder](https://openrouter.ai/openrouter/bodybuilder) را در OpenRouter ببینید.

اقدامات:

- برای افزودن یک مدل، روی **افزودن** یا هر جای دیگر در آن سطر کلیک کنید.

- برای حذف یک مدل، روی **X** کنار آن در بخش **مدل‌های انتخاب شده** یا روی **انتخاب شده** در سطر مدل موجود کلیک کنید.

- برای پاک کردن لیست، روی **لغو انتخاب همه** کلیک کنید. مدل رایگان اجباری در لیست باقی می‌ماند.

<br/>

> ℹ️ **یادداشت**<br/>
> اگر نمی‌خواهید بلافاصله اعتبار به OpenRouter اضافه کنید، ابتدا **فقط رایگان** را فعال کنید و مدل‌های رایگان را انتخاب کنید (نیازی به کارت اعتباری نیست). همچنین می‌توانید از Ollama برای اجرای مدل‌ها به صورت محلی بدون نیاز به کلید API استفاده کنید.

### زبان‌ها

از **تنظیمات** > **زبان‌ها** برای سازماندهی لیست زبان‌های مورد استفاده در برنامه استفاده کنید.

- **زبان‌های برتر** در بالای لیست زبان‌ها در بخش‌های **ترجمه** و **تبدیل** ثابت شده‌اند.
- **زبان سفارشی** به شما امکان می‌دهد زبانی را که در لیست داخلی وجود ندارد اضافه کنید.

اگر یک زبان سفارشی اضافه کنید، در انتخاب‌گرهای زبان کنار گزینه‌های داخلی ظاهر می‌شود.

<a id="cost-tracking"></a>
### ردیابی هزینه

از **تنظیمات** > **ردیابی هزینه** برای مدیریت اطلاعات هزینه استفاده کنید.

- **هزینه کل** مجموع در حال اجرا را نشان می‌دهد.
- **کپی مقدار** مجموع را به حافظه موقت کپی می‌کند.
- **بازنشانی هزینه** مجموع ذخیره شده را به صفر بازنشانی می‌کند.
- **همگام‌سازی با استفاده از کلید API** مجموع را با میزان استفاده گزارش شده توسط حساب OpenRouter شما تنظیم می‌کند (فقط OpenRouter).
- **استفاده از کلید API** جزئیات استفاده از OpenRouter را در صورت موجود بودن نشان می‌دهد.
- **حذف داده‌های هزینه** تمام داده‌ها یا فقط موارد قدیمی‌تر از یک تاریخ مشخص را حذف می‌کند.

**ردیابی هزینه:** هنگامی که از مدل‌های OpenRouter استفاده می‌کنید، برنامه میزان استفاده واقعی و هزینه شما را بر اساس اطلاعات هزینه از OpenRouter نشان می‌دهد. برای تمام ارائه‌دهندگان دیگر، برنامه هزینه‌ها را با استفاده از قیمت‌های منتشر شده توسط OpenRouter تخمین می‌زند، و اگر قیمتی در دسترس نباشد، تخمین ممکن است صفر باشد.

<br/>

> ℹ️ **یادداشت**<br/>
> **تمام اعداد هزینه تنها تخمینی هستند و صرفاً جهت اطلاع شما ارائه می‌شوند، نه بیانیه‌های رسمی صورتحساب.**

<br/>

> ⚠️ **هشدار**<br/>
> حذف داده‌ها قابل بازگشت نیست. قبل از حذف، مطمئن شوید داده‌های خود را پشتیبان گرفته یا از طریق [**تاریخچه**](#history)
> یا [**داشبورد** > **همهٔ فراخوانی‌ها**](#dashboard-tabs) صادر کرده‌اید، در غیر این صورت به طور دائم از بین خواهند رفت.
> تمام تاریخچه ورودی/خروجی مربوط به هر مورد فراخوانی API نیز حذف خواهد شد.

<br/>

### تبدیل (زبانه تنظیمات)

شما می‌توانید:

- دستورها را برای پشتیبان‌گیری یا اشتراک‌گذاری صادر کنید
- دستورهای نمونه را به لیست دستورها بارگیری کنید

### کاربران

<a id="api-config"></a>
### پیکربندی API

ارائه‌دهندگان پشتیبانی‌شده عبارتند از: OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و **Ollama** (مدل‌های محلی از طریق یک آدرس پایه). شما فقط نیاز دارید ارائه‌دهندگانی را که استفاده می‌کنید پیکربندی کنید.

**برنامه وب: فقط مدیر سیستم**

کلیدهای API از طریق متغیرهای محیطی سیستم یا داکر پیکربندی می‌شوند - این کلیدها در رابط کاربری وب وارد نمی‌شوند. این صفحه نشان می‌دهد که کدام ارائه‌دهندگان دارای کلید پیکربندی‌شده هستند و به شما امکان می‌دهد با کلیک روی دکمهٔ `Test` هر یک را تست کنید.

<br/>

> ℹ️ **توجه**<br/>
> برای تغییر یک کلید API، متغیر محیطی را در پیکربندی سیستم یا داکر خود به‌روز کنید و سرور یا کانتینر را مجدداً راه‌اندازی کنید.

<br/>

> ℹ️ **توجه**<br/>
> **پشتیبان‌گیری پیکربندی** (نگاه کنید به [**تنظیمات عمومی** → پشتیبان‌گیری پیکربندی](#general-settings)) می‌تواند کلیدهای ارائه‌دهندهٔ **حل‌شده** را درون فایل `config.json` در ZIP قرار دهد. بازیابی این فایل ZIP، این کلیدها را به فایل پیکربندی ذخیره‌شدهٔ سرور **کپی نمی‌کند** - کلیدهای فعال همچنان از محیط و وضعیت فایل موجود مطابق توضیحات آنجا تأمین می‌شوند.

<br/>

**برنامه دسکتاپ**

از بخش **پیکربندی API** برای ذخیره کلیدهای API هر ارائه‌دهنده‌ای که استفاده می‌کنید استفاده کنید. برای Ollama، به جای کلید API، **آدرس پایه** را وارد کنید.

<br/>

> 💡 **نکته** <br/>
> اگر نمی‌خواهید از کلید API استفاده کنید یا برای استفاده هزینه پرداخت کنید، می‌توانید [Ollama را دانلود کنید](https://ollama.com) و مدل‌ها (مانند `translategemma:4b`) را به صورت رایگان روی دستگاه خود اجرا کنید. همچنین می‌توانید یک حساب رایگان در OpenRouter ایجاد کنید (نیازی به کارت اعتباری نیست) تا از مدل‌های رایگان آن استفاده کنید، یا یک کلید API رایگان از Cerebras، Google، Groq یا Mistral AI دریافت کنید.

<br/>

- فقط ارائه‌دهندگانی را اضافه کنید که به آن‌ها نیاز دارید. در بخش **تنظیمات** > **مدل‌ها**، هر شناسهٔ مدل با ارائه‌دهنده شروع می‌شود (برای مثال `openrouter/openrouter/free`، `openai/gpt-4o`، `ollama/llama3`).

برای افزودن یک کلید API، مقدار آن را در کادر متنی وارد کرده و روی دکمهٔ `Save` کلیک کنید. برای جایگزینی یک کلید موجود، روی `Edit` کلیک کنید. برای بررسی صحت کارکرد یک کلید، روی `Test` کلیک کنید. برای آدرس پایهٔ Ollama، همیشه روی `Test` کلیک کنید تا اتصال بررسی شود.

<br/>

> ℹ️ **توجه**<br/>

### درباره

زبانهٔ **درباره** نمایش می‌دهد:

- پیوند به مخزن پروژه

<a id="common-issues"></a>
## مشکلات رایج

اگر چیزی همان‌طور که انتظار می‌رود کار نمی‌کند، ابتدا موارد زیر را بررسی کنید.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### برنامه متن را ترجمه، بازنویسی یا تبدیل نمی‌کند

بررسی کنید که:

- شما یک **مهارت** (آسان) یا **مدل** (پیشرفته) را در نوار ابزار انتخاب کرده‌اید
- در حالت **آسان**، در [**تنظیمات** > **تنظیمات عمومی**](#general-settings) یک **ارائه‌دهنده** با کلید فعال (یا URL Ollama) و حداقل یک مهارت برای آن ارائه‌دهنده وجود دارد
- در حالت **پیشرفته**، حداقل یک مدل در [**تنظیمات** > **مدل‌ها**](#models) فهرست شده است
- تنظیمات API شما در حال کار کردن است

اگر از برنامه دسکتاپ استفاده می‌کنید:

1. [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید.
2. بررسی کنید که حداقل یک کلید API ذخیره شده باشد.
3. روی **تست** کنار ارائه‌دهنده کلیک کنید تا مطمئن شوید کلید کار می‌کند.

<br/>

<a id="the-model-list-is-empty"></a>
### لیست مدل خالی است

در حالت **آسان**، [**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید، اطمینان حاصل کنید که **ارائه‌دهنده** تنظیم شده است و کلیدها را در [**پیکربندی API**](#api-config) اضافه یا تست کنید (برای دسکتاپ) یا از مدیر خود بخواهید (برای وب). برای **Ollama**، روی URL پایه دکمه **تست** را بزنید و اطمینان حاصل کنید که مدل‌ها به صورت محلی نصب شده‌اند.

در حالت **پیشرفته**، [**تنظیمات** > **مدل‌ها**](#models) را باز کنید و روی **تازه‌سازی** کلیک کنید. در صورت نیاز، مدلی را جستجو کنید، گزینه **فقط رایگان** را فعال کنید و مدل‌ها را به **مدل‌های انتخاب شده** اضافه کنید.

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### نتیجه بسیار کند یا بسیار پرهزینه است

یکی یا چند مورد از موارد زیر را امتحان کنید:

- انتخاب یک مهارت دیگر (آسان) یا مدل (پیشرفته)
- استفاده از ورودی کوتاه‌تر
- غیرفعال کردن **ترجمهٔ بلادرنگ (در حین تایپ)** در [**تنظیمات** > **تنظیمات عمومی**](#general-settings)
- استفاده از مدل‌های رایگان برای وظایف ساده (نگاه کنید به [مدل‌ها](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### رابط به زبان اشتباه است

روی آیکون کره زمین در [نوار ابزار](#toolbar) کلیک کنید و **زبان رابط** مورد نظر خود را انتخاب کنید.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### متن بسیار کوچک یا خواندن آن دشوار است

[**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید و تغییر دهید:

- **خانواده قلم**
- **اندازه**

<br/>

<a id="dashboard-summary-looks-empty"></a>
### خلاصه داشبورد خالی به نظر می‌رسد

این موضوع در صورتی طبیعی است که:

- شما فقط از **مدل‌های رایگان** استفاده می‌کنید و به اعداد **هزینه** نگاه می‌کنید (که ممکن است صفر باشند)؛ شاخص‌های تعداد فراخوانی در **خلاصه** همچنان به داده از دوره انتخاب‌شده نیاز دارند
- **فیلتر زمانی** انتخاب‌شده شامل دوره‌ای که فراخوانی‌ها در آن انجام شده نیست — برای بررسی از **همه** استفاده کنید

اگر پس از انتخاب **همه** شاخص‌ها همچنان صفر باشند، اطمینان حاصل کنید که فراخوانی‌ها در [**تاریخچه**](#history) یا در زبانه **همهٔ فراخوانی‌ها** نمایش داده می‌شوند.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### هزینه نمایش داده شده «در دسترس نیست» یا اشتباه به نظر می‌رسد

هنگامی که از مدل‌ها از طریق **OpenRouter** استفاده می‌کنید، برنامه مقدار واقعی هزینهٔ گزارش‌شده توسط OpenRouter را نمایش می‌دهد.

برای **سایر ارائه‌دهندگان** (مثل OpenAI مستقیم، Anthropic مستقیم و غیره)، هزینه بر اساس داده‌های قیمت‌گذاری منتشرشده توسط OpenRouter تخمین زده می‌شود. اگر قیمت متناظری برای یک مدل یافت نشود، هزینه به صورت **در دسترس نیست** نمایش داده می‌شود و به مجموع کل شما اضافه نمی‌شود.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### هزینه کل با صورتحساب ارائه‌دهنده من مطابقت ندارد

تمام ارقام هزینه در این برنامه **تنها تخمینی مرجع هستند** و بیانیه‌های رسمی صورتحساب محسوب نمی‌شوند.

برای نزدیک‌تر کردن مجموع به هزینه واقعی شما در OpenRouter، [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) را باز کنید و روی **همگام‌سازی با استفاده از کلید API** کلیک کنید.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### صفحه تاریخچه در نوار کناری وجود ندارد

ممکن است **نگه‌داری تاریخچه اجرا** غیرفعال باشد. [**تنظیمات** > **تنظیمات عمومی**](#general-settings) را باز کنید و آن را فعال کنید، مگر اینکه تاریخچه *توسط مدیر غیرفعال شده است* (`HISTORY_DISABLED` در محیط — به [README](README.fa.md#configuration-and-environment) مراجعه کنید). فعال کردن تاریخچه، متن‌های حذف‌شده قبلی را بازیابی نمی‌کند.

<br/>

<a id="web-app-session-expired"></a>
### برنامه تحت وب: به صورت غیرمنتظره به صفحه ورود هدایت می‌شوید

ممکن است جلسه کاری شما منقضی شده باشد. دوباره وارد شوید. اگر این اتفاق اغلب رخ دهد، تنظیمات مدت زمان جلسه کاری در پیکربندی سرور را بررسی کنید.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### مدیر وب: رمز عبور را فراموش کرده یا از دست داده‌اید

این مورد برای برنامهٔ تحت‌وبِ **مستقرشده توسط خود کاربر** (Docker) اعمال می‌شود، نه برنامهٔ دسکتاپ (الکترون).

- اگر مدیر دیگری همچنان می‌تواند وارد شود، می‌تواند به [**تنظیمات** > **کاربران**](#users) بروید، حساب کاربری را انتخاب کند و در آنجا یک **رمز عبور جدید** تنظیم کند.
- اگر شما **قفل شده‌اید** اما به **دسترسی به خط فرمان** دستگاه یا کانتینر دارید، با استفاده از ابزار کمکی که همراه تصویر ارائه می‌شود رمز عبور را بازنشانی کنید (`transrewrt` را در صورت تغییر نام پیش‌فرض جایگزین کنید و اگر رمز عبور شامل فاصله یا کاراکترهای خاص است، آن را در گیومه قرار دهید):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

نام کاربری پیش‌فرض مدیر `admin` است اگر هرگز حساب دیگری ایجاد نکرده باشید. هنگامی که فقط یک آرگومان ارسال کنید، به عنوان رمز عبور جدید برای `admin` در نظر گرفته می‌شود.

اگر از یک **بررسی منبع** (source checkout) به جای Docker استفاده می‌کنید، از این دستور استفاده کنید:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

این اسکریپت رکورد کاربر را در پایگاه داده SQLite به‌روز می‌کند (و در صورت وجود نداشتن، می‌تواند کاربر `admin` را ایجاد کند). پس از بازنشانی، با رمز عبور جدید وارد شوید.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### داشبورد داده‌ای برای سایر کاربران نمایش نمی‌دهد (وب)

فقط **مدیران** می‌توانند از طریق فیلتر **کاربر** داده‌های تمام کاربران را مشاهده کنند. کاربران معمولی فقط فعالیت خود را می‌بینند که این امر طبق طراحی سیستم است.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### من یک دستور را تغییر دادم و ویرایش‌ها از دست رفت

هنگام ویرایش یک دستور، همیشه قبل از کلیک کردن روی **ذخیره**، روی **بازگشت به اجرا** کلیک کنید.

<a id="quick-tips"></a>
## نکات سریع

- قبل از انتقال به [**بازنویسی**](#rewrite) یا [**تبدیل**](#transform)، با استفاده از [**ترجمه**](#translate) مطمئن شوید که تنظیمات شما به درستی کار می‌کنند.
- از [**بازنویسی**](#rewrite) برای بهبود روزمره متن استفاده کنید.
- از [**تبدیل**](#transform) زمانی استفاده کنید که نیاز به یک گردش کار قابل تکرار برای یک وظیفه خاص داشته باشید.
- در صورت تمایل به نظارت بر میزان استفاده و هزینه، از [**داشبورد**](#dashboard) استفاده کنید.
- از [**تاریخچه**](#history) برای بررسی عملیات گذشته و متن کامل ورودی/خروجی آن‌ها استفاده کنید.
- در صورتی که در حال ساخت کتابخانه‌ای از دستورها هستید که می‌خواهید ایمن نگه دارید (به [تبدیل](#transform) مراجعه کنید) یا می‌خواهید آن را با دیگران به اشتراک بگذارید، به طور منظم دستورها را صادرات کنید.
- تا زمانی که به کنترل دقیق روی شناسه مدل‌ها نیاز ندارید، در حالت **آسان** بمانید؛ زمانی که قبلاً می‌دانید کدام مدل‌ها را می‌خواهید، به حالت **پیشرفته** تغییر وضعیت دهید.
