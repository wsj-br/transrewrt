# راهنمای کاربر

<br/>

<a id="introduction"></a>
## معرفی

Transrewrt به شما در سه روش اصلی برای کار با متن کمک می‌کند:

- **ترجمه** - تبدیل متن از یک زبان به زبان دیگر.
- **بازنویسی** - بازفرم‌بندی متن با سبک متفاوت، مانند شفاف‌تر، کوتاه‌تر یا رسمی‌تر.
- **تبدیل** - پردازش متن با استفاده از دستورالعمل‌های هوش مصنوعی سفارشی که به آن‌ها «دستور (prompt)» گفته می‌شود.

<br/>

این راهنما نحوه استفاده از برنامه پس از نصب و راه‌اندازی آن را توضیح می‌دهد. برای مراحل نصب، به فایل اصلی **[README](README.fa.md)** مراجعه کنید.

<br/>

> ℹ️ **توجه**<br/>
> Transrewrt به عنوان یک برنامه دسکتاپ برای ویندوز و لینوکس و همچنین به عنوان یک برنامه تحت وب میزبانی‌شده در دسترس است. این راهنما بر روی استفاده روزمره از برنامه تمرکز دارد. در مواردی که ویژگی خاصی فقط به یک نسخه اعمال می‌شود، این موضوع به وضوح مشخص شده است.

<a id="before-you-start"></a>

## قبل از شروع

برای استفاده از Transrewrt، باید دسترسی به حداقل یک ارائه دهنده هوش مصنوعی داشته باشید. ارائه دهندگان پشتیبانی شده عبارتند از: [OpenRouter](https://openrouter.ai) (که مدل‌های زیادی را تجمیع می‌کند)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و [Ollama](https://ollama.com) برای مدل‌های محلی.

برای شروع لازم نیست مدل پولی انتخاب کنید. به محض اینکه کلید API OpenRouter خود را اضافه کنید، اپلیکیشن به طور خودکار گزینه **رایگان** داخلی OpenRouter را فعال می‌کند. این امر به شما اجازه می‌دهد فوراً متن را ترجمه، بازنویسی و تبدیل کنید. همچنین می‌توانید کلید API رایگان از Cerebras، Google، Groq یا Mistral AI تهیه کنید.

به زبان ساده:

- یک **مدل** موتور هوش مصنوعی است که کار را انجام می‌دهد. مدل‌ها با پیشوند **ارائه دهنده** فهرست شده‌اند (به عنوان مثال `openrouter/…`، `openai/…`، `ollama/…`).
- یک **کلید API** (یا برای Ollama، یک **آدرس URL پایه**) وسیله‌ای است که اپلیکیشن از طریق آن به ارائه دهنده دسترسی پیدا می‌کند.

اگر از **اپلیکیشن دسکتاپ** استفاده می‌کنید، کلیدهای مربوط به هر ارائه دهنده را در بخش [**تنظیمات** > **پیکربندی API**](#api-config) اضافه کنید. برای استفاده فقط از OpenRouter، پایین‌تر به بخش [نحوه تهیه یک کلید API](#how-to-get-an-api-key-desktop-app) مراجعه کنید. اگر نمی‌خواهید از کلید API استفاده کنید، می‌توانید Ollama را از [ollama.com](https://ollama.com) نصب کنید و به جای آن از مدل‌های محلی مانند `translategemma:4b` استفاده کنید.

اگر از **نسخه وب** استفاده می‌کنید، مدیر سرور ارائه دهندگان را از طریق متغیرهای محیطی پیکربندی می‌کند، بنابراین شما قادر به ورود مستقیم کلید API در برنامه نخواهید بود.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### نحوه تهیه یک کلید API رایگان OpenRouter (اپلیکیشن دسکتاپ)

اگر از اپلیکیشن دسکتا bean استفاده می‌کنید، مراحل زیر را دنبال کنید:

1. به [OpenRouter](https://openrouter.ai) در مرورگر وب خود بروید.
2. یک حساب کاربری ایجاد کنید یا وارد شوید.
3. صفحه [Keys](https://openrouter.ai/keys) را باز کنید.
4. روی دکمه ایجاد یک کلید API جدید کلیک کنید.
5. به کلید یک نام بدهید تا بتوانید در آینده آن را شناسایی کنید.
6. کلید API جدید را کپی کنید.
7. به Transrewrt بازگردید و بخش **تنظیمات** > **پیکربندی API** را باز کنید.
8. کلید را در فیلد **کلید API OpenRouter** (در بخش **تنظیمات** > **پیکربندی API**) بچسبانید.
9. روی دکمه **تست کلید OpenRouter** کلیک کنید تا از صحت عملکرد آن اطمینان حاصل کنید.

<br/><br/>

<a id="getting-started"></a>
## شروع کار

اگر برای اولین بار از Transrewrt استفاده می‌کنید، مراحل زیر را به ترتیب دنبال کنید:

1. اپلیکیشن را باز کنید.
2. در صورت نیاز، **زبان رابط** را از آیکون کره زمین انتخاب کنید.
3. اگر از **اپلیکیشن دسکتاپ** استفاده می‌کنید، بخش [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید، یک کلید API برای حداقل یک ارائه دهنده (مثلاً OpenRouter) اضافه کنید و روی دکمه **تست** کلیک کنید تا از کارکرد آن اطمینان حاصل شود.
4. بخش [**تنظیمات** > **مدل‌ها**](#models) را باز کنید و یک یا چند مدل را به بخش **مدل‌های انتخاب شده** اضافه کنید.
5. بخش [**تنظیمات** > **زبان‌ها**](#languages) را باز کنید و در صورت تمایل **زبان‌های برتر** خود را انتخاب کنید تا زبان‌های پرکاربرد شما اول نمایش داده شوند.
6. به بخش **ترجمه** بروید و یک ترجمه ساده انجام دهید تا مطمئن شوید همه چیز به درستی کار می‌کند.
7. پس از موفقیت در این اقدام، امتحان کنید بخش **بازنویسی** و سپس **تبدیل** را امتحان کنید.

ریتم این ترتیب مهم است. این ترتیب از رایج‌ترین مشکل اولین استفاده جلوگیری می‌کند، یعنی انجام یک کار قبل از اینکه اپلیکیشن اتصال API فعال یا مدل انتخاب شده‌ای داشته باشد.

<a id="toolbar"></a>

### نوار ابزار

نوار ابزار بسته به اینکه در کدام قسمت اپلیکیشن قرار دارید، کمی تغییر می‌کند.

- در سمت چپ، نام صفحه فعلی نمایش داده می‌شود.
- در سمت راست، **انتخابگر مدل** و **کنترل زبان رابط** نمایش داده می‌شود.

**انتخابگر مدل** به شما امکان می‌دهد که کدام موتور هوش مصنوعی برای کار جاری استفاده شود را انتخاب کنید.

  ![انتخابگر مدل](../images/screenshots/fa/model-selector.png)

ممکن است برخی مدل‌های رایگان همیشه در دسترس نباشند — گاهی آن‌ها آفلاین هستند یا محدودیت استفاده دارند. اگر این اتفاق افتاد، اپلیکیشن به‌طور خودکار آن مدل را از لیست مدل‌های قابل استفاده شما حذف می‌کند. برای کنترل اینکه کدام مدل‌ها نمایش داد

## تبدیل

از **تبدیل** زمانی استفاده کنید که می‌خواهید هوش مصنوعی دستورالعمل‌های سفارشی شما را دنبال کند.

![فضای کار تبدیل](../images/screenshots/fa/transform.png)

این بخشِ برنامه انعطاف‌پذیرترین قسمت است. می‌توانید از آن برای انجام وظایفی مانند موارد زیر استفاده کنید:

- خلاصه کردن یادداشت‌ها
- تبدیل متن خام به یک ایمیل روان و صاف
- استخراج نکات کلیدی
- تبدیل متون به قالب خاصی
- هر فعالیت سفارشی دیگری با متن ورودی

<br/>

<a id="run-an-existing-prompt"></a>
### اجرای یک دستور از پیش ساخته شده

1. بخش **تبدیل** را باز کنید.
2. یک دستور از لیست دستورها انتخاب کنید.
3. اگر جعبه‌ای با عنوان **زبان مقصد** ظاهر شد، در صورت تمایل، زبانی را انتخاب کنید.
4. متن خود را در قسمت **ورودی** تایپ یا جای‌گذاری کنید.
5. روی **تبدیل** کلیک کنید.
6. نتیجه را در قسمت **خروجی** بخوانید.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### در صورتی که هنوز دستوری ندارید

اگر لیست دستورات شما خالی است، روی گزینهٔ **بارگذاری دستورهای نمونه** کلیک کنید. این کار نمونه‌های درون‌ساخته‌ای را اضافه می‌کند تا بتوانید سریع‌تر شروع کنید.

<br/>

> ℹ️ **توجه**<br/>
> دستورهای نمونه به زبان انگلیسی ارائه می‌شوند. پس از بارگیری آنها، می‌توانید یک دستور را ویرایش کنید و از گزینهٔ **ترجمهٔ دستور** استفاده کنید تا آن را به زبان خود ترجمه کنید.

<br/>

<a id="create-a-prompt-quickly"></a>
### ایجاد سریع یک دستور

سریع‌ترین روش برای ایجاد یک دستور این است:

1. روی **دستور جدید** کلیک کنید.
2. روی **تولید دستور** کلیک کنید.
3. توضیح دهید که می‌خواهید دستور چه کاری انجام دهد.
4. یک مدل را انتخاب کنید.
5. اجازه دهید برنامه یک پیش‌نویس برای شما ایجاد کند.
6. پیش‌نویس را بررسی کنید و روی **ذخیره** کلیک کنید.

![تولید دستور](../images/screenshots/fa/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### ویرایش یک دستور

هنگامی که یک دستور ایجاد یا ویرایش می‌کنید، ویرایشگر در سمت چپ و یک فضای آزمایش در سمت راست ظاهر می‌شود.

![ویرایشگر دستور تبدیل](../images/screenshots/fa/transform-prompt-edit.png)

فیلدهای اصلی شامل موارد زیر است:

- **نام دستور**: نامی که در لیست دستورها نمایش داده می‌شود.
- **دستورالعمل‌های دستور (اختیاری)**: راهنمای کوتاهی که هنگام اجرای دستور به کاربر نمایش داده می‌شود.
- **نقش مدل**: نقش کلی که به هوش مصنوعی اختصاص داده می‌شود، مثل «شما یک دستیار مفید هستید.»
- **دستورالعمل‌های مدل (یکی در هر خط)**: قوانین دقیقی که می‌خواهید هوش مصنوعی دنبال کند.
- **توصیف خروجی**: یک کلمه یا عبارت کوتاه برای توصیف نتیجه، مثل «خلاصه» یا «بازنویسی».
- **دما (0.0 → 1.0)**: نحوهٔ رفتار مدل؛ به توضیحات پایین مراجعه کنید.
- **درخواست زبان مقصد**: هنگام اجرای دستور، یک گزینه‌ی انتخاب زبان مقصد اضافه می‌کند.

اگر اصطلاح فنی **دما** برای شما جدید است، به این صورت به آن فکر کنید:

- دمای **پایین‌تر** نتایج ثابت‌تر و قابل پیش‌بینی‌تری تولید می‌کند.
- دمای **بالاتر** تنوع و خلاقیت بیشتری ایجاد می‌کند.

شما همچنین می‌توانید از گزینه‌های زیر استفاده کنید:

- **`تولید دستور`** برای ساخت یک پیش‌نویس جدید از یک توصیف ساده
- **`بهبود دستور`** برای اصلاح یک دستور موجود
- **`ترجمهٔ دستور`** برای ترجمهٔ فیلدهای دستور

<br/>

> ⚠️ **هشدار**<br/>
> قبل از اینکه روی **`بازگشت به اجرا`** کلیک کنید، حتماً روی **`ذخیره`** کلیک کنید. اگر بدون ذخیره بازگردید، تغییرات شما از دست خواهد رفت.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### آزمایش یک دستور قبل از استفاده از آن

پنل آزمایش در سمت راست به شما امکان می‌دهد تا قبل از استفاده از دستور در کارهای روزمره، آن را با یک متن نمونه امتحان کنید.

این کار در شرایط زیر مفید است:

- هنگامی که دارید یک دستور جدید می‌سازید
- هنگامی که دو نسخه از یک دستور را مقایسه می‌کنید
- هنگامی که می‌خواهید لهجه، طول یا قالب خروجی را بررسی کنید

<br/>

> ℹ️ **توجه**<br/>
> می‌توانید دستورهای ذخیره شده را در بخش [**تنظیمات** > **دستورهای تبدیل**](#transform-prompts) صادر و وارد کنید.

<a id="general-settings"></a>
### تنظیمات عمومی

از **تنظیمات عمومی** برای کنترل رفتار تایپ، ذخیره‌سازی اطلاعات اجرا برای بخش **تاریخچه** و تنظیمات ظاهری استفاده کنید.

**رفتار**

- **رفار برای ENTER**: مشخص می‌کند که دکمه `Enter` آیا وظیفه را اجرا می‌کند یا خط جدیدی ایجاد می‌کند.
- **ترجمه خودکار هنگام چسباندن**: به محض چسباندن متن، فرآیند ترجمه را آغاز می‌کند.
- **کپی خودکار نتیجه در کلیپ‌بورد**: خروجی‌های موفق به‌صورت خودکار کپی می‌شوند.
- **ترجمه لحظه‌ای (در حین تایپ)**: در حین تایپ، ترجمه را انجام می‌دهد.
- **مهلت زمانی (میلی‌ثانیه)**: زمان انتظار برای ترجمه لحظه‌ای را تنظیم می‌کند.

**تاریخچه**

- **حفظ تاریخچه اجرا**: مشخص می‌کند که آیا هر ترجمه، بازنویسی و تبدیل، **متن ورودی و خروجی** را در بخش تاریخچه نوار کناری ذخیره کند. غیرفعال کردن این گزینه از شما تأیید می‌خواهد؛ در صورت تأیید، متون تاریخچه از پایگاه داده حذف می‌شوند.
- **حذف داده‌های تاریخچه**: به شما امکان می‌دهد تا متن‌های ذخیره‌شده را بر اساس مدت زمان (مثلاً قدیمی‌تر از چند ماه، یا **تمام داده‌ها (پاک کن)**) با استفاده از گزینه **حذف داده** پاک کنید. این عمل تنها بر متون اجرای ذخیره‌شده برای نمایش در بخش **تاریخچه** تأثیر می‌گذارد و **جمع‌بندی هزینه یا میزان استفاده** را حذف نمی‌کند. برای حذف یا کاهش داده‌های **هزینه**، از [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) استفاده کنید.

**ظاهر**

- **نمایش اطلاعات هزینه در عملیات**: نمایش هزینه هر عمل (در صورت موجود بودن) و جمع کل هزینه در پنل‌های خروجی ترجمه، بازنویسی و تبدیل را کنترل می‌کند.
- **تعداد ارقام اعشار هزینه**: نحوه نمایش اعشار هزینه را تغییر می‌دهد.
- **فقط وب:** **نمایش حاشیه‌ای در اطراف برنامه** فاصله اضافی دور رابط کاربری ایجاد می‌کند.
- **خانواده فونت**: فونت استفاده‌شده در پنل‌های متنی را تغییر می‌دهد.
- **اندازه**: اندازه فونت را تغییر می‌دهد.


<br/>

<a id="models"></a>

### مدل‌ها

برای انتخاب مدل‌هایی که در نوار ابزار نمایش داده می‌شوند، از مسیر **تنظیمات** > **مدل‌ها** استفاده کنید.

![برگه مدل‌های تنظیمات](../images/screenshots/fa/settings-models.png)

این صفحه دارای دو لیست است:

- **مدل‌های موجود** در سمت چپ
- **مدل‌های انتخاب‌شده** در سمت راست

کنترل‌های مفید شامل موارد زیر هستند:

- **جستجوی مدل‌ها...** برای یافتن مدلی با نام مشخص
- **تراشه‌های ارائه‌دهنده** برای محدود کردن لیست به یک موتور خاص (OpenRouter، OpenAI، Ollama، …)
- **فقط رایگان** برای نمایش تنها مدل‌های رایگان
- **تازه‌سازی** برای بارگذاری مجدد لیست
- **گسترش همه** و **بستن همه** هنگام مرتب‌سازی بر اساس ارائه‌دهنده

شناسه‌های مدل شامل پیشوند ارائه‌دهنده هستند (مثلاً `openrouter/…` در مقابل `openai/…`). نشان‌هایی مانند **OpenAI (OpenRouter)** در مقابل **OpenAI (مستقیم)** نشان می‌دهند که ترافیک چگونه مسیریابی می‌شود.

> ℹ️ **یادداشت**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) یک مدل مسیریابی است، نه یک مدل چت عمومی: پاسخ آن یک JSON است که بدنه درخواست‌های API OpenRouter را توصیف می‌کند (مثلاً یک آرایه `requests` با `model` و `messages`). اگر آن را برای **ترجمه**، **بازنویسی** یا **تبدیل** استفاده کنید، پنل خروجی این JSON را نشان می‌دهد نه متن نهایی. برای این وظایف، یک مدل متنی معمولی انتخاب کنید. [صفحه مدل Body Builder](https://openrouter.ai/openrouter/bodybuilder) را در OpenRouter ببینید.

اقدامات:

 - برای افزودن یک مدل، روی **افزودن** یا هر جای دیگر در آن ردیف کلیک کنید.

 - برای حذف یک مدل، روی **X** کنار آن در بخش **مدل‌های انتخاب‌شده** یا روی گزینه **انتخاب‌شده** در ردیف مدل موجود کلیک کنید.

 - برای پاک کردن فهرست، روی **عدم انتخاب همه** کلیک کنید. مدل رایگان ضروری در لیست باقی می‌ماند.

<br/>

> ℹ️ **یادداشت**<br/>
> اگر نمی‌خواهید بلافاصله اعتبار به OpenRouter اضافه کنید، ابتدا **فقط رایگان** را فعال و مدل‌های رایگان را انتخاب کنید (نیازی به کارت بانکی نیست). همچنین می‌توانید از Ollama برای اجرای مدل‌ها به صورت محلی بدون کلید API استفاده کنید.

<br/>

<a id="languages"></a>
### زبان‌ها

از مسیر **تنظیمات** > **زبان‌ها** برای سازماندهی فهرست زبان‌های استفاده‌شده در برنامه استفاده کنید.

- **زبان‌های اصلی** در بالای فهرست‌های زبان در بخش **ترجمه** و **تبدیل** ثابت شده‌اند.
- **زبان سفارشی** به شما امکان افزودن زبانی را می‌دهد که در لیست پیش‌فرض نیست.

اگر یک زبان سفارشی اضافه کنید، در کنار گزینه‌های پیش‌فرض در انتخاب‌کننده‌های زبان ظاهر می‌شود.

<br/>

<a id="cost-tracking"></a>
### ردیابی هزینه

از مسیر **تنظیمات** > **ردیابی هزینه** برای مدیریت اطلاعات هزینه استفاده کنید.

- **هزینه کل** مجموع فعال را نشان می‌دهد.
- **کپی کردن مقدار**، مجموع را به حافظه موقت کپی می‌کند.
- **بازنشانی هزینه**، مجموع ذخیره‌شده را به صفر بازمی‌گرداند.
- **همگام‌سازی با مصرف کلید API**، مجموع را با مصرف گزارش‌شده توسط حساب OpenRouter شما هماهنگ می‌کند (فقط OpenRouter).
- **مصرف کلید API** جزئیات مصرف OpenRouter را، در صورت در دسترس بودن، نشان می‌دهد.
- **حذف داده‌های هزینه** تمام داده‌ها یا فقط ورودی‌های قدیمی‌تر از یک تاریخ مشخص را حذف می‌کند.


**ردیابی هزینه:** هنگام استفاده از مدل‌های OpenRouter، برنامه مصرف واقعی و هزینه‌های شما را بر اساس اطلاعات هزینه از OpenRouter نمایش می‌دهد. برای تمام ارائه‌دهندگان دیگر، برنامه هزینه را با استفاده از قیمت‌های انتشار یافته توسط OpenRouter برآورد می‌کند؛ اگر قیمتی در دسترس نباشد، برآورد ممکن است صفر باشد.

<br/>

> ℹ️ **یادداشت**<br/>
> تمام مقادیر هزینه صرفاً برای اطلاعات شما برآورد شده‌اند و جایگزین صورت‌حساب رسمی نیستند.

<br/>

> ⚠️ **هشدار**<br/>
> حذف داده‌ها قابل بازیابی نیست. قبل از حذف، مطمئن شوید داده‌های خود را پشتیبان گرفته یا از طریق [**تاریخچه**](#history) یا [**داشبورد** > **تمامی فراخوانی‌ها**](#dashboard-tabs) صادر کرده‌اید. در غیر این صورت برای همیشه از بین خواهند رفت. تمام تاریخچه ورودی/خروجی مربوط به هر ورودی فراخوانی API نیز حذف خواهد شد.

<br/>

<a id="transform-prompts"></a>
### دستورهای تبدیل

از مسیر **تنظیمات** > **دستورهای تبدیل** برای مدیریت دستورها به صورت گروهی استفاده کنید.

شما می‌توانید:

- دستورهای ذخیره‌شده خود را مرور کنید
- دستورها را حذف کنید
- دستورها را از یک فایل وارد کنید
- دستورها را برای پشتیبان‌گیری یا اشتراک‌گذاری خارج کنید

<br/>

<a id="users"></a>
### کاربران

از بخش **کاربران** برای مدیریت حساب‌های کاربری در نسخه وب استفاده کنید. می‌توانید کاربران اضافه کنید، جزئیات آن‌ها را به‌روز کنید، رمز عبور را بازنشانی کنید و حساب‌ها را حذف کنید.

<br/>

<a id="api-config"></a>
### تنظیمات API

ارائه‌دهندگان پشتیبانی‌شده عبارتند از: OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras و **Ollama** (مدل‌های محلی از طریق یک آدرس URL پایه). شما تنها نیاز به تنظیم ارائه‌دهندگانی دارید که از آن‌ها استفاده می‌کنید.

**برنامه تحت وب: فقط مدیر**

کلیدهای API از طریق متغیرهای محیطی سیستم یا داکر تنظیم می‌شوند — در رابط کاربری وب وارد نمی‌شوند. این صفحه نشان می‌دهد کدام ارائه‌دهندگان دارای کلید تنظیم‌شده هستند و به شما اجازه می‌دهد با کلیک بر دکمه **`تست`** هر یک را آزمایش کنید.

<br/>

> ℹ️ **یادداشت**<br/>
> برای تغییر یک کلید API، متغیر محیطی را در پیکربندی سیستم یا داکر خود به‌روز کنید و سرور یا ظرف را مجدداً راه‌اندازی کنید.

<br/>

**برنامه دسکتاپ**

از **تنظیمات API** برای ذخیره کلیدهای API برای هر ارائه‌دهنده استفاده کنید. برای Ollama، به جای کلید API، **آدرس URL پایه** را وارد کنید.

<br/>

> 💡 **نکته** <br/>
> اگر نمی‌خواهید از کلید API استفاده کنید یا برای مصرف هزینه پرداخت کنید، می‌توانید [Ollama را دانلود کنید](https://ollama.com) و مدل‌ها (مانند `translategemma:4b`) را به صورت رایگان روی دستگاه خود اجرا کنید. به طور جایگزین، می‌توانید یک حساب رایگان OpenRouter ایجاد کنید (نیازی به کارت بانکی نیست) تا از مدل‌های رایگان آن‌ها استفاده کنید، یا یک کلید API رایگان از Cerebras، Google، Groq یا Mistral AI دریافت کنید.

<br/>

- تنها ارائه‌دهندگانی را اضافه کنید که نیاز دارید. در بخش **تنظیمات** > **مدل‌ها**، شناسه هر مدل با ارائه‌دهنده شروع می‌شود (مثلاً `openrouter/openrouter/free`، `openai/gpt-4o`، `ollama/llama3`).

برای افزودن یک کلید API، مقدار آن را در کادر متن وارد و روی **`ذخیره`** کلیک کنید. برای جایگزینی یک کلید موجود، روی **`ویرایش`** کلیک کنید. برای بررسی اینکه کلید درست کار می‌کند، روی **`تست`** کلیک کنید. برای آدرس URL پایه Ollama، همیشه روی **`تست`** کلیک کنید تا اتصال بررسی شود.

<br/>

> ℹ️ **یادداشت**<br/>
> شما نمی‌توانید مقدار کنونی یک کلید API را ببینید. فقط می‌توانید آن را با استفاده از دکمه **`ویرایش`** جایگزین کنید.
> کلیدهای API به صورت رمزنگاری شده در پیکربندی ذخیره می‌شوند.

<a id="common-issues"></a>
## مشکلات رایج

اگر چیزی مطابق انتظار کار نمی‌کند، ابتدا موارد زیر را بررسی کنید.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### برنامه متن را ترجمه، بازنویسی یا تبدیل نمی‌کند

مطمئن شوید که:

- یک مدل را در نوار ابزار انتخاب کرده‌اید
- حداقل یک مدل در بخش [**تنظیمات** > **مدل‌ها**](#models) فهرست شده باشد
- تنظیمات API شما به درستی کار می‌کند

اگر از نسخهٔ دسکتاپ استفاده می‌کنید:

1. [**تنظیمات** > **پیکربندی API**](#api-config) را باز کنید.
2. مطمئن شوید حداقل یک کلید API ذخیره شده باشد.
3. روی دکمهٔ **تست** کنار فراهم‌کننده کلیک کنید تا از صحت کلید اطمینان حاصل کنید.

<br/>

<a id="the-model-list-is-empty"></a>
### لیست مدل‌ها خالی است

به بخش [**تنظیمات** > **مدل‌ها**](#models) بروید و روی **به‌روزرسانی** کلیک کنید.

در صورت نیاز:

- یک مدل جستجو کنید
- گزینهٔ **فقط رایگان** را فعال کنید
- یک یا چند مدل را به بخش **مدل‌های انتخاب‌شده** اضافه کنید

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### نتیجه بسیار کند یا هزینهٔ بالایی دارد

یک یا چند مورد زیر را امتحان کنید:

- یک مدل متفاوت انتخاب کنید
- از ورودی کوتاه‌تری استفاده کنید
- در بخش [**تنظیمات** > **تنظیمات عمومی**](#general-settings) گزینهٔ **ترجمهٔ آنی (در حین تایپ)** را غیرفعال کنید
- برای وظایف ساده از مدل‌های رایگان استفاده کنید (نگاه کنید به [مدل‌ها](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### رابط به زبان اشتباه است

روی آیکون کرهٔ زمین در [نوار ابزار](#toolbar) کلیک کنید و **زبان رابط** موردنظر را انتخاب کنید.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### متن بسیار کوچک یا خواندن آن دشوار است

به بخش [**تنظیمات** > **تنظیمات عمومی**](#general-settings) بروید و تنظیمات زیر را تغییر دهید:

- **خانوادهٔ قلم**
- **اندازه**

<br/>

<a id="dashboard-charts-are-empty"></a>
### نمودارهای داشبورد خالی هستند

این امر در شرایط زیر طبیعی است:

- در حال حاضر فقط از **مدل‌های رایگان** استفاده می‌کنید (نمودارهای هزینه خالی باقی می‌مانند)
- **فیلتر زمانی** انتخاب‌شده دورهٔ انجام فراخوان‌ها را پوشش نمی‌دهد — امتحان کنید **همه** را انتخاب کنید تا بررسی کنید

اگر پس از انتخاب **همه** نمودارها همچنان خالی بودند، مطمئن شوید فراخوان‌ها در بخش [**تاریخچه**](#history) یا در برگهٔ **همهٔ فراخوان‌ها** ظاهر می‌شوند.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### هزینه «در دسترس نیست» نمایش داده می‌شود یا به نظر اشتباه می‌رسد

هنگامی که از مدل‌ها از طریق **OpenRouter** استفاده می‌کنید، برنامه میزان هزینهٔ واقعی‌تان که توسط OpenRouter گزارش شده را نشان می‌دهد.

برای **سایر فراهم‌کنندگان** (مثل OpenAI مستقیم، Anthropic مستقیم و غیره)، هزینه از روی داده‌های قیمت‌گذاری منتشرشده توسط OpenRouter تخمین زده می‌شود. اگر برای یک مدل، قیمت مطابقی یافت نشود، هزینه به صورت **در دسترس نیست** نمایش داده می‌شود و به مجموع کل هزینه اضافه نمی‌شود.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### هزینهٔ کل با قبض فراهم‌کنندهٔ من مطابقت ندارد

همهٔ اعداد و ارقام مربوط به هزینه در این برنامه **تنها برای مرجع بوده و تخمینی هستند** و صورتحساب رسمی محسوب نمی‌شوند.

برای اینکه مجموع هزینه به مقدار واقعی هزینهٔ شما در OpenRouter نزدیک‌تر شود، به بخش [**تنظیمات** > **ردیابی هزینه**](#cost-tracking) بروید و روی **همگام‌سازی با میزان استفاده از کلید API** کلیک کنید.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### صفحهٔ تاریخچه در نوار کناری گم شده است

مقدار **حفظ تاریخچهٔ اجرا** ممکن است غیرفعال باشد. به بخش [**تنظیمات** > **تنظیمات عمومی**](#general-settings) بروید و آن را فعال کنید. توجه داشته باشید که فعال کردن این گزینه داده‌های تاریخچهٔ حذف‌شده قبلی را بازیابی نمی‌کند.

<br/>

<a id="web-app-session-expired"></a>
### برنامهٔ تحت وب: به طور غیرمنتظره به صفحهٔ ورود هدایت شدم

ممکن است جلسهٔ شما منقضی شده باشد. دوباره وارد شوید. اگر این اتفاق اغلب رخ می‌دهد، تنظیمات طول عمر جلسه را در پیکربندی سرور بررسی کنید.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### داشبورد داده‌ای برای سایر کاربران نشان نمی‌دهد (وب)

فقط **مدیران** می‌توانند از طریق فیلتر **کاربر** داده‌های تمام کاربران را ببینند. کاربران عادی فقط فعالیت خودشان را طبق طراحی مشاهده می‌کنند.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### یک پِرامت را تغییر دادم و ویرایش‌هایم را از دست دادم

هنگام ویرایش یک پِرامت، قبل از کلیک روی **بازگشت به اجرا** همیشه روی دکمهٔ **ذخیره** کلیک کنید.

<br/><br/>

<a id="quick-tips"></a>
## نکات سریع

- از [**ترجمه**](#translate) برای اطمینان از صحت کارکرد تنظیمات خود در ابتدا استفاده کنید و قبل از اینکه به [**بازنویسی**](#rewrite) یا [**تبدیل**](#transform) بروید.
- از [**بازنویسی**](#rewrite) برای بهبود روزمرهٔ متن خود استفاده کنید.
- از [**تبدیل**](#transform) زمانی استفاده کنید که به یک روال قابل تکرار برای یک کار خاص نیاز داشته باشید.
- از [**داشبورد**](#dashboard) برای نظارت بر مصرف و هزینه‌ها استفاده کنید.
- از [**تاریخچه**](#history) برای بررسی عملیات قبلی و متن کامل ورودی/خروجی آن‌ها استفاده کنید.
- اگر در حال ساخت کتابخانه‌ای از پِرامت‌ها هستید که می‌خواهید آن را نگه دارید یا با دیگران به اشتراک بگذارید، به طور منظم آن‌ها را خارج‌سازی کنید (نگاه کنید به [پِرامت‌های تبدیل](#transform-prompts)).
