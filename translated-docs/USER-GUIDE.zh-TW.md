# 使用者指南

<br/>

<a id="introduction"></a>

## 簡介

Transrewrt 提供三種主要方式協助您處理文字：

- **翻譯** - 將文字從一種語言轉換為另一種語言。
- **改寫** - 以不同的風格重新表述文字，例如更清晰、更簡潔或更正式。
- **轉換** - 使用稱為提示（prompts）的自定義 AI 指令來處理文字。

<br/>

本指南說明應用程式安裝並執行後的操作方法。如需安裝步驟，請參閱主文件 **[README](README.zh-TW.md)**。

<br/>

> ℹ️ **注意**<br/>
> Transrewrt 可作為 Windows 和 Linux 的桌面應用程式，以及自架 Web 應用程式使用。本指南著重於應用程式的日常使用。若有僅適用於某個版本的功能，將會明確標示。

<a id="before-you-start"></a>

## 開始之前

要使用 Transrewrt，您至少需要存取一個 AI 服務提供者。支援的提供者包括：[OpenRouter](https://openrouter.ai)（整合多種模型）、OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、Mistral、xAI、Cerebras，以及用於本地模型的 [Ollama](https://ollama.com)。

您無需選擇付費模型即可開始使用。一旦您加入 OpenRouter 的 API 金鑰，應用程式便會自動啟用內建的**免費** OpenRouter 選項。這讓您可以立即開始翻譯、改寫和轉換文字。或者，您也可以從 Cerebras、Google、Groq 或 Mistral AI 取得免費的 API 金鑰。

簡單來說：

- **模型** 是執行工作的 AI 引擎。模型會以**提供者前綴**列出（例如 `openrouter/…`、`openai/…`、`ollama/…`）。
- **API 金鑰**（或對 Ollama 而言是**基礎 URL**）是應用程式用來連接該提供者的方式。

如果您使用的是**桌面應用程式**，請在 [**設定** > **API 設定**](#api-config) 中為您使用的每個提供者新增金鑰。若僅使用 OpenRouter，請參見下方的 [如何取得 API 金鑰](#how-to-get-an-api-key-desktop-app)。如果您不想使用 API 金鑰，也可以安裝 Ollama（來自 [ollama.com](https://ollama.com)）並改用本地模型，例如 `translategemma:4b`。

如果您使用的是**網頁版本**，伺服器管理員會透過環境變數來設定提供者，因此您無法直接在應用程式中輸入 API 金鑰。

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>

### 如何取得免費的 OpenRouter API 金鑰（桌面應用程式）

若您使用的是桌面應用程式，請遵循以下步驟：

1. 在您的網頁瀏覽器中前往 [OpenRouter](https://openrouter.ai)。
2. 建立帳號或登入。
3. 開啟 [Keys](https://openrouter.ai/keys) 頁面。
4. 按一下按鈕以建立新的 API 金鑰。
5. 為金鑰命名，以便日後辨識。
6. 複製新建立的 API 金鑰。
7. 返回 Transrewrt 並開啟 **設定** > **API 設定**。
8. 將金鑰貼上至 **OpenRouter API 金鑰**（位於 **設定** > **API 設定** 中）。
9. 按一下 **測試 OpenRouter 金鑰** 以確認其正常運作。

<a id="getting-started"></a>

## 開始使用

如果您是第一次使用 Transrewrt，請依照以下順序進行：

1. 開啟應用程式。
2. 如有需要，點擊 globe 圖示選擇您的**介面語言**。
3. 如果您使用的是**桌面應用程式**，請開啟 [**設定** > **API 設定**](#api-config)，為至少一個供應商（例如 OpenRouter）新增 API 金鑰，然後點擊**測試**以確認其正常運作。
4. 開啟 [**設定** > **模型**](#models)，並將一個或多個模型新增至**已選模型**。
5. 開啟 [**設定** > **語言**](#languages)，並選擇您的**優先語言**，讓您最常使用的語言優先顯示。
6. 前往**翻譯**頁面，執行一個簡單的翻譯以確認所有設定皆正常運作。
7. 當確認運作正常後，請嘗試**重寫**功能，然後再試用**轉換**功能。

此順序相當重要。它可避免最常見的初次使用問題：在應用程式尚未建立有效的 API 連線或選擇模型前就嘗試執行任務。

### 輸入與輸出面板

大多數工作區都使用左側的**輸入**面板和右側的**輸出**面板。

每個面板還會顯示：

| **輸入**                                                          | **輸出**                                                                                                                  |

## 翻譯

當您需要將文字從一種語言轉換為另一種語言時，請使用「翻譯」功能。

![翻譯工作區](../images/screenshots/zh-TW/translate.png)

<br/>

<a id="translate-text"></a>

### 翻譯文字

1. 開啟 **翻譯**。
2. 在 **從** 中選擇一種語言。
3. 在 **至** 中選擇一種語言。
4. 在工具列中選擇一個模型。
5. 在 **輸入** 區域中鍵入或貼上文字。
6. 按一下 **翻譯**。
7. 在 **輸出** 區域中查看結果。
8. 如果需要複製結果，可使用複製按鈕。

<br/>

<a id="language-selection"></a>

### 語言選擇

- **從** 可以是特定語言或 **偵測語言**。
- **到** 是您希望翻譯結果呈現的語言。

您選擇的 **常用語言** 將會出現在清單頂端。您可以在 [**設定** > **語言**](#languages) 中進行設定。

<br/>

<a id="helpful-translation-settings"></a>

### 有助益的翻譯設定

在[**設定** > **一般設定**](#general-settings)中，您可以變更翻譯的運作方式：

- **貼上時自動翻譯**：當您貼上文字時，立即執行翻譯。
- **自動複製結果到剪貼簿**：成功執行翻譯後，自動複製結果。
- **即時翻譯（輸入時）**：當您在輸入時即自動執行翻譯。
- **逾時時間（毫秒）**：控制應用程式在執行即時翻譯前等待的時間。
- **Enter 鍵行為**：控制您按下 `Enter` 時發生的事情：

<a id="rewrite"></a>

## 重寫

當您想要在不改變主要意義的情況下改善文字表述時，請使用「重寫」功能。

![重寫工作區](../images/screenshots/zh-TW/rewrite.png)

此功能適用於：

- 修正拼字與語法錯誤（**檢查拼字與語法**）
- 讓文字更清晰易懂（**提升清晰度**）
- 單次執行產生多種不同表述方式（**其他版本**）
- 讓文字更正式或更口語化（**正式**／**非正式**）
- 縮短或擴展文字內容（**縮短**／**擴展**）
- 讓文字更具技術性（**轉為技術性語氣**）

<br/>

> 💡 **小提示**<br/>
> 使用「**檢查拼字與語法**」模式時，輸出面板中會出現「**顯示變更**」切換開關（位於「複製」按鈕旁邊）。
> 可透過開啟或關閉此開關，來顯示或隱藏對您的文字所做的具體修正。

<a id="transform"></a>

## 轉換

當您在希望 AI 遵循自定義指令集時，請使用「轉換」功能。

![轉換工作區](../images/screenshots/zh-TW/transform.png)

這是應用程式中最靈活的區域，您可以用來執行諸如以下的任務：

- 摘要筆記
- 將草稿文字轉換為精煉的電子郵件
- 提取重點內容
- 將文字轉換為特定格式
- 對輸入的文字進行任何其他自訂處理

<br/>

<a id="run-an-existing-prompt"></a>

### 執行現有的提示

1. 開啟 **轉換**。
2. 從提示列表中選擇一個提示。
3. 如果出現 **目標** 語言欄位，可依需求選擇語言。
4. 在 **輸入** 區域中輸入或貼上文字。
5. 點選 **轉換**。
6. 在 **輸出** 區域查看結果。

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### 如果尚未有提示詞

如果您的提示詞列表是空的，請在 Transform 工作區中點選 **載入範例提示詞**。相同的控制項也始終位於 [**設定** > **Transform 提示詞**](#transform-prompts) 的匯入／匯出列中。這兩個方式都會加入內建範例，讓您快速開始使用。

<br/>

> ℹ️ **注意**<br/>
> 範例提示詞是以英文提供。載入後，您可以編輯提示詞，並使用 **翻譯提示詞** 將其翻譯成您使用的語言。

<br/>

<a id="create-a-prompt-quickly"></a>

### 快速建立提示詞

建立提示詞最快的方式如下：

1. 按一下 **新增提示詞**。
2. 按一下 **產生提示詞**。
3. 描述您希望此提示詞執行的內容。
4. 選擇一個模型。
5. 讓應用程式為您建立草稿。
6. 檢閱草稿後，按一下 **儲存**。

![產生提示詞](../images/screenshots/zh-TW/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>

### 編輯提示詞

當您建立或編輯提示詞時，編輯器會出現在左側，測試區域則出現在右側。

![轉換提示詞編輯器](../images/screenshots/zh-TW/transform-prompt-edit.png)

主要欄位包括：

- **提示詞名稱**：在提示詞列表中顯示的名稱。
- **提示詞說明（可選）**：執行提示詞時會顯示給使用者的簡短提示。
- **模型角色**：指定給 AI 的整體角色，例如「你是一個樂於助人的助理。」
- **模型說明（每行一項）**：您希望 AI 遵循的具體規則。
- **輸出描述**：描述結果的簡短詞語，例如「摘要」或「重寫」。
- **溫度（0.0 → 1.0）**：決定模型的行為模式；詳見下方說明。
- **詢問目標語言**：執行提示詞時，會額外加入目標語言選擇器。

若您不熟悉「**溫度（Temperature）**」這個技術術語，可以這樣理解：

- **較低**的溫度會產生更穩定、可預測性更高的結果。

- **較高**的溫度可帶來更多樣化和更具創意的結果。

您還可以使用：

- **`生成提示`**：根據簡短描述創建新草稿
- **`改進提示`**：優化現有的提示內容
- **`翻譯提示`**：翻譯提示欄位內容

<br/>

> ⚠️ **警告**<br/>
> 請在點擊 **`返回執行`** 前先點擊 **`儲存`**。若未儲存就返回，您的更改將會遺失。

<a id="general-settings"></a>

### 一般設定

使用「一般設定」可控制輸入行為、是否儲存執行詳細資料至「歷史記錄」，以及外觀顯示。

**行為**

- **Enter 鍵行為**：選擇按下 `Enter` 時是要執行任務還是插入新行。
- **貼上時自動翻譯**：貼上文字時立即開始翻譯。
- **自動複製結果到剪貼簿**：自動複製成功的翻譯結果。
- **即時翻譯（輸入時）**：在您輸入的同時進行翻譯。
- **逾時時間（毫秒）**：設定即時翻譯等待的時間。

**歷史記錄**

- **保留執行歷史**：控制每次翻譯、重寫和轉換是否將「輸入與輸出文字」儲存於側邊欄的［**歷史記錄**](#history) 檢視中。關閉此選項時會提示確認；若確認，資料庫中儲存的歷史記錄將被刪除。

- **刪除歷史資料** 可讓您依照時間（例如幾個月前的資料，或 **全部資料（清除）**）使用 **刪除資料** 功能來移除已儲存的文字。此操作僅影響 **歷史記錄** 頁面中儲存的執行文字，**不會** 刪除成本或使用量的總計資料。若要移除或修剪 **成本** 資料，請使用[**設定** > **成本追蹤**](#cost-tracking)。

**外觀**

- **在操作按鈕上顯示成本資訊** 可控制是否顯示每個操作的成本（若可用）以及「翻譯」、「重寫」和「轉換」輸出面板中的總成本。
- **成本小數位數** 可變更成本數值的小數點顯示方式。
- **僅限網頁版**：**在應用程式周圍顯示邊界間距** 可在介面周圍增加額外空間。
- **字型** 可變更文字面板中的書寫字體。
- **大小** 可調整字型大小。

**設定備份**

- **在備份中包含使用資料** — 啟用後，ZIP 檔案還會包含執行歷史記錄和 API 呼叫資料。

- **備份設定** — 會建立單一個 ZIP 檔案（預設命名為 `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`，使用 UTC 時間格式），內容包含 `config.json`、`state.json`、可選的加密金鑰、使用者資料、偏好設定、自訂提示與使用資料（若您已選擇包含使用資料）。備份成功後，確認訊息將顯示已儲存的檔案名稱。
- **從備份還原** — 將先開啟一個**確認對話視窗**。請在對話視窗中選擇備份的 ZIP 檔案（可點選「瀏覽」或使用檔案選擇器，支援拖曳放置功能），然後檢視以下選項：
  - **還原使用資料** — 若原始備份包含使用歷史資料，則將其匯入；若您僅想還原設定與提示，可不勾選此項。
  - **還原前清除舊的使用資料** — 在套用備份資料前，先移除目前安裝版本中的既有使用／歷史資料（可選；當您希望完全取代時使用）。

無論是在網頁版或桌面版建立的備份，皆可在另一個版本中還原。當在網頁版中還原桌面版的備份時，資料將會還原至管理員使用者。

### 模型

使用「設定」>「模型」來選擇工具列中要顯示的模型。

![設定中的模型頁籤](../images/screenshots/zh-TW/settings-models.png)

此頁面包含兩個清單：

- 左側的「可用模型」
- 右側的「已選擇模型」

實用的控制選項包括：

- 「搜尋模型...」可依名稱尋找模型
- 「提供者」標籤用於將清單縮小至單一引擎（OpenRouter、OpenAI、Ollama 等）
- 「僅限免費」用於僅顯示免費模型
- 「重新整理」用於重新載入清單

模型 ID 包含提供者前綴（例如 `openrouter/…` 與 `openai/…`）。標章如「OpenAI (OpenRouter)」與「OpenAI (direct)」則顯示流量的路由方式。

> ℹ️ **注意**<br/>

> **OpenRouter Body Builder** (`openrouter/bodybuilder`) 是一種路由模型，而非一般聊天模型：其回應為描述 OpenRouter API 請求內容的 JSON（例如包含 `model` 和 `messages` 的 `requests` 陣列）。若您將其用於**翻譯**、**重寫**或**轉換**等任務，輸出面板將顯示該 JSON，而非完成的文本。對於這些任務，請選擇一般的文字模型。詳情請見 OpenRouter 上的[Body Builder 模型頁面](https://openrouter.ai/openrouter/bodybuilder)。

操作方式：

 - 若要新增模型，請點擊**新增**按鈕，或點擊任一選項列的空白處。

 - 若要移除模型，請點擊**已選取模型**清單中旁邊的 **X**，或在可用模型列表中該項目旁的 **X**。

 - 若要清除清單，請點擊**全部取消選取**。必要之免費模型仍將保留在清單中。

<br/>

> ℹ️ **注意**<br/>

> 如果您不希望立即為 OpenRouter 添加積分，可先啟用「僅限免費」選項，並選擇免費模型（無需信用卡）。您也可以使用 Ollama 在本機執行模型，無需任何 API 金鑰。

### 成本追蹤

### API 設定

支援的服務提供者包括：OpenRouter、OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、Mistral、xAI、Cerebras，以及 **Ollama**（透過基本 URL 使用本地模型）。您只需設定所使用的服務提供者。

API 金鑰需透過系統或 Docker 環境變數進行設定——無法於網頁介面中輸入。此頁面會顯示哪些服務提供者已設定金鑰，並可透過點擊 **`測試`** 按鈕來測試每一項。

> 若要變更 API 金鑰，請更新系統或 Docker 設定中的環境變數，並重新啟動伺服器或容器。

> ℹ️ **注意**<br/>

> **設定備份**（參見[**一般設定** → 設定備份](#general-settings)）可在 ZIP 檔案的 `config.json` 中嵌入**已解析的**提供者金鑰。還原該 ZIP 檔案時，**不會**將這些金鑰複製回伺服器的持久化設定檔中——執行中的金鑰仍然來自於環境變數以及該處所述的既有檔案狀態。

<br/>

> 💡 **提示** <br/>
> 如果您不想使用 API 金鑰或付費用戶服務，可以[下載 Ollama](https://ollama.com) 並在您的機器上本地免費執行模型（例如 `translategemma:4b`）。或者，您也可以創建一個免費的 OpenRouter 帳戶（無需信用卡），使用他們提供的免費模型，或者從 Cerebras、Google、Groq 或 Mistral AI 取得免費的 API 金鑰。

<br/>

- 僅新增您需要的供應商。在「**設定**」>「**模型**」中，每個模型 ID 都以供應商名稱開頭（例如 `openrouter/openrouter/free`、`openai/gpt-4o`、`ollama/llama3`）。

如需新增 API 金鑰，請在文字欄位中輸入金鑰值，然後按一下「**`儲存`**」。若要取代現有的金鑰，請按一下「**`編輯`**」。若要測試金鑰是否有效，請按一下「**`測試`**」。對於 Ollama 的基礎 URL，請務必按一下「**`測試`**」以檢查連線狀況。

<br/>

> ℹ️ **注意**<br/>
> 您無法檢視目前 API 金鑰的值，只能透過「**`編輯`**」按鈕進行替換。
> API 金鑰會以加密方式儲存在設定檔中。

<a id="common-issues"></a>

## 常見問題

如果某些功能未如預期運作，請先檢查以下幾點。

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### 應用程式無法翻譯、改寫或轉換文字

請檢查以下事項：

- 您已在工具列中選擇一個模型
- 至少有一個模型列於[**設定** > **模型**](#models)中
- 您的API設定運作正常

如果您使用的是桌面應用程式：

1. 開啟[**設定** > **API 設定**](#api-config)。
2. 確認至少已儲存一個API金鑰。
3. 點選供應商旁邊的**測試**按鈕，以確認金鑰是否正常運作。

<br/>

<a id="the-model-list-is-empty"></a>

### 模型清單為空

開啟[**設定** > **模型**](#models)並點擊**重新整理**。

如有需要：

- 搜尋特定模型
- 啟用**僅限免費**
- 將一個或多個模型加入**已選模型**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>

### 結果太慢或太貴

請嘗試以下其中一項或多項：

- 選擇不同的模型
- 縮短輸入內容
- 在 [**設定** > **一般設定**](#general-settings) 中關閉**即時翻譯（輸入時翻譯）**功能
- 對簡單任務使用免費模型（參見 [模型](#models)）

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>

### 介面語言錯誤

按一下[工具列](#toolbar)中的地球圖示，然後選擇您偏好的**介面語言**。

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>

### 文字太小或難以閱讀

開啟[**設定** > **一般設定**](#general-settings) 並更改：

- **字型**
- **大小**

<br/>

<a id="dashboard-charts-are-empty"></a>

### 儀表板圖表為空白

如果出現以下情況，這是正常的：

- 您僅使用**免費模型**，且正在查看**成本**數據（成本可能為零）；在**摘要**中的**使用量**呼叫次數圖表仍需選定期間的數據
- 選定的**時間篩選器**未涵蓋實際呼叫的期間 — 請嘗試選擇**全部**來確認

如果選取**全部**後圖表仍然空白，請確認呼叫記錄是否出現在[**歷程**](#history)或**全部呼叫**分頁中。

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### 費用顯示為「不可用」或似乎有誤

當您透過 **OpenRouter** 使用模型時，應用程式會顯示 OpenRouter 所回報的實際花費。

對於**其他提供商**（如直接使用 OpenAI、Anthropic 等），費用是根據 OpenRouter 公布的定價資料進行估算。如果找不到對應模型的價格，費用將顯示為**不可用**，且不會計入您的累計總費用中。

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### 總成本與提供商帳單不符

應用程式中的所有成本數值均為**估算值，僅供參考**，並非正式的帳單憑證。

若要使總金額更接近您實際在 OpenRouter 的消費，請開啟 [**設定** > **成本追蹤**](#cost-tracking)，然後點選**與 API 金鑰使用量同步**。

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### 側邊欄中遺失歷史頁面

**保留執行程式歷史** 的功能可能已關閉。請開啟 [**設定** > **一般設定**](#general-settings) 並啟用此功能。請注意，開啟此功能並不會還原先前已刪除的歷史資料。

<br/>

<a id="web-app-session-expired"></a>

### 網頁應用程式：意外地被導向至登入頁面

您的工作階段可能已逾時。請重新登入。如果此情況頻繁發生，請檢查伺服器設定中的工作階段存留時間設定。

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### 網頁管理介面：忘記或遺失密碼

此方法適用於**自行託管的網頁應用程式**（Docker），不適用於桌面應用程式（Electron）。

- 如果仍有其他管理員可以登入，他們可開啟 [**設定** > **使用者**](#users)，選擇該帳號，並在那裡設定**新密碼**。
- 如果你已**無法登入**，但仍有機器或容器的**殼層存取權限**，可使用映像檔內建的工具重設密碼（若你更改了預設名稱，請將 `transrewrt` 取代為實際名稱；若密碼包含空格或特殊字元，請以引號包起來）：

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

如果你未曾建立其他帳號，預設的管理員帳號為 `admin`。若僅提供一個參數，則會被視為 `admin` 帳號的新密碼。

如果你是從**原始碼**執行而非使用 Docker，請使用：

```bash
pnpm run reset-web-password -- <username> <new-password>

此腳本會更新 SQLite 資料庫中的使用者記錄（如果缺少 `admin` 使用者，也可建立該使用者）。重設後，請使用新密碼登入。


<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>

### 儀表板對其他使用者顯示無資料（網頁）

只有 **管理員** 可以透過 **使用者** 篩選器查看所有使用者的資料。一般使用者依設計只能看到自己的活動紀錄。

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>

### 我修改了提示詞，但編輯內容卻不見了

編輯提示詞時，請務必先點擊 **儲存**，再點擊 **返回執行**。

<a id="quick-tips"></a>

## 快速提示

- 請先從 [**翻譯**](#translate) 開始，以確保您的設定可正常運作，再繼續進行 [**重寫**](#rewrite) 或 [**轉換**](#transform)。
- 日常的語句優化，請使用 [**重寫**](#rewrite)。
- 當您需要針對特定任務建立可重複的工作流程時，請使用 [**轉換**](#transform)。
- 若您想監控使用情況與成本，請使用 [**儀表板**](#dashboard)。
- 使用 [**歷史記錄**](#history) 來查看以往的操作及其完整的輸入/輸出內容。
- 若您正在建立需要保存的安全提示詞庫，或想要與他人分享，請定期匯出提示詞（參見 [轉換提示詞](#transform-prompts)）。
