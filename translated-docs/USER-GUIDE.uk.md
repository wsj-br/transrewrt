# Керівництво для користувача

<br/>

<a id="introduction"></a>
## Вступ

Transrewrt допомагає працювати з текстом трьома основними способами:

- **Перекласти** - перетворити текст з однієї мови на іншу.
- **Перефразування** - переформулювати текст у різних стилях, наприклад, зрозуміліше, коротше або формальніше.
- **Трансформація** - обробляти текст за допомогою спеціальних інструкцій для штучного інтелекту, які називаються промптами.

<br/>

У цьому керівництві пояснюється, як користуватися додатком після його встановлення та запуску. Щодо кроків встановлення, дивіться основний файл **[README](README.uk.md)**.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Transrewrt доступний як настільний додаток для Windows та Linux, а також як веб-додаток для самостійного розгортання. Це керівництво зосереджено на повсякденному використанні додатку. Якщо якась функція стосується лише однієї версії, це чітко позначено.

<a id="before-you-start"></a>
## Перш ніж почати

Щоб використовувати Transrewrt, вам потрібен доступ хоча б до одного постачальника ШІ. Підтримувані постачальники: [OpenRouter](https://openrouter.ai) (який об'єднує багато моделей), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras та [Ollama](https://ollama.com) для локальних моделей.

Вам не потрібно вибирати платну модель, щоб почати. Як тільки ви додасте свій ключ API OpenRouter, додаток автоматично активує вбудовану **безкоштовну** опцію OpenRouter. Це дозволяє одразу почати переклад, перефразування та трансформацію тексту. Крім того, ви можете отримати безкоштовний ключ API від Cerebras, Google, Groq або Mistral AI.

Простими словами:

- **Модель** - це рушій ШІ, який виконує роботу. Моделі вказані з **префіксом постачальника** (наприклад, `openrouter/…`, `openai/…`, `ollama/…`).
- **Ключ API** (або для Ollama - **базовий URL**) - це спосіб, за допомогою якого додаток зв'язується з постачальником.

Якщо ви використовуєте **настільний додаток**, додайте ключі в розділі [**Налаштування** > **Конфігурація API**](#api-config) для кожного постачальника, якого використовуєте. Якщо використовуєте лише OpenRouter, див. нижче [Як отримати ключ API](#how-to-get-an-api-key-desktop-app). Якщо ви не хочете використовувати ключ API, ви можете встановити Ollama (з [ollama.com](https://ollama.com)) і використовувати локальні моделі, наприклад `translategemma:4b`.

Якщо ви використовуєте **веб-версію**, власник сервера налаштовує постачальників через змінні середовища, тому ви не можете безпосередньо вводити ключі API в додатку.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Як отримати безкоштовний ключ API OpenRouter (настільний додаток)

Якщо ви використовуєте настільний додаток, виконайте такі кроки:

1. Перейдіть на сайт [OpenRouter](https://openrouter.ai) у своєму веб-браузері.
2. Створіть обліковий запис або увійдіть.
3. Відкрийте сторінку [Keys](https://openrouter.ai/keys).
4. Натисніть кнопку, щоб створити новий ключ API.
5. Надайте ключу назву, щоб ви змогли розпізнати його пізніше.
6. Скопіюйте новий ключ API.
7. Поверніться до Transrewrt і відкрийте **Налаштування** > **Конфігурація API**.
8. Вставте ключ у поле **OpenRouter API key** (у розділі **Налаштування** > **Конфігурація API**).
9. Натисніть **Test OpenRouter key**, щоб переконатися, що він працює.

<a id="getting-started"></a>
## Початок роботи

Якщо ви вперше використовуєте Transrewrt, дотримуйтесь такого порядку:

1. Відкрийте додаток.
2. За потреби виберіть **Мову інтерфейсу** за допомогою піктограми глобуса.
3. Якщо ви використовуєте **настільний додаток**, відкрийте [**Налаштування** > **Конфігурація API**](#api-config), додайте ключ API хоча б для одного постачальника (наприклад, OpenRouter) і натисніть **Тест**, щоб перевірити його роботу.
4. Відкрийте [**Налаштування** > **Моделі**](#models) і додайте одну або кілька моделей до **Вибраних моделей**.
5. Відкрийте [**Налаштування** > **Мови**](#languages) і виберіть свої **Найчастіші мови**, якщо хочете, щоб найчастіше використовувані мови відображались першими.
6. Перейдіть до **Перекладу** і виконайте простий переклад, щоб переконатися, що все працює.
7. Як тільки це спрацює, спробуйте **Перефразування**, а потім - **Трансформацію**.

Цей порядок важливий. Він запобігає найпоширенішій проблемі для нових користувачів: спробі виконати завдання до того, як додаток отримав робоче з'єднання API або вибрану модель.

### Панель інструментів

Панель інструментів трохи змінюється залежно від того, де ви перебуваєте в додатку.

- Зліва вона показує назву поточної сторінки.
- Справа вона показує **вибір моделі** та елемент керування **Мовою інтерфейсу**.

**Вибір моделі** дозволяє обрати, який рушій ШІ використовувати для поточного завдання.

![Model selector](../images/screenshots/uk/model-selector.png)

Деякі безкоштовні моделі можуть бути недоступними - іноді вони вимкнені або мають обмеження на використання. Якщо це трапиться, додаток автоматично видалить цю модель з вашого списку доступних. Щоб керувати тим, які моделі відображаються, перейдіть до [**Налаштувань** > **Моделі**](#models) та відредагуйте свій список моделей.
Ви також можете відкрити налаштування моделі безпосередньо, натиснувши на іконку постачальника ліворуч від назви моделі на панелі інструментів.

<br/>

**Іконка глобуса та код мови** змінюють мову інтерфейсу додатку, наприклад, меню та кнопки. Вони **не** змінюють мови перекладу, що використовуються в розділі **Перекласти**.

<a id="input-and-output-panels"></a>
### Панелі введення та виведення

Більшість робочих просторів використовують ліву панель **Введення** та праву панель **Результату**.

Кожна панель також показує:

| **Ввід**                                                          | **Результат**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Кількість символів <br/>- Кількість слів <br/>- Кількість абзаців   <br/> | - Час виконання завдання<br/>- **TPS** (токени за секунду)<br/>- Кількість символів, слів і абзаців<br/>- Використана модель |

Якщо ви цікавитесь технічними термінами:

- **Токен** означає невелику частину тексту. Ви можете уявити це як частину слова або коротке слово.
- **TPS** означає, скільки таких фрагментів тексту модель обробляє за секунду.

<br/>

Ви також можете відстежувати вартість кожної операції (якщо доступно) та загальну вартість, увімкнувши опцію `Показувати інформацію про вартість дій` в розділі [**Налаштування** > **Загальні налаштування**](#general-settings).

<a id="translate"></a>
## Перекласти

Використовуйте **Перекласти**, коли хочете перетворити текст з однієї мови на іншу.

![Translate workspace](../images/screenshots/uk/translate.png)

<br/>

<a id="translate-text"></a>
### Переклад тексту

1. Відкрийте **Перекласти**.
2. Виберіть мову в полі **З**.
3. Виберіть мову в полі **На**.
4. Виберіть модель на панелі інструментів.
5. Наберіть або вставте текст у поле **Ввід**.
6. Натисніть **Перекласти**.
7. Прочитайте результат у полі **Результат**.
8. Використовуйте кнопку копіювання, якщо хочете скопіювати результат.

<br/>

<a id="language-selection"></a>
### Вибір мови

- **З** може бути конкретною мовою або **Визначити мову**.
- **На** - це мова, на яку ви хочете отримати результат.

Ваші вибрані **Найпопулярніші мови** з'являються вгорі списку. Ви можете встановити їх у розділі [**Налаштування** > **Мови**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Корисні налаштування перекладу

У розділі [**Налаштування** > **Загальні налаштування**](#general-settings) можна змінити поведінку перекладу:

- **Автопереклад при вставці** - виконує переклад одразу після вставлення тексту.
- **Автокопіювання результату в буфер обміну** - автоматично копіює результат після успішного виконання.
- **Переклад у реальному часі (під час введення)** - виконує переклад під час набору тексту.
- **Тайм-аут (мс)** - визначає, як довго додаток чекає перед запуском перекладу в реальному часі.
- **Enter** - визначає, що відбувається при натисканні `Enter`:

<a id="rewrite"></a>
## Перефразування

Використовуйте **Перефразування**, коли хочете покращити формулювання, не змінюючи основного змісту.

![Rewrite workspace](../images/screenshots/uk/rewrite.png)

Це корисно для:

- виправлення правопису та граматики (**Перевірка правопису та граматики**)
- покращення ясності тексту (**Покращити ясність**)
- отримання кількох різних варіантів перефразування за один раз (**Альтернативні версії**)
- зробити текст більш формальним або неформальним (**Формальний** / **Неформальний**)
- скорочення або розширення тексту (**Скоротити** / **Розширити**)
- зробити текст більш технічним (**Зробити технічним**)

<br/>

> 💡 **ПОРАДА**<br/>
> Коли ви використовуєте режим "**Перевірка правопису та граматики**", у панелі результату (поруч із **Копіювати**) з'являється перемикач **Показати зміни**.

<a id="transform"></a>
## Трансформація

Використовуйте **Трансформацію**, коли хочете, щоб ШІ виконав користувацькі інструкції.

![Transform workspace](../images/screenshots/uk/transform.png)

Це найбільш гнучкий розділ додатку. Його можна використовувати для таких завдань, як:

- узагальнення нотаток
- перетворення сирого тексту на відредаговане електронне листування
- витягнення ключових пунктів
- перетворення тексту у певний формат
- будь-які інші користувацькі дії з вхідним текстом

<br/>

<a id="run-an-existing-prompt"></a>
### Виконати існуючий промпт

1. Відкрийте **Трансформацію**.
2. Виберіть промпт із списку промптів.
3. Якщо з’явиться поле **Цільова** мова, виберіть мову, якщо потрібно.
4. Введіть або вставте текст у поле **Ввід**.
5. Натисніть **Трансформація**.
6. Прочитайте результат у полі **Результат**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### Якщо у вас ще немає промптів

Якщо список промптів порожній, натисніть **Завантажити зразки промптів** у робочому просторі Трансформації. Цей самий елемент завжди доступний у розділі [**Налаштування** > **Промпти трансформації**](#transform-prompts) у рядку експорту/імпорту. Обидва варіанти додають вбудовані приклади, щоб ви могли швидко почати роботу.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Зразки промптів надаються англійською мовою. Після їх завантаження ви можете відредагувати промпт і використати **Перекласти запит**, щоб перекласти його вашою мовою.

<a id="create-a-prompt-quickly"></a>
### Швидке створення промпта

Найшвидший спосіб створити промпт - це:

1. Натисніть **Новий промпт**.
2. Натисніть **Створити запит**.
3. Опишіть, що має робити промпт.
4. Виберіть модель.
5. Дозвольте додатку створити проект.
6. Перегляньте проект і натисніть **Зберегти**.

![Generate prompt](../images/screenshots/uk/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### Редагувати промпт

Коли ви створюєте або редагуєте промпт, редактор з'являється зліва, а зправа - область тестування.

![Transform prompt editor](../images/screenshots/uk/transform-prompt-edit.png)

Основні поля:

- **Назва промпту**: назва, яка відображається у списку промптів.
- **Інструкції промпту (необов'язково)**: коротка підказка, яка відображається користувачеві під час виконання промпту.
- **Роль моделі**: загальна роль, призначена для ШІ, наприклад «Ви - корисний помічник».
- **Інструкції моделі (по одній на рядок)**: конкретні правила, яких має дотримуватися ШІ.
- **Опис результату**: коротке слово, що описує результат, наприклад «підсумок» або «перефразування».
- **Температура (0.0 → 1.0)**: характер поведінки моделі; див. нижче.
- **Запитувати цільову мову**: додає вибір цільової мови під час виконання промпту.

Якщо термін **Температура** для вас новий, уявіть його так:

- **Нижча** температура дає стабільніші, передбачуваніші результати.
- **Вища** температура дає більше різноманітності та креативності.

Ви також можете використовувати:

- **`Створити промпт`**, щоб створити новий варіант на основі простого опису
- **`Покращити промпт`**, щоб удосконалити існуючий промпт
- **`Перекласти промпт`**, щоб перекласти поля промпту

<br/>

> ⚠️ **ПОПЕРЕДЖЕННЯ**<br/>
> Натисніть **`Зберегти`**, перш ніж натиснути **`Назад до виконання`**. Якщо ви повернетесь назад без збереження, зміни буде втрачено.

<a id="general-settings"></a>
### Загальні налаштування

Використовуйте **Загальні налаштування**, щоб керувати поведінкою під час введення тексту, зберіганням даних виконання для **Історії** та зовнішнім виглядом.

**Поведінка**

- **Поведінка для ENTER** визначає, чи `Enter` виконує завдання чи вставляє новий рядок.
- **Автопереклад при вставці** розпочинає переклад одразу після вставки тексту.
- **Автокопіювання результату в буфер обміну** автоматично копіює успішні результати.
- **Переклад у реальному часі (під час введення)** перекладає текст під час його набирання.
- **Час очікування (мс)** встановлює час затримки для перекладу в реальному часі.

**Історія**

- **Зберігати історію виконання** керує тим, чи зберігаються **вхідний і вихідний текст** для кожної дії перекладу, перефразування та трансформації у вигляді [**Історія**](#history) на бічній панелі. Вимкнення цієї опції викличе підтвердження; якщо ви підтвердите, збережений текст історії буде видалено з бази даних.
- **Видалити дані історії** дозволяє видалити збережений текст за віком (наприклад, старіше кількох місяців або **усі дані (очистити)**) за допомогою **Видалити дані**. Це впливає лише на збережений текст виконання для перегляду **Історія**; це **не** видаляє дані про вартість чи загальні обсяги використання. Щоб видалити або скоротити дані про **вартість**, використовуйте [**Налаштування** > **Відстеження витрат**](#cost-tracking).

**Зовнішній вигляд**

- **Показувати інформацію про вартість на діях** керує відображенням вартості кожної операції (якщо доступно) та загальної вартості на панелях результатів **Перекласти**, **Перефразування** та **Трансформація**.
- **Кількість знаків після коми для вартості** змінює кількість десяткових знаків для відображення вартості.
- **Лише для веб-версії:** **показувати відступ навколо застосунку** додає додатковий простір навколо інтерфейсу.
- **Сімейство шрифтів** змінює шрифт у текстових панелях.
- **Розмір** змінює розмір шрифту.

**Резервне копіювання конфігурації**

- **Включити дані використання до резервної копії** - якщо ввімкнено, ZIP-файл також містить історію виконання та дані викликів API.
- **Створити резервну копію конфігурації** - створює один ZIP-файл (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` за умовчанням у часовому поясі UTC), що містить `config.json`, `state.json`, опційний ключ шифрування, користувачів, налаштування, користувацькі промпти та дані використання, якщо ви їх включили. Після успішного резервного копіювання підтвердження показує ім’я збереженого файлу.
- **Відновити з резервної копії** - спочатку відкриває **діалог підтвердження**. Виберіть ZIP-файл резервної копії у діалозі (**Огляд** / вибір файлу або перетягування, де це підтримується), потім перегляньте параметри:
  - **Відновити дані використання** - імпортувати використання/історію з ZIP-файлу, якщо він був створений з включеними даними використання; залиште вимкненим, якщо потрібні лише налаштування та промпти.
  - **Очистити старі дані використання перед відновленням** - видалити наявні дані використання/історію в цій установці перед застосуванням резервної копії (необов’язково; використовуйте, коли потрібне чисте заміщення).

Резервні копії, створені у веб- або настільній версії, можна відновити в іншій. Під час відновлення резервної копії настільної версії у веб-версії, дані будуть відновлені для користувача-адміністратора.

<a id="models"></a>
### Моделі

Використовуйте **Налаштування** > **Моделі**, щоб вибрати, які моделі відображатимуться на панелі інструментів.

![Settings Models tab](../images/screenshots/uk/settings-models.png)

Сторінка містить два списки:

- **Доступні моделі** зліва
- **Вибрані моделі** справа

Корисні елементи керування включають:

- **Пошук моделей...** для пошуку моделі за назвою
- Чипи **Постачальник** для звуження списку до одного движка (OpenRouter, OpenAI, Ollama, …)
- **Лише безкоштовні**, щоб показувати лише безкоштовні моделі
- **Оновити**, щоб перезавантажити список
- **Розгорнути все** та **Згорнути все**, коли ви сортуєте за постачальником

Ідентифікатори моделей включають префікс постачальника (наприклад, `openrouter/…` проти `openai/…`). Бейджі, такі як **OpenAI (OpenRouter)** проти **OpenAI (пряме)**, показують, як маршрутизується трафік.

> ℹ️ **ПРИМІТКА**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) - це маршрутизаторна модель, а не загальна чат-модель: її відповідь - це JSON, який описує тіла запитів до API OpenRouter (наприклад, масив `requests` з `model` та `messages`). Якщо ви використовуєте її для **Перекласти**, **Перефразування** або **Трансформації**, панель результату покаже цей JSON замість готового тексту. Для цих завдань оберіть звичайну текстову модель. Див. [сторінку моделі Body Builder](https://openrouter.ai/openrouter/bodybuilder) на OpenRouter.

Дії:

- Щоб додати модель, натисніть **Додати** або будь-де в записі.

- Щоб видалити модель, натисніть **X** поруч із нею у **Вибраних моделях** або **Вибрано** у записі Доступних моделей.

- Щоб очистити список, натисніть **Зняти вибір**. Обов’язкова безкоштовна модель залишиться у списку.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Якщо ви не хочете одразу додавати кредити до OpenRouter, спочатку увімкніть **Лише безкоштовні** та оберіть безкоштовні моделі (без необхідності вказувати кредитну картку). Ви також можете використовувати Ollama, щоб запускати моделі локально без будь-якого API-ключа.

<br/>

<a id="languages"></a>
### Мови

Використовуйте **Налаштування** > **Мови**, щоб організувати списки мов, які використовуються в додатку.

- **Найпопулярніші мови** закріплені вгорі списків мов у **Перекласти** та **Трансформація**.
- **Власна мова** дозволяє додати мову, якої немає у вбудованому списку.

Якщо ви додаєте власну мову, вона з’являється у вибірниках мов поряд із вбудованими варіантами.

<br/>

<a id="cost-tracking"></a>
### Відстеження витрат

Використовуйте **Налаштування** > **Відстеження витрат**, щоб керувати інформацією про витрати.

- **Загальна вартість** показує поточну суму.
- **Копіювати значення** копіює загальну суму в буфер обміну.
- **Скинути вартість** скидає збережену суму до нуля.
- **Синхронізувати з використанням API-ключа** встановлює суму відповідно до використання, повідомленого вашим обліковим записом OpenRouter (лише OpenRouter).
- **Використання API-ключа** показує деталі використання OpenRouter, якщо доступно.
- **Видалити дані про витрати** видаляє всі дані або лише записи, старіші за вибрану дату.

**Відстеження витрат:** Коли ви використовуєте моделі OpenRouter, додаток показує ваше фактичне використання та витрати на основі інформації про вартість від OpenRouter. Для всіх інших постачальників додаток оцінює витрати, використовуючи ціни, опубліковані OpenRouter; якщо ціна недоступна, оцінка може бути нульовою.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
>  Усі фінансові показники є орієнтовними та надаються виключно для вашого ознайомлення, а не як офіційні рахунки.

<br/>

> ⚠️ **ПОПЕРЕДЖЕННЯ**<br/>
> Видалення даних не можна скасувати. Перед видаленням обов’язково зробіть резервну копію або експортуйте дані через [**Історію**](#history)
> або [**Панель** > **Усі виклики**](#dashboard-tabs), інакше вони будуть втрачені назавжди.
> Вся історія вводу/виводу, пов’язана з кожним записом виклику API, також буде видалена.

<br/>

<a id="api-config"></a>  
### Конфігурація API

Підтримувані постачальники: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras та **Ollama** (локальні моделі через базову URL-адресу). Вам потрібно налаштувати лише тих постачальників, яких ви використовуєте.

**Веб-додаток: лише для адміністратора**

Ключі API налаштовуються через системні або Docker-змінні середовища - їх не вводять у веб-інтерфейсі. На цій сторінці показано, для яких постачальників налаштовано ключ, і дозволяє протестувати кожен із них, натиснувши кнопку **`Тест`**.

<br/>

> ℹ️ **ПРИМІТКА**<br/>  
> Щоб змінити ключ API, оновіть змінну середовища у вашій системі або конфігурації Docker і перезапустіть сервер або контейнер.

> ℹ️ **ПРИМІТКА**<br/>  
> **Резервні копії конфігурації** (див. [**Загальні налаштування** → Резервне копіювання конфігурації](#general-settings)) можуть вбудовувати **розшифровані** ключі постачальників у файл `config.json` у ZIP-архіві. Відновлення цього ZIP-файлу **не** копіює ті ключі назад у файл конфігурації сервера - активні ключі все ще беруться з середовища та існуючого стану файлів, як описано там.

<br/>

**Настільний додаток**

Використовуйте **Конфігурацію API**, щоб зберігати ключі API для кожного постачальника, якого ви використовуєте. Для Ollama введіть **базову URL-адресу** замість ключа API.

<br/>

> 💡 **Порада** <br/>  
> Якщо ви не хочете використовувати ключ API або платити за використання, ви можете [завантажити Ollama](https://ollama.com) і безкоштовно запускати моделі (наприклад, `translategemma:4b`) локально на своєму комп’ютері. Або ви можете створити безкоштовний обліковий запис OpenRouter (без кредитної картки) для використання їхніх безкоштовних моделей або отримати безкоштовний ключ API від Cerebras, Google, Groq чи Mistral AI.

<br/>

- Додавайте лише тих постачальників, які вам потрібні. У розділі **Налаштування** > **Моделі** кожен ідентифікатор моделі починається з назви постачальника (наприклад, `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Щоб додати ключ API, введіть значення у текстове поле та натисніть **`Зберегти`**. Щоб замінити існуючий ключ, натисніть **`Редагувати`**. Щоб перевірити, чи ключ працює, натисніть **`Тест`**. Для базової URL-адреси Ollama завжди натискайте **`Тест`**, щоб перевірити з’єднання.

<br/>

> ℹ️ **ПРИМІТКА**<br/>  
> Ви не можете переглянути поточне значення ключа API. Ви можете лише замінити його, використовуючи кнопку **`Редагувати`**.  
> Ключі API зберігаються в зашифрованому вигляді в конфігурації.

<a id="common-issues"></a>  
## Поширені проблеми

Якщо щось не працює, як очікувалося, спочатку перевірте такі пункти.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Додаток не буде перекладати, перефразовувати або трансформувати текст

Переконайтеся, що:

- ви вибрали модель на панелі інструментів
- принаймні одна модель вказана в розділі [**Налаштування** > **Моделі**](#models)
- ваша конфігурація API працює

Якщо ви використовуєте настільний додаток:

1. Відкрийте [**Налаштування** > **Конфігурація API**](#api-config).
2. Переконайтеся, що принаймні один API-ключ збережено.
3. Натисніть **Тест** біля постачальника, щоб підтвердити роботу ключа.

<br/>

<a id="the-model-list-is-empty"></a>
### Список моделей порожній

Відкрийте [**Налаштування** > **Моделі**](#models) і натисніть **Оновити**.

За потреби:

- знайдіть модель
- увімкніть **Лише безкоштовні**
- додайте одну або кілька моделей до **Вибраних моделей**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Результат надто повільний або надто дорогий

Спробуйте один або кілька із цих варіантів:

- виберіть іншу модель
- скористайтеся коротшим введенням
- вимкніть **Переклад у реальному часі (під час введення)** в [**Налаштування** > **Загальні налаштування**](#general-settings)
- використовуйте безкоштовні моделі для простих завдань (див. [Моделі](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Інтерфейс використовує неправильну мову

Натисніть на піктограму глобуса на [панелі інструментів](#toolbar) і виберіть потрібну **Мову інтерфейсу**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Текст надто малий або важко читати

Відкрийте [**Налаштування** > **Загальні налаштування**](#general-settings) і змініть:

- **Сімейство шрифтів**
- **Розмір**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Діаграми на панелі порожні

Це нормально, якщо:

- ви використовуєте лише **безкоштовні моделі** і дивитеся дані про **вартість** (вони можуть бути нульовими); діаграми кількості викликів у розділі **Підсумок** все ще потребують даних за вибраний період
- вибраний **фільтр часу** не охоплює період, коли були зроблені виклики - спробуйте **Усі**, щоб перевірити

Якщо після вибору **Усі** діаграми все ще порожні, переконайтеся, що виклики відображаються на вкладці [**Історія**](#history) або в розділі **Усі виклики**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Вартість показує «недоступно» або виглядає неправильною

Коли ви використовуєте моделі через **OpenRouter**, додаток показує фактичні витрати, повідомлені OpenRouter.

Для **інших постачальників** (OpenAI пряме, Anthropic пряме тощо) вартість оцінюється на основі цінових даних, опублікованих OpenRouter. Якщо для моделі не знайдено відповідної ціни, вартість буде вказана як **недоступна** і не додаватиметься до загальної суми.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Загальна вартість не відповідає моєму рахунку від постачальника

Усі показники вартості в додатку є **приблизними і наведені лише для довідки**, а не є офіційними рахунками.

Щоб зробити загальну суму ближчою до реальних витрат у OpenRouter, відкрийте [**Налаштування** > **Відстеження витрат**](#cost-tracking) і натисніть **Синхронізувати з використанням API-ключа**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Сторінка Історія відсутня в бічній панелі

Можливо, вимкнено опцію **Зберігати історію виконання**. Відкрийте [**Налаштування** > **Загальні налаштування**](#general-settings) і увімкніть її. Зверніть увагу, що її увімкнення не відновлює раніше видалені дані історії.

<br/>

<a id="web-app-session-expired"></a>
### Веб-додаток: неочікувано перенаправляє на сторінку входу

Час дії вашої сесії може закінчитися. Увійдіть знову. Якщо це трапляється часто, перевірте конфігурацію сервера щодо параметрів тривалості сесії.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### Веб-адмін: забули або втратили пароль

Це стосується **веб-додатку, розміщеного самостійно** (Docker), а не настільного додатку (Electron).

- Якщо інший адміністратор може увійти, він може відкрити [**Налаштування** > **Користувачі**](#users), вибрати обліковий запис і встановити там **новий пароль**.
- Якщо ви **заблоковані**, але маєте **доступ до оболонки** машини або контейнера, скиньте пароль за допомогою вбудованого інструменту, який постачається з образом (замініть `transrewrt`, якщо ви змінили ім'я за замовчуванням, і використовуйте лапки для пароля, якщо він містить пробіли або спеціальні символи):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Ім'я адміністратора за замовчуванням - `admin`, якщо ви ніколи не створювали інші облікові записи. Коли ви передаєте лише один аргумент, він вважається новим паролем для `admin`.

Якщо ви запускаєте додаток з **вихідного коду**, а не з Docker, використовуйте:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

Скрипт оновлює запис користувача в базі даних SQLite (і може створити користувача `admin`, якщо його немає). Після скидання увійдіть з новим паролем.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### На панелі відсутні дані інших користувачів (веб)

Лише **адміністратори** можуть переглядати дані всіх користувачів через фільтр **Користувач**. Звичайні користувачі за задумом бачать лише власну активність.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Я змінив промпт і втратив редагування

Під час редагування промпта завжди натискайте **Зберегти**, перш ніж натиснути **Назад до запуску**.

<a id="quick-tips"></a>
## Швидкі поради

- Почніть із [**Перекласти**](#translate), щоб переконатися, що ваша конфігурація працює, перш ніж переходити до [**Перефразування**](#rewrite) або [**Трансформації**](#transform).
- Використовуйте [**Перефразування**](#rewrite) для повсякденного покращення формулювань.
- Використовуйте [**Трансформація**](#transform), коли потрібен повторюваний робочий процес для певного завдання.
- Використовуйте [**Панель**](#dashboard), якщо хочете стежити за використанням і вартістю.
- Використовуйте [**Історія**](#history), щоб переглянути попередні операції та повний ввідний/вихідний текст.
- Регулярно експортуйте промпти, якщо ви створюєте бібліотеку промптів, яку хочете зберегти (див. [Промпти трансформації](#transform-prompts)), або якщо хочете поділитися нею з іншими.
