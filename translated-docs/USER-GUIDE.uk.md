# Керівництво для користувача

<br/>

<a id="introduction"></a>
## Вступ

Transrewrt допомагає працювати з текстом трьома основними способами:

- **Перекласти** - перетворити текст з однієї мови на іншу.
- **Перефразування** - перефразувати текст у різних стилях, наприклад, зрозуміліше, коротше або формальніше.
- **Трансформація** - обробка тексту за допомогою користувацьких інструкцій ШІ, які називаються запитами.

<br/>

У цьому посібнику пояснюється, як користуватися додатком після його встановлення та запуску. Щодо кроків встановлення дивіться основний **[README](README.uk.md)**.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Transrewrt доступний як настільний додаток для Windows та Linux, а також як веб-додаток, що розміщується самостійно. Цей посібник присвячений повсякденному використанню додатку. Якщо якийсь пункт стосується лише однієї версії, це чітко зазначено.

<a id="before-you-start"></a>
## Перш ніж почати

Щоб використовувати Transrewrt, вам потрібен доступ хоча б до одного постачальника ШІ. Підтримувані постачальники: [OpenRouter](https://openrouter.ai) (який об'єднує багато моделей), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras та [Ollama](https://ollama.com) для локальних моделей.

Вам не потрібно вибирати платну модель, щоб розпочати. Як тільки ви додасте свій ключ API OpenRouter, додаток автоматично активує вбудовану **безкоштовну** опцію OpenRouter. Це дозволяє одразу почати перекладати, переписувати та перетворювати текст. Крім того, ви можете отримати безкоштовний ключ API від Cerebras, Google, Groq або Mistral AI.

Простими словами:

- **Модель** — це рушій ШІ, який виконує роботу. Моделі перераховані з **префіксом постачальника** (наприклад, `openrouter/…`, `openai/…`, `ollama/…`).
- **Ключ API** (або для Ollama — **базова URL-адреса**) — це спосіб, за допомогою якого додаток зв'язується з цим постачальником.

Якщо ви використовуєте **настільний додаток**, додайте ключі в розділі [**Налаштування** > **Конфігурація API**](#api-config) для кожного постачальника, якого використовуєте. Якщо ви використовуєте лише OpenRouter, див. нижче [Як отримати ключ API](#how-to-get-an-api-key-desktop-app). Якщо ви не хочете використовувати ключ API, ви можете встановити Ollama (з [ollama.com](https://ollama.com)) і використовувати локальні моделі, наприклад `translategemma:4b`.

Якщо ви використовуєте **веб-версію**, адміністратор сервера налаштовує постачальників через змінні середовища, тому ви не можете безпосередньо вводити ключі API в додатку.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Як отримати безкоштовний ключ OpenRouter API (настільний додаток)

Якщо ви використовуєте настільний додаток, виконайте такі кроки:

1. Перейдіть до [OpenRouter](https://openrouter.ai) у своєму веб-браузері.
2. Створіть обліковий запис або увійдіть.
3. Відкрийте сторінку [Keys](https://openrouter.ai/keys).
4. Натисніть кнопку, щоб створити новий ключ API.
5. Надайте ключу назву, за якою ви зможете його розпізнати пізніше.
6. Скопіюйте новий ключ API.
7. Поверніться до Transrewrt і відкрийте **Налаштування** > **Налаштування API**.
8. Вставте ключ у поле **OpenRouter API key** (у розділі **Налаштування** > **Налаштування API**).
9. Натисніть **Test OpenRouter key**, щоб переконатися, що він працює.

<a id="getting-started"></a>
## Початок роботи

Якщо ви вперше використовуєте Transrewrt, дотримуйтесь такого порядку:

1. Відкрийте додаток.
2. За потреби виберіть свою **мову інтерфейсу** за допомогою піктограми глобуса.
3. Якщо ви використовуєте **десктопний додаток**, відкрийте [**Налаштування** > **Налаштування API**](#api-config), додайте ключ API хоча б для одного провайдера (наприклад, OpenRouter) і натисніть **Test**, щоб перевірити його роботу.
4. Відкрийте [**Налаштування** > **Моделі**](#models) і додайте одну або кілька моделей до **Обрані моделі**.
5. Відкрийте [**Налаштування** > **Мови**](#languages) і виберіть свої **Найважливіші мови**, якщо хочете, щоб найчастіше використовувані мови відображалися першими.
6. Перейдіть до **Перекладу** і виконайте простий переклад, щоб підтвердити, що все працює.
7. Після цього спробуйте **Перефразування**, а потім **Трансформацію**.

Цей порядок має значення. Він запобігає найпоширенішій проблемі для нових користувачів: спробі виконати завдання до того, як додаток отримав робоче з'єднання з API або вибрану модель.

### Панель інструментів

Панель інструментів трохи змінюється залежно від того, де ви перебуваєте в додатку.

- Зліва відображається назва поточної сторінки.
- Справа відображається **вибірник моделі** та елемент керування **Мовою інтерфейсу**.

**Вибірник моделі** дозволяє вибрати, який рушій ШІ використовувати для поточного завдання.

![Model selector](../images/screenshots/uk/model-selector.png)

Деякі безкоштовні моделі можуть бути недоступними — іноді вони вимкнені або мають обмеження на використання. Якщо це трапиться, додаток автоматично видалить цю модель зі списку доступних. Щоб керувати тим, які моделі відображаються, перейдіть до [**Налаштувань** > **Моделей**](#models) і відредагуйте свій список моделей. 
 Ви також можете відкрити налаштування моделі безпосередньо, натиснувши на піктограму постачальника ліворуч від назви моделі на панелі інструментів.

<br/>

**Піктограма глобуса та код мови** змінюють мову інтерфейсу додатку, наприклад, меню та кнопки. Це **не** змінює мови перекладу, які використовуються в **Перекладі**.

![Interface language selector](../images/screenshots/uk/language-selector.png)

<a id="input-and-output-panels"></a>
### Панелі вводу та результату

Більшість робочих просторів використовують ліву панель **Ввід** та праву панель **Результат**.

Кожна панель також показує:

| **Ввід**                                                          | **Результат**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Кількість символів <br/>- Кількість слів <br/>- Кількість абзаців   <br/> | - Як довго виконувалося завдання<br/>- **TPS** (токени за секунду)<br/>- Кількість символів, слів і абзаців<br/>- Використана модель |

Якщо ви цікавитеся технічними термінами:

- **Токен** означає невелику частину тексту. Можна уявити це як частину слова або коротке слово.
- **TPS** означає, скільки таких фрагментів тексту модель обробляє щосекунди.

<br/>

Ви також можете відстежувати вартість кожної операції (якщо доступно) та загальну вартість, увімкнувши опцію `Show cost information on the actions` в [**Налаштування** > **Загальні налаштування**](#general-settings).

<a id="translate"></a>
## Перекласти

Використовуйте **Перекласти**, коли потрібно перетворити текст з однієї мови на іншу.

![Translate workspace](../images/screenshots/uk/translate.png)

<br/>

<a id="translate-text"></a>
### Перекласти текст

1. Відкрийте **Переклад**.
2. Виберіть мову у полі **З**.
3. Виберіть мову у полі **На**.
4. Виберіть модель на панелі інструментів.
5. Введіть або вставте текст у поле **Введення**.
6. Натисніть **Перекласти**.
7. Прочитайте результат у полі **Виведення**.
8. Використовуйте кнопку копіювання, якщо хочете скопіювати результат.

<br/>

<a id="language-selection"></a>
### Вибір мови

- **З** може бути конкретною мовою або **Визначити мову**.
- **На** — це мова, на яку ви хочете отримати результат.

Ваші вибрані **топові мови** з’являються вгорі списку. Ви можете встановити їх у розділі [**Налаштування** > **Мови**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Корисні параметри перекладу

У розділі [**Налаштування** > **Загальні налаштування**](#general-settings) можна змінити поведінку перекладу:

- **Автоматичний переклад при вставці** запускає переклад одразу після вставки тексту.
- **Автоматичне копіювання результату в буфер обміну** автоматично копіює результат після успішного виконання.
- **Переклад у реальному часі (під час набору)** запускає переклад під час набору тексту.
- **Час очікування (мс)** визначає, як довго додаток чекає перед запуском перекладу в реальному часі.

<a id="rewrite"></a>
## Перефразування

Використовуйте **Перефразування**, коли хочете покращити формулювання, не змінюючи основного змісту.

![Rewrite workspace](../images/screenshots/uk/rewrite.png)

Це корисно для:

- виправлення орфографії та граматики (**Перевірка правопису та граматики**)
- покращення чіткості тексту (**Покращити чіткість**)
- кілька різних переформулювань за один запуск (**Альтернативні варіанти**)
- зробити текст більш формальним або неформальним (**Формальний** / **Неформальний**)
- скорочення або розширення тексту (**Скоротити** / **Розширити**)
- зробити текст більш технічним (**Зробити технічним**)

<br/>

> 💡 **ПІДКАЗКА**<br/>

## Трансформація

Використовуйте **Трансформацію**, коли хочете, щоб ШІ дотримувався спеціальних інструкцій.

![Transform workspace](../images/screenshots/uk/transform.png)

Це найгнучкіша частина додатка. Ви можете використовувати її для таких завдань, як:

- узагальнення нотаток
- перетворення сирого тексту на відредагований лист
- витягнення ключових моментів

<br/>

<a id="run-an-existing-prompt"></a>  
### Запустити існуючий промпт

1. Відкрийте **Перетворити**.
2. Виберіть запит із списку запитів.
3. Якщо з’являється поле **Мова призначення**, виберіть мову, якщо потрібно.
4. Введіть або вставте текст у поле **Вхід**.
5. Натисніть **Перетворити**.
6. Прочитайте результат у полі **Вихід**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>  
### Якщо у вас ще немає промптів

Той же елемент управління завжди доступний у [**Налаштуваннях** > **Промпти трансформації**](#transform-prompts) на рядку експорту/імпорту. Обидва додають вбудовані приклади, щоб ви могли швидко почати.

<br/>

> ℹ️ **ПРИМІТКА**<br/>  
> Зразки промптів надаються англійською мовою. Після їх завантаження ви можете редагувати промпт і використовувати **Перекласти запит**, щоб перекласти його на вашу мову.

<a id="create-a-prompt-quickly"></a>
### Створити промпт швидко

Найшвидший спосіб створити промпт:

1. Натисніть **Новий запит**.
2. Натисніть **Створити запит**.
3. Опишіть, що має робити запит.
4. Виберіть модель.
5. Дозвольте додатку створити проект.
6. Перегляньте проект і натисніть **Зберегти**.

![Generate prompt](../images/screenshots/uk/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### Редагувати промпт

Коли ви створюєте або редагуєте промпт, редактор з’являється зліва, а зправа — область тестування.

![Transform prompt editor](../images/screenshots/uk/transform-prompt-edit.png)

Основні поля:

- **Назва запиту**: назва, яка відображається у списку запитів.
- **Інструкції до запиту (необов’язково)**: коротка підказка, яка відображається користувачеві під час виконання запиту.
- **Роль моделі**: загальна роль, призначена ШІ, наприклад: «Ви — корисний помічник».
- **Інструкції моделі (по одній на рядок)**: конкретні правила, яких має дотримуватися ШІ.
- **Опис виходу**: коротке слово, що описує результат, наприклад «резюме» або «переписаний текст».
- **Температура (0,0 → 1,0)**: характер поведінки моделі; див. нижче.
- **Запитувати мову призначення**: додає вибір мови призначення під час виконання запиту.

Якщо технічний термін **Температура** для вас новий, уявіть його так:

- **Нижча** температура забезпечує стабільніші, передбачуваніші результати.
- **Вища** температура дає більше різноманітності та креативності.

Ви також можете використовувати:

- **`Generate prompt`** для створення нового чернетки на основі простого опису
- **`Improve prompt`** для вдосконалення існуючого промпту
- **`Translate prompt`** для перекладу полів промпту

<br/>

> ⚠️ **ПОПЕРЕДЖЕННЯ**<br/>
> Натисніть **`Save`**, перш ніж натиснути **`Back to Run`**. Якщо ви повернетесь назад без збереження, зміни буде втрачено.

<a id="test-a-prompt-before-using-it"></a>
### Протестуйте промпт перед використанням

Панель тестування праворуч дозволяє спробувати ваш промпт із прикладом тексту, перш ніж використовувати його у повсякденній роботі.

Це корисно, коли:

<br/>

> ℹ️ **ПРИМІТКА**<br/>

<a id="general-settings"></a>
### Загальні налаштування

Використовуйте **Загальні налаштування**, щоб керувати поведінкою введення тексту, тим, чи зберігаються деталі виконання для **Історії**, а також зовнішнім виглядом.

**Поведінка**

- **Поведінка для ENTER** визначає, чи `Enter` виконує завдання чи вставляє новий рядок.
- **Автоматичний переклад при вставці** запускає переклад одразу після вставки тексту.
- **Автоматичне копіювання результату в буфер обміну** автоматично копіює успішні результати.
- **Переклад у реальному часі (під час набору)** виконує переклад під час набору тексту.
- **Тайм-аут (мс)** встановлює час очікування для перекладу в реальному часі.

**Історія**

- **Зберігати історію виконання** визначає, чи кожен переклад, перефразування та трансформація зберігатимуть **ввідний і вихідний текст** для перегляду в бічній панелі [**Історія**](#history). Вимкнення цієї опції викликає підтвердження; якщо ви підтверджуєте, збережений текст історії видаляється з бази даних.
- **Видалити дані історії** дозволяє видалити збережений текст за віком (наприклад, старіше кількох місяців або **усі дані (очистити)**) за допомогою **Видалити дані**. Це впливає лише на збережений текст виконання для перегляду **Історії**; це **не** видаляє загальну вартість або підсумки використання. Щоб видалити або скоротити дані про **вартість**, використовуйте [**Налаштування** > **Відстеження витрат**](#cost-tracking).

**Зовнішній вигляд**

- **Показувати інформацію про вартість у діях** керує відображенням вартості кожної операції (якщо доступно) та загальної вартості на панелях виводу Перекладу, Переписування та Перетворення.
- **Кількість знаків після коми для вартості** змінює кількість десяткових знаків у відображенні вартості.
- **Лише для веб-версії:** **показувати поля навколо додатку** додає додатковий простір навколо інтерфейсу.
- **Сімейство шрифтів** змінює шрифт у текстових панелях.
- **Розмір** змінює розмір шрифту.

**Резервне копіювання конфігурації**

- **Включити дані використання у резервну копію** — якщо ввімкнено, ZIP також містить історію виконання та дані викликів API. 
- **Резервне копіювання конфігурації** — створює один файл ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` за умовчанням у UTC) з `config.json`, `state.json`, опційним ключем шифрування, користувачами, налаштуваннями, користувацькими підказками та даними використання, якщо ви погодилися. Після успішного резервного копіювання підтвердження показує ім'я збереженого файлу.
- **Відновлення з резервної копії** — спочатку відкриває **діалог підтвердження**. Виберіть файл резервної копії ZIP у діалозі (**Огляд** / вибір файлу або перетягування, де підтримується), потім перегляньте параметри:
  - **Відновити дані використання** — імпортувати використання/історію з ZIP, якщо вони були включені під час резервного копіювання; залиште вимкненим, якщо потрібні лише налаштування та підказки.
  - **Очистити старі дані використання перед відновленням** — видалити наявні дані використання/історію в цій установці перед застосуванням резервної копії (необов'язково; використовуйте, коли потрібне повне заміщення).

Резервні копії, створені у веб-або настільній версії, можна відновити в іншій. Під час відновлення резервної копії настільної версії у веб-версії, дані будуть відновлені для облікового запису адміністратора.

<a id="models"></a>
### Моделі

Скористайтеся **Налаштування** > **Моделі**, щоб вибрати, які моделі відображатимуться на панелі інструментів.

![Settings Models tab](../images/screenshots/uk/settings-models.png)

На сторінці є два списки:

- **Доступні моделі** зліва
- **Вибрані моделі** справа

Корисні елементи керування включають:

- **Пошук моделей...** для пошуку моделі за назвою
- **Мітки постачальника** для звуження списку до одного движка (OpenRouter, OpenAI, Ollama, …)
- **Лише безкоштовні** для відображення лише безкоштовних моделей
- **Оновити** для повторного завантаження списку
- **Розгорнути все** та **Згорнути все**, коли ви сортуєте за постачальником

Ідентифікатори моделей включають префікс постачальника (наприклад, `openrouter/…` проти `openai/…`). Мітки, такі як **OpenAI (OpenRouter)** проти **OpenAI (пряме)**, показують, як маршрутизується трафік.

> ℹ️ **ПРИМІТКА**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) — це маршрутизаторна модель, а не загальна чат-модель: її відповідь — це JSON, що описує тіла запитів до API OpenRouter (наприклад, масив `requests` з `model` та `messages`). Якщо використовувати її для **Перекласти**, **Перефразування** або **Трансформація**, на панелі результату буде показано цей JSON замість готового тексту. Для цих завдань оберіть звичайну текстову модель. Див. [сторінку моделі Body Builder](https://openrouter.ai/openrouter/bodybuilder) на OpenRouter.

Дії:

- Щоб додати модель, натисніть **Додати** або в будь-якому місці запису.

- Щоб видалити модель, натисніть **X** поруч із нею у **Вибраних моделях** або **Вибрано** у записі Доступних моделей.

- Щоб очистити список, натисніть **Зняти вибір**. Потрібна безкоштовна модель залишиться у списку.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Якщо ви не хочете додавати кредити до OpenRouter одразу, спочатку увімкніть **Лише безкоштовні** та виберіть безкоштовні моделі (без необхідності вказувати кредитну картку). Ви також можете використовувати Ollama для запуску моделей локально без будь-якого API-ключа.

<br/>

<a id="languages"></a>
### Мови

Використовуйте **Налаштування** > **Мови**, щоб упорядкувати списки мов, які використовуються в додатку.

- **Найпопулярніші мови** закріплені вгорі списків мов у функціях **Перекласти** та **Трансформація**.
- **Власна мова** дозволяє додати мову, якої немає у вбудованому списку.

Якщо ви додасте власну мову, вона з’явиться у вибірниках мов поряд із вбудованими варіантами.

<br/>

<a id="cost-tracking"></a>
### Відстеження витрат

Використовуйте **Налаштування** > **Відстеження витрат**, щоб керувати інформацією про витрати.

- **Загальна вартість** показує поточну суму.
- **Копіювати значення** копіює загальну суму в буфер обміну.
- **Скинути вартість** скидає збережену суму до нуля.
- **Синхронізувати з використанням ключа API** встановлює загальну суму відповідно до використання, зазначеного у вашому обліковому записі OpenRouter (лише OpenRouter).
- **Використання ключа API** показує деталі використання OpenRouter, якщо доступно.
- **Видалити дані вартості** видаляє всі дані або лише записи, старіші за вибрану дату.

**Відстеження витрат:** Коли ви використовуєте моделі OpenRouter, додаток показує ваше фактичне використання та витрати на основі інформації про вартість від OpenRouter. Для всіх інших провайдерів додаток оцінює витрати, використовуючи ціни, опубліковані OpenRouter; якщо ціна недоступна, оцінка може бути нульовою.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
>  **Усі дані про вартість є орієнтовними і надаються виключно для вашого ознайомлення, а не є офіційними рахунками.**

<br/>

> ⚠️ **ПОПЕРЕДЖЕННЯ**<br/>
> Видалення даних не можна скасувати. Перед видаленням обов’язково зробіть резервну копію або експортуйте свої дані через [**Історія**](#history) 
> або [**Панель** > **Усі виклики**](#dashboard-tabs), інакше вони будуть назавжди втрачені. 
> Також буде видалено всю історію вводу/результату, пов’язану з кожним записом виклику API.

<br/>

Ви можете:

<a id="api-config"></a>
### Конфігурація API

Підтримувані провайдери: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras та **Ollama** (локальні моделі через базовий URL). Вам потрібно налаштувати лише тих провайдерів, яких ви використовуєте.

**Веб-додаток: лише для адміністратора**

Ключі API налаштовуються через системні або Docker змінні середовища — їх не вводять у веб-інтерфейсі. На цій сторінці показано, для яких провайдерів налаштовано ключ, і можна протестувати кожен із них, натиснувши кнопку **`Test`**.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Щоб змінити ключ API, оновіть змінну середовища у конфігурації вашої системи або Docker і перезапустіть сервер або контейнер.

> ℹ️ **ПРИМІТКА**<br/>
> У **резервних копіях конфігурації** (див. [**Загальні налаштування** → Резервне копіювання конфігурації](#general-settings)) можуть зберігатися **вирішені** ключі постачальників у файлі `config.json` архіву ZIP. Відновлення цього архіву ZIP **не** копіює ті ключі назад у постійний конфігураційний файл сервера — активні ключі як і раніше беруться зі змінних середовища та існуючого стану файлу, як описано там.

<br/>

**Десктопний додаток**

Використовуйте **Конфігурацію API**, щоб зберігати ключі API для кожного постачальника, якого ви використовуєте. Для Ollama введіть **базову URL-адресу** замість ключа API.

<br/>

> 💡 **Порада** <br/>
> Якщо ви не хочете використовувати ключ API або платити за використання, ви можете [завантажити Ollama](https://ollama.com) і запускати моделі (наприклад, `translategemma:4b`) локально на своїй машині безкоштовно. Або ви можете створити безкоштовний обліковий запис OpenRouter (без необхідності вказувати кредитну картку), щоб використовувати їхні безкоштовні моделі, або отримати безкоштовний ключ API від Cerebras, Google, Groq або Mistral AI.

<br/>

- Додавайте лише тих постачальників, які вам потрібні. У розділі **Налаштування** > **Моделі** кожен ідентифікатор моделі починається з назви постачальника (наприклад, `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Щоб додати ключ API, введіть значення у текстове поле та натисніть **`Save`**. Щоб замінити існуючий ключ, натисніть **`Edit`**. Щоб перевірити, чи працює ключ, натисніть **`Test`**. Для базової URL-адреси Ollama завжди натискайте **`Test`**, щоб перевірити з’єднання.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Ви не можете переглянути поточне значення ключа API. Ви можете лише замінити його за допомогою кнопки **`Edit`**.
> Ключі API зберігаються в зашифрованому вигляді в конфігурації.

<a id="common-issues"></a>
## Поширені проблеми

Якщо щось не працює, як очікувалося, спочатку перевірте такі пункти.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Додаток не перекладає, перефразовує або трансформує текст

Переконайтеся, що:

- ви вибрали модель на панелі інструментів
- принаймні одна модель перерахована в розділі [**Налаштування** > **Моделі**](#models)
- ваша конфігурація API працює

Якщо ви використовуєте настільний додаток:

1. Відкрийте [**Налаштування** > **Конфігурація API**](#api-config).
2. Переконайтеся, що збережено принаймні один ключ API.
3. Натисніть **Тест** поруч із постачальником, щоб підтвердити роботу ключа.

<br/>

<a id="the-model-list-is-empty"></a>
### Список моделей порожній

Відкрийте [**Налаштування** > **Моделі**](#models) і натисніть **Оновити**.

За потреби:

- знайдіть модель
- увімкніть **Лише безкоштовні**
- додайте одну або кілька моделей до **Вибраних моделей**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Результат надто повільний або надто дорогий

Спробуйте один або кілька із цих варіантів:

- виберіть іншу модель
- скоротіть ввід
- вимкніть **Переклад у реальному часі (під час введення)** в розділі [**Налаштування** > **Загальні налаштування**](#general-settings)
- використовуйте безкоштовні моделі для простих завдань (див. [Моделі](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Інтерфейс вказано неправильною мовою

Натисніть на піктограму глобуса на [панелі інструментів](#toolbar) і виберіть потрібну **Мова інтерфейсу**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Текст занадто малий або важко читати

Відкрийте [**Налаштування** > **Загальні налаштування**](#general-settings) і змініть:

- **Сімейство шрифтів**
- **Розмір**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Панель показує порожні графіки

Це нормально, якщо:

- ви використовуєте лише **безкоштовні моделі** і дивитеся на показники **вартості** (вони можуть бути нульовими); графіки кількості **викликів** на вкладці **Підсумок** все ще потребують даних за обраний період
- обраний **фільтр часу** не охоплює період, коли відбувалися виклики — спробуйте **Усі**, щоб перевірити

Якщо графіки все ще порожні після вибору **Усі**, переконайтеся, що виклики відображаються в [**Історії**](#history) або на вкладці **Усі виклики**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Вартість показує "недоступно" або здається неправильною

Коли ви використовуєте моделі через **OpenRouter**, додаток показує ваші фактичні витрати, повідомлені OpenRouter.

Для **інших постачальників** (OpenAI пряме, Anthropic пряме тощо) вартість є приблизна на основі даних ціноутворення, опублікованих OpenRouter. Якщо відповідна ціна для моделі не знайдена, вартість буде вказана як **недоступна** і не буде додана до загальної суми.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Загальна вартість не збігається з рахунком вашого постачальника

Усі показники вартості в додатку є **приблизна для довідки**, а не офіційними розрахунками.

Щоб зробити загальну суму ближчою до ваших реальних витрат у OpenRouter, відкрийте [**Налаштування** > **Відстеження витрат**](#cost-tracking) і натисніть **Синхронізувати з використанням API-ключа**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Сторінка «Історія» відсутня в бічній панелі

**Зберігати історію виконання** може бути вимкнено. Відкрийте [**Налаштування** > **Загальні налаштування**](#general-settings) і ввімкніть цю опцію. Зверніть увагу, що її увімкнення не відновлює раніше видалені дані історії.

<br/>

<a id="web-app-session-expired"></a>
### Веб-додаток: неочікувано перенаправлено на сторінку входу

Час дії вашого сеансу може бути вичерпано. Увійдіть знову. Якщо це трапляється часто, перевірте конфігурацію сервера щодо параметрів тривалості сеансу.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### Веб-адмін: забуто або втрачено пароль

Це стосується **веб-додатку з самообслуговуванням** (Docker), а не настільного додатку (Electron).

- Якщо інший адміністратор може увійти, він може відкрити [**Налаштування** > **Користувачі**](#users), вибрати обліковий запис і встановити там **новий пароль**.
- Якщо ви **заблоковані**, але маєте **доступ до оболонки** машини або контейнера, скиньте пароль за допомогою вбудованого інструменту, який поставляється з образом (замініть `transrewrt`, якщо ви змінили ім'я за замовчуванням, і вкажіть пароль у лапках, якщо він містить пробіли або спеціальні символи):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Ім'я адміністратора за замовчуванням — `admin`, якщо ви ніколи не створювали інші облікові записи. Коли ви передаєте лише один аргумент, він розглядається як новий пароль для `admin`.

Якщо ви запускаєте додаток з **джерельного коду**, а не з Docker, використовуйте:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

Скрипт оновлює запис користувача в базі даних SQLite (і може створити користувача `admin`, якщо його немає). Після скидання увійдіть із новим паролем.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### Панель показує відсутність даних для інших користувачів (веб)

Тільки **адміністратори** можуть переглядати дані від усіх користувачів через фільтр **Користувач**. Звичайні користувачі бачать лише власну активність за задумом.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Я змінив промпт і втратив редагування

Під час редагування промпту завжди натискайте **Зберегти**, перш ніж натискати **Назад до запуску**.

<a id="quick-tips"></a>
## Швидкі поради

- Почніть з [**Перекладу**](#translate), щоб переконатися, що ваша конфігурація працює, перш ніж переходити до [**Переписування**](#rewrite) або [**Перетворення**](#transform).
- Використовуйте [**Переписування**](#rewrite) для щоденного покращення формулювань.

- Використовуйте [**Історію**](#history), щоб переглянути попередні операції та повний вхідний/вихідний текст.
- Регулярно експортуйте підказки, якщо ви створюєте бібліотеку підказок, яку хочете зберегти (див. [Підказки перетворення](#transform-prompts)), або якщо хочете поділитися ними з іншими.
