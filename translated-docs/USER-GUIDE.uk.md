# Керівництво користувача Transrewrt

<br />

<a id="introduction"></a>
## Вступ

Transrewrt допомагає працювати з текстом трьома основними способами:

- **Переклад** - конвертування тексту з однієї мови в іншу.
- **Переформулювання** - перефразування тексту в іншому стилі, наприклад, зрозумілішому, коротшому або більш формальному.
- **Перетворення** - обробка тексту за допомогою користувацьких інструкцій ШІ, які називаються промптами.

<br />

Цей посібник пояснює, як користуватися програмою після її встановлення та запуску. Щодо кроків встановлення, дивіться основний [README](../README.md).

<br />

> ℹ️ **ПРИМІТКА**<br/>
> Transrewrt доступний як десктоп-додаток для Windows і Linux, а також як самохостинговий веб-додаток. У цьому посібнику зосереджено увагу на повсякденному використанні програми. Дещо, що стосується лише однієї версії, чітко позначено.

<a id="before-you-start"></a>

## Перш ніж почати

Щоб використовувати Transrewrt, вам потрібен доступ до AI-сервісу через OpenRouter.

Вам не обов'язково обирати платну модель перед початком. У додатку завжди є вбудована **безкоштовна** модель, тому для звичайного використання цього достатньо, щоб почати перекладати, переписувати та трансформувати текст.

Простими словами:

- **Модель** — це AI-рушій, який виконує роботу.
- **API ключ** — це ваш особистий ключ доступу до цього сервісу.

Якщо ви користуєтесь **десктоп-додатком**, вам знадобиться API ключ. Детальні кроки дивіться нижче у розділі [Як отримати API ключ (десктоп-додаток)](#як-отримати-api-ключ-десктоп-додаток). Коротко: зареєструйте обліковий запис на [OpenRouter](https://openrouter.ai), відкрийте сторінку [Keys](https://openrouter.ai/keys), створіть новий ключ та вставте його в [**Налаштування** > **Конфігурація API**](#конфігурація-api) у Transrewrt.

Якщо ви користуєтесь **веб-версією**, власник сервера зазвичай налаштовує це за вас, тому вам, як правило, не потрібно вводити API ключ самостійно.

<br />

<a id="how-to-get-an-api-key-desktop-app"></a>
### Як отримати API ключ (десктоп-додаток)

Якщо ви користуєтесь десктоп-додатком, виконайте наступні кроки:

1. Перейдіть на [OpenRouter](https://openrouter.ai) у вашому веб-переглядачі.
2. Створіть обліковий запис або увійдіть.
3. Відкрийте сторінку [Keys](https://openrouter.ai/keys).
4. Натисніть кнопку, щоб створити новий API ключ.
5. Надайте ключу ім'я, щоб ви могли впізнати його пізніше.
6. Скопіюйте новий API ключ.
7. Поверніться до Transrewrt і відкрийте **Налаштування** > **Конфігурація API**.
8. Вставте ключ у поле **OpenRouter API Key**.
9. Натисніть **Перевірити конфігурацію API**, щоб переконатися, що вона працює.

> ℹ️ **ПРИМІТКА**<br/>
> Ви можете почати з безкоштовного маршруту OpenRouter або будь-якої з інших доступних безкоштовних моделей. У багатьох випадках цього достатньо, щоб почати використовувати Transrewrt, не обираючи платну модель.

<br /><br />

<a id="getting-started"></a>
## Початок роботи

Якщо ви вперше користуєтесь Transrewrt, дотримуйтесь такого порядку:

1. Відкрийте додаток.
2. За потреби оберіть **Мову інтерфейсу** за допомогою іконки глобуса.
3. Якщо ви користуєтесь **десктоп-додатком**, відкрийте [**Налаштування** > **Конфігурація API**](#конфігурація-api), вставте ваш OpenRouter API ключ і натисніть **Перевірити конфігурацію API**.
4. Відкрийте [**Налаштування** > **Моделі**](#моделі) і додайте одну або кілька моделей до **Вибрані моделі**.
5. Відкрийте [**Налаштування** > **Мови**](#мови) і оберіть ваші **Основні мови**, якщо ви хочете, щоб найчастіше використовувані мови відображалися першими.
6. Перейдіть до **Перекладу** і запустіть простий переклад, щоб переконатися, що все працює.
7. Якщо це спрацює, спробуйте **Переписати**, а потім **Трансформувати**.

Цей порядок має значення. Він запобігає найчастішій проблемі при першому використанні: спробі запустити завдання до того, як додаток отримає робоче підключення API або вибрану модель.

<a id="input-and-output-panels"></a>

### Панелі введення та виведення

Більшість робочих просторів використовують ліву панель **Введення** та праву панель **Виведення**.

Панель **Введення** показує:

- Кількість символів
- Кількість слів
- Кількість абзаців

Панель **Виведення** може показувати:

- Тривалість завдання
- Вартість цього завдання
- Загальна вартість
- **TPS** (токенів за секунду) – проста швидкісна характеристика
- Кількість символів, слів та абзаців
- Використану модель

Якщо вам цікаві технічні терміни:

- **Токен** означає невеликий фрагмент тексту. Можна уявляти його як частину слова або коротке слово.
- **TPS** означає скільки таких текстових фрагментів модель обробила за секунду.

<a id="translate"></a>
## Переклад

Використовуйте **Переклад**, коли хочете перетворити текст з однієї мови на іншу.

![Переклад workspace](../images/screenshots/uk/translate.png)

<br />

<a id="translate-text"></a>
### Переклад тексту

1. Відкрийте **Переклад**.
2. Виберіть мову в полі **З**.
3. Виберіть мову в полі **На**.
4. Виберіть модель у панелі інструментів.
5. Введіть або вставте текст у **Введення**.
6. Натисніть **Переклад**.
7. Перегляньте результат у **Виведенні**.
8. Використовуйте кнопку копіювання, якщо хочете скопіювати результат.

<br />

<a id="language-selection"></a>
### Вибір мови

- **З** може бути конкретна мова або **Визначити мову**.
- **На** – це мова, на яку ви хочете отримати результат.

Вибрані вами **Основні мови** з’являються у верхній частині списку. Налаштувати їх можна в [**Налаштування** > **Мови**](#languages).

<br />

<a id="helpful-translation-settings"></a>
### Корисні налаштування перекладу

У [**Налаштування** > **Загальні налаштування**](#general-settings) ви можете змінити поведінку перекладу:

- **Автопереклад при вставці** запускає переклад одразу після вставки тексту.
- **Автокопіювання результату в буфер обміну** копіює результат автоматично після успішного завершення.
- **Переклад у реальному часі (під час введення)** запускає переклад під час друку.
- **Час очікування (мс)** контролює, як довго додаток чекає перед запуском перекладу в реальному часі.

<br />

<a id="keyboard-shortcuts"></a>
### Гарячі клавіші

У [**Налаштування** > **Загальні налаштування**](#general-settings) **Поведінка клавіші Enter** визначає, що відбувається при натисканні Enter:

- **Enter** може запускати завдання, а **Shift+Enter** – додавати новий рядок.
- Або додаток може робити навпаки.

Поточне призначення також відображається на кнопці **Переклад**.

<a id="rewrite"></a>
## Перефразування

Використовуйте **Перефразування**, коли хочете покращити формулювання, не змінюючи основного змісту.

![Перефразування workspace](../images/screenshots/uk/rewrite.png)

Це корисно для:

- виправлення орфографії та граматики
- покращення зрозумілості тексту
- робити текст більш формальним або неформальним
- скорочення або розширення тексту
- наданню тексту більш технічного звучання

<br />

<a id="rewrite-text"></a>
### Перефразування тексту

1. Відкрийте **Перефразування**.
2. Виберіть **Режим**.
3. Виберіть модель у панелі інструментів.
4. Введіть або вставте текст у **Введення**.
5. Натисніть **Перефразування**.
6. Перегляньте результат у **Виведенні**.

Та сама поведінка клавіші Enter, описана в [**Переклад**](#keyboard-shortcuts), також застосовується тут.

<br /><br />

<a id="transform"></a>
## Трансформування

Використовуйте **Трансформування**, коли хочете, щоб ШІ дотримувався користувацького набору інструкцій.

![Трансформування workspace](../images/screenshots/uk/transform.png)

Це найбільш гнучка область додатка. Ви можете використовувати його для таких завдань:

- підсумовування нотаток
- перетворення приблизного тексту на випакований електронний лист
- видобуття ключових моментів
- перетворення тексту на конкретний формат

<br />

<a id="run-an-existing-prompt"></a>
### Запуск існуючого промпту

1. Відкрийте **Трансформування**.
2. Виберіть промпт із списку промптів.
3. Якщо з’являється поле **Цільова** мова, виберіть мову, якщо це потрібно.
4. Введіть або вставте текст у **Введення**.
5. Натисніть **Трансформування**.
6. Перегляньте результат у **Виведенні**.

<br />

<a id="if-you-have-no-prompts-yet"></a>
### Якщо у вас ще немає промптів

Якщо ваш список промптів порожній, натисніть **Завантажити зразки промптів**. Це додасть вбудовані приклади, щоб ви могли швидко почати.

> ℹ️ **ПРИМІТКА**<br/>
> Зразки промптів надаються англійською мовою. Після їх завантаження ви можете редагувати промпт і використовувати **Переклад промпту**, якщо хочете адаптувати текст промпту для іншої мови.

<br />

<a id="create-a-prompt-quickly"></a>

### Швидке створення промпту

Найшвидший спосіб створити промпт:

1. Клацніть **Новий промпт**.
2. Клацніть **Згенерувати промпт**.
3. Опишіть, що має робити промпт.
4. Виберіть модель.
5. Нехай додаток створить чернетку за вас.
6. Перегляньте чернетку та клацніть **Зберегти**.

![Згенерувати промпт](../images/screenshots/uk/transform-generate.png)


<br />

### Редагування промпту

Коли ви створюєте або редагуєте промпт, редактор з'являється зліва, а тестова область — справа.

![Редактор промпту Transform](../images/screenshots/uk/transform-prompt-edit.png)

Основні поля:

- **Назва промпту**: ім'я, що відображається у списку промптів.
- **Інструкції для промпту (необов'язково)**: коротка підказка, яка відображається користувачу під час запуску промпту.
- **Роль моделі**: загальна роль, призначена для ШІ, наприклад 'You are a helpful assistant.'
- **Інструкції для моделі (по одному на рядок)**: конкретні правила, які має дотримуватися ШІ.
- **Опис результату**: коротке слово, що описує результат, наприклад 'summary' або 'rewrite'.
- **Температура (0.0 → 1.0)**: повзунок творчості.
- Запит цільової мови: додає селектор цільової мови під час запуску промпту.

Якщо технічний термін **Температура** для вас новий, уявіть його так:

- **Нижча** температура дає стабільніші, більш передбачувані результати.
- **Вища** температура дає більше різноманітності та творчості.

Ви також можете використовувати:

- **`Згенерувати промпт`**, щоб створити нову чернетку з простого опису
- **`Покращити промпт`**, щоб удосконалити існуючий промпт
- **`Перекласти промпт`**, щоб перекласти поля промпту

> ⚠️ **УВАГА**<br/>
> Клацніть **`Зберегти`** перед тим, як клацнути **`Back to Run`**. Якщо ви повернетесь без збереження, ваші зміни будуть втрачені.

Тестова панель праворуч дозволяє спробувати ваш промпт із зразком тексту, перш ніж використовувати його в повсякденній роботі.

Це корисно, коли:

- ви створюєте новий промпт
- ви порівнюєте дві версії промпту
- ви хочете перевірити тон, довжину або формат виводу

<a id="settings"></a>
## Налаштування

Відкрийте **Налаштування** з бічної панелі, щоб налаштувати поведінку додатка.

Доступні вкладки можуть відрізнятися:

- **Конфігурація API** доступна лише в десктопному додатку.
- **Користувачі** доступна лише в веб-додатку і лише для адміністраторів.

<br />

<a id="general-settings"></a>

### Загальні налаштування

Використовуйте **Загальні налаштування**, щоб керувати поведінкою введення та виглядом.

**Поведінка**

- **Поведінка при натисканні Enter** обирає, чи запускає Enter завдання чи вставляє новий рядок.
- **Автопереклад при вставленні** запускає переклад відразу після вставлення тексту.
- **Автокопіювання результату в буфер обміну** автоматично копіює успішні результати.
- **Переклад у реальному часі (під час введення)** перекладає текст під час його введення.
- **Час очікування (мс)** встановлює час очікування для перекладу в реальному часі.

**Вид**

- **Кількість знаків після коми у вартості** змінює відображення десяткових розрядів вартості.
- **Шрифт** змінює шрифт для текстових панелей.
- **Розмір** змінює розмір шрифту.
- **Тільки для вебу:** **показувати поле навколо програми** додає додатковий простір навколо інтерфейсу.

<a id="models"></a>
### Моделі

Використовуйте **Налаштування** > **Моделі**, щоб обрати моделі, які з’являються на панелі інструментів.

![Вкладка моделей у налаштуваннях](../images/screenshots/uk/settings-models.png)

На сторінці є два списки:

- **Доступні моделі** зліва
- **Вибрані моделі** справа

Корисні елементи керування:

- **Пошук моделей...** для пошуку моделі за назвою
- **Тільки безкоштовні** щоб показувати лише безкоштовні моделі
- **Оновити** щоб перезавантажити список
- **Розгорнути всі** і **Згорнути всі** коли ви сортуєте за постачальником

Щоб додати модель, натисніть **Додати**.

Щоб видалити модель, натисніть **X** поруч з нею у списку **Вибрані моделі**.

Щоб очистити список, натисніть **Скасувати вибір усіх**. Потрібна безкоштовна модель залишиться у списку.

> ℹ️ **ПРИМІТКА**<br/>
> Якщо ви не хочете одразу поповнювати баланс у OpenRouter, почніть увімкнувши **Тільки безкоштовні** та обравши безкоштовні моделі.

### Мови

Використовуйте **Налаштування** > **Мови**, щоб організувати списки мов, що використовуються в програмі.

- **Головні мови** закріплені біля початку списків мов у розділах **Переклад** та **Трансформування**.
- **Своя мова** дозволяє додати мову, якої немає в вбудованому списку.

Якщо ви додасте свою мову, вона з’явиться у селекторах мов поряд з вбудованими варіантами.

<a id="cost-tracking"></a>
### Відстеження витрат

Використовуйте **Налаштування** > **Відстеження витрат** для керування інформацією про вартість.

- **Загальна вартість** показує накопичувальну суму.
- **Копіювати значення** копіює суму в буфер обміну.
- **Скинути вартість** обнуляє збережену суму.
- **Синхронізувати з використанням API ключа** встановлює суму відповідно до використання, яке повідомляє OpenRouter.
- **Використання API ключа** показує деталі використання, якщо вони доступні.
- **Видалити дані про вартість** видаляє всі дані або лише записи, старші за вибрану дату.

> ⚠️ **УВАГА**<br/>
> Видалення даних неможливо скасувати. Перед видаленням переконайтеся, що ви створили резервну копію даних або експортували їх через [**Панель керування** > **Усі виклики**](#dashboard-tabs), інакше вони будуть втрачені назавжди.

### Користувачі

**Тільки для вебу - тільки для адміністратора**

<br />

<a id="api-config"></a>
### Конфігурація API

**Тільки для настольного додатка**

Використовуйте **Конфігурація API**, щоб під'єднати настільний додаток до OpenRouter або до Transrewrt проксі.

- **Ключ API OpenRouter** – це місце, куди ви вставляєте свій ключ.
- **URL API** – це адреса сервісу. Залиште значення за замовчуванням, якщо вам не надали іншу.
- **Використовувати Transrewrt Proxy** направляє запити через проксі-сервіс замість прямого звернення до OpenRouter.
- **Seed ключа** з'являється, коли опцію проксі ввімкнено.
- **Перевірити конфігурацію API** перевіряє, чи працює поточна настройка.

Щоб дізнатися докладніше про отримання ключа API, дивіться [Як отримати ключ API](#how-to-get-an-api-key-desktop-app) вище.

> ℹ️ **ПРИМІТКА**<br/>
> Якщо ви не впевнені, що означають **URL API**, **Використовувати Transrewrt Proxy** або **Seed ключа**, залиште їх без змін і використовуйте налаштування OpenRouter за замовчуванням. Додаткову інформацію про проксі можна знайти у [сховищі Transrewrt Proxy](https://github.com/wsj-br/transrewrt-proxy).

<a id="common-issues"></a>
## Поширені проблеми

Якщо щось працює не як очікується, спочатку перевірте наступні пункти.

<br />

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Програма не перекладає, не переписує і не трансформує текст

Переконайтеся, що:

- ви обрали модель у панелі інструментів
- принаймні одна модель перерахована в [**Налаштування** > **Моделі**](#models)
- ваш API налаштований працювати

Якщо ви використовуєте десктопну програму:

1. Відкрийте [**Налаштування** > **Конфігурація API**](#api-config).
2. Переконайтеся, що ваш ключ API збережено.
3. Натисніть **Тестування конфігурації API**.

<br />

<a id="the-model-list-is-empty"></a>
### Список моделей порожній

Відкрийте [**Налаштування** > **Моделі**](#models) і натисніть **Оновити**.

При необхідності:

- знайдіть модель
- увімкніть **Тільки безкоштовні**
- додайте одну або кілька моделей до **Вибрані моделі**

<br />

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Результат занадто повільний або занадто дорогий

Спробуйте один або кілька з цих варіантів:

- виберіть іншу модель
- використайте коротший вхідний текст
- вимкніть **Переклад у реальному часі (під час введення)** в [**Налаштування** > **Загальні налаштування**](#general-settings)
- використовуйте безкоштовні моделі для простих завдань (див. [Моделі](#models))

<br />

<a id="the-interface-is-in-the-wrong-language"></a>
### Інтерфейс на невірній мові

Натисніть іконку планети в [панелі інструментів](#toolbar) і виберіть бажану **мову інтерфейсу**.

<br />

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Текст занадто малий або важкий для читання

Відкрийте [**Налаштування** > **Загальні налаштування**](#general-settings) і змініть:

- **Шрифт**
- **Розмір**

<br />

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Я змінив запит і втратив зміни

Під час редагування запиту завжди натискайте **Зберегти** перед тим, як натиснути **Повернутися до запуску**.
