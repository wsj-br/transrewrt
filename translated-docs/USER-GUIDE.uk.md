# Посібник для користувача

<br/>

<a id="introduction"></a>

## Вступ

Transrewrt допомагає працювати з текстом трьома основними способами:

- **Переклад** — перетворення тексту з однієї мови на іншу.
- **Переписання** — переформулювання тексту в іншому стилі, наприклад, чіткішому, коротшому або формальнішому.
- **Трансформація** — обробка тексту за допомогою спеціальних інструкцій штучного інтелекту, що називаються запитами.

<br/>

Цей посібник пояснює, як користуватися додатком після його встановлення та запуску. Щодо інструкцій з встановлення див. головний файл **[README](README.uk.md)**.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Transrewrt доступний як настільний додаток для Windows і Linux, а також як веб-додаток для самостійного розгортання. Цей посібник присвячений повсякденному використанню додатку. Там, де щось стосується лише однієї версії, це чітко позначено.

<a id="before-you-start"></a>

## Перш ніж почати

Для використання Transrewrt вам потрібен доступ хоча б до одного постачальника ШІ. Підтримувані постачальники: [OpenRouter](https://openrouter.ai) (який об’єднує багато моделей), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras та [Ollama](https://ollama.com) для локальних моделей.

Для початку використання не обов’язково вибирати платну модель. Як тільки ви додасте свій API-ключ OpenRouter, додаток автоматично активує вбудовану **безкоштовну** опцію OpenRouter. Це дозволяє одразу починати перекладати, переписувати та перетворювати текст. Або ж ви можете отримати безкоштовний API-ключ від Cerebras, Google, Groq чи Mistral AI.

Простими словами:

- **Модель** — це рушій ШІ, що виконує роботу. Моделі вказані з **префіксом постачальника** (наприклад, `openrouter/…`, `openai/…`, `ollama/…`).
- **API-ключ** (або для Ollama — **базову URL-адресу**) додаток використовує для зв’язку з цим постачальником.

Якщо ви використовуєте **настільний додаток**, додайте ключі в розділі [**Налаштування** > **Налаштування API**](#api-config) для кожного постачальника, якого використовуєте. Якщо ви використовуєте лише OpenRouter, перегляньте нижче розділ [Як отримати ключ API](#how-to-get-an-api-key-desktop-app). Якщо ви не бажаєте використовувати ключ API, ви можете встановити Ollama (з [ollama.com](https://ollama.com)) і використовувати локальні моделі, наприклад `translategemma:4b`.

Якщо ви використовуєте **веб-версію**, адміністратор сервера налаштовує постачальників через змінні середовища, тому ви не можете безпосередньо ввести ключі API в додатку.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>

### Як отримати безкоштовний API-ключ OpenRouter (настільний додаток)

Якщо ви використовуєте настільний додаток, дотримуйтесь таких кроків:

1. Перейдіть на сайт [OpenRouter](https://openrouter.ai) у своєму веб-браузері.
2. Створіть обліковий запис або увійдіть до нього.
3. Відкрийте сторінку [Keys](https://openrouter.ai/keys).
4. Натисніть кнопку, щоб створити новий API-ключ.
5. Задайте ключу назву, за якою ви зможете його розпізнати згодом.
6. Скопіюйте новий API-ключ.
7. Поверніться до Transrewrt і відкрийте **Налаштування** > **Налаштування API**.
8. Вставте ключ у поле **OpenRouter API key** (у розділі **Налаштування** > **Налаштування API**).
9. Натисніть **Test OpenRouter key**, щоб переконатися, що він працює.

<a id="getting-started"></a>

## Початок роботи

Якщо ви використовуєте Transrewrt вперше, дотримуйтесь такого порядку:

1. Відкрийте додаток.
2. За потреби виберіть мову інтерфейсу, натиснувши на іконку земної кулі.
3. Якщо ви використовуєте **настільний додаток**, відкрийте [**Налаштування** > **Налаштування API**](#api-config), додайте ключ API хоча б для одного провайдера (наприклад, OpenRouter) та натисніть **Тест**, щоб перевірити роботу.
4. Відкрийте [**Налаштування** > **Моделі**](#models) і додайте одну або кілька моделей до розділу **Обрані моделі**.
5. Відкрийте [**Налаштування** > **Мови**](#languages) і виберіть ваші **Основні мови**, якщо хочете, щоб найчастіше використовувані мови відображались першими.
6. Перейдіть до вкладки **Переклад** та виконайте простий переклад, щоб переконатися, що все працює.
7. Коли переклад вдасться, спробуйте функції **Переписати** та потім **Перетворити**.

Порядок важливий. Він допомагає уникнути найпоширенішої помилки для новачків: спроби виконати завдання до того, як додаток отримав робоче з'єднання з API або обрано модель.

### Панель інструментів

Панель інструментів трохи змінюється залежно від того, де ви перебуваєте в додатку.

- Зліва відображається назва поточної сторінки.
- Справа знаходяться **вибір моделі** та елемент керування **Мова інтерфейсу**.

**Вибір моделі** дозволяє обрати, який рушій ШІ використовувати для поточного завдання.

  ![Вибір моделі](../images/screenshots/uk/model-selector.png)

Деякі безкоштовні моделі можуть бути недоступними — іноді вони вимкнені або мають обмеження на використання. У такому разі додаток автоматично вилучить таку модель з вашого списку доступних. Щоб контролювати, які моделі відображаються, перейдіть у розділ [**Налаштування** > **Моделі**](#models) та змініть свій список моделей.
Також ви можете відкрити налаштування моделі безпосередньо, клацнувши на піктограму постачальника ліворуч від назви моделі на панелі інструментів.

<br/>

**Піктограма глобуса разом із кодом мови** змінює мову інтерфейсу додатку, наприклад, меню та кнопки. Вона **не** змінює мови перекладу, що використовуються у функції **Перекласти**.

<a id="input-and-output-panels"></a>

### Панелі введення та виведення

Більшість робочих просторів використовують ліву панель **Введення** та праву панель **Виведення**.

Кожна панель також показує:

| **Введення**                                                         | **Виведення**                                                                                                                      |
|----------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| - Кількість символів <br/>- Кількість слів <br/>- Кількість абзаців | - Як довго виконувалася задача<br/>- **TPS** (токенів за секунду)<br/>- Кількість символів, слів і абзаців<br/>- Використана модель |


Якщо вас цікавлять технічні терміни:

- **Токен** означає невеликий фрагмент тексту. Можна уявити його частину слова або коротке слово.
- **TPS** означає, скільки таких фрагментів тексту модель обробляє щосекунди.

Ви також можете відстежувати вартість кожної операції (якщо вона доступна) і загальну вартість, увімкнувши опцію "Показувати інформацію про вартість на діях" у розділі [**Налаштування** > **Загальні налаштування**](#general-settings).

<a id="translate"></a>

## Переклад

Використовуйте **Переклад**, коли потрібно перекласти текст з однієї мови на іншу.

![Інтерфейс Перекладу](../images/screenshots/uk/translate.png)

<br/>

<a id="translate-text"></a>

### Переклад тексту

1. Відкрийте **Переклад**.
2. Виберіть мову в полі **З**.
3. Виберіть мову в полі **На**.
4. Виберіть модель на панелі інструментів.
5. Наберіть або вставте текст у поле **Введення**.
6. Натисніть **Перекласти**.
7. Прочитайте результат у полі **Виведення**.
8. Скористайтеся кнопкою копіювання, якщо потрібно скопіювати результат.

<br/>

<a id="language-selection"></a>

### Вибір мови

- **З** може бути конкретною мовою або **Визначення мови**.
- **На** — це мова, на яку ви хочете отримати результат.

Ваші вибрані **Найпоширеніші мови** відображаються вгорі списку. Ви можете встановити їх у розділі [**Налаштування** > **Мови**](#languages).

<br/>

<a id="helpful-translation-settings"></a>

### Корисні параметри перекладу

У розділі [**Налаштування** > **Загальні налаштування**](#general-settings) можна змінити поведінку перекладу:

- **Автопереклад при вставці** — виконує переклад одразу після вставлення тексту.
- **Автоматично копіювати результат у буфер обміну** — автоматично копіює результат після успішного виконання.
- **Переклад у реальному часі (під час набору)** — виконує переклад у міру введення тексту.
- **Час очікування (мс)** — визначає, як довго додаток чекає перед виконанням перекладу в реальному часі.
- **Enter** — визначає дію при натисканні клавіші `Enter`:

<a id="rewrite"></a>

## Переписати

Використовуйте **Переписати**, коли потрібно поліпшити формулювання, не змінюючи основного змісту.

![Інтерфейс Переписати](../images/screenshots/uk/rewrite.png)

Це корисно для:

- виправлення орфографії та граматики (**Перевірити правопис і граматику**)
- підвищення чіткості тексту (**Покращити чіткість**)
- отримання кількох різних варіантів перефразування за один раз (**Альтернативні варіанти**)
- зробити текст більш формальним або неформальним (**Формально** / **Неформально**)
- скорочення або розширення тексту (**Скоротити** / **Розширити**)
- зробити текст більш технічним (**Уточнити технічно**)

<a id="edit-a-prompt"></a>

### Редагування запиту

Коли ви створюєте або редагуєте запит, редактор відображається зліва, а зправа з’являється тестова область.

![Редактор запитів Transrewrt](../images/screenshots/uk/transform-prompt-edit.png)

Головні поля:

- **Назва запиту**: назва, що відображається у списку запитів.
- **Інструкції до запиту (необов’язково)**: коротка підказка, яка відображається користувачеві під час виконання запиту.
- **Роль моделі**: загальна роль, призначена штучному інтелекту, наприклад: «Ти — корисний помічник».
- **Інструкції моделі (по одній на рядок)**: конкретні правила, яких має дотримуватися штучний інтелект.
- **Опис результату**: коротке слово, що описує результат, наприклад: «реферат» або «переписаний текст».
- **Температура (від 0,0 до 1,0)**: впливає на поведінку моделі; див. нижче.
- **Запитувати цільову мову**: додає вибір цільової мови, коли запит запускається.

Якщо для вас новий технічний термін **Температура**, розгляньте його таким чином:

- **Нижча** температура дає стабільніші, передбачуваніші результати.

- **Вища** температура забезпечує більшу різноманітність і креативність.

Ви також можете використовувати:

- **`Створити запит`**, щоб створити новий варіант на основі простого опису
- **`Поліпшити запит`**, щоб уточнити існуючий запит
- **`Перекласти запит`**, щоб перекласти поля запиту

<br/>

> ⚠️ **УВАГА**<br/>
> Натисніть **`Зберегти`**, перш ніж натискати **`Назад до запуску`**. Якщо ви повернетесь назад без збереження, всі зміни буде втрачено.

<a id="general-settings"></a>

### Загальні налаштування

Використовуйте **Загальні налаштування**, щоб керувати поведінкою під час набору тексту, зберіганням даних виконання для **Історії** та зовнішнім виглядом.

**Поведінка**

- **Дія клавіші ENTER** визначає, чи буде клавіша `Enter` виконувати завдання чи вставляти новий рядок.
- **Автоматичний переклад при вставці** розпочинає переклад одразу після вставки тексту.
- **Автоматичне копіювання результату в буфер обміну** автоматично копіює успішні результати.
- **Переклад у реальному часі (під час набору)** виконує переклад під час набору тексту.
- **Час очікування (мс)** встановлює час затримки для перекладу в реальному часі.

**Історія**

- **Зберігати історію виконання** визначає, чи будуть кожен переклад, переписування та перетворення зберігати **вхідний і вихідний текст** для перегляду в бічній панелі [**Історія**](#history). Вимкнення функції вимагає підтвердження; при підтвердженні збережений текст історії видаляється з бази даних.

- **Видалити історію даних** дає змогу видалити збережений текст за віком (наприклад, старіше кількох місяців або **всі дані (очистити)**) за допомогою **Видалити дані**. Це впливає лише на збережений текст у вигляді **Історія** і **не видаляє** загальну інформацію про витрати чи використання. Щоб видалити або скоротити інформацію про **витрати**, використовуйте [**Налаштування** > **Відстеження витрат**](#cost-tracking).

**Вигляд**

- **Показувати інформацію про вартість на діях** керує відображенням вартості кожної операції (якщо доступно) та загальною вартістю у панелях виведення Перекладу, Переписування та Перетворення.
- **Кількість знаків після коми у вартості** змінює кількість десяткових знаків для виведення вартості.
- **Лише для веб-версії:** **показувати поля навколо додатку** додає додатковий простір навколо інтерфейсу.
- **Сімейство шрифтів** змінює шрифт у текстових полях.
- **Розмір** змінює розмір шрифту.

**Резервне копіювання конфігурації**

- **Включити дані використання у резервну копію** — якщо увімкнено, у ZIP-файл також включаються історія виконань і дані викликів API.

- **Резервне копіювання конфігурації** — створює один архів ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`, за умовчанням у часовому поясі UTC), який містить `config.json`, `state.json`, опційний ключ шифрування, користувачів, налаштування, власні підказки та дані використання, якщо ви їх увімкнули. Після успішного резервного копіювання підтвердження покаже ім’я збереженого файлу.
- **Відновлення з резервної копії** — спочатку відкривається **діалогове вікно підтвердження**. Виберіть архів ZIP у цьому діалозі (**Огляд** / вибір файлу або перетягування, де це підтримується), потім перегляньте параметри:
  - **Відновити дані використання** — імпортувати історію/використання з архіву, якщо вони були включені під час резервного копіювання; залиште позначку знятою, якщо потрібно відновити лише налаштування та підказки.
  - **Очистити старі дані використання перед відновленням** — видалити існуючу історію/дані використання в цій установці перед застосуванням резервної копії (необов’язково; використовуйте, коли потрібне повне заміщення).

Резервні копії, створені в веб- або настільній версії, можна відновити в іншій версії. Під час відновлення резервної копії настільної версії у веб-версії дані будуть відновлені для користувача-адміністратора.

### Моделі

Скористайтеся **Налаштування** > **Моделі**, щоб обрати, які моделі відображатимуться на панелі інструментів.

![Вкладка моделей у налаштуваннях](../images/screenshots/uk/settings-models.png)

Сторінка містить два списки:

- **Доступні моделі** — ліворуч
- **Обрані моделі** — праворуч

Корисні елементи керування:

- **Пошук моделей...** — для пошуку моделі за назвою
- Фішки **Постачальник** — для звуження списку до одного движка (OpenRouter, OpenAI, Ollama тощо)
- **Лише безкоштовні** — показує лише безкоштовні моделі
- **Оновити** — щоб перезавантажити список
- **Розгорнути все** та **Згорнути все** — під час сортування за постачальником

Ідентифікатори моделей містять префікс постачальника (наприклад, `openrouter/…` або `openai/…`). Мітки, такі як **OpenAI (OpenRouter)** або **OpenAI (безпосередньо)**, показують, як маршрутизуються запити.

> ℹ️ **ПРИМІТКА**<br/>

> **OpenRouter Body Builder** (`openrouter/bodybuilder`) — це модель маршрутизатора, а не загальна модель для чатів: її відповідь — це JSON, що описує тіла запитів до API OpenRouter (наприклад, масив `requests` з `model` і `messages`). Якщо ви використовуєте її для **Перекладу**, **Переписування** чи **Перетворення**, на панелі виводу з'явиться цей JSON замість готового тексту. Для цих завдань обирайте звичайну текстову модель. Дивіться сторінку моделі [Body Builder](https://openrouter.ai/openrouter/bodybuilder) на OpenRouter.

Дії:

 - Щоб додати модель, натисніть **Додати** або в будь-якому місці запису.

 - Щоб видалити модель, натисніть **X** поруч із нею у розділі **Вибрані моделі** або **Обрано** у записі Доступних моделей.

 - Щоб очистити список, натисніть **Скасувати вибір усіх**. Обов’язкова безкоштовна модель залишиться у списку.

<br/>

> ℹ️ **ПРИМІТКА**<br/>

> Якщо ви не хочете одразу додавати кошти до OpenRouter, спочатку увімкніть **Безкоштовно** та оберіть безкоштовні моделі (без необхідності вказувати кредитну картку). Також ви можете використовувати Ollama для локального запуску моделей без будь-якого API-ключа.

<br/>

<a id="languages"></a>

### Мови

Використовуйте **Налаштування** > **Мови**, щоб організувати списки мов, які використовуються в додатку.

- **Найпопулярніші мови** закріплені вгорі списків мов у розділах **Перекласти** та **Перетворити**.
- **Користувацька мова** дозволяє додати мову, якої немає у вбудованому списку.

Якщо ви додасте користувацьку мову, вона з’явиться у вибирачах мови поряд із вбудованими варіантами.

<br/>

<a id="cost-tracking"></a>

### Відстеження витрат

Скористайтеся **Налаштування** > **Відстеження витрат**, щоб керувати інформацією про витрати.

- **Загальна вартість** відображає поточну суму.
- **Копіювати значення** копіює загальну суму в буфер обміну.
- **Скинути витрати** обнуляє збережену суму.
- **Синхронізувати з використанням API-ключа** встановлює суму згідно з даними використання, які надає ваш обліковий запис OpenRouter (лише для OpenRouter).
- **Використання API-ключа** відображає деталі використання OpenRouter, якщо доступно.
- **Видалити дані про витрати** видаляє всі дані або лише ті, що старіші за вибрану дату.


**Відстеження витрат:** під час використання моделей OpenRouter додаток відображає фактичне використання та витрати на основі інформації від OpenRouter. Для всіх інших провайдерів додаток обчислює вартість, використовуючи ціни, оприлюднені OpenRouter. Якщо ціна недоступна, оцінка може становити нуль.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> **Усі суми є орієнтовними і наводяться виключно для довідки. Це не є офіційними рахунками.**


<br/>

> ⚠️ **ПОПЕРЕДЖЕННЯ**<br/>

> Видалення даних не можна скасувати. Перед видаленням обов’язково створіть резервну копію даних або експортуйте їх через [**Історію**](#history) 
> або [**Панель керування** > **Усі запити**](#dashboard-tabs), інакше вони будуть остаточно втрачені. 
> Також буде видалена вся історія введених і виведених даних, пов’язаних із кожним записом виклику API.

<a id="api-config"></a>

### Налаштування API

Підтримувані провайдери: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras та **Ollama** (локальні моделі через базову URL-адресу). Потрібно налаштувати лише тих провайдерів, які ви використовуєте.

**Веб-додаток: лише для адміністратора**

Ключі API налаштовуються через системні або Docker змінні оточення — їх не вводять у веб-інтерфейсі. На цій сторінці показано, для яких провайдерів вже налаштовано ключі, а також надається можливість протестувати кожен із них, натиснувши кнопку **`Тест`**.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Щоб змінити ключ API, оновіть відповідну змінну оточення у вашій системі або конфігурації Docker і перезапустіть сервер або контейнер.

> ℹ️ **ПРИМІТКА**<br/>

> **Резервні копії конфігурації** (див. [**Загальні налаштування** → Резервна копія конфігурації](#general-settings)) можуть містити **підставлені** ключі провайдера всередині файлу `config.json` у ZIP-архіві. Відновлення цього архіву **не** призведе до копіювання цих ключів назад у конфігураційний файл сервера — активні ключі як і раніше беруться зі змінних середовища та існуючого стану файлу, як описано вище.

<br/>

**Десктопний додаток**

Використовуйте **Налаштування API**, щоб зберігати ключі API для кожного використовуваного провайдера. Для Ollama вкажіть **базову URL-адресу** замість ключа API.

<br/>

> 💡 **Підказка** <br/>
> Якщо ви не хочете використовувати API-ключ або платити за використання, ви можете [завантажити Ollama](https://ollama.com) та безкоштовно запускати моделі (наприклад, `translategemma:4b`) локально на своєму комп’ютері. Або ви можете створити безкоштовний обліковий запис OpenRouter (карта не потрібна), щоб користуватися їхніми безкоштовними моделями, або отримати безкоштовний API-ключ від Cerebras, Google, Groq чи Mistral AI.

- Додавайте лише тих постачальників, які вам потрібні. У розділі **Налаштування** > **Моделі** кожен ідентифікатор моделі починається з назви постачальника (наприклад, `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Щоб додати API-ключ, введіть його значення в текстове поле та натисніть **`Зберегти`**. Щоб змінити існуючий ключ, натисніть **`Редагувати`**. Щоб перевірити, чи працює ключ, натисніть **`Перевірити`**. Для базової URL-адреси Ollama завжди натискайте **`Перевірити`**, щоб перевірити з’єднання.

<br/>

> ℹ️ **ПРИМІТКА**<br/>
> Ви не можете переглянути поточне значення API-ключа. Ви можете лише замінити його, скориставшись кнопкою **`Редагувати`**.
> API-ключі зберігаються в зашифрованому вигляді в конфігурації.

<a id="common-issues"></a>

## Поширені проблеми

Якщо щось не працює так, як очікувалося, спочатку перевірте наступні пункти.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### Додаток не перекладатиме, не переписуватиме й не перетворюватиме текст

Переконайтеся, що:

- ви вибрали модель на панелі інструментів;
- принаймні одна модель вказана в розділі [**Налаштування** > **Моделі**](#models);
- ваша конфігурація API працює.

Якщо ви використовуєте настільний додаток:

1. Відкрийте [**Налаштування** > **Налаштування API**](#api-config).
2. Переконайтеся, що принаймні один ключ API збережено.
3. Натисніть **Тест** поруч із постачальником, щоб підтвердити роботу ключа.

<br/>

<a id="the-model-list-is-empty"></a>

### Список моделей порожній

Відкрийте [**Налаштування** > **Моделі**](#models) та натисніть **Оновити**.

За потреби:

- знайдіть модель
- увімкніть опцію **Лише безкоштовні**
- додайте одну або кілька моделей до **Вибрані моделі**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>

### Результат надто повільний або надто дорогий

Спробуйте один або кілька з цих варіантів:

- виберіть іншу модель
- скористайтеся коротшим введенням
- вимкніть **Переклад у реальному часі (під час друку)** в розділі [**Налаштування** > **Загальні налаштування**](#general-settings)
- використовуйте безкоштовні моделі для простих завдань (див. [Моделі](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>

### Інтерфейс відображається не тією мовою

Натисніть на піктограму глобуса в [панелі інструментів](#toolbar) та виберіть потрібну **мову інтерфейсу**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>

### Текст надто малий або важко читати

Відкрийте [**Налаштування** > **Загальні налаштування**](#general-settings) і змініть:

- **Сімейство шрифтів**
- **Розмір**

<br/>

<a id="dashboard-charts-are-empty"></a>

### Діаграми на інформаційній панелі порожні

Це нормально, якщо:

- ви використовуєте лише **безкоштовні моделі** і переглядаєте показники **вартості** (вони можуть бути нульовими); діаграми кількості викликів у розділі **Підсумок** все ще потребують даних за обраний період;
- обраний **фільтр часу** не охоплює період, коли були зроблені виклики — спробуйте вибрати **Все**, щоб перевірити.

Якщо після вибору **Все** діаграми все ще порожні, переконайтеся, що виклики відображаються у розділі [**Історія**](#history) або на вкладці **Усі виклики**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### Вартість показує "недоступна" або виглядає неправильною

Коли ви використовуєте моделі через **OpenRouter**, додаток відображає реальні витрати, повідомлені OpenRouter.

Для **інших провайдерів** (напряму OpenAI, напряму Anthropic тощо), вартість оцінюється на основі цінових даних, опублікованих OpenRouter. Якщо для моделі не знайдено відповідної ціни, вартість буде позначена як **недоступна** і не буде додана до загальної суми.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### Загальна вартість не збігається з рахунком вашого провайдера

Усі показники вартості в додатку — це **орієнтовні значення для довідки**, а не офіційні рахунки.

Щоб наблизити загальну суму до фактичних витрат на OpenRouter, відкрийте [**Налаштування** > **Відстеження вартості**](#cost-tracking) та натисніть **Синхронізувати з використанням API-ключа**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### Сторінка Історія відсутня в бічній панелі

Функція **Зберігати історію виконання** може бути вимкнена. Відкрийте [**Налаштування** > **Загальні налаштування**](#general-settings) і увімкніть її. Зауважте, що увімкнення не відновить видалені раніше дані історії.

<br/>

<a id="web-app-session-expired"></a>

### Веб-застосунок: неочікувано перенаправлено на сторінку входу

Можливо, ваш сеанс закінчився. Увійдіть знову. Якщо це відбувається часто, перевірте конфігурацію сервера щодо параметрів тривалості сеансу.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### Веб-адміністратор: втрачено або забуто пароль

Це стосується **локально встановленого веб-додатку** (Docker), а не стаціонарного додатку (Electron).

- Якщо інший адміністратор може увійти, він може відкрити [**Налаштування** > **Користувачі**](#users), вибрати обліковий запис і задати там **новий пароль**.
- Якщо ви **заблоковані**, але маєте **доступ до оболонки** машини чи контейнера, скиньте пароль за допомогою допоміжної утиліти, яка постачається разом із образом (замініть `transrewrt`, якщо ви змінили типове ім’я, і вкажіть пароль у лапках, якщо він містить пробіли чи спеціальні символи):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Типове ім’я адміністратора — `admin`, якщо ви ще не створили інших облікових записів. Якщо вказано лише один аргумент, він розглядається як новий пароль для `admin`.

Якщо ви запускаєте додаток із **локальної копії коду**, а не з Docker, використовуйте:

```bash
pnpm run reset-web-password -- <username> <new-password>

Скрипт оновлює запис користувача в базі даних SQLite (а також може створити користувача `admin`, якщо його відсутньо). Після скидання увійдіть знову, використовуючи новий пароль.


<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>

### На панелі стану відсутні дані для інших користувачів (веб)

Тільки **адміністратори** можуть переглядати дані від усіх користувачів через фільтр **Користувач**. Звичайні користувачі за задумом бачать лише власну активність.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>

### Я змінив промпт і втратив зміни

Під час редагування промпту завжди натискайте **Зберегти**, перш ніж натиснути **Назад до запуску**.

## Швидкі поради

- Регулярно експортуйте запити, якщо ви створюєте бібліотеку запитів, яку хочете зберегти (див. [Запити перетворення](#transform-prompts)) або хочете поділитися нею з іншими.
