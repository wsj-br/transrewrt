# Руководство пользователя

<br/>

<a id="introduction"></a>
## Введение

Transrewrt помогает работать с текстом тремя основными способами:

- **Перевести** — преобразовать текст с одного языка на другой.
- **Рерайт** — переформулировать текст в другом стиле, например, более ясно, кратко или формально.
- **Трансформация** — обработка текста с помощью пользовательских инструкций ИИ, называемых запросами.

<br/>

В этом руководстве объясняется, как использовать приложение после его установки и запуска. Инструкции по установке см. в основном **[README](README.ru.md)**.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Transrewrt доступен в виде настольного приложения для Windows и Linux, а также в виде веб-приложения с самостоятельным размещением. В этом руководстве основное внимание уделяется повседневному использованию приложения. Если что-либо относится только к одной версии, это четко указано.

<a id="before-you-start"></a>
## Перед началом

Для использования Transrewrt вам нужен доступ хотя бы к одному провайдеру ИИ. Поддерживаемые провайдеры: [OpenRouter](https://openrouter.ai) (который объединяет множество моделей), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras и [Ollama](https://ollama.com) для локальных моделей.

Вам не нужно выбирать платную модель, чтобы начать. Как только вы добавите свой API-ключ OpenRouter, приложение автоматически включает встроенную **бесплатную** опцию OpenRouter. Это позволяет сразу начать переводить, переписывать и преобразовывать текст. Кроме того, вы также можете получить бесплатный API-ключ от Cerebras, Google, Groq или Mistral AI.

Простыми словами:

- **Модель** — это движок ИИ, который выполняет работу. Модели перечислены с префиксом **провайдера** (например, `openrouter/…`, `openai/…`, `ollama/…`).
- **Ключ API** (или, для Ollama, **базовый URL**) — это способ, с помощью которого приложение подключается к провайдеру.

Если вы используете **настольное приложение**, добавьте ключи в разделе [**Настройки** > **Конфигурация API**](#api-config) для каждого используемого провайдера. Если вы используете только OpenRouter, см. ниже раздел [Как получить ключ API](#how-to-get-an-api-key-desktop-app). Если вы не хотите использовать ключ API, вы можете установить Ollama (с сайта [ollama.com](https://ollama.com)) и использовать локальные модели, например `translategemma:4b`.

Если вы используете **веб-версию**, владелец сервера настраивает провайдеров с помощью переменных окружения, поэтому вы не можете ввести ключи API непосредственно в приложении.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Как получить бесплатный ключ API OpenRouter (десктопное приложение)

Если вы используете настольное приложение, выполните следующие действия:

1. Перейдите на сайт [OpenRouter](https://openrouter.ai) в вашем веб-браузере.
2. Создайте учётную запись или войдите в неё.
3. Откройте страницу [Ключи](https://openrouter.ai/keys).
4. Нажмите кнопку, чтобы создать новый API-ключ.
5. Присвойте ключу имя, по которому вы сможете распознать его позже.
6. Скопируйте новый API-ключ.
7. Вернитесь в Transrewrt и откройте **Настройки** > **Конфигурация API**.
8. Вставьте ключ в поле **OpenRouter API key** (в разделе **Настройки** > **Конфигурация API**).
9. Нажмите **Проверить ключ OpenRouter**, чтобы убедиться, что он работает.

<a id="getting-started"></a>
## Начало работы

Если вы используете Transrewrt впервые, следуйте этому порядку:

1. Запустите приложение.
2. При необходимости выберите **язык интерфейса** через значок глобуса.
3. Если вы используете **настольное приложение**, откройте [**Настройки** > **Конфигурация API**](#api-config), добавьте API-ключ хотя бы одного провайдера (например, OpenRouter) и нажмите **Проверить**, чтобы убедиться в его работоспособности.
4. Откройте [**Настройки** > **Модели**](#models) и добавьте одну или несколько моделей в раздел **Выбранные модели**.
5. Откройте [**Настройки** > **Языки**](#languages) и выберите **Основные языки**, если хотите, чтобы ваши наиболее часто используемые языки отображались первыми.
6. Перейдите в раздел **Перевод** и выполните простой перевод, чтобы убедиться, что всё работает.
7. После этого попробуйте **Перефразирование**, а затем **Преобразование**.

Очерёдность важна. Она предотвращает наиболее распространённую проблему при первом использовании: попытку выполнить задачу до настройки рабочего подключения к API или выбора модели.

<a id="toolbar"></a>
### Панель инструментов

Панель инструментов немного изменяется в зависимости от того, где вы находитесь в приложении.

- Слева отображается название текущей страницы.
- Справа отображаются **средство выбора модели** и элемент управления **Язык интерфейса**.

**Средство выбора модели** позволяет выбрать, какой ИИ-движок использовать для текущей задачи.

![Model selector](../images/screenshots/ru/model-selector.png)

Некоторые бесплатные модели могут быть недоступны — иногда они отключены или имеют ограничение по использованию. В таком случае приложение автоматически удалит эту модель из вашего списка доступных. Чтобы управлять отображаемыми моделями, перейдите в раздел [**Настройки** > **Модели**](#models) и отредактируйте список моделей.  
Вы также можете открыть настройки модели напрямую, нажав на значок провайдера слева от названия модели в панели инструментов.

<br/>

**Значок глобуса и код языка** изменяют язык интерфейса приложения, например, меню и кнопки. Это **не** влияет на языки перевода, используемые в функции **Перевести**.

![Interface language selector](../images/screenshots/ru/language-selector.png)

<a id="input-and-output-panels"></a>
### Панели ввода и вывода

Большинство рабочих пространств используют левую панель **Ввод** и правую панель **Результат**.

На каждой панели также отображается:

| **Ввод**                                                          | **Результат**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Количество символов <br/>- Количество слов <br/>- Количество абзацев   <br/> | - Время выполнения задачи<br/>- **TPS** (токены в секунду)<br/>- Количество символов, слов и абзацев<br/>- Используемая модель |

Если вы задаётесь вопросом о технических терминах:

- **Token** означает небольшой фрагмент текста. Вы можете думать об этом как о части слова или коротком слове.
- **TPS** означает, сколько таких фрагментов текста модель обрабатывает каждую секунду.

<br/>

Вы также можете отслеживать стоимость каждой операции (если доступно) и общую стоимость, включив опцию `Show cost information on the actions` в разделе [**Настройки** > **Общие настройки**](#general-settings).

<a id="translate"></a>
## Перевести

Используйте **Перевести**, когда нужно преобразовать текст с одного языка на другой.

![Translate workspace](../images/screenshots/ru/translate.png)

<br/>

<a id="translate-text"></a>
### Перевести текст

1. Откройте **Перевод**.
2. Выберите язык в поле **С**.
3. Выберите язык в поле **На**.
4. Выберите модель на панели инструментов.
5. Введите или вставьте текст в поле **Ввод**.
6. Нажмите **Перевести**.
7. Прочитайте результат в поле **Вывод**.
8. Используйте кнопку копирования, если хотите скопировать результат.

<br/>

<a id="language-selection"></a>
### Выбор языка

- **From** может быть конкретным языком или параметром **Определить язык**.
- **To** — это язык, на который вы хотите перевести результат.

Ваши выбранные **Языки** отображаются в верхней части списка. Вы можете задать их в разделе [**Настройки** > **Языки**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Полезные настройки перевода

В разделе [**Настройки** > **Общие настройки**](#general-settings) можно изменить поведение перевода:

- **Автоматический перевод при вставке** запускает перевод сразу после вставки текста.
- **Автоматическое копирование результата в буфер обмена** автоматически копирует результат после успешного выполнения.
- **Перевод в реальном времени (во время ввода)** запускает перевод по мере ввода текста.
- **Тайм-аут (мс)** определяет, как долго приложение ждёт перед запуском перевода в реальном времени.
- **Enter** определяет, что происходит при нажатии `Enter`:

<a id="rewrite"></a>
## Рерайт

Используйте **Rewrite**, когда хотите улучшить формулировку, не меняя основного смысла.

![Rewrite workspace](../images/screenshots/ru/rewrite.png)

Это полезно для:

- исправление орфографии и грамматики (**Проверка орфографии и грамматики**)
- улучшение ясности текста (**Повысить ясность**)
- несколько различных переформулировок за один запуск (**Альтернативные варианты**)
- придание тексту более формального или менее формального стиля (**Формальный** / **Неформальный**)
- сокращение или расширение текста (**Сократить** / **Расширить**)
- придаёт тексту более технический характер (**Сделать техническим**)

<br/>

> 💡 **TIP**<br/>
> Когда вы используете режим "**Check Spelling & Grammar**", во вкладке результата появляется переключатель **Show changes** (рядом с **Copy**).
> Включите или выключите его, чтобы показать или скрыть конкретные исправления, применённые к вашему тексту.

<a id="transform"></a>
## Трансформация

Используйте **Трансформация**, когда вы хотите, чтобы ИИ следовал пользовательскому набору инструкций.

![Transform workspace](../images/screenshots/ru/transform.png)

Это наиболее гибкая область приложения. Вы можете использовать её для задач, таких как:

- обобщение заметок
- превращение черновика в готовое письмо
- выделение ключевых моментов
- преобразование текста в определённый формат
- любое другое пользовательское действие с входным текстом

<br/>

<a id="run-an-existing-prompt"></a>
### Запуск существующего промпта

1. Откройте **Преобразование**.
2. Выберите запрос из списка запросов.
3. Если появляется поле **Целевой язык**, выберите нужный язык.
4. Введите или вставьте текст в поле **Ввод**.
5. Нажмите **Преобразовать**.
6. Прочитайте результат в поле **Вывод**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### Если у вас еще нет промптов

Если ваш список промптов пуст, нажмите **Загрузить примеры промптов** в рабочей области Трансформации. Эта же кнопка всегда доступна в разделе [**Настройки** > **Промпты трансформации**](#transform-prompts) в строке экспорта/импорта. Оба способа добавляют встроенные примеры, чтобы вы могли быстро начать.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>

<a id="edit-a-prompt"></a>
### Редактировать промпт

При создании или редактировании промпта редактор отображается слева, а область тестирования — справа.

![Transform prompt editor](../images/screenshots/ru/transform-prompt-edit.png)

Основные поля:

- **Имя запроса**: имя, отображаемое в списке запросов.
- **Инструкции к запросу (необязательно)**: краткая подсказка, отображаемая пользователю при выполнении запроса.
- **Роль модели**: общая роль, назначенная ИИ, например: «Вы — полезный помощник».
- **Инструкции модели (по одной на строку)**: конкретные правила, которым должен следовать ИИ.
- **Описание результата**: краткое слово, описывающее результат, например «резюме» или «переформулировка».
- **Температура (0,0 → 1,0)**: определяет поведение модели; см. ниже.
- **Запросить целевой язык**: добавляет выбор целевого языка при запуске запроса.

Если технический термин **Температура** вам незнаком, представьте это следующим образом:

- **Низкая** температура даёт более стабильные и предсказуемые результаты.
- **Высокая** температура обеспечивает большее разнообразие и креативность.

Вы также можете использовать:

- **`Generate prompt`** для создания нового черновика на основе простого описания
- **`Improve prompt`** для улучшения существующего промпта
- **`Translate prompt`** для перевода полей промпта

> Нажмите **`Save`**, прежде чем нажимать **`Back to Run`**. Если вы вернётесь назад без сохранения, все изменения будут потеряны.

<a id="general-settings"></a>
### Общие настройки

Используйте **Общие настройки**, чтобы управлять поведением при вводе, сохранением сведений о выполнении для **Истории** и внешним видом.

**Поведение**

- **Поведение клавиши ENTER** определяет, будет ли `Enter` запускать задачу или вставлять новую строку.
- **Автоматический перевод при вставке** запускает перевод сразу после вставки текста.
- **Автоматическое копирование результата в буфер обмена** автоматически копирует успешные результаты.
- **Перевод в реальном времени (во время ввода)** выполняет перевод по мере ввода текста.
- **Тайм-аут (мс)** устанавливает время ожидания для перевода в реальном времени.

**История**

- **Сохранять историю выполнения** управляет тем, сохраняются ли **ввод и выходной текст** для бокового меню [**История**](#history). Отключение этой функции требует подтверждения; если вы подтвердите, сохраненный текст истории будет удален из базы данных.  
- **Удалить данные истории** позволяет вам удалить сохраненный текст по возрасту (например, старше нескольких месяцев или **все данные (очистить)**) с помощью **Удалить данные**. Это затрагивает только сохраненный текст выполнения для просмотра **История**; это **не** удаляет данные о стоимости или использовании. Чтобы удалить или обрезать данные о **стоимости**, используйте [**Настройки** > **Отслеживание расходов**](#cost-tracking).

**Внешний вид**

- **Показывать информацию о стоимости операций** управляет отображением стоимости каждой операции (если доступно) и общей стоимости на панелях вывода «Перевести», «Переформулировать» и «Преобразовать».
- **Количество знаков после запятой в стоимости** изменяет отображение десятичных разрядов стоимости.
- **Только веб:** **показывать отступ вокруг приложения** добавляет дополнительное пространство вокруг интерфейса.
- **Семейство шрифтов** изменяет шрифт в текстовых панелях.
- **Размер** изменяет размер шрифта.

**Резервное копирование конфигурации**

- **Включить данные об использовании в резервную копию** — при включении ZIP-файл также содержит историю выполнения и данные вызовов API. 
- **Создать резервную копию** — создаёт один ZIP-файл (по умолчанию `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` в UTC) с `config.json`, `state.json`, опциональным ключом шифрования, пользователями, настройками, пользовательскими запросами и данными об использовании, если вы дали на это согласие. После успешного создания резервной копии подтверждение показывает имя сохранённого файла.
- **Восстановить из резервной копии** — сначала открывается **диалог подтверждения**. Выберите ZIP-файл резервной копии в диалоге (**Обзор** / выбор файла или перетаскивание, где поддерживается), затем проверьте параметры:
  - **Восстановить данные об использовании** — импортировать использование/историю из ZIP-файла, если при создании резервной копии они были включены; отключите, если нужны только настройки и запросы.
  - **Очистить старые данные об использовании перед восстановлением** — удалить существующие данные об использовании/истории в текущей установке перед применением резервной копии (опционально; используйте, если требуется полная замена).

Резервные копии, созданные в веб- или десктопной версии, могут быть восстановлены в другой. При восстановлении резервной копии десктопной версии в веб-версии данные будут восстановлены для пользователя-администратора.

На странице два списка:

Полезные элементы управления включают:

Идентификаторы моделей включают префикс провайдера (например, `openrouter/…` против `openai/…`). Бейджи, такие как **OpenAI (OpenRouter)** против **OpenAI (напрямую)**, показывают, как маршрутизируется трафик.

> **OpenRouter Body Builder** (`openrouter/bodybuilder`) — это модель-маршрутизатор, а не общая модель для чата: её ответ — это JSON, описывающий тела запросов к API OpenRouter (например, массив `requests` с `model` и `messages`). Если вы используете её для **Перевести**, **Рерайт** или **Трансформация**, в панели результатов будет показан этот JSON вместо готового текста. Выберите обычную текстовую модель для этих задач. См. [страницу модели Body Builder](https://openrouter.ai/openrouter/bodybuilder) на OpenRouter.

Действия:

- Чтобы добавить модель, нажмите **Добавить** или в любом месте записи.

- Чтобы удалить модель, нажмите **X** рядом с ней в разделе **Выбранные модели** или **Выбрано** в записи Доступные модели.

- Чтобы очистить список, нажмите **Снять выделение**. Обязательная бесплатная модель останется в списке.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Если вы не хотите сразу добавлять кредиты в OpenRouter, начните с включения **Только бесплатные** и выберите бесплатные модели (без необходимости указывать данные кредитной карты). Вы также можете использовать Ollama для запуска моделей локально без какого-либо API-ключа.

<a id="cost-tracking"></a>
### Отслеживание расходов

Используйте **Настройки** > **Отслеживание расходов**, чтобы управлять информацией о расходах.

- **Общая стоимость** показывает накопленный итог.
- **Копировать значение** копирует общую сумму в буфер обмена.
- **Сбросить стоимость** сбрасывает накопленную сумму до нуля.
- **Синхронизировать с использованием ключа API** устанавливает общую сумму в соответствии с данными использования, предоставленными вашей учётной записью OpenRouter (только OpenRouter).
- **Использование ключа API** показывает подробности использования OpenRouter, если доступно.
- **Удалить данные о стоимости** удаляет все данные или только записи, старше выбранной даты.

**Отслеживание расходов:** Когда вы используете модели OpenRouter, приложение показывает фактическое использование и расходы на основе данных о стоимости от OpenRouter. Для всех остальных провайдеров приложение оценивает расходы, используя цены, опубликованные OpenRouter; если цена недоступна, оценка может быть нулевой.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
>  **Все суммы расходов являются оценочными и приведены только для вашего сведения, а не являются официальными счетами.**

<br/>

> ⚠️ **ПРЕДУПРЕЖДЕНИЕ**<br/>
> Удаление данных не может быть отменено. Перед удалением обязательно создайте резервную копию данных или экспортируйте их через [**История**](#history) 
> или [**Панель мониторинга** > **Все вызовы**](#dashboard-tabs); в противном случае данные будут безвозвратно утеряны. 
> Будет также удалена вся история ввода и вывода, связанная с каждой записью вызова API.

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> В **резервные копии конфигурации** (см. [**Общие настройки** → Резервное копирование конфигурации](#general-settings)) могут быть включены **разрешённые** ключи провайдера внутри `config.json` архива ZIP. Восстановление этого архива ZIP **не** приводит к возврату этих ключей в постоянный конфигурационный файл сервера — действующие ключи по-прежнему берутся из среды и существующего состояния файла, как описано там.

<br/>

**Приложение для рабочего стола**

Используйте **Конфигурация API**, чтобы сохранять ключи API для каждого используемого провайдера. Для Ollama введите **базовый URL** вместо ключа API.

<br/>

> 💡 **Совет** <br/>
> Если вы не хотите использовать ключ API или платить за использование, вы можете [скачать Ollama](https://ollama.com) и запускать модели (например, `translategemma:4b`) локально на своём компьютере бесплатно. В качестве альтернативы вы можете создать бесплатную учётную запись OpenRouter (без необходимости указывать кредитную карту), чтобы использовать их бесплатные модели, или получить бесплатный ключ API от Cerebras, Google, Groq или Mistral AI.

<br/>

- Добавляйте только нужных провайдеров. В разделе **Настройки** > **Модели** каждый идентификатор модели начинается с провайдера (например, `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Чтобы добавить API-ключ, введите значение в текстовое поле и нажмите **`Save`**. Чтобы заменить существующий ключ, нажмите **`Edit`**. Чтобы проверить, работает ли ключ, нажмите **`Test`**. Для базового URL Ollama всегда нажимайте **`Test`**, чтобы проверить соединение.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Вы не можете увидеть текущее значение ключа API. Вы можете только заменить его с помощью кнопки **`Edit`**.
> Ключи API хранятся в зашифрованном виде в конфигурации.

<a id="common-issues"></a>
## Распространённые проблемы

Если что-то работает не так, как ожидалось, сначала проверьте следующие пункты.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Приложение не будет переводить, переписывать или трансформировать текст

Проверьте следующее:

- вы выбрали модель в панели инструментов
- хотя бы одна модель указана в разделе [**Настройки** > **Модели**](#models)
- ваша настройка API работает

Если вы используете настольное приложение:

1. Откройте [**Настройки** > **Конфигурация API**](#api-config).
2. Убедитесь, что хотя бы один API-ключ сохранён.
3. Нажмите **Тест** рядом с провайдером, чтобы подтвердить работоспособность ключа.

<br/>

<a id="the-model-list-is-empty"></a>
### Список моделей пуст

Откройте [**Настройки** > **Модели**](#models) и нажмите **Обновить**.

При необходимости:

- поиск модели
- включение **Только бесплатные**
- добавление одной или нескольких моделей в **Выбранные модели**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Результат слишком медленный или слишком дорогой

Попробуйте один или несколько из следующих вариантов:

- выберите другую модель
- используйте более короткий ввод
- отключите **Перевод в реальном времени (при вводе)** в разделе [**Настройки** > **Общие настройки**](#general-settings)
- используйте бесплатные модели для простых задач (см. [Модели](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Интерфейс на неправильном языке

Нажмите на значок глобуса на [панели инструментов](#toolbar) и выберите предпочитаемый язык **интерфейса**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Текст слишком мал или его трудно читать

Откройте [**Настройки** > **Общие настройки**](#general-settings) и измените:

- **Семейство шрифтов**
- **Размер**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Панель мониторинга: диаграммы пусты

Это нормально, если:

- вы используете только **бесплатные модели** и смотрите на показатели **стоимости** (они могут быть нулевыми); графики количества вызовов **использования** на вкладке **Сводка** всё равно требуют данных за выбранный период
- выбранный **фильтр времени** не охватывает период, когда были совершены вызовы — попробуйте **Все**, чтобы проверить

Если диаграммы по-прежнему пусты после выбора **Все**, убедитесь, что вызовы отображаются в разделе [**История**](#history) или на вкладке **Все вызовы**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Стоимость показывает «недоступно» или выглядит неправильно

Когда вы используете модели через **OpenRouter**, приложение отображает ваши фактические расходы, сообщаемые OpenRouter.

Для **других поставщиков** (OpenAI напрямую, Anthropic напрямую и т. д.) стоимость рассчитывается примерно на основе ценовых данных, опубликованных OpenRouter. Если для модели не будет найдена соответствующая цена, стоимость будет отображаться как **недоступна** и не будет добавлена в вашу итоговую сумму.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Общая стоимость не соответствует счету моего провайдера

Все цифры стоимости в приложении являются **оценочными и приведены только для справки**, а не официальными платежными документами.

Чтобы приблизить итоговую сумму к реальным расходам в OpenRouter, откройте [**Настройки** > **Отслеживание расходов**](#cost-tracking) и нажмите **Синхронизировать с использованием API-ключа**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Страница История отсутствует в боковой панели

**Сохранять историю выполнения** может быть отключено. Откройте [**Настройки** > **Общие настройки**](#general-settings) и включите эту опцию. Обратите внимание, что включение не восстанавливает ранее удалённые данные истории.

<br/>

<a id="web-app-session-expired"></a>
### Веб-приложение: неожиданно перенаправляется на страницу входа

Ваш сеанс мог истечь. Войдите снова. Если это происходит часто, проверьте настройки времени жизни сеанса в конфигурации сервера.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### Веб-администратор: забыт или утерян пароль

Это относится к **веб-приложению с самостоятельным размещением** (Docker), а не к настольному приложению (Electron).

- Если другой администратор может войти в систему, он может открыть [**Настройки** > **Пользователи**](#users), выбрать учётную запись и задать там **новый пароль**.
- Если вы **заблокированы**, но имеете **доступ к оболочке** машины или контейнера, сбросьте пароль с помощью вспомогательной утилиты, поставляемой с образом (замените `transrewrt`, если изменили имя по умолчанию, и заключите пароль в кавычки, если он содержит пробелы или специальные символы):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Имя пользователя по умолчанию — `admin`, если вы никогда не создавали другие учётные записи. Когда вы передаёте только один аргумент, он рассматривается как новый пароль для `admin`.

Если вы запускаете из **исходного кода**, а не из Docker, используйте:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

Скрипт обновляет запись пользователя в базе данных SQLite (и может создать пользователя `admin`, если он отсутствует). После сброса войдите в систему с новым паролем.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### Панель мониторинга не отображает данные для других пользователей (веб)

Только **администраторы** могут просматривать данные всех пользователей с помощью фильтра **Пользователь**. Обычные пользователи по замыслу видят только свою собственную активность.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Я изменил промпт и потерял правки

При редактировании промпта всегда нажимайте **Сохранить**, прежде чем нажимать **Назад к запуску**.

<br/><br/>

<a id="quick-tips"></a>
## Быстрые советы

- Начните с [**Перевести**](#translate), чтобы убедиться, что настройка работает, прежде чем переходить к [**Переформулировать**](#rewrite) или [**Преобразовать**](#transform).
- Используйте [**Переформулировать**](#rewrite) для повседневного улучшения формулировок.
- Используйте [**Преобразовать**](#transform), когда вам нужен повторяемый рабочий процесс для конкретной задачи.
- Используйте [**Панель мониторинга**](#dashboard), если хотите следить за использованием и стоимостью.
- Используйте [**Историю**](#history), чтобы просматривать прошлые операции и полные тексты ввода/вывода.
- Регулярно экспортируйте запросы, если вы создаете библиотеку запросов, которую хотите сохранить (см. [Преобразовать запросы](#transform-prompts)) или хотите поделиться ею с другими.
