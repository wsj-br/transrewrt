# Руководство пользователя

<br/>

<a id="introduction"></a>
## Введение

Transrewrt помогает работать с текстом тремя основными способами:

- **Перевод** — преобразование текста с одного языка на другой.
- **Перефразирование** — изменение текста в другом стиле, например, более ясный, краткий или формальный.
- **Преобразование** — обработка текста с помощью пользовательских инструкций для ИИ, называемых промптами.

<br/>

Это руководство объясняет, как использовать приложение после его установки и запуска. Пошаговую инструкцию по установке см. в основном файле **[README](README.ru.md)**.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Transrewrt доступен в виде приложения для ПК под Windows и Linux, а также как веб-приложение с самостоятельным размещением. В этом руководстве рассматривается повседневное использование приложения. Если какая-либо информация относится только к одной версии, это чётко указано.

<a id="before-you-start"></a>

## Перед началом работы

Чтобы использовать Transrewrt, вы должны иметь доступ хотя бы к одному поставщику ИИ. Поддерживаемые поставщики: [OpenRouter](https://openrouter.ai) (который объединяет множество моделей), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras и [Ollama](https://ollama.com) для локальных моделей.

Для начала не обязательно выбирать платную модель. Как только вы добавите свой API-ключ OpenRouter, приложение автоматически включает встроенную **бесплатную** опцию OpenRouter. Это позволяет сразу начать переводить, переписывать и преобразовывать текст. Кроме того, вы можете получить бесплатный API-ключ от Cerebras, Google, Groq или Mistral AI.

Простыми словами:

- **Модель** — это движок ИИ, выполняющий работу. Модели перечисляются с **префиксом поставщика** (например, `openrouter/…`, `openai/…`, `ollama/…`).
- **API-ключ** (или для Ollama — **базовый URL**) — это способ, которым приложение связывается с поставщиком.

Если вы используете **настольное приложение**, добавьте ключи в разделе [**Настройки** > **Настройка API**](#api-config) для каждого используемого поставщика. Если вы используете только OpenRouter, см. раздел [Как получить API-ключ](#how-to-get-an-api-key-desktop-app) ниже. Если вы не хотите использовать API-ключ, можно установить Ollama (с сайта [ollama.com](https://ollama.com)) и использовать локальные модели, например `translategemma:4b`.

Если вы используете **веб-версию**, администратор сервера настраивает поставщиков с помощью переменных окружения, поэтому вы не можете ввести API-ключи напрямую в приложении.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Как получить бесплатный API-ключ OpenRouter (настольное приложение)

Если вы используете настольное приложение, выполните следующие шаги:

1. Перейдите на сайт [OpenRouter](https://openrouter.ai) в вашем веб-браузере.
2. Создайте учётную запись или войдите в неё.
3. Перейдите на страницу [Keys](https://openrouter.ai/keys).
4. Нажмите кнопку для создания нового API-ключа.
5. Присвойте ключу имя, по которому вы сможете его распознать позже.
6. Скопируйте новый API-ключ.
7. Вернитесь в Transrewrt и откройте **Настройки** > **Настройка API**.
8. Вставьте ключ в поле **OpenRouter API key** (в разделе **Настройки** > **Настройка API**).
9. Нажмите **Test OpenRouter key**, чтобы убедиться, что он работает.

<a id="getting-started"></a>
## Начало работы

Если вы впервые используете Transrewrt, выполните следующие шаги по порядку:

1. Запустите приложение.
2. При необходимости измените **язык интерфейса**, нажав на значок глобуса.
3. Если вы используете **настольное приложение**, откройте [**Настройки** > **Настройка API**](#api-config), добавьте API-ключ по крайней мере для одного поставщика (например, OpenRouter) и нажмите **Test**, чтобы проверить его работоспособность.
4. Перейдите в [**Настройки** > **Модели**](#models) и добавьте одну или несколько моделей в **Выбранные модели**.
5. Перейдите в [**Настройки** > **Языки**](#languages) и выберите **Основные языки**, чтобы самые используемые языки отображались в первую очередь.
6. Перейдите на вкладку **Перевести** и выполните простой перевод, чтобы убедиться в работоспособности приложения.
7. После этого протестируйте функции **Переписать**, а затем — **Преобразовать**.

Очень важно соблюдать такой порядок. Он помогает избежать наиболее распространённой проблемы при первом использовании: попытки запустить задачу до того, как приложение установлено подключение к API или не выбрана модель.

### Панель инструментов

Панель инструментов немного меняется в зависимости от того, где вы находитесь в приложении.

- Слева отображается название текущей страницы.
- Справа находятся **выбор модели** и элемент управления **языком интерфейса**.

С помощью **выбора модели** можно выбрать, какой движок ИИ использовать для текущей задачи.

  ![Выбор модели](../images/screenshots/ru/model-selector.png)

Некоторые бесплатные модели могут быть недоступны — иногда они отключены или имеют ограничение по использованию. В таком случае приложение автоматически уберёт модель из вашего списка доступных. Чтобы управлять отображением моделей, перейдите в раздел [**Настройки** > **Модели**](#models) и отредактируйте список моделей.  
Также вы можете открыть настройки модели напрямую, нажав на значок провайдера слева от названия модели на панели инструментов.

<br/>

**Значок земного шара и код языка** позволяют изменить язык интерфейса приложения, например, меню и кнопки. Однако это **не влияет** на языки перевода, используемые в режиме **Перевод**.

  ![Выбор языка интерфейса](../images/screenshots/ru/language-selector.png)

<a id="input-and-output-panels"></a>
### Панели ввода и вывода

Большинство рабочих пространств используют левую панель **Ввод** и правую панель **Вывод**.

Каждая панель показывает следующее:

| **Ввод**                                                          | **Вывод**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Количество символов <br/>- Количество слов <br/>- Количество абзацев   <br/> | - Сколько времени заняла операция<br/>- **TPS** (токенов в секунду)<br/>- Количество символов, слов и абзацев<br/>- Используемая модель |


Если вы задаётесь вопросом о технических терминах:

- **Токен** — небольшой фрагмент текста. Его можно представить как часть слова или короткое слово.
- **TPS** — количество таких фрагментов текста, обрабатываемых моделью за секунду.

<br/>

Вы также можете отслеживать стоимость каждой операции (если данные доступны) и итоговую стоимость, включив параметр `Показывать информацию о стоимости операций` в разделе [**Настройки** > **Основные настройки**](#general-settings).

<a id="translate"></a>
## Перевод

Используйте режим **Перевод**, когда хотите перевести текст с одного языка на другой.

![Рабочее пространство Перевод](../images/screenshots/ru/translate.png)

<br/>

<a id="translate-text"></a>
### Перевод текста

1. Откройте **Перевод**.
2. Выберите язык в поле **С**.
3. Выберите язык в поле **На**.
4. Выберите модель на панели инструментов.
5. Введите или вставьте текст в поле **Ввод**.
6. Нажмите **Перевести**.
7. Прочитайте результат в поле **Вывод**.
8. Нажмите кнопку копирования, если хотите скопировать результат.

<br/>

<a id="language-selection"></a>
### Выбор языка

- В поле **С** может быть указан конкретный язык или **Определить язык**.
- В поле **На** — язык, на который вы хотите перевести.

Ваши выбранные **основные языки** отображаются в начале списка. Вы можете настроить их в [**Настройки** > **Языки**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Полезные настройки перевода

В разделе [**Настройки** > **Основные настройки**](#general-settings) можно изменить поведение перевода:

- **Автоматический перевод при вставке** — перевод запускается сразу после вставки текста.
- **Автоматически копировать результат в буфер обмена** — результат копируется после успешного выполнения.
- **Перевод в реальном времени (во время ввода)** — перевод выполняется по мере ввода текста.
- **Задержка (мс)** — время, в течение которого приложение ждёт перед запуском перевода в реальном времени.
- **Enter** — определяет действие при нажатии клавиши `Enter`:

## Перефразирование

Используйте **Перефразирование**, когда нужно улучшить формулировку, не меняя основного смысла.

> Нажмите её, чтобы включить или отключить отображение исправлений — показать или скрыть конкретные изменения в тексте.

<a id="transform"></a>

## Преобразование

Используйте **Преобразование**, когда хотите, чтобы ИИ следовал собственным инструкциям.

![Рабочая область Преобразования](../images/screenshots/ru/transform.png)

Это наиболее гибкая часть приложения. Её можно использовать для задач, таких как:

- создание резюме заметок
- превращение чернового текста в отредактированное письмо
- выделение ключевых моментов
- преобразование текста в определённый формат
- любые другие пользовательские операции с исходным текстом

<br/>

<a id="run-an-existing-prompt"></a>
### Запуск существующего промпта

1. Откройте **Преобразование**.
2. Выберите промпт из списка промптов.
3. Если появится поле **Целевой язык**, выберите нужный язык.
4. Введите или вставьте текст в поле **Ввода**.
5. Нажмите **Преобразовать**.
6. Прочитайте результат в поле **Вывода**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### Если у вас пока нет промптов

Если ваш список промптов пуст, нажмите **Загрузить примеры промптов**. Будут добавлены встроенные примеры, чтобы вы могли начать быстро.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Примеры промптов представлены на английском языке. После загрузки вы можете отредактировать промпт и использовать **Перевести промпт**, чтобы перевести его на свой язык.

<br/>

<a id="create-a-prompt-quickly"></a>
### Быстрое создание промпта

Самый быстрый способ создания промпта:

1. Нажмите **Новый промпт**.
2. Нажмите **Создать промпт**.
3. Опишите, что вы хотите, чтобы делал промпт.
4. Выберите модель.

### Редактирование промпта

Когда вы создаете или редактируете промпт, редактор появляется слева, а справа — область тестирования.

![Редактор промптов Преобразования](../images/screenshots/ru/transform-prompt-edit.png)

Основные поля:

- **Название промпта**: отображаемое имя в списке промптов.

<a id="general-settings"></a>
### Общие настройки

Используйте **Общие настройки**, чтобы управлять поведением при вводе текста, сохранением деталей выполнения для **Истории** и внешним видом.

**Поведение**

- **Действие клавиши Enter** определяет, будет ли клавиша `Enter` запускать задачу или создавать новую строку.
- **Автоматический перевод при вставке** запускает перевод сразу после вставки текста.
- **Автоматически копировать результат в буфер** автоматически копирует успешные результаты.
- **Перевод в реальном времени (при вводе)** выполняет перевод во время ввода текста.
- **Таймаут (мс)** задаёт время ожидания для перевода в реальном времени.

**История**

- **Сохранять историю выполнения** определяет, сохраняются ли **входной и выходной текст** для каждого перевода, переписывания и преобразования в **Истории** на боковой панели. Отключение этой опции требует подтверждения; в случае подтверждения сохранённый текст удалится из базы данных.
- **Удалить данные истории** позволяет удалять сохранённые тексты по возрасту (например, старше нескольких месяцев, или **все данные (очистить)**) с помощью кнопки **Удалить данные**. Это затрагивает только сохранённые тексты выполнения для просмотра **Истории**; **не удаляет** данные о стоимости или общие итоги. Чтобы удалить или сократить данные о **затратах**, используйте [**Настройки** > **Отслеживание затрат**](#cost-tracking).

**Внешний вид**

- **Показывать информацию о стоимости в действиях** отображает стоимость одной операции (если доступно) и общую стоимость на панелях вывода Перевода, Переписывания и Преобразования.
- **Количество знаков после запятой у стоимости** устанавливает, сколько десятичных знаков отображается у стоимостей.
- **Только веб:** **показывать поля вокруг приложения** добавляет дополнительные отступы вокруг интерфейса.
- **Шрифт** меняет шрифт текста в панелях ввода.
- **Размер** меняет размер шрифта.

### Модели

Используйте **Настройки** > **Модели**, чтобы выбрать, какие модели будут отображаться на панели инструментов.

![Вкладка настроек моделей](../images/screenshots/ru/settings-models.png)

На странице два списка:

- **Доступные модели** — слева
- **Выбранные модели** — справа

Полезные элементы управления:

- **Поиск моделей...** — для поиска модели по названию
- **Фильтры провайдеров** — для сужения списка до одной платформы (OpenRouter, OpenAI, Ollama и др.)
- **Только бесплатные** — показывать только бесплатные модели
- **Обновить** — перезагрузить список
- **Развернуть всё** и **Свернуть всё** — при сортировке по провайдерам

Идентификаторы моделей содержат префикс провайдера (например, `openrouter/…` или `openai/…`). Бейджи, такие как **OpenAI (OpenRouter)** и **OpenAI (напрямую)**, показывают, как маршрутизируется трафик.

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) — это маршрутизирующая модель, а не универсальная чат-модель: её ответ — это JSON, описывающий тело запроса к API OpenRouter (например, массив `requests` с полями `model` и `messages`). При использовании в функциях **Translate**, **Rewrite** или **Transform** на панели вывода будет отображаться именно этот JSON, а не готовый текст. Для этих операций выбирайте обычную текстовую модель. Подробнее на [странице модели Body Builder](https://openrouter.ai/openrouter/bodybuilder) на OpenRouter.

Действия:

 - Чтобы добавить модель, нажмите **Добавить** или в любом месте записи.

 - Чтобы удалить модель, нажмите **X** рядом с ней в списке **Выбранные модели** или **Выбрано** в записи в списке доступных моделей.

 - Чтобы очистить список, нажмите **Отменить все**. Обязательная бесплатная модель останется в списке.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Если вы не хотите сразу добавлять средства на OpenRouter, начните с активации опции **Только бесплатные** и выбора бесплатных моделей (без необходимости указывать карту). Вы также можете использовать Ollama для локального запуска моделей без использования API-ключа.

<a id="cost-tracking"></a>
### Отслеживание расходов

Используйте **Настройки** > **Отслеживание расходов** для управления информацией о затратах.

- **Общая стоимость** — показывает накопленную сумму.
- **Копировать значение** — копирует сумму в буфер обмена.
- **Сбросить расходы** — обнуляет сохранённую сумму.
- **Синхронизировать с использованием API-ключа** — устанавливает сумму в соответствии с данными использования в вашей учётной записи OpenRouter (только OpenRouter).

**Отслеживание расходов**: при использовании моделей OpenRouter приложение показывает точные данные об использовании и расходах на основе информации от OpenRouter. Для всех других провайдеров приложение рассчитывает расходы с помощью цен, опубликованных OpenRouter; если цена недоступна, оценка может быть нулевой.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> **Все суммы являются оценочными и предоставляются исключительно для вашего удобства, а не являются официальными счетами.**

<br/>

> ⚠️ **ВНИМАНИЕ**<br/>
> Удаление данных необратимо. Перед удалением обязательно сделайте резервную копию или экспортируйте данные через раздел [**История**](#history)

<a id="api-config"></a>
### Конфигурация API

Поддерживаются следующие провайдеры: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, и **Ollama** (локальные модели через базовый URL). Настройте только те провайдеры, которые вы планируете использовать.

**Веб-приложение: только для администратора**

API-ключи настраиваются через системные или Docker-переменные окружения — они не вводятся в веб-интерфейсе. Эта страница показывает, для каких провайдеров задан ключ, и позволяет протестировать каждый из них кнопкой **`Тест`**.

<br/>

**Десктопное приложение**

Используйте **Конфигурацию API**, чтобы сохранять API-ключи для каждого используемого провайдера. Для Ollama введите **базовый URL**, а не API-ключ.

<br/>

> 💡 **Совет** <br/>
> Если вы не хотите использовать API-ключ или платить за использование, вы можете [установить Ollama](https://ollama.com) и бесплатно запускать модели (например, `translategemma:4b`) локально на своём компьютере. Альтернативно, вы можете зарегистрировать бесплатную учётную запись OpenRouter (без указания карты) и использовать их бесплатные модели, либо получить бесплатный API-ключ от Cerebras, Google, Groq или Mistral AI.

<br/>

- Добавляйте только необходимых провайдеров. В разделе **Настройки** > **Модели** идентификатор каждой модели начинается с названия провайдера (например, `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Чтобы добавить API-ключ, введите значение в текстовое поле и нажмите **`Сохранить`**. Чтобы заменить существующий ключ, нажмите **`Редактировать`**. Чтобы проверить, работает ли ключ, нажмите **`Тест`**. Для базового URL Ollama обязательно нажмите **`Тест`**, чтобы проверить подключение.

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Текущее значение API-ключа просмотреть невозможно. Вы можете только заменить его, используя кнопку **`Редактировать`**.

<a id="common-issues"></a>
## Типичные проблемы

Если что-то работает не так, как ожидается, сначала проверьте следующие моменты.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Приложение не переводит, не переписывает и не преобразует текст

Убедитесь, что:

- выбрана модель в панели инструментов
- хотя бы одна модель указана в разделе [**Настройки** > **Модели**](#models)
- настройки API работают корректно

Если вы используете настольное приложение:

1. Откройте [**Настройки** > **Конфигурация API**](#api-config).
2. Убедитесь, что хотя бы один API-ключ сохранён.
3. Нажмите **Тест** рядом с провайдером, чтобы проверить, работает ли ключ.

<br/>

<a id="the-model-list-is-empty"></a>
### Список моделей пуст

Откройте [**Настройки** > **Модели**](#models) и нажмите **Обновить**.

При необходимости:

- выполните поиск модели
- включите опцию **Только бесплатные**
- добавьте одну или несколько моделей в **Выбранные модели**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Результат слишком медленный или слишком дорогой

Попробуйте одно или несколько действий:

- выберите другую модель
- используйте более короткий ввод
- отключите **Перевод в реальном времени (при вводе)** в разделе [**Настройки** > **Основные настройки**](#general-settings)
- используйте бесплатные модели для простых задач (см. [Модели](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Интерфейс отображается не на том языке

Нажмите на значок глобуса в [панели инструментов](#toolbar) и выберите желаемый **язык интерфейса**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Текст слишком мал или плохо читается

Откройте [**Настройки** > **Основные настройки**](#general-settings) и измените:

- **Семейство шрифтов**
- **Размер**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Диаграммы на панели управления пустые

Это нормально, если:

- используются только **бесплатные модели** (диаграммы расходов будут пустыми)
- выбранный **фильтр времени** не охватывает период, в котором были совершены запросы — попробуйте значение **Всё**, чтобы проверить

Если диаграммы остаются пустыми даже после выбора **Всё**, проверьте, отображаются ли запросы в разделе [**История**](#history) или на вкладке **Все запросы**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### Стоимость отображается как «недоступна» или выглядит некорректной

Если вы используете модели через **OpenRouter**, в приложении отображается реальная сумма, предоставленная OpenRouter.

Для **других провайдеров** (прямые OpenAI, Anthropic и т.д.), стоимость оценивается на основе цен, опубликованных OpenRouter. Если цена модели не найдена, стоимость будет показана как **недоступна** и не будет включаться в общий итог.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Общая стоимость не совпадает со счётом провайдера

Все значения стоимости в приложении являются **оценочными и приведены только для справки**, а не официальными счетами.

Чтобы общая сумма была ближе к реальным затратам в OpenRouter, откройте [**Настройки** > **Отслеживание расходов**](#cost-tracking) и нажмите **Синхронизировать с использованием API-ключа**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Страница История отсутствует в боковой панели

Возможно, отключена опция **Сохранять историю выполнения**. Откройте [**Настройки** > **Основные настройки**](#general-settings) и включите её. Учтите, что включение этой опции не восстанавливает ранее удалённые данные.

<br/>

<a id="web-app-session-expired"></a>
### Веб-приложение: неожиданный переход на страницу входа

Ваша сессия могла истечь по времени. Повторно войдите в систему. Если это происходит часто, проверьте настройки конфигурации сервера для управления временем жизни сессии.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### На панели управления нет данных по другим пользователям (веб-версия)

Только **администраторы** могут просматривать данные всех пользователей с помощью фильтра **Пользователь**. Обычные пользователи по умолчанию видят только свою активность.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Я изменил промпт и потерял редактирование

При редактировании промпта всегда нажимайте **Сохранить**, прежде чем нажать **Назад к запуску**.

<br/><br/>

<a id="quick-tips"></a>
## Быстрые советы

- Начните с [**Перевода**](#translate), чтобы убедиться, что ваша настройка работает, прежде чем переходить к [**Перефразированию**](#rewrite) или [**Преобразованию**](#transform).
- Используйте [**Перефразирование**](#rewrite) для ежедневного улучшения формулировок.
- Используйте [**Преобразование**](#transform), когда вам нужен повторяемый рабочий процесс для конкретной задачи.
- Используйте [**Панель управления**](#dashboard), если хотите отслеживать использование и расходы.
- Используйте [**Историю**](#history), чтобы просматривать прошлые операции и полные тексты ввода/вывода.
- Регулярно экспортируйте промпты, если вы создаёте библиотеку промптов, которые хотите сохранить, или передать другим (см. [Промпты преобразования](#transform-prompts)).
