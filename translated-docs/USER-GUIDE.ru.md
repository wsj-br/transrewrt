# Руководство пользователя

<br/>

<a id="introduction"></a>
## Введение

Transrewrt помогает работать с текстом тремя основными способами:

- **Перевод** — преобразование текста с одного языка на другой.
- **Перефразирование** — изменение формулировки текста в другом стиле, например, более ясно, кратко или формально.
- **Преобразование** — обработка текста с помощью пользовательских инструкций для ИИ, называемых «запросы» (prompts).

<br/>

Это руководство объясняет, как использовать приложение после его установки и запуска. Пошаговые инструкции по установке см. в основном файле **[README](README.ru.md)**.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Трансреуерт доступен как настольное приложение для Windows и Linux, а также как веб-приложение с самостоятельным размещением. Это руководство посвящено повседневному использованию приложения. Если какая-то функция относится только к одной из версий, это будет чётко указано.

<a id="before-you-start"></a>

## Перед началом работы

Чтобы использовать Transrewrt, вам необходим доступ хотя бы к одному поставщику ИИ. Поддерживаемые поставщики: [OpenRouter](https://openrouter.ai) (объединяет множество моделей), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI и [Ollama](https://ollama.com) для локальных моделей.

Для начала работы не обязательно выбирать платную модель. Как только вы добавите свой API-ключ OpenRouter, приложение автоматически активирует встроенный **бесплатный** вариант OpenRouter. Это позволит сразу приступить к переводу, переписыванию и преобразованию текста.

Простыми словами:

- **Модель** — это движок ИИ, выполняющий работу. Модели перечисляются с **префиксом поставщика** (например, `openrouter/…`, `openai/…`, `ollama/…`).
- **API-ключ** (или для Ollama — **базовый URL**) — это способ, которым приложение обращается к поставщику.

Если вы используете **настольное приложение**, добавьте ключи в разделе [**Настройки** > **Конфигурация API**](#api-config) для каждого используемого вами поставщика. При использовании только OpenRouter смотрите ниже раздел [Как получить API-ключ](#how-to-get-an-api-key-desktop-app). Если вы не хотите использовать API-ключ, вместо этого вы можете установить Ollama (с сайта [ollama.com](https://ollama.com)) и использовать локальные модели.

Если вы используете **веб-версию**, администратор сервера настраивает поставщиков с помощью переменных окружения, поэтому, как правило, вводить API-ключи вам не нужно.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### Как получить бесплатный API-ключ OpenRouter (настольное приложение)

Если вы используете настольное приложение, выполните следующие действия:

1. Перейдите на сайт [OpenRouter](https://openrouter.ai) в вашем веб-браузере.
2. Создайте аккаунт или войдите в систему.
3. Откройте страницу [Keys](https://openrouter.ai/keys).
4. Нажмите кнопку для создания нового API-ключа.
5. Присвойте ключу имя, чтобы вы могли распознать его позже.
6. Скопируйте новый API-ключ.
7. Вернитесь в Transrewrt и откройте **Настройки** > **Конфигурация API**.
8. Вставьте ключ в поле **OpenRouter API key** (в разделе **Настройки** > **Конфигурация API**).
9. Нажмите **Test OpenRouter key**, чтобы убедиться, что он работает.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Вы можете начать с бесплатного тарифа OpenRouter или любой другой бесплатной модели, не указывая банковскую карту. Во многих случаях этого достаточно для начала использования Transrewrt без выбора платной модели. Альтернативно, вы можете использовать Ollama, чтобы запускать модели локально без API-ключа.

<br/><br/>

<a id="getting-started"></a>
## Начало работы

Если вы пользуетесь Transrewrt впервые, соблюдайте следующую последовательность действий:

1. Запустите приложение.
2. При необходимости выберите **язык интерфейса** с помощью значка земного шара.
3. Если вы используете **настольное приложение**, откройте [**Настройки** > **Конфигурация API**](#api-config), добавьте API-ключ хотя бы одного поставщика (например, OpenRouter) и нажмите **Test**, чтобы убедиться в его работоспособности.
4. Откройте [**Настройки** > **Модели**](#models) и добавьте одну или несколько моделей в раздел **Выбранные модели**.
5. Откройте [**Настройки** > **Языки**](#languages) и выберите **Основные языки**, если хотите, чтобы ваши наиболее часто используемые языки отображались первыми.
6. Перейдите в **Перевод** и выполните простой перевод, чтобы проверить работу всего приложения.
7. После успешного перевода попробуйте **Переписать** и затем **Преобразовать**.

Эта последовательность важна. Она помогает избежать наиболее распространённой неполадки при первом использовании: попытки выполнить задачу до настройки рабочего API-подключения или выбора модели.

### Панель инструментов

Внешний вид панели инструментов незначительно меняется в зависимости от того, где вы находитесь в приложении.

- Слева отображается название текущей страницы.
- Справа находятся **выбор модели** и элемент управления **языком интерфейса**.

С помощью **выбора модели** можно указать, какой ИИ-движок использовать для текущей задачи.

  ![Выбор модели](../images/screenshots/ru/model-selector.png)

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Некоторые бесплатные модели могут быть недоступны — иногда они отключены или имеют ограниченное использование. В таком случае приложение автоматически удалит их из доступного списка.<br/>
> Чтобы управлять отображаемыми моделями, перейдите в раздел [**Настройки** > **Модели**](#models) и измените ваш список моделей.  
> Вы также можете открыть настройки модели напрямую, щёлкнув по значку провайдера слева от имени модели на панели инструментов.

<br/>

Элемент **значок глобуса + код языка** изменяет язык интерфейса приложения, например, меню и кнопки. Он **не** влияет на языки перевода, используемые в модуле **Перевести**.

  ![Выбор языка интерфейса](../images/screenshots/ru/language-selector.png)

<a id="input-and-output-panels"></a>
### Панели ввода и вывода

Большинство рабочих областей используют левую панель **Ввод** и правую панель **Вывод**.

На панели **Ввод** отображается:

- Количество символов
- Количество слов
- Количество абзацев

На панели **Вывод** может отображаться:

- Время выполнения задачи
- Стоимость задачи (если имеется)
- Общая накопленная стоимость
- **TPS** (токены в секунду)
- Количество символов, слов и абзацев
- Используемая модель

Если вы не знакомы с терминологией:

- **Токен** — небольшой фрагмент текста. Его можно представить как часть слова или короткое слово.
- **TPS** — количество таких фрагментов текста, обрабатываемых моделью в секунду.

<a id="translate"></a>
## Перевести

Используйте функцию **Перевести**, если нужно преобразовать текст с одного языка на другой.

![Рабочая область Перевести](../images/screenshots/ru/translate.png)

<br/>

<a id="translate-text"></a>
### Перевод текста

1. Откройте **Перевести**.
2. Выберите язык в поле **С**.
3. Выберите язык в поле **На**.
4. Выберите модель на панели инструментов.
5. Введите или вставьте текст в поле **Ввод**.
6. Нажмите **Перевести**.
7. Прочитайте результат в поле **Вывод**.
8. Используйте кнопку копирования, если хотите скопировать результат.

<br/>

<a id="language-selection"></a>
### Выбор языков

- **С** может быть конкретным языком или **Определить язык**.
- **На** — язык, на который нужно перевести текст.

Выбранные вами **основные языки** появляются в начале списка. Вы можете задать их в разделе [**Настройки** > **Языки**](#languages).

<br/>

<a id="helpful-translation-settings"></a>
### Полезные настройки перевода

В разделе [**Настройки** > **Основные настройки**](#general-settings) можно настроить поведение перевода:

- **Переводить при вставке** автоматически запускает перевод сразу после вставки текста.
- **Автоматически копировать результат в буфер обмена** копирует результат после успешного выполнения.
- **Перевод в реальном времени (во время ввода)** запускает перевод по мере ввода текста.
- **Таймаут (мс)** задаёт задержку перед запуском перевода в режиме реального времени.

<br/>

<a id="keyboard-shortcuts"></a>
### Горячие клавиши

В разделе [**Настройки** > **Основные настройки**](#general-settings), опция **Поведение клавиши ENTER** определяет, что произойдёт при нажатии `Enter`:

- **Enter** может запускать задачу, а **Shift+Enter** — добавлять новую строку.
- Или наоборот.

Текущий режим также отображается на кнопке **Перевести**.

<a id="rewrite"></a>
## Переписать

Используйте функцию **Переписать**, если хотите улучшить формулировку без изменения основного смысла.

![Рабочая область Переписать](../images/screenshots/ru/rewrite.png)

Полезно для:

- исправления орфографии и грамматики
- упрощения текста
- придания тексту более формального или разговорного стиля
- сокращения или расширения текста
- придания тексту более технического характера

<br/>

<a id="rewrite-text"></a>

### Переписать текст

1. Откройте **Переписать**.
2. Выберите **Режим**.
3. Выберите модель на панели инструментов.
4. Введите текст или вставьте его в поле **Ввод**.
5. Нажмите **Переписать**.
6. Проверьте результат в поле **Вывод**.


То же поведение клавиши Enter, описанное в разделе [**Перевод**](#keyboard-shortcuts), действует и здесь.

<br/>

> 💡 **СОВЕТ**<br/>
> При использовании режима "**Проверка орфографии и грамматики**" в панели вывода появляется кнопка `Показать изменения`.
> Нажмите её, чтобы переключить отображение исправлений — показать или скрыть конкретные изменения, внесённые в ваш текст.

<a id="transform"></a>
## Преобразование

Используйте **Преобразование**, когда хотите, чтобы ИИ следовал вашим собственным инструкциям.

![Рабочая область «Преобразование»](../images/screenshots/ru/transform.png)

Это самая гибкая часть приложения. Её можно использовать для таких задач, как:

- краткое изложение заметок
- превращение чернового текста в отредактированное письмо
- выделение ключевых моментов
- преобразование текста в определённый формат

<br/>

<a id="run-an-existing-prompt"></a>
### Запуск существующего запроса

1. Откройте **Преобразование**.
2. Выберите запрос из списка запросов.
3. Если появляется поле **Целевой** язык, выберите нужный язык.
4. Введите текст или вставьте его в поле **Ввод**.
5. Нажмите **Преобразовать**.
6. Прочитайте результат в поле **Вывод**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### Если у вас ещё нет запросов

### Редактирование запроса

При создании или редактировании запроса редактор появляется слева, а область тестирования — справа.

![Редактор запроса в «Преобразовании»](../images/screenshots/ru/transform-prompt-edit.png)

Основные поля:

- **Название запроса**: название, отображаемое в списке запросов.
- **Инструкции к запросу (необязательно)**: краткая подсказка, отображаемая пользователю при запуске запроса.
- **Роль модели**: общая роль, назначаемая ИИ, например, «Вы — полезный помощник».
- **Инструкции модели (по одной на строку)**: конкретные правила, которым должен следовать ИИ.
- **Описание вывода**: краткое слово, описывающее результат, например «резюме» или «переписано».
- **Температура (0.0 → 1.0)**: степень творческого поведения модели; см. ниже.
- **Спрашивать целевой язык**: добавляет выбор целевого языка при запуске запроса.

Если технический термин **Температура** вам незнаком, представьте его следующим образом:

- **Низкое** значение температуры даёт более стабильные и предсказуемые результаты.
- **Высокое** значение температуры даёт больше разнообразия и творчества.

Вы также можете использовать:

- **`Создать запрос`**, чтобы сгенерировать черновик на основе простого описания
- **`Улучшить запрос`**, чтобы усовершенствовать существующий запрос
- **`Перевести запрос`**, чтобы перевести поля запроса

<br/>

> ⚠️ **ВНИМАНИЕ**<br/>
> Перед тем как нажать **`Назад к запуску`**, обязательно нажмите **`Сохранить`**. Если вы вернётесь назад без сохранения, все изменения будут потеряны.

<a id="general-settings"></a>

### Общие настройки

Используйте **Общие настройки**, чтобы управлять поведением при вводе текста, сохранением данных выполнения в **Истории** и внешним видом приложения.

**Поведение**

- **Действие клавиши ВВОД** определяет, будет ли клавиша `Enter` запускать задачу или вставлять новую строку.
- **Автоматический перевод при вставке** запускает перевод сразу после вставки текста.
- **Автоматическое копирование результата в буфер обмена** автоматически копирует успешные результаты.
- **Перевод в реальном времени (во время ввода)** переводит текст по мере его набора.
- **Таймаут (мс)** задаёт время ожидания перед переводом в режиме реального времени.

**История**

- **Сохранять историю выполнения** определяет, будут ли сохраняться **исходный и результирующий текст** для каждого перевода, переписывания и преобразования в боковой панели [**История**](#history). При отключении этой опции появится запрос на подтверждение; при подтверждении сохранённые данные будут удалены из базы.
- **Удалить данные истории** позволяет удалять сохранённые тексты по возрасту (например, старше нескольких месяцев) или **все данные (очистить)** с помощью кнопки **Удалить данные**. Это влияет только на сохранённые тексты выполнения для просмотра в разделе **История**; **не удаляются** данные о затратах или общая статистика использования. Чтобы удалить или очистить данные о **затратах**, используйте [**Настройки** > **Учёт затрат**](#cost-tracking).

**Внешний вид**

- **Число знаков после запятой у стоимости** изменяет отображение десятичных разрядов затрат.
- **Только веб:** **Показывать поля вокруг приложения** добавляет дополнительные отступы вокруг интерфейса.
- **Семейство шрифтов** изменяет шрифт в текстовых областях.
- **Размер** изменяет размер шрифта.

### Модели

Используйте **Настройки** > **Модели**, чтобы выбрать, какие модели будут отображаться на панели инструментов.

![Вкладка моделей в настройках](../images/screenshots/ru/settings-models.png)

Страница содержит два списка:

- **Доступные модели** слева
- **Выбранные модели** справа

Полезные элементы управления:

- **Поиск моделей...** — поиск по названию
- Фильтры **Провайдер** — для сужения списка до конкретного провайдера (OpenRouter, OpenAI, Ollama и др.)
- **Только бесплатные** — отображение только бесплатных моделей
- **Обновить** — перезагрузка списка
- **Развернуть всё** и **Свернуть всё** — удобны при сортировке по провайдерам

Идентификаторы моделей включают префикс провайдера (например, `openrouter/…` или `openai/…`). Метки, такие как **OpenAI (OpenRouter)** и **OpenAI (напрямую)**, показывают, как будет маршрутизироваться трафик.

Действия:

 - Чтобы добавить модель, нажмите **Добавить** или коснитесь любой части элемента списка.

 - Чтобы удалить модель, нажмите **X** рядом с ней в списке **Выбранных моделей** или **Выбрано** в списке доступных моделей.

 - Чтобы очистить список, нажмите **Отменить все выборы**. Обязательная бесплатная модель останется в списке.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Если вы не хотите сразу пополнять баланс OpenRouter, начните с включения опции **Только бесплатные** и выберите бесплатные модели (без указания кредитной карты). Вы также можете использовать Ollama для запуска моделей локально, без ключа API.

<a id="cost-tracking"></a>
### Учёт затрат

Используйте **Настройки** > **Учёт затрат**, чтобы управлять информацией о затратах.

- **Общая стоимость** показывает накопленную сумму.
- **Копировать значение** копирует общую сумму в буфер обмена.
- **Сбросить стоимость** обнуляет накопленную сумму.
- **Синхронизировать с использованием ключа API** устанавливает сумму в соответствии с данными использования, предоставляемыми вашей учётной записью OpenRouter (только OpenRouter).
- **Использование ключа API** показывает подробности использования OpenRouter, если доступно.
- **Удалить данные о затратах** удаляет все данные или только записи, старше выбранной даты.

**Учёт затрат:** При использовании моделей OpenRouter приложение показывает фактическое использование и расходы на основе данных от OpenRouter. Для всех остальных провайдеров приложение оценивает затраты на основе цен, опубликованных OpenRouter. Если цена недоступна, оценка может быть нулевой.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Все данные о стоимости являются приблизительными и предоставляются исключительно для справки. Они **не являются официальными счетами-фактурами**.

<br/>

> ⚠️ **ПРЕДУПРЕЖДЕНИЕ**<br/>
> Удалённые данные восстановить невозможно. Перед удалением обязательно сделайте резервную копию данных или экспортируйте их через [**Панель управления** > **Все вызовы**](#dashboard-tabs), иначе данные будут безвозвратно утеряны. <br/> 
> Удаляются также все исторические данные, связанные с каждым вызовом API.

<a id="api-config"></a>
### Конфигурация API

Поддерживаемые провайдеры: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI и **Ollama** (локальные модели через базовый URL). Настройте только тех провайдеров, которых вы используете.

**Веб-приложение: доступно только администратору**

Ключи API задаются через системные переменные среды или переменные среды Docker — они не вводятся в веб-интерфейсе. На этой странице отображается, для каких провайдеров задан ключ, а также можно проверить подключение к каждому из них, нажав кнопку **`Тест`**.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Чтобы изменить ключ API, отредактируйте переменную среды в конфигурации вашей системы или Docker и перезапустите сервер или контейнер.

<br/>

**Настольное приложение**

Используйте **Конфигурацию API**, чтобы хранить ключи API для каждого используемого провайдера. Для Ollama введите **базовый URL** вместо ключа API.

<br/>

> 💡 **Совет** <br/>
> Если вы не хотите использовать ключ API или платить за использование, вы можете [скачать Ollama](https://ollama.com) и бесплатно запускать модели локально на своём компьютере. Также можно создать бесплатную учётную запись OpenRouter (карта не требуется) и использовать их бесплатные модели.

- Добавляйте только тех провайдеров, которые вам нужны. В разделе **Настройки** > **Модели** каждое имя модели начинается с названия провайдера (например, `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Чтобы добавить ключ API, введите его значение в текстовое поле и нажмите **`Сохранить`**. Чтобы заменить существующий ключ, нажмите **`Изменить`**. Чтобы проверить работоспособность ключа, нажмите **`Тест`**.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Вы не можете увидеть текущее значение ключа API. Вы можете только заменить его с помощью кнопки **`Изменить`**.
> Ключи API хранятся в зашифрованном виде в конфигурационном файле.

<br/>

Подробные инструкции по получению ключа OpenRouter см. выше в разделе [Как получить ключ API](#how-to-get-an-api-key-desktop-app).

<a id="common-issues"></a>
## Частые проблемы

Если что-то работает не так, как ожидалось, проверьте сначала следующие моменты.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### Приложение не переводит, не переписывает и не преобразует текст

Проверьте следующее:

- выбрана ли модель в панели инструментов
- есть ли хотя бы одна модель в списке [**Настройки** > **Модели**](#models)
- работает ли настройка API

Если вы используете настольное приложение:

1. Откройте [**Настройки** > **Конфигурация API**](#api-config).
2. Убедитесь, что хотя бы один ключ API сохранён.
3. Нажмите **Тест** рядом с провайдером, чтобы подтвердить, что ключ работает.

<br/>

<a id="the-model-list-is-empty"></a>
### Список моделей пуст

Откройте [**Настройки** > **Модели**](#models) и нажмите **Обновить**.

При необходимости:

- выполните поиск модели
- включите опцию **Только бесплатные**
- добавьте одну или несколько моделей в **Выбранные модели**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### Результат слишком медленный или дорогостоящий

Попробуйте один или несколько следующих способов:

- выберите другую модель
- используйте более короткий ввод
- отключите опцию **Перевод в реальном времени (во время ввода)** в разделе [**Настройки** > **Общие настройки**](#general-settings)
- используйте бесплатные модели для простых задач (см. [Модели](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### Интерфейс отображается на неправильном языке

Нажмите на значок земного шара в [панели инструментов](#toolbar) и выберите нужный **язык интерфейса**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### Текст слишком мелкий или его трудно читать

Откройте [**Настройки** > **Общие настройки**](#general-settings) и измените:

- **Семейство шрифтов**
- **Размер**

<br/>

<a id="dashboard-charts-are-empty"></a>
### Диаграммы на панели статистики пустые

Это нормально, если:

- вы используете только **бесплатные модели** (графики затрат будут пустыми)
- выбранный **фильтр по времени** не охватывает период, когда выполнялись запросы — попробуйте фильтр **Всё**, чтобы проверить

Если после выбора **Всё** диаграммы остаются пустыми, убедитесь, что запросы отображаются в разделе [**История**](#history) или на вкладке **Все вызовы**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### Стоимость отображается как «не доступно» или кажется неверной

Когда вы используете модели через **OpenRouter**, приложение показывает фактическую стоимость, предоставленную OpenRouter.

Для **других провайдеров** (OpenAI напрямую, Anthropic напрямую и т.д.) стоимость оценивается на основе ценовой информации, опубликованной OpenRouter. Если для модели не найдена соответствующая цена, стоимость будет отображаться как **не доступно** и не будет добавлена к общей сумме.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### Общая стоимость не совпадает со счётом провайдера

Все суммы в приложении являются **оценочными и приведены только для справки**, а не являются официальными платежными документами.

Чтобы приблизить общую сумму к вашим реальным расходам в OpenRouter, откройте [**Настройки** > **Отслеживание стоимости**](#cost-tracking) и нажмите **Синхронизировать с использованием API-ключа**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### Страница Истории отсутствует в боковой панели

Возможно, отключена функция **сохранения истории выполнения**. Откройте [**Настройки** > **Основные настройки**](#general-settings) и включите её. Обратите внимание, что включение этой опции не восстановит ранее удалённые данные истории.

<br/>

<a id="web-app-session-expired"></a>
### Веб-приложение: неожиданный переход на страницу входа

Ваша сессия могла истечь. Повторно войдите в систему. Если это происходит часто, проверьте конфигурацию сервера настройки времени жизни сессии.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### На дашборде не отображаются данные других пользователей (веб)

Только **администраторы** могут просматривать данные всех пользователей с помощью фильтра **Пользователь**. Обычные пользователи по задумке видят только свою собственную активность.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### Я изменил промт и потерял эти правки

При редактировании промта всегда нажимайте **Сохранить** перед тем, как нажать **Назад к запуску**.

<br/><br/>

<a id="quick-tips"></a>
## Быстрые советы

- Начните с [**Перевода**](#translate), чтобы убедиться, что настройка работает, прежде чем переходить к [**Переформулированию**](#rewrite) или [**Преобразованию**](#transform).
- Используйте [**Переформулирование**](#rewrite) для ежедневного улучшения текста.
- Используйте [**Преобразование**](#transform), когда вам нужен воспроизводимый рабочий процесс для конкретной задачи.
- Используйте [**Дашборд**](#dashboard), если хотите следить за объёмом использования и стоимостью.
- Используйте [**Историю**](#history), чтобы просматривать прошлые операции и полные входные/выходные тексты.
- Регулярно экспортируйте промты, если вы создаёте библиотеку промтов, которую хотите сохранить в безопасности (см. [Преобразование промтов](#transform-prompts)) или поделиться с другими.
