# Руководство пользователя

<br/>

<a id="introduction"></a>

## Введение

Transrewrt помогает работать с текстом тремя основными способами:

- **Перевести** — конвертировать текст с одного языка на другой.
- **Переформулировать** — перефразировать текст в ином стиле, например, более ясно, кратко или формально.
- **Преобразовать** — обрабатывать текст с помощью пользовательских инструкций для ИИ, которые называются промтами.

<br/>

В этом руководстве объясняется, как пользоваться приложением после его установки и запуска. По вопросам установки см. основной файл **[README](README.ru.md)**.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Transrewrt доступен как настольное приложение для Windows и Linux, а также как веб-приложение для самостоятельного размещения. Это руководство посвящено повседневному использованию приложения. Если какая-либо функция доступна только в одной из версий, это будет чётко указано.

## Перед началом работы

Для использования Transrewrt вам нужен доступ хотя бы к одному поставщику ИИ. Поддерживаемые поставщики: [OpenRouter](https://openrouter.ai) (объединяет множество моделей), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras и [Ollama](https://ollama.com) для локальных моделей.

Для начала не обязательно выбирать платную модель. Как только вы добавите свой API-ключ OpenRouter, приложение автоматически включает встроенную **бесплатную** опцию OpenRouter. Это позволяет сразу приступить к переводу, переписыванию и преобразованию текста. Кроме того, вы можете получить бесплатный API-ключ от Cerebras, Google, Groq или Mistral AI.

Простыми словами:

- **Модель** — это движок ИИ, выполняющий работу. Модели перечисляются с **префиксом провайдера** (например, `openrouter/…`, `openai/…`, `ollama/…`).
- **API-ключ** (или для Ollama — **базовый URL**) — это способ, с помощью которого приложение связывается с поставщиком.

Если вы используете **настольное приложение**, добавьте ключи в разделе [**Настройки** > **Конфигурация API**](#api-config) для каждого используемого провайдера. Если вы используете только OpenRouter, см. ниже раздел [Как получить API-ключ](#how-to-get-an-api-key-desktop-app). Если вы не хотите использовать API-ключ, вы можете установить Ollama (с сайта [ollama.com](https://ollama.com)) и использовать локальные модели, такие как `translategemma:4b`.

Если вы используете **веб-версию**, администратор сервера настраивает провайдеров с помощью переменных окружения, поэтому вы не можете напрямую ввести API-ключи в приложении.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>

### Как получить бесплатный API-ключ OpenRouter (настольное приложение)

Если вы используете настольное приложение, выполните следующие шаги:

1. Перейдите на сайт [OpenRouter](https://openrouter.ai) в вашем веб-браузере.
2. Создайте аккаунт или войдите в существующий.
3. Откройте страницу [Ключи](https://openrouter.ai/keys).
4. Нажмите кнопку создания нового API-ключа.
5. Дайте ключу имя, чтобы вы могли распознать его позже.
6. Скопируйте новый API-ключ.
7. Вернитесь в Transrewrt и откройте **Настройки** > **Конфигурация API**.
8. Вставьте ключ в поле **OpenRouter API-ключ** (в разделе **Настройки** > **Конфигурация API**).
9. Нажмите **Проверить ключ OpenRouter**, чтобы убедиться в его работоспособности.

<a id="getting-started"></a>

## Начало работы

Если вы используете Transrewrt впервые, следуйте следующим шагам:

1. Запустите приложение.
2. При необходимости выберите **язык интерфейса** через иконку земного шара.
3. Если вы используете **настольное приложение**, откройте раздел [**Настройки** > **Конфигурация API**](#api-config), добавьте ключ API хотя бы для одного провайдера (например, OpenRouter) и нажмите **Проверить**, чтобы убедиться, что всё работает.
4. Откройте [**Настройки** > **Модели**](#models) и добавьте одну или несколько моделей в раздел **Выбранные модели**.
5. Перейдите в [**Настройки** > **Языки**](#languages) и укажите свои **Основные языки**, если хотите, чтобы наиболее часто используемые языки отображались в первую очередь.
6. Перейдите на вкладку **Перевод** и выполните простой перевод, чтобы убедиться в корректной работе приложения.
7. После успешного перевода попробуйте функции **Переформулировать**, а затем **Преобразовать**.

Очень важно соблюдать именно такой порядок. Это поможет избежать наиболее распространённой проблемы у новых пользователей: попытки запустить задачу до настройки рабочего подключения к API или выбора модели.

### Панель инструментов

Внешний вид панели инструментов немного меняется в зависимости от того, где вы находитесь в приложении.

- Слева отображается название текущей страницы.
- Справа находятся **выбор модели** и элемент управления **языком интерфейса**.

С помощью **выбора модели** вы можете указать, какой ИИ-движок использовать для текущей задачи.

  ![Выбор модели](../images/screenshots/ru/model-selector.png)

Некоторые бесплатные модели могут быть недоступны — временами они отключены или имеют ограничение по использованию. В таком случае приложение автоматически уберёт модель из вашего списка доступных. Чтобы управлять отображением моделей, перейдите в раздел [**Настройки** > **Модели**](#models) и отредактируйте свой список моделей.
Вы можете открыть настройки модели напрямую, нажав на значок провайдера слева от названия модели на панели инструментов.

<br/>

**Значок шара Земли и код языка** изменяют язык интерфейса приложения, например, меню и кнопки. При этом **не изменяются** языки перевода, используемые в режиме **Перевода**.

### Панели ввода и вывода

Большинство рабочих пространств используют левую панель **Ввода** и правую панель **Вывода**.

Каждая панель также отображает:

| **Ввод**                                                          | **Вывод**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - Количество символов <br/>- Количество слов <br/>- Количество абзацев   <br/> | - Длительность выполнения задачи<br/>- **TPS** (токены в секунду)<br/>- Количество символов, слов и абзацев<br/>- Используемая модель |

Если вы задаётесь вопросом о технических терминах:

- **Токен** — это небольшой фрагмент текста. Можно представить его как часть слова или короткое слово.
- **TPS** означает, сколько таких фрагментов текста модель обрабатывает за секунду.

<br/>

Вы также можете отслеживать стоимость каждой операции (если доступно) и общую стоимость, включив опцию `Показывать информацию о стоимости операций` в разделе [**Настройки** > **Общие настройки**](#general-settings).

## Перевод

Используйте **Перевод**, когда нужно преобразовать текст с одного языка на другой.

![Рабочая область Перевода](../images/screenshots/ru/translate.png)

<br/>

<a id="translate-text"></a>

### Перевод текста

1. Откройте **Перевод**.
2. Выберите язык в поле **С**.
3. Выберите язык в поле **На**.
4. Выберите модель на панели инструментов.
5. Введите или вставьте текст в поле **Ввод**.
6. Нажмите **Перевести**.
7. Прочитайте результат в поле **Вывод**.
8. Используйте кнопку копирования, если хотите скопировать результат.

<br/>

<a id="language-selection"></a>

### Выбор языка

- **Исходный язык** может быть конкретным языком или **Определение языка**.
- **Язык перевода** — это язык, на который вы хотите получить результат.

Ваши выбранные **основные языки** отображаются в верхней части списка. Вы можете задать их в разделе [**Настройки** > **Языки**](#languages).

<br/>

<a id="helpful-translation-settings"></a>

### Полезные настройки перевода

В разделе [**Параметры** > **Общие параметры**](#general-settings) можно изменить поведение перевода:

- **Авто-перевод при вставке** — перевод запускается сразу после вставки текста.
- **Автоматически копировать результат в буфер обмена** — результат автоматически копируется после успешного перевода.
- **Перевод в реальном времени (во время ввода)** — перевод запускается по мере ввода текста.
- **Таймаут (мс)** — определяет, как долго приложение ожидает перед запуском перевода в реальном времени.
- **Enter** — определяет действие при нажатии клавиши `Enter`:

<a id="rewrite"></a>

## Переписать

Используйте функцию **Переписать**, когда нужно улучшить формулировку, не меняя основного смысла.

![Рабочая область Переписать](../images/screenshots/ru/rewrite.png)

Это полезно для:

- исправления орфографии и грамматики (**Проверить орфографию и грамматику**)
- повышения ясности текста (**Повысить ясность**)
- получения нескольких различных вариантов переформулировки за один запуск (**Альтернативные версии**)
- придания тексту более формального или неформального стиля (**Формально** / **Неформально**)
- сокращения или расширения текста (**Сократить** / **Расширить**)
- придания тексту более технического характера (**Сделать техническим**)

<br/>

> 💡 **СОВЕТ**<br/>
> При использовании режима "**Проверить орфографию и грамматику**" во вкладке вывода появляется переключатель **Показать изменения** (рядом с кнопкой **Копировать**). 
> Включите или выключите его, чтобы показать или скрыть конкретные исправления, применённые к вашему тексту.

<a id="transform"></a>

## Преобразование

Используйте **Преобразование**, когда хотите, чтобы ИИ следовал вашим собственным инструкциям.

![Рабочая область Преобразования](../images/screenshots/ru/transform.png)

Это наиболее гибкая область приложения. Вы можете использовать её для таких задач, как:

- создание краткого содержания заметок
- превращение чернового текста в отредактированное письмо
- выделение ключевых моментов
- преобразование текста в определённый формат
- любые другие пользовательские действия с исходным текстом

<br/>

<a id="run-an-existing-prompt"></a>

### Запуск существующего запроса

1. Откройте **Преобразование**.
2. Выберите запрос из списка запросов.
3. Если появится поле **Целевой язык**, выберите язык, если это необходимо.
4. Введите или вставьте текст в поле **Ввод**.
5. Нажмите **Преобразовать**.
6. Прочитайте результат в поле **Вывод**.

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### Если у вас еще нет промтов

Если список промтов пуст, нажмите **Загрузить примеры промтов** в рабочей области Transform. Эта же кнопка всегда доступна в разделе [**Настройки** > **Промты Transform**](#transform-prompts) в строке импорта/экспорта. ### Редактирование запроса

При создании или редактировании запроса редактор появляется слева, а справа — область тестирования.

![Редактор преобразования запроса](../images/screenshots/ru/transform-prompt-edit.png)

Основные поля:

- **Название запроса**: название, отображаемое в списке запросов.
- **Инструкции к запросу (необязательно)**: краткая подсказка, показываемая пользователю при запуске запроса.
- **Роль модели**: общая роль, присваиваемая ИИ, например: «Вы — полезный помощник».

- **Описание результата**: краткое слово, описывающее результат, например «суммаризация» или «переписывание».

Если термин **Температура** для вас новый, представьте его следующим образом:

- Более **низкая** температура даёт более стабильные и предсказуемые результаты.

- **Более высокая** температура даёт большее разнообразие и креативность.

- **`Создать запрос`**, чтобы сгенерировать новый черновик на основе простого описания

> Нажмите **`Сохранить`**, прежде чем нажать **`Назад к запуску`**. Если вы вернётесь назад без сохранения, все изменения будут потеряны.

<a id="general-settings"></a>

### Общие настройки

Используйте **Общие настройки**, чтобы управлять поведением при вводе текста, сохранением данных выполнения в разделе **История** и внешним видом интерфейса.

**Поведение**

- **Действие клавиши ENTER** определяет, будет ли нажатие `Enter` запускать задачу или вставлять новую строку.
- **Автоматический перевод при вставке** запускает перевод сразу после вставки текста.
- **Автоматическое копирование результата в буфер обмена** автоматически копирует успешные результаты.
- **Перевод в режиме реального времени (во время ввода)** осуществляет перевод по мере набора текста.
- **Тайм-аут (мс)** задаёт время ожидания перед переводом в режиме реального времени.

**История**

- **Сохранять историю выполнения** определяет, сохраняются ли каждый перевод, переформулировка и преобразование вместе с **исходным и полученным текстом** в боковой панели [**История**](#history). При отключении этой опции появится запрос подтверждения; в случае подтверждения сохранённые тексты будут удалены из базы данных.

- **Удалить данные истории** позволяет удалять сохранённый текст по возрасту (например, старше нескольких месяцев) или **все данные (очистить)** с помощью кнопки **Удалить данные**. Это влияет только на сохранённые тексты выполнения в разделе **История**, но **не удаляет** данные о стоимости и объёме использования. Чтобы удалить или очистить данные о **стоимости**, используйте [**Настройки** > **Отслеживание расходов**](#cost-tracking).

**Внешний вид**

- **Показывать информацию о стоимости в действиях** — определяет, будут ли отображаться стоимость каждой операции (если доступно) и общая стоимость на панелях вывода перевода, переписывания и преобразования.
- **Количество знаков после запятой в стоимости** — изменяет отображение десятичных разрядов стоимости.
- **Только веб-версия:** **показывать отступ вокруг приложения** — добавляет дополнительное пространство вокруг интерфейса.
- **Семейство шрифтов** — изменяет шрифт в текстовых панелях.
- **Размер** — изменяет размер шрифта.

**Резервное копирование конфигурации**

- **Включить данные использования в резервную копию** — при включении ZIP-файл также будет содержать историю выполнений и данные о вызовах API.

- **Резервное копирование конфигурации** — создаёт один ZIP-файл (`transrewrt-config-backup-ГГГГ-ММ-ДД_ЧЧММСС.zip`, по умолчанию с временем по UTC), содержащий `config.json`, `state.json`, необязательный ключ шифрования, пользователей, настройки, пользовательские запросы и данные об использовании (если вы дали на это согласие). После успешного резервного копирования подтверждение отобразит имя сохранённого файла.
- **Восстановление из резервной копии** — сначала открывает **диалог подтверждения**. Выберите ZIP-файл резервной копии в этом диалоге (**Обзор** / выбор файла или перетаскивание, если поддерживается), затем проверьте параметры:
  - **Восстановить данные об использовании** — импортировать историю/данные об использовании из ZIP-файла, созданного с включёнными данными об использовании; снимите отметку, если вы хотите восстановить только настройки и запросы.
  - **Очистить старые данные об использовании перед восстановлением** — удалить существующие данные об использовании/историю в текущей установке до применения резервной копии (опционально; используйте, если хотите полную замену).

Резервные копии, созданные в веб- или настольной версии, могут быть восстановлены в другой версии. При восстановлении резервной копии настольной версии в веб-версии данные будут восстановлены для пользователя-администратора.

Страница содержит два списка:

- **Выбранные модели** справа

Полезные элементы управления включают:

- **Поиск моделей...** — для поиска модели по названию
- **Метки провайдеров** — для сужения списка до определённого движка (OpenRouter, OpenAI, Ollama и т.д.)
- **Только бесплатные** — показывать только бесплатные модели
- **Обновить** — перезагрузить список
- **Развернуть все** и **Свернуть все** — при сортировке по провайдерам

Идентификаторы моделей включают префикс провайдера (например, `openrouter/…` против `openai/…`). Значки, такие как **OpenAI (OpenRouter)** и **OpenAI (напрямую)**, показывают, как маршрутизируется трафик.

> ℹ️ **ПРИМЕЧАНИЕ**<br/>

> **OpenRouter Body Builder** (`openrouter/bodybuilder`) — это модель-маршрутизатор, а не общая модель для чата: её ответ представляет собой JSON, описывающий тела запросов к API OpenRouter (например, массив `requests` с `model` и `messages`). Если вы используете её для задач **Перевод**, **Переформулирование** или **Преобразование**, в панели вывода будет показан этот JSON вместо готового текста. Для этих задач выбирайте обычную текстовую модель. Подробнее на [странице модели Body Builder](https://openrouter.ai/openrouter/bodybuilder) на OpenRouter.

Действия:

 - Чтобы добавить модель, нажмите **Добавить** или в любом месте соответствующего элемента.

 - Чтобы удалить модель, нажмите **X** рядом с ней в разделе **Выбранные модели** или **Выбрано** в элементе Доступных моделей.

 - Чтобы очистить список, нажмите **Отменить все**. Обязательная бесплатная модель останется в списке.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>

> Если вы не хотите сразу добавлять кредиты на OpenRouter, начните с включения опции **Только бесплатно** и выберите бесплатные модели (без необходимости указания банковской карты). Вы также можете использовать Ollama для запуска моделей локально, не используя API-ключ.

<a id="cost-tracking"></a>

### Отслеживание расходов

Используйте **Настройки** > **Отслеживание расходов**, чтобы управлять информацией о затратах.

- **Общие расходы** — текущая общая сумма.
- **Копировать значение** — копирует общую сумму в буфер обмена.
- **Сбросить затраты** — обнуляет накопленную сумму.
- **Синхронизация с использованием API-ключа** — устанавливает общую сумму в соответствии с данными использования, указанными в вашей учетной записи OpenRouter (только для OpenRouter).
- **Использование API-ключа** — отображает детализацию использования OpenRouter, если доступно.
- **Удалить данные о расходах** — удаляет все данные или только записи, старше выбранной даты.

**Отслеживание расходов:** При использовании моделей OpenRouter приложение отображает фактическое использование и расходы на основе данных от OpenRouter. Для всех других поставщиков приложение оценивает расходы, используя публикуемые OpenRouter цены; если цена недоступна, оценка может быть равна нулю.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> **Все суммы являются приблизительными и предназначены только для справки, это не официальные выставления счетов.**

<br/>

> ⚠️ **ПРЕДУПРЕЖДЕНИЕ**<br/>

> Удаление данных не может быть отменено. Перед удалением обязательно создайте резервную копию данных или экспортируйте их через [**Историю**](#history)  
> или [**Панель управления** > **Все запросы**](#dashboard-tabs), иначе данные будут безвозвратно утеряны.  
> Также будут удалены все данные ввода и вывода, связанные с каждой записью вызова API.

<a id="api-config"></a>

### Настройка API

Поддерживаемые провайдеры: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras и **Ollama** (локальные модели через базовый URL). Вам нужно настроить только те провайдеры, которые вы используете.

**Веб-приложение: только администратор**

Ключи API настраиваются через системные переменные или переменные окружения Docker — они не вводятся в веб-интерфейсе. На этой странице показано, для каких провайдеров задан ключ, и вы можете проверить каждый из них, нажав кнопку **`Тест`**.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Чтобы изменить ключ API, обновите переменную окружения в вашей системе или конфигурации Docker и перезапустите сервер или контейнер.

> ℹ️ **ПРИМЕЧАНИЕ**<br/>

> **Резервные копии конфигурации** (см. [**Основные настройки** → Резервное копирование конфигурации](#general-settings)) могут включать **раскрытые** ключи провайдеров внутрь `config.json` в архиве ZIP. При восстановлении этой ZIP-копии ключи **не будут** перенесены обратно в сохранённый конфигурационный файл сервера — действующие ключи по-прежнему берутся из переменных окружения и текущего состояния файла, как описано выше.

<br/>

**Десктопное приложение**

Используйте **Настройку API**, чтобы сохранить API-ключи для каждого используемого провайдера. В случае Ollama введите **базовый URL**, а не API-ключ.


<br/>

> 💡 **Совет** <br/>
> Если вы не хотите использовать API-ключ или платить за использование, вы можете [скачать Ollama](https://ollama.com) и запускать модели (например, `translategemma:4b`) локально на своём компьютере бесплатно. Также вы можете создать бесплатный аккаунт OpenRouter (без указания кредитной карты), чтобы использовать их бесплатные модели, либо получить бесплатный API-ключ от Cerebras, Google, Groq или Mistral AI.

- Добавляйте только тех провайдеров, которые вам нужны. В разделе **Настройки** > **Модели** каждое название модели начинается с указания провайдера (например, `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

Чтобы добавить API-ключ, введите его значение в текстовое поле и нажмите **`Сохранить`**. Чтобы заменить существующий ключ, нажмите **`Изменить`**. Чтобы проверить работоспособность ключа, нажмите **`Проверить`**. Для базового URL Ollama всегда нажимайте **`Проверить`**, чтобы проверить соединение.

<br/>

> ℹ️ **ПРИМЕЧАНИЕ**<br/>
> Просмотреть текущее значение API-ключа невозможно. Вы можете только заменить его с помощью кнопки **`Изменить`**.
> API-ключи хранятся в зашифрованном виде в конфигурации.

<a id="common-issues"></a>

## Распространённые проблемы

Если что-то работает не так, как ожидается, сначала проверьте следующие пункты.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### Приложение не будет переводить, переписывать или преобразовывать текст

Проверьте следующее:

- Выбрали ли вы модель в панели инструментов
- Есть ли по крайней мере одна модель в разделе [**Настройки** > **Модели**](#models)
- Работает ли ваша настройка API

Если вы используете настольное приложение:

1. Откройте [**Настройки** > **Конфигурация API**](#api-config).
2. Убедитесь, что хотя бы один API-ключ сохранён.
3. Нажмите **Проверить** рядом с провайдером, чтобы подтвердить, что ключ работает.

<br/>

<a id="the-model-list-is-empty"></a>

### Список моделей пуст

Откройте [**Настройки** > **Модели**](#models) и нажмите **Обновить**.

При необходимости:

- найдите модель
- включите параметр **Только бесплатные**
- добавьте одну или несколько моделей в раздел **Выбранные модели**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>

### Результат слишком медленный или слишком дорогой

Попробуйте один или несколько из следующих вариантов:

- выберите другую модель
- используйте более короткий ввод
- отключите режим **Перевод в реальном времени (во время ввода)** в разделе [**Настройки** > **Основные настройки**](#general-settings)
- используйте бесплатные модели для простых задач (см. [Модели](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>

### Интерфейс отображается на неправильном языке

Нажмите на значок шарика в [панели инструментов](#toolbar) и выберите желаемый **язык интерфейса**.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>

### Текст слишком маленький или его трудно читать

Откройте [**Настройки** > **Общие настройки**](#general-settings) и измените:

- **Семейство шрифтов**
- **Размер**

<br/>

<a id="dashboard-charts-are-empty"></a>

### Графики на панели мониторинга пустые

Это нормально, если:

- вы используете только **бесплатные модели**, и смотрите показатели **стоимости** (они могут быть нулевыми); графики количества вызовов по **использованию** на вкладке **Обзор** всё ещё требуют данных за выбранный период;
- выбранный **фильтр времени** не охватывает период, когда были совершены вызовы — попробуйте выбрать **Все**, чтобы проверить.

Если графики остаются пустыми после выбора **Все**, убедитесь, что вызовы отображаются в разделе **[История](#history)** или на вкладке **Все вызовы**.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### Стоимость отображается как «недоступна» или кажется неправильной

Когда вы используете модели через **OpenRouter**, приложение показывает фактические расходы, предоставленные OpenRouter.

Для **других провайдеров** (OpenAI напрямую, Anthropic напрямую и т.д.) стоимость оценивается на основе ценовой информации, опубликованной OpenRouter. Если для модели не найдена соответствующая цена, стоимость будет отображаться как **недоступна** и не будет включена в общую сумму.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### Общая стоимость не соответствует счёту провайдера

Все данные о стоимости в приложении являются **сметными значениями для справки** и не представляют официальные счёта.

Чтобы приблизить общую сумму к реальным расходам в OpenRouter, откройте [**Настройки** > **Отслеживание затрат**](#cost-tracking) и нажмите **Синхронизировать с использованием API-ключа**.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### Страница «История» отсутствует в боковой панели

Возможно, отключено **сохранение истории выполнения**. Откройте [**Настройки** > **Общие настройки**](#general-settings) и включите эту опцию. Обратите внимание, что включение этой функции не восстанавливает ранее удалённые данные истории.

<br/>

<a id="web-app-session-expired"></a>

### Веб-приложение: неожиданная переадресация на страницу входа

Ваша сессия могла истечь. Войдите снова. Если это происходит часто, проверьте настройки времени жизни сессии в конфигурации сервера.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### Веб-админ: забыл или потерял пароль

Это относится к **веб-приложению с самостоятельным хостингом** (Docker), а не к десктопному приложению (Electron).

- Если другой администратор может войти в систему, он может открыть [**Настройки** > **Пользователи**](#users), выбрать нужную учётную запись и задать там **новый пароль**.
- Если вы **заблокированы**, но у вас есть **доступ к оболочке** машины или контейнера, сбросьте пароль с помощью встроенного помощника, поставляемого вместе с образом (замените `transrewrt`, если вы изменили имя по умолчанию; заключите пароль в кавычки, если он содержит пробелы или специальные символы):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Имя администратора по умолчанию — `admin`, если вы не создавали других учётных записей. Если передать только один аргумент, он будет считаться новым паролем для пользователя `admin`.

Если вы запускаете приложение из **исходного кода**, а не из Docker, используйте:

```bash
pnpm run reset-web-password -- <username> <new-password>

Скрипт обновляет запись пользователя в базе данных SQLite (и может создать пользователя `admin`, если он отсутствует). После сброса войдите, используя новый пароль.


<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>

### На панели мониторинга отсутствуют данные других пользователей (веб)

Только **администраторы** могут просматривать данные всех пользователей с помощью фильтра **Пользователь**. Обычные пользователи по замыслу видят только свою собственную активность.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>

### Я изменил промт и потерял правки

При редактировании промта всегда нажимайте **Сохранить**, прежде чем нажимать **Вернуться к запуску**.

## Быстрые советы

- Начните с [**Перевода**](#translate), чтобы убедиться, что ваша настройка работает, прежде чем переходить к [**Перефразированию**](#rewrite) или [**Преобразованию**](#transform).

- Применяйте [**Преобразование**](#transform), когда вам нужен повторяемый рабочий процесс для выполнения конкретной задачи.
- Воспользуйтесь [**Панелью мониторинга**](#dashboard), если хотите отслеживать объемы использования и расходы.
- Используйте [**Историю**](#history), чтобы просматривать предыдущие операции и их полные входные/выходные тексты.
