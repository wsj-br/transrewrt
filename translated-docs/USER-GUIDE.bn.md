# ব্যবহারকারী গাইড

<br/>

<a id="introduction"></a>
## ভূমিকা

ট্রান্সরিওয়ার্ট আপনাকে পাঠ্যের সাথে তিনটি প্রধান পদ্ধতিতে কাজ করতে সাহায্য করে:

- **অনুবাদ** - একটি ভাষা থেকে অন্য ভাষায় পাঠ্য রূপান্তর করুন।
- **পুনর্লেখন** - পাঠ্যটি ভিন্ন ধরনের শৈলীতে পুনর্লিখন করুন, যেমন আরও স্পষ্ট, সংক্ষিপ্ত বা আনুষ্ঠানিক।
- **রূপান্তর** - প্রম্পট নামে কাস্টম এআই নির্দেশ ব্যবহার করে পাঠ্য প্রক্রিয়াকরণ।

<br/>

এই গাইডটি অ্যাপ্লিকেশন ইনস্টল করা ও চালু করার পর এটি ব্যবহার করার পদ্ধতি ব্যাখ্যা করে। ইনস্টলেশনের ধাপগুলির জন্য মূল **[README](README.bn.md)** দেখুন।

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> ট্রান্সরিওয়ার্ট উইন্ডোজ এবং লিনাক্সের জন্য একটি ডেস্কটপ অ্যাপ্লিকেশন এবং একটি স্ব-হোস্টেড ওয়েব অ্যাপ্লিকেশন হিসাবে উপলব্ধ। এই গাইডটি অ্যাপ্লিকেশনটির দৈনন্দিন ব্যবহারের উপর অগ্রাধিকার দেয়। যেখানে কোনও বৈশিষ্ট্য কেবল একটি সংস্করণের জন্য প্রযোজ্য, সেখানে এটি স্পষ্টভাবে চিহ্নিত করা হবে।

<a id="before-you-start"></a>

## শুরু করার আগে

Transrewrt ব্যবহার করতে, আপনার অন্তত একটি এআই প্রদানকারীতে অ্যাক্সেস থাকা প্রয়োজন। সমর্থিত প্রদানকারীদের মধ্যে রয়েছে: [OpenRouter](https://openrouter.ai) (যা অনেকগুলি মডেল একত্রিত করে), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, এবং স্থানীয় মডেলের জন্য [Ollama](https://ollama.com)।

শুরু করার জন্য আপনার কাছে কোনো পেইড মডেল নেওয়ার প্রয়োজন নেই। যেই মুহূর্তে আপনি আপনার OpenRouter API কী যোগ করবেন, অ্যাপটিতে স্বয়ংক্রিয়ভাবে একটি অন্তর্নির্মিত **ফ্রি** OpenRouter বিকল্প সক্ষম হয়ে যাবে। এটি আপনাকে অবিলম্বে অনুবাদ, পুনঃলেখন এবং পাঠ্য রূপান্তরে শুরু করতে দেবে। বিকল্পভাবে, আপনি Cerebras, Google, Groq, বা Mistral AI-এর কাছ থেকে একটি ফ্রি API কী পেতে পারেন।

সহজ ভাষায়:

- একটি **মডেল** হল এআই ইঞ্জিন যা কাজ করে। মডেলগুলি **প্রদানকারীর উপসর্গ** সহ তালিকাভুক্ত থাকে (উদাহরণস্বরূপ `openrouter/…`, `openai/…`, `ollama/…`)।
- একটি **API কী** (অথবা Ollama-এর জন্য, একটি **বেস URL**) হল অ্যাপটির মাধ্যমে প্রদানকারীকে পৌঁছানোর উপায়।

আপনি যদি **ডেস্কটপ অ্যাপ** ব্যবহার করেন, তবে আপনি যে প্রদানকারীদের ব্যবহার করেন তাদের জন্য [**সেটিংস** > **API কনফিগ**](#api-config)-এ কী যোগ করুন। কেবলমাত্র OpenRouter ব্যবহারের জন্য, নিচে দেখুন [একটি API কী পাওয়ার পদ্ধতি](#how-to-get-an-api-key-desktop-app)। যদি আপনি API কী ব্যবহার করতে না চান, তবে আপনি [ollama.com](https://ollama.com) থেকে Ollama ইনস্টল করে স্থানীয় মডেল, যেমন `translategemma:4b` ব্যবহার করতে পারেন।

আপনি যদি **ওয়েব সংস্করণ** ব্যবহার করেন, তবে সার্ভার মালিকটি পরিবেশ চলক ব্যবহার করে প্রদানকারীদের কনফিগার করে দেয়, তাই আপনি টুলটিতে সরাসরি API কী লিখতে পারবেন না।

<a id="how-to-get-an-api-key-desktop-app"></a>
### একটি ফ্রি OpenRouter API কী পাওয়ার পদ্ধতি (ডেস্কটপ অ্যাপ)

আপনি যদি ডেস্কটপ অ্যাপ ব্যবহার করেন, নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. আপনার ওয়েব ব্রাউজারে [OpenRouter](https://openrouter.ai)-এ যান।
2. একটি অ্যাকাউন্ট তৈরি করুন অথবা লগ ইন করুন।
3. [Keys](https://openrouter.ai/keys) পৃষ্ঠাটি খুলুন।
4. একটি নতুন API কী তৈরি করতে বাটনে ক্লিক করুন।
5. পরে চিনতে পারার জন্য কী-টির একটি নাম দিন।
6. নতুন API কীটি কপি করুন।
7. Transrewrt-এ ফিরে আসুন এবং **সেটিংস** > **API কনফিগ** খুলুন।
8. এখানে **OpenRouter API কী** ( **সেটিংস** > **API কনফিগ**-এ) কীটি পেস্ট করুন।
9. এটি কাজ করছে কিনা তা নিশ্চিত করতে **OpenRouter কী পরীক্ষা করুন** বাটনে ক্লিক করুন।

<a id="getting-started"></a>
## শুরু করা

যদি আপনি প্রথমবার Transrewrt ব্যবহার করেন, তবে এই ক্রম অনুসরণ করুন:

1. অ্যাপটি খুলুন।
2. প্রয়োজন হলে গ্লোব আইকন থেকে আপনার **ইন্টারফেস ভাষা** নির্বাচন করুন।
3. যদি আপনি **ডেস্কটপ অ্যাপ** ব্যবহার করেন, তবে [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন, অন্তত একটি প্রদানকারীর (উদাহরণস্বরূপ OpenRouter) জন্য একটি API কী যোগ করুন এবং এটি কাজ করছে কিনা তা যাচাই করতে **পরীক্ষা করুন** ক্লিক করুন।
4. [**সেটিংস** > **মডেল**](#models) খুলুন এবং এক বা একাধিক মডেল **নির্বাচিত মডেলে** যোগ করুন।
5. [**সেটিংস** > **ভাষা**](#languages) খুলুন এবং যদি আপনি চান যে আপনার সবচেয়ে বেশি ব্যবহৃত ভাষাগুলি আগে দেখা যাক, তাহলে আপনার **শীর্ষ ভাষাগুলি** নির্বাচন করুন।
6. **অনুবাদ**-এ যান এবং সবকিছু কাজ করছে কিনা তা নিশ্চিত করতে একটি সাধারণ অনুবাদ চালান।
7. তা কাজ করলে, **পুনঃলেখন** এবং এরপর **রূপান্তর** চেষ্টা করুন।

এই ক্রমের বিষয়টি গুরুত্বপূর্ণ। এটি প্রথমবার ব্যবহারে হওয়া সবচেয়ে সাধারণ সমস্যা এড়ায়: অ্যাপটিতে কার্যকর API সংযোগ বা নির্বাচিত মডেল না থাকা সত্ত্বেও কোনো কাজ চালানোর চেষ্টা।

### টুলবার

অ্যাপের বিভিন্ন জায়গায় গেলে টুলবারটি সামান্য পরিবর্তিত হয়।

- বাম দিকে, বর্তমান পৃষ্ঠার নাম দেখানো হয়।
- ডান দিকে, **মডেল সিলেক্টর** এবং **ইন্টারফেস ভাষা** নিয়ন্ত্রণ দেখানো হয়।

**মডেল সিলেক্টর** বর্তমান কাজের জন্য কোন AI ইঞ্জিন ব্যবহার করবেন তা আপনাকে নির্বাচন করার সুযোগ দেয়।

  ![মডেল সিলেক্টর](../images/screenshots/bn/model-selector.png)

কিছু বিনামূল্যের মডেল সর্বদা উপলব্ধ নাও হতে পারে—মাঝে মাঝে তারা অফলাইন থাকে অথবা ব্যবহারের সীমা থাকে। এমন হলে, অ্যাপটি স্বয়ংক্রিয়ভাবে আপনার উপলব্ধ তালিকা থেকে সেই মডেলটি সরিয়ে দেবে। কোন মডেলগুলি দেখানো হবে তা নিয়ন্ত্রণ করতে, [**সেটিংস** > **মডেলস**](#models)-এ যান এবং আপনার মডেলের তালিকা সম্পাদনা করুন।
টুলবারে মডেলের নামের বাম পাশে প্রদানকারীর আইকনে ক্লিক করেও আপনি সরাসরি মডেল সেটিংস খুলতে পারেন।

<br/>

**গ্লোব আইকন + ভাষার কোড** অ্যাপের ইন্টারফেস ভাষা, যেমন মেনু এবং বোতামগুলি পরিবর্তন করে। এটি **অনুবাদ**-এ ব্যবহৃত অনুবাদ ভাষাগুলি পরিবর্তন করে না।

  ![ইন্টারফেস ভাষা সিলেক্টর](../images/screenshots/bn/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### ইনপুট এবং আউটপুট প্যানেল

অধিকাংশ কাজের স্থানে বাম পাশের **ইনপুট** প্যানেল এবং ডান পাশের **আউটপুট** প্যানেল ব্যবহার হয়।

প্রতিটি প্যানেল এছাড়াও দেখায়:

| **ইনপুট**                                                          | **আউটপুট**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - অক্ষরের সংখ্যা <br/>- শব্দের সংখ্যা <br/>- অনুচ্ছেদের সংখ্যা   <br/> | - কাজটি কতক্ষণ সময় নিয়েছে<br/>- **TPS** (প্রতি সেকেন্ডে টোকেন)<br/>- অক্ষর, শব্দ এবং অনুচ্ছেদের সংখ্যা<br/>- ব্যবহৃত মডেল |


যদি আপনি প্রযুক্তিগত শব্দগুলি নিয়ে ভাবছেন:

- **টোকেন** মানে একটি ছোট টেক্সট অংশ। আপনি এটিকে একটি শব্দের অংশ বা একটি খুব ছোট শব্দ হিসাবে ভাবতে পারেন।
- **TPS** মানে প্রতি সেকেন্ডে মডেল কতগুলো টেক্সট অংশ প্রক্রিয়া করছে।

<br/>

[**সেটিংস** > **জেনারেল সেটিংস**](#general-settings)-এ `কার্যকলাপগুলিতে খরচের তথ্য দেখানো হবে` বিকল্পটি চালু করে প্রতিটি ক্রিয়াকলাপের খরচ (যদি উপলব্ধ থাকে) এবং মোট খরচ মনিটর করতে পারবেন।

<a id="translate"></a>
## অনুবাদ

আপনি যখন কোনো টেক্সটকে এক ভাষা থেকে অন্য ভাষায় রূপান্তর করতে চান, তখন **অনুবাদ** ব্যবহার করুন।

![অনুবাদ কাজের স্থান](../images/screenshots/bn/translate.png)

<br/>

<a id="translate-text"></a>
### টেক্সট অনুবাদ করুন

1. **অনুবাদ** খুলুন।
2. **থেকে** একটি ভাষা নির্বাচন করুন।
3. **করে** একটি ভাষা নির্বাচন করুন।
4. টুলবারে একটি মডেল নির্বাচন করুন।
5. **ইনপুট**-এ টেক্সট টাইপ করুন অথবা পেস্ট করুন।
6. **অনুবাদ**-এ ক্লিক করুন।
7. **আউটপুট**-এ ফলাফল পড়ুন।
8. ফলাফলটি কপি করতে হলে কপি বোতাম ব্যবহার করুন।

<br/>

<a id="language-selection"></a>
### ভাষা নির্বাচন

- **থেকে** একটি নির্দিষ্ট ভাষা হতে পারে অথবা **ভাষা শনাক্ত করুন**।
- **করে** হল আপনি যে ভাষাতে ফলাফল চান।

আপনার নির্বাচিত **শীর্ষ ভাষা**গুলি তালিকার উপরে দেখানো হয়। আপনি এগুলি [**সেটিংস** > **ভাষা**](#languages) এ সেট করতে পারেন।

<br/>

<a id="helpful-translation-settings"></a>
### কার্যকরী অনুবাদ সেটিংস

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ, আপনি অনুবাদের আচরণ পরিবর্তন করতে পারেন:

- **পেস্ট করার সঙ্গে সঙ্গে অনুবাদ করুন**, আপনি যখনি টেক্সট পেস্ট করবেন, তখন অনুবাদ শুরু হয়ে যাবে।
- **ফলাফল স্বয়ংক্রিয়ভাবে ক্লিপবোর্ডে কপি করুন**, সফল অনুবাদের পর ফলাফল স্বয়ংক্রিয়ভাবে কপি করা হয়।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)**, আপনি যখন টাইপ করবেন তখনই অনুবাদ চলবে।
- **টাইমআউট (ms)**, এটি রিয়েল-টাইম অনুবাদ শুরু করার আগে অ্যাপটি কতক্ষণ অপেক্ষা করবে তা নিয়ন্ত্রণ করে।
- **এন্টার**, আপনি `এন্টার` চাপলে কী ঘটবে তা নিয়ন্ত্রণ করে:

## পুনরায় লেখা

আপনি যখন মূল অর্থ পরিবর্তন না করে শব্দচয়ন উন্নত করতে চান, তখন **পুনরায় লেখা** ব্যবহার করুন।

![পুনরায় লেখা কাজের স্থান](../images/screenshots/bn/rewrite.png)

এটি নিম্নলিখিত ক্ষেত্রে ব্যবহারুল:

- বানান ও ব্যাকরণ ঠিক করা
- টেক্সটকে আরও পরিষ্কার করা
- টেক্সটকে আরও আনুষ্ঠানিক বা অনানুষ্ঠানিক করা
- টেক্সট সংক্ষেপণ বা প্রসারণ

> কোন নির্দিষ্ট পরিবর্তনগুলি আপনার টেক্সটে করা হয়েছে তা দেখানো বা লুকানোর জন্য এই বোতামে ক্লিক করে প্রদর্শন টগল করুন।

<a id="transform"></a>

## রূপান্তর করুন

**রূপান্তর করুন** ব্যবহার করুন যখন আপনি চান যে কৃত্রিম বুদ্ধিমত্তা কাস্টম নির্দেশাবলী অনুসরণ করুক।

![রূপান্তর ওয়ার্কস্পেস](../images/screenshots/bn/transform.png)

এটি অ্যাপ্লিকেশনটির সবচেয়ে নমনীয় অংশ। আপনি নিম্নলিখিত কাজগুলির জন্য এটি ব্যবহার করতে পারেন:

- নোটগুলির সারসংক্ষেপ তৈরি করা
- রাফ লেখাকে সুন্দর ইমেলে রূপান্তরিত করা
- প্রধান বিষয়গুলি বেছে নেওয়া
- লেখাটিকে নির্দিষ্ট ফরম্যাটে রূপান্তর করা
- ইনপুট লেখার সাথে অন্যান্য কোনো কাস্টম কাজ

<br/>

<a id="run-an-existing-prompt"></a>
### একটি বিদ্যমান প্রম্পট চালান

1. **রূপান্তর করুন** খুলুন।
2. প্রম্পট তালিকা থেকে একটি প্রম্পট চয়ন করুন।
3. যদি একটি **লক্ষ্য** ভাষা বক্স দেখায়, চাইলে একটি ভাষা নির্বাচন করুন।
4. **ইনপুট** এ লেখা টাইপ করুন বা পেস্ট করুন।
5. **রূপান্তর করুন** এ ক্লিক করুন।
6. **আউটপুট** এ ফলাফল পড়ুন।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### যদি এখনও কোনো প্রম্পট না থাকে

আপনার প্রম্পট তালিকা খালি থাকলে, **নমুনা প্রম্পটগুলি লোড করুন** এ ক্লিক করুন। এটি অন্তর্নির্মিত উদাহরণগুলি যুক্ত করবে যাতে আপনি দ্রুত শুরু করতে পারেন।

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> নমুনা প্রম্পটগুলি ইংরেজিতে প্রদান করা হয়। সেগুলি লোড করার পরে, আপনি একটি প্রম্পট সম্পাদনা করতে পারেন এবং **অনুবাদ প্রম্পট** ব্যবহার করে এটিকে আপনার ভাষায় অনুবাদ করতে পারেন।

<br/>

<a id="create-a-prompt-quickly"></a>
### দ্রুত একটি প্রম্পট তৈরি করুন

একটি প্রম্পট তৈরির দ্রুততম উপায় হল:

1. **নতুন প্রম্পট** এ ক্লিক করুন।
2. **প্রম্পট তৈরি করুন** এ ক্লিক করুন।
3. আপনি চান যে প্রম্পটটি কী করবে তা বর্ণনা করুন।
4. একটি মডেল চয়ন করুন।
5. অ্যাপ্লিকেশনটি আপনার জন্য একটি খসড়া তৈরি করুক দিন।
6. খসড়াটি পর্যালোচনা করুন এবং **সংরক্ষণ করুন** এ ক্লিক করুন।

![প্রম্পট তৈরি করুন](../images/screenshots/bn/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### একটি প্রম্পট সম্পাদনা করুন

যখন আপনি একটি প্রম্পট তৈরি করেন বা সম্পাদনা করেন, তখন বাম দিকে এডিটর দেখা যায় এবং ডান দিকে একটি পরীক্ষার এলাকা দেখা যায়।

![রূপান্তর প্রম্পট এডিটর](../images/screenshots/bn/transform-prompt-edit.png)

প্রধান ফিল্ডগুলি হল:

- **প্রম্পটের নাম**: প্রম্পট তালিকায় দেখানো নাম।
- **প্রম্পট নির্দেশনা (ঐচ্ছিক)**: প্রম্পট চালানোর সময় ব্যবহারকারীকে দেখানো একটি ছোট হিন্ট।
- **মডেল ভূমিকা**: কৃত্রিম বুদ্ধিমত্তার জন্য নির্ধারিত সামগ্রিক ভূমিকা, যেমন 'আপনি একজন সহায়ক সহকারী'।
- **মডেল নির্দেশনা (প্রতি লাইনে একটি)**: কৃত্রিম বুদ্ধিমত্তার অনুসরণ করার জন্য আপনি চান এমন নির্দিষ্ট নিয়ম।
- **আউটপুট বর্ণনা**: ফলাফল বর্ণনার জন্য একটি ছোট শব্দ, যেমন 'সারাংশ' বা 'পুনর্লিখন'।
- **তাপমাত্রা (0.0 → 1.0)**: মডেল কীভাবে আচরণ করবে; নিচে দেখুন।
- **লক্ষ্য ভাষার জন্য জিজ্ঞাসা করুন**: প্রম্পট চালানোর সময় একটি লক্ষ্য ভাষা নির্বাচক যোগ করে।

যদি **তাপমাত্রা** নামের প্রযুক্তিগত শব্দটি আপনার কাছে নতুন হয়, তবে এটি এভাবে ভাবুন:

- **কম** তাপমাত্রা স্থিতিশীল এবং আরও পূর্বানুমেয় ফলাফল দেয়।
- **উচ্চ** তাপমাত্রা আরও বৈচিত্র্য এবং সৃজনশীলতা দেয়।

আপনি এছাড়াও ব্যবহার করতে পারেন:

- **`প্রম্পট তৈরি করুন`** একটি সাধারণ বর্ণনা থেকে নতুন খসড়া তৈরি করার জন্য
- **`প্রম্পট উন্নত করুন`** একটি বিদ্যমান প্রম্পট উন্নত করার জন্য
- **`প্রম্পট অনুবাদ করুন`** প্রম্পটের ফিল্ডগুলি অনুবাদ করার জন্য

<br/>

> ⚠️ **সতর্কতা**<br/>
> **`ফিরে যান`** এ ক্লিক করার আগে **`সংরক্ষণ করুন`** এ ক্লিক করুন। সংরক্ষণ না করে ফিরে গেলে আপনার পরিবর্তনগুলি হারিয়ে যাবে।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ব্যবহার করার আগে একটি প্রম্পট পরীক্ষা করুন

ডানদিকের পরীক্ষার প্যানেলটি আপনাকে দৈনন্দিন কাজে ব্যবহার করার আগে নমুনা লেখা দিয়ে আপনার প্রম্পট চেষ্টা করার অনুমতি দেয়।

এটি নিম্নলিখিত ক্ষেত্রে ব্যবহারিক:

- আপনি একটি নতুন প্রম্পট তৈরি করছেন
- আপনি দুটি সংস্করণের প্রম্পটের তুলনা করছেন
- আপনি আঙ্গিক, দৈর্ঘ্য বা আউটপুট ফরম্যাট পরীক্ষা করতে চান

> ℹ️ **দ্রষ্টব্য**<br/>
> আপনি [**সেটিংস** > **রূপান্তর প্রম্পট**](#transform-prompts) এ সংরক্ষিত প্রম্পটগুলি রপ্তানি এবং আমদানি করতে পারেন।

<a id="general-settings"></a>
### সাধারণ সেটিংস

**সাধারণ সেটিংস** ব্যবহার করুন টাইপিং আচরণ, এক্সেকিউশন বিবরণ কি সংরক্ষণ করা হবে **ইতিহাস** এর জন্য এবং চেহারা নিয়ন্ত্রণ করতে।

**আচরণ**

- **ENTER এর জন্য আচরণ** নির্বাচন করে যে `Enter` কি কাজটি চালাবে নাকি নতুন লাইন যুক্ত করবে।
- **পেস্ট করার সাথে সাথে স্বয়ংক্রিয় অনুবাদ** পাঠ্য পেস্ট করার মাত্র সঙ্গে অনুবাদ শুরু করে।
- **আউটপুট ক্লিপবোর্ডে স্বয়ংক্রিয়ভাবে নকল করুন** সফল ফলাফলগুলি স্বয়ংক্রিয়ভাবে কপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** আপনি টাইপ করার সময় এটা অনুবাদ করে।
- **সময় শেষ (মিলিসেকেন্ড)** রিয়েল-টাইম অনুবাদের জন্য অপেক্ষা সময় নির্ধারণ করে।

**ইতিহাস**

- **কার্যকর ইতিহাস রাখুন** নিয়ন্ত্রণ করে যে প্রতিটি অনুবাদ, পুনরায় লেখা এবং রূপান্তর কি বাম প্যানেলের [**ইতিহাস**](#history) দৃশ্যের জন্য **ইনপুট এবং আউটপুট পাঠ্য** সংরক্ষণ করবে কি না। এটা নিষ্ক্রিয় করলে নিশ্চিতকরণ চাওয়া হবে; যদি আপনি নিশ্চিত করেন, তবে সংরক্ষিত ইতিহাসের পাঠ্য ডেটাবেজ থেকে মুছে ফেলা হবে।
- **ইতিহাসের তথ্য মুছুন** বয়স অনুযায়ী (যেমন কয়েক মাসের বেশি পুরনো, অথবা **সমস্ত তথ্য (পরিষ্কার করুন)**) "তথ্য মুছুন" ব্যবহার করে সঞ্চিত পাঠ্য মুছে ফেলার অনুমতি দেয়। এটি কেবল **ইতিহাস** দৃশ্যের জন্য সংরক্ষিত কার্যকর পাঠ্যকে প্রভাবিত করে; এটি **খরচ বা ব্যবহারের মোট সংখ্যা মুছে ফেলে না**। **খরচ** তথ্য অপসারণ বা কমানোর জন্য, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking) ব্যবহার করুন।

**চেহারা**

- **ক্রিয়াকলাপে খরচ তথ্য প্রদর্শন করুন** ক্রিয়াকলাপ প্রতি খরচ (যদি উপলব্ধ হয়) এবং অনুবাদ, পুনরায় লেখা এবং রূপান্তর আউটপুট প্যানেলগুলিতে মোট খরচ প্রদর্শন নিয়ন্ত্রণ করে।
- **খরচের ভগ্নাংশ সংখ্যা** খরচের দশমিকগুলো কিভাবে প্রদর্শিত হবে তা পরিবর্তন করে।
- **শুধুমাত্র ওয়েব:** **অ্যাপের চারপাশে মার্জিন দেখান** ইন্টারফেসের চারপাশে অতিরিক্ত স্থান যুক্ত করে।
- **ফন্ট পরিবার** টেক্সট প্যানেলগুলিতে লেখার ফন্ট পরিবর্তন করে।
- **আকার** ফন্টের আকার পরিবর্তন করে।

<a id="models"></a>

### মডেলসমূহ

টুলবারে কোন মডেলগুলি প্রদর্শিত হবে তা নির্বাচন করতে **সেটিংস** > **মডেল** ব্যবহার করুন।

![সেটিংস মডেল ট্যাব](../images/screenshots/bn/settings-models.png)

এই পৃষ্ঠাতে দুটি তালিকা রয়েছে:

- বামদিকে **প্রাপ্য মডেল**
- ডানদিকে **নির্বাচিত মডেল**

নিম্নলিখিত নিয়ন্ত্রণগুলি দরকারি:

- **মডেল অনুসন্ধান...** নাম দ্বারা মডেল খুঁজতে
- **প্রদানকারী** চিপস একক ইঞ্জিনে (OpenRouter, OpenAI, Ollama ইত্যাদি) তালিকা সীমিত করতে
- কেবলমাত্র বিনামূল্যে মডেল প্রদর্শনের জন্য **কেবল বিনামূল্যে**
- তালিকা পুনরায় লোড করতে **রিফ্রেশ**
- **সব প্রসারিত করুন** এবং **সব সংকুচিত করুন**, যখন আপনি প্রদানকারী অনুযায়ী সাজাবেন

মডেল আইডি-এ প্রদানকারীর প্রিফিক্স অন্তর্ভুক্ত থাকে (উদাহরণস্বরূপ `openrouter/…` বনাম `openai/…`)। **OpenAI (OpenRouter)** বনাম **OpenAI (direct)** -এর মতো ব্যাজ দেখায় যে কীভাবে ট্রাফিক রুট করা হচ্ছে।

> ℹ️ **নোট**<br/>
> **OpenRouter বডি বিল্ডার** (`openrouter/bodybuilder`) একটি রাউটার মডেল, একটি সাধারণ চ্যাট মডেল নয়: এর উত্তর হল JSON, যা OpenRouter API রিকোয়েস্ট বডি বর্ণনা করে (উদাহরণস্বরূপ `model` এবং `messages` সহ একটি `requests` অ্যারে)। আপনি যদি এটি **অনুবাদ**, **পুনরায় লেখা** বা **রূপান্তর**-এর জন্য ব্যবহার করেন, তবে আউটপুট প্যানেল শেষ করা টেক্সটের পরিবর্তে সেই JSON দেখাবে। এই ধরনের কাজের জন্য একটি সাধারণ টেক্সট মডেল নির্বাচন করুন। OpenRouter-এ [বডি বিল্ডার মডেল পাতা](https://openrouter.ai/openrouter/bodybuilder) দেখুন।

ক্রিয়াকলাপ:

 - একটি মডেল যোগ করতে, **যোগ করুন** বা এন্ট্রির যেকোনো জায়গাতে ক্লিক করুন।

 - একটি মডেল সরাতে, **নির্বাচিত মডেলগুলি**-এ এটির পাশের **X**-এ ক্লিক করুন বা প্রাপ্য মডেলে এন্ট্রির **নির্বাচিত**-এ ক্লিক করুন।

 - তালিকা খালি করতে, **সবগুলি নির্বাচন সরান** এ ক্লিক করুন। প্রয়োজনীয় বিনামূল্যে মডেল তালিকাতে থাকবে।

<br/>

> ℹ️ **নোট**<br/>
> আপনি যদি OpenRouter-এ ক্রেডিট তৎক্ষণাৎ যোগ করতে না চান, তাহলে **কেবল বিনামূল্যে** সক্রিয় করে এবং বিনামূল্যে মডেল নির্বাচন করে শুরু করুন (ক্রেডিট কার্ডের প্রয়োজন নেই)। আপনি Ollama ব্যবহার করে কোনও API কী ছাড়াই স্থানীয়ভাবে মডেল চালাতে পারেন।

### ভাষা

অ্যাপে ব্যবহৃত ভাষার তালিকা সাজাতে **সেটিংস** > **ভাষা** ব্যবহার করুন।

- **শীর্ষ ভাষা** গুলি **অনুবাদ** এবং **রূপান্তর**-এ ভাষার তালিকার উপরের দিকে পিন করা থাকে।
- **কাস্টম ভাষা** বিল্ট-ইন তালিকাতে না থাকা ভাষা যোগ করতে দেয়।

আপনি যদি একটি কাস্টম ভাষা যোগ করেন, তবে এটি বিল্ট-ইন বিকল্পগুলির পাশাপাশি ভাষা নির্বাচকগুলিতে প্রদর্শিত হবে।

<a id="cost-tracking"></a>
### খরচ ট্র্যাকিং

খরচের তথ্য পরিচালনা করতে **সেটিংস** > **খরচ ট্র্যাকিং** ব্যবহার করুন।

- **মোট খরচ** চলমান মোট প্রদর্শন করে।
- **মান কপি করুন** ক্লিপবোর্ডে মোট কপি করে।
- **খরচ রিসেট করুন** সংরক্ষিত মোট শূন্যে রিসেট করে।
- **API কী ব্যবহারের সাথে সিঙ্ক করুন** আপনার OpenRouter অ্যাকাউন্ট দ্বারা প্রতিবেদিত ব্যবহারের সাথে মিল রেখে মোট সেট করে (শুধুমাত্র OpenRouter)।
- **API কী ব্যবহার** উপলব্ধ থাকলে OpenRouter ব্যবহারের বিশদ দেখায়।
- **খরচের তথ্য মুছুন** সমস্ত তথ্য মুছে ফেলে বা শুধুমাত্র নির্বাচিত তারিখের আগের এন্ট্রিগুলি।


**খরচ ট্র্যাকিং:** আপনি যখন OpenRouter মডেল ব্যবহার করেন, তখন অ্যাপটি OpenRouter থেকে প্রাপ্ত খরচের তথ্যের ভিত্তিতে আপনার প্রকৃত ব্যবহার এবং খরচ দেখায়। অন্যান্য সমস্ত প্রদানকারীদের ক্ষেত্রে, অ্যাপটি OpenRouter কর্তৃক প্রকাশিত মূল্য ব্যবহার করে খরচের অনুমান করে, যদি মূল্য অনুপলব্ধ হয় তবে অনুমান শূন্য হতে পারে।

<br/>

> ℹ️ **নোট**<br/>
> **সমস্ত খরচের চিত্র শুধুমাত্র আপনার তথ্যের জন্য, কোনো আনুষ্ঠানিক বিলিং বিবৃতি নয়।**


<br/>

> ⚠️ **সতর্কতা**<br/>
> ডেটা মুছে ফেলা পূর্বাবস্থায় ফেরানো যাবে না। মুছে ফেলার আগে আপনার ডেটা ব্যাক আপ করুন বা [**ইতিহাস**](#history) বা [**ড্যাশবোর্ড** > **সমস্ত কল**](#dashboard-tabs) এর মাধ্যমে রপ্তানি করুন, অন্যথায় এটি চিরতরে হারিয়ে যাবে। প্রতিটি API কল এন্ট্রির সাথে সম্পর্কিত সমস্ত ইনপুট/আউটপুট ইতিহাসও মুছে ফেলা হবে।

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### অ্যাপটি টেক্সট অনুবাদ, পুনরায় লেখা বা রূপান্তর করবে না

নিম্নলিখিতগুলি পরীক্ষা করুন:

- টুলবারে আপনি একটি মডেল নির্বাচন করেছেন কিনা
- কমপক্ষে একটি মডেল [**সেটিংস** > **মডেল**](#models)-এ তালিকাভুক্ত আছে কিনা

যদি আপনি ডেস্কটপ অ্যাপ ব্যবহার করেন:

1. [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন।
2. কমপক্ষে একটি API কী সংরক্ষিত আছে কিনা পরীক্ষা করুন।
3. কীটি কাজ করছে কিনা নিশ্চিত করতে প্রদানকারীর পাশে **পরীক্ষা করুন** ক্লিক করুন।

<br/>

<a id="the-model-list-is-empty"></a>
### মডেলের তালিকা খালি

[**সেটিংস** > **মডেল**](#models) খুলুন এবং **রিফ্রেশ** ক্লিক করুন।

প্রয়োজন হলে:

- একটি মডেল খুঁজুন
- **শুধুমাত্র বিনামূল্যে** চালু করুন
- এক বা একাধিক মডেল **নির্বাচিত মডেল**-এ যুক্ত করুন

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ফলাফল অত্যধিক ধীর বা ব্যয়বহুল

এগুলির এক বা একাধিক চেষ্টা করুন:

- একটি ভিন্ন মডেল বেছে নিন
- কম দৈর্ঘ্যের ইনপুট ব্যবহার করুন
- [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** বন্ধ করুন
- সহজ কাজের জন্য বিনামূল্যে মডেল ব্যবহার করুন (দেখুন [মডেল](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ইন্টারফেস ভুল ভাষায় আছে

[টুলবার](#toolbar)-এ গ্লোব আইকনে ক্লিক করে আপনার পছন্দসই **ইন্টারফেস ভাষা** নির্বাচন করুন।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### লেখাটি খুব ছোট বা পড়ার জন্য কঠিন

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং পরিবর্তন করুন:

- **ফন্ট ফ্যামিলি**
- **আকার**

<br/>

<a id="dashboard-charts-are-empty"></a>
### ড্যাশবোর্ড চার্টগুলি খালি

আপনি কেবল **বিনামূল্যের মডেল** ব্যবহার করলে (খরচ চার্ট ফাঁকা থাকবে) বা নির্বাচিত **সময় ফিল্টার** থেকে কলগুলি করার সময়কালকে যদি কভার না করে — পরীক্ষা করতে **সব** চয়ন করুন, এটি সাধারণ।

**সব** নির্বাচনের পরও যদি চার্টগুলি খালি থাকে, তাহলে [**ইতিহাস**](#history) বা **সব কল** ট্যাবে কলগুলি দেখা যায় কিনা তা নিশ্চিত করুন।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### খরচ "উপলব্ধ নয়" বা ভুল মনে হয়

যখন আপনি **OpenRouter**-এর মাধ্যমে মডেল ব্যবহার করেন, তখন অ্যাপটি OpenRouter রিপোর্ট করা আপনার প্রকৃত ব্যয় দেখায়।

**অন্যান্য প্রদানকারীদের** (সরাসরি OpenAI, সরাসরি Anthropic ইত্যাদি) জন্য, খরচটি OpenRouter প্রকাশিত মূল্য তথ্য থেকে অনুমান করা হয়। যদি একটি মডেলের জন্য মিল পাওয়া যায় না, তাহলে খরচ **উপলব্ধ নয়** হিসেবে দেখানো হবে এবং আপনার চলমান মোটের সাথে যোগ করা হবে না।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### মোট খরচ আমার প্রদানকারীর বিলের সাথে মেলে না

অ্যাপের সমস্ত খরচ চিত্রগুলি কেবলমাত্র **প্রতিটি অনুমানিত তথ্যের জন্য**, আনুমানিক নিষ্পত্তিপত্র, আধিকারিক বিলিং বিবৃতি নয়।

আপনার প্রকৃত OpenRouter ব্যয় আরও কাছাকাছি নিতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking) খুলুন এবং **API কী ব্যবহারের সাথে সিঙ্ক করুন** ক্লিক করুন।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### সাইডবার থেকে ইতিহাস পাতা অনুপস্থিত

**ক্রিয়াং ইতিহাস রাখুন** বন্ধ করা থাকতে পারে। [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং এটি চালু করুন। সতর্কীকরণ: এটি চালু করলে ইতিমধ্যে মুছে ফেলা ইতিহাসের তথ্য পুনরুদ্ধার হবে না।

<br/>

<a id="web-app-session-expired"></a>
### ওয়েব অ্যাপ: অপ্রত্যাশিতভাবে লগইন পাতায় পুনঃনির্দেশ হয়েছে

আপনার সেশন শেষ হয়ে গেছে হতে পারে। পুনরায় লগিন করুন। যদি এটি প্রায়শই ঘটে, তাহলে সেশন আয়ু সেটিংসের জন্য সার্ভার কনফিগারেশন পরীক্ষা করুন।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ড্যাশবোর্ড অন্যান্য ব্যবহারকারীদের জন্য তথ্য দেখায় না (ওয়েব)

কেবল **প্রশাসকরা** **ব্যবহারকারী** ফিল্টারের মাধ্যমে সমস্ত ব্যবহারকারীর ডেটা দেখতে পারে। স্বয়ংক্রিয়ভাবে সাধারণ ব্যবহারকারীরা কেবল নিজেদের নিজস্ব ক্রিয়াকলাপ দেখে।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### আমি একটি প্রম্পট পরিবর্তন করেছি এবং সম্পাদনাগুলি হারিয়ে ফেলেছি

প্রম্পট সম্পাদনা করার সময়, সবসময় **সেভ** ক্লিক করুন এবং তারপর **রানে ফিরুন** এ ক্লিক করুন।

<a id="quick-tips"></a>
## দ্রুত টিপস

- প্রথমে [**অনুবাদ করুন**](#translate) এ শুরু করুন যাতে আপনার সেটআপটি কাজ করছে কিনা তা নিশ্চিত করুন, তারপর [**পুনরায় লিখুন**](#rewrite) বা [**রূপান্তর করুন**](#transform) এ যান।
- দৈনিক ভাষা উন্নতির জন্য [**পুনরায় লিখুন**](#rewrite) ব্যবহার করুন।
- নির্দিষ্ট কাজের জন্য পুনরাবৃত্তিযোগ্য কাজের ধারা প্রয়োজন হলে [**রূপান্তর করুন**](#transform) ব্যবহার করুন।
- ব্যবহার এবং খরচ নজরে রাখতে [**ড্যাশবোর্ড**](#dashboard) ব্যবহার করুন।
- পূর্ববর্তী কাজগুলি এবং তাদের পূর্ণ ইনপুট/আউটপুট টেক্সট পর্যালোচনা করতে [**ইতিহাস**](#history) ব্যবহার করুন।
- আপনি যদি প্রম্পট লাইব্রেরি তৈরি করছেন যা সংরক্ষণ করতে চান বা অন্যদের সাথে শেয়ার করতে চান, তবে নিয়মিত প্রম্পটগুলি রপ্তানি করুন (দেখুন [ট্রান্সফর্ম প্রম্পটগুলি](#transform-prompts))।
