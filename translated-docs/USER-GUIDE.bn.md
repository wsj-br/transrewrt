# ব্যবহারকারী গাইড

<br/>

<a id="introduction"></a>
## ভূমিকা

Transrewrt আপনাকে তিনটি প্রধান উপায়ে টেক্সট নিয়ে কাজ করতে সাহায্য করে:

- **অনুবাদ** - একটি ভাষা থেকে অন্য ভাষায় টেক্সট রূপান্তর করুন।
- **পুনর্লিখন** - স্পষ্টতর, সংক্ষিপ্ত বা আরও আনুষ্ঠানিক ইত্যাদি ভিন্ন শৈলীতে টেক্সট পুনরায় লিখুন।
- **রূপান্তর** - প্রম্পট নামে পরিচিত কাস্টম এআই নির্দেশনা ব্যবহার করে টেক্সট প্রক্রিয়া করুন।

<br/>

এই গাইডটি অ্যাপ ইনস্টল করা এবং চালু করার পরে এটি কীভাবে ব্যবহার করতে হয় তা ব্যাখ্যা করে। ইনস্টলেশনের ধাপগুলির জন্য, প্রধান **[README](README.bn.md)** দেখুন।

<br/>

> ℹ️ **নোট**<br/>
> Transrewrt উইন্ডোজ এবং লিনাক্সের জন্য ডেস্কটপ অ্যাপ হিসাবে এবং স্ব-হোস্টেড ওয়েব অ্যাপ হিসাবে উপলব্ধ। এই গাইডটি অ্যাপটির দৈনিক ব্যবহার নিয়ে কেন্দ্রিত। যেখানে কিছু শুধুমাত্র একটি সংস্করণের জন্য প্রযোজ্য, সেখানে এটি স্পষ্টভাবে চিহ্নিত করা হয়েছে।

<a id="before-you-start"></a>
## শুরু করার আগে

Transrewrt ব্যবহার করতে, আপনার কমপক্ষে একটি এআই প্রদানকারীর অ্যাক্সেস প্রয়োজন। সমর্থিত প্রদানকারীগুলি হল: [OpenRouter](https://openrouter.ai) (যা অনেক মডেল একত্রিত করে), OpenAI, অ্যানথ্রোপিক, Google Gemini, ডিপসিক, গ্রোক, মিস্ট্রাল, xAI, Cerebras, এবং স্থানীয় মডেলের জন্য [Ollama](https://ollama.com)।

শুরু করার জন্য আপনার কোনো পেইড মডেল নির্বাচন করার প্রয়োজন নেই। আপনি যতক্ষণ আপনার OpenRouter API কী যোগ করবেন, অ্যাপটি স্বয়ংক্রিয়ভাবে একটি অন্তর্নির্মিত **বিনামূল্যে** OpenRouter বিকল্প সক্ষম করবে। এটি আপনাকে অবিলম্বে টেক্সট অনুবাদ, পুনর্লিখন এবং রূপান্তর শুরু করতে দেয়। বিকল্পভাবে, আপনি Cerebras, Google, Groq বা Mistral AI থেকে একটি বিনামূল্যে API কী পেতে পারেন।

সাধারণ ভাষায়:

- একটি **মডেল** হল এআই ইঞ্জিন যা কাজ করে। মডেলগুলি **প্রদানকারী উপসর্গ** সহ তালিকাভুক্ত করা হয় (উদাহরণস্বরূপ `openrouter/…`, `openai/…`, `ollama/…`)।
- একটি **API কী** (অথবা Ollama-এর ক্ষেত্রে, একটি **বেস URL**) হল অ্যাপটি যে উপায়ে প্রদানকারীর সাথে যোগাযোগ করে।

যদি আপনি **ডেস্কটপ অ্যাপ** ব্যবহার করেন, তবে আপনি যে প্রতিটি প্রদানকারী ব্যবহার করেন তাদের জন্য [**সেটিংস** > **API কনফিগ**](#api-config) এ কী যোগ করুন। শুধুমাত্র OpenRouter ব্যবহারের জন্য, নীচে [একটি API কী পাওয়ার পদ্ধতি](#how-to-get-an-api-key-desktop-app) দেখুন। যদি আপনি কোনো API কী ব্যবহার করতে না চান, তবে আপনি Ollama ইনস্টল করতে পারেন ([ollama.com](https://ollama.com) থেকে) এবং `translategemma:4b` এর মতো স্থানীয় মডেল ব্যবহার করতে পারেন।

যদি আপনি **ওয়েব সংস্করণ** ব্যবহার করেন, তবে সার্ভার মালিক পরিবেশ পরিবর্তনশীল ব্যবহার করে প্রদানকারীদের কনফিগার করেন, তাই আপনি অ্যাপ্লিকেশনে সরাসরি API কী প্রবেশ করতে পারবেন না।

<a id="how-to-get-an-api-key-desktop-app"></a>
### কীভাবে একটি বিনামূল্যে OpenRouter API কী পাবেন (ডেস্কটপ অ্যাপ)

যদি আপনি ডেস্কটপ অ্যাপ ব্যবহার করেন, তবে এই পদক্ষেপগুলি অনুসরণ করুন:

1. আপনার ওয়েব ব্রাউজারে [OpenRouter](https://openrouter.ai)-এ যান।
2. একটি অ্যাকাউন্ট তৈরি করুন বা সাইন ইন করুন।
3. [Keys](https://openrouter.ai/keys) পৃষ্ঠাটি খুলুন।
4. একটি নতুন API কী তৈরি করতে বোতামটি ক্লিক করুন।
5. পরে আপনি যাতে এটি চিনতে পারেন সেজন্য কীটির একটি নাম দিন।
6. নতুন API কীটি কপি করুন।
7. Transrewrt-এ ফিরে যান এবং **সেটিংস** > **API কনফিগ** খুলুন।
8. **OpenRouter API কী**-এ কীটি পেস্ট করুন (**সেটিংস** > **API কনফিগ**-এর অধীনে)।
9. এটি কাজ করছে কিনা তা নিশ্চিত করতে **OpenRouter কী পরীক্ষা করুন** ক্লিক করুন।

<a id="getting-started"></a>
## শুরু করা

যদি এটি আপনার প্রথমবার Transrewrt ব্যবহার করা হয়, তবে এই ক্রমটি অনুসরণ করুন:

1. অ্যাপটি খুলুন।
2. প্রয়োজনে গ্লোব আইকন থেকে আপনার **ইন্টারফেস ভাষা** নির্বাচন করুন।
3. যদি আপনি **ডেস্কটপ অ্যাপ**-এ থাকেন, তাহলে [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন, অন্তত একটি প্রদানকারীর জন্য (যেমন OpenRouter) একটি API কী যোগ করুন এবং এটি কাজ করছে কিনা তা যাচাই করতে **পরীক্ষা করুন** ক্লিক করুন।
4. [**সেটিংস** > **মডেল**](#models) খুলুন এবং এক বা একাধিক মডেল **নির্বাচিত মডেল**-এ যোগ করুন।
5. [**সেটিংস** > **ভাষা**](#languages) খুলুন এবং আপনার সবচেয়ে বেশি ব্যবহৃত ভাষাগুলি প্রথমে দেখানোর জন্য **শীর্ষ ভাষা** নির্বাচন করুন।
6. **অনুবাদ করুন**-এ যান এবং সবকিছু কাজ করছে কিনা তা নিশ্চিত করতে একটি সাধারণ অনুবাদ চালান।
7. এটি কাজ করলে, **পুনঃলেখন করুন** এবং তারপর **রূপান্তর করুন** চেষ্টা করুন।

এই ক্রমটি গুরুত্বপূর্ণ। এটি প্রথমবার ব্যবহারের সময় সবচেয়ে সাধারণ সমস্যাটি প্রতিরোধ করে: অ্যাপের কাছে কার্যকর API সংযোগ বা নির্বাচিত মডেল না থাকা সত্ত্বেও কোনো কাজ চালানোর চেষ্টা করা।

### টুলবার

অ্যাপের কোন অংশে আপনি আছেন তার উপর নির্ভর করে টুলবারটি সামান্য পরিবর্তিত হয়।

- বামদিকে, এটি বর্তমান পৃষ্ঠার নাম দেখায়।
- ডানদিকে, এটি **মডেল সিলেক্টর** এবং **ইন্টারফেস ভাষা** নিয়ন্ত্রণ দেখায়।

**মডেল সিলেক্টর** আপনাকে বর্তমান কাজের জন্য কোন এআই ইঞ্জিন ব্যবহার করবেন তা নির্বাচন করতে দেয়।

![Model selector](../images/screenshots/bn/model-selector.png)

কিছু বিনামূল্যের মডেল সবসময় উপলব্ধ নাও হতে পারে—কখনও কখনও তারা অফলাইন থাকে অথবা ব্যবহারের সীমা থাকে। এমন হলে, অ্যাপটি স্বয়ংক্রিয়ভাবে আপনার উপলব্ধ তালিকা থেকে সেই মডেলটি সরিয়ে দেবে। কোন মডেলগুলি দেখাবে তা নিয়ন্ত্রণ করতে, [**সেটিংস** > **মডেল**](#models) এ যান এবং আপনার মডেলের তালিকা সম্পাদনা করুন। 
 আপনি টুলবারে মডেলের নামের বাম দিকে প্রদানকারীর আইকনে ক্লিক করেও সরাসরি মডেল সেটিংস খুলতে পারেন।

<br/>

**গ্লোব আইকন + ভাষার কোড** অ্যাপের ইন্টারফেস ভাষা, যেমন মেনু এবং বোতামগুলি পরিবর্তন করে। এটি **অনুবাদ**-এ ব্যবহৃত অনুবাদ ভাষাগুলি পরিবর্তন করে **না**।

![Interface language selector](../images/screenshots/bn/language-selector.png)

<a id="input-and-output-panels"></a>
### ইনপুট এবং আউটপুট প্যানেল

অধিকাংশ ওয়ার্কস্পেস বাম দিকের **ইনপুট** প্যানেল এবং ডান দিকের **আউটপুট** প্যানেল ব্যবহার করে।

প্রতিটি প্যানেলে নিম্নলিখিতগুলিও দেখানো হয়:

| **ইনপুট**                                                          | **আউটপুট**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - অক্ষর সংখ্যা <br/>- শব্দ সংখ্যা <br/>- অনুচ্ছেদ সংখ্যা   <br/> | - কাজটি কতক্ষণ সময় নিয়েছে <br/>- **TPS** (প্রতি সেকেন্ডে টোকেনস)<br/>- অক্ষর, শব্দ এবং অনুচ্ছেদের সংখ্যা <br/>- ব্যবহৃত মডেল |

যদি আপনি প্রযুক্তিগত শব্দগুলি সম্পর্কে ভাবছেন:

- **টোকেন** মানে পাঠ্যের একটি ছোট অংশ। আপনি এটিকে একটি শব্দের অংশ বা একটি ছোট শব্দ হিসাবে ভাবতে পারেন।
- **TPS** মানে প্রতি সেকেন্ডে মডেলটি কতগুলি পাঠ্য অংশ প্রক্রিয়া করেছে।

<br/>

আপনি প্রতিটি ক্রিয়াকলাপের খরচ (যদি উপলব্ধ থাকে) এবং মোট খরচ নজরদারি করতে পারেন, [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) এ `Show cost information on the actions` বিকল্পটি সক্ষম করে।

## অনুবাদ

আপনি যখন একটি ভাষা থেকে অন্য ভাষায় পাঠ্য রূপান্তর করতে চান তখন **অনুবাদ** ব্যবহার করুন।

![Translate workspace](../images/screenshots/bn/translate.png)

<br/>

<a id="translate-text"></a>
### পাঠ্য অনুবাদ করুন

1. **অনুবাদ করুন** খুলুন।
2. **থেকে**-এ একটি ভাষা নির্বাচন করুন।
3. **করে**-এ একটি ভাষা নির্বাচন করুন।
4. টুলবারে একটি মডেল নির্বাচন করুন।
5. **ইনপুট**-এ টেক্সট টাইপ করুন বা পেস্ট করুন।
6. **অনুবাদ করুন** ক্লিক করুন।
7. **আউটপুট**-এ ফলাফল পড়ুন।
8. ফলাফল কপি করতে চাইলে কপি বোতামটি ব্যবহার করুন।

<br/>

<a id="language-selection"></a>
### ভাষা নির্বাচন

- **থেকে** একটি নির্দিষ্ট ভাষা হতে পারে অথবা **ভাষা সনাক্ত করো**।
- **কাছে** হল আপনি যে ভাষাতে ফলাফল চান।

আপনার নির্বাচিত **শীর্ষ ভাষা**গুলি তালিকার উপরে দেখানো হয়। আপনি [**সেটিংস** > **ভাষা**](#languages) এ এগুলি সেট করতে পারেন।

<br/>

<a id="helpful-translation-settings"></a>
### সহায়ক অনুবাদ সেটিংস

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) এ, আপনি অনুবাদের আচরণ কীভাবে পরিবর্তন করতে পারেন:

- **পেস্ট করার সাথে সাথে স্বয়ংক্রিয় অনুবাদ** আপনি যখনই কোনো টেক্সট পেস্ট করবেন তখনই একটি অনুবাদ চালায়।
- **ফলাফল ক্লিপবোর্ডে স্বয়ংক্রিয়ভাবে কপি করুন** সফলভাবে চালানোর পরে ফলাফলটি স্বয়ংক্রিয়ভাবে কপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** আপনি টাইপ করার সময় অনুবাদ চালায়।
- **টাইমআউট (মিলিসেকেন্ড)** রিয়েল-টাইম অনুবাদ চালানোর আগে অ্যাপটি কতক্ষণ অপেক্ষা করবে তা নিয়ন্ত্রণ করে।
- **Enter** চাপলে কী ঘটবে তা নিয়ন্ত্রণ করে `Enter`:

## পুনর্লিখন

**পুনর্লিখন** ব্যবহার করুন যখন আপনি মূল অর্থ পরিবর্তন না করেই ভাষার উন্নতি করতে চান।

![Rewrite workspace](../images/screenshots/bn/rewrite.png)

এটি নিম্নলিখিত ক্ষেত্রে কার্যকর:

- বানান ও ব্যাকরণ ঠিক করা (**বানান ও ব্যাকরণ পরীক্ষা করুন**)
- টেক্সটকে আরও স্পষ্ট করা (**স্পষ্টতা উন্নত করুন**)
- একটি চালানোর মধ্যে একাধিক আলাদা পুনঃসংগঠন (**বিকল্প সংস্করণ**)
- টেক্সটকে আরও আনুষ্ঠানিক বা অনানুষ্ঠানিক করা (**আনুষ্ঠানিক** / **অনানুষ্ঠানিক**)
- টেক্সট সংক্ষিপ্ত বা প্রসারিত করা (**সংক্ষিপ্ত করুন** / **প্রসারিত করুন**)
- টেক্সটকে আরও প্রযুক্তিগত করা (**প্রযুক্তিগত করুন**)

<br/>

> 💡 **টিপ**<br/>
> যখন আপনি "**বানান ও ব্যাকরণ পরীক্ষা করো**" মোডটি ব্যবহার করেন, তখন আউটপুট প্যানেলে (**কপি**-এর পাশে) একটি **পরিবর্তন দেখাও** সুইচ দেখা যায়।
> আপনার টেক্সটে প্রয়োগ করা নির্দিষ্ট সংশোধনগুলি দেখানো বা লুকানোর জন্য এটি চালু বা বন্ধ করুন।

<a id="transform"></a>
## রূপান্তর

**রূপান্তর** ব্যবহার করুন যখন আপনি চান যে এআই কাস্টম নির্দেশনার একটি সেট অনুসরণ করুক।

![Transform workspace](../images/screenshots/bn/transform.png)

এটি অ্যাপের সবচেয়ে নমনীয় অংশ। আপনি এটি নিম্নলিখিত কাজগুলির জন্য ব্যবহার করতে পারেন:

- নোটগুলির সারাংশ তৈরি করা
- খসড়া টেক্সটকে একটি পরিশীলিত ইমেলে রূপান্তর করা
- মূল বিষয়গুলি বেছে নেওয়া
- টেক্সটকে একটি নির্দিষ্ট ফরম্যাটে রূপান্তর করা
- ইনপুট টেক্সটের সাথে অন্য যেকোনো কাস্টম ক্রিয়াকলাপ

<br/>

<a id="run-an-existing-prompt"></a>
### একটি বিদ্যমান প্রম্পট চালান

1. **ট্রান্সফর্ম** খুলুন।
2. প্রম্পট তালিকা থেকে একটি প্রম্পট চয়ন করুন।
3. যদি একটি **লক্ষ্য** ভাষার বাক্স দেখায়, চাইলে একটি ভাষা চয়ন করুন।
4. **ইনপুট**-এ টেক্সট টাইপ করুন বা পেস্ট করুন।
5. **ট্রান্সফর্ম** ক্লিক করুন।
6. **আউটপুট**-এ ফলাফল পড়ুন।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### যদি আপনার কোন প্রম্পট না থাকে

যদি আপনার প্রম্পট তালিকা খালি থাকে, তবে রূপান্তর ওয়ার্কস্পেসে **নমুনা প্রম্পট লোড করো** ক্লিক করুন। একই নিয়ন্ত্রণটি সর্বদা [**সেটিংস** > **ট্রান্সফর্ম প্রম্পট**](#transform-prompts) এ এক্সপোর্ট/ইম্পোর্ট সারিতে পাওয়া যায়। উভয়ই অন্তর্নির্মিত উদাহরণ যোগ করে যাতে আপনি দ্রুত শুরু করতে পারেন।

<br/>

> ℹ️ **নোট**<br/>
> নমুনা প্রম্পটগুলি ইংরেজিতে প্রদান করা হয়। সেগুলি লোড করার পরে, আপনি একটি প্রম্পট সম্পাদনা করতে পারেন এবং এটিকে আপনার ভাষায় অনুবাদ করতে **অনুবাদ অনুরোধ** ব্যবহার করতে পারেন।

<br/>

<a id="create-a-prompt-quickly"></a>
### দ্রুত একটি প্রম্পট তৈরি করুন

একটি প্রম্পট তৈরি করার সবচেয়ে দ্রুত উপায় হল:

1. **নতুন প্রম্পট** ক্লিক করুন।
2. **প্রম্পট তৈরি করুন** ক্লিক করুন।
3. আপনি চান যে প্রম্পটটি কী করুক তা বর্ণনা করুন।
4. একটি মডেল চয়ন করুন।
5. অ্যাপটি আপনার জন্য একটি খসড়া তৈরি করুক।
6. খসড়াটি পর্যালোচনা করুন এবং **সংরক্ষণ** ক্লিক করুন।

![Generate prompt](../images/screenshots/bn/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### একটি প্রম্পট সম্পাদনা করুন

যখন আপনি একটি প্রম্পট তৈরি বা সম্পাদনা করেন, তখন সম্পাদক বাম দিকে এবং একটি পরীক্ষার এলাকা ডান দিকে দেখা যায়।

![Transform prompt editor](../images/screenshots/bn/transform-prompt-edit.png)

প্রধান ক্ষেত্রগুলি হল:

- **প্রম্পটের নাম**: প্রম্পট তালিকায় দেখানো নাম।
- **প্রম্পট নির্দেশাবলী (ঐচ্ছিক)**: প্রম্পট চালানোর সময় ব্যবহারকারীকে দেখানো একটি সংক্ষিপ্ত সূত্র।
- **মডেল ভূমিকা**: এআই-কে নির্ধারিত সামগ্রিক ভূমিকা, যেমন 'আপনি একজন সহায়ক সহকারী।'
- **মডেল নির্দেশাবলী (প্রতি লাইনে একটি)**: আপনি চান যে এআই অনুসরণ করুক এমন নির্দিষ্ট নিয়ম।
- **আউটপুট বর্ণনা**: ফলাফলের বর্ণনা করার জন্য একটি সংক্ষিপ্ত শব্দ, যেমন 'সারাংশ' বা 'পুনঃলেখন'।
- **তাপমাত্রা (0.0 → 1.0)**: মডেলটি কীভাবে আচরণ করবে; নীচে দেখুন।
- **লক্ষ্য ভাষা জিজ্ঞাসা করুন**: প্রম্পট চালানোর সময় একটি লক্ষ্য ভাষা নির্বাচক যোগ করে।

যদি প্রযুক্তিগত শব্দ **তাপমাত্রা** আপনার কাছে নতুন হয়, তবে এটিকে এভাবে ভাবুন:

- **নিম্ন** তাপমাত্রা স্থিতিশীল, অধিকতর পূর্বানুমেয় ফলাফল দেয়।
- **উচ্চ** তাপমাত্রা আরও বৈচিত্র্য এবং সৃজনশীলতা দেয়।

আপনি এটিও ব্যবহার করতে পারেন:

- **`Generate prompt`** একটি সহজ বিবরণ থেকে একটি নতুন খসড়া তৈরি করতে
- **`Improve prompt`** একটি বিদ্যমান প্রম্পট পরিশোধন করতে
- **`Translate prompt`** প্রম্পট ক্ষেত্রগুলি অনুবাদ করতে

<br/>

> ⚠️ **সতর্কবার্তা**<br/>
> **`Back to Run`** এ ক্লিক করার আগে **`Save`** এ ক্লিক করুন। আপনি যদি সংরক্ষণ না করে ফিরে যান, তাহলে আপনার পরিবর্তনগুলি হারিয়ে যাবে।

<a id="test-a-prompt-before-using-it"></a>
### ব্যবহারের আগে একটি প্রম্পট পরীক্ষা করুন

ডানদিকের পরীক্ষার প্যানেলটি আপনাকে দৈনন্দিন কাজে ব্যবহার করার আগে নমুনা টেক্সট দিয়ে আপনার প্রম্পট চেষ্টা করতে দেয়।

এটি তখন কাজে আসে যখন:

- আপনি একটি নতুন প্রম্পট তৈরি করছেন
- আপনি একটি প্রম্পটের দুটি সংস্করণ তুলনা করছেন
- আপনি টোন, দৈর্ঘ্য বা আউটপুট ফরম্যাট পরীক্ষা করতে চান

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> আপনি [**সেটিংস** > **ট্রান্সফর্ম প্রম্পট**](#transform-prompts) এ সংরক্ষিত প্রম্পটগুলি রপ্তানি এবং আমদানি করতে পারেন।

### ড্যাশবোর্ড ট্যাব

- **সারাংশ** আপনাকে ব্যবহার ও খরচের একটি ওভারভিউ দেয়। এতে অন্তর্ভুক্ত রয়েছে **সময়ের সাথে ব্যবহার** (দৈনিক অনুবাদ, পুনঃলেখন এবং রূপান্তরের জন্য দৈনিক সংযুক্ত **কল সংখ্যা**) এবং **মডেল অনুযায়ী ব্যবহার** (মোট **মডেল প্রতি কল**, রূপান্তরসহ)।
- **ব্যবহার অনুযায়ী** ক্রিয়াকলাপকে অনুবাদের ভাষা, পুনঃলেখন মোড এবং রূপান্তর প্রম্পট অনুযায়ী ভাগ করে।
- **মডেল অনুযায়ী** আপনি কোন মডেলগুলি ব্যবহার করেছেন এবং তাদের খরচ কত তা দেখায়।
- **দিন অনুযায়ী** দৈনিক মোট দেখায়।
- **সমস্ত কল** সম্পূর্ণ কল ইতিহাস দেখায় এবং এটি রপ্তানি করার অনুমতি দেয়।

সমস্ত ডেটা মুছে ফেলতে বা রেকর্ডগুলি তাদের বয়স অনুযায়ী মুছতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking)-এ যান। সেখানে আপনি সমস্ত সংরক্ষিত ডেটা মুছে ফেলার বা নির্দিষ্ট তারিখের আগের ডেটা মুছার বিকল্পগুলি পাবেন।

### সাধারণ সেটিংস

টাইপ করার আচরণ, **ইতিহাস**-এর জন্য কার্যকরণের বিবরণ সংরক্ষিত হবে কিনা এবং চেহারা নিয়ন্ত্রণ করতে **সাধারণ সেটিংস** ব্যবহার করুন।

**আচরণ**

- **ENTER-এর আচরণ** নির্ধারণ করে যে `Enter` কাজটি চালাবে নাকি একটি নতুন লাইন সন্নিবেশ করবে।
- **পেস্ট করার সাথে সাথে স্বয়ংক্রিয় অনুবাদ** আপনি যখনই টেক্সট পেস্ট করবেন তখনই অনুবাদ শুরু হবে।
- **ফলাফল ক্লিপবোর্ডে স্বয়ংক্রিয়ভাবে কপি করুন** সফল ফলাফলগুলি স্বয়ংক্রিয়ভাবে কপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** টাইপ করার সময় অনুবাদ করে।
- **টাইমআউট (মিলিসেকেন্ড)** রিয়েল-টাইম অনুবাদের জন্য অপেক্ষার সময় নির্ধারণ করে।

**ইতিহাস**

- **চালনের ইতিহাস রাখো** নিয়ন্ত্রণ করে যে প্রতিটি অনুবাদ, পুনর্লিখন এবং রূপান্তর সাইডবারের [**ইতিহাস**](#history) ভিউয়ের জন্য **ইনপুট এবং আউটপুট টেক্সট** সংরক্ষণ করবে কিনা। এটি বন্ধ করলে নিশ্চিতকরণ চাওয়া হবে; যদি আপনি নিশ্চিত করেন, তবে সংরক্ষিত ইতিহাসের টেক্সট ডেটাবেস থেকে মুছে ফেলা হবে।
- **ইতিহাসের ডেটা মুছে ফেলো** আপনাকে বয়স অনুযায়ী (যেমন কয়েক মাসের পুরানো, অথবা **সমস্ত ডেটা (মুছুন)**) সংরক্ষিত টেক্সট মুছতে দেয় **ডেটা মুছুন** ব্যবহার করে। এটি শুধুমাত্র **ইতিহাস** ভিউয়ের জন্য সংরক্ষিত কার্যকরণের টেক্সটকে প্রভাবিত করে; এটি **খরচ** বা ব্যবহারের মোট সংখ্যা মুছে ফেলে না। **খরচ** ডেটা মুছতে বা কাটতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking) ব্যবহার করুন।

**চেহারা**

- **ক্রিয়াকলাপগুলিতে খরচের তথ্য প্রদর্শন করুন** অপারেশন প্রতি খরচ (যদি উপলব্ধ থাকে) এবং অনুবাদ, পুনর্লেখন এবং রূপান্তর আউটপুট প্যানেলগুলিতে মোট খরচের প্রদর্শন নিয়ন্ত্রণ করে।
- **খরচের ভগ্নাংশ অঙ্ক** খরচের দশমিক প্রদর্শনের পদ্ধতি পরিবর্তন করে।
- **শুধুমাত্র ওয়েব:** **অ্যাপের চারপাশে মার্জিন দেখান** ইন্টারফেসের চারপাশে অতিরিক্ত জায়গা যোগ করে।
- **ফন্ট ফ্যামিলি** টেক্সট প্যানেলগুলিতে লেখার ফন্ট পরিবর্তন করে।
- **আকার** ফন্টের আকার পরিবর্তন করে।

**কনফিগারেশন ব্যাকআপ**

- **ব্যাকআপে ব্যবহারের তথ্য অন্তর্ভুক্ত করুন** - সক্ষম করলে, ZIP-এ ক্রিয়ান্বয়নের ইতিহাস এবং API কলের তথ্যও থাকে। 
- **ব্যাকআপ কনফিগারেশন** - একটি একক ZIP তৈরি করে (ডিফল্টভাবে UTC-এ `transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`), যাতে `config.json`, `state.json`, ঐচ্ছিক এনক্রিপশন কী, ব্যবহারকারী, পছন্দ, কাস্টম প্রম্পট এবং ব্যবহারের তথ্য থাকে যদি আপনি তা নির্বাচন করে থাকেন। সফল ব্যাকআপের পরে, নিশ্চিতকরণে সংরক্ষিত ফাইলের নাম দেখানো হয়।
- **ব্যাকআপ থেকে পুনরুদ্ধার করুন** - প্রথমে একটি **নিশ্চিতকরণ ডায়ালগ** খোলে। ডায়ালগের ভিতরে ব্যাকআপ ZIP নির্বাচন করুন (**ব্রাউজ করুন** / ফাইল পিকার বা সাপোর্ট করা জায়গায় ড্র্যাগ-অ্যান্ড-ড্রপ), তারপর বিকল্পগুলি পর্যালোচনা করুন:
  - **ব্যবহারের তথ্য পুনরুদ্ধার করুন** - যখন ব্যাকআপের সময় ব্যবহারের তথ্য সহ ব্যাকআপ করা হয়েছে তখন ZIP থেকে ব্যবহার/ইতিহাস আমদানি করুন; শুধুমাত্র সেটিংস এবং প্রম্পট চাইলে এটি বন্ধ রাখুন।
  - **পুনরুদ্ধারের আগে পুরানো ব্যবহারের তথ্য মুছুন** - ব্যাকআপ প্রয়োগ করার আগে এই ইনস্টলেশনে বিদ্যমান ব্যবহার/ইতিহাস মুছে ফেলুন (ঐচ্ছিক; যখন আপনি একটি পরিষ্কার প্রতিস্থাপন চান তখন ব্যবহার করুন)।

ওয়েব বা ডেস্কটপ সংস্করণে তৈরি করা ব্যাকআপগুলি অন্য পক্ষে পুনরুদ্ধার করা যেতে পারে। ওয়েব সংস্করণে একটি ডেস্কটপ ব্যাকআপ পুনরুদ্ধার করার সময়, ডেটা অ্যাডমিনিস্ট্রেটর ব্যবহারকারীতে পুনরুদ্ধার করা হবে।

<a id="models"></a>
### মডেল

টুলবারে কোন মডেলগুলি দেখাবে তা নির্বাচন করতে **সেটিংস** > **মডেল** ব্যবহার করুন।

![Settings Models tab](../images/screenshots/bn/settings-models.png)

পৃষ্ঠাটিতে দুটি তালিকা রয়েছে:

- বাম দিকে **উপলব্ধ মডেলসমূহ**
- ডান দিকে **নির্বাচিত মডেল**

উপযোগী নিয়ন্ত্রণগুলির মধ্যে রয়েছে:

- **মডেলগুলি অনুসন্ধান করুন...** নাম দ্বারা একটি মডেল খুঁজতে
- **প্রদানকারী** চিপস তালিকাটি একটি ইঞ্জিনে (OpenRouter, OpenAI, Ollama, …) সীমিত করতে
- **শুধুমাত্র ফ্রি** শুধুমাত্র ফ্রি মডেল দেখাতে
- **রিফ্রেশ** তালিকা পুনরায় লোড করতে
- **সব প্রসারিত করুন** এবং **সব সংকুচিত করুন** যখন আপনি প্রদানকারী অনুযায়ী সাজাচ্ছেন

মডেল আইডি-এ প্রদানকারীর উপসর্গ অন্তর্ভুক্ত থাকে (উদাহরণস্বরূপ `openrouter/…` বনাম `openai/…`)। **ওপেনএআই (ওপেনরাউটার)** বনাম **ওপেনএআই (সরাসরি)** এর মতো ব্যাজগুলি দেখায় যে ট্রাফিক কীভাবে রাউট করা হয়।

> ℹ️ **নোট**<br/>
> **ওপেনরাউটার বডি বিল্ডার** (`openrouter/bodybuilder`) একটি রাউটার মডেল, সাধারণ চ্যাট মডেল নয়: এর উত্তর হল জেসন যা ওপেনরাউটার এপিআই রিকোয়েস্ট বডিগুলি বর্ণনা করে (উদাহরণস্বরূপ `requests` অ্যারেতে `model` এবং `messages` সহ)। যদি আপনি এটি **অনুবাদ**, **পুনর্লিখন**, বা **রূপান্তর** এর জন্য ব্যবহার করেন, আউটপুট প্যানেলটি সম্পূর্ণ টেক্সটের পরিবর্তে সেই জেসন দেখাবে। এই কাজগুলির জন্য একটি সাধারণ টেক্সট মডেল নির্বাচন করুন। ওপেনরাউটারে [বডি বিল্ডার মডেল পৃষ্ঠা](https://openrouter.ai/openrouter/bodybuilder) দেখুন।

অ্যাকশন:

- একটি মডেল যোগ করতে, **যোগ করুন** অথবা এন্ট্রির যেকোনো জায়গায় ক্লিক করুন।

- একটি মডেল সরাতে, **নির্বাচিত মডেল**-এ এটির পাশের **X** অথবা উপলব্ধ মডেলগুলির এন্ট্রিতে **নির্বাচিত** এ ক্লিক করুন।

- তালিকা মুছে ফেলতে, **সব অনির্বাচন** এ ক্লিক করুন। প্রয়োজনীয় বিনামূল্যে মডেলটি তালিকাতে থাকবে।

<br/>

> ℹ️ **নোট**<br/>
> যদি আপনি ওপেনরাউটারে ক্রেডিট সঙ্গে সঙ্গে যোগ করতে না চান, তাহলে **শুধু বিনামূল্যে** সক্রিয় করে শুরু করুন এবং বিনামূল্যে মডেলগুলি নির্বাচন করুন (ক্রেডিট কার্ডের প্রয়োজন নেই)। আপনি কোনো এপিআই কী ছাড়াই মডেল স্থানীয়ভাবে চালাতে ওলামাও ব্যবহার করতে পারেন।

<a id="languages"></a>
### ভাষা

অ্যাপে ব্যবহৃত ভাষার তালিকা সাজাতে **সেটিংস** > **ভাষা** ব্যবহার করুন।

- **শীর্ষ ভাষা** গুলি **অনুবাদ** এবং **রূপান্তর**-এ ভাষার তালিকার উপরের দিকে পিন করা থাকে।
- **কাস্টম ভাষা** আপনাকে অন্তর্ভুক্ত তালিকায় না থাকা একটি ভাষা যোগ করতে দেয়।

আপনি যদি একটি কাস্টম ভাষা যোগ করেন, তবে এটি অন্তর্ভুক্ত বিকল্পগুলির পাশাপাশি ভাষা নির্বাচকগুলিতে দেখা যাবে।

<a id="cost-tracking"></a>
### খরচ ট্র্যাকিং

খরচের তথ্য পরিচালনা করতে **সেটিংস** > **খরচ ট্র্যাকিং** ব্যবহার করুন।

- **মোট খরচ** চলমান মোট দেখায়।
- **মান কপি করুন** মোট মানটি ক্লিপবোর্ডে কপি করে।
- **খরচ রিসেট করুন** সংরক্ষিত মোট শূন্যে রিসেট করে।
- **API কী ব্যবহারের সাথে সিঙ্ক করুন** মোট মানটি আপনার OpenRouter অ্যাকাউন্ট দ্বারা প্রতিবেদিত ব্যবহারের সাথে মিলিয়ে সেট করে (শুধুমাত্র OpenRouter)।
- **API কী ব্যবহার** OpenRouter ব্যবহারের বিস্তারিত তথ্য দেখায়, যদি উপলব্ধ থাকে।
- **খরচের তথ্য মুছুন** সমস্ত তথ্য মুছে ফেলে, অথবা নির্বাচিত তারিখের আগের এন্ট্রিগুলি মাত্র।

**খরচ ট্র্যাকিং:** যখন আপনি ওপেনরাউটার মডেল ব্যবহার করেন, তখন অ্যাপটি ওপেনরাউটার থেকে খরচের তথ্যের ভিত্তিতে আপনার প্রকৃত ব্যবহার এবং ব্যয় দেখায়। অন্য সমস্ত প্রদানকারীদের জন্য, অ্যাপটি ওপেনরাউটার দ্বারা প্রকাশিত মূল্য ব্যবহার করে খরচের অনুমান করে, যদি কোনো মূল্য অপ্রাপ্য হয়, তবে অনুমান শূন্য হতে পারে।

> ℹ️ **নোট**<br/>
>  **সমস্ত খরচের চিত্র শুধুমাত্র আপনার তথ্যের জন্য অনুমান, আনুষ্ঠানিক বিলিং বিবৃতি নয়।**

> ডেটা মুছে ফেলা হলে তা পুনরুদ্ধার করা যাবে না। মুছার আগে, অবশ্যই আপনার ডেটা ব্যাকআপ করুন অথবা [**ইতিহাস**](#history) বা [**ড্যাশবোর্ড** > **সমস্ত কল**](#dashboard-tabs) এর মাধ্যমে এক্সপোর্ট করুন, অন্যথায় এটি চিরতরে হারিয়ে যাবে।
> প্রতিটি API কল এন্ট্রির সাথে সম্পর্কিত সমস্ত ইনপুট/আউটপুট ইতিহাসও মুছে ফেলা হবে।

<a id="transform-prompts"></a>
### ট্রান্সফর্ম প্রম্পট

**সেটিংস** > **ট্রান্সফর্ম প্রম্পট** ব্যবহার করে আপনি প্রম্পটগুলি একসাথে পরিচালনা করতে পারেন।

আপনি পারেন:

- আপনার সংরক্ষিত প্রম্পটগুলি পর্যালোচনা করুন
- প্রম্পটগুলি মুছুন
- একটি ফাইল থেকে প্রম্পট আমদানি করুন
- ব্যাকআপ বা শেয়ার করার জন্য প্রম্পট রপ্তানি করুন
- প্রম্পট তালিকায় নমুনা প্রম্পট লোড করুন

<a id="users"></a>
### ব্যবহারকারীরা

ওয়েব সংস্করণে ব্যবহারকারী অ্যাকাউন্টগুলি পরিচালনা করতে **ব্যবহারকারীদের** ব্যবহার করুন। আপনি ব্যবহারকারী যোগ করতে পারেন, তাদের বিবরণ আপডেট করতে পারেন, পাসওয়ার্ড রিসেট করতে পারেন এবং অ্যাকাউন্টগুলি মুছে ফেলতে পারেন।

<a id="api-config"></a>
### API কনফিগ

সমর্থিত প্রদানকারীদের মধ্যে রয়েছে: ওপেনরাউটার, ওপেনএআই, অ্যানথ্রোপিক, গুগল জেমিনি, ডিপসিক, গ্রোক, মিস্ট্রাল, এক্সএআই, Cerebras এবং **ওলামা** (বেস ইউআরএলের মাধ্যমে স্থানীয় মডেল)। আপনি শুধুমাত্র আপনার ব্যবহৃত প্রদানকারীদের কনফিগার করার প্রয়োজন হবে।

**ওয়েব অ্যাপ্লিকেশন: শুধুমাত্র প্রশাসক**

API কীগুলি সিস্টেম বা ডকার পরিবেশ ভেরিয়েবলের মাধ্যমে কনফিগার করা হয় - ওয়েব UI-এ এগুলি প্রবেশ করানো হয় না। এই পৃষ্ঠাটি দেখায় কোন প্রদানকারীদের জন্য একটি কী কনফিগার করা হয়েছে এবং আপনি **`Test`** বোতামে ক্লিক করে প্রতিটি পরীক্ষা করতে পারেন।

<br/>

> ℹ️ **নোট**<br/>
> API কী পরিবর্তন করতে, আপনার সিস্টেম বা ডকার কনফিগারেশনে পরিবেশ ভেরিয়েবল আপডেট করুন এবং সার্ভার বা কনটেইনার পুনরায় চালু করুন।

> ℹ️ **নোট**<br/>
> **কনফিগারেশন ব্যাকআপ** (দেখুন [**সাধারণ সেটিংস** → কনফিগারেশন ব্যাকআপ](#general-settings)) ZIP এর `config.json` এর ভিতরে **রেজলভড** প্রদানকারী কী এম্বেড করতে পারে। সেই ZIP পুনরুদ্ধার করা হলে সার্ভারের স্থায়ী কনফিগ ফাইলে সেই কীগুলি ফিরে কপি করা হয় **না** - এখানে বর্ণিত হিসাবে লাইভ কী এখনও পরিবেশ এবং বিদ্যমান ফাইল অবস্থা থেকে আসে।

<br/>

**ডেস্কটপ অ্যাপ্লিকেশন**

**API কনফিগ** ব্যবহার করে আপনি যে প্রদানকারীদের ব্যবহার করেন তাদের জন্য API কী সংরক্ষণ করতে পারেন। ওলামার জন্য, API কী নয়, বরং **বেস ইউআরএল** প্রবেশ করান।

<br/>

> 💡 **টিপ** <br/>
> যদি আপনি API কী ব্যবহার করতে না চান বা ব্যবহারের জন্য অর্থ প্রদান করতে না চান, তবে আপনি [ওলামা ডাউনলোড করতে পারেন](https://ollama.com) এবং বিনামূল্যে আপনার মেশিনে স্থানীয়ভাবে মডেলগুলি (যেমন `translategemma:4b`) চালাতে পারেন। বিকল্পভাবে, আপনি তাদের বিনামূল্যে মডেলগুলি ব্যবহার করার জন্য একটি বিনামূল্যে ওপেনরাউটার অ্যাকাউন্ট তৈরি করতে পারেন (ক্রেডিট কার্ড প্রয়োজন নেই), অথবা Cerebras, গুগল, গ্রোক বা মিস্ট্রাল এআই থেকে একটি বিনামূল্যে API কী পেতে পারেন।

<br/>

- শুধুমাত্র আপনার প্রয়োজনীয় প্রদানকারীদের যোগ করুন। **সেটিংস** > **মডেল**-এ, প্রতিটি মডেল আইডি প্রদানকারী দিয়ে শুরু হয় (উদাহরণস্বরূপ `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

API কী যোগ করতে, মানটি টেক্সট ফিল্ডে প্রবেশ করান এবং **`Save`** বোতামে ক্লিক করুন। বিদ্যমান কী প্রতিস্থাপন করতে, **`Edit`** বোতামে ক্লিক করুন। কীটি কাজ করছে কিনা তা যাচাই করতে, **`Test`** বোতামে ক্লিক করুন। ওলামা বেস ইউআরএল-এর জন্য, সংযোগ পরীক্ষা করতে সর্বদা **`Test`** বোতামে ক্লিক করুন।

<br/>

> ℹ️ **নোট**<br/>
> আপনি বর্তমান API কী-এর মান দেখতে পারবেন না। আপনি শুধুমাত্র **`Edit`** বোতাম ব্যবহার করে এটি প্রতিস্থাপন করতে পারেন।
> API কীগুলি কনফিগারেশনে এনক্রিপ্ট করে সংরক্ষণ করা হয়।

<a id="common-issues"></a>
## সাধারণ সমস্যা

যদি কিছু আশা অনুযায়ী কাজ না করে, তাহলে প্রথমে নিম্নলিখিত বিষয়গুলি পরীক্ষা করুন।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### অ্যাপটি টেক্সট অনুবাদ, পুনর্লিখন বা রূপান্তর করছে না

নিশ্চিত করুন যে:

- আপনি টুলবারে একটি মডেল নির্বাচন করেছেন
- কমপক্ষে একটি মডেল [**সেটিংস** > **মডেল**](#models) এ তালিকাভুক্ত আছে
- আপনার API সেটআপ কাজ করছে

আপনি যদি ডেস্কটপ অ্যাপ ব্যবহার করেন:

1. [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন।
2. নিশ্চিত করুন যে কমপক্ষে একটি API কী সংরক্ষিত আছে।
3. কীটি কাজ করছে কিনা তা নিশ্চিত করতে প্রদানকারীর পাশে **পরীক্ষা** ক্লিক করুন।

<br/>

<a id="the-model-list-is-empty"></a>
### মডেল তালিকা খালি

[**সেটিংস** > **মডেল**](#models) খুলুন এবং **রিফ্রেশ** ক্লিক করুন।

প্রয়োজন হলে:

- একটি মডেল খুঁজুন
- **শুধু বিনামূল্যে** চালু করুন
- এক বা একাধিক মডেল **নির্বাচিত মডেল** এ যোগ করুন

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ফলাফল খুব ধীর বা খুব ব্যয়বহুল

এগুলির মধ্যে এক বা একাধিক চেষ্টা করুন:

- একটি ভিন্ন মডেল নির্বাচন করুন
- একটি ছোট ইনপুট ব্যবহার করুন
- [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) এ **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** বন্ধ করুন
- সহজ কাজের জন্য বিনামূল্যে মডেল ব্যবহার করুন (দেখুন [মডেল](#models))

<br/>

### ইন্টারফেস ভুল ভাষায় আছে

### টেক্সট খুব ছোট বা পড়তে কষ্ট হচ্ছে

<a id="dashboard-charts-are-empty"></a>  
### ড্যাশবোর্ড চার্টগুলি খালি

এটি স্বাভাবিক যদি:

- আপনি শুধুমাত্র **বিনামূল্যে মডেল** ব্যবহার করেন এবং আপনি **খরচ** সংক্রান্ত তথ্য দেখছেন (যা শূন্য হতে পারে); **সারসংক্ষেপ**-এ **ব্যবহার** কল-গণনা চার্টগুলি এখনও নির্বাচিত সময়কালের ডেটা প্রয়োজন  
- নির্বাচিত **সময় ফিল্টার** কলগুলি করা সময়কালকে কভার করে না - পরীক্ষা করতে **সব** চয়ন করুন

যদি **সব** নির্বাচন করার পরেও চার্টগুলি খালি থাকে, তাহলে নিশ্চিত করুন যে [**ইতিহাস**](#history) বা **সমস্ত কল** ট্যাবে কলগুলি দেখা যাচ্ছে।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>  
### খরচ "উপলব্ধ নয়" দেখাচ্ছে বা ভুল মনে হচ্ছে

যখন আপনি **ওপেনরাউটার** এর মাধ্যমে মডেল ব্যবহার করেন, তখন অ্যাপটি ওপেনরাউটার দ্বারা প্রতিবেদিত আপনার প্রকৃত খরচ দেখায়।

**অন্যান্য প্রদানকারীদের** (ওপেনএআই সরাসরি, অ্যানথ্রোপিক সরাসরি ইত্যাদি) ক্ষেত্রে, খরচ ওপেনরাউটার দ্বারা প্রকাশিত মূল্য তথ্য থেকে আনুমানিক করা হয়। যদি কোনো মডেলের জন্য মিল খুঁজে না পাওয়া যায়, তবে খরচ **উপলব্ধ নয়** হিসাবে দেখানো হবে এবং আপনার মোট খরচে যুক্ত হবে না।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>  
### মোট খরচ আপনার প্রদানকারীর বিলের সাথে মেলে না

অ্যাপের সমস্ত খরচের চিত্রগুলি শুধুমাত্র **তথ্যের জন্য আনুমানিক**, আনুষ্ঠানিক বিলিং বিবৃতি নয়।

মোটটি আপনার প্রকৃত ওপেনরাউটার খরচের কাছাকাছি আনতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking) খুলুন এবং **API কী ব্যবহারের সাথে সিঙ্ক করুন** এ ক্লিক করুন।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>  
### সাইডবার থেকে ইতিহাস পৃষ্ঠাটি নেই

**চালনের ইতিহাস রাখো** বন্ধ থাকতে পারে। [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং এটি চালু করুন। লক্ষ্য করুন যে এটি চালু করলে আগে মুছে ফেলা ইতিহাস ডেটা পুনরুদ্ধার হবে না।

<a id="web-app-session-expired"></a>  
### ওয়েব অ্যাপ: অপ্রত্যাশিতভাবে লগইন পৃষ্ঠায় পুনঃনির্দেশিত হচ্ছে

আপনার সেশন সময় শেষ হয়ে গেছে হতে পারে। আবার লগ ইন করুন। যদি এটি প্রায়শই ঘটে, তাহলে সেশন আজীবন সেটিংসের জন্য সার্ভার কনফিগারেশন পরীক্ষা করুন।

<a id="web-admin-forgot-or-lost-a-password"></a>  
### ওয়েব অ্যাডমিন: পাসওয়ার্ড ভুলে গেছেন বা হারিয়ে গেছেন

এটি **স্ব-হোস্ট করা ওয়েব অ্যাপ** (ডকার)-এ প্রযোজ্য, ডেস্কটপ (ইলেকট্রন) অ্যাপে নয়।

- যদি অন্য কোনো প্রশাসক এখনও সাইন ইন করতে পারেন, তারা [**সেটিংস** > **ব্যবহারকারীরা**](#users) খুলতে পারেন, অ্যাকাউন্টটি নির্বাচন করতে পারেন এবং সেখানে একটি **নতুন পাসওয়ার্ড** সেট করতে পারেন।  
- যদি আপনি **লক আউট** হয়ে থাকেন কিন্তু মেশিন বা কনটেইনারে **শেল অ্যাক্সেস** থাকে, তবে ইমেজের সাথে আসা হেল্পার ব্যবহার করে পাসওয়ার্ড রিসেট করুন (ডিফল্ট নাম পরিবর্তন করলে `transrewrt` পরিবর্তন করুন, এবং পাসওয়ার্ডে যদি স্পেস বা বিশেষ অক্ষর থাকে তবে উদ্ধৃতি ব্যবহার করুন):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ডিফল্ট অ্যাডমিন ব্যবহারকারীর নাম `admin` যদি আপনি কখনো অন্য অ্যাকাউন্ট তৈরি না করে থাকেন। যখন আপনি শুধুমাত্র একটি আর্গুমেন্ট দেন, তখন এটি `admin`-এর জন্য নতুন পাসওয়ার্ড হিসাবে বিবেচিত হয়।

যদি আপনি ডকারের পরিবর্তে একটি **সোর্স চেকআউট** থেকে চালান, তাহলে ব্যবহার করুন:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

স্ক্রিপ্টটি SQLite ডাটাবেসে ব্যবহারকারী রেকর্ড আপডেট করে (এবং `admin` ব্যবহারকারী না থাকলে তাকে তৈরি করতে পারে)। রিসেট করার পর, নতুন পাসওয়ার্ড দিয়ে সাইন ইন করুন।

<a id="dashboard-shows-no-data-for-other-users"></a>
### ড্যাশবোর্ড অন্যান্য ব্যবহারকারীদের জন্য কোনো ডেটা দেখায় না (ওয়েব)

শুধুমাত্র **প্রশাসকদের** **ব্যবহারকারী** ফিল্টারের মাধ্যমে সব ব্যবহারকারীদের ডেটা দেখার অনুমতি আছে। নিয়মিত ব্যবহারকারীরা নকশা অনুযায়ী শুধুমাত্র নিজেদের ক্রিয়াকলাপ দেখতে পারে।

### আমি একটি প্রম্পট পরিবর্তন করেছি এবং সম্পাদনাগুলি হারিয়ে গেছে

<a id="quick-tips"></a>
## দ্রুত টিপস

- [**অনুবাদ**](#translate) দিয়ে শুরু করুন যাতে আপনি নিশ্চিত হতে পারেন যে আপনার সেটআপ কাজ করছে আগে আপনি [**পুনর্লেখন**](#rewrite) বা [**রূপান্তর**](#transform) এ যাওয়ার আগে।
- দৈনন্দিন ভাষাগত উন্নতির জন্য [**পুনর্লেখন**](#rewrite) ব্যবহার করুন।
- একটি নির্দিষ্ট কাজের জন্য পুনরাবৃত্তিযোগ্য কাজের প্রবাহ প্রয়োজন হলে [**রূপান্তর**](#transform) ব্যবহার করুন।
- ব্যবহার এবং খরচ নজরদারি করতে চাইলে [**ড্যাশবোর্ড**](#dashboard) ব্যবহার করুন।
- [**ইতিহাস**](#history) ব্যবহার করুন অতীতের ক্রিয়াকলাপগুলি এবং তাদের সম্পূর্ণ ইনপুট/আউটপুট টেক্সট পর্যালোচনা করতে।
- যদি আপনি একটি প্রম্পট লাইব্রেরি তৈরি করছেন যা আপনি নিরাপদে রাখতে চান (দেখুন [ট্রান্সফর্ম প্রম্পট](#transform-prompts)) বা অন্যদের সাথে শেয়ার করতে চান তবে নিয়মিত প্রম্পট রপ্তানি করুন।
