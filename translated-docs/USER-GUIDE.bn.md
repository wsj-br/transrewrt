# ব্যবহারকারী গাইড

<br/>

<a id="introduction"></a>
## ভূমিকা

Transrewrt আপনাকে পাঠ্য নিয়ে কাজ করতে সাহায্য করে তিনটি প্রধান উপায়ে:

- **অনুবাদ** - একটি ভাষা থেকে অন্য ভাষায় পাঠ্য রূপান্তর করুন।
- **পুনর্লিখন** - পাঠ্য পুনরায় লিখুন ভিন্ন ধরনে, যেমন আরও স্পষ্ট, সংক্ষিপ্ত বা আনুষ্ঠানিক।
- **রূপান্তর** - প্রম্পট নামে কাস্টম AI নির্দেশনা ব্যবহার করে পাঠ্য প্রক্রিয়াকরণ করুন।

<br/>

এই গাইডটি অ্যাপটি ইনস্টল এবং চালানোর পর এটি ব্যবহার করার পদ্ধতি ব্যাখ্যা করে। ইনস্টলেশনের ধাপগুলির জন্য মূল **[README](README.bn.md)** দেখুন।

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> Transrewrt উইন্ডোজ এবং লিনাক্সের জন্য ডেস্কটপ অ্যাপ হিসাবে এবং স্ব-হোস্টেড ওয়েব অ্যাপ হিসাবে উপলব্ধ। এই গাইডটি অ্যাপটির দৈনিক ব্যবহার নিয়ে কেন্দ্রিত। যেখানে কিছু শুধুমাত্র একটি সংস্করণের জন্য প্রযোজ্য, সেখানে এটি স্পষ্টভাবে চিহ্নিত করা হয়েছে।

<a id="before-you-start"></a>
## শুরু করার আগে

Transrewrt ব্যবহার করতে হলে আপনার অন্তত একটি AI প্রদানকারীর অ্যাক্সেস থাকা প্রয়োজন। সমর্থিত প্রদানকারীদের মধ্যে রয়েছে: [ওপেনরাউটার](https://openrouter.ai) (যা অনেক মডেল একত্রিত করে), ওপেনএআই, অ্যানথ্রোপিক, গুগল জেমিনি, ডিপসিক, গ্রোক, মিস্ট্রাল, এক্সএআই, Cerebras এবং স্থানীয় মডেলের জন্য [ওলামা](https://ollama.com)।

শুরু করার জন্য আপনার কোনো পেইড মডেল নির্বাচন করা দরকার নেই। আপনি যেমনই আপনার ওপেনরাউটার API কী যোগ করবেন, অ্যাপটি স্বয়ংক্রিয়ভাবে একটি অন্তর্নির্মিত **বিনামূল্যে** ওপেনরাউটার বিকল্প সক্রিয় করবে। এটি আপনাকে অবিলম্বে অনুবাদ, পুনর্লিখন এবং টেক্সট রূপান্তর শুরু করতে দেয়। বিকল্পভাবে, আপনি Cerebras, গুগল, গ্রোক বা মিস্ট্রাল AI থেকে একটি বিনামূল্যে API কী পেতে পারেন।

সাধারণ ভাষায়:

- একটি **মডেল** হল সেই AI ইঞ্জিন যা কাজ করে। মডেলগুলি **প্রদানকারী উপসর্গ** সহ তালিকাভুক্ত করা হয় (যেমন `openrouter/…`, `openai/…`, `ollama/…`)।
- একটি **API কী** (বা, ওলামার ক্ষেত্রে, একটি **বেস URL**) হল কীভাবে অ্যাপটি সেই প্রদানকারীকে অ্যাক্সেস করে।

আপনি যদি **ডেস্কটপ অ্যাপ** ব্যবহার করেন, তাহলে আপনি যে প্রদানকারীদের ব্যবহার করবেন তাদের জন্য [**সেটিংস** > **API কনফিগ**](#api-config) এ কী যোগ করুন। শুধুমাত্র ওপেনরাউটার ব্যবহারের জন্য নীচে [একটি API কী পাওয়ার পদ্ধতি](#how-to-get-an-api-key-desktop-app) দেখুন। আপনি যদি কোনো API কী ব্যবহার করতে না চান, তাহলে আপনি [ollama.com](https://ollama.com) থেকে ওলামা ইনস্টল করতে পারেন এবং `translategemma:4b` এর মতো স্থানীয় মডেল ব্যবহার করতে পারেন।

আপনি যদি **ওয়েব সংস্করণ** ব্যবহার করেন, তাহলে সার্ভার মালিক পরিবেশ চলক ব্যবহার করে প্রদানকারীদের কনফিগার করেন, তাই আপনি অ্যাপ্লিকেশনের মধ্যে সরাসরি API কী প্রবেশ করতে পারবেন না।

<a id="how-to-get-an-api-key-desktop-app"></a>
### কীভাবে একটি বিনামূল্যে ওপেনরাউটার API কী পাবেন (ডেস্কটপ অ্যাপ)

আপনি যদি ডেস্কটপ অ্যাপ ব্যবহার করেন, তাহলে এই ধাপগুলি অনুসরণ করুন:

1. আপনার ওয়েব ব্রাউজারে [ওপেনরাউটার](https://openrouter.ai) এ যান।
2. একটি অ্যাকাউন্ট তৈরি করুন বা সাইন ইন করুন।
3. [কী](https://openrouter.ai/keys) পৃষ্ঠাটি খুলুন।
4. একটি নতুন API কী তৈরি করার জন্য বোতামে ক্লিক করুন।
5. পরে আপনি যাতে এটি চিনতে পারেন সেজন্য কীটির একটি নাম দিন।
6. নতুন API কীটি কপি করুন।
7. Transrewrt এ ফিরে যান এবং **সেটিংস** > **API কনফিগ** খুলুন।
8. **ওপেনরাউটার API কী**-এ কীটি পেস্ট করুন (**সেটিংস** > **API কনফিগ** এর অধীনে)।
9. এটি কাজ করছে কিনা তা নিশ্চিত করতে **ওপেনরাউটার কী পরীক্ষা করুন** এ ক্লিক করুন।

<a id="getting-started"></a>
## শুরু করা

যদি আপনি প্রথমবারের মতো Transrewrt ব্যবহার করছেন, তাহলে এই ক্রমটি অনুসরণ করুন:

1. অ্যাপটি খুলুন।
2. প্রয়োজন হলে গ্লোব আইকন থেকে আপনার **ইন্টারফেস ভাষা** নির্বাচন করুন।
3. আপনি যদি **ডেস্কটপ অ্যাপ** এ থাকেন, তাহলে [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন, অন্তত একটি প্রদানকারীর জন্য একটি API কী যোগ করুন (যেমন ওপেনরাউটার), এবং এটি কাজ করছে কিনা তা যাচাই করতে **পরীক্ষা** ক্লিক করুন।
4. [**সেটিংস** > **মডেল**](#models) খুলুন এবং এক বা একাধিক মডেল **নির্বাচিত মডেল**-এ যোগ করুন।
5. [**সেটিংস** > **ভাষা**](#languages) খুলুন এবং আপনার সবচেয়ে বেশি ব্যবহৃত ভাষাগুলি প্রথমে দেখানোর জন্য **শীর্ষ ভাষা** নির্বাচন করুন।
6. **অনুবাদ** এ যান এবং সবকিছু কাজ করছে কিনা তা নিশ্চিত করতে একটি সাধারণ অনুবাদ চালান।
7. এটি কাজ করলে, **পুনর্লিখন** এবং তারপর **রূপান্তর** চেষ্টা করুন।

এই ক্রমটি গুরুত্বপূর্ণ। এটি প্রথমবার ব্যবহারের সময় সবচেয়ে সাধারণ সমস্যা এড়ায়: অ্যাপের কাজের API সংযোগ বা নির্বাচিত মডেল না থাকা সত্ত্বেও কোনো কাজ চালানোর চেষ্টা করা।

### টুলবার

অ্যাপের কোন অংশে আপনি আছেন তার উপর নির্ভর করে টুলবার কিছুটা পরিবর্তিত হয়।

- বামদিকে, এটি বর্তমান পৃষ্ঠার নাম দেখায়।
- ডানদিকে, এটি **মডেল সিলেক্টর** এবং **ইন্টারফেস ভাষা** নিয়ন্ত্রণ দেখায়।

**মডেল সিলেক্টর** বর্তমান কাজের জন্য কোন AI ইঞ্জিন ব্যবহার করা হবে তা আপনাকে নির্বাচন করতে দেয়।

![Model selector](../images/screenshots/bn/model-selector.png)

কিছু বিনামূল্যে মডেল সবসময় উপলব্ধ নাও হতে পারে-কখনও কখনও তারা অফলাইন থাকে বা ব্যবহারের সীমা থাকে। এমন হলে, অ্যাপটি স্বয়ংক্রিয়ভাবে আপনার উপলব্ধ তালিকা থেকে সেই মডেলটি সরিয়ে দেবে। কোন মডেলগুলি দেখাবে তা নিয়ন্ত্রণ করতে, [**সেটিংস** > **মডেল**](#models)-এ যান এবং আপনার মডেলের তালিকা সম্পাদনা করুন।
আপনি টুলবারে মডেলের নামের বামদিকে প্রদানকারীর আইকনে ক্লিক করে সরাসরি মডেল সেটিংস খুলতে পারেন।

<br/>

**গ্লোব আইকন + ভাষার কোড** মেনু এবং বাটনগুলির মতো অ্যাপ ইন্টারফেস ভাষা পরিবর্তন করে। এটি **অনুবাদ**-এ ব্যবহৃত অনুবাদ ভাষাগুলি পরিবর্তন করে **না**।

![Interface language selector](../images/screenshots/bn/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### ইনপুট এবং আউটপুট প্যানেল

অধিকাংশ কাজের স্থানে বামদিকের **ইনপুট** প্যানেল এবং ডানদিকের **আউটপুট** প্যানেল ব্যবহার করা হয়।

প্রতিটি প্যানেল এছাড়াও দেখায়:

| **ইনপুট**                                                          | **আউটপুট**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - অক্ষর গণনা <br/>- শব্দ গণনা <br/>- অনুচ্ছেদ গণনা   <br/> | - কাজটি কতক্ষণ সময় নিয়েছে<br/>- **TPS** (প্রতি সেকেন্ডে টোকেন)<br/>- অক্ষর, শব্দ এবং অনুচ্ছেদ গণনা<br/>- ব্যবহৃত মডেল |

আপনি যদি প্রযুক্তিগত পদগুলি সম্পর্কে ভাবছেন:

- **টোকেন** মানে টেক্সটের একটি ছোট টুকরো। আপনি এটিকে একটি শব্দের অংশ বা একটি ছোট শব্দ হিসাবে ভাবতে পারেন।
- **TPS** মানে প্রতি সেকেন্ডে মডেলটি কতগুলি টেক্সট টুকরো প্রক্রিয়া করেছে।

<br/>

আপনি প্রতিটি ক্রিয়াকলাপের খরচ (যদি উপলব্ধ থাকে) এবং মোট খরচ পর্যবেক্ষণ করতে পারেন, [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ `ক্রিয়াকলাপগুলিতে খরচের তথ্য দেখান` বিকল্পটি সক্ষম করে।

## অনুবাদ

আপনি যখন একটি ভাষা থেকে অন্য ভাষায় টেক্সট রূপান্তর করতে চান তখন **অনুবাদ** ব্যবহার করুন।

![Translate workspace](../images/screenshots/bn/translate.png)

<br/>

<a id="translate-text"></a>
### টেক্সট অনুবাদ করুন

1. **অনুবাদ** খুলুন।
2. **থেকে** এর মধ্যে একটি ভাষা নির্বাচন করুন।
3. **এ** এর মধ্যে একটি ভাষা নির্বাচন করুন।
4. টুলবারে একটি মডেল নির্বাচন করুন।
5. **ইনপুট**-এ টেক্সট টাইপ করুন বা পেস্ট করুন।
6. **অনুবাদ** ক্লিক করুন।
7. **আউটপুট**-এ ফলাফল পড়ুন।
8. ফলাফল কপি করতে কপি বোতামটি ব্যবহার করুন।

<br/>

<a id="language-selection"></a>
### ভাষা নির্বাচন

- **থেকে** একটি নির্দিষ্ট ভাষা বা **ভাষা সনাক্ত করো** হতে পারে।
- **এ** হল সেই ভাষা যেখানে আপনি ফলাফল চান।

আপনার নির্বাচিত **শীর্ষ ভাষা** গুলি তালিকার উপরের দিকে দেখাবে। আপনি [**সেটিংস** > **ভাষা**](#languages) এ এগুলি সেট করতে পারেন।

<br/>

<a id="helpful-translation-settings"></a>
### সহায়ক অনুবাদ সেটিংস

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) এ, আপনি অনুবাদের আচরণ কীভাবে পরিবর্তন করতে চান তা পরিবর্তন করতে পারেন:

- **পেস্ট করলে স্বয়ংক্রিয় অনুবাদ** আপনি যখন টেক্সট পেস্ট করবেন তখনই একটি অনুবাদ চালায়।
- **ফলাফল স্বয়ংক্রিয়ভাবে ক্লিপবোর্ডে কপি করুন** সফলভাবে চালানোর পরে স্বয়ংক্রিয়ভাবে ফলাফল কপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** আপনি টাইপ করার সময় অনুবাদ চালায়।
- **টাইমআউট (ms)** নিয়ন্ত্রণ করে যে রিয়েল-টাইম অনুবাদ চালানোর আগে অ্যাপটি কতক্ষণ অপেক্ষা করবে।
- **Enter** নিয়ন্ত্রণ করে যা ঘটবে যখন আপনি `Enter` চাপ দেবেন:

## পুনর্লিখন

**পুনর্লিখন** ব্যবহার করুন যখন মূল অর্থ পরিবর্তন না করে শব্দচয়ন উন্নত করতে চান।

![Rewrite workspace](../images/screenshots/bn/rewrite.png)

এটি নিম্নলিখিত ক্ষেত্রে কার্যকর:

- বানান ও ব্যাকরণ ঠিক করা (**বানান ও ব্যাকরণ পরীক্ষা করো**)
- টেক্সটকে আরও স্পষ্ট করা (**স্পষ্টতা উন্নত করো**)
- একটি রানের মধ্যে একাধিক আলাদা পুনঃসূত্রকরণ (**বিকল্প সংস্করণগুলি**)
- টেক্সটকে আরও আনুষ্ঠানিক বা অনানুষ্ঠানিক করা (**আনুষ্ঠানিক** / **অনানুষ্ঠানিক**)
- টেক্সট সংক্ষিপ্ত বা বিস্তৃত করা (**সংক্ষিপ্ত করুন** / **বিস্তৃত করুন**)
- টেক্সটকে আরও প্রযুক্তিগত শোনানো (**প্রযুক্তিগত করুন**)

<br/>

> 💡 **টিপ**<br/>
> যখন আপনি "**বানান ও ব্যাকরণ পরীক্ষা করো**" মোড ব্যবহার করেন, আউটপুট প্যানেলে (**কপি**-এর পাশে) **পরিবর্তন দেখাও** সুইচ দেখায়।
> আপনার টেক্সটে প্রয়োগ করা নির্দিষ্ট সংশোধনগুলি দেখাতে বা লুকাতে এটি চালু বা বন্ধ করুন।

<a id="transform"></a>
## রূপান্তর

যখন আপনি চান যে এআই কাস্টম নির্দেশাবলী অনুসরণ করুক তখন **রূপান্তর** ব্যবহার করুন।

![Transform workspace](../images/screenshots/bn/transform.png)

এটি অ্যাপের সবচেয়ে নমনীয় অংশ। আপনি এটি নিম্নলিখিত কাজগুলির জন্য ব্যবহার করতে পারেন:

- নোটগুলি সংক্ষেপণ
- খসড়া টেক্সটকে পরিশীলিত ইমেলে রূপান্তর
- মূল বিষয়গুলি বের করা
- টেক্সটকে একটি নির্দিষ্ট ফরম্যাটে রূপান্তর
- ইনপুট টেক্সট দিয়ে অন্য যেকোনো কাস্টম কার্যকলাপ

<br/>

<a id="run-an-existing-prompt"></a>
### একটি বিদ্যমান প্রম্পট চালান

1. **রূপান্তর** খুলুন।
2. প্রম্পট তালিকা থেকে একটি প্রম্পট নির্বাচন করুন।
3. যদি একটি **লক্ষ্য** ভাষার বাক্স দেখায়, চাইলে একটি ভাষা নির্বাচন করুন।
4. **ইনপুট**-এ টেক্সট টাইপ করুন বা পেস্ট করুন।
5. **রূপান্তর** ক্লিক করুন।
6. **আউটপুট**-এ ফলাফল পড়ুন।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### যদি আপনার কাছে এখনও কোনো প্রম্পট না থাকে

যদি আপনার প্রম্পট তালিকা খালি থাকে, রূপান্তর ওয়ার্কস্পেসে **নমুনা প্রম্পট লোড করো** ক্লিক করুন। একই নিয়ন্ত্রণটি সর্বদা [**সেটিংস** > **ট্রান্সফর্ম প্রম্পট**](#transform-prompts) এ এক্সপোর্ট/ইম্পোর্ট সারিতে পাওয়া যায়। উভয়ই অন্তর্নির্মিত উদাহরণ যোগ করে যাতে আপনি দ্রুত শুরু করতে পারেন।

<br/>

> ℹ️ **নোট**<br/>
> নমুনা প্রম্পটগুলি ইংরেজিতে দেওয়া হয়েছে। এগুলি লোড করার পরে, আপনি একটি প্রম্পট সম্পাদনা করতে পারেন এবং **অনুবাদ অনুরোধ** ব্যবহার করে এটিকে আপনার ভাষায় অনুবাদ করতে পারেন।

<a id="create-a-prompt-quickly"></a>
### দ্রুত একটি প্রম্পট তৈরি করুন

একটি প্রম্পট তৈরি করার সবচেয়ে দ্রুত উপায় হল:

1. **নতুন প্রম্পট** ক্লিক করুন।
2. **প্রম্পট তৈরি করুন** ক্লিক করুন।
3. আপনি চান যে প্রম্পটটি কী করুক তা বর্ণনা করুন।
4. একটি মডেল নির্বাচন করুন।
5. অ্যাপটিকে আপনার জন্য একটি খসড়া তৈরি করতে দিন।
6. খসড়াটি পর্যালোচনা করুন এবং **সংরক্ষণ** ক্লিক করুন।

![Generate prompt](../images/screenshots/bn/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### একটি প্রম্পট সম্পাদনা করুন

যখন আপনি একটি প্রম্পট তৈরি বা সম্পাদনা করেন, বাম দিকে সম্পাদক দেখা যায় এবং ডানদিকে একটি পরীক্ষার এলাকা দেখা যায়।

![Transform prompt editor](../images/screenshots/bn/transform-prompt-edit.png)

প্রধান ক্ষেত্রগুলি হল:

- **প্রম্পটের নাম**: প্রম্পট তালিকায় দেখানো নাম।
- **প্রম্পট নির্দেশনা (ঐচ্ছিক)**: প্রম্পট চালানোর সময় ব্যবহারকারীকে দেখানো একটি সংক্ষিপ্ত ইঙ্গিত।
- **মডেল ভূমিকা**: এআই-কে নির্ধারিত সামগ্রিক ভূমিকা, যেমন 'আপনি একজন সহায়ক সহকারী'।
- **মডেল নির্দেশনা (প্রতি লাইনে একটি)**: এআই-এর অনুসরণ করার জন্য আপনি চান এমন নির্দিষ্ট নিয়ম।
- **আউটপুট বিবরণ**: ফলাফলের বর্ণনার জন্য একটি সংক্ষিপ্ত শব্দ, যেমন 'সারসংক্ষেপ' বা 'পুনর্লিখন'।
- **তাপমাত্রা (0.0 → 1.0)**: মডেলটি কীভাবে আচরণ করবে; নিচে দেখুন।
- **লক্ষ্য ভাষা জিজ্ঞাসা করো**: প্রম্পট চালানোর সময় একটি লক্ষ্য ভাষা নির্বাচক যোগ করে।

যদি আপনি প্রথমবারের মতো **তাপমাত্রা** নামক প্রযুক্তিগত পদটি শুনে থাকেন, তবে এটিকে এভাবে ভাবুন:

- **নিম্ন** তাপমাত্রা স্থিতিশীল, আরও ভালভাবে পূর্বানুমেয় ফলাফল দেয়।
- **উচ্চতর** তাপমাত্রা আরও বৈচিত্র্য এবং সৃজনশীলতা দেয়।

আপনি এগুলিও ব্যবহার করতে পারেন:

- **`প্রম্পট তৈরি করুন`** একটি সহজ বর্ণনা থেকে একটি নতুন খসড়া তৈরি করতে
- **`প্রম্পট উন্নত করুন`** একটি বিদ্যমান প্রম্পট নিখুঁত করতে
- **`প্রম্পট অনুবাদ করুন`** প্রম্পট ক্ষেত্রগুলি অনুবাদ করতে

<br/>

> ⚠️ **সতর্কীকরণ**<br/>
> **`পিছনে চলে যান`** ক্লিক করার আগে **`সংরক্ষণ`** ক্লিক করুন। আপনি যদি সংরক্ষণ না করে পিছনে যান, তাহলে আপনার পরিবর্তনগুলি হারিয়ে যাবে।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ব্যবহার করার আগে একটি প্রম্পট পরীক্ষা করুন

ডানদিকের পরীক্ষার প্যানেলটি আপনাকে দৈনিক কাজে ব্যবহার করার আগে নমুনা টেক্সট দিয়ে আপনার প্রম্পট চেষ্টা করার অনুমতি দেয়।

এটি তখন কার্যকর যখন:

- আপনি একটি নতুন প্রম্পট তৈরি করছেন
- আপনি একটি প্রম্পটের দুটি সংস্করণ তুলনা করছেন
- আপনি টোন, দৈর্ঘ্য বা আউটপুট ফরম্যাট পরীক্ষা করতে চান

<br/>

> ℹ️ **নোট**<br/>
> আপনি [**সেটিংস** > **রূপান্তর প্রম্পট**](#transform-prompts) এ সংরক্ষিত প্রম্পট এক্সপোর্ট এবং ইম্পোর্ট করতে পারেন।

<a id="dashboard-tabs"></a>
### ড্যাশবোর্ড ট্যাব

- **সারসংক্ষেপ** আপনাকে ব্যবহার এবং খরচের একটি ওভারভিউ দেয়। এতে **সময়ের সাথে ব্যবহার** (দিন অনুযায়ী অনুবাদ, পুনর্লিখন এবং রূপান্তরের জন্য ক্রমবর্ধমান **কল গণনা**) এবং **মডেল অনুযায়ী ব্যবহার** (**মডেল প্রতি মোট কল**, রূপান্তরসহ) অন্তর্ভুক্ত রয়েছে।
- **ব্যবহার অনুসারে** ক্রিয়াকলাপকে অনুবাদ ভাষা, পুনর্লিখন মোড এবং রূপান্তর প্রম্পট অনুযায়ী ভাগ করে।
- **মডেল অনুসারে** দেখায় আপনি কোন মডেলগুলি ব্যবহার করেছেন এবং তাদের খরচ কত।
- **দিন অনুসারে** দৈনিক মোট দেখায়।
- **সমস্ত কল** পূর্ণ কল ইতিহাস দেখায় এবং আপনাকে এটি এক্সপোর্ট করতে দেয়।

### একটি মডেলের জন্য সংরক্ষিত রেকর্ড মুছুন

**মডেল অনুসারে** বা **সমস্ত কল**-এ, আপনি "ট্র্যাশ বিন" আইকনে ক্লিক করে একটি মডেলের জন্য সংরক্ষিত রেকর্ডগুলি সরাতে পারেন।

> ⚠️ **সতর্কতা**<br/>
> সংরক্ষিত রেকর্ড মুছে ফেলা পূর্বাবস্থায় ফিরে যাবে না। শুধুমাত্র তখনই এটি ব্যবহার করুন যখন আপনি নিশ্চিত যে আপনার আর ঐ ইতিহাসের প্রয়োজন নেই।

সমস্ত ডেটা মুছে ফেলতে বা রেকর্ডগুলি তাদের বয়স অনুযায়ী মুছতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking) এ যান। সেখানে আপনি সমস্ত সংরক্ষিত ডেটা মুছে ফেলার বা নির্দিষ্ট তারিখের আগের ডেটা মুছার বিকল্প পাবেন।

<a id="general-settings"></a>
### সাধারণ সেটিংস

টাইপিং আচরণ, এক্সিকিউশন বিবরণ কি হবে **ইতিহাস** এর জন্য সংরক্ষিত এবং চেহারা নিয়ন্ত্রণ করতে **সাধারণ সেটিংস** ব্যবহার করুন।

**আচরণ**

- **ENTER এর জন্য আচরণ** নির্বাচন করে যে `Enter` কীটি কাজটি চালাবে নাকি নতুন লাইন যোগ করবে।
- **পেস্ট করলে স্বয়ংক্রিয় অনুবাদ** আপনি যখন টেক্সট পেস্ট করবেন তখনই অনুবাদ শুরু হবে।
- **ফলাফল স্বয়ংক্রিয়ভাবে ক্লিপবোর্ডে কপি করুন** সফল ফলাফলগুলি স্বয়ংক্রিয়ভাবে কপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** টাইপ করার সময় অনুবাদ করে।
- **টাইমআউট (মিলি সেকেন্ড)** রিয়েল-টাইম অনুবাদের জন্য অপেক্ষার সময় নির্ধারণ করে।

**ইতিহাস**

- **চালনের ইতিহাস রাখো** নিয়ন্ত্রণ করে যে প্রতিটি অনুবাদ, পুনর্লিখন এবং রূপান্তর সাইডবারের [**ইতিহাস**](#history) ভিউয়ের জন্য **ইনপুট এবং আউটপুট টেক্সট** সংরক্ষণ করবে কিনা। এটি বন্ধ করলে নিশ্চিতকরণ চাওয়া হবে; যদি আপনি নিশ্চিত করেন, তবে সংরক্ষিত ইতিহাস টেক্সট ডাটাবেজ থেকে মুছে ফেলা হবে।
- **ইতিহাসের ডেটা মুছুন** বয়স অনুযায়ী (যেমন কয়েক মাসের পুরনো, বা **সমস্ত ডেটা (মুছুন)**) সংরক্ষিত টেক্সট মুছে ফেলতে দেয় **ডেটা মুছুন** ব্যবহার করে। এটি কেবল **ইতিহাস** ভিউয়ের জন্য সংরক্ষিত এক্সিকিউশন টেক্সটকে প্রভাবিত করে; এটি **খরচ** বা ব্যবহারের মোট সংখ্যা মুছে ফেলে না। **খরচ** ডেটা মুছে ফেলতে বা কাটতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking) ব্যবহার করুন।

**চেহারা**

- **অ্যাকশনগুলিতে খরচের তথ্য দেখান** অপারেশন প্রতি খরচ (যদি উপলব্ধ থাকে) এবং অনুবাদ, পুনর্লিখন এবং রূপান্তর আউটপুট প্যানেলগুলিতে মোট খরচ প্রদর্শন নিয়ন্ত্রণ করে।
- **খরচের ভগ্নাংশ অঙ্ক** খরচের দশমিক প্রদর্শন কীভাবে পরিবর্তন করে।
- **শুধুমাত্র ওয়েব:** **অ্যাপের চারপাশে মার্জিন দেখান** ইন্টারফেসের চারপাশে অতিরিক্ত স্থান যোগ করে।
- **ফন্ট ফ্যামিলি** টেক্সট প্যানেলগুলিতে লেখার ফন্ট পরিবর্তন করে।
- **আকার** ফন্টের আকার পরিবর্তন করে।

**কনফিগারেশন ব্যাকআপ**

- **ব্যাকআপে ব্যবহারের তথ্য অন্তর্ভুক্ত করুন** - সক্রিয় করলে, জিপ ফাইলে এক্সিকিউশন ইতিহাস এবং API কল ডেটাও অন্তর্ভুক্ত থাকে।
- **কনফিগারেশন ব্যাকআপ করুন** - একটি একক জিপ ফাইল তৈরি করে (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`, ডিফল্টভাবে UTC অনুযায়ী) যাতে `config.json`, `state.json`, ঐচ্ছিক এনক্রিপশন কী, ব্যবহারকারী, পছন্দ, কাস্টম প্রম্পট এবং ব্যবহারের তথ্য (যদি আপনি সেটি নির্বাচন করে থাকেন) থাকে। সফল ব্যাকআপের পরে, নিশ্চিতকরণে সংরক্ষিত ফাইলের নাম দেখানো হয়।
- **ব্যাকআপ থেকে পুনরুদ্ধার করুন** - প্রথমে একটি **নিশ্চিতকরণ ডায়ালগ** খোলে। ডায়ালগের ভিতরে ব্যাকআপ জিপ ফাইল নির্বাচন করুন (**ব্রাউজ** / ফাইল পিকার বা সাপোর্ট করা ক্ষেত্রে ড্র্যাগ-অ্যান্ড-ড্রপ), তারপর বিকল্পগুলি পর্যালোচনা করুন:
  - **ব্যবহারের তথ্য পুনরুদ্ধার করুন** - ব্যাকআপের সময় ব্যবহারের তথ্য সহ ব্যাকআপ করা হলে জিপ থেকে ব্যবহার/ইতিহাস আমদানি করুন; শুধুমাত্র সেটিংস এবং প্রম্পট চাইলে এটি না করা ভালো।
  - **পুনরুদ্ধারের আগে পুরানো ব্যবহারের তথ্য মুছে ফেলুন** - ব্যাকআপ প্রয়োগ করার আগে এই ইনস্টলেশনে বিদ্যমান ব্যবহার/ইতিহাস মুছে ফেলুন (ঐচ্ছিক; যখন আপনি একটি পরিষ্কার প্রতিস্থাপন চান তখন ব্যবহার করুন)।

ওয়েব বা ডেস্কটপ সংস্করণে তৈরি করা ব্যাকআপগুলি অন্য সংস্করণে পুনরুদ্ধার করা যেতে পারে। ডেস্কটপ ব্যাকআপ ওয়েব সংস্করণে পুনরুদ্ধার করলে ডেটা প্রশাসক ব্যবহারকারীতে পুনরুদ্ধার করা হবে।

### মডেল

টুলবারে কোন মডেলগুলি দেখাবেন তা নির্বাচন করতে **সেটিংস** > **মডেল** ব্যবহার করুন।

![Settings Models tab](../images/screenshots/bn/settings-models.png)

পৃষ্ঠায় দুটি তালিকা রয়েছে:

- বাম দিকে **উপলব্ধ মডেলসমূহ**
- ডান দিকে **নির্বাচিত মডেল

উপযোগী নিয়ন্ত্রণগুলির মধ্যে রয়েছে:

- নাম দ্বারা মডেল খুঁজতে **মডেল খুঁজুন...**
- একটি ইঞ্জিনে (ওপেনরাউটার, ওপেনএআই, ওলামা, …) তালিকা সংকুচিত করতে **প্রদানকারী** চিপস
- শুধুমাত্র বিনামূল্যে মডেল দেখাতে **শুধু বিনামূল্যে**
- তালিকা পুনরায় লোড করতে **রিফ্রেশ**
- প্রদানকারী অনুযায়ী সাজানোর সময় **সব প্রসারিত করুন** এবং **সব সংকুচিত করুন**

মডেল আইডি-তে প্রদানকারী প্রিফিক্স অন্তর্ভুক্ত থাকে (উদাহরণস্বরূপ `openrouter/…` বনাম `openai/…`)। ব্যাডজ যেমন **ওপেনএআই (ওপেনরাউটার)** বনাম **ওপেনএআই (সরাসরি)** ট্রাফিক কীভাবে রাউট করা হয় তা দেখায়।

> ℹ️ **নোট**<br/>
> **ওপেনরাউটার বডি বিল্ডার** (`openrouter/bodybuilder`) একটি রাউটার মডেল, সাধারণ চ্যাট মডেল নয়: এর উত্তর হল জেসন যা ওপেনরাউটার API রিকোয়েস্ট বডিগুলি বর্ণনা করে (উদাহরণস্বরূপ `model` এবং `messages` সহ একটি `requests` অ্যারে)। আপনি যদি এটি **অনুবাদ**, **পুনর্লিখন**, বা **রূপান্তর**-এ ব্যবহার করেন, আউটপুট প্যানেলে সম্পন্ন টেক্সটের পরিবর্তে সেই জেসন দেখানো হবে। এই কাজগুলির জন্য একটি সাধারণ টেক্সট মডেল নির্বাচন করুন। ওপেনরাউটারে [বডি বিল্ডার মডেল পৃষ্ঠা](https://openrouter.ai/openrouter/bodybuilder) দেখুন।

অ্যাকশন:

- একটি মডেল যোগ করতে, **যোগ করুন** বা এন্ট্রির যেকোনো জায়গায় ক্লিক করুন।

- একটি মডেল সরাতে, **নির্বাচিত মডেল**-এ এর পাশের **X** বা উপলব্ধ মডেলগুলিতে এন্ট্রির **নির্বাচিত**-এ ক্লিক করুন।

- তালিকা মুছে ফেলতে, **সব অনির্বাচন** ক্লিক করুন। প্রয়োজনীয় বিনামূল্যে মডেল তালিকায় থাকবে।

<br/>

> ℹ️ **নোট**<br/>
> যদি আপনি ওপেনরাউটারে ক্রেডিট তৎক্ষণাৎ যোগ করতে না চান, তাহলে **শুধু বিনামূল্যে** সক্রিয় করে শুরু করুন এবং বিনামূল্যে মডেলগুলি নির্বাচন করুন (ক্রেডিট কার্ডের প্রয়োজন নেই)। আপনি কোনো API কী ছাড়াই মডেল স্থানীয়ভাবে চালাতে Ollama ব্যবহার করতে পারেন।

### ভাষা

অ্যাপে ব্যবহৃত ভাষার তালিকা সাজাতে **সেটিংস** > **ভাষা** ব্যবহার করুন।

- **শীর্ষ ভাষাগুলি** **অনুবাদ** এবং **রূপান্তর**-এ ভাষার তালিকার উপরের দিকে পিন করা থাকে।  
- **কাস্টম ভাষা** আপনাকে বিল্ট-ইন তালিকায় না থাকা একটি ভাষা যোগ করতে দেয়।

আপনি যদি একটি কাস্টম ভাষা যোগ করেন, তবে এটি বিল্ট-ইন বিকল্পগুলির পাশাপাশি ভাষার সিলেক্টরগুলিতে দেখা যাবে।

<a id="cost-tracking"></a>
### খরচ ট্র্যাকিং

খরচের তথ্য পরিচালনা করতে **সেটিংস** > **খরচ ট্র্যাকিং** ব্যবহার করুন।

- **মোট খরচ** চলমান মোট দেখায়।  
- **মান কপি করুন** মোট মানটি ক্লিপবোর্ডে কপি করে।  
- **খরচ রিসেট করো** সংরক্ষিত মোট খরচ শূন্যে রিসেট করে।  
- **API কী ব্যবহারের সাথে সিঙ্ক করুন** আপনার OpenRouter অ্যাকাউন্ট দ্বারা প্রতিবেদিত ব্যবহারের সাথে মিল রেখে মোট খরচ সেট করে (শুধুমাত্র OpenRouter)।  
- **API কী ব্যবহার** OpenRouter ব্যবহারের বিস্তারিত তথ্য দেখায়, যদি উপলব্ধ থাকে।  
- **খরচ ডেটা মুছুন** সমস্ত ডেটা অথবা নির্বাচিত তারিখের আগের এন্ট্রিগুলি মুছে ফেলে।

**খরচ ট্র্যাকিং:** যখন আপনি OpenRouter মডেলগুলি ব্যবহার করেন, তখন অ্যাপটি OpenRouter থেকে প্রাপ্ত খরচের তথ্যের ভিত্তিতে আপনার প্রকৃত ব্যবহার এবং খরচ দেখায়। অন্যান্য সমস্ত প্রদানকারীদের ক্ষেত্রে, অ্যাপটি OpenRouter দ্বারা প্রকাশিত মূল্য ব্যবহার করে খরচের অনুমান করে, যদি মূল্য অপ্রাপ্য হয় তবে অনুমান শূন্য হতে পারে।

> ℹ️ **নোট**<br/>
>  **সমস্ত খরচের চিত্রগুলি শুধুমাত্র আপনার তথ্যের জন্য অনুমানিত, আনুষ্ঠানিক বিলিং বিবৃতি নয়।**

<br/>

> ⚠️ **সতর্কতা**<br/>
> ডেটা মুছে ফেলা পূর্বাবস্থায় ফিরিয়ে আনা যাবে না। মুছে ফেলার আগে, অবশ্যই আপনার ডেটা ব্যাকআপ করুন বা [**ইতিহাস**](#history) বা [**ড্যাশবোর্ড** > **সমস্ত কল**](#dashboard-tabs) এর মাধ্যমে এক্সপোর্ট করুন, অন্যথায় এটি চিরতরে হারিয়ে যাবে।  
> প্রতিটি API কল এন্ট্রির সাথে সম্পর্কিত সমস্ত ইনপুট/আউটপুট ইতিহাসও মুছে ফেলা হবে।

<a id="transform-prompts"></a>
### ট্রান্সফর্ম প্রম্পট

ব্যাচ আকারে প্রম্পটগুলি পরিচালনা করতে **সেটিংস** > **ট্রান্সফর্ম প্রম্পট** ব্যবহার করুন।

আপনি পারেন:

- আপনার সংরক্ষিত প্রম্পটগুলি পর্যালোচনা করুন  
- প্রম্পটগুলি মুছুন  
- একটি ফাইল থেকে প্রম্পট আমদানি করুন  
- ব্যাকআপ বা শেয়ার করার জন্য প্রম্পটগুলি এক্সপোর্ট করুন  
- প্রম্পট তালিকায় নমুনা প্রম্পট লোড করুন

<a id="users"></a>
### ব্যবহারকারীরা

ওয়েব সংস্করণে ব্যবহারকারী অ্যাকাউন্টগুলি পরিচালনা করতে **ব্যবহারকারীদের** ব্যবহার করুন। আপনি ব্যবহারকারী যোগ করতে পারেন, তাদের বিবরণ আপডেট করতে পারেন, পাসওয়ার্ড রিসেট করতে পারেন এবং অ্যাকাউন্টগুলি মুছে ফেলতে পারেন।

<a id="api-config"></a>
### API কনফিগ

সমর্থিত প্রদানকারীরা হল: ওপেনরাউটার, ওপেনএআই, অ্যানথ্রোপিক, গুগল জেমিনি, ডিপসিক, গ্রোক, মিস্ট্রাল, এক্সএআই, Cerebras এবং **ওলামা** (বেস URL এর মাধ্যমে স্থানীয় মডেল)। আপনি শুধুমাত্র আপনার ব্যবহৃত প্রদানকারীদের কনফিগার করার প্রয়োজন হয়।

**ওয়েব অ্যাপ্লিকেশন: শুধুমাত্র প্রশাসক**

API কীগুলি সিস্টেম বা ডকার পরিবেশ ভেরিয়েবলের মাধ্যমে কনফিগার করা হয় - এগুলি ওয়েব UI-এ প্রবেশ করানো হয় না। এই পৃষ্ঠাটি দেখায় কোন প্রদানকারীদের জন্য একটি কী কনফিগার করা হয়েছে এবং আপনি **`পরীক্ষা`** বোতামে ক্লিক করে প্রতিটি পরীক্ষা করতে পারেন।

<br/>

> ℹ️ **নোট**<br/>
> একটি API কী পরিবর্তন করতে, আপনার সিস্টেম বা ডকার কনফিগারেশনে পরিবেশ ভেরিয়েবলটি আপডেট করুন এবং সার্ভার বা কনটেইনারটি পুনরায় চালু করুন।

> ℹ️ **নোট**<br/>
> **কনফিগারেশন ব্যাকআপ** ([**সাধারণ সেটিংস** → কনফিগারেশন ব্যাকআপ](#general-settings) দেখুন) ZIP-এর `config.json`-এর ভিতরে **রেজলভড** প্রদানকারী কীগুলি এম্বেড করতে পারে। সেই ZIP পুনরুদ্ধার করা **সেই কীগুলি** সার্ভারের স্থায়ী কনফিগ ফাইলে ফিরিয়ে আনে না - বর্তমান কীগুলি এখনও পরিবেশ এবং উল্লিখিত ফাইল স্টেট থেকে আসে।

<br/>

**ডেস্কটপ অ্যাপ্লিকেশন**

আপনি যে প্রতিটি প্রদানকারী ব্যবহার করেন তার জন্য API কীগুলি সংরক্ষণ করতে **API কনফিগ** ব্যবহার করুন। ওলামা-এর জন্য, একটি API কী এর পরিবর্তে **বেস ইউআরএল** প্রবেশ করান।

<br/>

> 💡 **টিপ** <br/>
> যদি আপনি কোনো API কী ব্যবহার করতে না চান বা ব্যবহারের জন্য অর্থ প্রদান করতে না চান, তবে আপনি [ওলামা ডাউনলোড করতে পারেন](https://ollama.com) এবং আপনার মেশিনে স্থানীয়ভাবে `translategemma:4b` এর মতো মডেলগুলি বিনামূল্যে চালাতে পারেন। বিকল্পভাবে, আপনি তাদের বিনামূল্যের মডেলগুলি ব্যবহার করতে অথবা Cerebras, গুগল, গ্রোক বা মিস্ট্রাল AI থেকে একটি বিনামূল্যের API কী পেতে একটি বিনামূল্যে ওপেনরাউটার অ্যাকাউন্ট তৈরি করতে পারেন (ক্রেডিট কার্ড প্রয়োজন নেই)।

<br/>

শুধুমাত্র আপনার প্রয়োজনীয় প্রদানকারীদের যোগ করুন। **সেটিংস** > **মডেল**-এ, প্রতিটি মডেল ID প্রদানকারী দিয়ে শুরু হয় (উদাহরণস্বরূপ `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

একটি API কী যোগ করতে, টেক্সট ফিল্ডে মান প্রবেশ করান এবং **`Save`** ক্লিক করুন। একটি বিদ্যমান কী প্রতিস্থাপন করতে, **`Edit`** ক্লিক করুন। একটি কী কাজ করছে কিনা তা যাচাই করতে, **`Test`** ক্লিক করুন। ওলামা বেস ইউআরএল-এর জন্য, সংযোগ পরীক্ষা করতে সর্বদা **`Test`** ক্লিক করুন।

<br/>

> ℹ️ **নোট**<br/>
> আপনি একটি API কী-এর বর্তমান মান দেখতে পারবেন না। আপনি শুধুমাত্র **`Edit`** বোতাম ব্যবহার করে এটি প্রতিস্থাপন করতে পারবেন।
> API কীগুলি কনফিগারেশনে এনক্রিপ্ট করে সংরক্ষণ করা হয়।

## সাধারণ সমস্যা

যদি কিছু আশানুরূপ কাজ না করে, তবে প্রথমে নিম্নলিখিত বিষয়গুলি পরীক্ষা করুন।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### অ্যাপটি টেক্সট অনুবাদ, পুনর্লিখন বা রূপান্তর করবে না

নিম্নলিখিতগুলি পরীক্ষা করুন:

- আপনি টুলবারে একটি মডেল নির্বাচন করেছেন কিনা
- কমপক্ষে একটি মডেল [**সেটিংস** > **মডেল**](#models) এ তালিকাভুক্ত আছে কিনা
- আপনার API সেটআপ কাজ করছে কিনা

আপনি যদি ডেস্কটপ অ্যাপ ব্যবহার করেন:

1. [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন।
2. নিশ্চিত করুন যে কমপক্ষে একটি API কী সংরক্ষিত আছে।
3. কীটি কাজ করছে কিনা তা নিশ্চিত করতে প্রদানকারীর পাশে **Test** ক্লিক করুন।

<br/>

<a id="the-model-list-is-empty"></a>
### মডেল তালিকা খালি

[**সেটিংস** > **মডেল**](#models) খুলুন এবং **রিফ্রেশ** ক্লিক করুন।

প্রয়োজন হলে:

- একটি মডেল খুঁজুন
- **শুধু বিনামূল্যে** চালু করুন
- এক বা একাধিক মডেল **নির্বাচিত মডেল**-এ যোগ করুন

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ফলাফল খুব ধীর বা খুব বেশি খরচ হচ্ছে

এগুলির মধ্যে এক বা একাধিক চেষ্টা করুন:

- একটি ভিন্ন মডেল নির্বাচন করুন
- একটি ছোট ইনপুট ব্যবহার করুন
- [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) এ **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** বন্ধ করুন
- সহজ কাজের জন্য বিনামূল্যে মডেল ব্যবহার করুন (দেখুন [মডেল](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ইন্টারফেস ভুল ভাষায় আছে

### টেক্সট খুব ছোট বা পড়তে কষ্ট হচ্ছে

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং পরিবর্তন করুন:

- **ফন্ট ফ্যামিলি**
- **আকার**

<a id="dashboard-charts-are-empty"></a>
### ড্যাশবোর্ড চার্টগুলি খালি

এটি স্বাভাবিক যদি:

- আপনি শুধুমাত্র **বিনামূল্যে মডেল** ব্যবহার করেন এবং আপনি **খরচ** সংক্রান্ত তথ্য দেখছেন (সেগুলি শূন্য হতে পারে); **সারসংক্ষেপ**-এ থাকা **ব্যবহার** কল-গণনা চার্টগুলির জন্য নির্বাচিত সময়কাল থেকে তথ্য প্রয়োজন
- নির্বাচিত **সময় ফিল্টার** কল করা সময়কালকে কভার করে না - পরীক্ষা করতে **সব** চয়ন করুন

যদি **সব** নির্বাচন করার পরেও চার্টগুলি খালি থাকে, তাহলে নিশ্চিত করুন যে [**ইতিহাস**](#history) বা **সমস্ত কল** ট্যাবে কলগুলি দেখা যাচ্ছে।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### খরচ "উপলব্ধ নয়" দেখাচ্ছে বা ভুল মনে হচ্ছে

যখন আপনি **ওপেনরাউটার** এর মাধ্যমে মডেল ব্যবহার করেন, অ্যাপটি ওপেনরাউটার দ্বারা প্রতিবেদিত আপনার প্রকৃত খরচ দেখায়।

**অন্যান্য প্রদানকারীদের** (ওপেনএআই সরাসরি, অ্যানথ্রোপিক সরাসরি ইত্যাদি) জন্য, খরচ ওপেনরাউটার দ্বারা প্রকাশিত মূল্য তথ্য থেকে আনুমানিক। যদি কোনো মডেলের জন্য মিলে যাওয়া মূল্য না পাওয়া যায়, খরচ **উপলব্ধ নয়** হিসাবে দেখাবে এবং আপনার মোট হিসাবে যোগ করা হবে না।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### মোট খরচ আমার প্রদানকারীর বিলের সাথে মেলে না

অ্যাপের সমস্ত খরচ চিত্র **শুধুমাত্র রেফারেন্সের জন্য আনুমানিক**, আনুষ্ঠানিক বিলিং বিবৃতি নয়।

আপনার প্রকৃত ওপেনরাউটার খরচের কাছাকাছি মোট আনতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking) খুলুন এবং **API কী ব্যবহারের সাথে সিঙ্ক করুন** এ ক্লিক করুন।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### সাইডবার থেকে ইতিহাস পৃষ্ঠাটি নেই

**চালনের ইতিহাস রাখো** বন্ধ করা থাকতে পারে। [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং এটি সক্রিয় করুন। লক্ষ্য রাখুন যে এটি চালু করলে আগে মুছে ফেলা ইতিহাসের ডেটা পুনরুদ্ধার হবে না।

<br/>

<a id="web-app-session-expired"></a>
### ওয়েব অ্যাপ: অপ্রত্যাশিতভাবে লগইন পৃষ্ঠায় পুনঃনির্দেশিত হয়েছে

আপনার সেশন সময় শেষ হয়ে গেছে হতে পারে। পুনরায় লগ ইন করুন। যদি এটি প্রায়শই ঘটে, তবে সেশন আয়ু সংক্রান্ত সেটিংসের জন্য সার্ভার কনফিগারেশন পরীক্ষা করুন।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### ওয়েব অ্যাডমিন: পাসওয়ার্ড ভুলে গেছেন বা হারিয়েছেন

এটি **সেলফ-হোস্টেড ওয়েব অ্যাপ** (ডকার)-এ প্রযোজ্য, ডেস্কটপ (ইলেকট্রন) অ্যাপ-এ নয়।

- যদি অন্য কোনো প্রশাসক এখনও সাইন ইন করতে পারেন, তবে তারা [**সেটিংস** > **ব্যবহারকারীরা**](#users) খুলতে পারেন, অ্যাকাউন্টটি নির্বাচন করতে পারেন এবং সেখানে একটি **নতুন পাসওয়ার্ড** সেট করতে পারেন।
- যদি আপনি **লক আউট** হয়ে থাকেন কিন্তু মেশিন বা কনটেইনারে **শেল অ্যাক্সেস** থাকে, তবে ইমেজের সাথে আসা হেল্পার ব্যবহার করে পাসওয়ার্ড রিসেট করুন (ডিফল্ট নাম পরিবর্তন করলে `transrewrt` পরিবর্তন করুন, এবং পাসওয়ার্ডে স্পেস বা বিশেষ অক্ষর থাকলে উদ্ধৃতি ব্যবহার করুন):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

আপনি যদি কখনও অন্য অ্যাকাউন্ট তৈরি না করে থাকেন তবে ডিফল্ট অ্যাডমিন ব্যবহারকারীর নাম হলো `admin`। যখন আপনি শুধুমাত্র একটি আর্গুমেন্ট পাস করেন, তখন তা `admin`-এর জন্য নতুন পাসওয়ার্ড হিসাবে বিবেচিত হয়।

যদি আপনি ডকারের পরিবর্তে একটি **সোর্স চেকআউট** থেকে চালান, তবে ব্যবহার করুন:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

স্ক্রিপ্টটি স্কুইট ডেটাবেসে ব্যবহারকারীর রেকর্ড আপডেট করে (এবং যদি অনুপস্থিত থাকে তবে `admin` ব্যবহারকারী তৈরি করতে পারে)। রিসেট করার পর, নতুন পাসওয়ার্ড দিয়ে সাইন ইন করুন।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ড্যাশবোর্ড অন্যান্য ব্যবহারকারীদের জন্য কোনো ডেটা দেখায় না (ওয়েব)

শুধুমাত্র **প্রশাসকদের** কাছে **ব্যবহারকারী** ফিল্টারের মাধ্যমে সব ব্যবহারকারীর ডেটা দেখার অনুমতি আছে। নিয়মিত ব্যবহারকারীরা নকশা অনুযায়ী শুধুমাত্র নিজেদের ক্রিয়াকলাপ দেখতে পারে।

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### আমি একটি প্রম্পট পরিবর্তন করেছি এবং সম্পাদনাগুলি হারিয়ে গেছে

একটি প্রম্পট সম্পাদনা করার সময়, সবসময় **সংরক্ষণ** ক্লিক করুন এবং তারপর **রানে ফিরুন** ক্লিক করুন।

<a id="quick-tips"></a>
## দ্রুত টিপস

- আপনার সেটআপ কাজ করছে কিনা তা নিশ্চিত করার জন্য [**অনুবাদ**](#translate) দিয়ে শুরু করুন, তারপর [**পুনর্লিখন**](#rewrite) বা [**রূপান্তর**](#transform) এ যান।
- দৈনিক ভাষার উন্নতির জন্য [**পুনর্লিখন**](#rewrite) ব্যবহার করুন।
- একটি নির্দিষ্ট কাজের জন্য পুনরাবৃত্তিযোগ্য কাজের প্রবাহ প্রয়োজন হলে [**রূপান্তর**](#transform) ব্যবহার করুন।
- ব্যবহার এবং খরচ নজরে রাখতে চাইলে [**ড্যাশবোর্ড**](#dashboard) ব্যবহার করুন।
- অতীত কার্যক্রম এবং তাদের পূর্ণ ইনপুট/আউটপুট টেক্সট পর্যালোচনা করতে [**ইতিহাস**](#history) ব্যবহার করুন।
- আপনি যদি একটি প্রম্পট লাইব্রেরি তৈরি করেন যা আপনি নিরাপদে রাখতে চান (দেখুন [ট্রান্সফর্ম প্রম্পট](#transform-prompts)) বা অন্যদের সাথে শেয়ার করতে চান, তবে নিয়মিত প্রম্পট এক্সপোর্ট করুন।
