# ব্যবহারকারী গাইড

<br/>

<a id="introduction"></a>

## ভূমিকা

Transrewrt তিনটি প্রধান উপায়ে আপনার সঙ্গে টেক্সট কাজ করতে সাহায্য করে:

- **অনুবাদ** - একটি ভাষা থেকে অপর ভাষায় টেক্সট রূপান্তর করুন।
- **পুনঃলেখন** - পরিষ্কার, সংক্ষিপ্ত বা আরও আনুষ্ঠানিকভাবে টেক্সট পুনরায় লেখার মতো ভিন্ন শৈলীতে লেখা পুনরায় সাজান।
- **রূপান্তর** - প্রম্পট নামে পরিচিত কাস্টম AI নির্দেশ ব্যবহার করে টেক্সট প্রক্রিয়াকরণ।

<br/>

এই গাইডটি অ্যাপটি ইনস্টল করা এবং চালু করার পর তা কীভাবে ব্যবহার করতে হয় তা ব্যাখ্যা করে। ইনস্টলেশনের ধাপগুলির জন্য মূল **[README](README.bn.md)** দেখুন।

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> Transrewrt উইন্ডোজ এবং লিনাক্সের জন্য একটি ডেস্কটপ অ্যাপ হিসেবে এবং স্ব-হোস্টেড ওয়েব অ্যাপ হিসেবে পাওয়া যায়। এই গাইডটি অ্যাপটির দৈনিক ব্যবহার কে কেন্দ্র করে তৈরি। যেখানে কোনো কিছু মাত্র একটি সংস্করণের জন্য প্রযোজ্য, সেগুলো পরিষ্কারভাবে চিহ্নিত করা হয়েছে।

<a id="before-you-start"></a>

## শুরু করার আগে

ট্রান্সরির্ত ব্যবহার করতে আপনার কাছে কমপক্ষে একটি এআই প্রদানকারীতে অ্যাক্সেস থাকা প্রয়োজন। সমর্থিত প্রদানকারীগুলি হল: [ওপেনরাউটার](https://openrouter.ai) (যা অনেক মডেলকে একত্রিত করে), ওপেনএআই, অ্যানথ্রোপিক, গুগল জেমিনি, ডিপসিক, গ্রক, মিস্ট্রাল, এক্সএআই, সেরেব্রাস এবং স্থানীয় মডেলের জন্য [ওলামা](https://ollama.com)।

শুরু করতে ব্যয়বহুল মডেল নির্বাচন করার প্রয়োজন নেই। আপনি আপনার ওপেনরাউটার এপিআই কী যোগ করতে সাথে সাথে, অ্যাপটি স্বয়ংক্রিয়ভাবে একটি অন্তর্নির্মিত **ফ্রি** ওপেনরাউটার বিকল্প সক্ষম করে। এটি আপনাকে তৎক্ষণাৎ টেক্সট অনুবাদ, পুনঃলেখন এবং রূপান্তর শুরু করতে দেয়। বিকল্পভাবে, আপনি সেরেব্রাস, গুগল, গ্রক বা মিস্ট্রাল এআই থেকে বিনামূল্যে এপিআই কী পেতে পারেন।

সাধারণ ভাষায়:

- একটি **মডেল** হল এআই ইঞ্জিন যা কাজটি করে। মডেলগুলি **প্রদানকারীর উপসর্গ** সহ তালিকাভুক্ত করা হয় (যেমন `openrouter/…`, `openai/…`, `ollama/…`)।
- একটি **এপিআই কী** (অথবা ওলামার জন্য, একটি **বেস ইউআরএল**) হল যে উপায়ে অ্যাপটি সেই প্রদানকারীর কাছে পৌঁছায়।

যদি আপনি **ডেস্কটপ অ্যাপ্লিকেশন** ব্যবহার করেন, তবে আপনার ব্যবহৃত প্রতিটি প্রদানকারীর জন্য [**সেটিংস** > **API কনফিগ**](#api-config) এ কী যুক্ত করুন। শুধুমাত্র OpenRouter ব্যবহারের ক্ষেত্রে, নিচে দেখুন [কীভাবে একটি API কী পাবেন](#how-to-get-an-api-key-desktop-app)। আপনি যদি কোনো API কী ব্যবহার করতে না চান, তবে আপনি [ollama.com](https://ollama.com) থেকে Ollama ইনস্টল করে `translategemma:4b` এর মতো স্থানীয় মডেল ব্যবহার করতে পারেন।

যদি আপনি **ওয়েব সংস্করণ** ব্যবহার করেন, তবে সার্ভার প্রপrietor পরিবেশ চলরাশি ব্যবহার করে প্রদানকারীদের কনফিগার করেন, তাই আপনি অ্যাপ্লিকেশনে সরাসরি API কী প্রবেশ করতে পারবেন না।

<a id="how-to-get-an-api-key-desktop-app"></a>

### কীভাবে একটি বিনামূল্যে ওপেনরাউটার এপিআই কী পাবেন (ডেস্কটপ অ্যাপ)

আপনি যদি ডেস্কটপ অ্যাপটি ব্যবহার করেন, তাহলে নিচের পদক্ষেপগুলি অনুসরণ করুন:

1. আপনার ওয়েব ব্রাউজারে [OpenRouter](https://openrouter.ai)-এ যান।
2. একটি অ্যাকাউন্ট তৈরি করুন অথবা সাইন ইন করুন।
3. [Keys](https://openrouter.ai/keys) পৃষ্ঠাটি খুলুন।
4. একটি নতুন API কী তৈরি করতে বাটনে ক্লিক করুন।
5. পরে আপনি এটি চেনার জন্য কী-এর একটি নাম দিন।
6. নতুন API কীটি কপি করুন।
7. ট্রান্সরার্ট-এ ফিরে যান এবং **সেটিংস** > **API কনফিগ** খুলুন।
8. **ওপেনরাউটার এপিআই কী**-এ কীটি পেস্ট করুন (**সেটিংস** > **API কনফিগ**-এর অধীনে)।
9. এটি কাজ করছে কিনা তা নিশ্চিত করার জন্য **ওপেনরাউটার কী টেস্ট করুন**-এ ক্লিক করুন।

<a id="getting-started"></a>

## শুরু করা যাক

যদি আপনি প্রথমবার Transrewrt ব্যবহার করেন, তাহলে নিম্নলিখিত ক্রমটি অনুসরণ করুন:

1. অ্যাপটি খুলুন।
2. প্রয়োজনে গ্লোব আইকন থেকে আপনার **ইন্টারফেস ভাষা** নির্বাচন করুন।
3. যদি আপনি **ডেস্কটপ অ্যাপ** ব্যবহার করেন, তাহলে [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন, অন্তত একটি প্রদানকারীর জন্য একটি API কী যোগ করুন (উদাহরণস্বরূপ OpenRouter), এবং এটি কাজ করছে কিনা তা যাচাই করতে **টেস্ট** ক্লিক করুন।
4. [**সেটিংস** > **মডেল**](#models) খুলুন এবং **নির্বাচিত মডেলগুলি**-এ এক বা একাধিক মডেল যোগ করুন।
5. [**সেটিংস** > **ভাষাগুলি**](#languages) খুলুন এবং আপনার সবচেয়ে বেশি ব্যবহৃত ভাষাগুলি প্রথমে দেখাতে চাইলে আপনার **শীর্ষ ভাষাগুলি** নির্বাচন করুন।
6. **অনুবাদ**-এ যান এবং সবকিছু কাজ করছে কিনা তা নিশ্চিত করতে একটি সাধারণ অনুবাদ চালান।
7. এটি কাজ হলে, **পুনঃলেখন** এবং তারপর **রূপান্তর** চেষ্টা করুন।

এই ক্রমটি গুরুত্বপূর্ণ। এটি সাধারণ প্রথমবারের ব্যবহারের সমস্যাকে রোধ করে: অ্যাপটির কার্যকর API সংযোগ বা নির্বাচিত মডেল না থাকা সত্ত্বেও কোনো কাজ চালানো।

### টুলবার

অ্যাপ্লিকেশনের মধ্যে আপনি কোথায় আছেন তার উপর নির্ভর করে টুলবার কিছুটা পরিবর্তিত হয়।

- বাম দিকে, এটি বর্তমান পৃষ্ঠার নাম দেখায়।
- ডান দিকে, এটি **মডেল সিলেক্টর** এবং **ইন্টারফেস ভাষা** নিয়ন্ত্রণ দেখায়।

**মডেল সিলেক্টর** দিয়ে বর্তমান কাজের জন্য কোন এআই ইঞ্জিন ব্যবহার করবেন তা আপনি বাছাই করতে পারেন।

  ![মডেল সিলেক্টর](../images/screenshots/bn/model-selector.png)

কিছু বিনামূল্যের মডেল সর্বদা পাওয়া যাবে না—কখনও কখনও তারা অফলাইন থাকতে পারে বা ব্যবহারের ক্যাপ থাকতে পারে। এটি ঘটলে, অ্যাপটি স্বয়ংক্রিয়ভাবে আপনার পাওয়া যাওয়া তালিকা থেকে সেই মডেলটি সরিয়ে নেবে। কোন মডেলগুলি দেখানো হবে তা নিয়ন্ত্রণ করতে [**সেটিংস** > **মডেল**](#models)-এ যান এবং আপনার মডেলের তালিকা সম্পাদনা করুন।
টুলবারে মডেলের নামের বামের প্রদানকারীর আইকনে ক্লিক করে আপনি সরাসরি মডেলের সেটিংস খুলতে পারেন।

<br/>

**গ্লোব আইকন + ভাষার কোড** অ্যাপটির ইন্টারফেস ভাষা (যেমন মেনু এবং বোতামগুলি) পরিবর্তন করে। এটি **ট্রান্সলেট** এ ব্যবহৃত অনুবাদ ভাষা পরিবর্তন করে **না**।

![ইন্টারফেসের ভাষা নির্বাচক](../images/screenshots/bn/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>

### ইনপুট এবং আউটপুট প্যানেল

অধিকাংশ কাজের জায়গাতে বামদিকের **ইনপুট** প্যানেল এবং ডানদিকের **আউটপুট** প্যানেল ব্যবহার করা হয়।

প্রতিটি প্যানেলে নিম্নলিখিতগুলিও দেখানো হয়:

| **ইনপুট**                                                             | **আউটপুট**                                                                                                                   |
|-----------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------|
| - অক্ষর গণনা <br/>- শব্দ গণনা <br/>- অনুচ্ছেদ গণনা   <br/> | - কাজটি কতক্ষণ সময় নিয়েছে<br/>- **TPS** (প্রতি সেকেন্ডে টোকেন)<br/>- অক্ষর, শব্দ এবং অনুচ্ছেদের সংখ্যা<br/>- ব্যবহৃত মডেল |


যদি আপনি প্রযুক্তিগত শব্দগুলি নিয়ে ভাবছেন:

- **টোকেন** মানে হল পাঠ্যের একটি ছোট অংশ। আপনি এটিকে একটি শব্দের অংশ বা একটি ছোট শব্দ হিসেবে ভাবতে পারেন।
- **TPS** মানে হল মডেলটি প্রতি সেকেন্ডে কতগুলি পাঠ্যের অংশ প্রক্রিয়া করেছে।

<br/>

আপনি প্রতিটি অপারেশনের (যদি উপলব্ধ থাকে) খরচ এবং মোট খরচও পর্যবেক্ষণ করতে পারেন, [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ `ক্রিয়াকলাপগুলিতে খরচের তথ্য দেখান` বিকল্পটি সক্রিয় করে।

## অনুবাদ

আপনি যখন একটি ভাষা থেকে অন্য ভাষায় পাঠ্য রূপান্তর করতে চান তখন **অনুবাদ** ব্যবহার করুন।

![অনুবাদ কাজের জায়গা](../images/screenshots/bn/translate.png)

<a id="translate-text"></a>

### টেক্সট অনুবাদ করুন

1. **অনুবাদ** খুলুন।
2. **থেকে** একটি ভাষা নির্বাচন করুন।
3. **প্রতি** একটি ভাষা নির্বাচন করুন।
4. টুলবারে একটি মডেল নির্বাচন করুন।
5. **ইনপুট**-এ টেক্সট লিখুন অথবা পেস্ট করুন।
6. **অনুবাদ** ক্লিক করুন।
7. **আউটপুট**-এ ফলাফল পড়ুন।
8. ফলাফল কপি করতে চাইলে কপি বাটন ব্যবহার করুন।

<br/>

<a id="language-selection"></a>

### ভাষা নির্বাচন

- **থেকে** হতে পারে একটি নির্দিষ্ট ভাষা অথবা **ভাষা শনাক্ত করুন**।
- **এতে** হলো সেই ভাষা যে ভাষায় আপনি ফলাফল চান।

আপনার নির্বাচিত **শীর্ষ ভাষাগুলো** তালিকার উপরের অংশে দেখানো হবে। আপনি এগুলো সেট করতে পারেন [**সেটিংস** > **ভাষা**](#languages)-এ।

<br/>

<a id="helpful-translation-settings"></a>

### সহায়ক অনুবাদ সেটিংস

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) এ আপনি অনুবাদের আচরণ পরিবর্তন করতে পারবেন:

- **পেস্ট করার সাথে সাথে অটো অনুবাদ** 'পেস্ট করা লেখা' সঙ্গে সঙ্গেই অনুবাদ চালু করে।
- **ফলাফলটি ক্লিপবোর্ডে অটো কপি করুন** সফল চালনার পরে স্বয়ংক্রিয়ভাবে ফলাফল অনুলিপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** টাইপ করার সময় অনুবাদ চালায়।
- **সময় শেষ (মিলি সেকেন্ডে)** অ্যাপ কতক্ষণ অপেক্ষা করবে তা নিয়ন্ত্রণ করে আমি রিয়েল-টাইম অনুবাদ চালানোর আগে।
- **এন্টার** আপনি যখন `এন্টার` চাপবেন তখন কি ঘটবে তা নিয়ন্ত্রণ করে:

## পুনঃলেখন

যখন মূল অর্থ না বদলে শব্দচয়ন উন্নত করার প্রয়োজন হবে তখন **পুনঃলেখন** ব্যবহার করুন।

![পুনঃলেখন কাজের জায়গা](../images/screenshots/bn/rewrite.png)

এটি নিম্নলিখিত ক্ষেত্রে কাজে লাগবে:

- বানান ও ব্যাকরণ ঠিক করা (**বানান ও ব্যাকরণ পরীক্ষা করুন**)
- পাঠ্যকে আরও স্পষ্ট করা (**স্পষ্টতা উন্নত করুন**)
- একটি চক্রে একাধিক আলাদা পুনঃসূত্রায়ন তৈরি করা (**বিকল্প সংস্করণ**)
- পাঠ্যকে আরও আনুষ্ঠানিক বা অনানুষ্ঠানিক করা (**আনুষ্ঠানিক** / **অনানুষ্ঠানিক**)
- পাঠ্য সংক্ষিপ্ত বা প্রসারিত করা (**সংক্ষেপণ** / **প্রসারণ**)
- পাঠ্যকে আরও প্রযুক্তিগতভাবে শোনানো (**প্রযুক্তিগত করুন**)

<br/>

> 💡 **টিপস**<br/>
> "**বানান ও ব্যাকরণ পরীক্ষা করুন**" মোড ব্যবহার করলে আউটপুট প্যানেলে (**কপি**-এর পাশে) "**পরিবর্তনগুলি দেখান**" স্যুইচ দেখা যাবে।
> আপনার পাঠ্যে প্রয়োগ করা নির্দিষ্ট সংশোধনগুলি দেখানো বা লুকানোর জন্য এটি চালু বা বন্ধ করুন।

<a id="transform"></a>

## রূপান্তর করুন

আপনি যখন কৃত্রিম বুদ্ধিমত্তাকে একটি কাস্টম নির্দেশাবলী অনুসরণ করতে চান, তখন **রূপান্তর (ট্রান্সফর্ম)** ব্যবহার করুন।

![রূপান্তর ওয়ার্কস্পেস](../images/screenshots/bn/transform.png)

এই অ্যাপের এটি সবচেয়ে নমনীয় অংশ। আপনি এটি নিম্নলিখিত কাজগুলির জন্য ব্যবহার করতে পারেন:

- নোটগুলি সংক্ষেপিত করা
- খসড়া টেক্সটকে চিকন চিঠিতে রূপান্তর করা
- মূল বিষয়গুলি বের করা
- টেক্সটকে একটি নির্দিষ্ট ফরম্যাটে রূপান্তর করা
- ইনপুট টেক্সটের সঙ্গে অন্য যেকোনো কাস্টম কার্যকলাপ

<br/>

<a id="run-an-existing-prompt"></a>

### একটি বিদ্যমান প্রম্পট চালান

1. **ট্রান্সফর্ম** খুলুন।
2. প্রম্পট তালিকা থেকে একটি প্রম্পট নির্বাচন করুন।
3. যদি একটি **টার্গেট** ভাষার বাক্স প্রদর্শিত হয়, তবে আপনি চাইলে একটি ভাষা চয়ন করুন।
4. **ইনপুট**-এ টেক্সট টাইপ করুন অথবা পেস্ট করুন।
5. **ট্রান্সফর্ম** ক্লিক করুন।
6. **আউটপুট**-এ ফলাফল পড়ুন।

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### আপনার কাছে এখনো কোন প্রম্পট নেই যদি

আপনার প্রম্পট তালিকা খালি থাকলে, ট্রান্সফর্ম ওয়ার্কস্পেসে **নমুনা প্রম্পট লোড করুন** এ ক্লিক করুন। রপ্তানি/আমদানি সারিতে [**সেটিংস** > **ট্রান্সফর্ম প্রম্পটস**](#transform-prompts) এ একই নিয়ন্ত্রণটি সর্বদা পাওয়া যায়। উভয় ক্ষেত্রেই অন্তর্নির্মিত উদাহরণগুলি যুক্ত হয় যাতে আপনি দ্রুত শুরু করতে পারেন।

<br/>

> ℹ️ **নোট**<br/>
> নমুনা প্রম্পটগুলি ইংরেজিতে সরবরাহ করা হয়। সেগুলি লোড করার পর, আপনি একটি প্রম্পট সম্পাদনা করতে পারেন এবং এটিকে আপনার ভাষায় অনুবাদ করতে **প্রম্পট অনুবাদ করুন** ব্যবহার করতে পারেন।

<br/>

<a id="create-a-prompt-quickly"></a>

### দ্রুত একটি প্রম্পট তৈরি করুন

একটি প্রম্পট তৈরি করার দ্রুততম উপায় হল:

1. **নতুন প্রম্পট**-এ ক্লিক করুন।
2. **প্রম্পট তৈরি করুন**-এ ক্লিক করুন।
3. আপনি কী চান যে প্রম্পটটি তা করুক, সেটি বর্ণনা করুন।
4. একটি মডেল নির্বাচন করুন।
5. অ্যাপটিকে আপনার জন্য একটি খসড়া তৈরি করতে দিন।
6. খসড়াটি পর্যালোচনা করুন এবং **সংরক্ষণ**-এ ক্লিক করুন।

![প্রম্পট তৈরি করুন](../images/screenshots/bn/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>

### একটি প্রম্পট সম্পাদনা করুন

যখন আপনি একটি প্রম্পট তৈরি করবেন বা সম্পাদনা করবেন, তখন বাম দিকে সম্পাদনা করার স্থান এবং ডান দিকে একটি পরীক্ষার অংশ প্রদর্শিত হয়।

![ট্রান্সফর্ম প্রম্পট সম্পাদক](../images/screenshots/bn/transform-prompt-edit.png)

মূল ক্ষেত্রগুলি হল:

- **প্রম্পটের নাম**: প্রম্পটের তালিকায় প্রদর্শিত নাম।
- **প্রম্পট নির্দেশনা (ঐচ্ছিক)**: প্রম্পট চালানোর সময় ব্যবহারকারীকে প্রদর্শিত সংক্ষিপ্ত নির্দেশনা।
- **মডেল ভূমিকা**: এআই-এর নির্ধারিত সামগ্রিক ভূমিকা, যেমন 'আপনি একটি সহায়ক সহকারী'।
- **মডেল নির্দেশনা (প্রতি লাইনে একটি করে)**: আপনি যে নির্দিষ্ট নিয়মগুলি এআই মেনে চলতে চান।
- **আউটপুট বিবরণ**: 'সারসংক্ষেপ' বা 'পুনরায় লেখা' এর মতো ফলাফল বর্ণনা করার একটি সংক্ষিপ্ত শব্দ।
- **তাপমাত্রা (০.০ → ১.০)**: মডেলটি কীভাবে আচরণ করবে, নীচে দেখুন।
- **লক্ষ্য ভাষা জিজ্ঞাসা করুন**: প্রম্পট চালানোর সময় লক্ষ্য ভাষার জন্য একটি নির্বাচক যোগ করে।

যদি প্রযুক্তিগত পরিভাষা **তাপমাত্রা** আপনার কাছে নতুন হয়, তবে এটি নিম্নরূপ ভাবুন:

- **নিম্ন** তাপমাত্রা স্থিতিশীল, আরও আশ্বাসপূর্ণ ফলাফল দেয়।

- একটি **উচ্চতর** তাপমাত্রা আরও বৈচিত্র্য ও সৃজনশীলতা প্রদান করে।

আপনি এটিও ব্যবহার করতে পারেন:

- **`প্রম্পট তৈরি করুন`** সহজ বিবরণ থেকে একটি নতুন খসড়া তৈরি করতে
- **`প্রম্পট উন্নত করুন`** বিদ্যমান প্রম্পটটি নিখুঁত করতে
- **`প্রম্পট অনুবাদ করুন`** প্রম্পট ক্ষেত্রগুলি অনুবাদ করতে

<br/>

> ⚠️ **সতর্কতা**<br/>
> **`Run-এ ফিরুন`**-এ ক্লিক করার আগে **`সংরক্ষণ করুন`**-এ ক্লিক করুন। সংরক্ষণ না করে আপনি যদি ফিরে যান, তাহলে আপনার পরিবর্তনগুলি চলে যাবে।

<br/>

<a id="test-a-prompt-before-using-it"></a>

### ব্যবহারের আগে একটি প্রম্পট পরীক্ষা করুন

ডান পাশের টেস্ট প্যানেলটি আপনাকে দৈনিক কাজে ব্যবহার করার আগে আপনার প্রম্পটকে নমুনা টেক্সট দিয়ে চেষ্টা করার সুযোগ দেয়।

এটি নিম্নলিখিত ক্ষেত্রে কাজে আসে:

- আপনি যখন একটি নতুন প্রম্পট তৈরি করছেন
- আপনি যখন একটি প্রম্পটের দুটি সংস্করণ তুলনা করছেন
- আপনি যখন টোন, দৈর্ঘ্য বা আউটপুট ফরম্যাট পরীক্ষা করতে চান

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> আপনি [**সেটিংস** > **ট্রান্সফর্ম প্রম্পটস**](#transform-prompts) এ সংরক্ষিত প্রম্পটগুলি রপ্তানি এবং আমদানি করতে পারেন।

## ড্যাশবোর্ড

> যদি আপনি শুধুমাত্র **ফ্রি** মডেল ব্যবহার করেন, তাহলে **খরচ** এর পরিমাণ শূন্য হতে পারে এবং খরচ কেন্দ্রিক সারসংক্ষেপ ফাঁকা মনে হতে পারে। **সারসংক্ষেপ**, **সময়ের সাথে সাথে ব্যবহার** এবং **মডেল অনুযায়ী ব্যবহার** এখনও **কলের সংখ্যা** (অনুবাদ, পুনঃলেখন এবং রূপান্তর) দেখাবে যখন নির্বাচিত সময়কালে আপনার কার্যকলাপ থাকে।

<a id="dashboard-tabs"></a>

### ড্যাশবোর্ড ট্যাব

- **সারসংক্ষেপ** আপনাকে ব্যবহার এবং খরচের একটি ওভারভিউ দেয়। এটিতে একটি **সময়ের সাথে ব্যবহার** (দৈনিক অনুবাদ, পুনঃলেখন এবং রূপান্তরের জন্য কল গণনার স্তরীকৃত সংযোজন) এবং **মডেল অনুযায়ী ব্যবহার** (মডেল অনুযায়ী মোট কল, রূপান্তর সহ) অন্তর্ভুক্ত রয়েছে।
- **ব্যবহার অনুযায়ী** ক্রিয়াকলাপকে অনুবাদের ভাষা, পুনঃলেখন মোড এবং রূপান্তর প্রম্পট অনুযায়ী ভাঙে।
- **মডেল অনুযায়ী** আপনি কোন মডেলগুলি ব্যবহার করেছেন এবং তাদের কত খরচ হয়েছে তা দেখায়।
- **দিন অনুযায়ী** দৈনিক মোট সংখ্যা দেখায়।
- **সমস্ত কল** পূর্ণ কল ইতিহাস দেখায় এবং আপনার তা রপ্তানি করার সুযোগ দেয়।

### ডেটা এক্সপোর্ট করুন

ড্যাশবোর্ডের টেবিলগুলি নিম্নলিখিত ফরম্যাটে ডেটা এক্সপোর্ট করতে পারে:

- **CSV**
- **XLSX**

এটি তখন কার্যকর হবে যখন আপনি অ্যাপের বাইরে কার্যকলাপ পর্যালোচনা করতে চাইবেন অথবা একটি প্রতিবেদন ভাগ করে নিতে চাইবেন।

<br/>

<a id="delete-stored-records-for-a-model"></a>

### মডেলের জন্য সংরক্ষিত রেকর্ডগুলি মুছুন

**মডেল অনুযায়ী** অথবা **সমস্ত কলগুলি** এ আপনি "আবর্জনা বাক্স" আইকনে ক্লিক করে কোনও মডেলের জন্য সংরক্ষিত রেকর্ডগুলি মুছে ফেলতে পারেন।

> ⚠️ **সতর্কতা**<br/>
> সংরক্ষিত রেকর্ডগুলি মুছে ফেলার পর তা পুনরুদ্ধার করা যায় না। কেবল তখনই এটি ব্যবহার করুন যদি আপনি নিশ্চিত হন যে আপনার ঐ ইতিহাসের আর প্রয়োজন নেই।

সমস্ত ডেটা মুছতে অথবা তাদের বয়সের উপর ভিত্তি করে রেকর্ডগুলি মুছতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking)-এ যান। সেখানে আপনি সমস্ত সংরক্ষিত ডেটা মুছার অথবা কোনও নির্দিষ্ট তারিখের আগের ডেটা মুছার বিকল্প পাবেন।

<a id="general-settings"></a>

### সাধারণ সেটিংস

**সাধারণ সেটিংস** ব্যবহার করে টাইপিংয়ের আচরণ নিয়ন্ত্রণ করুন, এটি নির্ধারণ করুন যে **ইতিহাস** এর জন্য কার্যকলাপের বিবরণ সংরক্ষণ করা হবে কিনা এবং চেহারা নির্ধারণ করুন।

**আচরণ**

- **ENTER এর জন্য আচরন** আপনার `এন্টার` কী যেটা কাজ করবে তা নির্বাচন করে—কাজটি চালাবে নাকি নতুন লাইন যোগ করবে।
- **পেস্ট করার সময় স্বয়ংক্রিয় অনুবাদ** আপনি যখন কোন টেক্সট পেস্ট করবেন তখনই অনুবাদ শুরু হবে।
- **ফলাফলটিকে ক্লিপবোর্ডে স্বয়ংক্রিয়ভাবে কপি করুন** সফল ফলাফল স্বয়ংক্রিয়ভাবে কপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** আপনি টাইপ করার সময় সঙ্গে সঙ্গে অনুবাদ করে।
- **সময় শেষ (ms)** রিয়েল-টাইম অনুবাদের জন্য অপেক্ষার সময় নির্ধারণ করে।

**ইতিহাস**

- **কার্যকলাপের ইতিহাস রাখুন** সাইডবারে প্রদর্শনের জন্য প্রতিটি অনুবাদ, পুনর্লেখন এবং রূপান্তরের জন্য **ইনপুট এবং আউটপুট টেক্সট** সংরক্ষণ করা হবে কিনা তা নিয়ন্ত্রণ করে। এটি বন্ধ করলে নিশ্চিতকরণের জন্য জিজ্ঞাসা করবে; আপনি যদি নিশ্চিত করেন, তবে সংরক্ষিত ইতিহাস সারা ডেটাবেজ থেকে মুছে ফেলা হবে।

- **ইতিহাস ডেটা মুছুন** বয়সের ভিত্তিতে সংরক্ষিত কোনো পাঠ্য মুছে ফেলার অনুমতি দেয় (যেমন, কয়েক মাসের পুরনো ডেটা বা **সব ডেটা (পরিষ্কার করুন)**), এটি করতে হলে **ডেটা মুছুন** ব্যবহার করুন। এটি কেবল **ইতিহাস** বিভাগে সংরক্ষিত কার্যক্রমের আউটপুটটি প্রভাবিত করে; এটি **ব্যয় বা ব্যবহারের মোট সংখ্যা মুছে ফেলে না**। ব্যয়ের তথ্য মুছতে বা কাটতে, [**সেটিংস** > **ব্যয় ট্র্যাকিং**](#cost-tracking) ব্যবহার করুন।

**চেহারা**

- **ক্রিয়াকলাপগুলিতে ব্যয়ের তথ্য দেখান** — এটি প্রতিটি অপারেশনে ব্যয় (যদি পাওয়া যায়) এবং অনুবাদ, পুনঃলেখন ও রূপান্তরের আউটপুট প্যানেলগুলিতে মোট ব্যয় দেখানোর নিয়ন্ত্রণ করে।
- **ব্যয়ের ভগ্নাংশ অঙ্ক** — ব্যয়ের দশমিক কিভাবে প্রদর্শিত হবে তা পরিবর্তন করে।
- **শুধুমাত্র ওয়েবের জন্য**: **অ্যাপের চারপাশে মার্জিন দেখান** — ইন্টারফেসের চারপাশে অতিরিক্ত জায়গা যোগ করে।
- **ফন্ট পরিবার** — পাঠ্য প্যানেলগুলিতে লেখার ফন্ট পরিবর্তন করে।
- **আকার** — ফন্টের আকার পরিবর্তন করে।

**কনফিগারেশন ব্যাকআপ**

- **ব্যাকআপে ব্যবহারের তথ্য অন্তর্ভুক্ত করুন** — এটি সক্ষম করলে, ZIP-এ কার্যক্রমের ইতিহাস এবং API কলের তথ্য অন্তর্ভুক্ত হবে।

- **ব্যাকআপ কনফিগারেশন** — ডিফল্টভাবে একটি একক জিপ ফাইল (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`, ইউটিসি সময় অনুসারে) তৈরি করে যাতে থাকে `config.json`, `state.json`, ঐচ্ছিক এনক্রিপশন কী, ব্যবহারকারী, পছন্দ, কাস্টম প্রম্পট এবং ব্যবহারের তথ্য (যদি আপনি সম্মত হন)। সফল ব্যাকআপের পর নিশ্চিতকরণ বার্তাতে সংরক্ষিত ফাইলের নাম দেখানো হবে।
- **ব্যাকআপ থেকে পুনরুদ্ধার** — প্রথমে একটি **নিশ্চিতকরণ ডায়ালগ** খোলে। ডায়ালগের ভিতরে ব্যাকআপ জিপ ফাইলটি নির্বাচন করুন (**ব্রাউজ** / ফাইল পিকার অথবা যেখানে সমর্থিত সেখানে ড্র্যাগ-অ্যান্ড-ড্রপ করুন), এরপর নিম্নলিখিত বিকল্পগুলি পর্যালোচনা করুন:
  - **ব্যবহারের তথ্য পুনরুদ্ধার করুন** — যদি ব্যাকআপটি ব্যবহারের তথ্যসহ করা হয়ে থাকে তবে সেই ব্যবহার/ইতিহাস জিপ থেকে আমদানি করুন; শুধুমাত্র সেটিংস এবং প্রম্পটগুলি চাইলে এই অপশনটি না করা।
  - **পুনরুদ্ধারের আগে পুরানো ব্যবহারের তথ্য মুছে ফেলুন** — ব্যাকআপ প্রয়োগ করার আগে এই ইনস্টলেশনের বিদ্যমান ব্যবহার/ইতিহাস মুছে ফেলুন (ঐচ্ছিক; পরিষ্কার প্রতিস্থাপন চাইলে ব্যবহার করুন)।

ওয়েব বা ডেস্কটপ সংস্করণ উভয় ক্ষেত্রেই তৈরি করা ব্যাকআপগুলি পুনরুদ্ধার করা যেতে পারে। ডেস্কটপ ব্যাকআপ ওয়েব সংস্করণে পুনরুদ্ধার করার সময়, ডেটা প্রশাসক ব্যবহারকারীর কাছে পুনরুদ্ধার করা হবে।

### মডেলগুলি

টুলবারে কোন মডেলগুলি প্রদর্শিত হবে তা চয়ন করতে **সেটিংস** > **মডেলগুলি** ব্যবহার করুন।

![সেটিংস মডেল ট্যাব](../images/screenshots/bn/settings-models.png)

পৃষ্ঠাটিতে দুটি তালিকা রয়েছে:

- বামদিকে **প্রাপ্য মডেলগুলি**
- ডানদিকে **নির্বাচিত মডেলগুলি**

উপযোগী নিয়ন্ত্রণগুলির মধ্যে রয়েছে:

- **মডেল খুঁজুন...** নাম অনুযায়ী মডেল খুঁজে পাওয়ার জন্য
- একটি ইঞ্জিনে (OpenRouter, OpenAI, Ollama, …) তালিকা সীমিত করার জন্য **প্রদানকারী** চিপ
- শুধুমাত্র বিনামূল্যের মডেল দেখানোর জন্য **শুধুমাত্র বিনামূল্যে**
- তালিকাটি পুনরায় লোড করতে **রিফ্রেশ**
- প্রদানকারী অনুযায়ী সাজানোর সময় **সব প্রসারিত করুন** এবং **সব সংকুচিত করুন**

মডেল আইডি-তে প্রদানকারীর উপসর্গ অন্তর্ভুক্ত থাকে (যেমন `openrouter/…` বনাম `openai/…`)। **OpenAI (OpenRouter)** বনাম **OpenAI (সরাসরি)**-এর মতো ব্যাজগুলি দেখায় কীভাবে ট্র্যাফিক রাউট করা হয়।

> ℹ️ **দ্রষ্টব্য**<br/>

> **OpenRouter বডি বিল্ডার** (`openrouter/bodybuilder`) একটি রাউটার মডেল, সাধারণ চ্যাট মডেল নয়: এর উত্তর হল জেসন (JSON), যা OpenRouter API অনুরোধ বডি বর্ণনা করে (উদাহরণস্বরূপ `requests` অ্যারেতে `model` এবং `messages`)। যদি আপনি এটি **অনুবাদ**, **পুনরায় লেখা** বা **রূপান্তর**-এর জন্য ব্যবহার করেন, তবে আউটপুট প্যানেলে সম্পূর্ণরূপে তৈরি হওয়া টেক্সটের পরিবর্তে জেসন দেখাবে। এই কাজের জন্য একটি সাধারণ টেক্সট মডেল নির্বাচন করুন। OpenRouter-এ [বডি বিল্ডার মডেল পৃষ্ঠা](https://openrouter.ai/openrouter/bodybuilder) দেখুন।

ক্রিয়াকলাপ:

 - কোনো মডেল যোগ করতে, **যোগ করুন** এ ক্লিক করুন অথবা এন্ট্রির যেকোনো জায়গাতে।

 - কোনো মডেল সরাতে, **নির্বাচিত মডেলগুলি** এবং উপলব্ধ মডেলগুলির এন্ট্রিতে **নির্বাচিত**-এর পাশের **X**-এ ক্লিক করুন।

 - তালিকা মুছে ফেলতে, **সবগুলি নির্বাচন অপসারণ করুন** এ ক্লিক করুন। প্রয়োজনীয় ফ্রি মডেল তালিকাতে থাকবে।

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>

> যদি আপনি তাত্ক্ষণিকভাবে OpenRouter-কে ক্রেডিট দিতে না চান, তবে প্রথমে **শুধুমাত্র ফ্রি** চালু করুন এবং ফ্রি মডেলগুলি নির্বাচন করুন (ক্রেডিট কার্ডের প্রয়োজন নেই)। আপনি কোনো API কী ছাড়াই মডেল স্থানীয়ভাবে চালানোর জন্য Ollama ব্যবহার করতে পারেন।

<a id="languages"></a>

### ভাষা

অ্যাপ-এ ব্যবহৃত ভাষার তালিকা সংগঠিত করতে **সেটিংস** > **ভাষা** ব্যবহার করুন।

- **শীর্ষ ভাষা** গুলি **অনুবাদ** এবং **রূপান্তর**-এ ভাষার তালিকার উপরের দিকে পিন করা থাকে।
- **কাস্টম ভাষা** আপনাকে অন্তর্নির্মিত তালিকায় না থাকা একটি ভাষা যুক্ত করার অনুমতি দেয়।

আপনি যদি একটি কাস্টম ভাষা যুক্ত করেন, তবে এটি অন্তর্নির্মিত ভাষাগুলির পাশাপাশি ভাষা নির্বাচকদের কাছে উপস্থিত হবে।

<a id="cost-tracking"></a>

### খরচ ট্র্যাকিং

**সেটিংস** > **খরচ ট্র্যাকিং** ব্যবহার করে খরচের তথ্য পরিচালনা করুন।

- **মোট খরচ** চলমান মোট দেখায়।
- **মান কপি করুন** মোট খরচ ক্লিপবোর্ডে কপি করে।
- **খরচ রিসেট করুন** সংরক্ষিত মোট খরচ শূন্যে সেট করে।
- **API কী ব্যবহারের সাথে সিঙ্ক করুন** আপনার OpenRouter অ্যাকাউন্ট দ্বারা প্রতিবেদিত ব্যবহারের সাথে মিল রেখে মোট খরচ সেট করে (শুধুমাত্র OpenRouter)।
- **API কী ব্যবহার** OpenRouter-এর ব্যবহারের বিস্তারিত দেখায়, যদি প্রাপ্য হয়।
- **খরচের ডেটা মুছুন** সমস্ত ডেটা অথবা নির্বাচিত তারিখের আগের এন্ট্রিগুলি মুছে ফেলে।

**খরচ ট্র্যাকিং:** যখন আপনি OpenRouter মডেল ব্যবহার করেন, অ্যাপ্লিকেশনটি আপনার প্রকৃত ব্যবহার এবং OpenRouter-এর তথ্য অনুযায়ী ব্যয় দেখায়। অন্য সমস্ত প্রদানকারীদের ক্ষেত্রে, অ্যাপ্লিকেশনটি OpenRouter দ্বারা প্রকাশিত মূল্য ব্যবহার করে খরচ অনুমান করে, যদি কোনো মূল্য অপ্রাপ্য হয়, তবে অনুমান শূন্যও হতে পারে।

<br/>

> ℹ️ **নোট**<br/>
> **সমস্ত খরচের তথ্য শুধুমাত্র আপনার তথ্যের জন্য অনুমান, অফিসিয়াল বিলিং বিবৃতি নয়।**

<br/>

> ⚠️ **সতর্কতা**<br/>

> ডেটা মুছলে তা আর ফিরে পাওয়া যাবে না। মুছার আগে আপনার ডেটা ব্যাকআপ করুন অথবা [**ইতিহাস**](#history)  
> অথবা [**ড্যাশবোর্ড** > **সমস্ত কল**](#dashboard-tabs)-এর মাধ্যমে এটি রপ্তানি করুন, নাহলে এটি স্থায়ীভাবে চলে যাবে।  
> প্রতিটি API কল এন্ট্রির সাথে সম্পর্কিত সমস্ত ইনপুট/আউটপুট ইতিহাসও মুছে ফেলা হবে।

<a id="transform-prompts"></a>

### প্রম্পটগুলি রূপান্তর করুন

আপনি প্রম্পটগুলি একত্রে পরিচালনা করতে **সেটিংস** > **ট্রান্সফর্ম প্রম্পটস** ব্যবহার করুন।

আপনি করতে পারেন:

- আপনার সংরক্ষিত প্রম্পটগুলি পর্যালোচনা করুন
- প্রম্পটগুলি মুছে ফেলুন
- একটি ফাইল থেকে প্রম্পট আমদানি করুন
- ব্যাকআপ বা শেয়ার করার জন্য প্রম্পটগুলি রপ্তানি করুন
- প্রম্পট তালিকায় নমুনা প্রম্পটগুলি লোড করুন

### ব্যবহারকারী

<a id="api-config"></a>

### API কনফিগারেশন

সমর্থিত প্রদানকারীদের তালিকা: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, এবং **Ollama** (বেস ইউআরএলের মাধ্যমে স্থানীয় মডেল)। আপনাকে কেবল আপনার ব্যবহৃত প্রদানকারীদের কনফিগার করতে হবে।

**ওয়েব অ্যাপ্লিকেশন: কেবলমাত্র প্রশাসক**

API কীগুলি সিস্টেম বা ডকার পরিবেশ ভেরিয়েবল মাধ্যমে কনফিগার করা হয় — ওয়েব ইউআই-এ এগুলি লেখা হয় না। এই পৃষ্ঠায় দেখানো হয় যে কোন প্রদানকারীদের কী কনফিগার করা হয়েছে এবং আপনি **`টেস্ট`** বাটনে ক্লিক করে প্রতিটি পরীক্ষা করতে পারেন।

<br/>

> ℹ️ **নোট**<br/>
> API কী পরিবর্তন করতে, আপনার সিস্টেম বা ডকার কনফিগারেশনে পরিবেশ ভেরিয়েবল আপডেট করুন এবং সার্ভার বা কনটেইনার পুনরায় চালু করুন।

> ℹ️ **নোট**<br/>

> **কনফিগারেশন ব্যাকআপ** (দেখুন [**সাধারণ সেটিংস** → কনফিগারেশন ব্যাকআপ](#general-settings)) ZIP ফাইলের `config.json`-এর মধ্যে **সমাধানকৃত** প্রদানকারী কীগুলি অন্তর্ভুক্ত করতে পারে। এই জিপ পুনরুদ্ধার করার সময় সার্ভারের সংরক্ষিত কনফিগ ফাইলে ঐ কীগুলি ফিরে কপি করা হয় **না** — বর্তমান চাবিগুলি এখনও পরিবেশ এবং উল্লিখিত অবস্থানে সংরক্ষিত ফাইলের অবস্থার মাধ্যমে আসে।

<br/>

**ডেস্কটপ অ্যাপ্লিকেশন**

যেসব প্রদানকারী আপনি ব্যবহার করছেন তাদের প্রত্যেকটির জন্য API কী সংরক্ষণ করতে **API কনফিগ** ব্যবহার করুন। Ollama-এর ক্ষেত্রে একটি API কী-এর পরিবর্তে বেস URL প্রবেশ করুন।

<br/>

> 💡 **টিপ** <br/>
> যদি আপনি API কী ব্যবহার করতে না চান অথবা ব্যবহারের জন্য অর্থ প্রদান করতে না চান, তবে আপনি [Ollama ডাউনলোড](https://ollama.com) করতে পারেন এবং আপনার মেশিনে স্থানীয়ভাবে (যেমন `translategemma:4b`) মডেলগুলি বিনামূল্যে চালাতে পারেন। বিকল্পভাবে, আপনি তাদের বিনামূল্যের মডেলগুলি ব্যবহারের জন্য একটি বিনামূল্যের OpenRouter অ্যাকাউন্ট তৈরি করতে পারেন (ক্রেডিট কার্ডের প্রয়োজন নেই), অথবা Cerebras, Google, Groq, বা Mistral AI থেকে একটি বিনামূল্যের API কী পেতে পারেন।

<br/>

- আপনার প্রয়োজন অনুযায়ী শুধুমাত্র প্রদানকারীদের যুক্ত করুন। **সেটিংস** > **মডেল**-এ, প্রতিটি মডেল আইডি প্রদানকারীর সাথে শুরু হয় (যেমন `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

একটি API কী যোগ করতে, টেক্সট ফিল্ডে মানটি লিখুন এবং **`সংরক্ষণ করুন`** ক্লিক করুন। একটি বিদ্যমান কী প্রতিস্থাপন করতে, **`সম্পাদন করুন`** ক্লিক করুন। কীটি কাজ করছে কিনা তা যাচাই করতে, **`পরীক্ষা করুন`** ক্লিক করুন। Ollama বেস URL-এর জন্য, সংযোগ পরীক্ষা করতে সবসময় **`পরীক্ষা করুন`** ক্লিক করুন।

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> আপনি একটি API কী-এর বর্তমান মান দেখতে পারবেন না। আপনি শুধুমাত্র **`সম্পাদন করুন`** বাটন ব্যবহার করে এটি প্রতিস্থাপন করতে পারেন।
> API কীগুলি কনফিগারেশনে এনক্রিপ্ট করে সংরক্ষণ করা হয়।

## সাধারণ সমস্যা

যদি কোনো কিছু আশা অনুযায়ী কাজ না করে, তবে প্রথমে নিম্নলিখিত বিষয়গুলি পরীক্ষা করুন।

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### অ্যাপটি কোনও টেক্সট অনুবাদ, পুনঃলেখা বা রূপান্তর করছে না

নিম্নলিখিতগুলি চেক করুন:

- টুলবারে আপনি একটি মডেল নির্বাচন করেছেন
- [**সেটিংস** > **মডেলস**](#models) এ অন্তত একটি মডেল তালিকাভুক্ত আছে কিনা
- আপনার API সেটআপটি কাজ করছে কিনা

আপনি যদি ডেস্কটপ অ্যাপ ব্যবহার করছেন:

1. [**সেটিংস** > **API কন নফিগ**](#api-config) খুলুন।
2. নিশ্চিত করুন অন্তত একটি API কী সংরক্ষিত আছে।
3. প্রদানকারীর পাশে থাকা **টেস্ট** ক্লিক করুন এবং কীটি কাজ করছে কিনা নিশ্চিত করুন।

<a id="the-model-list-is-empty"></a>

### মডেলের তালিকাটি খালি

[**সেটিংস** > **মডেল**](#models) খুলুন এবং **রিফ্রেশ** এ ক্লিক করুন।

প্রয়োজন হলে:

- একটি মডেল খুঁজুন
- কেবল **ফ্রি** চালু করুন
- এক বা একাধিক মডেল **নির্বাচিত মডেল**-এ যুক্ত করুন

<a id="the-result-is-too-slow-or-too-expensive"></a>

### ফলাফল অত্যন্ত ধীর অথবা ব্যয়বহুল

এগুলির মধ্যে এক বা একাধিক চেষ্টা করুন:

- একটি ভিন্ন মডেল নির্বাচন করুন
- একটি ছোট ইনপুট ব্যবহার করুন
- [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** বন্ধ করুন
- সহজ কাজের জন্য বিনামূল্যের মডেল ব্যবহার করুন (দেখুন [মডেলসমূহ](#models))

<a id="dashboard-charts-are-empty"></a>

### ড্যাশবোর্ডের চার্টগুলি খালি

এটি স্বাভাবিক হতে পারে যদি:

- আপনি কেবল **ফ্রি মডেল** ব্যবহার করেন এবং **খরচ** সংক্রান্ত তথ্য দেখছেন (যা শূন্য হতে পারে); **সারসংক্ষেপ** অংশে **ব্যবহার** সংক্রান্ত কল-কাউন্ট চার্টের নির্বাচিত সময়কালের তথ্য দরকার
- নির্বাচিত **সময় ফিল্টার** কলগুলি করা সময়কালকে অন্তর্ভুক্ত করে না — এটি পরীক্ষা করতে **সবান্তে** বেছে নিন

যদি **সবান্তে** বেছে নেওয়ার পরেও চার্টগুলি খালি থাকে, তবে নিশ্চিত করুন যে কলগুলি [**ইতিহাস**](#history) বা **সমস্ত কল** ট্যাবে দেখা যাচ্ছে।

<a id="cost-shows-not-available-or-seems-wrong"></a>

### খরচ "উপলব্ধ নেই" বা ভুল মনে হচ্ছে

**OpenRouter**-এর মাধ্যমে যখন আপনি মডেলগুলি ব্যবহার করেন, তখন অ্যাপটি OpenRouter দ্বারা রিপোর্ট করা আপনার প্রকৃত খরচ দেখায়।

**অন্যান্য প্রদানকারীদের** (OpenAI সরাসরি, Anthropic সরাসরি ইত্যাদি) ক্ষেত্রে, খরচটি OpenRouter দ্বারা প্রকাশিত মূল্য তথ্য থেকে অনুমান করা হয়। যদি কোনো মডেলের জন্য মিলে যাওয়া মূল্য না পাওয়া যায়, তাহলে খরচটি **"উপলব্ধ নেই"** হিসেবে দেখানো হবে এবং আপনার মোট হিসাবে তা যোগ করা হবে না।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### মোট খরচ আপনার প্রদানকারীর বিলের সাথে মেলে না

অ্যাপে সমস্ত খরচের হিসাব কেবলমাত্র **তুলনামূলক অনুমান**, অফিসিয়াল বিলিং বিবৃতি নয়।

আপনার প্রকৃত ওপেনরাউটার ব্যয়ের কাছাকাছি মোট পেতে, [**সেটিংস** > **খরচ ট্র‍্যাকিং**](#cost-tracking) খুলুন এবং **API কী ব্যবহারের সাথে সিঙ্ক করুন**-এ ক্লিক করুন।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### পার্শ্বদণ্ডে ইতিহাস পাতাটি অনুপস্থিত

**ক্রিয়ান্বয়নের ইতিহাস সংরক্ষণ করুন** বন্ধ থাকতে পারে। [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং এটি চালু করুন। লক্ষ্য রাখুন যে, এটি চালু করলে আগে মুছে যাওয়া ইতিহাসের তথ্য ফিরে পাওয়া যাবে না।

<br/>

<a id="web-app-session-expired"></a>

### ওয়েব অ্যাপ: অপ্রত্যাশিতভাবে লগইন পৃষ্ঠাতে পুনঃনির্দেশিত হয়েছেন

আপনার সেশন সময় শেষ হয়ে গেছে হতে পারে। আবার লগইন করুন। যদি এটি প্রায়শই ঘটে, তাহলে সেশন আয়ুর সেটিংসের জন্য সার্ভারের কনফিগারেশন পরীক্ষা করুন।

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### ওয়েব অ্যাডমিন: পাসওয়ার্ড ভুলে গেলে বা হারানো

এটি ডেস্কটপ (ইলেকট্রন) অ্যাপের পরিবর্তে **স্ব-হোস্ট করা ওয়েব অ্যাপ** (ডকার)-এ প্রযোজ্য।

- যদি অন্য কোনো অ্যাডমিনিস্ট্রেটর এখনও সাইন ইন করতে পারেন, তাহলে তিনি [**সেটিংস** > **ব্যবহারকারীদের**](#users) খুলে, সেই অ্যাকাউন্টটি নির্বাচন করে এবং **নতুন পাসওয়ার্ড** সেট করতে পারেন।
- যদি আপনি **প্রবেশাধিকার হারানোর** অবস্থায় থাকেন কিন্তু যন্ত্র বা কনটেইনারে **শেল অ্যাক্সেস** থাকে, তবে ছবিতে যুক্ত হেল্পার ব্যবহার করে পাসওয়ার্ড রিসেট করুন (যদি আপনি ডিফল্ট নাম পরিবর্তন করে থাকেন তাহলে `transrewrt`-এর পরিবর্তে নতুন নাম ব্যবহার করুন, এবং যদি পাসওয়ার্ডে স্পেস বা বিশেষ অক্ষর থাকে তবে তা উদ্ধৃতির মধ্যে রাখুন):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

আপনি যদি অন্য কোনো অ্যাকাউন্ট তৈরি না করে থাকেন, তবে ডিফল্ট অ্যাডমিন ব্যবহারকারীর নাম হলো `admin`। এক ক্ষেত্রে শুধুমাত্র একটি আর্গুমেন্ট দেওয়া হলে, তা `admin`-এর জন্য নতুন পাসওয়ার্ড হিসাবে গণ্য হবে।

যদি ডকারের পরিবর্তে **উৎস কোড থেকে** চালানো হয়, তবে নিম্নলিখিতটি ব্যবহার করুন:

```bash
pnpm run reset-web-password -- <username> <new-password>

স্ক্রিপ্টটি SQLite ডাটাবেস-এ ব্যবহারকারীর রেকর্ড আপডেট করে (এবং অনুপস্থিত থাকলে `admin` ব্যবহারকারী তৈরি করতে পারে)। রিসেট করার পর, নতুন পাসওয়ার্ড দিয়ে সাইন ইন করুন।

<a id="dashboard-shows-no-data-for-other-users"></a>

### ড্যাশবোর্ডে অন্যান্য ব্যবহারকারীদের জন্য কোনো ডেটা দেখায় না (ওয়েব)

কেবলমাত্র **প্রশাসকরা** **ব্যবহারকারী** ফিল্টারের মাধ্যমে সমস্ত ব্যবহারকারীদের ডেটা দেখতে পারবেন। সাধারণ ব্যবহারকারীদের জন্য ডিজাইন অনুযায়ী তাদের নিজেদের ক্রিয়াকলাপ ছাড়া অন্য কিছু দেখানো হয় না।

<a id="i-changed-a-prompt-and-lost-the-edits"></a>

### আমি একটি প্রম্পট পরিবর্তন করেছি এবং সম্পাদনাগুলি হারিয়ে ফেলেছি

কোনো প্রম্পট সম্পাদনা করার সময়, সর্বদা **প্রত্যাবর্তন চালানোর** আগে **সংরক্ষণ করুন** ক্লিক করুন।

## দ্রুত টিপস

- [**অনুবাদ করুন**](#translate) দিয়ে শুরু করুন, যাতে [**পুনরায় লেখা**](#rewrite) বা [**রূপান্তর করা**](#transform)-তে না যাওয়ার আগে আপনার সেটআপ কাজ করছে কিনা তা নিশ্চিত করা যায়।
- দৈনিক ভাষার উন্নতির জন্য [**পুনরায় লেখা**](#rewrite) ব্যবহার করুন।
- কোনো নির্দিষ্ট কাজের জন্য পুনরাবৃত্তিযোগ্য কাজের ধারা দরকার হলে [**রূপান্তর করুন**](#transform) ব্যবহার করুন।
- যদি আপনি ব্যবহার এবং খরচ নজরে রাখতে চান তবে [**ড্যাশবোর্ড**](#dashboard) ব্যবহার করুন।
- অতীত ক্রিয়াকলাপ এবং তাদের পূর্ণ ইনপুট/আউটপুট টেক্সট পর্যালোচনা করতে [**ইতিহাস**](#history) ব্যবহার করুন।
- যদি আপনি একটি প্রম্পট লাইব্রেরি তৈরি করেন যা আপনি নিরাপদে রাখতে চান (দেখুন [রূপান্তর প্রম্পট](#transform-prompts)) অথবা অন্যদের সাথে ভাগ করে নিতে চান, তবে নিযমিত প্রম্পট রপ্তানি করুন।
