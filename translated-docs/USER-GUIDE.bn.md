# ব্যবহারকারী গাইড

<br/>

<a id="introduction"></a>
## ভূমিকা

Transrewrt আপনাকে তিনটি প্রধান উপায়ে টেক্সট নিয়ে কাজ করতে সাহায্য করে:

- **অনুবাদ** - একটি ভাষা থেকে অন্য ভাষায় টেক্সট রূপান্তর করুন।
- **পুনঃলেখন** - ক্লিয়ার, সংক্ষিপ্ত বা আরও আনুষ্ঠানিক এর মতো বিভিন্ন ধরনে টেক্সটের পুনর্গঠন করুন।
- **রূপান্তর** - “প্রম্পট” নামে পরিচিত কাস্টম AI নির্দেশনা ব্যবহার করে টেক্সট প্রক্রিয়াকরণ করুন।

<br/>

এই গাইডটি অ্যাপ ইনস্টল এবং চালু করার পর ব্যবহার পদ্ধতি ব্যাখ্যা করে। ইনস্টলেশনের ধাপগুলির জন্য মূল **[README](README.bn.md)** দেখুন।

<br/>

> ℹ️ **দ্রষ্টব্য**<br/>
> Transrewrt উইন্ডোজ এবং লিনাক্সের জন্য ডেস্কটপ অ্যাপ হিসাবে এবং স্ব-হোস্টেড ওয়েব অ্যাপ হিসাবে পাওয়া যায়। এই গাইডটি অ্যাপটির নিত্যদিনের ব্যবহারের জন্য। কোনো বৈশিষ্ট্য যদি কেবল একটি ভার্সনে প্রযোজ্য হয়, তবে তা স্পষ্টভাবে চিহ্নিত করা হয়।

<a id="before-you-start"></a>

## শুরু করার আগে

Transrewrt ব্যবহার করতে হলে, আপনার কমপক্ষে একটি AI প্রদানকারী (provider) তে অ্যাক্সেস থাকা প্রয়োজন। সমর্থিত প্রদানকারীগুলি হল: [OpenRouter](https://openrouter.ai) (যা অনেকগুলি মডেল একত্রিত করে), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras এবং স্থানীয় মডেলের জন্য [Ollama](https://ollama.com)।

শুরু করার জন্য একটি পেইড মডেল নির্বাচন করা প্রয়োজন নেই। যেই মুহূর্তে আপনি আপনার OpenRouter API কী যোগ করবেন, অ্যাপটি স্বয়ংক্রিয়ভাবে একটি অন্তর্নির্মিত **বিনামূল্যের** OpenRouter বিকল্প সক্রিয় করবে। এর ফলে আপনি তৎক্ষণাৎ টেক্সট অনুবাদ, পুনঃলেখন এবং রূপান্তর শুরু করতে পারবেন। বিকল্পভাবে, আপনি Cerebras, Google, Groq বা Mistral AI-এর কাছ থেকেও বিনামূল্যে API কী পেতে পারেন।

সাধারণ ভাষায়:

- একটি **মডেল** হল সেই AI ইঞ্জিন যা কাজ করে। মডেলগুলি **প্রদানকারী উপসর্গ** সহ তালিকাভুক্ত করা হয় (যেমন `openrouter/…`, `openai/…`, `ollama/…`)।
- একটি **API কী** (অথবা Ollama-এর ক্ষেত্রে, একটি **বেস URL**) হল অ্যাপটি কীভাবে সেই প্রদানকারীর কাছে পৌঁছাবে তার উপায়।

আপনি যদি **ডেস্কটপ অ্যাপ** ব্যবহার করেন, তবে আপনার ব্যবহৃত প্রতিটি প্রদানকারীর জন্য [**সেটিংস** > **API কনফিগ**](#api-config)-এ কী যোগ করুন। শুধুমাত্র OpenRouter ব্যবহারের জন্য, নীচে দেওয়া [একটি API কী পাওয়ার পদ্ধতি](#how-to-get-an-api-key-desktop-app) দেখুন। আপনি যদি API কী ব্যবহার করতে না চান, তবে আপনি [ollama.com](https://ollama.com)-থেকে Ollama ইনস্টল করতে পারেন এবং `translategemma:4b`-এর মতো স্থানীয় মডেল ব্যবহার করতে পারেন।

যদি আপনি **ওয়েব সংস্করণ** ব্যবহার করেন, তবে সার্ভার মালিক পরিবেশ চলরাশি (environment variables) ব্যবহার করে প্রদানকারীদের কনফিগার করেন, তাই আপনি অ্যাপ্লিকেশনে সরাসরি API কী প্রবেশ করতে পারবেন না।

<a id="how-to-get-an-api-key-desktop-app"></a>
### বিনামূল্যের OpenRouter API কী পাওয়ার পদ্ধতি (ডেস্কটপ অ্যাপ)

আপনি যদি ডেস্কটপ অ্যাপ ব্যবহার করেন, তবে নিম্নলিখিত পদক্ষেপগুলো অনুসরণ করুন:

1. আপনার ওয়েব ব্রাউজারে [OpenRouter](https://openrouter.ai)-এ যান।
2. একটি অ্যাকাউন্ট তৈরি করুন বা সাইন ইন করুন।
3. [Keys](https://openrouter.ai/keys) পৃষ্ঠাটি খুলুন।
4. একটি নতুন API কী তৈরি করার জন্য বাটনে ক্লিক করুন।
5. ভবিষ্যতে আপনি যাতে কীটি চিনতে পারেন তার জন্য একটি নাম দিন।
6. নতুন API কীটি কপি করুন।
7. Transrewrt-এ ফিরে আসুন এবং **সেটিংস** > **API কনফিগ** খুলুন।
8. **OpenRouter API কী**-এ ( **সেটিংস** > **API কনফিগ** অধীনে) কীটি পেস্ট করুন।
9. এটি কাজ করছে কিনা তা নিশ্চিত করতে **OpenRouter কী পরীক্ষা করুন**-এ ক্লিক করুন।

<a id="getting-started"></a>
## শুরু করা

যদি এটি আপনার Transrewrt ব্যবহারের প্রথম সময় হয়, তবে নিম্নলিখিত ক্রমটি অনুসরণ করুন:

1. অ্যাপটি খুলুন।
2. প্রয়োজন হলে, গ্লোব আইকন থেকে আপনার **ইন্টারফেস ভাষা** নির্বাচন করুন।
3. আপনি যদি **ডেস্কটপ অ্যাপ** ব্যবহার করেন, তবে [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন, কমপক্ষে একটি প্রদানকারীর (যেমন OpenRouter) জন্য একটি API কী যোগ করুন এবং এর কার্যকারিতা যাচাই করতে **পরীক্ষা করুন**-এ ক্লিক করুন।
4. [**সেটিংস** > **মডেল**](#models) খুলুন এবং **নির্বাচিত মডেল**-এ এক বা একাধিক মডেল যোগ করুন।
5. [**সেটিংস** > **ভাষাগুলি**](#languages) খুলুন এবং চাইলে আপনার সবচেয়ে বেশি ব্যবহৃত ভাষাগুলি যাতে সবার আগে দেখায় তার জন্য **শীর্ষ ভাষাগুলি** নির্বাচন করুন।
6. **অনুবাদ**-এ যান এবং সব কিছু কাজ করছে কিনা তা নিশ্চিত করতে একটি সাধারণ অনুবাদ চালান।
7. একবার সেটা কাজ হলে, **পুনঃলেখন** এবং তারপর **রূপান্তর** চেষ্টা করুন।

এই ক্রমটি গুরুত্বপূর্ণ। এটি সবচেয়ে সাধারণ প্রথম ব্যবহারের সমস্যা—অ্যাপটির কার্যকরী API সংযোগ বা নির্বাচিত মডেল না থাকা অবস্থায় কোনো কাজ চালানোর চেষ্টা করা—থেকে বাঁচাতে সাহায্য করে।

### টুলবার

অ্যাপের বিভিন্ন জায়গায় টুলবারে কিছুটা পার্থক্য দেখা যায়।

- বাম দিকে, এটি বর্তমান পৃষ্ঠার নাম দেখায়।
- ডান দিকে, এটি **মডেল সিলেক্টর** এবং **ইন্টারফেস ভাষা** নিয়ন্ত্রণ দেখায়।

**মডেল সিলেক্টর** আপনাকে বর্তমান কাজের জন্য কোন কৃত্রিম বুদ্ধিমত্তা মডেল ব্যবহার করবেন তা নির্বাচন করতে দেয়।

  ![মডেল সিলেক্টর](../images/screenshots/bn/model-selector.png)

কিছু বিনামূল্যের মডেল সবসময় উপলব্ধ নাও হতে পারে — কখনও কখনও তারা অফলাইন থাকে অথবা ব্যবহারের সীমা থাকে। এমন হলে, অ্যাপটি স্বয়ংক্রিয়ভাবে আপনার উপলব্ধ তালিকা থেকে সেই মডেলটি সরিয়ে নেবে। কোন কোন মডেল প্রদর্শিত হবে তা নিয়ন্ত্রণ করতে, [**সেটিংস** > **মডেলস**](#models) এ যান এবং আপনার মডেলের তালিকায় পরিবর্তন করুন।
আপনি প্রদানকারীর আইকনে ক্লিক করে সরাসরি মডেল সেটিংস খুলতে পারেন, যা টুলবারে মডেলের নামের বাম দিকে থাকে।

<br/>

**গোল আইকন + ভাষার কোড** অ্যাপের ইন্টারফেস ভাষা, যেমন মেনু এবং বোতামগুলি পরিবর্তন করে। এটি **অনুবাদ**-এ ব্যবহৃত অনুবাদের ভাষাকে **পরিবর্তন** করে না।

  ![ইন্টারফেস ভাষা সিলেক্টর](../images/screenshots/bn/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### ইনপুট এবং আউটপুট প্যানেল

অধিকাংশ ওয়ার্কস্পেস বাম পাশের **ইনপুট** প্যানেল এবং ডান পাশের **আউটপুট** প্যানেল ব্যবহার করে।

প্রতিটি প্যানেল বর্তমানে নিম্নলিখিতগুলি দেখায়:

| **ইনপুট**                                                          | **আউটপুট**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - অক্ষর গণনা <br/>- শব্দ গণনা <br/>- অনুচ্ছেদ গণনা   <br/> | - কতক্ষণ সময় লাগল<br/>- **টিপিএস** (প্রতি সেকেন্ডে টোকেন)<br/>- অক্ষর, শব্দ এবং অনুচ্ছেদের গণনা<br/>- ব্যবহৃত মডেল |


যদি আপনি টেকনিকাল শব্দগুলি সম্পর্কে ভাবছেন:

- **টোকেন** মানে পাঠ্যের ছোট অংশ। আপনি এটিকে একটি শব্দের অংশ বা একটি ছোট শব্দ হিসেবে ভাবতে পারেন।
- **টিপিএস** মানে এক সেকেন্ডে মডেলটি কতগুলি পাঠ্য খণ্ড প্রক্রিয়াকরণ করে।

<br/>

আপনি প্রতিটি ক্রিয়াকলাপের খরচ (যদি উপলব্ধ হয়) এবং মোট খরচ মনিটর করতে পারেন, [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ `কর্মগুলিতে খরচের তথ্য প্রদর্শন করুন` বিকল্পটি সক্রিয় করে।

## অনুবাদ

আপনি যখন একটি ভাষা থেকে অন্য ভাষায় পাঠ্য রূপান্তর করতে চান তখন **অনুবাদ** ব্যবহার করুন।

![অনুবাদ ওয়ার্কস্পেস](../images/screenshots/bn/translate.png)

<a id="translate-text"></a>
### পাঠ্য অনুবাদ করুন

1. **অনুবাদ** খুলুন।
2. **থেকে** একটি ভাষা নির্বাচন করুন।
3. **করে** একটি ভাষা নির্বাচন করুন।
4. টুলবারে একটি মডেল নির্বাচন করুন।
5. **ইনপুট**-এ পাঠ্য টাইপ করুন বা পেস্ট করুন।
6. **অনুবাদ করুন** ক্লিক করুন।
7. **আউটপুট**-এ ফলাফল পড়ুন।
8. ফলাফল কপি করতে চাইলে কপি বোতামটি ব্যবহার করুন।

<br/>

<a id="language-selection"></a>
### ভাষা নির্বাচন

- **থেকে** হতে পারে একটি নির্দিষ্ট ভাষা অথবা **ভাষা শনাক্ত করুন**।
- **করে** হল যে ভাষায় আপনি ফলাফল চান।

আপনার নির্বাচিত **শীর্ষ ভাষাগুলি** তালিকার উপরের দিকে দেখা যাবে। আপনি [**সেটিংস** > **ভাষাসমূহ**](#languages)-এ এগুলি সেট করতে পারেন।

<br/>

<a id="helpful-translation-settings"></a>
### সহায়ক অনুবাদ সেটিংস

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ আপনি অনুবাদের আচরণ কীভাবে পরিবর্তন করতে পারেন:

- **পেস্ট করার সাথে সাথে অটো অনুবাদ** পাঠ্য পেস্ট করার সাথে সাথেই অনুবাদ চালাবে।
- **ক্লিপবোর্ডে স্বয়ংক্রিয়ভাবে ফলাফল কপি করুন** একটি সফল চালানোর পরে স্বয়ংক্রিয়ভাবে ফলাফল কপি করবে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** আপনি টাইপ করার সময় অনুবাদ করবে।
- **টাইম আউট (মিলিসেকেন্ড)** রিয়েল-টাইম অনুবাদ চালানোর আগে অ্যাপ কতক্ষণ অপেক্ষা করবে তা নিয়ন্ত্রণ করে।
- **এন্টার** আপনি `এন্টার` চাপলে কী ঘটবে তা নিয়ন্ত্রণ করে:

## পুনর্লিখন

<a id="transform"></a>

## রূপান্তর

**রূপান্তর** ব্যবহার করুন যখন আপনি কৃত্রিম বুদ্ধিমত্তাকে কোনো কাস্টম নির্দেশাবলী অনুসরণ করতে চান।

![রূপান্তর ওয়ার্কস্পেস](../images/screenshots/bn/transform.png)

এই অ্যাপের সবচেয়ে নমনীয় অংশ এটি। আপনি নিম্নলিখিত কাজগুলির জন্য এটি ব্যবহার করতে পারেন:

- নোটগুলির সারসংক্ষেপ
- মসৃণ করা না হওয়া লেখা থেকে একটি নিখুঁত ইমেল তৈরি করা
- মূল বিষয়গুলি উত্তোলন
- একটি নির্দিষ্ট বিন্যাসে লেখা রূপান্তর করা
- ইনপুট টেক্সটের সাথে অন্য যেকোনো কাস্টম কার্যকলাপ

<br/>

<a id="run-an-existing-prompt"></a>
### একটি বিদ্যমান প্রম্পট চালান

1. **রূপান্তর** খুলুন।
2. প্রম্পট তালিকা থেকে একটি প্রম্পট চয়ন করুন।
3. যদি একটি **লক্ষ্য** ভাষার বাক্স দেখায়, তাহলে একটি ভাষা চয়ন করুন।
4. **ইনপুট**-এ টেক্সটে টাইপ করুন অথবা পেস্ট করুন।
5. **রূপান্তর**-এ ক্লিক করুন।
6. **আউটপুট**-এ ফলাফল পড়ুন।

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### যদি এখনো আপনার কোনো প্রম্পট না থাকে

যদি আপনার প্রম্পট তালিকা খালি থাকে, তাহলে **নমুনা প্রম্পটগুলি লোড করুন**-এ ক্লিক করুন। এটি অন্তর্নির্মিত উদাহরণগুলি যোগ করবে যাতে আপনি দ্রুত শুরু করতে পারেন।

<br/>

> ℹ️ **নোট**<br/>
> নমুনা প্রম্পটগুলি ইংরেজিতে দেওয়া হয়েছে। তাদের লোড করার পর, আপনি একটি প্রম্পট সম্পাদনা করতে পারেন এবং আপনার ভাষাতে অনুবাদ করতে **অনুবাদ প্রম্পট** ব্যবহার করতে পারেন।

<br/>

<a id="create-a-prompt-quickly"></a>
### দ্রুত একটি প্রম্পট তৈরি করুন

একটি প্রম্পট তৈরি করার সবচেয়ে দ্রুত উপায় হল:

1. **নতুন প্রম্পট**-এ ক্লিক করুন।
2. **প্রম্পট তৈরি করুন**-এ ক্লিক করুন।
3. প্রম্পটটি দিয়ে আপনি কী করতে চান তা বর্ণনা করুন।
4. একটি মডেল চয়ন করুন।
5. অ্যাপটিকে আপনার জন্য একটি খসড়া তৈরি করতে দিন।
6. খসড়াটি পর্যালোচনা করুন এবং **সংরক্ষণ**-এ ক্লিক করুন।

![প্রম্পট তৈরি করুন](../images/screenshots/bn/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### একটি প্রম্পট সম্পাদনা করুন

যখন আপনি একটি প্রম্পট তৈরি করেন বা সম্পাদনা করেন, তখন বামদিকে সম্পাদক প্রদর্শিত হবে এবং ডানদিকে একটি পরীক্ষার এলাকা প্রদর্শিত হবে।

![রূপান্তর প্রম্পট এডিটর](../images/screenshots/bn/transform-prompt-edit.png)

প্রধান ক্ষেত্রগুলো হল:

- **প্রম্পট নাম**: প্রম্পট তালিকায় প্রদর্শিত নামটি।
- **প্রম্পট নির্দেশনা (ঐচ্ছিক)**: প্রম্পট চালানোর সময় ব্যবহারকারীকে প্রদর্শিত সংক্ষিপ্ত সূচনা।
- **মডেল ভূমিকা**: কৃত্রিম বুদ্ধিমত্তাকে দেওয়া সামগ্রিক ভূমিকা, যেমন 'আপনি একজন সহায়ক সহকারী।'
- **মডেল নির্দেশনা (প্রতি লাইনে একটি)**: কৃত্রিম বুদ্ধিমত্তার অনুসরণ করার জন্য আপনি চাওয়া নির্দিষ্ট নিয়মগুলি।
- **আউটপুট বর্ণনা**: ফলাফলের বর্ণনা করার একটি সংক্ষিপ্ত শব্দ, যেমন 'সারাংশ' বা 'পুনরায় লেখা'।
- **টেম্পারেচার (0.0 → 1.0)**: মডেলটি কীভাবে আচরণ করবে; নীচে দেখুন।
- **লক্ষ্য ভাষার জন্য জিজ্ঞাসা করুন**: প্রম্পট চালানোর সময় লক্ষ্য ভাষার নির্বাচক যোগ করে।

যদি **টেম্পারেচার** এর মতো প্রযুক্তিগত পদটি নতুন হয়, তবে এটি এইভাবে ভাবুন:

- **নিম্ন** টেম্পারেচার স্থিতিশীল, আরও ভবিষ্যদ্বাণীযোগ্য ফলাফল দেয়।
- **উচ্চতর** তাপমাত্রা আরও বৈচিত্র্য এবং সৃজনশীলতা দেয়।

আপনি এটিও ব্যবহার করতে পারেন:

- **`প্রম্পট তৈরি করুন`** একটি সাধারণ বর্ণনা থেকে একটি নতুন খসড়া তৈরি করতে
- **`প্রম্পট উন্নত করুন`** একটি বিদ্যমান প্রম্পট নিখুঁত করতে
- **`প্রম্পট অনুবাদ করুন`** প্রম্পটের ক্ষেত্রগুলি অনুবাদ করতে

<br/>

> ⚠️ **সতর্কতা**<br/>
> **`পিছনে ফিরুন`**-এ ক্লিক করার আগে **`সংরক্ষণ`**-এ ক্লিক করুন। আপনি যদি সংরক্ষণ না করে ফিরে যান তবে আপনার পরিবর্তনগুলি হারিয়ে যাবে।

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ব্যবহারের আগে একটি প্রম্পট পরীক্ষা করুন

ডানদিকের পরীক্ষার প্যানেলটি আপনাকে নিয়মিত কাজে ব্যবহার করার আগে নমুনা টেক্সটের সাহায্যে আপনার প্রম্পট চেষ্টা করার অনুমতি দেয়।

যখন তা সময় ব্যবহারী, যখন:

- আপনি একটি নতুন প্রম্পট তৈরি করছেন
- আপনি একটি প্রম্পটের দুটি সংস্করণ তুলনা করছেন
- আপনি টোন, দৈর্ঘ্য বা আউটপুট বিন্যাস পরীক্ষা করতে চান

<br/>

> ℹ️ **নোট**<br/>
> আপনি [**সেটিংস** > **ট্রান্সফর্ম প্রম্পট**](#transform-prompts)-এ সংরক্ষিত প্রম্পটগুলি রপ্তানি এবং আমদানি করতে পারেন।

সমস্ত ডেটা মুছে ফেলতে বা রেকর্ডের বয়সের উপর ভিত্তি করে রেকর্ড মুছে ফেলতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking)-এ যান। সেখানে আপনি সমস্ত সংরক্ষিত ডেটা মুছে ফেলা বা নির্দিষ্ট তারিখের আগের ডেটা মুছে ফেলার বিকল্প পাবেন।

<a id="general-settings"></a>
### সাধারণ সেটিংস

**সাধারণ সেটিংস** ব্যবহার করুন টাইপ করার আচরণ নিয়ন্ত্রণ করতে, **ইতিহাস**-এর জন্য কি কার্যকরিতা বিবরণ সংরক্ষণ করা হবে এবং চেহারা পরিবর্তন করতে।

**আচরণ**

- **ENTER-এর আচরণ** নির্বাচন করে যে `Enter` কী কাজটি চালায় নাকি নতুন লাইন সন্নিবেশ করে।
- **আটো-অনুবাদ পেস্ট করার সময়** আপনি যখনই পাঠ্য পেস্ট করেন তখন অনুবাদ শুরু হবে।
- **আউটপুট ক্লিপবোর্ডে অটো-কপি করুন** সফল ফলাফলগুলি স্বয়ংক্রিয়ভাবে কপি করে।
- **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** আপনি যখন টাইপ করেন তখন তা অনুবাদ করে।
- **টাইমআউট (ms)** রিয়েল-টাইম অনুবাদের জন্য অপেক্ষার সময় নির্ধারণ করে।

**ইতিহাস**

- **কার্যকরিতা ইতিহাস রাখুন** নিয়ন্ত্রণ করে যে প্রতিটি অনুবাদ, পুনরায় লেখা এবং রূপান্তরের জন্য **ইনপুট এবং আউটপুট পাঠ্য** পাশের বারের [**ইতিহাস**](#history) ভিউয়ের জন্য সংরক্ষিত হয় কিনা। বন্ধ করা হলে নিশ্চিতকরণ চাওয়া হবে; আপনি নিশ্চিত করলে সংরক্ষিত ইতিহাস পাঠ্য ডেটাবেজ থেকে মুছে ফেলা হবে।
- **ইতিহাস ডেটা মুছুন** আপনাকে বয়সের উপর ভিত্তি করে (যেমন কয়েক মাসের বেশি বয়সী, বা **সমস্ত ডেটা (পরিষ্কার)**) **ডেটা মুছুন** ব্যবহার করে সংরক্ষিত পাঠ্য মুছে ফেলতে দেয়। এটি কেবল **ইতিহাস** ভিউ-এর জন্য সংরক্ষিত কার্যকরিতা পাঠ্যকে প্রভাবিত করে; এটি **খরচ বা ব্যবহারের মোট** মুছে ফেলে না। **খরচ** ডেটা মুছে ফেলতে বা কাটছাঁট করতে, ব্যবহার করুন [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking)।

**চেহারা**

- **ক্রিয়াকলাপের উপর খরচের তথ্য দেখান** অপারেশন প্রতি খরচ (যদি উপলব্ধ হয়) এবং অনুবাদ, পুনরায় লেখা এবং রূপান্তর আউটপুট প্যানেলে মোট খরচ প্রদর্শন নিয়ন্ত্রণ করে।
- **খরচ ভগ্নাংশ অংক** খরচের দশমিকগুলি কিভাবে প্রদর্শিত হবে তা পরিবর্তন করে।
- **শুধুমাত্র ওয়েব:** **অ্যাপের চারপাশে মার্জিন দেখান** ইন্টারফেসের চারপাশে অতিরিক্ত স্থান যোগ করে।
- **ফন্ট ফ্যামিলি** পাঠ্য প্যানেলগুলিতে লেখার ফন্ট পরিবর্তন করে।
- **আকার** ফন্টের আকার পরিবর্তন করে।

<a id="models"></a>

### মডেলগুলি

**সেটিংস** > **মডেল** ব্যবহার করুন টুলবারে কোন মডেলগুলি প্রদর্শিত হবে তা নির্বাচন করতে।

![সেটিংস মডেল ট্যাব](../images/screenshots/bn/settings-model desperado.png)

এই পৃষ্ঠাতে দুটি তালিকা রয়েছে:

- বাম পাশে **উপলব্ধ মডেলগুলি**
- ডান পাশে **নির্বাচিত মডেলগুলি**

কার্যকরী নিয়ন্ত্রণগুলির মধ্যে রয়েছে:

- **মডেল খুঁজুন...** - নাম অনুযায়ী মডেল খুঁজতে
- **প্রদানকারী** চিপস - তালিকাকে একটি ইঞ্জিনে (OpenRouter, OpenAI, Ollama, ...) সীমিত করতে
- **কেবল ফ্রি** - কেবল ফ্রি মডেলগুলি দেখানোর জন্য
- **রিফ্রেশ** - তালিকা পুনরায় লোড করতে
- **সব এক্সপান্ড করুন** এবং **সব কলাপস করুন** - প্রদানকারী অনুসারে সাজানোর সময়

মডেল আইডি-তে প্রদানকারীর প্রিফিক্স অন্তর্ভুক্ত থাকে (উদাহরণস্বরূপ `openrouter/…` বনাম `openai/…`)। ব্যাজ যেমন **OpenAI (OpenRouter)** বনাম **OpenAI (ডিরেক্ট)** দেখায় যে ট্রাফিক কিভাবে রাউট করা হয়েছে।

> ℹ️ **নোট**<br/>
> **OpenRouter বডি বিল্ডার** (`openrouter/bodybuilder`) একটি রাউটার মডেল, একটি সাধারণ চ্যাট মডেল নয়: এর প্রতিক্রিয়া হচ্ছে JSON যা OpenRouter API রিকোয়েস্ট বডি বর্ণনা করে (যেমন একটি `requests` অ্যারে যাতে `model` এবং `messages` থাকে)। আপনি যদি এটি **অনুবাদ**, **পুনরায় লেখা**, বা **রূপান্তর** এর জন্য ব্যবহার করেন, তাহলে আউটপুট প্যানেলে সম্পূর্ণ পাঠ্যের পরিবর্তে এই JSONটি দেখানো হবে। সেই কাজগুলির জন্য একটি সাধারণ পাঠ্য মডেল নির্বাচন করুন। OpenRouter-এ [বডি বিল্ডার মডেল পৃষ্ঠা](https://openrouter.ai/openrouter/bodybuilder) দেখুন।

ক্রিয়াকলাপ:

 - একটি মডেল যোগ করতে **যোগ করুন** বা এন্ট্রির যেকোন জায়গায় ক্লিক করুন।

 - মডেল সরাতে **Selected Models**-এ এর পাশের **X** ক্লিক করুন অথবা Available Models-এ এন্ট্রির **Selected**-এ ক্লিক করুন।

 - তালিকা খালি করতে **সব অনির্বাচন করুন** ক্লিক করুন। প্রয়োজনীয় ফ্রি মডেলটি তালিকাতে থাকবে।

<br/>

> ℹ️ **নোট**<br/>
> যদি আপনি OpenRouter-এ তাড়াতাড়ি ক্রেডিট যোগ করতে না চান, তবে **শুধু ফ্রি** চালু করে শুরু করুন এবং ফ্রি মডেলগুলি নির্বাচন করুন (ক্রেডিট কার্ডের প্রয়োজন নেই)। Ollama ব্যবহার করে কোনও API কী ছাড়াই স্থানীয়ভাবে মডেল চালানো যায়।

### ভাষা

**সেটিংস** > **ভাষা** ব্যবহার করে অ্যাপে ব্যবহৃত ভাষার তালিকাগুলি সংগঠিত করুন।

- **শীর্ষ ভাষাগুলি** **অনুবাদ** এবং **রূপান্তর**-এ ভাষার তালিকার উপরের দিকে পিন করার জন্য থাকে।
- **কাস্টম ভাষা** আপনাকে ইন-বিল্ট তালিকাতে না থাকা ভাষা যোগ করতে দেয়।

যদি আপনি একটি কাস্টম ভাষা যোগ করেন, তবে ইন-বিল্ট বিকল্পগুলির পাশাপাশি ভাষার সিলেক্টরে এটি প্রদর্শিত হবে।

<a id="cost-tracking"></a>
### খরচ ট্র্যাকিং

**সেটিংস** > **খরচ ট্র্যাকিং** ব্যবহার করে খরচের তথ্য পরিচালনা করুন।

- **মোট খরচ** চলমান মোট দেখায়।
- **মান কপি করুন** মোট প্যানেল থেকে ক্লিপবোর্ডে কপি করে।
- **খরচ রিসেট করুন** সংরক্ষিত মোটকে শূন্যে সেট করে।
- **API কী ব্যবহারের সাথে সিঙ্ক করুন** আপনার OpenRouter অ্যাকাউন্টের প্রতিবেদিত ব্যবহারের সাথে মিলে যাওয়ার জন্য মোট সেট করে (শুধুমাত্র OpenRouter-এ)।
- **API কী ব্যবহার** OpenRouter ব্যবহারের বিবরণ দেখায়, যদি উপলব্ধ থাকে।
- **খরচ ডেটা মুছুন** সমস্ত তথ্য মুছে, অথবা নির্বাচিত তারিখের আগের এন্ট্রিগুলি মাত্র।

**খরচ ট্র্যাকিং:** যখন আপনি OpenRouter মডেল ব্যবহার করেন, অ্যাপ OpenRouter থেকে খরচের তথ্য অনুযায়ী আপনার আসল ব্যবহার এবং খরচ দেখায়। অন্য সমস্ত প্রদানকারীদের ক্ষেত্রে, অ্যাপ OpenRouter দ্বারা প্রকাশিত মূল্যের উপর ভিত্তি করে খরচ অনুমান করে, মূল্য অনুপস্থিত থাকলে অনুমান শূন্য হতে পারে।

<br/>

> ℹ️ **নোট**<br/>
> **সমস্ত খরচের চিত্র শুধুমাত্র আপনার তথ্যের জন্য, অফিসিয়াল বিলিং স্টেটমেন্ট নয়।**

<br/>

> ⚠️ **সতর্কতা**<br/>
> ডেটা মুছলে তা আর পুনরায় ফিরে পাওয়া যায় না। মুছে ফেলার আগে, আপনার ডেটা [**হিস্টোরি**](#history) বা [**ড্যাশবোর্ড** > **সমস্ত কল**](#dashboard-tabs) মাধ্যমে ব্যাকআপ বা রপ্তানি করার বিষয়টি নিশ্চিত করুন। না হলে, এটি স্থায়ীভাবে হারিয়ে যাবে। প্রতিটি API কল এন্ট্রির সাথে সম্পর্কিত সমস্ত ইনপুট/আউটপুট হিস্ট্রি মুছে ফেলা হবে।

- ব্যাকআপ বা শেয়ার করার জন্য প্রম্পট এক্সপোর্ট করুন

<a id="api-config"></a>
### API কনফিগ

সমর্থিত প্রদানকারী হল: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras এবং **Ollama** (একটি বেস URL মাধ্যমে স্থানীয় মডেল)। আপনার যে প্রদানকারীদের ব্যবহার করছেন শুধু তাদের কনফিগ করার প্রয়োজন রয়েছে।

**ওয়েব অ্যাপ্লিকেশন: কেবল প্রশাসক**

API কী গুলি সিস্টেম বা ডকার এনভায়রনমেন্ট ভ্যারিয়েবল মাধ্যমে কনফিগ করা হয় — এগুলি ওয়েব UI-তে প্রবেশ করা হয় না। এই পৃষ্ঠাটি দেখায় যে কোন প্রদানকারীদের একটি কী কনফিগ করা হয়েছে এবং **`টেস্ট`** বোতামে ক্লিক করে প্রতিটি পরীক্ষা করতে দেয়।

<br/>

> ℹ️ **নোট**<br/>
> API কী পরিবর্তন করতে, আপনার সিস্টেম বা ডকার কনফিগারেশনে এনভায়রনমেন্ট ভ্যারিয়েবল আপডেট করুন এবং সার্ভার বা কনটেইনার পুনরায় চালু করুন।

<br/>

**ডেস্কটপ অ্যাপ্লিকেশন**

**API কনফিগ**  ব্যবহার করুন প্রতিটি প্রদানকারীর জন্য API কী সংরক্ষণ করতে। Ollama এর জন্য, API কী ছাড়া বরং **বেস URL** লিখুন।

<br/>

> 💡 **টিপ** <br/>
> যদি আপনি API কী ব্যবহার না করতে চান বা ব্যবহারের জন্য অর্থ দিতে না চান, আপনি [Ollama ডাউনলোড](https://ollama.com) করে আপনার মেশিনে স্থানীয়ভাবে মডেল (যেমন `translategemma:4b`) চালাতে পারেন। বিকল্পভাবে, তাদের ফ্রি মডেল ব্যবহার করতে আপনি একটি ফ্রি OpenRouter অ্যাকাউন্ট খুলতে পারেন (ক্রেডিট কার্ডের প্রয়োজন নেই), অথবা Cerebras, Google, Groq, বা Mistral AI থেকে ফ্রি API কী পেতে পারেন।

<br/>

- শুধু আপনার প্রয়োজন এমন প্রদানকারী যোগ করুন। **সেটিংস** > **মডেল**, প্রতিটি মডেল আইডি প্রদানকারী দিয়ে শুরু হয় (যেমন `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)।

API কী যোগ করতে, টেক্সট ফিল্ডে মানটি লিখুন এবং **`সেভ`** বোতামে ক্লিক করুন। বিদ্যমান কী প্রতিস্থাপন করতে, **`সম্পাদন`** ক্লিক করুন। একটি কী কাজ করছে কি না তা যাচাই করতে, **`টেস্ট`** ক্লিক করুন। Ollama বেস URL-এর ক্ষেত্রে, সংযোগ পরীক্ষা করতে সবসময় **`টেস্ট`** ক্লিক করুন।

<br/>

> ℹ️ **নোট**<br/>
> আপনি একটি API কী এর বর্তমান মান দেখতে পাবেন না। আপনি শুধুমাত্র **`সম্পাদন`** বোতাম ব্যবহার করে এটি প্রতিস্থাপন করতে পারেন।
> API কী গুলি কনফিগে এনক্রিপ্ট করে সংরক্ষণ করা হয়।

<a id="common-issues"></a>
## সাধারণ সমস্যা

যদি কিছু ঠিকভাবে কাজ না করে, তাহলে প্রথমে নিচের বিষয়গুলি চেক করুন।

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### অ্যাপটি টেক্সট অনুবাদ, পুনর্লিখন বা রূপান্তর করবে না

চেক করুন যে:

- আপনি টুলবার থেকে একটি মডেল নির্বাচন করেছেন কিনা
- [**সেটিংস** > **মডেল**](#models)-এ অন্তত একটি মডেল তালিকাভুক্ত আছে কিনা
- আপনার API সেটআপ কাজ করছে কিনা

আপনি যদি ডেস্কটপ অ্যাপ ব্যবহার করেন:

1. [**সেটিংস** > **API কনফিগ**](#api-config) খুলুন।
2. নিশ্চিত করুন যে অন্তত একটি API কী সংরক্ষিত আছে।
3. কী কাজ করছে কিনা নিশ্চিত করতে প্রদানকারীর পাশের **টেস্ট**-এ ক্লিক করুন।

<br/>

<a id="the-model-list-is-empty"></a>
### মডেলের তালিকা খালি

[**সেটিংস** > **মডেল**](#models)-এ যান এবং **রিফ্রেশ**-এ ক্লিক করুন।

প্রয়োজনে:

- কোনো মডেল খুঁজুন
- **শুধু ফ্রি** চালু করুন
- **নির্বাচিত মডেল**-এ এক বা একাধিক মডেল যোগ করুন

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ফলাফল খুব ধীর বা খরচালো

নিচের যেকোনো একটি বা একাধিক করুন:

- একটি ভিন্ন মডেল নির্বাচন করুন
- একটি ছোট ইনপুট ব্যবহার করুন
- [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings)-এ **রিয়েল-টাইম অনুবাদ (টাইপ করার সময়)** বন্ধ করুন
- সহজ কাজের জন্য ফ্রি মডেল ব্যবহার করুন (দেখুন [মডেল](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ইন্টারফেসের ভাষা ভুল

[টুলবার](#toolbar)-এ গ্লোব আইকনে ক্লিক করে আপনার পছন্দের **ইন্টারফেস ভাষা** নির্বাচন করুন।

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### টেক্সট খুব ছোট বা পড়া কঠিন

[**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং পরিবর্তন করুন:

- **ফন্ট ফ্যামিলি**
- **আকার**

<br/>

<a id="dashboard-charts-are-empty"></a>
### ড্যাশবোর্ডের চার্ট খালি

যদি:

- আপনি কেবল **ফ্রি মডেল** ব্যবহার করছেন (খরচের চার্ট খালি থাকবে)
- নির্বাচিত **সময় ফিল্টার** কল হওয়ার সময়কাল কভার করছে না — তা চেক করতে **সব** চয়ন করুন

যদি **সব** নির্বাচনের পরও চার্ট খালি থাকে, তবে [**ইতিহাস**](#history) বা **সমস্ত কল** ট্যাবে কল আছে কিনা তা নিশ্চিত করুন।

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### খরচে দেখাচ্ছে "উপলব্ধ নেই" বা অস্পষ্ট

যখন আপনি **ওপেনরাউটার** মাধ্যমে মডেল ব্যবহার করেন, তখন অ্যাপটি ওপেনরাউটার থেকে রিপোর্ট করা আপনার প্রকৃত ব্যয় দেখায়।

**অন্যান্য প্রদানকারীদের** (ওপেনএআই সরাসরি, অ্যানথ্রোপিক সরাসরি ইত্যাদি) জন্য, খরচ ওপেনরাউটার কর্তৃক প্রকাশিত মূল্য প্রকাশনা থেকে অনুমান করা হয়। যদি কোন মডেলের জন্য মিল পাওয়া না যায়, তবে খরচ **উপলব্ধ নেই** হিসেবে দেখানো হবে এবং আপনার মোট খরচে যোগ হবে না।

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### মোট খরচ আমার প্রদানকারীর বিলের সাথে মেলে না

অ্যাপে দেখানো সকল খরচ **শুধুমাত্র রেফারেন্সের জন্য অনুমানিত**, আনুষ্ঠানিক বিলিং বিবৃতি নয়।

আপনার প্রকৃত ওপেনরাউটার ব্যয়ের সাথে মোট খরচ কাছাকাছি আনতে, [**সেটিংস** > **খরচ ট্র্যাকিং**](#cost-tracking)-এ যান এবং **API কী ব্যবহারের সাথে সিঙ্ক করুন**-এ ক্লিক করুন।

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### সাইডবার থেকে ইতিহাস পৃষ্ঠা নেই

**ক্রিয়াকলাপ ইতিহাস রাখুন** বন্ধ করা থাকতে পারে। [**সেটিংস** > **সাধারণ সেটিংস**](#general-settings) খুলুন এবং এটি চালু করুন। লক্ষ করুন যে চালু করলেও আগে মুছে যাওয়া ইতিহাসের ডেটা ফিরে পাওয়া যাবে না।

<br/>

<a id="web-app-session-expired"></a>
### ওয়েব অ্যাপ: লগইন পৃষ্ঠাতে আবার পুনঃনির্দেশ করা হয়েছে

আপনার সেশন সময় শেষ হয়ে গেছে হতে পারে। আবার লগইন করুন। যদি এটি ঘন ঘন ঘটে, তবে সার্ভার কনফিগারেশনের সেশন আজীবন সেটিংস চেক করুন।

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### ড্যাশবোর্ড অন্যান্য ব্যবহারকারীর জন্য কোন ডেটা দেখায় না (ওয়েব)

কেবলমাত্র **প্রশাসকদের** পার্থক্য **ব্যবহারকারী** ফিল্টার মাধ্যমে সকল ব্যবহারকারীর ডেটা দেখার অনুমতি আছে। নিয়মিত ব্যবহারকারীরা নকশা অনুযায়ী কেবল নিজেদের কার্যকলাপ দেখে।

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### আমি একটি প্রম্পট পরিবর্তন করেছি এবং সম্পাদনাগুলি হারিয়ে গেছে

প্রম্পট সম্পাদনা করার সময়, সর্বদা **সেভ**-এ ক্লিক করুন তারপর **রানে ফিরুন**-এ ক্লিক করুন।

<a id="quick-tips"></a>
## দ্রুত টিপস

- আপনি যদি [**পুনর্লিখন**](#rewrite) বা [**রূপান্তর**](#transform) এ যান তার আগে, আপনার সেটআপ কাজ করছে কিনা তা নিশ্চিত করতে [**অনুবাদ**](#translate)-এ শুরু করুন।
- দৈনিক ভাষার উন্নতির জন্য [**পুনর্লিখন**](#rewrite) ব্যবহার করুন।
- একটি নির্দিষ্ট কাজের জন্য পুনরাবৃত্তিযোগ্য কাজের ধারা প্রয়োজন হলে [**রূপান্তর**](#transform) ব্যবহার করুন।
- আপনি যদি ব্যবহার এবং খরচ উপর নজর রাখতে চান তবে [**ড্যাশবোর্ড**](#dashboard) ব্যবহার করুন।
- অতীতের কার্যকলাপ এবং তাদের সম্পূর্ণ ইনপুট/আউটপুট পাঠ্য পর্যালোচনা করতে [**ইতিহাস**](#history) ব্যবহার করুন।
- আপনি যদি একটি প্রম্পট লাইব্রেরি তৈরি করছেন যা আপনি সুরক্ষিত রাখতে চান (দেখুন [রূপান্তর প্রম্পট](#transform-prompts)) বা অন্যদের সাথে শেয়ার করতে চান তবে নিয়মিত প্রম্পট রপ্তানি করুন।
