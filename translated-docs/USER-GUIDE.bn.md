### দ্রুত একটি প্রম্পট তৈরি করুন

### দ্রুত একটি প্রম্পট তৈরি করুন

একটি প্রম্পট স্রImagine的最快的方法是:

1. **নতুন প্রম্পট** ক্লিক করুন।
2. **প্রম্পট তৈরি** ক্লিক করুন।
3. আপনি কী করতে চান তা প্রম্পটটি বর্ণনা করুন।
4. একটি মডেল নির্বাচন করুন।
5. অ্যাপটি আপনার জন্য একটি খসড়া তৈরি করতে দিন।
6. খসড়াটি পর্যালোচনা করুন এবং **সেভ** ক্লিক করুন।

![প্রম্পট তৈরি](../images/screenshots/bn/transform-generate.png)

<br />

### একটি প্রম্পট সম্পাদনা করুন

যখন আপনি একটি প্রম্পট তৈরি বা সম্পাদনা করেন, সম্পাদক বামে এবং একটি পরীক্ষা এলাকা ডানে দেখা যায়।

![প্রম্পট সম্পাদক](../images/screenshots/bn/transform-prompt-edit.png)

প্রধান ফিল্ডগুলি হল:

- **প্রম্পট নাম**: প্রম্পট তালিকায় দেখানো নাম।
- **প্রম্পট নির্দেশনা (ঐচ্ছিক)**: প্রম্পট চালানোর সময় ব্যবহারকারীকে দেখানোর জন্য একটি সংক্ষিপ্ত ইঙ্গিত।
- **মডেলের ভূমিকা**: এআইকে প্রদত্ত সামগ্রিক ভূমিকা, যেমন 'আপনি একজন সহায়ক সহকারী।'
- **মডেল নির্দেশনা (প্রতি লাইন একটি)**: আপনি এআইকে মান五指 stretching নির্দিষ্ট নিয়মগুলি।
- **আউটপুট বিবরণ**: ফলাফল বর্ণনা করার একটি সংক্ষিপ্ত শব্দ, যেমন 'সার**' বা 'পুনর্লিখন'।
- **টেম্পারেচার (০.০ → ১.০)**: একটি সৃজনশীল স্লাইডার।
- **লক্ষ্য ভাষা জিজ্ঞাসা করুন**: প্রম্পট চালানোর সময় একটি লক্ষ্য ভাষা সিলেক্টর যোগ করে।

যদি প্রযুক্তিগত শব্দ **টেম্পারেচার** আপনার জন্য নতুন হয়, তাহলে এটি এমনভাবে ভাবুন:

- একটি **নিম্ন** টেম্পারেচার আরও স্থির, আরও অনুমানযোগ্য ফল দেয়।
- একটি **উচ্চ** টেম্পারেচার আরও বৈচিত্র্য এবং সৃজনশীলতা দেয়।

আপনি এছাড়াও ব্যবহার করতে পারেন:

- **`Generate prompt`** একটি সরল বর্ণনা থেকে একটি নতুন খসড়া তৈরি করতে
- **`Improve prompt`** একটি বিদ্যমান প্রম্পট পরিশোধন করতে
- **`Translate prompt`** প্রম্পট ফিল্ডগুলি অনুবাদ করতে

> ⚠️ **সতর্কতা**<br/>
> আপনি **`Back to Run`** ক্লিক করার আগে **`Save`** ক্লিক করুন। যদি আপনি সংরক্ষণ না করে পেছনে যান, তাহলে আপনার পরিবর্তনগুলি হারিয়ে যাবে।

### সংরক্ষিত প্রম্পটগুলি ব্যবস্থাপনা করুন

<a id="api-config"></a>
### API কনফিগারেশন

**শুধু ডেস্কটপ**

**API Config** ব্যবহার করে ডেস্কটপ অ্যাপকে OpenRouter বা একটি Transrewrt প্রক্সির সাথে সংযোগ করুন।

- **OpenRouter API Key** এখানে আপনার কী পেস্ট করা হয়।
- **API URL** সার্ভিসের ঠিকানা। এটিকে ডিফল্ট রেখে দিন sebel of lenker আপনাকে অন্য কিছু দেওয়া হয়।
- **Use Transrewrt Proxy** অনুরোধগুলি progeny সরাসরি OpenRouter-এর পরিবর্তে একটি প্রক্সি সার্ভিসের মাধ্যমে রাউট করে।
- **Key Seed** প্রক্সি অপশন সক্রিয় হলে দেখা যায়।
- **Test API Configuration** বERIC_VALID করা হয়奠基当前位置 সেটআপ কাজ করছে কিনা তা যাচাই করে।

আপনার API key প্রিপ করার বিস্তৃত ধাপের জন্য, উপরে [How to get an API key](#how-to-get-an-api-key-desktop-app) দেখুন।

> ℹ️ **নোট**<br/>
> আপনি কি **API URL**, **Use Transrewrt Proxy**, বা **Key Seed** কীנה বোঝেননি, তাহলে এগুলো পরিবর্তন না রেখে ডিফল্ট OpenRouter সেটআপ ব্যবহার করুন। প্রক্সি সম্পর্কে আরও তথ্য [Transrewrt Proxy repository](https://github.com/wsj-br/transrewrt-proxy) এ পাওয়া যাবে।
