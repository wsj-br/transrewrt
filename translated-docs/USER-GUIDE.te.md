# వాడుకరి మార్గదర్శకం

<br/>

<a id="introduction"></a>

## పరిచయం

మూడు ప్రధాన మార్గాల్లో టెక్స్ట్‌తో పనిచేయడానికి ట్రాన్స్రీవ్రట్ సహాయపడుతుంది:

- **అనువాదం** - ఒక భాష నుండి మరొక భాషలోకి టెక్స్ట్ మార్చడం.
- **తిరిగి రాయడం** - స్పష్టంగా, సంక్షిప్తంగా లేదా సమీపంగా వంటి వేరొక శైలిలో టెక్స్ట్ ని పునరావృతం చేయడం.
- **పరివర్తన** - ప్రాంప్ట్ లు అని పిలుస్తారు అనుకూల AI సూచనలు ఉపయోగించి ప్రాసెస్ టెక్స్ట్.

<br/>

స్థాపించి ప్రారంభించిన తర్వాత అనువర్తనాన్ని ఉపయోగించడం ఎలాగో ఈ మార్గదర్శకం వివరిస్తుంది. స్థాపన దశల కోసం, ప్రధాన **[README](README.te.md)** చూడండి.

<br/>

> ℹ️ **గమనిక**<br/>
> ట్రాన్స్రీవ్రట్ Windows మరియు Linux కోసం డెస్క్‌టాప్ అనువర్తనంగా, మరియు స్వంతంగా హోస్ట్ చేసుకునే వెబ్ అనువర్తనంగా లభ్యంలో ఉంటుంది. ఈ మార్గదర్శకం అనువర్తనం యొక్క ప్రతిరోజు ఉపయోగాన్ని దృష్టిలో పెట్టుకుంటుంది. ఏదైనా ఒక సంస్కరణకు మాత్రమే అనువర్తించినప్పుడు, అది స్పష్టంగా గుర్తించబడుతుంది.

## ప్రారంభించే ముందు

ట్రాన్స్రివర్ట్ (Transrewrt) ఉపయోగించడానికి, మీరు కనీసం ఒక ఏఐ ప్రొవైడర్‌కు ప్రాప్యతను కలిగి ఉండాలి. మద్దతు ఇచ్చే ప్రొవైడర్స్ ఇలా ఉన్నాయి: చాలా మోడల్లను సమాహారం చేసే [OpenRouter](https://openrouter.ai), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras మరియు స్థానిక మోడల్ల కోసం [Ollama](https://ollama.com).

మీరు ప్రారంభించడానికి చెల్లింపు మోడల్‌ను ఎంచుకోవాల్సిన అవసరం లేదు. మీరు మీ OpenRouter API కీని చేర్చిన వెంటనే, అప్లికేషన్ అంతర్నిర్మిత **ఉచిత** OpenRouter ఎంపికను స్వయంచాలకంగా ప్రారంభిస్తుంది. ఇది మీరు వెంటనే పాఠాన్ని అనువదించడం, పునర్రాసన చేయడం మరియు పరివర్తన చేయడం చేయడానికి అనుమతిస్తుంది. ప్రత్యామ్నాయంగా, మీరు Cerebras, Google, Groq లేదా Mistral AI వద్ద ఉచిత API కీని సంపాదించవచ్చు.

సులభ భాషలో:

- ఒక **మోడల్** అనేది పని చేసే ఏఐ ఇంజిన్. మోడల్స్‌ను ఒక **ప్రొవైడర్ ప్రిఫిక్స్** (ఉదాహరణకు `openrouter/…`, `openai/…`, `ollama/…`)తో పాటు జాబితా చేయబడ్డాయి.
- ఒక **API కీ** (లేదా Ollama కోసం, ఒక **బేస్ URL**) అనేది ఆ ప్రొవైడర్‌కు అప్లికేషన్ చేరుకునే పద్ధతి.

డెస్క్ టాప్ అనువర్తనాన్ని ఉపయోగిస్తున్నట్లయితే, మీరు ఉపయోగించే ప్రతి ప్రొవైడర్ కోసం [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) లో కీలను జోడించండి. ఓపెన్ రూటర్ మాత్రమే ఉపయోగించడానికి, క్రింద ఉన్న [API కీ పొందడం ఎలా](#how-to-get-an-api-key-desktop-app) చూడండి. API కీని ఉపయోగించకూడదనుకుంటే, మీరు Ollamaని ఇన్ స్టాల్ చేయవచ్చు ([ollama.com](https://ollama.com) నుండి) మరియు `translategemma:4b` వంటి స్థానిక మోడల్స్ ఉపయోగించవచ్చు.

మీరు **వెబ్ వెర్షన్** ని ఉపయోగిస్తున్నట్లయితే, సర్వర్ యాజమాన్యం పర్యావరణ వేరియబుల్స్ ద్వారా ప్రొవైడర్లను కాన్ఫిగర్ చేస్తారు, కాబట్టి మీరు అనువర్తనంలో నేరుగా API కీలను ప్రవేశపెట్టలేరు.

<a id="how-to-get-an-api-key-desktop-app"></a>

### ఉచిత OpenRouter API కీని పొందే విధానం (డెస్క్‌టాప్ అప్లికేషన్)

మీరు డెస్క్‌టాప్ అప్లికేషన్ ఉపయోగిస్తున్నట్లయితే, కింది దశలను అనుసరించండి:

1. మీ వెబ్ బ్రౌజర్‌లో [OpenRouter](https://openrouter.ai)కి వెళ్లండి.
2. ఖాతాను సృష్టించండి లేదా సైన్ ఇన్ అవ్వండి.
3. [Keys](https://openrouter.ai/keys) పేజీని తెరవండి.
4. కొత్త API కీని సృష్టించడానికి బటన్‌పై క్లిక్ చేయండి.
5. తర్వాత మీరు దానిని గుర్తించడానికి సౌకర్యంగా ఉండేందుకు కీకి పేరు పెట్టండి.
6. కొత్త సృష్టించిన API కీని కాపీ చేసుకోండి.
7. తిరిగి Transrewrtకి వెళ్లి **సెట్టింగ్స్** > **API కాన్ఫిగ్** తెరవండి.
8. **సెట్టింగ్స్** > **API కాన్ఫిగ్** కింద ఉన్న **OpenRouter API కీ** పొలంలోకి కీని పేస్ట్ చేయండి.
9. కీ పనిచేస్తుందో లేదో ఖాత్రీ చేసుకోవడానికి **OpenRouter కీని పరీక్షించండి** పై క్లిక్ చేయండి.

<a id="getting-started"></a>

## ప్రారంభించడం

మీరు మొదటిసారి Transrewrt ఉపయోగిస్తున్నట్లయితే, ఈ క్రమాన్ని పాటించండి:

1. అప్లికేషన్‌ను తెరవండి.
2. అవసరమైతే, గ్లోబ్ ఐకాన్ నుండి మీ **ఇంటర్ఫేస్ భాష**ను ఎంచుకోండి.
3. మీరు **డెస్క్‌టాప్ అప్లికేషన్**‌లో ఉంటే, [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) తెరవండి, కనీసం ఒక ప్రొవైడర్ కోసం (ఉదాహరణకు ఓపెన్‌రౌటర్) API కీని జోడించండి మరియు అది పనిచేస్తుందో లేదో తనిఖీ చేయడానికి **పరీక్షించండి** పై క్లిక్ చేయండి.
4. [**సెట్టింగ్స్** > **మోడల్స్**](#models) తెరిచి, **ఎంచుకున్న మోడల్స్**కు ఒకటి లేదా అంతకంటే ఎక్కువ మోడల్స్ జోడించండి.
5. [**సెట్టింగ్స్** > **భాషలు**](#languages) తెరవండి మరియు మీకు ఎక్కువగా ఉపయోగించే భాషలు మొదట కనిపించాలనుకుంటే మీ **ప్రధాన భాషలు**ని ఎంచుకోండి.
6. **అనువాదం** కు వెళ్లి, అన్నీ సరిగా పనిచేస్తున్నాయో ఉన్నాయో నిర్ధారించడానికి సులభమైన అనువాదాన్ని ప్రారంభించండి.
7. అది పనిచేసిన తర్వాత, **పునఃరాయండి** మరియు తరువాత **రూపాంతరం** ప్రయత్నించండి.

ఈ క్రమం చాలా ముఖ్యం. ఇది సాధారణంగా ఎదురయ్యే సమస్యను నివారిస్తుంది: అప్లికేషన్‌కు పనిచేసే API కనెక్షన్ లేదా ఎంచుకున్న మోడల్ లేకుండానే పనిని చేపట్టడానికి ప్రయత్నించడం.

### టూల్‌బార్

మీరు యాప్ లో ఎక్కడ ఉన్నారో దాని బట్టి టూల్‌బార్ కొంచెం మారుతుంది.

- ఎడమ వైపు, ప్రస్తుత పేజీ పేరు కనిపిస్తుంది.
- కుడి వైపు, **మోడల్ సెలక్టర్** మరియు **ఇంటర్‌ఫేస్ భాషా** నియంత్రణలు కనిపిస్తాయి.

**మోడల్ ఎంపికదారు** ప్రస్తుత పని కోసం ఉపయోగించే కృత్రిమ మేధస్సు (ఎఐ) ఇంజిన్‌ను మీరు ఎంచుకోవడానికి అనుమతిస్తుంది.

  ![మోడల్ సెలక్టర్](../images/screenshots/te/model-selector.png)

స్వేచ్ఛా మోడల్స్ ఎల్లప్పుడూ లభించకపోవచ్చు — కొన్నిసార్లు అవి ఆఫ్ లేదా ఉపయోగ పరిమితి ఉండవచ్చు. ఇలా జరిగితే, యాప్ ఆ మోడల్‌ను మీ లభ్యమయ్యే జాబితా నుండి స్వయంచాలకంగా తొలగిస్తుంది. ఏ మోడల్ కనిపించాలో నియంత్రించడానికి, [**సెట్టింగ్స్** > **మోడల్స్**](#models)కు వెళ్లి మీ మోడల్ జాబితాను సవరించండి. 
టూల్‌బార్ లో మోడల్ పేరుకు ఎడమ వైపున ఉన్న ప్రొవైడర్ చిహ్నాన్ని క్లిక్ చేయడం ద్వారా మీరు మోడల్ సెట్టింగ్స్ ను నేరుగా తెరవవచ్చు.

<br/>

**గ్లోబ్ ఐకాన్ + భాషా కోడ్** మెనూలు మరియు బటన్ల వంటి యాప్ ఇంటర్‌ఫేస్ భాషను మారుస్తుంది. ఇది **అనువాదంలో** ఉపయోగించే అనువాద భాషలను మార్చదు.

![ఇంటర్ఫేస్ భాషా ఎంపిక](../images/screenshots/te/language-selector.png)

### ఇన్‌పుట్ మరియు అవుట్‌పుట్ ప్యానెల్స్

చాలా వర్క్‌స్పేస్‌లు ఎడమ వైపున ఉన్న **ఇన్‌పుట్** ప్యానెల్ మరియు కుడి వైపున ఉన్న **అవుట్‌పుట్** ప్యానెల్‌ను ఉపయోగిస్తాయి.

ప్రతి ప్యానెల్ కూడా ఈ క్రింది వాటిని చూపిస్తుంది:

| **ఇన్‌పుట్**                                                          | **అవుట్‌పుట్**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - అక్షరాల సంఖ్య <br/>- పదాల సంఖ్య <br/>- పేరాల సంఖ్య   <br/> | - పని ఎంత సమయం తీసుకుంది<br/>- **TPS** (సెకనుకు టోకెన్లు)<br/>- అక్షరాలు, పదాలు మరియు పేరాల సంఖ్య<br/>- ఉపయోగించిన మోడల్ |


మీరు సాంకేతిక పదాల గురించి ఆలోచిస్తున్నట్లయితే:

- **టోకెన్** అంటే టెక్స్ట్ యొక్క చిన్న భాగం. దీనిని పదంలోని ఒక భాగం లేదా ఒక చిన్న పదంగా పరిగణించవచ్చు.
- **TPS** అంటే మోడల్ ఒక సెకనులో ప్రాసెస్ చేసిన ఆ టెక్స్ట్ భాగాల సంఖ్య.

<br/>

ప్రతి ఆపరేషన్ ఖర్చు (అందుబాటులో ఉంటే) మరియు మొత్తం ఖర్చును [**సెట్టింగ్స్** > **సాధారణ సెట్టింగ్స్**](#general-settings) లో `చర్యల పై ఖర్చు సమాచారాన్ని చూపించు` ఎంపికను సక్రియం చేయడం ద్వారా పర్యవేక్షించవచ్చు.

## అనువాదం

మీరు ఒక భాషలో ఉన్న పాఠాన్ని మరొక భాషలోకి మార్చాలనుకున్నప్పుడు **అనువాదం** ఉపయోగించండి.

![అనువాద కార్యస్థలం](../images/screenshots/te/translate.png)

<br/>

<a id="translate-text"></a>

### పాఠ్యాన్ని అనువదించండి

1. **అనువదించు** ని తెరవండి.
2. **నుండి** వద్ద ఒక భాషను ఎంచుకోండి.
3. **కు** వద్ద ఒక భాషను ఎంచుకోండి.
4. టూల్ బార్ లో ఒక మోడల్ ని ఎంచుకోండి.
5. **ఇన్‌పుట్** లోకి పాఠ్యాన్ని టైప్ చేయండి లేదా పేస్ట్ చేయండి.
6. **అనువదించు** పై క్లిక్ చేయండి.
7. **అవుట్ పుట్** లో ఫలితాన్ని చదవండి.
8. ఫలితాన్ని కాపీ చేయాలనుకుంటే కాపీ బటన్ ఉపయోగించండి.

<br/>

<a id="language-selection"></a>

### భాష ఎంపిక

- **నుండి**, ఒక ప్రత్యేక భాష లేదా **భాషను గుర్తించు** కావచ్చు.
- **కు**, ఫలితాన్ని పొందాలనుకుంటున్న భాష.

ఎంచుకున్న **ప్రధాన భాషలు** జాబితా పైభాగంలో కనిపిస్తాయి. మీరు ఇవి [**సెట్టింగ్‌లు** > **భాషలు**](#languages)లో సెట్ చేసుకోవచ్చు.

<br/>

<a id="helpful-translation-settings"></a>

### ఉపయోగకరమైన అనువాద సెట్టింగ్‌లు

[**సెట్టింగ్‌లు** > **సాధారణ సెట్టింగ్‌లు**](#general-settings)లో, అనువాద ప్రవర్తనను మీరు మార్చవచ్చు:

- **పేస్ట్ చేసినప్పుడు స్వయంచాలకంగా అనువాదం** మీరు పాఠ్యాన్ని పేస్ట్ చేసిన వెంటనే అనువాదాన్ని ప్రారంభిస్తుంది.
- **ఫలితాన్ని క్లిప్‌బోర్డుకు స్వయంచాలకంగా కాపీ చేయి** విజయవంతమైన నడక తర్వాత ఫలితాన్ని స్వయంచాలకంగా కాపీ చేస్తుంది.
- **నిజ సమయ అనువాదం (టైపింగ్ సమయంలో)** మీరు టైప్ చేస్తున్నప్పుడు అనువాదాలను నడుపుతుంది.
- **టైమౌట్ (ms)** నిజ సమయ అనువాదాన్ని ప్రారంభించే ముందు యాప్ ఎంతకాలం వేచి ఉంటుందో నియంత్రిస్తుంది.
- **ఎంటర్** మీరు `ఎంటర్` నొక్కినప్పుడు ఏమి జరుగుతుందో నియంత్రిస్తుంది:

## రీరైట్

ప్రధాన అర్థాన్ని మార్చకుండా మాటలను మెరుగుపరచాలనుకున్నప్పుడు **రీరైట్** ఉపయోగించండి.

![రీరైట్ వర్క్‌స్పేస్](../images/screenshots/te/rewrite.png)

ఇది కింది వాటికి ఉపయోగకరం:

- సంధి తప్పులు మరియు వ్యాకరణాన్ని సరిచేయడం (**స్పెల్లింగ్ & గ్రామర్ తనిఖీ చేయండి**)
- పాఠ్యాన్ని స్పష్టంగా చేయడం (**స్పష్టత పెంచండి**)
- ఒకే రన్‌లో పలు విభిన్న రూపాంతరాలు (**ప్రత్యామ్నాయ వెర్షన్లు**)
- పాఠ్యాన్ని అధికారికంగా లేదా సౌహార్దపూరితంగా మార్చడం (**అధికారికం** / **అనధికారికం**)
- పాఠ్యాన్ని సంక్షిప్తీకరించడం లేదా విస్తరించడం (**సంక్షిప్తం చేయండి** / **విస్తరించండి**)
- పాఠ్యం సాంకేతికంగా ఉండేలా చేయడం (**సాంకేతికంగా మార్చండి**)

<br/>

> 💡 **టిప్**<br/>
> "**స్పెల్లింగ్ & గ్రామర్ తనిఖీ చేయి**" మోడ్ ఉపయోగించినప్పుడు, అవుట్‌పుట్ ప్యానెల్ లో (**కాపీ** పక్కన) **మార్పులు చూపించు** స్విచ్ కనిపిస్తుంది.
> మీ పాఠ్యానికి వర్తించిన ప్రత్యేక సర్దుబాట్లను చూపించడానికి లేదా దాచడానికి దీన్ని ఆన్ లేదా ఆఫ్ చేయండి.

<a id="transform"></a>

## పరివర్తన

మీరు ఏదైనా అనుకూల సూచనల సమితిని అనుసరించమని ఆర్టిఫిషియల్ ఇంటెలిజెన్స్‌ను అడగాలనుకున్నప్పుడు **పరివర్తన**ను ఉపయోగించండి.

![పరివర్తన వర్క్‌స్పేస్](../images/screenshots/te/transform.png)

ఇది అప్లికేషన్ లోని అత్యంత సమర్థవంతమైన ప్రాంతం. మీరు ఇలాంటి పనులలో దీనిని ఉపయోగించవచ్చు:

- గమనికలను సారాంశీకరించడం
- సున్నితమైన చిట్టా నుండి శుభ్రంగా ఇమెయిల్‌గా మార్చడం
- కీలక పాయింట్లను ఉపసంహరించుకోవడం
- పాఠ్యాన్ని ప్రత్యేక ఫార్మాట్‌లోకి మార్చడం
- ఇన్‌పుట్ టెక్స్ట్‌తో చేయగల మరేవైనా అనుకూల చర్యలు

<br/>

<a id="run-an-existing-prompt"></a>

### ఇప్పటికే ఉన్న ప్రాంప్ట్‌ని అమలు చేయండి

1. **పరివర్తన** తెరవండి.
2. ప్రాంప్ట్ జాబితా నుండి ఒక ప్రాంప్ట్‌ని ఎంచుకోండి.
3. ఒకవేళ **లక్ష్య** భాష బాక్స్ కనిపిస్తే, కావలసినట్లయితే ఒక భాషను ఎంచుకోండి.
4. **ఇన్‌పుట్** లోకి పఠనం చేయడం లేదా పేస్ట్ చేయడం.
5. **పరివర్తన** పై క్లిక్ చేయండి.
6. **అవుట్‌పుట్** లో ఫలితాన్ని చదవండి.

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### మీకు ఇంకా ప్రాంప్ట్‌లు లేకపోతే

మీ ప్రాంప్ట్ జాబితా ఖాళీగా ఉంటే, ట్రాన్స్‌ఫారమ్ వర్క్‌స్పేస్‌లో **సాంపిల్ ప్రాంప్ట్‌లను లోడ్ చేయండి** పై క్లిక్ చేయండి. [**సెట్టింగ్స్** > **ట్రాన్స్‌ఫారమ్ ప్రాంప్ట్‌లు**](#transform-prompts) లో ఎగుమతి/దిగుమతి వరుసలో ఇదే కంట్రోల్ ఎల్లప్పుడూ అందుబాటులో ఉంటుంది. రెండూ మీరు త్వరగా ప్రారంభించడానికి సహాయపడే మర్చిపోయే ఉదాహరణలను జోడిస్తాయి.

<br/>

> ℹ️ **గమనిక**<br/>
> సాంపిల్ ప్రాంప్ట్‌లు ఇంగ్లీష్ లో అందించబడతాయి. వాటిని లోడ్ చేసిన తర్వాత, మీరు ప్రాంప్ట్ ని సవరించి, దానిని మీ భాషలోకి అనువదించడానికి **ప్రాంప్ట్ ను అనువదించండి** ఉపయోగించవచ్చు.

<br/>

<a id="create-a-prompt-quickly"></a>

### ప్రమోట్‌ను త్వరగా సృష్టించండి

ప్రమోట్‌ను సృష్టించడానికి అత్యంత త్వరగా ఉన్న మార్గం:

1. **కొత్త ప్రమోట్**పై క్లిక్ చేయండి.
2. **ప్రమోట్‌ను సృష్టించండి**పై క్లిక్ చేయండి.
3. మీరు కోరుకున్న ప్రమోట్ ఏమి చేయాలో వివరించండి.
4. ఒక మోడల్‌ను ఎంచుకోండి.
5. మీ కోసం ఒక రూపురేఖను అనువర్తనం సృష్టించనివ్వండి.
6. రూపురేఖను సమీక్షించి **సేవ్**పై క్లిక్ చేయండి.

![ప్రమోట్‌ను సృష్టించండి](../images/screenshots/te/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>

### ప్రాంప్ట్‌ను మార్చు

ప్రాంప్ట్ సృష్టించినప్పుడు లేదా సవరించినప్పుడు, ఎడమ వైపు ఎడిటర్ కనిపిస్తుంది మరియు కుడి వైపు పరీక్షా ప్రాంతం కనిపిస్తుంది.

![ట్రాన్స్‌ఫారమ్ ప్రాంప్ట్ ఎడిటర్](../images/screenshots/te/transform-prompt-edit.png)

ప్రధాన ఫీల్డ్‌లు:

- **ప్రాంప్ట్ పేరు**: ప్రాంప్ట్ జాబితాలో చూపబడే పేరు.
- **ప్రాంప్ట్ సూచనలు (ఐచ్ఛికం)**: ప్రాంప్ట్ ను అమలు చేసేటప్పుడు వాడుకరికి చూపబడే చిన్న సూచన.
- **మోడల్ పాత్ర**: 'మీరు ఒక సహాయకులైన సహాయకుడు' వంటి ఐఐకి కేటాయించబడిన మొత్తం పాత్ర.
- **మోడల్ సూచనలు (ఒకదానికొకటి వేరు చేయాలి)**: ఐఐ అనుసరించాలనుకుంటున్న నిర్దిష్ట నియమాలు.
- **అవుట్‌పుట్ వివరణ**: 'సారాంశం' లేదా 'తిరిగి వ్రాయి' వంటి ఫలితాన్ని వివరించే చిన్న పదం.
- **ఉష్ణోగ్రత (0.0 → 1.0)**: మోడల్ ఎలా ప్రవర్తిస్తుందో; క్రింద చూడండి.
- **లక్ష్య భాష కోసం అడగండి**: ప్రాంప్ట్ ని అమలు చేసినప్పుడు లక్ష్య భాష ఎంపికను జోడిస్తుంది.

**ఉష్ణోగ్రత** అనే పారిభాషిక పదం కొత్తదైతే, దీన్ని ఈ విధంగా భావించండి:

- **తక్కువ** ఉష్ణోగ్రత స్థిరమైన, ఊహించదగిన ఫలితాలనిస్తుంది.

- **ఎక్కువ** ఉష్ణోగ్రత వల్ల మరింత వైవిధ్యం మరియు సృజనాత్మకత ఉంటుంది.

మీరు ఇవి కూడా ఉపయోగించవచ్చు:

- సరళ వివరణ నుండి కొత్త డ్రాఫ్ట్‌ను సృష్టించడానికి **`ప్రాంప్ట్‌ను సృష్టించండి`**
- ఇప్పటికే ఉన్న ప్రాంప్ట్‌ను సున్నితం చేయడానికి **`ప్రాంప్ట్‌ను మెరుగుపరచండి`**
- ప్రాంప్ట్ ఫీల్డ్‌లను అనువదించడానికి **`ప్రాంప్ట్‌ను అనువదించండి`**

<br/>

> ⚠️ **హెచ్చరిక**<br/>
> **`వెనక్కు రన్ కు వెళ్లు`** పై క్లిక్ చేయడానికి ముందు **`సేవ్`** పై క్లిక్ చేయండి. మీరు సేవ్ చేయకుండా వెనక్కు వెళితే మీ మార్పులు కోల్పోతాయి.

<br/>

<a id="test-a-prompt-before-using-it"></a>

### ఉపయోగించే ముందు ప్రాంప్ట్‌ను పరీక్షించండి

కుడివైపు ఉన్న టెస్ట్ పానెల్ మీ రోజువారీ పనిలో ఉపయోగించే ముందు మీ ప్రాంప్ట్‌కు నమూనా పాఠ్యాన్ని ఉపయోగించి పరీక్షించడానికి అనుమతిస్తుంది.

దీనిని కింది పరిస్థితుల్లో ఉపయోగించుకోవచ్చు:

- మీరు కొత్త ప్రాంప్ట్‌ను తయారు చేస్తున్నప్పుడు
- మీరు ఒక ప్రాంప్ట్ యొక్క రెండు వెర్షన్లను పోల్చుతున్నప్పుడు
- మీరు టోన్, పొడవు లేదా అవుట్‌పుట్ ఫార్మాట్‌ను సరిచూసుకోవాలనుకున్నప్పుడు

<br/>

> ℹ️ **గమనిక**<br/>
> [**సెట్టింగ్స్** > **ట్రాన్స్‌ఫారమ్ ప్రాంప్ట్స్**](#transform-prompts) లో సేవ్ చేసిన ప్రాంప్ట్స్‌ను మీరు ఎగుమతి చేసి, దిగుమతి చేసుకోవచ్చు.

## డాష్‌బోర్డ్

మీరు ఈ అప్లికేషన్‌ను ఎంత ఉపయోగిస్తున్నారో మరియు దాని ఖర్చు ఎంత ఉందో (చెల్లింపు మోడళ్లకు) చూడటానికి **డాష్‌బోర్డ్**ను ఉపయోగించండి.

![డాష్‌బోర్డ్ సారాంశం](../images/screenshots/te/dashboard-summary.png)


<br/>

> ℹ️ **గమనిక**<br/>
> మీరు **ఉచిత** మోడళ్లను మాత్రమే ఉపయోగిస్తుంటే, **ఖర్చు** మొత్తాలు సున్నా గా ఉండవచ్చు మరియు ఖర్చు-కేంద్రీకృత సారాంశాలు ఖాళీగా కనిపించవచ్చు. **సారాంశం**, **కాలం పరంగా ఉపయోగం** మరియు **మోడల్ ద్వారా ఉపయోగం**లో ఎంచుకున్న కాలంలో మీరు కార్యాచరణ కలిగి ఉంటే **కాల్‌ల సంఖ్య** (అనువాదం, తిరిగి వ్రాత మరియు మార్పిడి) ఇంకా చూపబడతాయి.

<br/>

<a id="filter-the-data"></a>

### డేటాను ఫిల్టర్ చేయండి

సమయ పరిధిని మార్చడానికి పైభాగంలో ఉన్న ఫిల్టర్ బటన్లను ఉపయోగించండి.

![డాష్‌బోర్డ్ ఫిల్టర్లు](../images/screenshots/te/dashboard-filter.png)

<br/>

> ℹ️ **గమనిక**<br/>
> **వాడుకరి** ఫిల్టర్ వెబ్ వెర్షన్‌లో కేవలం నిర్వాహకులకు మాత్రమే కనిపిస్తుంది. సాధారణ వాడుకరులు ఈ ఫిల్టర్‌ను చూడరు మరియు డెస్క్‌టాప్ అనువర్తనంలో ఇది అందుబాటులో ఉండదు.

<br/>

<a id="dashboard-tabs"></a>

### డాష్‌బోర్డు ట్యాబ్‌లు

- **సారాంశం** వినియోగం మరియు ఖర్చు గురించి సమగ్ర సమాచారాన్ని అందిస్తుంది. ఇందులో సమయంతోపాటు **వినియోగం** (రోజుకు అనువదించడం, మళ్లీ రాయడం మరియు మార్చడం కోసం రోజుకు మొత్తం **కాల్ కౌంట్లు**) మరియు **మోడల్ వారీగా వినియోగం** (ప్రతి మోడల్ కు మొత్తం **కాల్స్**, మార్చడంతో సహా) ఉంటాయి.
- **వినియోగం వారీగా** అనువాద భాష, మళ్లీ రాయడం మోడ్ మరియు మార్చడం ప్రాంప్ట్ వారీగా కార్యాచరణను వివరిస్తుంది.
- **మోడల్ వారీగా** మీరు ఉపయోగించిన మోడళ్లను, వాటి ఖర్చు ఎంత ఉందో చూపిస్తుంది.
- **రోజు వారీగా** ప్రతి రోజు మొత్తాలను చూపిస్తుంది.
- **అన్ని కాల్స్** పూర్తి కాల్ చరిత్రను చూపిస్తుంది మరియు దానిని ఎగుమతి చేయడానికి అనుమతిస్తుంది.

### మోడల్ కొరకు నిల్వ చేసిన రికార్డులను తొలగించండి

**మోడల్ ప్రకారం** లేదా **అన్ని కాల్స్** లో, మీరు "స్వీపర్ బిన్" ఐకాన్ పై క్లిక్ చేయడం ద్వారా ఒక మోడల్ నిమిత్తం నిల్వ చేసిన రికార్డులను తొలగించవచ్చు.

> ⚠️ **హెచ్చరిక**<br/>
> నిల్వ చేసిన రికార్డులను తొలగించడం చేయలేరు. మీరు ఆ చరిత్రను మరింత అవసరం లేదని నిర్ధారించిన తర్వాత మాత్రమే ఈ ఎంపికను ఉపయోగించండి.

అన్ని డేటాను తొలగించడానికి లేదా వాటి వయస్సు ఆధారంగా రికార్డులను తొలగించడానికి, [**సెట్టింగ్స్** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) కి వెళ్లండి. అక్కడ మీరు అన్ని నిల్వ చేసిన డేటా ని లేదా కొంత తేదీ కంటే పాతది మాత్రమే డేటా తొలగించడానికి ఐచ్ఛికాలను కనుగొంటారు.

<a id="general-settings"></a>

### సాధారణ సెట్టింగ్స్

**సాధారణ సెట్టింగ్స్** ద్వారా టైపింగ్ ప్రవర్తనను, **చరిత్ర**కు సంబంధించి ఎగ్జిక్యూషన్ వివరాలు నిల్వ చేయబడతాయో లేదో, మరియు రూపాన్ని నియంత్రించండి.

**ప్రవర్తన**

- **ENTER కోసం ప్రవర్తన** మీరు `Enter`ని టాస్క్ అమలు చేయడానికి లేదా కొత్త పంక్తి చేర్చడానికి ఉపయోగించాలని ఎంచుకుంటుంది.
- **పేస్ట్ చేసినప్పుడు ఆటో-అనువాదం** మీరు పాఠ్యాన్ని పేస్ట్ చేసిన వెంటనే అనువాదాన్ని ప్రారంభిస్తుంది.
- **క్లిప్‌బోర్డుకు ఫలితం ఆటో-కాపీ చేయి** విజయవంతమైన ఫలితాలను స్వయంచాలకంగా కాపీ చేస్తుంది.
- **రియల్-టైమ్ అనువాదం (టైప్ చేసేటప్పుడు)** మీరు టైప్ చేసే సమయంలో అనువాదిస్తుంది.
- **టైమౌట్ (ms)** రియల్-టైమ్ అనువాదానికి వేచి ఉండే సమయాన్ని సెట్ చేస్తుంది.

**చరిత్ర**

- **ఎగ్జిక్యూషన్ చరిత్రను ఉంచు** ప్రతి అనువాదం, పునర్-రాయడం, మరియు మార్పిడి సైడ్‌బార్లో ఇన్పుట్ మరియు అవుట్‌పుట్ పాఠ్యాన్ని నిల్వ చేస్తుందో లేదో నియంత్రిస్తుంది [**చరిత్ర**](#history) వీక్షణ. దీన్ని ఆపితే ఖచ్చితత్వాన్ని అడుగుతుంది; మీరు ఖచ్చితం చేసినట్లయితే, నిల్వ చేసిన చరిత్రా పాఠ్యం డేటాబేస్ నుండి తొలగించబడుతుంది.

- **చరిత్ర డేటాను తొలగించండి** అనేది **డేటాను తొలగించండి** ఉపయోగించి వయస్సు ప్రకారం (ఉదాహరణకు కొన్ని నెలల కంటే పాతది లేదా **అన్ని డేటా (స్పష్టం)**) నిల్వ చేసిన టెక్స్ట్‌ను తొలగించడానికి అనుమతిస్తుంది. ఇది **చరిత్ర** వీక్షణ కొరకు సేవ్ చేసిన నిర్వహణ టెక్స్ట్‌ను మాత్రమే ప్రభావితం చేస్తుంది; ఇది ఖర్చు లేదా ఉపయోగం మొత్తాలను తొలగించదు. **ఖర్చు** డేటాను తొలగించడానికి లేదా కత్తిరించడానికి, [**సెట్టింగ్‌లు** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) ఉపయోగించండి.

**కనిపించే రూపం**

- **చర్యలపై ఖర్చు సమాచారాన్ని చూపించు** ప్రతి కార్యాచరణకు ఖర్చు (అందుబాటులో ఉంటే) మరియు అనువాదం, పునర్నిర్మాణం మరియు మార్పిడి అవుట్‌పుట్ ప్యానెల్‌లపై మొత్తం ఖర్చు యొక్క ప్రదర్శనను నియంత్రిస్తుంది.
- **ఖర్చు భిన్నం అంకెలు** ఖర్చు దశాంశాలు ప్రదర్శించే విధానాన్ని మారుస్తుంది.
- **వెబ్ మాత్రమే:** **అప్లికేషన్ చుట్టూ ఒక మార్జిన్ చూపించు** ఇంటర్ఫేస్ చుట్టూ అదనపు స్థలాన్ని జోడిస్తుంది.
- **ఫాంట్ కుటుంబం** టెక్స్ట్ ప్యానెల్‌లలో వ్రాయడానికి ఫాంట్‌ను మారుస్తుంది.
- **పరిమాణం** ఫాంట్ పరిమాణాన్ని మారుస్తుంది.

**కాన్ఫిగరేషన్ బ్యాకప్**

- **బ్యాకప్‌లో ఉపయోగం డేటాను చేర్చండి** — ప్రారంభించినప్పుడు, ZIP కూడా నిర్వహణ చరిత్ర మరియు API కాల్ డేటాను కలిగి ఉంటుంది.

- **బ్యాకప్ కాన్ఫిగరేషన్** — డిఫాల్ట్‌గా UTC ప్రకారం ఒకే జిప్ ఫైల్‌ను (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip`) సృష్టిస్తుంది, దీనిలో `config.json`, `state.json`, ఎంపికన ఎంచుకున్న ఎన్‌క్రిప్షన్ కీ, వాడుకరులు, ప్రాధాన్యతలు, కస్టమ్ ప్రాంప్ట్‌లు, మరియు వాడుక డేటా (మీరు సమ్మతించినట్లయితే) ఉంటాయి. విజయవంతమైన బ్యాకప్ తర్వాత, దాచిన ఫైల్ పేరుతో నిర్ధారణ సందేశం కనిపిస్తుంది.
- **బ్యాకప్ నుండి పునరుద్ధరించు** — ముందుగా ఒక **నిర్ధారణ డైలాగ్** తెరుస్తుంది. డైలాగ్ లోపల బ్యాకప్ జిప్ ఫైల్ ను ఎంచుకోండి (**బ్రౌజ్** / ఫైల్ పికర్ లేదా సపోర్ట్ ఉన్న చోట డ్రాగ్ అండ్ డ్రాప్), ఆ తర్వాత కింది ఎంపికలను సమీక్షించండి:
  - **వాడుక డేటాను పునరుద్ధరించు** — బ్యాకప్ ను వాడుక డేటాతో సహా చేసినట్లయితే, బ్యాకప్ సమయంలో ఉన్న వాడుక/చరిత్ర డేటాను దిగుమతి చేసుకుంటుంది; మీరు కేవలం సెట్టింగులు మరియు ప్రాంప్ట్‌లు మాత్రమే కావాల్సినట్లయితే, దీన్ని ఆపేయండి.
  - **పునరుద్ధరించే ముందు పాత వాడుక డేటాను తొలగించు** — బ్యాకప్ ను అమలు చేయడానికి ముందు ఈ ఇన్‌స్టాల్ లో ఉన్న పాత ఉపయోగం/చరిత్రను తొలగించుము (ఎంపికన; మీరు శుభ్రమైన పునరుద్ధరణ కోరుకున్నప్పుడు ఉపయోగించండి).

వెబ్ లేదా డెస్క్‌టాప్ వెర్షన్‌లో సృష్టించిన బ్యాకప్‌లను మరొక దానిలో పునరుద్ధరించవచ్చు. వెబ్ వెర్షన్‌లో డెస్క్‌టాప్ బ్యాకప్‌ను పునరుద్ధరించినప్పుడు, డేటాను నిర్వాహక వినియోగదారుడికి పునరుద్ధరిస్తారు.

<a id="models"></a>

### మాడల్స్

టూల్‌బార్‌లో ఏ మాడల్స్ కనిపించాలో ఎంచుకోవడానికి **సెట్టింగ్స్** > **మాడల్స్** ఉపయోగించండి.

![సెట్టింగ్స్ మాడల్స్ టాబ్](../images/screenshots/te/settings-models.png)

ఈ పేజీ రెండు జాబితాలను కలిగి ఉంటుంది:

- ఎడమ వైపు **అందుబాటులో ఉన్న మాడల్స్**
- కుడి వైపు **ఎంచుకున్న మాడల్స్**

ఉపయోగకరమైన నియంత్రణలలో ఇవి ఉన్నాయి:

- పేరు ద్వారా మాడల్ కనుగొనడానికి **మాడల్స్‌లో శోధించండి...**
- ఒక ప్రాసెస్సర్‌కు జాబితాను పరిమితం చేయడానికి **ప్రొవైడర్ చిప్స్** (ఓపెన్‌రౌటర్, ఓపెన్‌ఏఐ, ఒలామా, …)
- మాత్రమే ఉచిత మాడల్స్ చూపించడానికి **ఉచితం మాత్రమే**
- జాబితాను మళ్లీ లోడ్ చేయడానికి **రీఫ్రెష్**
- మీరు ప్రొవైడర్ ద్వారా క్రమబద్దీకరిస్తున్నప్పుడు **అన్నీ విస్తరించు** మరియు **అన్నీ కుదించు**

మాడల్ ఐడీలు ప్రొవైడర్ ప్రీఫిక్స్ ని కలిగి ఉంటాయి (ఉదాహరణకు `openrouter/…` vs `openai/…` ). **OpenAI (OpenRouter)** లేదా **OpenAI (direct)** వంటి బ్యాడ్జీలు ట్రాఫిక్ ఎలా మార్చబడుతుందో చూపిస్తాయి.

> ℹ️ **గమనిక**<br/>

> **OpenRouter బాడీ బిల్డర్** (`openrouter/bodybuilder`) ఒక రౌటర్ మోడల్, సాధారణ చాట్ మోడల్ కాదు: దాని సమాధానం ఓపెన్రౌటర్ API రిక్వెస్ట్ బాడీలను వివరించే JSON ఫారమెట్ లో ఉంటుంది (ఉదాహరణకు `requests` అర్రేలో `model` మరియు `messages` ఉంటాయి). మీరు దీన్ని **అనువాదం**, **పునర్రచన**, లేదా **పరివర్తన** కోసం ఉపయోగిస్తే, ఫలిత టెక్స్ట్ కాకుండా అవుట్‌పుట్ ప్యానెల్ ఆ JSON చూపిస్తుంది. ఆ పనులకు సాధారణ టెక్స్ట్ మోడల్ ను ఎంచుకోండి. [బాడీ బిల్డర్ మోడల్ పేజీ](https://openrouter.ai/openrouter/bodybuilder) ని ఓపెన్రౌటర్ లో చూడండి.

చర్యలు:

 - మోడల్‌ను జోడించడానికి, **జోడించండి** నొక్కండి లేదా ఎంట్రీలో ఎక్కడైనా క్లిక్ చేయండి.

 - మోడల్ ను తొలగించడానికి, **ఎంచుకున్న మోడల్స్** లో దాని పక్కన ఉన్న **X** పై క్లిక్ చేయండి లేదా లభించే మోడల్స్ లో ఎంట్రీపై **ఎంచుకున్నవి** పై క్లిక్ చేయండి.

 - జాబితాను తుడిచివేయడానికి, **అన్నింటినీ డిసెలెక్ట్ చేయండి** నొక్కండి. అవసరమైన ఉచిత మోడల్ జాబితాలో ఉంటుంది.

<br/>

> ℹ️ **గమనిక**<br/>

> మీరు వెంటనే OpenRouterకి క్రెడిట్‌లు జోడించకపోతే, మొదట **ఫ్రీ ఓన్లీ** ని సక్రియం చేసి ఉచిత మాడళ్లను ఎంచుకోండి (క్రెడిట్ కార్డ్ అవసరం లేదు). మీరు Ollamaని API కీ లేకుండా స్థానికంగా నడిపేందుకు కూడా ఉపయోగించవచ్చు.

<a id="languages"></a>

### భాషలు

యాప్ లో ఉపయోగించే భాషా జాబితాలను సర్దుబాటు చేయడానికి **సెట్టింగ్స్** > **భాషలు** ఉపయోగించండి.

- **పై భాషలు** బట్టి **అనువాదం** మరియు **మార్చు**లో భాషా జాబితాల పైభాగంలో పిన్ చేయబడతాయి.
- **కస్టమ్ భాష** మీరు స్థిరంగా ఉన్న జాబితాలో లేని భాషను జోడించడానికి అనుమతిస్తుంది.

మీరు కస్టమ్ భాషను జోడిస్తే, ఇది స్థిరంగా ఉన్న ఎంపికలతో పాటు భాషా ఎంపికలలో కనిపిస్తుంది.

<a id="cost-tracking"></a>

### ఖర్చు ట్రాకింగ్

ఖర్చు సమాచారాన్ని నిర్వహించడానికి **సెట్టింగ్స్** > **ఖర్చు ట్రాకింగ్** ఉపయోగించండి.

- **మొత్తం ఖర్చు** అనేది మొత్తం క్రమబద్ధీకరణ మొత్తాన్ని చూపుతుంది.
- **విలువను కాపీ చేయి** మొత్తాన్ని క్లిప్బోర్డ్కు కాపీ చేస్తుంది.
- **ఖర్చును రీసెట్ చేయి** నిల్వ చేసిన మొత్తాన్ని సున్నాకు రీసెట్ చేస్తుంది.
- **API కీ వాడకంతో సింక్ చేయి** OpenRouter ఖాతా నివేదించిన వాడకానికి అనుగుణంగా మొత్తాన్ని అమర్చుతుంది (OpenRouter మాత్రమే).
- **API కీ వాడకం** అందుబాటులో ఉంటే OpenRouter వాడక వివరాలను చూపుతుంది.
- **ఖర్చు డేటా తొలగించు** అన్ని డేటా లేదా ఎంచుకున్న తేదీకి ముందు డేటాను తొలగిస్తుంది.

**ఖర్చు ట్రాకింగ్:** మీరు OpenRouter మోడల్స్ ఉపయోగించినప్పుడు, అప్లికేషన్ OpenRouter నుండి వచ్చిన ఖర్చు సమాచారం ఆధారంగా మీ వాస్తవ వాడకం మరియు ఖర్చును చూపుతుంది. ఇతర అన్ని ప్రొవైడర్లకు అప్లికేషన్ బహిర్గతం చేసిన ధరలను ఉపయోగించి ఖర్చులను అంచనా వేస్తుంది. ధర అందుబాటులో లేకపోతే, అంచనా సున్నా కావచ్చు.

<br/>

> ℹ️ **గమనిక**<br/>
> **అన్ని ఖర్చు పట్టికలు మీ సూచన కోసం మాత్రమే, అధికారిక బిల్లింగ్ ప్రకటనలు కావు.**

<br/>

> ⚠️ **హెచ్చరిక**<br/>

> డేటా తొలగింపును రద్దు చేయలేము. తొలగించే ముందు మీ డేటాను బ్యాకప్ చేయడం లేదా [**చరిత్ర**](#history) లేదా [**డాష్‌బోర్డ్** > **అన్ని కాల్స్**](#dashboard-tabs) ద్వారా దానిని ఎగుమతి చేయడం నిర్ధారించుకోండి, లేకుంటే అది శాశ్వతంగా కోల్పోబడుతుంది. ప్రతి API కాల్ ఎంట్రీకి సంబంధించిన ఇన్‌పుట్/అవుట్‌పుట్ చరిత్ర కూడా తొలగింపబడుతుంది.

### ప్రాంప్ట్లను మార్చండి

**సెట్టింగ్లు** > **ప్రాంప్ట్లను మార్చండి** ని ఉపయోగించి ప్రాంప్ట్లను సూచించిన విధంగా నిర్వహించండి.

మీరు చేయగల పనులు:

- మీరు భద్రపరచుకున్న ప్రాంప్ట్లను సమీక్షించడం
- ప్రాంప్ట్లను తొలగించడం
- ఫైల్ నుండి ప్రాంప్ట్లను దిగుమతి చేసుకోవడం
- బ్యాకప్ లేదా షేరింగ్ కోసం ప్రాంప్ట్లను ఎగుమతి చేయడం
- ప్రాంప్ట్ జాబితాకు నమూనా ప్రాంప్ట్లను లోడ్ చేయడం

### వాడుకరులు

<a id="api-config"></a>

### API కాన్ఫిగరేషన్

మద్దతు ఉన్న సరఫరాదారులు: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, మరియు **Ollama** (బేస్ URL ద్వారా స్థానిక మోడల్స్). మీరు ఉపయోగించే సరఫరాదారులను మాత్రమే కాన్ఫిగర్ చేయాలి.

**వెబ్ అప్లికేషన్: కేవలం నిర్వాహకుడు**

API కీలు సిస్టమ్ లేదా Docker పర్యావరణ వేరియబుల్స్ ద్వారా కాన్ఫిగర్ చేయబడతాయి — వాటిని వెబ్ UIలో ప్రవేశపెట్టకూడదు. ఈ పేజీ ఏయే సరఫరాదారులకు కీ కాన్ఫిగర్ చేయబడిందో చూపిస్తుంది మరియు ప్రతి ఒక్కదానికి **`పరీక్షించు`** బటన్ క్లిక్ చేయడం ద్వారా పరీక్షించుకునే వెసులుబాటు కల్పిస్తుంది.

<br/>

> ℹ️ **గమనిక**<br/>
> API కీని మార్చడానికి, మీ సిస్టమ్ లేదా Docker కాన్ఫిగరేషన్‌లోని పర్యావరణ వేరియబుల్‌ని నవీకరించి, సర్వర్ లేదా కంటైనర్‌ని రీస్టార్ట్ చేయండి.

> ℹ️ **గమనిక**<br/>

> **కాన్ఫిగరేషన్ బ్యాకప్‌లు** (చూడండి [**సాధారణ సెట్టింగులు** → కాన్ఫిగరేషన్ బ్యాకప్](#general-settings)) జిప్ యొక్క `config.json`లో **రిజాల్వ్ చేయబడిన** ప్రొవైడర్ కీలను చేర్చుతాయి. ఆ జిప్ ని రీస్టోర్ చేయడం ఆ కీలను సర్వర్ యొక్క పర్సిస్టెడ్ కాన్ఫిగ్ ఫైల్‌లోకి కాపీ చేయదు — జీవిస్తున్న కీలు ఇప్పటికీ పర్యావరణం మరియు అక్కడ వివరించిన ఫైల్ పరిస్థితి నుండి వస్తాయి.

<br/>

**డెస్క్‌టాప్ అప్లికేషన్**

మీరు ఉపయోగించే ప్రతి ప్రొవైడర్‌కి ఐపి కీలను నిల్వ చేయడానికి **API కాన్ఫిగ్** ఉపయోగించండి. ఓలామా కోసం, API కీ మర్చి మూలస్థానంలో **బేస్ URL** ని నమోదు చేయండి.

<br/>

> 💡 **సూచన** <br/>
> API కీ ఉపయోగించడానికి లేదా ఉపయోగం కోసం చెల్లించడానికి మీరు ఇష్టపడకపోతే, [ఓలామాని డౌన్‌లోడ్ చేసుకోండి](https://ollama.com) మరియు మీ సొంత మెషీన్‌లో ఉచితంగా మాడల్స్ (`translategemma:4b` వంటివి) నడుపుతారు. లేదా, వారి ఉచిత మాడళ్లను ఉపయోగించడానికి మీరు ఉచిత OpenRouter ఖాతాను సృష్టించవచ్చు (క్రెడిట్ కార్డు అవసరం లేదు), లేదా Cerebras, Google, Groq లేదా Mistral AI నుండి ఉచిత API కీని పొందవచ్చు.

- మీకు కావలసిన ప్రొవైడర్లను మాత్రమే జోడించండి. **సెట్టింగ్స్** > **మాడల్స్**లో, ప్రతి మాడల్ ఐడి ప్రొవైడర్‌తో ప్రారంభమవుతుంది (ఉదాహరణకు `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

API కీ జోడించడానికి, పాఠ్య ప్రదేశంలో విలువను నమోదు చేసి, **`Save`**పై క్లిక్ చేయండి. ఉన్న కీని భర్తీ చేయడానికి, **`Edit`**పై క్లిక్ చేయండి. కీ పనిచేస్తుందో లేదో సరిచూడటానికి, **`Test`** పై క్లిక్ చేయండి. Ollama బేస్ URL కోసం, కనెక్షన్‌ను సరిచూడటానికి ఎల్లప్పుడూ **`Test`** పై క్లిక్ చేయండి.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు API కీ ప్రస్తుత విలువను చూడలేరు. ఇది భర్తీ చేయడానికి మాత్రమే **`Edit`** బటన్ ఉపయోగించవచ్చు.
> API కీలు ఎన్‌క్రిప్ట్ చేయబడి, కాన్ఫిగరేషన్‌లో నిల్వ చేయబడతాయి.

<a id="common-issues"></a>

## సాధారణ సమస్యలు

ఏదైనా అనుకున్నట్లు పని చేయకపోతే, ముందుగా కింది విషయాలను సరిచూసుకోండి.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### యాప్ టెక్స్ట్‌ను అనువదించదు, రాయదు లేదా మార్చదు

ఇవి సరిచూసుకోండి:

- టూల్‌బార్‌లో మీరు ఒక మోడల్‌ను ఎంచుకున్నారని
- కనీసం ఒక మోడల్ [**సెట్టింగ్స్** > **మోడల్స్**](#models) లో పేర్కొనబడిందని
- మీ API సెటప్ పనిచేస్తోందని

మీరు డెస్క్‌టాప్ యాప్ ఉపయోగిస్తున్నట్లయితే:

1. [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) తెరవండి.
2. కనీసం ఒక API కీ సేవ్ చేయబడిందని సరిచూసుకోండి.
3. కీ పనిచేస్తుందో లేదో నిర్ధారించడానికి ప్రొవైడర్ పక్కన ఉన్న **టెస్ట్** పై క్లిక్ చేయండి.

<br/>

<a id="the-model-list-is-empty"></a>

### మోడల్ జాబితా ఖాళీగా ఉంది

[**సెట్టింగ్లు** > **మోడల్స్**](#models)ని తెరిచి, **రీఫ్రెష్** బటన్ పై క్లిక్ చేయండి.

అవసరమైతే:

- ఒక మోడల్ కోసం వెతకండి
- **ఉచితమాత్రమే** పై ప్రసరించండి
- **ఎంచుకున్న మోడల్స్** కి ఒకటి లేదా అంతకంటే ఎక్కువ మోడల్స్‌ని జోడించండి

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>

### ఫలితం చాలా నెమ్మదిగా లేదా ఖరీదైనదిగా ఉంది

ఇవి ఒకటి లేదా అంతకంటే ఎక్కువ ప్రయత్నించండి:

- వేరొక మాడల్‌ను ఎంచుకోండి
- చిన్న ఇన్‌పుట్‌ను ఉపయోగించండి
- [**సెట్టింగ్స్** > **జనరల్ సెట్టింగ్స్**](#general-settings)లో **రియల్-టైమ్ అనువాదం (టైప్ చేసేటప్పుడు)**ను ఆఫ్ చేయండి
- సరళమైన పనుల కోసం ఉచిత మాడల్స్ ఉపయోగించండి (చూడండి [మాడల్స్](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>

### ఇంటర్‌ఫేస్ తప్పు భాషలో ఉంది

[టూల్‌బార్](#toolbar)లోని గ్లోబ్ ఐకాన్‌పై క్లిక్ చేసి మీకు ఇష్టమైన **ఇంటర్‌ఫేస్ భాష**ను ఎంచుకోండి.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>

### పాఠ్యం స్వల్పంగా లేదా చదవడానికి కష్టంగా ఉంది

[**సెట్టింగ్స్** > **సాధారణ సెట్టింగ్స్**](#general-settings) తెరిచి మార్చండి:

- **ఫాంట్ కుటుంబం**
- **పరిమాణం**

<br/>

<a id="dashboard-charts-are-empty"></a>

### డాష్‌బోర్డ్ రేఖాచిత్రాలు ఖాళీగా ఉన్నాయి

ఇది సాధారణం అయితే:

- మీరు **ఉచిత మాడల్స్** మాత్రమే ఉపయోగించి, **ఖర్చు** గురించి చూస్తున్నారంటే (వాటి పరిమాణం సున్నా కావచ్చు); ఎంచుకున్న కాలపరిమితి నుంచి డేటా **సారాంశం**లోని **వాడకం** కాల్‌ల సంఖ్య రేఖాచిత్రానికి ఇంకా అవసరం
- కాల్స్ చేసిన కాలపరిమితిని కవర్ చేయని **సమయ వడపోత** ఎంచుకుంటే — సరిచూడటానికి **అన్నీ**ని ప్రయత్నించండి

**అన్నీ** ఎంచుకున్నా రేఖాచిత్రాలు ఖాళీగా ఉంటే, [**చరిత్ర**](#history) లేదా **అన్నీ కాల్స్** ట్యాబ్‌లో కాల్స్ కనిపిస్తున్నాయో లేదో ధృవీకరించండి.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### ఖర్చు "అందుబాటులో లేదు" లేదా తప్పుగా కనిపిస్తుంది

మీరు **OpenRouter** ద్వారా మోడల్స్ ఉపయోగించినప్పుడు, ఈ అప్లికేషన్ OpenRouter నివేదించిన మీ వాస్తవ ఖర్చును చూపిస్తుంది.

**ఇతర సరఫరాదారుల కొరకు** (OpenAI నేరుగా, Anthropic నేరుగా, మొదలైనవి), OpenRouter ప్రచురించిన ధర సమాచారం ఆధారంగా ఖర్చు అంచనా వేయబడుతుంది. ఒక మోడల్కు సరిపడిన ధర కనుగొనబడకపోతే, ఖర్చు **అందుబాటులో లేదు**గా కనిపించి మీ సమగ్ర మొత్తంలో కలపబడదు.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### మొత్తం ఖర్చు మీ ప్రొవైడర్ బిల్‌కు సరిపోవడం లేదు

యాప్‌లోని అన్ని ఖర్చు వివరాలు **సూచన కోసం మాత్రమే ఉంచబడిన అంచనాలు**, అధికారిక బిల్లింగ్ ప్రకటనలు కావు.

మొత్తాన్ని మీ నిజమైన OpenRouter ఖర్చుకు దగ్గరగా తీసుకురావడానికి, [**సెట్టింగ్స్** > **కాస్ట్ ట్రాకింగ్**](#cost-tracking) తెరిచి, **API కీ ఉపయోగంతో సింక్ చేయండి**పై క్లిక్ చేయండి.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### సైడ్‌బార్ లో చరిత్ర పేజీ లేదు

**క్రమం చరిత్రను నిలుపుదల చేయి** ఆఫ్ చేయబడి ఉండవచ్చు. [**సెట్టింగ్స్** > **సాధారణ సెట్టింగ్స్**](#general-settings) తెరిచి, దానిని చేర్చండి. చేర్చడం గతంలో తొలగించబడిన చరిత్ర డేటాను పునరుద్ధరించదని గమనించండి.

<br/>

<a id="web-app-session-expired"></a>

### వెబ్ అప్లికేషన్: అనుకోకుండా లాగిన్ పేజీకి మళ్లించబడింది

మీ సెషన్ గడువు ముగిసి ఉండవచ్చు. మళ్లీ లాగిన్ అవ్వండి. ఇది తరచుగా జరిగితే, సెషన్ జీవితకాల సెట్టింగుల కొరకు సర్వర్ కాన్ఫిగరేషన్‌ను సరిచూడండి.

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### వెబ్ అడ్మిన్: పాస్‌వర్డ్ మరిచిపోయారా లేదా కోల్పోయారా

ఇది డెస్క్‌టాప్ (ఎలక్ట్రాన్) అప్లికేషన్కు కాకుండా, **సెల్ఫ్-హోస్టెడ్ వెబ్ అప్లికేషన్** (డాకర్)కు వర్తిస్తుంది.

- మరో అడ్మినిస్ట్రేటర్ కొనసాగించి సైన్ ఇన్ చేయగలిగితే, వారు [**సెట్టింగ్లు** > **వినియోగదారులు**](#users) తెరిచి, ఖాతాను ఎంచుకొని, కొత్త పాస్‌వర్డ్‌ను నమోదు చేయవచ్చు.
- మీరు **లాక్ అవుట్ అయినా**, మీకు మెషీన్ లేదా కంటైనర్కు **షెల్ యాక్సెస్** ఉన్నట్లయితే, ఇమేజ్‌తో పాటు వచ్చే సహాయక ఉపకరణం ఉపయోగించి పాస్‌వర్డ్ రీసెట్ చేయండి (మీరు పేరు మార్చితే దానిని `transrewrt`గా మార్చండి, మరియు పాస్‌వర్డ్ లో స్పేస్‌లు లేదా ప్రత్యేక అక్షరాలు ఉంటే దానిని కొటేషన్ గుర్తులలో ఉంచండి):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

మీరు ఇతర ఖాతాలను సృష్టించకపోతే, డిఫాల్ట్ అడ్మిన్ వాడుకరి పేరు `admin` ఉంటుంది. మీరు ఒకే ఒక ఆర్గ్యుమెంట్ పంపితే, అది `admin`కు కొత్త పాస్‌వర్డ్‌గా పరిగణించబడుతుంది.

మీరు డాకర్ కాకుండా **సోర్స్ చెక్‌అవుట్** నుండి నడుస్తుంటే, ఉపయోగించండి:

```bash
pnpm run reset-web-password -- <username> <new-password>

స్క్రిప్ట్ సిక్వెల్ డేటాబేస్‌లో యూజర్ రికార్డును నవీకరిస్తుంది (మరియు `admin` యూజర్ లేకపోతే దానిని సృష్టించవచ్చు). రీసెట్ చేసిన తర్వాత, కొత్త పాస్వర్డ్‌తో సైన్ ఇన్ అవ్వండి.

### డాష్‌బోర్డ్ ఇతర వాడుకరులకు డేటాను చూపించదు (వెబ్)

**నిర్వాహకులు** మాత్రమే **వాడుకరి** ఫిల్టర్ ద్వారా అన్ని వాడుకరుల నుండి డేటాను చూడవచ్చు. సాధారణ వాడుకరులు రూపకల్పన ప్రకారం వారి సొంత క్రియాశీలత మాత్రమే చూస్తారు.

## త్వరిత సూచనలు

- [**అనువాదం**](#translate)తో మొదలు పెట్టండి, [**పునఃరాయండి**](#rewrite) లేదా [**పరివర్తించండి**](#transform)కు వెళ్ళే ముందు మీ సెటప్ పనిచేస్తుందో లేదో నిర్ధారించుకోండి.
- రోజువారీ పదబంధాల మెరుగుదలల కోసం [**పునఃరాయండి**](#rewrite)ను ఉపయోగించండి.
- ప్రత్యేక పని కోసం పునరావృతమయ్యే పని విధానం అవసరమయితే [**పరివర్తించండి**](#transform)ను ఉపయోగించండి.
- ఉపయోగం మరియు ఖర్చు పై దృష్టి ఉంచాలనుకుంటే [**డాష్‌బోర్డ్**](#dashboard)ను ఉపయోగించండి.
- గత కార్యకలాపాలు మరియు వాటి పూర్తి ఇన్‌పుట్/అవుట్‌పుట్ చూడాలనుకుంటే [**చరిత్ర**](#history)ను ఉపయోగించండి.
- మీరు సురక్షితంగా ఉంచాలనుకుంటున్న లేదా ఇతరులతో పంచుకోవాలనుకుంటున్న ప్రాంప్ట్ లైబ్రరీని సృష్టిస్తున్నట్లయితే, తరచుగా ప్రాంప్ట్‌లను ఎగుమతి చేసుకోండి (చూడండి [పరివర్తన ప్రాంప్ట్‌లు](#transform-prompts)).
