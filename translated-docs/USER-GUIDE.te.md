# వినియోగదారుడి మార్గదర్శకం

<br/>

<a id="introduction"></a>
## పరిచయం

Transrewrt మూడు ప్రధాన విధాలుగా మీకు పాఠ్య పనులలో సహాయపడుతుంది:

- **అనువాదం** - ఒక భాష నుండి ఇంకొక భాషలోకి టెక్స్ట్‌ను మార్చడం.
- **తిరిగి రాయడం** - స్పష్టంగా, చిన్నదిగా లేదా ఔపచారికంగా వంటి వేరొక శైలిలో పాఠ్య పునర్నిర్మాణం.
- **పరిణామం** - ప్రాంప్ట్ అని పిలుస్తారు కస్టమ్ AI సూచనలను ఉపయోగించి పాఠ్యం ప్రాసెస్ చేయడం.

<br/>

ఈ మార్గదర్శకం అప్లికేషన్‌ను ఇన్‌స్టాల్ చేసి నడుస్తున్నప్పుడు దాన్ని ఎలా ఉపయోగించాలో వివరిస్తుంది. ఇన్‌స్టాల్ చేయడానికి సంబంధించిన దశల కోసం, ప్రధాన **[README](README.te.md)** చూడండి.

<br/>

> ℹ️ **గమనిక**<br/>
> Transrewrt విండోస్ మరియు లినక్స్ కోసం డెస్క్‌టాప్ అప్లికేషన్ గాను, స్వంతంగా హోస్ట్ చేసే వెబ్ అప్లికేషన్ గాను అందుబాటులో ఉంది. ఈ మార్గదర్శకం అప్లికేషన్ యొక్క రోజువారీ ఉపయోగానికి సంబంధించినది. రెండు వెర్షన్లలో చాలా అంశాలు సాధారణంగా ఉన్నా, నిర్దిష్ట వెర్షన్‌కు మాత్రమే వర్తించే అంశాలు స్పష్టంగా గుర్తించబడతాయి.

## మీరు ప్రారంభించే ముందు

Transrewrt ఉపయోగించడానికి, మీరు కనీసం ఒక AI ప్రొవైడర్‌కు యాక్సెస్ కలిగి ఉండాలి. సపోర్టెడ్ ప్రొవైడర్లు: [OpenRouter](https://openrouter.ai) (చాలా మోడల్స్‌ను అందించేది), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras మరియు లోకల్ మోడల్స్ కోసం [Ollama](https://ollama.com).

ప్రారంభించడానికి మీరు చెల్లింపు మోడల్ ఎంచుకోవలసిన అవసరం లేదు. మీరు మీ OpenRouter API కీని చేర్చిన వెంటనే, అనువర్తనం ఇంటిగ్రేటెడ్ అయిన ఒక **ఉచిత** OpenRouter ఎంపికను స్వయంచాలకంగా ప్రారంభిస్తుంది. ఇది మీరు వెంటనే అనువాదం, తిరిగి వ్రాత మరియు పరివర్తన పనులను ప్రారంభించడానికి అనుమతిస్తుంది. ప్రత్యామ్నాయంగా, మీరు Cerebras, Google, Groq లేదా Mistral AI నుండి ఉచిత API కీని పొందవచ్చు.

సాధారణ భాషలో:

- ఒక **మోడల్** పనిచేసే AI ఇంజిన్. మోడల్స్ **ప్రొవైడర్ ప్రిఫిక్స్** తో జాబితా చేయబడతాయి (ఉదాహరణకు `openrouter/…`, `openai/…`, `ollama/…`).
- ఒక **API కీ** (లేదా Ollama కోసం, ఒక **బేస్ URL**) అనువర్తనం ఆ ప్రొవైడర్‌ను ఎలా తాకుతుందో సూచిస్తుంది.

మీరు **డెస్క్‌టాప్ అనువర్తనం** ఉపయోగిస్తున్నట్లయితే, మీరు ఉపయోగించే ప్రతి ప్రొవైడర్ కోసం [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) లో కీలు చేర్చండి. కేవలం OpenRouter కోసం ఉపయోగించాలనుకుంటే, కింద ఉన్న [API కీ ఎలా పొందాలి](#how-to-get-an-api-key-desktop-app) చూడండి. API కీని ఉపయోగించకూడదంటే, మీరు [ollama.com](https://ollama.com) నుండి Ollama ని స్థాపించి `translategemma:4b` వంటి లోకల్ మోడల్స్ ఉపయోగించవచ్చు.

మీరు **వెబ్ వెర్షన్** ఉపయోగిస్తున్నట్లయితే, సర్వర్ యజమాని పర్యావరణ వేరియబుల్స్ ద్వారా ప్రొవైడర్లను కాన్ఫిగర్ చేస్తారు, కాబట్టి మీరు అనువర్తనంలో సరాసరి API కీలను నమోదు చేయలేరు.

<a id="how-to-get-an-api-key-desktop-app"></a>
### ఉచిత OpenRouter API కీ ఎలా పొందాలి (డెస్క్‌టాప్ అనువర్తనం)

మీరు డెస్క్‌టాప్ అనువర్తనం ఉపయోగిస్తున్నట్లయితే, ఈ దశలను అనుసరించండి:

1. మీ వెబ్ బ్రౌజర్‌లో [OpenRouter](https://openrouter.ai) కి వెళ్లండి.
2. ఒక ఖాతాను సృష్టించండి లేదా సైన్ ఇన్ అవ్వండి.
3. [Keys](https://openrouter.ai/keys) పేజీని తెరవండి.
4. కొత్త API కీని సృష్టించడానికి బటన్‌పై క్లిక్ చేయండి.
5. మీరు తరువాత దానిని గుర్తించడానికి కీకి పేరు ఇవ్వండి.
6. కొత్త API కీని కాపీ చేయండి.
7. Transrewrt కు తిరిగి వెళ్ళి **సెట్టింగ్స్** > **API కాన్ఫిగ్** తెరవండి.
8. **OpenRouter API కీ** లో (అంటే **సెట్టింగ్స్** > **API కాన్ఫిగ్** కింద) కీని పేస్ట్ చేయండి.
9. అది పనిచేస్తుందో లేదో పరీక్షించడానికి **OpenRouter కీని పరీక్షించండి** పై క్లిక్ చేయండి.

## ప్రారంభించడం

మీరు మొదటిసారిగా Transrewrt ఉపయోగిస్తున్నట్లయితే, ఈ క్రమాన్ని అనుసరించండి:

1. అనువర్తనాన్ని తెరవండి.
2. అవసరమైతే గ్లోబ్ ఐకాన్ నుండి మీ **ఇంటర్ఫేస్ భాష** ను ఎంచుకోండి.
3. మీరు **డెస్క్‌టాప్ అనువర్తనం** లో ఉన్నట్లయితే, [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) తెరిచి, కనీసం ఒక ప్రొవైడర్ కోసం API కీ జోడించి (ఉదాహరణకి OpenRouter), అది పనిచేస్తుందో లేదో ధృవీకరించడానికి **పరీక్షించండి** పై క్లిక్ చేయండి.
4. [**సెట్టింగ్స్** > **మోడల్స్**](#models) తెరిచి, **ఎంచుకున్న మోడల్స్** లో ఒకటి లేదా అంతకంటే ఎక్కువ మోడల్స్ చేర్చండి.
5. [**సెట్టింగ్స్** > **భాషలు**](#languages) తెరిచి, మీరు ఎక్కువగా ఉపయోగించే భాషలు ముందుగా కనిపించాలనుకుంటే మీ **ప్రధాన భాషలు** ను ఎంచుకోండి.
6. **అనువాదం** కు వెళ్లి, పని చేస్తుందో లేదో నిర్ధారించడానికి ఒక సరళమైన అనువాదాన్ని చేయండి.
7. అది పనిచేస్తే, **తిరిగి వ్రాత** మరియు తరువాత **పరివర్తన** ని ప్రయత్నించండి.

ఈ క్రమం ముఖ్యమైనది. ఇది సాధారణంగా ఎదురయ్యే మొదటిసారి ఉపయోగించే సమస్యను నిరోధిస్తుంది: అనువర్తనానికి పనిచేసే API కనెక్షన్ లేకుండా లేదా ఎంచుకున్న మోడల్ లేకుండా పనిని అమలు చేయడానికి ప్రయత్నించడం.

## విండో యొక్క ప్రధాన భాగాలు

అనువర్తనం మూడు ప్రధ

### టూల్‌బార్

మీరు యాప్ లో ఎక్కడ ఉన్నారో బట్టి టూల్‌బార్ కొంచెం మారుతుంది.

- ఎడమ వైపు, ప్రస్తుత పేజీ పేరు చూపబడుతుంది.
- కుడి వైపు, ప్రస్తుత పని కోసం ఉపయోగించే **మోడల్ సెలెక్టర్** మరియు **ఇంటర్ఫేస్ భాష** నియంత్రణలు కనిపిస్తాయి.

ప్రస్తుత పని కోసం ఏ ఐఐ ఇంజన్ ఉపయోగించాలో మార్చుకోవడానికి **మోడల్ సెలెక్టర్** అనుమతిస్తుంది.

  ![మోడల్ సెలెక్టర్](../images/screenshots/te/model-selector.png)

కొన్ని ఉచిత మోడళ్ళు ఎప్పుడూ అందుబాటులో ఉండవు — నిర్దిష్ట సమయాల్లో అవి ఆఫ్‌లైన్ లో ఉండిపోతాయి లేదా ఉపయోగం పరిమితి ఉండవచ్చు. ఇలా జరిగితే, ఆ మోడల్ ను అందుబాటులో ఉన్న జాబితా నుండి యాప్ స్వయంచాలకంగా తొలగిస్తుంది. ఏ మోడళ్ళు కనిపించాలో నియంత్రించడానికి, [**సెట్టింగులు** > **మోడళ్ళు**](#models) కు వెళ్లి మీ మోడల్ జాబితాను సవరించండి. టూల్‌బార్ లో మోడల్ పేరుకు ఎడమ వైపున ఉన్న సరఫరా చేసే వారి ఐకాన్ పై క్లిక్ చేయడం ద్వారా మీరు నేరుగా మోడల్ సెట్టింగులను కూడా తెరవచ్చు.

<br/>

**భూమి ఐకాన్ + భాషా కోడ్** యాప్ ఇంటర్ఫేస్ భాషను, అంటే మెనులు మరియు బటన్లను మారుస్తుంది. ఇది **అనువాదం** లో ఉపయోగించే అనువాద భాషలను మాత్రం మార్చదు.

  ![ఇంటర్ఫేస్ భాష సెలెక్టర్](../images/screenshots/te/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### ఇన్‌పుట్ మరియు అవుట్‌పుట్ ప్యానళ్ళు

చాలా పని ప్రదేశాలు ఎడమ వైపున ఉన్న **ఇన్‌పుట్** ప్యానెల్ మరియు కుడి వైపున ఉన్న **అవుట్‌పుట్** ప్యానెల్ ఉపయోగిస్తాయి.

ప్రతి ప్యానెల్ కూడా ఇవి చూపుతుంది:

| **ఇన్‌పుట్**                                                          | **అవుట్‌పుట్**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - అక్షరాల సంఖ్య <br/>- పదాల సంఖ్య <br/>- పేరాల సంఖ్య   <br/> | - పని ఎంత సమయం పడింది<br/>- **TPS** (సెకనుకు టోకెన్లు)<br/>- అక్షరాలు, పదాలు మరియు పేరాల సంఖ్యలు<br/>- ఉపయోగించిన మోడల్ |


మీరు పాల్గొనే సాంకేతిక పదాల గురించి ఆశ్చర్యపోతున్నట్లయితే:

- **టోకెన్** అంటే చిన్న పాఠ్య భాగం. దీన్ని పదంలో ఒక భాగం లేదా చిన్న పదం అని ఆలోచించవచ్చు.
- **TPS** అంటే ఆ పాఠ్య భాగాల నుండి మోడల్ ఒక సెకనుకు ప్రాసెస్ చేసిన వాటి సంఖ్య.

<br/>

ప్రతి చర్య యొక్క ఖర్చు (సందర్భంలో సాధ్యమైతే) మరియు మొత్తం ఖర్చును [**సెట్టింగులు** > **సాధారణ సెట్టింగులు**](#general-settings) లో `చర్యలపై ఖర్చు సమాచారాన్ని చూపించు` ఎంపికను సక్రియం చేయడం ద్వారా మీరు అవసరమైతే పర్యవేక్షించవచ్చు.

## అనువాదం

మీరు ఒక భాష నుండి మరొక భాషకు పాఠ్యాన్ని మార్చాలనుకున్నప్పుడు **అనువాదం** ఉపయోగించండి.

![అనువాదం వర్క్‌స్పేస్](../images/screenshots/te/translate.png)

<br/>

<a id="translate-text"></a>
### పాఠ్యాన్ని అనువదించండి

1. **అనువాదం** తెరవండి.
2. **నుండి** లో భాషను ఎంచుకోండి.
3. **కు** లో భాషను ఎంచుకోండి.
4. టూల్‌బార్ లో ఒక మోడల్ ను ఎంచుకోండి.
5. **ఇన్‌పుట్** లో పాఠ్యాన్ని టైప్ చేయండి లేదా పేస్ట్ చేయండి.
6. **అనువదించు** పై క్లిక్ చేయండి.
7. **అవుట్‌పుట్** లో ఫలితాన్ని చదవండి.
8. ఫలితాన్ని కాపీ చేయాలనుకుంటే కాపీ బటన్‌ను ఉపయోగించండి.

<br/>

<a id="language-selection"></a>
### భాష ఎంపిక

- **నుండి** ఒక ప్రత్యేక భాష లేదా **భాషను గుర్తించండి** కావచ్చు.
- **కు** మీరు ఫలితాన్ని కావలసిన భాష.

మీ ఎంచుకున్న **ప్రముఖ భాషలు** జాబితాలో పైభాగంలో కనిపిస్తాయి. మీరు వాటిని [**సెట్టింగులు** > **భాషలు**](#languages) లో సెట్ చేయవచ్చు.

<br/>

<a id="helpful-translation-settings"></a>
### ఉపయోగకరమైన అనువాద సెట్టింగులు

[**సెట్టింగులు** > **సాధారణ సెట్టింగులు**](#general-settings) లో, అనువాదం ఎలా పనిచేస్తుందో మార్చవచ్చు:

- **పేస్ట్ పై స్వయంచాలక అనువాదం** మీరు పాఠ్యాన్ని పేస్ట్ చేసిన వెంటనే అనువాదాన్ని ప్రారంభిస్తుంది.
- **ఫలితాన్ని స్వయంచాలకంగా క్లిప్‌బోర్డ్‌లోకి కాపీ చేయండి** విజయవంతమైన అమలు తర్వాత ఫలితాన్ని స్వయంచాలకంగా కాపీ చేస్తుంది.
- **రియల్‌టైమ్ అనువాదం (టైప్ చేసేటప్పుడు)** మీరు టైప్ చేసేటప్పుడు అనువాదాలను ప్రారంభిస్తుంది.
- **సమయం ముగిసింది (ms)** రియల్‌టైమ్ అనువాదం ప్రారంభించే ముందు యాప్ ఎంత సమయం వేచి ఉంటుందో నియంత్రిస్తుంది.
- **ఎంటర్** `Enter` నొక్కినపుడు ఏమి జరగాలో నియంత్రిస్తుంది:

<a id="rewrite"></a>
## రీరైట్

ప్రధాన అర్థాన్ని మార్చకుండా పాఠ్యంలో మాటల నిర్మాణాన్ని మెరుగుపరచాలనుకున్నప్పుడు **రీరైట్** ఉపయోగించండి.

![రీరైట్ వర్క్‌స్పేస్](../images/screenshots/te/rewrite.png)

ఇది ద్వారా ఉపయోగకరం:

- చదువు రాత మరియు వ్యాకరణాన్ని సరిచేయడంలో
- పాఠ్యాన్ని స్పష్టంగా చేయడంలో
- పాఠ్యాన్ని మరింత ఔపచారికం లేదా అనౌపచారికం చేయడంలో
- పాఠ్యాన్ని సంక్షిప్తం చేయడం లేదా పొడిగించడంలో
- పాఠ్యాన్ని మరింత సాంకేతికంగా ఉండేలా చేయడంలో

<br/>

> 💡 **టిప్**<br/>
> మీరు "**అక్షరాస్యత మరియు వ్యాకరణాన్ని సరిచూడు**" మోడ్ ఉపయోగిస్తున్నప్పుడు, అవుట్‌పుట్ ప్యానెల్ లో `మార్పులను చూపించు` బటన్ కనిపిస్తుంది.
> మీ పాఠ్యానికి చేసిన ప్రత్యేక మార్పులను చూపించడానికి లేదా దాచడానికి ప్రదర్శనను మార్చడానికి ఈ బటన్ ను క్లిక్ చేయండి.

<a id="transform"></a>

## పరివర్తన (Transform)

AI కి స్వీయ-నిర్ణయించబడిన సూచనల సమితిని అనుసరించవలసినప్పుడు **పరివర్తన (Transform)** ఉపయోగించండి.

![పరివర్తన పని ప్రదేశం](../images/screenshots/te/transform.png)

ఇది యాప్ లోని అత్యంత సౌలభ్యత కలిగిన ప్రాంతం. క్రింది పనులతో సహా, ఇతర అన్ని పనులకు కూడా మీరు దీనిని ఉపయోగించవచ్చు:

- గమనికలను సంగ్రహించడం
- సున్నితం కాని పాఠ్యాన్ని మెరుగుపరచిన ఇమెయిల్‌గా మార్చడం
- ప్రధాన అంశాలను తీసుకురావడం
- పాఠ్యాన్ని ఇచ్చిన ఫార్మాట్ లోకి మార్చడం
- ఇన్‌పుట్ పాఠ్యంతో చేయాలనుకుంటున్న ఇతర స్వీయ కార్యకలాపాలు

<br/>

<a id="run-an-existing-prompt"></a>
### ఇప్పటికే ఉన్న ప్రాంప్ట్ ను నడుపుతున్నారు

1. **పరివర్తన (Transform)** ని తెరవండి.
2. ప్రాంప్ట్ లిస్ట్ నుండి ఒక ప్రాంప్ట్ ని ఎంచుకోండి.
3. **లక్ష్య (Target)** భాష బాక్స్ కనిపిస్తే, కావలసినది ఉంటే భాషని ఎంచుకోండి.
4. **ఇన్ పుట్ (Input)** లో పాఠ్యాన్ని టైప్ చేయండి లేదా అతికించండి.
5. **పరివర్తన (Transform)** క్లిక్ చేయండి.
6. **అవుట్ పుట్ (Output)** లో ఫలితాన్ని చదవండి.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### ఇంకా ప్రాంప్ట్ లు లేకపోతే

మీ ప్రాంప్ట్ లిస్ట్ ఖాళీగా ఉంటే, **మాదిరి ప్రాంప్ట్ లు లోడ్ చేయండి**పై క్లిక్ చేయండి. ఇది అంతర్నిర్మిత ఉదాహరణలను జోడిస్తుంది కాబట్టి మీరు వేగంగా ప్రారంభించవచ్చు.

<br/>

> ℹ️ **గమనిక**<br/>
> మాదిరి ప్రాంప్ట్ లు ఇంగ్లిష్ భాషలో అందించబడ్డాయి. వాటిని లోడవ్ చేసిన తరువాత, మీరు ప్రాంప్ట్ ని సవరించి, దానిని మీ భాషలోకి అనువదించడానికి **ప్రాంప్ట్ అనువాదం (Translate prompt)** ఉపయోగించవచ్చు.

<br/>

<a id="create-a-prompt-quickly"></a>
### త్వరగా ఒక ప్రాంప్ట్ సృష్టించండి

ఒక ప్రాంప్ట్ ని సృష్టించడం కోసం వేగవంతమైన మార్గం:

1. **కొత్త ప్రాంప్ట్ (New prompt)** పై క్లిక్ చేయండి.
2. **ప్రాంప్ట్ సృష్టించండి (Generate prompt)** పై క్లిక్ చేయండి.
3. ప్రాంప్ట్ ఏం చేయాలనుకుంటున్నారో వివరించండి.
4. ఒక మోడల్ ని ఎంచుకోండి.
5. యాప్ మీ కోసం ఓ ప్రాజెక్టు సృష్టించనివ్వండి.
6. ప్రాజెక్టును సమీక్షించి **సేవ్ (Save)** పై క్లిక్ చేయండి.

![ప్రాంప్ట్ సృష్టించండి](../images/screenshots/te/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### ప్రాంప్ట్ ని సవరించడం

మీరు ప్రాంప్ట్ ని సృష్టించినప్పుడు లేదా సవరించినప్పుడు, ఎడమ వైపు ఎడిటర్ కనిపిస్తుంది, కుడి వైపు పరీక్షణ ప్రాంతం కనిపిస్తుంది.

![పరివర్తన ప్రాంప్ట్ ఎడిటర్](../images/screenshots/te/transform-prompt-edit.png)

ప్రధాన ఫీల్డ్స్:

- **ప్రాంప్ట్ పేరు (Prompt name)**: ప్రాంప్ట్ లిస్ట్ లో కనిపించే పేరు.
- **ప్రాంప్ట్ సూచనలు (optional)**: ప్రాంప్ట్ ని నడిచినప్పుడు వాడుకరికి కనిపించే చిన్న సూచన.
- **మోడల్ పాత్ర (Model Role)**: AI కి కేటాయించిన మొత్తం పాత్ర, ఉదాహరణకు 'మీరు ఓ ఉపయోగపడే సహాయకుడు.'
- **మోడల్ సూచనలు (one per line)**: AI అనుసరించాలనుకునే ప్రత్యేక నియమాలు.
- **అవుట్ పుట్ వివరణ (Output description)**: ఫలితాన్ని సూచించే చిన్న పదం, ఉదాహరణకు 'సంగ్రహం' లేదా 'తిరిగి వ్రాసినది'.
- **ఉష్ణోగ్రత (Temperature) (0.0 → 1.0)**: మోడల్ ఎలా పనిచేస్తుంది; క్రింద చూడండి.
- **లక్ష్య భాష కోరండి (Ask for target language)**: ప్రాంప్ట్ ని నడిపినప్పుడు లక్ష్య భాష ఎంపికదారుని జోడిస్తుంది.

**ఉష్ణోగ్రత (Temperature)** అనే పారిభాషిక పదం మీకు కొత్తదైతే, దీన్ని ఈ విధంగా ఆలోచించండి:

- తక్కువ ఉష్ణోగ్రత **కొంచెం స్థిరమైన**, ఊహించదగిన ఫలితాలను ఇస్తుంది.
- ఎక్కువ ఉష్ణోగ్రత కొంచెం **వైవిధ్యమైన **(variety) మరియు సృజనాత్మకమైన ఫలితాలను ఇస్తుంది.

మీరు ఇవి కూడా ఉపయోగించవచ్చు:

- **`ప్రాంప్ట్ సృష్టించండి `(`Generate prompt`)**: సరళమైన వివరణ నుండి ఒక కొత్త ప్రాజెక్టు సృష్టించడానికి
- **`ప్రాంప్ట్ మెరుగుపరచండి `(`Improve prompt`)**: ఇప్పటికే ఉన్న ప్రాంప్ట్ ని మెరుగుపరచడానికి
- **`ప్రాంప్ట్ అనువాదం `(`Translate prompt`)**: ప్రాంప్ట్ ఫీల్డ్స్ ని అనువదించడానికి

<br/>

> ⚠️ **హెచ్చరిక**<br/>
> **`వెనక్కి రన్ కి `(`Back to Run`)** పై క్లిక్ చేయడానికి ముందు **`సేవ్ `(`Save`)** పై క్లిక్ చేయండి. సేవ్ చేయకుండా తిరిగి వెళితే, మీ మార్పులన్నీ కోల్పోతారు.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ఉపయోగించే ముందు ప్రాంప్ట్ ని పరీక్షించండి

కుడివైపు ఉన్న పరీక్షణ ప్యానెల్, మీ రోజువారీ పనిలో ఉపయోగించే ముందు మీరు మీ ప్రాంప్ట్ కి మాదిరి పాఠ్యంతో పరీక్ష చేయడానికి అనుమతిస్తుంది.

ఇది ఉపయోగపడేది:

- మీరు కొత్త ప్రాంప్ట్ ని సృష్టిస్తున్నప్పుడు
- మీరు రెండు ప్రాంప్ట్ వెర్షన్లను పోల్చుతున్నప్పుడు
- మీరు టోన్, పొడవు లేదా అవుట్ పుట్ ఫార్మాట్ ని ధృవీకరించాలనుకున్నప్పుడు

<br/>

> ℹ️ **గమనిక**<br/>
> [**సెట్టింగ్స్** > **పరివర్తన ప్రాంప్ట్స్**](#transform-prompts)లో మీకు కూడా సేవ్ చేసిన ప్రాంప్ట్స్ ని ఎగుమతి చేసుకోవచ్చు లేదా దిగుమతి చేసుకోవచ్చు.

మీరు యాప్ ఎంత మేరకు ఉపయోగిస్తున్నారో మరియు దాని వ్యయం కూడా (చెల్లించిన మోడల్స్ కోసం) చూడటానికి **డాష్ బోర్డ్ (Dashboard)**ని ఉపయోగించండి.

![డాష్ బోర్డ్ సారాంశం](../images/screenshots/te/dashboard-summary.png)


<br/>

> ℹ️ **గమనిక**<br/>
> మీరు ఉచిత మోడల్స్ మాత్రమే ఉపయోగిస్తుంటే, ఖర్చుతో సంబంధం ఉన్న చార్ట్ లు ఖాళీగా ఉంటాయి.

<br/>

<a id="filter-the-data"></a>
### డేటాని వడపోత చేయండి

సమయ పరిధిని మార్చడానికి పైభాగంలో ఉన్న వడపోత బటన్లను ఉపయోగించండి.

![డాష్ బోర్డ్ వడపోత](../images/screenshots/te/dashboard-filter.png)

<br/>

> ℹ️ **గమనిక**<br/>
> **వాడుకరి (User)** వడపోత వెబ్ వెర్షన్ లో మాత్రమే నిర్వాహకులకు కనిపిస్తుంది. సాధారణ వాడుకరులకు ఈ వడపోత కనిపించదు. డెస్క్టాప్ యాప్ లో ఇది లభ్యం కాదు.

<br/>

<a id="dashboard-tabs"></a>

### డాష్‌బోర్డ్ టాబ్‌లు

- **సారాంశం**: ఉపయోగం మరియు ఖర్చు గురించి ఓ సమగ్ర సమాచారాన్ని అందిస్తుంది.
- **ఉపయోగం ప్రకారం**: అనువాద భాష, రీరైట్ మోడ్ మరియు ట్రాన్స్‌ఫారమ్ ప్రాంప్ట్‌ల వారీగా కార్యాచరణను విడదీస్తుంది.
- **మోడల్ ప్రకారం**: మీరు ఉపయోగించిన మోడళ్లు మరియు వాటి ఖర్చు ఎంత ఉందో చూపిస్తుంది.
- **రోజు ప్రకారం**: ప్రతి రోజు మొత్తాన్ని చూపిస్తుంది.
- **అన్ని పిలుపులు**: పిలుపుల చరిత్రను పూర్తిగా చూపిస్తుంది మరియు మీరు దీన్ని ఎగుమతి చేయడానికి అనుమతిస్తుంది.

<br/>

<a id="export-data"></a>
### డేటాను ఎగుమతి చేయండి

డాష్‌బోర్డ్ పట్టికలు కింది ఫార్మాట్‌లలో డేటాను ఎగుమతి చేయగలవు:

- **JSON**
- **CSV**
- **XLSX**

అప్లికేషన్ బయట మీ కార్యాచరణను సమీక్షించాలనుకుంటే లేదా ప్రతిని పంచుకోవాలనుకుంటే ఇది ఉపయోగకరంగా ఉంటుంది.

<br/>

<a id="delete-stored-records-for-a-model"></a>
### మోడల్ కోసం నిల్వ చేసిన రికార్డులను తొలగించండి

**మోడల్ ప్రకారం** లేదా **అన్ని పిలుపులు** లో, "చెత్తబుట్ట" చిహ్నంపై క్లిక్ చేయడం ద్వారా మీరు ఓ నిర్దిష్ట మోడల్ కోసం ఉన్న నిల్వ చేసిన రికార్డులను తొలగించవచ్చు.

> ⚠️ **హెచ్చరిక**<br/>
> నిల్వ చేసిన రికార్డులను తొలగించడానికి వెనక్కి తిరిగి చేయలేరు. మీకు ఆ చరిత్ర ఇక అవసరం లేదని ఖచ్చితంగా తెలిసినప్పుడు మాత్రమే దీన్ని ఉపయోగించండి.

అన్ని డేటాను తొలగించడానికి లేదా డేటా వయస్సు ఆధారంగా రికార్డులను తొలగించడానికి, [**సెట్టింగ్‌లు** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) కి వెళ్లండి. అక్కడ అన్ని నిల్వ చేసిన డేటాను లేదా ఒక నిర్దిష్ట తేదీ కంటే పాతదాన్ని తొలగించడానికి ఎంపికలు ఉంటాయి.

### చరిత్ర డేటాను ఎగుమతి చేయండి

చరిత్ర పేజీ వడపోత చేసిన డేటాను కింది ఫార్మాట్‌లలో ఎగుమతి చేయగలదు:

- **JSON**
- **CSV**
- **XLSX**

అప్లికేషన్ బయట మీ కార్యాచరణను సమీక్షించాలనుకుంటే లేదా ప్రతిని పంచుకోవాలనుకుంటే ఇది ఉపయోగకరంగా ఉంటుంది.

## సెట్టింగ్‌లు

అప్లికేషన్ ప్రవర్తనను స్వీయ రూపొందించడానికి పక్క బారు నుండి **సెట్టింగ్‌లు** తెరవండి.

అందుబాటులో ఉన్న టాబ్‌లు వేదిక మరియు మీ పాత్రపై ఆధారపడి ఉంటాయి:

  |-------------------|:-------:|:-----------:|:------------------:|
  | సాధారణ సెట్టింగ్‌లు  |   అవును   |     అవును     |        అవును         |
  | మోడళ్లు            |   అవును   |     అవును     |        అవును         |
  | భాషలు         |   అవును   |     అవును     |        అవును         |
  | ఖర్చు ట్రాకింగ్     |   అవును   |     అవును     |         —          |
  | ట్రాన్స్‌ఫారమ్ ప్రాంప్ట్‌లు |   అవును   |     అవును     |        అవును         |
  | వాడుకరులు             |    —    |     అవును     |         —          |
  | API కాన్ఫిగ్        |   అవును   |     అవును     |         —          |
  | గురించి             |   అవును   |     అవును     |        అవును         |

### మాడల్స్

టూల్‌బార్‌లో కనిపించే మాడళ్లను ఎంచుకోవడానికి **సెట్టింగ్స్** > **మాడళ్లు**ని ఉపయోగించండి.

![సెట్టింగ్స్ మాడళ్ల ట్యాబ్](../images/screenshots/te/settings-models.png)

ఈ పేజీ రెండు జాబితాలను కలిగి ఉంటుంది:

- ఎడమ వైపు **లభ్యమయ్యే మాడళ్లు**
- కుడి వైపు **ఎంచుకున్న మాడళ్లు**

ఉపయోగకరమైన నియంత్రణలలో ఇవి ఉంటాయి:

- పేరు ద్వారా మాడల్‌ని కనుగొనడానికి **మాడళ్లు శోధించండి...**
- ఒక ఇంజిన్ (OpenRouter, OpenAI, Ollama, …) కి జాబితాను పరిమితం చేయడానికి **ప్రొవైడర్** చిప్స్
- ఉచిత మాడళ్లను మాత్రమే చూపించడానికి **ఫ్రీ ఓన్లీ**
- జాబితాను తిరిగి లోడ్ చేయడానికి **రిఫ్రెష్**
- మీరు ప్రొవైడర్ ద్వారా క్రమబద్ధీకరిస్తున్నప్పుడు **అన్నీ విస్తరించండి** మరియు **అన్నీ సంకోచించండి**

మాడల్ ఐడిలలో ప్రొవైడర్ ప్రిఫిక్స్ ఉంటుంది (ఉదాహరణకు `openrouter/…`కి బదులుగా `openai/…`). **OpenAI (OpenRouter)**కి బదులుగా **OpenAI (direct)** వంటి బ్యాడ్జెస్ ట్రాఫిక్ ఎలా రూట్ చేయబడిందో చూపిస్తాయి.

> ℹ️ **గమనిక**<br/>
> **OpenRouter బాడీ బిల్డర్** (`openrouter/bodybuilder`) సాధారణ చాట్ మాడల్ కాదు, ఇది రూటర్ మాడల్: దాని సమాధానం JSON, ఇది OpenRouter API రిక్వెస్ట్ బాడీలను వివరిస్తుంది (ఉదాహరణకు `model` మరియు `messages` ఉన్న `requests` అర్రే). మీరు దీన్ని **అనువదించడానికి**, **తిరిగి వ్రాయడానికి**, లేదా **రూపాంతరం చేయడానికి** ఉపయోగిస్తే, ఫినిష్డ్ టెక్స్ట్ కి బదులుగా అవుట్‌పుట్ ప్యానెల్ JSON చూపుతుంది. ఆ పనుల కోసం సాధారణ టెక్స్ట్ మాడల్‌ని ఎంచుకోండి. OpenRouter లో [బాడీ బిల్డర్ మాడల్ పేజీ](https://openrouter.ai/openrouter/bodybuilder) చూడండి.

చర్యలు:

 - మాడల్‌ని జతచేయడానికి, **Add** లేదా ఎంట్రీలో ఎక్కడైనా క్లిక్ చేయండి.

 - మాడల్‌ని తొలగించడానికి, **Selected Models** లో దాని పక్కన ఉన్న **X** పై క్లిక్ చేయండి లేదా లభ్యమయ్యే మాడళ్లలోని ఎంట్రీలో **Selected** పై క్లిక్ చేయండి.

 - జాబితాను క్లియర్ చేయడానికి, **Deselect all**పై క్లిక్ చేయండి. అవసరమైన ఉచిత మాడల్ జాబితాలో మిగిలిపోతుంది.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు OpenRouterకి వెంటనే క్రెడిట్లు జతచేయకుండా ఉండాలనుకుంటే, మొదటగా **Free Only**ని సక్రియం చేసి, ఉచిత మాడళ్లను ఎంచుకోండి (క్రెడిట్ కార్డ్ అవసరం లేదు). API కీ అవసరం లేకుండా మాడళ్లను స్థానికంగా నడపడానికి Ollamaని కూడా ఉపయోగించవచ్చు.

<a id="languages"></a>
### భాషలు

యాప్ లో ఉపయోగించే భాషా జాబితాలను సంస్థాపించడానికి **సెట్టింగ్స్** > **భాషలు**ని ఉపయోగించండి.

- **పై స్థాయి భాషలు** **అనువదించు** మరియు **రూపాంతరం చేయు** లో భాషా జాబితాల పైన పిన్ చేయబడతాయి.
- **కస్టమ్ భాష** అంతర్నిర్మిత జాబితాలో లేని భాషను జతచేయడానికి మిమ్మల్ని అనుమతిస్తుంది.

మీరు కస్టమ్ భాషను జతచేసినట్లయితే, అది అంతర్నిర్మిత ఎంపికలతో పాటు భాషా సెలెక్టర్లలో కనిపిస్తుంది.

<a id="cost-tracking"></a>
### ఖర్చు ట్రాకింగ్

ఖర్చు సమాచారాన్ని నిర్వహించడానికి **సెట్టింగ్స్** > **ఖర్చు ట్రాకింగ్** ఉపయోగించండి.

- **మొత్తం ఖర్చు** ప్రస్తుత మొత్తాన్ని చూపుతుంది.
- **విలువను కాపీ చేయండి** మొత్తాన్ని క్లిప్‌బోర్డుకి నకలు చేస్తుంది.
- **ఖర్చుని రీసెట్ చేయండి** నిల్వ చేయబడిన మొత్తాన్ని సున్నాకి రీసెట్ చేస్తుంది.
- **API కీ ఉపయోగంతో సమకాలీకరణ** మీ OpenRouter ఖాతా (OpenRouter మాత్రమే) నివేదించిన ఉపయోగానికి అనుగుణంగా మొత్తాన్ని సెట్ చేస్తుంది.
- **API కీ ఉపయోగం** OpenRouter ఉపయోగ వివరాలను, అందుబాటులో ఉంటే, చూపుతుంది.
- **ఖర్చు డేటాని తొలగించండి** డేటాపై అంతిమంగా, లేదా ఎంచుకున్న తేదీ కంటే పాతది మాత్రమే.

 **ఖర్చు ట్రాకింగ్:** మీరు OpenRouter మాడళ్లను ఉపయోగించినప్పుడు, అప్లికేషన్ OpenRouter నుండి ఖర్చు సమాచారం ఆధారంగా మీ వాస్తవ ఉపయోగం మరియు ఖర్చుని చూపుతుంది. మిగిలిన ఇతర ప్రొవైడర్ల కోసం, ఖరీదు అందుబాటులో ఉండదా అని OpenRouter ప్రచురించిన ధరల ఆధారంగా అప్లికేషన్ ఖర్చులను అంచనా వేస్తుంది, ఏదైనా ధర అందుబాటులో లేకపోతే, అంచనా సున్నా కావచ్చు.

<br/>

> ℹ️ **గమనిక**<br/>
>  **అన్ని ఖర్చు సంఖ్యలు మీ సౌకర్యార్థం మాత్రమే ఉపయోగపడే అంచనాలు, అధికారిక బిల్లింగ్ స్టేట్మెంట్లు కావు.**


<br/>

> ⚠️ **హెచ్చరిక**<br/>
> డేటా తొలగింపుని రద్దు చేయలేరు. తొలగించడానికి ముందు, మీ డేటా ను బ్యాకప్ చేయడం లేదా [**చరిత్ర**](#history) లేదా [**డాష్‌బోర్డ్** > **అన్ని కాల్స్**](#dashboard-tabs) ద్వారా ఎగుమతి చేయడం చేయండి, లేకుంటే ఇది శాశ్వతంగా నష్టపోతుంది.
> ప్రతి API కాల్ ఎంట్రీకి సంబంధించిన ఇన్‌పుట్/అవుట్‌పుట్ చరిత్ర కూడా తొలగించబడుతుంది.

### రూపాంతరం చేయడానికి సూచనలు

సూచనలను బల్క్ గా నిర్వహించడానికి **సెట్టింగ్స్** > **రూపాంతరం చేయడానికి సూచనలు** ఉపయోగించండి.

మీరు:

- మీ సేవ్ చేసిన సూచనలను సమీక్షించవచ్చు
- సూచనలను తొలగించవచ్చు
- ఫైల్ నుండి సూచనలను ఇంపోర్ట్ చేసుకోవచ్చు
- బ్యాకప్ లేదా షేరింగ్ కోసం సూచనలను ఎగుమతి చేసుకోవచ్చు

### వాడుకరులు

వెబ్ వెర్షన్ లో వాడుకరి ఖాతాలను నిర్వహించడానికి **వాడుకరులు**ని ఉపయోగించండి. మీరు వాడుకరులను జతచేయగలరు, వారి వివరాలను నవీకరించగలరు, పాస్ వర్డ్ లు రీసెట్ చేయగలరు మరియు ఖాతాలను తొలగించగలరు.

<a id="api-config"></a>
### API కాన్ఫిగ్

మద్దతు ఇచ్చే ప్రొవైడర్లు: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras మరియు **Ollama** (బేస్ URL ద్వారా స్థానిక మాడళ్లు). మీరు ఉపయోగించే ప్రొవైడర్లను మాత్రమే కాన్ఫిగర్ చేయాల్సి ఉంటుంది.

**వెబ్ అప్లికేషన్: నిర్వాహకుడు మాత్రమే**

API కీలు సిస్టమ్ లేదా డాకర్ పర్యావరణ వేరియబుల్స్ ద్వారా కాన్ఫిగర్ చేయబడతాయి — వాటిని వెబ్ UI లో నమోదు చేయరు. ఈ పేజీ ఏ ప్రొవైడర్లకు కీ కాన్ఫిగర్ చేయబడిందో చూపుతుంది మరియు ప్రతి ఒక్కటి **`పరీక్ష`** బటన్ పై క్లిక్ చేయడం ద్వారా పరీక్షించడానికి అనుమతిస్తుంది.

> ℹ️ **గమనిక**<br/>
> API కీ మార్చడానికి, మీ సిస్టమ్ లేదా డాకర్ కాన్ఫిగరేషన్ లో పర్యావరణ వేరియబుల్ ని నవీకరించి, సర్వర్ లేదా కంటెయినర్ ని తిరిగి ప్రారంభించండి.

<br/>

**డెస్క్‌టాప్ అప్లికేషన్**

మీరు ఉపయోగించే ప్రతి ప్రొవైడర్ కోసం API కీలను నిల్వ చేయడానికి **API కాన్ఫిగ్** ఉపయోగించండి. Ollama కోసం, API కీ కి బదులుగా **బేస్ URL** నమోదు చేయండి.


<br/>

> 💡 **సూచన** <br/>
> మీరు API కీని ఉపయోగించకుండా ఉండాలనుకుంటే లేదా ఉపయోగం కోసం చెల్లించకూడదనుకుంటే, మీ యంత్రంలో ఉచితంగా మాడళ్లను (ఉదాహరణకు `translategemma:4b`) స్థానికంగా నడపడానికి [Ollamaని డౌన్‌లోడ్](https://ollama.com) చేసుకోవచ్చు. లేదా, వారి ఉచిత మాడళ్లను ఉపయోగించడానికి ఉచిత OpenRouter ఖాతాను సృష్టించవచ్చు (క్రెడిట్ కార్డ్ అవసరం లేదు), లేదా Cerebras, Google, Groq, లేదా Mistral AI నుండి ఉచిత API కీని పొందవచ్చు.

<br/>

- మీరు అవసరమైన ప్రొవైడర్లను మాత్రమే జత చేయండి. **సెట్టింగ్స్** > **మాడళ్లు** లో, ప్రతి మాడల్ ఐడి ప్రొవైడర్ తో ప్రారంభమవుతుంది (ఉదాహరణకు `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

API కీ ని జత చేయడానికి, పాఠ్య ప్రదేశంలో విలువను నమోదు చేసి **`సేవ్`** పై క్లిక్ చేయండి. ఇప్పటికే ఉన్న కీని భర్తీ చేయడానికి **`సవరణ`** పై క్లిక్ చేయండి. కీ సరిగ్గా పనిచేస్తుందో లేదో తనిఖీ చేయడానికి **`పరీక్ష`** పై క్లిక్ చేయండి. Ollama బేస్ URL కోసం, కనెక్షన్ తనిఖీ చేయడానికి ఎప్పుడూ **`పరీక్ష`** పై క్లిక్ చేయండి.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు ఒక API కీ యొక్క ప్రస్తుత విలువను చూడలేరు. దానిని **`సవరణ`** బటన్ ఉపయోగించి మాత్రమే భర్తీ చేయవచ్చు.
> API కీలు కాన్ఫిగరేషన్ లో ఎన్‌క్రిప్టెడ్ గా నిల్వ చేయబడతాయి.

<a id="common-issues"></a>
## సాధారణ సమస్యలు

ఏదైనా అందగతంగా పనిచేయకపోతే, ముందుగా కింది వాటిని సరిచూసుకోండి.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### యాప్ టెక్స్ట్‌ని అనువాదం చేయడం, మళ్లీ వ్రాయడం లేదా మార్చడం చేయదు

సరిచూసుకోండి:

- టూల్‌బార్‌లో మీరు ఒక మోడల్‌ని ఎంచుకున్నారా
- [**సెట్టింగులు** > **మోడల్స్**](#models)లో ఒకటి లేదా అంతకంటే ఎక్కువ మోడల్స్ ఉన్నాయా
- మీ API సెటప్ పనిచేస్తోందేమో

డెస్క్టాప్ అప్లికేషన్ ఉపయోగిస్తున్నట్లయితే:

1. [**సెట్టింగులు** > **API కాన్ఫిగ్**](#api-config) తెరవండి.
2. కనీసం ఒక API కీ సేవ్ అయిందో లేదో సరిచూసుకోండి.
3. కీ పనిచేస్తుందో లేదో నిర్ధారించడానికి ప్రొవైడర్ పక్కన ఉన్న **పరీక్షించండి** బటన్ నొక్కండి.

<br/>

<a id="the-model-list-is-empty"></a>
### మోడల్ జాబితా ఖాళీగా ఉంది

[**సెట్టింగులు** > **మోడల్స్**](#models) తెరిచి **రిఫ్రెష్** బటన్ నొక్కండి.

అవసరం అయితే:

- ఒక మోడల్‌ని వెతకండి
- **కొంతమాత్రమే ఉచితం** ఎంపికను ఆన్ చేయండి
- **ఎంచుకున్న మోడల్స్**కు ఒకటి లేదా అంతకంటే ఎక్కువ మోడల్స్ జతచేయండి

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ఫలితం చాలా నెమ్మదిగా లేదా ఖరీదుగా ఉంది

ఇవి చేయండి:

- వేరొక మోడల్ ఎంచుకోండి
- తక్కువ ఇన్‌పుట్ ఉపయోగించండి
- [**సెట్టింగులు** > **సాధారణ సెట్టింగులు**](#general-settings)లో **నిజ సమయంలో అనువాదం (టైప్ చేసేటప్పుడు)** ని ఆఫ్ చేయండి
- సరళమైన పనులకు ఉచిత మోడల్స్ ఉపయోగించండి (చూడండి [మోడల్స్](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ఇంటర్‌ఫేస్ తప్పు భాషలో ఉంది

[టూల్‌బార్](#toolbar)లో గ్లోబ్ ఐకాన్ పై నొక్కి మీరు ప్రాధాన్యత ఇచ్చిన **ఇంటర్‌ఫేస్ భాష**ని ఎంచుకోండి.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### టెక్స్ట్ చాలా చిన్నగా లేదా చదవడానికి కష్టముగా ఉంది

[**సెట్టింగులు** > **సాధారణ సెట్టింగులు**](#general-settings) తెరిచి మార్చండి:

- **ఫాంట్ కుటుంబం**
- **పరిమాణం**

<br/>

<a id="dashboard-charts-are-empty"></a>
### డాష్‌బోర్డ్ చార్ట్స్ ఖాళీగా ఉన్నాయి

ఇది సాధారణమే, కింది సందర్భాలలో:

- మీరు **ఉచిత మోడల్స్** మాత్రమే ఉపయోగిస్తుంటే (ఖర్చు చార్ట్లు ఖాళీగా ఉంటాయి)
- ఎంచుకున్న **సమయ ఫిల్టర్** కాల్స్ జరిగిన వ్యవధిని కవర్ చేయకపోతే — **అన్నీ** ఎంచుకుని సరిచూసుకోండి

**అన్నీ** ఎంచుకున్నా చార్ట్లు ఖాళీగానే ఉంటే, కాల్స్ [**చరిత్ర**](#history) లో లేదా **అన్నీ కాల్స్** టాబ్‌లో కనిపిస్తున్నాయో లేదో ధృవీకరించండి.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ఖర్చు "లభ్యం కాదు" లేదా తప్పుగా కనిపిస్తుంది

మీరు **OpenRouter** ద్వారా మోడల్స్ ఉపయోగిస్తున్నప్పుడు, యాప్ OpenRouter నివేదించిన మీ నిజమైన ఖర్చును చూపిస్తుంది.

**ఇతర ప్రొవైడర్ల** (గుణోత్తర డైరెక్ట్, ఆంథ్రోపిక్ డైరెక్ట్, మొదలైనవి) కోసం, ఖర్చు OpenRouter ప్రచురించిన ధరల సమాచారం నుండి అంచనా వేయబడుతుంది. మోడల్‌కు సరిపోయే ఖర్చు లభించకపోతే, అది **లభ్యం కాదు**గా కనిపిస్తుంది మరియు మీ మొత్తం మొత్తంలో కలపబడదు.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### మొత్తం ఖర్చు నా ప్రొవైడర్ బిల్లుతో సరిపోలడం లేదు

యాప్ లోని అన్ని ఖర్చు పరిమాణాలు **సూచన కోసం మాత్రమే అంచనాలు**, అధికారిక బిల్లింగ్ ప్రకటనలు కావు.

మొత్తం మొత్తం మీ వాస్తవిక OpenRouter ఖర్చుకు దగ్గరగా ఉండేలా చేయడానికి, [**సెట్టింగులు** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) తెరిచి **API కీ ఉపయోగంతో సింక్ చేయి** బటన్ నొక్కండి.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### సైడ్‌బార్ నుండి చరిత్ర పేజీ కొరవడింది

**క్రమబద్ధీకరణ చరిత్రను ఉంచండి** ఆఫ్ అయి ఉండవచ్చు. [**సెట్టింగులు** > **సాధారణ సెట్టింగులు**](#general-settings) తెరిచి దానిని ఆన్ చేయండి. దీనిని ఆన్ చేయడం ముందు డిలీట్ చేసిన చరిత్ర డేటాను తిరిగి తెస్తుందని గమనించండి.

<br/>

<a id="web-app-session-expired"></a>
### వెబ్ యాప్: లాగిన్ పేజీకి ఆకస్మికంగా రీడైరెక్ట్ అయ్యాం

మీ సెషన్ గడువు ముగిసి ఉండవచ్చు. తిరిగి లాగిన్ అవ్వండి. ఇంకా తరచుగా జరిగితే, సర్వర్ కాన్ఫిగరేషన్‌లో సెషన్ జీవితకాల సెట్టింగులను సరిచూసుకోండి.

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### డాష్‌బోర్డ్ ఇతర వాడుకదారులకు డేటా చూపించడం లేదు (వెబ్)

**నిర్వాహకులు** మాత్రమే **వాడుకదారు** ఫిల్టర్ ద్వారా అన్ని వాడుకదారుల డేటాను చూడగలరు. సాధారణ వాడుకదారులు రూపొందించినట్లు వారి స్వంత క్రియాశీలతను మాత్రమే చూస్తారు.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### నేను ఒక సూచనను మార్చాను, సవరణలు పోయాయి

సూచనను సవరించినప్పుడు, ఎల్లప్పుడూ **తిరిగి రన్ కు వెళ్లు**పై క్లిక్ చేయడానికి ముందు **సేవ్**పై క్లిక్ చేయండి.

<a id="quick-tips"></a>
## త్వరిత సూచనలు

- [**అనువదించు**](#translate)తో మొదలుపెట్టండి, [**మళ్లీ వ్రాయి**](#rewrite) లేదా [**మార్చు**](#transform)కి వెళ్లే ముందు మీ సెటప్ పనిచేస్తుందేమో సరిచూసుకోండి.
- రోజువారీ మాటల మెరుగుదలల కోసం [**మళ్లీ వ్రాయి**](#rewrite) ని ఉపయోగించండి.
- ప్రత్యేక పని కోసం పునరావృత్తమయ్యే పనిప్రవాహం అవసరమైతే [**మార్చు**](#transform) ఉపయోగించండి.
- ఉపయోగం మరియు ఖర్చుపై దృష్టి పెట్టాలనుకుంటే [**డాష్‌బోర్డ్**](#dashboard) ని ఉపయోగించండి.
- గత ఆపరేషన్స్ మరియు వాటి పూర్తి ఇన్‌పుట్/అవుట్‌పుట్ టెక్స్ట్ పై సమీక్ష చేయడానికి [**చరిత్ర**](#history) ని ఉపయోగించండి.
- సురక్షితంగా ఉంచాలనుకునే సూచనల సేకరణ నిర్మాణం చేస్తున్నట్లయితే లేదా ఇతరులతో పంచుకోవాలనుకుంటే సూచనలను ఎప్పటికప్పుడు ఎగుమతి చేయండి (చూడండి [ట్రాన్స్ఫారమ్ సూచనలు](#transform-prompts)).
