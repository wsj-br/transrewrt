# వినియోగదారు మార్గదర్శకం

<br/>

<a id="introduction"></a>
## పరిచయం

Transrewrt మూడు ప్రధాన పద్ధతులలో పాఠ్యంతో పనిచేయడానికి సహాయపడుతుంది:

- **అనువాదం** - ఒక భాష నుండి మరొక భాషలోకి పాఠ్యాన్ని మార్చడం.
- **పునర్లిఖించు** - స్పష్టంగా, చిన్నదిగా లేదా మరింత ఔపచారికంగా ఉండేలా పాఠ్యాన్ని మళ్లీ రాయడం.
- **పరివర్తన** - ప్రాంప్ట్లు అని పిలువబడే కస్టమ్ AI సూచనలను ఉపయోగించి పాఠ్యంపై ప్రాసెస్ చేయడం.

<br/>

ఈ మార్గదర్శకం స్థాపించిన తర్వాత మరియు ప్రారంభించిన తర్వాత అప్లికేషన్ ఉపయోగించడం గురించి వివరిస్తుంది. స్థాపన దశల కొరకు ప్రధాన **[README](README.te.md)** చూడండి.

<br/>

> ℹ️ **గమనిక**<br/>
> Transrewrt Windows మరియు Linux కొరకు డెస్క్‌టాప్ అప్లికేషన్ గా మరియు స్వీయ-హోస్ట్ చేయబడిన వెబ్ అప్లికేషన్ గా అందుబాటులో ఉంది. ఈ మార్గదర్శకం అప్లికేషన్ యొక్క రోజువారీ ఉపయోగాన్ని ప్రధానంగా చూస్తుంది. ఏదైనా ఏకైక వెర్షన్‌కు మాత్రమే వర్తించినట్లయితే అది క్లుప్తంగా గుర్తించబడుతుంది.

<a id="before-you-start"></a>

## మీరు ప్రారంభించే ముందు

Transrewrt ఉపయోగించడానికి, మీరు కనీసం ఒక ఎఐ సరఫరాదారుకు ప్రాప్యత కలిగి ఉండాలి. మద్దతు ఇచ్చే సరఫరాదారులు ఇలా ఉన్నారు: [OpenRouter](https://openrouter.ai) (చాలా మోడళ్లను కూడగట్టేది), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras మరియు స్థానిక మోడళ్ల కోసం [Ollama](https://ollama.com).

ప్రారంభించడానికి మీరు చెల్లింపు చేసే మోడల్‌ను ఎంచుకోవలసిన అవసరం లేదు. మీరు OpenRouter API కీని చేరిన వెంటనే, అప్లికేషన్ అంతర్నిర్మిత **ఉచిత** OpenRouter ఎంపికను స్వయంచాలకంగా సక్రియం చేస్తుంది. ఇది వెంటనే టెక్స్ట్ ను అనువదించడం, తిరిగి వ్రాయడం, పరివర్తించడం సాధ్యమవుతుంది. ప్రత్యామ్నాయంగా, Cerebras, Google, Groq లేదా Mistral AI నుండి ఉచిత API కీని కూడా పొందవచ్చు.

సాధారణ భాషలో:

- ఒక **మోడల్** పనిని చేసే ఎఐ ఇంజన్. మోడళ్ళు **సరఫరాదారు ఉపసర్గ** తో జాబితా చేయబడతాయి (ఉదాహరణకు `openrouter/…`, `openai/…`, `ollama/…`).
- **API కీ** (లేదా Ollama కొరకు, ఒక **బేస్ URL**) అనేది అప్లికేషన్ ఆ సరఫరాదారును ఎలా చేరుకుంటుందో చూపిస్తుంది.

మీరు **డెస్క్‌టాప్ అప్లికేషన్** ఉపయోగిస్తున్నట్లయితే, మీరు ఉపయోగించే ప్రతి సరఫరాదారుకు [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) లో కీలను జోడించండి. కేవలం OpenRouter ఉపయోగించడానికి, క్రింద ఉన్న [API కీ పొందడం ఎలా](#how-to-get-an-api-key-desktop-app) చూడండి. మీరు API కీని ఉపయోగించకుండా ఉండాలనుకుంటే, స్థానిక మోడళ్ల బదులుగా `translategemma:4b` వంటి వాటిని ఉపయోగించడానికి [ollama.com](https://ollama.com) నుండి Ollama ని ఇన్‌స్టాల్ చేయవచ్చు.

మీరు **వెబ్ వెర్షన్** ఉపయోగిస్తున్నట్లయితే, సర్వర్ యజమాని పర్యావరణ వేరియబుల్స్ ద్వారా సరఫరాదారులను కాన్ఫిగర్ చేస్తారు కాబట్టి మీరు అప్లికేషన్‌లో నేరుగా ఐపి కీలను నమోదు చేయలేరు.

<a id="how-to-get-an-api-key-desktop-app"></a>
### ఉచిత OpenRouter API కీ సంపాదించడం ఎలా (డెస్క్‌టాప్ అప్లికేషన్)

మీరు డెస్క్‌టాప్ అప్లికేషన్ ఉపయోగిస్తున్నట్లయితే, ఈ దశలను అనుసరించండి:

1. మీ వెబ్ బ్రౌజర్‌లో [OpenRouter](https://openrouter.ai) కు వెళ్లండి.
2. ఒక ఖాతాను సృష్టించండి లేదా సైన్ ఇన్ అవ్వండి.
3. [Keys](https://openrouter.ai/keys) పేజీని తెరవండి.
4. కొత్త API కీని సృష్టించడానికి బటన్ పై క్లిక్ చేయండి.
5. తరువాత మీరు గుర్తించగలిగేలా కీకి పేరు ఇవ్వండి.
6. కొత్త API కీని కాపీ చేసుకోండి.
7. Transrewrt కు తిరిగి వెళ్లి **సెట్టింగ్స్** > **API కాన్ఫిగ్** తెరవండి.
8. **OpenRouter API కీ** లో (అనగా **సెట్టింగ్స్** > **API కాన్ఫిగ్** క్రింద) కీని పేస్ట్ చేయండి.
9. అది పనిచేస్తుందో లేదో పరీక్షించడానికి **OpenRouter కీని పరీక్షించండి** బటన్ పై క్లిక్ చేయండి.

<a id="getting-started"></a>
## ప్రారంభించడం

మీరు మొదటిసారిగా Transrewrt ఉపయోగిస్తుంటే, ఈ వరుస ప్రకారం చేయండి:

1. అప్లికేషన్‌ను తెరవండి.
2. అవసరమైతే గ్లోబ్ ఐకాన్ నుండి మీ **ఇంటర్‌ఫేస్ భాషను** ఎంచుకోండి.
3. మీరు **డెస్క్‌టాప్ అప్లికేషన్** లో ఉన్నట్లయితే, [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) తెరిచి, కనీసం ఒక సరఫరాదారుకు API కీని (ఉదాహరణకు OpenRouter) చేర్చి, అది పనిచేస్తుందో లేదో నిర్ధారించడానికి **పరీక్షించు** పై క్లిక్ చేయండి.
4. [**సెట్టింగ్స్** > **మోడళ్లు**](#models) తెరిచి **ఎంచుకున్న మోడళ్లు** క్రింద ఒకటి లేదా అంతకంటే ఎక్కువ మోడళ్లను జోడించండి.
5. మీకు ఎక్కువగా ఉపయోగించే భాషలు ముందుగా కనిపించాలనుకుంటే, [**సెట్టింగ్స్** > **భాషలు**](#languages) తెరిచి మీ **ప్రధాన భాషలను** ఎంచుకోండి.
6. **అనువాదం** కు వెళ్లి, ప్రతిదీ సరిగా పనిచేస్తుందో నిర్ధారించడానికి సరళ అనువాదాన్ని నడుపుతారు.
7. అది సరిగా పనిచేస్తే, **తిరిగి వ్రాయి** తర్వాత **పరివర్తించు** ప్రయత్నించండి.

ఈ క్రమం కీలకం. అప్లికేషన్‌కు పనిచేసే API కనెక్షన్ లేదా ఎంచుకున్న మోడల్ లేకుండా పనిని నడపడానికి ప్రయత్నించడం వంటి అత్యంత సాధారణమైన మొదటి ఉపయోగ సమస్యను ఇది నివారిస్తుంది.

### టూల్‌బార్

మీరు అప్లికేషన్‌లో ఎక్కడ ఉన్నారో బట్టి టూల్‌బార్ కొద్దిగా మారుతుంది.

- ఎడమవైపు, ప్రస్తుత పేజీ పేరు కనిపిస్తుంది.
- కుడివైపు, ప్రస్తుత పని కొరకు ఉపయోగించే **మోడల్ సెలెక్టర్** మరియు **ఇంటర్‌ఫేస్ భాష** కంట్రోల్ కనిపిస్తాయి.

**మోడల్ సెలెక్టర్** ప్రస్తుత పని కొరకు ఏ ఐఐ ఇంజిన్‌ను ఉపయోగించాలో ఎంచుకోవడానికి అనుమతిస్తుంది.

  ![మోడల్ సెలెక్టర్](../images/screenshots/te/model-selector.png)

చాలా ఉచిత మోడళ్లు ఎల్లప్పుడూ అందుబాటులో ఉండవు — కొన్నిసార్లు అవి ఆఫ్‌లైన్‌లో ఉంటాయి లేదా వాడకపు పరిమితి ఉంటుంది. ఇలాంటి సందర్భంలో, ఆ మోడల్‌ని మీ అందుబాటు జాబితా నుండి అప్లికేషన్ స్వయంచాలకంగా తీసేస్తుంది. ఏయే మోడళ్లు కనిపించాలో నియంత్రించడానికి, [**సెట్టింగ్స్** > **మోడళ్లు**](#models)కు వెళ్లి మీ మోడల్ జాబితాను సవరించండి.  
అలాగే టూల్‌బార్‌లో మోడల్ పేరుకు ఎడమ వైపున ఉన్న ప్రొవైడర్ ఐకాన్‌పై క్లిక్ చేయడం ద్వారా మీరు నేరుగా మోడల్ సెట్టింగ్స్‌ను తెరవవచ్చు.

<br/>

### ఇన్‌పుట్ మరియు అవుట్‌పుట్ ప్యానెల్స్

ఎక్కువ పని ప్రదేశాలు ఎడమవైపు ఉన్న **ఇన్‌పుట్** ప్యానెల్ మరియు కుడివైపు ఉన్న **అవుట్‌పుట్** ప్యానెల్‌ను ఉపయోగిస్తాయి.

ప్రతి ప్యానెల్ కింది సమాచారాన్ని కూడా చూపిస్తుంది:

| **ఇన్‌పుట్**                                                          | **అవుట్‌పుట్**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - అక్షరాల సంఖ్య <br/>- పదాల సంఖ్య <br/>- పేరాల సంఖ్య   <br/> | - పని పూర్తి చేయడానికి పట్టిన సమయం<br/>- **TPS** (సెకనుకు టోకెన్లు)<br/>- అక్షరాలు, పదాలు మరియు పేరాల సంఖ్య<br/>- ఉపయోగించిన మోడల్ |


మీరు సాంకేతిక పదాల గురించి ఆలోచిస్తున్నట్లయితే:

- **టోకెన్** అంటే చిన్న పాఠ్య భాగం. దీన్ని పదంలోని భాగం లేదా చిన్న పదంగా భావించవచ్చు.
- **TPS** అంటే మోడల్ సెకనుకు ఎన్ని పాఠ్య భాగాలను సంస్కరించింది.

<br/>

[**సెట్టింగ్స్** > **సాధారణ సెట్టింగ్స్**](#general-settings) వద్ద `చర్యలపై ఖర్చు సమాచారాన్ని చూపించు` ఎంపికను ప్రారంభించడం ద్వారా ప్రతి ఆపరేషన్ యొక్క ఖర్చు మరియు మొత్తం ఖర్చును కూడా మీరు పర్యవేక్షించవచ్చు (అందుబాటులో ఉంటే).

<a id="translate"></a>
## అనువాదం

మీరు ఒక భాష నుండి మరొక భాషకు పాఠ్యాన్ని మార్చాలనుకున్నప్పుడు **అనువాదం** ఉపయోగించండి.

![అనువాదం వర్క్‌స్పేస్](../images/screenshots/te/translate.png)

<br/>

<a id="translate-text"></a>
### పాఠ్యాన్ని అనువదించండి

1. **అనువాదం** తెరవండి.
2. **ఇక్కడ నుండి** వద్ద భాషను ఎంచుకోండి.
3. **ఇక్కడికి** వద్ద భాషను ఎంచుకోండి.
4. టూల్‌బార్‌లో ఒక మోడల్‌ను ఎంచుకోండి.
5. **ఇన్‌పుట్** లోకి పాఠ్యాన్ని టైప్ చేయండి లేదా అతికించండి.
6. **అనువాదం**పై క్లిక్ చేయండి.
7. **అవుట్‌పుట్** లో ఫలితాన్ని చదవండి.
8. ఫలితాన్ని కాపీ చేయాలనుకుంటే కాపీ బటన్ ఉపయోగించండి.

<br/>

<a id="language-selection"></a>
### భాషా ఎంపిక

- **ఇక్కడ నుండి** ఏదేని ప్రత్యేక భాష గానీ, **భాషను గుర్తించండి** గానీ ఉండవచ్చు.
- **ఇక్కడికి** మీరు ఫలితాన్ని కావాలనుకుంటోన్న భాష.

మీరు ఎంచుకున్న **టాప్ భాషలు** జాబితా పైభాగంలో కనిపిస్తాయి. మీరు వాటిని [**సెట్టింగ్స్** > **భాషలు**](#languages) వద్ద సెట్ చేయవచ్చు.

<br/>

<a id="helpful-translation-settings"></a>
### ఉపయోగకరమైన అనువాద సెట్టింగ్స్

[**సెట్టింగ్స్** > **సాధారణ సెట్టింగ్స్**](#general-settings) వద్ద, అనువాదం ఎలా పనిచేస్తుందో మార్చవచ్చు:

- **అతికించిన తర్వాత స్వయంచాలకంగా అనువదించు**, మీరు పాఠ్యాన్ని అతికించిన వెంటనే అనువాదం ప్రారంభిస్తుంది.
- **ఫలితాన్ని క్లిప్‌బోర్డుకు స్వయంచాలకంగా కాపీ చేయి**, విజయవంతమైన అనువాదం తర్వాత ఫలితాన్ని స్వయంచాలకంగా కాపీ చేస్తుంది.
- **రియల్-టైమ్ అనువాదం (టైప్ చేస్తూ ఉండగానే)**, మీరు టైప్ చేస్తూ ఉండగా అనువాదాలను ప్రారంభిస్తుంది.
- **టైమ్‌అవుట్ (ms)**, రియల్-టైమ్ అనువాదాన్ని ప్రారంభించే ముందు అప్లికేషన్ ఎంత సమయం వేచి ఉంటుందో నియంత్రిస్తుంది.
- **నమోదు చేయి**, మీరు `నమోదు చేయి` నొక్కినప్పుడు ఏమి జరగాలో నియంత్రిస్తుంది:

<a id="rewrite"></a>
## పునర్ రాయండి

ప్రధాన అర్థాన్ని మార్చకుండా మెరుగుపరచడానికి మీరు పాఠ్యాన్ని **పునర్ రాయండి** ఉపయోగించండి.

![పునర్ రాయండి వర్క్‌స్పేస్](../images/screenshots/te/rewrite.png)

ఇది కింది వాటికి ఉపయోగకరం:

- సన్నివేశం మరియు వ్యాకరణాన్ని సరిచేయడం
- పాఠ్యాన్ని స్పష్టంగా చేయడం
- పాఠ్యాన్ని మరింత ఔపచారికంగా లేదా అనౌపచారికంగా చేయడం
- పాఠ్యాన్ని సంక్షిప్తపరచడం లేదా విస్తరించడం
- పాఠ్యాన్ని మరింత సాంకేతికంగా ధ్వనించేలా చేయడం

<br/>

> 💡 **టిప్**<br/>
> మీరు "**సన్నివేశం & వ్యాకరణాన్ని తనిఖీ చేయి**" మోడ్ ఉపయోగించినప్పుడు, అవుట్‌పుట్ ప్యానెల్ లో `మార్పులను చూపించు` బటన్ కనిపిస్తుంది.
> మీ పాఠ్యానికి చేసిన ప్రత్యేక మార్పులను చూపించడం లేదా దాచడం, మార్పుల ప్రదర్శనను మార్చడానికి ఈ బటన్‌పై క్లిక్ చేయండి.

<a id="transform"></a>

## పరివర్తన

మీరు AI కస్టమ్ సూచనలను అనుసరించాలనుకున్నప్పుడు **పరివర్తన** ఉపయోగించండి.

![పరివర్తన వర్క్స్పేస్](../images/screenshots/te/transform.png)

ఇది అప్లికేషన్ యొక్క అత్యంత అనుకూల ప్రాంతం. దీనిని కింది వాటి కోసం ఉపయోగించవచ్చు:

- సంగ్రహాలు రాయడం
- సున్నితమైన పాఠాన్ని పరిష్కరించిన ఇమెయిల్‌గా మార్చడం
- కీ పాయింట్లను సేకరించడం
- పాఠాన్ని నిర్దిష్ట ఫార్మాట్‌లోకి మార్చడం
- ఇన్‌పుట్ టెక్స్ట్‌తో ఏదైనా కస్టమ్ చర్య

<br/>

<a id="run-an-existing-prompt"></a>
### ఉన్న ప్రాంప్ట్ ని అమలు చేయండి

1. **పరివర్తన** ని తెరవండి.
2. ప్రాంప్ట్ జాబితా నుండి ఒక ప్రాంప్ట్ ఎంచుకోండి.
3. **లక్ష్యం** భాష బాక్స్ కనిపిస్తే, కావలసినట్లయితే ఒక భాషను ఎంచుకోండి.
4. **ఇన్‌పుట్** లో పాఠాన్ని టైప్ చేయండి లేదా పేస్ట్ చేయండి.
5. **పరివర్తన** పై క్లిక్ చేయండి.
6. **అవుట్‌పుట్** లో ఫలితాన్ని చదవండి.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### మీ దగ్గర ఇంకా ప్రాంప్ట్స్ లేనట్లయితే

మీ ప్రాంప్ట్ జాబితా ఖాళీగా ఉంటే, **నమూనా ప్రాంప్ట్‌లు లోడ్ చేయండి** పై క్లిక్ చేయండి. దీనివల్ల ఇంబిల్ట్ ఉదాహరణలు జోడించబడతాయి, అందువల్ల మీరు త్వరగా ప్రారంభించవచ్చు.

<br/>

> ℹ️ **గమనిక**<br/>
> నమూనా ప్రాంప్ట్‌లు ఇంగ్లీష్‌లో అందించబడతాయి. వాటిని లోడ్ చేసిన తర్వాత, మీరు ప్రాంప్ట్‌ని సవరించి, **ప్రాంప్ట్ అనువాదం** ఉపయోగించి మీ భాషలోకి అనువదించవచ్చు.

<br/>

<a id="create-a-prompt-quickly"></a>
### త్వరగా ఒక ప్రాంప్ట్ సృష్టించండి

ప్రాంప్ట్ సృష్టించడానికి అతి వేగవంతమైన మార్గం:

1. **కొత్త ప్రాంప్ట్** పై క్లిక్ చేయండి.
2. **ప్రాంప్ట్ జనరేట్ చేయండి** పై క్లిక్ చేయండి.
3. మీరు కావాలనుకుంటున్న ప్రాంప్ట్ ఏమి చేయాలో వివరించండి.
4. ఒక మోడల్ ని ఎంచుకోండి.
5. క్రాఫ్ట్ ని మీ కోసం అప్లికేషన్ సృష్టించనివ్వండి.
6. క్రాఫ్ట్ ని సమీక్షించి **సేవ్** పై క్లిక్ చేయండి.

![ప్రాంప్ట్ జనరేట్ చేయండి](../images/screenshots/te/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ఒక ప్రాంప్ట్ ని సవరించండి

మీరు ప్రాంప్ట్ సృష్టించినప్పుడు లేదా సవరించినప్పుడు, సవరణ ప్యానెల్ ఎడమవైపు మరియు పరీక్షా ప్యానెల్ కుడివైపు కనిపిస్తాయి.

![పరివర్తన ప్రాంప్ట్ ఎడిటర్](../images/screenshots/te/transform-prompt-edit.png)

ప్రధాన ఫీల్డ్‌లు:

- **ప్రాంప్ట్ పేరు**: ప్రాంప్ట్ జాబితాలో చూపబడే పేరు.
- **ప్రాంప్ట్ సూచనలు (ఐచ్ఛికం)**: ప్రాంప్ట్ నడుస్తున్నప్పుడు వినియోగదారుడికి ప్రదర్శించబడే సూచన.
- **మోడల్ పాత్ర**: 'మీరు సహాయకుడిగా ఉండండి.' వంటి సహాయకి కేటాయించగా ఉన్న మొత్తం పాత్ర.
- **మోడల్ సూచనలు (ఒక్కొక్క పంక్తికి ఒక్కటి)**: మీరు కోరుకున్న నియమాలు సహాయకి అనుసరించాలి.
- **అవుట్‌పుట్ వివరణ**: 'సంగ్రహం' లేదా 'రీరైట్' వంటి ఫలితాన్ని సూచించే పదం.
- **ఉష్ణోగ్రత (0.0 → 1.0)**: మోడల్ ఎలా పనిచేస్తుంది; కింద చూడండి.
- **లక్ష్య భాష అడగండి**: ప్రాంప్ట్ నడుస్తున్నప్పుడు లక్ష్య భాష ఎంపికను జోడిస్తుంది.

టెక్నికల్ పదం **ఉష్ణోగ్రత** మీకు కొత్తది అయితే, దీనిని ఇలా ఆలోచించండి:

- **తక్కువ** ఉష్ణోగ్రత స్థిరమైన, ఊహించదగిన ఫలితాలు ఇస్తుంది.
- **ఎక్కువ** ఉష్ణోగ్రత రకరకాల మరియు సృజనాత్మక ఫలితాలు ఇస్తుంది.

మీరు ఇవి కూడా ఉపయోగించవచ్చు:

- **`ప్రాంప్ట్ జనరేట్ చేయి`**, సరళ వివరణ నుండి కొత్త క్రాఫ్ట్ సృష్టించడానికి
- **`ప్రాంప్ట్ మెరుగుపరుచు`**, ఇప్పటికే ఉన్న ప్రాంప్ట్ మెరుగుపరచడానికి
- **`ప్రాంప్ట్ అనువదించు`**, ప్రాంప్ట్ ఫీల్డ్‌లను అనువదించడానికి

<br/>

> ⚠️ **హెచ్చరిక**<br/>
> **`వెనక్కి అమలు చేయి`** పై క్లిక్ చేసే ముందు **`సేవ్`** పై క్లిక్ చేయండి. సేవ్ చేయకుండా వెనక్కి వెళ్తే, మీ మార్పులు కోల్పోతాయి.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ఉపయోగించే ముందు

### డాష్‌బోర్డ్ ట్యాబ్‌లు

- **సారాంశం** ఉపయోగం మరియు ఖర్చుల గురించి అవలోకనాన్ని అందిస్తుంది.
- **ఉపయోగం ప్రకారం** అనువాద భాష, పునర్రచన విధం మరియు పరివర్తన ప్రాంప్ట్ ప్రకారం కార్యకలాపాలను విభజిస్తుంది.
- **మోడల్ ప్రకారం** మీరు ఏ మోడల్స్ ఉపయోగించారో మరియు వాటికి ఎంత ఖర్చు అయ్యిందో చూపిస్తుంది.
- **రోజు ప్రకారం** ప్రతిరోజు మొత్తాలను చూపిస్తుంది.
- **అన్ని కాల్స్** పూర్తి కాల్ చరిత్రను చూపిస్తుంది మరియు మీరు దాన్ని ఎగుమతి చేసేందుకు అనుమతిస్తుంది.

<br/>

<a id="export-data"></a>
### డేటాను ఎగుమతి చేయండి

డాష్‌బోర్డ్ పట్టికలు క్రింది ఫార్మాట్‌లలో డేటాను ఎగుమతి చేయవచ్చు:

- **JSON**
- **CSV**
- **XLSX**

మీరు అప్లికేషన్ బయట కార్యకలాపాలను సమీక్షించాలనుకుంటే లేదా నివేదికను పంచుకోవాలనుకుంటే ఇది ఉపయోగకరంగా ఉంటుంది.

<br/>

<a id="delete-stored-records-for-a-model"></a>
### ఒక మోడల్ కోసం నిల్వ చేయబడిన రికార్డ్‌లను తొలగించండి

**మోడల్ ప్రకారం** లేదా **అన్ని కాల్స్** లో, మీరు "చెత్తబుట్ట" చిహ్నంపై క్లిక్ చేయడం ద్వారా ఒక మోడల్ కోసం నిల్వ చేయబడిన రికార్డ్‌లను తొలగించవచ్చు.

> ⚠️ **హెచ్చరిక**<br/>
> నిల్వ చేసిన రికార్డ్‌లను తొలగించడం రద్దు చేయబడదు. ఆ చరిత్ర ఇకపై అవసరం లేదని మీరు నిర్ధారించుకున్నప్పుడు మాత్రమే దీన్ని ఉపయోగించండి.

అన్ని డేటాను తొలగించడానికి లేదా వారసత్వం ఆధారంగా రికార్డ్‌లను తీసివేయడానికి, [**సెట్టింగ్స్** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) కి వెళ్లండి. అక్కడ అన్ని నిల్వ చేసిన డేటాను లేదా ఏదైనా తేదీకి మించిన డేటాను మాత్రమే తొలగించే ఎంపికలు ఉంటాయి.

<a id="settings"></a>
## సెట్టింగ్స్

అప్లికేషన్ ప్రవర్తనను అనుకూలీకరించడానికి సైడ్ బార్ నుండి **సెట్టింగ్స్**ను తెరవండి.

అందుబాటులోని ట్యాబ్‌లు ప్లాట్‌ఫామ్ మరియు మీ పాత్రకు బట్టి మారుతూ ఉంటాయి:

  | ట్యాబ్               | డెస్క్‌టాప్ | వెబ్ (నిర్వాహకుడు) | వెబ్ (సాధారణ వాడుకరి) |
  |-------------------|:-------:|:-----------:|:------------------:|
  | సాధారణ సెట్టింగ్స్  |   అవును   |     అవును     |        అవును         |
  | మోడల్స్            |   అవును   |     అవును     |        అవును         |
  | భాషలు         |   అవును   |     అవును     |        అవును         |
  | ఖర్చు ట్రాకింగ్     |   అవును   |     అవును     |         —          |
  | పరివర్తన ప్రాంప్ట్స్ |   అవును   |     అవును     |        అవును         |
  | వాడుకరులు             |    —    |     అవును     |         —          |
  | API కాన్ఫిగ్        |   అవును   |     అవును     |         —          |
  | గురించి             |   అవును   |     అవును     |        అవును         |

<br/>

> ℹ️ **గమనిక**<br/>
> వెబ్ వెర్షన్‌లో, ప్రతి వాడుకరికి వారి స్వంత కాన్ఫిగరేషన్ ఉంటుంది. ఎంచుకున్న మోడల్స్, భాషలు, సాధారణ ఎంపికలు మరియు పరివర్తన ప్రాంప్ట్ల వంటి సెట్టింగ్స్ ప్రతి వాడుకరి ప్రకారం నిల్వ చేయబడతాయి. మీరు చేసిన మార్పులు ఇతర వాడుకరులను ప్రభావితం చేయవు.

### సాధారణ సెట్టింగ్స్

**సాధారణ సెట్టింగ్స్**ను టైపింగ్ ప్రవర్తనాన్ని, **చరిత్ర** కోసం అమలు వివరాలు నిల్వ చేయబడతాయా లేదా అనే దాన్ని మరియు రూపాన్ని నియంత్రించడానికి ఉపయోగించండి.

**ప్రవర్తన**

- **ENTER కోసం ప్రవర్తన** `Enter` టాస్క్‌ను నడుపుతుందా లేదా కొత్త పంక్తిని చొప్పిస్తుందా అని ఎంచుకుంటుంది.
- **పేస్ట్ చేసినప్పుడు స్వయంచాలకంగా అనువాదం** మీరు పాఠ్యాన్ని పేస్ట్ చేసిన వెంటనే అనువాదం ప్రారంభిస్తుంది.
- **క్లిప్‌బోర్డ్‌కి ఫలితాన్ని స్వయంచాలకంగా కాపీ చేయండి** విజయవంతమైన ఫలితాలను స్వయంచాలకంగా కాపీ చేస్తుంది.
- **నిజ కాల అనువాదం (టైప్ చేసేటప్పుడు)** మీరు టైప్ చేసేటప్పుడు అనువాదం చేస్తుంది.
- **సమయపరిమితి (ms)** నిజ సమయ అనువాదానికి వేచి ఉన్న సమయాన్ని నిర్దేశిస్తుంది.

**చరిత్ర**

- **అమలు చరిత్రను ఉంచండి** ప్రతి అనువాదం, పునర్రచన మరియు పరివర్తన సైడ్ బార్ [**చరిత్ర**](#history) వీక్షణకు **ఇన్‌పుట్ మరియు ఔట్‌పుట్ పాఠ్యాన్ని** నిల్వ చేస్తుందో లేదో నియంత్రిస్తుంది. దానిని ఆపితే నిర్ధారణ అడుగుతుంది; మీరు నిర్ధారిస్తే, నిల్వ చేసిన చరిత్ర పాఠ్యం డేటాబేస్ నుంచి తీసివేయబడుతుంది.
- **చరిత్ర డేటాను తొలగించండి** వయస్సు ద్వారా (ఉదాహరణకు కొన్ని నెలల కంటే పాతది లేదా **అన్ని డేటా (స్పష్టం)**) **డేటాను తొలగించు** ఉపయోగించి నిల్వ చేసిన పాఠ్యాన్ని తొలగించడానికి అనుమతిస్తుంది. ఇది **చరిత్ర** వీక్షణ కోసం సేవ్ చేసిన అమలు పాఠ్యంపై మాత్రమే ప్రభావం చూపుతుంది; ఇది **ఖర్చు** లేదా **ఉపయోగం మొత్తాలను** తొలగించదు. **ఖర్చు** డేటాను తుడిచివేయడానికి లేదా తగ్గించడానికి, [**సెట్టింగ్స్** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) ని ఉపయోగించండి.

**అవుట్‌లుక్**

- **చర్యలపై ఖర్చు సమాచారాన్ని చూపించండి** అనువాదం, పునర్రచన మరియు పరివర్తన అవుట్‌పుట్ ప్యానెల్స్‌లో ఆపరేషన్ ప్రతిదానికి ఖర్చు (అందుబాటులో ఉంటే) మరియు మొత్తం ఖర్చు ప్రదర్శనను నియంత్రిస్తుంది.
- **ఖర్చు భిన్న అంకెలు** ఖర్చు దశాంశాలు ఎలా చూపబడతాయో మారుస్తుంది.
- **కేవలం వెబ్:** **అప్లికేషన్ చుట్టూ మార్జిన్ చూపించండి** ఇంటర్‌ఫేస్ చుట్టూ అదనపు స్థలాన్ని జోడిస్తుంది.
- **ఫాంట్ కుటుంబం** టెక్స్ట్ ప్యానెల్స్‌లో రాయడానికి ఫాంట్ ని మారుస్తుంది.
- **పరిమాణం** ఫాంట్ పరిమాణాన్ని మారుస్తుంది.

### మోడల్స్

**செట్టింగ్స్** > **మోడల్స్** ఉపయోగించి పÊర్స్‌బార్‌లో ఏ మోడల్స్ ఉండాలో ఎంపిక చేయండి.

![Settings Models tab](../images/screenshots/te/settings-models.png)

పేజీలో రెండు లిస్ట prosecutors ఉన్నాయి:

- **అందుబాటులో ఉన్న మోడల్స్** ఎడమవైపు
- **ఎంపిక చేసిన మోడల్స్** కుడివైపు

ప్రయోజనకరమైన నియంత్రకాలు:

- **మోడల్స్‌ను వెతుకు...** – పేరు ద్వారా మోడల్‌ను కనుగొనడానికి
- **ప్రొవైడర్** చిప్స్ – కొత్త ఒక ఇంజిన్‌కి (OpenRouter, OpenAI, Ollama, ...) జాబితా సomaత Telugu
- **మాత్రమే ఉచిత** – ఉచిత మోడల్స్‌ మాత్రమే చూపించడానికి
- **రీఫ్రెష్** – జాబితాను మళ్లీ లోడ్ చేయడానికి
- **అన్నీ విస్తరించు** మరియు **అన్నీ కూలా చేయి** – మీరు ప్రొవైడర్ ప్రకారం విభజిస్తున్నప్పుడు

మోడల్ IDలలో ప్రొవైడర్ ప్రిఫిక్స్ ఉంటుంది (ఉదాహరణకు `openrouter/…` vs `openai/…`). **OpenAI (OpenRouter)** vs **OpenAI (direct)** వంటి బాడ్జీలు ట్రాఫిక్ ఎలా రూట్ అవుతుందో చూపిస్తాయి.

> ℹ️ **గమనిక**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) ఒక రౌటర్ మోడల్, సాధారణ చాట్ మోడల్ కాదు: దాని ప్రతిస్పందన JSON గా ఉంటుంది, దీని మాదిరిగా OpenRouter API రీక్వెస్ట్ బాడీలను వివరిస్తుంది (ఉదాహరణకు `requests` అరే(src), దీనిలో `model` మరియు `messages` ఉంటాయి). దానిని **ట్రాన్స్‌లేట్**, **రీరైట్**, లేదా **ట్రాన్స్‌ఫార్మ్** కోసం వాడితే, ఆఉట్‌పుట్ ప్యానely నిర్జాతీయ జెసెన్‌ 대신 ఆ JSON చూపిస్తుంది. ఆ పనులకు సాధారణ టెక్స్ట్ మోడల్‌ను ఎంపిక చేయండి. OpenRouterలో [Body Builder model page](https://openrouter.ai/openrouter/bodybuilder) చూడండి.

ఎక్షన్లు:

 - మోడల్‌ను జోడించడానికి, **Add** లేదా ఎంట్రీలో ఎక్కడైనా క్లిక్ చేయండి.

 - మోడల్‌ను తీసివేయడానికి, **Selected Models**లో దాని పక్కకు **X** లేదా Available Modelsలో ఎంట్రీలో **Selected** వైపు క్లిక్ చేయండి.

 - జాబితాను పునరుద్ధరించడానికి, **Deselect all** క్లిక్ చేయండి. అవసరమైన ఉచిత మోడల్ జాబితాలో html ఉండగలదు.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు కానీ OpenRouterకు ఇ డిట్‌లు జాగ్రత్తగా జోడించడానికి లేదు, మీరు **Free Only**‌ను ఎనేబుల్ చేసి గుర్తించటం న Dres free మోడల్స్‌ (క్రెడిట్ కార్డ్ అవసరం లేదు). మీరు Ollama ఉపయోగించి స్థానికంగా మోడల్స్‌ను అప్‌లైను నడిపించవచ్చు, ఏ API కీ అవసరం లేకుండా. మీరు ఇతర ప్రావైడర్లకు కూడా ఉచిత API కీలను పొందవచ్చు లేదా Cerebras, Google, Groq, లేదా Mistral AI నుండి ఉచిత API కీలను పొందవచ్చు.

### భాషలు

**Settings** > **Languages** ఉపయోగించి యాప్‌లో ఉపయోగించే భాషా జాబితాలను నిర్వహించండి.

- ** టాప్ భాషలు** **Translate** మరియు **Transform** లో భాషా జాబితాల పైన చిట్కించబడతాయి.
- **కస్టమ్ భాష** మీకు బిల్ట్-ఇన్ జాబితాయilogy లో ఉన్న భాషను జోడించడానికి ఇవ్వబడింది.

మీరు కస్టమ్ భాష జేర Carr మీరు జోడించినది, అది బిల్ట్-ఇన్ ఎంపికలతో పాటు భాషా సెలెక్టర్లో కనిపిస్తుంది.

### ఖర్చు ట్రాకింగ్

**Settings** > **Cost Tracking** ఉపయోగించి ఖర్చు సమాచారాన్ని నిర్వహించండి.

- **Total Cost** పర్యవేక్షణ మొత్తాన్ని చూపిస్తుంది.
- **Copy Value** – మొత్తాన్ని క్లిప్‌బోర్డ్‌కి కాపీ చేస్తుంది.
- **Reset Cost** – నిల్వ ఉన్న మొత్తాన్ని సurya కానై సETE చేస్తుంది.
- **Sync with API key usage** – మొత్తాన్ని మీ OpenRouter అకౌంట్ నుండి Report చేసిన వాడకానికి అనుగుణంగా ఏర్పాటు చేస్తుంది (OpenRouter మాత్రమే).
- **API Key Usage** – అందుబాటులో ఉంటే OpenRouter వాడక వివరాలను చూపిస్తుంది.
- **Delete cost data** – అన్ని డేటాను తీసివేస్తుంది, లేదా ఎంపిక చేసిన తేదీ కంటే పాత ఎంట్రీలను మాత్రమే తీసివేస్తుంది.

 **Cost tracking:** మీరు OpenRouter మోడల్స్‌ను వాడినప్పుడు, యాప్ మీ అసలు వినియోగాన్ని మరియు OpenRouter నుండి ఖర్చు సమాచారాన్ని ఆధారంగా స్ధిరం చేస్తుంది. ఇతర ప్రావైడర్లకు, OpenRouter ప్రకటించిన ధరలను ఉపయోగించి యాప్ ఖర్చులను అంచనా వేస్తుంది; ఒక ధర అందుబాటులో ఉన్నట్లయితే, అంచనా సున్నా ఉండవచ్చు.

<a id="api-config"></a>
### API config

బిహారం ప్రావైడర్లు: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, మరియు **Ollama** (స్థానిక మోడల్స్ ఒక బేస్ URL ద్వారా). మీరు వాడే ప్రావైడర్లానే కాన్ఫిగర్ చేయాలి.

**వెబ్ అనుఎప్లికేషన్: అడ‌మినిస్ట్రేటర్ మాత్రమే**

API కీలు సిస్టమ్ లేదా Docker ఎన్విరాన్‌మెంట్ వేరియబుల్స్ ద్వారా కాన్ఫిగర్ చేయబడతాయి – అవ వెబ్ UI లో టైప్ చేయబడవు. ఈ పేజీ ఏ ప్రావైడర్లకి కీ కాన్ఫిగర్ అయిందో చూపిస్తుంది మరియు ప్రతి ఒక్కటిని **`Test`** బటన్‌ను క్లిక్ చేయడం ద్వారా పరీక్షించడానికి మీకు అనుమతిస్తుంది.

<br/>

> ℹ️ **గమనిక**<br/>
> API కీను మార్చడానికి, మీ సిస్టమ్ లేదా Docker Kong是因為 నందిన ఎన్విరాన్‌మెంట్ వేరియబుల్‌ను అప్డేట్ చేయి మరియు సర్వర్ లేదా కంటైనర్‌ను రీస్టార్ట్ చేయండి.

<br/>

**డెస్క్‌టాప్ అనుఎప్లికేషన్**

మీరు వాడే ప్రతి ప్రావైడర్ కోసం API కీలను నిల్వ చేయడానికి **API Config** ఉపయోగించండి. Ollama కోసం, API కీ బదలుగా **బేస్ URL** వద్ద ఇంట్రు చేయండి.


<br/>

> 💡 **సూచన** <br/>
> మీరు API కీని వాడకం లేదా వాడకం కోసం డబ్లూ పేరు కాకపోతే, మీరు [Ollama](https://ollama.com)‌ను డౌన్‌లోడ్ చేసి మీ మషీన్‌లో స్థానికంగా మోడల్స్‌ను ఉచితంగా (ఉదాహరణకు `translategemma:4b`) నడిపించవచ్చు. మరో కాక, మీరు ఉచిత OpenRouter అకౌంట్‌(క్రెడిట్ కార్డ్ అవసరం లేదు) సృష్టించి వారి ఉచిత మోడల్స్‌ను వాడవచ్చు, లేదా Cerebras, Google, Groq, లేదా Mistral AI నుండి ఉచిత API కీ పొందవచ్చు.

<br/>

- మీరు అవసరమైన ప్రావైడర్లను మాత్రమే జోడించండి. **Settings** > **Models**లో, ప్రతి మోడల్ ID ప్రావైడర్‌తో ప్రారంభమవుతుంది (ఉదాహరణకు `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

API కీ జోడించడానికి, టెక్స్ట్ ఫీల్డ్‌లో విలువను టైప్ చేసి **`Save`** డబ్లయుట్ క్లిక్ చేయండి. ఇప్పటికి ఉన్న కీని మార్చడానికి, **`Edit`** టప్పటని క్లిక్ చేయండి. ఒక కీ పనిచేస్తుందో తనిఖీ చేయడానికి, **`Test`** టప్పటని క్లిక్ చేయండి. Ollama బేస్ URL కోసం, కనెక్షన్ తనిఖీ చేయడానికి ఎల్లప్పుడు **`Test`** క్లిక్ చేయండి.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు API కీ యొక్క ప్రస్తుత విలువను చూడలేరు. మీరు దాన్ని **`Edit`** బటన్ ఉపయోగించి మాత్రం పదార్థం చేయవచ్చు.
> API కೀలు కాన్ఫిగరేషన్లో ఎన్‌క్రిప్టెడ్ గా నిల్వ అవుతాయి.

<a id="common-issues"></a>
## సాధারণ సమస్యలు

ఏదైనా ప్రతీకించినవివి లేకుండా పనిచేయకపోతే, మొదట ఈ పాయింట్లు తనిఖీ చేయండి.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### యాప్ టెక్స్ట్‌ను అనువదించడం, రీరైట్ చేయడం లేదా రూపాంతరం చేయడం లేకుండా ఉంటుంది

ఇవి నిర్ధారించండి:

- మీరు టూల్‌బార్‌లో ఒక మోడల్‌ను ఎంచుకున్నాయా
- [**సెట్టింగ్స్** > **మోడల్స్**](#models) లో కనీయగా కనిపించే ఒక మోడల్ ఉంది
- మీ API సెట్యప్ పనిచేస్తోంది

మీరు డెస్క్‌టాప్ యాప్‌ను వాడుతున్నతే:

1. [**సెట్టింగ్స్** > **API కాన్‌ఫిగ్**](#api-config) తెరవండి.
2. కనీయగా కనిపించే ఒక API కీ సేవ్ అయినది అని తనిఖీ చేయండి.
3. కీ పనిచేస్తోందని నిర్ధారించడానికి ప్రొవైడర్ దగ్గర **టెస్ట్** ను క్లిక్ చేయండి.

<br/>

<a id="the-model-list-is-empty"></a>
### మోడల్ లిస్ట్ ఖాళీగా ఉంది

[**సెట్టింగ్స్** > **మోడల్స్**](#models) తెరవి **రీఫ్రెష్** ను క్లిక్ చేయండి.

అవసరమైతే:

- ఒక మోడల్ కోసం శోధించండి
- **ఫ్రీ ఓన్లి** ని ఆన్ చేయండి
- **ఎంచుకున్న మోడల్స్**కు ఒక లేదా అంతకంటే ఎక్కువ మోడల్స్ని జోడించండి

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ఫలితం చాలా మందిగా లేదా చాలా ఖర్చుకంగా ఉంది

ఈవిటిని ఒకటి లేదా అంతకంటే ప్రయత్నించండి:

- వేరొక మోడల్‌ను ఎంచుకోండి
- చిన్న ఇన్‌పుట్‌ను వాడండి
- [**సెట్టింగ్స్** > **జనరల్ సెట్టింగ్స్**](#general-settings)లో **రియల్-టైమ్ అనువాదం (టైప్ చేస్తున్నప్పుడు)** ని ఆఫ్ చేయండి
- సాధారణ పనులకు ఫ్రీ మోడల్స్‌ను వాడండి ([మోడల్స్](#models) చూడండి)

<a id="the-interface-is-in-the-wrong-language"></a>

[**సెట్టింగ్స్** > **జనరల్ సెట్టింగ్స్**](#general-settings) తెరవి మార్స Instant Family*

<a id="dashboard-charts-are-empty"></a>
### డాష్‌బోర్డ్ చార్ట్స్ ఖాళీగా ఉన్నాయి

ఇది సాధారణం కాదు:

- మీరు **ఫ్రీ మోడల్స్** () మాత్రమే వాడICs (కాస్ట్ చార్ట్స్ ఖాళీగా ఉంటాయి)
- ఎంచుకున్న **టైమ్ ఫిల్టర్** కాల్‌లు జరిగిన కాలాన్ని కవర్ చేయకుండా ఉంది — తనిఖీ చేయడానికి **అన్ని** ని ప్రయత్నించండి

**అన్ని**ని ఎంచుకొన్న తరువాత కూడా చార్ట్స్ ఖాళీగా ఉంటే, [**హిస్టరీ**](#history) లో లేదా **అల్ కాల్స్** టాబ్‌లో కాల్‌లు కనిపించాయో ధృవీకరించండి.

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ఖర్చు "లభ్యం కాదు" అని చూపిస్తుంది లేదా తప్పు అనిపిస్తుంది

మీరు **OpenRouter** ద్వారా మోడల్స్‌ను ఉపయోగించినప్పుడు, యాప్ మీ *అసలు* వ్యయం OpenRouter అనుసరించి చూపుతుంది.

**ఇáticos ప్రొవైడర్లకు** (OpenRouter స్థిరంగా, Anthropic స్థిరంగా మొదలైనవి), ఖర్చు OpenRouter ద్వారా ప్రచురించిన ధరల డేటా నుండి అంచనా వేయబడుతుంది. మోడల్‌కు అనుకూలమైన ధర అరుకుంటే, ఖర్చు **లభ్యం కాదు** అని చూపిస్తుంది మరియు మీ నడుము మొత్తంకు జోడించబడదు.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### మొత్తం ఖర్చు నా ప్రొవైడర్ బిల్ల్‌తో సరిపోలడం లేదు

యాప్‌లోని అన్ని ఖర్చు అంచనాలు **స楚天** కోసం మాత్రమే, అధికారిక బిల్లింగ్ స్టేట్‌మెంట్లు కాదు.

మీ నిజమైన OpenRouter వ్యయానికి దగ్గరగా వచ్చే మొత్తాన్ని పెట్టడానికి, [**సెట్టింగ్స్** > **కాస్ట్ ట్రాకింగ్**](#cost-tracking) తెరవి **API కీ వినియోగంతో సింక్రనై*z్** ను క్లిక్ చేయండి.

మీ సెషన్ టైం‌అవ్ట్ అయ్యి ఉండవచ్చు. మళ్లీ లాగిన్ చేయండి. తరచుగా అని సంఘటితే, సెషన్ లైఫ్‌టైమ్ సెట్టింగ్ల కోసం సర్వర్ కాన్‌ఫిగరేషన్‌ను తనిఖీ చేయండి.

<a id="dashboard-shows-no-data-for-other-users"></a>
### డాష్‌బోర్డ్ ఇతర వినియోగదారులకు డేటాను చూపడం లేదు (వెబ్)

**అడ్మినిస్ట్రేటర倶రు** మాత్రమే **యూజర్** ఫిల్టర్ ద్వారా అన్ని వినియోగదారుల నుండి డేటాను చూడగలరు. సాధారణ వినియోగదారులు డిజైన్ ప్రకారం కేval మార్కి స్వయంగా చేసిన కార్యకలాపాన్ని చూడతారు.

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### నేను ఒక ప్రాంప్ట్‌ను మార్చి సవరణలను కోల్పోయాను

ప్రాంప్ట్‌ను సవరించినప్పుడు, **బ్యాక్ టు రన్** ను క్లిక్ చేయడానికి ముందు ఎప్పుడూ **సేవ్** ను క్లిక్ చేయండి.

<a id="quick-tips"></a>
## ట్యూక్ టిప్స్

- మీ సెట్టప్ పనిచేస్తుందని నిర్ధరించడానికి ముందు [**ట్రాన్స్లేట్**](#translate)తో ప్రారంభించడం
- రోజువారీ పదబంధ మెరుగుదలలకు [**రీరైట్**](#rewrite)ను వాడండి.
- మీరు ఒక నిర్దిష్ట పనికి పునరావృత వర్క్‌ఫ్లో అవసరమైతే [**ట్రాన్స్‌ఫార్మ్**](#transform)ను వాడండి.
- వినియోగం మరియు ఖర్చు పై దృష్టి పెట్టాలనుకుంటే [**డాష్‌బోర్డ్**](#dashboard)ను వాడండి.
- గత పనులను మరియు వాటి పూర్తి ఇన్‌పుట్/అవుట్‌పుట్ టెక్స్ట్‌ను సమీక్షించడానికి [**హిస్టరీ**](#history)ను వాడండి.
- మీరు నిల్వ చేయాలనుకుంటున్న ప్రాంప్ట్ లైబ్రరీని నిర్మిస్తున్నálgyా, లేదా వాటిని ఇతరులతో పంచుకోాలనుకుంటే, మీరు తరచుగా ప్రాంట్‌లను ఎક్స్‌పోర్ట్ చేయాలి ([ట్రాన్స్‌ఫార్్ ప్యాట్](#transform-prompts) చూడండి).
