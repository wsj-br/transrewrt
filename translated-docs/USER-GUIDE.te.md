# వినియోగదారు మార్గదర్శకం

<br/>

<a id="introduction"></a>
## పరిచయం

Transrewrt మూడు ప్రధాన విధాలుగా మీకు టెక్స్ట్‌తో పనిచేయడంలో సహాయపడుతుంది:

- **అనువాదం** - ఒక భాష నుండి మరొక భాషలోకి టెక్స్ట్‌ను మార్చడం.
- **పునర్రచన** - స్పష్టంగా, సంక్షిప్తంగా లేదా అధిక ఔపచారికత కలిగిన శైలిలో టెక్స్ట్‌ను మళ్లీ రాయడం.
- **మార్పు** - ప్రాంప్ట్ అని పిలుస్తారు కస్టమ్ కృత్రిమ మేధస్సు సూచనలను ఉపయోగించి టెక్స్ట్‌పై ప్రాసెస్ చేయడం.

<br/>

ఇది ఇన్‌స్టాల్ చేసి, ప్రారంభించిన తర్వాత అప్లికేషన్ ఉపయోగించడానికి ఈ మార్గదర్శికం సహాయపడుతుంది. ఇన్‌స్టాల్ చేయడానికి దశల కొరకు, ప్రధాన **[README](README.te.md)**ను చూడండి.

<br/>

> ℹ️ **గమనిక**<br/>
> Transrewrt విండోస్ మరియు లినక్స్ కొరకు డెస్క్‌టాప్ అప్లికేషన్ గా, మరియు స్వంతంగా హోస్ట్ చేయబడిన వెబ్ అప్లికేషన్ గా అందుబాటులో ఉంది. అప్లికేషన్ యొక్క ప్రతిరోజు వాడకాన్ని ఈ మార్గదర్శికం వివరిస్తుంది. ఇవి ఒక ప్రత్యేక వెర్షన్ కు మాత్రమే వర్తించే చోట్ల, అది స్పష్టంగా గుర్తించబడింది.

## మీరు ప్రారంభించే ముందు

Transrewrt ని ఉపయోగించడానికి, మీకు కనీసం ఒక ఏఐ ప్రొవైడర్‌కు ప్రాప్యత అవసరం. మద్దతు ఇచ్చే ప్రొవైడర్లు: [OpenRouter](https://openrouter.ai) (చాలా మోడళ్లను సేకరిస్తుంది), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI మరియు స్థానిక మోడళ్ల కోసం [Ollama](https://ollama.com).

మీరు ప్రారంభం కోసం చెల్లింపు మోడల్‌ను ఎంచుకోవాల్సిన పనిలేదు. మీరు మీ OpenRouter API కీని చేరిన వెంటనే, అప్లికేషన్ అమర్చిన **ఉచిత** OpenRouter ఐచ్ఛికాన్ని ఆటోమాటిక్‌గా సక్రియం చేస్తుంది. ఇది మిమ్మల్ని తక్షణమే టెక్స్ట్‌ను అనువదించడం, తిరిగి వ్రాయడం మరియు మార్చడానికి అనుమతిస్తుంది.

సాధారణ పదాలలో:

- ఒక **మోడల్** పని చేసే ఏఐ ఇంజిన్. మోడళ్లు **ప్రొవైడర్ ప్రిఫిక్స్‌తో** పేర్కొనబడతాయి (ఉదాహరణకు `openrouter/…`, `openai/…`, `ollama/…`).
- ఒక **API కీ** (లేదా Ollama కోసం, ఒక **బేస్ URL**) అప్లికేషన్ ఆ ప్రొవైడర్‌ను చేరుకునే పద్ధతి.

మీరు **డెస్క్‌టాప్ అప్లికేషన్** ఉపయోగిస్తుంటే, మీరు ఉపయోగించే ప్రతి ప్రొవైడర్ కోసం [**సెట్టింగులు** > **API కాన్ఫిగ్**](#api-config)లో కీలను జోడించండి. కేవలం OpenRouter వాడకానికి, క్రింద [ఒక API కీ ఎలా పొందాలి](#how-to-get-an-api-key-desktop-app) చూడండి. మీరు API కీని ఉపయోగించకూడదనుకుంటే, [ollama.com](https://ollama.com) నుండి Ollama ని ఇన్‌స్టాల్ చేసి స్థానిక మోడళ్లను ఉపయోగించవచ్చు.

మీరు **వెబ్ వెర్షన్** ని ఉపయోగిస్తుంటే, సర్వర్ యజమాని environment variables ఉపయోగించి ప్రొవైడర్‌లను కాన్ఫిగర్ చేస్తారు, కాబట్టి సాధారణంగా మీరు స్వయంగా API కీలను నమోదు చేయరు.

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### ఉచిత OpenRouter API కీ ఎలా పొందాలి (డెస్క్‌టాప్ అప్లికేషన్)

మీరు డెస్క్‌టాప్ అప్లికేషన్ ఉపయోగిస్తుంటే, ఈ దశలను అనుసరించండి:

1. మీ వెబ్ బ్రౌజర్‌లో [OpenRouter](https://openrouter.ai) కు వెళ్లండి.
2. ఒక ఖాతాను సృష్టించండి లేదా లాగిన్ అవ్వండి.
3. [Keys](https://openrouter.ai/keys) పేజీని తెరవండి.
4. కొత్త API కీని సృష్టించడానికి బటన్ పై క్లిక్ చేయండి.
5. తరువాత మీరు దానిని గుర్తించగలిగేలా కీకి పేరు ఇవ్వండి.
6. కొత్త API కీని కాపీ చేయండి.
7. Transrewrt కు తిరిగి వెళ్లి **సెట్టింగులు** > **API కాన్ఫిగ్** తెరవండి.
8. కీని **OpenRouter API కీ**లోకి ( **సెట్టింగులు** > **API కాన్ఫిగ్** క్రింద) పేస్ట్ చేయండి.
9. ఇది పనిచేస్తుందో లేదో నిర్ధారించడానికి **OpenRouter కీని పరీక్షించండి** నొక్కండి.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు క్రెడిట్ కార్డును జోడించకుండానే స్వేచ్ఛగా OpenRouter యొక్క ఉచిత మార్గాన్ని లేదా లభ్యమయ్యే ఇతర ఉచిత మోడళ్లలో ఏదైనా ఉపయోగించడంతో ప్రారంభించవచ్చు. చాలా సందర్భాల్లో, చెల్లింపు మోడల్‌ను ఎంచుకోకుండా Transrewrt ఉపయోగించడానికి ఇది చాలు. ప్రత్యామ్నాయంగా, మీరు ఏదైనా API కీ లేకుండా స్థానికంగా మోడళ్లను నడపడానికి Ollama ఉపయోగించవచ్చు.

<a id="getting-started"></a>
## ప్రారంభించడం

ఇది మీకు మొట్టమొదటిసారిగా Transrewrtని ఉపయోగిస్తున్నట్లయితే, ఈ క్రమాన్ని అనుసరించండి:

1. అప్లికేషన్ ని తెరవండి.
2. అవసరమైతే ప్రపంచ చిహ్నం నుండి మీ **ఇంటర్‌ఫేస్ భాష**ని ఎంచుకోండి.
3. మీరు **డెస్క్‌టాప్ అప్లికేషన్** లో ఉంటే, [**సెట్టింగులు** > **API కాన్ఫిగ్**](#api-config) ని తెరవండి, కనీసం ఒక ప్రొవైడర్ కోసం ఒక API కీని (ఉదాహరణకు OpenRouter) జోడించి, ఇది పనిచేస్తుందో లేదో నిర్ధారించడానికి **పరీక్షించండి** పై క్లిక్ చేయండి.
4. [**సెట్టింగులు** > **మోడళ్లు**](#models) ని తెరవండి మరియు **ఎంపిక చేసిన మోడళ్లకు** ఒకటి లేదా అంతకంటే ఎక్కువ మోడళ్లను జోడించండి.
5. మీరు ఎక్కువగా ఉపయోగించే భాషలు మొదట కనిపించాలనుకుంటే [**సెట్టింగులు** > **భాషలు**](#languages) లోకి వెళ్లి మీ **టాప్ భాషలు**ని ఎంచుకోండి.
6. **అనువదించు** కు వెళ్లి ప్రతిదీ పనిచేస్తుందో నిర్ధారించడానికి సరళమైన అనువాదాన్ని అమలు చేయండి.
7. ఇది పనిచేసిన తరువాత, **తిరిగి వ్రాయండి** మరియు ఆ తరువాత **మార్చండి** ప్రయత్నించండి.

ఈ క్రమం చాలా ముఖ్యమైనది. అప్లికేషన్ కి పనిచేసే API కనెక్షన్ లేదా ఎంపిక చేసిన మోడల్ లేకుండా ముందు పని చేయడానికి ప్రయత్నించడం వంటి సాధారణ తొలిసారి ఉపయోగించే సమస్యలను ఇది నివారిస్తుంది.

### టూల్‌బార్

మీరు యాప్‌లో ఎక్కడ ఉన్నారో దాని బట్టి టూల్‌బార్ కొంచెం మారుతుంది.

- ఎడమ వైపు, ప్రస్తుత పేజీ పేరు చూపబడుతుంది.
- కుడి వైపు, **మోడల్ సెలెక్టర్** మరియు **ఇంటర్ఫేస్ భాష** నియంత్రణ చూపబడతాయి.

**మోడల్ సెలెక్టర్** ప్రస్తుత పని కోసం ఏ ఎఐ ఇంజన్ ఉపయోగించాలో ఎంచుకోవడానికి మీకు అనుమతిస్తుంది.

  ![మోడల్ సెలెక్టర్](../images/screenshots/te/model-selector.png)

> ℹ️ **గమనిక**<br/>
> కొన్ని ఉచిత మోడళ్లు ఎల్లప్పుడూ లభించవు—కొన్నిసార్లు అవి ఆఫ్‌లైన్‌లో ఉంటాయి లేదా ఉపయోగ పరిమితి ఉంటుంది. ఇలా జరిగితే, ఆ మోడల్‌ని మీ లభ్యమయ్యే జాబితా నుండి యాప్ స్వయంచాలకంగా తొలగిస్తుంది.<br/>
> ఏయే మోడళ్లు కనిపించాలో నియంత్రించడానికి, [**సెట్టింగ్స్** > **మోడళ్లు**](#models)కి వెళ్లి, మీ మోడల్ జాబితాను సవరించండి. 
> టూల్‌బార్‌లో మోడల్ పేరుకు ఎడమ వైపున ఉన్న ప్రొవైడర్ ఐకాన్‌పై క్లిక్ చేసి నేరుగా మోడల్ సెట్టింగ్స్‌ని కూడా తెరవవచ్చు.

<br/>

**గ్లోబ్ ఐకాన్ + భాషా కోడ్** యాప్ ఇంటర్ఫేస్ భాషను (మెనులు మరియు బటన్లు వంటివి) మారుస్తుంది. ఇది **అనువాదం**లో ఉపయోగించే అనువాద భాషలను **మార్చదు**.

<a id="input-and-output-panels"></a>
### ఇన్‌పుట్ మరియు అవుట్‌పుట్ ప్యానెల్స్

చాలా వర్క్‌స్పేస్‌లు ఎడమ వైపున ఉన్న **ఇన్‌పుట్** ప్యానెల్ మరియు కుడి వైపున ఉన్న **అవుట్‌పుట్** ప్యానెల్‌ని ఉపయోగిస్తాయి.

**ఇన్‌పుట్** ప్యానెల్‌ చూపిస్తుంది:

- అక్షరాల సంఖ్య
- పదాల సంఖ్య
- పేరాల సంఖ్య

**అవుట్‌పుట్** ప్యానెల్ చూపించగలదు:

- పని పూర్తి చేయడానికి పట్టిన సమయం
- ఆ పని యొక్క ఖర్చు (సందర్భం అందుబాటులో ఉంటే)
- మీ మొత్తం మొత్తం ఖర్చు
- **TPS** (సెకనుకు టోకెన్లు)
- అక్షరాలు, పదాలు మరియు పేరాల సంఖ్య
- ఉపయోగించిన మోడల్

సాంకేతిక పదాలపై మీకు ఆశ్చర్యం ఉంటే:

- **టోకెన్** అంటే చిన్న పాటి వాక్యాంశం. మీరు దీన్ని పదంలో ఒక భాగం లేదా చిన్న పదంగా భావించవచ్చు.
- **TPS** అంటే మోడల్ ప్రతి సెకనుకు ఎన్ని వాక్యాంశాల్ని ప్రాసెస్ చేస్తుందో.

<a id="translate"></a>
## అనువాదం

మీరు ఒక భాషలోని పాఠ్యాన్ని మరొక భాషలోకి మార్చాలనుకున్నప్పుడు **అనువాదం** ఉపయోగించండి.

![అనువాద వర్క్‌స్పేస్](../images/screenshots/te/translate.png)

<br/>

<a id="translate-text"></a>
### పాఠ్యాన్ని అనువదించండి

1. **అనువాదం** తెరవండి.
2. **నుండి**లో ఒక భాషను ఎంచుకోండి.
3. **కు**లో ఒక భాషను ఎంచుకోండి.
4. టూల్‌బార్‌లో ఒక మోడల్‌ని ఎంచుకోండి.
5. **ఇన్‌పుట్**లో పాఠ్యాన్ని టైప్ చేయండి లేదా పేస్ట్ చేయండి.
6. **అనువాదం**పై క్లిక్ చేయండి.
7. **అవుట్‌పుట్**లో ఫలితాన్ని చదవండి.
8. ఫలితాన్ని కాపీ చేయాలనుకుంటే కాపీ బటన్‌ను ఉపయోగించండి.

<br/>

<a id="language-selection"></a>
### భాషా ఎంపిక

- **నుండి** ప్రత్యేక భాష కావచ్చు లేదా **భాషను గుర్తించండి**.
- **కు** మీరు ఫలితంగా కావలసిన భాష.

మీరు ఎంచుకున్న **ప్రధాన భాషలు** జాబితా పైన కనిపిస్తాయి. ఈ సెట్టింగ్స్‌ని మీరు [**సెట్టింగ్స్** > **భాషలు**](#languages)లో సెట్ చేసుకోవచ్చు.

<br/>

<a id="helpful-translation-settings"></a>
### ఉపయోగకరమైన అనువాద సెట్టింగ్స్

[**సెట్టింగ్స్** > **సాధారణ సెట్టింగ్స్**](#general-settings)లో, అనువాదం ఎలా పనిచేస్తుందో మార్చవచ్చు:

- **పేస్ట్ చేసిన వెంటనే అనువాదం** మీరు పాఠ్యాన్ని పేస్ట్ చేసిన వెంటనే అనువాదం ప్రారంభిస్తుంది.
- **ఫలితాన్ని క్లిప్‌బోర్డుకు స్వయంచాలకంగా కాపీ చేయి** విజయవంతమైన రన్ తర్వాత ఫలితాన్ని స్వయంచాలకంగా కాపీ చేస్తుంది.
- **సరళమైన అనువాదం (టైప్ చేసేటప్పుడు)** మీరు టైప్ చేసేటప్పుడు అనువాదాలు నిర్వహిస్తుంది.
- **సమయానుకూల సెట్టింగు** (ms) సరిలి (ms)** సరళమైన అనువాదాన్ని నిర్వహించే ముందు యాప్ ఎంత సమయం వేచి ఉంటుందో నియంత్రిస్తుంది.

- రఫ్ టెక్స్ట్‌ను పəlిష్డ్ ఇంకా మార్పు
- కీ పాయింట్లు ఎక్స్ట్రాక్ట్ చేయడం
- టెక్స్ట్‌ను ప్రత్యేక ఫార్మాట్‌కు మార్చడం

<br/>

<a id="run-an-existing-prompt"></a>
### ఇదంతా ఉన్న ప్రాంప్ట్‌ను నడగొట్టు

1. **Transform**ను తెరువుడి.
2. ప్రాంప్ట్ లిస్ట్‌ నుండి ఒక ప్రాంప్ట్‌ను ఎంచుకోండి.
3. **Target** language బాక్స్ కనిపించినప్పుడు, మీరు భాష అవసరం ఉంటే ఎంచుకోండి.
4. **Input**లో టెక్స్ట్‌ను టైప్ చేయండి లేదా పేస్ట్ చేయండి.
5. **Transform** బటన్‌ను క్లిక్ చేయండి.
6. **Output**లో ఫలితాన్ని చదవండి.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### మీకు ఇంకా ప్రాంప్ట్లు లేదైనల

మీ ప్రాంప్ట్ లిస్ట్ ఖాళీగా ఉంటే, **Load sample prompts** అని క్లిక్ చేయండి. ఇది బిల్ట్-ఇన్ ఉదాహరణలని జోడిస్తుంది, మీరు వేగంగా ప్రారంభించడానికి అవసరం.

<br/>

> ℹ️ **గమనిక**<br/>
> సాంప్ల ప్రాంప్ట్లు ఇంగ్లీష్‌లో అందించబడ్డాయి. వాటిని లోడ్ చేసిన తర్వాత, మీరు ఒక ప్రాంప్ట్‌ను సవరించవచ్చు మరియు **Translate prompt** వాడి దాన్ని మీ భాషకు అనువదించవచ్చు.

<br/>

<a id="create-a-prompt-quickly"></a>
### వెంటనే ప్రాంప్ట్‌ని సృష్టించynamodb

వేగంగా ప్రాంప్ట్‌ని సృష్టించడానికి సమయం:

1. **New prompt** క్లిక్ చేయండి.
2. **Generate prompt** క్లిక్ చేయండి.
3. మీరు ప్రాంప్ట్ ఏమి చేయాలనుకుంటున్నారు అని వివరించండి.
4. ఒక మోడల్ని ఎంచుకోండి.
5. యాప్‌కి మీరు ఒక డ్రాఫ్ట్‌ని సృష్టించడానికi అనుమతించండి.
6. డ్రాఫ్ట్‌ను సమీక్షించండి మరియు **Save** క్లిక్ చేయండి.

![ప్రాంప్ట్‌ను సృష్టించండి](../images/screenshots/te/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ప్రాంప్ట్‌ను సవరించండి

మీరు ప్రాంప్ట్‌ని సృష్టించినప్పుడు లేదా సవరించినప్పుడు, ఎడమవైపు ఎడిటర్ కనిపిస్తుంది మరియు కుడివైపు ఒక టెస్ట్ ప్రాంతం కనిపిస్తుంది.

![Transform prompt editor](../images/screenshots/te/transform-prompt-edit.png)

ప్రధాన ఫీల్డ్స్:

- **Prompt name**: ప్రాంప్ట్ లిస్ట్‌లో చూపబడే పేరు.
- **Prompt instructions (optional)**: ప్రాంప్ట్‌ను నడగొట్టినప్పుడు యూజర్‌కి చూపబడే చిన్న హింట్.
- **Model Role**: AIకి అనుసరించే మొత్తం పాత్ర, ఉదాహరణకు 'You are a helpful assistant.'
- **Model Instructions (one per line)**: మీరు AIకి అనుసరించాలని కోరే నిర్దిష్ట నిబంధనలు.
- **Output description**: ఫలితాన్ని వర్ణించే చిన్న పదం, ఉదాహరణకు 'summary' లేదా 'rewrite'.
- **Temperature (0.0 → 1.0)**: మోడల్ ఎలా వర్తింది; క్రింది దాన్ని చూడండి.
- **Ask for target language**: ప్రాంప్ట్ నడిగినప్పుడు టార్గెట్ భాష సెలెక్టర్‌ని జోడిస్తుంది.

**Temperature** అనేgaanzt గణిత శాస్త్ర పదం మీకు కొత్తది అయితే, దానిని ఇలా భావించండి:

- **కొవ్వు** Temperature స్థిరమైన, మరింత పబ్ధిక్షెబుల్ ఫలితాలను ఇస్తుంది.
- **ఎక్కువ** Temperature మరింత వైవిధ్యం మరియు సృజనాత్మకతను ఇస్తుంది.

మీరు కూడా ఈ గురించి వాడవచ్చు:

- **`Generate prompt`** సాదాహారణ వివరణ నుండి కొత్త డ్రాఫ్ట్‌ను సృష్టించడానికి
- **`Improve prompt`** ఇప్పటికి ఉన్న ప్రాంప్ట్‌ను మెరుగుపరచడానికి
- **`Translate prompt`** ప్రాంప్ట్ ఫీల్డ్స్‌ను అనువదించడానికి

<br/>

> ⚠️ **హెచ్చరిక**<br/>
> **`Back to Run`** క్లిక్ చేయడానికి ముందు **`Save`** క్లిక్ చేయండి. మీరు సేవ్ చేయకుండా తిరిగి వెళ్లితే, మీ మార్పులు కోల్పోతాయి.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### దానిని ఉపయోగించడానికి ముందు ప్రాంప్ట్‌ను టెస్ట్ చేయండి

కుడివైపున్న టెస్ట్ ప్యానెల్ మీరు మీ రోజువారీ పనిలో దానిని వాడే ముందు మీ ప్రాంప్ట్‌ను నమూనా టెక్స్ట్‌తో ప్రయోగించడానికి అనుమతిస్తుంది.

ఇది సంకలిగినప్పుడు వ国库ు:

- మీరు కొత్త ప్రాంప్ట్‌ని నిర్మిస్తున్నప్పుడు
- మీరు ప్రాంప్ట్ రెండు వెర్షన్లను పోల్చుతున్నప్పుడు
- మీరు టోన్, పరిమాణం, లేదా అవుట్‌పుట్ ఫార్మాట్‌ను చెక్ చేయాలనుకుంటున్నప్పుడు

<br/>

<a id="manage-saved-prompts"></a>
### సేవ్ చేసిన ప్రాంప్ట్లను నిర్వహించండి

సేవ్ చేసిన ప్రాంప్ట్లను ఒక చోటu నిర్వహించడానికి, [**Settings** > **Transform Prompts**](#transform-prompts)ను తెరువుడి.

అక్కడ మీరు:

- మీ ప్రాంప్ట్లను జాబితా చేయవచ్చు మరియు తీసివేయవచ్చు
- ప్రాంప్ట్లను **JSON**, **CSV**, లేదా **XLSX** గా ఎక్స్‌పోర్ట్ చేయవచ్చు
- ఫైల్ నుండి ప్రాంప్ట్లను ఇంపోర్ట్ చేయవచ్చు

- **మోడల్ ప్రకారం** మీరు ఉపయోగించిన మోడళ్లు మరియు వాటి ఖర్చులను చూపిస్తుంది.
- **రోజు ప్రకారం** రోజువారీ మొత్తాలను చూపిస్తుంది.
- **అన్ని కాల్లు** పూర్తి కాల్ చరిత్రను చూపిస్తుంది మరియు దానిని ఎగుమతి చేయడానికి అనుమతిస్తుంది.

<a id="delete-stored-records-for-a-model"></a>
### మోడల్ కోసం నిల్వ చేసిన రికార్డ్లను తొలగించండి

**మోడల్ ప్రకారం** లేదా **అన్ని కాల్లు**‌లో, "చెత్తబుట్ట" చిహ్నంపై క్లిక్ చేయడం ద్వారా మోడల్ కోసం నిల్వ చేసిన రికార్డ్లను తొలగించవచ్చు.

> ⚠️ **హెచ్చరిక**<br/>
> నిల్వ చేసిన రికార్డ్లను తొలగించడం రద్దు చేయలేరు. ఆ చరిత్ర మరింత అవసరం లేదని ఖచ్చితంగా తెలుసుకున్నప్పుడు మాత్రమే దీనిని ఉపయోగించండి.

అన్ని డేటాను తొలగించడానికి లేదా డేటా వయస్సు ఆధారంగా రికార్డ్లను తొలగించడానికి, [**సెట్టింగ్స్** > **ఖర్చు ట్రాకింగ్**](#cost-tracking)కి వెళ్లండి. మీరు అన్ని నిల్వ చేసిన డేటాను లేదా ఒక ప్రత్యేక తేదీకి ముందు డేటాను మాత్రమే తొలగించడానికి ఎంపికలను కనుగొంటారు.

మీరు అనువర్తనం వెలుపల కార్యకలాపాలను సమీక్షించాలనుకుంటే లేదా నివేదికను పంచుకోవాలనుకుంటే ఇది ఉపయోగపడుతుంది.

### సాధారణ సెట్టింగ్లు

**సాధారణ సెట్టింగ్లు** టైపింగ్ ప్రవర్తనను, **చరిత్ర** కొరకు అమలు వివరాలు నిల్వ చేయబడతాయో లేదో, మరియు రూపాపారాలను నియంత్రించడానికి ఉపయోగించబడతాయి.

**ప్రవర్తన**

- **ENTER కొరకు ప్రవర్తన** `Enter` జాబ్ నడుపుతుందో లేదా కొత్త పంక్తిని చొప్పిస్తుందో నిర్ణయిస్తుంది.
- **పేస్ట్ చేసినప్పుడు స్వయంచాలకంగా అనువాదం** మీరు పాఠాన్ని పేస్ట్ చేసిన వెంటనే అనువాదాన్ని ప్రారంభిస్తుంది.
- **క్లిప్బోర్డుకు ఫలితాన్ని స్వయంచాలకంగా నకలు చేయండి** విజయవంతమైన ఫలితాలను స్వయంచాలకంగా నకలు చేస్తుంది.
- **తదుపరి కాలంలో అనువాదం (టైప్ చేసేటప్పుడు)** మీరు టైప్ చేసేటప్పుడు అనువాదిస్తుంది.
- **సమయం ముగిసింది (ms)** తదుపరి కాలంలో అనువాదానికి వేచి ఉండే సమయాన్ని నిర్దేశిస్తుంది.

**చరిత్ర**

- **అమలు చరిత్రను ఉంచండి** ప్రతి అనువాదం, పునర్నిర్మాణం మరియు మార్పు కొరకు పార్శ్వపుటంలోని [**చరిత్ర**](#history) వీక్షణకు **ఇన్‌పుట్ మరియు అవుట్‌పుట్ పాఠాన్ని** నిల్వ చేస్తుందో లేదో నియంత్రిస్తుంది. ఇది ఆపివేస్తే ధృవీకరణ కోసం అడుగుతుంది; మీరు ధృవీకరిస్తే, నిల్వ చేయబడిన చరిత్ర పాఠం డేటాబేస్ నుండి తొలగించబడుతుంది.
- **చరిత్ర డేటాను తొలగించు** **డేటాను తొలగించు** ఉపయోగించి వయస్సు ప్రకారం (ఉదాహరణకు కొన్ని నెలల కన్నా పాతది లేదా **అన్ని డేటా (స్పష్టం)**) నిల్వ చేయబడిన పాఠాన్ని తొలగించడానికి అనుమతిస్తుంది. ఇది **చరిత్ర** వీక్షణ కొరకు సేవ్ చేయబడిన అమలు పాఠాన్ని మాత్రమే ప్రభావితం చేస్తుంది; ఇది **వ్యయం లేదా ఉపయోగం మొత్తాలను తొలగించదు**. **వ్యయం** డేటాను తొలగించడానికి లేదా కత్తిరించడానికి, [**సెట్టింగులు** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) ని ఉపయోగించండి.

**రూపాపారం**

- **వ్యయం భిన్న అంకెలు** వ్యయం దశాంశాలు ఎలా చూపించబడతాయో మారుస్తుంది.
- **వెబ్ మాత్రమే:** **యాప్ చుట్టూ మార్జిన్ చూపించు** ఇంటర్ఫేస్ చుట్టూ అదనపు స్థలాన్ని జోడిస్తుంది.
- **ఫాంట్ ఫ్యామిలీ** పాఠ ప్యానెల్స్ లో రాయడం ఫాంటును మారుస్తుంది.
- **పరిమాణం** ఫాంట్ పరిమాణాన్ని మారుస్తుంది.

<a id="models"></a>
### మోడల్స్

టూల్ బార్లో ఏ మోడల్స్ కనిపించాలో నిర్ణయించడానికి **సెట్టింగులు** > **మోడల్స్** ని ఉపయోగించండి.

![సెట్టింగులు మోడల్స్ టాబ్](../images/screenshots/te/settings-models.png)

ఈ పేజీ రెండు జాబితాలు కలిగి ఉంటుంది:

- ఎడమ వైపు **అందుబాటు లో ఉన్న మోడల్స్**
- కుడి వైపు **ఎంచుకున్న మోడల్స్**

ఉపయోగకరమైన నియంత్రణలలో ఇవి ఉన్నాయి:

- పేరు ద్వారా మోడల్‌ని కనుగొనడానికి **మోడల్స్ వెతకండి...**
- ఒక ఎంజిన్‌కు (OpenRouter, OpenAI, Ollama, …) జాబితాను పరిమితం చేయడానికి **సరఫరాదారు** చిప్స్
- ఉచిత మోడల్స్ మాత్రమే చూపించడానికి **మాత్రమే ఉచితం**
- జాబితాను తిరిగి లోడ్ చేయడానికి **రీఫ్రెష్**
- సరఫరాదారు ద్వారా మీరు క్రమబద్దీకరించేటప్పుడు **అన్నింటిని విస్తరించండి** మరియు **అన్నింటిని కుదించండి**

మోడల్ ఐడీలు ప్రొవైడర్ ప్రిఫిక్స్‌ని చేర్చాయి (ఉదాహరణకు `openrouter/…` vs `openai/…`). **OpenAI (OpenRouter)** vs **OpenAI (డైరెక్ట్)** వంటి బ్యాడ్జీలు ట్రాఫిక్ ఎలా మార్చబడుతుందో చూపిస్తాయి.

చర్యలు:

 - మోడల్ ని జోడించడానికి, **జోడించు** లేదా ఎంట్రీ మొత్తంలో ఎక్కడైనా క్లిక్ చేయండి.

 - మోడల్ ని తొలగించడానికి, **ఎంచుకున్న మోడల్స్** లో దాని పక్కన ఉన్న **X** లేదా అందుబాటు లో ఉన్న మోడల్స్ లోని ఎంట్రీలో **ఎంచుకోబడింది** పై క్లిక్ చేయండి.

 - జాబితాను ఖాళీ చేయడానికి, **అన్నింటిని ఎంచుకోవద్దు** పై క్లిక్ చేయండి. అవసరమైన ఉచిత మోడల్ జాబితాలో ఉంటుంది.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు OpenRouter కు వెంటనే క్రెడిట్లు జోడించకూడదనుకుంటే, మొదట **ఉచితమాత్రమే** ను ప్రారంభించి, ఉచిత మోడల్స్‌ను (క్రెడిట్ కార్డ్ అవసరం లేదు) ఎంచుకోండి. మీరు Ollama ని ఆపై API కీ లేకుండా స్థానికంగా మోడల్స్‌ను నడపడానికి కూడా ఉపయోగించవచ్చు.

### భాషలు

యాప్ లో ఉపయోగించే భాషల జాబితాలను నిర్వహించడానికి **సెట్టింగులు** > **భాషలు** ని ఉపయోగించండి.

- **ప్రముఖ భాషలు** **అనువాదం** మరియు **మార్చు** లోని భాషా జాబితాల పైన పిన్ చేయబడతాయి.
- **కస్టమ్ భాష** నిర్మిత జాబితాలో లేని భాషను జోడించడానికి అనుమతిస్తుంది.

మీరు కస్టమ్ భాషను జోడిస్తే, నిర్మిత ఎంపికలతో పాటు భాషా సెలెక్టర్లలో అది కనిపిస్తుంది.

<a id="cost-tracking"></a>
### ఖర్చు ట్రాకింగ్

ఖర్చు సమాచారాన్ని నిర్వహించడానికి **సెట్టింగులు** > **ఖర్చు ట్రాకింగ్** ని ఉపయోగించండి.

- **మొత్తం ఖర్చు** నడుస్తున్న మొత్తాన్ని చూపిస్తుంది.
- **విలువను నకలు చేయండి** మొత్తాన్ని క్లిప్బోర్డుకు నకలు చేస్తుంది.
- **ఖర్చును రీసెట్ చేయండి** నిల్వ చేయబడిన మొత్తాన్ని సున్నాకి రీసెట్ చేస్తుంది.
- **API కీ ఉపయోగంతో సింక్ చేయండి** OpenRouter ఖాతా ద్వారా నివేదించబడిన ఉపయోగానికి సరిపోయేలా మొత్తాన్ని సెట్ చేస్తుంది (కేవలం OpenRouter).
- **API కీ ఉపయోగం** లభ్యమైతే OpenRouter ఉపయోగ వివరాలను చూపిస్తుంది.
- **ఖర్చు డేటాను తొలగించండి** అన్ని డేటాను లేదా ఎంచుకున్న తేదీ కన్నా పాతదైన ఎంట్రీలను మాత్రమే తొలగిస్తుంది.

**ఖర్చు ట్రాకింగ్:** మీరు OpenRouter మోడల్స్ ఉపయోగించినప్పుడు, యాప్ OpenRouter నుండి డేటా ఆధారంగా మీ వాస్తవ ఉపయోగం మరియు ఖర్చులను చూపిస్తుంది. ఇతర అన్ని సరఫరాదారుల కొరకు, యాప్ ధర OpenRouter ద్వారా ప్రచురించబడిన ధరల ఆధారంగా ఖర్చులను అంచనా వేస్తుంది, ఒకవేళ ధర అందుబాటులో లేకపోతే, అంచనా సున్నా కావచ్చు.

<br/>

> ℹ️ **గమనిక**<br/>
> **అన్ని ఖర్చు పట్టిక అంశాలు మీ సౌకర్యం కొరకు మాత్రమే అంచనాలు, అధికారిక బిల్లింగ్ ప్రకటనలు కాదు.**

<br/>

> ⚠️ **హెచ్చరిక**<br/>
> డేటా తొలగింపును రద్దు చేయలేరు. తొలగించే ముందు, మీ డేటాను బ్యాకప్ చేసుకోండి లేదా [**డాష్‌బోర్డ్** > **అన్ని కాల్స్**](#dashboard-tabs) ద్వారా దిగుమతి చేసుకోండి, అప్పుడు అది శాశ్వతంగా పోతుంది. <br/>
> ప్రతి API కాల్ ఎంట్రీకి సంబంధించిన చరిత్ర కూడా తొలగించబడుతుంది.

<br/>

<a id="transform-prompts"></a>

### రూపాంతరాల కోసం ప్రాంప్ట్‌లు

**సెట్టింగ్స్** > **రూపాంతర ప్రాంప్ట్స్** ఉపయోగించి బ్యాచ్‌గా ప్రాంప్ట్ లను నిర్వహించండి.

మీరు:

- మీరు సేవ్ చేసిన ప్రాంప్ట్లను సమీక్షించవచ్చు
- ప్రాంప్ట్లను తొలగించవచ్చు
- ఫైల్ నుండి ప్రాంప్ట్లను దిగుమతి చేసుకోవచ్చు
- బ్యాకప్ లేదా పంపిణీ కోసం ప్రాంప్ట్లను ఎగుమతి చేయవచ్చు

<br/>

<a id="users"></a>
### వాడుకరులు

**వెబ్: నిర్వాహకుడు మాత్రమే**

వెబ్ వెర్షన్‌లో వాడుకరి ఖాతాలను నిర్వహించడానికి **వాడుకరులు** ఉపయోగించండి. మీరు వాడుకరులను జోడించవచ్చు, వారి వివరాలను నవీకరించవచ్చు, సంకేతపదాలను రీసెట్ చేయవచ్చు మరియు ఖాతాలను తొలగించవచ్చు.

<br/>

<a id="api-config"></a>
### API కాన్ఫిగరేషన్

మద్దతు ఇచ్చే ప్రొవైడర్లు: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI మరియు **Ollama** (బేస్ URL ద్వారా స్థానిక మోడల్స్). మీరు ఉపయోగించే ప్రొవైడర్ల కొరకు మాత్రమే కాన్ఫిగర్ చేయాలి.

**వెబ్ అప్లికేషన్: నిర్వాహకుడు మాత్రమే**

API కీలు సిస్టమ్ లేదా డాకర్ పర్యావరణ వేరియబుల్స్ ద్వారా కాన్ఫిగర్ చేయబడతాయి — వాటిని వెబ్ UIలో ప్రవేశపెట్టరు. ఈ పేజీ ఏ ప్రొవైడర్‌కు కీని కాన్ఫిగర్ చేశారో చూపిస్తుంది మరియు ప్రతి ఒక్కదాన్ని **`పరీక్షించండి`** బటన్‌పై క్లిక్ చేసి పరీక్షించుకోవచ్చు.

<br/>

> ℹ️ **గమనిక**<br/>
> API కీని మార్చడానికి, మీ సిస్టమ్ లేదా డాకర్ కాన్ఫిగరేషన్‌లో పర్యావరణ వేరియబుల్‌ను నవీకరించి సర్వర్ లేదా కంటైనర్‌ను రీస్టార్ట్ చేయండి.

<br/>

**డెస్క్‍టాప్ అప్లికేషన్**

మీరు ఉపయోగించే ప్రతి ప్రొవైడర్ కోసం API కీలను నిల్వ చేయడానికి **API కాన్ఫిగ్** ఉపయోగించండి. Ollama కోసం, API కీ స్థానంలో **బేస్ URL** ని నమోదు చేయండి.


<br/>

> 💡 **సూచన** <br/>
> మీరు API కీని ఉపయోగించకూడదని లేదా వాడకానికి సొమ్ము చెల్లించకూడదని కోరుకుంటే, మీ యంత్రంలో [Ollama డౌన్‌లోడ్](https://ollama.com) చేసి ఉచితంగా స్థానికంగా మోడళ్లను నడపవచ్చు. లేదా, మీరు వారి ఉచిత మోడళ్లను ఉపయోగించడానికి (క్రెడిట్ కార్డు అవసరం లేకుండా) ఉచిత OpenRouter ఖాతాను సృష్టించవచ్చు.

- మీకు అవసరమైన ప్రొవైడర్లను మాత్రమే జోడించండి. **సెట్టింగ్స్** > **మోడళ్లు** లో, ప్రతి మోడల్ ఐడి ప్రొవైడర్తో మొదలవుతుంది (ఉదాహరణకు `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

API కీని జోడించడానికి, విలువను టెక్స్ట్ ఫీల్డ్‌లో టైప్ చేసి **`సేవ్`** బటన్‌పై క్లిక్ చేయండి. ఉన్న కీని మార్చడానికి, **`ఎడిట్`** బటన్‌పై క్లిక్ చేయండి. కీ పనిచేస్తుందో లేదో తనిఖీ చేయడానికి, **`పరీక్షించండి`** బటన్‌పై క్లిక్ చేయండి.

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు ప్రస్తుత API కీ విలువను చూడలేరు. మీరు దానిని **`ఎడిట్`** బటన్ ద్వారా మాత్రమే భర్తీ చేయవచ్చు.
> API కీలు కాన్ఫిగరేషన్ ఫైల్‌లో ఎన్‌క్రిప్ట్ చేసి నిల్వ చేయబడతాయి.

<br/>

OpenRouter కీ పొందడానికి సవివరమైన దశల కొరకు, పైకి [API కీ ఎలా పొందాలి](#how-to-get-an-api-key-desktop-app) చూడండి.

<a id="common-issues"></a>
## సాధారణ సమస్యలు

ఏదైనా ప్రతీకారంగా పనిచేయకపోతే, ముందుగా ఈ పాయింట్లను తనిఖీ చేయండి.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### యాప్ పాఠాన్ని అనువదించదు, తిరిగి రాయదు లేదా రూపాంతరం చేయదు

తనిఖీ చేయండి:

- మీరు టూల్‌బార్‌లో మోడల్‌ను ఎంచుకున్నారా
- [**సెట్టింగ్స్** > **మోడళ్లు**](#models)లో కనీసం ఒక మోడల్ ఉందా
- మీ API సెటప్ పనిచేస్తుందా

మీరు డెస్క్‍టాప్ అప్లికేషన్ ఉపయోగిస్తున్నట్లయితే:

1. [**సెట్టింగ్స్** > **API కాన్ఫిగ్**](#api-config) తెరవండి.
2. కనీసం ఒక API కీ సేవ్ అయ్యిందో తనిఖీ చేయండి.
3. కీ పనిచేస్తుందో నిర్ధారించడానికి ప్రొవైడర్ పక్కన ఉన్న **పరీక్షించండి** పై క్లిక్ చేయండి.

<br/>

<a id="the-model-list-is-empty"></a>
### మోడల్ జాబితా ఖాళీగా ఉంది

[**సెట్టింగ్స్** > **మోడళ్లు**](#models) తెరిచి **తాజాకరించండి** పై క్లిక్ చేయండి.

అవసరమైతే:

- మోడల్ కోసం శోధించండి
- **ఫ్రీ మాత్రమే** ఆన్ చేయండి
- **ఎంచుకున్న మోడళ్లు**కు ఒకటి లేదా అంతకంటే ఎక్కువ మోడళ్లను జోడించండి

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ఫలితం చాలా నెమ్మదిగా ఉంది లేదా చాలా ఖరీదైనది

ఇవి ఏదైనా ఒకటి ప్రయత్నించండి:

- భిన్నమైన మోడల్‌ను ఎంచుకోండి
- తక్కువ ఇన్ పుట్ ఉపయోగించండి
- [**సెట్టింగ్స్** > **జనరల్ సెట్టింగ్స్**](#general-settings)లో **తక్షణ అనువాదం (టైప్ చేసేటప్పుడు)** ఆఫ్ చేయండి
- సులభమైన పనుల కోసం ఉచిత మోడళ్లను ఉపయోగించండి (చూడండి [మోడళ్లు](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ఇంటర్ఫేస్ తప్పు భాషలో ఉంది

[టూల్‌బార్](#toolbar)లో గ్లోబ్ ఐకాన్‌పై క్లిక్ చేసి మీకు ఇష్టమైన **ఇంటర్ఫేస్ భాష** ఎంచుకోండి.

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### పాఠం చాలా చిన్నగా ఉంది లేదా చదవడానికి ఇబ్బందిగా ఉంది

[**సెట్టింగ్స్** > **జనరల్ సెట్టింగ్స్**](#general-settings) తెరిచి మార్చండి:

- **ఫాంట్ ఫ్యామిలీ**
- **పరిమాణం**

<br/>

<a id="dashboard-charts-are-empty"></a>
### డాష్‌బోర్డ్ చార్ట్‌లు ఖాళీగా ఉన్నాయి

ఇవి అయితే సాధారణం:

- మీరు **ఉచిత మోడళ్లను** మాత్రమే ఉపయోగిస్తున్నారు (ఖర్చు చార్ట్‌లు ఖాళీగా ఉంటాయి)
- పిలవడాలు చేశాయి కాలం కనెక్ట్ కాకపోతే ఎంచుకున్న **సమయం ఫిల్టర్** — తనిఖీ చేయడానికి **అన్నీ** ప్రయత్నించండి

**అన్నీ** ఎంచుకున్న తర్వాత కూడా చార్ట్‌లు ఖాళీగా ఉంటే, పిలవడాలు [**చరిత్ర**](#history) లేదా **అన్ని కాల్స్** ట్యాబ్‌లో కనిపిస్తున్నాయని ధృవీకరించండి.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### ఖర్చు "అందుబాటులో లేదు" లేదా తప్పుగా కనిపిస్తుంది

మీరు **OpenRouter** ద్వారా మోడల్‌లను ఉపయోగించినప్పుడు, యాప్ మీ వాస్తవ ఖర్చును OpenRouter నివేదించినట్లుగా చూపిస్తుంది.

**ఇతర ప్రొవైడర్ల** (నేరుగా OpenAI, నేరుగా Anthropic మొదలైనవి) కోసం, ఖర్చు OpenRouter ప్రచురించిన ధరల సమాచారం ఆధారంగా అంచనా వేయబడుతుంది. ఒక మోడల్ కోసం సరిపోయే ధర దొరకకపోతే, ఖర్చు **అందుబాటులో లేదు** గా కనిపిస్తుంది మరియు మీ సమగ్ర మొత్తంలో చేర్చబడదు.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### మొత్తం ఖర్చు నా ప్రొవైడర్ బిల్లుతో సరిపోలలేదు

యాప్ లోని అన్ని ఖర్చు వివరాలు **పరిశీలనకు మాత్రమే**, అధికారిక బిల్లింగ్ పత్రాలు కావు.

మీ OpenRouter వాస్తవ ఖర్చుకు దగ్గరగా మొత్తాన్ని తీసుకురావడానికి, [**సెట్టింగ్స్** > **కాస్ట్ ట్రాకింగ్**](#cost-tracking) ని తెరిచి, **API కీ వాడకంతో సింక్ చేయి** పై క్లిక్ చేయండి.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### సైడ్బార్ నుండి హిస్టరీ పేజీ కనిపించడం లేదు

**ఎగ్జిక్యూషన్ హిస్టరీ ఉంచండి** ఆఫ్ చేయబడి ఉండవచ్చు. [**సెట్టింగ్స్** > **సాధారణ సెట్టింగ్స్**](#general-settings) ని తెరిచి దానిని ప్రారంభించండి. ఇది ప్రారంభించడం మునుపటికి తొలగించబడిన చారిత్రక డేటా పునరుద్ధరించబడదని గమనించండి.

మీ సెషన్ సమయం ముగిసి ఉండవచ్చు. మళ్లీ లాగిన్ అవ్వండి. ఇది తరచుగా జరుగుతుంటే, సెషన్ జీవితకాలం సెట్టింగ్స్ కోసం సర్వర్ కాన్ఫిగరేషన్ ని తనిఖీ చేయండి.

### డాష్‌బోర్డ్ ఇతర వాడుకరుల కోసం ఏ డేటాను ప్రదర్శించదు (వెబ్)

**అడ్మినిస్ట్రేటర్లు** మాత్రమే **వాడుకరి** ఫిల్టర్ ద్వారా అన్ని వాడుకరుల డేటాను చూడగలుగుతారు. సాధారణ వాడుకరులు వారి సొంత కార్యాచరణను మాత్రమే చూస్తారు.

### నేను ఒక ప్రాంప్ట్ మార్చి ఎడిటింగ్ కోల్పోయాను

ఒక ప్రాంప్ట్ ని మార్చుతున్నప్పుడు, ఎప్పుడూ **బ్యాక్ టు రన్** క్లిక్ చేయడానికి ముందు **సేవ్** పై క్లిక్ చేయండి.

<a id="quick-tips"></a>
## త్వరిత సూచనలు

- మీరు [**రిరైట్**](#rewrite) లేదా [**ట్రాన్స్‌ఫార్మ్**](#transform) కి వెళ్లే ముందు మీ సెటప్ పనిచేస్తుందని నిర్ధారించుకోవడానికి [**అనువాదం**](#translate) తో ప్రారంభించండి.
- రోజువారీ పదబంధాల మెరుగుపరచడానికి [**రిరైట్**](#rewrite) ఉపయోగించండి.
- ప్రత్యేక పని కోసం పునరావృత పనిప్రవాహాన్ని కలిగి ఉండాలని మీరు కోరుకున్నప్పుడు [**ట్రాన్స్‌ఫార్మ్**](#transform) ఉపయోగించండి.
- మీరు ఉపయోగం మరియు ఖర్చుపై దృష్టి ఉంచాలనుకుంటే [**డాష్‌బోర్డ్**](#dashboard) ఉపయోగించండి.
- గత కార్యకలాపాలు మరియు వాటి పూర్తి ఇన్‌పుట్/అవుట్‌పుట్ టెక్స్ట్ లను సమీక్షించడానికి [**హిస్టరీ**](#history) ఉపయోగించండి.
- మీరు సురక్షితంగా నిల్వ చేయాలనుకునే ప్రాంప్ట్ పుస్తకాన్ని నిర్మాణం చేస్తున్నట్లయితే (చూడండి [ప్రాంప్ట్‌లను మార్చండి](#transform-prompts)) లేదా మరింతమందితో పంచుకోవాలనుకుంటే ప్రాంప్ట్‌లను ఆదా చేయండి.
