# వాడుకరి మార్గదర్శకం

<br/>

<a id="introduction"></a>
## పరిచయం

ట్రాన్స్‌రీవర్ట్ మూడు ప్రధాన మార్గాల్లో పాఠ్యంతో పనిచేయడంలో సహాయపడుతుంది:

- **అనువదించు** - ఒక భాష నుండి మరొక భాషలోకి పాఠ్యాన్ని మార్చడం.
- **రీరైట్** - స్పష్టంగా, సంక్షిప్తంగా లేదా మరింత ఔపచారికంగా వంటి వేరొక శైలిలో పాఠ్యాన్ని పునరావృతం చేయడం.
- **ట్రాన్స్‌ఫార్మ్** - ప్రాంప్ట్‌లు అని పిలువబడే కస్టమ్ AI సూచనలను ఉపయోగించి పాఠ్యాన్ని ప్రాసెస్ చేయడం.

<br/>

ఇది స్థాపించి నడుస్తున్నప్పుడు అప్లికేషన్ ఉపయోగించడం ఎలాగో ఈ మార్గదర్శకం వివరిస్తుంది. స్థాపన దశల కోసం, ప్రధాన **[README](README.te.md)** చూడండి.

<br/>

> ℹ️ **గమనిక**<br/>
> ట్రాన్స్‌రీవర్ట్ Windows మరియు Linux కోసం డెస్క్‌టాప్ అప్లికేషన్ గాను, స్వంతంగా హోస్ట్ చేయబడిన వెబ్ అప్లికేషన్ గాను అందుబాటులో ఉంది. ఈ మార్గదర్శకం అప్లికేషన్ యొక్క రోజువారీ ఉపయోగాన్ని దృష్టిలో పెట్టుకుంటుంది. ఒక వెర్షన్‌కు మాత్రమే వర్తించే ఏదైనా స్పష్టంగా గుర్తించబడుతుంది.

## మీరు ప్రారంభించే ముందు

Transrewrt ఉపయోగించడానికి, మీరు కనీసం ఒక ఏఐ ప్రదాతకు ప్రాప్యత కలిగి ఉండాలి. మద్దతు ఇచ్చే ప్రదాతలు: [OpenRouter](https://openrouter.ai) (ఇది చాలా మోడల్‌లను సమాహారం చేస్తుంది), OpenAI, యాంథ్రోపిక్, గూగుల్ జెమిని, డీప్సీక్, గ్రోక్, మిస్ట్రల్, ఎక్స్ఏఐ, Cerebras మరియు స్థానిక మోడల్‌ల కోసం [Ollama](https://ollama.com).

మీరు ప్రారంభించడానికి చెల్లింపు మోడల్‌ను ఎంచుకోవలసిన అవసరం లేదు. మీరు మీ OpenRouter API కీని జోడించిన వెంటనే, అప్లికేషన్ అంతర్నిర్మిత **ఉచిత** OpenRouter ఎంపికను స్వయంచాలకంగా ప్రారంభిస్తుంది. ఇది మీరు వెంటనే పాఠ్యాన్ని అనువదించడం, రీరైట్ చేయడం మరియు ట్రాన్స్‌ఫార్మ్ చేయడం ప్రారంభించడానికి అనుమతిస్తుంది. ప్రత్యామ్నాయంగా, మీరు Cerebras, గూగుల్, గ్రోక్ లేదా మిస్ట్రల్ ఏఐ నుండి ఉచిత API కీని పొందవచ్చు.

సులభ భాషలో:

- ఒక **మోడల్** పని చేసే ఏఐ ఇంజిన్. మోడల్‌లను **ప్రదాత ప్రిఫిక్స్**తో పట్టికలో చేర్చారు (ఉదాహరణకు `openrouter/…`, `openai/…`, `ollama/…`).
- ఒక **API కీ** (లేదా Ollama కోసం, ఒక **బేస్ URL**) అప్లికేషన్ ఆ ప్రదాతను చేరుకునే విధానం.

మీరు **డెస్క్‌టాప్ అప్లికేషన్** ఉపయోగిస్తుంటే, మీరు ఉపయోగించే ప్రతి ప్రదాత కోసం [**సెట్టింగ్‌లు** > **API కాన్ఫిగ్**](#api-config)లో కీలను జోడించండి. కేవలం OpenRouter ఉపయోగించడానికి, క్రింద [API కీని పొందడం ఎలా](#how-to-get-an-api-key-desktop-app) చూడండి. మీరు API కీని ఉపయోగించకూడదనుకుంటే, [ollama.com](https://ollama.com) నుండి Ollamaని ఇన్‌స్టాల్ చేసి, `translategemma:4b` వంటి స్థానిక మోడల్‌లను ఉపయోగించవచ్చు.

మీరు **వెబ్ వెర్షన్** ఉపయోగిస్తుంటే, సర్వర్ యజమాని పర్యావరణ వేరియబుల్స్ ద్వారా ప్రదాతలను కాన్ఫిగర్ చేస్తారు, కాబట్టి మీరు అప్లికేషన్‌లో నేరుగా API కీలను నమోదు చేయలేరు.

<a id="how-to-get-an-api-key-desktop-app"></a>
### ఉచిత OpenRouter API కీని పొందడం ఎలా (డెస్క్‌టాప్ అప్లికేషన్)

మీరు డెస్క్‌టాప్ అప్లికేషన్ ఉపయోగిస్తుంటే, ఈ దశలను అనుసరించండి:

1. మీ వెబ్ బ్రౌజర్‌లో [OpenRouter](https://openrouter.ai)కి వెళ్లండి.
2. ఖాతాను సృష్టించండి లేదా సైన్ ఇన్ అవ్వండి.
3. [Keys](https://openrouter.ai/keys) పేజీని తెరవండి.
4. కొత్త API కీని సృష్టించడానికి బటన్‌పై క్లిక్ చేయండి.
5. మీరు తర్వాత దానిని గుర్తించగలిగేలా కీకి పేరు ఇవ్వండి.
6. కొత్త API కీని కాపీ చేయండి.
7. Transrewrtకి తిరిగి వెళ్లి **సెట్టింగ్‌లు** > **API కాన్ఫిగ్** తెరవండి.
8. **OpenRouter API కీ**లోకి కీని అతికించండి (**సెట్టింగ్‌లు** > **API కాన్ఫిగ్** కింద).
9. అది పనిచేస్తుందో లేదో నిర్ధారించడానికి **OpenRouter కీని పరీక్షించండి**పై క్లిక్ చేయండి.

## ప్రారంభించడం

మీరు Transrewrtని మొదటిసారి ఉపయోగిస్తున్నట్లయితే, ఈ క్రమాన్ని అనుసరించండి:

1. అప్లికేషన్‌ను తెరవండి.
2. అవసరమైతే గ్లోబ్ ఐకాన్ నుండి మీ **ఇంటర్‌ఫేస్ భాష**ను ఎంచుకోండి.
3. మీరు **డెస్క్‌టాప్ అప్లికేషన్**లో ఉంటే, [**సెట్టింగ్‌లు** > **API కాన్ఫిగ్**](#api-config) తెరవండి, కనీసం ఒక ప్రదాత కోసం API కీని జోడించండి (ఉదాహరణకు OpenRouter) మరియు అది పనిచేస్తుందో లేదో నిర్ధారించడానికి **పరీక్ష**పై క్లిక్ చేయండి.
4. [**సెట్టింగ్‌లు** > **మోడల్‌లు**](#models) తెరవండి మరియు **ఎంపిక చేసిన మోడల్‌లు**కు ఒకటి లేదా అంతకంటే ఎక్కువ మోడల్‌లను జోడించండి.
5. [**సెట్టింగ్‌లు** > **భాషలు**](#languages) తెరవండి మరియు మీరు ఎక్కువగా ఉపయోగించే భాషలు మొదట కనిపించాలనుకుంటే **పై భాషలు** ఎంచుకోండి.
6. **అనువదించు**కి వెళ్లి ప్రతిదీ పనిచేస్తుందని నిర్ధారించడానికి సరళ అనువాదాన్ని నడుపుతారు.
7. అది పనిచేసిన తర్వాత, **రీరైట్** మరియు తర్వాత **ట్రాన్స్‌ఫార్మ్**ని ప్రయత్నించండి.

ఈ క్రమం ముఖ్యమైనది. ఇది అప్లికేషన్‌కు పనిచేసే API కనెక్షన్ లేదా ఎంపిక చేసిన మోడల్ లేకుండా పనిని ప్రారంభించడానికి ప్రయత్నించడం వంటి సాధారణ మొదటి ఉపయోగ సమస్యను నివారిస్తుంది.

## విండో యొక్క ప్రధాన భాగాలు

అప్లికేషన్ మూడు ప్రధాన ప్రాంతాలుగా విభజించబడింది:

- ఎడమ వైపు ఉన్న **సైడ్‌బార్**.
- పైన ఉన్న **టూల్‌బార్**.
- మధ్యలో ఉన్న **పని ప్రాంతం**.

### టూల్‌బార్

మీరు అప్లికేషన్‌లో ఎక్కడ ఉన్నారో బట్టి టూల్‌బార్ కొంచెం మారుతుంది.

- ఎడమ వైపు, ప్రస్తుత పేజీ పేరు చూపబడుతుంది.
- కుడి వైపు, **మోడల్ సెలెక్టర్** మరియు **ఇంటర్‌ఫేస్ భాష** నియంత్రణ చూపబడుతుంది.

**మోడల్ సెలెక్టర్** ప్రస్తుత పని కోసం ఏ ఏఐ ఇంజిన్‌ను ఉపయోగించాలో ఎంచుకోవడానికి మీకు అనుమతిస్తుంది.

![Model selector](../images/screenshots/te/model-selector.png)

కొన్ని ఉచిత మోడల్‌లు ఎల్లప్పుడూ అందుబాటులో ఉండవు—కొన్నిసార్లు అవి ఆఫ్‌లైన్‌లో ఉంటాయి లేదా ఉపయోగం పరిమితి ఉంటుంది. ఇలా జరిగితే, అప్లికేషన్ ఆ మోడల్‌ను మీ అందుబాటు జాబితా నుండి స్వయంచాలకంగా తొలగిస్తుంది. ఏయే మోడల్‌లు కనిపించాలో నియంత్రించడానికి, [**సెట్టింగ్‌లు** > **మోడల్‌లు**](../{{URL_PLACE HOLDER_0}})కు వెళ్లి మీ మోడల్ జాబితాను సవరించండి.
 టూల్‌బార్‌లో మోడల్ పేరుకు ఎడమవైపు ఉన్న ప్రదాత ఐకాన్‌పై క్లిక్ చేయడం ద్వారా మీరు మోడల్ సెట్టింగ్‌లను నేరుగా తెరవవచ్చు.

<br/>

**గ్లోబ్ ఐకాన్ + భాషా కోడ్** మెనులు మరియు బటన్ల వంటి అప్లికేషన్ ఇంటర్‌ఫేస్ భాషను మారుస్తుంది. ఇది **అనువాదం**లో ఉపయోగించే అనువాద భాషలను **మార్చదు**.

![Interface language selector](../images/screenshots/te/language-selector.png)

<a id="input-and-output-panels"></a>
### ఇన్‌పుట్ మరియు అవుట్‌పుట్ ప్యానెల్స్

చాలా వర్క్‌స్పేస్‌లు ఎడమ వైపు **ఇన్‌పుట్** ప్యానెల్ మరియు కుడి వైపు **అవుట్‌పుట్** ప్యానెల్ ఉపయోగిస్తాయి.

ప్రతి ప్యానెల్ కూడా చూపిస్తుంది:

| **ఇన్‌పుట్**                                                          | **అవుట్‌పుట్**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - అక్షరాల సంఖ్య <br/>- పదాల సంఖ్య <br/>- పేరాల సంఖ్య   <br/> | - పని ఎంత సమయం పడింది<br/>- **TPS** (సెకనుకు టోకెన్‌లు)<br/>- అక్షరాలు, పదాలు మరియు పేరాల సంఖ్యలు<br/>- ఉపయోగించిన మోడల్ |

మీరు సాంకేతిక పదాల గురించి ఆలోచిస్తున్నట్లయితే:

- **టోకెన్** అంటే చిన్న పాఠ్య ముక్క. దీన్ని పదంలో ఒక భాగం లేదా చిన్న పదంగా భావించవచ్చు.
- **TPS** అంటే మోడల్ ప్రతి సెకనుకు ప్రాసెస్ చేసిన ఆ పాఠ్య ముక్కల సంఖ్య.

<br/>

ప్రతి పని యొక్క ఖర్చు (అందుబాటులో ఉంటే) మరియు మొత్తం ఖర్చును [**సెట్టింగ్‌లు** > **సాధారణ సెట్టింగ్‌లు**](#general-settings) వద్ద `చర్యలపై ఖర్చు సమాచారాన్ని చూపించు` ఎంపికను సక్రియం చేయడం ద్వారా మీరు పర్యవేక్షించవచ్చు.

<a id="translate"></a>
## అనువాదం

మీరు ఒక భాష నుండి మరొక భాషకు పాఠ్యాన్ని మార్చాలనుకున్నప్పుడు **అనువాదం** ఉపయోగించండి.

![Translate workspace](../images/screenshots/te/translate.png)

<br/>

<a id="translate-text"></a>
### పాఠ్యాన్ని అనువదించు

1. **అనువాదం** తెరవండి.
2. **నుండి** లో ఒక భాషను ఎంచుకోండి.
3. **కు** లో ఒక భాషను ఎంచుకోండి.
4. టూల్‌బార్‌లో ఒక మోడల్‌ను ఎంచుకోండి.
5. **ఇన్‌పుట్** లో పాఠ్యాన్ని టైప్ చేయండి లేదా అతికించండి.
6. **అనువదించు**పై క్లిక్ చేయండి.
7. **అవుట్‌పుట్** లో ఫలితాన్ని చదవండి.
8. ఫలితాన్ని కాపీ చేయాలనుకుంటే కాపీ బటన్ ఉపయోగించండి.

<br/>

<a id="language-selection"></a>
### భాష ఎంపిక

- **నుండి** ప్రత్యేక భాష లేదా **భాషను గుర్తించు** కావచ్చు.
- **కు** మీరు ఫలితాన్ని కావలసిన భాష.

మీరు ఎంచుకున్న **ప్రధాన భాషలు** జాబితా పైన కనిపిస్తాయి. మీరు వాటిని [**సెట్టింగ్‌లు** > **భాషలు**](#languages) వద్ద సెట్ చేయవచ్చు.

<br/>

<a id="helpful-translation-settings"></a>
### ఉపయోగకరమైన అనువాద సెట్టింగ్‌లు

[**సెట్టింగ్‌లు** > **సాధారణ సెట్టింగ్‌లు**](#general-settings)లో, అనువాదం ఎలా పనిచేస్తుందో మీరు మార్చవచ్చు:

- **పేస్ట్ చేసినప్పుడు ఆటో-అనువాదం** మీరు పాఠ్యాన్ని పేస్ట్ చేసిన వెంటనే అనువాదాన్ని ప్రారంభిస్తుంది.
- **ఫలితాన్ని క్లిప్‌బోర్డ్‌కు ఆటో-కాపీ చేయి** విజయవంతమైన అమలు తర్వాత ఫలితాన్ని స్వయంచాలకంగా కాపీ చేస్తుంది.
- **రియల్-టైమ్ అనువాదం (టైప్ చేస్తున్నప్పుడు)** మీరు టైప్ చేస్తున్నప్పుడు అనువాదాలను ప్రారంభిస్తుంది.
- **టైమౌట్ (ms)** రియల్-టైమ్ అనువాదాన్ని ప్రారంభించే ముందు అప్లికేషన్ ఎంతకాలం వేచి ఉంటుందో నియంత్రిస్తుంది.
- **Enter** మీరు `Enter` నొక్కినప్పుడు ఏమి జరుగుతుందో నియంత్రిస్తుంది:

<a id="rewrite"></a>
## రీరైట్

ప్రధాన అర్థాన్ని మార్చకుండా పదబంధాలను మెరుగుపరచాలనుకున్నప్పుడు **రీరైట్** ఉపయోగించండి.

![Rewrite workspace](../images/screenshots/te/rewrite.png)

ఇది కింది వాటికి ఉపయోగకరం:

- స్పెల్లింగ్ మరియు వ్యాకరణాన్ని సరిచేయడం (**స్పెల్లింగ్ & గ్రామర్ తనిఖీ**)
- పాఠ్యాన్ని స్పష్టంగా చేయడం (**స్పష్టత మెరుగుపరచు**)
- ఒకే అమలులో అనేక విభిన్న పునర్నిర్మాణాలు (**ప్రత్యామ్నాయ సంస్కరణలు**)
- పాఠ్యాన్ని మరింత ఔపచారికంగా లేదా అనౌపచారికంగా మార్చడం (**ఔపచారికం** / **అనౌపచారికం**)
- పాఠ్యాన్ని కుదించడం లేదా విస్తరించడం (**కుదించు** / **విస్తరించు**)
- పాఠ్యం మరింత సాంకేతికంగా అనిపించేలా చేయడం (**సాంకేతికంగా మార్చు**)

> మీరు "**స్పెల్లింగ్ & గ్రామర్ తనిఖీ**" మోడ్‌ను ఉపయోగించినప్పుడు, అవుట్‌పుట్ ప్యానెల్‌లో (**కాపీ** పక్కన) **మార్పులను చూపించు** స్విచ్ కనిపిస్తుంది.
> మీ పాఠ్యానికి వర్తించిన ప్రత్యేక సర్దుబాట్లను చూపించడానికి లేదా దాచడానికి దాన్ని ఆన్ లేదా ఆఫ్ చేయండి.

<a id="transform"></a>
## ట్రాన్స్‌ఫార్మ్

మీరు AI కస్టమ్ సూచనల సమితిని అనుసరించాలనుకున్నప్పుడు **ట్రాన్స్‌ఫార్మ్** ఉపయోగించండి.

![Transform workspace](../images/screenshots/te/transform.png)

ఇది అప్లికేషన్ యొక్క అత్యంత సౌలభ్యమైన ప్రాంతం. మీరు దీన్ని కింది పనుల కోసం ఉపయోగించవచ్చు:

- గమనికలను సంగ్రహించడం
- సున్నితమైన పాఠ్యాన్ని పాలిష్ చేసిన ఇమెయిల్‌గా మార్చడం
- కీలక పాయింట్లను ఉపసంహరించుకోవడం
- పాఠ్యాన్ని ప్రత్యేక ఫార్మాట్‌లోకి మార్చడం
- ఇన్‌పుట్ పాఠ్యంతో ఏదైనా ఇతర కస్టమ్ కార్యాచరణ

<br/>

<a id="run-an-existing-prompt"></a>
### ఉన్న ప్రాంప్ట్‌ను అమలు చేయండి

1. **ట్రాన్స్‌ఫార్మ్** తెరవండి.
2. ప్రాంప్ట్ జాబితా నుండి ఒక ప్రాంప్ట్‌ను ఎంచుకోండి.
3. **లక్ష్యం** భాష బాక్స్ కనిపిస్తే, కావలసినట్లయితే భాషను ఎంచుకోండి.
4. **ఇన్‌పుట్** లోకి పాఠ్యాన్ని టైప్ చేయండి లేదా పేస్ట్ చేయండి.
5. **ట్రాన్స్‌ఫార్మ్** పై క్లిక్ చేయండి.
6. **అవుట్‌పుట్** లో ఫలితాన్ని చదవండి.

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### మీకు ఇంకా ప్రాంప్ట్‌లు లేకపోతే

మీ ప్రాంప్ట్ జాబితా ఖాళీగా ఉంటే, ట్రాన్స్‌ఫార్మ్ వర్క్‌స్పేస్‌లో **నమూనా ప్రాంప్ట్‌లు లోడ్ చేయి**పై క్లిక్ చేయండి. ఎగుమతి/దిగుమతి వరుసలో [**సెట్టింగ్‌లు** > **ట్రాన్స్‌ఫార్మ్ ప్రాంప్ట్‌లు**](#transform-prompts) లో ఇదే నియంత్రణ ఎల్లప్పుడూ అందుబాటులో ఉంటుంది. రెండూ మీరు త్వరగా ప్రారంభించడానికి అంతర్నిర్మిత ఉదాహరణలను జోడిస్తాయి.

<br/>

> ℹ️ **గమనిక**<br/>
> నమూనా ప్రాంప్ట్‌లు ఇంగ్లీష్‌లో అందించబడతాయి. వాటిని లోడ్ చేసిన తర్వాత, మీరు ప్రాంప్ట్‌ను సవరించి, దాన్ని మీ భాషలోకి అనువదించడానికి **అనువాదం ప్రాంప్ట్** ఉపయోగించవచ్చు.

<br/>

<a id="create-a-prompt-quickly"></a>
### త్వరగా ప్రాంప్ట్‌ను సృష్టించండి

ప్రాంప్ట్‌ను సృష్టించడానికి అతి వేగవంతమైన మార్గం:

1. **కొత్త ప్రాంప్ట్**పై క్లిక్ చేయండి.
2. **ప్రాంప్ట్‌ని సృష్టించండి**పై క్లిక్ చేయండి.
3. మీరు ప్రాంప్ట్ ఏమి చేయాలనుకుంటున్నారో వివరించండి.
4. ఒక మోడల్‌ను ఎంచుకోండి.
5. మీ కోసం డ్రాఫ్ట్‌ను సృష్టించడానికి అప్లికేషన్‌ను అనుమతించండి.
6. డ్రాఫ్ట్‌ను సమీక్షించి **సేవ్ చేయి**పై క్లిక్ చేయండి.

![Generate prompt](../images/screenshots/te/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### ప్రాంప్ట్ ని సవరించు

మీరు ప్రాంప్ట్ ని సృష్టించినప్పుడు లేదా సవరించినప్పుడు, ఎడమ వైపు ఎడిటర్ కనిపిస్తుంది మరియు కుడి వైపు పరీక్షా ప్రాంతం కనిపిస్తుంది.

![Transform prompt editor](../images/screenshots/te/transform-prompt-edit.png)

ప్రధాన ఫీల్డ్‌లు:

- **ప్రాంప్ట్ పేరు**: ప్రాంప్ట్ జాబితాలో చూపబడే పేరు.
- **ప్రాంప్ట్ సూచనలు (ఐచ్ఛికం)**: ప్రాంప్ట్ ని అమలు చేసినప్పుడు వాడుకరికి చూపబడే సూచన.
- **మోడల్ పాత్ర**: AI కి కేటాయించిన సమగ్ర పాత్ర, ఉదాహరణకు 'మీరు ఒక సహాయక సహాయకుడు'.
- **మోడల్ సూచనలు (ఒక్కో పంక్తికి ఒకటి)**: AI అనుసరించాలనుకున్న ప్రత్యేక నియమాలు.
- **అవుట్‌పుట్ వివరణ**: 'సారాంశం' లేదా 'రీరైట్' వంటి ఫలితాన్ని సూచించే చిన్న పదం.
- **ఉష్ణోగ్రత (0.0 → 1.0)**: మోడల్ ఎలా ప్రవర్తిస్తుందో; క్రింద చూడండి.
- **లక్ష్య భాష అడగండి**: ప్రాంప్ట్ ని అమలు చేసినప్పుడు లక్ష్య భాష ఎంపికను జోడిస్తుంది.

**ఉష్ణోగ్రత** అనే సాంకేతిక పదం మీకు కొత్తదైతే, దీనిని ఇలా ఆలోచించండి:

- **తక్కువ** ఉష్ణోగ్రత స్థిరమైన, ఊహించదగిన ఫలితాలను ఇస్తుంది.
- **ఎక్కువ** ఉష్ణోగ్రత ఎక్కువ వైవిధ్యం మరియు సృజనాత్మకతను ఇస్తుంది.

మీరు క్రింది వాటిని కూడా ఉపయోగించవచ్చు:

- **`ప్రాంప్ట్ ని సృష్టించు`** సరళమైన వివరణ నుండి కొత్త డ్రాఫ్ట్ ని సృష్టించడానికి
- **`ప్రాంప్ట్ ని మెరుగుపరచు`** ఇప్పటికే ఉన్న ప్రాంప్ట్ ని మెరుగుపరచడానికి
- **`ప్రాంప్ట్ ని అనువదించు`** ప్రాంప్ట్ ఫీల్డ్‌లను అనువదించడానికి

<br/>

> ⚠️ **హెచ్చరిక**<br/>
> **`వెనక్కి ప్రారంభించు`** పై క్లిక్ చేయడానికి ముందు **`సేవ్`** పై క్లిక్ చేయండి. మీరు సేవ్ చేయకుండా వెనక్కి వెళితే, మీ మార్పులు కోల్పోతాయి.

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ఉపయోగించే ముందు ప్రాంప్ట్ ని పరీక్షించండి

కుడి వైపు ఉన్న పరీక్షా ప్యానెల్ మీరు ప్రతిరోజు పనిలో ఉపయోగించే ముందు మీ ప్రాంప్ట్ ని నమూనా పాఠ్యంతో పరీక్షించడానికి అనుమతిస్తుంది.

ఇది క్రింది సందర్భాలలో ఉపయోగకరం:

- మీరు కొత్త ప్రాంప్ట్ ని రూపొందిస్తున్నప్పుడు
- మీరు ప్రాంప్ట్ యొక్క రెండు వెర్షన్‌లను పోల్చుతున్నప్పుడు
- మీరు టోన్, పొడవు లేదా అవుట్‌పుట్ ఫార్మాట్ ని తనిఖీ చేయాలనుకున్నప్పుడు

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు [**సెట్టింగ్‌లు** > **ట్రాన్స్‌ఫార్మ్ ప్రాంప్ట్‌లు**](#transform-prompts) లో సేవ్ చేసిన ప్రాంప్ట్‌లను ఎగుమతి చేసుకోవచ్చు మరియు దిగుమతి చేసుకోవచ్చు.

<a id="dashboard"></a>
## డ్యాష్‌బోర్డ్

మీరు యాప్ ని ఎంత ఉపయోగిస్తున్నారో మరియు దాని ఖర్చు ఎంత ఉందో (చెల్లింపు మోడల్‌ల కోసం) చూడటానికి **డ్యాష్‌బోర్డ్** ని ఉపయోగించండి.

![Dashboard summary](../images/screenshots/te/dashboard-summary.png)

<br/>

> ℹ️ **గమనిక**<br/>
> మీరు **ఉచిత** మోడల్‌లను మాత్రమే ఉపయోగిస్తే, **ఖర్చు** మొత్తాలు సున్నాగా ఉండవచ్చు మరియు ఖర్చు-ఆధారిత సారాంశాలు ఖాళీగా కనిపించవచ్చు. **సారాంశం**, **కాలక్రమేణా ఉపయోగం** మరియు **మోడల్ ద్వారా ఉపయోగం** ఎంచుకున్న కాలంలో మీరు క్రియాశీలకంగా ఉన్నప్పుడు **కాల్స్ సంఖ్యలను** (అనువదించు, రీరైట్ మరియు ట్రాన్స్‌ఫార్మ్) చూపిస్తాయి.

<br/>

<a id="filter-the-data"></a>
### డేటాను ఫిల్టర్ చేయండి

సమయ పరిధిని మార్చడానికి పైన ఉన్న ఫిల్టర్ బటన్‌లను ఉపయోగించండి.

![Dashboard filters](../images/screenshots/te/dashboard-filter.png)

<br/>

> ℹ️ **గమనిక**<br/>
> **వాడుకరి** ఫిల్టర్ వెబ్ వెర్షన్‌లో మాత్రమే నిర్వాహకులకు కనిపిస్తుంది. సాధారణ వినియోగదారులు ఈ ఫిల్టర్‌ను చూడరు మరియు డెస్క్‌టాప్ అప్లికేషన్‌లో ఇది అందుబాటులో ఉండదు.

<br/>

<a id="dashboard-tabs"></a>
### డ్యాష్‌బోర్డ్ ట్యాబ్‌లు

- **సారాంశం** వాడకం మరియు ఖర్చు గురించి సమగ్ర సమాచారాన్ని అందిస్తుంది. ఇది **కాలక్రమేణా ఉపయోగం** (**అనువాదం**, **రీరైట్**, మరియు **ట్రాన్స్‌ఫార్మ్** కోసం రోజుకు మొత్తం కాల్ కౌంట్లు పేరుకుపోయినవి) మరియు **మోడల్ ద్వారా ఉపయోగం** (**మోడల్ ప్రకారం మొత్తం కాల్స్**, ట్రాన్స్‌ఫార్మ్ సహా) లను చూపిస్తుంది.
- **వాడకం ప్రకారం** అనువాద భాష, రీరైట్ మోడ్ మరియు ట్రాన్స్‌ఫార్మ్ ప్రాంప్ట్ ద్వారా కార్యాచరణను విభజిస్తుంది.
- **మోడల్ వారీగా** మీరు ఉపయోగించిన మోడల్‌లు మరియు వాటి ఖర్చు గురించి చూపిస్తుంది.
- **రోజు వారీగా** రోజువారీ మొత్తాలను చూపిస్తుంది.
- **అన్ని కాల్స్** పూర్తి కాల్ చరిత్రను చూపిస్తుంది మరియు దానిని ఎగుమతి చేయడానికి అనుమతిస్తుంది.

<br/>

<a id="export-data"></a>
### డేటాను ఎగుమతి చేయండి

డ్యాష్‌బోర్డ్ పట్టికలు కింది ఫార్మాట్‌లలో డేటాను ఎగుమతి చేయగలవు:

- **జెసన్**
- **సిఎస్వి**
- **ఎక్స్‌ఎల్‌ఎస్‌ఎక్స్**

మీరు అప్లికేషన్ వెలుపల కార్యాచరణను సమీక్షించాలనుకుంటే లేదా నివేదికను పంచుకోవాలనుకుంటే ఇది ఉపయోగకరంగా ఉంటుంది.

### మోడల్ కోసం నిల్వ చేసిన రికార్డ్‌లను తొలగించండి

**మోడల్ వారీగా** లేదా **అన్ని కాల్స్** లో, "చెత్తబుట్ట" చిహ్నాన్ని క్లిక్ చేయడం ద్వారా మీరు ఒక మోడల్ కోసం నిల్వ చేసిన రికార్డ్‌లను తొలగించవచ్చు.

> ⚠️ **హెచ్చరిక**<br/>
> నిల్వ చేసిన రికార్డ్‌లను తొలగించడం రద్దు చేయబడదు. మీకు ఆ చరిత్ర ఇక అవసరం లేదని ఖచ్చితంగా తెలిసినప్పుడు మాత్రమే దీన్ని ఉపయోగించండి.

అన్ని డేటాను తొలగించడానికి లేదా వాటి వయస్సు ఆధారంగా రికార్డ్‌లను తొలగించడానికి, [**సెట్టింగ్‌లు** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) కి వెళ్లండి. అక్కడ మీరు నిల్వ చేసిన అన్ని డేటాను లేదా నిర్దిష్ట తేదీ కంటే పాతది మాత్రమే తొలగించడానికి ఎంపికలు కనుగొంటారు.

<a id="general-settings"></a>
### సాధారణ సెట్టింగ్‌లు

టైపింగ్ ప్రవర్తనను, **చరిత్ర** కోసం అమలు వివరాలు నిల్వ చేయబడతాయో లేదో మరియు రూపాన్ని నియంత్రించడానికి **సాధారణ సెట్టింగ్‌లు** ఉపయోగించండి.

**వర్తనం**

- **ENTER కోసం వర్తనం** `Enter` బటన్ పనిని నడుపుతుందో లేదా కొత్త పంక్తిని చొప్పిస్తుందో ఎంచుకుంటుంది.
- **పేస్ట్ చేసినప్పుడు ఆటో-అనువాదం** మీరు పాఠ్యాన్ని పేస్ట్ చేసిన వెంటనే అనువాదాన్ని ప్రారంభిస్తుంది.
- **ఫలితాన్ని క్లిప్‌బోర్డ్‌కు ఆటో-కాపీ చేయి** విజయవంతమైన ఫలితాలను స్వయంచాలకంగా కాపీ చేస్తుంది.
- **రియల్-టైమ్ అనువాదం (టైప్ చేస్తున్నప్పుడు)** మీరు టైప్ చేస్తున్నప్పుడే అనువాదం చేస్తుంది.
- **సమయం ముగిసింది (ms)** రియల్-టైమ్ అనువాదానికి వేచి ఉండే సమయాన్ని సెట్ చేస్తుంది.

**చరిత్ర**

- **అమలు చరిత్రన ఉంచండి** పక్కటి ప్యానెల్ [**చరిత్ర**](#history) వీక్షణ కోసం ప్రతి అనువాదం, రీరైట్ మరియు ట్రాన్స్‌ఫార్మ్ **ఇన్‌పుట్ మరియు అవుట్‌పుట్ టెక్స్ట్** నిల్వ చేస్తుందో లేదో నియంత్రిస్తుంది. దీన్ని ఆపితే ధృవీకరణ అడుగుతుంది; మీరు ధృవీకరిస్తే, నిల్వ చేసిన చరిత్ర పాఠ్యం డేటాబేస్ నుండి తొలగించబడుతుంది.
- **చరిత్ర డేటన తొలగించండి** వయస్సు ప్రకారం (ఉదాహరణకు కొన్ని నెలల కంటే పాతది లేదా **మొత్తం డేటా (క్లియర్)**) నిల్వ చేసిన పాఠ్యాన్ని **డేటాను తొలగించు** ఉపయోగించి తొలగించడానికి అనుమతిస్తుంది. ఇది **చరిత్ర** వీక్షణ కోసం సేవ్ చేసిన అమలు పాఠ్యాన్ని మాత్రమే ప్రభావితం చేస్తుంది; ఇది ఖర్చు లేదా ఉపయోగ మొత్తాలను **తొలగించదు**. **ఖర్చు** డేటాను తొలగించడానికి లేదా తగ్గించడానికి, [**సెట్టింగ్‌లు** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) ఉపయోగించండి.

**రూపం**

- **చర్యలపై ఖర్చు సమాచారాన్ని చూపించండి** ఆపరేషన్ ప్రతి ఖర్చు (అందుబాటులో ఉంటే) మరియు అనువాదం, రీరైట్ మరియు ట్రాన్స్‌ఫార్మ్ అవుట్‌పుట్ ప్యానెల్స్ పై మొత్తం ఖర్చు ప్రదర్శనను నియంత్రిస్తుంది.
- **ఖర్చు భిన్నం అంకెలు** ఖర్చు దశాంశాలు ఎలా ప్రదర్శించబడతాయో మారుస్తుంది.
- **వెబ్ మాత్రమే:** **యాప్ చుట్టూ మార్జిన్ చూపించు** ఇంటర్ఫేస్ చుట్టూ అదనపు స్థలాన్ని జోడిస్తుంది.
- **ఫాంట్ కుటుంబం** పాఠ్య ప్యానెల్స్ లో రాయడానికి ఫాంట్ ను మారుస్తుంది.
- **పరిమాణం** ఫాంట్ పరిమాణాన్ని మారుస్తుంది.

**కాన్ఫిగరేషన్ బ్యాకప్**

- **బ్యాకప్‌లో ఉపయోగం సమాచారాన్ని చేర్చండి** — ప్రారంభించినప్పుడు, ZIP అమలు చరిత్ర మరియు API కాల్ డేటాను కూడా కలిగి ఉంటుంది.
- **కాన్ఫిగరేషన్ బ్యాకప్ చేయండి** — `config.json`, `state.json`, ఐచ్ఛిక ఎన్‌క్రిప్షన్ కీ, వాడుకరులు, ప్రాధాన్యతలు, కస్టమ్ ప్రాంప్ట్‌లు మరియు మీరు ఎంచుకున్నట్లయితే ఉపయోగ డేటాతో కూడిన ఒకే ఒక ZIP (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` UTC లో డిఫాల్ట్ గా) సృష్టిస్తుంది. విజయవంతమైన బ్యాకప్ తర్వాత, ధృవీకరణ సేవ్ చేసిన ఫైల్ పేరును చూపిస్తుంది.
- **బ్యాకప్ నుండి పునరుద్ధరించు** — ముందుగా **ధృవీకరణ డైలాగ్** తెరుస్తుంది. డైలాగ్ లోపల బ్యాకప్ ZIP ఎంచుకోండి (**బ్రౌజ్** / ఫైల్ పికర్ లేదా మద్దతు ఉన్న చోట డ్రాగ్-అండ్-డ్రాప్), తర్వాత ఎంపికలను సమీక్షించండి:
  - **ఉపయోగ డేటాను పునరుద్ధరించండి** — ఉపయోగం/చరిత్రను బ్యాకప్ చేసినప్పుడు ఉపయోగంతో కలిపి ఉంటే ZIP నుండి దిగుమతి చేసుకోండి; మీరు సెట్టింగ్‌లు మరియు ప్రాంప్ట్‌లు మాత్రమే కావాలనుకుంటే ఆపివేయండి.
  - **పునరుద్ధరించే ముందు పాత ఉపయోగ డేటాను తొలగించండి** — బ్యాకప్ వర్తించే ముందు ఈ ఇన్‌స్టాల్ లో ఉన్న ఉపయోగం/చరిత్రను తొలగించండి (ఐచ్ఛికం; మీరు స్వచ్ఛమైన భర్తీ కోసం ఉపయోగించండి).

వెబ్ లేదా డెస్క్‌టాప్ వెర్షన్ లో సృష్టించిన బ్యాకప్‌లను మరొకదానిలో పునరుద్ధరించవచ్చు. వెబ్ వెర్షన్ లో డెస్క్‌టాప్ బ్యాకప్ ను పునరుద్ధరించినప్పుడు, డేటా కార్యదర్శి వాడుకరికి పునరుద్ధరించబడుతుంది.

### మోడల్‌లు

టూల్‌బార్ లో కనిపించే మోడల్‌లను ఎంచుకోవడానికి **సెట్టింగ్‌లు** > **మోడల్‌లు** ఉపయోగించండి.

![Settings Models tab](../images/screenshots/te/settings-models.png)

ఈ పేజీ రెండు జాబితాలను కలిగి ఉంటుంది:

- ఎడమ వైపు **అందుబాటులో ఉన్న మోడల్‌లు**
- కుడి వైపు **ఎంపిక చేసిన మోడల్‌లు**

ఉపయోగకరమైన నియంత్రణలలో ఇవి ఉన్నాయి:

- **మోడల్‌లను శోధించు...** పేరు ప్రకారం మోడల్ కనుగొనడానికి
- **ప్రదాత** చిప్స్ ఒక ఇంజిన్ (ఓపెన్రౌటర్, ఓపెన్ఏఐ, ఓలామా, …) కు జాబితాను సన్నగిల్లడానికి
- **ఉచితవి మాత్రమే** ఉచిత మోడల్‌లను మాత్రమే చూపించడానికి
- **రిఫ్రెష్** జాబితాను మళ్లీ లోడ్ చేయడానికి
- **అన్నీ విస్తరించు** మరియు **అన్నీ కుదించు** మీరు ప్రదాత ప్రకారం క్రమబద్ధీకరిస్తున్నప్పుడు

మోడల్ ఐడీలు ప్రదాత ప్రిఫిక్స్‌ను కలిగి ఉంటాయి (ఉదాహరణకు `openrouter/…` బదులుగా `openai/…`). **OpenAI (OpenRouter)** బదులుగా **OpenAI (నేరుగా)** వంటి బ్యాడ్జెస్ ట్రాఫిక్ ఎలా మార్గం చేయబడుతుందో చూపిస్తాయి.

> ℹ️ **గమనిక**<br/>
> **ఓపెన్రౌటర్ బాడీ బిల్డర్** (`openrouter/bodybuilder`) ఒక సాధారణ చాట్ మోడల్ కాకుండా రౌటర్ మోడల్: దాని సమాధానం ఓపెన్రౌటర్ API రిక్వెస్ట్ బాడీలను వివరించే జెసన్ (ఉదాహరణకు `model` మరియు `messages`తో కూడిన `requests` శ్రేణి). మీరు **అనువదించు**, **రీరైట్**, లేదా **ట్రాన్స్‌ఫార్మ్** కోసం దీన్ని ఉపయోగిస్తే, పూర్తి చేసిన పాఠాను కాకుండా ఆ జెసన్‌ను అవుట్‌పుట్ ప్యానెల్ చూపిస్తుంది. ఆ పనుల కోసం సాధారణ పాఠ్య మోడల్‌ను ఎంచుకోండి. ఓపెన్రౌటర్ లోని [బాడీ బిల్డర్ మోడల్ పేజి](https://openrouter.ai/openrouter/bodybuilder) చూడండి.

చర్యలు:

- మోడల్‌ను జోడించడానికి, **జోడించు** పై లేదా ఎంట్రీలో ఎక్కడైనా క్లిక్ చేయండి.

- మోడల్‌ను తొలగించడానికి, **ఎంపిక చేసిన మోడల్‌లు** లో దాని పక్కన **X** పై లేదా అందుబాటులో ఉన్న మోడల్‌లలో ఎంట్రీ పై **ఎంపిక చేయబడింది** పై క్లిక్ చేయండి.

- జాబితాను క్లియర్ చేయడానికి, **అన్నీ ఎంపిక తొలగించు** పై క్లిక్ చేయండి. అవసరమైన ఉచిత మోడల్ జాబితాలో ఉంటుంది.

<br/>

> ℹ️ **గమనిక**<br/>
> ఓపెన్రౌటర్‌కు వెంటనే క్రెడిట్‌లు జోడించకూడదనుకుంటే, మొదట **ఉచితం మాత్రమే** ని సక్రియం చేసి, ఉచిత మోడల్‌లను ఎంచుకోండి (క్రెడిట్ కార్డ్ అవసరం లేదు). ఏదైనా API కీ లేకుండా మోడల్‌లను స్థానికంగా నడపడానికి మీరు ఓలామా కూడా ఉపయోగించవచ్చు.

<a id="languages"></a>
### భాషలు

**సెట్టింగ్‌లు** > **భాషలు** ఉపయోగించి అప్లికేషన్‌లో ఉపయోగించే భాషా జాబితాలను సంఘటించండి.

- **పై భాషలు** **అనువదించు** మరియు **ట్రాన్స్‌ఫార్మ్** లోని భాషా జాబితాల పైన పిన్ చేయబడతాయి.
- **కస్టమ్ భాష** అంతర్నిర్మిత జాబితాలో లేని భాషను జోడించడానికి మిమ్మల్ని అనుమతిస్తుంది.

మీరు కస్టమ్ భాషను జోడిస్తే, అది అంతర్నిర్మిత ఎంపికలతో పాటు భాషా ఎంపికదారులలో కనిపిస్తుంది.

<a id="cost-tracking"></a>
### ఖర్చు ట్రాకింగ్

**సెట్టింగ్‌లు** > **ఖర్చు ట్రాకింగ్** ఉపయోగించి ఖర్చు సమాచారాన్ని నిర్వహించండి.

- **మొత్తం ఖర్చు** పరిమితి మొత్తాన్ని చూపిస్తుంది.
- **విలువను కాపీ చేయి** మొత్తాన్ని క్లిప్‌బోర్డ్‌కు కాపీ చేస్తుంది.
- **ఖర్చు రీసెట్** నిల్వ చేసిన మొత్తాన్ని సున్నాకు రీసెట్ చేస్తుంది.
- **API కీ వినియోగంతో సింక్ చేయి** మీ ఓపెన్రౌటర్ ఖాతా నివేదించిన వినియోగానికి అనుగుణంగా మొత్తాన్ని సెట్ చేస్తుంది (ఓపెన్రౌటర్ మాత్రమే).
- **API కీ వినియోగం** అందుబాటులో ఉంటే, ఓపెన్రౌటర్ వినియోగ వివరాలను చూపిస్తుంది.
- **ఖర్చు డేటాను తొలగించు** అన్ని డేటాను లేదా ఎంచుకున్న తేదీకి ముందు ఉన్న ఎంట్రీలను మాత్రమే తొలగిస్తుంది.

**ఖర్చు ట్రాకింగ్:** మీరు ఓపెన్రౌటర్ మోడల్‌లను ఉపయోగించినప్పుడు, ఓపెన్రౌటర్ నుండి ఖర్చు సమాచారం ఆధారంగా మీ వాస్తవ వినియోగం మరియు ఖర్చును అప్లికేషన్ చూపిస్తుంది. ఇతర అన్ని ప్రదాతల కోసం, ఓపెన్రౌటర్ ప్రచురించిన ధరలను ఉపయోగించి అప్లికేషన్ ఖర్చులను అంచనా వేస్తుంది, ధర అందుబాటులో లేకపోతే, అంచనా సున్నా కావచ్చు.

<br/>

> ℹ️ **గమనిక**<br/>
>  **అన్ని ఖర్చు సంఖ్యలు మీ సౌకర్యం కోసం మాత్రమే అంచనాలు, అధికారిక బిల్లింగ్ స్టేట్‌మెంట్లు కావు.**

<br/>

> ⚠️ **హెచ్చరిక**<br/>
> డేటా తొలగింపును తిరిగి చేయలేరు. తొలగించే ముందు, మీ డేటాను బ్యాకప్ చేసుకోండి లేదా [**చరిత్ర**](#history) ద్వారా లేదా [**డ్యాష్‌బోర్డ్** > **అన్ని కాల్స్**](#dashboard-tabs) ద్వారా ఎగుమతి చేసుకోండి, లేకపోతే అది శాశ్వతంగా కోల్పోబడుతుంది. ప్రతి API కాల్ ఎంట్రీకి సంబంధించిన ఇన్‌పుట్/అవుట్‌పుట్ చరిత్ర కూడా తొలగించబడుతుంది.

<a id="transform-prompts"></a>
### ట్రాన్స్‌ఫార్మ్ ప్రాంప్ట్‌లు

**సెట్టింగ్‌లు** > **ట్రాన్స్‌ఫార్మ్ ప్రాంప్ట్‌లు** ఉపయోగించి ప్రాంప్ట్‌లను బల్క్‌గా నిర్వహించండి.

మీరు:

- మీరు సేవ్ చేసిన ప్రాంప్ట్‌లను సమీక్షించండి  
- ప్రాంప్ట్‌లను తొలగించండి  
- ఫైల్ నుండి ప్రాంప్ట్‌లను దిగుమతి చేసుకోండి  
- బ్యాకప్ లేదా షేరింగ్ కోసం ప్రాంప్ట్‌లను ఎగుమతి చేయండి  
- ప్రాంప్ట్ జాబితాకు నమూనా ప్రాంప్ట్‌లు లోడ్ చేయి

<a id="users"></a>
### వినియోగదారులు

వెబ్ వెర్షన్‌లో వాడుకరి ఖాతాలను నిర్వహించడానికి **వినియోగదారులు** ఉపయోగించండి. మీరు వాడుకరులను జోడించవచ్చు, వారి వివరాలను నవీకరించవచ్చు, పాస్‌వర్డ్‌లను రీసెట్ చేయవచ్చు మరియు ఖాతాలను తొలగించవచ్చు.

<a id="api-config"></a>
### API కాన్ఫిగ్

మద్దతు ఇచ్చే ప్రదాతలు: ఓపెన్రౌటర్, ఓపెన్ఏఐ, యాంథ్రోపిక్, గూగుల్ జెమిని, డీప్సీక్, గ్రోక్, మిస్ట్రల్, ఎక్స్ఏఐ, Cerebras మరియు **ఓలామా** (బేస్ URL ద్వారా స్థానిక మోడల్‌లు). మీరు ఉపయోగించే ప్రదాతలను మాత్రమే కాన్ఫిగర్ చేయాలి.

**వెబ్ అప్లికేషన్: కేవలం నిర్వాహకుడు మాత్రమే**

API కీలను సిస్టమ్ లేదా డాకర్ పర్యావరణ వేరియబుల్స్ ద్వారా కాన్ఫిగర్ చేస్తారు — వాటిని వెబ్ UIలో నమోదు చేయరు. ఈ పేజీ ఏ ప్రదాతకు కీ కాన్ఫిగర్ చేయబడిందో చూపిస్తుంది మరియు ప్రతి ఒక్కదానికి **`పరీక్ష`** బటన్‌పై క్లిక్ చేయడం ద్వారా పరీక్షించడానికి అనుమతిస్తుంది.

<br/>

> ℹ️ **గమనిక**<br/>
> API కీని మార్చడానికి, మీ సిస్టమ్ లేదా డాకర్ కాన్ఫిగరేషన్‌లో పర్యావరణ వేరియబుల్‌ను నవీకరించి, సర్వర్ లేదా కంటైనర్‌ను రీస్టార్ట్ చేయండి.

> ℹ️ **గమనిక**<br/>
> **కాన్ఫిగరేషన్ బ్యాకప్‌లు** ([**సాధారణ సెట్టింగ్‌లు** → కాన్ఫిగరేషన్ బ్యాకప్](#general-settings) చూడండి) ZIP యొక్క `config.json`లో **రిజాల్వ్ చేయబడిన** ప్రదాత కీలను ఎంబెడ్ చేయవచ్చు. ఆ ZIPని పునరుద్ధరించడం ఆ కీలను సర్వర్ యొక్క పర్సిస్టెడ్ కాన్ఫిగ్ ఫైల్‌లోకి కాపీ చేయదు — ఇక్కడ వివరించినట్లు సజీవ కీలు ఇప్పటికీ పర్యావరణం మరియు ఉన్న ఫైల్ స్థితి నుండి వస్తాయి.

<br/>

**డెస్క్‌టాప్ అప్లికేషన్**

మీరు ఉపయోగించే ప్రతి ప్రదాత కోసం API కీలను నిల్వ చేయడానికి **API కాన్ఫిగ్** ఉపయోగించండి. ఓలామా కోసం, API కీ బదులుగా **బేస్ URL** ని నమోదు చేయండి.

> మీరు API కీని ఉపయోగించకూడదని లేదా ఉపయోగం కోసం చెల్లించకూడదని కోరుకుంటే, మీ యంత్రంలో [ఓలామాను డౌన్‌లోడ్ చేసుకోవచ్చు](https://ollama.com) మరియు ఉచితంగా మోడల్‌లను (ఉదా: `translategemma:4b`) స్థానికంగా నడుపుతారు. ప్రత్యామ్నాయంగా, వారి ఉచిత మోడల్‌లను ఉపయోగించడానికి మీరు ఉచిత ఓపెన్రౌటర్ ఖాతాను సృష్టించవచ్చు (క్రెడిట్ కార్డ్ అవసరం లేదు), లేదా Cerebras, గూగుల్, గ్రోక్ లేదా మిస్ట్రల్ AI నుండి ఉచిత API కీని పొందవచ్చు.

<br/>

- మీకు అవసరమైన ప్రదాతలను మాత్రమే జోడించండి. **సెట్టింగ్‌లు** > **మోడల్‌లు**లో, ప్రతి మోడల్ ID ప్రదాతతో ప్రారంభమవుతుంది (ఉదాహరణకు `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`).

API కీని జోడించడానికి, పాఠ్య రంగంలో విలువను నమోదు చేసి **`సేవ్`** బటన్‌పై క్లిక్ చేయండి. ఉన్న కీని భర్తీ చేయడానికి, **`సవరించు`** బటన్‌పై క్లిక్ చేయండి. కీ పనిచేస్తుందో లేదో నిర్ధారించడానికి, **`పరీక్ష`** బటన్‌పై క్లిక్ చేయండి. ఓలామా బేస్ URL కోసం, కనెక్షన్‌ను తనిఖీ చేయడానికి ఎల్లప్పుడూ **`పరీక్ష`** బటన్‌పై క్లిక్ చేయండి.

<a id="common-issues"></a>
## సాధారణ సమస్యలు

ఏదైనా అనుకోకుండా పని చేయకపోతే, ముందుగా కింది పాయింట్లను తనిఖీ చేయండి.

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### అనువాదం, రీరైట్ లేదా ట్రాన్స్‌ఫార్మ్ చేయడానికి అప్లికేషన్ పాటించదు

ఇవి సరిచూసుకోండి:

- టూల్‌బార్‌లో మీరు ఒక మోడల్‌ని ఎంపిక చేసారా
- [**సెట్టింగ్‌లు** > **మోడల్‌లు**](#models)లో కనీసం ఒక మోడల్ జాబితాలో ఉందా
- మీ API సెటప్ పనిచేస్తోందా

డెస్క్‌టాప్ అప్లికేషన్ ఉపయోగిస్తున్నట్లయితే:

1. [**సెట్టింగ్‌లు** > **API కాన్ఫిగ్**](#api-config) తెరవండి.
2. కనీసం ఒక API కీ సేవ్ అయిందో లేదో సరిచూసుకోండి.
3. కీ పనిచేస్తుందో లేదో నిర్ధారించడానికి ప్రదాత పక్కన ఉన్న **పరీక్ష**పై క్లిక్ చేయండి.

<br/>

<a id="the-model-list-is-empty"></a>
### మోడల్ జాబితా ఖాళీగా ఉంది

[**సెట్టింగ్‌లు** > **మోడల్‌లు**](#models) తెరిచి **రిఫ్రెష్**పై క్లిక్ చేయండి.

అవసరమైతే:

- ఒక మోడల్ కోసం వెతకండి
- **ఉచితం మాత్రమే** ఆన్ చేయండి
- **ఎంపిక చేసిన మోడల్‌లు**కి ఒకటి లేదా అంతకంటే ఎక్కువ మోడల్‌లను జోడించండి

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ఫలితం చాలా నెమ్మదిగా లేదా ఖరీదైనదిగా ఉంది

ఇవి ఒకటి లేదా అంతకంటే ఎక్కువ ప్రయత్నించండి:

- వేరొక మోడల్‌ని ఎంచుకోండి
- చిన్న ఇన్‌పుట్ ఉపయోగించండి
- [**సెట్టింగ్‌లు** > **సాధారణ సెట్టింగ్‌లు**](#general-settings)లో **రియల్-టైమ్ అనువాదం (టైప్ చేస్తున్నప్పుడు)** ఆపివేయండి
- సరళమైన పనులకు ఉచిత మోడల్‌లను ఉపయోగించండి (చూడండి [మోడల్‌లు](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### ఇంటర్‌ఫేస్ తప్పు భాషలో ఉంది

[టూల్‌బార్](#toolbar)లో గ్లోబ్ ఐకాన్‌పై క్లిక్ చేసి మీకు ఇష్టమైన **ఇంటర్‌ఫేస్ భాష**ని ఎంచుకోండి.

<a id="the-text-is-too-small-or-hard-to-read"></a>
### టెక్స్ట్ చాలా చిన్నదిగా లేదా చదవడానికి కష్టంగా ఉంది

[**సెట్టింగ్‌లు** > **సాధారణ సెట్టింగ్‌లు**](#general-settings) తెరిచి మార్చండి:

- **ఫాంట్ కుటుంబం**
- **పరిమాణం**

<a id="dashboard-charts-are-empty"></a>
### డ్యాష్‌బోర్డ్ చార్ట్‌లు ఖాళీగా ఉన్నాయి

ఇది సాధారణం కావచ్చు కింది పరిస్థితుల్లో:

- మీరు **ఉచిత మోడల్‌లు** మాత్రమే ఉపయోగిస్తున్నారు మరియు **ఖర్చు** వివరాలను చూస్తున్నారు (వాటి విలువ సున్నా కావచ్చు); **సారాంశం**లో ఉన్న **ఉపయోగం** కాల్-కౌంట్ చార్ట్‌లకు ఎంచుకున్న కాలం నుండి డేటా అవసరం
- ఎంచుకున్న **సమయ ఫిల్టర్** కాల్స్ చేసిన కాలాన్ని కవర్ చేయడం లేదు — తనిఖీ చేయడానికి **అన్నీ** ప్రయత్నించండి

**అన్నీ** ఎంచుకున్న తర్వాత కూడా పట్టికలు ఖాళీగా ఉంటే, [**చరిత్ర**](#history) లేదా **అన్ని కాల్స్** ట్యాబ్‌లో కాల్స్ కనిపిస్తున్నాయో లేదో ధృవీకరించండి.

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ఖర్చు "అందుబాటులో లేదు" లేదా తప్పుగా కనిపిస్తుంది

మీరు **ఓపెన్రౌటర్** ద్వారా మోడల్‌లను ఉపయోగించినప్పుడు, ఓపెన్రౌటర్ నివేదించిన మీ వాస్తవ ఖర్చును అప్లికేషన్ చూపిస్తుంది.

**ఇతర ప్రదాతల** (నేరుగా ఓపెన్ఏఐ, నేరుగా యాంథ్రోపిక్, మొదలైనవి) కోసం, ఓపెన్రౌటర్ ప్రచురించిన ధరల సమాచారం ఆధారంగా ఖర్చు అంచనా వేయబడుతుంది. ఒక మోడల్ కోసం సరిపోయే ధర కనుగొనబడకపోతే, ఖర్చు **అందుబాటులో లేదు** గా కనిపిస్తుంది మరియు మీ మొత్తం మొత్తంలో చేర్చబడదు.

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### మొత్తం ఖర్చు మీ ప్రదాత బిల్లుతో సరిపోవడం లేదు

అప్లికేషన్‌లోని అన్ని ఖర్చు సంఖ్యలు **సూచన కోసం మాత్రమే అంచనాలు**, అధికారిక బిల్లింగ్ ప్రకటనలు కావు.

మొత్తాన్ని మీ నిజమైన ఓపెన్రౌటర్ ఖర్చుకు దగ్గరగా తీసుకురావడానికి, [**సెట్టింగ్‌లు** > **ఖర్చు ట్రాకింగ్**](#cost-tracking) ని తెరిచి, **API కీ వినియోగంతో సింక్ చేయి** బటన్‌పై క్లిక్ చేయండి.

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### సైడ్‌బార్ నుండి చరిత్ర పేజీ కోల్పోయింది

**అమలు చరిత్రను ఉంచండి** ఆఫ్ చేయబడి ఉండవచ్చు. [**సెట్టింగ్‌లు** > **సాధారణ సెట్టింగ్‌లు**](#general-settings) ని తెరిచి, దాన్ని ప్రారంభించండి. దీన్ని ప్రారంభించడం మునుకు తొలగించబడిన చరిత్ర డేటాను పునరుద్ధరించదని గమనించండి.

<a id="web-app-session-expired"></a>
### వెబ్ అప్లికేషన్: అనుకోకుండా లాగిన్ పేజీకి మళ్లించబడింది

మీ సెషన్ సమయం ముగిసి ఉండవచ్చు. మళ్లీ లాగిన్ అవ్వండి. ఇది తరచుగా జరిగితే, సెషన్ జీవితకాల సెట్టింగ్‌ల కోసం సర్వర్ కాన్ఫిగరేషన్ ని తనిఖీ చేయండి.

<a id="web-admin-forgot-or-lost-a-password"></a>
### వెబ్ కార్యదర్శి: పాస్‌వర్డ్ మర్చిపోయారు లేదా పోయింది

ఇది **స్వంతంగా హోస్ట్ చేసిన వెబ్ అప్లికేషన్** (డాకర్) కు వర్తిస్తుంది, డెస్క్‌టాప్ (ఎలక్ట్రాన్) అప్లికేషన్ కాదు.

- మరో కార్యదర్శి ఇంకా సైన్ ఇన్ చేయగలిగితే, వారు [**సెట్టింగ్‌లు** > **వినియోగదారులు**](#users) ని తెరిచి, ఖాతాను ఎంచుకొని, అక్కడ **కొత్త పాస్‌వర్డ్** సెట్ చేయవచ్చు.
- మీరు **లాక్ అవుట్** అయినా, మీకు మెషీన్ లేదా కంటైనర్‌కు **షెల్ యాక్సెస్** ఉంటే, ఇమేజ్‌తో పంపిణీ చేయబడిన సహాయకితో పాస్‌వర్డ్ ని రీసెట్ చేయండి (డిఫాల్ట్ పేరు మార్చినట్లయితే `transrewrt` ని మార్చండి, మరియు పాస్‌వర్డ్ లో స్పేస్‌లు లేదా ప్రత్యేక అక్షరాలు ఉంటే దాన్ని ఉదాహరణలో చూపినట్లు కోట్ చేయండి):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

మీరు ఇతర ఖాతాలు ఎప్పుడూ సృష్టించకపోతే డిఫాల్ట్ కార్యదర్శి వాడుకరి పేరు `admin`. మీరు ఒకే ఒక వాదనను పాస్ చేసినప్పుడు, దాన్ని `admin` కు కొత్త పాస్‌వర్డ్ గా పరిగణిస్తారు.

మీరు డాకర్ కాకుండా **సోర్స్ చెక్‌అవుట్** నుండి నడుస్తుంటే, ఉపయోగించండి:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

స్క్రిప్ట్ SQLite డేటాబేస్ లోని వాడుకరి రికార్డ్ ని నవీకరిస్తుంది (మరియు `admin` వాడుకరి లేకపోతే సృష్టించవచ్చు). రీసెట్ చేసిన తర్వాత, కొత్త పాస్‌వర్డ్ తో సైన్ ఇన్ అవ్వండి.

### డ్యాష్‌బోర్డ్ ఇతర వాడుకరుల కోసం డేటా చూపించడం లేదు (వెబ్)

**కార్యదర్శులు** మాత్రమే **వాడుకరి** ఫిల్టర్ ద్వారా అన్ని వాడుకరుల నుండి డేటాను చూడగలరు. సాధారణ వాడుకరులు వారి స్వంత కార్యాచరణ మాత్రమే చూస్తారు.

### నేను ప్రాంప్ట్ ని మార్చాను మరియు సవరణలు కోల్పోయాను

ప్రాంప్ట్‌ను సవరించినప్పుడు, **బ్యాక్ టు రన్**పై క్లిక్ చేయడానికి ముందు ఎల్లప్పుడూ **సేవ్**పై క్లిక్ చేయండి.

<a id="quick-tips"></a>
## త్వరిత చిట్కాలు

- [**అనువదించు**](#translate)తో ప్రారంభించండి, తర్వాత [**రీరైట్**](#rewrite) లేదా [**ట్రాన్స్‌ఫార్మ్**](#transform)కు వెళ్లే ముందు మీ సెటప్ పనిచేస్తుందని నిర్ధారించుకోండి.
- రోజువారీ పదబంధాల మెరుగుదలకు [**రీరైట్**](#rewrite)ను ఉపయోగించండి.
- ప్రత్యేక పని కోసం పునరావృత వర్క్‌ఫ్లో అవసరమైనప్పుడు [**ట్రాన్స్‌ఫార్మ్**](#transform)ను ఉపయోగించండి.
- ఉపయోగం మరియు ఖర్చుపై దృష్టి పెట్టాలనుకుంటే [**డ్యాష్‌బోర్డ్**](#dashboard)ను ఉపయోగించండి.
- గత ఆపరేషన్లు మరియు వాటి పూర్తి ఇన్‌పుట్/అవుట్‌పుట్ టెక్స్ట్‌ను సమీక్షించడానికి [**చరిత్ర**](#history)ను ఉపయోగించండి.
- మీరు సురక్షితంగా ఉంచాలనుకుంటున్న ప్రాంప్ట్ లైబ్రరీని నిర్మాణం చేస్తున్నట్లయితే (చూడండి [ట్రాన్స్‌ఫార్మ్ ప్రాంప్ట్‌లు](#transform-prompts)) లేదా ఇతరులతో పంచుకోవాలనుకుంటే, ప్రాంప్ట్‌లను తరచుగా ఎగుమతి చేసుకోండి.
