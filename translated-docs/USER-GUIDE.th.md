# คู่มือการใช้งาน

<br/>

<a id="introduction"></a>

## บทนำ

Transrewrt ช่วยให้คุณทำงานกับข้อความได้สามวิธีหลัก ดังนี้:

- **แปลภาษา** - แปลงข้อความจากภาษาหนึ่งไปอีกภาษาหนึ่ง
- **เขียนใหม่** - เขียนข้อความใหม่ในรูปแบบที่ต่างออกไป เช่น ให้ชัดเจนขึ้น สั้นลง หรือเป็นทางการมากขึ้น
- **ปรับเปลี่ยนรูปแบบ** - ประมวลผลข้อความโดยใช้คำแนะนำปัญญาประดิษฐ์แบบกำหนดเองที่เรียกว่า prompts

<br/>

คู่มือนี้อธิบายขั้นตอนการใช้งานแอปพลิเคชันเมื่อได้ติดตั้งและรันเรียบร้อยแล้ว สำหรับขั้นตอนการติดตั้ง โปรดดูที่ไฟล์หลัก **[README](README.th.md)**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> Transrewrt มีให้ใช้งานเป็นแอปเดสก์ท็อปสำหรับ Windows และ Linux และยังสามารถใช้เป็นเว็บแอปพลิเคชันที่ผู้ใช้โฮสต์เองได้ คู่มือนี้เน้นการใช้งานทั่วไปของแอปพลิเคชัน โดยในกรณีที่คุณสมบัติใดๆ ใช้ได้เฉพาะกับรุ่นใดรุ่นหนึ่งจะมีการระบุไว้อย่างชัดเจน

## ก่อนที่คุณจะเริ่มต้น

ในการใช้งาน Transrewrt คุณจะต้องมีการเข้าถึงผู้ให้บริการปัญญาประดิษฐ์ (AI) อย่างน้อย 1 ราย ผู้ให้บริการที่รองรับ ได้แก่ [OpenRouter](https://openrouter.ai) (ที่รวบรวมโมเดลต่างๆ เอาไว้), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ [Ollama](https://ollama.com) สำหรับโมเดลที่ใช้งานในเครื่อง (local models)

คุณไม่จำเป็นต้องเลือกโมเดลแบบเสียเงินเพื่อเริ่มต้น เมื่อคุณเพิ่มคีย์ API ของ OpenRouter แล้ว แอปจะเปิดใช้งานตัวเลือก OpenRouter แบบ **ฟรี** ในตัวโดยอัตโนมัติ ซึ่งช่วยให้คุณสามารถเริ่มแปล ปรับเรียบเรียงข้อความ หรือแปลงข้อความต่างๆ ได้ทันที อีกทางเลือกหนึ่ง คุณสามารถขอรับคีย์ API ฟรีจาก Cerebras, Google, Groq หรือ Mistral AI ได้เช่นกัน

ในทางปฏิบัติ:

- **โมเดล** คือเครื่องยนต์ปัญญาประดิษฐ์ที่ทำหน้าที่ประมวลผล โมเดลจะถูกรายงานพร้อมคำนำหน้าของ **ผู้ให้บริการ** (ตัวอย่างเช่น `openrouter/…`, `openai/…`, `ollama/…`)
- **คีย์ API** (หรือสำหรับ Ollama คือ **URL หลัก (base URL)**) คือสิ่งที่แอปใช้ติดต่อกับผู้ให้บริการนั้นๆ

ถ้าคุณใช้ **แอปเดสก์ท็อป** ให้เพิ่มกุญแจในส่วน [**การตั้งค่า** > **การตั้งค่า API**](#api-config) สำหรับผู้ให้บริการแต่ละรายที่คุณใช้ หากใช้เฉพาะ OpenRouter โปรดดูที่ [วิธีรับกุญแจ API](#how-to-get-an-api-key-desktop-app) ด้านล่าง หากคุณไม่ต้องการใช้กุญแจ API คุณสามารถติดตั้ง Ollama (จาก [ollama.com](https://ollama.com)) แล้วใช้โมเดลท้องถิ่นแทน เช่น `translategemma:4b`

ถ้าคุณใช้ **เวอร์ชันเว็บ** ผู้ดูแลระบบเซิร์ฟเวอร์จะตั้งค่าผู้ให้บริการผ่านตัวแปรสภาพแวดล้อม ดังนั้นคุณจะไม่สามารถป้อนกุญแจ API ลงไปในแอปพลิเคชันได้โดยตรง

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>

### วิธีรับคีย์ API OpenRouter ฟรี (แอปเดสก์ท็อป)

หากคุณใช้แอปเดสก์ท็อป ให้ทำตามขั้นตอนต่อไปนี้:

1. เปิดเว็บไซต์ [OpenRouter](https://openrouter.ai) ในเว็บเบราว์เซอร์ของคุณ
2. สร้างบัญชีผู้ใช้หรือเข้าสู่ระบบ
3. เปิดหน้า [Keys](https://openrouter.ai/keys)
4. คลิกปุ่มเพื่อสร้างคีย์ API ใหม่
5. ตั้งชื่อคีย์เพื่อให้คุณสามารถจดจำได้ในภายหลัง
6. คัดลอกคีย์ API ใหม่นี้
7. กลับไปที่ Transrewrt และเปิด **ตั้งค่า** > **การตั้งค่า API**
8. วางคีย์ลงในช่อง **OpenRouter API key** (ภายใต้ **ตั้งค่า** > **การตั้งค่า API**)
9. คลิก **Test OpenRouter key** เพื่อตรวจสอบว่าใช้งานได้

<a id="getting-started"></a>

## เริ่มต้นใช้งาน

ถ้าเป็นครั้งแรกที่คุณใช้ Transrewrt ให้ทำตามขั้นตอนเหล่านี้:

1. เปิดแอปพลิเคชัน
2. เลือก**ภาษาอินเทอร์เฟซ**ของคุณจากไอคอนรูปโลก หากจำเป็น
3. หากใช้**แอปเดสก์ท็อป** ให้เปิดที่ [**การตั้งค่า** > **การกำหนดค่า API**](#api-config) เพิ่มคีย์ API อย่างน้อยหนึ่งผู้ให้บริการ (เช่น OpenRouter) จากนั้นคลิก **ทดสอบ** เพื่อยืนยันว่าใช้งานได้
4. ไปที่ [**การตั้งค่า** > **โมเดล**](#models) แล้วเพิ่มโมเดลหนึ่งหรือมากกว่าไปยัง **โมเดลที่เลือก**
5. เปิดที่ [**การตั้งค่า** > **ภาษา**](#languages) และเลือก**ภาษาหลัก** ถ้าคุณต้องการให้ภาษาที่ใช้บ่อยที่สุดแสดงขึ้นมาก่อน
6. เข้าไปที่ **แปล** แล้วลองแปลข้อความง่ายๆ เพื่อยืนยันว่าทุกอย่างทำงานได้ถูกต้อง
7. เมื่อทุกอย่างใช้งานได้แล้ว ให้ลองใช้ **เขียนใหม่** แล้วตามด้วย **แปลง**

ขั้นตอนนี้มีความสำคัญ เพราะจะช่วยหลีกเลี่ยงปัญหาทั่วไปที่ผู้ใช้พบเมื่อใช้ครั้งแรก คือ การพยายามดำเนินการใดๆ ก่อนที่แอปจะเชื่อมต่อกับ API ได้สำเร็จ หรือยังไม่ได้เลือกโมเดล

### แถบเครื่องมือ

แถบเครื่องมือจะเปลี่ยนแปลงเล็กน้อยขึ้นอยู่กับตำแหน่งที่คุณอยู่ในแอปพลิเคชัน

- ด้านซ้ายจะแสดงชื่อหน้าปัจจุบัน
- ด้านขวาจะแสดง **ตัวเลือกโมเดล** และการควบROLS **ภาษาอินเตอร์เฟซ**

**ตัวเลือกโมเดล** ช่วยให้คุณสามารถเลือกได้ว่าจะใช้เอนจินปัญญาประดิษฐ์ (AI) ตัวใดสำหรับงานปัจจุบัน

  ![ตัวเลือกโมเดล](../images/screenshots/th/model-selector.png)

โมเดลฟรีบางตัวอาจไม่สามารถใช้งานได้ตลอดเวลา — บางครั้งอาจออฟไลน์หรือมีขีดจำกัดการใช้งาน หากเกิดเหตุการณ์แบบนี้ แอปจะลบโมเดลนั้นออกจากรายการตัวเลือกของคุณโดยอัตโนมัติ เพื่อควบคุมว่าโมเดลใดจะปรากฏขึ้น ให้ไปที่ [**การตั้งค่า** > **โมเดล**](#models) และแก้ไขรายชื่อโมเดลของคุณ  
นอกจากนี้ คุณยังสามารถเปิดการตั้งค่าโมเดลได้โดยตรงด้วยการคลิกที่ไอคอนผู้ให้บริการที่อยู่ทางด้านซ้ายของชื่อโมเดลในแถบเครื่องมือ

<br/>

**ไอคอนโลก + รหัสภาษา** จะเปลี่ยนภาษาอินเตอร์เฟซของแอป เช่น เมนูและปุ่มต่าง ๆ แต่จะ **ไม่** เปลี่ยนภาษาที่ใช้ในการแปลในฟีเจอร์ **แปล**

![ตัวเลือกภาษาอินเทอร์เฟซ](../images/screenshots/th/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>

### แผงป้อนข้อมูลและแสดงผลลัพธ์

พื้นที่ทำงานส่วนใหญ่ใช้แผง **ป้อนข้อมูล** ด้านซ้าย และแผง **แสดงผลลัพธ์** ด้านขวา

แต่ละแผงจะแสดงข้อมูลดังนี้:

| **ป้อนข้อมูล**                                                          | **แสดงผลลัพธ์**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - จำนวนอักขระ <br/>- จำนวนคำ <br/>- จำนวนย่อหน้า   <br/> | - กิจกรรมใช้เวลานานเท่าใด<br/>- **TPS** (จำนวนโทเคนต่อวินาที)<br/>- จำนวนอักขระ คำ และย่อหน้า<br/>- โมเดลที่ใช้ |


หากคุณสงสัยเกี่ยวกับคำศัพท์ทางเทคนิค:

- **โทเคน** หมายถึง ชิ้นส่วนข้อความขนาดเล็ก คุณสามารถมองว่าเป็นส่วนหนึ่งของคำ หรือคำสั้น ๆ ก็ได้
- **TPS** หมายถึง จำนวนชิ้นส่วนข้อความที่โมเดลประมวลผลต่อวินาที

<br/>

คุณยังสามารถติดตามต้นทุนของแต่ละการดำเนินการ (หากมี) และต้นทุนรวมได้ โดยการเปิดใช้งานตัวเลือก `แสดงข้อมูลค่าใช้จ่ายในการดำเนินการ` ที่ [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)

<br/><br/>

<a id="translate"></a>

## แปล

ใช้ **แปล** เมื่อคุณต้องการแปลงข้อความจากรูปภาษาหนึ่งไปเป็นอีกรูปภาษาหนึ่ง

![พื้นที่ทำงานการแปล](../images/screenshots/th/translate.png)

<br/>

<a id="translate-text"></a>

### แปลข้อความ

1. เปิด **แปล**
2. เลือกภาษาในช่อง **จาก**
3. เลือกภาษาในช่อง **ถึง**
4. เลือกโมเดลในแถบเครื่องมือ
5. พิมพ์หรือวางข้อความลงในช่อง **ป้อนข้อมูล**
6. คลิกที่ **แปล**
7. อ่านผลลัพธ์ในช่อง **ผลลัพธ์**
8. ใช้ปุ่มคัดลอกหากคุณต้องการคัดลอกผลลัพธ์

<br/>

<a id="language-selection"></a>

### การเลือกภาษา

- **จาก** สามารถเป็นภาษาเฉพาะเจาะจงได้ หรือเลือก **ตรวจจับภาษา**
- **ถึง** คือ ภาษาที่คุณต้องการให้ผลลัพธ์แสดงในรูปแบบนั้น

ภาษา **ชั้นต้นที่คุณเลือก** จะแสดงอยู่ด้านบนสุดของรายการ คุณสามารถตั้งค่าได้ที่ [**การตั้งค่า** > **ภาษา**](#languages)

<br/>

<a id="helpful-translation-settings"></a>

### การตั้งค่าการแปลที่เป็นประโยชน์

ในส่วน [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) คุณสามารถเปลี่ยนวิธีการทำงานของการแปลได้ดังนี้:

- **แปลอัตโนมัติเมื่อวาง** จะทำการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** จะคัดลอกผลลัพธ์ไปยังคลิปบอร์ดโดยอัตโนมัติหลังจากการแปลสำเร็จ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** จะทำการแปลทันทีขณะที่คุณพิมพ์
- **ไทม์เอ้าต์ (มิลลิวินาที)** ใช้ควบคุมระยะเวลาที่แอปจะรอ ก่อนเริ่มการแปลแบบเรียลไทม์
- **Enter** ใช้ควบคุมสิ่งที่เกิดขึ้นเมื่อคุณกด `Enter`:

<a id="rewrite"></a>

## เขียนทับใหม่

ใช้ฟังก์ชัน **เขียนทับใหม่** เมื่อคุณต้องการปรับปรุงการถ้อยคำโดยไม่เปลี่ยนความหมายหลัก

![พื้นที่ทำงาน เขียนทับใหม่](../images/screenshots/th/rewrite.png)

ฟังก์ชันนี้มีประโยชน์สำหรับ:

- แก้ไขคำสะกดและไวยากรณ์ (**ตรวจสอบการสะกดและไวยากรณ์**)
- ทำให้ข้อความชัดเจนยิ่งขึ้น (**ปรับความชัดเจน**)
- สร้างรูปแบบใหม่ที่แตกต่างกันหลายๆ รูปแบบในครั้งเดียว (**รูปแบบทางเลือก**)
- ทำให้ข้อความเป็นทางการหรือลำลองมากขึ้น (**เป็นทางการ** / **ไม่เป็นทางการ**)
- ย่อข้อความหรือขยายข้อความให้ยาวขึ้น (**ย่อ** / **ขยาย**)
- ทำให้ข้อความฟังดูมีลักษณะทางเทคนิคมากขึ้น (**ทำให้มีลักษณะที่เป็นเทคนิคมากขึ้น**)

<br/>

> 💡 **คำแนะนำ**<br/>
> เมื่อคุณใช้โหมด "**ตรวจสอบการสะกดและไวยากรณ์**" จะมีตัวเลือก **แสดงการเปลี่ยนแปลง** ปรากฏในแผงผลลัพธ์ (อยู่ถัดจากปุ่ม **คัดลอก**)
> เปิดหรือปิดตัวเลือกนี้เพื่อแสดงหรือซ่อนการแก้ไขเฉพาะที่ถูกนำไปใช้กับข้อความของคุณ

<a id="transform"></a>

## แปลงข้อมูล

ใช้ฟีเจอร์ **แปลงข้อมูล (Transform)** เมื่อคุณต้องการให้ปัญญาประดิษฐ์ (AI) ทำตามชุดคำสั่งที่คุณกำหนดเอง

![พื้นที่ทำงานของฟีเจอร์แปลงข้อมูล](../images/screenshots/th/transform.png)

นี่คือพื้นที่ที่ยืดหยุ่นที่สุดของแอปพลิเคชัน คุณสามารถใช้มันในการทำงานต่างๆ เช่น:

- สรุปบันทึก
- แปลงข้อความดิบให้กลายเป็นอีเมลที่มีรูปแบบเรียบร้อย
- สกัดประเด็นสำคัญ
- แปลงข้อความให้อยู่ในรูปแบบเฉพาะ
- หรือกิจกรรมอื่นๆ ที่กำหนดเองกับข้อความป้อนเข้า

<br/>

<a id="run-an-existing-prompt"></a>

### รันพรอมต์ที่มีอยู่แล้ว

1. เปิด **แปลงรูปแบบ**
2. เลือกพรอมต์จากรายการพรอมต์
3. ถ้าปรากฏช่อง **ภาษาเป้าหมาย** ให้เลือกภาษาที่ต้องการ
4. พิมพ์หรือวางข้อความลงในช่อง **อินพุต**
5. คลิก **แปลงรูปแบบ**
6. อ่านผลลัพธ์ที่ได้ในช่อง **เอาต์พุต**

<br/>

<a id="if-you-have-no-prompts-yet"></a>

### หากคุณยังไม่มีพรอมต์

หากรายการพรอมต์ของคุณยังว่างเปล่า ให้คลิก **โหลดตัวอย่างพรอมต์** ในพื้นที่ทำงาน	Transform ส่วนควบคุมนี้จะสามารถใช้ได้เสมอที่ [**การตั้งค่า** > **พรอมต์แปลง**](#transform-prompts) บนแถวส่งออก/นำเข้า ทั้งสองวิธีจะเพิ่มตัวอย่างที่มีอยู่ภายในระบบ เพื่อให้คุณสามารถเริ่มต้นได้อย่างรวดเร็ว

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ตัวอย่างพรอมต์จะจัดทำเป็นภาษาอังกฤษ เมื่อคุณโหลดแล้ว คุณสามารถแก้ไขพรอมต์นั้นและใช้งาน **แปลพรอมต์** เพื่อแปลเป็นภาษาของคุณได้

<br/>

<a id="create-a-prompt-quickly"></a>

### สร้างพรอมต์อย่างรวดเร็ว

วิธีการสร้างพรอมต์ที่เร็วที่สุดคือ:

1. คลิกที่ **New prompt**
2. คลิกที่ **Generate prompt**
3. อธิบายสิ่งที่คุณต้องการให้พรอมต์นั้นทำ
4. เลือกโมเดล
5. ปล่อยให้แอปสร้างร่างให้คุณ
6. ตรวจสอบร่างที่สร้างขึ้นแล้วคลิก **Save**

![Generate prompt](../images/screenshots/th/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>

### แก้ไขพร้อมต์

เมื่อคุณสร้างหรือแก้ไขพร้อมต์ ตัวแก้ไขจะปรากฏที่ด้านซ้าย และพื้นที่ทดสอบจะปรากฏที่ด้านขวา

![ตัวแก้ไขพร้อมต์แปลง](../images/screenshots/th/transform-prompt-edit.png)

ฟิลด์หลักๆ มีดังนี้:

- **ชื่อพร้อมต์**: ชื่อที่แสดงในรายการพร้อมต์
- **คำแนะนำพร้อมต์ (ไม่บังคับ)**: คำใบ้สั้นๆ ที่จะแสดงให้ผู้ใช้เห็นเมื่อรันพร้อมต์
- **บทบาทโมเดล**: บทบาทโดยรวมที่กำหนดให้กับปัญญาประดิษฐ์ เช่น 'คุณเป็นผู้ช่วยที่มีประโยชน์'
- **คำแนะนำโมเดล (หนึ่งบรรทัดต่อหนึ่งข้อ)**: กฎเฉพาะเจาะจงที่คุณต้องการให้ปัญญาประดิษฐ์ปฏิบัติตาม
- **คำอธิบายผลลัพธ์**: คำสั้นๆ ที่อธิบายผลลัพธ์ เช่น 'สรุป' หรือ 'เขียนใหม่'
- **อุณหภูมิ (0.0 → 1.0)**: ลักษณะการตอบสนองของโมเดล; ดูคำอธิบายด้านล่าง
- **ขอภาษาเป้าหมาย**: เพิ่มตัวเลือกภาษาเป้าหมายเมื่อรันพร้อมต์

หากคุณยังไม่คุ้นเคยกับศัพท์เทคนิคอย่าง **อุณหภูมิ (Temperature)** ให้ลองเข้าใจตามนี้:

- อุณหภูมิที่ **ต่ำกว่า** จะให้ผลลัพธ์ที่คงที่และคาดการณ์ได้มากกว่า

- อุณหภูมิที่ **สูงขึ้น** จะให้ความหลากหลายและความคิดสร้างสรรค์มากขึ้น

คุณยังสามารถใช้:

- **`สร้างพรอมต์`** เพื่อสร้างร่างใหม่จากคำอธิบายง่ายๆ
- **`ปรับปรุงพรอมต์`** เพื่อพัฒนาพรอมต์ที่มีอยู่ให้ดียิ่งขึ้น
- **`แปลพรอมต์`** เพื่อแปลข้อความในช่องพรอมต์

<br/>

> ⚠️ **คำเตือน**<br/>
> คลิก **`บันทึก`** ก่อนคลิก **`กลับไปที่รัน`** หากคุณย้อนกลับโดยไม่ได้บันทึก การเปลี่ยนแปลงของคุณจะสูญหาย

<br/>

<a id="test-a-prompt-before-using-it"></a>

### ทดสอบพรอมต์ก่อนใช้งาน

แผงทดสอบด้านขวาช่วยให้คุณสามารถลองใช้พรอมต์ร่วมกับข้อความตัวอย่าง ก่อนนำไปใช้ในงานประจำวัน

สิ่งนี้มีประโยชน์ในกรณีต่อไปนี้:

- คุณกำลังสร้างพรอมต์ใหม่
- คุณต้องการเปรียบเทียบสองเวอร์ชันของพรอมต์
- คุณต้องการตรวจสอบน้ำเสียง ความยาว หรือรูปแบบผลลัพธ์ที่ได้

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณสามารถส่งออกและนำเข้าพรอมต์ที่บันทึกไว้ใน [**การตั้งค่า** > **แปลงพรอมต์**](#transform-prompts)

<br/><br/>

### แท็บแดชบอร์ด

- **สรุปภาพรวม** ให้ข้อมูลภาพรวมเกี่ยวกับการใช้งานและค่าใช้จ่าย ประกอบด้วย **การใช้งานตามช่วงเวลา** (แสดงจำนวน **การเรียกใช้งานสะสมแบบเรียงซ้อนรายวัน** สำหรับการแปล, การเขียนใหม่ และการแปลงรูปแบบ) และ **การใช้งานตามโมเดล** (**จำนวนครั้งที่เรียกใช้งานต่อโมเดล** ทั้งหมด รวมถึงการแปลงรูปแบบ)
- **ตามการใช้งาน** แบ่งกิจกรรมออกตามภาษาที่ใช้แปล โหมดการเขียนใหม่ และตัวอย่างคำสั่งสำหรับการแปลงรูปแบบ (transform prompt)
- **ตามโมเดล** แสดงให้เห็นว่าคุณใช้โมเดลใดบ้าง และมีค่าใช้จ่ายเท่าใด
- **ตามวัน** แสดงยอดรวมรายวัน
- **การเรียกใช้งานทั้งหมด** แสดงประวัติการเรียกใช้งานทั้งหมด และให้คุณสามารถส่งออกข้อมูลได้

<a id="general-settings"></a>

### การตั้งค่าทั่วไป

ใช้ **การตั้งค่าทั่วไป** เพื่อควบคุมพฤติกรรมการพิมพ์ ควบคุมว่าจะเก็บรายละเอียดการดำเนินการไว้ใน **ประวัติการใช้งาน** หรือไม่ และการปรับลักษณะการปรากฏของหน้าจอ

**พฤติกรรม**

- **พฤติกรรมของ ENTER** ช่วยเลือกได้ว่า `Enter` จะใช้ในการรันงาน หรือขึ้นบรรทัดใหม่
- **แปลอัตโนมัติเมื่อวาง** จะเริ่มการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** จะคัดลอกผลลัพธ์ที่สำเร็จไปยังคลิปบอร์ดโดยอัตโนมัติ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** จะแปลข้อความทันทีขณะที่คุณพิมพ์
- **เวลาหมดอายุ (มิลลิวินาที)** ตั้งค่าระยะเวลาที่รอสำหรับการแปลแบบเรียลไทม์

**ประวัติการใช้งาน**

- **เก็บประวัติการดำเนินการ** ควบคุมว่าแต่ละครั้งที่มีการแปล เขียนใหม่ หรือเปลี่ยนรูปแบบ จะเก็บ **ข้อความต้นฉบับและข้อความผลลัพธ์** ไว้เพื่อแสดงในแถบด้านข้างที่ชื่อ [**ประวัติการใช้งาน**](#history) หรือไม่ การปิดฟีเจอร์นี้จะมีการขอการยืนยัน; หากคุณยืนยัน ข้อความประวัติที่จัดเก็บจะถูกลบออกจากฐานข้อมูล

- **ลบข้อมูลประวัติ** ช่วยให้คุณลบข้อความที่จัดเก็บไว้ตามอายุข้อมูล (ตัวอย่างเช่น ข้อมูลที่เก่ากว่าหลายเดือน หรือ **ข้อมูลทั้งหมด (ล้างข้อมูล)**) โดยใช้ **ลบข้อมูล** การกระทำนี้จะส่งผลเฉพาะกับข้อความการดำเนินการที่บันทึกไว้สำหรับมุมมอง **ประวัติ** เท่านั้น แต่จะ **ไม่** ลบข้อมูลค่าใช้จ่ายหรือสถิติการใช้งาน หากต้องการลบหรือปรับข้อมูล **ค่าใช้จ่าย** โปรดใช้ [**ตั้งค่า** > **การติดตามค่าใช้จ่าย**](#cost-tracking)

**การแสดงผล**

- **แสดงข้อมูลค่าใช้จ่ายบนปุ่มดำเนินการ** ใช้ควบคุมการแสดงค่าใช้จ่ายต่อการดำเนินการ (หากมี) และค่าใช้จ่ายรวมบนแผงผลลัพธ์ของฟีเจอร์แปล รีย์ไรท์ และแปลงข้อมูล
- **จำนวนทศนิยมของค่าใช้จ่าย** ใช้กำหนดรูปแบบการแสดงทศนิยมของค่าใช้จ่าย
- **เฉพาะเว็บ:** **แสดงระยะขอบรอบแอป** เพิ่มพื้นที่ว่างรอบอินเตอร์เฟซ
- **ตระกูลแบบอักษร** เปลี่ยนแบบอักษรที่ใช้ในแผงข้อความ
- **ขนาด** เปลี่ยนขนาดของแบบอักษร

**การสำรองข้อมูลการตั้งค่า**

- **รวมข้อมูลการใช้งานในการสำรองข้อมูล** — เมื่อเปิดใช้งาน ZIP ที่ได้จะรวมข้อมูลประวัติการดำเนินการและข้อมูลการเรียกใช้ API ด้วย

- **สำรองข้อมูลการตั้งค่า** — สร้างไฟล์ ZIP เดียว (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` เวลา UTC เป็นค่าเริ่มต้น) ที่มี `config.json`, `state.json`, กุญแจการเข้ารหัส (ถ้ามี), ผู้ใช้, การตั้งค่าทั่วไป, พรอมต์ที่ปรับแต่งเอง และข้อมูลการใช้งาน (หากเลือกสำรองไว้) หลังจากสำรองข้อมูลเรียบร้อยแล้ว ระบบจะแสดงชื่อไฟล์ที่บันทึกไว้
- **กู้คืนจากข้อมูลสำรอง** — จะเปิด **กล่องโต้ตอบยืนยันก่อน** เลือกไฟล์ ZIP สำรองข้อมูลภายในกล่องโต้ตอบนั้น (**เรียกดู** / เครื่องมือเลือกไฟล์ หรือลากวางไฟล์ถ้าเบราว์เซอร์รองรับ) จากนั้นตรวจสอบตัวเลือก:
  - **กู้คืนข้อมูลการใช้งาน** — นำเข้าประวัติการใช้งานจากไฟล์ ZIP ที่ถูกสำรองไว้ แต่เฉพาะกรณีที่มีข้อมูลการใช้งานอยู่ในไฟล์สำรองด้วย; ปล่อยตัวเลือกนี้ไว้หากคุณต้องการเพียงการตั้งค่าและพรอมต์เท่านั้น
  - **ล้างข้อมูลการใช้งานเดิมก่อนกู้คืน** — ลบประวัติการใช้งานที่มีอยู่ในตัวติดตั้งปัจจุบันก่อนนำข้อมูลสำรองมาใช้ (ตัวเลือกเสริม; ใช้เมื่อต้องการแทนที่ทั้งหมดอย่างสมบูรณ์)

สำเนาข้อมูลสำรองที่สร้างจากเวอร์ชันเว็บหรือเดสก์ท็อปสามารถกู้คืนได้ในอีกเวอร์ชันหนึ่ง ในการกู้คืนข้อมูลสำรองจากเดสก์ท็อปในเวอร์ชันเว็บ ข้อมูลจะถูกกู้คืนไปยังผู้ใช้ระดับผู้ดูแลระบบ

### โมเดล

ใช้ **ตั้งค่า** > **โมเดล** เพื่อเลือกโมเดลที่จะแสดงในแถบเครื่องมือ

![แท็บโมเดลในการตั้งค่า](../images/screenshots/th/settings-models.png)

หน้านี้มีสองรายการ:

- **โมเดลที่มีอยู่** ทางด้านซ้าย
- **โมเดลที่เลือก** ทางด้านขวา

การควบคุมที่เป็นประโยชน์ ได้แก่:

- **ค้นหาโมเดล...** เพื่อค้นหาโมเดลตามชื่อ
- ตัวเลือก **ผู้ให้บริการ** เพื่อกรองรายการตามเครื่องยนต์ตัวใดตัวหนึ่ง (OpenRouter, OpenAI, Ollama, …)
- **เฉพาะแบบฟรี** เพื่อแสดงเฉพาะโมเดลที่ไม่เสียค่าใช้จ่าย
- **รีเฟรช** เพื่อรีโหลดรายการใหม่
- **ขยายทั้งหมด** และ **ยุบทั้งหมด** เมื่อคุณเรียงลำดับตามผู้ให้บริการ

รหัสโมเดลจะรวมคำนำหน้าของผู้ให้บริการด้วย (ตัวอย่างเช่น `openrouter/…` เทียบกับ `openai/…`) ป้ายชื่อ เช่น **OpenAI (OpenRouter)** เทียบกับ **OpenAI (โดยตรง)** จะแสดงวิธีการส่งต่อการรับส่งข้อมูล

> ℹ️ **หมายเหตุ**<br/>

> **OpenRouter Body Builder** (`openrouter/bodybuilder`) เป็นโมเดลเราเตอร์ ไม่ใช่โมเดลการสนทนาทั่วไป: การตอบกลับของมันคือ JSON ที่อธิบายเนื้อหาของคำขอ OpenRouter API (ตัวอย่างเช่น อาเรย์ `requests` ที่มี `model` และ `messages`) หากคุณใช้มันเพื่อ **แปล**, **เขียนใหม่** หรือ **แปลงรูปแบบ** แผงผลลัพธ์จะแสดง JSON นั้นแทนข้อความที่เสร็จสมบูรณ์ โปรดเลือกโมเดลข้อความธรรมดาสำหรับงานเหล่านี้ ดูได้ที่ [หน้าโมเดล Body Builder](https://openrouter.ai/openrouter/bodybuilder) บน OpenRouter

การดำเนินการ:

 - เพื่อเพิ่มโมเดล ให้คลิก **เพิ่ม** หรือคลิกที่ตำแหน่งใดก็ได้ในช่องข้อมูล

 - เพื่อลบโมเดล ให้คลิกที่ปุ่ม **X** ข้างๆ โมเดลในส่วน **โมเดลที่เลือก** หรือในส่วน **ที่เลือก** บนรายการโมเดลที่มีอยู่

 - เพื่อล้างรายการทั้งหมด ให้คลิก **ยกเลิกการเลือกทั้งหมด** โมเดลฟรีที่จำเป็นจะยังคงอยู่ในรายการ

<br/>

> ℹ️ **หมายเหตุ**<br/>

> หากคุณไม่ต้องการเพิ่มเครดิตให้กับ OpenRouter ทันที ให้เริ่มต้นด้วยการเปิดใช้งาน **เฉพาะแบบฟรีเท่านั้น** และเลือกรุ่นฟรี (ไม่ต้องใช้บัตรเครดิต) คุณยังสามารถใช้ Ollama เพื่อรันโมเดลในเครื่องโดยไม่ต้องใช้คีย์ API เลย

### ภาษา

ใช้ **ตั้งค่า** > **ภาษา** เพื่อจัดการรายชื่อภาษาที่ใช้ในแอป

- **ภาษาที่สำคัญที่สุด** จะถูกตรึงไว้ใกล้ด้านบนสุดของรายชื่อภาษาในหน้า **แปล** และ **แปลงรูปแบบ**
- **ภาษาแบบกำหนดเอง** ช่วยให้คุณเพิ่มภาษาที่ไม่มีอยู่ในรายชื่อเริ่มต้นได้

หากคุณเพิ่มภาษาแบบกำหนดเอง ภาษาดังกล่าวจะแสดงในตัวเลือกภาษา ร่วมกับตัวเลือกเริ่มต้น

<br/>

<a id="cost-tracking"></a>

### การติดตามค่าใช้จ่าย

ใช้ **ตั้งค่า** > **การติดตามค่าใช้จ่าย** เพื่อจัดการข้อมูลค่าใช้จ่าย

- **ค่าใช้จ่ายรวม** แสดงผลรวมทั้งหมดที่สะสมไว้
- **คัดลอกค่า** คัดลอกรวมทั้งหมดไปยังคลิปบอร์ด
- **รีเซ็ตค่าใช้จ่าย** ตั้งค่าผลรวมที่จัดเก็บไว้เป็นศูนย์
- **ซิงค์กับการใช้รหัส API** ตั้งค่าผลรวมให้ตรงกับข้อมูลการใช้งานที่รายงานโดยบัญชี OpenRouter ของคุณ (เฉพาะ OpenRouter เท่านั้น)
- **การใช้รหัส API** แสดงรายละเอียดการใช้งานของ OpenRouter หากมีข้อมูล
- **ลบข้อมูลค่าใช้จ่าย** ลบข้อมูลทั้งหมด หรือเฉพาะรายการที่เก่ากว่าวันที่ที่เลือกไว้

**การติดตามค่าใช้จ่าย:** เมื่อคุณใช้โมเดล OpenRouter แอปพลิเคชันจะแสดงการใช้งานและค่าใช้จ่ายที่แท้จริงของคุณ โดยอิงจากข้อมูลค่าใช้จ่ายจาก OpenRouter สำหรับผู้ให้บริการรายอื่น ๆ แอปพลิเคชันจะประมาณการค่าใช้จ่ายโดยใช้ราคาที่เผยแพร่โดย OpenRouter หากไม่มีราคาให้ ค่าประมาณอาจเป็นศูนย์

<br/>

> ℹ️ **หมายเหตุ**<br/>
>  **ตัวเลขค่าใช้จ่ายทั้งหมดเป็นเพียงตัวเลขประมาณการเพื่อการอ้างอิงของคุณเท่านั้น ไม่ใช่ใบแจ้งหนี้อย่างเป็นทางการ**

<br/>

> ⚠️ **คำเตือน**<br/>

> การลบข้อมูลไม่สามารถทำกลับได้ ก่อนการลบ โปรดสำรองข้อมูลหรือส่งออกข้อมูลผ่านทาง [**ประวัติ**](#history)  
> หรือ [**แผงควบคุม** > **การเรียกทั้งหมด**](#dashboard-tabs) มิฉะนั้นข้อมูลจะหายไปอย่างถาวร  
> ประวัติการป้อนข้อมูล/ผลลัพธ์ที่เกี่ยวข้องกับแต่ละรายการการเรียก API จะถูกลบด้วยเช่นกัน


<br/>

<a id="transform-prompts"></a>

### เปลี่ยนแปลงพรอมต์

ใช้ **ตั้งค่า** > **เปลี่ยนแปลงพรอมต์** เพื่อจัดการพรอมต์จำนวนมากพร้อมกัน

คุณสามารถ:

- ตรวจสอบพรอมต์ที่คุณบันทึกไว้
- ลบพรอมต์
- นำเข้าพรอมต์จากไฟล์
- ส่งออกพรอมต์เพื่อสำรองข้อมูลหรือแบ่งปัน
- โหลดตัวอย่างพรอมต์ลงในรายการพรอมต์

<br/>

<a id="users"></a>

### ผู้ใช้งาน

ใช้ **ผู้ใช้งาน** ในการจัดการบัญชีผู้ใช้งานบนเวอร์ชันเว็บ คุณสามารถเพิ่มผู้ใช้งาน อัปเดตรายละเอียด เปลี่ยนรหัสผ่าน และลบบัญชีได้

<br/>

<a id="api-config"></a>

### การตั้งค่า API

ผู้ให้บริการที่รองรับได้แก่: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ **Ollama** (ใช้โมเดลท้องถิ่นผ่าน URL พื้นฐาน) คุณจำเป็นต้องตั้งค่าเฉพาะผู้ให้บริการที่คุณใช้งานเท่านั้น

**สำหรับแอปพลิเคชันเว็บ: เฉพาะผู้ดูแลระบบเท่านั้น**

คีย์ API ถูกตั้งค่าผ่านตัวแปรสภาพแวดล้อมของระบบหรือ Docker — ไม่สามารถป้อนผ่านหน้าเว็บ UI ได้ หน้านี้จะแสดงว่าผู้ให้บริการใดมีการตั้งค่าคีย์เรียบร้อยแล้ว และช่วยให้คุณสามารถทดสอบการทำงานแต่ละตัวได้โดยคลิกที่ปุ่ม **`ทดสอบ`**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ในการเปลี่ยนคีย์ API ให้อัปเดตตัวแปรสภาพแวดล้อมในระบบหรือการตั้งค่า Docker ของคุณ แล้วรีสตาร์ทเซิร์ฟเวอร์หรือคอนเทนเนอร์

> ℹ️ **หมายเหตุ**<br/>

> **การสำรองข้อมูลการตั้งค่า** (ดูที่ [**การตั้งค่าทั่วไป** → การสำรองข้อมูลการตั้งค่า](#general-settings)) สามารถฝังกุญแจผู้ให้บริการที่ **ถูกแก้ไขแล้ว** ไว้ภายในไฟล์ `config.json` ใน ZIP ได้ อย่างไรก็ตาม การกู้คืนจากไฟล์ ZIP นี้จะ **ไม่** คัดลอกกุญแจเหล่านั้นกลับไปยังไฟล์การตั้งค่าของเซิร์ฟเวอร์ กุญแจที่ใช้งานจริงยังคงถูกดึงมาจากสภาพแวดล้อม (environment) และสถานะของไฟล์เดิมตามที่อธิบายไว้

<br/>

**แอปพลิเคชันเดสก์ท็อป**

ใช้ **การตั้งค่า API** เพื่อจัดเก็บกุญแจ API สำหรับแต่ละผู้ให้บริการที่คุณใช้ สำหรับ Ollama ให้กรอก **URL พื้นฐาน** แทนที่จะใส่กุญแจ API

<br/>

> 💡 **เคล็ดลับ** <br/>
> ถ้าคุณไม่ต้องการใช้กุญแจ API หรือไม่ต้องการจ่ายเงินสำหรับการใช้งาน คุณสามารถ [ดาวน์โหลด Ollama](https://ollama.com) และรันโมเดล (เช่น `translategemma:4b`) บนเครื่องของคุณเองได้ฟรี หรืออีกทางหนึ่ง คุณสามารถสร้างบัญชี OpenRouter ฟรี (ไม่ต้องใช้บัตรเครดิต) เพื่อใช้โมเดลฟรีของพวกเขานอกจากนี้ ยังสามารถขอรับกุญแจ API ฟรีจาก Cerebras, Google, Groq หรือ Mistral AI ได้อีกด้วย

<br/>

- เพิ่มเฉพาะผู้ให้บริการที่คุณต้องการเท่านั้น ที่ **การตั้งค่า** > **โมเดล** รหัสของแต่ละโมเดลจะขึ้นต้นด้วยชื่อผู้ให้บริการ (ตัวอย่างเช่น `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)

ในการเพิ่มคีย์ API ให้ป้อนค่าลงในช่องข้อความแล้วคลิก **`บันทึก`** เพื่อเปลี่ยนคีย์ที่มีอยู่แล้ว ให้คลิก **`แก้ไข`** เพื่อตรวจสอบว่าคีย์ทำงานได้หรือไม่ ให้คลิก **`ทดสอบ`** สำหรับ URL พื้นฐานของ Ollama ให้คลิก **`ทดสอบ`** เสมอเพื่อตรวจสอบการเชื่อมต่อ

<br/>

> ℹ️ **ข้อควรทราบ**<br/>
> คุณจะไม่สามารถดูค่าของคีย์ API ที่ใช้อยู่ได้ คุณสามารถแก้ไขใหม่ได้เฉพาะโดยใช้ปุ่ม **`แก้ไข`** เท่านั้น  
> คีย์ API จะถูกจัดเก็บแบบเข้ารหัสไว้ในข้อมูลการตั้งค่า

<br/>

<a id="common-issues"></a>

## ปัญหาทั่วไป

หากมีบางอย่างไม่ทำงานตามที่คาดไว้ โปรดตรวจสอบประเด็นต่อไปนี้ก่อน

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>

### แอปพลิเคชันจะไม่แปล ปรับถ้อยคำ หรือเปลี่ยนแปลงข้อความ

โปรดตรวจสอบว่า:

- คุณได้เลือกโมเดลในแถบเครื่องมือแล้ว
- มีการระบุโมเดลอย่างน้อยหนึ่งตัวในส่วน [**การตั้งค่า** > **โมเดล**](#models)
- การตั้งค่า API ของคุณทำงานได้ถูกต้อง

หากคุณใช้แอปพลิเคชันรุ่นเดสก์ท็อป:

1. เปิดที่ [**การตั้งค่า** > **การตั้งค่า API**](#api-config)
2. ตรวจสอบว่ามีการบันทึกคีย์ API อย่างน้อยหนึ่งคีย์
3. คลิกที่ปุ่ม **ทดสอบ** ถัดจากผู้ให้บริการ เพื่อยืนยันว่าคีย์นั้นใช้งานได้

<br/>

<a id="the-model-list-is-empty"></a>

### รายการโมเดลว่างเปล่า

เปิดไปที่ [**การตั้งค่า** > **โมเดล**](#models) แล้วคลิก **รีเฟรช**

ถ้าจำเป็น:

- ค้นหาโมเดล
- เปิดใช้งาน **เฉพาะแบบฟรี**
- เพิ่มโมเดลหนึ่งรายการหรือมากกว่าเข้าไปที่ **โมเดลที่เลือก**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>

### ผลลัพธ์ช้าเกินไปหรือมีค่าใช้จ่ายสูงเกินไป

ลองทำอย่างใดอย่างหนึ่ง หรือมากกว่าต่อไปนี้:

- เลือกใช้โมเดลที่ต่างออกไป
- ใช้ข้อความนำเข้าที่สั้นลง
- ปิดฟีเจอร์ **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** ใน [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)
- ใช้โมเดลฟรีสำหรับงานง่าย ๆ (ดูที่ [โมเดล](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>

### อินเทอร์เฟซแสดงภาษายังไม่ถูกต้อง

คลิกที่ไอคอนรูปโลกใน [แถบเครื่องมือ](#toolbar) แล้วเลือก **ภาษาอินเทอร์เฟซ** ที่คุณต้องการ

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>

### ข้อความมีขนาดเล็กเกินไปหรืออ่านยาก

เปิด [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) แล้วเปลี่ยนแปลง:

- **ตระกูลแบบอักษร**
- **ขนาด**

<br/>

<a id="dashboard-charts-are-empty"></a>

### กราฟในแดชบอร์ดว่างเปล่า

เป็นเรื่องปกติหาก:

- คุณใช้เฉพาะ **โมเดลฟรี** และกำลังดูตัวเลข **ต้นทุน** (อาจเป็นศูนย์ได้); กราฟจำนวนการใช้งานในแท็บ **สรุป** ยังต้องการข้อมูลจากระยะเวลาที่เลือก
- **ตัวกรองเวลา** ที่เลือกไม่ครอบคลุมช่วงเวลาที่มีการเรียกใช้งาน — ลองใช้ **ทั้งหมด** เพื่อตรวจสอบ

หากกราฟยังคงว่างแม้หลังจากเลือก **ทั้งหมด** ให้ตรวจสอบว่ามีรายการเรียกใช้งานปรากฏอยู่ในแท็บ [**ประวัติ**](#history) หรือในแท็บ **การเรียกทั้งหมด**

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### ต้นทุนแสดงเป็น "ไม่สามารถระบุได้" หรือดูเหมือนไม่ถูกต้อง

เมื่อคุณใช้โมเดลผ่าน **OpenRouter** แอปจะแสดงค่าใช้จ่ายจริงที่รายงานโดย OpenRouter

สำหรับ **ผู้ให้บริการอื่นๆ** (เช่น OpenAI โดยตรง, Anthropic โดยตรง ฯลฯ) ต้นทุนจะถูกประมาณการจากข้อมูลราคาที่เผยแพร่โดย OpenRouter หากไม่พบราคาที่ตรงกับโมเดล ต้นทุนจะแสดงเป็น **ไม่สามารถระบุได้** และจะไม่ถูกรวมในยอดรวมของคุณ

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>

### ค่าใช้จ่ายรวมไม่ตรงกับใบเรียกเก็บเงินจากผู้ให้บริการของฉัน

ตัวเลขค่าใช้จ่ายทั้งหมดในแอปพลิเคชันนี้เป็นเพียง **ประมาณการสำหรับการอ้างอิงเท่านั้น** ไม่ใช่ใบแจ้งหนี้ทางการ

หากต้องการให้ยอดรวมใกล้เคียงกับค่าใช้จ่ายจริงของคุณบน OpenRouter ให้เปิดที่ [**การตั้งค่า** > **การติดตามต้นทุน**](#cost-tracking) แล้วคลิก **ซิงค์กับการใช้งาน API key**

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>

### หน้าประวัติหายไปจากรูปด้านข้าง

**เก็บประวัติการดำเนินการ** อาจถูกปิดอยู่ ให้เปิด [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) แล้วเปิดใช้งานฟีเจอร์นี้ โปรดสังเกตว่าการเปิดใช้งานจะไม่คืนข้อมูลประวัติที่ถูกลบไปก่อนหน้านี้กลับมา

<br/>

<a id="web-app-session-expired"></a>

### แอปเว็บ: ถูกเปลี่ยนเส้นทางไปยังหน้าล็อกอินโดยไม่คาดคิด

เซสชันของคุณอาจหมดเวลา โปรดล็อกอินอีกครั้ง หากปัญหานี้เกิดขึ้นบ่อยครั้ง ให้ตรวจสอบการตั้งค่าเว็บเซิร์ฟเวอร์เกี่ยวกับระยะเวลาของเซสชัน

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>

### การจัดการเว็บ: ลืมหรือสูญหายรหัสผ่าน

สิ่งนี้ใช้กับ **แอปเว็บแบบติดตั้งเอง** (Docker) เท่านั้น ไม่ใช่กับแอปตัวติดตั้งบนเดสก์ท็อป (Electron)

- ถ้ามีผู้ดูแลระบบคนอื่นยังสามารถเข้าสู่ระบบได้ พวกเขาสามารถเปิดที่ [**ตั้งค่า** > **ผู้ใช้**](#users) เลือกบัญชีที่ต้องการ แล้วตั้ง **รหัสผ่านใหม่** ได้ที่นั่น
- หากคุณ **เข้าสู่ระบบไม่ได้** แต่สามารถเข้าถึง **shell** ของเครื่องหรือคอนเทนเนอร์ได้ ให้รีเซ็ตรหัสผ่านโดยใช้คำสั่งช่วยที่มากับภาพ (image) (หากคุณเปลี่ยนชื่อจากค่าเริ่มต้น ให้แทนที่ `transrewrt` ด้วยชื่อที่คุณใช้ และห่อรหัสผ่านด้วยเครื่องหมายคำพูดหากมีช่องว่างหรืออักขระพิเศษ):

```bash
docker exec transrewt reset-web-password '<username>' '<new-password>'
```

ชื่อผู้ใช้ผู้ดูแลเริ่มต้นคือ `admin` หากคุณยังไม่ได้สร้างบัญชีอื่นไว้ เมื่อคุณระบุอาร์กิวเมนต์เพียงหนึ่งค่า ระบบจะตีความว่าเป็นรหัสผ่านใหม่สำหรับ `admin`

หากคุณรันจากการ **ดึงซอร์สโค้ดมาใช้งาน** แทนที่จะใช้ Docker ให้ใช้คำสั่ง:

```bash
pnpm run reset-web-password -- <username> <new-password>

สคริปต์นี้จะอัปเดตข้อมูลผู้ใช้ในฐานข้อมูล SQLite (และสามารถสร้างผู้ใช้ `admin` ได้หากไม่มีอยู่) หลังจากรีเซ็ตแล้ว ให้เข้าสู่ระบบด้วยรหัสผ่านใหม่


<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>

### แดชบอร์ดไม่แสดงข้อมูลของผู้ใช้รายอื่น (เว็บ)

เฉพาะ **ผู้ดูแลระบบ** เท่านั้นที่สามารถดูข้อมูลจากผู้ใช้ทั้งหมดผ่านตัวกรอง **ผู้ใช้** ผู้ใช้ทั่วไปจะเห็นเฉพาะกิจกรรมของตนเองเท่านั้นตามการออกแบบ

### ฉันเปลี่ยนพรอมต์แล้วแต่การแก้ไขหายไป

เมื่อทำการแก้ไขพรอมต์ อย่าลืมคลิกที่ **บันทึก** ก่อนคลิกที่ **กลับไปที่รัน**

<a id="quick-tips"></a>

## เคล็ดลับที่ควรรู้

- เริ่มต้นด้วย [**แปล**](#translate) เพื่อตรวจสอบให้แน่ใจว่าการตั้งค่าของคุณทำงานได้ก่อนไปยัง [**เขียนใหม่**](#rewrite) หรือ [**แปลง**](#transform)
- ใช้ [**เขียนใหม่**](#rewrite) เพื่อปรับปรุงข้อความในชีวิตประจำวัน
- ใช้ [**แปลง**](#transform) เมื่อต้องการเวิร์กโฟลว์ที่สามารถทำซ้ำได้สำหรับงานเฉพาะอย่าง
- ใช้ [**แดชบอร์ด**](#dashboard) หากต้องการติดตามการใช้งานและค่าใช้จ่าย
- ใช้ [**ประวัติ**](#history) เพื่อทบทวนการทำงานก่อนหน้า พร้อมทั้งข้อความนำเข้าและส่งออกทั้งหมด
- ส่งออกพรอมต์อย่างสม่ำเสมอ หากคุณกำลังสร้างคลังพรอมต์ที่ต้องการสำรองไว้อย่างปลอดภัย (ดู [พรอมต์แปลง](#transform-prompts)) หรือหากต้องการแบ่งปันกับผู้อื่น
