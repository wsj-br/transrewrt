# คู่มือการใช้งาน Transrewrt

<br />

<a id="introduction"></a>
## การนำเสนอ

Transrewrt ช่วยให้คุณทำงานกับข้อความได้ในสามวิธีหลัก:

- **Translate** - แปลงข้อความจากภาษาหนึ่งเป็นอีกภาษาหนึ่ง
- **Rewrite** - เปลี่ยนรูปแบบข้อความให้ดีขึ้น เช่น ให้𝑡ique ที่ชัดเจน สั้นขึ้น หรือเป็นทางการขึ้น
- **Transform** - ประมวลผลข้อความโดยใช้อUCTION AI ที่กำหนดเอง เรียกว่า prompts

<br />

คู่มือนี้อธิบายวิธีการใช้แอปฯ หลังจากการติดตั้งและรันอยู่แล้ว สำหรับขั้นตอนการติดตั้ง ให้ดูที่ [README](../README.md) หลัก

<br />

> ℹ️ **หมายเหตุ**<br/>
> Transrewrt มี semenjadiแอปเดสก์ท็อประสำหรับ Windows และ Linux และแอปเว็บที่ซื้อ-Host คู่มือนี้เน้นการใช้แอปภายในleben крикета-use เป็นประจำ หากมีบางสิ่ง言情เฉพาะเวอร์ชันใดเวอร์ชันหนึ่ง จะระบุชัดเจน

<a id="before-you-start"></a>

## ก่อนเริ่ม

เพื่อใช้ Transrewrt คุณจำเป็นต้องเข้าถึงบริการ AI ผ่าน OpenRouter.

คุณไม่จำเป็นต้องเลือกโมเดลที่เสียเงินก่อนเริ่ม การ应用中Arrivesรวมโมเดล **ฟรี** ที่มีอยู่แล้ว ดังนั้นในการใช้งานปกติ มันเพียงพอสำหรับการเริ่มการแปล การเขียนใหม่ และการแปลงข้อความ

 perfume ข้อความ:

- **โมเดล** คือ AI engine ที่ทำงาน
- **คีย์ API** คือข้อมูลรับรองการเข้าถึงส่วนตัวของคุณสำหรับบริการนั้น

หากคุณใช้ **แอปเดสก์ท็อป** คุณจะต้องการคีย์ API สำหรับขั้นตอนที่ละเอ向下 see [วิธีการได้รับคีย์ API](#how-to-get-an-api-key-desktop-app) ด้านล่าง โดยสรุป: สร้างบัญชีที่ [OpenRouter](https://openrouter.ai) เปิดหน้า [คีย์](https://openrouter.ai/keys) สร้างคีย์ใหม่ และวางไว้ใน [**การตั้งค่า** > **การกำหนดค่า API**](#api-config) ใน Transrewrt

หากคุณใช้ **เวอร์ชันเว็บ** เจ้าของเซิร์ฟเวอร์จะทำการตั้งให้โดยทั่วไป จะไม่จำเป็นให้คุณใส่คีย์ API ด้วยเองโดยปกติ

<br />

<a id="how-to-get-an-api-key-desktop-app"></a>
### วิธีการได้รับคีย์ API (แอปเดสก์ท็อป)

หากคุณใช้แอปเดสก์ท็อป ให้ทำตามขั้นตอนเหล่านี้:

1. ไปที่ [OpenRouter](https://openrouter.ai) ในเว็บเบราว์เซอร์ของคุณ
2. สร้างบัญชีหรือลงชื่อเข้าใช้
3. เปิดหน้า [คีย์](https://openrouter.ai/keys)
4. คลิกปุ่มเพื่อสร้างคีย์ API ใหม่
5. ตั้งชื่อให้คีย์เพื่อให้คุณจำได้ในภายหลัง
6. คัดลอกคีย์ API ใหม่
7. กลับไปที่ Transrewrt และเปิด **การตั้งค่า** > **การกำหนดค่า API**
8. วางคีย์ใน **คีย์ API ของ OpenRouter**
9. คลิก **ทดสอบการกำหนดค่า API** เพื่อให้แน่ใจว่ามันทำงาน

> ℹ️ **หมายเหตุ**<br/>
> คุณสามารถเริ่มกับ free route ฟรีของ OpenRouter หรือโมเดลฟรีอื่นๆ ที่มีให้ ในหลายกรณี มันเพียงพอสำหรับการใช้ Transrewrt โดยไม่ต้องเลือกโมเดลที่เสียเงิน

<br /><br />

<a id="getting-started"></a>
## เริ่มต้นใช้งาน

หากนี้เป็นครั้งแรกที่คุณใช้ Transrewrt ทำตามลำดับนี้:

1. เปิดแอป
2. เลือก **ภาษ嫡โปรแกรม** จากไอคอน globe หากจำเป็น
3. หากคุณอยู่บน **แอปเดสก์ท็อป** เปิด [**การตั้งค่า** > **การกำหนดค่า API**](#api-config) วางคีย์ API ของ OpenRouter และคลิก **ทดสอบการกำหนดค่า API**
4. เปิด [**การตั้งค่า** > **โมเดล**](#models) และเพิ่มโมเดลหนึ่ง或多个ไปใน **โมเดลที่เลือก**
5. เปิด [**การตั้งค่า** > **ภาษา**](#languages) และเลือก **ภาษ塌ที่ใช้บ่อย** หากคุณต้องการภาษาที่ใช้บ่อยจะปรากฏก่อน
6. ไปที่ **แปล** และรันการแปลอย่างง่ายเพื่อยืนยันว่าทุกอย่างทำงาน
7. เมื่อมันทำงานแล้ว ลอง **เขียนใหม่** และต่อมา **แปลง**

ลำดับนี้สำคัญ มันป้องกันปัญหาที่พบบ่อยเมื่อใช้งานครั้งแรก: พยายามรันงานก่อนที่แอปจะมีIkkeการเชื่อมต่อ API ที่ทำงานหรือไม่มีโมเดลที่เลือก

<a id="input-and-output-panels"></a>
## แผงข้อมูลเข้าและข้อมูลออก

### พ্যানেলInputและOutput

ส่วนใหญ่ของ workstation ใช้พ্যানেল **Input** ด้านซ้ายและพ্যানেল **Output** ด้านขวา

พ্যানেল **Input** แสดง:

- จำนวนตัวอักษร
- จำนวนคำ
- จำนวนย่อหน้า

พ্যানেল **Output** สามารถแสดง:

- ระยะเวลาที่งานใช้
- ต้นทุนของงานนั้น
- ต้นทุนรวมทั้งหมดของคุณ
- **TPS** (tokens per second) ซึ่งเป็นตัวชี้วัดความเร็วอย่างง่าย
- จำนวนตัวอักษร คำ และย่อหน้า
- โมเดลที่ใช้

หากคุณสงสัยเกี่ยวกับคำศัพท์ทางเทคนิค:

- **Token** หมายถึงส่วนเล็กๆ ของข้อความ คุณคิดว่าเป็นส่วนหนึ่งของคำหรือคำสั้นๆ
- **TPS** หมายถึงจำนวนส่วนข้อความที่โมเดลประมวลผลในหนึ่งวินาที

<a id="translate"></a>
## Translate

ใช้ **Translate** เมื่อคุณต้องการแปลงข้อความจากภาษาหนึ่งเป็นอีกภาษาหนึ่ง

![Translate workspace](../images/screenshots/th/translate.png)

<br />

<a id="translate-text"></a>
### แปลข้อความ

1. เปิด **Translate**
2. เลือกภาษาใน **From**
3. เลือกภาษาใน **To**
4. เลือกโมเดลในแถบเครื่องมือ
5. พิมพ์หรือวางข้อความใน **Input**
6. คลิก **Translate**
7. อ่านผลลัพธ์ใน **Output**
8. ใช้ปุ่มคัดลอกหากคุณต้องการคัดลอกผลลัพธ์

<br />

<a id="language-selection"></a>
### การเลือกภาษา

- **From** สามารถเป็นภาษาก aluminium หรือ **Detect Language**
- **To** เป็นภาษาที่คุณต้องการผลลัพธ์

ภาษาที่คุณโปรดปราน **Top languages** จะปรากฏที่ด้านบนของรายการ คุณสามารถตั้งค่าใน [**Settings** > **Languages**](#languages)

<br />

<a id="helpful-translation-settings"></a>
### การตั้งค่าการแปลที่เป็นประโยชน์

ใน [**Settings** > **General Settings**](#general-settings) คุณสามารถเปลี่ยนพฤติกรรมการแปล:

- **Auto-translate on paste** ดำเนินการแปลทันทีที่คุณวางข้อความ
- **Auto-copy result to clipboard** คัดลอกผลลัพธ์โดยอัตโนมัติหลังงานเสร็จสมบูรณ์
- **Real-time translation (while typing)** ออกแบบการแปลขณะที่คุณพิมพ์
- **Timeout (ms)** ควบคุมระยะเวลาสักคร Horsefly ที่แอปจะ.wait ก่อนดำเนินการแปลแบบเรียลไทม

<a id="rewrite"></a>
## Rewrite

ใช้ **Rewrite** เมื่อคุณต้องการปรับปรุงการใช้คำโดยไม่เปลี่ยนความหมายหลัก

![Rewrite workspace](../images/screenshots/th/rewrite.png)

สิ่งนี้มีประโยชน์สำหรับ:

- แก้fon spell และไวยากรณ์
- ทำให้ข้อความชัดเจนขึ้น
- ทำให้ข้อความเป็นทางการหรือเป็นกันเองมากขึ้น
- แxor หรือขยายข้อความ
- ทำให้ข้อความดูเป็นทางเทคนิคมากขึ้น

<br />

<a id="rewrite-text"></a>
### Rewriteข้อความ

1. เปิด **Rewrite**
2. เลือก **Mode**
3. เลือกโมเดลในแถบเครื่องมือ
4. พิมพ์หรือวางข้อความใน **Input**
5. คลิก **Rewrite**
6. ตรวจสอบผลลัพธ์ใน **Output**

พฤติกรรมของคีย์ Enter เหมือนกับที่อธิบายใน [**Translate**](#keyboard-shortcuts) ก็ใช้ที่นี่ด้วย

<a id="transform"></a>
## Transform

ใช้ **Transform** เมื่อคุณต้องการให้ AI ตามชุดคำสั่งที่กำหนดเอง

![Transform workspace](../images/screenshots/th/transform.png)

นี้เป็นพื้นที่ที่ยืดหยุ่นที่สุดของแอป คุณสามารถใช้สำหรับงานเช่น:

- สรุปบันทึก
- แปลงข้อความที่คลุมเครือเป็นอีเมลที่มีการจัดรูปแบบ
- แยกจุดสำคัญ
- แปลงข้อความเป็นรูปแบบที่จำเพาะ

<br />

<a id="run-an-existing-prompt"></a>
### รัน promptที่มีอยู่

1. เปิด **Transform**
2. เลือก prompt จากรายการ prompt
3. หากกล่องภาษา **Target** ปรากฏ เลือกภาษาหากต้องการ
4. พิมพ์หรือวางข้อความใน **Input**
5. คลิก **Transform**
6. อ่านผลลัพธ์ใน **Output**

<a id="create-a-prompt-quickly"></a>

### สร้างพรอมท์อย่างรวดเร็ว

วิธีสร้างพรอมท์อย่างรวดเร็วที่สุดคือ:

1.คลิก **พรอมท์ใหม่**.
2.คลิก **สร้างพรอมท์**.
3.อธิบายสิ่งที่ต้องการให้พรอมท์ทำ.
4.เลือกโมเดล.
5.แอปจะสร้าง Preliminary Draft ให้คุณ.
6.ตรวจสอบ Preliminary Draft และคลิก **บันทึก**.

![สร้างพรอมท์](../images/screenshots/th/transform-generate.png)


<br />

### แก้ไขพรอมท์

เมื่อคุณสร้างหรือแก้ไขพรอมท์ ผู้แก้ไขจะปรากฏด้านซ้ายและพื้นที่ทดสอบจะปรากฏด้านขวา.

![แก้ไขพรอมท์](../images/screenshots/th/transform-prompt-edit.png)

ฟิลด์หลักคือ:

- **ชื่อพรอมท์**: ชื่อที่แสดงในรายการพรอมท์.
- **คำสั่งพรอมท์ (ไม่จำเป็น)**: คำแนะนำสั้นที่แสดงให้กับผู้ใช้เมื่อรันพรอมท์.
- **บทบาทของโมเดล**: บทบาทโดยรวมที่กำหนดให้กับ AI เช่น 'คุณเป็นผู้ช่วยที่เป็นประโยชน์.'
- **คำInstructionsของโมเดล (หนึ่งรายการต่อบรรทัด)**: กฎเฉพาะที่คุณต้องการให้ AI ตาม.
- **ลักษณะผลลัพท์**: คำสั้นที่อธิบายผลลัพธ์ เช่น 'สรุป' หรือ 'เขียนใหม่'.
- **อุณหภูมิ (0.0 → 1.0)**: เส้นเลื่อนความสร้างสรรค์.
- **ร้องขอภาษเป้าหมาย**: เพิ่มตัวเลือกภาษเป้าหมายเมื่อรันพรอมท์.

หากคำศัพท์เทคนิค **อุณหภูมิ** เป็นสิ่งใหม่สำหรับคุณ คิดในทิศทางนี้:

- **อุณหภูมิต่ำ** จะให้ผลลัพท์ที่มั่นคง  przewritable.
- **อุณหภูมิสูง** จะให้ความหลากหลายและสร้างสรรค์มากขึ้น.

คุณยังสามารถใช้:

- **`สร้างพรอมท์`** เพื่อสร้าง Preliminary Draft ใหม่จากคำอธิบายง่ายๆ
- **`ปรับปรุงพรอมท์`** เพื่อปรับพรอมท์ที่มีอยู่
- **`แปลพรอมท์`** เพื่อแปลฟิลด์พรอมท์

> ⚠️ **คำเตือน**<br/>
- คลิก **`บันทึก`** ก่อนคลิก **`กลับไปรัน`**. หากกลับไปโดยไม่บันทึก การเปลี่ยนแปลงของคุณจะสูญหาย.

<a id="general-settings"></a>

### การตั้งค่าทั่วไป

ใช้ **การตั้งค่าทั่วไป** เพื่อควบคุมพฤติกรรมการพิมพ์และรูป outward

**พฤติกรรม**

- **พฤติกรรมสำหรับคีย์ ENTER** ใช้เลือกว่าคีย์ ENTER จะรันงานหรือแทรกบรรทัดใหม่
- **แปลอัตโนมัติเมื่อวาง** เริ่มการแปลทันทีเมื่อคุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดโดยอัตโนมัติ** คัดลอกผลลัพธ์ที่สำเร็จไปยังคลิปบอร์ดโดยอัตโนมัติ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** ทำการแปลขณะที่คุณพิมพ์
- **เวลารอ (มิลลิวินาที)** กำหนดระยะเวลารอสำหรับการแปลแบบเรียลไทม์

**ลักษณะ внешний**

- **จำนวนทศนิยมของ Fraction Cost** เปลี่ยนวิธีแสดงทศนิยมของค่าใช้จ่าย
- **ตระกูลตัวอักษร** เปลี่ยนตัวอักษรที่ใช้ในแผ่นข้อความ
- **ขนาด** เปลี่ยนขนาดตัวอักษร
- **เฉพาะ Web:** **แสดงขอบínioรอบแอพ** เพิ่มพื้นที่อิสระรอบ界面

<a id="cost-tracking"></a>
### การติดตามค่าใช้จ่าย

ใช้ **การตั้งค่า** > **การติดตามค่าใช้จ่าย** เพื่อจัดการข้อมูลค่าใช้จ่าย

- **ลบข้อมูลค่าใช้จ่าย** ลบข้อมูลทั้งหมด หรือลบรายการที่เก่ากกว่าวันที่เลือกเท่านั้น

> ⚠️ **คำเตือน**<br/>

**เฉพาะ Desktop**

ใช้ **การตั้งค่า API** เชื่อมต่อแอพ Desktop กับ OpenRouter หรือ Transrewrt proxy

- **API Key ของ OpenRouter** เป็นพื้นที่ที่คุณวางคีย์
- **URL ของ API** เป็นที่อยู่ of the servicio ปล่อยไว้เป็นค่าเริ่มต้น except คุณได้รับที่アドress อื่น
- **ใช้ Transrewrt Proxy** เส้นทางการRequests ผ่านบริการПрокศิ-in สำหรับแทนการส่งตรงไปยัง OpenRouter
- **Seed ของ Key** ปรากฏเมื่อเปิดตัวเลือกПрокศิ-in
- **ทดสอบการตั้งค่า API** ตรวจสอบว่าตั้งค่าปัจจุบันทำงานหรือไม่

สำหรับขั้นตอนที่ละเอียด regarding การได้ API key ของคุณ ดู [วิธีได้รับ API key](#how-to-get-an-api-key-desktop-app) ข้างต้น

> ℹ️ **หมายเหตุ**<br/>
> หากคุณไม่แน่ใจว่าคำว่า **URL ของ API**, **ใช้ Transrewrt Proxy**, หรือ **Seed ของ Key** หมายความrequent อะไร ปล่อยให้คงอยู่不变และใช้การตั้งค่า OpenRouter เริ่มต้น ข้อมูลเพิ่มเติมเกี่ยวกับПрокศி-in มีอยู่ใน [ที่พักเน集体的 Transrewrt Proxy](https://github.com/wsj-br/transrewrt-proxy)

<a id="common-issues"></a>
## ปัญหาที่พบบ่อย

หากสิ่งใดไม่ทำงานตามที่คาดหวัง ให้ตรวจสอบจุดต่อไปนี้ก่อน

<br />

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### แอปจะไม่แปล, เขียนใหม่, หรือแปลงข้อความ

ตรวจสอบว่า:

- คุณได้เลือกโมเดลในแถบเครื่องมือ
- มีอย่างน้อยหนึ่งโมเดลอยู่ใน [**การตั้งค่า** > **โมเดล**](#models)
- การกำหนดค่า API ของคุณทำงานได้

หากคุณใช้แอปเดสก์ท็อป:

1. เปิด [**การตั้งค่า** > **การกำหนดค่า API**](#api-config).
2. ตรวจสอบว่า API key ของคุณถูกบันทึก.
3. คลิก **ทดสอบการกำหนดค่า API**.

<br />

<a id="the-model-list-is-empty"></a>
### รายการโมเดลว่างเปล่า

เปิด [**การตั้งค่า** > **โมเดล**](#models) แล้วคลิก **รีเฟรช**.

หากจำเป็น:

- ค้นหาโมเดล
- เปิด **ฟรีเท่านั้น**
- เพิ่มโมเดลหนึ่งตัวหรือมากกว่า Into **โมเดลที่เลือก**

<br />

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ผลลัพธ์ช้าหรือแพงเกินไป

ลองอย่างหนึ่งหรือมากกว่า:

- เลือกโมเดลอื่น
- ใช้ข้อมูลอินพุตที่สั้นลง
- ปิด **การแปลตามเรียลไทม์ (ขณะพิมพ์)** ใน [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)
- ใช้โมเดลฟรีสำหรับงานง่าย (ดู [โมเดล](#models))

<br />

<a id="the-interface-is-in-the-wrong-language"></a>
### ส่วนติดต่ออยู่ในภาษาที่ไม่ถูกต้อง

คลิกไอคอนGlobe ใน [แถบเครื่องมือ](#toolbar) แล้วเลือก **ภาษalletsส่วนติดต่อ** ที่คุณต้องการ

<br />

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ข้อความเล็กเกินไปหรืออ่านยาก

เปิด [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) แล้วปรับเปลี่ยน:

- **ประเภทฟอนต์**
- **ขนาด**

<br />

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ฉันแก้ไขพรอมต์และ改变ถูกทำหาย

เมื่อแก้ไขพรอมต์ ต้องคลิก **บันทึก** ก่อนคลิก **กลับไปรัน**

<br /><br />

<a id="quick-tips"></a>
## เคล็ดลับด่วน

- เริ่มต้นด้วย [**แปล**](#translate) To ensure your setup works before moving to [**เขียนใหม่**](#rewrite) or [**แปลง**](#transform)
- ใช้ [**เขียนใหม่**](#rewrite) สำหรับปรับปรุงภาษ Provides ในชีวิตประจำวัน
- ใช้ [**แปลง**](#transform) เมื่อต้องการเวิর্ক์โฟลว์ที่ทำซ้ำได้สำหรับงานที่เฉพาะเจาะจง
- ใช้ [**แดชบอร์ด**](#dashboard) หากต้องการติดตามการใช้และค่าใช้จ่าย
- ส่งออกพรอมต์อย่างสม่ำเสมอหากสร้างคลังพรอมต์ที่ต้องการรักษาความปลอดภัย (ดู [พรอมต์การแปลง](#transform-prompts))
