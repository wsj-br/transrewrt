# คู่มือผู้ใช้งาน

<br/>

<a id="introduction"></a>
## บทนำ

Transrewrt ช่วยให้คุณทำงานกับข้อความได้ 3 วิธีหลัก ดังนี้:

- **แปลภาษา** - แปลงข้อความจากรูปแบบภาษาหนึ่งไปยังอีกภาษาหนึ่ง
- **เขียนใหม่** - เขียนข้อความใหม่ในรูปแบบที่ต่างออกไป เช่น ให้เข้าใจง่ายขึ้น สั้นลง หรือเป็นทางการมากขึ้น
- **แปลงรูปแบบ** - ประมวลผลข้อความโดยใช้คำแนะนำปัญญาประดิษฐ์แบบกำหนดเองที่เรียกว่า "พรอมต์"

<br/>

คู่มือนี้อธิบายวิธีใช้งานแอปพลิเคชันหลังจากติดตั้งและเริ่มใช้งานเรียบร้อยแล้ว สำหรับขั้นตอนการติดตั้ง ดูที่ **[README](README.th.md)** หลัก

<br/>

> ℹ️ **หมายเหตุ**<br/>
> Transrewrt มีให้ใช้งานเป็นแอปพลิเคชันสำหรับเดสก์ท็อปบน Windows และ Linux และยังมีเป็นเว็บแอปพลิเคชันแบบติดตั้งเองได้ คู่มือนี้เน้นไว้สำหรับการใช้งานทั่วไป โดยหากสิ่งใดใช้ได้กับรุ่นใดรุ่นหนึ่งเฉพาะ จะมีการระบุไว้อย่างชัดเจน

<a id="before-you-start"></a>

## ก่อนที่คุณจะเริ่มต้น

หากต้องการใช้งาน Transrewrt คุณจำเป็นต้องมีการเข้าถึงผู้ให้บริการ AI อย่างน้อยหนึ่งราย ผู้ให้บริการที่รองรับได้แก่ [OpenRouter](https://openrouter.ai) (ซึ่งรวบรวมโมเดลจำนวนมากเข้าไว้ด้วยกัน), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI และ [Ollama](https://ollama.com) สำหรับโมเดลที่ใช้งานในเครื่อง

คุณไม่จำเป็นต้องเลือกใช้โมเดลแบบเสียเงินในการเริ่มต้น เมื่อคุณเพิ่ม API key ของ OpenRouter แล้ว แอปจะเปิดใช้งานทางเลือกของ OpenRouter ที่ให้บริการฟรีโดยอัตโนมัติ สิ่งนี้ทำให้คุณสามารถเริ่มแปล ปรับปรุงข้อความ และเปลี่ยนรูปแบบข้อความได้ทันที

อธิบายอย่างง่าย:

- **โมเดล** คือ เครื่องยนต์ปัญญาประดิษฐ์ที่ทำหน้าที่ประมวลผล โดยโมเดลจะแสดงรายชื่อพร้อมคำนำหน้าของ **ผู้ให้บริการ** (เช่น `openrouter/…`, `openai/…`, `ollama/…`)
- **API key** (หรือสำหรับ Ollama คือ **base URL**) คือ วิธีที่แอปใช้ในการเชื่อมต่อกับผู้ให้บริการนั้น

หากคุณกำลังใช้ **แอปเดสก์ท็อป** ให้เพิ่มคีย์ในส่วน [**การตั้งค่า** > **การกำหนดค่า API**](#api-config) สำหรับผู้ให้บริการแต่ละรายที่คุณใช้ หากใช้เฉพาะ OpenRouter ให้ดูที่ [วิธีรับ API key](#how-to-get-an-api-key-desktop-app) ด้านล่าง หากคุณไม่ต้องการใช้ API key คุณสามารถติดตั้ง Ollama (จาก [ollama.com](https://ollama.com)) และใช้โมเดลในเครื่องแทนได้

หากคุณใช้ **รุ่นเว็บ** ผู้ดูแลระบบเซิร์ฟเวอร์จะเป็นผู้กำหนดผู้ให้บริการผ่านตัวแปรสภาพแวดล้อม (environment variables) ดังนั้นคุณจะไม่ต้องป้อน API key เองในทางปกติ

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### วิธีรับ API key ของ OpenRouter ฟรี (สำหรับแอปเดสก์ท็อป)

หากคุณใช้แอปเดสก์ท็อป ให้ทำตามขั้นตอนต่อไปนี้:

1. เปิดเว็บเบราว์เซอร์แล้วไปที่ [OpenRouter](https://openrouter.ai)
2. สร้างบัญชีผู้ใช้หรือลงชื่อเข้าใช้
3. เข้าสู่หน้า [Keys](https://openrouter.ai/keys)
4. คลิกปุ่มเพื่อสร้าง API key ใหม่
5. ตั้งชื่อให้กับคีย์นี้เพื่อให้คุณสามารถระบุได้ในอนาคต
6. คัดลอก API key ใหม่ที่ได้
7. กลับไปที่ Transrewrt แล้วเปิด **การตั้งค่า** > **การกำหนดค่า API**
8. วางคีย์ลงในช่อง **OpenRouter API key** (ภายใต้ **การตั้งค่า** > **การกำหนดค่า API**)
9. คลิก **Test OpenRouter key** เพื่อทดสอบว่าใช้งานได้

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณสามารถเริ่มต้นใช้บริการเส้นทางฟรีของ OpenRouter หรือโมเดลอื่นที่มีให้ใช้ฟรีโดยไม่ต้องใส่ข้อมูลบัตรเครดิตได้ ในหลายกรณี นี่เพียงพอสำหรับการเริ่มต้นใช้ Transrewrt โดยไม่ต้องเลือกโมเดลแบบเสียเงิน อีกทางเลือกหนึ่ง คุณสามารถใช้ Ollama เพื่อเรียกใช้โมเดลบนเครื่องโดยไม่ต้องใช้ API key เลย

<a id="getting-started"></a>
## เริ่มต้นใช้งาน

หากนี่คือครั้งแรกที่คุณใช้ Transrewrt ให้ทำตามลำดับนี้:

1. เปิดแอป
2. เลือก **ภาษาอินเตอร์เฟซ** จากรูปไอคอนโลก หากจำเป็น
3. หากใช้ **แอปเดสก์ท็อป** ให้เปิดที่ [**การตั้งค่า** > **การกำหนดค่า API**](#api-config) เพิ่ม API key ของผู้ให้บริการอย่างน้อยหนึ่งราย (ตัวอย่างเช่น OpenRouter) แล้วคลิก **ทดสอบ** เพื่อตรวจสอบว่าสามารถใช้งานได้
4. เปิดที่ [**การตั้งค่า** > **โมเดล**](#models) แล้วเพิ่มโมเดลหนึ่งตัวขึ้นไปไปยัง **โมเดลที่เลือก**
5. เปิดไปที่ [**การตั้งค่า** > **ภาษา**](#languages) แล้วเลือก **ภาษาที่ใช้บ่อยที่สุด** หากต้องการให้ภาษาที่คุณใช้มากที่สุดแสดงขึ้นก่อน
6. ไปที่ **แปล** แล้วทำการแปลข้อความง่ายๆ เพื่อตรวจสอบว่าทุกอย่างทำงานได้ถูกต้อง
7. เมื่อแน่ใจแล้ว ให้ลองใช้ **เขียนใหม่** แล้วจึงลอง **แปลงรูปแบบ**

ลำดับนี้มีความสำคัญ เพราะช่วยป้องกันปัญหาที่พบได้บ่อยที่สุดตอนใช้ครั้งแรก คือ การพยายามทำงานก่อนที่แอปจะเชื่อมต่อ API ได้สำเร็จหรือยังไม่ได้เลือกโมเดล

### เครื่องมือ

แถบเครื่องมือจะเปลี่ยนแปลงเล็กน้อยขึ้นอยู่กับตำแหน่งที่คุณอยู่ในแอป

- ด้านซ้ายจะแสดงชื่อหน้าปัจจุบัน
- ด้านขวาจะแสดงตัวเลือก **โมเดล** และการควบคุม **ภาษาของอินเตอร์เฟซ**

  ![ตัวเลือกโมเดล](../images/screenshots/th/model-selector.png)

> ℹ️ **หมายเหตุ**<br/>
> โมเดลแบบฟรีบางตัวอาจไม่สามารถใช้งานได้ตลอดเวลา—บางครั้งอาจออฟไลน์หรือมีข้อจำกัดการใช้งาน หากเกิดเหตุการณ์เช่นนี้ แอปจะลบโมเดลนั้นออกจากรายการที่ใช้งานได้ของคุณโดยอัตโนมัติ<br/>
> เพื่อควบคุมว่าจะให้โมเดลใดปรากฏ ให้ไปที่ [**การตั้งค่า** > **โมเดล**](#models) และแก้ไขรายการโมเดลของคุณ  
> คุณยังสามารถเปิดการตั้งค่าโมเดลได้โดยตรงโดยคลิกที่ไอคอนผู้ให้บริการด้านซ้ายของชื่อโมเดลในแถบเครื่องมือ

<br/>

**ไอคอนโลกพร้อมรหัสภาษา** ใช้เปลี่ยนภาษาของอินเตอร์เฟซแอป เช่น เมนูและปุ่มต่างๆ แต่จะ **ไม่** เปลี่ยนภาษาที่ใช้ในฟังก์ชัน **แปลภาษา**

  ![ตัวเลือกภาษาอินเตอร์เฟซ](../images/screenshots/th/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### แผงนำเข้าและแผงแสดงผล

พื้นที่ทำงานส่วนใหญ่จะใช้แผง **นำเข้า (Input)** ด้านซ้าย และแผง **แสดงผล (Output)** ด้านขวา

**แผงนำเข้า (Input)** จะแสดง:

- จำนวนอักขระ
- จำนวนคำ
- จำนวนย่อหน้า

**แผงแสดงผล (Output)** สามารถแสดง:

- ระยะเวลางานใช้ไปเท่าไร
- ค่าใช้จ่ายของงานนั้น (ถ้ามีข้อมูล)
- ยอดรวมค่าใช้จ่ายสะสม
- **TPS** (จำนวนโทเค็นต่อวินาที)
- จำนวนอักขระ คำ และย่อหน้า
- โมเดลที่ถูกใช้งาน

หากคุณสงสัยเกี่ยวกับคำศัพท์ทางเทคนิค:

- **โทเค็น (Token)** หมายถึงส่วนเล็ก ๆ ของข้อความ ซึ่งสามารถมองว่าเป็นส่วนหนึ่งของคำ หรือคำสั้น ๆ
- **TPS** หมายถึงจำนวนส่วนของข้อความที่โมเดลประมวลผลในหนึ่งวินาที

<br/><br/>

<a id="translate"></a>
## แปลภาษา

ใช้ **แปลภาษา** เมื่อคุณต้องการแปลข้อความจากภาษาหนึ่งเป็นอีกภาษาหนึ่ง

![พื้นที่ทำงานแปลภาษา](../images/screenshots/th/translate.png)

<br/>

<a id="translate-text"></a>
### แปลข้อความ

1. เปิดเมนู **แปลภาษา**
2. เลือกภาษาในช่อง **จาก (From)**
3. เลือกภาษาในช่อง **ไปยัง (To)**
4. เลือกโมเดลในแถบเครื่องมือ
5. พิมพ์หรือวางข้อความลงในช่อง **นำเข้า (Input)**
6. คลิกที่ปุ่ม **แปลภาษา**
7. อ่านผลลัพธ์ที่ได้จากช่อง **แสดงผล (Output)**
8. ใช้ปุ่มคัดลอกหากคุณต้องการสำเนาผลลัพธ์

<br/>

<a id="language-selection"></a>
### การเลือกภาษา

- **จาก (From)** อาจเป็นภาษาใดภาษาหนึ่งที่ระบุ หรือเลือกเป็น **ตรวจจับภาษาอัตโนมัติ (Detect Language)**
- **ไปยัง (To)** คือภาษาที่คุณต้องการให้ผลลัพธ์ปรากฏ

**ภาษาที่ตั้งไว้เป็นภาษาหลัก** จะปรากฏอยู่ด้านบนสุดของรายการ คุณสามารถตั้งค่าได้ที่ [**การตั้งค่า** > **ภาษา**](#languages)

<br/>

<a id="helpful-translation-settings"></a>
### การตั้งค่าที่เป็นประโยชน์สำหรับการแปล

ใน [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) คุณสามารถปรับเปลี่ยนพฤติกรรมของการแปลภาษาได้:

- **แปลทันทีเมื่อวาง (Auto-translate on paste)** จะเริ่มการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดโดยอัตโนมัติ (Auto-copy result to clipboard)** จะคัดลอกรผลลัพธ์ไปยังคลิปบอร์ดทันทีหลังจากแปลสำเร็จ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์) (Real-time translation (while typing))** จะเริ่มแปลทันทีขณะที่คุณพิมพ์
- **ตั้งค่าหมดเวลา (Timeout (ms))** ใช้กำหนดระยะเวลาที่แอปจะรอ ก่อนเริ่มการแปลแบบเรียลไทม์

<br/>

<a id="keyboard-shortcuts"></a>
### ปุ่มลัดคีย์บอร์ด

ใน [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) ตัวเลือก **พฤติกรรมของ ENTER (Behaviour for ENTER)** จะควบคุมว่าจะเกิดอะไรขึ้นเมื่อกดปุ่ม `Enter`:

- **Enter** อาจใช้เพื่อเริ่มงาน และ **Shift+Enter** ใช้เพื่อขึ้นบรรทัดใหม่
- หรือแอปสามารถทำกลับกันก็ได้

โหมดปัจจุบันจะแสดงอยู่บนปุ่ม **แปลภาษา** ด้วย

<br/><br/>

<a id="rewrite"></a>
## เขียนใหม่

ใช้ **เขียนใหม่** เมื่อคุณต้องการปรับปรุงรูปแบบการเขียนข้อความ โดยไม่เปลี่ยนความหมายหลัก

![พื้นที่ทำงานเขียนใหม่](../images/screenshots/th/rewrite.png)

ฟังก์ชันนี้มีประโยชน์สำหรับ:

- การแก้ไขการสะกดคำและความถูกต้องทางไวยากรณ์
- ทำให้ข้อความชัดเจนยิ่งขึ้น
- ทำให้ข้อความเป็นทางการ หรือไม่เป็นทางการมากขึ้น
- ทำให้ข้อความสั้นลงหรือยาวขึ้น
- ทำให้ข้อความฟังดูมีความเป็นทางวิชาการหรือเทคนิคมากขึ้น

<br/>

<a id="rewrite-text"></a>

### แปลข้อความใหม่

1. เปิด **เขียนใหม่**
2. เลือก **โหมด**
3. เลือกโมเดลในแถบเครื่องมือ
4. พิมพ์หรือวางข้อความลงในช่อง **ป้อนข้อมูล**
5. คลิก **เขียนใหม่**
6. ทบทวนผลลัพธ์ในช่อง **ผลลัพธ์**

การกดปุ่ม Enter ที่อธิบายไว้ใน [**แปลภาษา**](#keyboard-shortcuts) นั้นใช้ได้กับฟีเจอร์นี้เช่นกัน

<br/>

> 💡 **คำแนะนำ**<br/>
> เมื่อคุณใช้โหมด "**ตรวจสอบการสะกดและไวยากรณ์**" จะมีปุ่ม `แสดงการเปลี่ยนแปลง` ปรากฏในแผงแสดงผลลัพธ์  
> คลิกปุ่มนี้เพื่อสลับการแสดงการแก้ไข โดยจะแสดงหรือซ่อนการเปลี่ยนแปลงเฉพาะที่ทำกับข้อความของคุณ

<a id="transform"></a>
## แปลงรูปแบบ

ใช้ฟีเจอร์ **แปลงรูปแบบ** เมื่อคุณต้องการให้ AI ทำตามคำชี้แนะที่กำหนดเอง

![พื้นที่ทำงานแปลงรูปแบบ](../images/screenshots/th/transform.png)

นี่คือส่วนที่ยืดหยุ่นที่สุดของแอปพลิเคชัน คุณสามารถใช้มันในการทำงาน เช่น:

- สรุปบันทึก
- เปลี่ยนข้อความร่างให้กลายเป็นอีเมลที่มีความประณีต
- ดึงประเด็นสำคัญ
- แปลงข้อความเป็นรูปแบบเฉพาะ

<br/>

<a id="run-an-existing-prompt"></a>
### รันพรอมต์ที่มีอยู่

1. เปิด **แปลงรูปแบบ**
2. เลือกพรอมต์จากรายการพรอมต์
3. หากปรากฏช่อง **ภาษาปลายทาง** ให้เลือกภาษาที่ต้องการ (ถ้ามี)
4. พิมพ์หรือวางข้อความลงในช่อง **ป้อนข้อมูล**
5. คลิก **แปลงรูปแบบ**
6. อ่านผลลัพธ์ในช่อง **ผลลัพธ์**

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### หากคุณยังไม่มีพรอมต์

หากช่องรายการพรอมต์ของคุณว่างเปล่า ให้คลิก **โหลดตัวอย่างพรอมต์** ซึ่งจะเพิ่มตัวอย่างที่มีอยู่แล้วในระบบ เพื่อให้คุณเริ่มต้นได้อย่างรวดเร็ว

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ตัวอย่างพรอมต์ที่ให้มานั้นเป็นภาษาอังกฤษ เมื่อคุณโหลดตัวอย่างแล้ว คุณสามารถแก้ไขพรอมต์และใช้ **แปลพรอมต์** เพื่อแปลเป็นภาษาของคุณ

<br/>

<a id="create-a-prompt-quickly"></a>
### สร้างพรอมต์อย่างรวดเร็ว

วิธีเร็วที่สุดในการสร้างพรอมต์คือ:

1. คลิก **พรอมต์ใหม่**
2. คลิก **สร้างพรอมต์**
3. อธิบายสิ่งที่คุณต้องการให้พรอมต์ทำ
4. เลือกโมเดล
5. ปล่อยให้แอปสร้างร่างให้คุณ
6. ทบทวนร่างนั้น แล้วคลิก **บันทึก**

![สร้างพรอมต์](../images/screenshots/th/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### แก้ไขพรอมต์

เมื่อคุณสร้างหรือแก้ไขพรอมต์ ตัวแก้ไขจะปรากฏทางด้านซ้าย และพื้นที่ทดสอบจะปรากฏทางด้านขวา

![ตัวแก้ไขพรอมต์ของฟีเจอร์แปลงรูปแบบ](../images/screenshots/th/transform-prompt-edit.png)

ช่องหลักๆ ได้แก่:

- **ชื่อพรอมต์**: ชื่อที่แสดงในรายการพรอมต์
- **คำชี้แจงพรอมต์ (ไม่บังคับ)**: คำแนะนำสั้นๆ ที่แสดงให้ผู้ใช้เห็นเมื่อรันพรอมต์
- **บทบาทของโมเดล**: บทบาทโดยรวมที่กำหนดให้กับ AI เช่น 'คุณคือผู้ช่วยที่มีประโยชน์'
- **คำแนะนำของโมเดล (หนึ่งบรรทัดต่อหนึ่งข้อ)**: กฎเฉพาะที่คุณต้องการให้ AI ปฏิบัติตาม
- **คำอธิบายผลลัพธ์**: คำสั้นๆ ที่อธิบายผลลัพธ์ เช่น 'สรุป' หรือ 'เขียนใหม่'
- **อุณหภูมิ (0.0 → 1.0)**: ลักษณะการตอบสนองของโมเดล ดูคำอธิบายด้านล่าง
- **ขอภาษาปลายทาง**: เพิ่มตัวเลือกภาษาปลายทางเมื่อรันพรอมต์

หากไม่คุ้นเคยกับคำศัพท์เทคนิคอย่าง **"อุณหภูมิ"** ให้พิจารณาเช่นนี้:

- อุณหภูมิที่ **ต่ำกว่า** จะให้ผลลัพธ์ที่มั่นคงและคาดเดาได้มากกว่า
- อุณหภูมิที่ **สูงกว่า** จะให้ผลลัพธ์ที่หลากหลายและสร้างสรรค์มากขึ้น

คุณยังสามารถใช้:

- **`สร้างพรอมต์`** เพื่อสร้างร่างใหม่จากคำอธิบายง่ายๆ
- **`ปรับปรุงพรอมต์`** เพื่อพัฒนาพรอมต์ที่มีอยู่
- **`แปลพรอมต์`** เพื่อแปลช่องต่างๆ ของพรอมต์

<br/>

> ⚠️ **ข้อควรระวัง**<br/>
> อย่าลืมคลิก **`บันทึก`** ก่อนคลิก **`กลับไปรัน`** หากคุณกลับไปโดยไม่ได้บันทึก การเปลี่ยนแปลงของคุณจะหายไป

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ทดสอบพรอมต์ก่อนใช้งานจริง

แผงทดสอบทางด้านขวาช่วยให้คุณสามารถทดลองใช้พรอมต์กับข้อความตัวอย่างก่อนที่จะนำไปใช้ในงานประจำวัน

สิ่งนี้มีประโยชน์เมื่อ:

- คุณกำลังสร้างพรอมต์ใหม่
- คุณต้องการเปรียบเทียบสองเวอร์ชันของพรอมต์
- คุณต้องการตรวจสอบน้ำเสียง ความยาว หรือรูปแบบของผลลัพธ์

<br/>

<a id="manage-saved-prompts"></a>
### จัดการพรอมต์ที่บันทึกไว้

เพื่อจัดการพรอมต์ที่บันทึกไว้ในที่เดียว ให้เปิดที่ [**ตั้งค่า** > **พรอมต์แปลงรูปแบบ**](#transform-prompts)

ในส่วนนั้น คุณสามารถ:

- แสดงรายชื่อและลบพรอมต์ของคุณออก
- ส่งออกพรอมต์เป็นไฟล์ **JSON**, **CSV**, หรือ **XLSX**
- นำเข้าพรอมต์จากไฟล์

- **ตามโมเดล** แสดงว่าคุณใช้โมเดลใดไปบ้าง และมีค่าใช้จ่ายเท่าใด
- **ตามวัน** แสดงยอดรวมรายวัน
- **การเรียกทั้งหมด** แสดงประวัติการเรียกใช้งานทั้งหมด และช่วยให้คุณสามารถส่งออกข้อมูลได้

- **JSON**
- **CSV**
- **XLSX**

<a id="delete-stored-records-for-a-model"></a>
### ลบประวัติที่เก็บไว้สำหรับโมเดลหนึ่งตัว

<a id="general-settings"></a>

### การตั้งค่าทั่วไป

ใช้ **การตั้งค่าทั่วไป** เพื่อควบคุมพฤติกรรมการพิมพ์ ว่ารายละเอียดการดำเนินการจะถูกเก็บไว้ใน **ประวัติ** หรือไม่ และการกำหนดรูปลักษณ์

**พฤติกรรม**

- **พฤติกรรมของปุ่ม ENTER** เลือกว่า `Enter` จะรันงานหรือขึ้นบรรทัดใหม่
- **แปลอัตโนมัติเมื่อวาง** เริ่มการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** คัดลอกผลลัพธ์ที่สำเร็จโดยอัตโนมัติ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** แปลในขณะที่คุณพิมพ์
- **เวลาหมดอายุ (มิลลิวินาที)** กำหนดเวลาที่รอสำหรับการแปลแบบเรียลไทม์

**ประวัติ**

- **เก็บประวัติการดำเนินการ** ควบคุมว่าแต่ละการแปล เขียนใหม่ หรือแปลง จะเก็บ **ข้อความนำเข้าและส่งออก** ไว้สำหรับมุมมอง [**ประวัติ**](#history) ด้านข้างหรือไม่ การปิดตัวเลือกนี้จะขอการยืนยัน; หากคุณยืนยัน ข้อความที่จัดเก็บไว้ในประวัติจะถูกลบออกจากฐานข้อมูล
- **ลบข้อมูลประวัติ** อนุญาตให้คุณลบข้อความที่จัดเก็บด้วยอายุ (เช่น ข้อมูลที่เก่ากว่าไม่กี่เดือน หรือ **ข้อมูลทั้งหมด (ล้าง)**) โดยใช้ **ลบข้อมูล** ซึ่งจะกระทบเฉพาะข้อความการดำเนินการที่บันทึกไว้สำหรับมุมมอง **ประวัติ** เท่านั้น แต่ **จะไม่** ลบยอดรวมค่าใช้จ่ายหรือการใช้งานเพื่อ ลบหรือตัดข้อมูล **ค่าใช้จ่าย** ให้ใช้ [**การตั้งค่า** > **ติดตามค่าใช้จ่าย**](#cost-tracking)

**รูปลักษณ์**

- **จำนวนตำแหน่งทศนิยมของค่าใช้จ่าย** เปลี่ยนวิธีแสดงจำนวนทศนิยมของค่าใช้จ่าย
- **เฉพาะเว็บ:** **แสดงพื้นที่ว่างรอบแอป** เพิ่มพื้นที่ว่างรอบอินเตอร์เฟซ
- **ตระกูลแบบอักษร** เปลี่ยนแบบอักษรที่ใช้ในแผงข้อความ
- **ขนาด** เปลี่ยนขนาดตัวอักษร

<br/>

<a id="models"></a>
### โมเดล

ใช้ **การตั้งค่า** > **โมเดล** เพื่อเลือกว่าโมเดลใดจะปรากฏในแถบเครื่องมือ

![แท็บโมเดลการตั้งค่า](../images/screenshots/th/settings-models.png)

หน้านี้มีสองรายการ:

- **โมเดลที่มีอยู่** ด้านซ้าย
- **โมเดลที่เลือก** ด้านขวา

การควบคุมที่เป็นประโยชน์ ได้แก่:

- **ค้นหาโมเดล...** เพื่อค้นหาโมเดลตามชื่อ
- **ชิปผู้ให้บริการ** เพื่อจำกัดรายการให้แคบลงตามบริษัทที่ให้บริการ (OpenRouter, OpenAI, Ollama, …)
- **เฉพาะโมเดลฟรี** เพื่อแสดงเฉพาะโมเดลฟรี
- **รีเฟรช** เพื่อรีโหลดรายการ
- **ขยายทั้งหมด** และ **ยุบทั้งหมด** เมื่อคุณจัดเรียงตามผู้ให้บริการ

รหัสโมเดลมีคำนำหน้าผู้ให้บริการ (เช่น `openrouter/…` กับ `openai/…`) สัญลักษณ์บอกข้อมูล เช่น **OpenAI (OpenRouter)** กับ **OpenAI (โดยตรง)** แสดงให้เห็นว่าทราฟฟิกถูกส่งผ่านอย่างไร

การดำเนินการ:

 - เพื่อเพิ่มโมเดล ให้คลิก **เพิ่ม** หรือที่ใดก็ได้ในรายการ

 - เพื่อลบโมเดล ให้คลิก **X** ถัดจากโมเดลในรายการ **โมเดลที่เลือก** หรือคลิก **เลือก** ในรายการโมเดลที่มีอยู่

 - เพื่อล้างรายการ ให้คลิก **ยกเลิกการเลือกทั้งหมด** โมเดลฟรีที่ต้องการจะยังคงอยู่ในรายการ

<br/>

> ℹ️ **หมายเหตุ**<br/>
> หากคุณไม่ต้องการเติมเครดิตใน OpenRouter ทันที ให้เริ่มต้นโดยเปิดใช้งาน **เฉพาะโมเดลฟรี** และเลือกโมเดลฟรี (ไม่ต้องใช้บัตรเครดิต) คุณยังสามารถใช้ Ollama เพื่อรันโมเดลในเครื่องโดยไม่ต้องใช้ API key

<br/>

<a id="languages"></a>
### ภาษา

ใช้ **การตั้งค่า** > **ภาษา** เพื่อจัดการรายการภาษาที่ใช้ในแอป

- **ภาษาหลัก** จะติดอยู่ด้านบนสุดของรายการภาษาในฟังก์ชัน **แปล** และ **แปลง**
- **ภาษาที่กำหนดเอง** อนุญาตให้คุณเพิ่มภาษาที่ไม่มีอยู่ในรายการเริ่มต้น

หากคุณเพิ่มภาษาที่กำหนดเอง ภาษาดังกล่าวจะปรากฏในตัวเลือกภาษาพร้อมกับตัวเลือกเริ่มต้น

<br/>

<a id="cost-tracking"></a>
### การติดตามค่าใช้จ่าย

ใช้ **การตั้งค่า** > **ติดตามค่าใช้จ่าย** เพื่อจัดการข้อมูลค่าใช้จ่าย

- **ค่าใช้จ่ายรวม** แสดงยอดรวมสะสม
- **คัดลอกค่า** คัดลอกยอดรวมไปยังคลิปบอร์ด
- **รีเซ็ตค่าใช้จ่าย** ตั้งค่ายอดรวมที่จัดเก็บเป็นศูนย์
- **ซิงค์กับการใช้งานคีย์ API** ตั้งค่ายอดรวมให้ตรงกับการใช้งานที่รายงานโดยบัญชี OpenRouter ของคุณ (เฉพาะ OpenRouter)
- **การใช้งานคีย์ API** แสดงรายละเอียดการใช้งาน OpenRouter หากมีให้
- **ลบข้อมูลค่าใช้จ่าย** ลบข้อมูลทั้งหมด หรือเฉพาะรายการที่มีอายุเก่ากว่าวันที่ที่เลือก

**การติดตามค่าใช้จ่าย:** เมื่อคุณใช้โมเดล OpenRouter แอปจะแสดงการใช้งานและการใช้จ่ายจริงของคุณตามข้อมูลจาก OpenRouter สำหรับผู้ให้บริการรายอื่น แอปจะประมาณค่าใช้จ่ายโดยอิงจากราคาที่ OpenRouter ประกาศไว้ หากไม่มีราคา ค่าประมาณอาจเป็นศูนย์

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ตัวเลขค่าใช้จ่ายทั้งหมดเป็นเพียงการประมาณการเพื่อการอ้างอิงของคุณเท่านั้น ไม่ใช่ใบแจ้งหนี้อย่างเป็นทางการ

<br/>

> ⚠️ **คำเตือน**<br/>
> การลบข้อมูลไม่สามารถยกเลิกได้ ก่อนลบข้อมูล โปรดสำรองข้อมูลหรือส่งออกผ่าน [**แผงควบคุม** > **การเรียกทั้งหมด**](#dashboard-tabs) มิฉะนั้นข้อมูลจะสูญหายอย่างถาวร <br/> 
> ประวัติทั้งหมดที่เกี่ยวข้องกับแต่ละรายการการเรียก API ก็จะถูกลบเช่นกัน

- ลบคำสั่ง

<a id="api-config"></a>
### ตั้งค่า API

ผู้ให้บริการที่รองรับได้แก่ OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI และ **Ollama** (โมเดลแบบท้องถิ่นผ่านทาง URL หลัก) คุณต้องตั้งค่าเฉพาะผู้ให้บริการที่คุณใช้เท่านั้น

**แอปพลิเคชันเว็บ: ผู้ดูแลระบบเท่านั้น**

คีย์ API ถูกกำหนดค่าผ่านตัวแปรสภาพแวดล้อมระบบหรือ Docker — ไม่ได้ป้อนในหน้าเว็บ UI หน้านี้จะแสดงว่าผู้ให้บริการใดมีคีย์ตั้งค่าเอาไว้แล้ว และให้คุณทดสอบแต่ละตัวได้โดยคลิกปุ่ม **`ทดสอบ`**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> เพื่อเปลี่ยนคีย์ API ให้แก้ไขตัวแปรสภาพแวดล้อมในระบบหรือการตั้งค่าของ Docker แล้วรีสตาร์ทเซิร์ฟเวอร์หรือคอนเทนเนอร์

<br/>

**แอปพลิเคชันเดสก์ท็อป**

ใช้ **ตั้งค่า API** เพื่อจัดเก็บคีย์ API สำหรับผู้ให้บริการแต่ละรายที่คุณใช้ สำหรับ Ollama ให้ป้อน **URL หลัก** แทนที่จะเป็นคีย์ API

> หากคุณไม่ต้องการใช้คีย์ API หรือจ่ายค่าบริการ คุณสามารถ [ดาวน์โหลด Ollama](https://ollama.com) และรันโมเดลในเครื่องของคุณได้ฟรี หรืออีกทางเลือกหนึ่ง คุณสามารถสร้างบัญชี OpenRouter ฟรี (ไม่ต้องใช้บัตรเครดิต) เพื่อใช้โมเดลฟรีของพวกเขาได้

- เพิ่มเฉพาะผู้ให้บริการที่คุณต้องการเท่านั้น ใน **ตั้งค่า** > **โมเดล** รหัสโมเดลแต่ละตัวจะเริ่มต้นด้วยชื่อผู้ให้บริการ (เช่น `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)

ในการเพิ่มคีย์ API ให้พิมพ์ค่าลงในช่องข้อความแล้วคลิก **`บันทึก`** หากต้องการเปลี่ยนคีย์เดิมที่มีอยู่แล้ว ให้คลิก **`แก้ไข`** และหากต้องการตรวจสอบว่าคีย์ทำงานได้หรือไม่ ให้คลิก **`ทดสอบ`**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณไม่สามารถดูค่าปัจจุบันของคีย์ API ได้ คุณสามารถเปลี่ยนใหม่ได้เฉพาะผ่านปุ่ม **`แก้ไข`**
> คีย์ API จะถูกจัดเก็บในรูปแบบเข้ารหัสไว้ในไฟล์การตั้งค่า

<br/>

สำหรับขั้นตอนโดยละเอียดในการรับคีย์ OpenRouter ดูได้ที่ [วิธีรับคีย์ API](#how-to-get-an-api-key-desktop-app) ด้านบน

- เลขเวอร์ชัน

<a id="common-issues"></a>
## ปัญหาทั่วไป

หากมีบางอย่างทำงานไม่เป็นไปตามที่คาดไว้ โปรดตรวจสอบประเด็นต่อไปนี้ก่อน

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### แอปไม่สามารถแปล แก้ไข หรือแปลงข้อความได้

โปรดตรวจสอบให้แน่ใจว่า:

- คุณเลือกโมเดลไว้ที่แถบเครื่องมือแล้ว
- มีโมเดลอย่างน้อยหนึ่งตัวที่ปรากฏใน [**ตั้งค่า** > **โมเดล**](#models)
- การตั้งค่า API ของคุณทำงานได้ดี

หากคุณใช้แอปเดสก์ท็อป:

1. เปิด [**ตั้งค่า** > **ตั้งค่า API**](#api-config)
2. ตรวจสอบว่ามีการบันทึกคีย์ API ไว้อย่างน้อยหนึ่งคีย์
3. คลิก **ทดสอบ** ที่อยู่ถัดจากผู้ให้บริการเพื่อยืนยันว่าคีย์ทำงานได้

<br/>

<a id="the-model-list-is-empty"></a>
### รายการโมเดลว่างเปล่า

เปิด [**ตั้งค่า** > **โมเดล**](#models) แล้วคลิก **รีเฟรช**

หากจำเป็น:

- ค้นหาโมเดล
- เปิดใช้งาน **เฉพาะโมเดลฟรี**
- เพิ่มโมเดลหนึ่งตัวขึ้นไปใน **โมเดลที่เลือก**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ผลลัพธ์ช้าเกินไปหรือมีค่าใช้จ่ายสูงเกินไป

ลองทำอย่างใดอย่างหนึ่งหรือมากกว่าดังต่อไปนี้:

- เลือกโมเดลอื่น
- ใช้ข้อความที่สั้นลง
- ปิดฟังก์ชัน **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** ใน [**ตั้งค่า** > **ตั้งค่าทั่วไป**](#general-settings)
- ใช้โมเดลฟรีสำหรับงานง่าย ๆ (ดูที่ [โมเดล](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### อินเทอร์เฟซแสดงเป็นภาษาที่ผิด

คลิกที่ไอคอนโลกใน [แถบเครื่องมือ](#toolbar) แล้วเลือก **ภาษาอินเทอร์เฟซ** ที่คุณต้องการ

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ตัวอักษรเล็กเกินไปหรืออ่านยาก

เปิด [**ตั้งค่า** > **ตั้งค่าทั่วไป**](#general-settings) แล้วเปลี่ยน:

- **ครอบครัวแบบอักษร**
- **ขนาด**

<br/>

<a id="dashboard-charts-are-empty"></a>
### แผนภูมิในแดชบอร์ดว่างเปล่า

สิ่งนี้เป็นปกติหาก:

- คุณใช้ **โมเดลฟรี** เท่านั้น (แผนภูมิค่าใช้จ่ายจะว่างเปล่า)
- **ตัวกรองเวลา** ที่เลือกไม่ได้ครอบคลุมช่วงเวลาที่ใช้งาน — ลองใช้ **ทั้งหมด** เพื่อตรวจสอบ

หากแผนภูมิยังคงว่างอยู่หลังจากเลือก **ทั้งหมด** ให้ยืนยันว่ามีการบันทึกการเรียกใช้งานใน [**ประวัติ**](#history) หรือในแท็บ **การเรียกทั้งหมด**

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>

### ต้นทุนแสดงว่า"ไม่พร้อมใช้งาน" หรือดูเหมือนจะผิด

เมื่อคุณใช้โมเดลผ่าน **OpenRouter** แอปจะแสดงค่าใช้จ่ายจริงที่รายงานโดย OpenRouter

สำหรับ **ผู้ให้บริการอื่นๆ** (เช่น OpenAI โดยตรง, Anthropic โดยตรง ฯลฯ) ต้นทุนจะคำนวณโดยประมาณจากข้อมูลราคาที่เปิดเผยโดย OpenRouter หากไม่พบราคาที่ตรงกับโมเดลนั้นๆ ต้นทุนจะแสดงเป็น **ไม่พร้อมใช้งาน** และจะไม่ถูกรวมในยอดรวมที่แสดงอยู่

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ยอดรวมต้นทุนไม่ตรงกับใบแจ้งหนี้จากผู้ให้บริการของฉัน

ตัวเลขต้นทุนทั้งหมดในแอปเป็นเพียง **ค่าประมาณเพื่อการอ้างอิงเท่านั้น** ไม่ใช่ใบแจ้งหนี้อย่างเป็นทางการ

หากต้องการให้ยอดรวมใกล้เคียงกับค่าใช้จ่ายจริงกับ OpenRouter ให้เปิด [**การตั้งค่า** > **การติดตามต้นทุน**](#cost-tracking) และคลิก **ซิงค์กับการใช้งาน API key**

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### หน้าประวัติหายไปจากแถบด้านข้าง

ตัวเลือก **เก็บประวัติการรัน** อาจถูกปิดอยู่ ให้เปิด [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) แล้วเปิดใช้งานตัวเลือกนี้ โปรดทราบว่าการเปิดใช้งานจะไม่กู้คืนข้อมูลประวัติที่ถูกลบไปก่อนหน้านี้

<br/>

<a id="web-app-session-expired"></a>
### แอปเว็บ: ถูกเปลี่ยนเส้นทางไปยังหน้าล็อกอินโดยไม่คาดคิด

เซสชันของคุณอาจหมดอายุ กรุณาล็อกอินใหม่ หากปัญหานี้เกิดขึ้นบ่อย ให้ตรวจสอบการตั้งค่าระยะเวลาของเซสชันในเซิร์ฟเวอร์

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### แดชบอร์ดไม่แสดงข้อมูลของผู้ใช้คนอื่น (เว็บ)

เฉพาะ **ผู้ดูแลระบบ** เท่านั้นที่สามารถดูข้อมูลของผู้ใช้ทุกคนได้ผ่านตัวกรอง **ผู้ใช้** ผู้ใช้ทั่วไปจะเห็นเฉพาะกิจกรรมของตนเองโดยออกแบบมาเช่นนั้น

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### เปลี่ยนพรอมต์แล้วสูญเสียการแก้ไข

เมื่อคุณแก้ไขพรอมต์ โปรดคลิก **บันทึก** ก่อนคลิก **กลับไปรัน**

<br/><br/>

<a id="quick-tips"></a>
## เคล็ดลับเบื้องต้น

- เริ่มต้นด้วย [**แปล**](#translate) เพื่อให้แน่ใจว่าการตั้งค่าของคุณใช้งานได้ ก่อนไปยัง [**เขียนใหม่**](#rewrite) หรือ [**แปลง**](#transform)
- ใช้ [**เขียนใหม่**](#rewrite) เพื่อปรับปรุงข้อความในชีวิตประจำวัน
- ใช้ [**แปลง**](#transform) เมื่อคุณต้องการเวิร์กโฟลว์ที่ซ้ำได้สำหรับงานเฉพาะ
- ใช้ [**แดชบอร์ด**](#dashboard) หากคุณต้องการติดตามการใช้งานและต้นทุน
- ใช้ [**ประวัติ**](#history) เพื่อทบทวนการทำงานในอดีต พร้อมข้อความนำเข้าและผลลัพธ์ทั้งหมด
- ส่งออกพรอมต์อย่างสม่ำเสมอ หากคุณกำลังสร้างห้องสมุดพรอมต์ที่ต้องการเก็บรักษาไว้อย่างปลอดภัย (ดู [แปลงพรอมต์](#transform-prompts)) หรือหากคุณต้องการแบ่งปันกับผู้อื่น
