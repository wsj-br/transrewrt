# คู่มือผู้ใช้งาน

<br/>

<a id="introduction"></a>
## บทนำ

Transrewrt ช่วยให้คุณทำงานกับข้อความได้ 3 วิธีหลัก ดังนี้:

- **แปล** - แปลงข้อความจากภาษาหนึ่งไปยังอีกภาษาหนึ่ง
- **เขียนทับใหม่** - ถ่ายทอดข้อความใหม่ในรูปแบบที่ต่างออกไป เช่น ให้ชัดเจนขึ้น สั้นลง หรือเป็นทางการมากขึ้น
- **แปลงรูปแบบ** - ประมวลผลข้อความโดยใช้คำสั่งปัญญาประดิษฐ์ที่กำหนดเอง เรียกว่า "พรอมต์"

<br/>

คู่มือนี้อธิบายวิธีการใช้งานแอปฯ หลังจากที่ติดตั้งและเริ่มใช้งานแล้ว สำหรับขั้นตอนการติดตั้ง โปรดดูที่ไฟล์ **[README](README.th.md)**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> Transrewrt มีให้ใช้งานเป็นแอปเดสก์ท็อปสำหรับ Windows และ Linux และยังมีเวอร์ชันเว็บแอปที่สามารถโฮสต์เองได้ คู่มือนี้เน้นการใช้งานทั่วไป หากมีข้อใดที่ใช้ได้กับเวอร์ชันใดเวอร์ชันหนึ่งเท่านั้น จะมีการระบุไว้อย่างชัดเจน

<a id="before-you-start"></a>

## ก่อนเริ่มต้น

ในการใช้งาน Transrewrt คุณต้องมีการเข้าถึงผู้ให้บริการ AI อย่างน้อยหนึ่งราย ผู้ให้บริการที่รองรับ ได้แก่ [OpenRouter](https://openrouter.ai) (ซึ่งรวบรวมแบบจำลองจำนวนมาก), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ [Ollama](https://ollama.com) สำหรับโมเดลใช้งานท้องถิ่น

คุณไม่จำเป็นต้องเลือกใช้โมเดลแบบเสียเงินเพื่อเริ่มต้น เมื่อคุณเพิ่มคีย์ API ของ OpenRouter เข้ามาแล้ว แอปจะเปิดใช้งานตัวเลือก **ฟรี** ผ่าน OpenRouter โดยอัตโนมัติ ทำให้คุณสามารถเริ่มแปล ปรับข้อความ และเปลี่ยนแปลงข้อความได้ทันที อีกทางเลือกหนึ่ง คุณสามารถรับคีย์ API ฟรีจาก Cerebras, Google, Groq หรือ Mistral AI ได้เช่นกัน

สรุปให้เข้าใจง่าย:

- **โมเดล** คือ เครื่องยนต์ AI ที่ทำงานจริง มักจะถูกรายชื่อด้วยคำนำหน้าของ **ผู้ให้บริการ** (ตัวอย่างเช่น `openrouter/…`, `openai/…`, `ollama/…`)
- **คีย์ API** (หรือสำหรับ Ollama คือ **URL พื้นฐาน**) คือ ข้อมูลที่แอปใช้ติดต่อกับผู้ให้บริการนั้นๆ

หากคุณใช้งาน **แอปเดสก์ท็อป** ให้เพิ่มคีย์ในส่วน [**การตั้งค่า** > **การตั้งค่า API**](#api-config) สำหรับผู้ให้บริการที่คุณใช้แต่ละราย สำหรับผู้ใช้ OpenRouter เพียงรายเดียว ให้ดูวิธีการที่หัวข้อ [วิธีรับคีย์ API ฟรีจาก OpenRouter](#how-to-get-an-api-key-desktop-app) ด้านล่าง หากคุณไม่ต้องการใช้คีย์ API คุณสามารถติดตั้ง Ollama (จาก [ollama.com](https://ollama.com)) แล้วใช้โมเดลท้องถิ่นแทน เช่น `translategemma:4b`

หากคุณใช้ **รุ่นเว็บ** เจ้าของเซิร์ฟเวอร์จะต้องตั้งค่าผู้ให้บริการผ่านตัวแปรสภาพแวดล้อม (environment variables) ดังนั้นคุณจะไม่สามารถป้อนคีย์ API โดยตรงในแอปได้

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### วิธีรับคีย์ API ฟรีจาก OpenRouter (แอปเดสก์ท็อป)

หากคุณใช้แอปเดสก์ท็อป ให้ทำตามขั้นตอนต่อไปนี้:

1. ไปที่เว็บไซต์ [OpenRouter](https://openrouter.ai) โดยใช้เบราว์เซอร์
2. สร้างบัญชีหรือเข้าสู่ระบบ
3. เข้าไปที่หน้า [Keys](https://openrouter.ai/keys)
4. คลิกปุ่มเพื่อสร้างคีย์ API ใหม่
5. ตั้งชื่อคีย์เพื่อให้คุณสามารถจากรองคีย์นั้นได้ในภายหลัง
6. คัดลอกคีย์ API ที่สร้างใหม่นี้
7. กลับไปยัง Transrewrt แล้วเปิดไปที่ **การตั้งค่า** > **การตั้งค่า API**
8. วางคีย์นี้ลงในช่อง **OpenRouter API key** (ภายใต้ **การตั้งค่า** > **การตั้งค่า API**)
9. คลิก **Test OpenRouter key** เพื่อตรวจสอบว่าทำงานได้ถูกต้อง

<a id="getting-started"></a>
## เริ่มต้นใช้งาน

หากนี่เป็นครั้งแรกที่คุณใช้งาน Transrewrt ให้ทำตามลำดับต่อไปนี้:

1. เปิดแอป
2. เลือก **ภาษาอินเตอร์เฟซ** ของคุณจากไอคอนดวงโลก หากจำเป็น
3. หากคุณใช้ **แอปเดสก์ท็อป** ให้เปิด [**การตั้งค่า** > **การตั้งค่า API**](#api-config) เพิ่มคีย์ API สำหรับผู้ให้บริการอย่างน้อยหนึ่งราย (ตัวอย่างเช่น OpenRouter) แล้วคลิก **ทดสอบ** เพื่อยืนยันว่าทำงานได้
4. เปิดไปที่ [**การตั้งค่า** > **โมเดล**](#models) แล้วเพิ่มโมเดลหนึ่งรายการหรือมากกว่าเข้าไปใน **โมเดลที่เลือก**
5. เปิดไปที่ [**การตั้งค่า** > **ภาษา**](#languages) และเลือก **ภาษาที่ใช้บ่อย** ของคุณ หากต้องการให้ภาษาที่คุณใช้บ่อยที่สุดแสดงขึ้นก่อน
6. ไปที่ **แปล** แล้วทำการแปลข้อความง่ายๆ เพื่อยืนยันว่าทุกอย่างทำงานได้ถูกต้อง
7. เมื่อแน่ใจแล้ว ให้ลองใช้ **ปรับข้อความ** และต่อจากนั้นลอง **เปลี่ยนแปลง**

ลำดับนี้มีความสำคัญ เพราะช่วยป้องกันปัญหาทั่วไปที่พบเมื่อใช้ครั้งแรก ได้แก่ การพยายามทำงานบางอย่างก่อนที่แอปจะมีการเชื่อมต่อ API ที่ใช้งานได้หรือยังไม่ได้เลือกโมเดล

### แถบเครื่องมือ

แถบเครื่องมือจะเปลี่ยนแปลงเล็กน้อยขึ้นอยู่กับตำแหน่งที่คุณอยู่ภายในแอป

- ด้านซ้ายจะแสดงชื่อหน้าปัจจุบัน
- ด้านขวามี **ตัวเลือกโมเดล** และการควบคุม **ภาษาอินเตอร์เฟซ**

**ตัวเลือกโมเดล** ช่วยให้คุณสามารถเลือกได้ว่าจะใช้เอนจินปัญญาประดิษฐ์ (AI) ตัวใดสำหรับงานปัจจุบัน

  ![ตัวเลือกโมเดล](../images/screenshots/th/model-selector.png)

โมเดลบางตัวที่ให้ใช้ฟรีอาจไม่สามารถใช้งานได้ตลอดเวลา — บางครั้งอาจออฟไลน์หรือมีขีดจำกัดการใช้งาน หากเกิดกรณีนี้ แอปจะลบโมเดลนั้นออกจากลิสต์ที่คุณเลือกได้โดยอัตโนมัติ เพื่อกำหนดว่าโมเดลใดจะแสดงผล ให้ไปที่ [**การตั้งค่า** > **โมเดล**](#models) แล้วจัดการลิสต์โมเดลของคุณ  
คุณยังสามารถเปิดการตั้งค่าโมเดลได้โดยตรงจากการคลิกที่ไอคอนผู้ให้บริการซึ่งอยู่ทางด้านซ้ายของชื่อโมเดลบนแถบเครื่องมือ

<br/>

**ไอคอนโลก + รหัสภาษา** จะใช้เปลี่ยนภาษาของอินเตอร์เฟซแอป เช่น เมนูและปุ่มต่าง ๆ อย่างไรก็ตาม ไม่ได้เปลี่ยน **ภาษาที่ใช้ในการแปล** ในหน้า **แปล**

  ![ตัวเลือกภาษาอินเตอร์เฟซ](../images/screenshots/th/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### แผงนำเข้าและแผงแสดงผล

พื้นที่ทำงานส่วนใหญ่จะใช้แผง **ป้อนข้อมูล (Input)** ทางด้านซ้าย และแผง **แสดงผล (Output)** ทางด้านขวา

แผงแต่ละตัวยังแสดงข้อมูลดังนี้:

| **ป้อนข้อมูล (Input)**                                                          | **แสดงผล (Output)**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - จำนวนอักขระ <br/>- จำนวนคำ <br/>- จำนวนย่อหน้า   <br/> | - เวลาที่ใช้ในการทำงาน<br/>- **TPS** (โทเคนต่อวินาที)<br/>- จำนวนอักขระ คำ และย่อหน้า<br/>- โมเดลที่ใช้ |

หากคุณสงสัยเกี่ยวกับศัพท์ทางเทคนิค:

- **โทเคน (Token)** หมายถึง ข้อความชิ้นเล็ก ๆ ซึ่งสามารถเข้าใจได้ว่าเป็นส่วนหนึ่งของคำ หรือคำสั้น ๆ
- **TPS** หมายถึง จำนวนชิ้นส่วนข้อความที่โมเดลประมวลผลได้ในแต่ละวินาที

<br/>

คุณยังสามารถตรวจสอบต้นทุนการดำเนินการแต่ละครั้ง (ถ้ามี) และต้นทุนรวมได้ โดยเปิดใช้งานตัวเลือก `แสดงข้อมูลต้นทุนในการดำเนินการ` ที่ [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)

<br/><br/>

<a id="translate"></a>
## แปล

ใช้ **แปล** เมื่อคุณต้องการแปลข้อความจากภาษาหนึ่งไปเป็นอีกภาษาหนึ่ง

![พื้นที่ทำงานแปล](../images/screenshots/th/translate.png)

<br/>

<a id="translate-text"></a>
### แปลข้อความ

1. เปิดใช้งาน **แปล**
2. เลือกภาษาที่ต้องการในช่อง **จาก (From)**
3. เลือกภาษาที่ต้องการในช่อง **ไปเป็น (To)**
4. เลือกโมเดลที่แถบเครื่องมือ
5. พิมพ์หรือวางข้อความในช่อง **ป้อนข้อมูล (Input)**
6. คลิก **แปล**
7. อ่านผลลัพธ์ในช่อง **แสดงผล (Output)**
8. ใช้ปุ่มคัดลอกถ้าคุณต้องการคัดลอกผลลัพธ์

<br/>

<a id="language-selection"></a>
### การเลือกภาษา

- **จาก (From)** อาจเป็นภาษาเฉพาะหรือเลือกเป็น **ตรวจจับภาษา**
- **ไปเป็น (To)** คือภาษาที่คุณต้องการให้ผลลัพธ์ออกมา

**ภาษายอดนิยม** ที่คุณเลือกจะแสดงอยู่ด้านบนสุดของรายการ คุณสามารถตั้งค่าได้ที่ [**การตั้งค่า** > **ภาษา**](#languages)

<br/>

<a id="helpful-translation-settings"></a>
### การตั้งค่าเพื่อช่วยในการแปล

ที่ [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) คุณสามารถเปลี่ยนพฤติกรรมการแปลได้ดังนี้:

- **แปลอัตโนมัติเมื่อวาง** จะเริ่มแปลข้อความทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** จะคัดลอกผลลัพธ์ไปยังคลิปบอร์ดโดยอัตโนมัติหลังจากแปลสำเร็จ
- **การแปลแบบเรียลไทม์ (ระหว่างพิมพ์)** จะเริ่มแปลข้อความขณะคุณกำลังพิมพ์
- **ระยะเวลาหมดเวลา (ms)** ใช้ควบคุมระยะเวลาที่แอปจะรอ ก่อนเริ่มแปลแบบเรียลไทม์
- **ปุ่ม Enter** ควบคุมสิ่งที่เกิดขึ้นเมื่อคุณกด `Enter`:

## เขียนใหม่

ใช้ **เขียนใหม่** เมื่อต้องการปรับปรุงถ้อยคำโดยไม่เปลี่ยนความหมายหลัก

![พื้นที่ทำงานเขียนใหม่](../images/screenshots/th/rewrite.png)

เครื่องมือนี้เหมาะสำหรับ:

- แก้ไขการสะกดคำและไวยากรณ์
- ทำให้ข้อความชัดเจนยิ่งขึ้น
- ทำให้ข้อความเป็นทางการหรือไม่เป็นทางการมากขึ้น
- สั้นหรือยาวข้อความให้มากขึ้น
- ทำให้ข้อความฟังดูมีความเป็นเทคนิคมากขึ้น

<br/>

> 💡 **เคล็ดลับ**<br/>
> เมื่อคุณใช้โหมด "**ตรวจสอบการสะกดคำและไวยากรณ์**" จะมีปุ่ม `แสดงการเปลี่ยนแปลง` ขึ้นมาที่แผงแสดงผล
> คลิกปุ่มนี้เพื่อสลับการแสดงผลการแก้ไข โดยสามารถแสดงหรือซ่อนการเปลี่ยนแปลงเฉพาะที่ทำกับข้อความของคุณได้

<a id="transform"></a>

## เปลี่ยนรูปแบบ

ใช้ **เปลี่ยนรูปแบบ** เมื่อคุณต้องการให้ปัญญาประดิษฐ์ (AI) ปฏิบัติตามชุดคำแนะนำเฉพาะที่คุณกำหนดเอง

![พื้นที่ทำงาน เปลี่ยนรูปแบบ](../images/screenshots/th/transform.png)

นี่คือส่วนที่ยืดหยุ่นที่สุดของแอปพลิเคชัน คุณสามารถใช้มันเพื่อทำงานต่าง ๆ เช่น:

- สรุปบันทึก
- เปลี่ยนข้อความร่างให้กลายเป็นอีเมลที่เรียบร้อย
- สกัดประเด็นสำคัญ
- แปลงข้อความให้อยู่ในรูปแบบเฉพาะ
- กิจกรรมอื่นๆ ที่กำหนดเองกับข้อความต้นฉบับ

<br/>

<a id="run-an-existing-prompt"></a>
### รันคำสั่งที่มีอยู่แล้ว

1. เปิด **เปลี่ยนรูปแบบ**
2. เลือกคำสั่งจากรายการคำสั่ง
3. ถ้ามีช่อง **ภาษาเป้าหมาย** ปรากฏขึ้น ให้เลือกภาษา หากต้องการ
4. พิมพ์หรือวางข้อความในช่อง **อินพุต**
5. คลิก **เปลี่ยนรูปแบบ**
6. อ่านผลลัพธ์ที่ได้ในช่อง **เอาต์พุต**

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### ถ้ายังไม่มีคำสั่งใดๆ

หากรายการคำสั่งของคุณยังว่างเปล่า ให้คลิก **โหลดตัวอย่างคำสั่ง** สิ่งนี้จะเพิ่มตัวอย่างที่มีอยู่ในตัวแอป เพื่อให้คุณเริ่มต้นได้อย่างรวดเร็ว

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ตัวอย่างคำสั่งจะจัดให้เป็นภาษาอังกฤษ หลังจากรับเข้ามาแล้ว คุณสามารถแก้ไขคำสั่งและใช้ **แปลคำสั่ง** เพื่อแปลเป็นภาษาของคุณ

<br/>

<a id="create-a-prompt-quickly"></a>
### สร้างคำสั่งอย่างรวดเร็ว

วิธีที่เร็วที่สุดในการสร้างคำสั่งคือ:

1. คลิก **คำสั่งใหม่**
2. คลิก **สร้างคำสั่ง**
3. อธิบายว่าคุณต้องการให้คำสั่งนี้ทำงานอย่างไร
4. เลือกโมเดล
5. ให้แอปร่างคำสั่งให้คุณ
6. ตรวจสอบร่างที่ได้ และคลิก **บันทึก**

![สร้างคำสั่ง](../images/screenshots/th/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### แก้ไขคำสั่ง

เมื่อคุณสร้างหรือแก้ไขคำสั่ง เครื่องมือแก้ไขจะปรากฏทางด้านซ้าย และพื้นที่ทดสอบจะปรากฏทางด้านขวา

![ตัวแก้ไขคำสั่ง เปลี่ยนรูปแบบ](../images/screenshots/th/transform-prompt-edit.png)

ช่องหลักๆ ได้แก่:

- **ชื่อคำสั่ง**: ชื่อที่แสดงในรายการคำสั่ง
- **คำแนะนำคำสั่ง (ไม่บังคับ)**: คำใบ้สั้นๆ ที่แสดงให้ผู้ใช้เห็นขณะรันคำสั่ง
- **บทบาทโมเดล**: บทบาทโดยรวมที่กำหนดให้กับ AI เช่น 'คุณคือผู้ช่วยที่มีประโยชน์'
- **คำสั่งโมเดล (หนึ่งบรรทัดต่อหนึ่งข้อ)**: กฎเฉพาะที่คุณต้องการให้ AI ปฏิบัติตาม
- **คำอธิบายผลลัพธ์**: คำสั้นๆ ที่อธิบายผลลัพธ์ เช่น 'สรุป' หรือ 'เขียนใหม่'
- **อุณหภูมิ (0.0 → 1.0)**: ลักษณะการทำงานของโมเดล ดูคำอธิบายด้านล่าง
- **ขอภาษาเป้าหมาย**: เพิ่มตัวเลือกภาษาเป้าหมายเมื่อรันคำสั่ง

หากคำศัพท์ทางเทคนิคเรื่อง **อุณหภูมิ (Temperature)** ยังไม่คุ้นเคย ให้คิดแบบนี้:

- อุณหภูมิ **ต่ำ** จะให้ผลลัพธ์ที่มั่นคงและคาดเดาได้ง่ายกว่า
- อุณหภูมิ **สูง** จะให้ผลลัพธ์ที่หลากหลายและสร้างสรรค์มากขึ้น

คุณยังสามารถใช้:

- **`สร้างคำสั่ง`** เพื่อสร้างร่างใหม่จากคำอธิบายง่ายๆ
- **`ปรับปรุงคำสั่ง`** เพื่อพัฒนาคำสั่งเดิมให้ดีขึ้น
- **`แปลคำสั่ง`** เพื่อแปลช่องต่างๆ ของคำสั่ง

<br/>

> ⚠️ **คำเตือน**<br/>
> คลิก **`บันทึก`** ก่อนคลิก **`กลับไปรัน`** หากคุณกลับโดยไม่บันทึก การเปลี่ยนแปลงของคุณจะสูญหาย

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ทดสอบคำสั่งก่อนใช้งาน

แผงทดสอบด้านขวามือช่วยให้คุณสามารถลองใช้คำสั่งของคุณกับข้อความตัวอย่างก่อนใช้งานจริงในชีวิตประจำวัน

สิ่งนี้มีประโยชน์เมื่อ:

- คุณกำลังสร้างคำสั่งใหม่
- คุณกำลังเปรียบเทียบคำสั่งสองเวอร์ชัน
- คุณต้องการตรวจสอบน้ำเสียง ความยาว หรือรูปแบบผลลัพธ์

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณสามารถส่งออกและนำเข้าคำสั่งที่บันทึกไว้ได้ในส่วน [**การตั้งค่า** > **คำสั่งเปลี่ยนรูปแบบ**](#transform-prompts)

ใช้ปุ่มตัวกรองด้านบนเพื่อเปลี่ยนช่วงเวลา

### แท็บแดชบอร์ด

- **CSV**
- **XLSX**

<br/>

<a id="delete-stored-records-for-a-model"></a>
### ลบบันทึกที่จัดเก็บไว้สำหรับโมเดล

ในส่วน **ตามโมเดล** หรือ **การเรียกทั้งหมด** คุณสามารถลบบันทึกที่จัดเก็บไว้สำหรับโมเดลหนึ่งๆ โดยคลิกที่ไอคอน "ถังขยะ"

> ⚠️ **คำเตือน**<br/>
> การลบบันทึกที่จัดเก็บไว้แล้วไม่สามารถกู้คืนได้ โปรดใช้ฟีเจอร์นี้เฉพาะเมื่อแน่ใจว่าไม่ต้องการประวัติดังกล่าวอีกต่อไป

หากต้องการลบข้อมูลทั้งหมด หรือลบข้อมูลตามอายุของข้อมูล ให้ไปที่ [**ตั้งค่า** > **การติดตามต้นทุน**](#cost-tracking) ซึ่งคุณจะพบตัวเลือกสำหรับลบข้อมูลทั้งหมด หรือลบเฉพาะข้อมูลที่เก่ากว่าช่วงเวลาที่กำหนด

<a id="general-settings"></a>
### การตั้งค่าทั่วไป

ใช้ **การตั้งค่าทั่วไป** เพื่อควบคุมพฤติกรรมการพิมพ์ ตัวเลือกการจัดเก็บรายละเอียดการดำเนินการสำหรับ **ประวัติ** และรูปลักษณ์ภายนอก

**พฤติกรรม**

- **พฤติกรรมของปุ่ม ENTER** เลือกว่า `Enter` ควรดำเนินการงาน หรือแทรกบรรทัดใหม่
- **แปลอัตโนมัติเมื่อวาง** เริ่มต้นการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดโดยอัตโนมัติ** คัดลอกผลลัพธ์ที่สำเร็จไปยังคลิปบอร์ดโดยอัตโนมัติ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** ดำเนินการแปลขณะที่คุณพิมพ์
- **เวลาหมดระยะ (มิลลิวินาที)** ตั้งค่าเวลาที่รอสำหรับการแปลแบบเรียลไทม์

**ประวัติ**

- **เก็บประวัติการดำเนินการ** ควบคุมว่าการแปล เขียนใหม่ และแปลงแต่ละครั้งจะต้องจัดเก็บ **ข้อความนำเข้าและส่งออก** เพื่อแสดงในมุมมอง [**ประวัติ**](#history) หรือไม่ การปิดตัวเลือกนี้จะถามยืนยัน และหากคุณยืนยัน ข้อความประวัติที่จัดเก็บไว้จะถูกลบออกจากฐานข้อมูล
- **ลบข้อมูลประวัติ** อนุญาตให้คุณลบข้อความที่จัดเก็บตามอายุ (เช่น ข้อมูลที่เก่ากว่าหลายเดือน หรือ **ข้อมูลทั้งหมด (ล้าง)**) โดยใช้ฟีเจอร์ **ลบข้อมูล** ฟีเจอร์นี้มีผลเฉพาะกับข้อความการดำเนินการที่จัดเก็บไว้เพื่อแสดงในมุมมอง **ประวัติ** เท่านั้น และ **ไม่** ลบยอดรวมต้นทุนหรือการใช้งาน หากต้องการลบหรือตัดข้อมูล **ต้นทุน** ให้ใช้งานที่ [**การตั้งค่า** > **การติดตามต้นทุน**](#cost-tracking)

**รูปลักษณ์**

- **แสดงข้อมูลต้นทุนในการดำเนินการ** ควบคุมการแสดงต้นทุนต่อการดำเนินการ (ถ้ามี) และต้นทุนรวมบนแผงผลลัพธ์แปล เขียนใหม่ และแปลง
- **จำนวนหลักทศนิยมของต้นทุน** เปลี่ยนรูปแบบการแสดงตัวเลขทศนิยมของต้นทุน
- **เฉพาะเว็บ:** **แสดงระยะขอบรอบแอป** เพิ่มพื้นที่ว่างรอบอินเตอร์เฟซ
- **ตระกูลแบบอักษร** เปลี่ยนแบบอักษรที่ใช้ในแผงข้อความ
- **ขนาด** เปลี่ยนขนาดแบบอักษร


<br/>

<a id="models"></a>

### โมเดล

ใช้ **การตั้งค่า** > **โมเดล** เพื่อเลือกโมเดลที่จะแสดงในแถบเครื่องมือ

![แท็บโมเดลการตั้งค่า](../images/screenshots/th/settings-models.png)

หน้านี้มีรายการสองรายการ:

- **โมเดลที่มีอยู่** ทางด้านซ้าย
- **โมเดลที่เลือก** ทางด้านขวา

การควบคุมที่มีประโยชน์ ได้แก่:

- **ค้นหาโมเดล...** เพื่อค้นหาโมเดลตามชื่อ
- **ชิปผู้ให้บริการ** เพื่อจำกัดรายชื่อให้เหลือเฉพาะเครื่องยนต์เดียว (OpenRouter, OpenAI, Ollama, …)
- **เฉพาะแบบไม่เสียค่าใช้จ่าย** เพื่อแสดงเฉพาะโมเดลที่ไม่เสียค่าใช้จ่าย
- **รีเฟรช** เพื่อโหลดรายชื่อใหม่
- **ขยายทั้งหมด** และ **ยุบทั้งหมด** เมื่อคุณจัดเรียงตามผู้ให้บริการ

รหัสโมเดลจะรวมคำนำหน้าจากผู้ให้บริการ (ตัวอย่างเช่น `openrouter/…` หรือ `openai/…`) ป้ายกำกับ เช่น **OpenAI (OpenRouter)** เทียบกับ **OpenAI (โดยตรง)** แสดงให้เห็นว่าการรับ-ส่งข้อมูลจะถูกส่งต่ออย่างไร

> ℹ️ **หมายเหตุ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) เป็นโมเดลตัวควบคุมเส้นทาง (router model) ไม่ใช่โมเดลแชททั่วไป โดยช่องตอบกลับจะส่งผลลัพธ์ในรูปแบบ JSON ที่อธิบายตัวแปรการร้องขอ API ของ OpenRouter (ตัวอย่างเช่น อาร์เรย์ `requests` ที่มี `model` และ `messages`) หากคุณใช้โมเดลนี้ในงาน **แปล**, **เขียนใหม่** หรือ **แปลงรูปแบบ** แผงผลลัพธ์จะแสดง JSON แทนข้อความที่เสร็จสมบูรณ์ ให้เลือกใช้โมเดลข้อความทั่วไปสำหรับงานดังกล่าว ดูหน้าข้อมูลโมเดล [Body Builder](https://openrouter.ai/openrouter/bodybuilder) บน OpenRouter

การดำเนินการ:

- เพื่อเพิ่มโมเดล ให้คลิก **เพิ่ม** หรือคลิกที่รายการใดก็ได้ในรายการที่จะเพิ่ม

- เพื่อลบโมเดล ให้คลิกที่ **X** ถัดจากโมเดลนั้นในส่วน **Selected Models** หรือคลิกที่ **Selected** บนรายการใน **Available Models**

- เพื่อล้างรายการ เลือก **Deselect all** โมเดลฟรีที่จำเป็นจะยังคงอยู่ในรายการ

<br/>

> ℹ️ **หมายเหตุ**<br/>
> หากคุณไม่ต้องการเติมเครดิตใน OpenRouter ทันที ให้เปิดใช้งาน **เฉพาะแบบไม่เสียค่าใช้จ่าย** ก่อน แล้วเลือกโมเดลที่ไม่เสียค่าใช้จ่าย (ไม่จำเป็นต้องใช้บัตรเครดิต) คุณยังสามารถใช้ Ollama เพื่อรันโมเดลในเครื่องโดยไม่ต้องใช้คีย์ API ได้อีกด้วย

<br/>

<a id="languages"></a>
### ภาษา

ใช้ **การตั้งค่า** > **ภาษา** เพื่อจัดการรายการภาษาที่ใช้ในแอป

- **ภาษาที่ตั้งไว้ด้านบน** จะถูกปักหมุดไว้ด้านบนของรายการภาษาใน **แปล** และ **แปลงรูปแบบ**
- **ภาษาที่กำหนดเอง** ช่วยให้คุณเพิ่มภาษาที่ไม่มีอยู่ในรายการเริ่มต้นได้

หากคุณเพิ่มภาษาที่กำหนดเอง ภาษาดังกล่าวจะปรากฏในตัวเลือกภาษาพร้อมกับตัวเลือกเริ่มต้น

<br/>

<a id="cost-tracking"></a>
### การติดตามต้นทุน

ใช้ **การตั้งค่า** > **การติดตามต้นทุน** เพื่อจัดการข้อมูลต้นทุน

- **ต้นทุนรวม** แสดงผลรวมที่คำนวณสะสม
- **คัดลอกค่า** คัดลอกผลรวมไปยังคลิปบอร์ด
- **รีเซ็ตต้นทุน** ตั้งค่าผลรวมที่เก็บไว้เป็นศูนย์
- **ซิงค์กับการใช้งานคีย์ API** ตั้งค่าผลรวมให้ตรงกับข้อมูลการใช้งานจากระบบ OpenRouter (เฉพาะ OpenRouter)
- **การใช้งานคีย์ API** แสดงรายละเอียดการใช้งานของ OpenRouter ถ้ามีข้อมูล
- **ลบข้อมูลต้นทุน** ลบข้อมูลทั้งหมด หรือเฉพาะรายการที่เก่ากว่าวันที่ที่เลือก

**การติดตามต้นทุน:** เมื่อคุณใช้โมเดล OpenRouter แอปจะแสดงการใช้งานและการใช้จ่ายจริงตามข้อมูลต้นทุนจาก OpenRouter ส่วนผู้ให้บริการอื่นๆ แอปจะคำนวณต้นทุนโดยอ้างอิงจากราคาที่ OpenRouter ประกาศ หากไม่มีราคา ค่าประมาณอาจเป็นศูนย์

<br/>

> ℹ️ **หมายเหตุ**<br/>
> **ตัวเลขต้นทุนทั้งหมดเป็นเพียงค่าประมาณเพื่อการอ้างอิงเท่านั้น ไม่ใช่ใบเรียกเก็บเงินอย่างเป็นทางการ**

<br/>

> ⚠️ **คำเตือน**<br/>
> การลบข้อมูลไม่สามารถทำกลับได้ ก่อนจะลบข้อมูล โปรดสำรองหรือส่งออกข้อมูลผ่าน [**ประวัติ**](#history) หรือ [**แดชบอร์ด** > **การร้องขอทั้งหมด**](#dashboard-tabs) มิฉะนั้นข้อมูลจะหายไปถาวร ประวัติการป้อนข้อมูลและผลลัพธ์ทั้งหมดที่เกี่ยวข้องกับแต่ละรายการการร้องขอ API จะถูกลบไปด้วย

<br/>

<a id="transform-prompts"></a>
### พรอมต์แปลงรูปแบบ

ใช้ **การตั้งค่า** > **พรอมต์แปลงรูปแบบ** เพื่อจัดการพรอมต์จำนวนมากพร้อมกัน

คุณสามารถ:

- ตรวจสอบพรอมต์ที่บันทึกไว้
- ลบพรอมต์
- นำเข้าพรอมต์จากไฟล์
- ส่งออกพรอมต์เพื่อสำรองหรือแบ่งปัน

<br/>

<a id="users"></a>
### ผู้ใช้

ใช้ **ผู้ใช้** เพื่อจัดการบัญชีผู้ใช้ในเวอร์ชันเว็บ คุณสามารถเพิ่มผู้ใช้ แก้ไขข้อมูล อัปเดตรหัสผ่าน และลบบัญชีได้

<br/>

<a id="api-config"></a>
### การตั้งค่า API

ผู้ให้บริการที่รองรับ ได้แก่ OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ **Ollama** (โมเดลในเครื่องผ่านที่อยู่ URL หลัก) คุณจะต้องตั้งค่าเฉพาะผู้ให้บริการที่คุณใช้งานเท่านั้น

**แอปพลิเคชันเว็บ: สำหรับผู้ดูแลระบบเท่านั้น**

คีย์ API ถูกตั้งค่าผ่านตัวแปรสภาพแวดล้อมระบบหรือ Docker — ไม่ได้ป้อนผ่านหน้าเว็บ UI หน้านี้จะแสดงว่าผู้ให้บริการใดมีการตั้งค่าคีย์ไว้แล้ว และช่วยให้คุณทดสอบแต่ละตัวโดยการคลิกที่ปุ่ม **`Test`**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> เพื่อเปลี่ยนคีย์ API ให้อัปเดตตัวแปรสภาพแวดล้อมในระบบหรือการตั้งค่า Docker ของคุณ แล้วรีสตาร์ทเซิร์ฟเวอร์หรือคอนเทนเนอร์

<br/>

**แอปพลิเคชันเดสก์ท็อป**

ใช้ **การตั้งค่า API** เพื่อจัดเก็บคีย์ API สำหรับแต่ละผู้ให้บริการที่ใช้ สำหรับ Ollama ให้ป้อน **ที่อยู่ URL หลัก** แทนที่จะเป็นคีย์ API

<br/>

> 💡 **เคล็ดลับ** <br/>
> หากคุณไม่ต้องการใช้คีย์ API หรือไม่ต้องการจ่ายค่าใช้บริการ คุณสามารถ [ดาวน์โหลด Ollama](https://ollama.com) และรันโมเดล (เช่น `translategemma:4b`) ในเครื่องของคุณได้ฟรี หรืออีกทางเลือก คุณสามารถสร้างบัญชี OpenRouter ฟรี (ไม่ต้องใช้บัตรเครดิต) เพื่อใช้โมเดลฟรี หรือรับคีย์ API ฟรีจาก Cerebras, Google, Groq หรือ Mistral AI

<br/>

- เพิ่มเฉพาะผู้ให้บริการที่คุณต้องการเท่านั้น ใน **การตั้งค่า** > **โมเดล** รหัสโมเดลแต่ละตัวจะเริ่มต้นด้วยผู้ให้บริการ (ตัวอย่างเช่น `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)

เพื่อเพิ่มคีย์ API ให้ป้อนค่าในช่องข้อความ แล้วคลิก **`บันทึก`** เพื่อแทนที่คีย์เดิม ให้คลิกที่ **`แก้ไข`** เพื่อยืนยันว่าคีย์ทำงานได้ ให้คลิก **`ทดสอบ`** ส่วนที่อยู่ URL หลักของ Ollama ควรคลิก **`ทดสอบ`** เสมอเพื่อตรวจสอบการเชื่อมต่อ

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณไม่สามารถดูค่าคีย์ API ปัจจุบันได้ คุณสามารถเปลี่ยนแปลงได้โดยใช้ปุ่ม **`แก้ไข`** เท่านั้น
> คีย์ API จะถูกเก็บไว้อย่างปลอดภัยในรูปแบบเข้ารหัสในไฟล์การตั้งค่า

<br/>

<a id="common-issues"></a>
## ปัญหาทั่วไป

หากมีบางสิ่งที่ไม่ทำงานตามที่คาดหวัง ให้ตรวจสอบจุดต่อไปนี้ก่อน

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### แอปไม่แปล เขียนใหม่ หรือเปลี่ยนแปลงข้อความ

โปรดตรวจสอบว่า:

- คุณได้เลือกโมเดลในแถบเครื่องมือแล้ว
- มีโมเดลอย่างน้อยหนึ่งตัวอยู่ใน [**การตั้งค่า** > **โมเดล**](#models)
- การตั้งค่า API ของคุณใช้งานได้

หากคุณใช้แอปบนเดสก์ท็อป:

1. เปิด [**การตั้งค่า** > **การกำหนดค่า API**](#api-config)
2. ตรวจสอบว่ามีการบันทึกคีย์ API อย่างน้อยหนึ่งคีย์
3. คลิก **ทดสอบ** ถัดจากผู้ให้บริการ เพื่อยืนยันว่าคีย์ใช้งานได้

<br/>

<a id="the-model-list-is-empty"></a>
### รายการโมเดลว่างเปล่า

ให้เปิด [**การตั้งค่า** > **โมเดล**](#models) แล้วคลิก **รีเฟรช**

หากต้องการ:

- ค้นหาโมเดล
- เปิดใช้งาน **เฉพาะแบบฟรี**
- เพิ่มโมเดลหนึ่งตัวขึ้นไปใน **โมเดลที่เลือก**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ผลลัพธ์ช้าเกินไปหรือมีค่าใช้จ่ายสูงเกินไป

ให้ลองวิธีต่อไปนี้อย่างใดอย่างหนึ่ง:

- เลือกใช้โมเดลอื่น
- ใช้ข้อความนำเข้าที่สั้นลง
- ปิด **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** ใน [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)
- ใช้โมเดลฟรีสำหรับงานที่ง่าย (ดูหัวข้อ [โมเดล](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### อินเตอร์เฟซอยู่ในภาษาที่ไม่ต้องการ

คลิกไอคอนรูปโลกใน [แถบเครื่องมือ](#toolbar) แล้วเลือก **ภาษาอินเตอร์เฟซ** ที่คุณต้องการ

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ข้อความตัวเล็กเกินไปหรืออ่านยาก

เปิด [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) เเล้วเปลี่ยน:

- **ประเภทตัวอักษร**
- **ขนาด**

<br/>

<a id="dashboard-charts-are-empty"></a>
### กราฟในแดชบอร์ดว่างเปล่า

เรื่องนี้ปกติเมื่อ:

- คุณใช้ **โมเดลฟรี** เท่านั้น (กราฟค่าใช้จ่ายจะว่างเปล่า)
- ตัวกรอง **ช่วงเวลา** ที่เลือกไม่ครอบคลุมช่วงเวลาที่มีการเรียกใช้งาน — ลองเลือก **ทั้งหมด** เพื่อตรวจสอบ

หากกราฟยังคงว่างหลังจากเลือก **ทั้งหมด** ให้ยืนยันว่ามีการเรียกใช้งานปรากฏใน [**ประวัติการใช้งาน**](#history) หรือในแท็บ **การเรียกทั้งหมด**

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ค่าใช้จ่ายแสดงข้อความ "ไม่พร้อมใช้งาน" หรือดูเหมือนไม่ถูกต้อง

เมื่อคุณใช้โมเดลผ่าน **OpenRouter** แอปจะแสดงค่าใช้จ่ายจริงที่ OpenRouter รายงานมา

สำหรับ **ผู้ให้บริการอื่น** (OpenAI โดยตรง, Anthropic โดยตรง ฯลฯ) ค่าใช้จ่ายจะถูกประมาณการจากข้อมูลราคาที่ OpenRouter ประกาศไว้ หากไม่พบราคาที่ตรงกับโมเดล ค่าใช้จ่ายจะแสดงเป็น **ไม่พร้อมใช้งาน** และจะไม่ถูกเพิ่มไปยังผลรวมของคุณ

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ค่าใช้จ่ายรวมไม่ตรงกับบิลของผู้ให้บริการ

ตัวเลขค่าใช้จ่ายทั้งหมดในแอปเป็น **ตัวประมาณการเพื่ออ้างอิงเท่านั้น** ไม่ใช่ใบเรียกเก็บเงินอย่างเป็นทางการ

เพื่อให้ยอดรวมใกล้เคียงกับยอดใช้จ่ายจริงบน OpenRouter ของคุณ ให้เปิด [**การตั้งค่า** > **การติดตามค่าใช้จ่าย**](#cost-tracking) และคลิก **ซิงค์กับการใช้คีย์ API**

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### หน้าประวัติหายไปจากแถบด้านข้าง

อาจเป็นเพราะปิดการใช้งาน **เก็บข้อมูลประวัติการประมวลผล** อยู่ ให้เปิด [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) แล้วเปิดใช้งาน โปรดทราบว่าการเปิดใช้งานอีกครั้งจะไม่กู้คืนข้อมูลที่ถูกลบไปก่อนหน้านี้

<br/>

<a id="web-app-session-expired"></a>
### แอปเว็บ: เปลี่ยนเส้นทางไปยังหน้าเข้าสู่ระบบโดยไม่คาดคิด

เซสชันของคุณอาจหมดอายุ ให้เข้าสู่ระบบอีกครั้ง หากเกิดบ่อยครั้ง ให้ตรวจสอบการตั้งค่าเซิร์ฟเวอร์เกี่ยวกับระยะเวลาการใช้งานเซสชัน

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### แดชบอร์ดไม่แสดงข้อมูลของผู้ใช้อื่น (เว็บ)

เฉพาะ **ผู้ดูแลระบบ** เท่านั้นที่สามารถดูข้อมูลของผู้ใช้ทุกคนได้ผ่านตัวกรอง **ผู้ใช้** ผู้ใช้ทั่วไปจะเห็นกิจกรรมของตนเองเท่านั้นตามการออกแบบ

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ฉันแก้ไขตัวพรอมต์แล้วแต่กลับหาย

เมื่อแก้ไขตัวพรอมต์ อย่าลืมคลิก **บันทึก** ก่อนคลิก **กลับไปยังการรัน**

<br/><br/>

<a id="quick-tips"></a>
## เคล็ดลับรวดเร็ว

- เริ่มต้นด้วย [**แปล**](#translate) เพื่อตรวจสอบว่าการตั้งค่าของคุณใช้งานได้ก่อนที่จะไปยัง [**เขียนใหม่**](#rewrite) หรือ [**เปลี่ยนรูปแบบ**](#transform)
- ใช้ [**เขียนใหม่**](#rewrite) เพื่อปรับปรุงถ้อยคำสำหรับการใช้งานทั่วไป
- ใช้ [**เปลี่ยนรูปแบบ**](#transform) เมื่อคุณต้องการทำงานซ้ำได้สำหรับงานเฉพาะอย่าง
- ใช้ [**แดชบอร์ด**](#dashboard) หากต้องการติดตามการใช้งานและค่าใช้จ่าย
- ใช้ [**ประวัติการใช้งาน**](#history) เพื่อตรวจสอบการดำเนินการก่อนหน้า พร้อมข้อความนำเข้าและส่งออกทั้งหมด
- ส่งออกตัวพรอมต์เป็นประจำหากคุณกำลังสร้างคลังพรอมต์ที่ต้องการเก็บไว้อย่างปลอดภัย (ดูที่ [พรอมต์สำหรับการเปลี่ยนรูปแบบ](#transform-prompts)) หรือต้องการแบ่งปันให้ผู้อื่น
