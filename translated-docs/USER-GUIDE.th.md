# คู่มือการใช้งาน

<br/>

<a id="introduction"></a>
## บทนำ

Transrewrt ช่วยคุณทำงานกับข้อความได้สามวิธีหลักๆ:

- **แปล** - แปลงข้อความจากภาษาหนึ่งไปยังอีกภาษาหนึ่ง
- **เขียนใหม่** - เขียนข้อความใหม่ในรูปแบบที่ต่างออกไป เช่น ให้ชัดเจนขึ้น สั้นลง หรือเป็นทางการมากขึ้น
- **แปลงรูปแบบ** - ประมวลผลข้อความโดยใช้คำสั่งปัญญาประดิษฐ์ที่กำหนดเอง ซึ่งเรียกว่า "พร้อมต์"

<br/>

คู่มือนี้อธิบายวิธีการใช้งานแอปพลิเคชันหลังจากที่ติดตั้งเรียบร้อยแล้ว สำหรับขั้นตอนการติดตั้ง โปรดดูที่ไฟล์ **[README](README.th.md)** หลัก

<br/>

> ℹ️ **หมายเหตุ**<br/>
> Transrewrt มีให้ใช้งานทั้งในรูปแบบแอปพลิเคชันเดสก์ท็อปสำหรับ Windows และ Linux และในรูปแบบเว็บแอปพลิเคชันที่สามารถติดตั้งใช้งานเองได้ คู่มือนี้เน้นการใช้งานทั่วไปของแอปพลิเคชัน หากมีข้อมูลใดที่ใช้ได้กับเวอร์ชันใดเวอร์ชันหนึ่งเท่านั้น จะมีคำระบุไว้อย่างชัดเจน

<a id="before-you-start"></a>

## ก่อนที่คุณจะเริ่มต้น

ในการใช้งาน Transrewrt คุณต้องมีการเข้าถึงผู้ให้บริการปัญญาประดิษฐ์ (AI) อย่างน้อยหนึ่งราย ผู้ให้บริการที่รองรับได้แก่: [OpenRouter](https://openrouter.ai) (ซึ่งรวบรวมโมเดลหลายตัว), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ [Ollama](https://ollama.com) สำหรับโมเดลที่รันภายในเครื่อง

คุณไม่จำเป็นต้องเลือกโมเดลแบบชำระเงินเพื่อเริ่มต้น เมื่อคุณเพิ่ม API key ของ OpenRouter แล้ว แอปจะเปิดใช้งานตัวเลือก OpenRouter แบบ **ฟรี** ในตัวโดยอัตโนมัติ ซึ่งช่วยให้คุณเริ่มต้นการแปล เขียนใหม่ และแปลงข้อความได้ทันที หรืออีกทางหนึ่ง คุณยังสามารถขอรับ API key ฟรีจาก Cerebras, Google, Groq หรือ Mistral AI ได้อีกด้วย

ในทางปฏิบัติ:

- **โมเดล** คือเครื่องมือ AI ที่ทำหน้าที่ประมวลผล โมเดลจะแสดงพร้อมคำนำหน้า **ของผู้ให้บริการ** (เช่น `openrouter/…`, `openai/…`, `ollama/…`)
- **API key** (หรือสำหรับ Ollama คือ **URL พื้นฐาน**) คือวิธีที่แอปใช้ติดต่อกับผู้ให้บริการนั้น

หากคุณใช้ **แอปเดสก์ท็อป** ให้เพิ่มคีย์ในส่วน [**ตั้งค่า** > **การกำหนดค่า API**](#api-config) สำหรับผู้ให้บริการแต่ละรายที่คุณใช้ หากใช้เฉพาะ OpenRouter โปรดดูวิธี "การขอรับ API key" ด้านล่าง หากคุณไม่ต้องการใช้ API key คุณสามารถติดตั้ง Ollama (จาก [ollama.com](https://ollama.com)) และใช้โมเดลภายในเครื่องแทน เช่น `translategemma:4b`

หากคุณใช้ **รุ่นเว็บ** ผู้ดูแลระบบเซิร์ฟเวอร์จะกำหนดค่าผู้ให้บริการผ่านตัวแปรสภาพแวดล้อม ดังนั้นคุณจะไม่สามารถป้อน API key ได้โดยตรงในแอปพลิเคชัน

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### วิธีการขอรับ API key ฟรีจาก OpenRouter (สำหรับแอปเดสก์ท็อป)

หากคุณใช้แอปเดสก์ท็อป ให้ทำตามขั้นตอนต่อไปนี้:

1. เปิดเว็บเบราว์เซอร์และไปที่ [OpenRouter](https://openrouter.ai)
2. สร้างบัญชีผู้ใช้หรือเข้าสู่ระบบ
3. เข้าสู่หน้า [Keys](https://openrouter.ai/keys)
4. กดปุ่มเพื่อสร้าง API key ใหม่
5. ตั้งชื่อคีย์เพื่อให้คุณสามารถจดจำได้ในอนาคต
6. คัดลอก API key ที่สร้างขึ้นมาใหม่
7. กลับไปที่ Transrewrt และเปิด **ตั้งค่า** > **การกำหนดค่า API**
8. วางคีย์ลงในช่อง **OpenRouter API key** (ภายใต้ **ตั้งค่า** > **การกำหนดค่า API**)
9. กด **Test OpenRouter key** เพื่อตรวจสอบว่าใช้งานได้ถูกต้อง

<a id="getting-started"></a>
## เริ่มต้นใช้งาน

หากนี่เป็นครั้งแรกที่คุณใช้ Transrewrt ให้ทำตามลำดับต่อไปนี้:

1. เปิดแอปพลิเคชัน
2. เลือก **ภาษาการติดต่อ** จากไอคอนโลก หากต้องการ
3. ถ้าคุณใช้ **แอปเดสก์ท็อป** ให้เปิด [**ตั้งค่า** > **การกำหนดค่า API**](#api-config) เพิ่ม API key ของผู้ให้บริการอย่างน้อยหนึ่งราย (เช่น OpenRouter) แล้วกด **ทดสอบ** เพื่อยืนยันว่าใช้งานได้
4. เปิด [**ตั้งค่า** > **โมเดล**](#models) และเพิ่มโมเดลหนึ่งตัวหรือมากกว่าลงใน **โมเดลที่เลือก**
5. เปิด [**ตั้งค่า** > **ภาษา**](#languages) และเลือก **ภาษาหลักของคุณ** หากต้องการให้ภาษาที่ใช้บ่อยแสดงก่อน
6. ไปที่หน้า **แปล** และทดลองแปลข้อความง่ายๆ เพื่อตรวจสอบว่าทุกอย่างทำงานได้ถูกต้อง
7. หลังจากนั้นลองใช้ **เขียนใหม่** และ **แปลง**

ลำดับนี้มีความสำคัญ เพราะจะช่วยป้องกันปัญหาทั่วไปสำหรับผู้ใช้มือใหม่ที่พยายามทำงานก่อนที่แอปจะเชื่อมต่อกับ API ได้สำเร็จ หรือก่อนที่จะเลือกโมเดล

### แถบเครื่องมือ

แถบเครื่องมือจะเปลี่ยนไปเล็กน้อย ขึ้นอยู่กับว่าคุณอยู่ที่ส่วนใดของแอป

- ด้านซ้ายจะแสดงชื่อหน้าปัจจุบัน
- ด้านขวามี **ตัวเลือกโมเดล** และการควบคุม **ภาษาอินเทอร์เฟซ**

**ตัวเลือกโมเดล** ช่วยให้คุณเลือกได้ว่าจะใช้เอ็นจิน AI ใดในงานปัจจุบัน

  ![ตัวเลือกโมเดล](../images/screenshots/th/model-selector.png)

โมเดลฟรีบางตัวอาจไม่พร้อมใช้งานเสมอไป—บางครั้งอาจออฟไลน์ หรือมีขีดจำกัดการใช้งาน เมื่อเกิดเหตุการณ์เช่นนี้ แอปจะลบโมเดลนั้นออกจากเมนูตัวเลือกโดยอัตโนมัติ หากต้องการควบคุมว่าโมเดลใดปรากฏขึ้น ให้ไปที่ [**การตั้งค่า** > **โมเดล**](#models) แล้วแก้ไขรายการโมเดลของคุณ  
คุณยังสามารถเปิดการตั้งค่าโมเดลได้โดยตรง โดยการคลิกไอคอนผู้ให้บริการ ด้านซ้ายของชื่อโมเดลในแถบเครื่องมือ

<br/>

**ไอคอนโลกพร้อมรหัสภาษา** ใช้เปลี่ยนภาษาอินเทอร์เฟซของแอป เช่น เมนูและปุ่มต่างๆ แต่จะ **ไม่** เปลี่ยนภาษาที่ใช้แปลในฟีเจอร์ **แปล (Translate)**

  ![ตัวเลือกภาษาอินเทอร์เฟซ](../images/screenshots/th/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### แผงข้อมูลนำเข้าและออก

เวิร์กสเปซส่วนใหญ่ใช้แผง **ข้อมูลนำเข้า (Input)** ทางด้านซ้าย และแผง **ข้อมูลออก (Output)** ทางด้านขวา

แผงแต่ละแผงแสดงข้อมูลดังต่อไปนี้:

| **ข้อมูลนำเข้า**                                                          | **ข้อมูลออก**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - จำนวนตัวอักษร <br/>- จำนวนคำ <br/>- จำนวนย่อหน้า   <br/> | - แสดงระยะเวลาที่ใช้ในการทำงาน<br/>- **TPS** (tokens ต่อวินาที)<br/>- จำนวนตัวอักษร คำ และย่อหน้า<br/>- โมเดลที่ใช้ |

หากคุณสงสัยเกี่ยวกับคำศัพท์ทางเทคนิค:

- **โทเคน** หมายถึงส่วนย่อยเล็ก ๆ ของข้อความ คุณสามารถมองว่าเป็นส่วนหนึ่งของคำ หรือคำสั้น ๆ
- **TPS** หมายถึงจำนวนชิ้นส่วนข้อความที่โมเดลประมวลผลได้ในแต่ละวินาที

<br/>

คุณยังสามารถตรวจสอบค่าใช้จ่ายของการดำเนินการแต่ละครั้ง (ถ้ามี) และค่าใช้จ่ายทั้งหมด โดยการเปิดใช้งานตัวเลือก `แสดงข้อมูลค่าใช้จ่ายในการดำเนินการ` ที่ [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)

<a id="translate"></a>
## แปล

ใช้ฟีเจอร์ **แปล** เมื่อคุณต้องการแปลข้อความจากภาษาหนึ่งไปยังอีกภาษาหนึ่ง

![เวิร์กสเปซแปล](../images/screenshots/th/translate.png)

<br/>

<a id="translate-text"></a>
### แปลข้อความ

1. เปิด **แปล**
2. เลือกภาษาที่ต้องการแปลออกจากช่อง **จาก (From)**
3. เลือกภาษาที่ต้องการแปลเป็นในช่อง **ถึง (To)**
4. เลือกโมเดลจากรายการในแถบเครื่องมือ
5. พิมพ์หรือวางข้อความในช่อง **ข้อมูลนำเข้า (Input)**
6. คลิก **แปล**
7. อ่านผลลัพธ์ที่ได้ในช่อง **ข้อมูลออก (Output)**
8. คลิกปุ่มคัดลอกหากต้องการคัดลอกผลลัพธ์

<br/>

<a id="language-selection"></a>
### การเลือกภาษา

- **จาก (From)** สามารถระบุเป็นภาษาเฉพาะได้ หรือจะเลือกเป็น **ตรวจจับภาษาอัตโนมัติ**
- **ถึง (To)** คือภาษาที่คุณต้องการให้ข้อความแปลเป็น

**ภาษาที่ตั้งไว้เป็นอันดับต้น** จะแสดงที่ด้านบนสุดของรายการ คุณสามารถตั้งค่าได้ที่ [**การตั้งค่า** > **ภาษา**](#languages)

<br/>

<a id="helpful-translation-settings"></a>
### การตั้งค่าการแปลที่เป็นประโยชน์

ที่ [**การตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) คุณสามารถเปลี่ยนพฤติกรรมการแปลได้ ดังนี้:

- **แปลอัตโนมัติเมื่อวาง** จะเริ่มการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** จะคัดลอกผลลัพธ์ไปยังคลิปบอร์ดโดยอัตโนมัติหลังจากแปลสำเร็จ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** จะแปลข้อความขณะที่คุณกำลังพิมพ์
- **เวลาหมดอายุ (ms)** ใช้กำหนดระยะเวลาที่แอปรอ ก่อนจะเริ่มการแปลแบบเรียลไทม์
- **ปุ่ม Enter** ใช้กำหนดสิ่งที่จะเกิดขึ้นเมื่อคุณกด `Enter`:

<a id="rewrite"></a>
## เขียนใหม่

ใช้ฟีเจอร์ **เขียนใหม่** เมื่อคุณต้องการปรับปรุงการใช้ถ้อยคำ โดยที่ยังคงความหมายหลักเดิมเอาไว้

![เวิร์กสเปซเขียนใหม่](../images/screenshots/th/rewrite.png)

ฟีเจอร์นี้มีประโยชน์ในกรณีต่าง ๆ ดังนี้:

- แก้ไขการสะกดคำ และไวยากรณ์
- ทำให้ข้อความชัดเจนยิ่งขึ้น
- ทำให้ข้อความเป็นทางการหรือเป็นกันเองมากยิ่งขึ้น
- ย่อหรือขยายความยาวของข้อความ
- ทำให้ข้อความฟังดูมีความเป็นทางเทคนิคมากขึ้น

<br/>

> 💡 **เคล็ดลับ**<br/>
> เมื่อคุณใช้โหมด "**ตรวจสอบการสะกดคำ & ไวยากรณ์**" ปุ่ม `แสดงการเปลี่ยนแปลง` จะปรากฏขึ้นในแผงข้อมูลออก  
> คลิกปุ่มนี้เพื่อสลับการแสดงการแก้ไข โดยจะแสดงหรือซ่อนรายละเอียดการเปลี่ยนแปลงที่ทำกับข้อความของคุณ

<a id="transform"></a>

## แปลง

ใช้ **แปลง** เมื่อคุณต้องการให้ปัญญาประดิษฐ์ (AI) ปฏิบัติตามคำแนะนำเฉพาะของคุณเอง

![พื้นที่ทำงานแปลง](../images/screenshots/th/transform.png)

นี่คือส่วนที่ยืดหยุ่นที่สุดของแอป คุณสามารถใช้มันเพื่อทำงานต่าง ๆ เช่น:

- สรุปโน้ต
- เปลี่ยนข้อความร่างให้กลายเป็นอีเมลที่เรียบร้อย
- สกัดประเด็นสำคัญ
- แปลงข้อความให้อยู่ในรูปแบบเฉพาะ
- กิจกรรมแบบกำหนดเองอื่น ๆ กับข้อความที่ป้อนเข้า

<br/>

<a id="run-an-existing-prompt"></a>
### เรียกใช้พรอมต์ที่มีอยู่แล้ว

1. เปิด **แปลง**
2. เลือกพรอมต์จากรายชื่อพรอมต์
3. หากปรากฏช่อง **ภาษาเป้าหมาย** ให้เลือกภาษาที่ต้องการ
4. พิมพ์หรือวางข้อความในช่อง **ป้อนข้อมูล**
5. คลิก **แปลง**
6. อ่านผลลัพธ์ในช่อง **ผลลัพธ์**

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### หากยังไม่มีพรอมต์

ถ้ารายชื่อพรอมต์ของคุณว่างเปล่า ให้คลิก **โหลดตัวอย่างพรอมต์** ซึ่งจะเพิ่มตัวอย่างที่มีมาให้แล้ว เพื่อให้คุณเริ่มต้นได้อย่างรวดเร็ว

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ตัวอย่างพรอมต์จะจัดไว้ให้เป็นภาษาอังกฤษ เมื่อโหลดแล้ว คุณสามารถแก้ไขพรอมต์และใช้ **แปลพรอมต์** เพื่อแปลเป็นภาษาของคุณได้

<br/>

<a id="create-a-prompt-quickly"></a>
### สร้างพรอมต์อย่างรวดเร็ว

วิธีที่เร็วที่สุดในการสร้างพรอมต์คือ:

1. คลิก **พรอมต์ใหม่**
2. คลิก **สร้างพรอมต์**
3. อธิบายสิ่งที่คุณต้องการให้พรอมต์ทำ
4. เลือกโมเดล
5. ปล่อยให้แอปสร้างร่างให้คุณ
6. ตรวจสอบร่างและคลิก **บันทึก**

![สร้างพรอมต์](../images/screenshots/th/transform-generate.png)


<br/>

<a id="edit-a-prompt"></a>
### แก้ไขพรอมต์

เมื่อคุณสร้างหรือแก้ไขพรอมต์ ตัวแก้ไขจะปรากฏทางด้านซ้าย และพื้นที่ทดสอบจะปรากฏทางด้านขวา

![ตัวแก้ไขพรอมต์แปลง](../images/screenshots/th/transform-prompt-edit.png)

ช่องหลักได้แก่:

- **ชื่อพรอมต์**: ชื่อที่แสดงในรายการพรอมต์
- **คำแนะนำพรอมต์ (ไม่บังคับ)**: คำใบ้สั้น ๆ ที่แสดงแก่ผู้ใช้เมื่อรันพรอมต์
- **บทบาทของโมเดล**: บทบาทโดยรวมที่กำหนดให้ AI เช่น 'คุณคือผู้ช่วยที่เป็นประโยชน์'
- **คำแนะนำโมเดล (หนึ่งบรรทัดต่อหนึ่งคำสั่ง)**: กฎเฉพาะที่คุณต้องการให้ AI ปฏิบัติตาม
- **คำอธิบายผลลัพธ์**: คำสั้น ๆ อธิบายผลลัพธ์ เช่น 'สรุป' หรือ 'เขียนใหม่'
- **อุณหภูมิ (0.0 → 1.0)**: การทำงานของโมเดล ดูคำอธิบายด้านล่าง
- **ขอภาษาเป้าหมาย**: เพิ่มตัวเลือกภาษาเป้าหมายเมื่อรันพรอมต์

หากคุณยังไม่คุ้นเคยกับคำศัพท์ทางเทคนิค **อุณหภูมิ (Temperature)** ให้เข้าใจดังนี้:

- อุณหภูมิ **ต่ำ** จะให้ผลลัพธ์ที่มั่นคงและคาดเดาได้มากกว่า
- อุณหภูมิ **สูง** จะให้ความหลากหลายและความคิดสร้างสรรค์มากกว่า

คุณยังสามารถใช้:

- **`สร้างพรอมต์`** เพื่อสร้างร่างพรอมต์ใหม่จากรายละเอียดอย่างง่าย
- **`ปรับปรุงพรอมต์`** เพื่อพัฒนาพรอมต์ที่มีอยู่ให้ดีขึ้น
- **`แปลพรอมต์`** เพื่อแปลช่องข้อมูลของพรอมต์

<br/>

> ⚠️ **คำเตือน**<br/>
> คลิก **`บันทึก`** ก่อนคลิก **`กลับไปรัน`** หากคุณกลับโดยไม่ได้บันทึก การเปลี่ยนแปลงของคุณจะหายไป

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ทดสอบพรอมต์ก่อนใช้งาน

แผงทดสอบทางด้านขวาช่วยให้คุณสามารถลองใช้พรอมต์กับข้อความตัวอย่างก่อนนำพรอมต์ไปใช้งานจริงในชีวิตประจำวัน

สิ่งนี้มีประโยชน์เมื่อ:

- คุณกำลังสร้างพรอมต์ใหม่
- คุณเปรียบเทียบสองรุ่นของพรอมต์
- คุณต้องการตรวจสอบ น้ำเสียง ความยาว หรือรูปแบบผลลัพธ์

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณสามารถส่งออกและนำเข้าพรอมต์ที่บันทึกไว้ได้ที่ [**การตั้งค่า** > **พรอมต์แปลง**](#transform-prompts)

<a id="delete-stored-records-for-a-model"></a>
### ลบบันทึกที่จัดเก็บสำหรับโมเดล

ในหน้า **ตามโมเดล** หรือ **การเรียกใช้ทั้งหมด** คุณสามารถลบบันทึกที่จัดเก็บไว้สำหรับโมเดลได้โดยการคลิกที่ไอคอน "ถังขยะ"

> ⚠️ **คำเตือน**<br/>
> การลบบันทึกที่จัดเก็บแล้วไม่สามารถยกเลิกได้ โปรดใช้งานเมื่อคุณแน่ใจแล้วว่าไม่ต้องการประวัติดังกล่าวอีกต่อไป

หากต้องการลบข้อมูลทั้งหมด หรือลบบันทึกตามช่วงเวลา อ่านเพิ่มเติมได้ที่ [**การตั้งค่า** > **ติดตามค่าใช้จ่าย**](#cost-tracking) ซึ่งคุณจะพบตัวเลือกในการลบข้อมูลทั้งหมด หรือแค่ข้อมูลที่เก่ากว่าวันที่กำหนด

<a id="general-settings"></a>
### การตั้งค่าทั่วไป

ใช้ **การตั้งค่าทั่วไป** เพื่อควบคุมพฤติกรรมการพิมพ์ ว่ารายละเอียดการดำเนินการจะถูกจัดเก็บไว้ใน **ประวัติการใช้งาน** หรือไม่ รวมถึงรูปลักษณ์ของแอป

**พฤติกรรม**

- **พฤติกรรมของปุ่ม ENTER** กำหนดว่า `Enter` จะเริ่มทำงานทันที หรือจะขึ้นบรรทัดใหม่
- **แปลอัตโนมัติเมื่อวาง** จะเริ่มการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** จะคัดลอกผลลัพธ์ที่สำเร็จโดยอัตโนมัติ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** จะแปลทันทีขณะที่คุณพิมพ์
- **เวลาออก (ms)** ตั้งค่าช่วงเวลารอสำหรับการแปลแบบเรียลไทม์

**ประวัติการใช้งาน**

- **เก็บประวัติการดำเนินการ** ควบคุมว่าแต่ละการแปล เขียนใหม่ และเปลี่ยนรูปแบบ จะเก็บ **ข้อความนำเข้าและผลลัพธ์** ไว้สำหรับแสดงในส่วน [**ประวัติการใช้งาน**](#history) หรือไม่ การปิดใช้งานจะมีการยืนยัน หากคุณยืนยัน ข้อความประวัติที่จัดเก็บไว้จะถูกลบออกจากฐานข้อมูล
- **ลบข้อมูลประวัติ** ให้คุณลบข้อความที่จัดเก็บตามอายุ (เช่น ข้อมูลที่เก่ากว่าไม่กี่เดือน หรือ **ข้อมูลทั้งหมด (ล้าง)**) โดยใช้ **ลบข้อมูล** ซึ่งจะมีผลเฉพาะต่อข้อความการดำเนินการที่บันทึกไว้เพื่อใช้ในมุมมอง **ประวัติการใช้งาน** เท่านั้น แต่จะ **ไม่** ลบข้อมูลยอดรวมค่าใช้จ่ายหรือการใช้งาน หากต้องการลบหรือตัดข้อมูล **ค่าใช้จ่าย** ให้ใช้ [**การตั้งค่า** > **ติดตามค่าใช้จ่าย**](#cost-tracking)

**รูปลักษณ์**

- **แสดงข้อมูลค่าใช้จ่ายในการดำเนินการ** ควบคุมการแสดงค่าใช้จ่ายต่อการดำเนินการ (ถ้ามี) และยอดรวมค่าใช้จ่าย บนแผงผลลัพธ์ของการแปล เขียนใหม่ และเปลี่ยนรูปแบบ
- **จำนวนทศนิยมของค่าใช้จ่าย** เปลี่ยนการแสดงทศนิยมของค่าใช้จ่าย
- **เฉพาะเว็บ:** **แสดงระยะขอบรอบแอป** เพิ่มพื้นที่ว่างรอบอินเทอร์เฟซ
- **ตระกูลแบบอักษร** เปลี่ยนแบบอักษรในแผงข้อความ
- **ขนาด** เปลี่ยนขนาดตัวอักษร

<br/>

<a id="models"></a>

### โมเดล

ใช้ **ตั้งค่า** > **โมเดล** เพื่อเลือกโมเดลที่จะแสดงในแถบเครื่องมือ

![แท็บตั้งค่าโมเดล](../images/screenshots/th/settings-models.png)

หน้านี้มีสองรายการ:

- **โมเดลที่มีอยู่** อยู่ด้านซ้าย
- **โมเดลที่เลือก** อยู่ด้านขวา

ปุ่มควบคุมที่เป็นประโยชน์ ได้แก่:

- **ค้นหาโมเดล...** เพื่อค้นหาโมเดลตามชื่อ
- **ชิปผู้ให้บริการ** เพื่อจำกัดรายการให้เหลือเฉพาะเอนจินหนึ่ง (OpenRouter, OpenAI, Ollama, …)
- **เฉพาะแบบฟรี** เพื่อแสดงโมเดลที่ไม่เสียค่าใช้จ่ายเท่านั้น
- **รีเฟรช** เพื่อโหลดรายการใหม่
- **ขยายนิรันดร์** และ **ยุบรวม** เมื่อคุณจัดเรียงตามผู้ให้บริการ

รหัสโมเดลมีคำนำหน้าจากผู้ให้บริการ (ตัวอย่างเช่น `openrouter/…` เทียบกับ `openai/…`) ป้ายคำว่า **OpenAI (OpenRouter)** กับ **OpenAI (direct)** แสดงวิธีการส่งข้อมูลการร้องขอ

> ℹ️ **หมายเหตุ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) เป็นโมเดลรูทเตอร์ ไม่ใช่โมเดลแชททั่วไป: ผลตอบกลับของมันคือ JSON ที่อธิบายโครงสร้างคำขอ API ของ OpenRouter (เช่น อาร์เรย์ `requests` ที่มี `model` และ `messages`) หากคุณใช้มันใน **แปล**, **เขียนใหม่**, หรือ **แปลงรูปแบบ** แผงผลลัพธ์จะแสดง JSON นั้นแทนข้อความสำเร็จรูป ควรเลือกโมเดลข้อความธรรมดาสำหรับงานเหล่านี้ ดูเพิ่มเติมที่ [หน้าโมเดล Body Builder](https://openrouter.ai/openrouter/bodybuilder) บน OpenRouter

การกระทำ:

 - เพื่อเพิ่มโมเดล ให้คลิก **เพิ่ม** หรือคลิกที่ส่วนใดก็ได้ของรายการ

 - เพื่อลบโมเดล ให้คลิก **X** ถัดจากรายการใน **โมเดลที่เลือก** หรือคลิกที่ **เลือกแล้ว** บนรายการในโมเดลที่มีอยู่

 - เพื่อล้างรายการ ให้คลิก **ยกเลิกการเลือกทั้งหมด** โมเดลฟรีที่จำเป็นจะยังคงอยู่ในรายการ

<br/>

> ℹ️ **หมายเหตุ**<br/>
> หากคุณไม่ต้องการเติมเครดิตเข้า OpenRouter ทันที ให้เริ่มต้นโดยเปิดใช้งาน **เฉพาะแบบฟรี** และเลือกโมเดลที่ไม่เสียค่าใช้จ่าย (ไม่ต้องใช้บัตรเครดิต) คุณยังสามารถใช้ Ollama เพื่อรันโมเดลในเครื่องโดยไม่ต้องใช้ API key

<br/>

<a id="languages"></a>
### ภาษา

ใช้ **ตั้งค่า** > **ภาษา** เพื่อจัดการรายการภาษาที่ใช้ในแอปพลิเคชัน

- **ภาษาที่นิยม** จะถูกตรึงไว้ด้านบนของรายการภาษาใน **แปล** และ **แปลงรูปแบบ**
- **ภาษาแบบกำหนดเอง** ให้คุณเพิ่มภาษาที่ไม่อยู่ในรายการเริ่มต้น

หากคุณเพิ่มภาษาแบบกำหนดเอง รายการนั้นจะปรากฏขึ้นในตัวเลือกภาษาพร้อมกับรายการเริ่มต้น

<a id="cost-tracking"></a>
### การติดตามค่าใช้จ่าย

ใช้ **ตั้งค่า** > **ติดตามค่าใช้จ่าย** เพื่อจัดการข้อมูลค่าใช้จ่าย

- **ค่าใช้จ่ายรวม** แสดงยอดรวมสะสม
- **คัดลอกราคา** คัดลอกยอดรวมไปยังคลิปบอร์ด
- **รีเซ็ตค่าใช้จ่าย** ตั้งค่ายอดรวมเก็บไว้เป็นศูนย์
- **ซิงค์ตามการใช้งานคีย์ API** ตั้งค่ายอดรวมให้ตรงกับการใช้งานที่แจ้งโดยบัญชี OpenRouter ของคุณ (เฉพาะ OpenRouter)
- **การใช้งานคีย์ API** แสดงรายละเอียดการใช้งาน OpenRouter หากมี
- **ลบข้อมูลค่าใช้จ่าย** ลบข้อมูลทั้งหมด หรือเฉพาะรายการที่เก่ากว่าวันที่ที่เลือกไว้

**การติดตามค่าใช้จ่าย:** เมื่อคุณใช้โมเดล OpenRouter แอปจะแสดงการใช้งานและการใช้จ่ายจริงของคุณ ตามข้อมูลต้นทุนจาก OpenRouter ส่วนผู้ให้บริการอื่น แอปจะประมาณการค่าใช้จ่ายโดยใช้ราคาที่ OpenRouter ประกาศ หากไม่มีราคา ค่าที่ประมาณอาจเป็นศูนย์

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ตัวเลขค่าใช้จ่ายทั้งหมดเป็นเพียงการประมาณสำหรับการอ้างอิงของคุณเท่านั้น ไม่ใช่ใบแจ้งหนี้อย่างเป็นทางการ

<br/>

> ⚠️ **คำเตือน**<br/>
> การลบข้อมูลไม่สามารถทำกลับได้ ก่อนลบข้อมูล โปรดสำรองหรือส่งออกระหว่างทางผ่าน [**ประวัติ**](#history)  
> หรือ [**แดชบอร์ด** > **การเรียกทั้งหมด**](#dashboard-tabs) มิฉะนั้นข้อมูลจะหายอย่างถาวร  
> ประวัติข้อมูลนำเข้าและส่งออกทั้งหมดที่เกี่ยวข้องกับแต่ละการใช้ API จะถูกลบด้วย

<br/>

ใช้ **ตั้งค่า** > **พร้อมท์แปลงรูปแบบ** เพื่อจัดการพร้อมท์จำนวนมากพร้อมกัน

- ลบพร้อมท์
- นำเข้าพร้อมท์จากไฟล์
- ส่งออกพร้อมท์สำหรับการสำรองหรือแบ่งปัน

<a id="users"></a>
### ผู้ใช้

ใช้ **ผู้ใช้** เพื่อจัดการบัญชีผู้ใช้ในเวอร์ชันเว็บ คุณสามารถเพิ่มผู้ใช้ แก้ไขข้อมูล ตั้งรหัสผ่านใหม่ และลบบัญชีได้

<br/>

<a id="api-config"></a>
### การตั้งค่า API

ผู้ให้บริการที่รองรับ ได้แก่: OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ **Ollama** (โมเดลในเครื่องผ่าน URL พื้นฐาน) คุณต้องตั้งค่าเฉพาะผู้ให้บริการที่คุณใช้เท่านั้น

**แอปเว็บ: สำหรับผู้ดูแลระบบเท่านั้น**

คีย์ API ถูกตั้งค่าผ่านตัวแปรสภาพแวดล้อมในระบบหรือ Docker — ไม่ได้ป้อนในหน้าเว็บ หน้านี้แสดงว่าผู้ให้บริการใดมีการตั้งค่าคีย์ไว้ และช่วยให้คุณทดสอบแต่ละตัวได้โดยคลิกปุ่ม **`ทดสอบ`**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> เพื่อเปลี่ยนคีย์ API ให้อัปเดตตัวแปรสภาพแวดล้อมในระบบหรือการตั้งค่า Docker ของคุณ แล้วรีสตาร์ทเซิร์ฟเวอร์หรือคอนเทนเนอร์

<br/>

**แอปพลิเคชันเดสก์ท็อป**

ใช้ **การตั้งค่า API** เพื่อจัดเก็บคีย์ API สำหรับผู้ให้บริการแต่ละรายที่คุณใช้ สำหรับ Ollama ให้ป้อน **URL พื้นฐาน** แทนที่จะเป็นคีย์ API

<br/>

> 💡 **เคล็ดลับ** <br/>
> ถ้าไม่ต้องการใช้ API key หรือไม่ต้องการจ่ายค่าใช้จ่าย คุณสามารถ [ดาวน์โหลด Ollama](https://ollama.com) และรันโมเดล (เช่น `translategemma:4b`) ในเครื่องโดยไม่ต้องเสียค่าใช้จ่าย ทางเลือกอื่น คือ คุณสามารถสร้างบัญชี OpenRouter ฟรี (ไม่ต้องใช้บัตรเครดิต) เพื่อใช้โมเดลฟรีของพวกเขา หรือรับคีย์ API ฟรีจาก Cerebras, Google, Groq, หรือ Mistral AI

<br/>

- เพิ่มเฉพาะผู้ให้บริการที่จำเป็นเท่านั้น ใน **ตั้งค่า** > **โมเดล** รหัสแต่ละโมเดลจะขึ้นต้นด้วยผู้ให้บริการ (ตัวอย่างเช่น `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)

ในการเพิ่มคีย์ API ให้ป้อนค่าลงในช่องข้อความแล้วคลิก **`บันทึก`** หากต้องการเปลี่ยนคีย์เดิม ให้คลิก **`แก้ไข`** เพื่อยืนยันว่าคีย์ใช้งานได้ ให้คลิก **`ทดสอบ`** สำหรับ URL พื้นฐานของ Ollama ให้คลิก **`ทดสอบ`** เสมอเพื่อตรวจสอบการเชื่อมต่อ

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณไม่สามารถดูค่าคีย์ API ปัจจุบันได้ คุณสามารถแทนที่ได้เฉพาะโดยใช้ปุ่ม **`แก้ไข`**  
> คีย์ API จะถูกจัดเก็บในรูปแบบเข้ารหัสในการตั้งค่า

<br/>

<a id="common-issues"></a>
## ปัญหาทั่วไป

หากสิ่งใดไม่ทำงานตามที่คาดไว้ ให้ตรวจสอบข้อต่อไปนี้ก่อน

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### แอปไม่สามารถแปล เขียนใหม่ หรือเปลี่ยนข้อความได้

โปรดตรวจสอบว่า:

- คุณได้เลือกโมเดลในแถบเครื่องมือแล้ว
- มีการระบุโมเดลอย่างน้อยหนึ่งตัวใน [**ตั้งค่า** > **โมเดล**](#models)
- การตั้งค่า API ของคุณใช้งานได้

หากคุณใช้แอปเดสก์ท็อป:

1. เปิด [**ตั้งค่า** > **ตั้งค่า API**](#api-config)
2. ตรวจสอบว่ามีการบันทึกคีย์ API อย่างน้อยหนึ่งชุด
3. คลิก **ทดสอบ** ข้างผู้ให้บริการ เพื่อยืนยันว่าคีย์ใช้งานได้

<br/>

<a id="the-model-list-is-empty"></a>
### รายการโมเดลว่างเปล่า

เปิด [**ตั้งค่า** > **โมเดล**](#models) แล้วคลิก **รีเฟรช**

หากจำเป็น ให้:

- ค้นหาโมเดล
- เปิดใช้งาน **เฉพาะแบบฟรี**
- เพิ่มโมเดลหนึ่งตัวหรือมากกว่าลงใน **โมเดลที่เลือก**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ผลลัพธ์ช้าเกินไปหรือมีค่าใช้จ่ายสูงเกินไป

ลองทำวิธีใดวิธีหนึ่งต่อไปนี้:

- เลือกโมเดลอื่น
- ใช้ข้อความนำเข้าที่สั้นลง
- ปิด **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** ใน [**ตั้งค่า** > **ตั้งค่าทั่วไป**](#general-settings)
- ใช้โมเดลฟรีสำหรับงานง่าย ๆ (ดู [โมเดล](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### อินเทอร์เฟซใช้ภาษาที่ไม่ถูกต้อง

คลิกไอคอนรูปโลกใน [แถบเครื่องมือ](#toolbar) แล้วเลือก **ภาษาอินเทอร์เฟซ** ที่คุณต้องการ

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ตัวอักษรเล็กเกินไปหรืออ่านยาก

เปิด [**ตั้งค่า** > **ตั้งค่าทั่วไป**](#general-settings) แล้วเปลี่ยน:

- **แบบอักษร (Font Family)**
- **ขนาด**

<br/>

<a id="dashboard-charts-are-empty"></a>
### แผนภูมิในแดชบอร์ดว่างเปล่า

สิ่งนี้ถือว่าปกติ หาก:

- คุณใช้ **โมเดลแบบฟรีเท่านั้น** (แผนภูมิค่าใช้จ่ายจะว่างเปล่า)
- ตัวกรอง **ช่วงเวลา** ที่เลือกไม่ได้ครอบคลุมช่วงเวลาที่มีการเรียกใช้งาน — ให้ลองเลือก **ทั้งหมด** เพื่อตรวจสอบ

หากแผนภูมิยังคงว่างแม้จะเลือก **ทั้งหมด** แล้ว ให้ตรวจสอบว่ามีการปรากฏการเรียกใช้งานในหน้า [**ประวัติ**](#history) หรือในแท็บ **การเรียกทั้งหมด** หรือไม่

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### แสดงค่าใช้จ่ายว่า "ไม่พร้อมใช้งาน" หรือดูเหมือนผิดพลาด

เมื่อคุณใช้โมเดลผ่าน **OpenRouter** แอปจะแสดงค่าใช้จ่ายจริงที่ OpenRouter แสดงรายงาน

สำหรับ **ผู้ให้บริการอื่น ๆ** (OpenAI โดยตรง, Anthropic โดยตรง ฯลฯ) ค่าใช้จ่ายจะเป็นการประมาณค่าจากข้อมูลราคาที่ OpenRouter เผยแพร่ หากไม่พบราคาที่ตรงกับโมเดลนั้น ค่าใช้จ่ายจะแสดงเป็น **ไม่พร้อมใช้งาน** และจะไม่ถูกนับรวมในยอดรวมที่คำนวณ

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ยอดรวมไม่ตรงกับใบแจ้งหนี้ของผู้ให้บริการ

ตัวเลขค่าใช้จ่ายทั้งหมดในแอปถือเป็น **ค่าประมาณสำหรับการอ้างอิงเท่านั้น** ไม่ใช่ใบเสร็จทางการ

เพื่อให้ยอดรวมใกล้เคียงกับค่าใช้จ่ายจริงใน OpenRouter ของคุณมากขึ้น ให้เปิด [**ตั้งค่า** > **ติดตามค่าใช้จ่าย**](#cost-tracking) แล้วคลิก **ซินค์กับการใช้งานคีย์ API**

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### หน้าประวัติหายไปจากแถบด้านข้าง

ตัวเลือก **เก็บข้อมูลประวัติการดำเนินการ** อาจถูกปิดไว้ โปรดเปิด [**ตั้งค่า** > **ตั้งค่าทั่วไป**](#general-settings) แล้วเปิดการใช้งานตัวเลือกนี้ โปรดทราบว่าการเปิดใช้งานตัวเลือกนี้จะไม่กู้คืนข้อมูลประวัติที่ถูกลบไปก่อนหน้านี้

<br/>

<a id="web-app-session-expired"></a>
### แอปเว็บ: ถูกเปลี่ยนเส้นทางไปยังหน้าล็อกอินโดยไม่คาดคิด

เซสชันของคุณอาจหมดอายุ กรุณาล็อกอินใหม่ หากปัญหานี้เกิดขึ้นบ่อยครั้ง ให้ตรวจสอบการตั้งค่าบนเซิร์ฟเวอร์เกี่ยวกับอายุการใช้งานของเซสชัน

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### แดชบอร์ดไม่แสดงข้อมูลของผู้ใช้รายอื่น (เว็บ)

ผู้ใช้ที่มีสิทธิ์ **ผู้ดูแลระบบ (administrator)** เท่านั้นที่สามารถดูข้อมูลจากผู้ใช้ทุกคนผ่านตัวกรอง **ผู้ใช้** ผู้ใช้ทั่วไปโดยการออกแบบจะเห็นเฉพาะกิจกรรมของตนเองเท่านั้น

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ฉันเปลี่ยนพรอมต์แล้วแต่สูญเสียการแก้ไข

เมื่อแก้ไขพรอมต์ อย่าลืมคลิก **บันทึก** ก่อนคลิก **กลับไปรัน**

<br/><br/>

<a id="quick-tips"></a>
## เคล็ดลับแบบรวดเร็ว

- เริ่มต้นด้วย [**แปล**](#translate) เพื่อยืนยันว่าการตั้งค่าของคุณใช้งานได้ ก่อนจะไปยัง [**เขียนใหม่**](#rewrite) หรือ [**เปลี่ยนรูปแบบ**](#transform)
- ใช้ [**เขียนใหม่**](#rewrite) เพื่อปรับปรุงปรับคำในชีวิตประจำวัน
- ใช้ [**เปลี่ยนรูปแบบ**](#transform) เมื่อคุณต้องการเวิร์กโฟลว์ที่ทำซ้ำได้สำหรับงานเฉพาะ
- ใช้ [**แดชบอร์ด**](#dashboard) หากคุณต้องการติดตามการใช้งานและค่าใช้จ่าย
- ใช้ [**ประวัติ**](#history) เพื่อทบทวนงานในอดีต พร้อมข้อความนำเข้าและส่งออกทั้งหมด
- ส่งออกพรอมต์อย่างสม่ำเสมอ หากคุณกำลังสร้างคลังพรอมต์ที่ต้องการเก็บไว้อย่างปลอดภัย (ดู [พรอมต์เปลี่ยนรูปแบบ](#transform-prompts)) หรือต้องการแบ่งปันกับผู้อื่น
