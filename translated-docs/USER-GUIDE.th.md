# คู่มือผู้ใช้

<br/>

<a id="introduction"></a>
## บทนำ

Transrewrt ช่วยให้คุณทำงานกับข้อความได้สามวิธีหลัก ดังนี้:

- **แปล** - แปลงข้อความจากภาษาหนึ่งไปยังอีกภาษาหนึ่ง  
- **เขียนใหม่** - เขียนข้อความใหม่ในรูปแบบที่ต่างออกไป เช่น ให้ชัดเจนขึ้น สั้นลง หรือเป็นทางการมากขึ้น  
- **แปลง** - ประมวลผลข้อความโดยใช้คำสั่งปัญญาประดิษฐ์ที่กำหนดเอง เรียกว่า คำสั่ง

<br/>

คู่มือนี้อธิบายวิธีการใช้งานแอปหลังจากที่ติดตั้งและเริ่มทำงานแล้ว สำหรับขั้นตอนการติดตั้ง โปรดดูที่ไฟล์ **[README](README.th.md)** หลัก

<br/>

> ℹ️ **หมายเหตุ**<br/>
> Transrewrt มีให้ใช้งานเป็นแอปเดสก์ท็อปสำหรับ Windows และ Linux และยังมีเป็นแอปเว็บที่สามารถโฮสต์เองได้ คู่มือนี้เน้นการใช้งานประจำวันของแอป หากมีสิ่งใดที่ใช้ได้เฉพาะกับเวอร์ชันใดเวอร์ชันหนึ่ง จะมีการระบุไว้อย่างชัดเจน

<a id="before-you-start"></a>
## ก่อนที่คุณจะเริ่มต้น

ในการใช้งาน Transrewrt คุณจำเป็นต้องมีการเข้าถึงผู้ให้บริการ AI อย่างน้อยหนึ่งราย ผู้ให้บริการที่รองรับ ได้แก่ [OpenRouter](https://openrouter.ai) (ซึ่งรวมโมเดลหลายตัวเข้าด้วยกัน), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ [Ollama](https://ollama.com) สำหรับโมเดลท้องถิ่น

คุณไม่จำเป็นต้องเลือกโมเดลแบบเสียเงินเพื่อเริ่มต้น เมื่อคุณเพิ่มคีย์ API ของ OpenRouter แล้ว แอปจะเปิดใช้งานตัวเลือก OpenRouter **ฟรี** ในตัวโดยอัตโนมัติ ซึ่งช่วยให้คุณสามารถเริ่มแปล เขียนใหม่ และแปลงข้อความได้ทันที หรืออีกทางหนึ่ง คุณยังสามารถขอรับคีย์ API ฟรีจาก Cerebras, Google, Groq หรือ Mistral AI ได้อีกด้วย

กล่าวอย่างง่าย ๆ คือ:

- **โมเดล** คือ เครื่องยนต์ AI ที่ทำหน้าที่ทำงาน โมเดลจะแสดงพร้อมคำนำหน้าของ **ผู้ให้บริการ** (ตัวอย่างเช่น `openrouter/…`, `openai/…`, `ollama/…`)
- **คีย์ API** (หรือสำหรับ Ollama คือ **URL พื้นฐาน**) คือ วิธีที่แอปใช้ในการติดต่อกับผู้ให้บริการนั้น

หากคุณใช้ **แอปเดสก์ท็อป** ให้เพิ่มคีย์ในส่วน [**ตั้งค่า** > **การตั้งค่า API**](#api-config) สำหรับผู้ให้บริการแต่ละรายที่คุณใช้ หากใช้เฉพาะ OpenRouter โปรดดู [วิธีรับคีย์ API](#how-to-get-an-api-key-desktop-app) ด้านล่าง หากคุณไม่ต้องการใช้คีย์ API คุณสามารถติดตั้ง Ollama (จาก [ollama.com](https://ollama.com)) และใช้โมเดลท้องถิ่นแทน เช่น `translategemma:4b`

หากคุณใช้ **เวอร์ชันเว็บ** ผู้ดูแลระบบเซิร์ฟเวอร์จะเป็นผู้ตั้งค่าผู้ให้บริการผ่านตัวแปรสภาพแวดล้อม ดังนั้นคุณจึงไม่สามารถป้อนคีย์ API ได้โดยตรงในแอปพลิเคชัน

<br/>

<a id="how-to-get-an-api-key-desktop-app"></a>
### วิธีรับคีย์ API ฟรีจาก OpenRouter (แอปเดสก์ท็อป)

หากคุณใช้แอปเดสก์ท็อป ให้ทำตามขั้นตอนต่อไปนี้:

1. เข้าไปที่ [OpenRouter](https://openrouter.ai) ผ่านเว็บเบราว์เซอร์ของคุณ
2. สร้างบัญชีหรือลงชื่อเข้าใช้
3. เปิดหน้า [Keys](https://openrouter.ai/keys)
4. คลิกปุ่มเพื่อสร้างคีย์ API ใหม่
5. ตั้งชื่อคีย์เพื่อให้คุณสามารถระบุได้ในภายหลัง
6. คัดลอกคีย์ API ใหม่นั้น
7. กลับไปที่ Transrewrt และเปิด **ตั้งค่า** > **การตั้งค่า API**
8. วางคีย์ลงในช่อง **OpenRouter API key** (ภายใต้ **ตั้งค่า** > **การตั้งค่า API**)
9. คลิก **ทดสอบคีย์ OpenRouter** เพื่อให้แน่ใจว่าใช้งานได้

<a id="getting-started"></a>
## เริ่มต้นใช้งาน

หากนี่เป็นครั้งแรกที่คุณใช้ Transrewrt ให้ทำตามลำดับต่อไปนี้:

1. เปิดแอป
2. เลือก **ภาษาอินเทอร์เฟซ** ของคุณจากไอคอนรูปโลก หากต้องการ
3. หากคุณใช้ **แอปเดสก์ท็อป** ให้เปิด [**ตั้งค่า** > **การตั้งค่า API**](#api-config) เพิ่มคีย์ API สำหรับผู้ให้บริการอย่างน้อยหนึ่งราย (ตัวอย่างเช่น OpenRouter) แล้วคลิก **ทดสอบ** เพื่อยืนยันว่าใช้งานได้
4. เปิด [**ตั้งค่า** > **โมเดล**](#models) และเพิ่มโมเดลหนึ่งตัวหรือมากกว่าไปยัง **โมเดลที่เลือก**
5. เปิด [**ตั้งค่า** > **ภาษา**](#languages) และเลือก **ภาษาหลัก** ของคุณ หากต้องการให้ภาษาที่คุณใช้บ่อยที่สุดแสดงขึ้นก่อน
6. ไปที่ **แปล** และดำเนินการแปลง่าย ๆ เพื่อยืนยันว่าทุกอย่างทำงานได้
7. เมื่อทำได้แล้ว ให้ลองใช้ **เขียนใหม่** แล้วตามด้วย **แปลง**

ลำดับนี้มีความสำคัญ เพราะจะช่วยป้องกันปัญหาทั่วไปที่พบบ่อยที่สุดเมื่อใช้ครั้งแรก นั่นคือ การพยายามดำเนินการงานก่อนที่แอปจะมีการเชื่อมต่อ API ที่ใช้งานได้ หรือก่อนที่จะมีการเลือกโมเดล

### แถบเครื่องมือ

แถบเครื่องมือจะเปลี่ยนแปลงเล็กน้อยขึ้นอยู่กับตำแหน่งที่คุณอยู่ในแอป

- ด้านซ้ายจะแสดงชื่อหน้าปัจจุบัน
- ด้านขวาจะแสดงตัวเลือก **โมเดล** และการควบคุม **ภาษาอินเทอร์เฟซ**

ตัวเลือก **โมเดล** ช่วยให้คุณเลือกได้ว่าจะใช้เครื่องมือปัญญาประดิษฐ์ใดสำหรับงานปัจจุบัน

![Model selector](../images/screenshots/th/model-selector.png)

บางโมเดลฟรีอาจไม่สามารถใช้งานได้ตลอดเวลา—บางครั้งอาจออฟไลน์หรือมีขีดจำกัดการใช้งาน หากเกิดเหตุการณ์นี้ แอปจะลบโมเดลดังกล่าวออกจากรายการที่ใช้ได้โดยอัตโนมัติ ในการควบคุมว่าโมเดลใดจะปรากฏ ให้ไปที่ [**ตั้งค่า** > **โมเดล**](#models) และแก้ไขรายการโมเดลของคุณ
คุณยังสามารถเปิดการตั้งค่าโมเดลได้โดยตรงโดยคลิกที่ไอคอนผู้ให้บริการทางด้านซ้ายของชื่อโมเดลในแถบเครื่องมือ

<br/>

ไอคอน **รูปโลก + รหัสภาษา** เปลี่ยนภาษาอินเทอร์เฟซของแอป เช่น เมนูและปุ่ม แต่จะ **ไม่** เปลี่ยนภาษาที่ใช้ในการแปลในหน้า **การแปล**

![Interface language selector](../images/screenshots/th/language-selector.png)

<br/>

<a id="input-and-output-panels"></a>
### แผงข้อมูลนำเข้าและผลลัพธ์

พื้นที่ทำงานส่วนใหญ่จะใช้แผง **ข้อมูลนำเข้า** ด้านซ้ายและแผง **ผลลัพธ์** ด้านขวา

แต่ละแผงยังแสดงข้อมูลดังนี้:

| **ข้อมูลนำเข้า**                                                          | **ผลลัพธ์**                                                                                                                  |
|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| - จำนวนตัวอักษร <br/>- จำนวนคำ <br/>- จำนวนย่อหน้า   <br/> | - ระยะเวลาที่ใช้ในการทำงาน<br/>- **TPS** (โทเค็นต่อวินาที)<br/>- จำนวนตัวอักษร คำ และย่อหน้า<br/>- โมเดลที่ใช้ |

หากคุณสงสัยเกี่ยวกับศัพท์เทคนิค:

- **โทเค็น** หมายถึง ชิ้นส่วนข้อความขนาดเล็ก คุณสามารถคิดว่าเป็นส่วนหนึ่งของคำ หรือคำสั้น ๆ
- **TPS** หมายถึง จำนวนชิ้นส่วนข้อความที่โมเดลประมวลผลได้ในแต่ละวินาที

<br/>

คุณยังสามารถตรวจสอบค่าใช้จ่ายของการดำเนินการแต่ละครั้ง (ถ้ามี) และต้นทุนรวมได้ โดยเปิดใช้งานตัวเลือก `แสดงข้อมูลค่าใช้จ่ายในการดำเนินการ` ที่ [**ตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)

<a id="translate"></a>
## การแปล

ใช้ **การแปล** เมื่อคุณต้องการแปลข้อความจากภาษาหนึ่งไปยังอีกภาษาหนึ่ง

![Translate workspace](../images/screenshots/th/translate.png)

<br/>

<a id="translate-text"></a>
### แปลข้อความ

1. เปิด **การแปล**
2. เลือกภาษาในช่อง **จาก**
3. เลือกภาษาในช่อง **ถึง**
4. เลือกโมเดลในแถบเครื่องมือ
5. พิมพ์หรือวางข้อความลงในช่อง **ข้อมูลนำเข้า**
6. คลิก **แปล**
7. อ่านผลลัพธ์ในช่อง **ผลลัพธ์**
8. ใช้ปุ่มคัดลอกหากคุณต้องการคัดลอกผลลัพธ์

<br/>

<a id="language-selection"></a>
### การเลือกภาษา

- **จาก** อาจเป็นภาษาเฉพาะ หรือ **ตรวจจับภาษา**
- **ถึง** คือภาษาที่คุณต้องการให้ผลลัพธ์ออกมาเป็น

**ภาษาชั้นนำ** ที่คุณเลือกจะปรากฏอยู่ด้านบนสุดของรายการ คุณสามารถตั้งค่าได้ที่ [**ตั้งค่า** > **ภาษา**](#languages)

<br/>

<a id="helpful-translation-settings"></a>
### การตั้งค่าการแปลที่มีประโยชน์

ใน [**ตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) คุณสามารถเปลี่ยนวิธีการทำงานของการแปลได้:

- **แปลอัตโนมัติเมื่อวาง** จะเริ่มการแปลทันทีที่คุณวางข้อความ  
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** จะคัดลอกผลลัพธ์ไปยังคลิปบอร์ดโดยอัตโนมัติหลังจากดำเนินการสำเร็จ  
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** จะเริ่มการแปลขณะที่คุณพิมพ์  
- **เวลาหมดอายุ (มิลลิวินาที)** ควบคุมระยะเวลาที่แอปรอ ก่อนจะเริ่มการแปลแบบเรียลไทม์  
- **Enter** ควบคุมสิ่งที่เกิดขึ้นเมื่อคุณกด `Enter`:

<a id="rewrite"></a>
## เขียนใหม่

ใช้ **เขียนใหม่** เมื่อคุณต้องการปรับปรุงถ้อยคำโดยไม่เปลี่ยนความหมายหลัก

![Rewrite workspace](../images/screenshots/th/rewrite.png)

คุณสมบัตินี้มีประโยชน์สำหรับ:

- แก้ไขการสะกดและการใช้ไวยากรณ์ (**ตรวจสอบการสะกดและความถูกต้องทางไวยากรณ์**)  
- ทำให้ข้อความชัดเจนขึ้น (**ปรับให้ชัดเจนขึ้น**)  
- สร้างรูปแบบการเขียนใหม่หลายแบบในครั้งเดียว (**เวอร์ชันอื่น ๆ**)  
- ทำให้ข้อความเป็นทางการหรือไม่เป็นทางการมากขึ้น (**ทางการ** / **ไม่เป็นทางการ**)  
- ทำให้ข้อความสั้นลงหรือยาวขึ้น (**ทำให้สั้นลง** / **ทำให้ยาวขึ้น**)  
- ทำให้ข้อความฟังดูมีความเป็นทางเทคนิคมากขึ้น (**ทำให้มีความเป็นทางเทคนิค**)

<br/>

> 💡 **เคล็ดลับ**<br/>
> เมื่อคุณใช้โหมด "**ตรวจสอบการสะกดและความถูกต้องทางไวยากรณ์**" จะมีสวิตช์ **แสดงการเปลี่ยนแปลง** ปรากฏในแผงผลลัพธ์ (อยู่ข้างๆ **คัดลอก**)  
> เปิดหรือปิดเพื่อแสดงหรือซ่อนการแก้ไขเฉพาะที่ถูกนำไปใช้กับข้อความของคุณ

<a id="transform"></a>
## แปลง

ใช้ **แปลง** เมื่อคุณต้องการให้ AI ปฏิบัติตามชุดคำแนะนำที่กำหนดเอง

![Transform workspace](../images/screenshots/th/transform.png)

นี่คือส่วนที่ยืดหยุ่นที่สุดของแอป คุณสามารถใช้มันเพื่องานต่าง ๆ เช่น:

- สรุปบันทึก  
- แปลงข้อความร่างให้กลายเป็นอีเมลที่เรียบร้อย  
- ดึงประเด็นสำคัญ  
- แปลงข้อความให้อยู่ในรูปแบบเฉพาะ  
- กิจกรรมอื่น ๆ ที่กำหนดเองกับข้อความนำเข้า

<br/>

<a id="run-an-existing-prompt"></a>
### รันพรอมต์ที่มีอยู่แล้ว

1. เปิด **แปลง**  
2. เลือกพรอมต์จากรายการพรอมต์  
3. หากปรากฏช่อง **เป้าหมาย** ให้เลือกภาษาที่ต้องการ  
4. พิมพ์หรือวางข้อความลงในช่อง **ข้อมูลนำเข้า**  
5. คลิก **แปลง**  
6. อ่านผลลัพธ์ในช่อง **ผลลัพธ์**

<br/>

<a id="if-you-have-no-prompts-yet"></a>
### หากคุณยังไม่มีพรอมต์

หากรายการพรอมต์ของคุณว่างเปล่า ให้คลิก **โหลดพรอมต์ตัวอย่าง** ในพื้นที่ทำงานแปลง การควบคุมเดียวกันนี้จะมีให้ใช้งานเสมอใน [**ตั้งค่า** > **คำสั่งแปลง**](#transform-prompts) ที่แถวส่งออก/นำเข้า ทั้งสองตัวเลือกจะเพิ่มตัวอย่างในตัวเพื่อให้คุณเริ่มต้นได้อย่างรวดเร็ว

<br/>

> ℹ️ **หมายเหตุ**<br/>
> พรอมต์ตัวอย่างจะจัดเตรียมไว้เป็นภาษาอังกฤษ หลังจากโหลดแล้ว คุณสามารถแก้ไขพรอมต์และใช้ **แปลคำสั่ง** เพื่อแปลเป็นภาษาของคุณ

<br/>

<a id="create-a-prompt-quickly"></a>
### สร้างพรอมต์อย่างรวดเร็ว

วิธีที่เร็วที่สุดในการสร้างพรอมต์คือ:

1. คลิก **คำสั่งใหม่**  
2. คลิก **สร้างพรอมต์**  
3. อธิบายสิ่งที่คุณต้องการให้พรอมต์ทำ  
4. เลือกโมเดล  
5. ให้แอปสร้างร่างให้คุณ  
6. ตรวจสอบร่างและคลิก **บันทึก**

![Generate prompt](../images/screenshots/th/transform-generate.png)

<br/>

<a id="edit-a-prompt"></a>
### แก้ไขคำสั่ง

เมื่อคุณสร้างหรือแก้ไขคำสั่ง ตัวแก้ไขจะปรากฏทางด้านซ้าย และพื้นที่ทดสอบจะปรากฏทางด้านขวา

![Transform prompt editor](../images/screenshots/th/transform-prompt-edit.png)

ช่องหลักมีดังนี้:

- **ชื่อคำสั่ง**: ชื่อที่แสดงในรายการคำสั่ง  
- **คำสั่งคำแนะนำ (ไม่บังคับ)**: คำแนะนำสั้น ๆ ที่แสดงให้ผู้ใช้เห็นเมื่อรันคำสั่ง  
- **บทบาทโมเดล**: บทบาทโดยรวมที่กำหนดให้กับ AI เช่น 'คุณคือผู้ช่วยที่มีประโยชน์'  
- **คำสั่งโมเดล (หนึ่งบรรทัดต่อคำสั่ง)**: กฎเฉพาะที่คุณต้องการให้ AI ปฏิบัติตาม  
- **คำอธิบายผลลัพธ์**: คำสั้น ๆ ที่อธิบายผลลัพธ์ เช่น 'สรุป' หรือ 'เขียนใหม่'  
- **อุณหภูมิ (0.0 → 1.0)**: ลักษณะการตอบสนองของโมเดล; ดูคำอธิบายด้านล่าง  
- **สอบถามภาษาเป้าหมาย**: เพิ่มตัวเลือกภาษาเป้าหมายเมื่อรันคำสั่ง

หากคุณยังไม่คุ้นกับศัพท์เทคนิค **อุณหภูมิ** ให้คิดง่าย ๆ ดังนี้:

- อุณหภูมิ**ต่ำ** จะให้ผลลัพธ์ที่มั่นคงและคาดเดาได้มากขึ้น  
- อุณหภูมิ**สูง** จะให้ผลลัพธ์ที่หลากหลายและสร้างสรรค์มากขึ้น

คุณยังสามารถใช้:

- **`สร้างคำสั่ง`** เพื่อสร้างร่างใหม่จากคำอธิบายง่าย ๆ  
- **`ปรับปรุงคำสั่ง`** เพื่อปรับแต่งคำสั่งที่มีอยู่  
- **`แปลคำสั่ง`** เพื่อแปลช่องต่าง ๆ ของคำสั่ง

<br/>

> ⚠️ **คำเตือน**<br/>
> คลิก **`บันทึก`** ก่อนคลิก **`กลับไปรัน`** หากคุณกลับโดยไม่บันทึก การเปลี่ยนแปลงของคุณจะสูญหาย

<br/>

<a id="test-a-prompt-before-using-it"></a>
### ทดสอบคำสั่งก่อนใช้งาน

แผงทดสอบทางด้านขวามือช่วยให้คุณลองใช้คำสั่งกับข้อความตัวอย่างก่อนนำไปใช้ในงานประจำวัน

สิ่งนี้มีประโยชน์เมื่อ:

- คุณกำลังสร้างคำสั่งใหม่  
- คุณกำลังเปรียบเทียบสองเวอร์ชันของคำสั่ง  
- คุณต้องการตรวจสอบน้ำเสียง ความยาว หรือรูปแบบผลลัพธ์

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณสามารถส่งออกและนำเข้าคำสั่งที่บันทึกไว้ได้ที่ [**ตั้งค่า** > **คำสั่งแปลง**](#transform-prompts)

## แดชบอร์ด

ใช้ **แดชบอร์ด** เพื่อดูว่าคุณใช้แอปนี้มากน้อยเพียงใด และค่าใช้จ่ายเป็นเท่าไร (สำหรับโมเดลที่เสียเงิน)

<br/>

> ℹ️ **หมายเหตุ**<br/>

<a id="filter-the-data"></a>
### กรองข้อมูล

ใช้ปุ่มตัวกรองที่ด้านบนเพื่อเปลี่ยนช่วงเวลา

![Dashboard filters](../images/screenshots/th/dashboard-filter.png)

<br/>

> ℹ️ **หมายเหตุ**<br/>
> ตัวกรอง **ผู้ใช้** จะมองเห็นได้เฉพาะผู้ดูแลระบบในเวอร์ชันเว็บเท่านั้น ผู้ใช้ทั่วไปจะไม่เห็นตัวกรองนี้ และไม่สามารถใช้งานได้ในแอปเดสก์ท็อป

<br/>

<a id="dashboard-tabs"></a>
### แท็บแดชบอร์ด

- **สรุป** ให้ภาพรวมของการใช้งานและค่าใช้จ่าย ซึ่งรวมถึง **การใช้งานตามลำดับเวลา** (จำนวน **การเรียกใช้งาน** สะสมแบบเรียงซ้อนรายวัน สำหรับการแปล เขียนใหม่ และแปลง) และ **การใช้งานตามโมเดล** (จำนวน **การเรียกใช้งานต่อโมเดล** ทั้งหมด รวมถึงการแปลง)
- **ตามการใช้งาน** แยกกิจกรรมออกตามภาษาที่แปล โหมดการปรับแต่ง และคำขอเปลี่ยน
- **ตามโมเดล** แสดงโมเดลที่คุณใช้และค่าใช้จ่ายที่เกิดขึ้น
- **ตามวัน** แสดงยอดรวมรายวัน
- **การเรียกใช้งานทั้งหมด** แสดงประวัติการเรียกใช้งานทั้งหมด และให้คุณส่งออกข้อมูลได้

<a id="general-settings"></a>
### การตั้งค่าทั่วไป

ใช้ **การตั้งค่าทั่วไป** เพื่อควบคุมพฤติกรรมการพิมพ์ ว่าจะเก็บรายละเอียดการรันสำหรับ **ประวัติ** หรือไม่ และรูปลักษณ์ของแอป

**พฤติกรรม**

- **พฤติกรรมสำหรับ ENTER** เลือกว่า `Enter` จะรันงานหรือขึ้นบรรทัดใหม่
- **แปลอัตโนมัติเมื่อวาง** เริ่มการแปลทันทีที่คุณวางข้อความ
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** คัดลอกผลลัพธ์ที่สำเร็จโดยอัตโนมัติ
- **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** แปลขณะที่คุณพิมพ์
- **หมดเวลา (มิลลิวินาที)** ตั้งค่าระยะเวลาที่รอสำหรับการแปลแบบเรียลไทม์

**ประวัติ**

- **เก็บประวัติการรัน** ควบคุมว่าแต่ละการแปล เขียนใหม่ และแปลง จะเก็บ **ข้อความนำเข้าและข้อความนำออก** สำหรับมุมมอง [**ประวัติ**](#history) ในแถบด้านข้างหรือไม่ การปิดใช้งานจะขอการยืนยัน; หากคุณยืนยัน ข้อความประวัติที่จัดเก็บจะถูกลบออกจากฐานข้อมูล
- **ลบข้อมูลประวัติ** ช่วยให้คุณลบข้อความที่จัดเก็บตามอายุ (เช่น ข้อมูลที่เก่ากว่าไม่กี่เดือน หรือ **ข้อมูลทั้งหมด (ล้าง)**) โดยใช้ **ลบข้อมูล** ซึ่งจะส่งผลเฉพาะกับข้อความการรันที่บันทึกไว้สำหรับมุมมอง **ประวัติ** เท่านั้น; แต่จะ **ไม่** ลบข้อมูลต้นทุนหรือยอดการใช้งานรวม เพื่อลบหรือตัดข้อมูล **ค่าใช้จ่าย** ให้ใช้ [**ตั้งค่า** > **การติดตามต้นทุน**](#cost-tracking)

**รูปลักษณ์**

- **แสดงข้อมูลค่าใช้จ่ายบนการดำเนินการ** ควบคุมการแสดงค่าใช้จ่ายต่อการดำเนินการ (ถ้ามี) และต้นทุนรวมบนแผงผลลัพธ์การแปล เขียนใหม่ และแปลง
- **จำนวนหลักทศนิยมของค่าใช้จ่าย** เปลี่ยนการแสดงตัวเลขทศนิยมของค่าใช้จ่าย
- **เฉพาะเว็บ:** **แสดงระยะขอบรอบแอป** เพิ่มพื้นที่ว่างรอบอินเตอร์เฟซ
- **ตระกูลแบบอักษร** เปลี่ยนแบบอักษรที่ใช้ในแผงข้อความ
- **ขนาด** เปลี่ยนขนาดตัวอักษร

**การสำรองข้อมูลการตั้งค่า**

- **รวมข้อมูลการใช้งานในการสำรองข้อมูล** — เมื่อเปิดใช้งาน ZIP จะมีข้อมูลประวัติการรันและข้อมูลการเรียกใช้ API ด้วย
- **สำรองข้อมูลการตั้งค่า** — สร้างไฟล์ ZIP เดียว (`transrewrt-config-backup-YYYY-MM-DD_HHMMSS.zip` ตามเวลามาตรฐานสากลโดยค่าเริ่มต้น) ซึ่งมี `config.json`, `state.json`, กุญแจการเข้ารหัส (ถ้ามี), ผู้ใช้, ค่าตั้งค่า, คำสั่งที่กำหนดเอง และข้อมูลการใช้งาน (ถ้าคุณเลือกไว้) หลังจากสำรองข้อมูลสำเร็จ ข้อความยืนยันจะแสดงชื่อไฟล์ที่บันทึกไว้
- **กู้คืนข้อมูลจากไฟล์สำรอง** — จะเปิด **กล่องยืนยันก่อน** เลือกไฟล์ ZIP สำรองข้อมูลภายในกล่องยืนยัน (**เรียกดู** / เลือกไฟล์ หรือลากแล้วปล่อยหากเบราว์เซอร์รองรับ) จากนั้นตรวจสอบตัวเลือก:
  - **คืนค่าข้อมูลการใช้งาน** — นำเข้าข้อมูลการใช้งาน/ประวัติจาก ZIP ที่สำรองไว้เมื่อมีการรวมข้อมูลการใช้งานไว้; ปล่อยไว้ไม่ติ๊กหากคุณต้องการเฉพาะการตั้งค่าและคำสั่ง
  - **ล้างข้อมูลการใช้งานเก่าก่อนการกู้คืน** — ลบข้อมูลการใช้งาน/ประวัติที่มีอยู่ในการติดตั้งนี้ก่อนนำข้อมูลสำรองมาใช้ (ตัวเลือก; ใช้เมื่อต้องการแทนที่ข้อมูลอย่างสมบูรณ์)

สามารถกู้คืนข้อมูลสำรองที่สร้างจากทั้งเวอร์ชันเว็บและเดสก์ท็อปในอีกเวอร์ชันหนึ่งได้ เมื่อกู้คืนข้อมูลสำรองจากเดสก์ท็อปในเวอร์ชันเว็บ ข้อมูลจะถูกกู้คืนไปยังผู้ใช้ผู้ดูแลระบบ

<br/>

<a id="models"></a>
### โมเดล

ใช้ **ตั้งค่า** > **โมเดล** เพื่อเลือกว่าโมเดลใดจะแสดงในแถบเครื่องมือ

![Settings Models tab](../images/screenshots/th/settings-models.png)

หน้านี้มีสองรายการ:

- **โมเดลที่มีอยู่** ทางด้านซ้าย
- **โมเดลที่เลือก** ทางด้านขวา

ตัวควบคุมที่มีประโยชน์ ได้แก่:

- **ค้นหาโมเดล...** เพื่อค้นหาโมเดลตามชื่อ
- ชิป **ผู้ให้บริการ** เพื่อจำกัดรายการให้เหลือเฉพาะเอนจินเดียว (OpenRouter, OpenAI, Ollama, …)
- **เฉพาะฟรี** เพื่อแสดงเฉพาะโมเดลฟรี
- **รีเฟรช** เพื่อรีโหลดรายการ
- **ขยายทั้งหมด** และ **ยุบขั้นตอนทั้งหมด** เมื่อคุณจัดเรียงตามผู้ให้บริการ

รหัสโมเดลรวมถึงคำนำหน้าของผู้ให้บริการ (ตัวอย่างเช่น `openrouter/…` เทียบกับ `openai/…`) ป้ายชื่อ เช่น **OpenAI (OpenRouter)** เทียบกับ **OpenAI (โดยตรง)** แสดงให้เห็นว่าการรับส่งข้อมูลถูกส่งผ่านอย่างไร

> ℹ️ **หมายเหตุ**<br/>
> **OpenRouter Body Builder** (`openrouter/bodybuilder`) เป็นโมเดลเราเตอร์ ไม่ใช่โมเดลแชททั่วไป: คำตอบของมันคือ JSON ที่อธิบายร่างคำขอ API ของ OpenRouter (ตัวอย่างเช่น อาร์เรย์ `requests` ที่มี `model` และ `messages`) หากคุณใช้มันสำหรับ **แปล**, **เขียนใหม่**, หรือ **แปลง**, แผงผลลัพธ์จะแสดง JSON นั้นแทนข้อความที่เสร็จสมบูรณ์ โปรดเลือกโมเดลข้อความทั่วไปสำหรับงานเหล่านี้ ดูหน้า [โมเดล Body Builder](https://openrouter.ai/openrouter/bodybuilder) บน OpenRouter

การกระทำ:

- เพื่อเพิ่มโมเดล ให้คลิก **เพิ่ม** หรือคลิกที่ใดก็ได้ในรายการ

- เพื่อลบโมเดล ให้คลิก **X** ถัดจากมันใน **โมเดลที่เลือก** หรือคลิก **เลือกแล้ว** ที่รายการในโมเดลที่มีอยู่

- เพื่อล้างรายการ ให้คลิก **ยกเลิกการเลือกทั้งหมด** โมเดลฟรีที่จำเป็นจะยังคงอยู่ในรายการ

<br/>

> ℹ️ **หมายเหตุ**<br/>
> หากคุณไม่ต้องการเติมเครดิตให้กับ OpenRouter ทันที ให้เริ่มต้นด้วยการเปิดใช้งาน **เฉพาะฟรี** และเลือกโมเดลฟรี (ไม่ต้องใช้บัตรเครดิต) คุณยังสามารถใช้ Ollama เพื่อรันโมเดลในเครื่องโดยไม่ต้องใช้คีย์ API ใดๆ

<br/>

<a id="languages"></a>
### ภาษา

ใช้ **ตั้งค่า** > **ภาษา** เพื่อจัดการรายการภาษาที่ใช้ในแอป

- **ภาษาที่ใช้บ่อย** จะถูกตรึงไว้ด้านบนสุดของรายการภาษาใน **แปล** และ **แปลง**
- **ภาษาที่กำหนดเอง** ช่วยให้คุณเพิ่มภาษาที่ไม่มีอยู่ในรายการเริ่มต้น

หากคุณเพิ่มภาษาที่กำหนดเอง มันจะปรากฏในตัวเลือกภาษาพร้อมกับตัวเลือกเริ่มต้น

<a id="cost-tracking"></a>
### การติดตามต้นทุน

ใช้ **ตั้งค่า** > **การติดตามต้นทุน** เพื่อจัดการข้อมูลต้นทุน

- **ต้นทุนรวม** แสดงผลรวมสะสม
- **คัดลอกค่า** คัดลอกผลรวมไปยังคลิปบอร์ด
- **รีเซ็ตค่าใช้จ่าย** ตั้งค่าผลรวมที่จัดเก็บไว้เป็นศูนย์
- **ซิงค์กับการใช้งานคีย์ API** ตั้งค่าผลรวมให้ตรงกับการใช้งานที่รายงานโดยบัญชี OpenRouter ของคุณ (เฉพาะ OpenRouter)
- **การใช้งานคีย์ API** แสดงรายละเอียดการใช้งาน OpenRouter หากมี
- **ลบข้อมูลต้นทุน** ลบข้อมูลทั้งหมด หรือเฉพาะรายการที่เก่ากว่าวันที่ที่เลือก

**การติดตามต้นทุน:** เมื่อคุณใช้โมเดล OpenRouter แอปจะแสดงการใช้งานและการใช้จ่ายจริงของคุณตามข้อมูลต้นทุนจาก OpenRouter สำหรับผู้ให้บริการอื่นๆ แอปจะประมาณการต้นทุนโดยใช้ราคาที่เผยแพร่โดย OpenRouter หากไม่มีราคา ตัวประมาณอาจเป็นศูนย์

<br/>

> ℹ️ **หมายเหตุ**<br/>
>  ตัวเลขต้นทุนทั้งหมดเป็นเพียงการประมาณการเพื่อการอ้างอิงของคุณเท่านั้น ไม่ใช่ใบแจ้งหนี้อย่างเป็นทางการ

<br/>

> ⚠️ **คำเตือน**<br/>
> การลบข้อมูลไม่สามารถย้อนกลับได้ ก่อนลบข้อมูล โปรดสำรองข้อมูลหรือส่งออกผ่าน [**ประวัติ**](#history)
> หรือ [**แดชบอร์ด** > **การโทรทั้งหมด**](#dashboard-tabs) มิฉะนั้นข้อมูลจะสูญหายอย่างถาวร
> ประวัติข้อมูลนำเข้า/ผลลัพธ์ที่เกี่ยวข้องกับแต่ละรายการการเรียก API จะถูกลบด้วย

<br/>

<a id="transform-prompts"></a>
### คำสั่งแปลง

ใช้ **ตั้งค่า** > **คำสั่งแปลง** เพื่อจัดการคำสั่งจำนวนมาก

คุณสามารถ:

- ตรวจสอบคำสั่งที่คุณบันทึกไว้  
- ลบคำสั่ง  
- นำเข้าคำสั่งจากไฟล์  
- ส่งออกคำสั่งเพื่อสำรองข้อมูลหรือแบ่งปัน  
- โหลดพรอมต์ตัวอย่างไปยังรายการคำสั่ง

<br/>

<a id="users"></a>
### ผู้ใช้

ใช้ **ผู้ใช้** เพื่อจัดการบัญชีผู้ใช้ในเวอร์ชันเว็บ คุณสามารถเพิ่มผู้ใช้ อัปเดตรายละเอียด รีเซ็ตรหัสผ่าน และลบบัญชีได้

<br/>

<a id="api-config"></a>
### การตั้งค่า API

ผู้ให้บริการที่รองรับ ได้แก่ OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras และ **Ollama** (โมเดลท้องถิ่นผ่าน URL พื้นฐาน) คุณจำเป็นต้องตั้งค่าเฉพาะผู้ให้บริการที่คุณใช้งานเท่านั้น

**แอปพลิเคชันเว็บ: ผู้ดูแลระบบเท่านั้น**

คีย์ API จะถูกตั้งค่าผ่านตัวแปรสภาพแวดล้อมของระบบหรือ Docker — ไม่ได้ป้อนผ่านหน้าเว็บ UI หน้านี้แสดงว่าผู้ให้บริการใดมีการตั้งค่าคีย์แล้ว และให้คุณทดสอบแต่ละตัวโดยคลิกที่ปุ่ม **`ทดสอบ`**

<br/>

> ℹ️ **หมายเหตุ**<br/>
> เพื่อเปลี่ยนคีย์ API ให้อัปเดตตัวแปรสภาพแวดล้อมในระบบหรือการตั้งค่า Docker ของคุณ แล้วรีสตาร์ทเซิร์ฟเวอร์หรือคอนเทนเนอร์

> ℹ️ **หมายเหตุ**<br/>
> **การสำรองข้อมูลการตั้งค่า** (ดูที่ [**การตั้งค่าทั่วไป** → การสำรองข้อมูลการตั้งค่า](#general-settings)) สามารถฝังคีย์ผู้ให้บริการที่ **แก้ไขแล้ว** ไว้ภายในไฟล์ `config.json` ของ ZIP ได้ การกู้คืนไฟล์ ZIP นั้นจะ **ไม่** คัดลอกคีย์เหล่านั้นกลับไปยังไฟล์การตั้งค่าที่เซิร์ฟเวอร์เก็บไว้ — คีย์ที่ใช้งานยังคงมาจากสภาพแวดล้อมและสถานะไฟล์ที่มีอยู่ตามที่อธิบายไว้

<br/>

**แอปพลิเคชันเดสก์ท็อป**

ใช้ **การตั้งค่า API** เพื่อจัดเก็บคีย์ API สำหรับผู้ให้บริการแต่ละรายที่คุณใช้ สำหรับ Ollama ให้ป้อน **URL พื้นฐาน** แทนที่จะเป็นคีย์ API

<br/>

> 💡 **เคล็ดลับ** <br/>
> หากคุณไม่ต้องการใช้คีย์ API หรือไม่ต้องการจ่ายค่าบริการ คุณสามารถ [ดาวน์โหลด Ollama](https://ollama.com) และรันโมเดล (เช่น `translategemma:4b`) บนเครื่องของคุณเองได้ฟรี อีกทางเลือกหนึ่ง คุณสามารถสร้างบัญชี OpenRouter ฟรี (ไม่ต้องใช้บัตรเครดิต) เพื่อใช้โมเดลฟรีของพวกเขา หรือขอรับคีย์ API ฟรีจาก Cerebras, Google, Groq หรือ Mistral AI

<br/>

- เพิ่มเฉพาะผู้ให้บริการที่คุณต้องการเท่านั้น ใน **ตั้งค่า** > **โมเดล** รหัสโมเดลแต่ละตัวจะขึ้นต้นด้วยชื่อผู้ให้บริการ (ตัวอย่างเช่น `openrouter/openrouter/free`, `openai/gpt-4o`, `ollama/llama3`)

ในการเพิ่มคีย์ API ให้ป้อนค่าลงในช่องข้อความแล้วคลิก **`บันทึก`** เพื่อเปลี่ยนคีย์ที่มีอยู่ ให้คลิก **`แก้ไข`** เพื่อยืนยันว่าคีย์ทำงานได้หรือไม่ ให้คลิก **`ทดสอบ`** สำหรับ URL พื้นฐานของ Ollama ให้คลิก **`ทดสอบ`** เสมอเพื่อตรวจสอบการเชื่อมต่อ

<br/>

> ℹ️ **หมายเหตุ**<br/>
> คุณไม่สามารถดูค่าคีย์ API ปัจจุบันได้ คุณสามารถเปลี่ยนค่าได้เฉพาะโดยใช้ปุ่ม **`แก้ไข`** เท่านั้น
> คีย์ API จะถูกจัดเก็บในรูปแบบเข้ารหัสภายในไฟล์การตั้งค่า

<br/>

<a id="common-issues"></a>
## ปัญหาทั่วไป

หากมีบางอย่างไม่ทำงานตามที่คาดหวัง ให้ตรวจสอบประเด็นต่อไปนี้ก่อน

<br/>

<a id="the-app-will-not-translate-rewrite-or-transform-text"></a>
### แอปจะไม่แปล ไม่เขียนใหม่ หรือไม่แปลงข้อความ

โปรดตรวจสอบว่า:

- คุณได้เลือกโมเดลในแถบเครื่องมือแล้ว
- มีโมเดลอย่างน้อยหนึ่งโมเดลที่แสดงอยู่ใน [**ตั้งค่า** > **โมเดล**](#models)
- การตั้งค่า API ของคุณทำงานได้ถูกต้อง

หากคุณใช้แอปเดสก์ท็อป:

1. เปิด [**ตั้งค่า** > **การตั้งค่า API**](#api-config)
2. ตรวจสอบว่ามีการบันทึกคีย์ API อย่างน้อยหนึ่งคีย์
3. คลิก **ทดสอบ** ถัดจากผู้ให้บริการ เพื่อยืนยันว่าคีย์ทำงานได้

<br/>

<a id="the-model-list-is-empty"></a>
### รายการโมเดลว่างเปล่า

เปิด [**ตั้งค่า** > **โมเดล**](#models) แล้วคลิก **รีเฟรช**

หากจำเป็น:

- ค้นหาโมเดล
- เปิดใช้งาน **เฉพาะฟรี**
- เพิ่มโมเดลหนึ่งตัวหรือมากกว่าลงใน **โมเดลที่เลือก**

<br/>

<a id="the-result-is-too-slow-or-too-expensive"></a>
### ผลลัพธ์ช้าเกินไปหรือมีค่าใช้จ่ายสูงเกินไป

ลองทำอย่างใดอย่างหนึ่งหรือมากกว่าต่อไปนี้:

- เลือกโมเดลอื่น
- ใช้ข้อมูลนำเข้าที่สั้นลง
- ปิด **การแปลแบบเรียลไทม์ (ขณะพิมพ์)** ใน [**ตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings)
- ใช้โมเดลฟรีสำหรับงานง่าย ๆ (ดู [โมเดล](#models))

<br/>

<a id="the-interface-is-in-the-wrong-language"></a>
### อินเทอร์เฟซอยู่ในภาษาที่ผิด

คลิกไอคอนโลกใน [แถบเครื่องมือ](#toolbar) แล้วเลือก **ภาษาอินเทอร์เฟซ** ที่คุณต้องการ

<br/>

<a id="the-text-is-too-small-or-hard-to-read"></a>
### ข้อความมีขนาดเล็กเกินไปหรืออ่านยาก

เปิด [**ตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) แล้วเปลี่ยน:

- **ตระกูลแบบอักษร**
- **ขนาด**

<br/>

<a id="dashboard-charts-are-empty"></a>
### แผนภูมิในแดชบอร์ดว่างเปล่า

นี่เป็นเรื่องปกติหาก:

- คุณใช้เฉพาะ **โมเดลฟรี** และคุณกำลังดูตัวเลข **ค่าใช้จ่าย** (อาจเป็นศูนย์); แผนภูมิจำนวน **การเรียกใช้งาน** ในหน้า **สรุป** ยังต้องการข้อมูลจากระยะเวลาที่เลือก
- **ตัวกรองเวลา** ที่เลือกไม่ครอบคลุมช่วงเวลาที่มีการเรียกใช้งาน — ลองใช้ **ทั้งหมด** เพื่อตรวจสอบ

หากแผนภูมิยังคงว่างเปล่าหลังจากเลือก **ทั้งหมด** ให้ยืนยันว่ามีการเรียกใช้งานปรากฏใน [**ประวัติ**](#history) หรือในแท็บ **การโทรทั้งหมด**

<br/>

<a id="cost-shows-not-available-or-seems-wrong"></a>
### ค่าใช้จ่ายแสดงว่า "ไม่พร้อมใช้งาน" หรือดูเหมือนผิด

เมื่อคุณใช้โมเดลผ่าน **OpenRouter** แอปจะแสดงค่าใช้จ่ายจริงที่ OpenRouter รายงาน

สำหรับ **ผู้ให้บริการอื่นๆ** (OpenAI โดยตรง, Anthropic โดยตรง ฯลฯ) ค่าใช้จ่ายจะถูกประมาณการจากข้อมูลราคาที่ OpenRouter ประกาศไว้ หากไม่พบราคาที่ตรงกับโมเดล ค่าใช้จ่ายจะแสดงเป็น **ไม่พร้อมใช้งาน** และจะไม่ถูกเพิ่มเข้าไปในยอดรวมของคุณ

<br/>

<a id="total-cost-does-not-match-my-provider-bill"></a>
### ต้นทุนรวมไม่ตรงกับใบแจ้งหนี้จากผู้ให้บริการ

ตัวเลขค่าใช้จ่ายทั้งหมดในแอปเป็น **ตัวประมาณการเพื่อการอ้างอิงเท่านั้น** ไม่ใช่ใบแจ้งหนี้อย่างเป็นทางการ

เพื่อให้ยอดรวมใกล้เคียงกับค่าใช้จ่ายจริงของคุณผ่าน OpenRouter ให้เปิด [**ตั้งค่า** > **การติดตามต้นทุน**](#cost-tracking) แล้วคลิก **ซิงค์กับการใช้งานคีย์ API**

<br/>

<a id="the-history-page-is-missing-from-the-sidebar"></a>
### หน้าประวัติหายไปจากแถบด้านข้าง

**เก็บประวัติการรัน** อาจถูกปิดอยู่ ให้เปิด [**ตั้งค่า** > **การตั้งค่าทั่วไป**](#general-settings) แล้วเปิดใช้งาน โปรดทราบว่าการเปิดใช้งานจะไม่กู้คืนข้อมูลประวัติที่ถูกลบไปก่อนหน้านี้

<br/>

<a id="web-app-session-expired"></a>
### เว็บแอป: ถูกเปลี่ยนเส้นทางไปยังหน้าเข้าสู่ระบบโดยไม่คาดคิด

เซสชันของคุณอาจหมดเวลา ให้เข้าสู่ระบบอีกครั้ง หากเกิดขึ้นบ่อยครั้ง ให้ตรวจสอบการตั้งค่าระยะเวลาของเซสชันในเซิร์ฟเวอร์

<br/>

<a id="web-admin-forgot-or-lost-a-password"></a>
### เว็บผู้ดูแลระบบ: ลืมหรือสูญเสียรหัสผ่าน

สิ่งนี้ใช้กับ **เว็บแอปที่โฮสต์เอง** (Docker) ไม่ใช่แอปเดสก์ท็อป (Electron)

- หากผู้ดูแลระบบคนอื่นยังสามารถเข้าสู่ระบบได้ พวกเขาสามารถเปิด [**ตั้งค่า** > **ผู้ใช้**](#users) เลือกบัญชี และตั้ง **รหัสผ่านใหม่** ได้ที่นั่น
- หากคุณ **ถูกล็อกออก** แต่มี **การเข้าถึง shell** ไปยังเครื่องหรือคอนเทนเนอร์ ให้รีเซ็ตรหัสผ่านโดยใช้เครื่องมือช่วยที่มากับอิมเมจ (เปลี่ยน `transrewrt` หากคุณเปลี่ยนชื่อเริ่มต้น และใส่เครื่องหมายคำพูดล้อมรหัสผ่านหากมีช่องว่างหรืออักขระพิเศษ):

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ชื่อผู้ใช้ผู้ดูแลระบบเริ่มต้นคือ `admin` หากคุณไม่เคยสร้างบัญชีอื่น เมื่อคุณใส่เพียงหนึ่งอาร์กิวเมนต์ มันจะถูกตีความว่าเป็นรหัสผ่านใหม่สำหรับ `admin`

หากคุณรันจาก **การเช็คเอาต์ซอร์ส** แทน Docker ให้ใช้:

```bash
pnpm run reset-web-password -- <username> <new-password>
```

สคริปต์จะอัปเดตข้อมูลผู้ใช้ในฐานข้อมูล SQLite (และสามารถสร้างผู้ใช้ `admin` ได้หากไม่มี) หลังจากรีเซ็ต ให้เข้าสู่ระบบด้วยรหัสผ่านใหม่

<br/>

<a id="dashboard-shows-no-data-for-other-users"></a>
### แดชบอร์ดไม่แสดงข้อมูลของผู้ใช้อื่น (เว็บ)

เฉพาะ **ผู้ดูแลระบบ** เท่านั้นที่สามารถดูข้อมูลจากผู้ใช้ทั้งหมดผ่านตัวกรอง **ผู้ใช้** ผู้ใช้ทั่วไปจะเห็นเฉพาะกิจกรรมของตนเองตามการออกแบบ

<br/>

<a id="i-changed-a-prompt-and-lost-the-edits"></a>
### ฉันเปลี่ยนคำสั่งแล้วแต่สูญเสียการแก้ไข

เมื่อแก้ไขคำสั่ง ให้คลิก **บันทึก** เสมอก่อนคลิก **กลับไปยังการดำเนินการ**

<br/><br/>

<a id="quick-tips"></a>
## เคล็ดลับด่วน

- เริ่มต้นด้วย [**แปล**](#translate) เพื่อให้แน่ใจว่าการตั้งค่าของคุณทำงานได้ก่อนที่จะไปยัง [**เขียนใหม่**](#rewrite) หรือ [**แปลง**](#transform)
- ใช้ [**เขียนใหม่**](#rewrite) เพื่อปรับปรุงถ้อยคำในชีวิตประจำวัน
- ใช้ [**แปลง**](#transform) เมื่อคุณต้องการเวิร์กโฟลว์ที่สามารถทำซ้ำได้สำหรับงานเฉพาะอย่าง
- ใช้ [**แดชบอร์ด**](#dashboard) หากคุณต้องการติดตามการใช้งานและค่าใช้จ่าย
- ใช้ [**ประวัติ**](#history) เพื่อทบทวนการดำเนินการก่อนหน้าและข้อความนำเข้า/นำออกทั้งหมด
- ส่งออกคำสั่งอย่างสม่ำเสมอ หากคุณกำลังสร้างห้องสมุดคำสั่งที่ต้องการเก็บรักษาไว้อย่างปลอดภัย (ดู [คำสั่งแปลง](#transform-prompts)) หรือหากคุณต้องการแบ่งปันกับผู้อื่น

<br/><br/>

## ข้อจำกัดความรับผิดชอบ
