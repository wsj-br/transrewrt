Utilizați **Panoul de control** pentru a vedea cât de mult utilizați aplicația și ce costuri aveți (pentru modelele plătite).

![Rezumatul panoului de control](/images/screenshots/ro/dashboard-summary.png)

:::note
Dacă utilizați doar modele **gratuite**, sumele de cost pot fi zero. Indicatorii de performanță ai apelurilor (KPI) de pe **Rezumat** necesită totuși activitate în perioada selectată.
:::

## Filtrați datele

Utilizați butoanele de filtrare de sus pentru a schimba intervalul de timp.

:::note
Filtrul **Utilizator** este vizibil doar pentru administratori în versiunea web. Nu este disponibil pe desktop.
:::

## File

- **Rezumat** — indicatori de performanță: cost total, modele utilizate, număr de apeluri și cost pe mod, cost mediu pe apel, TPS mediu, modelele principale după numărul de apeluri
- **Pe model** — apeluri, cost și TPS pe model; extindeți o linie pentru a obține o defalcare a modului
- **Toate apelurile** — jurnalul complet al apelurilor (paginat sau în formă de carduri) cu export

## Exportați datele

Exportați tabelele în format **JSON**, **CSV** sau **XLSX**.

## Ștergeți înregistrările stocate pentru un model

În **Pe model** sau **Toate apelurile**, utilizați iconița de coș de gunoi pentru a șterge înregistrările pentru un model.

:::caution
Ștergerea nu poate fi anulată. Pentru a șterge după vârstă sau a curăța toate datele de cost, utilizați [Setări → Urmărirea costurilor](/docs/settings/#cost-tracking).
:::
