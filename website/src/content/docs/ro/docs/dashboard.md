Utilizați **Tabloul de bord** pentru a vedea cât de mult utilizați aplicația și cât costă (pentru modelele plătite).

![Sumarul Tabloului de bord](/images/screenshots/ro/dashboard-summary.png)

:::note
Dacă utilizați doar modele **gratuite**, sumele costurilor pot fi zero. KPI-urile de număr de apeluri din **Sumar** necesită în continuare activitate în perioada selectată.
:::

## Filtrați datele

Utilizați butoanele de filtrare din partea de sus pentru a schimba intervalul de timp.

:::note
Filtrul **Utilizator** este vizibil doar pentru administratori în versiunea web. Nu este disponibil pe desktop.
:::

## File

- **Sumar** — KPI-uri: cost total, modele utilizate, număr de apeluri și cost per mod, cost mediu per apel, TPS mediu, modele de top după numărul de apeluri
- **După model** — apeluri, cost și TPS per model; extindeți un rând pentru o defalcare pe moduri
- **Toate apelurile** — jurnal complet de apeluri (paginat sau carduri) cu export

## Exportați datele

Exportați tabelele ca **JSON**, **CSV** sau **XLSX**.

## Ștergeți înregistrările stocate pentru un model

În **După model** sau **Toate apelurile**, utilizați pictograma coș de gunoi pentru a elimina înregistrările pentru un model.

:::caution
Ștergerea nu poate fi anulată. Pentru a șterge după vechime sau a șterge toate datele de cost, utilizați [Setări → Urmărirea costurilor](/docs/settings/#cost-tracking).
:::
