Χρησιμοποιήστε το **Μετασχηματισμός** όταν θέλετε η AI να ακολουθήσει προσαρμοσμένες οδηγίες — να συνοψίσει, να βελτιώσει ένα email, να εξαγάγει βασικά σημεία, να αναδιαμορφώσει κείμενο ή οποιαδήποτε ροή εργασίας ορίσετε.

![Χώρος εργασίας Μετασχηματισμού](/images/screenshots/el/transform.png)

## Εκτέλεση υπάρχουσας προτροπής

1. Ανοίξτε το **Μετασχηματισμός**.
2. Επιλέξτε μια προτροπή από τη λίστα.
3. Εάν εμφανιστεί ένα πλαίσιο γλώσσας **Από**, ορίστε μια γλώσσα εάν το επιθυμείτε.
4. Πληκτρολογήστε ή επικολλήστε κείμενο στο **Εισαγωγή**.
5. Κάντε κλικ στο **Μετασχηματισμός**.
6. Διαβάστε το αποτέλεσμα στην **Έξοδο**.

## Φόρτωση δειγμάτων προτροπών

Εάν η λίστα είναι κενή, κάντε κλικ στο **Φόρτωση δειγμάτων προτροπών** στον χώρο εργασίας Μετασχηματισμού (διαθέσιμο επίσης στις [Ρυθμίσεις → Μετασχηματισμός](/docs/settings/#transform)). Τα δείγματα είναι στα Αγγλικά. Μετά τη φόρτωση, επεξεργαστείτε μια προτροπή και χρησιμοποιήστε το **Μετάφραση προτροπής** εάν χρειάζεται.

## Δημιουργία προτροπής

1. Κάντε κλικ στο **Νέα προτροπή**.
2. Κάντε κλικ στο **Δημιουργία προτροπής**.
3. Περιγράψτε τι θέλετε να κάνει η προτροπή.
4. Επιλέξτε μια προεπιλογή (Εύκολο) ή ένα μοντέλο (Προχωρημένο).
5. Ελέγξτε το προσχέδιο και κάντε κλικ στο **Αποθήκευση**.

## Επεξεργασία προτροπής

Ο επεξεργαστής βρίσκεται στα αριστερά. Ένας χώρος δοκιμής βρίσκεται στα δεξιά.

![Επεξεργαστής προτροπών Μετασχηματισμού](/images/screenshots/el/transform-prompt-edit.png)

Κύρια πεδία:

- **Όνομα προτροπής** — εμφανίζεται στη λίστα προτροπών
- **Οδηγίες προτροπής (προαιρετικό)** — σύντομη υπόδειξη κατά την εκτέλεση της προτροπής
- **Ρόλος μοντέλου** — συνολικός ρόλος για την AI
- **Οδηγίες μοντέλου (μία ανά γραμμή)** — κανόνες που πρέπει να ακολουθηθούν
- **Περιγραφή εξόδου** — σύντομη ετικέτα για το αποτέλεσμα (π.χ. συνοψισμένο)
- **Θερμοκρασία (0.0 → 1.0)** — χαμηλότερη είναι πιο σταθερή· υψηλότερη είναι πιο ποικίλη
- **Ζητήστε γλώσσα στόχο** — προσθέτει έναν επιλογέα γλώσσας κατά την εκτέλεση

Βοηθοί: **Δημιουργία προτροπής**, **Βελτίωση προτροπής**, **Μετάφραση προτροπής** (το Εύκολο χρησιμοποιεί προεπιλογές· το Προχωρημένο χρησιμοποιεί τη λίστα μοντέλων).

:::caution
Κάντε κλικ στο **Αποθήκευση** πριν από το **Επιστροφή στην εκτέλεση**. Η επιστροφή χωρίς αποθήκευση απορρίπτει τις επεξεργασίες.
:::

## Δοκιμή πριν από την καθημερινή χρήση

Χρησιμοποιήστε τον πίνακα δοκιμών στα δεξιά με δείγμα κειμένου κατά τη δημιουργία ή τη σύγκριση προτροπών.

Εξαγωγή και εισαγωγή προτροπών μαζικά στην ενότητα [Ρυθμίσεις → Μετασχηματισμός](/docs/settings/#transform).
