## Τοποθεσίες αρχείων διαμόρφωσης

| Ανάπτυξη | Φάκελος δεδομένων |
| --- | --- |
| Electron (Windows) | `%APPDATA%\transrewrt\` |
| Electron (Linux) | `~/.config/transrewrt/` |
| Web / Docker | `/app/data/` (χρησιμοποιήστε έναν τόμο για διατήρηση) |

Ο φάκελος δεδομένων περιέχει όλα όσα αξίζει να δημιουργήσετε αντίγραφα ασφαλείας:

- `config.json` — ρυθμίσεις και (επιτραπέζιοι) κρυπτογραφημένοι κωδικοί API
- `state.json` — τελευταίες χρησιμοποιούμενες γλώσσες, μοντέλο και κατάσταση προβολής
- `presets.json` — προσωρινά αποθηκευμένος κατάλογος προεπιλογών Easy-mode
- `transrewrt.db` — βάση δεδομένων SQLite με ιστορικό, κόστος, προτροπές, γλωσσάρι και (ιστού) χρήστες

Μπορείτε επίσης να δημιουργήσετε ένα φορητό ZIP αντιγράφου ασφαλείας από την εφαρμογή — δείτε [Ρυθμίσεις → Γενικές Ρυθμίσεις](/docs/settings/#general-settings).

## Μεταβλητές περιβάλλοντος (web / Docker)

Το Electron χρησιμοποιεί το τοπικό αρχείο διαμόρφωσης. Μόνο για τον διακομιστή web/Docker:

| Μεταβλητή | Περιγραφή |
| --- | --- |
| `PORT` | Θύρα ακρόασης διακομιστή (προεπιλογή `5000`) |
| `CONFIG_PATH` | Διαδρομή προς το αρχείο διαμόρφωσης (προεπιλογή `/app/data/config.json`) |
| `TZ` | Ζώνη ώρας για την ώρα από την πλευρά του διακομιστή (προεπιλογή `Europe/London`) |
| `HISTORY_DISABLED` | Αναγκαστική απενεργοποίηση ιστορικού εκτέλεσης (`true` / `1`) |
| `OPENROUTER_API_KEY` | Κλειδί API OpenRouter |
| `OPENAI_API_KEY` | Κλειδί API OpenAI |
| `CEREBRAS_API_KEY` | Κλειδί API Cerebras |
| `ANTHROPIC_API_KEY` | Κλειδί API Anthropic |
| `GOOGLE_API_KEY` | Κλειδί API Google Gemini |
| `DEEPSEEK_API_KEY` | Κλειδί API DeepSeek |
| `GROQ_API_KEY` | Κλειδί API Groq |
| `MISTRAL_API_KEY` | Κλειδί API Mistral |
| `LOCAL_LLM_URL` | Πλήρης διεύθυνση URL βάσης API συμβατή με OpenAI για έναν τοπικό διακομιστή, συμπεριλαμβανομένης της διαδρομής (για παράδειγμα Ollama `http://host.docker.internal:11434/v1`, LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | Κλειδί API xAI |
| `NVIDIA_API_KEY` | Κλειδί API NVIDIA |
| `ALIBABA_API_KEY` | Κλειδί API Alibaba Cloud (DashScope) |
| `APIFUN_API_KEY` | Κλειδί API apikey.fun |
| `CUSTOM_PROVIDER_NAME` | Όνομα εμφάνισης για έναν προσαρμοσμένο πάροχο συμβατό με OpenAI |
| `CUSTOM_PROVIDER_URL` | Βασική διεύθυνση URL για έναν προσαρμοσμένο πάροχο συμβατό με OpenAI |
| `CUSTOM_PROVIDER_API_KEY` | Κλειδί API για τον προσαρμοσμένο πάροχο |

Και οι τρεις μεταβλητές `CUSTOM_PROVIDER_*` απαιτούνται κατά τη χρήση ενός προσαρμοσμένου τελικού σημείου. Τα μοντέλα εμφανίζονται σε λειτουργία **Για προχωρημένους** ως `{providerName}/…`.

## Μεταβλητές περιβάλλοντος (επιτραπέζιος υπολογιστής)

| Μεταβλητή | Περιγραφή |
| --- | --- |
| `TRANSREWRT_DISABLE_GPU` | Ορίστε σε `1` για απενεργοποίηση της επιτάχυνσης υλικού (χρήσιμο όταν το Chromium εκτυπώνει σφάλματα GPU / EGL σε Linux) |
| `HISTORY_DISABLED` | Αναγκαστική απενεργοποίηση του ιστορικού εκτέλεσης (`true` / `1`) — δείτε [Λειτουργία απορρήτου](#privacy-mode) |

## Λειτουργία απορρήτου

Ορίστε το `HISTORY_DISABLED` σε `true` ή `1` στη διαδικασία διακομιστή web/Docker και/ή στην κύρια διαδικασία Electron για να αναγκάσετε την απενεργοποίηση του ιστορικού ανεξάρτητα από το `config.json` ή τις προτιμήσεις ανά χρήστη. Αυτό απενεργοποιεί την αποθήκευση του ιστορικού εισόδου/εξόδου, κλειδώνει τις **Ρυθμίσεις → Γενικές Ρυθμίσεις → Ιστορικό** και μπλοκάρει τα API που σχετίζονται με το Ιστορικό.

## Διατήρηση δεδομένων (Docker)

Προσαρτήστε έναν τόμο στο `/app/data`, ώστε τα αρχεία διαμόρφωσης και η βάση δεδομένων SQLite (βλ. [Τοποθεσίες αρχείων διαμόρφωσης](#config-file-locations)) να επιβιώνουν από τις επανεκκινήσεις του κοντέινερ. Χωρίς τόμο, τα δεδομένα χάνονται όταν το κοντέινερ σταματήσει.

## Έλεγχος ταυτότητας ιστού

- Προεπιλεγμένος διαχειριστής: `admin` / `transrewrt26`
- Διαχειριστείτε χρήστες, λήξη χρονικού ορίου περιόδου λειτουργίας και ανάκληση περιόδου λειτουργίας στις **Ρυθμίσεις → Χρήστες** — δείτε [Ρυθμίσεις](/docs/settings/#users)
- Κάθε συνδεδεμένος χρήστης μπορεί να αλλάξει τον δικό του κωδικό πρόσβασης ή να αποσυνδεθεί από το μενού χρήστη στο κάτω μέρος της πλευρικής γραμμής
- Επαναφορά κωδικού πρόσβασης:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
Αλλάξτε τον προεπιλεγμένο κωδικό πρόσβασης διαχειριστή αμέσως σε οποιονδήποτε προσβάσιμο μέσω δικτύου κεντρικό υπολογιστή.
:::

:::caution
Ο διακομιστής χρησιμοποιεί απλό HTTP. Εάν τον εκθέσετε πέρα από τον localhost ή ένα αξιόπιστο δίκτυο, τοποθετήστε τον πίσω από έναν αντίστροφο διακομιστή μεσολάβησης με HTTPS (για παράδειγμα Caddy, nginx ή Traefik), ώστε οι κωδικοί πρόσβασης και το κείμενο να μην αποστέλλονται σε απλό κείμενο.
:::

## Εμφάνιση κόστους

Το OpenRouter επιστρέφει το ακριβές χρεωμένο κόστος όταν είναι εφικτό. Άλλοι πάροχοι χρησιμοποιούν **εκτιμώμενο** κόστος από τη δημόσια τιμολόγηση μοντέλων του OpenRouter όταν είναι διαθέσιμο ένα κλειδί OpenRouter. Οι εκτιμήσεις δεν είναι τιμολόγια.

Για το UI Ρυθμίσεων (γραμματοσειρές, μοντέλα, ιστορικό, αντίγραφα ασφαλείας), δείτε [Ρυθμίσεις](/docs/settings/).
