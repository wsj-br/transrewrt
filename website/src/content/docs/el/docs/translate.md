Χρησιμοποιήστε τη λειτουργία **Μετάφραση** για να μετατρέψετε κείμενο από μία γλώσσα σε άλλη.

![Χώρος εργασίας μετάφρασης](/images/screenshots/el/translate.png)

## Προαπαιτούμενα

- Τουλάχιστον ένα κλειδί παρόχου (για επιτραπέζιους υπολογιστές) ή κλειδί περιβάλλοντος διακομιστή (για τον ιστό) — δείτε [Κλειδί API](/docs/api-key/)
- Μια **προεπιλογή** (Εύκολη) ή ένα **μοντέλο** (Προχωρημένο) επιλεγμένο στη γραμμή εργαλείων

## Μετάφραση κειμένου

1. Ανοίξτε τη λειτουργία **Μετάφραση** στην πλαϊνή γραμμή.
2. Επιλέξτε μια γλώσσα στην ενότητα **Από** (ή **Ανίχνευση γλώσσας**).
3. Επιλέξτε μια γλώσσα στην ενότητα **Προς**.
4. Επιλέξτε μια προεπιλογή ή ένα μοντέλο στη γραμμή εργαλείων.
5. Πληκτρολογήστε ή επικολλήστε κείμενο στην ενότητα **Εισαγωγή**.
6. Κάντε κλικ στην επιλογή **Μετάφραση**.
7. Διαβάστε το αποτέλεσμα στην ενότητα **Έξοδος** και, στη συνέχεια, αντιγράψτε το εάν χρειάζεται.

Οι **Κορυφαίες γλώσσες** εμφανίζονται πρώτες στις λίστες — ορίστε τις στις [Ρυθμίσεις → Γλώσσες](/docs/settings/#languages).

## Χρήσιμες ρυθμίσεις

Στις [Ρυθμίσεις → Γενικές Ρυθμίσεις](/docs/settings/#general-settings):

- **Αυτόματη εκτέλεση κατά την επικόλληση** — εκτελείται μόλις επικολλήσετε
- **Αυτόματη αντιγραφή αποτελέσματος στο πρόχειρο** — αντιγράφει μετά από επιτυχή εκτέλεση
- **Μετάφραση σε πραγματικό χρόνο κατά την πληκτρολόγηση** — εκτελείται ενώ πληκτρολογείτε (μπορεί να αυξήσει το κόστος)
- **Χρονικό όριο (ms)** — αναμονή πριν από μια εκτέλεση σε πραγματικό χρόνο
- **Συμπεριφορά για το ENTER** — εάν το Enter εκτελεί την εργασία ή εισάγει μια νέα γραμμή

## Διάταξη και πληκτρολόγιο

- **Εναλλαγή διάταξης** — τα κουμπιά πάνω από τα πλαίσια εναλλάσσουν μεταξύ διατάξεων Εισόδου/Εξόδου **δίπλα-δίπλα** και **στοιβαγμένων**. Η επιλογή ισχύει για τη Μετάφραση, την Επανεγγραφή και τον Μετασχηματισμό και αποθηκεύεται σε αυτήν τη συσκευή.
- Το **Enter** ή το **Shift+Enter** εκτελεί την εργασία, ανάλογα με τη **Συμπεριφορά για το ENTER** (βλ. παραπάνω).
- Το **Escape** καθαρίζει το πλαίσιο Εισόδου (ή κλείνει πρώτα ένα ανοιχτό μενού ή παράθυρο διαλόγου).

## Βελτίωση μετάφρασης

Μετά από μια επιτυχή εκτέλεση, εμφανίζονται οι επιλογές **Αναδιατύπωση…** και ένα αναπτυσσόμενο μενού έκδοσης δίπλα στον επιλογέα **Προς:**:

1. **Αναδιατύπωση…** (χωρίς επιλογή) — μια άλλη πλήρης μετάφραση της ίδιας εισόδου. Έως και **πέντε** εκδόσεις. Το μοντέλο βλέπει τις προηγούμενες εκδόσεις, οπότε η διατύπωση μπορεί να διαφέρει. Κάντε κλικ στην επιλογή **Διακοπή μετάφρασης** για να ακυρώσετε μια εν εξελίξει αναδιατύπωση.
2. **Εναλλακτικές λέξεις** — επιλέξτε λέξεις ή μια σύντομη φράση, στη συνέχεια κάντε δεξί κλικ ή επιλέξτε **Αναδιατύπωση…**. Επιλέξτε μια εναλλακτική για να αντικαταστήσετε το τμήμα (μπορεί να διευρυνθεί ελαφρώς για γραμματικούς λόγους). Σε πέντε εκδόσεις, ενημερώνεται μόνο η έκδοση 5.
3. Κάθε αίτημα αναδιατύπωσης ή εναλλακτικών χρησιμοποιεί ξανά το μοντέλο και μπορεί να προσθέσει κόστος.

## Χρήση του γλωσσαρίου

Ένα **γλωσσάρι** είναι ζεύγη όρων πηγής/στόχου για ένα ζεύγος γλωσσών. Όταν είναι ενεργοποιημένο, οι όροι που ταιριάζουν αποστέλλονται στο μοντέλο, ώστε η προτιμώμενη διατύπωση να παραμένει συνεπής.

1. Ενεργοποιήστε το **Γλωσσάρι** στον πίνακα εισόδου.
2. Μεταφράστε ως συνήθως — οι όροι για αυτό το ζεύγος **Από** / **Προς** εφαρμόζονται αυτόματα.
3. Κάντε κλικ στο **Προσθήκη στο Γλωσσάρι** (δίπλα στο **Από:**) για να καταγράψετε γρήγορα ένα νέο ζεύγος.
4. Διαχειριστείτε όλους τους όρους στις [Ρυθμίσεις → Γλωσσάρι](/docs/settings/#glossary).

:::note
Οι όροι του γλωσσαρίου αντιστοιχίζονται ανά ζεύγος γλωσσών. Δεν μπορούν να χρησιμοποιηθούν με την επιλογή **Ανίχνευση γλώσσας** ως πηγή.
:::
