Το Transrewrt δεν περιλαμβάνει δική του AI — στέλνει το κείμενό σας σε έναν πάροχο AI που επιλέγετε. Για να συνδέσετε έναν πάροχο, προσθέτετε ένα **κλειδί API**: έναν ιδιωτικό κωδικό, που εκδίδεται από τον πάροχο, ο οποίος λειτουργεί σαν κωδικός πρόσβασης για την υπηρεσία τους. Χρειάζεστε μόνο **έναν** πάροχο για να ξεκινήσετε, και δεν χρειάζεται να πληρώσετε: αρκετοί πάροχοι προσφέρουν δωρεάν μοντέλα ή δωρεάν επίπεδα, και μπορείτε επίσης να εκτελέσετε μοντέλα στον δικό σας υπολογιστή χωρίς καθόλου κλειδί.

Οι υποστηριζόμενοι πάροχοι περιλαμβάνουν OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, οποιοδήποτε συμβατό τελικό σημείο OpenAI και τοπικούς συμβατούς διακομιστές OpenAI (Ollama, LM Studio, llama.cpp και παρόμοια).

## Βήμα 1 — Επιλέξτε έναν πάροχο

Οποιοσδήποτε υποστηριζόμενος πάροχος λειτουργεί. Εάν δεν είστε σίγουροι ποιον να επιλέξετε:

- **Δωρεάν για αρχή**: Οι OpenRouter, Google Gemini, Groq, Mistral, Cerebras και NVIDIA προσφέρουν όλοι δωρεάν μοντέλα ή δωρεάν επίπεδα.
- **Έχετε ήδη λογαριασμό;** Εάν χρησιμοποιείτε ήδη OpenAI, Anthropic ή άλλον υποστηριζόμενο πάροχο, μπορείτε απλά να επαναχρησιμοποιήσετε αυτόν τον λογαριασμό.
- **Προτιμάτε να κρατήσετε τα πάντα στον δικό σας υπολογιστή;** Παραλείψτε εντελώς το κλειδί και χρησιμοποιήστε ένα [τοπικό μοντέλο](#using-a-local-model-instead-no-api-key) αντ' αυτού.

## Βήμα 2 — Δημιουργήστε ένα κλειδί API

Τα ακριβή βήματα διαφέρουν ελαφρώς ανά πάροχο, αλλά το μοτίβο είναι το ίδιο παντού:

1. Εγγραφείτε ή συνδεθείτε στην ιστοσελίδα του παρόχου. Στις **Ρυθμίσεις → Διαμόρφωση API** του Transrewrt, κάθε πάροχος έχει έναν σύνδεσμο **Άνοιγμα ιστοσελίδας παρόχου** που σας οδηγεί στο σωστό μέρος.
2. Βρείτε τη σελίδα **Κλειδιά API** (μερικές φορές κάτω από τις ρυθμίσεις λογαριασμού, πίνακα ελέγχου ή προγραμματιστή) και δημιουργήστε ένα νέο κλειδί. Ορισμένοι πάροχοι σας ζητούν να ονομάσετε το κλειδί ή να ορίσετε ένα όριο δαπανών — και τα δύο είναι προαιρετικά.
3. Αντιγράψτε το κλειδί. Είναι μια μεγάλη συμβολοσειρά γραμμάτων και αριθμών, που συχνά ξεκινά με κάτι σαν `sk-`.

:::note
Να αντιμετωπίζετε ένα κλειδί API σαν κωδικό πρόσβασης: μην το μοιράζεστε, μην το δημοσιεύετε και μην το στέλνετε σε κανέναν. Εάν ένα κλειδί διαρρεύσει, διαγράψτε το από τον ιστότοπο του παρόχου και δημιουργήστε ένα νέο.
:::

## Βήμα 3 — Προσθήκη και δοκιμή του κλειδιού (επιτραπέζιος υπολογιστής)

1. Στο Transrewrt, ανοίξτε τις **Ρυθμίσεις → Διαμόρφωση API**.
2. Επικολλήστε το κλειδί στο πεδίο για τον πάροχό σας (για παράδειγμα **Κλειδί API Google Gemini**) και αποθηκεύστε το.
3. Κάντε κλικ στο **Δοκιμή** δίπλα στο πεδίο για να επιβεβαιώσετε ότι το κλειδί λειτουργεί.

Μόλις η δοκιμή επιτύχει, είστε έτοιμοι — επιλέξτε αυτόν τον πάροχο στην κύρια οθόνη και ξεκινήστε τη μετάφραση.

## Χρήση τοπικού μοντέλου αντ' αυτού (χωρίς κλειδί API)

Μπορείτε να εκτελέσετε μοντέλα στον δικό σας υπολογιστή με Ollama, LM Studio, llama.cpp ή άλλο συμβατό διακομιστή OpenAI (για παράδειγμα `google/gemma-4-e2b` μέσω LM Studio). Τίποτα δεν φεύγει από το μηχάνημά σας και δεν απαιτείται κλειδί API.

Για να συνδέσετε ένα, ορίστε τη βασική διεύθυνση URL του τοπικού LLM στην πλήρη βάση API, συμπεριλαμβανομένης της διαδρομής — για παράδειγμα `http://localhost:11434/v1`. Στον επιτραπέζιο υπολογιστή, ορίστε αυτό στις **Ρυθμίσεις → Διαμόρφωση API**. Στο Docker, ορίστε αντ' αυτού τη μεταβλητή περιβάλλοντος `LOCAL_LLM_URL`.

:::tip
Εάν χρησιμοποιείτε έναν τοπικό διακομιστή LLM από άλλη συσκευή ή κοντέινερ, ρυθμίστε τον ώστε να επιτρέπει εξωτερικές συνδέσεις (όχι μόνο localhost).
:::

## Docker / web

Εάν χρησιμοποιείτε το Transrewrt σε ένα πρόγραμμα περιήγησης, τα κλειδιά διαχειρίζονται από αυτόν που εκτελεί τον διακομιστή, δεν πληκτρολογούνται στη διεπαφή χρήστη του προγράμματος περιήγησης. Ο διαχειριστής ορίζει τα κλειδιά παρόχου ως **μεταβλητές περιβάλλοντος** στον διακομιστή (για παράδειγμα `PROVIDER_API_KEY`) — δείτε [Διαμόρφωση](/docs/configuration/).

## Λίστα ελέγχου πρώτης εκτέλεσης

1. Ανοίξτε την εφαρμογή και ορίστε τη **Γλώσσα διεπαφής** εάν χρειάζεται.
2. Προσθέστε και δοκιμάστε τουλάχιστον ένα κλειδί παρόχου — ή διαμορφώστε ένα τοπικό μοντέλο (επιτραπέζιος υπολογιστής), ή επιβεβαιώστε ότι ο διακομιστής έχει κλειδιά περιβάλλοντος (διαδίκτυο).
3. Στη λειτουργία **Εύκολη**, επιλέξτε έναν **Πάροχο** στις Γενικές Ρυθμίσεις. Στην **Προηγμένη** λειτουργία, προσθέστε μοντέλα στις **Ρυθμίσεις → Μοντέλα** — δείτε [Ρυθμίσεις](/docs/settings/#general-settings) για τις δύο λειτουργίες.
4. Στην **Μετάφραση**, επιλέξτε μια προεπιλογή ή ένα μοντέλο και εκτελέστε μια σύντομη δοκιμή — δείτε [Μετάφραση κειμένου](/docs/translate/).

## Εάν κάτι δεν λειτουργεί

- **Ο έλεγχος κλειδιού αποτυγχάνει**: βεβαιωθείτε ότι το κλειδί αντιγράφηκε πλήρως (χωρίς κενά πριν ή μετά) και ότι δεν έχει διαγραφεί ή απενεργοποιηθεί στον ιστότοπο του παρόχου.
- **Οι μεταφράσεις αποτυγχάνουν με σφάλμα ορίου ή πίστωσης**: οι δωρεάν βαθμίδες έχουν ημερήσια ή μηνιαία όρια. Περιμένετε, μεταβείτε σε άλλο δωρεάν πάροχο ή προσθέστε πίστωση.
- **Δεν εμφανίζεται πάροχος στην Εύκολη λειτουργία**: ανοίξτε τις **Ρυθμίσεις → Διαμόρφωση API** και επιβεβαιώστε ότι τουλάχιστον ένα κλειδί (ή η διεύθυνση URL του Τοπικού LLM) έχει διαμορφωθεί και δοκιμαστεί.
