Το Transrewrt χρειάζεται πρόσβαση σε τουλάχιστον έναν πάροχο AI. Δεν χρειάζεστε **οπωσδήποτε** ένα επί πληρωμή μοντέλο για να ξεκινήσετε: το OpenRouter προσφέρει δωρεάν μοντέλα αφού προσθέσετε ένα κλειδί, και αρκετοί άλλοι πάροχοι προσφέρουν επίσης δωρεάν επίπεδα.

Οι υποστηριζόμενες υπηρεσίες περιλαμβάνουν [OpenRouter](https://openrouter.ai), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, οποιοδήποτε συμβατό τελικό σημείο OpenAI και τοπικούς συμβατούς με OpenAI εξυπηρετητές (Ollama, LM Studio, llama.cpp, και παρόμοιους).

## Εύκολο vs Προχωρημένο

- **Εύκολο** κατάσταση (προεπιλογή): επιλέξτε ένα **προκαθορισμένο** (Δωρεάν (OpenRouter), Προηγμένο, Προηγμένο, ή Τεχνικό) που αντιστοιχεί σε einen **υπηρεσία παροχέα**. Οι προκαθορισμένες ρυθμίσεις με αντιστοίχηση για τον τρέχοντα παροχέα εμφανίζονται μόνο.
- **Προηγμένο** κατάσταση: επιλέξτε τα μοντέλα απευθείας. Οι αναγνωριστικοί κωδικοί μοντέλων χρησιμοποιούν ένα πρόθεμα παροχέα (για παράδειγμα `openrouter/…`, `openai/…`, `local/…`).

## Δωρεάν κλειδί OpenRouter (επιτραπέζιος υπολογιστής)

1. Μεταβείτε στο [openrouter.ai](https://openrouter.ai) και εγγραφείτε ή συνδεθείτε.
2. Ανοίξτε τη σελίδα [Κλειδιά](https://openrouter.ai/keys) και δημιουργήστε ένα νέο κλειδί (δώστε του ένα όνομα· προαιρετικό όριο πίστωσης). Μπορείτε να χρησιμοποιήσετε δωρεάν μοντέλα χωρίς να προσθέσετε πίστωση.
3. Στο Transrewrt, ανοίξτε τις **Ρυθμίσεις → Διαμόρφωση API**, επικολλήστε το κλειδί στο **Κλειδί API OpenRouter** και κάντε κλικ στο **Δοκιμή κλειδιού OpenRouter**.

:::caution
Μην χρησιμοποιείτε το μοντέλο **Body Builder** του OpenRouter (`openrouter/bodybuilder`) για μετάφραση, αναδιατύπωση ή μετασχηματισμό — επιστρέφει ωφέλιμα φορτία αιτημάτων JSON, όχι ολοκληρωμένο κείμενο.
:::

## Άλλες δωρεάν επιλογές

Μπορείτε επίσης να λάβετε δωρεάν κλειδιά API από την Cerebras, το Google, το Groq, το Mistral AI ή την [NVIDIA](https://build.nvidia.com/) (API συμβατό με το OpenAI) ή να εκτελέσετε μοντέλα τοπικά με το Ollama, το LM Studio, το llama.cpp ή έναν άλλο διακομιστή συμβατό με το OpenAI (για παράδειγμα `translategemma:4b` μέσω Ollama). Ρυθμίστε τη βάση URL του τοπικού LLM στο πλήρες API βάσης (περιλαμβάνοντας τη διαδρομή, π.χ. `http://localhost:11434/v1`) στις Ρυθμίσεις (εγκατάσταση επιφάνειας εργασίας) ή `LOCAL_LLM_URL` (Docker).

:::caution
Εάν χρησιμοποιείτε έναν τοπικό εξυπηρετητή LLM από άλλη συσκευή ή контέινερ, ρυθμίστε τον για να επιτρέπει εξωτερικές συνδέσεις (όχι μόνο localhost).
:::

## Docker / web

Ορίστε τα κλειδιά παρόχου ως **μεταβλητές περιβάλλοντος** στον διακομιστή (για παράδειγμα `PROVIDER_API_KEY`). Οι χρήστες δεν μπορούν να πληκτρολογήσουν κλειδιά στο UI του προγράμματος περιήγησης. Ανατρέξτε στην ενότητα [Διαμόρφωση](/docs/configuration/).

## Λίστα ελέγχου πρώτης εκτέλεσης

1. Ανοίξτε την εφαρμογή και ορίστε τη **Γλώσσα διεπαφής** εάν χρειάζεται.
2. Προσθέστε και δοκιμάστε τουλάχιστον ένα κλειδί παρόχου (desktop) ή επιβεβαιώστε ότι ο διακομιστής έχει κλειδιά περιβάλλοντος (web).
3. Στη λειτουργία **Easy**, επιλέξτε έναν **Πάροχο** στις Γενικές Ρυθμίσεις. Στη λειτουργία **Advanced**, προσθέστε μοντέλα στην ενότητα **Ρυθμίσεις → Μοντέλα**.
4. Στην ενότητα **Μετάφραση**, επιλέξτε μια προεπιλογή ή ένα μοντέλο και εκτελέστε μια σύντομη δοκιμή — δείτε [Μετάφραση κειμένου](/docs/translate/).
