Εάν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα αυτά τα σημεία.

## Η εφαρμογή δεν μεταφράζει, δεν ξαναγράφει ή δεν μετασχηματίζει

Ελέγξτε ότι:

- έχετε επιλέξει μια **προεπιλογή** (Εύκολη) ή ένα **μοντέλο** (Προηγμένη) στη γραμμή εργαλείων
- στην **Εύκολη** λειτουργία, οι **Ρυθμίσεις → Γενικές Ρυθμίσεις** έχουν έναν **Πάροχο** με ένα λειτουργικό κλειδί (ή URL τοπικού LLM)
- στην **Προηγμένη** λειτουργία, τουλάχιστον ένα μοντέλο παρατίθεται στις **Ρυθμίσεις → Μοντέλα**
- η ρύθμιση του API σας λειτουργεί (επιφάνεια εργασίας: **Ρυθμίσεις → Διαμόρφωση API → Δοκιμή**)

## Η λίστα μοντέλων είναι κενή

Στην **Εύκολη** λειτουργία, επιβεβαιώστε ότι ο **Πάροχος** έχει οριστεί και ότι τα κλειδιά/URL έχουν δοκιμαστεί. Για το **Τοπικό LLM**, βεβαιωθείτε ότι ο τοπικός σας διακομιστής εκτελείται και ότι τα μοντέλα έχουν φορτωθεί.

Στην **Προχωρημένη** λειτουργία, ανοίξτε τις **Ρυθμίσεις → Μοντέλα**, κάντε κλικ στην **Ανανέωση** και προσθέστε μοντέλα στα **Επιλεγμένα Μοντέλα**. Προαιρετικά ενεργοποιήστε το **Μόνο δωρεάν**.

## Πολύ αργό ή πολύ ακριβό

- Επιλέξτε διαφορετική προεπιλογή ή μοντέλο
- Χρησιμοποιήστε μικρότερη εισαγωγή
- Απενεργοποιήστε την **Μετάφραση σε πραγματικό χρόνο κατά την πληκτρολόγηση** στις Γενικές Ρυθμίσεις
- Χρησιμοποιήστε δωρεάν μοντέλα για απλές εργασίες

## Λανθασμένη γλώσσα διεπαφής

Κάντε κλικ στο εικονίδιο της υδρογείου στη γραμμή εργαλείων και επιλέξτε τη **Γλώσσα διεπαφής**.

## Το κείμενο είναι πολύ μικρό ή δύσκολο στην ανάγνωση

**Ρυθμίσεις → Γενικές Ρυθμίσεις** → αλλάξτε την **Οικογένεια γραμματοσειράς** και το **Μέγεθος**.

## Η σύνοψη του πίνακα εργαλείων εμφανίζεται κενή

Αυτό είναι φυσιολογικό εάν:

- χρησιμοποιείτε μόνο **δωρεάν μοντέλα** και κοιτάτε τα στοιχεία **κόστους** (μπορεί να είναι μηδέν)· οι δείκτες KPI καταμέτρησης κλήσεων εξακολουθούν να χρειάζονται δεδομένα για την επιλεγμένη περίοδο
- το επιλεγμένο **φίλτρο χρόνου** δεν καλύπτει το πότε έγιναν οι κλήσεις — δοκιμάστε **Όλα**

Εάν οι δείκτες KPI εξακολουθούν να είναι μηδέν μετά το **Όλα**, ελέγξτε το [Ιστορικό](/docs/history/) ή Πίνακας εργαλείων → **Όλες οι κλήσεις**.

## Το κόστος εμφανίζει "μη διαθέσιμο" ή φαίνεται λανθασμένο

Το OpenRouter εμφανίζει την πραγματική δαπάνη όταν ισχύει. Για άλλους παρόχους, το κόστος εκτιμάται από την τιμολόγηση του OpenRouter· εάν δεν υπάρχει αντιστοιχία τιμής, το κόστος εμφανίζεται ως **μη διαθέσιμο** και δεν προστίθεται στο σύνολο.

## Το συνολικό κόστος δεν ταιριάζει με τον λογαριασμό του παρόχου μου

Τα στοιχεία στην εφαρμογή είναι **εκτιμήσεις για αναφορά**, όχι τιμολόγια. Για το OpenRouter, χρησιμοποιήστε **Ρυθμίσεις → Παρακολούθηση κόστους → Συγχρονισμός με χρήση κλειδιού API**.

## Η σελίδα Ιστορικού λείπει από την πλευρική γραμμή

Η επιλογή **Διατήρηση ιστορικού εκτέλεσης** μπορεί να είναι απενεργοποιημένη. Ενεργοποιήστε την στις Γενικές Ρυθμίσεις, εκτός εάν το ιστορικό έχει απενεργοποιηθεί από τον διαχειριστή (`HISTORY_DISABLED` — δείτε [Διαμόρφωση](/docs/configuration/#privacy-mode)).

## Web: ανακατεύθυνση σε σύνδεση απροσδόκητα

Η συνεδρία σας ενδέχεται να έχει λήξει. Συνδεθείτε ξανά. Εάν συμβαίνει συχνά, ελέγξτε τις ρυθμίσεις διάρκειας συνεδρίας διακομιστή.

## Διαχειριστής Web: ξεχάσατε τον κωδικό πρόσβασης

Εάν ένας άλλος διαχειριστής μπορεί να συνδεθεί, μπορεί να επαναφέρει τον κωδικό πρόσβασης στην ενότητα **Ρυθμίσεις → Χρήστες**. Εάν έχετε αποκλειστεί αλλά έχετε πρόσβαση στο κέλυφος:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Το προεπιλεγμένο όνομα χρήστη διαχειριστή είναι `admin`. Από μια εξαγωγή πηγαίου κώδικα: `pnpm run reset-web-password -- <username> <new-password>`.

## Ο πίνακας εργαλείων δεν εμφανίζει δεδομένα για άλλους χρήστες (web)

Μόνο οι **διαχειριστές** μπορούν να δουν άλλους χρήστες μέσω του φίλτρου **Χρήστης**. Οι απλοί χρήστες βλέπουν μόνο τη δική τους δραστηριότητα.

## Άλλαξα μια προτροπή και έχασα τις επεξεργασίες

Κατά την επεξεργασία μιας προτροπής Transform, κάντε κλικ στο κουμπί **Αποθήκευση** πριν από το **Επιστροφή στην εκτέλεση**.

## Γρήγορες συμβουλές

- Ξεκινήστε με τη [Μετάφραση](/docs/translate/) για να επιβεβαιώσετε τη ρύθμισή σας πριν από την Επανεγγραφή ή τον Μετασχηματισμό
- Χρησιμοποιήστε την [Επανεγγραφή](/docs/rewrite/) για καθημερινές βελτιώσεις διατύπωσης
- Χρησιμοποιήστε τον [Μετασχηματισμό](/docs/transform/) για επαναλαμβανόμενες προσαρμοσμένες ροές εργασίας
- Παραμείνετε στη λειτουργία **Εύκολη** μέχρι να χρειαστείτε λεπτομερή αναγνωριστικά μοντέλων
- Εξάγετε τα μηνύματα τακτικά εάν δημιουργείτε μια βιβλιοθήκη μηνυμάτων
- Χρησιμοποιήστε τον [Πίνακα εργαλείων](/docs/dashboard/) και το [Ιστορικό](/docs/history/) για να ελέγξετε τη χρήση και τις προηγούμενες εκτελέσεις
