Εάν κάτι δεν λειτουργεί όπως αναμένεται, ελέγξτε πρώτα αυτά τα σημεία.

## Η εφαρμογή δεν μεταφράζει, δεν αναδιατυπώνει ή δεν μετασχηματίζει

Ελέγξτε ότι:

- έχετε επιλέξει μια **προεπιλογή** (Εύκολη) ή ένα **μοντέλο** (Προηγμένη) στη γραμμή εργαλείων
- στην **Εύκολη** λειτουργία, οι **Ρυθμίσεις → Γενικές Ρυθμίσεις** έχουν έναν **Πάροχο** με ένα λειτουργικό κλειδί (ή URL τοπικού LLM)
- στην **Προηγμένη** λειτουργία, ένα μοντέλο είναι επιλεγμένο στη γραμμή εργαλείων (επιτρέπεται μια κενή λίστα, αλλά χρειάζεστε τουλάχιστον ένα μοντέλο στις **Ρυθμίσεις → Μοντέλα** για να εκτελεστεί)
- η ρύθμιση του API σας λειτουργεί (επιφάνεια εργασίας: **Ρυθμίσεις → Διαμόρφωση API → Δοκιμή**)

## Η λίστα μοντέλων είναι κενή

Στην **Εύκολη** λειτουργία, επιβεβαιώστε ότι ο **Πάροχος** έχει οριστεί και ότι τα κλειδιά/URL έχουν δοκιμαστεί. Για το **Τοπικό LLM**, βεβαιωθείτε ότι ο τοπικός σας διακομιστής εκτελείται και ότι τα μοντέλα έχουν φορτωθεί.

Στην **Προηγμένη** λειτουργία, τα επιλεγμένα μοντέλα ενδέχεται να είναι κενά. Ανοίξτε τις **Ρυθμίσεις → Μοντέλα**, κάντε κλικ στην **Ανανέωση** και προσθέστε μοντέλα στα **Επιλεγμένα Μοντέλα**. Προαιρετικά, ενεργοποιήστε το **Μόνο Δωρεάν**. Η αφαίρεση του τελευταίου μοντέλου της γραμμής εργαλείων ανοίγει επίσης τις Ρυθμίσεις → Μοντέλα.

## Πολύ αργό ή πολύ ακριβό

- Επιλέξτε διαφορετική προεπιλογή ή μοντέλο
- Χρησιμοποιήστε μικρότερη εισαγωγή
- Απενεργοποιήστε την **Μετάφραση σε πραγματικό χρόνο κατά την πληκτρολόγηση** στις Γενικές Ρυθμίσεις
- Χρησιμοποιήστε δωρεάν μοντέλα για απλές εργασίες

## Λανθασμένη γλώσσα διεπαφής

Κάντε κλικ στο εικονίδιο της υδρογείου στη γραμμή εργαλείων και επιλέξτε τη **Γλώσσα διεπαφής**.

## Το κείμενο είναι πολύ μικρό ή δυσανάγνωστο

**Ρυθμίσεις → Γενικές Ρυθμίσεις** → αλλάξτε **Οικογένεια Γραμματοσειράς** και **Μέγεθος**.

## Η Σύνοψη Πίνακα Ελέγχου φαίνεται κενή

Αυτό είναι φυσιολογικό εάν:

- χρησιμοποιείτε μόνο **δωρεάν μοντέλα** και κοιτάτε τα στοιχεία **κόστους** (μπορεί να είναι μηδέν)· οι δείκτες απόδοσης κλήσεων εξακολουθούν να χρειάζονται δεδομένα για την επιλεγμένη περίοδο
- το επιλεγμένο **φίλτρο χρόνου** δεν καλύπτει το πότε έγιναν οι κλήσεις — δοκιμάστε **Όλα**

Εάν οι δείκτες απόδοσης εξακολουθούν να είναι μηδέν μετά το **Όλα**, ελέγξτε το [Ιστορικό](/docs/history/) ή τον Πίνακα Ελέγχου → **Όλες οι Κλήσεις**.

## Το κόστος εμφανίζει "μη διαθέσιμο" ή φαίνεται λανθασμένο

Το OpenRouter εμφανίζει το πραγματικό κόστος όπου ισχύει. Για άλλους παρόχους, το κόστος εκτιμάται από την τιμολόγηση του OpenRouter. Εάν δεν υπάρχει αντιστοιχία τιμής, το κόστος εμφανίζεται ως **μη διαθέσιμο** και δεν προστίθεται στο σύνολο.

## Το συνολικό κόστος δεν αντιστοιχεί στον λογαριασμό του παρόχου μου

Τα στοιχεία στην εφαρμογή είναι **εκτιμήσεις για αναφορά**, όχι τιμολόγια. Για το OpenRouter, χρησιμοποιήστε **Ρυθμίσεις → Παρακολούθηση κόστους → Συγχρονισμός με χρήση κλειδιού API**.

## Η σελίδα Ιστορικού λείπει από την πλαϊνή γραμμή

Η επιλογή **Διατήρηση ιστορικού εκτέλεσης** ενδέχεται να είναι απενεργοποιημένη. Ενεργοποιήστε την στις Γενικές Ρυθμίσεις, εκτός εάν το ιστορικό έχει απενεργοποιηθεί από τον διαχειριστή (`HISTORY_DISABLED` — δείτε [Διαμόρφωση](/docs/configuration/#privacy-mode)).

## Web: ανακατεύθυνση σε σύνδεση απροσδόκητα

Η συνεδρία σας ενδέχεται να έχει λήξει. Συνδεθείτε ξανά. Εάν συμβαίνει συχνά, ζητήστε από έναν διαχειριστή να αυξήσει το **Χρονικό όριο συνεδρίας** στις [Ρυθμίσεις → Χρήστες](/docs/settings/#users) (ένας διαχειριστής μπορεί επίσης να έχει ανακαλέσει τις συνεδρίες σας).

## Διαχειριστής Web: ξέχασα τον κωδικό πρόσβασης

Εάν ένας άλλος διαχειριστής μπορεί να συνδεθεί, μπορεί να επαναφέρει τον κωδικό πρόσβασης στις **Ρυθμίσεις → Χρήστες**. Εάν έχετε αποκλειστεί αλλά έχετε πρόσβαση στο κέλυφος:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Το προεπιλεγμένο όνομα χρήστη διαχειριστή είναι `admin`. Από μια εξαγωγή πηγαίου κώδικα: `pnpm run reset-web-password -- <username> <new-password>`.

## Ο πίνακας εργαλείων δεν εμφανίζει δεδομένα για άλλους χρήστες (web)

Μόνο οι **διαχειριστές** μπορούν να δουν άλλους χρήστες μέσω του φίλτρου **Χρήστης**. Οι κανονικοί χρήστες βλέπουν μόνο τη δική τους δραστηριότητα.

## Άλλαξα μια προτροπή και έχασα τις επεξεργασίες

Κατά την επεξεργασία μιας προτροπής Μετασχηματισμού, κάντε κλικ στο **Αποθήκευση** πριν από το **Επιστροφή στην εκτέλεση**.

## Γρήγορες συμβουλές

- Ξεκινήστε με το [Μετάφραση](/docs/translate/) για να επιβεβαιώσετε τη ρύθμισή σας πριν από την Επανεγγραφή ή τον Μετασχηματισμό
- Χρησιμοποιήστε το [Επανεγγραφή](/docs/rewrite/) για καθημερινές βελτιώσεις διατύπωσης
- Χρησιμοποιήστε το [Μετασχηματισμός](/docs/transform/) για επαναλαμβανόμενες προσαρμοσμένες ροές εργασίας
- Παραμείνετε σε λειτουργία **Εύκολη** μέχρι να χρειαστείτε λεπτομερή αναγνωριστικά μοντέλων
- Εξάγετε προτροπές τακτικά εάν δημιουργείτε μια βιβλιοθήκη προτροπών
- Χρησιμοποιήστε το [Πίνακας εργαλείων](/docs/dashboard/) και το [Ιστορικό](/docs/history/) για να ελέγξετε τη χρήση και τις προηγούμενες εκτελέσεις
