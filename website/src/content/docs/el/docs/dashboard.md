Χρησιμοποιήστε τον **Πίνακα Ελέγχου** για να δείτε πόσο χρησιμοποιείτε την εφαρμογή και πόσο κοστίζει (για μοντέλα επί πληρωμή).

![Σύνοψη Πίνακα Ελέγχου](/images/screenshots/el/dashboard-summary.png)

:::note
Εάν χρησιμοποιείτε μόνο **δωρεάν** μοντέλα, τα ποσά κόστους ενδέχεται να είναι μηδενικά. Τα KPI καταμέτρησης κλήσεων στην **Σύνοψη** εξακολουθούν να χρειάζονται δραστηριότητα στην επιλεγμένη περίοδο.
:::

## Φιλτράρισμα των δεδομένων

Χρησιμοποιήστε τα κουμπιά φίλτρου στην κορυφή για να αλλάξετε το χρονικό εύρος.

:::note
Το φίλτρο **Χρήστης** είναι ορατό μόνο στους διαχειριστές στην έκδοση web. Δεν είναι διαθέσιμο στην επιφάνεια εργασίας.
:::

## Καρτέλες

- **Σύνοψη** — KPI: συνολικό κόστος, μοντέλα που χρησιμοποιήθηκαν, καταμέτρηση κλήσεων ανά λειτουργία και κόστος, μέσο κόστος ανά κλήση, μέσος όρος TPS, κορυφαία μοντέλα ανά καταμέτρηση κλήσεων
- **Ανά Μοντέλο** — κλήσεις ανά μοντέλο, κόστος και TPS· αναπτύξτε μια γραμμή για ανάλυση λειτουργίας
- **Όλες οι Κλήσεις** — πλήρες αρχείο καταγραφής κλήσεων (σελιδωτό ή κάρτες) με εξαγωγή

## Εξαγωγή δεδομένων

Εξαγωγή πινάκων ως **JSON**, **CSV** ή **XLSX**.

## Διαγραφή αποθηκευμένων εγγραφών για ένα μοντέλο

Στο **Ανά Μοντέλο** ή **Όλες οι Κλήσεις**, χρησιμοποιήστε το εικονίδιο του κάδου απορριμμάτων για να αφαιρέσετε εγγραφές για ένα μοντέλο.

:::caution
Η διαγραφή δεν μπορεί να αναιρεθεί. Για να διαγράψετε ανά ηλικία ή να διαγράψετε όλα τα δεδομένα κόστους, χρησιμοποιήστε τις [Ρυθμίσεις → Παρακολούθηση Κόστους](/docs/settings/#cost-tracking).
:::
