Το **Transrewrt** είναι ένα εργαλείο κειμένου με τεχνητή νοημοσύνη ανοιχτού κώδικα για:

- **Μετάφραση** — μεταξύ δεκάδων γλωσσών, με αυτόματη ανίχνευση πηγής και γλωσσάρια
- **Επανεγγραφή** — διόρθωση γραμματικής, βελτίωση σαφήνειας, αλλαγή τόνου ή μήκους
- **Μετασχηματισμός** — εκτελέστε τις δικές σας προσαρμοσμένες προτροπές AI σε οποιοδήποτε κείμενο

Υποστηρίζει πολλούς παρόχους τεχνητής νοημοσύνης (OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, τελικά σημεία συμβατά με το OpenAI και τοπικούς διακομιστές συμβατούς με το OpenAI, όπως Ollama, LM Studio ή llama.cpp). Εκτελέστε το ως **εφαρμογή υπολογιστή** (Windows / Linux) ή ως **εφαρμογή ιστού Docker**.

Τα κλειδιά σας, τα μοντέλα σας, ο οικοδεσπότης σας — δεν υπάρχει λογαριασμός cloud Transrewrt.

## Πώς είναι οργανωμένο το παράθυρο

![Χώρος εργασίας μετάφρασης](/images/screenshots/el/translate.png)

- **Πλευρική γραμμή** — η κύρια πλοήγηση: Μετάφραση, Επανεγγραφή, Μετασχηματισμός, Πίνακας ελέγχου, Ιστορικό, Ρυθμίσεις (και ο συνδεδεμένος χρήστης στον ιστό).
- **Γραμμή εργαλείων** — ο τίτλος της σελίδας, ο επιλογέας **προεπιλογής** (Εύκολο) ή **μοντέλου** (Για προχωρημένους), η **Γλώσσα διεπαφής** (εικονίδιο υδρόγειος· δεν αλλάζει το Μετάφραση Από/Προς) και η Βοήθεια (**?**) που συνδέεται με αυτά τα έγγραφα. Το μενού προεπιλογής/μοντέλου μπορεί επίσης να **Αλλάξει σε λειτουργία Εύκολη/Για προχωρημένους** (πάνω από το Άνοιγμα ρυθμίσεων).
- **Περιοχή εργασίας** — οι πίνακες Εισόδου και Εξόδου, με μετρήσεις, χρονισμό, TPS και προαιρετικό κόστος. Η γραμμή ενεργειών εμφανίζει έναν μικρό σύνδεσμο **έκδοσης** εφαρμογής (κάτω δεξιά) στον ιστότοπο GitHub Pages.

Από προεπιλογή, η εφαρμογή εκτελείται σε λειτουργία **Εύκολο**: επιλέξτε μια **προεπιλογή** και έναν **Πάροχο** στις Ρυθμίσεις. Μεταβείτε σε **Προχωρημένο** στις [Ρυθμίσεις → Γενικές Ρυθμίσεις](/docs/settings/#general-settings) για μια πλήρη λίστα μοντέλων ή χρησιμοποιήστε τον διακόπτη στο μενού προεπιλογής/μοντέλου της γραμμής εργαλείων.
