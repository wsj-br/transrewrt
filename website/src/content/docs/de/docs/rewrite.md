Verwenden Sie **Umschreiben**, um die Formulierung zu verbessern, ohne die Hauptbedeutung zu ändern. Der Text bleibt in derselben Sprache.

![Arbeitsbereich „Umschreiben“](/images/screenshots/de/rewrite.png)

Modi umfassen:

- **Rechtschreibung & Grammatik prüfen**
- **Klarheit verbessern**
- **Alternative Versionen** (mehrere Umformulierungen in einem Durchgang)
- **Formalisieren** / **Informalisieren**
- **Kürzen** / **Erweitern**
- **Technisch formulieren**

## Text umschreiben

1. Öffnen Sie **Umschreiben**.
2. Wählen Sie einen **Modus**.
3. Optional stellen Sie **Von** auf die Sprache Ihres Textes ein (oder lassen Sie **Sprache erkennen**).
4. Geben Sie Text in **Eingabe** ein oder fügen Sie ihn dort ein.
5. Klicken Sie auf **Umschreiben**.
6. Lesen Sie das Ergebnis in **Ausgabe**.

Die [Layout-Umschaltung und Tastenkombinationen](/docs/translate/#layout-and-keyboard) funktionieren genauso wie bei der Übersetzung.

:::tip
Nach einer Umschreibung erscheint ein Schalter **Änderungen anzeigen** (**Änderungen**) neben **Kopieren** für **jeden** Umschreibungsmodus. Schalten Sie ihn um, um einen Unterschied zwischen Eingabe und Ausgabe anzuzeigen oder auszublenden.
:::

:::note
**Alternative Versionen** liefert mehrere Umformulierungen in einem **einzigen** Durchgang, getrennt durch `----`. Das unterscheidet sich von **Neu formulieren…**, das eine Versionshistorie über die Zeit aufbaut.
:::

## Eine Umschreibung verfeinern

Nach einem erfolgreichen Durchlauf erscheinen **Neu formulieren…** und das Versions-Dropdown auf der Ausgabeseite (gleiches Prinzip wie bei der [Übersetzung](/docs/translate/#refine-a-translation), aber der Text bleibt in derselben Sprache und behält den aktuellen **Modus** bei):

1. **Neu formulieren…** (keine Auswahl) – eine weitere vollständige Umschreibung mit anderer Formulierung. Bis zu fünf Versionen. Klicken Sie auf **Umschreiben stoppen**, um abzubrechen.
2. **Wortalternativen** – Text auswählen, dann Rechtsklick oder **Neu formulieren…**.
3. Jede Anfrage kann Nutzungskosten verursachen.
