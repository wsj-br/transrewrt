Verwenden Sie **Umschreiben**, um die Formulierung zu verbessern, ohne die Hauptbedeutung zu ändern. Der Text bleibt in derselben Sprache.

![Arbeitsbereich „Umschreiben“](/images/screenshots/de/rewrite.png)

Modi umfassen:

- **Rechtschreibung & Grammatik prüfen**
- **Klarheit verbessern**
- **Alternative Versionen** (mehrere Umformulierungen in einem Durchlauf)
- **Formalisieren** / **Informalisieren**
- **Kürzen** / **Erweitern**
- **Technisch formulieren**

## Text umschreiben

1. Öffnen Sie **Umschreiben**.
2. Wählen Sie einen **Modus**.
3. Optional stellen Sie **Von** auf die Sprache Ihres Textes ein (oder lassen Sie **Sprache erkennen**).
4. Geben Sie Text in das Feld **Eingabe** ein oder fügen Sie ihn dort ein.
5. Klicken Sie auf **Umschreiben**.
6. Lesen Sie das Ergebnis in **Ausgabe**.

:::tip
Unter **Rechtschreibung & Grammatik prüfen** erscheint neben **Kopieren** ein Schalter **Änderungen anzeigen**. Schalten Sie ihn um, um Korrekturen anzuzeigen oder auszublenden.
:::

:::note
**Alternative Versionen** liefert mehrere Umformulierungen in einem **einzigen** Durchlauf, getrennt durch `----`. Das unterscheidet sich von **Neu formulieren…**, das im Laufe der Zeit einen Versionsverlauf erstellt.
:::

## Eine Umformulierung verfeinern

Nach einem erfolgreichen Durchlauf erscheinen **Neu formulieren…** und das Versions-Dropdown auf der Ausgabeseite (ähnlich wie bei [Übersetzen](/docs/translate/#refine-a-translation), aber der Text bleibt in derselben Sprache und behält den aktuellen **Modus** bei):

1. **Neu formulieren…** (keine Auswahl) – eine weitere vollständige Umformulierung mit anderer Formulierung. Bis zu fünf Versionen. Klicken Sie auf **Umschreiben beenden**, um abzubrechen.
2. **Wortalternativen** – Text auswählen, dann Rechtsklick oder **Neu formulieren…**.
3. Jede Anfrage kann Nutzungskosten verursachen.
