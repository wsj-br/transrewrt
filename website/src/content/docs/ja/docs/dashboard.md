**Dashboard**を使用して、アプリの使用量とコスト（有料モデルの場合）を確認します。

![ダッシュボードの概要](/images/screenshots/ja/dashboard-summary.png)

:::note
**free**モデルのみを使用している場合、コストはゼロになる場合があります。**Summary**の呼び出し回数KPIには、選択した期間内のアクティビティが必要です。
:::

## データをフィルタリングする

上部のフィルタボタンを使用して、時間範囲を変更します。

:::note
**User**フィルタは、Web版の管理者にのみ表示されます。デスクトップ版では利用できません。
:::

## タブ

- **Summary** — KPI: 合計コスト、使用されたモデル、モードごとの呼び出し回数とコスト、1回あたりの平均コスト、平均TPS、呼び出し回数別の上位モデル
- **By Model** — モデルごとの呼び出し、コスト、TPS。行を展開するとモードの内訳が表示されます
- **All Calls** — エクスポート付きの完全な呼び出しログ（ページネーションまたはカード）

## データをエクスポートする

テーブルを**JSON**、**CSV**、または**XLSX**としてエクスポートします。

## モデルの保存されたレコードを削除する

**By Model**または**All Calls**で、ゴミ箱アイコンを使用してモデルのレコードを削除します。

:::caution
削除は元に戻せません。経過時間で削除する場合や、すべてのコストデータを消去するには、[設定 → コストトラッキング](/docs/settings/#cost-tracking)を使用します。
:::
