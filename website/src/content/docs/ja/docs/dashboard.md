アプリの使用量とコスト（有料モデルの場合）を確認するには、**ダッシュボード**を使用します。

![ダッシュボードの概要](/images/screenshots/ja/dashboard-summary.png)

:::note
**無料**モデルのみを使用している場合、コストはゼロになることがあります。**概要**の呼び出し回数KPIには、選択した期間内のアクティビティが必要です。
:::

## データをフィルタリングする

上部のフィルタボタンを使用して時間範囲を変更します。

:::note
**ユーザー**フィルタは、Web版の管理者にのみ表示されます。デスクトップ版では利用できません。
:::

## タブ

- **概要** — KPI: 総コスト、使用されたモデル、モードごとの呼び出し回数とコスト、呼び出しあたりの平均コスト、平均TPS、呼び出し回数による上位モデル
- **モデルごと** — モデルごとの呼び出し、コスト、TPS。行を展開するとモードの内訳が表示されます
- **すべての呼び出し** — エクスポート付きの完全な呼び出しログ（ページネーションまたはカード）

## データをエクスポートする

テーブルを**JSON**、**CSV**、または**XLSX**としてエクスポートします。

## モデルの保存されたレコードを削除する

**モデルごと**または**すべての呼び出し**で、ゴミ箱アイコンを使用してモデルのレコードを削除します。

:::caution
削除は元に戻せません。期間を指定して削除するか、すべてのコストデータを消去するには、[設定 → コストトラッキング](/docs/settings/#cost-tracking)を使用します。
:::
