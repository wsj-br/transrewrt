期待通りに動作しない場合は、まずこれらのポイントを確認してください。

## アプリが翻訳、リライト、または変換しない

以下を確認してください：

- ツールバーで**プリセット**（Easy）または**モデル**（Advanced）を選択していること
- **Easy**モードで、**設定 → 一般設定**の**プロバイダー**に有効なキー（またはローカルLLM URL）があること
- **Advanced**モードで、**設定 → モデル**に少なくとも1つのモデルがリストされていること
- APIのセットアップが機能していること（デスクトップ版: **設定 → API設定 → テスト**）

## モデルリストが空である

**Easy**モードでは、**プロバイダー**が設定され、キー/URLがテスト済みであることを確認してください。**ローカルLLM**の場合は、ローカルサーバーが実行されており、モデルが読み込まれていることを確認してください。

**Advanced**モードでは、**Settings → Models**を開き、**Refresh**をクリックして、モデルを**Selected Models**に追加します。必要に応じて**Free Only**をオンにします。

## 遅すぎる、またはコストが高すぎる

- 別のプリセットまたはモデルを選択する
- より短い入力を使用する
- General Settingsで**入力中のリアルタイム翻訳**をオフにする
- 単純なタスクには無料モデルを使用する

## インターフェースの言語が間違っている

ツールバーの地球アイコンをクリックし、**インターフェース言語**を選択してください。

## テキストが小さすぎる、または読みにくい

**Settings → General Settings** → **Font Family**と**Size**を変更します。

## ダッシュボードの概要が空に見える

以下の場合は正常です：

- **無料モデル**のみを使用しており、**コスト**の数値を確認している場合（ゼロになる場合があります）。呼び出し回数のKPIには、選択した期間のデータがまだ必要です
- 選択した**時間フィルター**が呼び出しが行われた期間をカバーしていない場合 — **すべて**を試してください

**すべて**を選択してもKPIがゼロのままである場合は、[履歴](/docs/history/)またはダッシュボード → **すべての呼び出し**を確認してください。

## コストが「利用不可」と表示される、または間違っているように見える

OpenRouterは、該当する場合に実際の消費額を表示します。他のプロバイダの場合、コストはOpenRouterの価格から推定されます。一致する価格がない場合、コストは**利用不可**として表示され、合計には加算されません。

## 合計コストがプロバイダの請求書と一致しない

アプリ内の数値は**参考用の推定値**であり、請求書ではありません。OpenRouterの場合は、**設定 → コスト追跡 → APIキーの使用量と同期**を使用してください。

## サイドバーに履歴ページがない

**実行履歴を保持**がオフになっている可能性があります。管理者によって履歴が無効化されていない限り（`HISTORY_DISABLED` — [設定](/docs/configuration/#privacy-mode)を参照）、一般設定で有効にしてください。

## Web版：予期せずログイン画面にリダイレクトされる

セッションがタイムアウトした可能性があります。再度ログインしてください。頻繁に発生する場合は、サーバーのセッション有効期間設定を確認してください。

## Web管理者：パスワードを忘れた

別の管理者がサインインできる場合、**Settings → Users**でパスワードをリセットできます。ロックアウトされているがシェルアクセスがある場合:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

デフォルトの管理者ユーザー名は`admin`です。ソースのチェックアウトからの場合：`pnpm run reset-web-password -- <username> <new-password>`。

## ダッシュボードに他のユーザーのデータが表示されない（ウェブ）

**管理者**のみが**ユーザー**フィルターを介して他のユーザーを表示できます。一般ユーザーは自分のアクティビティのみを表示できます。

## プロンプトを変更して編集内容が失われた

Transformプロンプトを編集する際、**Back to Run**をクリックする前に**Save**をクリックしてください。

## クイックヒント

- [Translate](/docs/translate/)から始めて、RewriteまたはTransformの前にセットアップを確認してください
- 日常的な表現の改善には[Rewrite](/docs/rewrite/)を使用してください
- 繰り返し可能なカスタムワークフローには[Transform](/docs/transform/)を使用してください
- 細かなモデルIDが必要になるまで、**Easy**モードを使用してください
- プロンプトライブラリを構築している場合は、定期的にプロンプトをエクスポートしてください
- [ダッシュボード](/docs/dashboard/)と[履歴](/docs/history/)を使用して、使用量と過去の実行を確認してください

[Report an issue](https://github.com/wsj-br/transrewrt/issues)
