期待通りに動作しない場合は、まず以下の点を確認してください。

## アプリが翻訳、書き換え、変換を行わない

以下の点を確認してください：

- ツールバーで**プリセット**（Easy）または**モデル**（Advanced）を選択していること
- **Easy**モードでは、**設定 → 一般設定**の**プロバイダー**に有効なキー（またはローカルLLMのURL）が設定されていること
- **Advanced**モードでは、ツールバーでモデルが選択されていること（空のリストも許可されますが、実行するには**設定 → モデル**に少なくとも1つのモデルが必要です）
- APIのセットアップが機能していること（デスクトップ版: **設定 → API 設定 → テスト**）

## モデルリストが空です

**Easy**モードでは、**プロバイダー**が設定され、キー/URLがテスト済みであることを確認してください。**ローカルLLM**の場合は、ローカルサーバーが実行中で、モデルが読み込まれていることを確認してください。

**詳細**モードでは、選択されたモデルが空になる場合があります。**設定 → モデル**を開き、**更新**をクリックして、使用したいモデルにチェックを入れます（または**プリセットから選択**を使用します）。必要に応じて**無料のみ**をオンにします。ツールバーの最後のモデルを削除すると、設定 → モデルも開きます。

## 速度が遅い、またはコストが高い

- 別のプリセットまたはモデルを選択してください
- 入力テキストを短くしてください
- General Settingsで**Real-time translation while typing**をオフにしてください
- 単純なタスクには無料モデルを使用してください

## インターフェイス言語が正しくない

ツールバーの地球アイコンをクリックし、**インターフェイス言語**を選択してください。

## テキストが小さすぎる、または読みにくい

**設定 → 一般設定** → **フォントファミリー**と**サイズ**を変更します。

## ダッシュボードサマリーが空に見える

これは正常な場合があり、以下の条件に該当します：

- **free models**のみを使用していて、**cost**の数値を見ている場合（ゼロの場合があります）；コール数のKPIは選択期間のデータが必要です
- 選択した**time filter**が通話の作成時期をカバーしていない — **All**を試してください

**すべて**を選択してもKPIがゼロのままの場合は、[履歴](/docs/history/)またはダッシュボード → **すべての通話**を確認してください。

## コストに「利用不可」と表示される、または正しくない

OpenRouterとxAIは、APIが実際の支出を返すときにそれを表示します。他のプロバイダについては、コストは[models.dev](https://models.dev/)の価格設定から推定されます。価格が一致しない場合、コストは**利用不可**と表示され、合計には加算されません。

## 合計コストがプロバイダーの請求と一致しない

アプリ内の数値は**参考用の見積もり**であり、請求書ではありません。OpenRouterの場合は、**設定 → コスト追跡 → APIキー使用量と同期**を使用してください。

## サイドバーに履歴ページが表示されない

**実行履歴を保持**がオフになっている可能性があります。履歴が管理者によって無効化されていない限り、一般設定で有効にしてください（`HISTORY_DISABLED` — [構成](/docs/configuration/#privacy-mode)を参照）。

## Web: 予期せずログイン画面にリダイレクトされる

セッションがタイムアウトした可能性があります。再度ログインしてください。頻繁に発生する場合は、管理者に[設定 → ユーザー](/docs/settings/#users)の**セッションタイムアウト**の延長を依頼してください（管理者がセッションを取り消した可能性もあります）。

## Web管理者: パスワードを忘れた

別の管理者がサインインできる場合、**Settings → Users**でパスワードをリセットできます。ロックアウトされているがシェルアクセスがある場合:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

デフォルトの管理者ユーザー名は`admin`です。ソースチェックアウトから: `pnpm run reset-web-password -- <username> <new-password>`。

## ダッシュボードで他のユーザーにデータなしと表示される（web）

**administrators**のみが**User**フィルターを通じて他のユーザーを表示できます。一般ユーザーは自身のアクティビティのみを確認できます。

## プロンプトを変更して編集内容が失われた

変換プロンプトを編集する際、**実行に戻る**の前に**保存**をクリックしてください。

## クイックヒント

- RewriteやTransformの前に[Translate](/docs/translate/)で設定を確認してください
- 日常的な表現の改善には[Rewrite](/docs/rewrite/)を使用してください
- 繰り返し可能なカスタムワークフローには[Transform](/docs/transform/)を使用してください
- 細かなモデルIDが必要になるまで**Easy**モードを使用してください
- プロンプトライブラリを構築している場合は、定期的にプロンプトをエクスポートしてください
- 使用状況と過去の実行を確認するには[Dashboard](/docs/dashboard/)と[History](/docs/history/)を使用してください

[問題を報告](https://github.com/wsj-br/transrewrt/issues)
