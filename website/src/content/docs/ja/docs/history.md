title: 履歴の参照
description: 過去の翻訳、書き換え、変換の実行を、入力テキストと出力テキストを含めて確認します。
---



**履歴**を開くと、各実行の入力と出力を含む過去の操作を確認できます。

![履歴ページ](/images/screenshots/ja/history.png)

履歴は[ダッシュボード](/docs/dashboard/)と同じ時間範囲フィルターを使用します。

:::note
**Webアプリ**では、すべてのユーザー（管理者を含む）が自分自身の実行履歴のみを表示できます。ダッシュボードの**ユーザー**フィルターはここでは適用されません。
:::

## エクスポート

フィルター済みリストを**JSON**、**CSV**、または**XLSX**としてエクスポートします。

## 履歴が見つからない場合

**実行履歴を保持**がオフになっている可能性があります。管理者が`HISTORY_DISABLED`を設定していない限り、[設定 → 一般設定](/docs/settings/#general-settings)で有効にしてください — [設定](/docs/configuration/#privacy-mode)を参照してください。
