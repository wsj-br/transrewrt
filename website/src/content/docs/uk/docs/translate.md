Використовуйте **Перекласти**, щоб перетворити текст з однієї мови на іншу.

![Робоча область перекладу](/images/screenshots/uk/translate.png)

## Передумови

- Принаймні один ключ провайдера (для десктопу) або ключ середовища сервера (для вебу) — див. [Ключ API](/docs/api-key/)
- **Набір параметрів** (простий) або **модель** (розширений) вибрано на панелі інструментів

## Перекласти текст

1. Відкрийте **Перекласти** на бічній панелі.
2. Виберіть мову в полі **З** (або **Визначити мову**).
3. Виберіть мову в полі **На**.
4. Виберіть набір параметрів або модель на панелі інструментів.
5. Введіть або вставте текст у поле **Введення**.
6. Натисніть **Перекласти**.
7. Прочитайте результат у полі **Виведення**, потім скопіюйте, якщо потрібно.

**Найпопулярніші мови** відображаються першими у списках — налаштуйте їх у [Налаштування → Мови](/docs/settings/#languages).

## Корисні налаштування

У [Налаштування → Загальні налаштування](/docs/settings/#general-settings):

- **Автоматичне виконання при вставці** — запускається одразу після вставки
- **Автоматичне копіювання результату в буфер обміну** — копіює після успішного виконання
- **Переклад у реальному часі під час набору тексту** — запускається під час набору тексту (може збільшити вартість)
- **Таймаут (мс)** — час очікування перед запуском у реальному часі
- **Поведінка для ENTER** — чи запускає Enter завдання, чи вставляє новий рядок

## Макет та клавіатура

- **Перемикач макета** — кнопки над панелями перемикають між **розташованими поруч** та **складеними** макетами введення/виведення. Вибір застосовується до функцій «Перекласти», «Переписати» та «Трансформувати» і запам'ятовується на цьому пристрої.
- **Enter** або **Shift+Enter** запускає завдання, залежно від **Поведінки для ENTER** (див. вище).
- **Escape** очищає панель введення (або спочатку закриває відкрите меню чи діалогове вікно).

## Уточнити переклад

Після успішного виконання поруч із селектором **На:** з'являються **Перефразувати…** та спадне меню версій:

1. **Перефразувати…** (без вибору) — ще один повний переклад того ж вхідного тексту. До **п'яти** версій; модель бачить попередні версії, тому формулювання може відрізнятися. Натисніть **Зупинити переклад**, щоб скасувати поточне перефразування.
2. **Альтернативи слів** — виберіть слова або коротку фразу, потім клацніть правою кнопкою миші або **Перефразувати…**. Виберіть альтернативу для заміни фрагмента (може трохи розширитися для граматики). Для п'яти версій оновлюється лише версія 5.
3. Кожен запит на перефразування або альтернативи використовує модель знову і може збільшити вартість.

## Використання глосарію

**Глосарій** — це пари термінів джерело/ціль для мовної пари. Коли він увімкнений, відповідні терміни надсилаються моделі, щоб бажане формулювання залишалося послідовним.

1. Увімкніть **Глосарій** на панелі введення.
2. Перекладайте як зазвичай — терміни для цієї пари **З** / **На** застосовуються автоматично.
3. Натисніть **Додати до глосарію** (поруч із **З:**), щоб швидко додати нову пару.
4. Керуйте всіма термінами в [Налаштування → Глосарій](/docs/settings/#glossary).

:::note
Терміни глосарію зіставляються за мовною парою. Їх не можна використовувати з функцією **Визначити мову** як джерело.
:::
