Якщо щось працює не так, як очікувалося, спочатку перевірте ці пункти.

## Додаток не перекладає, не переписує та не трансформує

Перевірте, що:

- ви вибрали **попередньо встановлену конфігурацію** (Easy) або **модель** (Advanced) на панелі інструментів
- у режимі **Easy** в розділі **Settings → General Settings** є **Provider** з робочим ключем (або URL-адресою локальної LLM)
- у режимі **Advanced** принаймні одна модель вказана в розділі **Settings → Models**
- ваша конфігурація API працює (для десктопної версії: **Settings → API Config → Test**)

## Список моделей порожній

У режимі **Easy** переконайтеся, що **Provider** налаштовано, а ключі/URL-адреси перевірено. Для **Local LLM** переконайтеся, що ваш локальний сервер запущено та моделі завантажено.

У режимі **Advanced** відкрийте **Налаштування → Моделі**, натисніть **Оновити** та додайте моделі до **Вибраних моделей**. За бажанням увімкніть **Тільки безкоштовні**.

## Занадто повільно або занадто дорого

- Виберіть інший шаблон або модель
- Використовуйте коротший ввід
- Вимкніть **Переклад у реальному часі під час набору тексту** в Загальних налаштуваннях
- Використовуйте безкоштовні моделі для простих завдань

## Неправильна мова інтерфейсу

Натисніть піктограму глобуса на панелі інструментів і виберіть **Мову інтерфейсу**.

## Текст занадто малий або важко читається

**Налаштування → Загальні налаштування** → змініть **Сімейство шрифтів** та **Розмір**.

## Зведення на інформаційній панелі виглядає порожнім

Це нормально, якщо:

- ви використовуєте лише **безкоштовні моделі** і дивитеся на показники **вартості** (вони можуть бути нульовими); KPI кількості викликів все ще потребують даних за вибраний період
- вибраний **фільтр часу** не охоплює час здійснення викликів — спробуйте **Усі**

Якщо KPI все ще нульові після вибору **Усі**, перевірте [Історію](/docs/history/) або Інформаційна панель → **Усі виклики**.

## Вартість показує «недоступно» або здається неправильною

OpenRouter показує фактичні витрати, якщо це можливо. Для інших провайдерів вартість оцінюється за цінами OpenRouter; якщо ціна не відповідає, вартість відображається як **недоступно** і не додається до загальної суми.

## Загальна вартість не відповідає рахунку від мого провайдера

Цифри в додатку є **орієнтовними для довідки**, а не рахунками-фактурами. Для OpenRouter використовуйте **Налаштування → Відстеження витрат → Синхронізувати з використанням ключа API**.

## Сторінка історії відсутня на бічній панелі

Можливо, вимкнено опцію **Зберігати історію виконання**. Увімкніть її в Загальних налаштуваннях, якщо історія не вимкнена адміністратором (`HISTORY_DISABLED` — див. [Конфігурація](/docs/configuration/#privacy-mode)).

## Веб: несподівано перенаправлено на сторінку входу

Можливо, ваш сеанс закінчився. Увійдіть знову. Якщо це трапляється часто, перевірте налаштування часу життя сеансу сервера.

## Веб-адміністратор: забули пароль

Якщо інший адміністратор може увійти, він може скинути пароль у розділі **Налаштування → Користувачі**. Якщо ви заблоковані, але маєте доступ до оболонки:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Типове ім'я користувача адміністратора — `admin`. З вихідного коду: `pnpm run reset-web-password -- <username> <new-password>`.

## Інформаційна панель не показує дані для інших користувачів (веб)

Лише **адміністратори** можуть переглядати інших користувачів за допомогою фільтра **Користувач**. Звичайні користувачі бачать лише власну активність.

## Змінено підказку та втрачено зміни

Під час редагування підказки Transform натисніть **Зберегти** перед **Повернутися до запуску**.

## Короткі поради

- Почніть з [Перекласти](/docs/translate/), щоб підтвердити налаштування перед Переписом або Трансформацією
- Використовуйте [Переписати](/docs/rewrite/) для щоденних покращень формулювань
- Використовуйте [Трансформувати](/docs/transform/) для повторюваних користувацьких робочих процесів
- Залишайтеся в режимі **Легкий**, доки вам не знадобляться детальні ідентифікатори моделей
- Регулярно експортуйте підказки, якщо ви створюєте бібліотеку підказок
- Використовуйте [Інформаційну панель](/docs/dashboard/) та [Історію](/docs/history/) для перегляду використання та минулих запусків
