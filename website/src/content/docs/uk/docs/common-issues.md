Якщо щось працює не так, як очікувалося, спочатку перевірте ці пункти.

## Застосунок не перекладає, не переписує або не трансформує

Перевірте, що:

- ви вибрали **шаблон** (Easy) або **модель** (Advanced) на панелі інструментів
- у режимі **Easy** в розділі **Settings → General Settings** є **Provider** з робочим ключем (або URL локальної LLM)
- у режимі **Advanced** модель вибрано на панелі інструментів (допускається порожній список, але для запуску потрібна хоча б одна модель у **Settings → Models**)
- налаштування вашого API працює (для комп'ютера: **Settings → API Config → Test**)

## Список моделей порожній

У режимі **Easy** переконайтеся, що **Provider** встановлено, а ключі/URL-адреси перевірено. Для **Local LLM** переконайтеся, що ваш локальний сервер запущено, а моделі завантажено.

У режимі **Advanced** вибрані моделі можуть бути порожніми. Відкрийте **Settings → Models**, натисніть **Refresh** та додайте моделі до **Selected Models**. За бажанням увімкніть **Free Only**. Видалення останньої моделі з панелі інструментів також відкриває Settings → Models.

## Занадто повільно або занадто дорого

- Виберіть інший шаблон або модель
- Використовуйте коротший вхідний текст
- Вимкніть **Real-time translation while typing** у General Settings
- Використовуйте безкоштовні моделі для простих завдань

## Неправильна мова інтерфейсу

Натисніть піктограму глобуса на панелі інструментів і виберіть **Interface language**.

## Текст занадто малий або важко читається

**Settings → General Settings** → змініть **Font Family** та **Size**.

## Зведення на інформаційній панелі виглядає порожнім

Це нормально, якщо:

- ви використовуєте лише **безкоштовні моделі** і дивитеся на показники **вартості** (вони можуть бути нульовими); для KPI кількості викликів все ще потрібні дані за вибраний період
- вибраний **фільтр часу** не охоплює період, коли були здійснені виклики — спробуйте **All**

Якщо KPI все ще нульові після **All**, перевірте [History](/docs/history/) або Dashboard → **All Calls**.

## Вартість показує «недоступно» або здається неправильною

OpenRouter показує фактичні витрати, якщо це можливо. Для інших провайдерів вартість оцінюється за цінами OpenRouter; якщо ціна не відповідає, вартість відображається як **недоступна** і не додається до загальної суми.

## Загальна вартість не відповідає рахунку мого провайдера

Цифри в застосунку є **орієнтовними для довідки**, а не рахунками-фактурами. Для OpenRouter використовуйте **Налаштування → Відстеження витрат → Синхронізувати з використанням ключа API**.

## Сторінка історії відсутня на бічній панелі

Можливо, вимкнено опцію **Зберігати історію виконання**. Увімкніть її в Загальних налаштуваннях, якщо історія не вимкнена адміністратором (`HISTORY_DISABLED` — див. [Конфігурація](/docs/configuration/#privacy-mode)).

## Веб: несподівано перенаправлено на сторінку входу

Можливо, ваш сеанс закінчився. Увійдіть знову. Якщо це трапляється часто, попросіть адміністратора збільшити **Час очікування сеансу** в розділі [Налаштування → Користувачі](/docs/settings/#users) (адміністратор також міг відкликати ваші сеанси).

## Веб-адміністратор: забув пароль

Якщо інший адміністратор може увійти, він може скинути пароль у розділі **Налаштування → Користувачі**. Якщо ви заблоковані, але маєте доступ до оболонки:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Ім'я користувача адміністратора за замовчуванням — `admin`. З вихідного коду: `pnpm run reset-web-password -- <username> <new-password>`.

## Панель інструментів не показує дані для інших користувачів (веб)

Лише **адміністратори** можуть переглядати інших користувачів за допомогою фільтра **Користувач**. Звичайні користувачі бачать лише власну активність.

## Змінив підказку і втратив редагування

Під час редагування підказки Transform натисніть **Зберегти** перед **Повернутися до запуску**.

## Короткі поради

- Почніть з [Перекладу](/docs/translate/), щоб підтвердити налаштування перед Переписуванням або Трансформацією
- Використовуйте [Переписування](/docs/rewrite/) для щоденних покращень формулювань
- Використовуйте [Трансформацію](/docs/transform/) для повторюваних користувацьких робочих процесів
- Залишайтеся в режимі **Легкий**, доки вам не знадобляться детальні ідентифікатори моделей
- Регулярно експортуйте підказки, якщо ви створюєте бібліотеку підказок
- Використовуйте [Панель інструментів](/docs/dashboard/) та [Історію](/docs/history/) для перегляду використання та минулих запусків
