## Розташування файлів конфігурації

| Розгортання | Папка даних |
| --- | --- |
| Electron (Windows) | `%APPDATA%\transrewrt\` |
| Electron (Linux) | `~/.config/transrewrt/` |
| Web / Docker | `/app/data/` (використовуйте том для збереження) |

Папка даних містить усе, що варто резервувати:

- `config.json` — налаштування та (десктопні) зашифровані ключі API
- `state.json` — останні використані мови, модель та стан перегляду
- `presets.json` — кешований каталог попередніх налаштувань Easy-mode
- `transrewrt.db` — база даних SQLite з історією, витратами, підказками, глосарієм та (веб) користувачами

Ви також можете створити портативний ZIP-архів резервної копії з програми — дивіться [Налаштування → Загальні налаштування](/docs/settings/#general-settings).

## Збереження даних (Docker)

Змонтуйте том за адресою `/app/data`, щоб файли конфігурації та база даних SQLite (див. [Розташування файлів конфігурації](#config-file-locations)) зберігалися після перезапуску контейнера. Без тому дані втрачаються при зупинці контейнера.

## Змінні середовища (веб / Docker)

Electron використовує локальний файл конфігурації. Лише для веб/Docker сервера:

| Змінна | Опис |
| --- | --- |
| `PORT` | Порт прослуховування сервера (за замовчуванням `5000`) |
| `CONFIG_PATH` | Шлях до файлу конфігурації (за замовчуванням `/app/data/config.json`) |
| `TZ` | Часовий пояс для серверного часу (за замовчуванням `Europe/London`) |
| `HISTORY_DISABLED` | Примусове вимкнення історії виконання (`true` / `1`) |
| `OPENROUTER_API_KEY` | Ключ API OpenRouter |
| `OPENAI_API_KEY` | Ключ API OpenAI |
| `CEREBRAS_API_KEY` | Ключ API Cerebras |
| `ANTHROPIC_API_KEY` | Ключ API Anthropic |
| `GOOGLE_API_KEY` | Ключ API Google Gemini |
| `DEEPSEEK_API_KEY` | Ключ API DeepSeek |
| `GROQ_API_KEY` | Ключ API Groq |
| `MISTRAL_API_KEY` | Ключ API Mistral |
| `LOCAL_LLM_URL` | Повна базова URL-адреса API, сумісна з OpenAI, для локального сервера, включно зі шляхом (наприклад, Ollama `http://host.docker.internal:11434/v1`, LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | Ключ API xAI |
| `NVIDIA_API_KEY` | Ключ API NVIDIA |
| `ALIBABA_API_KEY` | Ключ API Alibaba Cloud (DashScope) |
| `APIFUN_API_KEY` | Ключ API apikey.fun |
| `CUSTOM_PROVIDER_NAME` | Відображуване ім'я для власного провайдера, сумісного з OpenAI |
| `CUSTOM_PROVIDER_URL` | Базова URL-адреса для власного провайдера, сумісного з OpenAI |
| `CUSTOM_PROVIDER_API_KEY` | Ключ API для власного провайдера |

Усі три змінні `CUSTOM_PROVIDER_*` є обов'язковими при використанні власної кінцевої точки. Моделі з'являються в режимі **Advanced** як `{providerName}/…`.

## Змінні середовища (десктоп)

| Змінна | Опис |
| --- | --- |
| `TRANSREWRT_DISABLE_GPU` | Встановіть на `1`, щоб вимкнути апаратне прискорення (корисно, коли Chromium виводить помилки GPU / EGL на Linux) |
| `HISTORY_DISABLED` | Примусово вимкнути історію виконання (`true` / `1`) — див. [Режим конфіденційності](#privacy-mode) |

## Режим конфіденційності

Встановіть `HISTORY_DISABLED` на `true` або `1` у веб-процесі/процесі сервера Docker та/або головному процесі Electron, щоб примусово вимкнути історію незалежно від `config.json` або налаштувань для кожного користувача. Це вимикає збереження історії введення/виведення, блокує **Settings → General Settings → History** та блокує API, пов'язані з історією.

## Веб-автентифікація

- Адміністратор за замовчуванням: `admin` / `transrewrt26`
- Керуйте користувачами, часом очікування сеансу та відкликанням сеансу в **Налаштування → Користувачі** — див. [Налаштування](/docs/settings/#users)
- Кожен користувач, який увійшов у систему, може змінити свій пароль або вийти з меню користувача внизу бічної панелі
- Скинути пароль:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
Негайно змініть пароль адміністратора за замовчуванням на будь-якому доступному в мережі хості.
:::

:::caution
Сервер використовує звичайний HTTP. Якщо ви надаєте до нього доступ за межами localhost або довіреної мережі, розмістіть його за зворотним проксі-сервером з HTTPS (наприклад, Caddy, nginx або Traefik), щоб паролі та текст не надсилалися у відкритому вигляді.
:::

## Відображення вартості

OpenRouter повертає точну вартість рахунку, якщо це можливо. Інші провайдери використовують **орієнтовну** вартість з публічних цін моделі OpenRouter, якщо доступний ключ OpenRouter. Оцінки не є рахунками-фактурами.

Щодо інтерфейсу користувача налаштувань (шрифти, моделі, історія, резервні копії), дивіться [Налаштування](/docs/settings/).
