Використовуйте **Transform**, коли ви хочете, щоб ШІ дотримувався власних інструкцій — узагальнював, покращував електронний лист, витягував ключові моменти, переформатовував текст або будь-який робочий процес, який ви визначаєте.

![Робоча область Transform](/images/screenshots/uk/transform.png)

## Запуск наявної підказки

1. Відкрийте **Transform**.
2. Виберіть підказку зі списку.
3. Якщо з’явиться поле мови **З**, встановіть мову, якщо вона потрібна.
4. Введіть або вставте текст у **Вхідні дані**.
5. Натисніть **Transform**.
6. Прочитайте результат у **Вихідних даних**.

## Завантажити зразки підказок

Якщо список порожній, натисніть **Завантажити зразки підказок** у робочій області Transform (також доступно в [Налаштування → Transform](/docs/settings/#transform)). Зразки англійською мовою; після завантаження відредагуйте підказку та скористайтеся **Перекласти підказку**, якщо потрібно.

## Створити підказку

1. Натисніть **Нова підказка**.
2. Натисніть **Згенерувати підказку**.
3. Опишіть, що ви хочете, щоб робила підказка.
4. Виберіть попередньо встановлену (Легко) або модель (Розширено).
5. Перегляньте чернетку та натисніть **Зберегти**.

## Редагувати підказку

Редактор знаходиться ліворуч; область тестування — праворуч.

![Редактор підказок Transform](/images/screenshots/uk/transform-prompt-edit.png)

Основні поля:

- **Назва підказки** — відображається у списку підказок
- **Інструкції підказки (необов’язково)** — коротка підказка під час запуску підказки
- **Роль моделі** — загальна роль для ШІ
- **Інструкції моделі (один рядок)** — правила, яких слід дотримуватися
- **Опис вихідних даних** — коротка мітка для результату (наприклад, узагальнено)
- **Температура (0.0 → 1.0)** — нижча стабільніша; вища різноманітніша
- **Запитати цільову мову** — додає селектор мови під час запуску

Помічники: **Згенерувати підказку**, **Покращити підказку**, **Перекласти підказку** (Легко використовує попередні налаштування; Розширено використовує список моделей).

:::caution
Натисніть **Зберегти** перед **Повернутися до запуску**. Повернення без збереження відкидає зміни.
:::

## Тестуйте перед щоденним використанням

Використовуйте праву тестову панель зі зразком тексту під час створення або порівняння запитів.

Експортуйте та імпортуйте запити масово в розділі [Налаштування → Перетворення](/docs/settings/#transform).
