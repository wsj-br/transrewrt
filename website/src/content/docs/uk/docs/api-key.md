Transrewrt не містить власного ШІ — він надсилає ваш текст обраному вами постачальнику ШІ. Щоб підключити постачальника, ви додаєте **ключ API**: приватний код, виданий постачальником, який працює як пароль для його послуги. Вам потрібен лише **один** постачальник, щоб почати, і вам не потрібно платити: кілька постачальників пропонують безкоштовні моделі або безкоштовні рівні, а також ви можете запускати моделі на власному комп’ютері без будь-якого ключа.

Підтримувані постачальники включають OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, будь-яку сумісну з OpenAI кінцеву точку та локальні сумісні з OpenAI сервери (Ollama, LM Studio, llama.cpp тощо).

## Крок 1 — Виберіть постачальника

Будь-який підтримуваний постачальник працює. Якщо ви не впевнені, який вибрати:

- **Безкоштовно для початку**: OpenRouter, Google Gemini, Groq, Mistral, Cerebras та NVIDIA пропонують безкоштовні моделі або безкоштовні рівні.
- **Вже маєте обліковий запис?** Якщо ви вже використовуєте OpenAI, Anthropic або іншого підтримуваного постачальника, ви можете просто повторно використати цей обліковий запис.
- **Бажаєте зберігати все на власному комп’ютері?** Повністю пропустіть ключ і натомість використовуйте [локальну модель](#using-a-local-model-instead-no-api-key).

## Крок 2 — Створіть ключ API

Точні кроки дещо відрізняються залежно від постачальника, але шаблон скрізь однаковий:

1. Зареєструйтесь або увійдіть на вебсайті постачальника. У **Налаштуваннях → Конфігурація API** Transrewrt кожен постачальник має посилання **Відкрити вебсайт постачальника**, яке переведе вас у потрібне місце.
2. Знайдіть сторінку **Ключі API** (іноді в розділі облікового запису, панелі інструментів або налаштувань розробника) і створіть новий ключ. Деякі постачальники просять назвати ключ або встановити ліміт витрат — обидва є необов’язковими.
3. Скопіюйте ключ. Це довгий рядок літер і цифр, який часто починається з чогось на зразок `sk-`.

:::note
Ставтеся до ключа API як до пароля: не діліться ним, не публікуйте його та не надсилайте нікому. Якщо ключ потрапив до сторонніх осіб, видаліть його на вебсайті постачальника та створіть новий.
:::

## Крок 3 — Додайте та протестуйте ключ (настільний комп’ютер)

1. У Transrewrt відкрийте **Налаштування → Конфігурація API**.
2. Вставте ключ у поле для вашого постачальника (наприклад, **Ключ API Google Gemini**) і збережіть його.
3. Натисніть **Тест** поруч із полем, щоб переконатися, що ключ працює.

Після успішного тестування ви готові — виберіть цього постачальника на головному екрані та почніть переклад.

## Використання локальної моделі замість (без ключа API)

Ви можете запускати моделі на власному комп’ютері за допомогою Ollama, LM Studio, llama.cpp або іншого сумісного з OpenAI сервера (наприклад, `google/gemma-4-e2b` через LM Studio). Нічого не залишає вашу машину, і ключ API не потрібен.

Щоб підключити його, встановіть базову URL-адресу локального LLM на повну базову адресу API, включаючи шлях — наприклад, `http://localhost:11434/v1`. На настільному комп’ютері встановіть це в **Налаштуваннях → Конфігурація API**; у Docker замість цього встановіть змінну середовища `LOCAL_LLM_URL`.

:::tip
Якщо ви використовуєте локальний сервер LLM з іншого пристрою або контейнера, налаштуйте його так, щоб дозволити зовнішні з’єднання (не лише localhost).
:::

## Docker / веб

Якщо ви використовуєте Transrewrt у браузері, ключами керує той, хто запускає сервер, а не вводяться в інтерфейс браузера. Адміністратор встановлює ключі постачальника як **змінні середовища** на сервері (наприклад, `PROVIDER_API_KEY`) — див. [Конфігурація](/docs/configuration/).

## Контрольний список першого запуску

1. Відкрийте програму та за потреби встановіть **Мову інтерфейсу**.
2. Додайте та протестуйте принаймні один ключ постачальника — або налаштуйте локальну модель (настільний комп’ютер), або переконайтеся, що сервер має ключі середовища (веб).
3. У режимі **Easy** виберіть **Постачальника** в Загальних налаштуваннях; у режимі **Advanced** додайте моделі в **Налаштування → Моделі** — див. [Налаштування](/docs/settings/#general-settings) для двох режимів.
4. На **Перекладі** виберіть попередньо встановлену модель або модель і запустіть короткий тест — див. [Перекласти текст](/docs/translate/).

## Якщо щось не працює

- **Перевірка ключа не вдається**: перевірте, чи ключ скопійовано повністю (без пробілів до або після), і чи він не був видалений або вимкнений на вебсайті провайдера.
- **Переклади не вдаються через помилку квоти або кредиту**: безкоштовні тарифи мають щоденні або місячні ліміти; зачекайте, перейдіть до іншого безкоштовного провайдера або додайте кредит.
- **У легкому режимі не відображається жоден провайдер**: відкрийте **Налаштування → Конфігурація API** та переконайтеся, що принаймні один ключ (або URL-адреса локальної LLM) налаштований та протестований.
