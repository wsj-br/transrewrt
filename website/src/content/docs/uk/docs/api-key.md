Transrewrt потрібен доступ щонайменше до одного постачальника ШІ. Вам **не** потрібна платна модель, щоб почати: OpenRouter пропонує безкоштовні моделі після додавання ключа, а кілька інших постачальників також пропонують безкоштовні рівні.

Підтримувані провайдери включають [OpenRouter](https://openrouter.ai), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, будь-яку сумісну з OpenAI кінцеву точку та локальні сервери, сумісні з OpenAI (Ollama, LM Studio, llama.cpp та подібні).

## Простий проти Розширеного

- **Легкий** режим (за замовчуванням): виберіть **пресет** (Безкоштовний (OpenRouter), Стандартний, Розширений або Технічний) відображений до **постачальника**. Відображаються лише пресети з відображенням для поточного постачальника.
- **Розширений** режим: виберіть моделі безпосередньо. Ідентифікатори моделей використовують префікс постачальника (наприклад, `openrouter/…`, `openai/…`, `local/…`).

## Безкоштовний ключ OpenRouter (для ПК)

1. Перейдіть на [openrouter.ai](https://openrouter.ai) та зареєструйтесь або увійдіть.
2. Відкрийте сторінку [Ключі](https://openrouter.ai/keys) та створіть новий ключ (назвіть його; необов'язковий кредитний ліміт). Ви можете використовувати безкоштовні моделі без додавання кредиту.
3. У Transrewrt відкрийте **Налаштування → Конфігурація API**, вставте ключ у поле **Ключ API OpenRouter** та натисніть **Перевірити ключ OpenRouter**.

:::caution
Не використовуйте модель OpenRouter **Body Builder** (`openrouter/bodybuilder`) для перекладу, переписування або трансформації — вона повертає корисні дані запиту JSON, а не завершений текст.
:::

## Інші безкоштовні варіанти

Ви також можете отримати безкоштовні ключі API від Cerebras, Google, Groq, Mistral AI або [NVIDIA](https://build.nvidia.com/) (API, сумісний з OpenAI), або запускати моделі локально за допомогою Ollama, LM Studio, llama.cpp чи іншого сервера, сумісного з OpenAI (наприклад, `translategemma:4b` через Ollama). Встановіть базову URL-адресу локального LLM на повну базу API (включно зі шляхом, наприклад, `http://localhost:11434/v1`) у Налаштуваннях (для настільних ПК) або `LOCAL_LLM_URL` (для Docker).

:::caution
Якщо ви використовуєте локальний сервер ЛЛМ з іншого пристрою або контейнера, настройте його для дозволу зовнішніх підключень (не лише localhost).
:::

## Docker / веб

Встановіть ключі провайдера як **змінні середовища** на сервері (наприклад, `PROVIDER_API_KEY`). Користувачі не можуть вводити ключі в інтерфейсі браузера. Дивіться [Конфігурація](/docs/configuration/).

## Контрольний список першого запуску

1. Відкрийте програму та за потреби встановіть **Мову інтерфейсу**.
2. Додайте та перевірте принаймні один ключ провайдера (для десктопної версії) або переконайтеся, що сервер має ключі середовища (для вебверсії).
3. У **Простому** режимі виберіть **Провайдера** в Загальних налаштуваннях; у **Розширеному** режимі додайте моделі в розділі **Налаштування → Моделі**.
4. На вкладці **Переклад** виберіть попередньо встановлену модель або модель і запустіть короткий тест — див. [Переклад тексту](/docs/translate/).
