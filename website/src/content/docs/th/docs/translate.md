ใช้ **Translate** เพื่อแปลงข้อความจากภาษาหนึ่งไปอีกภาษาหนึ่ง

![พื้นที่ทำงานการแปล](/images/screenshots/th/translate.png)

## ข้อกำหนดเบื้องต้น

- คีย์ผู้ให้บริการอย่างน้อยหนึ่งคีย์ (เดสก์ท็อป) หรือคีย์สภาพแวดล้อมเซิร์ฟเวอร์ (เว็บ) — ดูที่ [คีย์ API](/docs/api-key/)
- **ค่าที่ตั้งไว้ล่วงหน้า** (ง่าย) หรือ **โมเดล** (ขั้นสูง) ที่เลือกในแถบเครื่องมือ

## แปลข้อความ

1. เปิด **Translate** ในแถบด้านข้าง
2. เลือกภาษาใน **From** (หรือ **Detect Language**)
3. เลือกภาษาใน **To**
4. เลือกค่าที่ตั้งไว้ล่วงหน้าหรือโมเดลในแถบเครื่องมือ
5. พิมพ์หรือวางข้อความลงใน **Input**
6. คลิก **Translate**
7. อ่านผลลัพธ์ใน **Output** จากนั้นคัดลอกหากจำเป็น

**ภาษาที่ใช้บ่อยที่สุด** จะปรากฏขึ้นก่อนในรายการ — ตั้งค่าได้ที่ [การตั้งค่า → ภาษา](/docs/settings/#languages)

## การตั้งค่าที่เป็นประโยชน์

ในการตั้งค่า [การตั้งค่า → การตั้งค่าทั่วไป](/docs/settings/#general-settings):

- **ดำเนินการอัตโนมัติเมื่อวาง** — ทำงานทันทีที่คุณวาง
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** — คัดลอกหลังจากดำเนินการสำเร็จ
- **แปลแบบเรียลไทม์ขณะพิมพ์** — ทำงานขณะที่คุณพิมพ์ (อาจเพิ่มค่าใช้จ่าย)
- **หมดเวลา (มิลลิวินาที)** — รอสักครู่ก่อนดำเนินการแบบเรียลไทม์
- **ลักษณะการทำงานของปุ่ม Enter** — กำหนดว่าปุ่ม Enter จะรันงานหรือแทรกบรรทัดใหม่

## เค้าโครงและแป้นพิมพ์

- **สลับเลย์เอาต์** — ปุ่มด้านบนแผงจะสลับระหว่างเลย์เอาต์ Input/Output แบบ **เคียงข้างกัน** และแบบ **ซ้อนกัน** ตัวเลือกนี้ใช้กับการแปล การเขียนใหม่ และการแปลง และจะจดจำไว้ในอุปกรณ์นี้
- **Enter** หรือ **Shift+Enter** จะเรียกใช้งานตาม **ลักษณะการทำงานสำหรับ ENTER** (ดูด้านบน)
- **Escape** จะล้างแผง Input (หรือปิดเมนูหรือกล่องโต้ตอบที่เปิดอยู่ก่อน)

## ปรับปรุงการแปล

หลังจากรันสำเร็จ **Rephrase…** และเมนูแบบเลื่อนลงเวอร์ชันจะปรากฏถัดจากตัวเลือก **To:**

1. **ปรับสำนวน…** (ไม่มีการเลือก) — การแปลอินพุตเดียวกันทั้งหมดอีกครั้ง สูงสุด **ห้า** เวอร์ชัน โมเดลจะเห็นเวอร์ชันก่อนหน้า ดังนั้นสำนวนอาจแตกต่างกันไป คลิก **หยุดการแปล** เพื่อยกเลิกการปรับสำนวนที่กำลังดำเนินการอยู่
2. **คำทางเลือก** — เลือกคำหรือวลีสั้นๆ จากนั้นคลิกขวาหรือ **ปรับสำนวน…** เลือกทางเลือกเพื่อแทนที่ส่วนที่เลือก (อาจขยายเล็กน้อยเพื่อความถูกต้องทางไวยากรณ์) เมื่อถึงห้าเวอร์ชัน จะมีการอัปเดตเฉพาะเวอร์ชันที่ 5 เท่านั้น
3. การปรับสำนวนหรือคำทางเลือกแต่ละครั้งจะใช้โมเดลอีกครั้งและอาจมีค่าใช้จ่ายเพิ่มเติม

## ใช้คำศัพท์

**อภิธานศัพท์** คือคู่คำศัพท์ต้นฉบับ/คำศัพท์เป้าหมายสำหรับคู่ภาษา เมื่อเปิดใช้งาน คำศัพท์ที่ตรงกันจะถูกส่งไปยังโมเดลเพื่อให้การใช้คำที่ต้องการมีความสอดคล้องกัน

1. เปิด **อภิธานศัพท์** ในแผงอินพุต
2. แปลตามปกติ — คำศัพท์สำหรับคู่ **จาก** / **ถึง** นั้นจะถูกนำไปใช้โดยอัตโนมัติ
3. คลิก **เพิ่มลงในอภิธานศัพท์** (ถัดจาก **จาก:**) เพื่อบันทึกคู่ใหม่ได้อย่างรวดเร็ว
4. จัดการคำศัพท์ทั้งหมดใน [การตั้งค่า → อภิธานศัพท์](/docs/settings/#glossary)

:::note
คำศัพท์ในอภิธานศัพท์จะถูกจับคู่ตามคู่ภาษา ไม่สามารถใช้กับ **ตรวจจับภาษา** เป็นภาษาต้นฉบับได้
:::
