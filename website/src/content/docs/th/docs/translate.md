ใช้ **แปล** เพื่อแปลงข้อความจากภาษาหนึ่งไปอีกภาษาหนึ่ง

![พื้นที่ทำงานการแปล](/images/screenshots/th/translate.png)

## ข้อกำหนดเบื้องต้น

- คีย์ผู้ให้บริการอย่างน้อยหนึ่งคีย์ (เดสก์ท็อป) หรือคีย์สภาพแวดล้อมเซิร์ฟเวอร์ (เว็บ) — ดู [คีย์ API](/docs/api-key/)
- **ค่าที่ตั้งไว้ล่วงหน้า** (ง่าย) หรือ **โมเดล** (ขั้นสูง) ที่เลือกในแถบเครื่องมือ

## แปลข้อความ

1. เปิด **แปล** ในแถบด้านข้าง
2. เลือกภาษาใน **จาก** (หรือ **ตรวจจับภาษา**)
3. เลือกภาษาใน **ถึง**
4. เลือกค่าที่ตั้งไว้ล่วงหน้าหรือโมเดลในแถบเครื่องมือ
5. พิมพ์หรือวางข้อความลงใน **อินพุต**
6. คลิก **แปล**
7. อ่านผลลัพธ์ใน **เอาต์พุต** จากนั้นคัดลอกหากจำเป็น

**ภาษาหลัก** จะปรากฏขึ้นก่อนในรายการ — ตั้งค่าได้ภายใต้ [การตั้งค่า → ภาษา](/docs/settings/#languages)

## การตั้งค่าที่เป็นประโยชน์

ใน [การตั้งค่า → การตั้งค่าทั่วไป](/docs/settings/#general-settings):

- **ดำเนินการอัตโนมัติเมื่อวาง** — ทำงานทันทีที่คุณวาง
- **คัดลอกผลลัพธ์ไปยังคลิปบอร์ดอัตโนมัติ** — คัดลอกหลังจากดำเนินการสำเร็จ
- **การแปลแบบเรียลไทม์ขณะพิมพ์** — ทำงานขณะที่คุณพิมพ์ (อาจเพิ่มค่าใช้จ่าย)
- **หมดเวลา (มิลลิวินาที)** — รอสักครู่ก่อนดำเนินการแบบเรียลไทม์
- **ลักษณะการทำงานสำหรับ ENTER** — ไม่ว่า Enter จะรันงานหรือแทรกบรรทัดใหม่

## ปรับปรุงการแปล

หลังจากดำเนินการสำเร็จ **ปรับสำนวน...** และเมนูดรอปดาวน์เวอร์ชันจะปรากฏขึ้นถัดจากตัวเลือก **ถึง:**:

1. **ปรับสำนวน...** (ไม่มีการเลือก) — การแปลฉบับเต็มอีกครั้งของอินพุตเดียวกัน สูงสุด **ห้า** เวอร์ชัน; โมเดลจะเห็นเวอร์ชันก่อนหน้าเพื่อให้ถ้อยคำแตกต่างกันได้ คลิก **หยุดการแปล** เพื่อยกเลิกการปรับสำนวนที่กำลังดำเนินการอยู่
2. **คำทางเลือก** — เลือกคำหรือวลีสั้นๆ จากนั้นคลิกขวาหรือ **ปรับสำนวน...** เลือกทางเลือกเพื่อแทนที่ส่วนนั้น (อาจขยายเล็กน้อยเพื่อไวยากรณ์) ที่ห้าเวอร์ชัน จะมีการอัปเดตเฉพาะเวอร์ชัน 5 เท่านั้น
3. การปรับสำนวนหรือคำทางเลือกแต่ละครั้งจะใช้โมเดลอีกครั้งและอาจเพิ่มค่าใช้จ่าย

## ใช้คำศัพท์

**คำศัพท์** คือคู่คำศัพท์ต้นฉบับ/เป้าหมายสำหรับคู่ภาษา เมื่อเปิดใช้งาน คำศัพท์ที่ตรงกันจะถูกส่งไปยังโมเดลเพื่อให้ถ้อยคำที่ต้องการมีความสอดคล้องกัน

1. เปิด **คำศัพท์** ในแผงอินพุต
2. แปลตามปกติ — คำศัพท์สำหรับคู่ **จาก** / **ถึง** นั้นจะถูกนำไปใช้โดยอัตโนมัติ
3. คลิก **เพิ่มลงในคำศัพท์** (ถัดจาก **จาก:**) เพื่อบันทึกคู่ใหม่ได้อย่างรวดเร็ว
4. จัดการคำศัพท์ทั้งหมดใน [การตั้งค่า → คำศัพท์](/docs/settings/#glossary)

:::note
คำศัพท์ในอภิธานศัพท์จะถูกจับคู่ตามคู่ภาษา ไม่สามารถใช้กับ **ตรวจหาภาษา** เป็นภาษาต้นฉบับได้
:::
