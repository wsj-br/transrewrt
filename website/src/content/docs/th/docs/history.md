เปิด **ประวัติ** เพื่อดูการดำเนินการที่ผ่านมา รวมถึงอินพุตและเอาต์พุตของการเรียกใช้แต่ละครั้ง

![หน้าประวัติ](/images/screenshots/th/history.png)

ประวัติใช้ตัวกรองช่วงเวลาเดียวกับ [แดชบอร์ด](/docs/dashboard/)

:::note
ใน **เว็บแอป** ทุกคน (รวมถึงผู้ดูแลระบบ) จะเห็นเฉพาะประวัติการดำเนินการของตนเองเท่านั้น ตัวกรอง **ผู้ใช้** ของแดชบอร์ดไม่สามารถใช้ได้ที่นี่
:::

## ส่งออก

ส่งออกรายการที่กรองแล้วเป็น **JSON**, **CSV** หรือ **XLSX**

## หากประวัติหายไป

**เก็บประวัติการดำเนินการ** อาจปิดอยู่ เปิดใช้งานได้ใน [การตั้งค่า → การตั้งค่าทั่วไป](/docs/settings/#general-settings) เว้นแต่ผู้ดูแลระบบจะตั้งค่า `HISTORY_DISABLED` — ดู [การกำหนดค่า](/docs/configuration/#privacy-mode)
