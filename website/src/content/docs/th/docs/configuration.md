## ตำแหน่งไฟล์กำหนดค่า

| การปรับใช้ | โฟลเดอร์ข้อมูล |
| --- | --- |
| Electron (Windows) | `%APPDATA%\transrewrt\` |
| Electron (Linux) | `~/.config/transrewrt/` |
| เว็บ / Docker | `/app/data/` (ใช้โวลุ่มเพื่อคงอยู่) |

โฟลเดอร์ข้อมูลเก็บทุกสิ่งที่ควรสำรองข้อมูล:

- `config.json` — การตั้งค่าและคีย์ API ที่เข้ารหัส (เดสก์ท็อป)
- `state.json` — ภาษาที่ใช้ล่าสุด, โมเดล และสถานะมุมมอง
- `presets.json` — แค็ตตาล็อกพรีเซ็ตโหมด Easy ที่แคชไว้
- `transrewrt.db` — ฐานข้อมูล SQLite ที่มีประวัติ, ค่าใช้จ่าย, พร้อมต์, อภิธานศัพท์ และผู้ใช้ (เว็บ)

คุณยังสามารถสร้างไฟล์ ZIP สำรองแบบพกพาจากแอปได้ — ดูที่ [การตั้งค่า → การตั้งค่าทั่วไป](/docs/settings/#general-settings)

## ตัวแปรสภาพแวดล้อม (เว็บ / Docker)

Electron ใช้ไฟล์กำหนดค่าภายใน สำหรับเซิร์ฟเวอร์เว็บ/Docker เท่านั้น:

| ตัวแปร | คำอธิบาย |
| --- | --- |
| `PORT` | พอร์ตการฟังของเซิร์ฟเวอร์ (ค่าเริ่มต้น `5000`) |
| `CONFIG_PATH` | พาธไปยังไฟล์กำหนดค่า (ค่าเริ่มต้น `/app/data/config.json`) |
| `TZ` | เขตเวลาสำหรับเวลาฝั่งเซิร์ฟเวอร์ (ค่าเริ่มต้น `Europe/London`) |
| `HISTORY_DISABLED` | บังคับปิดประวัติการดำเนินการ (`true` / `1`) |
| `OPENROUTER_API_KEY` | คีย์ API ของ OpenRouter |
| `OPENAI_API_KEY` | คีย์ API ของ OpenAI |
| `CEREBRAS_API_KEY` | คีย์ API ของ Cerebras |
| `ANTHROPIC_API_KEY` | คีย์ API ของ Anthropic |
| `GOOGLE_API_KEY` | คีย์ API ของ Google Gemini |
| `DEEPSEEK_API_KEY` | คีย์ API ของ DeepSeek |
| `GROQ_API_KEY` | คีย์ API ของ Groq |
| `MISTRAL_API_KEY` | คีย์ API ของ Mistral |
| `LOCAL_LLM_URL` | URL พื้นฐานของ API ที่เข้ากันได้กับ OpenAI สำหรับเซิร์ฟเวอร์ภายในเครื่อง รวมถึงพาธ (เช่น Ollama `http://host.docker.internal:11434/v1`, LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | คีย์ API ของ xAI |
| `NVIDIA_API_KEY` | คีย์ API ของ NVIDIA |
| `ALIBABA_API_KEY` | คีย์ API ของ Alibaba Cloud (DashScope) |
| `APIFUN_API_KEY` | คีย์ API ของ apikey.fun |
| `CUSTOM_PROVIDER_NAME` | ชื่อที่แสดงสำหรับผู้ให้บริการที่เข้ากันได้กับ OpenAI แบบกำหนดเอง |
| `CUSTOM_PROVIDER_URL` | URL พื้นฐานสำหรับผู้ให้บริการที่เข้ากันได้กับ OpenAI แบบกำหนดเอง |
| `CUSTOM_PROVIDER_API_KEY` | คีย์ API สำหรับผู้ให้บริการแบบกำหนดเอง |

ตัวแปร `CUSTOM_PROVIDER_*` ทั้งสามตัวจำเป็นเมื่อใช้ปลายทางที่กำหนดเอง โมเดลจะปรากฏในโหมด **ขั้นสูง** เป็น `{providerName}/…`

## ตัวแปรสภาพแวดล้อม (เดสก์ท็อป)

| ตัวแปร | คำอธิบาย |
| --- | --- |
| `TRANSREWRT_DISABLE_GPU` | ตั้งค่าเป็น `1` เพื่อปิดใช้งานการเร่งฮาร์ดแวร์ (มีประโยชน์เมื่อ Chromium พิมพ์ข้อผิดพลาด GPU / EGL บน Linux) |
| `HISTORY_DISABLED` | บังคับปิดประวัติการดำเนินการ (`true` / `1`) — ดู [โหมดความเป็นส่วนตัว](#privacy-mode) |

## โหมดความเป็นส่วนตัว

ตั้งค่า `HISTORY_DISABLED` เป็น `true` หรือ `1` บนกระบวนการเซิร์ฟเวอร์เว็บ/Docker และ/หรือกระบวนการหลักของ Electron เพื่อบังคับปิดประวัติโดยไม่คำนึงถึง `config.json` หรือการตั้งค่าของผู้ใช้แต่ละราย ซึ่งจะปิดใช้งานการจัดเก็บประวัติอินพุต/เอาต์พุต ล็อก **การตั้งค่า → การตั้งค่าทั่วไป → ประวัติ** และบล็อก API ที่เกี่ยวข้องกับประวัติ

## การคงอยู่ของข้อมูล (Docker)

เมานต์วอลุ่มที่ `/app/data` เพื่อให้ไฟล์คอนฟิกและฐานข้อมูล SQLite (ดู [ตำแหน่งไฟล์คอนฟิก](#config-file-locations)) ยังคงอยู่หลังจากการรีสตาร์ทคอนเทนเนอร์ หากไม่มีวอลุ่ม ข้อมูลจะสูญหายเมื่อคอนเทนเนอร์หยุดทำงาน

## การรับรองความถูกต้องของเว็บ

- ผู้ดูแลระบบเริ่มต้น: `admin` / `transrewrt26`
- จัดการผู้ใช้, การหมดเวลาเซสชัน, และการเพิกถอนเซสชันใน **การตั้งค่า → ผู้ใช้** — ดู [การตั้งค่า](/docs/settings/#users)
- ผู้ใช้ที่ลงชื่อเข้าใช้แต่ละคนสามารถเปลี่ยนรหัสผ่านของตนเองหรือลงชื่อออกได้จากเมนูผู้ใช้ที่ด้านล่างของแถบด้านข้าง
- รีเซ็ตรหัสผ่าน:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
เปลี่ยนรหัสผ่านผู้ดูแลระบบเริ่มต้นทันทีบนโฮสต์ที่เข้าถึงได้ผ่านเครือข่ายใดๆ
:::

:::caution
เซิร์ฟเวอร์ใช้ HTTP แบบธรรมดา หากคุณเปิดเผยเซิร์ฟเวอร์นอกเหนือจาก localhost หรือเครือข่ายที่เชื่อถือได้ ให้วางไว้หลังพร็อกซีแบบย้อนกลับด้วย HTTPS (เช่น Caddy, nginx หรือ Traefik) เพื่อไม่ให้รหัสผ่านและข้อความถูกส่งแบบไม่เข้ารหัส
:::

## การแสดงต้นทุน

OpenRouter จะคืนค่าใช้จ่ายที่เรียกเก็บจริงเมื่อมีผลบังคับใช้ ผู้ให้บริการรายอื่นใช้ต้นทุนที่ **ประมาณการ** จากราคาโมเดลสาธารณะของ OpenRouter เมื่อมีคีย์ OpenRouter ให้ใช้งาน การประมาณการไม่ใช่ใบแจ้งหนี้

สำหรับ UI การตั้งค่า (ฟอนต์, โมเดล, ประวัติ, การสำรองข้อมูล) โปรดดู [การตั้งค่า](/docs/settings/)
