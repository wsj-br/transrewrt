ใช้ **แดชบอร์ด** เพื่อดูว่าคุณใช้งานแอปมากน้อยเพียงใด และมีค่าใช้จ่ายเท่าไร (สำหรับโมเดลแบบชำระเงิน)

![สรุปแดชบอร์ด](/images/screenshots/th/dashboard-summary.png)

:::note
หากคุณใช้เฉพาะโมเดล **ฟรี** จำนวนค่าใช้จ่ายอาจเป็นศูนย์ KPI จำนวนการโทรบน **สรุป** ยังคงต้องมีกิจกรรมในช่วงเวลาที่เลือก
:::

## กรองข้อมูล

ใช้ปุ่มตัวกรองที่ด้านบนเพื่อเปลี่ยนช่วงเวลา

:::note
ตัวกรอง **ผู้ใช้** จะมองเห็นได้เฉพาะผู้ดูแลระบบในเวอร์ชันเว็บเท่านั้น ไม่สามารถใช้งานได้บนเดสก์ท็อป
:::

## แท็บ

- **สรุป** — KPI: ค่าใช้จ่ายทั้งหมด, โมเดลที่ใช้, จำนวนการโทรและค่าใช้จ่ายต่อโหมด, ค่าใช้จ่ายเฉลี่ยต่อการโทร, TPS เฉลี่ย, โมเดลยอดนิยมตามจำนวนการโทร
- **ตามโมเดล** — การโทรต่อโมเดล, ค่าใช้จ่าย และ TPS; ขยายแถวเพื่อดูรายละเอียดโหมด
- **การโทรทั้งหมด** — บันทึกการโทรทั้งหมด (แบ่งหน้าหรือการ์ด) พร้อมการส่งออก

## ส่งออกข้อมูล

ส่งออกตารางเป็น **JSON**, **CSV** หรือ **XLSX**

## ลบบันทึกที่จัดเก็บไว้สำหรับโมเดล

ใน **ตามโมเดล** หรือ **การโทรทั้งหมด** ให้ใช้ไอคอนถังขยะเพื่อลบบันทึกสำหรับโมเดล

:::caution
การลบไม่สามารถยกเลิกได้ หากต้องการลบตามอายุหรือล้างข้อมูลค่าใช้จ่ายทั้งหมด ให้ใช้ [การตั้งค่า → การติดตามค่าใช้จ่าย](/docs/settings/#cost-tracking)
:::
