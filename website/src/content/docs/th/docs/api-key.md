Transrewrt ไม่มี AI ของตัวเอง แต่จะส่งข้อความของคุณไปยังผู้ให้บริการ AI ที่คุณเลือก หากต้องการเชื่อมต่อผู้ให้บริการ คุณต้องเพิ่ม **คีย์ API**: ซึ่งเป็นรหัสส่วนตัวที่ออกโดยผู้ให้บริการ ทำหน้าที่เหมือนรหัสผ่านสำหรับบริการของพวกเขา คุณต้องการผู้ให้บริการเพียง **หนึ่งราย** เพื่อเริ่มต้น และคุณไม่จำเป็นต้องจ่ายเงิน: ผู้ให้บริการหลายรายมีโมเดลฟรีหรือระดับฟรี และคุณยังสามารถเรียกใช้โมเดลบนคอมพิวเตอร์ของคุณเองได้โดยไม่ต้องใช้คีย์เลย

ผู้ให้บริการที่รองรับ ได้แก่ OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, ปลายทางที่เข้ากันได้กับ OpenAI และเซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI ในเครื่อง (Ollama, LM Studio, llama.cpp และที่คล้ายกัน)

## ขั้นตอนที่ 1 — เลือกผู้ให้บริการ

ผู้ให้บริการที่รองรับทุกรายใช้งานได้ หากคุณไม่แน่ใจว่าจะเลือกรายใด:

- **เริ่มต้นฟรี**: OpenRouter, Google Gemini, Groq, Mistral, Cerebras และ NVIDIA ทั้งหมดมีโมเดลฟรีหรือระดับฟรี
- **มีบัญชีอยู่แล้วใช่ไหม?** หากคุณใช้ OpenAI, Anthropic หรือผู้ให้บริการที่รองรับรายอื่นอยู่แล้ว คุณสามารถใช้บัญชีนั้นซ้ำได้เลย
- **ต้องการเก็บทุกอย่างไว้ในคอมพิวเตอร์ของคุณเองใช่ไหม?** ข้ามคีย์ไปเลยและใช้ [โมเดลในเครื่อง](#using-a-local-model-instead-no-api-key) แทน

## ขั้นตอนที่ 2 — สร้างคีย์ API

ขั้นตอนที่แน่นอนจะแตกต่างกันเล็กน้อยตามผู้ให้บริการ แต่รูปแบบจะเหมือนกันทุกที่:

1. ลงทะเบียนหรือเข้าสู่ระบบบนเว็บไซต์ของผู้ให้บริการ ใน Transrewrt's **Settings → API Config** ผู้ให้บริการแต่ละรายจะมีลิงก์ **Open provider website** ที่จะนำคุณไปยังตำแหน่งที่ถูกต้อง
2. ค้นหาหน้า **API keys** (บางครั้งอยู่ภายใต้บัญชี แดชบอร์ด หรือการตั้งค่านักพัฒนา) และสร้างคีย์ใหม่ ผู้ให้บริการบางรายขอให้คุณตั้งชื่อคีย์หรือกำหนดวงเงินการใช้จ่าย — ทั้งสองอย่างเป็นทางเลือก
3. คัดลอกคีย์ เป็นสตริงยาวของตัวอักษรและตัวเลข ซึ่งมักจะเริ่มต้นด้วยบางอย่างเช่น `sk-`

:::note
ปฏิบัติต่อ API key เหมือนรหัสผ่าน: ห้ามแชร์ โพสต์ หรือส่งให้ใคร หากคีย์รั่วไหล ให้ลบออกจากเว็บไซต์ของผู้ให้บริการและสร้างคีย์ใหม่
:::

## ขั้นตอนที่ 3 — เพิ่มและทดสอบคีย์ (เดสก์ท็อป)

1. ใน Transrewrt ให้เปิด **Settings → API Config**
2. วางคีย์ลงในช่องสำหรับผู้ให้บริการของคุณ (เช่น **Google Gemini API key**) และบันทึก
3. คลิก **Test** ถัดจากช่องเพื่อยืนยันว่าคีย์ใช้งานได้

เมื่อการทดสอบสำเร็จ คุณก็พร้อมแล้ว — เลือกผู้ให้บริการนั้นบนหน้าจอหลักและเริ่มแปลได้เลย

## การใช้โมเดลในเครื่องแทน (ไม่มีคีย์ API)

คุณสามารถเรียกใช้โมเดลบนคอมพิวเตอร์ของคุณเองด้วย Ollama, LM Studio, llama.cpp หรือเซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI อื่นๆ (เช่น `google/gemma-4-e2b` ผ่าน LM Studio) ไม่มีอะไรออกจากเครื่องของคุณและไม่จำเป็นต้องใช้คีย์ API

หากต้องการเชื่อมต่อ ให้ตั้งค่า Local LLM base URL เป็น API base แบบเต็ม รวมถึงพาธ — ตัวอย่างเช่น `http://localhost:11434/v1` บนเดสก์ท็อป ให้ตั้งค่านี้ใน **Settings → API Config**; บน Docker ให้ตั้งค่าตัวแปรสภาพแวดล้อม `LOCAL_LLM_URL` แทน

:::tip
หากคุณใช้เซิร์ฟเวอร์ LLM ในเครื่องจากอุปกรณ์หรือคอนเทนเนอร์อื่น ให้กำหนดค่าเพื่ออนุญาตการเชื่อมต่อภายนอก (ไม่ใช่เฉพาะ localhost)
:::

## Docker / เว็บ

หากคุณใช้ Transrewrt ในเบราว์เซอร์ คีย์จะถูกจัดการโดยผู้ที่เรียกใช้เซิร์ฟเวอร์ ไม่ได้พิมพ์ลงใน UI ของเบราว์เซอร์ ผู้ดูแลระบบจะตั้งค่าคีย์ผู้ให้บริการเป็น **ตัวแปรสภาพแวดล้อม** บนเซิร์ฟเวอร์ (เช่น `PROVIDER_API_KEY`) — ดู [Configuration](/docs/configuration/)

## รายการตรวจสอบการรันครั้งแรก

1. เปิดแอปและตั้งค่า **Interface language** หากจำเป็น
2. เพิ่มและทดสอบคีย์ผู้ให้บริการอย่างน้อยหนึ่งคีย์ — หรือกำหนดค่าโมเดลในเครื่อง (เดสก์ท็อป) หรือยืนยันว่าเซิร์ฟเวอร์มีคีย์ env (เว็บ)
3. ในโหมด **Easy** ให้เลือก **Provider** ใน General Settings; ในโหมด **Advanced** ให้เพิ่มโมเดลภายใต้ **Settings → Models** — ดู [Settings](/docs/settings/#general-settings) สำหรับสองโหมดนี้
4. บน **Translate** ให้เลือกพรีเซ็ตหรือโมเดลและทำการทดสอบสั้นๆ — ดู [Translate text](/docs/translate/)

## หากมีบางอย่างไม่ทำงาน

- **การทดสอบคีย์ล้มเหลว**: ตรวจสอบว่าคีย์ถูกคัดลอกทั้งหมด (ไม่มีช่องว่างก่อนหรือหลัง) และไม่ได้ถูกลบหรือปิดใช้งานบนเว็บไซต์ของผู้ให้บริการ
- **การแปลล้มเหลวเนื่องจากโควต้าหรือข้อผิดพลาดด้านเครดิต**: ระดับฟรีมีขีดจำกัดรายวันหรือรายเดือน ให้รอ เปลี่ยนไปใช้ผู้ให้บริการฟรีรายอื่น หรือเพิ่มเครดิต
- **ไม่มีผู้ให้บริการปรากฏในโหมด Easy**: เปิด **การตั้งค่า → การกำหนดค่า API** และยืนยันว่ามีการกำหนดค่าและทดสอบคีย์อย่างน้อยหนึ่งคีย์ (หรือ URL ของ LLM ภายในเครื่อง) แล้ว
