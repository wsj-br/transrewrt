Transrewrt ต้องการการเข้าถึงผู้ให้บริการ AI อย่างน้อยหนึ่งราย คุณ **ไม่** จำเป็นต้องมีโมเดลแบบชำระเงินเพื่อเริ่มต้น: OpenRouter มีโมเดลฟรีให้หลังจากที่คุณเพิ่มคีย์ และผู้ให้บริการอื่นๆ อีกหลายรายก็มีระดับฟรีให้เช่นกัน

ผู้ให้บริการที่รองรับ ได้แก่ [OpenRouter](https://openrouter.ai), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, ปลายทางที่เข้ากันได้กับ OpenAI และเซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI ในเครื่อง (Ollama, LM Studio, llama.cpp และที่คล้ายกัน)

## โหมดง่ายเทียบกับโหมดขั้นสูง

- โหมด **ง่าย** (ค่าเริ่มต้น): เลือก **ค่าที่ตั้งไว้ล่วงหน้า** (ฟรี (OpenRouter), มาตรฐาน, ขั้นสูง หรือทางเทคนิค) ที่แมปกับ **ผู้ให้บริการ** ค่าที่ตั้งไว้ล่วงหน้าที่มีการแมปสำหรับผู้ให้บริการปัจจุบันเท่านั้นที่จะปรากฏ
- โหมด **ขั้นสูง**: เลือกโมเดลโดยตรง รหัสโมเดลใช้คำนำหน้าผู้ให้บริการ (เช่น `openrouter/…`, `openai/…`, `local/…`)

## คีย์ OpenRouter ฟรี (เดสก์ท็อป)

1. ไปที่ [openrouter.ai](https://openrouter.ai) และลงทะเบียนหรือเข้าสู่ระบบ
2. เปิดหน้า [Keys](https://openrouter.ai/keys) และสร้างคีย์ใหม่ (ตั้งชื่อ; วงเงินเครดิตเสริม) คุณสามารถใช้โมเดลฟรีได้โดยไม่ต้องเพิ่มเครดิต
3. ใน Transrewrt ให้เปิด **Settings → API Config** วางคีย์ลงใน **OpenRouter API key** แล้วคลิก **Test OpenRouter key**

:::caution
อย่าใช้โมเดล **Body Builder** ของ OpenRouter (`openrouter/bodybuilder`) สำหรับการแปล การเขียนใหม่ หรือการแปลง — มันจะส่งคืนเพย์โหลดคำขอ JSON ไม่ใช่ข้อความที่สมบูรณ์
:::

## ตัวเลือกฟรีอื่นๆ

คุณยังสามารถขอรับคีย์ API ฟรีจาก Cerebras, Google, Groq, Mistral AI หรือ [NVIDIA](https://build.nvidia.com/) (API ที่เข้ากันได้กับ OpenAI) หรือเรียกใช้โมเดลในเครื่องด้วย Ollama, LM Studio, llama.cpp หรือเซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI อื่นๆ (เช่น `translategemma:4b` ผ่าน Ollama) ตั้งค่า URL พื้นฐานของ Local LLM เป็นฐาน API แบบเต็ม (รวมพาธ เช่น `http://localhost:11434/v1`) ในการตั้งค่า (เดสก์ท็อป) หรือ `LOCAL_LLM_URL` (Docker)

:::caution
หากคุณใช้เซิร์ฟเวอร์ LLM ในเครื่องจากอุปกรณ์หรือคอนเทนเนอร์อื่น ให้กำหนดค่าเพื่ออนุญาตการเชื่อมต่อภายนอก (ไม่ใช่เฉพาะ localhost)
:::

## Docker / เว็บ

ตั้งค่าคีย์ของผู้ให้บริการเป็น **ตัวแปรสภาพแวดล้อม** บนเซิร์ฟเวอร์ (เช่น `PROVIDER_API_KEY`) ผู้ใช้ไม่สามารถพิมพ์คีย์ลงใน UI ของเบราว์เซอร์ได้ โปรดดูที่ [การกำหนดค่า](/docs/configuration/)

## รายการตรวจสอบการเรียกใช้ครั้งแรก

1. เปิดแอปและตั้งค่า **ภาษาของอินเทอร์เฟซ** หากจำเป็น
2. เพิ่มและทดสอบคีย์ผู้ให้บริการอย่างน้อยหนึ่งคีย์ (เดสก์ท็อป) หรือยืนยันว่าเซิร์ฟเวอร์มีคีย์ env (เว็บ)
3. ในโหมด **Easy** ให้เลือก **ผู้ให้บริการ** ในการตั้งค่าทั่วไป; ในโหมด **Advanced** ให้เพิ่มโมเดลภายใต้ **การตั้งค่า → โมเดล**
4. บน **แปล** เลือกค่าที่ตั้งไว้ล่วงหน้าหรือโมเดลแล้วทำการทดสอบสั้นๆ — ดู [แปลข้อความ](/docs/translate/)
