หากมีบางอย่างไม่ทำงานตามที่คาดไว้ ให้ตรวจสอบประเด็นเหล่านี้ก่อน

## แอปไม่แปล ไม่เขียนใหม่ หรือไม่แปลง

ตรวจสอบว่า:

- คุณได้เลือก **preset** (ง่าย) หรือ **model** (ขั้นสูง) ในแถบเครื่องมือแล้ว
- ในโหมด **ง่าย** **การตั้งค่า → การตั้งค่าทั่วไป** มี **ผู้ให้บริการ** ที่มีคีย์ที่ใช้งานได้ (หรือ URL ของ LLM ในเครื่อง)
- ในโหมด **ขั้นสูง** มีการเลือกโมเดลในแถบเครื่องมือ (อนุญาตให้มีรายการว่างเปล่า แต่คุณต้องมีโมเดลอย่างน้อยหนึ่งโมเดลใน **การตั้งค่า → โมเดล** เพื่อเรียกใช้)
- การตั้งค่า API ของคุณทำงานได้ (เดสก์ท็อป: **การตั้งค่า → การกำหนดค่า API → ทดสอบ**)

## รายการโมเดลว่างเปล่า

ในโหมด **ง่าย** ยืนยันว่าได้ตั้งค่า **ผู้ให้บริการ** และได้ทดสอบคีย์/URL แล้ว สำหรับ **LLM ในเครื่อง** ตรวจสอบให้แน่ใจว่าเซิร์ฟเวอร์ในเครื่องของคุณกำลังทำงานและโหลดโมเดลแล้ว

ในโหมด **ขั้นสูง** โมเดลที่เลือกอาจว่างเปล่า เปิด **การตั้งค่า → โมเดล** คลิก **รีเฟรช** และเพิ่มโมเดลลงใน **โมเดลที่เลือก** คุณสามารถเลือกเปิด **เฉพาะฟรี** ได้ การลบโมเดลแถบเครื่องมือสุดท้ายยังเปิดการตั้งค่า → โมเดล

## ช้าเกินไปหรือแพงเกินไป

- เลือก preset หรือโมเดลอื่น
- ใช้ข้อมูลป้อนเข้าที่สั้นลง
- ปิด **การแปลแบบเรียลไทม์ขณะพิมพ์** ในการตั้งค่าทั่วไป
- ใช้โมเดลฟรีสำหรับงานง่ายๆ

## ภาษาอินเทอร์เฟซผิด

คลิกไอคอนรูปโลกในแถบเครื่องมือและเลือก **ภาษาอินเทอร์เฟซ** ของคุณ

## ข้อความเล็กเกินไปหรืออ่านยาก

**การตั้งค่า → การตั้งค่าทั่วไป** → เปลี่ยน **ชุดแบบอักษร** และ **ขนาด**

## สรุปแดชบอร์ดดูว่างเปล่า

นี่เป็นเรื่องปกติหาก:

- คุณใช้ **โมเดลฟรี** เท่านั้น และคุณกำลังดูตัวเลข **ค่าใช้จ่าย** (อาจเป็นศูนย์) KPI การนับการโทรยังคงต้องการข้อมูลสำหรับช่วงเวลาที่เลือก
- **ตัวกรองเวลา** ที่เลือกไม่ครอบคลุมช่วงเวลาที่มีการโทร — ลอง **ทั้งหมด**

หาก KPI ยังคงเป็นศูนย์หลังจาก **ทั้งหมด** ให้ตรวจสอบ [ประวัติ](/docs/history/) หรือ แดชบอร์ด → **การโทรทั้งหมด**

## ค่าใช้จ่ายแสดงว่า "ไม่พร้อมใช้งาน" หรือดูเหมือนผิดปกติ

OpenRouter จะแสดงค่าใช้จ่ายจริงเมื่อสามารถทำได้ สำหรับผู้ให้บริการรายอื่น ค่าใช้จ่ายจะถูกประมาณจากราคาของ OpenRouter หากไม่มีราคาที่ตรงกัน ค่าใช้จ่ายจะแสดงเป็น **ไม่พร้อมใช้งาน** และจะไม่ถูกเพิ่มในยอดรวม

## ค่าใช้จ่ายรวมไม่ตรงกับบิลของผู้ให้บริการของฉัน

ตัวเลขในแอปเป็น **การประมาณเพื่อใช้อ้างอิง** ไม่ใช่ใบแจ้งหนี้ สำหรับ OpenRouter ให้ใช้ **การตั้งค่า → การติดตามค่าใช้จ่าย → ซิงค์กับการใช้งานคีย์ API**

## หน้าประวัติหายไปจากแถบด้านข้าง

**เก็บประวัติการดำเนินการ** อาจถูกปิดอยู่ เปิดใช้งานได้ในการตั้งค่าทั่วไป เว้นแต่ประวัติจะถูกปิดใช้งานโดยผู้ดูแลระบบ (`HISTORY_DISABLED` — ดู [การกำหนดค่า](/docs/configuration/#privacy-mode))

## เว็บ: ถูกเปลี่ยนเส้นทางไปยังหน้าเข้าสู่ระบบโดยไม่คาดคิด

เซสชันของคุณอาจหมดเวลาแล้ว เข้าสู่ระบบอีกครั้ง หากเกิดขึ้นบ่อยครั้ง ให้ขอให้ผู้ดูแลระบบเพิ่ม **ระยะหมดเวลาของเซสชัน** ภายใต้ [การตั้งค่า → ผู้ใช้](/docs/settings/#users) (ผู้ดูแลระบบอาจยกเลิกเซสชันของคุณแล้ว)

## ผู้ดูแลระบบเว็บ: ลืมรหัสผ่าน

หากผู้ดูแลระบบคนอื่นสามารถลงชื่อเข้าใช้ได้ พวกเขาสามารถรีเซ็ตรหัสผ่านได้ภายใต้ **การตั้งค่า → ผู้ใช้** หากคุณถูกล็อกไม่ให้เข้าถึงแต่มีสิทธิ์เข้าถึงเชลล์:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ชื่อผู้ใช้ผู้ดูแลระบบเริ่มต้นคือ `admin` จากการตรวจสอบแหล่งที่มา: `pnpm run reset-web-password -- <username> <new-password>`

## แดชบอร์ดไม่แสดงข้อมูลสำหรับผู้ใช้รายอื่น (เว็บ)

เฉพาะ **ผู้ดูแลระบบ** เท่านั้นที่สามารถดูผู้ใช้รายอื่นผ่านตัวกรอง **ผู้ใช้** ผู้ใช้ทั่วไปจะเห็นเฉพาะกิจกรรมของตนเอง

## เปลี่ยนพรอมต์และสูญเสียการแก้ไข

เมื่อแก้ไขพรอมต์ Transform ให้คลิก **บันทึก** ก่อน **กลับไปที่การรัน**

## เคล็ดลับด่วน

- เริ่มต้นด้วย [แปล](/docs/translate/) เพื่อยืนยันการตั้งค่าของคุณก่อนที่จะเขียนใหม่หรือแปลง
- ใช้ [เขียนใหม่](/docs/rewrite/) เพื่อปรับปรุงถ้อยคำในชีวิตประจำวัน
- ใช้ [แปลง](/docs/transform/) สำหรับเวิร์กโฟลว์ที่กำหนดเองที่ทำซ้ำได้
- อยู่ในโหมด **ง่าย** จนกว่าคุณจะต้องการรหัสโมเดลที่มีรายละเอียด
- ส่งออกพรอมต์เป็นประจำหากคุณกำลังสร้างไลบรารีพรอมต์
- ใช้ [แดชบอร์ด](/docs/dashboard/) และ [ประวัติ](/docs/history/) เพื่อตรวจสอบการใช้งานและการรันที่ผ่านมา
