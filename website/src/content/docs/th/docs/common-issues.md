หากมีบางอย่างไม่เป็นไปตามที่คาดไว้ ให้ตรวจสอบประเด็นเหล่านี้ก่อน

## แอปไม่แปล ไม่เขียนใหม่ หรือไม่แปลง

ตรวจสอบว่า:

- คุณได้เลือก **preset** (Easy) หรือ **model** (Advanced) ในแถบเครื่องมือ
- ในโหมด **Easy** ให้ตรวจสอบว่า **Settings → General Settings** มี **Provider** ที่มีคีย์ที่ใช้งานได้ (หรือ Local LLM URL)
- ในโหมด **Advanced** มีโมเดลอย่างน้อยหนึ่งรายการอยู่ใน **Settings → Models**
- การตั้งค่า API ของคุณทำงานได้ (เดสก์ท็อป: **Settings → API Config → Test**)

## รายการโมเดลว่างเปล่า

ในโหมด **Easy** ให้ยืนยันว่าได้ตั้งค่า **Provider** และได้ทดสอบคีย์/URL แล้ว สำหรับ **Local LLM** ตรวจสอบให้แน่ใจว่าเซิร์ฟเวอร์ในเครื่องของคุณกำลังทำงานและโหลดโมเดลแล้ว

ในโหมด **ขั้นสูง** ให้เปิด **การตั้งค่า → โมเดล** คลิก **รีเฟรช** และเพิ่มโมเดลลงใน **โมเดลที่เลือก** คุณสามารถเปิด **เฉพาะฟรี** ได้

## ช้าเกินไปหรือแพงเกินไป

- เลือกค่าที่ตั้งไว้ล่วงหน้าหรือโมเดลอื่น
- ใช้ข้อมูลนำเข้าที่สั้นลง
- ปิด **การแปลแบบเรียลไทม์ขณะพิมพ์** ในการตั้งค่าทั่วไป
- ใช้โมเดลฟรีสำหรับงานง่ายๆ

## ภาษาอินเทอร์เฟซผิด

คลิกไอคอนรูปโลกในแถบเครื่องมือและเลือก **ภาษาอินเทอร์เฟซ** ของคุณ

## ข้อความเล็กเกินไปหรืออ่านยาก

**การตั้งค่า → การตั้งค่าทั่วไป** → เปลี่ยน **ตระกูลแบบอักษร** และ **ขนาด**

## สรุปแดชบอร์ดดูว่างเปล่า

นี่เป็นเรื่องปกติหาก:

- คุณใช้เฉพาะ **โมเดลฟรี** และคุณกำลังดูตัวเลข **ค่าใช้จ่าย** (อาจเป็นศูนย์); KPI จำนวนการโทรยังคงต้องการข้อมูลสำหรับช่วงเวลาที่เลือก
- **ตัวกรองเวลา** ที่เลือกไม่ครอบคลุมช่วงเวลาที่มีการโทร — ลองใช้ **ทั้งหมด**

หาก KPI ยังคงเป็นศูนย์หลังจาก **ทั้งหมด** ให้ตรวจสอบ [ประวัติ](/docs/history/) หรือ แดชบอร์ด → **การโทรทั้งหมด**

## ค่าใช้จ่ายแสดงว่า "ไม่พร้อมใช้งาน" หรือดูเหมือนผิดปกติ

OpenRouter จะแสดงค่าใช้จ่ายจริงเมื่อมี สำหรับผู้ให้บริการรายอื่น ค่าใช้จ่ายจะถูกประมาณจากราคาของ OpenRouter; หากไม่มีราคาที่ตรงกัน ค่าใช้จ่ายจะแสดงเป็น **ไม่พร้อมใช้งาน** และจะไม่ถูกเพิ่มในยอดรวม

## ค่าใช้จ่ายรวมไม่ตรงกับบิลของผู้ให้บริการของฉัน

ตัวเลขในแอปเป็น **ค่าประมาณสำหรับการอ้างอิง** ไม่ใช่ใบแจ้งหนี้ สำหรับ OpenRouter ให้ใช้ **การตั้งค่า → การติดตามค่าใช้จ่าย → ซิงค์กับการใช้งานคีย์ API**

## หน้าประวัติหายไปจากแถบด้านข้าง

**เก็บประวัติการดำเนินการ** อาจถูกปิดใช้งาน เปิดใช้งานในการตั้งค่าทั่วไป เว้นแต่ประวัติจะถูกปิดใช้งานโดยผู้ดูแลระบบ (`HISTORY_DISABLED` — ดู [การกำหนดค่า](/docs/configuration/#privacy-mode))

## เว็บ: ถูกเปลี่ยนเส้นทางไปยังการเข้าสู่ระบบโดยไม่คาดคิด

เซสชันของคุณอาจหมดอายุแล้ว เข้าสู่ระบบอีกครั้ง หากเกิดขึ้นบ่อย ให้ตรวจสอบการตั้งค่าอายุเซสชันของเซิร์ฟเวอร์

## ผู้ดูแลระบบเว็บ: ลืมรหัสผ่าน

หากผู้ดูแลระบบคนอื่นสามารถลงชื่อเข้าใช้ได้ พวกเขาสามารถรีเซ็ตรหัสผ่านได้ภายใต้ **การตั้งค่า → ผู้ใช้** หากคุณถูกล็อกไม่ให้เข้าถึงแต่มีสิทธิ์เข้าถึงเชลล์:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

ชื่อผู้ใช้ผู้ดูแลระบบเริ่มต้นคือ `admin` จากการตรวจสอบแหล่งที่มา: `pnpm run reset-web-password -- <username> <new-password>`

## แดชบอร์ดไม่แสดงข้อมูลสำหรับผู้ใช้รายอื่น (เว็บ)

เฉพาะ **ผู้ดูแลระบบ** เท่านั้นที่สามารถดูผู้ใช้รายอื่นผ่านตัวกรอง **ผู้ใช้** ผู้ใช้ทั่วไปจะเห็นเฉพาะกิจกรรมของตนเอง

## เปลี่ยนข้อความแจ้งและสูญเสียการแก้ไข

เมื่อแก้ไขข้อความแจ้งการแปลง ให้คลิก **บันทึก** ก่อน **กลับไปที่การเรียกใช้**

## เคล็ดลับด่วน

- เริ่มต้นด้วย [แปล](/docs/translate/) เพื่อยืนยันการตั้งค่าของคุณก่อนการเขียนใหม่หรือการแปลง
- ใช้ [เขียนใหม่](/docs/rewrite/) สำหรับการปรับปรุงคำพูดในชีวิตประจำวัน
- ใช้ [แปลง](/docs/transform/) สำหรับเวิร์กโฟลว์ที่กำหนดเองที่ทำซ้ำได้
- อยู่ในโหมด **ง่าย** จนกว่าคุณจะต้องการรหัสโมเดลที่ละเอียด
- ส่งออกพรอมต์เป็นประจำหากคุณกำลังสร้างไลบรารีพรอมต์
- ใช้ [แดชบอร์ด](/docs/dashboard/) และ [ประวัติ](/docs/history/) เพื่อตรวจสอบการใช้งานและการรันที่ผ่านมา
