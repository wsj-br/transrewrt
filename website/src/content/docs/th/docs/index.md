**Transrewrt** เป็นเครื่องมือข้อความที่ขับเคลื่อนด้วย AI แบบโอเพนซอร์สสำหรับ:

- **แปล** — ระหว่างหลายสิบภาษา พร้อมการตรวจจับแหล่งที่มาอัตโนมัติและอภิธานศัพท์
- **เขียนใหม่** — แก้ไขไวยากรณ์ ปรับปรุงความชัดเจน เปลี่ยนโทนเสียงหรือความยาว
- **แปลง** — เรียกใช้พร้อมต์ AI ที่กำหนดเองของคุณเองกับข้อความใดๆ

รองรับผู้ให้บริการ AI หลายราย (OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, ปลายทางที่เข้ากันได้กับ OpenAI และเซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI ในเครื่อง เช่น Ollama, LM Studio หรือ llama.cpp) เรียกใช้เป็น **แอปพลิเคชันเดสก์ท็อป** (Windows / Linux) หรือ **เว็บแอปพลิเคชัน Docker**

คีย์ของคุณ โมเดลของคุณ โฮสต์ของคุณ — ไม่มีบัญชีคลาวด์ Transrewrt

## การจัดระเบียบหน้าต่าง

![พื้นที่ทำงานการแปล](/images/screenshots/th/translate.png)

- **แถบด้านข้าง** — การนำทางหลัก: แปล, เขียนใหม่, แปลง, แดชบอร์ด, ประวัติ, การตั้งค่า (และผู้ใช้ที่เข้าสู่ระบบบนเว็บ)
- **แถบเครื่องมือ** — ชื่อหน้า, ตัวเลือก **ค่าที่ตั้งไว้ล่วงหน้า** (ง่าย) หรือ **โมเดล** (ขั้นสูง), **ภาษาของอินเทอร์เฟซ** (ไอคอนรูปโลก; ไม่เปลี่ยน แปลจาก/เป็น), และวิธีใช้ (**?**) ที่เชื่อมโยงไปยังเอกสารเหล่านี้ เมนูค่าที่ตั้งไว้ล่วงหน้า/โมเดลยังสามารถ **สลับไปโหมดง่าย/ขั้นสูง** (เหนือ เปิดการตั้งค่า)
- **พื้นที่ทำงาน** — แผงอินพุตและเอาต์พุต พร้อมจำนวน, เวลา, TPS และค่าใช้จ่ายเสริม แถบการดำเนินการแสดงลิงก์ **เวอร์ชัน** ของแอปขนาดเล็ก (ล่างขวา) ไปยังไซต์ GitHub Pages

โดยค่าเริ่มต้น แอปจะทำงานในโหมด **ง่าย**: เลือก **ค่าที่ตั้งไว้ล่วงหน้า** และ **ผู้ให้บริการ** ในการตั้งค่า สลับไปที่ **ขั้นสูง** ภายใต้ [การตั้งค่า → การตั้งค่าทั่วไป](/docs/settings/#general-settings) เพื่อดูรายการโมเดลทั้งหมด หรือใช้สวิตช์ในเมนูค่าที่ตั้งไว้ล่วงหน้า/โมเดลของแถบเครื่องมือ

## เริ่มต้นใช้งาน

1. [เริ่มต้นอย่างรวดเร็ว](/docs/quick-start/) — ติดตั้งบนเดสก์ท็อปหรือเรียกใช้ด้วย Docker
