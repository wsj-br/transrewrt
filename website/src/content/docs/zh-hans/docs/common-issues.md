如果某些功能未按预期工作，请先检查这些要点。

## 应用无法翻译、改写或转换

请检查：

- 您已在工具栏中选择了 **预设**（简易）或 **模型**（高级）
- 在 **简易** 模式下，**设置 → 通用设置** 中的 **提供商** 具有可用的密钥（或本地 LLM URL）
- 在 **高级** 模式下，**设置 → 模型** 中列出了至少一个模型
- 您的 API 设置工作正常（桌面版：**设置 → API 配置 → 测试**）

## 模型列表为空

在 **简易** 模式下，确认已设置 **提供商** 并测试了密钥/URL。对于 **本地 LLM**，请确保您的本地服务器正在运行且模型已加载。

在 **高级** 模式下，打开 **设置 → 模型**，点击 **刷新**，并将模型添加到 **已选模型**。可选择开启 **仅免费**。

## 太慢或太贵

- 选择不同的预设或模型
- 使用更短的输入
- 在常规设置中关闭 **输入时实时翻译**
- 对简单任务使用免费模型

## 界面语言错误

点击工具栏中的地球图标并选择您的 **界面语言**。

## 文本太小或难以阅读

**设置 → 常规设置** → 更改 **字体族** 和 **大小**。

## 仪表板摘要看起来为空

在以下情况下，这是正常的：

- 您只使用 **免费模型** 并且正在查看 **成本** 数据（它们可能为零）；调用次数 KPI 仍需要所选时间段的数据
- 所选的 **时间过滤器** 未覆盖进行调用的时段 — 尝试 **全部**

如果在选择 **全部** 后 KPI 仍为零，请检查[历史记录](/docs/history/) 或仪表板 → **所有调用**。

## 成本显示为“不可用”或似乎不正确

OpenRouter 在适用时会显示实际支出。对于其他提供商，成本是根据 OpenRouter 的定价估算的；如果没有匹配的价格，成本将显示为 **不可用**，并且不计入总计。

## 总成本与我的提供商账单不匹配

应用中的数据是 **供参考的估算值**，而非发票。对于 OpenRouter，请使用 **设置 → 成本跟踪 → 与 API 密钥使用情况同步**。

## 侧边栏缺少历史记录页面

**保留执行历史记录** 可能已关闭。请在通用设置中启用它，除非管理员禁用了历史记录（`HISTORY_DISABLED` — 参见[配置](/docs/configuration/#privacy-mode)）。

## 网页版：意外重定向到登录页面

您的会话可能已超时。请重新登录。如果经常发生这种情况，请检查服务器会话生命周期设置。

## 网页版管理员：忘记密码

如果其他管理员可以登录，他们可以在**设置 → 用户**下重置密码。如果您被锁定但拥有 shell 访问权限：

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

默认管理员用户名是 `admin`。从源代码检出中：`pnpm run reset-web-password -- <username> <new-password>`。

## 仪表板未显示其他用户的数据（网页版）

只有 **管理员** 可以通过 **用户** 过滤器查看其他用户。普通用户只能看到自己的活动。

## 更改了提示词并丢失了编辑内容

在编辑转换提示词时，请先点击**保存**，再点击**返回运行**。

## 快速提示

- 从[翻译](/docs/translate/) 开始，以在重写或转换之前确认您的设置
- 使用[重写](/docs/rewrite/) 进行日常用词改进
- 使用[转换](/docs/transform/) 进行可重复的自定义工作流
- 保持在 **简单** 模式，直到您需要细粒度的模型 ID
- 如果您正在构建提示词库，请定期导出提示词
- 使用[仪表板](/docs/dashboard/) 和[历史记录](/docs/history/) 查看使用情况和过去的运行记录

[Report an issue](https://github.com/wsj-br/transrewrt/issues)
