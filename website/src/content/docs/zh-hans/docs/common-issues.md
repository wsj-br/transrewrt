description: Transrewrt 的故障排除与快速提示。
---



如果运行情况与预期不符，请先检查以下几点。

## 应用无法翻译、改写或转换

请检查：

- 您已在工具栏中选择 **预设**（简单）或 **模型**（高级）
- 在 **简单**模式下，**设置 → 常规设置** 中的 **提供商** 具有有效的密钥（或本地 LLM URL）
- 在 **高级**模式下，工具栏中已选择模型（允许列表为空，但您需要在 **设置 → 模型** 中至少有一个模型才能运行）
- 您的 API 设置正常工作（桌面版：**设置 → API 配置 → 测试**）

## 模型列表为空

在 **简单**模式下，确认已设置 **提供商** 并且密钥/URL 已通过测试。对于 **本地 LLM**，请确保本地服务器正在运行且模型已加载。

在 **高级**模式下，所选模型可能为空。打开 **设置 → 模型**，点击 **刷新**，然后将模型添加到 **已选模型** 中。可选择开启 **仅免费**。移除工具栏中的最后一个模型也会打开“设置 → 模型”。

## 速度太慢或费用太高

- 选择不同的预设或模型
- 使用较短的输入
- 在常规设置中关闭 **输入时实时翻译**
- 对简单任务使用免费模型

## 界面语言错误

点击工具栏中的地球图标并选择您的 **界面语言**。

## 文本太小或难以阅读

**设置 → 常规设置** → 更改 **字体** 和 **大小**。

## 仪表盘摘要看起来为空

如果出现以下情况，这是正常的：

- 您仅使用 **免费模型** 并且正在查看 **费用** 数据（它们可能为零）；调用次数 KPI 仍需要所选时间段的数据
- 所选的 **时间过滤器** 未覆盖进行调用的时间段 — 请尝试 **全部**

如果在选择 **全部** 后 KPI 仍为零，请检查[历史记录](/docs/history/)或仪表盘 → **所有调用**。

## 费用显示“不可用”或看起来不正确

OpenRouter 会在适用时显示实际支出。对于其他提供商，费用根据 OpenRouter 定价估算；如果没有匹配的价格，费用显示为**不可用**，且不计入总计。

## 总费用与我的提供商账单不一致

应用中的数据为**仅供参考的估算**，并非发票。对于 OpenRouter，请使用**设置 → 费用跟踪 → 与 API 密钥用量同步**。

## 侧边栏缺少历史记录页面

**保留执行历史**可能已关闭。请在通用设置中启用它，除非管理员已禁用历史记录（`HISTORY_DISABLED` — 参见[配置](/docs/configuration/#privacy-mode)）。

## Web：意外重定向到登录页

您的会话可能已超时。请重新登录。如果频繁发生，请让管理员在[设置 → 用户](/docs/settings/#users)下增加**会话超时**（管理员也可能已撤销您的会话）。

## Web 管理员：忘记密码

如果另一位管理员可以登录，他们可以在**设置 → 用户**下重置密码。如果您被锁定但拥有 shell 访问权限：

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

默认管理员用户名为`admin`。从源码检出：`pnpm run reset-web-password -- <username> <new-password>`。

## 仪表板未显示其他用户的数据（Web）

只有**管理员**可以通过**用户**筛选器查看其他用户。普通用户只能看到自己的活动。

## 修改了提示词并丢失编辑

编辑 Transform 提示词时，请在**返回运行**之前点击**保存**。

## 快速提示

- 先从[翻译](/docs/translate/)开始，以在 Rewrite 或 Transform 之前确认您的设置
- 使用[Rewrite](/docs/rewrite/)进行日常用词改进
- 使用[Transform](/docs/transform/)进行可重复的自定义工作流
- 保持在**Easy**模式，直到您需要细粒度的模型 ID
- 如果您正在构建提示词库，请定期导出提示词
- 使用[仪表板](/docs/dashboard/)和[历史记录](/docs/history/)查看用量和过往运行

[Report an issue](https://github.com/wsj-br/transrewrt/issues)
