使用 **仪表板** 查看应用的使用量及成本（针对付费模型）。

![仪表板摘要](/images/screenshots/zh-Hans/dashboard-summary.png)

:::note
如果您使用免费模型、提供商不支持成本跟踪，或者您正在使用本地 LLM，成本金额可能会显示为 **$0**。**摘要** 上的调用次数 KPI 始终反映实际使用情况——只有在所选期间内没有任何活动时，它们才会为零。
:::

## 筛选数据

使用顶部的筛选按钮更改时间范围。

**用户** 筛选器仅在 Web 版本中对管理员可见；在桌面版上不可用。

## 标签页

- **摘要** — KPI：总成本、已用模型、各模式调用次数和成本、每次调用平均成本、平均 TPS、按调用次数排名的顶级模型
- **按模型** — 各模型的调用次数、成本和 TPS；展开某一行可查看模式细分
- **所有调用** — 完整调用日志（分页或卡片形式），支持导出

## 导出数据

将表格导出为 **JSON**、**CSV** 或 **XLSX**。

## 删除模型的存储记录

在 **按模型** 或 **所有调用** 中，使用垃圾桶图标移除某个模型的记录。

:::caution
删除操作无法撤销。要按时间删除或清除所有成本数据，请使用[设置 → 成本跟踪](/docs/settings/#cost-tracking)。
:::
