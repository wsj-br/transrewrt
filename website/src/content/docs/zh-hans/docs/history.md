打开**历史**以查看过去的操作，包括每次运行的输入和输出。

![历史页面](/images/screenshots/zh-Hans/history.png)

历史使用与[仪表板](/docs/dashboard/)相同的时间范围筛选器。

:::note
在**Web 应用**中，所有人（包括管理员）只能看到自己的执行历史。仪表板的**用户**筛选器在此处不适用。
:::

## 导出

将筛选后的列表导出为 **JSON**、**CSV** 或 **XLSX**。

## 如果历史记录缺失

**保留执行历史**可能已关闭。在[设置 → 常规设置](/docs/settings/#general-settings)中启用它，除非管理员设置了 `HISTORY_DISABLED` — 参见[配置](/docs/configuration/#privacy-mode)。
