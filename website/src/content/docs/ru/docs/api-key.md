Transrewrt требуется доступ хотя бы к одному поставщику ИИ. Вам **не** нужна платная модель для начала: OpenRouter предлагает бесплатные модели после добавления ключа, и несколько других поставщиков также предлагают бесплатные тарифы.

Поддерживаемые провайдеры включают [OpenRouter](https://openrouter.ai), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, любой совместимый с OpenAI конечную точку и локальные серверы, совместимые с OpenAI (Ollama, LM Studio, llama.cpp и аналогичные).

## Простой и расширенный режимы

- **Легкий** режим (по умолчанию): выберите **предустановку** (Бесплатный (OpenRouter), Стандартный, Расширенный или Технический), сопоставленный с **провайдером**. Отображаются только предустановки с сопоставлением для текущего провайдера.
- **Расширенный** режим: выберите модели напрямую. Идентификаторы моделей используют префикс провайдера (например, `openrouter/…`, `openai/…`, `local/…`).

## Бесплатный ключ OpenRouter (для настольных ПК)

1. Перейдите на [openrouter.ai](https://openrouter.ai) и зарегистрируйтесь или войдите в систему.
2. Откройте страницу [Ключи](https://openrouter.ai/keys) и создайте новый ключ (дайте ему имя; необязательный кредитный лимит). Вы можете использовать бесплатные модели без добавления кредита.
3. В Transrewrt откройте **Настройки → Конфигурация API**, вставьте ключ в поле **Ключ API OpenRouter** и нажмите **Проверить ключ OpenRouter**.

:::caution
Не используйте модель **Body Builder** OpenRouter (`openrouter/bodybuilder`) для перевода, переписывания или преобразования — она возвращает полезные данные запроса JSON, а не завершенный текст.
:::

## Другие бесплатные варианты

Вы также можете получить бесплатные ключи API от Cerebras, Google, Groq, Mistral AI или [NVIDIA](https://build.nvidia.com/) (API, совместимый с OpenAI), либо запустить модели локально с помощью Ollama, LM Studio, llama.cpp или другого сервера, совместимого с OpenAI (например, `translategemma:4b` через Ollama). Установите базовый URL-адрес локального LLM на полный базовый API (включите путь, например, `http://localhost:11434/v1`) в настройках (для настольных компьютеров) или `LOCAL_LLM_URL` (для Docker).

:::caution
Если вы используете локальный сервер LLM с другого устройства или контейнера, настройте его для разрешения внешних подключений (не только localhost).
:::

## Docker / веб

Установите ключи провайдера в качестве **переменных среды** на сервере (например, `PROVIDER_API_KEY`). Пользователи не могут вводить ключи в пользовательском интерфейсе браузера. См. [Конфигурация](/docs/configuration/).

## Контрольный список первого запуска

1. Откройте приложение и при необходимости установите **Язык интерфейса**.
2. Добавьте и протестируйте хотя бы один ключ провайдера (для настольной версии) или убедитесь, что на сервере есть ключи среды (для веб-версии).
3. В режиме **Easy** выберите **Провайдера** в общих настройках; в режиме **Advanced** добавьте модели в разделе **Настройки → Модели**.
4. На вкладке **Перевод** выберите предустановку или модель и запустите короткий тест — см. [Перевод текста](/docs/translate/).
