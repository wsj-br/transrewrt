## Расположение файлов конфигурации

| Развертывание | Папка данных |
| --- | --- |
| Electron (Windows) | `%APPDATA%\transrewrt\` |
| Electron (Linux) | `~/.config/transrewrt/` |
| Веб / Docker | `/app/data/` (используйте том для сохранения) |

Папка данных содержит все, что стоит резервировать:

- `config.json` — настройки и (настольные) зашифрованные ключи API
- `state.json` — последние использованные языки, модель и состояние представления
- `presets.json` — кэшированный каталог предустановок Easy-mode
- `transrewrt.db` — база данных SQLite с историей, затратами, подсказками, глоссарием и (веб) пользователями

Вы также можете создать переносимый ZIP-архив резервной копии из приложения — см. [Настройки → Общие настройки](/docs/settings/#general-settings).

## Сохранение данных (Docker)

Подключите том по пути `/app/data`, чтобы файлы конфигурации и база данных SQLite (см. [Расположение файлов конфигурации](#config-file-locations)) сохранялись после перезапуска контейнера. Без тома данные теряются при остановке контейнера.

## Переменные среды (веб / Docker)

Electron использует локальный файл конфигурации. Только для веб-сервера/сервера Docker:

| Переменная | Описание |
| --- | --- |
| `PORT` | Порт прослушивания сервера (по умолчанию `5000`) |
| `CONFIG_PATH` | Путь к файлу конфигурации (по умолчанию `/app/data/config.json`) |
| `TZ` | Часовой пояс для серверного времени (по умолчанию `Europe/London`) |
| `HISTORY_DISABLED` | Принудительное отключение истории выполнения (`true` / `1`) |
| `OPENROUTER_API_KEY` | Ключ API OpenRouter |
| `OPENAI_API_KEY` | Ключ API OpenAI |
| `CEREBRAS_API_KEY` | Ключ API Cerebras |
| `ANTHROPIC_API_KEY` | Ключ API Anthropic |
| `GOOGLE_API_KEY` | Ключ API Google Gemini |
| `DEEPSEEK_API_KEY` | Ключ API DeepSeek |
| `GROQ_API_KEY` | Ключ API Groq |
| `MISTRAL_API_KEY` | Ключ API Mistral |
| `LOCAL_LLM_URL` | Полный базовый URL-адрес API, совместимого с OpenAI, для локального сервера, включая путь (например, Ollama `http://host.docker.internal:11434/v1`, LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | Ключ API xAI |
| `NVIDIA_API_KEY` | Ключ API NVIDIA |
| `ALIBABA_API_KEY` | Ключ API Alibaba Cloud (DashScope) |
| `APIFUN_API_KEY` | Ключ API apikey.fun |
| `CUSTOM_PROVIDER_NAME` | Отображаемое имя для пользовательского провайдера, совместимого с OpenAI |
| `CUSTOM_PROVIDER_URL` | Базовый URL-адрес для пользовательского провайдера, совместимого с OpenAI |
| `CUSTOM_PROVIDER_API_KEY` | Ключ API для пользовательского провайдера |

Все три переменные `CUSTOM_PROVIDER_*` обязательны при использовании пользовательской конечной точки. Модели отображаются в режиме **Advanced** как `{providerName}/…`.

## Переменные среды (для настольных ПК)

| Переменная | Описание |
| --- | --- |
| `TRANSREWRT_DISABLE_GPU` | Установите значение `1`, чтобы отключить аппаратное ускорение (полезно, когда Chromium выводит ошибки GPU / EGL в Linux) |
| `HISTORY_DISABLED` | Принудительное отключение истории выполнения (`true` / `1`) — см. [Режим конфиденциальности](#privacy-mode) |

## Режим конфиденциальности

Установите `HISTORY_DISABLED` в `true` или `1` в процессе веб-сервера/Docker и/или в основном процессе Electron, чтобы принудительно отключить историю независимо от `config.json` или пользовательских настроек. Это отключает хранение истории ввода/вывода, блокирует **Настройки → Общие настройки → История** и блокирует API, связанные с историей.

## Веб-аутентификация

- Администратор по умолчанию: `admin` / `transrewrt26`
- Управление пользователями, временем ожидания сеанса и отзывом сеанса в разделе **Настройки → Пользователи** — см. [Настройки](/docs/settings/#users)
- Каждый вошедший в систему пользователь может изменить свой пароль или выйти из системы через меню пользователя в нижней части боковой панели.
- Сброс пароля:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
Немедленно измените пароль администратора по умолчанию на любом доступном по сети хосте.
:::

:::caution
Сервер использует обычный HTTP. Если вы предоставляете к нему доступ за пределами localhost или доверенной сети, разместите его за обратным прокси-сервером с HTTPS (например, Caddy, nginx или Traefik), чтобы пароли и текст не передавались в открытом виде.
:::

## Отображение стоимости

OpenRouter возвращает точную стоимость по счету, если применимо. Другие провайдеры используют **ориентировочную** стоимость из публичных цен моделей OpenRouter, если доступен ключ OpenRouter. Оценки не являются счетами.

Для пользовательского интерфейса настроек (шрифты, модели, история, резервные копии) см. [Настройки](/docs/settings/).
