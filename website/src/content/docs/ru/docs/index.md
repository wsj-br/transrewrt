**Transrewrt** — это текстовый инструмент на базе ИИ с открытым исходным кодом для:

- **Перевода** — между десятками языков, с автоматическим определением источника и глоссариями
- **Переписывания** — исправление грамматики, улучшение ясности, изменение тона или длины
- **Трансформации** — запуск собственных пользовательских запросов ИИ на любом тексте

Он поддерживает множество поставщиков ИИ (OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, совместимые с OpenAI конечные точки и локальные совместимые с OpenAI серверы, такие как Ollama, LM Studio или llama.cpp). Запустите его как **настольное приложение** (Windows / Linux) или **веб-приложение Docker**.

Ваши ключи, ваши модели, ваш хост — облачной учетной записи Transrewrt нет.

## Как организовано окно

![Рабочая область перевода](/images/screenshots/ru/translate.png)

- **Боковая панель** — основная навигация: Translate (Перевести), Rewrite (Переписать), Transform (Преобразовать), Dashboard (Панель управления), History (История), Settings (Настройки) (и вошедший в систему пользователь в веб-версии).
- **Панель инструментов** — заголовок страницы, селектор **пресета** (Easy) или **модели** (Advanced), **Язык интерфейса** (значок глобуса; не меняет Translate From/To) и Help (Помощь) (**?**), ведущая к этой документации. Меню пресетов/моделей также может **Переключиться в режим Easy/Advanced** (над Open Settings).
- **Рабочая область** — панели ввода и вывода с подсчетами, временем, TPS и опциональной стоимостью. Панель действий показывает небольшую ссылку на **версию** приложения (внизу справа) на сайт GitHub Pages.

По умолчанию приложение работает в **Простом** режиме: выберите **пресет** и **Провайдера** в Настройках. Переключитесь на **Расширенный** в [Настройки → Общие настройки](/docs/settings/#general-settings) для полного списка моделей или используйте переключатель в меню пресетов/моделей на панели инструментов.
