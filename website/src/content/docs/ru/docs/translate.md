Используйте **Перевести** для преобразования текста с одного языка на другой.

![Рабочая область перевода](/images/screenshots/ru/translate.png)

## Предварительные условия

- Как минимум один ключ провайдера (для настольной версии) или ключ серверной среды (для веб-версии) — см. [Ключ API](/docs/api-key/)
- Выбранный **пресет** (простой) или **модель** (расширенный) на панели инструментов

## Перевести текст

1. Откройте **Перевести** на боковой панели.
2. Выберите язык в поле **Из** (или **Определить язык**).
3. Выберите язык в поле **В**.
4. Выберите пресет или модель на панели инструментов.
5. Введите или вставьте текст в поле **Ввод**.
6. Нажмите **Перевести**.
7. Прочитайте результат в поле **Вывод**, затем скопируйте, если необходимо.

**Основные языки** отображаются первыми в списках — их можно настроить в [Настройки → Языки](/docs/settings/#languages).

## Полезные настройки

В [Настройки → Общие настройки](/docs/settings/#general-settings):

- **Автоматическое выполнение при вставке** — запускается сразу после вставки
- **Автоматическое копирование результата в буфер обмена** — копирует после успешного выполнения
- **Перевод в реальном времени во время набора текста** — запускается во время набора текста (может увеличить стоимость)
- **Тайм-аут (мс)** — задержка перед запуском в реальном времени
- **Поведение для ENTER** — определяет, запускает ли Enter задачу или вставляет новую строку

## Макет и клавиатура

- **Переключатель макета** — кнопки над панелями переключают между **рядом** и **стопкой** макетов ввода/вывода. Выбор применяется к функциям «Перевести», «Переписать» и «Преобразовать» и запоминается на этом устройстве.
- **Enter** или **Shift+Enter** запускает задачу, в зависимости от **Поведения для ENTER** (см. выше).
- **Escape** очищает панель ввода (или сначала закрывает открытое меню или диалоговое окно).

## Уточнить перевод

После успешного выполнения рядом с селектором **Кому:** появляются **Перефразировать…** и выпадающий список версий:

1. **Перефразировать…** (без выбора) — еще один полный перевод того же ввода. До **пяти** версий; модель видит предыдущие версии, поэтому формулировка может отличаться. Нажмите **Остановить перевод**, чтобы отменить выполняющееся перефразирование.
2. **Альтернативы слов** — выберите слова или короткую фразу, затем щелкните правой кнопкой мыши или **Перефразировать…**. Выберите альтернативу для замены выделенного фрагмента (может немного расшириться для грамматики). При пяти версиях обновляется только версия 5.
3. Каждый запрос на перефразирование или альтернативы снова использует модель и может увеличить стоимость.

## Использование глоссария

**Глоссарий** — это пары терминов источник/цель для языковой пары. При включении соответствующие термины отправляются в модель, чтобы предпочтительная формулировка оставалась согласованной.

1. Включите **Глоссарий** на панели ввода.
2. Переводите как обычно — термины для этой пары **С** / **На** применяются автоматически.
3. Нажмите **Добавить в глоссарий** (рядом с **С:**), чтобы быстро добавить новую пару.
4. Управляйте всеми терминами в [Настройки → Глоссарий](/docs/settings/#glossary).

:::note
Термины глоссария сопоставляются по языковой паре. Их нельзя использовать с функцией **Определить язык** в качестве исходного языка.
:::
