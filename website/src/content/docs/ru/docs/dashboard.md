Используйте **Панель мониторинга**, чтобы увидеть, насколько вы используете приложение и сколько это стоит (для платных моделей).

![Сводка панели мониторинга](/images/screenshots/ru/dashboard-summary.png)

:::note
Суммы затрат могут отображаться как **$0**, если вы используете бесплатные модели, поставщик не поддерживает отслеживание затрат или вы используете локальную LLM. Показатели KPI по количеству вызовов в разделе **Сводка** отражают фактическое использование независимо от этого — они равны нулю только в том случае, если в выбранный период не было активности.
:::

## Фильтрация данных

Используйте кнопки фильтра вверху, чтобы изменить временной диапазон.

Фильтр **Пользователь** виден только администраторам в веб-версии; он недоступен на настольных компьютерах.

## Вкладки

- **Сводка** — KPI: общая стоимость, используемые модели, количество вызовов и стоимость по моделям, средняя стоимость вызова, среднее количество TPS, лучшие модели по количеству вызовов
- **По модели** — вызовы, стоимость и TPS по моделям; разверните строку для детализации по режимам
- **Все вызовы** — полный журнал вызовов (страничный или карточный) с экспортом

## Экспорт данных

Экспортируйте таблицы в форматах **JSON**, **CSV** или **XLSX**.

## Удаление сохраненных записей для модели

В разделах **По модели** или **Все вызовы** используйте значок корзины, чтобы удалить записи для модели.

:::caution
Удаление нельзя отменить. Чтобы удалить по возрасту или очистить все данные о затратах, используйте [Настройки → Отслеживание затрат](/docs/settings/#cost-tracking).
:::
