Используйте **Панель мониторинга**, чтобы узнать, сколько вы используете приложение и сколько это стоит (для платных моделей).

![Сводка панели мониторинга](/images/screenshots/ru/dashboard-summary.png)

:::note
Если вы используете только **бесплатные** модели, суммы затрат могут быть нулевыми. KPI количества вызовов в разделе **Сводка** по-прежнему требуют активности в выбранном периоде.
:::

## Фильтрация данных

Используйте кнопки фильтра вверху, чтобы изменить временной диапазон.

:::note
Фильтр **Пользователь** виден только администраторам в веб-версии. Он недоступен на настольных компьютерах.
:::

## Вкладки

- **Сводка** — KPI: общая стоимость, используемые модели, количество вызовов и стоимость по режимам, средняя стоимость вызова, среднее количество TPS, лучшие модели по количеству вызовов
- **По модели** — вызовы, стоимость и TPS по моделям; разверните строку для детализации по режимам
- **Все вызовы** — полный журнал вызовов (страничный или карточный) с экспортом

## Экспорт данных

Экспортируйте таблицы в форматах **JSON**, **CSV** или **XLSX**.

## Удаление сохраненных записей для модели

В разделах **По модели** или **Все вызовы** используйте значок корзины, чтобы удалить записи для модели.

:::caution
Удаление невозможно отменить. Чтобы удалить по возрасту или очистить все данные о затратах, используйте [Настройки → Отслеживание затрат](/docs/settings/#cost-tracking).
:::
