Если что-то работает не так, как ожидалось, сначала проверьте эти пункты.

## Приложение не переводит, не переписывает и не преобразует текст

Убедитесь, что:

- вы выбрали **пресет** (Easy) или **модель** (Advanced) на панели инструментов
- в режиме **Easy** в разделе **Settings → General Settings** указан **Provider** с рабочим ключом (или URL-адресом локальной LLM)
- в режиме **Advanced** в разделе **Settings → Models** указана хотя бы одна модель
- ваша настройка API работает (для настольной версии: **Settings → API Config → Test**)

## Список моделей пуст

В режиме **Easy** убедитесь, что **Provider** настроен, а ключи/URL-адреса проверены. Для **Local LLM** убедитесь, что ваш локальный сервер запущен и модели загружены.

В **расширенном** режиме откройте **Настройки → Модели**, нажмите **Обновить** и добавьте модели в **Выбранные модели**. При желании включите **Только бесплатные**.

## Слишком медленно или слишком дорого

- Выберите другой пресет или модель
- Используйте более короткий ввод
- Отключите **Перевод в реальном времени во время набора текста** в общих настройках
- Используйте бесплатные модели для простых задач

## Неправильный язык интерфейса

Нажмите значок глобуса на панели инструментов и выберите **Язык интерфейса**.

## Слишком мелкий или трудночитаемый текст

**Настройки → Общие настройки** → измените **Семейство шрифтов** и **Размер**.

## Сводка на панели мониторинга выглядит пустой

Это нормально, если:

- вы используете только **бесплатные модели** и смотрите на показатели **стоимости** (они могут быть нулевыми); для KPI количества вызовов все еще нужны данные за выбранный период
- выбранный **фильтр времени** не охватывает время выполнения вызовов — попробуйте **Все**

Если KPI по-прежнему равны нулю после выбора **Все**, проверьте [Историю](/docs/history/) или Панель мониторинга → **Все вызовы**.

## Стоимость отображается как «недоступно» или кажется неверной

OpenRouter показывает фактические расходы, если применимо. Для других провайдеров стоимость оценивается по ценам OpenRouter; если цена не соответствует, стоимость отображается как **недоступно** и не добавляется к общей сумме.

## Общая стоимость не соответствует счету моего провайдера

Цифры в приложении являются **оценочными для справки**, а не счетами. Для OpenRouter используйте **Настройки → Отслеживание затрат → Синхронизировать с использованием ключа API**.

## Страница истории отсутствует на боковой панели

Возможно, отключена опция **Сохранять историю выполнения**. Включите ее в Общих настройках, если история не отключена администратором (`HISTORY_DISABLED` — см. [Конфигурация](/docs/configuration/#privacy-mode)).

## Веб: неожиданно перенаправлено на страницу входа

Возможно, время вашей сессии истекло. Войдите снова. Если это происходит часто, проверьте настройки времени жизни сессии сервера.

## Веб-администратор: забыл пароль

Если другой администратор может войти в систему, он может сбросить пароль в разделе **Настройки → Пользователи**. Если вы заблокированы, но имеете доступ к оболочке:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Имя пользователя администратора по умолчанию — `admin`. Из исходного кода: `pnpm run reset-web-password -- <username> <new-password>`.

## Панель мониторинга не показывает данные для других пользователей (веб)

Только **администраторы** могут просматривать других пользователей с помощью фильтра **Пользователь**. Обычные пользователи видят только свою активность.

## Изменили подсказку и потеряли изменения

При редактировании подсказки Transform нажмите **Сохранить** перед **Назад к запуску**.

## Краткие советы

- Начните с [Перевода](/docs/translate/), чтобы подтвердить свои настройки перед Перезаписью или Преобразованием
- Используйте [Перезапись](/docs/rewrite/) для повседневных улучшений формулировок
- Используйте [Преобразование](/docs/transform/) для повторяющихся пользовательских рабочих процессов
- Оставайтесь в режиме **Простой**, пока вам не понадобятся точные идентификаторы моделей
- Регулярно экспортируйте промпты, если вы создаете библиотеку промптов
- Используйте [Панель мониторинга](/docs/dashboard/) и [Историю](/docs/history/) для просмотра использования и прошлых запусков
