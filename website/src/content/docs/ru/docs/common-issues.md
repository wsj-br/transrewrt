title: Частые проблемы
description: Устранение неполадок и быстрые советы для Transrewrt.
---



Если что-то работает не так, как ожидалось, сначала проверьте следующие пункты.

## Приложение не переводит, не переписывает и не трансформирует

Убедитесь, что:

- вы выбрали **пресет** (Easy) или **модель** (Advanced) на панели инструментов
- в режиме **Easy** в разделе **Settings → General Settings** указан **Provider** с рабочим ключом (или URL локальной LLM)
- в режиме **Advanced** на панели инструментов выбрана модель (пустой список допустим, но для запуска вам нужна хотя бы одна модель в **Settings → Models**)
- ваша настройка API работает (для настольных ПК: **Settings → API Config → Test**)

## Список моделей пуст

В режиме **Easy** убедитесь, что **Provider** установлен, а ключи/URL протестированы. Для **Local LLM** убедитесь, что ваш локальный сервер запущен и модели загружены.

В режиме **Advanced** выбранные модели могут быть пустыми. Откройте **Settings → Models**, нажмите **Refresh** и добавьте модели в **Selected Models**. При желании включите **Free Only**. Удаление последней модели с панели инструментов также открывает Settings → Models.

## Слишком медленно или слишком дорого

- Выберите другой пресет или модель
- Используйте более короткий ввод
- Отключите **Real-time translation while typing** в General Settings
- Используйте бесплатные модели для простых задач

## Неправильный язык интерфейса

Нажмите значок глобуса на панели инструментов и выберите **Interface language**.

## Текст слишком мелкий или трудночитаемый

**Settings → General Settings** → измените **Font Family** и **Size**.

## Сводка на панели мониторинга выглядит пустой

Это нормально, если:

- вы используете только **бесплатные модели** и смотрите на показатели **стоимости** (они могут быть нулевыми); для KPI количества вызовов все еще нужны данные за выбранный период
- выбранный **фильтр времени** не охватывает период, когда были сделаны вызовы — попробуйте **All**

Если KPI все еще равны нулю после **All**, проверьте [History](/docs/history/) или Dashboard → **All Calls**.

## Стоимость показывает «недоступно» или кажется неверной

OpenRouter показывает фактические расходы, если применимо. Для других провайдеров стоимость оценивается по ценам OpenRouter; если цена не найдена, стоимость отображается как **недоступна** и не добавляется к общей сумме.

## Общая стоимость не соответствует счету провайдера

Цифры в приложении являются **оценочными для справки**, а не счетами. Для OpenRouter используйте **Настройки → Отслеживание затрат → Синхронизация с использованием ключа API**.

## Страница «История» отсутствует в боковой панели

Возможно, отключена функция **Сохранять историю выполнения**. Включите ее в Общих настройках, если история не отключена администратором (`HISTORY_DISABLED` — см. [Конфигурация](/docs/configuration/#privacy-mode)).

## Веб: неожиданно перенаправляет на страницу входа

Возможно, время вашей сессии истекло. Войдите снова. Если это происходит часто, попросите администратора увеличить **Время ожидания сессии** в разделе [Настройки → Пользователи](/docs/settings/#users) (администратор также мог отозвать ваши сессии).

## Веб-администратор: забыл пароль

Если другой администратор может войти в систему, он может сбросить пароль в разделе **Настройки → Пользователи**. Если вы заблокированы, но имеете доступ к оболочке:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

Имя пользователя администратора по умолчанию — `admin`. Из исходного кода: `pnpm run reset-web-password -- <username> <new-password>`.

## Панель мониторинга не показывает данные для других пользователей (веб)

Только **администраторы** могут просматривать других пользователей с помощью фильтра **Пользователь**. Обычные пользователи видят только свою активность.

## Изменил промпт и потерял изменения

При редактировании промпта Transform нажмите **Сохранить** перед **Назад к запуску**.

## Краткие советы

- Начните с [Перевести](/docs/translate/), чтобы подтвердить настройки перед использованием Переписать или Преобразовать
- Используйте [Переписать](/docs/rewrite/) для повседневных улучшений формулировок
- Используйте [Преобразовать](/docs/transform/) для повторяющихся пользовательских рабочих процессов
- Оставайтесь в режиме **Простой**, пока вам не понадобятся точные идентификаторы моделей
- Регулярно экспортируйте промпты, если вы создаете библиотеку промптов
- Используйте [Панель мониторинга](/docs/dashboard/) и [История](/docs/history/) для просмотра использования и прошлых запусков
