از **داشبورد** برای مشاهده میزان استفاده از برنامه و هزینه آن (برای مدل‌های پولی) استفاده کنید.

![خلاصه داشبورد](/images/screenshots/fa/dashboard-summary.png)

:::note
اگر فقط از مدل‌های **رایگان** استفاده می‌کنید، ممکن است مبالغ هزینه صفر باشد. KPIهای تعداد تماس در **خلاصه** همچنان به فعالیت در دوره انتخابی نیاز دارند.
:::

## فیلتر کردن داده‌ها

از دکمه‌های فیلتر در بالا برای تغییر محدوده زمانی استفاده کنید.

:::note
فیلتر **کاربر** فقط برای مدیران در نسخه وب قابل مشاهده است. در دسکتاپ در دسترس نیست.
:::

## برگه‌ها

- **خلاصه** — KPIها: هزینه کل، مدل‌های استفاده شده، تعداد تماس‌ها و هزینه به ازای هر حالت، میانگین هزینه به ازای هر تماس، میانگین TPS، مدل‌های برتر بر اساس تعداد تماس
- **بر اساس مدل** — تماس‌ها، هزینه و TPS به ازای هر مدل؛ یک ردیف را برای تفکیک حالت گسترش دهید
- **همه تماس‌ها** — گزارش کامل تماس (صفحه‌بندی شده یا کارت‌ها) با قابلیت خروجی گرفتن

## خروجی گرفتن از داده‌ها

جداول را به صورت **JSON**، **CSV** یا **XLSX** خروجی بگیرید.

## حذف رکوردهای ذخیره‌شده برای یک مدل

در **بر اساس مدل** یا **همه تماس‌ها**، از نماد سطل زباله برای حذف رکوردها برای یک مدل استفاده کنید.

:::caution
حذف قابل بازگشت نیست. برای حذف بر اساس سن یا پاک کردن تمام داده‌های هزینه، از [تنظیمات ← ردیابی هزینه](/docs/settings/#cost-tracking) استفاده کنید.
:::
