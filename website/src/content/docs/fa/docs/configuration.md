## مکان‌های فایل پیکربندی

| استقرار | پوشه داده |
| --- | --- |
| Electron (ویندوز) | `%APPDATA%\transrewrt\` |
| Electron (لینوکس) | `~/.config/transrewrt/` |
| وب / داکر | `/app/data/` (برای پایداری از یک volume استفاده کنید) |

پوشه داده شامل هر چیزی است که ارزش پشتیبان‌گیری دارد:

- `config.json` — تنظیمات و کلیدهای API رمزگذاری شده (دسکتاپ)
- `state.json` — زبان‌های آخرین استفاده، مدل، و وضعیت نمایش
- `presets.json` — کاتالوگ از پیش تنظیم شده حالت آسان کش شده
- `transrewrt.db` — پایگاه داده SQLite با تاریخچه، هزینه‌ها، درخواست‌ها، واژه‌نامه، و کاربران (وب)

همچنین می‌توانید یک فایل ZIP پشتیبان قابل حمل از برنامه ایجاد کنید — به [تنظیمات ← تنظیمات عمومی](/docs/settings/#general-settings) مراجعه کنید.

## متغیرهای محیطی (وب / داکر)

Electron از فایل پیکربندی محلی استفاده می‌کند. فقط برای سرور وب/داکر:

| متغیر | توضیحات |
| --- | --- |
| `PORT` | پورت گوش دادن سرور (پیش‌فرض `5000`) |
| `CONFIG_PATH` | مسیر فایل پیکربندی (پیش‌فرض `/app/data/config.json`) |
| `TZ` | منطقه زمانی برای زمان سمت سرور (پیش‌فرض `Europe/London`) |
| `HISTORY_DISABLED` | اجبار خاموش کردن تاریخچه اجرا (`true` / `1`) |
| `OPENROUTER_API_KEY` | کلید API OpenRouter |
| `OPENAI_API_KEY` | کلید API OpenAI |
| `CEREBRAS_API_KEY` | کلید API Cerebras |
| `ANTHROPIC_API_KEY` | کلید API Anthropic |
| `GOOGLE_API_KEY` | کلید API Google Gemini |
| `DEEPSEEK_API_KEY` | کلید API دیپ‌سیک (DeepSeek) |
| `GROQ_API_KEY` | کلید API گروک (Groq) |
| `MISTRAL_API_KEY` | کلید API میسترال (Mistral) |
| `LOCAL_LLM_URL` | URL پایه API سازگار با OpenAI برای یک سرور محلی، شامل مسیر (به عنوان مثال Ollama `http://host.docker.internal:11434/v1`، LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | کلید API ایکس‌ای‌آی (xAI) |
| `NVIDIA_API_KEY` | کلید API انویدیا (NVIDIA) |
| `ALIBABA_API_KEY` | کلید API علی‌بابا کلود (دش‌اسکوپ) |
| `APIFUN_API_KEY` | کلید API apikey.fun |
| `CUSTOM_PROVIDER_NAME` | نام نمایشی برای یک ارائه‌دهنده سفارشی سازگار با OpenAI |
| `CUSTOM_PROVIDER_URL` | URL پایه برای یک ارائه‌دهنده سفارشی سازگار با OpenAI |
| `CUSTOM_PROVIDER_API_KEY` | کلید API برای ارائه‌دهنده سفارشی |

هر سه متغیر `CUSTOM_PROVIDER_*` هنگام استفاده از یک نقطه پایانی سفارشی مورد نیاز هستند. مدل‌ها در حالت **پیشرفته** به صورت `{providerName}/…` ظاهر می‌شوند.

## متغیرهای محیطی (دسکتاپ)

| متغیر | توضیحات |
| --- | --- |
| `TRANSREWRT_DISABLE_GPU` | برای غیرفعال کردن شتاب‌دهنده سخت‌افزاری روی `1` تنظیم شود (هنگامی که کرومیوم خطاهای GPU / EGL را در لینوکس چاپ می‌کند مفید است) |
| `HISTORY_DISABLED` | اجبار غیرفعال کردن تاریخچه اجرا (`true` / `1`) — به [حالت حریم خصوصی](#privacy-mode) مراجعه کنید |

## حالت حریم خصوصی

`HISTORY_DISABLED` را روی `true` یا `1` در فرآیند سرور وب/داکر و/یا فرآیند اصلی الکترون تنظیم کنید تا تاریخچه بدون توجه به `config.json` یا تنظیمات برگزیده هر کاربر، اجباراً غیرفعال شود. این کار ذخیره تاریخچه ورودی/خروجی را غیرفعال می‌کند، **تنظیمات ← تنظیمات عمومی ← تاریخچه** را قفل می‌کند و APIهای مربوط به تاریخچه را مسدود می‌کند.

## پایداری داده (داکر)

یک ولوم را در `/app/data` مونت کنید تا فایل‌های پیکربندی و پایگاه داده SQLite (به [مکان‌های فایل پیکربندی](#config-file-locations) مراجعه کنید) پس از راه‌اندازی مجدد کانتینر باقی بمانند. بدون ولوم، داده‌ها هنگام توقف کانتینر از بین می‌روند.

## احراز هویت وب

- مدیر پیش‌فرض: `admin` / `transrewrt26`
- کاربران، زمان‌بندی نشست و لغو نشست را در **تنظیمات ← کاربران** مدیریت کنید — به [تنظیمات](/docs/settings/#users) مراجعه کنید
- هر کاربر وارد شده می‌تواند رمز عبور خود را تغییر دهد یا از منوی کاربر در پایین نوار کناری خارج شود
- بازنشانی رمز عبور:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
رمز عبور مدیر پیش‌فرض را بلافاصله در هر هاست قابل دسترسی از طریق شبکه تغییر دهید.
:::

:::caution
سرور از HTTP ساده استفاده می‌کند. اگر آن را فراتر از localhost یا یک شبکه مورد اعتماد در معرض دید قرار می‌دهید، آن را پشت یک پروکسی معکوس با HTTPS (مانند Caddy، nginx یا Traefik) قرار دهید تا رمزهای عبور و متن به صورت واضح ارسال نشوند.
:::

## نمایش هزینه

OpenRouter در صورت لزوم هزینه دقیق صورت‌حساب شده را برمی‌گرداند. سایر ارائه‌دهندگان از هزینه **تخمینی** از قیمت‌گذاری مدل عمومی OpenRouter استفاده می‌کنند، زمانی که کلید OpenRouter در دسترس باشد. تخمین‌ها صورت‌حساب نیستند.

برای رابط کاربری تنظیمات (فونت‌ها، مدل‌ها، تاریخچه، پشتیبان‌گیری)، به [تنظیمات](/docs/settings/) مراجعه کنید.
