اگر چیزی طبق انتظار کار نمی‌کند، ابتدا این نکات را بررسی کنید.

## برنامه ترجمه، بازنویسی یا تبدیل نمی‌کند

بررسی کنید که:

- شما یک **پیش‌تنظیم** (آسان) یا **مدل** (پیشرفته) را در نوار ابزار انتخاب کرده‌اید
- در حالت **آسان**، **تنظیمات → تنظیمات عمومی** دارای یک **تأمین‌کننده** با یک کلید کارا (یا URL LLM محلی) است
- در حالت **پیشرفته**، حداقل یک مدل در **تنظیمات → مدل‌ها** فهرست شده است
- تنظیمات API شما کار می‌کند (رایانه: **تنظیمات → پیکربندی API → آزمایش**)

## لیست مدل‌ها خالی است

در حالت **آسان**، تأیید کنید که **تأمین‌کننده** تنظیم شده و کلیدها/URLها آزمایش شده‌اند. برای **LLM محلی**، اطمینان حاصل کنید که سرور محلی شما در حال اجرا است و مدل‌ها بارگذاری شده‌اند.

در حالت **پیشرفته**، **تنظیمات ← مدل‌ها** را باز کنید، روی **تازه‌سازی** کلیک کنید و مدل‌ها را به **مدل‌های انتخاب شده** اضافه کنید. به صورت اختیاری **فقط رایگان** را روشن کنید.

## خیلی کند یا خیلی گران

- یک پیش‌تنظیم یا مدل متفاوت انتخاب کنید
- از ورودی کوتاه‌تر استفاده کنید
- **ترجمه بلادرنگ هنگام تایپ** را در تنظیمات عمومی خاموش کنید
- برای کارهای ساده از مدل‌های رایگان استفاده کنید

## زبان رابط کاربری اشتباه است

روی نماد کره زمین در نوار ابزار کلیک کنید و **زبان رابط کاربری** خود را انتخاب کنید.

## متن خیلی کوچک یا خواندن آن دشوار است

**تنظیمات ← تنظیمات عمومی** ← **خانواده فونت** و **اندازه** را تغییر دهید.

## خلاصه داشبورد خالی به نظر می‌رسد

این طبیعی است اگر:

- شما فقط از **مدل‌های رایگان** استفاده می‌کنید و به ارقام **هزینه** نگاه می‌کنید (ممکن است صفر باشند)؛ KPI‌های تعداد تماس هنوز برای دوره انتخاب شده به داده نیاز دارند
- **فیلتر زمانی** انتخاب شده، زمان برقراری تماس‌ها را پوشش نمی‌دهد — **همه** را امتحان کنید

اگر KPIها پس از انتخاب **همه** همچنان صفر هستند، [تاریخچه](/docs/history/) یا داشبورد → **همه تماس‌ها** را بررسی کنید.

## هزینه "در دسترس نیست" نشان می‌دهد یا اشتباه به نظر می‌رسد

OpenRouter در صورت لزوم، هزینه واقعی را نشان می‌دهد. برای سایر ارائه‌دهندگان، هزینه از قیمت‌گذاری OpenRouter تخمین زده می‌شود؛ اگر هیچ قیمتی مطابقت نداشته باشد، هزینه به صورت **در دسترس نیست** نمایش داده می‌شود و به کل اضافه نمی‌شود.

## کل هزینه با صورت‌حساب ارائه‌دهنده من مطابقت ندارد

ارقام در برنامه **تخمین‌هایی برای مرجع** هستند، نه فاکتور. برای OpenRouter، از **تنظیمات → ردیابی هزینه → همگام‌سازی با استفاده از کلید API** استفاده کنید.

## صفحه تاریخچه از نوار کناری گم شده است

**نگهداری تاریخچه اجرا** ممکن است خاموش باشد. آن را در تنظیمات عمومی فعال کنید مگر اینکه تاریخچه توسط مدیر غیرفعال شده باشد (`HISTORY_DISABLED` — به [پیکربندی](/docs/configuration/#privacy-mode) مراجعه کنید).

## وب: به طور غیرمنتظره به صفحه ورود هدایت شدم

ممکن است جلسه شما منقضی شده باشد. دوباره وارد شوید. اگر این اتفاق زیاد می‌افتد، تنظیمات طول عمر جلسه سرور را بررسی کنید.

## مدیر وب: رمز عبور را فراموش کردم

اگر مدیر دیگری می‌تواند وارد شود، می‌تواند رمز عبور را در **Settings → Users** بازنشانی کند. اگر شما قفل شده‌اید اما دسترسی شل دارید:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

نام کاربری پیش‌فرض مدیر `admin` است. از یک بررسی منبع: `pnpm run reset-web-password -- <username> <new-password>`.

## داشبورد برای سایر کاربران داده‌ای نشان نمی‌دهد (وب)

فقط **مدیران** می‌توانند سایر کاربران را از طریق فیلتر **کاربر** مشاهده کنند. کاربران عادی فقط فعالیت خود را می‌بینند.

## یک اعلان را تغییر دادم و ویرایش‌ها را از دست دادم

هنگام ویرایش یک اعلان تبدیل، قبل از **Back to Run** روی **Save** کلیک کنید.

## نکات سریع

- قبل از بازنویسی یا تبدیل، با [ترجمه](/docs/translate/) شروع کنید تا تنظیمات خود را تأیید کنید
- برای بهبودهای روزمره در کلمات، از [بازنویسی](/docs/rewrite/) استفاده کنید
- برای گردش‌های کاری سفارشی قابل تکرار، از [تبدیل](/docs/transform/) استفاده کنید
- تا زمانی که به شناسه‌های مدل دقیق نیاز ندارید، در حالت **آسان** بمانید
- اگر در حال ساخت یک کتابخانه پرامپت هستید، پرامپت‌ها را به طور منظم صادر کنید
- از [داشبورد](/docs/dashboard/) و [تاریخچه](/docs/history/) برای بررسی میزان استفاده و اجراهای گذشته استفاده کنید
