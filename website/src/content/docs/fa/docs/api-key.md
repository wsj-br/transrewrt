Transrewrt به حداقل یک ارائه‌دهنده هوش مصنوعی نیاز دارد. برای شروع به مدل پولی **نیاز ندارید**: OpenRouter پس از افزودن کلید، مدل‌های رایگان ارائه می‌دهد و چندین ارائه‌دهنده دیگر نیز سطوح رایگان ارائه می‌دهند.

ارائه‌دهندگان پشتیبانی‌شده شامل [OpenRouter](https://openrouter.ai)، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras، NVIDIA، Alibaba Cloud، apikey.fun، هر نقطه پایانی سازگار با OpenAI، و سرورهای محلی سازگار با OpenAI (Ollama، LM Studio، llama.cpp، و موارد مشابه) هستند.

## آسان در مقابل پیشرفته

- حالت **آسان** (پیش‌فرض): یک **پیش‌تنظیم** (رایگان (OpenRouter)، استاندارد، پیشرفته، یا فنی) را انتخاب کنید که به یک **ارائه‌دهنده** نگاشت شده است. فقط پیش‌تنظیم‌هایی که برای ارائه‌دهنده فعلی نگاشت دارند، ظاهر می‌شوند.
- حالت **پیشرفته**: مدل‌ها را مستقیماً انتخاب کنید. شناسه‌های مدل از یک پیشوند ارائه‌دهنده استفاده می‌کنند (برای مثال `openrouter/…`، `openai/…`، `local/…`).

## کلید رایگان OpenRouter (دسکتاپ)

1. به [openrouter.ai](https://openrouter.ai) بروید و ثبت‌نام یا وارد شوید.
2. صفحه [کلیدها](https://openrouter.ai/keys) را باز کنید و یک کلید جدید ایجاد کنید (نام‌گذاری کنید؛ محدودیت اعتبار اختیاری است). می‌توانید از مدل‌های رایگان بدون افزودن اعتبار استفاده کنید.
3. در Transrewrt، **تنظیمات ← پیکربندی API** را باز کنید، کلید را در **کلید API OpenRouter** جای‌گذاری کنید، و روی **تست کلید OpenRouter** کلیک کنید.

:::caution
از مدل **Body Builder** OpenRouter (`openrouter/bodybuilder`) برای ترجمه، بازنویسی یا تبدیل استفاده نکنید — این مدل بارهای JSON درخواست را برمی‌گرداند، نه متن کامل‌شده.
:::

## سایر گزینه‌های رایگان

همچنین می‌توانید کلیدهای API رایگان را از Cerebras، Google، Groq، Mistral AI یا [NVIDIA](https://build.nvidia.com/) (API سازگار با OpenAI) دریافت کنید، یا مدل‌ها را به صورت محلی با Ollama، LM Studio، llama.cpp یا یک سرور سازگار با OpenAI دیگر (به عنوان مثال `translategemma:4b` از طریق Ollama) اجرا کنید. URL پایه LLM محلی را روی پایه کامل API (شامل مسیر، به عنوان مثال `http://localhost:11434/v1`) در تنظیمات (دسکتاپ) یا `LOCAL_LLM_URL` (داکر) تنظیم کنید.

:::caution
اگر از یک سرور LLM محلی از دستگاه یا کانتینر دیگری استفاده می‌کنید، آن را طوری پیکربندی کنید که اتصالات خارجی را مجاز کند (نه فقط localhost).
:::

## Docker / وب

کلیدهای ارائه‌دهنده را به عنوان **متغیرهای محیطی** در سرور تنظیم کنید (مثلاً `PROVIDER_API_KEY`). کاربران نمی‌توانند کلیدها را در رابط کاربری مرورگر تایپ کنند. به [پیکربندی](/docs/configuration/) مراجعه کنید.

## چک‌لیست اولین اجرا

1. برنامه را باز کنید و در صورت نیاز **زبان رابط کاربری** را تنظیم کنید.
2. حداقل یک کلید ارائه‌دهنده (دسکتاپ) را اضافه و آزمایش کنید یا تأیید کنید که سرور دارای کلیدهای محیطی (وب) است.
3. در حالت **آسان**، یک **ارائه‌دهنده** را در تنظیمات عمومی انتخاب کنید؛ در حالت **پیشرفته**، مدل‌ها را در **تنظیمات ← مدل‌ها** اضافه کنید.
4. در **ترجمه**، یک پیش‌تنظیم یا مدل را انتخاب کرده و یک آزمایش کوتاه اجرا کنید — به [ترجمه متن](/docs/translate/) مراجعه کنید.
