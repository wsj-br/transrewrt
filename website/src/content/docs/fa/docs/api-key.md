Transrewrt هوش مصنوعی مخصوص به خود را ندارد — متن شما را به ارائه‌دهنده هوش مصنوعی که شما انتخاب می‌کنید ارسال می‌کند. برای اتصال یک ارائه‌دهنده، یک **کلید API** اضافه می‌کنید: یک کد خصوصی که توسط ارائه‌دهنده صادر می‌شود و مانند یک رمز عبور برای سرویس آن‌ها عمل می‌کند. برای شروع فقط به **یک** ارائه‌دهنده نیاز دارید و لازم نیست هزینه پرداخت کنید: چندین ارائه‌دهنده مدل‌های رایگان یا سطوح رایگان ارائه می‌دهند، و همچنین می‌توانید مدل‌ها را بدون هیچ کلیدی روی رایانه خود اجرا کنید.

ارائه‌دهندگان پشتیبانی‌شده شامل OpenRouter، OpenAI، Anthropic، Google Gemini، DeepSeek، Groq، Mistral، xAI، Cerebras، NVIDIA، Alibaba Cloud، apikey.fun، هر نقطه پایانی سازگار با OpenAI، و سرورهای محلی سازگار با OpenAI (Ollama، LM Studio، llama.cpp و موارد مشابه) هستند.

## گام ۱ — یک ارائه‌دهنده انتخاب کنید

هر ارائه‌دهنده پشتیبانی‌شده‌ای کار می‌کند. اگر مطمئن نیستید کدام را انتخاب کنید:

- **شروع رایگان**: OpenRouter، Google Gemini، Groq، Mistral، Cerebras، و NVIDIA همگی مدل‌های رایگان یا سطوح رایگان ارائه می‌دهند.
- **از قبل حساب کاربری دارید؟** اگر از قبل از OpenAI، Anthropic، یا یک ارائه‌دهنده پشتیبانی‌شده دیگر استفاده می‌کنید، می‌توانید به سادگی از همان حساب کاربری استفاده کنید.
- **ترجیح می‌دهید همه چیز روی رایانه خودتان بماند؟** کلید را به طور کامل نادیده بگیرید و به جای آن از یک [مدل محلی](#using-a-local-model-instead-no-api-key) استفاده کنید.

## گام ۲ — یک کلید API ایجاد کنید

مراحل دقیق بسته به ارائه‌دهنده کمی متفاوت است، اما الگو در همه جا یکسان است:

1. در وب‌سایت ارائه‌دهنده ثبت‌نام کنید یا وارد شوید. در **تنظیمات → پیکربندی API** Transrewrt، هر ارائه‌دهنده یک پیوند **باز کردن وب‌سایت ارائه‌دهنده** دارد که شما را به مکان صحیح هدایت می‌کند.
2. صفحه **کلیدهای API** را پیدا کنید (گاهی اوقات در بخش حساب، داشبورد یا تنظیمات توسعه‌دهنده) و یک کلید جدید ایجاد کنید. برخی از ارائه‌دهندگان از شما می‌خواهند که کلید را نام‌گذاری کنید یا یک محدودیت هزینه تعیین کنید — هر دو اختیاری هستند.
3. کلید را کپی کنید. این یک رشته طولانی از حروف و اعداد است که اغلب با چیزی شبیه به `sk-` شروع می‌شود.

:::note
با کلید API مانند رمز عبور رفتار کنید: آن را به اشتراک نگذارید، پست نکنید یا برای کسی ارسال نکنید. اگر کلیدی فاش شد، آن را در وب‌سایت ارائه‌دهنده حذف کرده و یک کلید جدید ایجاد کنید.
:::

## گام ۳ — کلید را اضافه و آزمایش کنید (دسکتاپ)

1. در Transrewrt، به **Settings → API Config** بروید.
2. کلید را در فیلد مربوط به ارائه‌دهنده خود (برای مثال **Google Gemini API key**) جای‌گذاری کرده و آن را ذخیره کنید.
3. برای تأیید عملکرد کلید، روی **Test** در کنار فیلد کلیک کنید.

پس از موفقیت‌آمیز بودن آزمایش، آماده هستید — آن ارائه‌دهنده را در صفحه اصلی انتخاب کرده و شروع به ترجمه کنید.

## استفاده از یک مدل محلی به جای آن (بدون کلید API)

می‌توانید مدل‌ها را روی رایانه خود با Ollama، LM Studio، llama.cpp، یا یک سرور دیگر سازگار با OpenAI (برای مثال `google/gemma-4-e2b` از طریق LM Studio) اجرا کنید. هیچ چیز از دستگاه شما خارج نمی‌شود و نیازی به کلید API نیست.

برای اتصال یکی، URL پایه LLM محلی را به پایه کامل API، شامل مسیر، تنظیم کنید — برای مثال `http://localhost:11434/v1`. در دسکتاپ، این را در **تنظیمات ← پیکربندی API** تنظیم کنید؛ در Docker، به جای آن متغیر محیطی `LOCAL_LLM_URL` را تنظیم کنید.

:::tip
اگر از سرور LLM محلی از دستگاه یا کانتینر دیگری استفاده می‌کنید، آن را طوری پیکربندی کنید که اتصالات خارجی را مجاز کند (نه فقط localhost).
:::

## داکر / وب

اگر از Transrewrt در یک مرورگر استفاده می‌کنید، کلیدها توسط هر کسی که سرور را اجرا می‌کند مدیریت می‌شوند، نه اینکه در رابط کاربری مرورگر تایپ شوند. مدیر کلیدهای ارائه‌دهنده را به عنوان **متغیرهای محیطی** روی سرور تنظیم می‌کند (برای مثال `PROVIDER_API_KEY`) — به [پیکربندی](/docs/configuration/) مراجعه کنید.

## چک‌لیست اولین اجرا

1. برنامه را باز کنید و در صورت نیاز **زبان رابط کاربری** را تنظیم کنید.
2. حداقل یک کلید ارائه‌دهنده را اضافه و آزمایش کنید — یا یک مدل محلی (دسکتاپ) را پیکربندی کنید، یا تأیید کنید که سرور دارای کلیدهای محیطی (وب) است.
3. در حالت **آسان**، یک **ارائه‌دهنده** را در تنظیمات عمومی انتخاب کنید؛ در حالت **پیشرفته**، مدل‌ها را در **تنظیمات ← مدل‌ها** اضافه کنید — برای دو حالت به [تنظیمات](/docs/settings/#general-settings) مراجعه کنید.
4. در **ترجمه**، یک پیش‌تنظیم یا مدل را انتخاب کرده و یک آزمایش کوتاه اجرا کنید — به [ترجمه متن](/docs/translate/) مراجعه کنید.

## اگر چیزی کار نکرد

- **تست کلید ناموفق است**: بررسی کنید که کلید به طور کامل کپی شده باشد (بدون فاصله قبل یا بعد)، و اینکه در وب‌سایت ارائه‌دهنده حذف یا غیرفعال نشده باشد.
- **ترجمه‌ها با خطای سهمیه یا اعتبار ناموفق هستند**: طرح‌های رایگان دارای محدودیت‌های روزانه یا ماهانه هستند؛ صبر کنید، به یک ارائه‌دهنده رایگان دیگر تغییر دهید، یا اعتبار اضافه کنید.
- **هیچ ارائه‌دهنده‌ای در حالت آسان ظاهر نمی‌شود**: **تنظیمات ← پیکربندی API** را باز کنید و تأیید کنید که حداقل یک کلید (یا URL LLM محلی) پیکربندی و آزمایش شده است.
