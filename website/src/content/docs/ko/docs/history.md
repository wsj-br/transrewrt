각 실행의 입력 및 출력을 포함한 과거 작업을 보려면 **기록**을 엽니다.

![기록 페이지](/images/screenshots/ko/history.png)

기록은 [대시보드](/docs/dashboard/)와 동일한 시간 범위 필터를 사용합니다.

:::note
**웹 앱**에서는 모든 사용자(관리자 포함)가 자신의 실행 기록만 볼 수 있습니다. 대시보드의 **사용자** 필터는 여기에 적용되지 않습니다.
:::

## 내보내기

필터링된 목록을 **JSON**, **CSV** 또는 **XLSX**로 내보냅니다.

## 기록이 누락된 경우

**실행 기록 유지**가 꺼져 있을 수 있습니다. 관리자가 `HISTORY_DISABLED`을(를) 설정하지 않은 경우 [설정 → 일반 설정](/docs/settings/#general-settings)에서 활성화하세요. [구성](/docs/configuration/#privacy-mode)을 참조하세요.
