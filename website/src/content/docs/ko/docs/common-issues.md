---
title: 일반적인 문제
description: Transrewrt 문제 해결 및 빠른 팁
---



예상대로 작동하지 않으면 먼저 다음 사항을 확인하세요.

## 앱이 번역, 재작성 또는 변환을 하지 않음

다음 사항을 확인하세요:

- 툴바에서 **사전 설정**(Easy) 또는 **모델**(Advanced)을 선택했습니다
- **Easy** 모드에서 **설정 → 일반 설정**에 작동하는 키(또는 로컬 LLM URL)가 있는 **제공자**가 있습니다
- **Advanced** 모드에서 툴바에서 모델이 선택되어 있습니다(빈 목록도 허용되지만, 실행하려면 **설정 → 모델**에 최소 하나의 모델이 필요합니다)
- API 설정이 작동 중입니다(데스크톱: **설정 → API 구성 → 테스트**)

## 모델 목록이 비어 있음

**Easy** 모드에서 **제공자**가 설정되어 있고 키/URL이 테스트되었는지 확인하십시오. **로컬 LLM**의 경우 로컬 서버가 실행 중이고 모델이 로드되었는지 확인하십시오.

**고급** 모드에서는 선택된 모델이 비어 있을 수 있습니다. **설정 → 모델**을 열고, **새로 고침**을 클릭한 다음 원하는 모델을 선택하십시오 (또는 **사전 설정에서 선택**을 사용하십시오). 필요에 따라 **무료만**을 켜십시오. 마지막 툴바 모델을 제거하면 설정 → 모델도 열립니다.

## 너무 느리거나 비용이 많이 듦

- 다른 프리셋 또는 모델 선택
- 입력 길이 줄이기
- 일반 설정에서 **입력 중 실시간 번역** 끄기
- 간단한 작업에는 무료 모델 사용

## 인터페이스 언어가 잘못됨

도구 모음의 지구본 아이콘을 클릭하고 **인터페이스 언어**를 선택하세요.

## 텍스트가 너무 작거나 읽기 어려움

**설정 → 일반 설정** → **글꼴** 및 **크기** 변경.

## 대시보드 요약이 비어 보임

다음 경우에 정상입니다:

- **무료 모델**만 사용하고 **비용** 수치를 확인하는 경우(0일 수 있음); 호출 수 KPI는 선택한 기간에 대한 데이터가 필요합니다
- 선택한 **시간 필터**가 호출이 수행된 시간을 포함하지 않는 경우 — **전체** 시도

**모두**를 선택한 후에도 KPI가 0이라면 [기록](/docs/history/) 또는 대시보드 → **모든 통화**를 확인하십시오.

## 비용이 "사용 불가"로 표시되거나 잘못된 것 같음

OpenRouter와 xAI는 API가 실제 지출액을 반환할 때 이를 표시합니다. 다른 제공자의 경우, 비용은 [models.dev](https://models.dev/) 가격을 기준으로 추정됩니다. 일치하는 가격이 없으면 비용은 **사용 불가**로 표시되며 총액에 포함되지 않습니다.

## 총 비용이 제공자 청구서와 일치하지 않습니다

앱의 수치는 청구서가 아닌 **참고용 추정치**입니다. OpenRouter의 경우 **설정 → 비용 추적 → API 키 사용량과 동기화**를 사용하세요.

## 사이드바에 기록 페이지가 없습니다

**실행 기록 유지**가 꺼져 있을 수 있습니다. 관리자가 기록을 비활성화하지 않은 경우 일반 설정에서 이를 활성화하세요 (`HISTORY_DISABLED` — [구성](/docs/configuration/#privacy-mode) 참조).

## 웹: 예기치 않게 로그인으로 리디렉션됨

세션이 만료되었을 수 있습니다. 다시 로그인하십시오. 자주 발생하는 경우 관리자에게 [설정 → 사용자](/docs/settings/#users)에서 **세션 시간 초과**를 늘려달라고 요청하십시오(관리자가 세션을 취소했을 수도 있습니다).

## 웹 관리자: 비밀번호 분실

다른 관리자가 로그인할 수 있는 경우, **설정 → 사용자**에서 비밀번호를 재설정할 수 있습니다. 계정이 잠겨 있지만 셸 액세스 권한이 있는 경우:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

기본 관리자 사용자 이름은 `admin`입니다. 소스 체크아웃에서: `pnpm run reset-web-password -- <username> <new-password>`.

## 대시보드에 다른 사용자에 대해 데이터 없음 표시(웹)

**관리자**만 **사용자** 필터를 통해 다른 사용자를 볼 수 있습니다. 일반 사용자는 자신의 활동만 볼 수 있습니다.

## 프롬프트를 변경했을 때 편집 내용을 잃어버림

Transform 프롬프트를 편집할 때 **실행으로 돌아가기** 전에 **저장**을 클릭하세요.

## 빠른 팁

- Rewrite 또는 Transform 전에 설정을 확인하려면 [Translate](/docs/translate/)으로 시작하세요
- 일상적인 문구 개선에는 [Rewrite](/docs/rewrite/)을 사용하세요
- 반복 가능한 사용자 정의 워크플로에는 [Transform](/docs/transform/)을 사용하세요
- 세분화된 모델 ID가 필요할 때까지 **Easy** 모드를 유지하세요
- 프롬프트 라이브러리를 구축하는 경우 정기적으로 프롬프트를 내보내세요
- 사용량 및 과거 실행을 검토하려면 [Dashboard](/docs/dashboard/) 및 [History](/docs/history/)를 사용하세요

[문제 보고](https://github.com/wsj-br/transrewrt/issues)
