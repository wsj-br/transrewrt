예상대로 작동하지 않는 경우, 먼저 다음 사항을 확인하십시오.

## 앱이 번역, 재작성 또는 변환되지 않음

다음을 확인하십시오:

- 툴바에서 **사전 설정**(Easy) 또는 **모델**(Advanced)을 선택했습니다
- **Easy** 모드에서 **Settings → General Settings**의 **Provider**에 작동하는 키(또는 Local LLM URL)가 설정되어 있습니다
- **Advanced** 모드에서 **Settings → Models**에 하나 이상의 모델이 나열되어 있습니다
- API 설정이 정상적으로 작동합니다(데스크톱: **Settings → API Config → Test**)

## 모델 목록이 비어 있음

**Easy** 모드에서는 **Provider**가 설정되고 키/URL이 테스트되었는지 확인하세요. **Local LLM**의 경우 로컬 서버가 실행 중이고 모델이 로드되었는지 확인하세요.

**고급** 모드에서 **설정 → 모델**을 열고 **새로 고침**을 클릭한 다음 **선택한 모델**에 모델을 추가하십시오. 선택적으로 **무료만**을 켭니다.

## 너무 느리거나 비용이 너무 많이 듦

- 다른 사전 설정 또는 모델 선택
- 더 짧은 입력 사용
- 일반 설정에서 **입력하는 동안 실시간 번역** 끄기
- 간단한 작업에는 무료 모델 사용

## 잘못된 인터페이스 언어

툴바에서 지구본 아이콘을 클릭하고 **인터페이스 언어**를 선택하십시오.

## 텍스트가 너무 작거나 읽기 어려움

**설정 → 일반 설정** → **글꼴 패밀리** 및 **크기**를 변경합니다.

## 대시보드 요약이 비어 있는 것으로 표시됨

다음의 경우에는 정상입니다:

- **무료 모델**만 사용하고 **비용** 수치를 보고 있는 경우(0일 수 있음); 호출 수 KPI에는 여전히 선택한 기간의 데이터가 필요합니다
- 선택한 **시간 필터**가 호출이 발생한 시간을 포함하지 않음 — **전체**를 시도해 보십시오

**전체**를 선택한 후에도 KPI가 0인 경우, [기록](/docs/history/) 또는 대시보드 → **모든 호출**을 확인하십시오.

## 비용이 "사용할 수 없음"으로 표시되거나 잘못된 것 같음

OpenRouter는 해당하는 경우 실제 지출을 표시합니다. 다른 제공자의 경우 비용은 OpenRouter 가격 책정을 기준으로 추정됩니다; 일치하는 가격이 없으면 비용이 **사용할 수 없음**으로 표시되며 총액에 추가되지 않습니다.

## 총 비용이 제공자 청구서와 일치하지 않음

앱의 수치는 청구서가 아닌 **참고용 추정치**입니다. OpenRouter의 경우 **설정 → 비용 추적 → API 키 사용량과 동기화**를 사용하십시오.

## 사이드바에 기록 페이지가 없음

**실행 기록 유지**가 꺼져 있을 수 있습니다. 관리자가 기록을 비활성화하지 않은 경우 일반 설정에서 활성화하십시오 (`HISTORY_DISABLED` — [구성](/docs/configuration/#privacy-mode) 참조).

## 웹: 예기치 않게 로그인으로 리디렉션됨

세션이 만료되었을 수 있습니다. 다시 로그인하십시오. 자주 발생하는 경우 서버 세션 수명 설정을 확인하십시오.

## 웹 관리자: 비밀번호 분실

다른 관리자가 로그인할 수 있다면 **Settings → Users**에서 비밀번호를 재설정할 수 있습니다. 계정이 잠겨 있지만 셸 액세스 권한이 있는 경우:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

기본 관리자 사용자 이름은 `admin`입니다. 소스 체크아웃에서: `pnpm run reset-web-password -- <username> <new-password>`.

## 대시보드에 다른 사용자의 데이터가 표시되지 않음(웹)

**관리자**만 **사용자** 필터를 통해 다른 사용자를 볼 수 있습니다. 일반 사용자는 자신의 활동만 볼 수 있습니다.

## 프롬프트를 변경하고 편집 내용을 잃어버린 경우

Transform 프롬프트를 편집할 때 **Back to Run**을 클릭하기 전에 **Save**를 클릭하세요.

## 빠른 팁

- Rewrite 또는 Transform 전에 [번역](/docs/translate/)으로 설정을 확인하십시오
- 일상적인 문구 개선에는 [Rewrite](/docs/rewrite/)를 사용하십시오
- 반복 가능한 사용자 지정 워크플로에는 [Transform](/docs/transform/)을 사용하십시오
- 세분화된 모델 ID가 필요할 때까지 **간편** 모드를 유지하십시오
- 프롬프트 라이브러리를 구축하는 경우 정기적으로 프롬프트를 내보내십시오
- [대시보드](/docs/dashboard/) 및 [기록](/docs/history/)을 사용하여 사용량 및 과거 실행을 검토하십시오
