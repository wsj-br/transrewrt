**Dashboard**를 사용하여 앱 사용량과 비용(유료 모델의 경우)을 확인하세요.

![대시보드 요약](/images/screenshots/ko/dashboard-summary.png)

:::note
**free** 모델만 사용하는 경우 비용 금액이 0일 수 있습니다. **Summary**의 호출 수 KPI에는 여전히 선택한 기간 내의 활동이 필요합니다.
:::

## 데이터 필터링

상단의 필터 버튼을 사용하여 시간 범위를 변경하세요.

:::note
**User** 필터는 웹 버전의 관리자에게만 표시됩니다. 데스크톱에서는 사용할 수 없습니다.
:::

## 탭

- **Summary** — KPI: 총 비용, 사용된 모델, 모드별 호출 수 및 비용, 호출당 평균 비용, 평균 TPS, 호출 수 기준 상위 모델
- **By Model** — 모델별 호출, 비용 및 TPS; 모드 분석을 보려면 행을 펼치세요
- **All Calls** — 내보내기 기능이 있는 전체 호출 로그(페이지 매김 또는 카드)

## 데이터 내보내기

테이블을 **JSON**, **CSV** 또는 **XLSX**로 내보내세요.

## 모델의 저장된 기록 삭제

**By Model** 또는 **All Calls**에서 휴지통 아이콘을 사용하여 모델의 기록을 제거하세요.

:::caution
삭제는 되돌릴 수 없습니다. 기간별로 삭제하거나 모든 비용 데이터를 지우려면 [설정 → 비용 추적](/docs/settings/#cost-tracking)을 사용하세요.
:::
