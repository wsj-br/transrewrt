開啟 **歷史** 以查看過去的操作，包含每次執行的輸入與輸出。

![歷史頁面](/images/screenshots/zh-Hant/history.png)

歷史使用與 [Dashboard](/docs/dashboard/) 相同的時間範圍篩選器。

:::note
在 **網頁應用程式** 中，所有人（包括管理員）只能看到自己的執行歷史。Dashboard 的 **使用者** 篩選器在此不適用。
:::

## 匯出

將篩選後的清單匯出為 **JSON**、**CSV** 或 **XLSX**。

## 如果歷史紀錄遺失

**保留執行歷史** 可能已關閉。請在 [設定 → 一般設定](/docs/settings/#general-settings) 中啟用它，除非管理員設定了 `HISTORY_DISABLED` — 請參閱 [配置](/docs/configuration/#privacy-mode)。
