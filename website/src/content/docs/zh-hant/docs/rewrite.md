---
title: 重寫文字
description: 改善同一語言的文字表達——包括清晰度、語氣、長度和語法等方面。
---



使用 **Rewrite** 來改善文字表達而不改變主要意義。文字保持同一語言。

![重寫工作區](/images/screenshots/zh-Hant/rewrite.png)

模式包括：

- **Check Spelling & Grammar**
- **Improve Clarity**
- **Alternative versions**（一次執行多個改寫版本）
- **Make Formal** / **Make Informal**
- **Shorten** / **Expand**
- **Make Technical**

## 重寫文字

1. 開啟 **Rewrite**。
2. 選擇一個 **Mode**。
3. 選擇性地將 **From** 設為您文字的語言（或保留 **Detect Language**）。
4. 在 **Input** 中輸入或貼上文字。
5. 點擊 **Rewrite**。
6. 在 **Output** 中閱讀結果。

[版面配置切換和鍵盤快捷鍵](/docs/translate/#layout-and-keyboard) 的運作方式與翻譯功能相同。

:::tip
重寫後，**Show changes**（**Changes**）開關會出現在**every**重寫模式的**Copy**旁邊。切換它可以顯示或隱藏輸入與輸出之間的差異。
:::

:::note
**替代版本**會在**單次**執行中傳回多個重新表述的版本，並以 `----` 分隔。這與**重新措辭…** 不同，後者會隨時間建立版本歷史。
:::

## 精煉重寫

成功執行後，輸出端會出現 **Rephrase…** 和版本下拉選單（概念與[翻譯](/docs/translate/#refine-a-translation)相同，但文字保持同一語言並保留當前 **Mode**）：

1. **Rephrase…**（未選取）——使用不同措辭的另一次完整重寫。最多五個版本。點擊 **Stop Rewrite** 以取消。
2. **Word alternatives**——選取文字，然後按右鍵或使用 **Rephrase…**。
3. 每個請求可能會增加使用量費用。
