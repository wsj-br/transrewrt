使用 **重寫** 來改善用詞而不改變主要含義。文字會保持同一種語言。

![重寫工作區](/images/screenshots/zh-Hant/rewrite.png)

模式包含：

- **檢查拼寫與文法**
- **提升清晰度**
- **替代版本**（一次執行產生數個改寫版本）
- **設為正式** / **設為非正式**
- **縮短** / **擴充**
- **設為技術性**

## 重寫文字

1. 開啟 **重寫**。
2. 選擇一個 **模式**。
3. 選擇性地將 **來源** 設為您文字的語言（或保留 **偵測語言**）。
4. 在 **輸入** 中輸入或貼上文字。
5. 點擊 **重寫**。
6. 在 **輸出** 中閱讀結果。

:::tip
在 **檢查拼寫與文法** 中，**複製** 旁邊會出現一個 **顯示變更** 開關。切換它以顯示或隱藏修正。
:::

:::note
**替代版本** 會在 **單次** 執行中傳回數個改寫版本，並以 `----` 分隔。這與 **改寫…** 不同，後者會隨時間建立版本歷史。
:::

## 精煉重寫

成功執行後，**改寫…** 和版本下拉選單會出現在輸出側（與 [翻譯](/docs/translate/#refine-a-translation) 的概念相同，但文字保持同一種語言並保留目前的 **模式**）：

1. **改寫…**（未選取）——另一個使用不同用詞的完整重寫。最多五個版本。點擊 **停止重寫** 以取消。
2. **字詞替代**——選取文字，然後右鍵點擊或使用 **改寫…**。
3. 每個請求都可能增加使用成本。
