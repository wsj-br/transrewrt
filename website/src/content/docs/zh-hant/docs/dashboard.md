title: 使用儀表板
description: 檢閱使用量、成本和呼叫日誌 — 篩選、匯出並管理已儲存的記錄。
---



使用 **Dashboard** 來查看您使用了多少應用程式以及花費了多少（適用於付費模型）。

![儀表板摘要](/images/screenshots/zh-Hant/dashboard-summary.png)

:::note
如果您只使用 **free** 模型，成本金額可能為零。**Summary** 上的呼叫次數 KPI 仍需要所選時段內的活動。
:::

## 篩選資料

使用頂部的篩選按鈕來變更時間範圍。

:::note
**User** 篩選器僅在網頁版中對管理員可見。桌面版不提供此功能。
:::

## 分頁

- **Summary** — KPI：總成本、已使用模型、各模式呼叫次數與成本、每次呼叫平均成本、平均 TPS、依呼叫次數排名的熱門模型
- **By Model** — 各模型的呼叫次數、成本和 TPS；展開資料列以查看模式細項
- **All Calls** — 完整呼叫日誌（分頁或卡片），可匯出

## 匯出資料

將表格匯出為 **JSON**、**CSV** 或 **XLSX**。

## 刪除模型的已儲存記錄

在 **By Model** 或 **All Calls** 中，使用垃圾桶圖示來移除模型的記錄。

:::caution
刪除後無法復原。若要依存在時間刪除或清除所有成本資料，請使用 [設定 → 成本追蹤](/docs/settings/#cost-tracking)。
:::
