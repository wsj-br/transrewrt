title: Browse History
description: Review past translate, rewrite, and transform runs with full input and output text.
---

Open **History** to see past operations, including the input and output of each run.

![History page](/images/screenshots/en-GB/history.png)

History uses the same time-range filters as the [Dashboard](/docs/dashboard/).

:::note
In the **web app**, everyone (including administrators) sees only their own execution history. The Dashboard **User** filter does not apply here.
:::

## Export

Export the filtered list as **JSON**, **CSV**, or **XLSX**.

## If History is missing

**Keep execution history** may be off. Enable it in [Settings → General Settings](/docs/settings/#general-settings) unless the administrator set `HISTORY_DISABLED` — see [Configuration](/docs/configuration/#privacy-mode).
