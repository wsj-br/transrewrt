**Transrewrt** è uno strumento di testo open source basato sull'intelligenza artificiale per:

- **Tradurre** — tra decine di lingue, con rilevamento automatico della sorgente e glossari
- **Riscrivere** — correggere la grammatica, migliorare la chiarezza, cambiare tono o lunghezza
- **Trasformare** — eseguire i propri prompt AI personalizzati su qualsiasi testo

Supporta molti provider di IA (OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, endpoint compatibili con OpenAI e server locali compatibili con OpenAI come Ollama, LM Studio o llama.cpp). Eseguilo come **app desktop** (Windows/Linux) o **app web self-hosted** (Docker).

Le tue chiavi, i tuoi modelli, il tuo host — non esiste un account cloud Transrewrt.

## Come è organizzata la finestra

- **Barra laterale** — Traduci, Riscrivi, Trasforma, Dashboard, Cronologia, Impostazioni (e l'utente connesso sul web)
- **Barra degli strumenti** — titolo della pagina, selettore **predefinito** (Facile) o **modello** (Avanzato) e **Lingua dell'interfaccia** (icona del globo; non modifica Traduci da/a)
- **Area di lavoro** — Pannelli di input e output con conteggi, tempi, TPS e costo opzionale

Per impostazione predefinita l'app viene eseguita in modalità **Facile**: scegli un **preset** e un **Provider** in Impostazioni. Passa ad **Avanzato** in [Impostazioni → Impostazioni generali](/docs/settings/#general-settings) per un elenco completo dei modelli.
