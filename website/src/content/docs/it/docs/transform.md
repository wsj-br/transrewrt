Usa **Trasforma** quando vuoi che l'AI segua istruzioni personalizzate: riassumere, perfezionare un'e-mail, estrarre punti chiave, riformattare il testo o qualsiasi flusso di lavoro tu definisca.

![Area di lavoro Trasforma](/images/screenshots/it/transform.png)

## Esegui un prompt esistente

1. Apri **Trasforma**.
2. Scegli un prompt dall'elenco.
3. Se viene visualizzata una casella della lingua **Da**, imposta una lingua se lo desideri.
4. Digita o incolla il testo in **Input**.
5. Fai clic su **Trasforma**.
6. Leggi il risultato in **Output**.

## Carica prompt di esempio

Se l'elenco è vuoto, fai clic su **Carica prompt di esempio** nell'area di lavoro Trasforma (disponibile anche in [Impostazioni → Trasforma](/docs/settings/#transform)). Gli esempi sono in inglese; dopo il caricamento, modifica un prompt e usa **Traduci prompt** se necessario.

## Crea un prompt

1. Fai clic su **Nuovo prompt**.
2. Fai clic su **Genera prompt**.
3. Descrivi cosa vuoi che faccia il prompt.
4. Scegli un preset (Facile) o un modello (Avanzato).
5. Rivedi la bozza e fai clic su **Salva**.

## Modifica un prompt

L'editor è a sinistra; un'area di test è a destra.

![Editor di prompt Trasforma](/images/screenshots/it/transform-prompt-edit.png)

Campi principali:

- **Nome prompt** — mostrato nell'elenco dei prompt
- **Istruzioni prompt (facoltativo)** — breve suggerimento durante l'esecuzione del prompt
- **Ruolo modello** — ruolo generale per l'AI
- **Istruzioni modello (una per riga)** — regole da seguire
- **Descrizione output** — breve etichetta per il risultato (es. riassunto)
- **Temperatura (0.0 → 1.0)** — più bassa è più stabile; più alta è più varia
- **Chiedi lingua di destinazione** — aggiunge un selettore di lingua durante l'esecuzione

Aiuti: **Genera prompt**, **Migliora prompt**, **Traduci prompt** (Facile usa i preset; Avanzato usa l'elenco dei modelli).

:::caution
Fai clic su **Salva** prima di **Torna a Esegui**. Tornare indietro senza salvare annulla le modifiche.
:::

## Test prima dell'uso quotidiano

Usa il pannello di test a destra con il testo di esempio quando crei o confronti i prompt.

Esporta e importa i prompt in blocco in [Impostazioni → Trasforma](/docs/settings/#transform).
