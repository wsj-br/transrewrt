## مواقع ملفات التهيئة

| النشر | مجلد البيانات |
| --- | --- |
| Electron (Windows) | `%APPDATA%\transrewrt\` |
| Electron (Linux) | `~/.config/transrewrt/` |
| الويب / Docker | `/app/data/` (استخدم وحدة تخزين للاستمرارية) |

يحتوي مجلد البيانات على كل ما يستحق النسخ الاحتياطي:

- `config.json` — الإعدادات ومفاتيح API المشفرة (للسطح المكتب)
- `state.json` — اللغات المستخدمة مؤخرًا، والنموذج، وحالة العرض
- `presets.json` — كتالوج الإعدادات المسبقة لوضع Easy-mode المخزنة مؤقتًا
- `transrewrt.db` — قاعدة بيانات SQLite مع السجل، والتكاليف، والمطالبات، والمسرد، والمستخدمين (الويب)

يمكنك أيضًا إنشاء نسخة احتياطية محمولة بتنسيق ZIP من التطبيق — راجع [الإعدادات ← الإعدادات العامة](/docs/settings/#general-settings).

## متغيرات البيئة (الويب / Docker)

يستخدم Electron ملف التهيئة المحلي. لخادم الويب/Docker فقط:

| المتغير | الوصف |
| --- | --- |
| `PORT` | منفذ الاستماع للخادم (الافتراضي `5000`) |
| `CONFIG_PATH` | مسار ملف التهيئة (الافتراضي `/app/data/config.json`) |
| `TZ` | المنطقة الزمنية للوقت من جانب الخادم (الافتراضي `Europe/London`) |
| `HISTORY_DISABLED` | فرض إيقاف سجل التنفيذ (`true` / `1`) |
| `OPENROUTER_API_KEY` | مفتاح OpenRouter API |
| `OPENAI_API_KEY` | مفتاح OpenAI API |
| `CEREBRAS_API_KEY` | مفتاح Cerebras API |
| `ANTHROPIC_API_KEY` | مفتاح Anthropic API |
| `GOOGLE_API_KEY` | مفتاح Google Gemini API |
| `DEEPSEEK_API_KEY` | مفتاح DeepSeek API |
| `GROQ_API_KEY` | مفتاح Groq API |
| `MISTRAL_API_KEY` | مفتاح Mistral API |
| `LOCAL_LLM_URL` | عنوان URL الأساسي لواجهة برمجة التطبيقات المتوافق تمامًا مع OpenAI لخادم محلي، بما في ذلك المسار (على سبيل المثال Ollama `http://host.docker.internal:11434/v1`، LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | مفتاح xAI API |
| `NVIDIA_API_KEY` | مفتاح NVIDIA API |
| `ALIBABA_API_KEY` | مفتاح Alibaba Cloud (DashScope) API |
| `APIFUN_API_KEY` | مفتاح apikey.fun API |
| `CUSTOM_PROVIDER_NAME` | اسم العرض لموفر مخصص متوافق مع OpenAI |
| `CUSTOM_PROVIDER_URL` | عنوان URL الأساسي لموفر مخصص متوافق مع OpenAI |
| `CUSTOM_PROVIDER_API_KEY` | مفتاح API للموفر المخصص |

جميع متغيرات `CUSTOM_PROVIDER_*` الثلاثة مطلوبة عند استخدام نقطة نهاية مخصصة. تظهر النماذج في وضع **Advanced** كـ `{providerName}/…`.

## متغيرات البيئة (سطح المكتب)

| المتغير | الوصف |
| --- | --- |
| `TRANSREWRT_DISABLE_GPU` | اضبط على `1` لتعطيل تسريع الأجهزة (مفيد عندما يطبع Chromium أخطاء GPU / EGL على Linux) |
| `HISTORY_DISABLED` | فرض إيقاف سجل التنفيذ (`true` / `1`) — انظر [وضع الخصوصية](#privacy-mode) |

## وضع الخصوصية

اضبط `HISTORY_DISABLED` على `true` أو `1` في عملية خادم الويب/Docker و/أو عملية Electron الرئيسية لفرض إيقاف السجل بغض النظر عن `config.json` أو تفضيلات المستخدم. يؤدي هذا إلى تعطيل تخزين سجل الإدخال/الإخراج، ويقفل **الإعدادات ← الإعدادات العامة ← السجل**، ويحظر واجهات برمجة التطبيقات المتعلقة بالسجل.

## استمرارية البيانات (Docker)

قم بتركيب وحدة تخزين في `/app/data` بحيث تظل ملفات التكوين وقاعدة بيانات SQLite (انظر [مواقع ملفات التكوين](#config-file-locations)) موجودة بعد إعادة تشغيل الحاوية. بدون وحدة تخزين، ستفقد البيانات عند توقف الحاوية.

## مصادقة الويب

- المسؤول الافتراضي: `admin` / `transrewrt26`
- إدارة المستخدمين ومهلة الجلسة وإلغاء الجلسة في **الإعدادات ← المستخدمون** — راجع [الإعدادات](/docs/settings/#users)
- يمكن لكل مستخدم مسجل الدخول تغيير كلمة المرور الخاصة به أو تسجيل الخروج من قائمة المستخدم في الجزء السفلي من الشريط الجانبي
- إعادة تعيين كلمة المرور:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
غيّر كلمة مرور المسؤول الافتراضية فورًا على أي مضيف يمكن الوصول إليه عبر الشبكة.
:::

:::caution
يتحدث الخادم بروتوكول HTTP عادي. إذا قمت بكشفه خارج المضيف المحلي أو شبكة موثوقة، فضعه خلف وكيل عكسي مع HTTPS (على سبيل المثال Caddy أو nginx أو Traefik) حتى لا يتم إرسال كلمات المرور والنصوص بشكل واضح.
:::

## عرض التكلفة

يعرض OpenRouter التكلفة الفعلية المحاسبة عند الاقتضاء. يستخدم مقدمو الخدمة الآخرون التكلفة **المقدرة** من تسعير نموذج OpenRouter العام عندما يكون مفتاح OpenRouter متاحًا. التقديرات ليست فواتير.

لواجهة مستخدم الإعدادات (الخطوط، النماذج، السجل، النسخ الاحتياطية)، راجع [الإعدادات](/docs/settings/).
