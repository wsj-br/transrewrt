استخدم **لوحة المعلومات** لمعرفة مدى استخدامك للتطبيق وما هي تكلفته (للموديلات المدفوعة).

![ملخص لوحة المعلومات](/images/screenshots/ar/dashboard-summary.png)

:::note
إذا كنت تستخدم موديلات **مجانية** فقط، فقد تكون مبالغ التكلفة صفرًا. لا تزال مؤشرات الأداء الرئيسية لعدد المكالمات في **الملخص** تحتاج إلى نشاط في الفترة المحددة.
:::

## تصفية البيانات

استخدم أزرار التصفية في الأعلى لتغيير النطاق الزمني.

:::note
مرشح **المستخدم** مرئي للمسؤولين فقط في إصدار الويب. وهو غير متاح على سطح المكتب.
:::

## علامات التبويب

- **الملخص** — مؤشرات الأداء الرئيسية: التكلفة الإجمالية، الموديلات المستخدمة، عدد المكالمات والتكلفة لكل وضع، متوسط التكلفة لكل مكالمة، متوسط TPS، أهم الموديلات حسب عدد المكالمات
- **حسب الموديل** — المكالمات والتكلفة وTPS لكل موديل؛ قم بتوسيع صف للحصول على تفصيل الوضع
- **جميع المكالمات** — سجل المكالمات الكامل (صفحات أو بطاقات) مع التصدير

## تصدير البيانات

تصدير الجداول بتنسيق **JSON** أو **CSV** أو **XLSX**.

## حذف السجلات المخزنة لموديل

في **حسب الموديل** أو **جميع المكالمات**، استخدم أيقونة سلة المهملات لإزالة السجلات لموديل.

:::caution
لا يمكن التراجع عن الحذف. لحذف حسب العمر أو مسح جميع بيانات التكلفة، استخدم [الإعدادات ← تتبع التكلفة](/docs/settings/#cost-tracking).
:::
