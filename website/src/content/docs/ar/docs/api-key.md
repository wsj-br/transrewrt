Transrewrt يحتاج إلى الوصول إلى مزود ذكاء اصطناعي واحد على الأقل. لا تحتاج **إلى** نموذج مدفوع لبدء التشغيل: يقدم OpenRouter نماذج مجانية بعد إضافة المفتاح، كما يقدم العديد من المزودين الآخرين مستويات مجانية.

يشمل الموفرون المدعومون [OpenRouter](https://openrouter.ai)، وOpenAI، وAnthropic، وGoogle Gemini، وDeepSeek، وGroq، وMistral، وxAI، وCerebras، وNVIDIA، وAlibaba Cloud، وapikey.fun، وأي نقطة نهاية متوافقة مع OpenAI، والخوادم المحلية المتوافقة مع OpenAI (Ollama، وLM Studio، وllama.cpp، وما شابه).

## سهل مقابل متقدم

- وضع **السهل** (الافتراضي): اختر **إعدادًا مسبقًا** (مجاني (OpenRouter)، أو قياسي، أو متقدم، أو تقني) يتم تعيينه إلى **موفر**. تظهر فقط الإعدادات المسبقة التي تحتوي على تعيين للموفر الحالي.
- وضع **المتقدم**: اختر النماذج مباشرة. تستخدم معرفات النماذج بادئة موفر (على سبيل المثال `openrouter/…`، `openai/…`، `local/…`).

## مفتاح OpenRouter مجاني (سطح المكتب)

1. انتقل إلى [openrouter.ai](https://openrouter.ai) واشترك أو سجل الدخول.
2. افتح صفحة [المفاتيح](https://openrouter.ai/keys) وأنشئ مفتاحًا جديدًا (سمّه؛ حد ائتمان اختياري). يمكنك استخدام النماذج المجانية دون إضافة رصيد.
3. في Transrewrt، افتح **الإعدادات ← تهيئة واجهة برمجة التطبيقات**، الصق المفتاح في **مفتاح OpenRouter API**، وانقر على **اختبار مفتاح OpenRouter**.

:::caution
لا تستخدم نموذج **Body Builder** (`openrouter/bodybuilder`) الخاص بـ OpenRouter للترجمة أو إعادة الكتابة أو التحويل — فهو يُرجع حمولات طلب JSON، وليس نصًا مكتملًا.
:::

## خيارات مجانية أخرى

يمكنك أيضًا الحصول على مفاتيح API مجانية من Cerebras أو Google أو Groq أو Mistral AI أو [NVIDIA](https://build.nvidia.com/) (واجهة برمجة تطبيقات متوافقة مع OpenAI)، أو تشغيل النماذج محليًا باستخدام Ollama أو LM Studio أو llama.cpp أو خادم آخر متوافق مع OpenAI (على سبيل المثال `translategemma:4b` عبر Ollama). اضبط عنوان URL الأساسي لـ Local LLM على قاعدة API الكاملة (تضمين المسار، على سبيل المثال `http://localhost:11434/v1`) في الإعدادات (سطح المكتب) أو `LOCAL_LLM_URL` (Docker).

:::caution
إذا كنت تستخدم خادم LLM محليًا من جهاز أو حاوية أخرى، فقم بتكوينه للسماح بالاتصالات الخارجية (وليس localhost فقط).
:::

## Docker / الويب

عيّن مفاتيح الموفر كـ **متغيرات بيئة** على الخادم (على سبيل المثال `PROVIDER_API_KEY`). لا يمكن للمستخدمين كتابة المفاتيح في واجهة مستخدم المتصفح. راجع [التكوين](/docs/configuration/).

## قائمة التحقق للتشغيل الأول

1. افتح التطبيق واضبط **لغة الواجهة** إذا لزم الأمر.
2. أضف واختبر مفتاح مزود واحد على الأقل (للسطح المكتب) أو تأكد من أن الخادم يحتوي على مفاتيح بيئة (للويب).
3. في وضع **السهل**، اختر **مزودًا** في الإعدادات العامة؛ في وضع **المتقدم**، أضف نماذج ضمن **الإعدادات ← النماذج**.
4. في **الترجمة**، اختر إعدادًا مسبقًا أو نموذجًا وقم بإجراء اختبار قصير — راجع [ترجمة النص](/docs/translate/).
