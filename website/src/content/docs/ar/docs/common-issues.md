## التطبيق لا يترجم أو يعيد صياغة أو يحول

تحقق مما يلي:

- لقد حددت **إعدادًا مسبقًا** (سهل) أو **نموذجًا** (متقدم) في شريط الأدوات
- في وضع **السهل**، تحتوي **الإعدادات ← الإعدادات العامة** على **موفر** بمفتاح عامل (أو عنوان URL لـ LLM المحلي)
- في وضع **المتقدم**، يتم إدراج نموذج واحد على الأقل في **الإعدادات ← النماذج**
- إعداد API الخاص بك يعمل (سطح المكتب: **الإعدادات ← تكوين API ← اختبار**)

## قائمة النماذج فارغة

في وضع **السهل**، تأكد من تعيين **الموفر** واختبار المفاتيح/عناوين URL. بالنسبة لـ **LLM المحلي**، تأكد من تشغيل الخادم المحلي الخاص بك وتحميل النماذج.

في وضع **متقدم**، افتح **الإعدادات ← النماذج**، وانقر فوق **تحديث**، وأضف النماذج إلى **النماذج المحددة**. اختياريًا، قم بتشغيل **مجاني فقط**.

## بطيء جدًا أو مكلف جدًا

- اختر إعدادًا مسبقًا أو نموذجًا مختلفًا
- استخدم إدخالًا أقصر
- قم بإيقاف تشغيل **الترجمة في الوقت الفعلي أثناء الكتابة** في الإعدادات العامة
- استخدم النماذج المجانية للمهام البسيطة

## لغة الواجهة خاطئة

انقر فوق أيقونة الكرة الأرضية في شريط الأدوات واختر **لغة الواجهة** الخاصة بك.

## النص صغير جدًا أو يصعب قراءته

**الإعدادات ← الإعدادات العامة** ← تغيير **عائلة الخط** و**الحجم**.

## ملخص لوحة المعلومات يبدو فارغًا

هذا أمر طبيعي إذا:

- كنت تستخدم **النماذج المجانية** فقط وتنظر إلى أرقام **التكلفة** (قد تكون صفرًا)؛ لا تزال مؤشرات الأداء الرئيسية لعدد المكالمات تحتاج إلى بيانات للفترة المحددة
- لا يغطي **مرشح الوقت** المحدد وقت إجراء المكالمات — جرب **الكل**

إذا كانت مؤشرات الأداء الرئيسية لا تزال صفرًا بعد **الكل**، فتحقق من [السجل](/docs/history/) أو لوحة المعلومات ← **جميع المكالمات**.

## التكلفة تظهر "غير متوفرة" أو تبدو خاطئة

يعرض OpenRouter الإنفاق الفعلي عند الاقتضاء. بالنسبة للموفرين الآخرين، تُقدر التكلفة من تسعير OpenRouter؛ إذا لم يتطابق أي سعر، تظهر التكلفة على أنها **غير متوفرة** ولا تُضاف إلى الإجمالي.

## التكلفة الإجمالية لا تتطابق مع فاتورة الموفر الخاص بي

الأرقام في التطبيق هي **تقديرات مرجعية**، وليست فواتير. بالنسبة لـ OpenRouter، استخدم **الإعدادات ← تتبع التكلفة ← المزامنة مع استخدام مفتاح API**.

## صفحة السجل مفقودة من الشريط الجانبي

قد يكون **الاحتفاظ بسجل التنفيذ** معطلاً. قم بتمكينه في الإعدادات العامة ما لم يتم تعطيل السجل بواسطة المسؤول (`HISTORY_DISABLED` — انظر [التكوين](/docs/configuration/#privacy-mode)).

## الويب: تم إعادة التوجيه إلى تسجيل الدخول بشكل غير متوقع

قد تكون جلستك قد انتهت. سجل الدخول مرة أخرى. إذا حدث ذلك كثيرًا، فتحقق من إعدادات مدة جلسة الخادم.

## مسؤول الويب: نسيت كلمة المرور

إذا تمكن مسؤول آخر من تسجيل الدخول، فيمكنه إعادة تعيين كلمة المرور ضمن **الإعدادات ← المستخدمون**. إذا تم قفل حسابك ولكن لديك وصول إلى shell:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

اسم مستخدم المسؤول الافتراضي هو `admin`. من سحب المصدر: `pnpm run reset-web-password -- <username> <new-password>`.

## لوحة المعلومات لا تعرض بيانات للمستخدمين الآخرين (الويب)

يمكن لـ **المسؤولين** فقط عرض المستخدمين الآخرين عبر مرشح **المستخدم**. يرى المستخدمون العاديون نشاطهم الخاص فقط.

## تم تغيير مطالبة وفقدان التعديلات

عند تحرير مطالبة تحويل، انقر فوق **حفظ** قبل **العودة إلى التشغيل**.

## نصائح سريعة

- ابدأ بـ [الترجمة](/docs/translate/) لتأكيد إعداداتك قبل إعادة الكتابة أو التحويل
- استخدم [إعادة الكتابة](/docs/rewrite/) لتحسين الصياغة اليومية
- استخدم [التحويل](/docs/transform/) لسير العمل المخصص القابل للتكرار
- ابقَ في وضع **السهل** حتى تحتاج إلى معرفات نموذج دقيقة
- قم بتصدير المطالبات بانتظام إذا كنت تقوم بإنشاء مكتبة مطالبات
- استخدم [لوحة المعلومات](/docs/dashboard/) و [السجل](/docs/history/) لمراجعة الاستخدام والتشغيلات السابقة

[Report an issue](https://github.com/wsj-br/transrewrt/issues)
