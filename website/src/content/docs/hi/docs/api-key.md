ट्रांसरेवर्ट को कम से कम एक एआई प्रदाता तक पहुंच की आवश्यकता है। आपको शुरू करने के लिए सशुल्क मॉडल की आवश्यकता **नहीं** है: कुंजी जोड़ने के बाद ओपनराउटर निःशुल्क मॉडल प्रदान करता है, और कई अन्य प्रदाता भी निःशुल्क टियर प्रदान करते हैं।

समर्थित प्रदाताओं में [OpenRouter](https://openrouter.ai), OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Mistral, xAI, Cerebras, NVIDIA, Alibaba Cloud, apikey.fun, कोई भी OpenAI-संगत एंडपॉइंट, और स्थानीय OpenAI-संगत सर्वर (Ollama, LM Studio, llama.cpp, और इसी तरह के) शामिल हैं।

## आसान बनाम उन्नत

- **आसान** मोड (डिफ़ॉल्ट): एक **प्रीसेट** (फ्री (OpenRouter), स्टैंडर्ड, एडवांस्ड, या टेक्निकल) चुनें जो एक **प्रदाता** से मैप किया गया हो। वर्तमान प्रदाता के लिए मैपिंग वाले प्रीसेट ही दिखाई देते हैं।
- **एडवांस्ड** मोड: सीधे मॉडल चुनें। मॉडल आईडी एक प्रदाता उपसर्ग का उपयोग करते हैं (उदाहरण के लिए `openrouter/…`, `openai/…`, `local/…`)।

## निःशुल्क ओपनराउटर कुंजी (डेस्कटॉप)

1. [openrouter.ai](https://openrouter.ai) पर जाएं और साइन अप करें या लॉग इन करें।
2. [कुंजी](https://openrouter.ai/keys) पृष्ठ खोलें और एक नई कुंजी बनाएं (इसे नाम दें; वैकल्पिक क्रेडिट सीमा)। आप क्रेडिट जोड़े बिना निःशुल्क मॉडल का उपयोग कर सकते हैं।
3. ट्रांसरेवर्ट में, **सेटिंग्स → एपीआई कॉन्फ़िग** खोलें, कुंजी को **ओपनराउटर एपीआई कुंजी** में पेस्ट करें, और **ओपनराउटर कुंजी का परीक्षण करें** पर क्लिक करें।

:::caution
अनुवाद, पुनर्लेखन या परिवर्तन के लिए ओपनराउटर के **बॉडी बिल्डर** मॉडल (`openrouter/bodybuilder`) का उपयोग न करें — यह JSON अनुरोध पेलोड लौटाता है, पूर्ण पाठ नहीं।
:::

## अन्य निःशुल्क विकल्प

आप Cerebras, Google, Groq, Mistral AI, या [NVIDIA](https://build.nvidia.com/) (OpenAI-संगत API) से भी निःशुल्क API कुंजियाँ प्राप्त कर सकते हैं, या Ollama, LM Studio, llama.cpp, या किसी अन्य OpenAI-संगत सर्वर (उदाहरण के लिए Ollama के माध्यम से `translategemma:4b`) के साथ स्थानीय रूप से मॉडल चला सकते हैं। स्थानीय LLM बेस URL को पूर्ण API बेस (पाथ शामिल करें, जैसे `http://localhost:11434/v1`) सेटिंग्स (डेस्कटॉप) या `LOCAL_LLM_URL` (डॉकर) में सेट करें।

:::caution
यदि आप किसी अन्य डिवाइस या कंटेनर से स्थानीय LLM सर्वर का उपयोग करते हैं, तो उसे बाहरी कनेक्शन (केवल लोकलहोस्ट नहीं) की अनुमति देने के लिए कॉन्फ़िगर करें।
:::

## डॉकर / वेब

सर्वर पर प्रदाता कुंजियों को **पर्यावरण चर** के रूप में सेट करें (उदाहरण के लिए `PROVIDER_API_KEY`)। उपयोगकर्ता ब्राउज़र UI में कुंजियाँ टाइप नहीं कर सकते। [कॉन्फ़िगरेशन](/docs/configuration/) देखें।

## पहली बार चलाने की चेकलिस्ट

1. ऐप खोलें और यदि आवश्यक हो तो **इंटरफ़ेस भाषा** सेट करें।
2. कम से कम एक प्रदाता कुंजी (डेस्कटॉप) जोड़ें और उसका परीक्षण करें या पुष्टि करें कि सर्वर में env कुंजियाँ (वेब) हैं।
3. **आसान** मोड में, सामान्य सेटिंग्स में एक **प्रदाता** चुनें; **उन्नत** में, **सेटिंग्स → मॉडल** के तहत मॉडल जोड़ें।
4. **अनुवाद** पर, एक प्रीसेट या मॉडल चुनें और एक छोटा परीक्षण चलाएँ — [टेक्स्ट का अनुवाद करें](/docs/translate/) देखें।
