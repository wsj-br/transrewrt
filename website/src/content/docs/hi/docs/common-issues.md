यदि कुछ अपेक्षा के अनुरूप काम नहीं करता है, तो पहले इन बिंदुओं की जाँच करें।

## ऐप अनुवाद, पुनर्लेखन या रूपांतरण नहीं करेगा

जाँच करें कि:

- आपने टूलबार में एक **प्रीसेट** (आसान) या **मॉडल** (उन्नत) चुना है
- **आसान** मोड में, **सेटिंग्स → सामान्य सेटिंग्स** में एक काम करने वाली कुंजी (या स्थानीय LLM URL) के साथ एक **प्रदाता** है
- **उन्नत** मोड में, **सेटिंग्स → मॉडल** में कम से कम एक मॉडल सूचीबद्ध है
- आपकी API सेटअप काम कर रहा है (डेस्कटॉप: **सेटिंग्स → API कॉन्फ़िग → टेस्ट**)

## मॉडल सूची खाली है

**आसान** मोड में, पुष्टि करें कि **प्रदाता** सेट है और कुंजियाँ/URL परीक्षण किए गए हैं। **स्थानीय LLM** के लिए, सुनिश्चित करें कि आपका स्थानीय सर्वर चल रहा है और मॉडल लोड किए गए हैं।

**उन्नत** मोड में, **सेटिंग्स → मॉडल** खोलें, **रिफ्रेश** पर क्लिक करें, और **चयनित मॉडल** में मॉडल जोड़ें। वैकल्पिक रूप से **केवल निःशुल्क** चालू करें।

## बहुत धीमा या बहुत महंगा

- एक अलग प्रीसेट या मॉडल चुनें
- छोटा इनपुट उपयोग करें
- सामान्य सेटिंग्स में **टाइप करते समय वास्तविक समय अनुवाद** बंद करें
- सरल कार्यों के लिए निःशुल्क मॉडल का उपयोग करें

## गलत इंटरफ़ेस भाषा

टूलबार में ग्लोब आइकन पर क्लिक करें और अपनी **इंटरफ़ेस भाषा** चुनें।

## टेक्स्ट बहुत छोटा या पढ़ने में मुश्किल

**सेटिंग्स → सामान्य सेटिंग्स** → **फ़ॉन्ट परिवार** और **आकार** बदलें।

## डैशबोर्ड सारांश खाली दिख रहा है

यह सामान्य है यदि:

- आप केवल **मुफ्त मॉडल** का उपयोग करते हैं और आप **लागत** के आंकड़ों को देख रहे हैं (वे शून्य हो सकते हैं); कॉल-काउंट KPI को अभी भी चयनित अवधि के लिए डेटा की आवश्यकता है
- चयनित **समय फ़िल्टर** उन कॉलों को कवर नहीं करता है जब कॉल किए गए थे — **सभी** का प्रयास करें

यदि **सभी** के बाद भी KPI शून्य हैं, तो [इतिहास](/docs/history/) या डैशबोर्ड → **सभी कॉल** की जाँच करें।

## लागत "उपलब्ध नहीं" दिखाती है या गलत लगती है

ओपनराउटर लागू होने पर वास्तविक खर्च दिखाता है। अन्य प्रदाताओं के लिए, लागत ओपनराउटर मूल्य निर्धारण से अनुमानित है; यदि कोई मूल्य मेल नहीं खाता है, तो लागत **उपलब्ध नहीं** के रूप में दिखाई देती है और कुल में नहीं जोड़ी जाती है।

## कुल लागत मेरे प्रदाता बिल से मेल नहीं खाती है

ऐप में आंकड़े **संदर्भ के लिए अनुमान** हैं, चालान नहीं। ओपनराउटर के लिए, **सेटिंग्स → लागत ट्रैकिंग → API कुंजी उपयोग के साथ सिंक करें** का उपयोग करें।

## साइडबार से इतिहास पृष्ठ गायब है

**निष्पादन इतिहास रखें** बंद हो सकता है। इसे सामान्य सेटिंग्स में सक्षम करें जब तक कि व्यवस्थापक द्वारा इतिहास अक्षम न किया गया हो (`HISTORY_DISABLED` — [कॉन्फ़िगरेशन](/docs/configuration/#privacy-mode) देखें)।

## वेब: अप्रत्याशित रूप से लॉगिन पर रीडायरेक्ट किया गया

आपका सत्र समाप्त हो गया होगा। फिर से लॉग इन करें। यदि यह अक्सर होता है, तो सर्वर सत्र जीवनकाल सेटिंग्स की जाँच करें।

## वेब एडमिन: पासवर्ड भूल गए

यदि कोई अन्य एडमिन साइन इन कर सकता है, तो वे **सेटिंग्स → यूज़र्स** के अंतर्गत पासवर्ड रीसेट कर सकते हैं। यदि आप लॉक आउट हो गए हैं लेकिन आपके पास शेल एक्सेस है:

```bash
docker exec transrewrt reset-web-password '<username>' '<new-password>'
```

डिफ़ॉल्ट व्यवस्थापक उपयोगकर्ता नाम `admin` है। एक स्रोत चेकआउट से: `pnpm run reset-web-password -- <username> <new-password>`।

## डैशबोर्ड अन्य उपयोगकर्ताओं के लिए कोई डेटा नहीं दिखाता है (वेब)

केवल **व्यवस्थापक** ही **उपयोगकर्ता** फ़िल्टर के माध्यम से अन्य उपयोगकर्ताओं को देख सकते हैं। नियमित उपयोगकर्ता केवल अपनी गतिविधि देखते हैं।

## एक प्रॉम्प्ट बदला और संपादन खो दिया

ट्रांसफ़ॉर्म प्रॉम्प्ट संपादित करते समय, **बैक टू रन** से पहले **सेव** पर क्लिक करें।

## त्वरित सुझाव

- रीराइट या ट्रांसफ़ॉर्म से पहले अपनी सेटअप की पुष्टि करने के लिए [अनुवाद करें](/docs/translate/) से शुरू करें
- रोज़मर्रा के शब्दों में सुधार के लिए [रीराइट](/docs/rewrite/) का उपयोग करें
- दोहराने योग्य कस्टम वर्कफ़्लो के लिए [ट्रांसफ़ॉर्म](/docs/transform/) का उपयोग करें
- जब तक आपको बारीक-बारीक मॉडल ID की आवश्यकता न हो, तब तक **आसान** मोड पर रहें
- यदि आप एक प्रॉम्प्ट लाइब्रेरी बना रहे हैं तो प्रॉम्प्ट को नियमित रूप से निर्यात करें
- उपयोग और पिछले रन की समीक्षा करने के लिए [डैशबोर्ड](/docs/dashboard/) और [इतिहास](/docs/history/) का उपयोग करें
