## कॉन्फ़िग फ़ाइल स्थान

| परिनियोजन | कॉन्फ़िग स्थान |
| --- | --- |
| इलेक्ट्रॉन (विंडोज) | `%APPDATA%\transrewrt\` |
| इलेक्ट्रॉन (लिनक्स) | `~/.config/transrewrt/` |
| वेब / डॉकर | `/app/data/config.json` (बनाए रखने के लिए एक वॉल्यूम का उपयोग करें) |

## परिवेश चर (वेब / डॉकर)

इलेक्ट्रॉन स्थानीय कॉन्फ़िग फ़ाइल का उपयोग करता है। केवल वेब/डॉकर सर्वर के लिए:

| चर | विवरण |
| --- | --- |
| `PORT` | सर्वर सुनने वाला पोर्ट (डिफ़ॉल्ट `5000`) |
| `CONFIG_PATH` | कॉन्फ़िग फ़ाइल का पथ (डिफ़ॉल्ट `/app/data/config.json`) |
| `TZ` | सर्वर-साइड समय के लिए टाइमज़ोन (डिफ़ॉल्ट `Europe/London`) |
| `HISTORY_DISABLED` | निष्पादन इतिहास को बंद करने के लिए बाध्य करें (`true` / `1`) |
| `OPENROUTER_API_KEY` | OpenRouter API कुंजी |
| `OPENAI_API_KEY` | OpenAI API कुंजी |
| `CEREBRAS_API_KEY` | Cerebras API कुंजी |
| `ANTHROPIC_API_KEY` | Anthropic API कुंजी |
| `GOOGLE_API_KEY` | Google Gemini API कुंजी |
| `DEEPSEEK_API_KEY` | DeepSeek API कुंजी |
| `GROQ_API_KEY` | Groq API कुंजी |
| `MISTRAL_API_KEY` | Mistral API कुंजी |
| `LOCAL_LLM_URL` | स्थानीय सर्वर के लिए पूर्ण OpenAI-संगत API बेस URL (पाथ शामिल करें, जैसे Ollama `http://host.docker.internal:11434/v1`, LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | एक्सएआई एपीआई कुंजी |
| `NVIDIA_API_KEY` | एनवीडिया एपीआई कुंजी |
| `ALIBABA_API_KEY` | अलीबाबा क्लाउड (डैशस्कोप) एपीआई कुंजी |
| `APIFUN_API_KEY` | एपीकेई.फ़न एपीआई कुंजी |
| `CUSTOM_PROVIDER_NAME` | एक कस्टम ओपनएआई-संगत प्रदाता के लिए प्रदर्शन नाम |
| `CUSTOM_PROVIDER_URL` | एक कस्टम ओपनएआई-संगत प्रदाता के लिए बेस यूआरएल |
| `CUSTOM_PROVIDER_API_KEY` | कस्टम प्रदाता के लिए एपीआई कुंजी |

एक कस्टम एंडपॉइंट का उपयोग करते समय तीनों `CUSTOM_PROVIDER_*` वेरिएबल आवश्यक हैं। मॉडल **एडवांस्ड** मोड में `{providerName}/…` के रूप में दिखाई देते हैं।

## गोपनीयता मोड

`HISTORY_DISABLED` को वेब/डॉकर सर्वर प्रक्रिया और/या इलेक्ट्रॉन मुख्य प्रक्रिया पर `true` या `1` पर सेट करें ताकि `config.json` या प्रति-उपयोगकर्ता प्राथमिकताओं की परवाह किए बिना इतिहास बंद हो जाए। यह इनपुट/आउटपुट इतिहास को संग्रहीत करने को अक्षम करता है, **सेटिंग्स → सामान्य सेटिंग्स → इतिहास** को लॉक करता है, और इतिहास से संबंधित एपीआई को ब्लॉक करता है।

## डेटा स्थायित्व (डॉकर)

`/app/data` पर एक वॉल्यूम माउंट करें ताकि `config.json` और एसक्यूएलाइट डेटाबेस कंटेनर पुनरारंभ होने पर जीवित रहें। बिना वॉल्यूम के, डेटा कंटेनर रुकने पर खो जाता है।

## वेब प्रमाणीकरण

- डिफ़ॉल्ट प्रशासक: `admin` / `transrewrt26`
- **सेटिंग्स → उपयोगकर्ता** में उपयोगकर्ताओं का प्रबंधन करें
- पासवर्ड रीसेट करें:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
किसी भी नेटवर्क-सुलभ होस्ट पर डिफ़ॉल्ट प्रशासक पासवर्ड को तुरंत बदलें।
:::

## लागत प्रदर्शन

ओपनराउटर लागू होने पर सटीक बिल की गई लागत लौटाता है। अन्य प्रदाता ओपनराउटर की सार्वजनिक मॉडल मूल्य निर्धारण से **अनुमानित** लागत का उपयोग करते हैं जब ओपनराउटर कुंजी उपलब्ध होती है। अनुमान चालान नहीं हैं।

सेटिंग्स UI (फ़ॉन्ट, मॉडल, इतिहास, बैकअप) के लिए, [सेटिंग्स](/docs/settings/) देखें।
