## कॉन्फ़िग फ़ाइल स्थान

| परिनियोजन | डेटा फ़ोल्डर |
| --- | --- |
| इलेक्ट्रॉन (विंडोज) | `%APPDATA%\transrewrt\` |
| इलेक्ट्रॉन (लिनक्स) | `~/.config/transrewrt/` |
| वेब / डॉकर | `/app/data/` (बनाए रखने के लिए एक वॉल्यूम का उपयोग करें) |

डेटा फ़ोल्डर में बैकअप लेने लायक सब कुछ होता है:

- `config.json` — सेटिंग्स और (डेस्कटॉप) एन्क्रिप्टेड एपीआई कुंजियाँ
- `state.json` — अंतिम-उपयोग की गई भाषाएँ, मॉडल और दृश्य स्थिति
- `presets.json` — कैश किया गया ईज़ी-मोड प्रीसेट कैटलॉग
- `transrewrt.db` — इतिहास, लागत, प्रॉम्प्ट, शब्दावली और (वेब) उपयोगकर्ताओं के साथ SQLite डेटाबेस

आप ऐप से एक पोर्टेबल बैकअप ZIP भी बना सकते हैं — [सेटिंग्स → सामान्य सेटिंग्स](/docs/settings/#general-settings) देखें।

## परिवेश चर (वेब / डॉकर)

इलेक्ट्रॉन स्थानीय कॉन्फ़िग फ़ाइल का उपयोग करता है। केवल वेब/डॉकर सर्वर के लिए:

| चर | विवरण |
| --- | --- |
| `PORT` | सर्वर सुनने वाला पोर्ट (डिफ़ॉल्ट `5000`) |
| `CONFIG_PATH` | कॉन्फ़िग फ़ाइल का पथ (डिफ़ॉल्ट `/app/data/config.json`) |
| `TZ` | सर्वर-साइड समय के लिए टाइमज़ोन (डिफ़ॉल्ट `Europe/London`) |
| `HISTORY_DISABLED` | निष्पादन इतिहास को बंद करने के लिए बाध्य करें (`true` / `1`) |
| `OPENROUTER_API_KEY` | OpenRouter API कुंजी |
| `OPENAI_API_KEY` | OpenAI API कुंजी |
| `CEREBRAS_API_KEY` | Cerebras API कुंजी |
| `ANTHROPIC_API_KEY` | Anthropic API कुंजी |
| `GOOGLE_API_KEY` | Google Gemini API कुंजी |
| `DEEPSEEK_API_KEY` | डीपसीक एपीआई कुंजी |
| `GROQ_API_KEY` | ग्रोक एपीआई कुंजी |
| `MISTRAL_API_KEY` | मिस्ट्रल एपीआई कुंजी |
| `LOCAL_LLM_URL` | स्थानीय सर्वर के लिए पूर्ण OpenAI-संगत API बेस URL, जिसमें पाथ भी शामिल है (उदाहरण के लिए Ollama `http://host.docker.internal:11434/v1`, LM Studio `http://host.docker.internal:1234/v1`) |
| `XAI_API_KEY` | xAI एपीआई कुंजी |
| `NVIDIA_API_KEY` | NVIDIA एपीआई कुंजी |
| `ALIBABA_API_KEY` | अलीबाबा क्लाउड (डैशस्कोप) एपीआई कुंजी |
| `APIFUN_API_KEY` | apikey.fun एपीआई कुंजी |
| `CUSTOM_PROVIDER_NAME` | कस्टम OpenAI-संगत प्रदाता के लिए प्रदर्शन नाम |
| `CUSTOM_PROVIDER_URL` | कस्टम OpenAI-संगत प्रदाता के लिए बेस URL |
| `CUSTOM_PROVIDER_API_KEY` | कस्टम प्रदाता के लिए एपीआई कुंजी |

कस्टम एंडपॉइंट का उपयोग करते समय तीनों `CUSTOM_PROVIDER_*` वैरिएबल आवश्यक हैं। मॉडल **एडवांस्ड** मोड में `{providerName}/…` के रूप में दिखाई देते हैं।

## पर्यावरण वैरिएबल (डेस्कटॉप)

| वैरिएबल | विवरण |
| --- | --- |
| `TRANSREWRT_DISABLE_GPU` | हार्डवेयर त्वरण को अक्षम करने के लिए `1` पर सेट करें (जब क्रोमियम लिनक्स पर GPU / EGL त्रुटियाँ प्रिंट करता है तो उपयोगी) |
| `HISTORY_DISABLED` | निष्पादन इतिहास को बंद करने के लिए बाध्य करें (`true` / `1`) — [गोपनीयता मोड](#privacy-mode) देखें |

## गोपनीयता मोड

`config.json` या प्रति-उपयोगकर्ता प्राथमिकताओं की परवाह किए बिना इतिहास को बंद करने के लिए वेब/डॉकर सर्वर प्रक्रिया और/या इलेक्ट्रॉन मुख्य प्रक्रिया पर `HISTORY_DISABLED` को `true` या `1` पर सेट करें। यह इनपुट/आउटपुट इतिहास को संग्रहीत करना अक्षम करता है, **सेटिंग्स → सामान्य सेटिंग्स → इतिहास** को लॉक करता है, और इतिहास-संबंधित API को ब्लॉक करता है।

## डेटा परसिस्टेंस (डॉकर)

`/app/data` पर एक वॉल्यूम माउंट करें ताकि कॉन्फ़िग फ़ाइलें और SQLite डेटाबेस ([कॉन्फ़िग फ़ाइल स्थान](#config-file-locations) देखें) कंटेनर रीस्टार्ट होने पर भी बने रहें। वॉल्यूम के बिना, कंटेनर बंद होने पर डेटा खो जाता है।

## वेब प्रमाणीकरण

- डिफ़ॉल्ट एडमिन: `admin` / `transrewrt26`
- **सेटिंग्स → यूज़र्स** में यूज़र्स, सेशन टाइमआउट और सेशन रिवोकेशन मैनेज करें — [सेटिंग्स](/docs/settings/#users) देखें
- हर साइन-इन किया हुआ यूज़र साइडबार के नीचे यूज़र मेन्यू से अपना पासवर्ड बदल सकता है या साइन आउट कर सकता है
- पासवर्ड रीसेट करें:

```bash
docker exec <container> reset-web-password '<username>' '<new-password>'
```

:::danger
किसी भी नेटवर्क-एक्सेसिबल होस्ट पर डिफ़ॉल्ट एडमिन पासवर्ड तुरंत बदलें।
:::

:::caution
सर्वर प्लेन HTTP बोलता है। यदि आप इसे लोकलहोस्ट या किसी विश्वसनीय नेटवर्क से बाहर उजागर करते हैं, तो इसे HTTPS के साथ एक रिवर्स प्रॉक्सी (उदाहरण के लिए कैडी, nginx, या Traefik) के पीछे रखें ताकि पासवर्ड और टेक्स्ट स्पष्ट रूप से न भेजे जाएं।
:::

## लागत प्रदर्शन

OpenRouter लागू होने पर सटीक बिल की गई लागत लौटाता है। अन्य प्रोवाइडर OpenRouter की सार्वजनिक मॉडल मूल्य निर्धारण से **अनुमानित** लागत का उपयोग करते हैं जब OpenRouter कुंजी उपलब्ध होती है। अनुमान इनवॉइस नहीं होते हैं।

सेटिंग्स UI (फ़ॉन्ट, मॉडल, इतिहास, बैकअप) के लिए, [सेटिंग्स](/docs/settings/) देखें।
