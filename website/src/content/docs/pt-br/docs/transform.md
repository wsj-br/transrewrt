Use **Transformar** quando quiser que a IA siga instruções personalizadas — resumir, aprimorar um e-mail, extrair pontos-chave, reformatar texto ou qualquer fluxo de trabalho que você definir.

![Espaço de trabalho Transformar](/images/screenshots/pt-BR/transform.png)

## Executar um prompt existente

1. Abra **Transformar**.
2. Escolha um prompt na lista.
3. Se uma caixa de idioma **De** aparecer, defina um idioma, se desejar.
4. Digite ou cole o texto em **Entrada**.
5. Clique em **Transformar**.
6. Leia o resultado em **Saída**.

O [alternador de layout e os atalhos de teclado](/docs/translate/#layout-and-keyboard) funcionam da mesma forma que em Traduzir.

## Carregar prompts de exemplo

Se a lista estiver vazia, clique em **Carregar prompts de exemplo** no espaço de trabalho Transformar (também disponível em [Configurações → Transformar](/docs/settings/#transform)). Os exemplos estão em inglês; após carregar, edite um prompt e use **Traduzir prompt**, se necessário.

## Criar um prompt

1. Clique em **Novo prompt**.
2. Clique em **Gerar prompt**.
3. Descreva o que você quer que o prompt faça.
4. Escolha um predefinido (Fácil) ou modelo (Avançado).
5. Revise o rascunho e clique em **Salvar**.

## Editar um prompt

O editor está à esquerda; uma área de teste está à direita.

![Editor de prompt Transformar](/images/screenshots/pt-BR/transform-prompt-edit.png)

Campos principais:

- **Nome do prompt** — mostrado na lista de prompts
- **Instruções do prompt (opcional)** — dica curta ao executar o prompt
- **Função do modelo** — função geral para a IA
- **Instruções do modelo (uma por linha)** — regras a seguir
- **Descrição da saída** — rótulo curto para o resultado (por exemplo, resumido)
- **Temperatura (0.0 → 1.0)** — menor é mais estável; maior é mais variado
- **Pedir idioma de destino** — adiciona um seletor de idioma ao executar

Ajudantes: **Gerar prompt**, **Melhorar prompt**, **Traduzir prompt** (Fácil usa predefinidos; Avançado usa a lista de modelos).

:::caution
Clique em **Salvar** antes de **Voltar para Executar**. Voltar sem salvar descarta as edições.
:::

## Teste antes do uso diário

Use o painel de teste à direita com texto de exemplo ao criar ou comparar prompts.

Exporte e importe prompts em massa em [Configurações → Transformar](/docs/settings/#transform).
