# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Use conventional types (Added, Changed, Fixed, etc.) and short descriptions.

## Unreleased

- **Fixed**: String extraction no longer mangles `\n` (and other JS escape sequences) inside `t()` calls: `scripts/extract-strings.js` now uses `i18next-scanner`'s AST-based parser instead of regex, so multi-line confirmation messages (e.g. "Revoke all sessions…?\n\nThey will need to log in again.") are stored correctly in `strings.json` and locale files.
- **Changed**: All confirmation dialogs now use `\n\n` to separate the action question from the consequence/warning ("This cannot be undone.", "They will need to log in again.", etc.), making destructive warnings more visually distinct.
- **Fixed**: Settings > Transform prompts: delete confirmation message now replaces `{{name}}` with the prompt name using `interpolateTemplate`.
- **Fixed**: Resolved all ESLint errors and warnings (unused imports, useless try/catch wrappers, unnecessary hook dependencies).
- **Changed**: Dashboard export (By Model, By Day, All Calls): CSV and XLSX headers now use translated labels via t() so exported files match the UI language.
- **Changed**: Dashboard > By Model tab: chart first, then download row directly above the table.
- **Changed**: Dashboard > By Model table and export: removed Avg translation and Avg rewrite columns (table and JSON/CSV/XLSX).
- **Fixed**: Dashboard > By Model table: Model column no longer overflows into Translation calls; first column constrained with ellipsis and full name on hover.
- **Changed**: Transform “translate output to target language” instruction moved from hardcoded string in apiService to `prompts.json` (`shared.transform.translateToTargetLang`) with `{{targetLang}}` placeholder.
- **Fixed**: Transform prompt temperature from the slider is now rounded to 2 decimal places when saving, so JSON no longer shows spurious digits (e.g. `0.7000000000000001`).
- **Fixed**: When the user aborts translation/rewrite/transform, the output box now shows the localized "Translation/Rewrite/Transform stopped by user." instead of the raw "Error: signal is aborted without reason". The API layer (apiService) now treats any abort-like error (AbortError or message containing "aborted" / "failed to fetch") as cancellation and returns `{ cancelled: true }` so the UI always receives `result.cancelled` and displays the friendly message regardless of how the environment reports the abort (e.g. DOMException with "signal is aborted without reason"). Error and partial-result messages use `interpolateTemplate()` for i18n placeholder substitution.
- **Changed**: Output panel header (Cost and Total) now uses the same Cost fraction digits style (Settings > General) as Cost tracking and Dashboard; value through cents uses success green (like Dashboard/Cost tracking) so it stands out from the muted header; fraction digits keep the chosen style.
- **Changed**: Rewrite diff now uses jsdiff (`diffWordsWithSpace`) for the main diff instead of custom line/word alignment; consecutive removed+added pairs use `diffChars` for in-word granularity.
- **Fixed**: Browser console: Griffel no longer warns on unsupported `borderColor` (replaced with longhand border-*-color in Dashboard filter button); invalid CSS selector `& $table` replaced with `& table` in tab table content; Fluent Option in ModelSelector given `text` prop when children include non-string nodes; Recharts ResponsiveContainer width/height -1 warnings addressed by giving chart containers a minimum height (summaryChartContainer, byUsageChartContainer, and By Model chart wrapper).
- **Changed**: Model selector in header updates immediately (optimistic) and persists in background; no loading feedback.
- **Changed**: Provider icons use in-memory URL cache and are preloaded at startup for faster, cached display. Provider .ico files (from renderer/assets) are inlined in webpack (asset/inline) in both dev and production so they load with the bundle and require no network requests; only the favicon (images/) remains an emitted asset. CSP updated with img-src 'self' data: so inlined data-URL icons are allowed.

- **Changed**: Dashboard > Summary: KPI cards use horizontal layout (label beside value) when viewport height is small (max-height 480px), with minimal padding to avoid text cropping; KPI grid has 4 equal rows so Avg TPS card sizes like the others; Summary tab allows vertical scroll when content exceeds the panel so all information is visible without cropping.
