# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Use conventional types (Added, Changed, Fixed, etc.) and short descriptions.

## Unreleased

- **Fixed**: Settings > General font sample label "Sample:" was invisible (white on light background); use theme token and Label. i18n: `t('Sample:')` returned empty because i18next treats `:` as namespace separator; set `nsSeparator: false` in i18n init so keys containing colons (e.g. "Sample:") resolve correctly.
- **Removed**: Settings > General "Application" section (Interface language dropdown); language is now selected via the header globe on all pages.
- **Added**: Diff toggle on Rewrite output panel to show input vs output differences (same / removed / added styling). "Show diffs" button (File / FileDiff icon) to the left of Copy; diff view uses position-based word alignment and character-level diff for changed words (white unchanged, muted strikethrough removed, blue added).
- **Removed**: Input and output text color support (config keys and UI); single font/size sample kept in Settings > General.
- **Changed**: Moved `server/` and `shared/` under `src/` so all application source lives in `src/` (src/server, src/shared). Updated scripts/check-node-version.js, Dockerfile (COPY src/server and src/shared), and docs.
- **Changed**: Shared DB schema and queries: added `src/shared/db/appSchema.js` as single source of truth for api_calls and custom_prompts schema (applyAppSchema) and all shared SQL (sql.*, buildWhereFromTo, promptTargetLanguageToDb, replaceWhere). Electron `src/main/appDb.js` and server `src/server/db/appDb.js` + routes (calls, customPrompts) now use it; server keeps server-only sessions table in appDb. Schema or query changes are made in one place.
- **Removed**: Legacy migration code (app unreleased): no poliverb.db→transrewrt.db copy in Electron or server; no custom_prompts target_language schema migration; no legacy session state migration; no legacy SHA-256 password hash support (auth uses Argon2 only). Simplifies dev; delete existing config/state/DB to start fresh.
- **Changed**: Codebase refactor (plan codebase_refactor_plan_00ed772b): split `src/main/main.js` into `configPath.js`, `encryption.js`, and `ipc/` (configIpc, apiIpc, windowIpc); split the server (src/server) into `db/appDb.js`, `utils/configFile.js`, and `routes/` (config, auth, apiProxy, calls, customPrompts, status); reorganized `src/renderer/utils/` into domain subfolders `config/`, `api/`, `security/`, `misc/`; introduced `src/renderer/features/dashboard/` (DashboardPage, SettingsDialogCostTrackingTab, useCostTracking, costUtils) with barrel `index.js`. Transform and settings features remain in components/ for a follow-up.
- **Changed**: SYSTEM-OVERVIEW.md updated to match current codebase: i18n (react-i18next, locales, ui_locale) and renderer folder structure (locales/, index.js i18n entry).
- **Changed**: Extract script no longer adds UI_LANGUAGES `label` to strings.json (label is already in the local language; only `englishName` is extracted for translation).
- **Added**: `generate-translations.js`: `--dry-run` / `-d` to show what would be translated per language (no API calls or file writes); `--show-strings` / `-s` to list source strings that need translation (key + text) per language; `--help` / `-h` documented in script and help output.
- **Changed**: Dashboard "All Calls" table refactored: new layout with separate header and body tables, shared colgroup (flexible column widths, min 1090px); vertical scrollbar overlays last column (no extra width), horizontal scrollbar always visible; columns truncate with ellipsis; header fixed, body scrolls from header bottom to table bottom; paging and cell content unchanged.
